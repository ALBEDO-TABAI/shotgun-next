# 01 · 产品定位与范围

最后更新：R3（2026-09-17）
本轮变化：范围表"输入"一行由待定改为已定（D-17）。

## 一句话

**[建议]** shotgun 是一个桌面应用：用户输入一条视频需求，一组各司其职的 AI 影视工种 agent 沿着自动展开的工作流逐步产出剧本、导演方案、美术/角色/摄影/声音设计、生成提示与素材，用户在每一步与对应 agent 确认后再推进，最终得到一条可审看、可组装、可导出到专业剪辑软件的高质量 AI 生成视频。

## 目标用户

- **[用户]** 目前是工作室内的朋友。
- **[建议]** 含义：可以假设用户懂影视语言、能读分镜表与台账、愿意为质量多点几次；不需要面向大众的极简引导。二次确认之类的"仪式感"可以保留，但要有快捷路径。

## 范围边界

| 项目 | 决定 | 来源 |
|---|---|---|
| 制作媒介 | **只做 AI 生成，不做实拍策划** | [用户] R2-8 → D-01 |
| 输入 | 文字需求为起点；**初步沟通阶段即引导用户注入参考图与品牌素材**，存入项目资源库，供后续所有需要的节点调用 | [用户] R3 → D-17 |
| 输出 | 一条成片 + 可导入 PR / 达芬奇的工程 | [用户] R2-7 |
| 剪辑 | 基础剪辑 + 部分图形制作能力即可；专业调色交给 PR / 达芬奇 | [用户] R2-7 |
| 音乐 | 由音乐生成服务生成 | [用户] R2-10 |
| 配音 / 音效 | 写进视频生成提示词，随视频一起生成 | [用户] R2-10 |
| 多用户 / 协作 | 未提及；默认单人 | — |
| 自治唤醒 / 后台 agent 公司 | 不需要（旧方案的 wake engine、autonomy lanes、3D floor 不进本产品） | [建议]，用户 R2-5 同意忽略旧方案 |

## 命名与语气

- **[用户]** 应用名暂定 shotgun（霰弹枪）。
- **[用户]** 界面中英混合（pull the trigger / hold / move on / sort / fire + 中文文档）是为了趣味，不是硬性要求。
- **[建议]** 保留一处"扳机"隐喻即可。R1 指出"pull the trigger"（散开）与"fire"（生成）两次用枪的动词会混淆；建议第一次改为 load / spread，把 fire 留给真正花钱的生成。未定，见 Q-11。

## 成功的样子（供后续验收）

**[建议]** 一次完整流程：输入"30 秒植物护肤品牌片，克制、明亮、中文市场" → 纸上出现导演构想与各工种任务单 → 扳机 → 编剧、导演先解冻，其余磨砂 → 用户与编剧确认剧本 → 导演解冻 → … → 生成清单校验通过 → fire → Take 逐个落地并带审片结论 → 组装 → 导出 mp4 与 OTIO/FCPXML。
