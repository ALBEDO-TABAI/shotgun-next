## 文档约定

- 决策编号 `D-xx`，问题编号 `Q-xx`，跨文档引用时用编号。
- 每份文档顶部有「最后更新 / 本轮变化」两行。
- 用户原话来源的内容标 **[用户]**；我的分析或建议标 **[建议]**；外部调研标 **[调研]**，并带日期，因为工具能力与价格是带日期的当期参数。
- 尚未被用户确认的建议不进 07-decisions，只留在各文档的「建议」段或 08-open-questions。
