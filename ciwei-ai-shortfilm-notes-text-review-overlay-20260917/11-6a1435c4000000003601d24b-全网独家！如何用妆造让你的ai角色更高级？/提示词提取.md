# 11｜妆造提示词：不确定原词保留疑点，新设计写明因果

## 原例信息

原材料展示少年将军、清冷公子、宫廷贵妃与落魄状态等方向。f_0026—f_0031 可读发型、服装硬挺／单色、干净克制等特征，但部分称谓仍是输入过程或 OCR 疑词。下列不作为逐字原文。

f_0044 的状态板中，赴宴、失宠、战场归来、受伤、逃婚、流放、完成任务、册封等类别较可辨；后续多格有缺损。不能据此给出声称完全恢复的 20 格内容。

## 模板 A：同身份改造型〔本次新增〕

```text
保持已绑定人物主参考的身份与年龄感，设计用于[批准场合]的造型。
世界／时代规则：[项目已确认的规则]。
人物处境与目的：[职业、资源、此刻想呈现的状态]。
轮廓与服装结构：[具体设计]。
材质、主要色彩与配饰：[必要项目]。
发型与妆面：[服务人物和场合的变化]。
不改变人物身材比例，不把角色改成另一张脸，不增加与世界规则冲突的装饰。
```

“保持身份”仍需看结果；不是输入一张脸就天然完成身份锁定。

## 模板 B：收到坏消息后的连续镜头〔本次新增〕

```text
这是紧接上一镜的同一时刻，保留原来的礼服、妆容和发饰位置。
她刚听见已批准的坏消息，尚未换衣或卸妆。
只设计当前动作造成的变化：她伸手扶正原本已经端正的发饰，手停住后放下。
保持妆造完整，情绪通过动作和视线呈现，不突然变成素服、散发或战损。
```

这个方案适用于连续时间。是否使用扶发饰的动作仍要看角色手的位置、饰物是否存在以及故事动机。

## 模板 C：经过一段时间后的状态版本〔本次新增〕

```text
同一人物，在[明确时间跨度]后的新场景。
期间实际经历：[批准事件]。
因此出现的可见变化：[来源明确的衣服、头发、妆面或配饰变化]。
仍保留：[身份特征、未更换的衣物结构、关键物件]。
新增状态作为[状态版本 ID]保存，供这一段连续镜头使用。
```

## 可读状态类别的设计转译〔本次新增，不是原板复原〕

| 类别 | 先确认什么 | 可以考虑的可见变化 |
| --- | --- | --- |
| 赴宴／宴后 | 是到场前、宴会中还是离席后 | 规整度、披肩位置、经实际动作改变的细节 |
| 战场归来 | 场地、时间、装备与受损原因 | 有位置和材料依据的磨损、尘土、衣褶 |
| 受伤 | 受伤部位与之后发生的处理 | 局部衣物和姿态变化，不任意增加其他部位伤痕 |
| 流放／长途赶路 | 经过多久、能否换洗与整理 | 逐渐积累的使用痕迹，而非刚宣布就全身破损 |
| 册封／正式任职 | 仪式要求与人物态度 | 经批准的礼服、发饰和配件，不凭称谓编历史制度 |
| 失宠／权力变化 | 是否已知、是否有时间改变外观 | 可以保持体面，也可以主动调整，必须说明原因 |

设计选择要回到人物，不必让一个情节标签只对应一种造型。
