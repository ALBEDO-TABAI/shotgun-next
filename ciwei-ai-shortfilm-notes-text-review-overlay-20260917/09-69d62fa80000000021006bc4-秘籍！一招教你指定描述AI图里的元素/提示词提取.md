# 09｜指定修改、移动与清理标注的提示词

## 原始可读片段

OCR f_0032：

> 帮我把标号1红色箭头指着的地方的刺绣改成superi，并去掉红色的1和箭头

这是 OCR 文本，不是本次对截图像素的逐字校验。它表达了对象、替换内容和辅助标记清理三项要求。后面的移动挂画例子只有部分输入过程，不据此编造完整原句。

## 模板 A：改刺绣文字〔本次扩写〕

```text
以无标注原图为画面依据，标注图只用于定位。
只修改编号 1 的箭头尖端所指的那一处刺绣文字，改为小写 superi。
保留该处原有刺绣工艺感、布料起伏、透视方向和合理尺寸；其他刺绣与衣服结构不变。
清除本次辅助数字、箭头和圈线，不删除原图中的其他文字。
输出不含辅助标记的编辑结果。
```

实际工具只接收一张图时，应把“无标注原图／标注图”改成真实输入方式，不引用未提供的文件。文字准确性必须检查，提示词不能保证拼写正确。

## 模板 B：移动挂画〔本次重写〕

```text
编号 1 指向需要移动的那幅挂画，编号 2 指向目标墙面位置。
把同一幅挂画移到位置 2，不复制第二幅。
原位置补回连续的墙面纹理，并去掉原挂画造成且不再合理的阴影。
目标位置的画框与墙面透视、尺度、遮挡和光线一致；保持画框与画作内容身份不变。
其他物件、门窗和整体构图保持原样。
去除本次加上的所有辅助标记。
```

“位置 2”最好用不遮挡墙面关键边缘的小型目标框或落点说明来表示。若目标区域小到放不下原物件，要先决定改变物件尺寸、改变位置，还是根本不执行移动。

## 模板 C：删除唯一指定对象〔本次新增〕

```text
只删除编号 1 指向的对象及其应随之消失的局部投影。
恢复其背后合理、连续的表面，不添加新装饰，不改变相邻对象。
保留原图其他内容，并清除本次辅助标注。
```

不要把“删除影子”扩大为删除整张图的所有阴影。反射、遮挡背景或相邻接触也可能需要局部处理，由具体图像决定。

## 编辑完成后的检查单

| 检查 | 通过条件 |
| --- | --- |
| 指代 | 改的是指定对象，没有误改相似对象 |
| 操作 | 替换／移动／删除与请求一致 |
| 内容 | 文字、形态、数量符合批准要求 |
| 空间 | 透视、接触、光线与所在位置一致 |
| 清理 | 辅助标记完全移除，原有必要文字仍保留 |
| 保真 | 非目标区域没有不可接受的身份或结构漂移 |

以上是验收标准，不是声称本次已生成并测试了这些示例图片。
