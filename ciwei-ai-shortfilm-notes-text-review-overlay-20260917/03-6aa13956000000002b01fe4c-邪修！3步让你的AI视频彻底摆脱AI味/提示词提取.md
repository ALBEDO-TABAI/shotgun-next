# 03｜真实感提示词：保留因果，不抄表面症状

## 原材料中的关键补回

OCR f_0058 的画外男声是情绪触发，而不是可有可无的装饰。原句见本组方法论文档。手机／耳机及不完整年代信息不能未经核对混进同一份提示词。模型品牌分工是教程经验，不是本稿复测结果。

## 模板 A：把批准情节转成可见反应〔本次新增〕

```text
镜头事实：[角色与对方的关系、发生了什么，仅用已批准内容]。
参考分工：[人物身份参考]；[当前服装与状态]；[场景参考]。

镜头开始时，她正在[原图已有、可延续的动作]。
听见[批准对白或声响]后，主动作短暂停住；她看向[明确对象／方向]。
随后她选择[一个可见动作]，表现出[她正在努力达到的目的]。
次级动态仅来自上述动作和已有环境，不另加无动机的风、泪水或摆拍。
镜头结束时：[道具归属、姿态和下一镜所需状态]。
```

## 模板 B：告别反应镜头〔本次创作示例〕

这是利用原教程“声音触发反应”思路的新场景，不是恢复原截图：

```text
沿用已批准的角色和房间。中近景固定机位，取到她的脸和桌边正在整理信封的手。
她听见画外的告别话语，指尖停在信封边缘，目光仍落在桌面。
短暂停顿后，她把信封放回原处，手收回身侧，再看向画面右侧的说话人。
她想保持平静，不哭喊，不同时做多组表情；动作速度自然，留出观众理解选择的时间。
声音使用已批准的画外对白和低声级房间环境声，不追加配乐。
```

使用本例前必须确认场景里确实有信封，参考起始姿势能接上此动作。原教程的道具不能因为本例而被改成信封。

## 模板 C：要求分析失败原因，而不是再堆形容词〔本次新增〕

```text
镜头任务：[必须被观众看懂的事件]。
批准参考：[实际使用文件及版本]。
当前问题：[说明看见的错误与时间范围]。

先把问题分到：身份、几何／接触、运动、光线材质、表演因果、剪辑声音。
只提出最可能有效的一项修改；说明它会影响哪些原有约束。
不要默认更换模型，不增加与任务无关的动作、滤镜或摄影品牌。
```

这份模板的输入必须是实际观察结果。不能仅凭生成模型名称判断“必然塑料”或“必然更有审美”。

## 生成外的工作

输出比例和清晰度在产品设置中确定；声音方案与剪辑落点在实际成片中复查。记录每个候选的可用起止时间，而不是只保存最漂亮的一张截图。若切掉瑕疵会使关键交接消失，则不能把“剪掉了问题”判成故事镜头通过。
