# 12｜生命力提示词：分清构思、执行与后期

## 原教程的重要元提示词内容

OCR f_0052 提出依据图片姿势、表情、视线和手部位置，构思小剧情动作与微表情；强调自然衔接、约五秒内一个主要动作、动作小而可见，不只呼吸眨眼飘发。其完整后续内容未全部显示，不能标为完整原文。

这一工具适合探索，正式生产需要增加“不改变批准剧情”的边界。

## 模板 A：探索阶段的动作构思〔本次新增〕

```text
请先描述参考图中直接可见的姿态、视线、手部占用和环境，不推定未给出的剧情。
再提出两个不同的小剧情候选，明确标成创作设想。
每个候选只含一个主动作、一个自然跟随的次级变化、一个由事件触发的反应。
动作应能从原图姿势接起，在目标时长内完成，不凭空增加关键道具或人物。
说明两个方案各自会让观众理解成什么，供导演选择。
```

## 模板 B：正式生产的动作设计〔本次新增〕

```text
已批准故事：[当前事件、人物目的、对手关系]。
输入姿态：[实际起始图中的姿态]。
允许动作：[本镜头可发生的事件]。
必须结束于：[下一镜需要的姿态、位置与物件状态]。

请写一个镜头执行稿，不再编新的故事。
主动作：[一个]；次级变化：[由身体／环境自然引起的一个]；情绪变化：[由已知信息触发的一个]。
景别和摄影机安排必须让这些变化可见，删掉在当前景别下无法读出的微小要求。
```

## 模板 C：小跑后注意到集市〔本次重写〕

```text
沿用人物和古街参考。她从画面左侧沿街道向右侧小跑，摄影机从侧面以相近速度跟随。
她用原本空闲的手轻提已有裙摆，衣袖和发丝随步伐自然摆动。
看见前方已存在的集市入口后，她的注意力转向入口，脚步略缓，露出一次短暂的欣喜。
保持一条清楚的行动路径，不突然转向镜头，不把跑动改成无缘由的原地摆拍。
```

这保留教程的“主动作＋跟随＋情绪反应”，但路线与末段节奏是新增编排，不是原例逐字转录。脸部太小就不应把验收全压在嘴角变化上。

## 模板 D：屏风后接近对方〔本次重写〕

```text
场景布局已确认：她在屏风后，对方站在屏风外靠内侧的位置，出口在远处。
她想私下说出批准台词，先从屏风边观察外侧通道，确认没有旁人后走到对方身边。
对方察觉她靠近，转向她，给她说话的机会。
保持两人的身份、方向和屏风位置，动作完成后再进入主要对白，不把观察、走近和长台词全挤在同一瞬间。
```

若时间不足，拆成靠近镜头与对话镜头；不能把对方人物删成无反应的布景。

## 后期执行说明〔新增〕

```text
先确定可用素材和剪口，再对齐已批准对白与反应时间。
环境底声保持空间连续；动作声与实际可见接触对齐。
点缀音效标明场内声源或非写实用途，避免每次转头都响同一声风铃。
基础画面匹配后再试辉光类效果，并与关闭效果的版本对照。
检查高光、肤色和服装纹理；记录实际选中的效果及参数，不记录仅在搜索框输入过的名称。
```

这些是后期任务，不应全部混进一个图生视频提示词。支持原生音频的工具可承担部分声音生成，但精确对白、音效落点与整体混音仍以成片为准。
