# 23｜改图：指出位置，还要说清前后世界

## 先把编辑范围说清

“让它好一点”没有定义变化。“让这个房间更温暖”可能改光、改材质、改陈设，也可能全改。先选目标：只改光，还是需要换家具？主体是否必须保持？需要复用哪张可靠原图？

编辑的核心结构是：**原图 + 目标区域 + 操作 + 预期结果 + 重要保留项**。

## 指认方式从简单到复杂

只有一只杯子时，“桌上的杯子”可能已经足够；物件很多时，用框、箭头、标号、局部裁切或工具支持的蒙版减少歧义。不要不分任务一律画满辅助标记。

图上的红箭头是可见指示；蒙版通常是接口中的编辑范围输入，二者不是同一种机制。即使提供蒙版，也不应假设外部像素绝对不变。OpenAI官方文档明确说明其图像蒙版是指导，不保证精确沿蒙版形状执行。[2]

## 四种常用操作，各有不同后果

| 操作 | 要明确的事 | 要检查的事 |
| --- | --- | --- |
| 删除 | 删对象，还是连影子、倒影与固定件一起删？ | 背景修复、残影、重复纹理 |
| 替换 | 继承原尺寸姿态，还是连结构一起改变？ | 接触、材质、主体身份 |
| 移动 | 原处不留副本，新位置如何落地？ | 透视、比例、阴影与遮挡 |
| 重打光 | 哪个光源与区域变化，造型是否保持？ | 光影合理、脸与产品是否被重新生成 |

## 一个可用的移动说明

```text
使用未打标的原图作为画面基础，打标图仅帮助定位。把标1的这只花瓶移动到标2的桌面空位；原位置修复为同一张桌面的连续纹理，不保留第二只花瓶。保持瓶型、花枝数量与主要朝向，按新位置匹配透视和接触阴影。人物、桌子结构与画幅不变，最终画面没有任何定位标记。
```

只有工具可同时理解这两张输入且角色分工清楚时才这样提交；否则用一张轻标注图或原生蒙版。不要为了“信息完整”上传互相矛盾的多个底图。

## 用保留项保护任务，不堆无关禁令

需要保住包装文字，就把字标列为重点；背景远处无关纹理的变化可以按使用目的决定是否接受。若要求逐像素保留非编辑区，最好在后期把通过的局部合成回可靠原图，而不是依赖一大段“其他地方绝对不动”。

标记不要盖住你希望保留的结构；已经盖住时另给未遮挡原图或清晰局部，不能要求模型从不存在的信息里还原精确设计。

## 完成后做两次比较

第一次只看编辑目标是否对；第二次看原本正确的区域是否被连带改变。需要品牌、包装和连续人物时，这两步同样重要。

连续编辑发生漂移，就退回最后通过的版本，按区域分步处理。不要把每一张中间结果都称为新的“最终图”。如何记最少状态，见[资产与多镜头](/workflows/05-assets-multishot.md)。
