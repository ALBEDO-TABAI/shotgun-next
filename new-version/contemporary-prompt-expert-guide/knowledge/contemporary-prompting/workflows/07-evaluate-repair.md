# 27｜评价与修复：别用“AI味”掩盖问题在哪

## 看成片之前，先写两个判断点

例如“观众能认出是同一瓶产品”和“结尾感到松开，而不是虚弱”。判断点不必很多，必须对应这个项目。技术上没有问题，却完全不像品牌想要的表达，也不能通过。

第一次看，不读提示词，只写看到了什么、听到了什么；第二次再与任务对照。这样比较不容易被自己投入的文字说服。

## 失败分层，再动手

| 表现 | 先检查 | 优先修改方向 |
| --- | --- | --- |
| 画面漂亮但没说清什么 | 体验与信息任务 | 重选载体或观看组织 |
| 人物像在示范表情 | 情境、对象与主动作 | 减少表情清单，补真实任务 |
| 手与物件乱 | 首帧、持有状态、接触复杂度 | 简化动作或拆镜，补有效参考 |
| 场景变了 | 多图布局是否一致 | 先修场景事实，不先调色 |
| 底图像贴上去 | 光、尺度、边缘与透视 | 回到图像关系，非直接加颗粒 |
| 配音机械 | 台词、角色差异、节奏、声音模式 | 先判断哪层有错，再试听修改 |
| 切起来突然 | 起终状态、声桥、节拍 | 改选片区间或补接头 |

## 一次改一件主要事情，不是只允许改一个字

假设问题是“紧张不明显”。可以做两种候选：加一处手部停顿，或改变景别让原本反应可见。先不要同时换演员、灯光、模型和运镜，否则无法知道是哪个方向解决了问题。

必要时一次修改一个相互依赖的小组：移动花瓶就需要同时修改旧位置背景与新阴影，不应为“单变量”故意让画面不完整。

## 保持比较条件尽可能相近

记录工具与模型版本、输入素材、设置、提示和选取区间。若工具支持种子，可以保留用于同条件比较；不同工具或模型的同一数字种子不意味着相同随机过程。

相同设置也可能得到不同结果。不要只展示最成功样本然后称为普遍规律。积累经验时，至少留下失败类型与适用范围，不必假装样本很少的测试有统计显著性。

## 用失败去改变假设

假设“缺手部动作导致人物僵硬”，加动作后还是僵硬，先检查是否其实是机位看不到反应、声音太规整或首帧姿态不适合。不要把失败解释为提示词还不够长，继续添动作。

如果多次尝试都只能得到不稳定的指尖操作，任务形式可能应改成更可读的大动作或剪辑，而不是继续追求一镜到底。

## 停止条件也要写

当关键任务通过、局部缺陷可以在后期低成本修复，继续生成可能只是在追求不可定义的“更好”。当核心表达仍错，局部精修没有意义；应返回创作方案。当工具不适合所需控制，换路线而不是继续消耗。

“通过”建议分为：**可用**、**可用但需指定修补**、**需重做**。避免把“还可以”变成无人知道下一步做什么的状态。

## 复盘留下可迁移知识

不记录“这条提示很神”，而记录：在何种输入、何类动作、何种画幅中，哪些关系表达有效，哪些控制并不可靠。保留具体成功片段及失败片段的索引；没有真实媒体时只标为创作假设。
