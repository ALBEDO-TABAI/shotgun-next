# IV · 生成与迭代

把创作说明适配到具体任务，接续资产、输出与修复。

- [21｜从一句需求，到几个真正不同的方向](/workflows/01-brief-to-options.md) — 先判断表达任务与已有条件，再展开方案；不把模糊需求直接扩成大提示词。

- [22｜文字生图：先造一个可读的画面](/workflows/02-text-to-image.md) — 从视觉层级到材质细节，按依赖顺序推进，不让细节修补错误结构。

- [23｜改图：指出位置，还要说清前后世界](/workflows/03-image-edit.md) — 区分指认、操作和保留项；把标记视作辅助，别误当精确蒙版。

- [24｜图生视频：让已经存在的画面继续发生](/workflows/04-image-to-video.md) — 分清首帧与身份参考，用当前姿态启动动作，并为结尾留出可继续制作的状态。

- [25｜多镜头与资产：丰富地准备，克制地提交](/workflows/05-assets-multishot.md) — 用少量可靠状态连接镜头，避免参考堆积与版本冲突。

- [26｜复杂镜头：什么时候该离开文字，做预演](/workflows/06-previs.md) — 用草图、计时、运动参考和粗模解决语言不擅长的空间控制。

- [27｜评价与修复：别用“AI味”掩盖问题在哪](/workflows/07-evaluate-repair.md) — 先定观看目标，再按证据诊断，做能解释结果的最小改动。

- [28｜工具适配：同一创意，不必使用同一段提示词](/workflows/08-model-adaptation.md) — 区分创作层与模型接口；附同一镜头的四种提交方式。
