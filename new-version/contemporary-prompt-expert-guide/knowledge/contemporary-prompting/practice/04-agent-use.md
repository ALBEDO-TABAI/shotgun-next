# 40｜给创作助手与团队的用法

## 先识别现在在做什么

探索、写稿、准备资产、生成、修图、验片、剪辑，是不同任务。用户只要一句提示词时，不输出整套制片流程；用户要系列制作时，也不能只给一句漂亮描述就结束。

检索时先看包根目录，再取当前任务相关的两三个概念。需要身体表演就读表演、动作和当前案例；不要每次把全部47个概念都拼进模型上下文。这里的数字以当前交付为准，后续增删应随目录更新。

## 角色分工保持简单

| 专业判断 | 主要决定什么 | 提示词作者负责什么 |
| --- | --- | --- |
| 导演或创意负责人 | 观众体验、故事与形式选择 | 准确表达，不暗中改题 |
| 美术与摄影 | 造型、空间、材质、光与观看位置 | 组织有效参考和清楚描述 |
| 表演与声音 | 人物行为、说话关系、听觉结构 | 保持声线与当场状态分离 |
| 编辑与生成执行 | 片段选择、接头、参数与任务模式 | 把说明编成接口可用输入，记录实际结果 |

一人可以兼任多项，Agent也可以协作。关键不是人头数，而是决定有没有被准确传递。

## 给助手的最小工作顺序

读已有目标与实际素材；指出影响任务的矛盾；在必要范围内展开或执行；给一份可使用的结果；说明还需验证什么。除非任务复杂，不要求每次把这五步的过程全文输出。

探索阶段可提出多个方向；执行阶段不擅自新增人物、换包装或改结局。若已有方案不成立，提出最小变更与影响，而不是默默执行另一套创意。

## 对参考、参数与工具保持诚实

文件名不等于文件已上传，编号不等于引用已绑定，文字中的时长不等于真实参数，任务提交成功不等于媒体通过。没有读到的图像和没有听到的音频不得宣布验收。

本指南不会自动调用模型、安装插件或购买服务。付费生成需用户对实际请求与开销作明确决定。把创作样稿当作调用许可，是两种不同事情。

## 生产只有一份当前决定

当前镜头说明、批准素材与实际通过区间应能相互对应。不把旧提示词、旧状态、旧回执当作最新依据。新改动影响服装、台词或终点时，更新受影响交接；与本镜无关的信息不必传给所有人。

## 知识更新与实验

某条方法在一个模型里有效，只记录到它的适用条件，不立刻升格为全平台原则。具体模型接口变化优先更新[工具适配](/workflows/08-model-adaptation.md)与第一方来源，艺术方法不用随每次发布重写。

核心六层框架和通感图谱是本次综合提出的创作工具，适合由使用者用实际作品反复检验。把不同结果补充为带媒体依据的案例，不编造“已验证最佳实践”。

本包附有轻量消费入口`skills/contemporary-prompt-expert/SKILL.md`，位于交付工作区而非本知识包目录；它只是导航文件，不代表已在任何应用中安装。
