# 37｜可直接改用的工具箱：六张轻模板

这些模板是给人或创作助手的工作文本，不是跨模型通用API。方括号是需要替换的槽位；已知信息不重复问，缺少高风险信息时明确指出，低风险假设可以标注后继续。

## 模板一：先长出方向，不急着写最终提示

```text
我要制作[用途与媒介]，希望观众首先感到/理解[主要体验]。现有材料是[实际资料]，必须保留[关键事实]。
请给出三个在表达机制上不同的方向，而不是同一画面换配色。每个方向写：一段有画面感的感受描述；它如何落到人物/物件/空间/声音；一个最值得保留的细节；一个可能失败的地方。
允许直接表达，也允许间接表达，不默认克制、写实或三幕结构更好。先保持创作开放，不编造已经存在的参考素材或模型实测结果。
```

## 模板二：把感受稿转成一张图

```text
感受稿：[一句感受或一小段联想]
画面用途：[概念图/角色资产/场景资产/主视觉/最终静帧]
把感受中真正有用的关系提取出来，再选择两三个可见载体；不要把所有比喻字面画出来。
生成说明应交代视觉中心、空间关系、材料/光或绘画语言，以及必要留白。没有叙事需求时不强加故事。已有产品或角色必须按实际参考保持，不用重新想象代替。
最后给我一版自然语言提示词，并用一句话解释本版最重要的视觉选择。
```

## 模板三：让当前首帧继续发生

```text
这是[首帧/身份参考/布局参考]，请先按实际任务区分它的作用。
本镜头要完成：[一项主要事件或感受变化]
起点：[可见姿势、视线、手与道具位置]
终点：[需要延续到后面的状态]
观看方式：[机位/取景/一项主要运动，或保持原图]
声音：[对白/环境/音乐，注明谁听见、谁发声]
请写一版适合当前工具的执行稿。只细化关键接触与情绪转折，自然过渡留给模型；不要追加新人物、新剧情、无理由的表情菜单。
```

## 模板四：声音不是情绪标签

```text
台词正文：[准确台词，不混入备注]
角色长期声音：[语言、口音、音区、声音质地]
当场关系：[对谁说，想怎样影响对方，身体正在做什么]
变化：[哪几个词需要强调，何处改变节奏或收住]
空间：[耳边/正常距离/电话/门后等]
请给出自然的表演说明，保留台词的可读性。不要把标点转换成保证执行的秒数；如需精确时长，列为试听后调整项。
```

音乐另从[音乐章节](/craft/07-sound-music.md)选择“进入—展开—收尾”的结构，不把台词模板硬套配乐。

## 模板五：参考分工与冲突消解

```text
下面是本次实际可用的素材及用途：[列表]
请先检查角色、服装、场景布局、光向和时间状态有没有互相冲突，区分首帧、身份、风格、运动与声音参考。
冲突能从已批准版本解决时直接采用批准版本；不能确定时指出影响，不默默混合。
只保留当前镜头需要的输入，输出一份精简的引用分工与执行稿，不把整个素材库全部塞进去。
```

## 模板六：看结果，再修提示

```text
本次任务与必须项：[目标]
实际输出：[可读取的媒体或用户提供的具体观察]
请区分内容正确性、表达效果、制作可用性。先描述你实际能看见/听见的现象，不从提示词推断结果已经完成。
找出最影响任务的一处问题，提出一个最小修改和一个备选制作路线。不要一次换掉角色、风格、机位与模型；除非问题本身需要连带修改。
没有可读取媒体时，只能做文本与条件审查，不宣称验片通过。
```

## 模板不是统一成稿格式

需要提交纯文本的模型，就从模板里编出一段自然说明；参考引用和参数放进有效接口；过程解释不用一并提交。使用模板后，再做一次[改写诊所](/language/06-rewrite-clinic.md)的删减检查。
