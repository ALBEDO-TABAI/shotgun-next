# III · 视听专业

分别调动表演、摄影、美术、声音、剪辑与平面设计。

- [12｜表演：让情绪有对象、有代价、有变化](/craft/01-acting.md) — 从人物在做什么开始，选择动作和反应，而不是替面部肌肉排班。

- [13｜台词与声音：不是换一副嗓子，是换一种说话关系](/craft/02-dialogue-voice.md) — 把角色声线、当场策略、语言节奏与声学空间分别设计。

- [14｜动作与调度：让物体有来处，让角色有去处](/craft/03-action-blocking.md) — 拆清空间任务、接触和持有状态；用自然过程连接关键事实。

- [15｜镜头：不是更会运动，而是更会选择](/craft/04-camera-attention.md) — 把观看位置、信息顺序与摄影机动作分开；让机位服务表达。

- [16｜光与材质：让空气、表面和重量互相解释](/craft/05-light-material.md) — 分清方向、软硬、明暗、颜色与材质反应，把质感落到具体表面。

- [17｜美术与妆造：世界不是背景，身份不只是一张脸](/craft/06-world-art-costume.md) — 用空间、使用方式和状态痕迹设计人物与世界，避免性别和风格模板。

- [18｜音乐与声音：让看不见的东西改变画面](/craft/07-sound-music.md) — 从听觉视点、叙事功能和时间变化设计声音，而不是只填流派与情绪。

- [19｜静态图像、平面与风格化：不必把一张图写成电影](/craft/08-still-graphic-style.md) — 在没有时间轴时组织主次、关系、材料与阅读顺序，允许非叙事图像成立。

- [20｜时间与剪辑：提示词里发生了，不代表观众来得及读](/craft/09-time-montage.md) — 把动作时长、信息读取、反应和转场放进同一个观看节奏。
