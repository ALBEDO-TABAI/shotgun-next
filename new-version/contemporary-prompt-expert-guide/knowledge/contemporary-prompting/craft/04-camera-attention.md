# 15｜镜头：不是更会运动，而是更会选择

> 摄影机可以靠近一个人，也可以拒绝靠近。后一种选择，有时比推到眼泪上更有力量。

## 先说观众站在哪里

眼平、贴地、俯瞰不直接等于自然、压迫或脆弱。它们先改变可见内容与空间关系，具体感受还取决于人物、光、距离、剪辑和声音。教程10提供的是一种有效方向，不是“平视必假”的规律。[1]

**贴近桌面**可能让一只迟迟没有接过来的手变得重要；**隔着人群**可能让错过发生在视线里；**正面平视**可以让人像坐在角色对面，直接承受一句话。选机位时，先问这个位置让谁知道什么。

## 六个要素，不要混叫“运镜”

| 要素 | 人话问法 | 例子 |
| --- | --- | --- |
| 位置与高度 | 摄影机在哪里？ | 门内侧、桌沿高度 |
| 朝向 | 看向哪里？ | 看向窗边的人，而非房间中心 |
| 取景范围 | 让多少内容进入？ | 只见手、杯与对面空椅 |
| 透视关系 | 近处与远处怎样相处？ | 近处栏杆占画面，人物在后方 |
| 运动 | 摄影机本身怎么变？ | 向右平移，让门框退出前景 |
| 焦点与成像 | 哪一层清楚，运动怎样留下痕迹？ | 焦点在握杯的手，不在窗外 |

“推近”有时指摄影机前移，有时指变焦。需要视差和遮挡变化时，应写清前移或横移；单纯放大画面不能自动让你看见遮挡物后面。[2] 类似地，摇摄是改变观看方向，不是摄影机绕主体换位置。

## 一条镜头，先选一件主要工作

**跟随**：与人物保持一段距离，让变化在路途中出现。

**揭示**：从局部到关系，例如门框后的人进入可见范围。

**逼近**：减少退路或扩大一个反应的重要性。

**撤离**：把人物留给环境，或显示事情比原先大。

**等待**：不替观众挑反应，给事件自行发生的机会。

这些可以组合，但不必在八秒内全做。把“推进、环绕、升高、拉焦、甩镜”串在一起，往往没有说明最重要的观看任务。

## 镜头与人物可以不同步

跟得太准像展示，略晚一点可能像发现；但“略晚”也可以掩掉关键动作。举例：

> 她先起身离开画面，摄影机晚一点才转向门口。转过去时她已经停在门边，像还有一句话没说。

这里延迟本身形成观看关系。若剧情要求看清她把钥匙藏入包里，就不能让摄影机晚到而错过。

## 现场感来自可解释的观看限制

轻微走路起伏、前景擦过、自动对焦调整可以提供拍摄状态；但干净稳定的画面也可以很真实。选择手机Vlog时，手臂距离和持机方式重要；选择产品静物时，稳定和反射控制可能更重要。

镜头上水滴、强眩光和剧烈晃动都属于强烈表达，不是默认的真实感修复剂。别让它们遮掉脸、产品标签或情节。

## 让注意力得到接力

一个人说话，另一个人的手开始动，摄影机再发现道具，这可以形成自然的信息接力。观看研究与电影分析提供了相关观察，但不能保证所有观众逐点照看。[3] 实际验片可以请不了解提示词的人只说“你先看到了什么”。

物理机位词不足时，补一张构图草图或预演，而不是堆更多“流畅电影感”。对应方法见[预演与复杂控制](/workflows/06-previs.md)。
