# 当代提示词专家指南

## 让感受有落点，让生成有方向

不是把“梦幻、真实、高级”换成更长的句子，而是知道它们该由什么承载、怎样被看见与听见，又该在什么地方停笔。

本书从13组AI影视教程的文字复审材料出发，重组为40篇主体知识与7篇参考，共47个可独立阅读和引用的知识单元。你可以顺着读，也可以按任务进入。案例、图谱和模板是创作设计与工作方法，不冒充已实测的生成配方。

## 先读哪几篇

**建立方法**：[六层转译](/foundations/02-six-layer-method.md) → [三种稿子](/foundations/03-three-drafts.md) → [通感转译](/language/01-sensory-translation.md) → [一个品牌片案例](/cases/01-brand-film.md)。

**今天要写一条提示**：先用[改写诊所](/language/06-rewrite-clinic.md)，再选[文字生图](/workflows/02-text-to-image.md)、[改图](/workflows/03-image-edit.md)或[图生视频](/workflows/04-image-to-video.md)。

**作品很好看但没有表达**：读[联想工作坊](/language/02-association-workshop.md)、[情绪图谱](/language/04-emotion-atlas.md)、[氛围图谱](/language/05-atmosphere-atlas.md)，再回到[评价表](/practice/03-review-rubric.md)。

**团队或Agent复用**：读[使用方式](/practice/04-agent-use.md)与[多镜头资产](/workflows/05-assets-multishot.md)，按任务检索，不把全书一次塞进上下文。

## 本书的核心主张

感受可以抽象，承托它的关系要清楚；细节可以丰富，主次不能消失；控制关键事实，也为自然过渡留空间。写实、克制、低机位、手持、道具与音乐都只是选择，不是唯一正确答案。
