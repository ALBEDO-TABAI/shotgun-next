# V · 完整案例

八个原创设计案例，从感受到执行，再到验收和替代路线。

- [29｜完整案例：30秒洗发水品牌片《留一点空隙》](/cases/01-brand-film.md) — 从感受、联想、镜头与音乐到生成拆分，完成一条原创品牌片的设计样稿。

- [30｜完整案例：餐桌上，一句没有被问完的话](/cases/02-relationship.md) — 用普通台词、物件与听者反应表现关系；同时提供直接表达的替代方案。

- [31｜完整案例：喜悦真的可以冲出来](/cases/03-big-emotion.md) — 用强动作与真实接触表现外放情绪，纠正“自然就是克制”的偏见。

- [32｜完整案例：谁在拍谁——12秒咖啡馆Vlog](/cases/04-vlog.md) — 用拍摄视点、手部占用和转场保持生活感，而非靠统一晃动滤镜。

- [33｜完整案例：空走廊为什么会让人等下去](/cases/05-empty-corridor.md) — 不用人物脸部与重型音乐，靠听觉、遮挡与延迟组织悬念。

- [34｜完整案例：不追求实拍的香水图与短动效](/cases/06-surreal-perfume.md) — 把风格化视作自己的世界规则，而不是不够真实的失败品。

- [35｜完整案例：安静自习室里的零食袋](/cases/07-comedy.md) — 让喜剧来自目标、阻力与反应，而不是给角色加夸张表情。

- [36｜完整案例：两份文件，谁最后拿着哪一份](/cases/08-object-exchange.md) — 用状态与观看证据规划一镜到底，并提供更经济的多镜头替代。
