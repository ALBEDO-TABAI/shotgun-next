# 06｜通感不是堆比喻，是转移一种关系

> “这段配乐像薄荷”很好，但薄荷不是一种乐器。继续问：要的是入口的凉、清透的气，还是吞下去之后留下的一线清醒？

## 先找共性，再换载体

创作中的通感可以借用一种感觉的结构，去组织另一种媒介。这里说的是表达方法，不是在诊断生理性的联觉，也不是说观众必定共享同一套对应表。跨感官与情绪联想有研究基础，但具体文化、材料与上下文都重要。[2]

| 感觉维度 | 先想象身体经验 | 可转入的画面或声音关系 |
| --- | --- | --- |
| 重量 | 拎起、下坠、承住、卸下 | 运动加速度、物体形变、低频重量、收尾长度 |
| 温度 | 靠近暖源、冷空气贴住皮肤 | 局部冷暖关系、呼吸和衣着反应、声音的亲近或锐利 |
| 触感 | 细砂、湿绸、硬边、绒面 | 高频细节、反射边缘、摩擦声、音的起落形状 |
| 密度 | 挤满、稀疏、透气、结成团 | 构图间距、节拍数量、声部重叠、信息出现频率 |
| 距离 | 耳边、隔墙、很远、贴身 | 声音直达与混响、镜头位置、遮挡、人物间隔 |
| 张力 | 拉住、悬着、要断未断 | 未完成动作、持续音、画面偏重、迟迟未到的落点 |
| 节奏 | 犹豫、冲出、回弹、停稳 | 句子断法、动作节拍、剪辑间隔、重复中的变化 |

这些是联想入口，不是“高频必然清爽”“蓝色必然冷漠”的字典。

## 一条完整转译链

感受稿：**“她的声音像晒过太阳、又被折起来的棉布。”**

先拆出我们真正想借的性质：温和，不光滑得像广播；有一点褶皱般的停顿，但不疲惫。

创作说明：这是一位熟悉的人，不急着把话说完。声音柔和、近，句子中偶尔停一下再接上，像她还在一边整理手边的东西。

执行稿：

```text
用温和、放松的成年女声读这句话。音量适中，距离感亲近，保留一点自然气息，不要主持人口吻。“回来啦”轻轻接住对方，不做戏剧性的升调；后半句稍停再说，像边叠衣服边聊天。台词：“回来啦。饭还热着。”
```

这不是必须添加布料摩擦声。需要现实布料时再让画面或声音承担。**比喻里的物体，可以不在作品里出现。**

## 同一个比喻，两种相反用法

“玻璃感”可以是清澈、易碎、冷硬，也可以是折射、轻脆、透明。护肤广告也许要的是薄薄的清透反光；悬疑片也许要的是物件接触桌面时过于清晰的一声。没有选定性质之前，直接写“玻璃感情绪”会让创作者自己也不知道要检查什么。

“像水”可以缓慢包裹，也可以锋利冲刷；“像呼吸”可以平稳舒展，也可以忽紧忽松。问清动作关系，再选择感官材料。

## 限定一次转译的主轴

“丝绸般、刀锋般、奶油般、冰块般”同时出现，可能只是四个漂亮的词。先选一个主轴，再保留一项对照：

> 画面大部分像被柔布擦过，只有瓶口留一道清楚的冷亮边。

这句有主从。柔与锐没有互相否定，而是分配给不同区域。

## 如何检查是否有效

把比喻暂时拿掉，只读执行说明，是否仍能明确选择光、动作或音色？再把执行说明拿掉，只看成片，是否还能感到原先要借的性质？前者检查翻译，后者检查表达。二者都不保证时，先换一个更贴近材料的联想，而不是继续加修辞。
