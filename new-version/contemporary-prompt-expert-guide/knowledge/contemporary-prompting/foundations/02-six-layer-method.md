# 02｜六层转译：从感受到生成

> “让观众松一口气”不是让人物必须叹气。那口气，也可以由空间、节奏或声音替他松开。

## 六层不是六个必填表格

本指南提出一个便于检查的工作模型。简单任务可以用三句话穿过六层，复杂项目才需要拆开。它不是生成成功率公式，也不要求每层都出一份文件。

| 层次 | 要问的问题 | “下班后，终于属于自己”的一种回答 |
| --- | --- | --- |
| 1．体验 | 观众此刻要感到、理解或注意什么？ | 从被催促转为可以慢一点 |
| 2．关系 | 什么在发生，什么力量正在改变？ | 公共时间退后，个人时间回来 |
| 3．载体 | 谁或什么承载这件事？ | 一只脱下的鞋、一扇门、仍紧握的手 |
| 4．感知 | 观众具体看见、听见什么？ | 鞋落地，手松开，走廊噪声被门隔远 |
| 5．组织 | 从哪里看，先后怎样，哪些不展示？ | 不拍夸张笑脸，先留门口半秒空白 |
| 6．提交 | 交给哪个任务、哪些参考和参数？ | 首帧图生视频，保留机位，只生成松手和门声变化 |

**体验是目的；关系是结构；载体是材料；感知是证据；组织是表达；提交是执行。** 实际制作中可以倒着走：先有一张极好的光影照片，再寻找它适合承载的关系。六层用来查断点，不是限制灵感的入口。

## 同一目标，至少允许三条路

“清爽”可以是冰凉水流，也可以是热天里终于有风，还可以是一张不再挤满信息的产品海报。先提出不同机制，再选方案。换三种蓝绿色并不等于三个创意。

例如“从束缚到松开”：

**身体路线**：手指从紧扣杯柄到只轻轻搭着；肩膀慢慢落下来。适合人物体验，不需要大场面。

**空间路线**：开头视野被门框压窄，后来人物跨入更宽的光面。适合把变化交给构图，但别把房间莫名放大。

**声音路线**：细碎通知音一直在抢话，门合上之后只剩水与呼吸。适合声音先行，画面可以保持安静。

三条路线可以合作，但不要都做到最大。否则观众会同时收到“松开”的三个感叹号。

## 让重要意图有证据，不让每个细节背任务

关键情节如“她拿到了真信”要有可辨认的道具和交接；气氛如“有一点不舍”可以保留多义性。杯子不一定是婚姻的隐喻，窗帘也不必每次象征自由。只为需要观众读懂的地方安排证据，其余允许生活的余量。

一条简单判断：**删掉这句说明，观众还会从成片中获得同样的体验吗？** 若不会，而画面没有对应细节，就存在表达空缺；若会，这句话可能只是创作者自己的解释。

## 五种常见断点

“她很后悔”没有外部表现，是体验到感知的断点。“围着人物拍一圈”没有观看理由，是组织与体验的断点。“保持同一瓶身”却没提供瓶身参考，是条件的断点。“固定机位”与运镜菜单的推近冲突，是提交的断点。“画面很美但产品认不出来”，则是评价时把次要美感压过了核心任务。

修哪一层，就先回哪一层。不要所有失败都靠改几个形容词补救。下一步可用[三种稿子](/foundations/03-three-drafts.md)把层次转为自然的工作文本。
