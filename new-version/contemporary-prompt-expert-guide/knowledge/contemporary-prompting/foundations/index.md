# I · 基础框架

先理解这门手艺的对象与边界，掌握六层转译与三稿分工。

- [01｜这门手艺，究竟在做什么](/foundations/01-what-this-field-is.md) — 把当代提示词理解为跨媒介创作说明，而不是神秘语法或独立于创作的捷径。

- [02｜六层转译：从感受到生成](/foundations/02-six-layer-method.md) — 用六个可来回检查的层次，连接观众体验、媒介选择与实际输入。

- [03｜感受稿、创作说明、执行稿](/foundations/03-three-drafts.md) — 把联想的丰富与提交的清楚分开；不让诗意和工程互相挤占。

- [04｜精确到哪里，留白在哪里](/foundations/04-freedom-and-constraints.md) — 锁定身份与关键结果，开放自然过渡；不把控制误写成保证。

- [05｜怎样知道一句提示真的有用](/foundations/05-how-to-know.md) — 区分看见的事实、创作解释、工具承诺与实测结果。
