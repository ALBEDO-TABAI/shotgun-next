## 这一版补了什么

旧版的骨架没有变：按问题路由、证据分层、风格库、时间核算、多媒介与多题材分流、反伪精度。新增的是 AI 生成的“最后一公里”，全部作为按需模块：

- **帧描述规范**：九宫格与归一化坐标、深度层与遮挡序、主体定位、光向钟点、固有色与光染色、材质光学签名、取证句式、可逆性与一致性自检、从清点到生成描述的转换。读参考帧、写首帧、比对生成帧共用一套口径。
- **提示词编译**：参考资产一项一职、空间语义锚点、逐镜字段、首帧与关键帧、生成单元与接缝、字数与压缩、生成前检查门、单变量重试；附参数化骨架与结构校验脚本。
- **生成审片**：P0/P1/P2、保护好表演、四级返工路由、症状到根因到修法表、Take 结论、通过标准。
- **空间与状态、表演、导演决策、光色材质的升级**：关系图契约、尺度契约、镜内生态表、连续性等级与可用帧口径；刺激与时序、通道限制、生成表演失真表；节拍与调度状态；光向钟点与材质签名。
- **新 addon 场记与连续性监督**：连续性协议、三本账、知识卡与项目风格档案、三份 CSV 模板。
- **摄影、角色、美术、剪辑的小补**：承托与速度曲线、光学效果节制、关键帧的尺度与落位、语义锚点、参考传代劣化、剪辑可解优先。

逐文件的改动见 [CHANGELOG](CHANGELOG.md)；方法来源与证据边界见导演技能的[来源](director-skill/vvf-director-skill/references/sources.md)。

## 与两份外部技能的关系

- **Leos 六部门导演组技能**：它的操作闭环被吸收为方法与字段，没有整包复制；它的 5000 字上限、纯文本格式、`@image` 句柄、强调符号、六角色乘每镜的全覆盖审稿、生成门口令，都按“带日期的当期参数”或“可选模式”处理，不作通用规则。
- **图像反推描述技能**：保持独立。导演技能的帧描述规范是它的精简版；有它时读图直接用它的结构化结果，没有它也能按规范工作。

## 可以直接这样提出任务

> 用导演技能把这段故事做成45秒分镜。保留所有台词，明亮、克制，允许全程固定。先说明必要假设，再交完整分镜。

> 把这份分镜的 S01–S02 编译成图生视频的生成单元。参考图各自只承担一件事，工具上限按我给的当次说明，时长不要补默认值。

> 用帧描述规范读这张参考图，每条判断带依据，认不出的写不可辨，末尾给存疑清单。

> 这三条生成片段按生成审片分级，先保护成立的表演，给最小返工路由和只改一项的下一版。

> 用场记技能给这一版提示词建版本账，并核对上一镜出口和本镜入口。

## 校验

结构检查沿用上级目录的 `tools/validate_bundle.py`（需要 PyYAML 与 markdown-it-py）：

```bash
python tools/validate_bundle.py new-version --report new-version/validation/structure.json
```

它检查入口不超过 5 KB、参考不超过 12 KB、链接不悬空、每份资料都能从入口到达、链接不越出单个技能。生成提示的结构检查用导演技能的 `scripts/validate_prompt.py`。两者都只查结构，不评价创作。

## 边界

分镜、提示词、审片记录完成不代表影片已生成、已实拍或获用户批准。工具能力、字数上限、句柄语法、价格是带日期的当期参数，由当次官方说明或实测核对。本版没有做生成对照实验；新增机制的效果要在实际项目里用同素材、同工具的前后对照检验。
