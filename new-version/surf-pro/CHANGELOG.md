# 变更记录

## 2.0.0 · 2026-09-18

从用户提供的 `surf-pro-ready.zip` 重构，保留技能名 `surf-pro`。

新增需求画像、模糊性分流、核心/前提/延展问题图、受控延展准入、多路径检索与轮次信息增益检查。改为结论级证据审查，明确实际阅读范围、源头独立性、冲突与可比口径。输出深度与文件交付解耦，支持快速任务与诚实的部分完成。

视觉模块增加空间、构图、运动、镜头交接、节奏和声音，区分观察、创作者自述、效果推断及执行建议。移除固定访谈/口号配额，取消未随包提供的浏览器技能硬依赖。

统一标准目录与元数据，添加模板、教学案例、可选研究记录校验、离线测试、行为验收集和真实验证边界。删除打包杂项，不附带凭据、素材版权授权或调度能力。
