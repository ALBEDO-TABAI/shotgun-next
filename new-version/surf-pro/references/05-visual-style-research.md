# 视觉、广告与影片风格研究扩展

## 1. 适用边界

仅在任务涉及图片、作品、影片、视觉风格、广告创作参考或相关方法论时读取。本模块延续原版“不要把风格名当内容”“从实际作品和主创资料建立规则”的优点，但不再要求每个项目强制集齐固定数量的访谈、口号与 A 级来源。

风格标签只是检索入口。先识别具体作品、时期、媒介与创作主体，不把一个品牌几十年的表达压缩为同一个外观；不凭一张静帧总结镜头运动与整片叙事。

## 2. 将风格拆成可研究的创作选择

下表是检查地图，不是每项都必须填满的清单。平面任务删去纯运动维度；影片任务不要漏掉声音与时间组织。

| 维度 | 研究问题 | 有用证据 | 不应推断 |
|---|---|---|---|
| 用途与情绪 | 对谁表达什么？情绪如何推进？ | 作品、brief/访谈、版本比较 | 只凭标题猜受众或效果 |
| 世界与现实程度 | 哪些规则写实，哪里有超现实处理？ | 作品序列、美术/导演资料 | “梦幻”直接等同某制作技术 |
| 色彩与光线 | 主色起什么作用？明暗如何组织注意？ | 已核验画面、调色/摄影资料 | 从颜色直接断言固定心理效果 |
| 构图与空间 | 主体、前中后景、留白、层次如何安排？ | 清晰图像、连续镜头 | 一个中心构图代表全部风格 |
| 镜头运动 | 谁动、朝哪里动、何时开始/停止、为何移动？ | 完整片段、摄影/制作记录 | 静帧推断轨道、手持或具体设备 |
| 场面调度 | 人物、物体与摄影机如何共同改变关系？ | 连续动作、排练/幕后资料 | 只把运动归因于摄影机 |
| 镜头衔接 | 出入画、视线、动作、形状、声音如何连接？ | 相邻镜头及声音 | 单个漂亮镜头能说明剪辑机制 |
| 节奏与时长 | 镜头长度、动作密度、留白如何形成节拍？ | 带时间轴片段、剪辑记录 | 只凭快慢标签推出观众反应 |
| 人物与表演 | 群像/个体、姿态、动作、服装如何服务表达？ | 实际作品、选角/表演资料 | 根据形象推断个人身份背景 |
| 材质与视觉元素 | 场景、服装、产品、风水烟雾等如何作用？ | 图像、制作设计说明 | 元素出现就有统一象征意义 |
| 文案与叙事 | 信息何时揭示？口号起何作用？ | 作品文字与结构、创作说明 | 一句口号等同完整叙事 |
| 声音与视听关系 | 音乐、环境声、对白、静默如何配合画面？ | 可听完整片段、声音制作资料 | 仅凭画面猜音乐及节拍 |
| 时期与变体 | 哪些稳定、哪些随项目改变？ | 多时期作品、可核实时间线 | 少量方便样本代表全集 |
| 反例与边界 | 相似但不同在哪里？怎样会“看起来像却作用不同”？ | 对照作品、失败分析 | 分析者偏好冒充作者禁令 |

## 3. 视觉证据获取

先看真实且已加载的目标内容。网页标题、空白预览、cookie 层、拒绝访问截图不能证明视觉特征。作品截图可以是有效证据，只要内容可见、来源可追溯且分析范围与截图匹配；不要因“它是截图”就一概拒绝。

原图/完整视频可得时优先查看；不可得时明确只看到局部或转述。PDF 涉及图表/作品时，使用宿主可用的页面渲染/截图能力查看相关页。不要把搜索缩略图说成已读原图，把标题简介说成已观看视频。

用户要求本地素材包时才按许可与工具能力保存必要文件。每份素材记录来源页、实际查看范围、时间码/页码、保存路径、使用限制；哈希用于识别文件，不证明真实性或版权许可。

## 4. 观察、意图、效果、转化必须分开

**可观察描述**：“这段素材中，主体从右侧进入；镜头在进入后开始横移；下一镜在动作未结束时切入。”需要实际连续片段。

**主创意图**：“主创称这样处理为了……”需要相应访谈或制作记录，不能仅凭观察补写。

**观众效果**：“因此所有观众都会更激动”属于外推；没有相符受众研究只能说“可能形成某种阅读/情绪路径，是分析假设”。

**创作转化**：“在当前方案中可测试……”是建议，需要说明前提、替代方案和检查方式，而不是把观察升格为普遍法则。

原版把主创访谈描述为某些工艺细节的唯一来源，本版改为按主张选择材料：访谈适合意图与自述，制作记录、幕后、技术文档也可能提供直接证据；实际画面可直接支持有限的可观察特征。

## 5. 镜头与衔接的研究卡

```text
研究对象：作品/版本/时间段
发生了什么：主体运动、摄影机运动、空间关系、声音
前一镜 → 当前镜 → 后一镜：信息、动作、视线、形状、声音如何交接
选择时机：什么时候开始移动/切换，什么变化触发它
可能功能：只写材料支持或明确标为分析假设的功能
竞争解释：可能只是场景限制、制作条件或其他原因吗
执行转化：当前需求可以借鉴的具体做法
不适用条件：空间、叙事、节奏或生成工具的限制
验证方式：观看连续性、动作可读性、信息揭示是否符合目标
来源：实际已看片段/主创资料的具体定位
```

不要从观感猜测准确焦距、快门、帧率或器材型号。除非有可靠制作资料，可写“呈现较强透视/较浅景深等可观察特征”，并区分估计与确认。

## 6. 从调研到规则，不输出空泛形容词

推荐规则形式：

> 当【叙事/情绪/信息目标】且满足【条件】时，考虑【可执行选择】；它可能通过【机制解释】产生作用。不要在【反例条件】机械使用。检查【可观察验收点】。依据是【作品观察/创作者陈述/研究/分析推断】，尚缺【未知项】。

例如“镜头有呼吸感”不足以执行。应继续问：是停留时长、运动加减速、人物动作、声音留白还是景别变化造成这种感受？随后搜集能够区分这些解释的片段和资料。

没有资料支撑的“禁止事项”写成当前项目的候选约束，不冒充某导演、品牌或流派的官方规则。

## 7. 延展何时有用

用户问运镜：可补查动作连续性、注意力引导与镜头衔接，因为它们直接决定运镜在序列中能否成立；不自动扩成完整电影史。

用户找品牌广告风格：可补查时期变化、产品出现时机、声音与文案机制；但若只要十个参考链接，不强制写完整论文。

用户建方法论知识包：从“有哪些技巧”延展到“何时用、何时不用、为什么、怎么检验”；这属于用途必需的深度，不是随意增加邻近主题。

## 8. 归档与表达边界

默认保留精简、必要的语料和原文定位；不要求“历代口号全列”或长篇逐字收录。外部图片、影片和音乐可观看或可下载不代表拥有商用权；内部研究也不能被当作自动获得复制许可的理由。

输出面向用户时，先给可区分的表达路径、选择条件和实际案例解释；后附素材索引。不要只给情绪词、调色名或一串品牌名称。
