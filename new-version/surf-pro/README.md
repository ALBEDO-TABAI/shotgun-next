# Surf Pro 2.0 · 研究增强 Skill

把“搜索很多”升级为“理解用途、答准问题、证据可查、适度多想一层”。保留原版的机制研究、来源追溯与视觉研究能力，但不再把每次搜索都变成重型资料归档。

## 使用

技能名仍为 `surf-pro`。可直接提出自然语言任务，例如：

> 用 surf-pro 帮我搜集这个方向的方法论。我现在描述得不一定准确，请先按实际用途理解；补足会影响判断的前提，再适度延展，最后输出能执行的知识包。

> 核实这个功能目前是否支持，只要结论和出处，不需要延展或建资料库。

> 我想找一些清爽但不幼稚的品牌短片参考，用来研究镜头表达。除了案例，还要告诉我方法适合什么时候使用、有什么反例。

不需要填写 JSON 或记住英文模式名。深度和延展策略由自然语言需求决定。

## 安装与升级

压缩包只有一个技能根目录 `surf-pro/`，根内有 `SKILL.md`。这是本地 skill 包，不是插件市场发布包。

按 [OpenAI 构建说明](https://learn.chatgpt.com/docs/build-skills)，本地 Codex 可使用项目目录 `.agents/skills/surf-pro/` 或个人目录 `~/.agents/skills/surf-pro/`。把解压后的整个目录放在相应位置；不要多套一层导致 `SKILL.md` 位置错误。桌面端按当前 Skills 界面支持的本地添加方式操作；本次未验证具体客户端的 ZIP 导入界面。

**升级时禁用或移出旧版后再启用新版。** 原压缩包目录为 `surf-pro-ready`，入口名称却为 `surf-pro`；新版统一为 `surf-pro`。同名技能不会被自动合并，避免新旧规则同时生效。不要把旧版四个 reference 文件继续拼入新版入口；迁移说明见 `docs/review-and-migration.md`。

## 能力与依赖

核心是指令与参考材料，不需要 API key、Python 或额外安装依赖。联网研究使用宿主实际提供的搜索/读取能力；文件、视频、浏览器、连接器与调度能力均由宿主决定。

可选 `scripts/validate_research.py` 使用 Python 3.10+ 标准库，离线检查机读研究记录。它不检索、不调用模型、不写文件、不验证外部事实。普通聊天任务不必运行它。

## 主要改进

| 原有倾向 | 新版处理 |
|---|---|
| 宽泛主题直接拆固定数量机制桶 | 先明确用途和成功标准，再按需建问题图 |
| 模糊就采用默认值 | 消歧、可撤回假设、条件分支和关键澄清 |
| 延展主要依赖补资料缺口 | 显式识别必要前提与有价值的邻近问题 |
| 全站 A/B/C/D 等级承载结论 | 按主张核对证据、阅读范围、独立性与适用条件 |
| 每桶三来源、固定额外搜索轮数 | 用关键问题闭合、矛盾处理与信息增益收敛 |
| 每次生成完整本地证据库 | 简报/报告/资料包按任务选择 |
| 风格扩展偏口号与主创来源 | 增加构图、运镜、衔接、节奏、声音及观察边界 |
| 原工具环境隐含前提较多 | 无硬编码浏览器技能；能力缺失时诚实降级 |

## 文件导航

- `SKILL.md`：真正运行入口；按需读取 `references/`，不一次性塞入全部文档。
- `references/`：需求、搜索、证据、交付、视觉、安全、数据合同和方法来源。
- `templates/`：简报、报告和可选机读记录。
- `examples/`：三种教学构造案例；不是已经完成的外部调研。
- `scripts/` 与 `tests/`：可选记录校验与离线测试。
- `evals/`：目标宿主的触发、边界与对抗验收案例。
- `docs/review-and-migration.md`：逐项原版审查、保留/修改理由与升级注意事项。
- `docs/validation-report.md`：本次真实执行的校验结果及未验证项。

## 校验

在技能根目录运行：

```bash
python -m unittest discover -s tests -v
python scripts/validate_research.py templates/research-record.json
```

检查真实研究记录：

```bash
python scripts/validate_research.py /path/to/topic/research-record.json
```

素材路径默认相对于该 JSON 所在目录；需要其他素材根目录时使用 `--root /path/to/topic`。退出码 `0` 表示结构检查无错误，`1` 表示记录错误，`2` 表示命令/文件/JSON 读取失败。警告不会被伪装成事实核验结果。

本包区分**离线测试实际通过**和**行为案例尚未实测**。完整边界以验证报告为准；不承诺一定答准所有需求、彻底阻断注入或自动提升某个百分比。
