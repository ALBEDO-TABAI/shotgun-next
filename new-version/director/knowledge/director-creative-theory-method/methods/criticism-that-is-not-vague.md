# 步骤

1. 组织为：**具体选择 → 在作品中的关系 → 可能收益 → 代价或盲点 → 对照或反例 → 评价范围**。
2. 示例："本片多次在争执后离开受伤者，转向解释实施者的动机。这可能增加行动者复杂性，也减少了后果被经历的时间。在研究关心与控制的任务下，我认为它使后者显得过于轻易。"仍可争论，但有可定位对象，允许他人提出相反证据。
3. "导演太自恋""很有灵气""没有温度"可表达感受，不能独自承担分析——转译成作品或工作方式中的具体问题，不对未知人格作断言。
4. **偏见检查**：是否仅因不熟悉某种表演或文化惯例而判它失败？是否把流畅当成唯一美学？是否对知名作者的失误给予额外宽容，却对新人拒绝相同解释？用来检查判断，不保证消除全部偏见。
