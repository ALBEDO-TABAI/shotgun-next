# 步骤

1. **方向探索**：少量真正不同的方向。为每个方向写核心问题、必要事实、开放部分、潜在收益、主要代价、需要验证的未知。选方向不必假装有唯一最优解，但应能说明取舍。
2. **场景与形式设计**：叙事内容建立人物行动、信息依赖和关系变化；非叙事内容建立材料、节奏、对照、重复与变化规则。
3. **声画与空间预演**：先用足以回答问题的材料做原型——简单排练、平面走位、声音草图、动态图像、有限分镜。静态分镜无法证明表演节奏；无音轨动态预演无法证明听觉层级；生成视频的成功单段不证明全片身份和空间一致。
4. **整体组合与修订**：每轮指向明确问题，尽量保留可比较条件；不为更"丰富"不断增加事件、灯光变化和音乐层。问题来自上层行动→回到剧本；来自观看距离→回到调度；来自局部声画竞争→才进入后期微调。
