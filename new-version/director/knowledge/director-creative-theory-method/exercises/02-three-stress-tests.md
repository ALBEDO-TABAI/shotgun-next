# 任务

1. **预算缩减测试**：总时长与核心任务不变，少一个场景和一半覆盖机位。先标出不能丢的关系证据，再改实现。不能以无关美图补足形式体面。
2. **主创更换测试**：新摄影或声音设计加入后，仅凭当前材料能否知道哪些是目标、哪些是候选、哪些已批准？若必须靠导演口头记忆，交接尚未完成。
3. **善意异议测试**：让一位专业人员提出最有根据的反对意见。导演能否复述该意见所保护的价值，再说明取舍？若只能诉诸职位或审美权威，决定还缺少可讨论的依据。
4. **改动记录任务**：选一次虚构或实际有记录的跨部门改动，分别写出改动前的问题、候选方案、批准关系、被牺牲的局部优势、下游收到的信息、成片结果。缺项明确标缺失，不用理想流程补齐历史。最后问：导演的整合究竟发生在哪里？

# 验收

- 每项测试有可指认的材料或对话记录，而不是"感觉能通过"。
