# 任务

## 六种训练

| 训练 | 做法 |
|---|---|
| 观察 | 记录具体动作、声音与空间使用，不急于命名主题。把"悲伤的人"改成他如何处理某个物件、如何接收别人的帮助 |
| 替代 | 对同一情境设计两种真正不同的观看关系，说明各自代价。仅更换色调不算完成 |
| 限制 | 暂时不用自己最熟悉的一种手段，看关切能否由其他形式承担；辨认习惯与必要性的差别 |
| 反例 | 找一部与既有作者画像不一致的作品，认真解释差异，而不是先把它塞回标签 |
| 协作 | 让不同部门提出非预期方案，记录哪项改动真正提高作品，而不是只记最终导演决定 |
| 伦理 | 把一个最有感染力的场景拆成实际制作步骤，逐项判断需要谁承担什么，是否有同样有效而更尊重边界的替代 |

## 三组任务

1. **同一关切，不同形式**：以"如何接受他人的帮助"为问题，分别设计一段多人对话、一组静物照片和一条材料影像；不得使用相同情节模板。比较哪些关切能迁移，哪些必须改变。
2. **同一形式，不同问题**：保留固定机位，分别处理合作、拒绝和纯粹的运动韵律。检查固定机位在每个任务中实际做了什么，防止把手段当成意义本身。
3. **为自己的选择写反方意见**：不嘲讽不喜欢它的人，认真写出这项选择可能使观众失去哪些信息或经验。再决定修改、增加条件，还是保留并承担代价。

# 验收

没有自动评分答案。标准是能否把观察、形式选择、条件和后果连接起来，而不是能否写出最宏大的导演宣言。
