# 任务

1. 选一段自己很喜欢的影像，写一句完整解释。
2. 标出句中所有"导演想""象征""必然让观众"，逐项问证据是什么。
3. 保留有证据的部分，其余改为假设，补一种替代解释。
4. **三层读法**（虚构：父亲说"我从来不干涉你"，同时把女儿收好的行李移回房间）：
   - 第一层只记录：他说了什么、做了什么、女儿如何回应。
   - 第二层提出解释：言语与行动存在张力，可能涉及自我理解与实际控制的差异。
   - 第三层讨论作品：摄影是否让观众注意到矛盾，是否给女儿反应与选择的时间，后续是否改变对父亲的判断。
   - 到此仍不能断言导演现实中如何看待自己的家庭。

# 验收

- 解释的流畅度不超过证据；一个范围准确的解释比毫无缺口的宏大阐释更能指导下一次创作。
