# 导演创作理论与方法知识包 · Overview

母题：**导演创作理论与方法**——从导演风格识别、职责与跨部门整合、创作出发点与意图，到人物／表演／对白、世界与置景、信息分配与视点、桥段与场景行动、叙事顺序与节奏、调度与摄影、灯光色彩、声音音乐、整体成片与媒介适配、导演个性与伦理，最后到拉片研究→导演方案→迭代交付的工作流。来源为《导演创作理论与方法知识包 · 14 模块》（`new-version/director/导演创作理论与方法知识包_14模块/`，2026-09-18 整理）。

全包共用一套证据约定：来源分五类（原作者理论、主创证言、实证研究、机构材料、本包综合），各自只能支持特定强度的论断；所有修理铺、洗衣店、母女告别、45 秒洗护片等案例均为自拟教学案例。见 [来源使用与证据边界总原则](principles/source-use-and-evidence-boundaries.md) 与 [证据协议：六种陈述身份](frameworks/six-evidence-statement-types.md)。

# 阅读路线

* **建立理论基础**：先读 [01 导演风格识别](topics/01-director-style-identification.md)（概念边界、八轴、归因、证据协议），再按 02→13 依次读各篇枢纽，最后读 [14 工作流](topics/14-film-study-director-plan-iteration.md) 看它们如何接起来。
* **分析现成作品（反向路径）**：[01](topics/01-director-style-identification.md) 做风格定位 → [风格研究十步](methods/style-research-ten-step-workflow.md)／[拉片五遍](methods/film-study-five-passes.md) 建立过程 → 按问题调用 04–11 各篇的框架与检查表 → [13](topics/13-personality-expression-ethics.md) 讨论作者性与伦理 → 用 [E-H-D-T-V 证据账](frameworks/evidence-ledger-e-h-d-t-v.md) 记录。
* **从零创作或带团队（正向路径）**：[03 创作出发点](topics/03-creative-origin-and-intent.md) 把兴趣变成命题 → [02 职责与整合](topics/02-director-role-and-integration.md) 安排判断层级与共同问题接口 → 调用人物、世界、信息、场景、时间、画面、光色、声音各篇做出决定 → [12 整体成片](topics/12-whole-film-post-adaptation.md) 完成整体判断与版本 → [14](topics/14-film-study-director-plan-iteration.md) 的 [创作流程](methods/creation-flow-direction-scene-preview-revision.md)、[门禁](frameworks/gates-hard-problems-vs-aesthetic-disagreement.md) 与 [最小交付协议](templates/minimum-delivery-protocol.md)。
* **按问题调用模块**：见 [知识包使用地图与任务路由](frameworks/knowledge-pack-usage-map-fourteen-modules.md) 与 [统一 skill 接口](skills/skill-director-unified-interface.md)；每篇各有一个 [Skill 接口](skills/)。
* **AI／Agent 参与时**：先读 [AI／Agent 工作边界](principles/ai-agent-working-boundaries.md) 与 [交接必须消费当前决定](principles/handoff-must-consume-current-decisions.md)。

# 主题枢纽 · Topics

* [01 导演风格识别：从视觉标签到有证据的创作规则](topics/01-director-style-identification.md) - 导演风格是有模式的创作选择而非外观标签；概念边界→研究路线→分析尺度→条件规则→四类作用→八轴→混合→归因→证据→流程→量化→评价→接口。
* [02 导演职责与跨部门创作整合](topics/02-director-role-and-integration.md) - 导演如何让不同人的专业判断形成同一件作品；职责拆分、权力区分、判断层级、共同问题接口、前期／现场／后期方法、案例与失效修复。
* [03 创作出发点、导演意图与表达命题](topics/03-creative-origin-and-intent.md) - 作品为什么从这里开始，兴趣如何变成具体选择，分析者怎样讨论意图而不替人编造动机；五种为什么、起点类型、命题四层、假设树、导演阐述。
* [04 人物关系、表演与对白导演](topics/04-character-performance-dialogue.md) - 把人物从设定与情绪标签转化为可被演员执行、被对手影响、被观众辨认的行为；六层人物分析、对白双层、结果型指令改写、排练、选角、摄影剪辑对表演的影响、伦理边界。
* [05 世界观、空间与场景置景](topics/05-world-space-set.md) - 一个世界怎样通过人的生活与行动被相信；场景怎样参与叙事、表演与声音；世界观四件事、规则句式、五张关系表、三种空间、道具与服化的动作状态。
* [06 信息分配、叙述视点与留白](topics/06-information-focalization-gaps.md) - 决定观众何时能够知道、推断、误解、怀疑或等待，而不把少说一点误认为自动高级；四层状态、观看位置五变量、五种没说、悬念好奇惊讶、隐瞒边界。
* [07 桥段、场景行动与情节设计](topics/07-setpiece-scene-action-plot.md) - 一个点子如何成为一段值得经历的行动；场景价值来源、工作模型、冲突与阻力、因果检查、节拍转向、铺垫回收、桥段机制、评价与重写。
* [08 叙事顺序、时间结构与节奏](topics/08-order-time-rhythm.md) - 区分世界中事件怎样发生与作品怎样让观众经历它们；四种时间、顺序选项、时长五种模式、频率、六个节奏层级、认知与计量的边界。
* [09 人物调度、摄影与画面表达](topics/09-staging-cinematography.md) - 先决定观众怎样接近人物、行动和空间，再决定镜头如何实现；三种调度与三条路线、观看距离四层、镜头参数的认知边界、连续性作为资源、长镜头与覆盖。
* [10 灯光、色彩与氛围设计](topics/10-lighting-color-atmosphere.md) - 从情绪标签到可拍摄、可延续的感知条件；五件常被混写的事、色彩研究边界、五类灯光功能、颜色角色、技术可信、广告与生成。
* [11 声音设计、音效与音乐](topics/11-sound-design-music.md) - 组织一个与画面共同成立的听觉世界；要设计的是声音的全部工作而非配乐；声音事件卡、声画关系、音乐七问、实证边界、前景接力、作曲协作、可及性。
* [12 整体成片、后期与媒介适配](topics/12-whole-film-post-adaptation.md) - 让局部好选择在完整作品中共同成立；素材／版本／作品区分、七个层面、剪辑阶段、批准关系、试映、广告与平面、纪录与实验、版本案例、交付卡。
* [13 导演个性、个人表达与创作伦理](topics/13-personality-expression-ethics.md) - 从可识别外观到可承担的选择；个人／作者／风格／声誉四对象、作者论限度、五个独立判断、坚持与修改、三重伦理检查、事实责任、批评方法、章程。
* [14 从拉片研究到导演方案：可执行的研究、创作与迭代工作流](topics/14-film-study-director-plan-iteration.md) - 把前十三篇连接成一套可选择使用的工作方法；使用地图、两条共享证据的路径、来源策略、证据账本、五遍拉片、创作流程、试验设计、门禁、Agent 边界、训练库、最小交付协议、维护规则。
