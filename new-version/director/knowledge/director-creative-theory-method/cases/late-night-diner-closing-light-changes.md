# 推演

- 可以只拍成逐渐变暗，也可以把每次光变变成行动：前一次关灯可被理解为催促，后一次开灯可修正这种理解——但必须与表演、声音和动作共同建立，不指望灯光独自说明善意。
- **A 版**：光变作为明确事件，人物注意到、作出反应，声音留下开关与空间变化。更容易形成具体关系。
- **B 版**：不突出开关动作，空间逐渐改变，观众可能先感到结束正在接近。可能保留环境时间感。
- 不能只按"更含蓄"判定 B 更高级。

## 测试问题

观众什么时候知道餐馆要关门？把第一次关灯理解为什么？最后开灯改变了什么判断？没有识别开关声的人是否仍能理解必要行动？光变是否使关键身体动作失去可见性？
