# 情境

店员想尽快结束工作，却不愿把对方留在没有解决办法的处境中。店铺有入口、洗烘设备、折衣台、柜台、储物区；顾客不能自行进储物区；店员能关设备但不能控制已离开的其他顾客。"误拿"是否可能取决于真实流程，正式制作前应向从业者核对。

# 推演

- **空间承担冲突**：柜台完全隔开两人→请求与答复；折衣台在共同区域→一边核对一边重新分工。选择取决于研究制度距离还是临时合作。店员准备关灯时发现顾客仍在设备前，灯的操作成为"继续营业还是结束"的行动。
- **可见范围**：顾客从入口能看见折衣台却看不见储物区；店员知道后面有一袋无人认领的衣服。观众何时看见由第六模块决定，本篇保证位置与人物知识相容。若摄影机提前展示袋子而顾客站在同一视线位置却完全不看，形成不合理的信息限制——改变遮挡、位置或注意任务，而不是命令顾客"假装没看见"。
- **可听范围**：烘干机使第一次请求没被完整听见；店员关掉设备后双方才听清，同时改变交流条件与关店状态，不必另写"你刚才说什么"。噪声真实到对白无法使用会伤害制作，需与录音、声音设计提前协商。
- **道具动作**：顾客手上不属于自己的衣服是误拿证据；店员把关店牌翻回来是承担后果的动作；储物袋拿出后"只有店员能进入"的边界发生有限变化。结尾不必找回衣服，可在两人决定留联系方式时结束。
- **平面变体**：店员一手扶着尚未翻回的关店牌、另一手接过衣物的瞬间；但单张照片不必然让人理解完整情节，标题、组照或文字可能承担部分信息。
- **AI／虚拟制作变体**：先生成空间关系基准，再分别测试站位与道具动作；每次生成后检查柜台、门、储物区关系是否保持，而非只查色调。

# 教训

空间支持的是关系变化，而不必强迫戏剧性大团圆。
