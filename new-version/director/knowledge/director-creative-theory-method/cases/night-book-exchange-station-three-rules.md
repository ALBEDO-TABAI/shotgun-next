# 情境

一个人带来缺页的书试图交换，发现不能进入指定书架；另一个人正在工作台修补纸页。第一个人需要决定求助、放弃还是寻找另一种交换。观众需要知道的最低规则是为什么他暂时不能完成目标，以及有什么可见选择。

# 推演

- **规则与置景共同设计**：借阅卡有可辨认位置；两个书架的进入条件有稳定提示但不像教程占满画面；共享工作台使两人可合作也可保持距离。想让求助有成本，让工具明显属于另一人，不必凭空设置恶意管理者。
- **三种导演方案**：A 让观众提前知道规则，关注人物是否愿意开口（需早期可读提示）；B 随人物一起发现限制（需明确发现顺序）；C 暂不解释完整制度，把修补动作与交换失败联系起来让观众推断（需足够证据而不过度说明）。一个漂亮布景不能自动支持所有叙述方式。
- **声音**：纸页、工具、门、室外环境建立有人使用的空间。提示音需说明谁能听见、何时触发、是否泄露原本延迟的信息。音乐能组织节奏但不能替代规则证据——不安音乐不会让观众知道借阅卡怎样工作。
- **不为结尾变法**：缺页的书最后被接受须有可理解的条件改变：经过修补、换了允许该状态的书架、有人有权例外。作品可有意揭示规则荒诞或被误传，但要作为新事件处理，不把结构矛盾当巧妙反转。

## 状态对照测试

开场：归还的书混在待修区，访客不知哪些可取；中段：一本书被翻开发现缺页；结尾：工作人员把它移到两人共同使用的桌面。真正改变的是物件的使用资格与人与人的工作关系，不只是灯光变暖。

三种删改：删去待修区标识→破坏规则理解；标识移到镜头看不见的位置→破坏信息可见性；保留空间信息却把最后的书换成另一册→破坏物件连续性。三个问题都表现为"观众没看懂"，修复方式却不同。

# 教训

设定文档可以解释每个区域，但观众只能依据实际获得的线索判断。导演验收场景时至少把一项重要规则放进真实行动或预演。
