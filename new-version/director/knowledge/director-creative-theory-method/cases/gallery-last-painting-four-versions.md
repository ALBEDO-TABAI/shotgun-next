# 情境

画廊即将关门。四个版本共享实际事件，让观众在不同位置形成不同问题。

# 推演

| 版本 | 观众位置 | 重点 | 风险／要求 |
|---|---|---|---|
| A 提前知道她在等人 | 开场给简短可信的等待信息 | 阻止取画读为争取时间；注意工作人员是否愿意配合；悬念可来自来人是否赶得上，也可主要研究陌生人协作 | 把等待者拍成单纯善良、工作人员单纯冷漠→通过双方真实工作条件保留复杂性 |
| B 只知道她没有权力 | 先看到她被礼貌提醒无决定权，不知为何坚持 | 动机好奇与关系协商 | 避免任意谜语：清楚呈现她在争取有限延迟而非阻止全部工作，她可帮忙收尾以显示目的与代价 |
| C 结尾才发现她并非作者 | 前段可合理以为她与画作有创作关系 | 揭示后回看早期行为仍能成立 | 不能凭空提供错误客观证据——保留凝视、熟悉、坚持，不添加没发生的签名镜头 |
| D 不揭示等待者是谁 | 只让来人到门口与她一起看画 | 保留关系历史而非当前行动目的 | 若连为何暂缓撤展都无法理解，判断是确实希望维持不可解还是漏掉线索 |

# 教训

分别写出每个版本的预期理解与误解，而不是把"藏得更多"自动当成"更巧妙"。版本 C 的检查区分重新解释与改写已呈现事实。
