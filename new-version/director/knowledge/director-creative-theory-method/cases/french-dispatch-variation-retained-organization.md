# 情境

ASC 的制作访谈记录，这部作品在黑白／彩色和画幅之间变化，同时保留对称、深焦等构图倾向；Yeoman 说明了剧本、动态预演与后续讨论的协作流程。

# 推演

- **可确认的文献层事实**：多种视觉处理与某些持续构图倾向同时存在；导演预演与团队实施之间有具体工作环节。
- **可提出的分析问题**：不同叙述层如何触发变化？哪些组织让变化仍容易被辨认？外观改变时，表演、声音和镜头运动是否也改变？
- **不能直接推出**：所有转换具有同一意义；每个细节均由导演独自设计；导演全部作品都遵守本片规则。

# 教训

借鉴混合风格时，分析"变什么、留什么、何时切换"比复制一套配色更有用。这是本包从案例提出的实践建议。

# 适用边界

- 依据所列访谈展示如何形成问题，不宣称本次已逐镜头重测。
