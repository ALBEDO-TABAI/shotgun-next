# 情境

夜班工作者洗完头后重新获得轻盈感。摄影想持续运动，美术想搭巨大茶叶空间，作曲想第一秒进入完整旋律，品牌希望全程清楚展示包装。全部拉满会使人物变成道具或产品被奇观掩盖。

# 推演

1. **重写任务**：呈现从紧绷到松动的感官变化；产品是这段使用经验的具体对象；不暗示一次洗护解决工作处境或产生未经证实的功效。
2. **三段各一个主要承担者**：第一段身体与环境声（不解释完整人生）；第二段动作、材质与清楚的产品信息；第三段音乐扩大感受但不取消人物仍在真实生活中。
3. **部门替代方案**：摄影从贴随紧绷身体转向较宽裕的共同运动；美术用产品语境允许的材质表达清新并检查成分误解；音乐先以呼吸性节拍或稀疏动机试验；包装在拿取、按压、放回中呈现，必要文字另留独立画面。
4. **预演发现**：按压时反光遮住标签；双手与泡沫镜头衔接需更长；音乐完整进入时人物尚未完成变化造成"已治愈"误读。修订对应同一段功能：改瓶身角度与反射环境；延长关键动作删重复环境镜头；延后旋律进入。不是部门各自退让平均分配。
5. **现场变更**：演员提出先重复一次机械整理头发再注意到头发落下。导演允许试拍但通知剪辑——第三段首个识别点变了，否则声音仍按旧版时间制造转折。
6. **最终检查**：产品认得出；使用动作可信；感受未过度承诺；人物仍有生活；无声版保留必要信息；竖版未裁掉关系变化；音乐与文字授权已关闭。

# 教训

最终评价不写"统筹得很好"，而写具体关系：包装识别与身体动作不再冲突，音乐不再抢先命名转折，短版仍保留状态变化的证据。实际受众效果仍需测试。

# 适用边界

- 项目、人物、时长与冲突均为教学构造；时间数字用于可执行，不是效果最优值。
