# 原则

1. 某条表演单看最强烈，可能提前揭示人物态度；某个产品镜头最华丽，可能破坏段落刚建立的真实尺度。剪辑把镜头的相邻、时长和关系变成新的时间与空间组织（Yale 剪辑指南提供基础术语，不代替具体取舍）。
2. **虚构推演**：女儿即将离家，母亲最后把汤改成便携包装。素材里有一条动人的母亲近景——看着行李箱轻轻点头。放在女儿提出离开之前，整场可能被理解为母亲早已完全接受、只是维持告别仪式；这与"母亲在现场逐渐改变挽留方式"是不同组织。保留则后面的包装动作不再承担相同转向；推迟则观看者先从行动中发现改变。不能只比较哪一条更感人。
3. **讨论方法**：先描述当前剪辑使观众何时形成了哪种认识；再说明希望这个认识提前、推迟还是保持开放；最后决定移动、删减或重组。不要先宣布"演员演太满"——问题可能来自位置。
4. **同一优点在不同尺度上变成代价**：精彩转场把相隔数日的事误接为同一时刻；强烈音乐让随后真正重要的变化失去对照；精美产品镜头把人物经验改造成展示姿态。
5. 整体评审做两次方向相反的追问：这个局部为作品提供了什么；作品为了保留它付出了什么。答案不必然导向删除——有时重新安排上下文比牺牲好素材更有效。
