# 原则

1. 不规定各平台统一技术门槛，要求每个交付方案写清主要观看环境并在实际条件下检查。
2. 重要信息只依赖很细微的远处声音时，创作版可保留精度；判断传播版能否通过画面、字幕或其他线索提供支持。补充不能随意改变悬念顺序——提前用字幕写出未知声源身份可能让观众比原方案更早知道答案。
3. W3C 对预录字幕的说明包含理解内容所需的非言语声音；哪些声音必要需结合内容判断。尚未识别的门外声音，字幕先描述其可听性质，而非替观众宣布"母亲回来了"（表达设计建议，措辞与无障碍专业人员核对）。音频描述尊重重要视觉信息与现有声音的时间关系，不把每个镜头填满解释。

## 交付前声音审查单

1. 确认版本身份和声画是否同步。
2. 确认关键言语与事件可理解。
3. 检查声音视点、前景接力与入点是否仍与最终画面一致。
4. 核对目标格式、可及性及素材使用条件。

技术检测能发现部分错误，不能判断一个停顿是否真诚、一段音乐是否过度解释；创作判断也不能代替技术和权利确认。不能用"导演已经听过"覆盖全部交付责任。
