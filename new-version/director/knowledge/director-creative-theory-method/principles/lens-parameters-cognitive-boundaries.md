# 原则

1. 焦距、机位、传感器尺寸、裁切、光圈与对焦距离共同影响画面。相似图像可由不同参数组合得到，单帧通常不足以唯一反推。
2. 几何上：改变观察位置改变物体间透视关系；仅改焦距并维持观察点主要改变取景范围。实拍为保持人物大小常同时改距离，不能把全部空间效果归因于焦距一个变量。
3. 正式项目涉及精确镜头、景深、畸变、合焦或虚拟摄影匹配时，用真实元数据与测试，不由模型看图猜数值。反向分析可描述透视、景深和画面关系，没有制作资料时不断言唯一镜头型号或精确焦距。摄影方案需要参数时提出待测试范围与实现目标；不让分析者猜出的数字反过来成为现场不可质疑的约束。
4. **焦点不只是"主体清楚、背景虚化"**：焦点转移可改变信息顺序；深焦允许多个行动同时存在；浅焦限制注意但也可能把本该被比较的人排除。讨论焦点时问"这时需要谁与谁同时被观察"，而不只是"这里要一次漂亮拉焦"。焦点在人物开始回应前就转走可改变场景的伦理与叙事位置；一直全清晰却无注意变化也可使关键转向难辨认——看完整时间而非静帧。
5. 遮挡可延迟发现，也可能只是构图问题；大景深保留多个行动，但观众是否注意仍受动作、光线、声音影响。
6. 任何方案检查它在演员实际移动后是否仍成立。
