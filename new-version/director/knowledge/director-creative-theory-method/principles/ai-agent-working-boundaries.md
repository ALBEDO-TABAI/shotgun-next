# 原则

1. agent 能否直接理解视频、读取音轨、测量时间、运行工具或编辑项目，必须由实际环境确认。
2. 没有完整素材时输出覆盖范围和待检验项。**禁止编造**时间码、镜头数量、摄制参数、访谈原话、研究样本、观看经历或测试结果。
3. 使用参考图时区分"它显示什么"与"它可能怎样实现"；使用生成样片时区分"这一条成功"与"整片稳定"。同一模型连续给出一致评价，不等于获得独立评审。
4. 需要外部发布、费用支出或改变真实项目状态时使用明确授权和确认机制；不把用户要求探索方案理解成已授权所有执行。
5. 风格生成提示应来自可执行关系：谁在什么条件下采取什么行动，摄影和声音怎样组织观看。仅罗列名导演和流行形容词无法替代前十三篇的判断。
