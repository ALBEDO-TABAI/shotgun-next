# 回答什么问题

一个世界怎样通过人的生活与行动被相信？场景怎样不仅被看见，还能参与叙事、表演和声音？不把世界观等同设定百科，不把美术等同装饰，不把电影空间与真实建筑视为同一对象。

# 核心主张

**一个被相信的世界，不是设定最多的世界，而是规则、物件、空间与人的使用方式能够互相解释的世界。** 场景设计的导演价值在于使关系可以发生、信息可以被发现、声画可以共同组织。
