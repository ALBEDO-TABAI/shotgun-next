# 主题枢纽 · Topics

每个源模块一个枢纽：回答什么问题、核心主张、本篇概念清单与跨篇交接。

# 01 导演风格识别
* [01 导演风格识别：从视觉标签到有证据的创作规则](01-director-style-identification.md) - 本篇枢纽：导演风格是有模式的创作选择而非外观标签；按概念边界→研究路线→分析尺度→条件规则→四类作用→八轴→混合→归因→证据→流程→量化→评价→接口的顺序组织。

# 02 导演职责与跨部门整合
* [02 导演职责与跨部门创作整合](02-director-role-and-integration.md) - 本篇枢纽：导演如何让不同人的专业判断形成同一件作品，而不是把所有判断集中在自己手上；职责拆分、权力区分、判断层级、共同问题接口、前期／现场／后期方法、案例与失效修复。

# 03 创作出发点与导演意图
* [03 创作出发点、导演意图与表达命题](03-creative-origin-and-intent.md) - 本篇枢纽：作品为什么从这里开始，兴趣如何变成具体选择，分析者怎样讨论意图而不替人编造动机；五种为什么、起点类型、命题四层、可检查对象、假设树、导演阐述、案例与诊断。

# 04 人物关系、表演与对白
* [04 人物关系、表演与对白导演](04-character-performance-dialogue.md) - 本篇枢纽：把人物从背景设定与情绪标签转化为可被演员执行、被对手影响、被观众辨认的行为；六层人物分析、对白双层、结果型指令改写、排练、选角、摄影剪辑对表演的影响、伦理边界。

# 05 世界观、空间与置景
* [05 世界观、空间与场景置景](05-world-space-set.md) - 本篇枢纽：一个世界怎样通过人的生活与行动被相信；场景怎样不仅被看见还参与叙事、表演与声音；世界观四件事、规则句式、五张关系表、三种空间、道具与服化的动作状态、介绍世界的方式、案例与评价。

# 06 信息分配、视点与留白
* [06 信息分配、叙述视点与留白](06-information-focalization-gaps.md) - 本篇枢纽：决定观众何时能够知道、推断、误解、怀疑或继续等待，而不把少说一点误认为自动高级；四层状态、观看位置五变量、五种没说、悬念好奇惊讶、最小可理解信息、载体代价、隐瞒边界、声音与字幕、案例。

# 07 桥段、场景行动与情节
* [07 桥段、场景行动与情节设计](07-setpiece-scene-action-plot.md) - 本篇枢纽：一个点子如何成为一段值得经历的行动；怎样让变化发生而不是让人物轮流解释变化；概念区分、场景价值来源、工作模型、冲突与阻力、因果检查、节拍转向、铺垫回收、桥段机制、案例、评价与重写。

# 08 叙事顺序、时间与节奏
* [08 叙事顺序、时间结构与节奏](08-order-time-rhythm.md) - 本篇枢纽：区分世界中事件怎样发生与作品怎样让观众经历它们；把节奏快慢拆成可观察可修改的变量；四种时间、顺序选项、时长五种模式、频率、六个节奏层级、认知与计量的边界、案例与诊断。

# 09 调度、摄影与画面
* [09 人物调度、摄影与画面表达](09-staging-cinematography.md) - 本篇枢纽：先决定观众怎样接近人物、行动和空间，再决定镜头如何实现；三种调度与三条路线、观看距离四层、镜头参数的认知边界、连续性作为资源、摄影机运动、长镜头与覆盖、案例、反向分析、平面与多画幅、接口。

# 10 灯光、色彩与氛围
* [10 灯光、色彩与氛围设计：从情绪标签到可拍摄、可延续的感知条件](10-lighting-color-atmosphere.md) - 本篇枢纽：导演如何与摄影、灯光、美术、服化和调色共同设计光与色，并使氛围在人物行动、镜头衔接及实际放映中成立；五件常被混写的事、色彩研究边界、五类灯光功能、讨论变量、颜色角色、技术可信、流程、案例、广告与生成、接口。

# 11 声音设计与音乐
* [11 声音设计、音效与音乐：组织一个与画面共同成立的听觉世界](11-sound-design-music.md) - 本篇枢纽：导演如何在构思、写作、拍摄和后期中安排听觉视点、声音事件、音乐与声画关系；要设计的是声音的全部工作而非配乐；基础区分、声音事件卡、声画关系、音乐七问、实证边界、前景接力、制作环节、案例、作曲协作、对照测试、可及性。

# 12 整体成片与媒介适配
* [12 整体成片、后期与媒介适配：让局部好选择在完整作品中共同成立](12-whole-film-post-adaptation.md) - 本篇枢纽：导演如何在剪辑、声音、调色、视觉效果、文字与交付之间完成整体判断，并把作品重构为广告、平面、剧情、纪录或展览版本；素材／版本／作品的区分、七个层面、剪辑阶段、批准关系、试映、广告与平面、纪录与实验、可及性、版本案例、返工诊断、交付卡。

# 13 导演个性、表达与伦理
* [13 导演个性、个人表达与创作伦理：从可识别外观到可承担的选择](13-personality-expression-ethics.md) - 本篇枢纽：如何理解和发展导演的个人表达，怎样评价其发现力与形式选择，如何处理作者性、协作和创作关系；个人／作者／风格／声誉四对象、作者论限度、五个独立判断、表达从哪里生长、四层联系、坚持与修改、三重伦理检查、事实责任、案例、批评方法、训练、章程。
