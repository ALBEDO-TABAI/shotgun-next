# 触发

提炼导演出发点、写导演阐述、解释创作动机、从简报形成方案、判断形式与意图是否一致、重构过于笼统的主题。

# 最小输入

材料与版本、项目任务、已知事实、允许的开放度、现有方向、主要限制。没有主创自述时可分析作品功能，但不得伪造真实意图。

# 处理

拆开主题、任务、观察与效果目标；找出至少一个具体创作问题；形成真正不同的方案；把方案拆成必要事实、开放解释和体验假设；建立验证路径；明确当前确认与待发现部分。

# 输出

工作性导演阐述；命题转译表；意图假设树；证据与未知；两种以上可比较的组织路径（确有必要时）；最小试验；不能擅自作出的商业、伦理或制作批准。

# 质量门禁

- 引用名导演不替代问题定义。
- 声称意图必须有来源。
- 效果目标不能冒充测试结果。
- 开放解释不能掩盖基础信息缺失。
- 多个方案必须在组织关系上不同，而不是只改形容词。
- 未经资料支持的产品事实保留待核，而不是编造后投入剧情。
