# Skill 接口 · Skill Interfaces

各模块的触发、最小输入、处理、输出与质量门禁，以及统一接口。

# 01 导演风格识别
* [Skill：导演风格识别与创作规则提炼](skill-director-style-identification.md) - 触发、最小输入、核心过程、必须输出与质量门禁；任务或证据不支持作者归因时允许以作品层风格描述为最终成果。

# 02 导演职责与跨部门整合
* [Skill：导演跨部门创作整合](skill-director-integration.md) - 输入项目目的、材料版本、主创与批准关系、限制、争议与本轮范围；输出一页任务说明、共同问题表、取舍记录、可执行试验、版本与批准边界、下一责任人；门禁与规模缩放规则。

# 03 创作出发点与导演意图
* [Skill：创作出发点提炼与导演阐述](skill-creative-origin-and-intent.md) - 触发：提炼出发点、写导演阐述、解释创作动机、从简报形成方案、判断形式与意图一致性、重构笼统主题。输出工作性阐述、命题转译表、假设树、证据与未知、可比较路径、最小试验。

# 04 人物关系、表演与对白
* [Skill：人物关系、表演与对白导演](skill-character-performance-dialogue.md) - 输入场景文本、上下文、已知事实、表演风格、拍摄条件、已有视频；输出人物当前行动卡、关系图说明、对白修改建议、可执行指导、两至三个试演差异、观察指标与未确认项；五条门禁。

# 05 世界观、空间与置景
* [Skill：世界观、空间与场景置景](skill-world-space-set.md) - 输入场景任务、人物关系、必要事件、现实／虚构程度、视听材料、场地与制作限制；输出最小世界规则、空间行动说明、道具状态表、取舍、需核对的生活事实、部门共同问题、测试与验收方法；五条门禁。

# 06 信息分配、视点与留白
* [Skill：信息分配、视点与留白设计](skill-information-design.md) - 输入作品版本、上下文、可访问声画范围、项目类型、开放度、必要事实、观众与发布条件；输出信息状态表、揭示表、留白说明、可读性风险、替代方案与代价、测试问题；五条门禁。

# 07 桥段、场景行动与情节
* [Skill：桥段与场景行动设计](skill-setpiece-scene-action.md) - 输入段落任务、人物与已知信息、初始与目标状态、空间与资源、文本或素材、媒介、伦理与事实限制；输出桥段说明、前后状态表、行动节拍、必要铺垫、声画职责、替代方案、风险与小规模验证；五条门禁。

# 08 叙事顺序、时间与节奏
* [Skill：叙事顺序、时间结构与节奏](skill-time-structure-rhythm.md) - 输入事件事实与不确定项、呈现版本、场景功能、目标时长、声画材料、观看条件、需保留的复杂性；输出时间结构说明、功能与时长依据、重排候选及代价、需补的过渡、节奏诊断、版本删改依赖、测试方法；五条门禁。

# 09 调度、摄影与画面
* [Skill：人物调度、摄影与画面表达](skill-staging-cinematography.md) - 输入场景功能、人物与空间关系、信息要求、参考材料及覆盖范围、画幅与媒介、现有素材、资源限制；输出镜头意图表、调度说明、关键可见信息、连续性与有意偏离、覆盖用途、未知技术参数、测试方法、跨部门问题；五条门禁。

# 10 灯光、色彩与氛围
* [Skill：灯光、色彩与氛围设计](skill-lighting-color-atmosphere.md) - 输入作品任务、场景行动、空间与时间条件、实际材料或参考范围、摄影与交付限制、必须准确的产品或人物信息；输出氛围论述、关键光色关系表、联合测试结论、连续性说明、技术交接项、未验证风险及回退原则；门禁不是够不够电影感。

# 11 声音设计与音乐
* [Skill：声音设计、音效与音乐](skill-sound-design-music.md) - 输入作品任务、场景行动、信息图、可用画面与音轨、观看条件、音乐与录音资源、授权和交付限制；输出听觉阐述、声音事件表、配乐任务书、入点退出表、需拍摄或补录素材、对照结果、交付检查与未知项；六条门禁。

# 12 整体成片与媒介适配
* [Skill：整体成片、后期与媒介适配](skill-whole-film-post-adaptation.md) - 输入明确版本、素材范围、创作与商业任务、批准关系、真实交付要求、已知问题和可修改资源；输出整体诊断、变更清单、保留与放弃的理由、版本差异、交付检查、未解决限制和发布条件。

# 13 导演个性、表达与伦理
* [Skill：导演个性、个人表达与创作伦理](skill-personal-expression-ethics.md) - 输入作品或作品集合、明确版本、相关比较条件、主创资料、任务与制作边界、分析目的；输出作者倾向假设、证据与例外、分层评价、协作贡献边界、个人表达发展方向、伦理风险与可执行替代方案；五条门禁。

# 14 拉片研究与迭代工作流
* [导演创作 Skill 统一接口：十三个模块 Skill 的共同输入、处理骨架、输出与总门禁](skill-director-unified-interface.md) - 所有模块 Skill 共享：输入必含明确版本、材料覆盖范围与分析目的；处理骨架为区分身份→建立条件关系→形成对照→在完整声画中复核→记录决定与未知；输出必含覆盖范围与待检验项；总门禁禁止编造、禁止把解释当事实、禁止把意图当效果、禁止把单帧当整片。
