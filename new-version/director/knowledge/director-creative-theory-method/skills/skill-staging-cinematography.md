# 最小输入

场景功能、人物与空间关系、信息要求、参考材料及其覆盖范围、画幅与媒介、现有摄影或测试素材、资源限制。

# 处理

定义观看任务→分别设计人物、摄影机和镜头间调度→检查可见性、连续性与例外→明确声音和美术依赖→比较候选→用实际动作试验→复核多版本。

# 输出

镜头意图表；调度说明；关键可见信息；连续性与有意偏离；覆盖用途；未知技术参数；测试方法；跨部门问题。

# 质量门禁

- 不能从单帧断言完整运镜。
- 不能把所有长镜头称为一镜到底实拍。
- 不能把主观镜头等同认同。
- 不能把设备名当作风格解释。
- 没有测试不得承诺精确实现与技术安全。
