# 最小输入

作品或作品集合、明确版本、相关比较条件、主创资料、任务与制作边界、分析目的。

# 处理

区分作品与人格→建立条件性规则→调查协作归因→分离识别、组织、任务与价值判断→检查反例→检查制作与发行关系→提炼可迁移关切及其边界。

# 输出

作者倾向假设；证据与例外；分层评价；协作贡献边界；个人表达发展方向；伦理风险与可执行替代方案。

# 质量门禁

- 不从成片诊断作者人格。
- 不以声誉替代证据。
- 不把合作者隐去。
- 不把个人表达用作伤害或误导的豁免。
- 不把所有作品强行解释为同一主题。
