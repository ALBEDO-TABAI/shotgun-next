# 最小输入

明确版本、素材范围、创作与商业任务、批准关系、真实交付要求、已知问题和可修改资源。

# 处理

完整观看→区分问题层级→生成最小对照→检查跨部门影响→重新观看整片→分版本验证→确认批准与交付。

# 输出

整体诊断；变更清单；保留与放弃的理由；版本差异；交付检查；未解决限制；发布条件。

# 质量门禁

- 七个层面各有状态，不相互抵消。
- 四条判断线各有清楚结论，必要时保留"不适用"或"未核实"。
- 被观看、被批准、被发布的对象可建立可靠对应。
- 短版有自己的任务与验证，不借长版观看者的补足。
