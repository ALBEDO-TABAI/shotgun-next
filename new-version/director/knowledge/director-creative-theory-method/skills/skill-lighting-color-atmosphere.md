# 最小输入

作品任务、场景行动、空间与时间条件、实际材料或参考范围、摄影与交付限制、必须准确的产品或人物信息。

# 处理

拆开感受与手段→识别可见性任务→建立光色角色与变化→联合测试→看完整声画→核对输出链→记录选择与例外。

# 输出

氛围论述；关键光色关系表；联合测试结论；场景连续性说明；技术交接项；未验证风险及回退原则。

# 质量门禁

- 关键行动可读。
- 光色变化与项目目标有关系。
- 产品及人物没有非预期失真。
- 不同观看条件下的风险被明确。
- 没有用色彩联想研究冒充任意观众反应的保证。
