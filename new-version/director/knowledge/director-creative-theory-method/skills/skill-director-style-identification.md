# 职责

对作品、作品集合或参考材料形成有证据的形式画像，区分局部模式和作者倾向，输出可供创作检验的规则。

# 触发

分析导演风格、判断"像谁"、拆解参考片、比较作者或团队、评估混合风格、从案例提取创作方法。需要完整剧作、摄影或声音实施方案时转交相应模块。

# 最小输入

研究问题；材料与可访问范围；作品版本；比较对象或参考范围；已知任务与限制；输出用途。信息不全时缩小范围并记录未知项；不为填表虚构观看、版本、镜头或制作事实。

# 处理

界定概念与尺度 → 记录完整体验与客观特征 → 建立八轴中相关的证据 → 提出条件规则 → 比较基线与反例 → 调查协作者与生产条件 → 分别写出观察、解释、意图、效果、评价 → 输出可迁移原则。

# 输出

结论摘要（条件性描述）；证据与覆盖范围（材料、时间段、版本、是否实际观看）；规则画像（手段组合、条件、时序、例外）；比较与归因；未知与反例；创作转译（可迁移机制、不可照搬的表面、适用条件、验证方式）。

# 质量门禁

- 不通过：未分清影片风格与导演长期风格；无可定位证据却声称完整拉片；把单帧推成运动／剪辑／声画结论；把观众理解和情绪写成未经测试的普遍必然；把主创陈述当效果证据，或将文献分析伪装为本次独立观察。
- 需修订：只有支持例子、没有反例或外部基线；只给导演名和形容词、写不出一条有条件的规则。
- 允许：以"作品层风格描述"为最终成果。
