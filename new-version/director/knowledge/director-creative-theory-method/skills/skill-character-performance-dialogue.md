# 最小输入

场景文本、上下文、人物已知事实、表演风格、拍摄条件、已有视频及覆盖范围。只有文字时，只能评价潜在行动和对白组织，不能判定演员实际倾听或成片表演。

# 处理

事实／推断分离→关系分析→行动与策略变化→对白双层标注→排练候选→跨部门可见性检查→边界确认。

# 输出

人物当前行动卡；场景关系图的文字说明；对白修改建议及理由；可执行的演员指导；两至三个必要的试演差异；观察指标；未确认项。

# 质量门禁

- 不得以人格诊断代替角色分析。
- 不得把微表情当作真实心理的确定证据。
- 不得把"更真实"自动等同自然主义。
- 不得建议越过同意边界。
- 不得声称文本分析已验证了表演效果。
