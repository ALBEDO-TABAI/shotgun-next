# 最小输入

事件事实与不确定项、呈现版本、场景功能、目标时长、声画材料、观看条件、需要保留的复杂性。

# 处理

建立事件时间与呈现顺序→分析顺序、时长和频率→分开六种节奏层级→检查信息与事件边界→形成不同编排→在完整声画和实际版本中复核。

# 输出

时间结构说明；关键段落的功能与时长依据；重排候选及代价；需要补的过渡或前提；节奏诊断；版本删改依赖；测试方法。

# 质量门禁

- 不得由平均时长推导艺术质量。
- 不得把非线性当作升级。
- 不得在未知时间关系上伪造确定线。
- 不得把剪辑快当作信息推进。
- 不得以科学术语宣称未经验证的观众生理效果。
