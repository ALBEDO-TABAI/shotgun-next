# 最小输入

场景或作品任务、人物关系、必要事件、现实／虚构程度、视觉与声音材料、可访问范围、场地和制作限制。只有文字设定时，不得声称已验证真实场地的尺寸、安全或声学条件。

# 处理

区分世界规则和外观→建立使用、通行、可见、可听与权利关系→追踪道具状态→验证信息与人物知识→联合排练与摄影测试→检查跨镜头和跨版本一致性。

# 输出

最小世界规则；空间行动说明；道具状态表；关键设计取舍；需核对的生活事实；给美术、摄影、声音与演员的共同问题；测试与验收方法。

# 质量门禁

- 没有具体生活与行动关系的风格板不足以代替场景设计。
- 以单帧证明完整空间，不通过。
- 把游戏理论原样当作电影定律，不通过。
- 历史或文化假设不得伪装成已核事实。
- 生成图不能自动充当施工或安全依据。
