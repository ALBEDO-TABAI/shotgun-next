# 共同最小输入

明确版本或作品范围；材料覆盖范围（全片／片段／截图／剧本／简报）；分析或创作目的；工作模式（聚焦分析／项目开发／深度研究／版本诊断）。

# 共同处理骨架

区分陈述身份（观察／资料／证言／解释／接受／评价）→建立条件关系（在什么条件下什么组合怎样变化）→形成少量真正不同的对照→在完整声画与实际版本中复核→记录决定、代价与未知。

# 共同输出

除各模块特有输出外，必含：材料覆盖范围与缺失；未确认项与待检验项；本次不展开的范围。

# 总门禁

- 不编造时间码、镜头数量、参数、原话、样本、观看经历或测试结果。
- 不把功能解释当制作事实；不把创作意图当已实现效果。
- 不从单帧断言运镜、剪辑、时长或声画；不从单片断言作者人格。
- 不以声誉、设备名或流行形容词替代证据。
- 不把个人表达用作伤害或误导的豁免。
- 外部发布、费用或改变真实项目状态需明确授权。
