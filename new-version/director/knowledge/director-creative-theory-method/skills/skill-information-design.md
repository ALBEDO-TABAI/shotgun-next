# 最小输入

作品或脚本版本、完整上下文、可访问声画范围、项目类型、想保留的开放度、必要事实、已知观众与发布条件。

# 处理

建立世界／人物／观众线索三层状态→标出疑问、答案和更新→检查揭示依赖与注意机会→比较多种分配方式→检查人物行为合理性、声画语气与实际版本。

# 输出

信息状态表；关键揭示表；留白说明；可读性风险；替代方案与代价；测试问题；不能由现有材料确定的意图或受众效果。

# 质量门禁

- 不从摘要声称已核对所有铺垫。
- 不把剧本写了当作成片看得见。
- 不以"观众应该懂"代替证据。
- 不把人物隐瞒与作者信息遮挡混同。
- 不把反转、悬念或含蓄当作通用于所有媒介的优先目标。
