# 要点

| 类型 | 机制 | 提醒 |
|---|---|---|
| 选择型 | 在真实不相容的事情之间作出选择 | 难度来自代价，不是选项看起来都很戏剧化 |
| 发现型 | 新证据改变已知关系 | 重点是发现前后行动怎样不同 |
| 协调型 | 多人完成同一任务却有不同知识、节奏或目标 | 合作、喜剧、劳动、群像；不必总有反派 |
| 失败与修复型 | 第一次办法失败，人物改变方法 | 改变要产生认识或关系后果，避免同一笑料简单放大 |
| 重复变奏型 | 同一动作或形式重复，条件和意义变化 | 广告、组照、音乐影像、非叙事段落 |
| 显露后果型 | 事件在画外，场景关注承受与处理 | 不是"没有戏"，而是把中心放在结果 |

## 四种生成入口

任务（多人需在离开前拍一张合照）；不能同时满足的愿望（想被承认又不愿被突出）；空间限制（所有人都能看见主角却只有一个人能与其说话）；形式参数（稳定重复的动作逐渐改变执行者）。起点还不是完整桥段——继续确定谁行动、遇到什么、为什么改变、观众通过什么认出变化、是否影响后续。若桥段已让一种关系被重新看见，不必再添加隐藏身份或意外事故证明"有戏"。
