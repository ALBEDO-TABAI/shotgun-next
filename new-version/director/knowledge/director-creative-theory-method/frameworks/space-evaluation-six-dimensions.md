# 要点

| 维度 | 问题 |
|---|---|
| 生活可信度 | 物件、磨损、使用与维护是否有关系（不是"旧东西越多越真"） |
| 行动可用性 | 演员能否完成所需行为，空间是否提供阻力或机会 |
| 信息可读性 | 作品希望观众知道的关系是否可见或可听 |
| 形式组织 | 重复、边界、材质和空间变化是否进入整体 |
| 制作可实现性 | 摄影、录音、安全、复位、特效与版本需求能否满足 |
| 伦理与事实边界 | 真实地点、文化材料与产品暗示是否被准确处理 |

# 适用边界

- 不能无条件相加成总分；按作品类型决定权重。
