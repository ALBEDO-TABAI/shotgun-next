# 要点

| 共同问题 | 主要参与者 | 本轮需形成的结论 | 下一环节如何使用 |
|---|---|---|---|
| 人物为什么此刻改变策略 | 导演、编剧、演员 | 行动目标、触发、不能提前出现的反应 | 排练与表演取舍 |
| 哪个动作必须完整可见 | 导演、演员、摄影、美术 | 人物位置、道具状态、视线、可见范围 | 机位与场景搭建 |
| 哪种环境声不能丢 | 导演、录音、剪辑、声音设计 | 声源、时间关系、备用采集方案 | 拍摄及声音编辑 |
| 产品怎样进入表达 | 导演、创意、品牌、摄影 | 信息依据、出现功能、不可误导之处 | 场景、包装及版本检查 |
| 哪个段落可被压缩 | 导演、剪辑、制片、批准者 | 核心证据与可删部分 | 短版重构而非随意截断 |
| 临时变化影响了什么 | 相关主创、制片、副导演 | 变更范围、代价、当前批准状态 | 更新所有被影响的执行材料 |

只有当某问题确实跨部门时才组织相关人员；纯技术实现细节由负责人员在已确认边界内决定。

**接口的质量不在于字段多，而在于接收者知道自己应依据哪条决定做什么。**
