# 要点

| 失败身份 | 表现 | 对策 |
|---|---|---|
| 观察失败 | 作品围绕未经核对的生活假设（以为某职业总用某动作，实际不成立） | 回到资料、访谈或实践观察，不能只加强表演 |
| 问题失败 | 问题太空泛，任何情境都能套入（"表达美好"） | 缩小为具体矛盾，或承认主要是形式展示并改用相应标准 |
| 转译失败 | 关切清楚，但所选情境不能使其发生 | 重选行动关系，不增加解释性对白 |
| 实现失败 | 情境有效，但关键线索在画面或声音中没被读到 | 进入摄影、表演、剪辑或声音的具体修订 |
| 接受差异 | 观看者理解了作品但不认同或不喜欢 | 可能是重要反思，也可能是可保留的分歧；不自动归为技术失败 |

分开五种身份，减少"每次反馈都重写全部作品"与"永远只修最后一个镜头"两种极端。
