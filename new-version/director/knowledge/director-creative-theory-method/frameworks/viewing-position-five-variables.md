# 要点

| 维度 | 问题 | 提醒 |
|---|---|---|
| 知识范围 | 观众比某人物知道更多、更少还是不同？ | 具体到某件事，不给整部作品永久等级；知识关系常交叉：知道危险所在却不知主角为何坚持 |
| 接近深度 | 是否进入记忆、梦、内心言语或感官经验？ | 主观镜头让我们看见所见却不告诉怎样理解；远景加内心声音也可能很接近；接近≠相信≠道德认同 |
| 信息来源 | 现场观察、人物陈述、文件、回忆、他人转述、作品另行提供？ | 不把所有信息当透明事实，也不因经人物叙述就一律怀疑 |
| 注意机会 | 大小、时长、竞争动作、字幕、声音、观看设备 | 不能用逐帧暂停发现的小字证明首次观看已公平提供答案 |
| 评价位置 | 给某人更多时间、反应或解释机会是否影响判断？ | 可讨论的作用，不是机械结果 |
