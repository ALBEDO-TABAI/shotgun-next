# 要点

| 模块 | 核心任务 | 与相邻模块的边界 |
|---|---|---|
| [01 导演风格识别](/topics/01-director-style-identification.md) | 识别条件性风格规则 | 不把单片外观直接归为终身作者人格 |
| [02 导演职责与跨部门整合](/topics/02-director-role-and-integration.md) | 界定导演与各部门的决策协作 | 不替代具体合同或专业实施 |
| [03 创作出发点与导演意图](/topics/03-creative-origin-and-intent.md) | 将出发点转为表达问题 | 不把意图当成已实现的效果 |
| [04 人物关系、表演与对白](/topics/04-character-performance-dialogue.md) | 组织人物行动、表演与对白 | 不只写性格或情绪标签 |
| [05 世界观、空间与置景](/topics/05-world-space-set.md) | 建立世界运行与空间行动条件 | 不把置景等同于漂亮背景 |
| [06 信息分配、视点与留白](/topics/06-information-focalization-gaps.md) | 设计信息、视点与留白 | 侧重知识分配，而非全部时间节奏 |
| [07 桥段、场景行动与情节](/topics/07-setpiece-scene-action-plot.md) | 发展桥段及场景变化 | 不强制所有内容成为因果故事 |
| [08 叙事顺序、时间与节奏](/topics/08-order-time-rhythm.md) | 组织顺序、时长、频率与节奏 | 不只统计镜头平均长度 |
| [09 调度、摄影与画面](/topics/09-staging-cinematography.md) | 设计调度与观看关系 | 不从单帧反推唯一摄影参数 |
| [10 灯光、色彩与氛围](/topics/10-lighting-color-atmosphere.md) | 组织光色与氛围条件 | 不把色彩词当成情绪定律 |
| [11 声音、音效与音乐](/topics/11-sound-design-music.md) | 组织声音、音效与音乐 | 不把配乐当成后期情绪补丁 |
| [12 整体成片与媒介适配](/topics/12-whole-film-post-adaptation.md) | 完成整体与不同媒介版本 | 不把局部最优误作整体最优 |
| [13 个性、个人表达与伦理](/topics/13-personality-expression-ethics.md) | 评价与发展个人表达 | 不把声誉、人格、伦理和作品价值混成一项 |
| [14 拉片、方案与迭代](/topics/14-film-study-director-plan-iteration.md) | 研究、交接、试验、迭代与交付 | 不创建冗余事实源或伪装已执行的工具能力 |

## 按问题调用

不知道作品到底在做什么→01、03；人物行动不成立→04、06、07；空间与声画关系失配→05、09—11；完整版本或不同媒介不能成立→08、12；评价个人表达与工作关系→13。

单次执行范围由问题决定：只问一段对白为何不自然，不需要先完成导演生涯风格史。先检查最低充分修复，不把每个局部问题升级为重新设计整部作品。

## 任务路由句式

> 当前问题是【可定位现象】；主要影响【理解／关系／形式／实现／交付】；已有材料支持先检查【模块及变量】；若出现【具体证据】，再转入【关联模块】；本轮不展开【无关或材料不足的范围】。

例："第二十秒开始显得重复，先检查信息是否已由动作完成、对白是否再次复述；若删减后人物转向失去依据，再检查该动作的可读性，而不是立即要求摄影重拍。"人工团队也可用一句清晰任务描述完成同样控制。
