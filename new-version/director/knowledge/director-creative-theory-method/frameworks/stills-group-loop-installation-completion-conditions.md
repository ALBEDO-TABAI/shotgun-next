# 要点

| 形态 | 完成条件 |
|---|---|
| 单张平面 | 观看者不一定按预计次序阅读；关键关系尽可能在单图内部成立：主体、动作、物件、文字的层级是否清楚，裁切后有没有必要参照，细节是否只能放大后辨认。一张图的情境可能由标题或旁边另一张决定；不把"纯净构图"当全部交付而忽略商品页、海报、轮播、直播画面。某个电影镜头依赖前后文，抽成海报后只剩模糊情绪——平面的导演性工作是重新安排这个瞬间的证据 |
| 组照 | 可有指定顺序也可能被平台拆分；每张能否独立承担最低信息，哪些意义只有连续观看才出现；重复可能有节奏作用，也可能只是没有选掉近似素材 |
| 循环影像 | 结尾同时是下一次开头；接缝是隐藏、强调还是允许；渐强音乐结尾接回安静开头可能每轮都像被打断，也可能是有意的形式事件；必须在至少一次完整回环中观看 |
| 安装与展示环境 | 是否需要重复定位信息、是否接受部分观看成为主要经验，在构思阶段决定；针对条件的设计推演，不是关于展览观众行为的统计结论 |

横幅改竖版时人物距离、道具位置和文字空间都可能变化——裁切不仅是尺寸工作，也可能是关系重写。
