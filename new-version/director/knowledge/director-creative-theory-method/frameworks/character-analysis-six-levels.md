# 要点

| 层次 | 问题 | 提醒 |
|---|---|---|
| 已确认事实 | 年龄、职业、关系、经历、此刻地点与已知信息 | 区分文本明确事实／合理推断／团队新增；背景写得厚≠演员有更多可用信息；不影响当前行动的设定暂不占排练中心 |
| 当前需要 | 此刻想得到什么具体变化：被原谅、获得许可、拖延离开、确认对方还关心、掩盖失误、结束谈话 | "想得到爱"太宽→他要对方现在做哪件事才会暂时相信被爱？但矛盾与犹疑也可以是工作材料 |
| 关系与地位 | 谁有权提出请求？谁可以不回答？谁习惯照顾谁？地位来自制度、家庭习惯、知识差还是当下局面？ | 同一人可以控制房间钥匙却在情感上等待认可 |
| 策略与行动 | 劝说、安抚、诱导、挑衅、拖延、试探、转移、保护、拒绝 | 动词必须有对象与条件："你在威胁她"→用什么后果？希望她怎样变？真打算执行？她相信吗？ |
| 身体与环境条件 | 做饭、打包、维修、站立等待；道具位置、衣服限制、椅子距离、房间嘈杂 | 服务于行动，不附加无关难度；让人真的听不清、真的受伤不是必要方法 |
| 自我解释与他人解释 | 人物认为自己在关心，别人体验为干涉 | 演员从人物自己的合理性出发，作品通过关系和后果显示更复杂的意义 |
