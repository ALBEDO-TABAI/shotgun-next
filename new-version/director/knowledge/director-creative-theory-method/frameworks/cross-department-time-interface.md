# 要点

| 部门 | 提供 |
|---|---|
| 编剧 | 事件与因果，不只给时长估计 |
| 演员 | 动作真实需要的时间及可改变部分 |
| 摄影 | 镜内变化与移动条件 |
| 声音 | 进入、持续、转移注意的时间结构 |
| 剪辑 | 把这些放进整体 |
| 制片 | 版本和交付限制 |

**动态预演**不能只用静态图匀速播放：关键动作、文字、对白和声音至少以近似时长出现。预演可验证阅读时间与信息连接，未必预测演员细微关系、真实材质和最终音乐的作用；说明每次测试代表什么。

## 音乐节拍与剪辑

- 有节拍的音乐提供时间参照，但不意味着每次切镜都落在重拍：切在前、切在后、跨越乐句、暂时不切各成不同关系。
- 先确定哪些动作、信息或情绪转向需要被时间化，再决定音乐提供稳定、推动、延迟还是对照。
- 音乐为配合每个镜头不断改变、镜头又为音乐不断改变→没有上层目标的循环。保留一种基线版本用于比较。
- 临时音乐的节奏不应未经讨论就锁定全部表演长度；画面锁定后若没有空间完成必要音乐结构，重新讨论声画共同方案。
