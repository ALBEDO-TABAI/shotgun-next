# 要点

| 身份 | 合适表述 | 不能自动证明 |
|---|---|---|
| 观察 | 在指定版本和时间段，声音先于人物出现 | 谁决定这样做、所有观众怎样理解 |
| 制作资料 | 摄影师访谈称方案在预演后作过修改 | 完整决策链、最终受众效果 |
| 意图证言 | 导演表示希望保留关系的含混 | 成片确实达成含混，或含混一定有价值 |
| 机制／意义解释 | 该组合可能延迟观众对动机的判断 | 对全部观众成立的因果 |
| 接受材料 | 在说明条件的某次观看中，受访者作出某种解释 | 其他文化、场合或人群必然如此 |
| 评价 | 在明确任务下，这种延迟带来何种收益与代价 | 无条件、跨任务的普遍高低 |

**覆盖身份**："某论文分析认为本片存在某模式"是文献事实，不是本次重新拉片证实的事实。预告片剪辑不等于正片；剧照不必等于发行版画面。

**信心**："高把握观察""中等把握机制解释""低把握个人归因"可并存。不给整个画像虚假统一置信度；模型自报的"87%"不是校准概率。
