# 要点

- 实践上问：谁有权提出修改；谁需要被咨询；谁批准创作版本；谁批准产品或事实内容；谁批准费用和交付；谁可以发布。
- 文件写着"final"不能证明以上已全部完成。批准应指向明确版本与明确用途。
- 客户要求与导演主张冲突时同时记录两个事实：某版本被批准发行；某项创作担忧仍然存在。不把被批准等同于所有人审美一致，也不把个人异议伪装成版本未完成。

## 对象一致性

导演批准了带临时字幕的预览片，技术人员替换正式字幕重新导出——新文件仍应检查字幕是否对应当前画面、是否遮挡动作、是否改变阅读时间、声音和结尾是否完整。客户同时收到旧链接和新文件时明确哪个供审、哪个供发。链接名"最终版"不构成版本依据；文件时间最新不自动意味内容正确。修正一处错字不必重新争论全部艺术选择，但确认没有引入连带错误；若字幕改动实际改变了产品条件或人物身份，不再是纯技术修正。**被观看的版本、被批准的内容和被发布的文件之间应能建立可靠对应。**
