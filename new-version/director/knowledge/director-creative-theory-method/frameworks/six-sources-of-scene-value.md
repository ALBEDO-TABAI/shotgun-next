# 要点

| 变化 | 内容 | 提醒 |
|---|---|---|
| 目标进展 | 更接近或远离想做的事 | 不必顺利，也不必每次都失败 |
| 关系变化 | 请求变命令、怀疑变合作、照顾变许可、亲近变距离 | 要有行为证据，不是只在编剧说明里改标签 |
| 知识变化 | 人物或观众获得新信息，旧行动被重新理解 | 可能没有外部大场面 |
| 资源与责任变化 | 谁拿到钥匙、谁签字、谁承担损失、谁失去离开的机会 | 比情绪形容词更容易构成明确转向 |
| 感知与形式变化 | 重复动作渐显差异、声音从背景到前景、空间由熟悉变陌生 | 不硬套目标与障碍，追踪观看经验怎样被改变 |
| 余波与停留 | 看似没有新事件的时间让观众接触后果 | 不因"没有推进"删去；也不因"留白"免于检查是否形成新的注意与理解 |
