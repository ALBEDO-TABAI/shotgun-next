# 要点

| 层 | 内容 | 提醒 |
|---|---|---|
| 物理距离 | 摄影机离人物多远 | 不把演员需要的工作空间完全当作构图变量 |
| 画面尺度 | 人物占画面多大；与物理距离、焦距、裁切共同有关 | 决定哪些细节有机会被看见，不直接决定观众是否同情 |
| 信息接近 | 是否获得人物视线、感知、记忆和反应 | 身体近景可仍限制动机；远景配某种声音可提供大量内在信息 |
| 判断距离 | 是否允许观众自行比较关系，还是通过反应、音乐与剪辑倾向一种解释 | 没有机位天然中立；保持距离不自动等于伦理优越 |

四层分开，避免"更近＝更有情感""更远＝更尊重人物"。
