# 要点

| 标准 | 问题 |
|---|---|
| 具体性 | 是否属于这组人物、物件、空间和任务，而非任何角色替换都不变 |
| 行动可信度 | 每一步在当时信息和需要下是否可能；是否依靠人物突然失去判断力 |
| 变化可读性 | 观众能否认出重要差异，还是只在梗概里成立 |
| 后果连接 | 这段是否改变后面，或以其他明确方式贡献整体 |
| 形式与情节关系 | 摄影、声音和节奏是否让变化发生，而不只是强调 |
| 复杂性与边界 | 是否把人物压成按钮；是否通过虚假的牺牲、伤害或误导获得廉价效果 |

不是通用加权分数；不同作品选择不同价值，但评价应说明选择及代价。
