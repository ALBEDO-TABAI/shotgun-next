# 检查清单 · Checklists

症状—先查什么—修复方向表，以及压力测试与问题改写表。

# 01 导演风格识别
* [把评价改写为可分析问题：冷峻、留白、电影感、真实、模仿、混搭、音乐救活、一定感动](evaluation-to-analyzable-question.md) - 八条常见评价说法各对应一条更精确的研究问题。

# 02 导演职责与跨部门整合
* [跨部门整合的常见失效与针对性修复](integration-failure-repair-table.md) - 八种失效（成片吵、导演反复说不对、只执行不反馈、现场推翻方案、版本打架、后期靠音乐补救、客户意见叠加、导演成瓶颈）各列先核对什么、优先修复、不宜先做什么。

# 03 创作出发点与导演意图
* [错误诊断：导演阐述听起来正确，作品仍然不成立](statement-sounds-right-work-fails.md) - 八种表现（主题宏大场景空、人人说同一道理、画面符合参考意义漂移、留白致基础事件不可辨、每次试映全改方向、用访谈意图反驳观众、商业内容硬塞、真实成为冒险理由）对应可能问题与下一步。

# 04 人物关系、表演与对白
* [表演诊断与修改优先级：症状—优先核对—可试修订](performance-symptom-repair-table.md) - 先查场景行动与信息，再查对手关系与环境，再查演员任务可执行性，最后微调表情节奏；八种症状：等台词、情绪过早、说明书对白、动作多却空、细腻看不见、越排越僵、同一口吻、真实任务吞掉关系。

# 05 世界观、空间与置景
* [空间与置景的常见失误与修复](space-failure-repair-table.md) - 样板间、设定多观众仍迷惑、道具像刻意伏笔、地理关系不断变化、演员动线别扭、环境声只能后期救、历史感只是符号堆叠、抽象空间被批不真实——原因与修复方向。

# 06 信息分配、视点与留白
* [信息设计的常见失误诊断](information-design-failure-table.md) - 结尾必须解释一大段、人物能看到却没反应、反转令人觉得被耍、留白变成没看懂在干什么、全片只有疑问没有进展、多通道重复同一句、无声版失去故事、字幕提前泄露——问题与修复。

# 07 桥段、场景行动与情节
* [桥段的常见失败与修复](setpiece-failure-repair-table.md) - 有设定没发展、转折突然、情绪满关系没变、所有桥段一样、配角只负责阻挠、结尾靠巧合、回收像做题、产品突然出现——诊断问题与修复方向。

# 09 调度、摄影与画面
* [摄影与调度常见问题与修复顺序](cinematography-common-problems-repair-order.md) - 镜头都美场景却没关系、观众漏看关键动作、运镜无理由、切换顺畅情绪空、长镜头中段停滞、多画幅剪坏关系、近景越拍越像强调、参数精确却不可复现——先查的层级与可行方向。

# 10 灯光、色彩与氛围
* [光色常见失误与更有针对性的修复](lighting-color-common-mistakes-repair.md) - 没有氛围、脸不好看、产品不高级、颜色不统一、画面太平、暗部看不清——先排查什么、不宜立刻采取的动作（无条件降曝光加雾加蓝、磨掉所有纹理、无限加高光慢动作、套同一处理、只加对比、用克制为技术错误辩护）。

# 11 声音设计与音乐
* [诊断：不要让声音承担它无法独自修好的问题](sound-cannot-fix-alone-diagnosis.md) - 转折突然、人物不可信、段落松散、情绪过度、空间不成立、字幕剧透——可能需要先修复的层面与声音可以怎样参与（强化已存在的动作不捏造原因、保留倾听的真实时间、用声部变化组织阶段但不假装有事件、分配主次延迟音乐判断、调整来源而非换素材、核对揭示时序兼顾可及性）。
