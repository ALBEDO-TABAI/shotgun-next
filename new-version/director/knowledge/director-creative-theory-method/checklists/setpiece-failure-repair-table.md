# 清单

| 失败 | 诊断问题 | 修复方向 |
|---|---|---|
| 有设定，没有发展 | 人物是否真正尝试并收到回应 | 给目标、限制和策略变化 |
| 转折突然 | 是否缺少条件或前面行动 | 补因果与知识，而不是加煽情音乐 |
| 情绪很满，关系没变 | 后续仍能完全照旧吗 | 改责任、要求或可行动范围 |
| 所有桥段一样 | 是否只使用同一冲突模板 | 换机制，允许协调、发现或形式变化 |
| 配角只负责阻挠 | 对方有没有自己的合理任务 | 写双方成本，而非只加反派强度 |
| 结尾靠巧合解决 | 主角选择是否仍有作用 | 让前面条件参与结果，或明确偶然主题 |
| 回收像做题 | 是否过度突出所有伏笔 | 保留普通生活，减少机械重复 |
| 产品突然出现 | 产品与行动是否可互相替换 | 重构桥段机制，而非末尾多给特写 |
