# 清单

| 表现 | 先查的层级 | 可行方向 |
|---|---|---|
| 镜头都美，场景却没关系 | 行动与观看任务 | 重做调度和注意分配 |
| 观众漏看关键动作 | 可见性与竞争信息 | 改位置、时长、焦点或声画主次 |
| 运镜显得无理由 | 运动与任务的关系 | 比较静止及不同起止点 |
| 切换顺畅但情绪空 | 场景变化与表演 | 不把连续性当成全部质量 |
| 长镜头中段停滞 | 镜内任务是否更新 | 重排行动、改变注意或允许剪辑 |
| 多画幅剪坏关系 | 适配从末端才开始 | 预先验证必要关系与独立版本 |
| 近景越拍越像强调 | 反应是否过早或重复 | 恢复共同空间或调整信息位置 |
| 镜头参数写得精确却不可复现 | 参数来源不明 | 用真实测试和元数据，不猜测 |
