# 清单

| 失误 | 更可能的原因 | 修复方向 |
|---|---|---|
| 场景像样板间 | 只有外观，没有使用与维护逻辑 | 从人物的一天反推必要痕迹 |
| 设定很多，观众仍迷惑 | 信息没有进入行动与观看 | 明确必需事实的载体和出现机会 |
| 道具像刻意伏笔 | 出现方式只为未来解释 | 给它当前功能，或减少突出 |
| 地理关系不断变化 | 镜头各自设计，没有共同空间关系 | 建立关键位置与通行约束 |
| 演员动线别扭 | 布景先定，行动后塞 | 先用临时空间排练，再微调搭建 |
| 环境声只能后期救 | 空间设计未考虑可听关系 | 前期确定重要声源和采集方案 |
| 历史感只是符号堆叠 | 未区分时期、阶层与使用情境 | 补资料，删除无依据的显著元素 |
| 抽象空间被批"不真实" | 评价目标未区分 | 明确形式规则，不套生活场景标准 |
