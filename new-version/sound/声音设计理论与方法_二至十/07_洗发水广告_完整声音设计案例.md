# 七、用洗发水广告设定，完整推演从想法到声音时间线

> 对应原十点体系的第七点。本篇不是再列一套抽象理论，而是把前六篇的判断转化为一份可供导演、作曲、声音设计、剪辑、混音与 agent 共同使用的案例蓝图。
>
> 资料核查日期：2026-09-18。沿用对话中的梦幻、轻快、清爽、愉悦、蓝绿色、茶叶、泡沫与 118 BPM；30 秒是前文案例采用的教学片长，不是已核实的真实项目硬要求。所有镜头、声轨、文案窗口和交付参数均为本篇明确提出的假设。未提供真实影片，未生成音频，未完成试听、授权或观众测试。

## 1. 先建立信息边界，避免案例变成虚构的项目事实

| 类型 | 当前内容 | 工作处理 |

| 本次可以完成 | 任务拆解、方向选择示范、拍点算术、声音关系、brief、检查与交付计划 | 属于设计文件。 |

这里的未知不是阻止构想的理由，而是规定构想的证据身份。可以假设有一段 4 秒旁白，却不能断言真实文案一定能自然说完；可以设计叶片声音，却不能暗示产品确含某种未经提供证明的成分。

## 2. 把目标写成变化，而不是形容词集合

本案把体验轨迹暂定为：**接近一个细节 → 进入微观想象 → 看见细节形成秩序 → 理解必要信息 → 体验舒展 → 回到产品与品牌。**

“梦幻”在这里被解释为现实起点与非现实延展之间的连续转化，而不是全程长混响。“轻快”被解释为运动可跟随、事件有间隙，不是不断增加打击。“清爽”被解释为从细密局部到较少竞争、较大舒展的关系，而不是简单提高高频。“愉悦”被解释为探索得到温和满足，而非强烈庆功。

这些定义是本案选择，不是词语的普遍含义。音乐情绪研究说明参数与被感知情绪存在可研究关系，但材料和测量范围有限，不能证明本案某种配器必然产生清爽。[^EER]

商业层的目标另行记录：产品需要在最后被明确识别，必要信息需被听懂，感官幻想不能替代功效证据。音乐动机被记住与品牌被记住是不同结果，不能在案例中自动画等号。

## 3. 提出三条真正不同的方向

**A：日常护理的亲密。**以手、瓶身、水与真实空间为主，音乐轻量。它强调体验可进入、人物与产品有具体生活关系。若画面大量超现实变形，需要额外解释两种现实程度怎样统一。

**B：微观植物世界的轻盈幻想。**叶片、水滴和泡沫的行为逐步转为音乐。它强调从细节到空间的连续变化，适合本案想象中的微观镜头，但可能滑向甜腻、玩具感或湿黏联想。

**C：时装装置式的清爽秩序。**用精确节奏、有限材料、明显停顿回应产品和头发运动。它可以利落，但若处理过硬，可能把舒展转成紧绷或竞技感。

本案选择 B 继续推演，因为它与“从物体细节进入幻想”的教学目标最一致；这不是受测观众证明的优胜方案，也不是对洗发水品类的普遍推荐。真实项目应在代表段落里比较，广告音乐契合及听众涉入本来就需要结合条件讨论。[^MAC]

## 4. 声音命题与四条不可替代的规则

**声音命题：不是用一次巨大冲击证明清爽，而是让微小声音逐渐形成轻盈秩序，再让这种秩序舒展开来。**

第一，音乐与物体声在行为上相互联系。相似的起音、短尾或运动方向可以成为联系，不必每次都使用同一条采样。

第二，变化主要来自事件密度、音区、配器和空间交接，而不只来自整体变响。这里不是禁止动态变化，而是防止把“展开”简化为响度递增。

第三，只为主要动作设计清楚落点。次要泡沫和每次切镜不自动获得独立强调，以免微观世界变成连续提示音。

第四，幻想要回到产品实体。最后的声音保留具体对象与身份，不继续漂移成与品牌无关的抽象尾声。

这些规则可以用于否定方案。例如一条开头满鼓、结尾巨响的音乐即使好听，也与当前命题冲突；若导演想改成宣告式广告，就应修改命题，而非在旧命题下不断例外。

## 5. 先区分声音现实，不让每层都处于同一种距离

本案采用三种听觉关系：现实锚点、转化材料、音乐结构。

**现实锚点**包括叶片轻动、液滴脱离、产品接触和必要人声。它们帮助观众理解正在发生的动作，不要求所有细节都严格纪录式写实。

**转化材料**从现实声的形态出发，逐渐拥有更明确的音高、重复和空间。它们处于事件与音乐之间，不必强行归入一种固定类别。

**音乐结构**负责跨镜组织体验，保留短动机和节拍参照。其存在应能与转化材料相连，而不是突然换成另一部片子的背景音乐。

Smalley 的形态描述提供了观察声音如何由孤立事件变成纹理的语言。[^SMA] 本案的三层及转化顺序是应用设计，不是原论文提出的广告流程。

## 6. 时间计算：30 秒不自然等于整数个 4/4 小节

本案规定四分音符为一拍，固定 118 BPM。因此：

```text
一拍时长 = 60 / 118 = 30 / 59 ≈ 0.508474576 秒
一小节时长 = 4 × 30 / 59 = 120 / 59 ≈ 2.033898305 秒
12 小节 = 48 拍 = 1440 / 59 ≈ 24.406779661 秒
明确音乐拍点起始 = 3.000000000 秒
12 小节结束 = 3 + 1440 / 59 ≈ 27.406779661 秒
到 30 秒剩余尾部 = 153 / 59 ≈ 2.593220339 秒
```

这里的分配是：3 秒声音入口，12 小节有拍结构，约 2.593 秒收束尾部。前 3 秒可以已经有来自物体的音高材料，但不把它标成已建立的主拍。

尾部并不要求持续 2.593 秒混响。它是可使用的结束窗口，可以先让音乐短尾完成，再留少量空间；也可以由产品现实声和短动机共同收束。是否好听尚待制作。

本篇数值按分数计算，显示小数是派生值。真实项目改变片长、音乐起点或拍单位后，应重算，不手动修补各行使其表面相加。

## 8. C01：先让耳朵靠近，不急着告诉观众“这是一条广告”

画面假设为叶片与液滴细节。主要任务是让一个小动作值得被注意，不是立即展示完整音乐高潮。

声音候选包括轻微叶片运动、一个具体液滴事件，以及极少量周围空气。不要把普通微观镜头铺成森林全景，也不要给液滴加巨大落点。声音尺度应与本案亲近、细致的命题相容。

音乐可以完全不出现，或只在液滴尾部保留尚不能明确听成乐句的短音。两者应作为可比较版本，而不是认为没有音乐就一定更有品质。

**硬锚点**只在明确设计为同一事件的液滴接触等位置设置；实际动作帧未提供，不能填写真实帧号。**软锚点**是注意被收拢后再出现音乐延展。验收关注：观众是否注意到细节，是否感到声音与动作相连，有没有不必要的沉重或黏腻。

## 9. C02–C03：让音乐从材料中生长，而不是突然铺上来

C02 在第 3 秒建立音乐参考，但前两小节不必直接上完整鼓组。可以由少量短音和间隙暗示拍点，让原先可辨认的物体声开始有组织地回应。

C03 的第 3–4 小节增加轻量节奏层，微观泡沫与植物运动获得更清楚的推进。这里增加的是可跟随关系，不是所有声部都更繁忙。主音色可保持圆润音头、细碎短尾；具体乐器尚未锁定。

**动机假设。**采用一个短小节奏轮廓作为识别核心，例如两个短动作之后一个较长回应。前段可以只出现部分，后段再完成。是否需要明确音高、采用什么音程，都留给作曲与试听；不把一组音程宣称为“天然清爽”。

**音效关系。**少量主泡沫动作与节奏相关，次要泡沫仅形成低调纹理或不强调。若每颗泡泡都对应高音短响，容易出现游戏奖励或玩具联想，这是需要检查的风险，不是已发生结果。

## 10. C04：给信息以真正的空间，而不只是降低总音量

本案暂设实际旁白主要落在 12–16 秒，处于 C04 窗口内。真实文案尚未提供，这个区间只是容量假设，不代表任何具体句子一定能自然说完。

进入 C04 前，音乐减少新的前景旋律事件；可以保留拍点与较稳定支撑，避免体验突然中断。音效不在每句中间重复大型强调，产品主动作若与语言冲突，应明确谁优先，必要时调整剪辑或文案位置。

语言内容必须由产品事实与已审定文案决定。本案不编写未经证据支持的“深层修复”“有效治疗”等承诺，也不把茶叶画面自动当作真实成分证明。

如果后来确认没有旁白，C04 不应简单照搬原来的空档。可以成为材质或产品动作的重点段，但需要重新安排音乐发展，使其不是一段为不存在语言预留的能量凹陷。

Berklee 的作曲课程将音乐与影像任务、对白等协作纳入专业训练。[^BER] 本案的具体保护窗口与配器方案仍属设计选择，不能由课程大纲推断已经保证可懂度。

## 11. C05：把“舒展”做成结构变化

C05 的目标不是突然更响，而是从细密局部转为连续、柔软、较开阔的运动。画面可假设为头发或水流逐渐舒展，但不能当作真实分镜已锁定。

音乐可让短动机更完整，延长部分声部的运动，同时减少此前过多颗粒。密度减少与音域展开可以并存；“更饱满”不必等于同时新增多个乐器。

音效从单个泡沫事件转向柔软摩擦与气流。可以探索非头发来源的材料，但保留掠过的连续性，不引入鞭打、厚重织物或巨大风暴的尺度。实际素材来源与听感分别记录。

这里适合检验“清爽”的项目定义：观众是否经历到从细密到舒展，还是只感到音量突然升高？如果后者突出，应回看前段与交接，而不是继续提高亮度或加更多高音。

## 12. C06–C07：让品牌收束与前文有关系

C06 逐渐撤去最活跃打击，保留产品实体与短动机。产品放置或姿态稳定可以获得一个清楚、适度的动作声，但具体锚点必须以实际画面为准。

C07 不再展开新的旋律主题。可使用此前动机的简化或完成形态作为候选声音身份，并让尾部在 30 秒内有意结束。它尚不是经过认知测试的品牌声音标识，也不是已完成版权检索的原创资产。

若真实品牌已有获准使用的声音标识，应优先研究它与新材料如何连接，而不是为了一致性擅自改写既有标识。若新标识的制作属于本项目范围，应另设识别、独特性与权利检查。

避免同时出现音乐结尾、产品撞击、闪光提示、品牌提示与转场冲击五个“最后强调”。可以共同强调，但需说明它们怎样被听成一个收束，而不是五个争夺结束的声音。

## 13. 作曲蓝图：四类材料及其行为

| 材料角色 | 行为设定 | 主要出现位置 | 排除项 |
|---|---|---|---|
| 短动机 | 圆润短音、清楚但不尖锐，允许部分出现 | C02 建立，C05 展开，C06–07 回收 | 过强儿歌感、持续占据旁白。 |
| 节奏层 | 轻量、能跟随、有间隙 | C03 明确，C04 收敛，C06 退出 | 每镜必落重拍、持续厚重踢鼓。 |
| 和声／持续支撑 | 稳定世界，不抢逐字理解 | C03–05 为主 | 过量长尾把主体推远。 |
| 运动／转化层 | 在现实事件与音乐之间连接 | C01–03 与 C05 交接 | 与物体毫无关系的连续转场模板。 |

这些是功能角色，不是必须四条轨，也不是四种固定乐器。实际工程可以更多或更少，但应能解释哪些文件承担哪个角色，并保留必要的独立控制。

对和声可提出“前段不急于完整落地、体验段更明确、结尾完成”的结构要求，不预先声称某种大小调最适合产品。对演奏可要求有限变化，但关键动作关联稳定，避免把随机时值误差当作有机感。

## 15. 三份可以直接用于委托的文字 brief

### 给导演／策划

本案的声音从可辨认细节进入微观幻想，再从颗粒化运动转为连续舒展。开头不以大冲击抢注意；产品信息段以理解优先；结尾通过前文材料回收形成身份。不以听觉手段暗示未经证实的产品功效。需要确认真实旁白、品牌标识、主要动作及传播条件。

### 给作曲与声音设计

固定 118 BPM，四分音符为一拍，4/4。明确拍点从 3 秒开始，12 小节到约 27.407 秒，其后为结束窗口。前两小节从现实短声形成动机；第 3–4 小节建立轻律动；第 5–7 小节减少新的前景事件保护语言；第 8–10 小节展开动机与连续运动；第 11–12 小节收束，尾部不新增主题。保持材料亲缘，不将所有泡沫动作做成独立音高提示。

### 给生成／素材探索环节

生成或寻找能用于“微观细节逐渐形成轻盈秩序”的材料候选：圆润短音、细密但不刺耳的颗粒、柔和持续层、连续而轻的摩擦。目标不是完整商业成片。分别提供材料用途、可用时长与希望独立控制的部分；不能保证的精确拍速、分轨、尾部、无语言或权利事项，返回时明确为未验证，不以文件名代替事实。

三份文本共享同一目标，但粒度不同。给生成环节的说明不是要求模型代替导演决定产品信息与品牌立场。

## 16. 混音策略：安排前景，再决定技术目标

本案前景顺序暂定为：细节事件 → 转化关系 → 轻节奏 → 必要人声 → 连续运动与音乐 → 产品与短动机。各层不是永久前景，也不应在所有段落保持相同活动。

信息段先通过编配和事件减少让位，再检查是否需要动态处理。若只有把音乐压得几乎听不见才能听清旁白，可能是配器与语言本身冲突，而不仅是混音技术问题。

空间上，可以让主体音头相对近，尾部承担有限展开；不过度把所有声音放进同一巨大混响。产品实体返回时，空间关系应足以让观众重新理解对象，而不是只留下抽象宽声场。

技术上，ITU-R BS.1770 的响度与真峰值算法可作为测量依据之一，但并不指定本案统一发布电平。[^1770] 最终声道、采样率、位深、响度、峰值和尾部规范应按真实目的地确认。

若为教学先设立体声、48 kHz、24 bit，可作为内部交换假设，不能写成所有广告的唯一标准。没有真实输出文件，当前也不能声称这些参数已满足。

## 17. 视频帧与音频拍点：不要把小数显示当成实际同步

本案目前用秒和音乐位置设计，未获得真实帧率。若后来选 25 帧／秒，仅作为一个示例，则最近帧量化的最大时间偏差为半帧，即 0.02 秒；但这只是数学上最近帧取整的界限，不是所有声音都能容忍的同步标准。

音乐的精确拍点不需要全部吸附到帧边界。画面动作可以在帧上确定，音频内部仍按采样时间保持拍速。关键是哪些声音需要与动作作为同一事件，哪些只是软性情绪或段落变化。

假设 C03 的显示边界为 7.068 秒，其精确值来自节拍计算；不要把 7.068 当作第二个独立真相，长期手动更新。媒体时间、帧索引和小节位置应有明确映射与来源。

这能避免一个常见交接问题：导演按秒确认、作曲按小节修改、剪辑按旧帧号移动，三个字段分别“正确”却不再指向同一位置。

## 18. 15 秒与 6 秒版本：保留关系，不是单纯压缩

短版本需要重新决定任务数量。不能默认把 30 秒音频加速或截短，就保留了同样体验和音乐身份。

**15 秒教学方案。**可保留约 1 秒具体细节，随后使用 6 小节，即约 12.203 秒，最后剩约 1.797 秒收束。这个计算只说明时间可容纳，不代表实际听感成立。结构可压缩为“细节—体验—产品”，必要信息若过多应另行取舍。

**6 秒教学方案。**可采用约 0.4 秒入口，2 小节约 4.068 秒，余约 1.532 秒用于结尾。重点可能只保留一个动作关系与一个身份回收，不再试图建立完整微观旅行。

两个版本都需要检查动机出现与品牌联系，不能仅复制结尾标识。真实平台对片长、片尾和信息的要求应另查，本文不假设投放渠道已经确定。

长短版可以共享资产和规则，但审批应分别对应实际版本。30 秒版通过，不自动证明 6 秒版的旁白可懂、动作同步或尾部完整。

## 19. 测试计划：把“看起来像清爽”与实际结果分开

本案建议先做三轮不同目的的检查，而不是一次问“你喜欢吗”。

**关系原型轮**：以粗材料测试现实到音乐是否连续、前景交接是否清楚。允许音质未精修，但不能比较一个完整方案与一个缺层方案后归因到风格。

**适配轮**：用接近完成的视听版本，先开放询问观看体验、注意对象与产品理解，再询问轻盈、舒展、甜腻、湿黏等候选描述。目标词不先告诉听者，以免回答被提示。

**交付轮**：在实际预期设备和播放场景中检查信息、单声道或声道变化、尾部、突变、字幕相关声音说明。W3C 的可访问性指南提醒，媒体可访问性涉及重要声音信息的表达，不只是把对白转成文字。[^WAI]

这些是计划，没有样本、测试日志和实际音频时，不报告“多数观众”“提升百分比”或“已验证清爽”。小规模反馈可以揭示问题，但不能自动预测转化或总体受众偏好。

## 20. 失败模式与具体返修方向

| 观察到的问题 | 可能原因，需验证 | 优先返修 |
|---|---|---|
| 听起来像儿童动画 | 短音音区、发音、规则过于玩具化 | 先改发音与节奏语言，不必推翻整体微观命题。 |
| 泡沫显得黏腻 | 近距离湿声过多或尾部过长 | 减少口腔式／黏连细节，重选材料尺度。 |
| 旁白难懂 | 多层同时新增信息或空间覆盖 | 先减活动，再检查混音与语速。 |
| 体验段只有更响 | 前文缺少结构准备或材料变化不足 | 重做交接、音区与密度关系。 |
| 结尾像突然停止 | 乐句与文件边界冲突 | 改写收束或尾部，不只套淡出。 |
| 记得音乐却不记得产品 | 动机与产品行为／名称缺少联系 | 重审身份建立与品牌呈现，而非只重复旋律。 |
| 幻想与实体像两条片子 | 材料和空间缺少过渡 | 找共同动作或音色行为，设计返回路径。 |

这些不是已发现的真实缺陷，而是预先建立的诊断方向。真正返修时需指向具体版本、位置和证据，不能把表中的可能原因当作已经确定的根因。

## 21. 实施后的交付计划：哪些应成为文件，哪些应成为记录？

本篇交付的是蓝图，不包含下列尚未制作的音频。进入生产后，可按真实需求安排主混音、音乐版本、必要声音分组、语言版本和参考视频，并同时提供当前画面版本、点位表、资产来源与审听记录。

音乐分组需说明它们是原始制作导出，还是由主混音进行源分离所得的估计。后者可能有串音或处理痕迹，不能改名为“原始分轨”消除不确定性。对白去除版也不自动等于完整国际化音乐音效版，可能仍有现场声音缺失需要补齐。

权利记录需区分作品、录音、样本、声音表演与品牌标识等相关对象，并按实际地区和用途核查。美国版权局对作品与录音的区分可作为基础参考，但不能替代个案合同。[^COPY]

批准必须绑定具体文件或版本。修改了音乐尾部、替换了资产或改变旁白后，原来批准哪些仍有效、哪些需要重验，应在交接中说明。

## 22. 案例回看：这套方案真正的设计在哪里？

它不在于选择了某种合成器或给提示词加了“梦幻”。核心设计是：音乐从可辨细节获得材料身份；旁白段不新增竞争；体验段通过减少颗粒和延展运动完成变化；产品实体与短动机在最后回收；每种效果都留下测试与修改入口。

其中任何一项都可以改。例如真实画面是日常人物使用而不是微观奇观，就可能转向 A；若真实品牌需要利落宣告，可以重写命题选择 C。可复用的是推演方法与数据关系，不是要求所有洗发水广告照抄这条时间线。

一个案例只有在把假设、选择、代价、实施依赖与验证边界一起展示时，才适合作为 skill 的训练材料。只展示一张看似完美的秒表，会让下游误以为创作判断已经全部确定。


## 23. 将纸面案例推进到首轮声音原型：先验证三处接力

进入制作后，不必立刻精修全部三十秒。可以先制作三个与核心命题有关的局部关系，再回到完整片段。

**入口接力：现实水滴到音乐短动机。**需要同时准备一个可辨水滴锚点和一个保持某些发音特征的音乐回应。先比较它们是否被体验成同一材料的展开，再讨论哪一层音色更漂亮。如果联系没有建立，添加更多植物声未必有帮助。

**信息接力：音乐活动减少，旁白成为前景。**这里应使用真实的暂定录音，而不是仅按文字字数想象时长。先检查句首、关键内容和句尾的需要，再确认 C04 的配器活动。最终文案变化后，此处必须复核。

**返回接力：体验空间回到产品实体。**让柔软连续的运动逐渐让位于明确、但不厚重的产品动作声，再由短动机收束。检查是否像同一作品的返回，而不是广告结尾突然插入另一段标志音乐。

三处关系原型不等于三段独立成片。局部通过后，仍要检查它们在完整时间线中的积累：开头是否承诺过多，中段是否已经用尽变化，结尾是否有足够空间。

## 24. 当真实输入与教学假设不一致时，怎样修改本案？

本案把旁白暂定为十二至十六秒，并为其提供更宽的 C04 支撑区间。这不是旁白合同，更不是根据中文平均语速推定的必然可行值。

如果真实录音延续到十八秒，它会与 C05 的释放开始重叠。至少可以考虑三条路径：经批准调整文案或表达；延后释放但保留片尾任务；让释放先通过画面和稳定音乐发生，等语言结束再增加新的音乐事件。

三条路径改变的对象不同，不能由声音 agent 默默选一条后通知其他部门“已解决”。应比较所需修改、保留目标和代价，再更新受影响点位。

如果最终画面没有茶叶近景，S01 等材料不必因为蓝图曾经列出就强行保留。可以把“细小现实事件逐渐音乐化”的规则转移到水、瓶身或其他实际存在的动作，而不是让声音暗示不存在的配方成分。

如果画面最终更接近日常人物生活，则应重评是否仍采用 B 方向。可复用的规则是材料联系、前景交接与身份回收；微观幻想不是必须保留的教条。

## 25. 时间线的复算片段：计算只验证数学，不验证听感

下面的 Python 代码使用标准库精确分数，复算本案例固定拍速下的边界。它不读取或生成音频，也不替代实际剪辑的帧率和拍点核对。

```python
from fractions import Fraction

bpm = 118
beats_per_bar = 4
music_start = Fraction(3, 1)
film_end = Fraction(30, 1)
bar_seconds = Fraction(60 * beats_per_bar, bpm)

# 每段使用的小节数分别为 2、2、3、3、2，共十二小节。
bars_by_cue = [("C02", 2), ("C03", 2), ("C04", 3),
               ("C05", 3), ("C06", 2)]
cursor = music_start
intervals = [("C01", Fraction(0), music_start)]
for cue_id, bars in bars_by_cue:
    end = cursor + bars * bar_seconds
    intervals.append((cue_id, cursor, end))
    cursor = end

assert cursor <= film_end, "音乐主体超出片长，需重新设计。"
intervals.append(("C07", cursor, film_end))
assert all(a < b for _, a, b in intervals)
assert all(intervals[i][2] == intervals[i + 1][1]
           for i in range(len(intervals) - 1))
for cue_id, start, end in intervals:
    print(cue_id, f"{float(start):.3f}", f"{float(end):.3f}")
```

代码输出的小数只作阅读显示，精确关系仍在分数计算中。进入实际工程后，音乐速度改变、引子弱起或表演时值偏离都需要反映在真实节奏映射里，不能继续套用这段固定 BPM 示例。

## 26. 从本案提炼可以迁移、也可以否定的规则

最值得迁移的不是“洗发水一定用短音和颗粒”，而是四种关系：让材料身份在前后出现中可追踪；把关键语言视为有具体窗口的信息；用密度与运动关系组织释放；让品牌结尾回收此前已经存在的特征。

每条规则也有反例。若作品的目标是刻意制造品牌插入的突兀感，结尾不连贯可能是所需形式；若整片没有语言，就不必预留相同的旁白结构；若材料本身需要宏大尺度，细小颗粒也不是正确选择。

把规则和适用条件一起保存，才能让后续 skill 根据新任务重新推演，而不是把一次案例误学成整个品类的标准答案。
