# 概念

和声变化速度（harmonic rhythm）≠ BPM。118 BPM 下可四拍换一次和声，也可两小节才换一次，或保持同一低音只让上方局部移动。

# 任务

1. 复制一段八小节草稿，**旋律与节拍不动**。
2. 做三版：
   - A：每小节换和声
   - B：每两小节换和声
   - C：低音持续，只改变一个内声
3. 放进画面比较：推进感究竟来自和声、节奏，还是配器？

# 延伸：增加发展不一定多换和弦

- 让原本不被注意的内声逐渐显露；
- 把持续音的作用从"稳定"转为"阻力"。
