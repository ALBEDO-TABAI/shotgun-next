# 清单（每个新声部）

- [ ] **为什么由它演？**
- [ ] **为什么在这个音区？**
- [ ] **它怎样开始和结束？**（起音、持续、释放）
- [ ] **它与现有声部是融合还是区分？**
- [ ] 数量：独奏还是分组？
- [ ] 力度记号能否在该乐器、该音区自然实现？（Belkin：写下力度记号 ≠ 乐器与音区自然能实现）
- [ ] 具体弓法、指法、可演奏性是否已与演奏者核对？不知道时**不伪造专业标记**。

# 反例："柔软的弦乐"不是完整指令

长音、短弓、拨弦、弱音器、独奏或分组、靠近哪种发音状态——都会使实际声音不同。

# 前景与伴奏

- Belkin：通过**音色、音区和节奏的对比**突出独奏者，而不是始终把伴奏降到几乎没有。
- 本包迁移到广告人声（创作迁移，非该教材对广告的实验）：需要话语清晰时，先检查伴奏活动是否与话语同时竞争。
