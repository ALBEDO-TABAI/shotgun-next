# 检查顺序（本包综合，非强制插件链）
- [ ] **1 时间**：两者是否一直在时间上重叠？能让装饰晚一点"说话"，就不必挖掉它的存在感。
- [ ] **2 音区与持续方式**：是否过于相似？换伴奏排列或缩短尾部，可保留音色又减少竞争。
- [ ] **3 电平与自动化**：只有一句需要后退，就不必整首降低。
- [ ] **4 EQ／动态处理**：对仍存在的具体频率问题处理。有清楚的共振、齿音、轰鸣时直接处理也合理——**不是禁止先用 EQ**。

# 选频提示
- 在素材**与整体中**定位问题。
- 窄带：定位某些持续共振；宽曲线：改变整体倾向。
- 不要按统一的"200–400 Hz 浑浊""3 kHz 清晰"表格加工所有声音。
