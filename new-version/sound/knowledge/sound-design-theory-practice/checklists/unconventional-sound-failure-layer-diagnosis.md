# 五个层级
| 层级 | 症状示例 | 修改方向 |
|---|---|---|
| 来源联想 | 泡沫被听成黏液 | 换材料，不必放弃微观幻想 |
| 动作对应 | 接受了材料，但不知道哪个动作重要 | 调整落点与注意分配 |
| 时间结构 | 变化太早／太晚、缺少建立 | 调整段落与强度轨迹 |
| 叙述立场 | 关系理解了，但品牌态度显得轻浮 | 重审命题 |
| 项目边界 | 暗示了不存在的性能、事实误导 | 按项目边界收回 |

# 规则
- 一次修改针对**当前最有依据**的层级，保留未变部分，避免把所有创意重新随机化。
- 结论不是"越真实越安全"或"越特别越有创意"，而是保留产生具体表达收益、代价可接受的偏离。
- 无法说明收益的复杂处理可以删除；暂未成功但任务明确的构想可以继续针对关系改进。
