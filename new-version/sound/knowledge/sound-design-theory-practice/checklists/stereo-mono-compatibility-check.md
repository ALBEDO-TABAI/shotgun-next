# 检查
- [ ] 主声音需要多稳定的位置？哪些材料可以在两侧展开？
- [ ] 关键旁白或动作**不只依赖侧向差异**才存在。
- [ ] 主动折叠为单声道：主旋律、低音、动作是否明显失去内容？
- [ ] 若问题来自扩宽或延迟处理：减少它，或保留更稳定的主体（不把所有左右差异都当缺陷）。
- [ ] 相位相关表只作线索，**以实际听辨为准**。
- [ ] 在实际目标设备或合理替代设备上检查；**记录真实听过哪些条件**，不凭空保证手机外放表现。
