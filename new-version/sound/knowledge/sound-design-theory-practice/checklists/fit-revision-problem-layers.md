# 层级 → 修法
| 问题层级 | 典型表现 | 修改方向 |
|---|---|---|
| 目标 | 方向与作品目标矛盾 | 回到方向选择 |
| 关系 | 叙述距离、入点、声源归属不对 | 改入点、叙述距离或声源归属 |
| 结构 | 乐句未完成、高潮太早 | 调整结构 |
| 材料 | 音色、配器、具体曲子不对 | 换音色、配器或曲目 |
| 呈现 | 与对白、音效的空间冲突 | 调整空间与平衡 |

# 规则
- 不总从成本最低的一层修上层问题：品牌要可信日常，声音命题却是超现实胜利宣告，**降两分贝不会让方向变正确**。
- 反之，问题只在旁白区太密时，推翻全曲会造成不必要返工。

# 高质量反馈格式
> 当前位置发生了什么 → 与哪个目标矛盾 → 优先改哪一层 → 改后用什么检查
