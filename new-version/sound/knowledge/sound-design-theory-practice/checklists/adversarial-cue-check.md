# 正向检查（过度或错位）
- [ ] 这个入点是不是**仅因为这里有切镜**？
- [ ] 音乐是否在观众还没理解事实时就**替其下结论**？
- [ ] 音效是否强调了不重要的转场，却**漏掉真正关键动作**？
- [ ] 片尾是否技术上没超时，却把**乐句截成未完成**？
- [ ] 所谓留白是否**只是某条素材漏出**？
- [ ] 是否存在**上一个版本的音乐尾巴仍覆盖新旁白**？

# 反向检查（过度防御）
- [ ] 为避免煽情，是否删掉了作品**需要的明确态度**？
- [ ] 为保持自然，是否让**关键来源根本无法辨认**？
- [ ] 为尊重乐句，是否**忽略了片长和信息目标**？

> 好的时间设计不是永远克制，而是每次强调和省略都有可说明的理由。
