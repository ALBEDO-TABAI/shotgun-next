# 清单

| 问题 | 只能由什么回答 | 理论包能提供什么 |
|---|---|---|
| 哪些具体声音能完成目标？ | 真实画面与播放条件下的试验 | 功能、适配、描述、时间线框架 |
| 哪些效果属于目标受众？ | 适当的受众研究 | [对照测试与评价链](/topics/09-sound-evaluation-acceptance.md) |
| 哪些文件满足交付？ | 按约定规范实际测量 | [技术验收方法](/topics/09-sound-evaluation-acceptance.md)、[ITU-R BS.1770](/references/itu-bs-1770.md)、[EBU R128](/references/ebu.md) |
| 哪些素材可以发布？ | 项目对应的许可与批准 | [权利对象区分](/topics/10-ai-team-sound-collaboration.md)、[版权说明](/references/copy.md) |

# 使用时自查
- [ ] 某项研究的支持，是否被误当成全部模板已被实证？
- [ ] 复杂或高成本用途，是否保留了任务级试验和专业审查？
- [ ] 工具能力、素材许可、交付合同、目的地规范是否已按具体项目重新核对（示例参数不是平台通用标准）？
- [ ] "计划时间"、"技术同步"、"符号正确（如 MIDI）" 是否被当成听感或商业效果已验证？
