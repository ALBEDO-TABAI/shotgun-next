# 改写表
| 模糊词 | 需要追问的差异 | 可执行的改写示例 |
|---|---|---|
| 轻 | 音量小、重量小、密度少，还是动作敏捷？ | 主体短音收尾快，不加入大体积低频落点。 |
| 圆润 | 音头不尖、频谱柔和，还是连续平滑？ | 降低刺出的瞬态，保留短音起点的清楚程度。 |
| 通透 | 层次可分、混响少，还是高频多？ | 先减少持续竞争层，让前景动作及其尾部可区分。 |
| 有机 | 材料自然、时值有变化，还是像在生长？ | 让密度随动作变化，但保留可辨认的共同运动。 |
| 梦幻 | 来源模糊、时间延伸，还是空间不现实？ | 现实音头清楚，尾部逐渐转成非现实持续层。 |
| 高级 | 克制、精确、独特，还是符合某种社会联想？ | 明确采用"少数事件、精细变化、避免模板落点"的方向。 |

# 使用规则
- 表中改写是**候选解释**，团队使用前应确认它确实符合表达目标。
- 选定的解释应写成**项目内约定**（见 [描述校准过程](/methods/description-calibration-process.md)），而不是通用定律。
- 相关词"更干""柔软"的多义拆解见 [柔软的三种制作说明](/cases/soft-three-production-notes.md)。
