# 依据
W3C WAI 的媒体无障碍指导涉及字幕、重要非语言声音信息和音频描述[2]：对理解有意义的声音不限于对白；视觉信息也可能需要其他路径提供。

# Checklist
- [ ] 某个剧情揭示完全依靠画外声音时，字幕是否保留了必要信息？又是否**过早泄露**身份？
- [ ] 一条静音浏览的广告，关键品牌与事实信息是否仍有合理的呈现路径？
- [ ] 旁白、对白和音频描述是否会**争夺同一窗口**？
- [ ] 是否只是在结尾写"支持字幕"就视为解决？（不行）
- [ ] 艺术上有意的含糊，是否被机械地在字幕里解释得一清二楚？（避免；应共同设计可达性与揭示时机）

# 边界
这些是制作检查问题，**不据此推断任何地区或渠道的法律义务**。
