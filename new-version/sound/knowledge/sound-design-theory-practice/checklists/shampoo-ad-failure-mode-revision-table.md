> 证据身份：预先建立的诊断方向，**不是已发现的真实缺陷**。真正返修需指向具体版本、位置和证据。

| 观察到的问题 | 可能原因（需验证） | 优先返修 |
|---|---|---|
| 听起来像儿童动画 | 短音音区、发音、规则过于玩具化 | 先改发音与节奏语言，不必推翻整体微观命题 |
| 泡沫显得黏腻 | 近距离湿声过多或尾部过长 | 减少口腔式／黏连细节，重选材料尺度 |
| 旁白难懂 | 多层同时新增信息或空间覆盖 | 先减活动，再检查混音与语速 |
| 体验段只有更响 | 前文缺少结构准备或材料变化不足 | 重做交接、音区与密度关系 |
| 结尾像突然停止 | 乐句与文件边界冲突 | 改写收束或尾部，不只套淡出 |
| 记得音乐却不记得产品 | 动机与产品行为／名称缺少联系 | 重审身份建立与品牌呈现，而非只重复旋律 |
| 幻想与实体像两条片子 | 材料和空间缺少过渡 | 找共同动作或音色行为，设计返回路径 |
