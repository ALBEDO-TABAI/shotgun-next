# Checklist
- [ ] **因果动词**：所有"让、使、导致"的句子，表达的是设计目标、合理解释，还是实际因果结果？需要哪个等级的依据？
- [ ] **意图句**：所有"导演为了、作曲家想"的句子，是否有对应一手来源？
- [ ] **技术名词**：是否真的确认了乐器、调式、拍速、滤波或空间格式？"听起来像"是否在后文悄悄变成"实际上用了"？
- [ ] **概括范围**：片段结论是否被扩大到全片？某部作品是否被扩大到一种流派？个人体验是否被写成观众共同反应？
- [ ] **事后套话**（§21）：每次渐强都是"张力增长"、每次安静都是"真实"、每个特殊音色都是"深层象征"？若不论作品怎样安排都能得到同样结论，说明分析还没接触作品的具体关系。
- [ ] **修改建议**：是否把自己偏好的替代版本当成客观纠错？（见 [分析建议不是唯一修复](/principles/analysis-recommendation-not-sole-fix.md)）

# 反向平衡
防止**过度怀疑**使分析无法工作：不是每个解释都需要实验才能提出。只要明确其地位、有声画依据、有可比较的替代解释，就能形成有价值的理解。严谨不是只写无意义的音色清单，而是让解释**可追溯、可讨论、可修正**。
