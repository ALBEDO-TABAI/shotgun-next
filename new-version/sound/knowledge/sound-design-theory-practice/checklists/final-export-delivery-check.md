# 交付前确认（向目标平台／播出方）
- [ ] 文件格式
- [ ] 声道
- [ ] 采样率、位深
- [ ] 响度与真峰值要求（**按合同读取**）

> EBU R128 是特定广播响度建议体系；它或网上常见的 −14 LUFS **都不是**所有广告、影院和社交平台的统一目标。[2]

# 导出后完整试听
- [ ] 听的是**导出文件**，不只是工程
- [ ] 起止位置、尾部是否被截
- [ ] 静音／独奏状态是否残留
- [ ] 是否错版
- [ ] 侧链触发、返回轨是否丢失
- [ ] 需有损发布时，检查**实际编码版本**，不只听无损母文件
