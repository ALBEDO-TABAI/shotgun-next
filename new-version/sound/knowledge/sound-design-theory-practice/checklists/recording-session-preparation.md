# 录音包

- [ ] 正在使用的伴奏或画面
- [ ] 速度／拍号／起始信息
- [ ] 目标情绪变化
- [ ] 需要保留的句子
- [ ] 可自由处理的范围
- [ ] 乐手需要乐谱时：清楚的总谱／分谱、排练标记、调性与移调说明，并请实际演奏者核对可演奏性

# take 策略

- [ ] 不说"多录几条"，而给**不同任务**：完整表达版、克制版、关键句更明确版
- [ ] 保留一次相对连续的演奏作为语气与连贯性参照，再补录确实需要的局部

# 开录前技术检查

- [ ] 回放一小段：输入正确
- [ ] 监听不重复
- [ ] 没有意外削波
- [ ] 底噪与房间可接受

# 收尾

- [ ] 表演者结束后留出自然尾音
- [ ] 需要空间连续性时，单独录制**相同设置**下的环境底
- 数量由素材变化决定，不设所有项目统一时长的硬规则。
