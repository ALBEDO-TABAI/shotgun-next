# 检查表（本包工作模型）
| 检查层 | 问题 |
|---|---|
| 可听 | 关键声音是否实际到达了观众？ |
| 显著 | 它是否有机会被注意？ |
| 可识别 | 需要辨认来源时，观众能否辨认？ |
| 可理解 | 需要理解的信息或关系是否成立？ |
| 可记忆 | 需要形成记忆的特征，之后能否被认出？ |

**不是神经加工的五个固定阶段**，而是五种不同的验收结果。一个声音可以很响却难识别；可以容易识别却没必要成为注意力中心。

# 实际原则
- 评估时**不要只数有几条轨道**，要检查有几项内容正在同时要求观众辨认、理解或跟随。
- 不要把“同时最多三个声音”之类经验说法写成普遍听觉定律。
