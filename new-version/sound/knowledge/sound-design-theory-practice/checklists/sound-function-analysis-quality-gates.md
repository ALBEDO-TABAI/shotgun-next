# 质量门槛（全部满足）
- [ ] 区分**听见的形式**与**解释**
- [ ] 指定任务的**对象**与**时间**
- [ ] 指出与其他声音的**关系**
- [ ] 说出**什么情况会使解释不成立**（无法被推翻 = 修辞）

# 常见误判 → 修正
| 误判 | 修正方向 |
|---|---|
| 把音乐音量当作用大小 | 描述关系变化而非电平 |
| 把短时唤醒当成情节理解 | 用理解题/开放回答检验 |
| 把感动当成品牌记忆 | 分开测"感动"与"品牌归属" |
| 把听者喜欢当成作品适合 | 回到任务与目标 |
| 把"安静"自动视为真实 | 说明安静在做什么 |
| 把所有突变称为注意力设计 | 说明指向了什么对象 |
| 把每次主题出现都解释成深层象征 | 检查是否建立了可追踪关系 |

修正不是删除感性描述，而是给它补上**对象、依据与边界**。

# 另两条
- 接受"音乐暂时不承担任务"；不为每个音符编造叙事功能。
- 看似背景的一层也可能在撤掉时暴露关键组织作用——用对照确认。
- 目标不是功能越多越好，而是**需要的任务被可靠完成，不需要的解释没有被无意加上**。
