# 步骤
1. **明确缺口类型**：
   - 素材来源 → 制作人员原始说明；
   - 情绪线索 → 相应研究；
   - 发行版本 → 能定位该版本的资料。
   不用一个来源同时解决所有问题。
2. **三层检索，先具体后理论**：作品及场景具体资料 → 作曲／声音设计／混音人员一手记录 → 相关学术研究。避免先找到一个有名理论就把全片套进去。
3. **记录查阅层级**：是否打开正文、只读摘要、只看出版信息，还是只有搜索片段。找到书名≠读了书；引用列表里有某论文≠其正文支持当前结论。
4. **核对研究**：研究对象、材料、操作方式、结果类型。例：评价"音乐表达的情绪"的研究不能写成"听众的实际情绪"；用特定片段的研究不能改写成所有类型影片的结论。对创作者资料确认说话人、作品、阶段、所指对象。
5. **保留简短排除记录**：未获正文；找不到原始引文；资料讨论的是预告而非正片；论文材料与本问题差异过大。用于下次检索，不必塞进最终分析。
