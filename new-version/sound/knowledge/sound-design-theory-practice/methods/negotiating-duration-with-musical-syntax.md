# 公式（恒定速度）

- 一拍秒数 = 60 / BPM
- 4/4 一小节秒数 = 240 / BPM

# Examples：118 BPM

| 长度 | 秒 |
|---|---|
| 4 小节 | ≈ 8.135593 |
| 14 小节 | ≈ 28.474576 |
| 15 小节 | ≈ 30.508475 |

→ 30 秒**不是** 118 BPM 下的整数 4/4 小节。

# 协商选项

1. 自由引子 + 有拍主体
2. 提前停止新音，保留尾部
3. 调整弱起或局部拍号
4. 允许时调整速度

# 反模式

- 每个画面切点都强迫音乐重拍。
- 靠拉伸整条音频掩盖结尾没写好。

# 注意

- 配套 MIDI 只覆盖四小节；其速度元事件存在微秒取整误差（508475 µs/四分音符 ≈ 117.9999 BPM），见 [MIDI 三版本对照](/exercises/midi-four-bar-motif-comparison.md)。
- 画面帧率与音频采样率需在真实工程中分别设置。
