# 为何较可控
局部规律由作品自身建立，不完全依赖观众共享同一种文化经验；但仍需要**充分而不过度**地建立。

# 可用的打破方式
- 重复一个动作—声音关系，在关键处改变结尾；
- 让稳定间隔逐渐延长；
- 每次切换都有声音回应，最后一次却没有；
- 熟悉动机从完整变成残缺。
变化要与当前任务相关，不是为证明形式复杂。

# 规则证据（必须记录）
| 字段 | 说明 |
|---|---|
| 展示位置 | 作品在哪些位置展示过这条规律 |
| 可辨性 | 展示方式是否足够可辨 |
| 掩盖 | 是否被其他声音掩盖 |

只有说明书声称"已形成期待"不算证据。**不规定必须重复三次或四次**——次数取决于材料、时长与上下文。

# 变化之后
- 一次缺失可暂时保持未知、后面揭示；也可永不解决以保留形式。
- 无论哪种，都要确认这是**有意状态**，而不是资产漏失。
