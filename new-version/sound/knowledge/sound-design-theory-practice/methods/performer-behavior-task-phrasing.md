# 步骤

1. 开场可以给情绪说明（"温柔一点"），但随即改成**行为任务**，例如：
   > "这句前半像试探，第三个音才肯定下来；不要每个音都同样突出；句末留住，不急着给结论。"
2. 让演奏者提出实际可行的处理。
3. 把乐句标成三处：**起点 / 目标 / 离开方式**。
4. 分别尝试用 力度、音长、发音、局部时序 实现——不同时改变一切。
5. 先录一个**完整解释**，再比较其他解释。

# 依据

Belkin *Improving Orchestral Simulation through Musical Knowledge*：乐句各处重要性不同，真实乐器表达资源不同；快速构思与高保真模拟不应投入相同细节。本包只采用其音乐性与分层投入原则，不把较早技术能力评价当作 2026 年产品事实。
