# 步骤
1. **片段级电平整理**。
2. 听具体问题：口部噪声、衣物、底噪、房间变化……
3. **局部缺陷局部处理**，并与未处理版本比较；处理顺序由问题决定，不给所有对白套同一长串插件。
4. **三种状态检查**：
   | 状态 | 检查 |
   |---|---|
   | 单独对白 | 是否自然 |
   | 带环境 | 是否连续 |
   | 带音乐 | 是否清楚 |
5. 降噪副作用（水声、金属感、拖尾）可能独听明显、整体中被掩盖，或相反；**不能只凭频谱图更干净就宣布更好**。

# 补录与限制
- 有条件时，补录一句完整表演往往比拼补多个字更可控。
- 无法补录：明确限制，**保留原始录音和处理前版本**。
- 纪实材料：避免通过重组对白**改变原意**。
