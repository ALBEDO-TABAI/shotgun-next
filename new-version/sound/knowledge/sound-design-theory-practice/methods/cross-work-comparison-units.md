# 问题
只挑各自最精彩片段比较两条广告，会把**不同任务**误判为**不同能力**。一条在交代信息、一条在制造体验，声音密度差异明显也不能推导哪条更专业。

# 步骤
1. 建立任务相近的**比较单位**：产品首次出现、主要动作完成、旁白核心信息、情绪转折、品牌收束。
2. 对每个单位记录：材料、入点、活动层次、空间、留白。
3. 检查相同任务如何由不同关系完成。
4. 任务本就不同时，把差异**作为解释条件**（如一条强调人物日常、一条强调超现实产品世界，真实环境声的多少不宜脱离目标排序）。
5. 也可做**同一作品内**段落比较：动机第一次如何建立、第二次保留什么、最后改变什么——往往比"全片统一风格"更有证据含量。

# 结论写法
写成**可迁移关系**：在什么条件下，某种组织解决了什么问题，付出了什么代价。不要只记品牌名、导演名和流派标签。
