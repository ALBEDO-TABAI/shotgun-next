# 依据

Open Music Theory *Texture in Pop Music*：以节拍、低音、和声、旋律、新奇层等**功能层**描述织体；某层可由多个乐器组成；关注层的缺席、切换与参与。（本包不声称通读其援引的全部研究。）

# 步骤（编配练习）

1. 给八小节草稿列出功能层。
2. 逐小节标记每层：**活动 / 维持 / 退出**。
3. 允许一个音色换角色；一层不必始终存在。

# 给旁白让位的编配操作

| 操作 | 效果 |
|---|---|
| 删掉一个新旋律句 | 移走与话语竞争的前景 |
| 中部和声由短促反复改为长音 | 降低活动密度 |
| 缩短打击尾部 | 腾出语句间的时间 |
| 装饰只出现在语句之间 | 与话语交替而非重叠 |

结果：音乐仍可能保持完整，而不是像"被关小"。
