# 公式（本包基于事件视角提出的操作模板，不是 Gaver 原文表格）
> **发声对象 × 作用方式 × 接触对象 × 动作变化 × 所处空间**

# 步骤
1. 写下名词（“脚步声”）。
2. 逐项补全：谁／什么在发声 → 怎样施力 → 与什么接触 → 动作节律如何变化 → 在什么空间。
3. 补上**个体行为**（停顿、拖擦、犹豫）。
4. 检查这句话能否被设计、评价、返修。

# Examples
| 名词 | 事件描述 |
|---|---|
| 脚步声 | 一个穿硬底鞋的人，在空旷的木质走廊上，走得很慢；每次落脚之后稍有停顿，脚掌离地时有轻微拖擦。 |
| 未来科技音效 | 一个体积不大的装置，先产生不稳定的内部振动，经过两次失败的启动后才进入连续运转；成功时不是爆发，而是杂乱细节逐渐收束成稳定状态。 |

后者包含可供设计、评价和返修的**行为逻辑**。

# 适用
拟音、实拍声、合成声、生成式声音提示。
