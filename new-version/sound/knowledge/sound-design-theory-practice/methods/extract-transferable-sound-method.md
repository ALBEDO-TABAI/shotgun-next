# 四项提炼
| 项 | 说明 |
|---|---|
| 原作任务 | 该处声音在做什么；原作目标不明时标为"分析假设"，不阻止提炼但保留证据状态 |
| 关键关系 | 声音与画面、信息、人物之间的具体关系 |
| 成立条件 | 迁移时哪些条件必须满足 |
| 失效边界 | 在哪些条件下不成立 |

# 区分三个层次
- **材料**：某段使用弦乐。
- **关系**：音乐延后到人物反应之后。
- **任务**：避免替表演提前定性。

真正的 skill 应保存**关系与任务**及其条件，而不是只保存"弦乐"标签。

# Examples
- 可迁移："在意义尚未揭示时用声音维持一个待解释对象。"
- 标签替代（不可取）："每次人物孤独就用低频。"
- 从声源延迟揭示中提炼："先提供足够追踪的线索，再在有意义的位置确认来源。"迁移到广告时要确认观众有时间追踪、揭示与产品有关；迁移到六秒短片时这些条件可能不成立。
