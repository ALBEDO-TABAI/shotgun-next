# 合同最少字段
1. 当前段落任务
2. 时间范围
3. 允许变化的音乐维度
4. 声音材料关系
5. 需要避让的内容
6. 禁止项
7. 预期返回形式（本轮是探索还是锁定）

# Examples
不够：
> 制作轻盈的泡沫声音。

够用（源文示例，洗发水广告自拟情境）：
> 为七至十一秒的微观泡沫运动准备一组候选声音。事件由少量孤立颗粒逐渐形成稀疏组织，不出现巨大撞击或明显吞咽质感；主要作用是连接已存在的水滴材料与音乐短音。此轮只探索材料行为，不输出已锁定的终混。

# 两类内容要分开
| 类别 | 处理 |
|---|---|
| 工具**可控制**的参数 | 可写入合同并验收 |
| 只能作为**期望描述**的内容 | 不能在后续合同中假设已实现；如服务不提供精确时长或真正分轨 |

# 输出后核查
- 按真实资产检查（时长、内容、禁止项），不按请求补写。
- 只有立体声混合文件时，不能复制数份命名为鼓／旋律／氛围宣称分轨。
