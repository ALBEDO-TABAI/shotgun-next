# 原则
"剪到规定秒数" ≠ 解决音乐结构。

# 选项与代价
| 方法 | 可能收益 | 需检查的代价 |
|---|---|---|
| 改变起始位置 | 高潮落到关键画面 | 可能切掉必要准备 |
| 删去一段重复 | 缩短时长 | 段落发展是否仍成立 |
| 延长尾部 | 处理最后空余 | 不能用无意义混响填补缺少的结构 |
| 改写乐句 | 结构性解决 | 需要真实可编辑性；不能假设主混音能无损实现 |
| 时间伸缩／局部调速 | 小幅对齐 | 是否影响音高、瞬态、纹理；工具如何实现；**数值小不等于听不出** |

也可调整引子、弱起、持续段、句尾、重复次数。

# 目标
在约定时长中保留能被体验的**开端、关系变化与终止**。作品可以故意不完成，但须在交付中说明这是设计，不是被截断的事故。
