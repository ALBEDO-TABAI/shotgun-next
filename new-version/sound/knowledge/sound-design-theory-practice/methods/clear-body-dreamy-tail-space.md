# 区分三件事
| 参数 | 控制 |
|---|---|
| predelay 预延迟 | 原声与混响开始之间的延迟，帮助原声与尾部分离 [2] |
| 尾部长度 | 空间延展 |
| 干湿关系 | 直达与空间比例 |

# 做法（本包建议）
1. "梦幻但清楚"做成**两层**：主体保持轮廓，尾部承担扩展。
2. 先听短空间是否已足够；需要更明显幻想时，把更长空间**只发给适合的音**，不要整段不断累计。
3. 对照起点（音乐短音）：预延迟约 **15–35 ms**、尾部约 **0.6–1.2 s**，与明显更长尾部比较。
4. 不必强制混响对拍（例如因 118 BPM 某音符值恰好是某毫秒数）；**尾部是否遮住后续事件更重要**。

# 远近感
"变远"不只是加湿度：还要检查**直达声比例、细节、动态、遮挡和整体空间关系**。
