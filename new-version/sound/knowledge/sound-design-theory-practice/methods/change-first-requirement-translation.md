# 步骤

1. **问变化**：观众在前后两个时刻有什么不同？
   - "清爽"可以是拥挤→通透、慵懒→精神、黏滞→流动——三种不同的声音过程。
   - "有力量"可能是稳健、爆发、持续推进、坚定拒绝——不应默认低频撞击。
2. **写一句话初译**：

   > 在【具体段落】让观众从【初始体验】走向【目标体验】，主要通过【一种变化】；不要变成【容易误入的方向】。

   例（教学假设）：在头发舒展开的段落，从细碎、局部的触感走向连贯的流动；主要靠节奏减少、音域展开和声部连贯，不做胜利式高潮。
3. **先定硬限制，不必问全细节**：片长、画面版本、旁白是否确定、是否服务多个短版本、是否允许歌词、需要人声／乐手还是纯合成。其余偏好用短草稿澄清。

# 边界

- 例句是教学假设，不是对所有洗护广告的结论。
- 这句话是方向假设，必须配合"什么时候算失败"（见 [目标—操作—证据表](/templates/goal-operation-evidence-table.md)）。
