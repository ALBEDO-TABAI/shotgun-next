# 步骤
1. 写出本段**首要任务**（只一个）。
2. 列出**必要的次要任务**。
3. 写出**不能破坏的条件**。
4. 选择与之相容的声音行为；指定谁承担、谁支撑、何时交接。

# 例
- 首要：让观众听懂关键承诺。
- 次要：保持轻运动感。
- 不可破坏：话语的可信与自然。
- → 音乐并非无作用，而应选择**不会同时提出大量新信息**的行为。

# 注意
- 不因七类功能表有七行而要求每段逐项完成。
- 返修时首先保护首要任务与不可破坏条件，附带效果不自动升级为硬要求。
