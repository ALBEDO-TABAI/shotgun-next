# 输入
- 至少：目标、段落上下文、可用材料。
- **只有文字 → 只做功能构想；有音视频 → 才做实际观察。**
- 缺少前后文要记录限制，不把孤立十秒推论扩成全片结论。

# 步骤
1. 独立记录画面与语言**已经表达**的内容。
2. 记录声音实际的进入、退出和关系变化。
3. 提出首要与次要任务。
4. 列出至少一个替代解释。
5. 检查任务由哪一层承担、是否存在无意竞争。
6. 提出最小对照与可观察结果。

反模式：先为所有声音寻找象征，再倒推场景。

# 输出
填写[声音功能卡](/templates/sound-function-card.md)；证据不足可输出"不确定"并说明补证途径。
