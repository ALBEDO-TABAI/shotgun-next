# 编码表应规定
- 分析单位；
- 术语含义与例子；
- 边界（什么不算）；
- 允许的不确定状态。

不是只给一串标签。例：
- "音乐进入"指音高材料首次出现，还是首次成为前景？
- "主观声音"需要哪些证据？
- "主题回归"要求保留哪些可辨特征？

# 步骤
1. 用少量共同片段**独立标注**。
2. 讨论分歧，归类原因：**漏听／时间定位／术语含义／解释立场**——四者修正方法不同。
3. 不为表面一致强迫所有人选同一情绪词。
4. 若要量化一致性：**预先**确定标签、单位与合适的统计方法；不能临时算个比例就宣布体系可靠。

# 边界
对解释性分析，保留合理分歧往往比追求一个总数更重要。原文未实施任何标注实验（本包综合方法）。
