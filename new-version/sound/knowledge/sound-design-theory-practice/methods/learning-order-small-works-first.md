# 步骤
1. 完成一段**四小节**的动机、低音与和声练习；
2. 试**删出旁白空间**；
3. 给同一段做**两种发音与演奏解释**；
4. **录一个物体动作**，制作三个变体；
5. 完成一次短片段的**前后景交接与导出检查**。

# 分支补课
| 需求 | 优先补 |
|---|---|
| 与乐手协作 | 乐器法、读谱、记谱、排练与录音沟通 |
| 纹理型电子音乐 | 合成、采样、时间包络、听觉比较 |

不必学完整个音乐理论才创作，也**不能用"有 AI"替代对实际声音的判断**。

> 核心句：完整的生产型 skill 应把"懂了"推进到"做出了一个对象"，再把"做出了"推进到"知道怎样修改它"。
