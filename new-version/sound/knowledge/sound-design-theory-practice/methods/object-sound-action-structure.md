# 要点
先决定**事件怎样发生**，再决定用什么素材发声。证据身份：本包综合。

# 步骤
1. **写动作结构**：把目标声音拆为四段——
   | 段 | 回答的问题 |
   |---|---|
   | 接触之前 | 有没有预备、气流、靠近？ |
   | 接触瞬间 | 接触是否清楚、硬还是软？ |
   | 持续过程 | 摩擦／滚动／流动是否连续、多重？ |
   | 分离与余响 | 如何离开、是否留下空间尾部？ |
2. **按表达任务取舍**：每段是否需要可听，由表达任务决定，不必完整复刻物理事件。
3. **分析动作参数再试材料**：例"头发滑过肩膀"——先分析速度、接触面积、摩擦连续性、离开方式；再试真实头发、柔软织物、轻气流等。替代素材的目的是获得**适合画面的动作质感**，不是证明来源奇怪。
4. **建立家族素材库**：同一动作录几种力度、速度、距离、结束方式，并记录差异。后续需要的是同一家族的**可变动作**，而不是一条被反复贴用的"完美音效"。

# 常见误做
- 只存"最好的一条"，导致重复贴用、机械感。
- 用素材名称（"头发声"）代替动作描述去搜索素材。
