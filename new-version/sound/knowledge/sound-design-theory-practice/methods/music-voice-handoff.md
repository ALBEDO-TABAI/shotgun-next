# 原则
旁白与音乐不必互斥，但要知道**各自何时提出新信息**。稳定持续层与人声共存，和每拍出现新旋律与人声共存，难度不同。混音能改善共存，但**不能代替前期任务分配**。

# 按语句位置处理（本包建议）
| 位置 | 处理 |
|---|---|
| 句首 | 避免新音乐线索抢占理解 |
| 关键内容 | 保留空间 |
| 句尾 | 是否给音乐回应取决于需要确认、反问还是继续 |
| 句间 | 不必每个空隙都填一个音 |

音效同理：核心产品接触声给明确位置，音乐可改变配器或暂时减少活动；辅助运动声不必每次压过旁白。
