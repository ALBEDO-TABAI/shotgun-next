# 依据

DeSantis *Arranging as a Subtractive Process*：先让材料占据时间线，再通过删除建立结构（可选方法）。本包做了短片适配。

# 步骤（短片版，本包调整）

1. 选定一个主要段落，建立其**最充分版本**（所有候选层都在）。
2. 分别从它删出四种状态：
   - 引入
   - 旁白（为话语让位）
   - 释放
   - 收束
3. 把四种状态按片子时间顺序排布，检查过渡。

# 其他非线性写法

- 先写最有表达价值的**转折**。
- 先确定**片尾怎样收束**，再反向准备前段（时间严格的广告尤其适用）。

# 边界

"先铺满再删"不是所有项目都必须经历的步骤。
