# 做法
1. **不马上换整首**。回放指定段落，追问或提出对照：
   - 旋律过分直白？
   - 节奏太满？
   - 音色有廉价联想？
   - 录音暴露房间？
   - 混音太挤？
2. 表达不精确**不意味着审美需求无效**；执行者需要建立**可操作解释**。
3. 有明显可试方向时，先交**小范围对照**，不要把沟通变成二十个专业问题。
