# 问题
"更干"：导演可能指混响少；作曲者理解为演奏更短；混音师理解为减少空间效果；生成模型可能返回音色更薄。与其重复同一个词，不如用**局部对照**明确差异。

# 步骤
1. 建立少量经确认的描述样本，**每个样本只说明一种可听变化**（短尾 vs 长尾；连续音 vs 离散颗粒；稳定重复 vs 轻微时值变化）。
2. 为每个词条写五项：
   - 所指维度
   - 参照位置
   - 希望增加或减少的性质
   - 与相近词的区别
   - 不能顺带改变的条件
3. 作为**项目约定**使用，允许通过试听修改定义。
4. 样本仅用于团队内部校准，**不把某个参考文件永久认作"高级"的定义**。

# Examples
> 本项目里的"通透"暂指前景清楚、持续层不过度填满、动作之后留有可听空间；它不要求所有素材都提高高频，也不允许把产品触感变得尖硬。
