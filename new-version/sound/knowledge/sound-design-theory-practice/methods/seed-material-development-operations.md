# 依据

DeSantis 以旋律轮廓作为写作入口（上行／下行、级进／跳进、高点安排）——属风格相关练习建议，不是好旋律的唯一标准。

# 三类操作（本包建议）

| 操作 | 做法 |
|---|---|
| 保持辨识点 | 保留节奏轮廓或独特起音，只改其他部分 |
| 制造发展 | 缩短、延长、重新分组、改变句末、转移音区、让另一声部接话 |
| 改变功能 | 前景动机→背景片段；现实声→节奏；完整句→片尾标记 |

# Examples

同一个"短—短—长"材料：首次独奏 → 第二次只露出前两音 → 结尾才完成。

# 反模式

每次都换一套素材来假装发展。
