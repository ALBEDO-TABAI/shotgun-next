# 步骤
1. **记录目标与参照**：常规方案是什么？为什么值得偏离？
2. **选择保留项与偏离项**（见 [三元模板](/frameworks/keep-one-link-change-one-expectation.md)）。
3. **做候选**：同一画面上的 常规 / 轻度变形 / 较明显变形 三版。数量可调，关键是差异清楚、可比较。
4. **控制比较条件**：
   - 只检查来源替代 → 不同时改音乐情绪、剪辑时长和整体响度；
   - 比较完整方向 → 承认无法把结果归因到单一参数。
   实验设计与问题相称，不是越复杂越科学 [2]。
5. **先开放后具体提问**：
   - 开放："你认为发生了什么""哪些声音使你注意到变化""有没有不需要的联想"；
   - 之后才问目标词，避免提前教会听者回答"轻盈"或"恐惧"。
6. **保留失败材料及原因**：没建立常态、尺度错误、前景竞争、来源过于明确、目标与画面矛盾……这些记录比"最终最怪"的音效更能形成 skill。
