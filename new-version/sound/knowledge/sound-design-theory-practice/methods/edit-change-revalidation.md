# 依据
音乐编辑的职责包含追踪画面修改（Berklee 职业说明）[2]；本包转成小型变更流程。

# 步骤
1. **判断改动性质**：单纯插入／删除时长，还是事件顺序、人物反应、关键文案改变？
   - 例：人物反应镜头被删后，原本"理解后"进入的音乐变成在消息出现时就直接表达结论——技术同步保留，叙事理由被破坏。
2. **按依赖追踪受影响项**：动作锚点、乐句终止、旁白保护区、跨场尾声、主题首次建立、片尾文件边界。
   - 未受影响的素材不必重新生成；依赖已变的批准标为**待重验**。
3. **完整回看相关前后段**：不能只看改动附近两帧——音乐身份或期待可能建立在更前面。

# 输出
分别记录两个结果，不把前者等同于后者：
- ☐ 技术位置已更新
- ☐ 艺术关系已复核
