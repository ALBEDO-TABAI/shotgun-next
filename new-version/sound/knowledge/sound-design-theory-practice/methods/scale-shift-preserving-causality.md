# 尺度的四个分项（本包综合）
| 分项 | 说明 |
|---|---|
| 声源大小 | 物体被听成多大 |
| 听觉距离 | 我们离它多近 |
| 空间范围 | 所处空间多大 |
| 内部细节 | 能听到多少内部结构 |

改变尺度不只是加大或减小音量，而是改变观众与对象的关系。四项分开决定：为泡沫微观镜头增加近距离细节，不必同时把空间做成巨大洞穴；为巨型装置建立重量，也不应把每个小动作都做成爆炸。

# 最重要的检查：事件展开仍可理解
- 液滴尚未落下就出现完整接触声 → 明显时间错误。
- 一次轻触包含长时间碎裂 → 暗示对象损坏。
- 故意违反因果可以，但必须是设计目的，不是"更有质感"的无意副作用。

# 产品广告的额外边界
尺度夸张可能被误读为实际性能：把普通开合做成沉重、绝对密封的机械动作，可能暗示并不存在的构造。**感官表达与事实展示的边界由项目明确，不能由音效单独决定。**
