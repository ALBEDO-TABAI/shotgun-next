# 步骤

1. 标注参考的**具体段落**与**借鉴对象**，例如：
   - "借其鼓与低音的相互留白，不借旋律与音色"
   - "借中段从近到远的空间变化，不借曲式"
   - "借演唱的克制，不借歌手身份或原曲歌词"
2. 每条参考至少三项：**要保留的特征 / 不要继承的特征 / 转化成我们作品的办法**。
3. 找不到合适参考时，允许先做**三个短试验**代替参考（借用 Design Council 双钻的"展开—界定—小规模试验—迭代"原则；不把工业设计框架强套为作曲定律）。

# 目的

- 避免沟通含糊。
- 防止被一首临时配乐（temp track）锁死。
