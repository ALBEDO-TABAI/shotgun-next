# 步骤
1. **观察依据**：引用可复查的位置与变化。
2. **上下文需求**：此处叙事／信息／人物需要什么。
3. **作用路径**：声音怎样通过叙事关系、信息状态或注意力组织产生作用。不必是神经机制；**没有充分研究依据时不用"激活杏仁核""刺激多巴胺"等术语替代说明**。
4. **至少一个替代解释**，并写出区分它们的检查点。

# Examples
> "在人物拒绝帮助后，音乐仍保持未完成短句，而他没有离开；这可能维持拒绝与依赖之间的矛盾，使台词不被当成最后结论。"

低沉持续声的三种可能：威胁／工业空间的实体感／仅连接两个镜头。区分方法：
- 是否随人物情绪变化？
- 是否延续到无人场景？
- 是否有已揭示的来源？
- 替换或撤去后哪一层关系发生变化？

# 研究边界
Ansani 等人的研究把声轨作为影响人物与场景判断的变量[2]。这为功能假设提供**研究方向**，但不能证明某个具体镜头一定产生了该作用；手中的片子仍需实际观察与适当测试。
