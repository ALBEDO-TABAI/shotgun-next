# 按失败类别选动作
| 失败原因 | 下一动作 |
|---|---|
| 素材不可访问／缺文件 | 修复访问 |
| 工具不支持目标能力 | 改变工作路径或交接 |
| 输入矛盾／目标矛盾 | 返回决策者 |
| 参数不合适、局部音色不合适 | 才考虑编辑或有限的新候选 |
| 未通过艺术评审 | 定位层级后局部修改 |

# 每次返修三件事
1. 保留哪个**已通过基线**；
2. 尝试**改变什么**；
3. 用**什么判断**是否改善。

不要用新候选不断覆盖旧资产导致无法比较；不要因最后一个服务回执成功就把整体状态改为成功。

# 停止条件
任务已满足 · 继续修改没有明确问题 · 预算或授权边界到达 · 必要输入缺失。停止不一定是失败——有时需要的是创作决定，而不是更多计算。

# 汇报措辞必须区分
"已执行了修改" ≠ "新候选已取得" ≠ "通过了某项检查" ≠ "允许最终交付"。
