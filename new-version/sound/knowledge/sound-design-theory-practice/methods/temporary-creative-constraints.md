# 依据

Dennis DeSantis《Making Music》公开章节 *Arbitrary Constraints*：主动限制材料可减少选择瘫痪；限制可在不再有帮助时撤销。（本包仅概括其操作思想，练习自行设计。）

# 步骤

1. 选一个限制，服务一个具体问题。
2. 在限制内做完一个"开始—改变—结束"的短段落。
   - 自定练习：只用**三个音高 + 一段摩擦录音 + 一个持续层**。
3. 听：限制暴露了什么想法？
4. 限制不再帮助时撤销，补回被禁材料。

# Examples

- 为"克制但有动感"暂时**禁止完整鼓组**，迫使寻找音长、停顿和低音的推动方式；最后若仍需鼓组再加入。

# 边界

- 限制的是搜索范围，不是宣布"三个音永远比复杂音乐更好"。
