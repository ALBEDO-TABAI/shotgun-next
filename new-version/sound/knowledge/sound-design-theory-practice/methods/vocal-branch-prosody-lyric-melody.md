# 依据

Pat Pattison（Berklee Online Take Note）以 **prosody** 讨论歌词、音乐与核心表达之间的关系。本包采用其"各元素服务同一表达"的创作观点，不等同于语言学韵律概念全部含义，也不采用文中未经查证的思想史归属。

# 四步小实验

1. 把词**自然说**一遍
2. **只按节奏念**一遍
3. **只唱元音骨架**
4. **唱完整歌词**

比较四者是否在表达同一件事。

# 与演唱者核对

- [ ] 舒适音区
- [ ] 连续高音负担
- [ ] 换气位置
- [ ] 长音所承载的词
- [ ] 辅音是否挤在关键拍点

# 中文歌词注意

- 请母语演唱者与听者确认字义是否清楚。
- 不机械套用英语重音规则；也不把字调与旋律的关系缩成一条必守的轮廓公式。

# Examples

- 品牌句关键字不要因旋律设计只能快速带过。
- 需要自然亲密时，不必把每个字唱成同样漂亮的长音。
- 无词哼唱、气声、合唱纹理也要说明任务：人的亲近感、空间材料，还是旋律主体？
