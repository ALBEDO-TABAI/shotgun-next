# 两个方向
- 外部配乐 → 揭示为房间里真实播放；
- 人物播放的音乐 → 逐渐扩展为跨场结构。
基础电影声音分析将故事内外、画内画外与声音时间分开处理 [2]。

# 管理对象：观众认为声音属于哪里
- 突然加房间混响 **不自动完成** 来源揭示；可能还需画面、音量关系或人物行为作依据。
- 来源不入画也可能已经清楚，不必为了"揭示"多插一个特写。

# Examples（自拟）
人物独自工作，背景似有规律音乐；镜头后来发现节奏来自窗外施工与室内设备的组合。
- 可解释为"人物把环境组织成自己的节律"，也可能只是形式游戏。
- 需决定哪种解释被作品支持，**不能两种都写成作者已知意图**。

# 声源模糊的边界
观众应该好奇来源，还是已经不需要来源？若观众一直忙于猜是什么，而没经历本想表达的亲密或平静 → 重新分配线索。
