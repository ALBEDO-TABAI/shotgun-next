# 四段行为模型（本包综合）
| 阶段 | 设计问题 | 示例 |
|---|---|---|
| 常态 | 平时怎样运转？ | 可辨认的规律节律 |
| 受刺激 | 被触碰／受力／人物靠近时发生什么？ | 启动前犹豫 |
| 反应 | 怎样回应？ | 节奏略变、类似呼吸的起伏 |
| 恢复 | 怎样回到常态？ | 迟疑恢复；恢复越来越慢 |

- 行为规则需在作品内**前后一致**，才会被理解为性格，而非随机变化。
- 情绪可以放进互动：机器的脆弱感可来自**恢复过程**，不一定来自悲伤音乐；友好装置可通过"等待人的动作再回应"建立关系，不必用可爱音效。

# 边界
- 若作为产品性能展示，避免夸大真实反馈能力。
- 素材方案可多样：真实机械录音的节奏编辑、合成纹理、低调的非语言人声材料等。
- 涉及真实人物声音须另查授权；不需要克隆某人声纹就能探索类生命的动作形态。
