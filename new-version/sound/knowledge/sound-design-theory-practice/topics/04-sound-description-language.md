# 本篇核心问题
怎么把"感觉"翻译成音乐与音效的具体语言？描述的目标不是显得专业，而是**减少不可见的分歧**——让体验词获得可试听、可修改、可验收的对应物。本篇面向不熟悉乐理的导演与策划，也为作曲、声音设计与生成式工具提供共同接口。不存在脱离上下文的"高级音色""治愈频率"或能自动保证情绪的提示词。

# 核心知识段
声音描述应把体验目标翻译为可听特征、可操作参数、时间关系与验收条件，而不是堆叠情绪词、流派词或技术术语。分别描述速度、拍点、节奏、密度与律动；分别描述音高组织、音色、发音、配器活动、空间与动态。音效以事件、动作、接触关系和起势—持续—转化—终止来描述。对"轻、暖、通透、梦幻、高级"等词给出项目内解释，用正向特征与排除项校准。音乐情绪与音色语义研究提供条件性依据，不构成通用映射。技术测量只回答技术问题；提示词只记录请求，不证明结果。无听音或测量依据时保留"未判定"，建议参数与原片事实分开。

* [发音与演奏行为](/frameworks/articulation-performance-behavior.md) - 乐器名不是声音描述；把"自然一点"改写成行为。

* [动态、响度与峰值](/frameworks/dynamics-loudness-peak-distinction.md) - 五个不同的量；"高潮不够"的五种可能。
* [五种变化关系](/frameworks/describing-change-five-relations.md) - 数量、频谱、时间、空间、来源；用层级与时间解开矛盾词。
