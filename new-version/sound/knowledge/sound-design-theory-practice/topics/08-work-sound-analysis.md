# 本篇核心问题
分析现成作品时，怎样让听感猜测、技术猜测和作者意图不再彼此冒充？本篇把声音分析组织为可追溯的**观察 → 形式描述 → 功能解释 → 意图核查 → 对照研究**。原文没有待分析影片或音频，所有片段记录均为假设性示范；未做真实听音、频谱测量、源分离或创作者访谈。

# 核心知识段
作品声音分析应先确认素材、版本、范围和能力边界，再分别记录可听事实、形式关系、功能假设、创作者意图和受众结果。用准确位置与声音变化建立证据，声源不明时描述形态，不由听感猜测实际制作。把局部放回前后文，区分单次事件与全片规律，为主要解释保留替代解释和可推翻条件。一手资料支持创作者陈述，实验支持特定条件下的结果，两者都不能自动证明当前作品的全部作用。只听音频、静音、撤去配乐、独听分组和算法源分离回答不同问题，必须说明改变了什么。测量仅用于其适用范围。最终提炼任务、关系、成立条件与失效边界，而非把作品表面材料固化成通用配方。
