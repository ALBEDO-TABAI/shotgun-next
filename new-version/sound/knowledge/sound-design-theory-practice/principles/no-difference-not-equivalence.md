# 未检出差异时先检查
1. 结果的不确定性；
2. 指标是否敏感；
3. 条件是否真正不同；
4. 样本与任务是否足以回答问题。

不要自动解释成"音乐不起作用"，也不要宣布两方案"已被证明等效"。

# 样本量
NIST 专门说明样本量取决于**目标差异、变异程度及错误风险**等前提，没有脱离这些条件的统一答案[2]。原文不套用其示例样本数，也未完成具体功效计算。

# 证据有限时仍可决策
例：主要目标上未发现实质差别，但一个方案**更易合法取得和修改** → 可基于制作条件推进。须明确这是**综合项目决策**，不是证明其审美更优。

# 反方向
一次明显的个体不适或误解也不一定意味着淘汰方案；按问题严重性、目标群体、可修改性和使用情境处理。机械投票既可能错过重要风险，也可能抹去作品合理的个性。
