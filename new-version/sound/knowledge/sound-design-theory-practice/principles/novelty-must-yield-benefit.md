# 收益必须能说出来
| 收益类型 | 示例 |
|---|---|
| 更准确的感知 | 让微观动作的柔软被感到 |
| 更有用的多义性 | 保留作品需要的开放 |
| 更清楚的主题关系 | 声音行为与人物关系呼应 |
| 形式上的新经验 | 使观众意识到构造 |

"没有人用过"不足以说明它为何属于这部作品。

# 观众不必说出隐喻
- 未能命名"空间打开"，但经历了从紧密到舒展的变化 → 可能已完成任务；
- 准确猜到"这是鲸鱼声"，却不再关注影片对象 → 素材识别抢走了表达。

# 最终检查五问
1. 联系能否成立？
2. 偏离是否有理由？
3. 变化是否有组织？
4. 误读代价是否可接受？
5. 技术结果是否稳定？

经比较后退回较常规方案**不是创意失败**，而是发现当前片子不需要那种偏离。
