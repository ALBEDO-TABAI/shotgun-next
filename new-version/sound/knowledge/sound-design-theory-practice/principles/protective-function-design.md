# 原则
每段追问：
> 本段允许声音支持哪些解释，必须暂时保留哪些开放问题，不能无依据地暗示哪些事实？

# 例
- 人物短片呈现生活困难，但暂不要求观众把人物理解为可怜 → 保留劳动节奏、空间细节、行动连续，不提前加入规定同情姿态的音乐。
- 产品展示让操作明确，却不夸大阻力、重量或效果 → 提供足够动作锚点，不把每次接触设计成大型机械动作。

# 意义
- 克制不是审美上的自动优越，而是在**维护明确边界**。
- 适合导演、音乐统筹与声音设计共同讨论；使**无配乐、延后进入、保留普通环境声**成为正向选择，而非"尚未完成"。
