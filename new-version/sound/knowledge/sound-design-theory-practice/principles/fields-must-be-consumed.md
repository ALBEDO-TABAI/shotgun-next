# 原则
字段的价值在于**被消费**。对每个重要字段检查四问：
1. 谁读取？
2. 何时读取？
3. 影响哪项动作？
4. 没有值时怎样处理？

# 字段—消费者—失效示例
| 字段 | 消费者与动作 | 不应发生的失效 |
|---|---|---|
| 旁白前景窗口 | 作曲减少活动；声音设计避开关键落点；混音确认实际关系 | 文档写了窗口，各部门仍各自铺满 |
| 音乐退出条件 | 音乐编辑设出点；混音保留指定现场声 | 因"最后更完整"自动把配乐补回 |
| 权利适用范围 | 制片及发布环节核对用途和版本 | 生成完成后直接写成"可发布" |
| 剪辑版本依赖 | 变更检查识别需重新适配的 cue | 新画面沿用旧 QC 结果 |
| 听觉立场 | 声音设计与混音共同决定选择性保留和距离 | 所有声音机械跟随摄影机距离 |
| 禁止项 | 生成、编辑、评审分别检查实际内容 | 只把禁止项发给模型，之后不验收 |

# 操作建议
- 项目开始时做一次消费检查，之后只为**新增字段**补查。
- 不为"看起来完整"不断增加从未影响行动的元数据。
- 证据身份：**本包综合**的工作方案。
