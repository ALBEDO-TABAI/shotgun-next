# 三种尺度
1. 某个位置发生了什么；
2. 若干位置共同形成什么规律；
3. 这些规律怎样参与作品整体。

局部到整片之间需要**重复、差异或结构联系**作为桥梁，不能仅靠修辞扩大。只完成第一层就保留局部结论，不附"这正是导演一贯的哲学"。

# "观众"的三种表述
| 依据 | 表述 |
|---|---|
| 个人观看 | "这一处理使我更注意某个动作" |
| 形式分析 | "这里提供了把注意转向该动作的线索" |
| 实际收集的反馈 | "某些受测者理解为……" |

# 可修正条件
结论后保留一句：若发现另一发行版本没有这段声音、若完整前文赋予相反动机、若创作资料指向不同对象，当前解释要怎样调整。让分析能进入后续研究，而非以气势封闭讨论。

# 保存反例
知识库不应只收录成功解释的片段，也要记录某套理论**不能解释什么**、为何证据不足——这样训练出的 skill 才不会把任何影片都分析成同一套预设故事。
