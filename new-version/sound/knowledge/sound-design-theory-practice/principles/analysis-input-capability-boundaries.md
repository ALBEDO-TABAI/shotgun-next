# 原则
**先看手里有什么材料，再决定能说什么。** 输入能力决定了哪些结论不能作出。

| 已有材料 | 可以做什么 | 不宜声称什么 |
|---|---|---|
| 完整音视频 | 观察声画关系、前后语境、整体重复 | 未查资料就断言具体音源或作者意图 |
| 只有音频 | 分析可听结构、材料关系、空间表现 | 断言与未知画面同步或象征某镜头 |
| 只有画面／截图 | 提出声音设计假设、标记可见动作 | 描述原片实际音色、配乐入点和混音 |
| 只有字幕／转录 | 分析文字信息与可能的声音任务 | 判断真实演奏、距离、密度、质感 |
| 原始工程分组 | 检查分组关系与可编辑结构 | 自动等同于最终发布版听感 |
| 源分离估计 | 辅助辨听与提出假设 | 当作创作者原始分轨或真实制作来源 |

# 要点
- 这是**能力边界，不是价值排序**：只有脚本也能做深入构想，只需把任务名称改为"设计建议"；只有片段也能做精确局部分析，只需避免越界归纳。
- **agent 特别提示**：模型能解释"恐怖配乐"这个词，不代表它实际听到了所指音频。使用转录、关键帧或文本摘要时必须保留此界限。
- 没有音视频输入时，报告名称应改为"声音设计假设"或"分析计划"。
