# 原则
1. 进入信息段前，音乐**减少新的前景旋律事件**，保留拍点与较稳定支撑，避免体验中断。
2. 音效不在句中重复大型强调；产品主动作与语言冲突时明确优先级，必要时调整剪辑或文案位置。
3. 之后才检查是否需要动态处理（闪避、侧链等）。
4. 诊断信号：只有把音乐压到几乎听不见才能听清旁白 → 配器与语言本身冲突。

# 为什么
"降低总音量"只能换来可懂度，却可能制造能量凹陷；安排活动才能同时保住体验连续与语言清晰。

# 证据身份
本包综合（来自洗发水广告案例的设计选择）；Berklee 课程大纲只确认"对白下写作"是专业任务范围，不证明本做法已保证可懂度。
