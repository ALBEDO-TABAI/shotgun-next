# 原则
导演、作曲家、声音设计师或混音师的访谈、制作文章、原始工作记录，可以支持**"创作者如何说明自己的选择"**。Murch 与 Thom 的作者文章是这类一手实践资料的例子[2][3]。

# 使用规则
1. **保留语境**：说话人、作品、制作阶段；区分"在这个案例中这样做"与"对所有电影都这样做"。
2. **版本对应**：回顾性访谈不自动覆盖具体剪辑版本；制作计划是否进入最终声轨仍需检查。
3. **来源 ≠ 效果**：创作者可描述素材来源，但实际成片效果仍通过聆听分析。
4. **受众解释不反写**：观众形成作者未预设的解释，可以作为接受层证据，但不应被反写为作者原意。
5. **说法不一致时**：记录各人职责、阶段、具体对象，不急于统一故事（如一人讲作曲前设想、一人讲终混删改，未必矛盾）；无法确认则保留差异。
6. **拒绝无源转引**：不凭二手评论反复转引"导演说过"；没有一手证据时明确写"评论者的解释"或"本次分析推测"。
