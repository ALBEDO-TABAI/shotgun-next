# 原则
测量工具的结果取决于输入、算法和参数，**不能不经确认就当作精确制作事实**，更不能替代美学判断。

| 工具 | 可以做 | 不能证明 |
|---|---|---|
| 波形 | 检查起止、突变、削波、相对结构 | 声音的意义 |
| 频谱表示 | 观察能量与频率随时间变化 | 使用了某乐器；"清爽"之类感受 |
| 拍速估计 | 提出候选 | 精确拍速（可能给出半拍／倍拍候选） |
| 音高检测、语音识别 | 提出候选 | 无显著识别结果≠没有人声 |
| BS.1770 响度／真峰值 | 节目响度与真峰值的技术问题[2] | 情绪、真实性、品牌价值；也不等于听者设备输出的实际声压 |

# 规则
- 自动结果必须与原音、上下文和人工复核相连。
- **没有运行工具时写"建议测量"，不写"已测得"。**
- 只有截图或转录时，不生成看似专业的频谱、响度或混音参数来填空。
