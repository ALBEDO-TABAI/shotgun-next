# 原则（来源支持：Randy Thom 关于声音分镜的文章）
相比泛泛的发动机声音，**具有独特问题、习性和反应**的机器声音，更有机会揭示人与机器之间的关系（原文以摩托车为例）。

# 创作转化（示例）
- 一台咖啡机总在最后一步犹豫；
- 一扇门需要轻推两次才能关上；
- 一只瓶盖在松开前先有一小段阻力。

这些细节可以成为**人物生活方式、产品手感或空间性格**的组成部分，而不只是“真实感素材”。

# 边界
是否突出由作品任务决定——**不能把每个物体都设计成抢戏的角色**（见 [协调强调而非各自叠满](/principles/coordinated-emphasis-not-stacking.md)）。
