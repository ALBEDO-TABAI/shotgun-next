# 原则
知识的价值在于**改变行动**：少生成一个无关候选、发现一个提前泄露信息的入点、避免把计划分轨当真实分轨、让重要声音得到明确交接。

# 每次调用应返回
决定 · 依据 · 候选 · 验证方式——而不只是引用术语。

# 评价 skill 实现的标准
- 字段是否进入生产（见 [字段必须被消费](/principles/fields-must-be-consumed.md)）；
- 错误是否被具体定位；
- 批准是否绑定正确资产；
- 下一动作是否来自当前状态。
**不能**以回答长度、理论名称数量或 agent 数量判断系统成熟度。
