# 一、后期制作 ≠ 故事外声音
后期录制的脚步可以完全属于故事世界；拍摄现场播放的临时音乐也不自动成为故事内音乐。**制作来源与叙事归属是两回事。**

# 二、“听见却看不见” ≠ “不知道是什么”
Chion 用 **acousmatic** 描述听到声音却看不见发声原因的情形。声音可以先展示声源后留在画外，也可以先被听到再揭示来源。分开记录：
- 声源是否**可见**？
- 声源是否**已被识别**？
（熟人电话里的声音容易被认出，但人不在画面中。）

# 三、听起来像什么 ≠ 实际上用了什么
| 句子 | 性质 |
|---|---|
| “像金属刮擦” | 听觉描述 |
| “由金属刮擦录音制作” | 制作事实 |
| “表现角色内心的撕裂” | 解释 |
| “创作者为了表现撕裂而使用金属录音” | 需要制作资料支持的意图断言 |

# 四、分类不清楚，有时就是设计结果
持续声可以暂时处于机器噪声与音乐之间；人声可以处于记忆、想象与现场回声之间。Skill 不应为填表强行确定，而应允许三种取值：
> 边界模糊是有意设计；当前证据不足；需要后续镜头或声音揭示。
