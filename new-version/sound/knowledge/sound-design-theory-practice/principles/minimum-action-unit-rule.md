# Schema
| 字段 | 回答 |
|---|---|
| 条件 | 什么情况下使用？ |
| 动作 | 做哪个动作？ |
| 对象 | 改变哪个对象（音符、声部、素材、包络、自动化……）？ |
| 预期 | 预期听到什么？ |
| 失败信号 | 什么现象说明失败？ |
| 下一步 | 失败后如何改？ |

# Examples
❌ "保证音乐有呼吸感。"

✅ "若连续领奏遮挡旁白，先复制该段，删去一个完整回答句，保留低音和主要和声；带旁白比较信息清晰度与音乐连贯性；若清楚但掉气，尝试以持续层或句间短回应连接，不立即恢复原先全部音符。"
