# 原则
- 安静房间戴耳机认真比较，与嘈杂环境只看一遍，不是同一种任务。前者帮助定位细节，后者可能更接近某些传播条件；**没有一种环境天然代表所有用途**。
- 顺序：先在能解释问题的控制条件下判断局部关系 → 再选少量真实目标条件检查稳健性。目标条件差异很大时，明确是否需要**不同版本**，而不是要求单一混音在所有环境同等精细。

# 参与者来源
团队同事、声音专业人员、品牌现有用户、第一次接触产品的人带有不同先验。不能仅因同属某年龄段就认为观看经验和任务相同。

# 发布后数据
画面、文案、投放位置、频次、受众分配都可能同时变化。没有合适比较设计时，结果只说明**整体版本在当前条件下**的表现，不能单独宣布声音带来某比例的提升。

# 报告要求
明确"对**哪个版本、哪些材料、什么任务、哪些听者和播放条件**有效"，而不是保存为永久的品类规律。
