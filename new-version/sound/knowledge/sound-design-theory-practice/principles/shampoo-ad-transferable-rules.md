# 可迁移的四种关系
| 规则 | 反例（不适用条件） |
|---|---|
| 让材料身份在前后出现中可追踪 | — |
| 把关键语言视为有具体窗口的信息 | 整片没有语言 → 不必预留相同的旁白结构 |
| 用密度与运动关系组织释放 | 材料本身需要宏大尺度 → 细小颗粒不是正确选择 |
| 让品牌结尾回收此前已存在的特征 | 目标是刻意制造品牌插入的突兀感 → 结尾不连贯可能正是所需形式 |

**不是**"洗发水一定用短音和颗粒"。

# 保存方式
规则与适用条件一起保存，后续 skill 才能根据新任务重新推演，而不是把一次案例误学成整个品类的标准答案。
