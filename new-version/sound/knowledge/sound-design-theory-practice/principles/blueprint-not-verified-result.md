# 原则
1. 分开 **给定方向 / 教学假设 / 真实未知**（见 [信息边界表](/cases/shampoo-ad-information-boundary.md)）。
2. 分别记录：生成请求、计划文件、实际资产、技术合规、艺术批准、权利许可——任何一项不能冒充另一项。
3. 时间计算与代码只验证数学，不验证听感。
4. 没有样本、日志和实际音频，不报告"多数观众""提升百分比""已验证"。
