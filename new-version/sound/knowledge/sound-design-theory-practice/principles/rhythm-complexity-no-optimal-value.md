# 两项研究，不是互相推翻
- **Witek 等 2014**：特定鼓点材料中，中等切分与较高自评愉悦及运动欲望相关；后有勘误（刺激索引与记谱附件），作者称不改变主要结论。[2]
- **Senn 等 2024**：另一组更具惯用风格的鼓型，以**被感知复杂度**为变量，未得到同样的复杂度效应。[3]
- 两者操作化的变量不同，不能整理成"中等复杂度最舒服"去指导所有广告节奏。

# 原则
**先说清你改变了什么，再判断什么结果可以归因于它。**

# 把"节奏太复杂"拆开
| 可能原因 | 对应修改方向 |
|---|---|
| 重音难以预判 | 调整重音位置／建立可预期周期 |
| 事件数量太多 | 降低事件密度 |
| 层之间彼此冲突 | 撤掉一条竞争节奏线 |
| 重复周期太长 | 缩短或标记周期 |
| 听者无法辨认主拍 | 强化拍点参照 |

旋律与打击同时不断变化时，单纯减慢速度可能只是让混乱持续更久。

# Examples
```text
主拍并不难跟随，问题出在每次对白停顿都同时出现两个不同节奏回应；
先保留木质短音，撤掉另一条切分线。
```
