# 原则
混音首先组织**声音之间的关系**，而不是把每条轨独奏做到"丰满"。

# 操作
1. 从最重要的一层开始：需要理解的旁白、推动体验的音乐，或需要近距离感受的动作声。
2. 加入其他层时判断：它是否**增加了需要的关系**？
3. 粗平衡回答三问：**这一刻谁在前景？下一刻交给谁？哪个层次保持不变？**
4. 一条轨可在不同段落拥有不同位置，不必从头到尾一个音量。
5. 先得到**没有复杂总线处理、但结构已清楚**的版本。

# 问题归因
| 现象 | 去向 |
|---|---|
| 句子没有方向 | 返回作曲 |
| 仅几个音忽然突出 | 进入动态处理 |

并非所有问题都必须先回上游——要找**实际原因**。
