# 原则
分析者提出的更合口味版本，并不证明原作有问题。原作追求疏离、模糊或不稳定时，让它变顺畅不一定是改进。

# 提建议前写出四项
1. 原作可以被支持的目标；
2. 当前处理与该目标的关系；
3. 实际存在的困难；
4. 自己的建议是否**改变了目标**。

例："撤去持续声后更自然"可能是改变了作品的非写实立场，而非修复混音——应标为**另一种创作方向**，而不是客观纠错。

# 真正缺陷 vs 艺术分歧
- **可确认的矛盾**（缺陷）：指定条件下需要听清的语句无法理解；已建立的身份线索被无意替换；交付文件与获批版本不同。
- **艺术选择的分歧**：保留可成立的替代解释，不伪装成缺陷。
