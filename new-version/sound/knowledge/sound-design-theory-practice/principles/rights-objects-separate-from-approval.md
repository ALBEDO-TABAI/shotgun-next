# 原则
1. **区分权利对象**：美国版权局音乐人指南区分**音乐作品**与**录音制品**。使用某首歌的作品，与使用某一版实际录音，是两个核查问题（来源支持）。
2. **不替合同下结论**：需要哪些权利、由谁授权，须结合当地规则与实际合同确认；本包不构成法律意见。
3. **生成输出不自动免责**：核对所用服务条款、输入素材、约定用途与必要授权；未核查则保持"未确认"。
4. **批准对象不可混用**：用户批准"这个声音方向可以继续"≠ 批准使用可识别真人的声音 ≠ 批准购买某首音乐 ≠ 批准公开上传未发布素材。它们对象不同、后果不同。

# 工作表建议分开记录的项
| 项 | 说明 |
|---|---|
| 作品来源 | 词曲作品权属 |
| 录音来源 | 具体录音版本权属 |
| 样本来源 | 采样／素材库来源 |
| 表演或声音使用同意 | 演员、歌手、可识别声音 |
| 适用地区 | |
| 媒体用途 | 广告／线上／影院等 |
| 使用期限 | |
| 修改权限 | 是否允许剪辑、改编 |
| 证明位置 | 合同、条款、回执存放处 |
