# 原则（来源支持：Chion）
没有声源的视觉提示时，观众反而可能**更强烈地追问声音的原因**，而不是自然进入还原聆听。

- “看不见来源” ≠ “抽象”；
- “不知道是什么” ≠ “观众已经不在乎是什么”。

# 失败方式
创作者希望观众欣赏质地，观众却一直被“到底什么东西在响”占据——声音没有完成预期任务。

# 检查
- 本段预期主导聆听模式是什么（见 [三种聆听模式](/frameworks/three-listening-modes.md)）？
- 如果希望还原聆听，是否提供了让原因问题暂时落地（先揭示、或明确保持模糊的规则）的条件？
- 用对照观看检查观众的实际关注点（见 [事实—技术—艺术分开验收](/methods/fact-technical-artistic-acceptance.md)）。
