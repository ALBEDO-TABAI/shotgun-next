# 原则

全包（理论 01–10 与实践包）共用一套证据约定：**不同性质的材料承担不同的证明责任**。

## 五类内容身份

| 身份 | 能支持 | 不能支持 |
|---|---|---|
| 学术研究（实验/机制论文） | 特定材料、样本、操作化下的结果 | 任意作品的效果保证、普遍美学定律 |
| 一手创作／工程经验（Murch、Thom、Belkin、DeSantis 等） | 可转化为流程问题的方法建议 | 知觉科学结论、受众统计证据 |
| 官方标准／手册／机构材料（ITU、EBU、W3C、NIST、厂商手册） | 测量算法、处理机制、交付/可及性考虑 | 艺术适配或叙事效果；具体项目的合规结论（需读约定版本全文） |
| 本包综合（分类、流程、点位表、交接模型、模板） | 可用的工作方法 | 已存在的学派或已验证标准 |
| 自拟教学案例（洗发水广告、24 秒等待、同一房间三套世界等） | 演示方法如何落地；时间计算与代码可核验 | 听感、商业效果、受众结果 |

## 综合时的四条规则
1. **定义不互相吞并**：功能 ≠ 流派 ≠ 技法 ≠ 指标；表达的情绪 ≠ 听者感受的情绪。
2. **实验操作不被换成软件旋钮**：研究里被操纵的"线索"不能直接当插件参数。
3. **特定材料结果不升级为普遍效果**：尤其区分切分与被感知复杂度、音乐表达与听者感受、技术质量与艺术适配。
4. **原始事实、本文推演与待执行任务分开记录**。

## 应用
- 每个概念注明其论断属于哪种身份；引用了文献不等于综合模型已被实证。
- 未查阅完整标准时不宣称逐条合规；未通读著作时不虚构章节结论；只查摘要的来源在 [Reference](/references/) 中注明查阅层级。
- 没有真实片源、音频、受众数据时，只提出**假设与待验证项**（见 [关键待实践问题](/checklists/open-practice-questions.md)）。
