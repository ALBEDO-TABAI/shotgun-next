# 要点
- 示例：25 帧／秒时，最近帧量化的最大时间偏差为半帧 = **0.02 秒**；这是数学上最近帧取整的界限，**不是**所有声音都能容忍的同步标准。
- 音乐的精确拍点不需要全部吸附到帧边界：画面动作在帧上确定，音频内部仍按采样时间保持拍速。
- 关键是区分：哪些声音必须与动作作为**同一事件**（硬锚点），哪些只是软性情绪或段落变化。
- 显示值（如 C03 边界 7.068 秒）来自节拍计算的精确值，**不是第二个独立真相**，不应长期手动更新。

# 防止的交接问题
导演按秒确认、作曲按小节修改、剪辑按旧帧号移动——三个字段各自"正确"，却不再指向同一位置。
→ 媒体时间、帧索引、小节位置需有明确映射与来源（一个权威时间基准派生其余）。
