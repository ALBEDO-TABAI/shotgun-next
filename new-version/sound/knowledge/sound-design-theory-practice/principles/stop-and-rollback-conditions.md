# 来源
DeSantis《Diminishing Returns》讨论后期不断微调却不再有意义改善的问题（来源支持）；以下停止条件为**本包综合**。[2]

# 停止条件（同时满足）
- [ ] 当前任务已经完成
- [ ] 重要信息与技术条件通过
- [ ] 新增修改只是**平行口味**，而非清楚改善
- [ ] 可回退版本已保存

# 继续条件
- 仍有**明确缺陷** → 继续修。
- 只是"不能接受结束" → 不要用新增处理制造虚假进展。

# 记录什么
最有价值的历史记录是 **"这次为什么改、改后解决什么、失去什么"**，而不是全部插件参数长截图。正式交付仍需保留足够重开工程的文件和依赖。
