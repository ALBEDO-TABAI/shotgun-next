# 原则
把"音乐合适"改成评分表**不会自动增加科学性**。必须解释量表或任务怎样对应目标，以及还有哪些因素可能影响结果。

# Examples
- 用"这段让我觉得节奏清楚"评价运动组织，比问"专业吗"更接近对象；但仍不能独立证明镜头关系清楚。
- 用复述品牌名称检查记忆，能提供相关信息，但不能证明观众理解了产品用途。

# 每个指标加两项
| 项 | 说明 |
|---|---|
| 支持范围 | 这个指标能支持什么结论 |
| 替代解释 | 例：记住片尾声音，也许因为它特别突兀；更易复述旁白，也许因为已看过其他版本 |

# 保留组成信息
NIST 在变量选择指导中提醒，不宜只保存多个测量合成的结果而丢失组成项[2]。用于声音评审：**分别记录可理解性、喜欢程度、品牌归属**，而不只留下一个综合适配分。
