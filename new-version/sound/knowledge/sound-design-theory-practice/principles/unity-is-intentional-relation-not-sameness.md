# 原则
> **整体性不是同质性，而是关系有意图。**

# 示例（假设性设计）
1. 叶片摩擦最初属于环境细节；
2. 重复后成为节奏材料；
3. 其尾部被延伸为音乐纹理；
4. 最后又回到可辨认的叶片声音。

统一来自**变化链条可理解**，而不只是音色一致。

# 反向也成立
一部作品可以建立两个故意不相容的声音世界，只要它们的**交替、冲突或侵入有组织**。
