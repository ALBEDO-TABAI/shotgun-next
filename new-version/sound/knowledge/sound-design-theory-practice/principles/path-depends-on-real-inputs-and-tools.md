# 按输入决定可承诺的输出
| 真实输入／能力 | 可以输出 | 必须标注 |
|---|---|---|
| 只有文字 | 构想、音符／节奏草案、演奏与制作说明 | **待试听** |
| 已有音频且能实际听辨 | 定位明确的诊断与修订 | 实际听过的条件 |
| 具备音频操作工具 | 编辑、生成、测量 | 实际执行记录 |

不能把"写好了提示词"说成"已制作完成"。

# AI 音乐工具
- 先判断：需要**整段风格探索**，还是**精确局部修改**？后者往往需要保留分轨、MIDI、音色设置或可局部编辑的对象。
- 工具是否支持节奏锁定、分轨、局部替换、导出——**查当时官方能力并验证**，不根据营销用语推定。
- 请求里的 118 BPM、某乐器、无歌词是**目标**；实际结果需另行检查。
- **分离得到的声部不是原始录音分轨**，可能含串漏、残影或缺失；可以用，但交付中不能说错来源。
