# 原则

"越来越响"不是高潮的唯一（也常不是最好的）手段。分别尝试改变：

- 音区跨度
- 发音连续性
- 声部数量
- 节奏细分
- 和声移动

看哪种变化真正服务画面。

# 减法也是展开

前段细碎，后段只保留一条完整旋律，反而更像展开。

# 保留一种没用尽的资源

例如：第一次完整动机、第一次更长的呼吸、第一次宽空间、第一次低音明确落地。

# 边界

不要求每条片子有单一最大高潮；实验作品可以故意维持平台或拒绝完成。
