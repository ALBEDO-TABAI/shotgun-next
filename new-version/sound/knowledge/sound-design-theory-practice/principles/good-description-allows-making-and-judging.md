# 标准
- 让执行者知道**对象、方向、时间和边界**。
- 能产生**至少一种可听操作**，并告诉评审**什么变化算成功**。
- 只含评价词、只含技术数值或只含乐器名称，都不够。

# 反向解释检验
让另一位执行者用自己的话复述预期结果（不重复原文形容词）。若一人理解为减少音量、另一人理解为减少事件，接口仍未校准——用两个极简对照迅速确认，不必先做整条成片。

# 不要伪精确
| 没有… | 就不要… |
|---|---|
| 测量 | 报告小数点后的响度 |
| 听谱依据 | 声明精确和弦 |
| 真实剪辑 | 假装已完成逐帧 spotting |
