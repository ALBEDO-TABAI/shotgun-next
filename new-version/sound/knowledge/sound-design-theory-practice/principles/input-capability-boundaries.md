# 需要确认的输入
作品目标、剧本或剪辑版本、关键人物与空间、已有声音素材、传播条件、必须遵守的事实边界。

# 输入 → 允许的结论
| 手里有什么 | 可以 | 不可以 |
|---|---|---|
| 实际音视频 | 分析听到的关系 | — |
| 只有剧本 | 构想方案 | 把构想当原片事实 |
| 只有截图 | — | 把推测中的声音当成原片事实 |
| 只有转录文字 | 讨论语言内容 | 判断真实音色、距离、混音或音乐结构 |

# 产出（阶段 A）
> **已知条件、尚未确定的问题、允许提出的假设。**

不要直接生成风格词。
