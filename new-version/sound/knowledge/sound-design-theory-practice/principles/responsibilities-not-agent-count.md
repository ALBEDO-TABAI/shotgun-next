# 原则
AI 声音团队按**必须有人负责的判断**划分，而不是按传统职位清单或 agent 数量划分。

先问三个问题：
1. 哪些判断**必须有人负责**？
2. 哪些判断需要**不同的证据**？
3. 哪些任务在**边界明确后可以独立完成**？

# 不可缺少的责任（无论团队多小）
| 责任 | 说明 |
|---|---|
| 目标解释 | 把作品任务解释为声音任务 |
| 时间线决策 | 入点、出点、留白、交接 |
| 声音制作 | 音乐、音效、素材的实际产出 |
| 关系整合 | 混音与层次，前后景安排 |
| 验证 | 真实文件对照目标与规范 |
| 最终批准 | 谁批准、在什么范围内 |

# 依据与推论
- 一位创作者可兼任音乐统筹、剪辑与声音设计；复杂项目也可能多人共担同一职责。
- 音乐编辑的职责可能贯穿初期 spotting、临时音乐、剪辑变化与终混协作，而不只是最后剪一首歌（来源支持：Berklee 职业说明）。
- 声音应参与上游构想（Randy Thom 一手创作论述）。转入 AI 制作后，不应因为生成音频方便就把声音压回最后一个装饰环节。
- 证据身份：职责划分为**本包综合**；两条依据为职业说明与创作经验，**不是**效果实验。
