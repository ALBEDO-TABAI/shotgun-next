# 八轴
| 适配轴 | 观察问题 | 不宜采取的捷径 |
|---|---|---|
| 任务适配 | 是否完成此段最重要的工作？ | 曲子好听就默认完成目标 |
| 情绪与态度 | 表达强度、距离和转折是否合适？ | 用单一情绪词覆盖整段 |
| 结构与时间 | 乐句、转折和片长能否合理组织？ | 必须每个切镜都卡拍 |
| 动作与材质 | 发音、持续、运动与对象如何呼应？ | 某种乐器天然属于某种材料 |
| 语义与文化 | 歌词、熟悉度、使用历史带来什么联想？ | 按年龄、国籍或性别直接配流派 |
| 声音空间 | 能否与对白、环境及音效共存？ | 后期降音量就能解决一切 |
| 作品身份 | 是否形成自身规则和可识别关系？ | 与竞品越像越安全 |
| 制作与权利 | 能否编辑、取得所需版本并合法使用？ | 已下载或已付款就认为所有用途获准 |

# 写法
不要求量化。写**证据与风险**：
> 当前试剪中，副歌第一句的歌词与旁白争夺理解；器乐版本尚未获得，因此可用性未确认。

比"适配度 87 分"更能指导下一动作。

# 有意冲突
历史背景中的现代音乐可能追求当下感而非时代写实 → 记录为**有意选择**，并检查作品是否建立了这种用法，不假装音乐符合历史。
