# 要点（来源支持）
- 听出悲伤 ≠ 自己正在悲伤；欣赏一种悲伤表达也不等于体验不愉快。[2]
- 在视听层面，Ansani 等用特定模糊场景与不同音乐条件，考察观众对人物、情境与可能剧情的判断——值得研究的结果远不止"好不好听"；但刺激和任务有限，不能把某曲结果移植到另一条广告。[3]

# 对工作的含义
- 评估时分别问："音乐像在表达什么？" 与 "观看时你自己有什么感受？"——混成一个问题会使答案无法解释。
- 若目标是尊重地呈现失落、让观众保持思考，受测者**没有报告强烈悲伤不一定是失败**。
- 本篇因此不建立"某种音乐必然使观众怎样"的查表系统，而建立 **任务假设—形式选择—证据—复核** 回路。

# 边界
依据为期刊页面与摘要；不把两者视为必然一致，也不视为必然分离。
