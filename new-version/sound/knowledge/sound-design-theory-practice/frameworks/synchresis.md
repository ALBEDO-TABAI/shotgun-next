# 概念（来源支持）
Chion 用 **synchresis** 描述同时发生的视觉与听觉事件被感知为相互关联的融合现象，为声音与画面的**创造性重新配对**提供理论解释。实验层面，Shams、Kamitani、Shimojo 的研究展示听觉信息可以改变视觉知觉——但它只支持跨感官相互作用的存在，**不证明**某种广告音效必然产生某种情绪或品牌判断。

# 错误简化
> “只要同步，任何声音都能配任何画面。”

# 更合适的创作测试
1. 同步是否建立了关联？
2. 声音的**运动、材料感和上下文**是否支持我们希望观众接受的那一种关联？

# 根本变化
声音不只“给图像加情绪”，还可能参与决定：这是什么物体、有多大、动作是否有力、空间是否真实、事件是否已完成、我们是否相信眼前发生的事。→ 整体声音设计应与**摄影、美术、动作设计和剪辑**共同讨论，而不只与配乐讨论。
