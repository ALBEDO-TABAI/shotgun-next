# 定义（本包综合）
> 围绕作品的表达目标，组织声音的**来源、可听性、空间、时间、听觉立场、注意力层级和变化规则**，并使它们与画面、表演、剪辑及传播条件共同成立。

“整体听觉世界设计”是本次整理采用的工作概念，**不是某个现成学派的正式名称**。

# 设计对象：作品如何规定
- 什么能够被听见；
- 从哪里被听见；
- 由谁来听；
- 哪些声音构成同一件事，哪些彼此竞争；
- 这些关系怎样随时间变化；
- 以及**哪些声音缺席**。

# 为什么声音清单不等于设计
清单“旁白、脚步、风声、机械声、电子音乐、片尾提示音”仍未回答：旁白是解释事实还是角色记忆？脚步是交代动作还是追踪看不见的人？机械声是背景还是逐渐被听成威胁？电子音乐与机械声融合还是故意不相容？——决定体验的是**关系**，不是素材。

# 边界
- 不等于把音乐、对白、音效、环境声全部填满；
- 不等于让所有声音拥有同一种风格（见 [整体性不是同质性](/principles/unity-is-intentional-relation-not-sameness.md)）；
- 声音应参与上游创作决策，声音影响画面、画面也影响声音（Thom 的一手方法观点）。
