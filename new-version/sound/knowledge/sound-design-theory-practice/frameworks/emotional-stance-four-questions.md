# 四问（工作区分，不宣称是四个独立心理系统）
1. 音乐听起来表达什么？
2. 观众自己感到什么？
3. 观众认为人物感到什么？
4. 作品邀请观众以什么态度对待人物？

角色在庆祝，观众却可能感到危险；忧伤音乐也可能带来安慰、审美享受或同情。

# 从标签到立场描述
- 弱："悲伤"。
- 强："人物表面轻松；观众逐渐意识到他在回避；作品保持关切，不嘲笑他的自我保护。"——限制了戏谑程度、进入时机与表达强度。

# 情绪是有方向的过程
- "安心"是状态；"先建立安心，再暴露安心依赖一个脆弱条件"是结构。
- 可以材料不变、只改变完整程度或关系：同一动机第一次完整、第二次被打断、第三次由人物实际演奏。
- 过程不意味着必须有传统高潮；需要避免的是未确定意图就默认每段都要更强、更积极、更易懂。
