# 对照表
| 方式 | 能回答 | 局限 |
|---|---|---|
| 只听声音 | 声轨自身的段落、空间、材料关系 | 失去画面后产生的新联想不一定是完整观看的体验 |
| 全片静音 | 视觉与文字本身提供了什么 | 同时拿掉音乐、人声、动作、环境，不能把差异全归因于配乐 |
| 只撤去音乐 | 更接近检查音乐贡献 | 需要可信分组；对终混做算法分离，差异会混入分离痕迹 |
| 独听某分组 | 发现处理细节 | 不代表终混中观众能听到同等程度；为融合设计的层独听时奇怪不代表失败 |
| 算法源分离 | 辅助辨听、提出假设 | 不是创作者原始分轨或真实制作来源 |

# 规则
报告要写明**比较改变了什么**。说"无配乐版更真实"前，确认是否只去掉了配乐，还是连同环境、底噪或动态一起改变。对照方法不清，结论就容易过度。
