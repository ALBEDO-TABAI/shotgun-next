# 定义（本包综合的工作分类）
一条广告的声音可以技术很干净但旁白难懂；可以讨喜却使人误认产品类别；也可以不悦耳却准确完成令人不安的剧情。它们不是同一个分数的不同说法。

| 面向 | 核心问题 | 不能被什么替代 |
|---|---|---|
| 表达适配 | 是否完成了这部作品、这个段落的表达任务？ | "这首歌好听" |
| 形式与审美 | 材料、结构、变化和关系是否构成有意图的组织？ | 没有技术瑕疵 |
| 感知与理解 | 观众是否注意、辨认并理解了需要理解的内容？ | 波形上存在、平均响度足够 |
| 技术与播放 | 同步、文件、动态、声道和目标设备表现是否符合约定？ | 创作者耳机上满意 |
| 事实、权利与责任 | 有无误导事实、未确认的素材使用、不当交付？ | 创意效果好 |
| 项目目标 | 对品牌识别、传播等目标有无可支持的贡献？ | 受众说"有感觉" |

# 使用要点
- 每次评价**先说明自己在判断哪个面向**。
- 不反过来要求所有作品满足同一套商业目标：实验影像可主动让声源不明，剧情片可能需要错误预期。此时评估不确定性**是否有组织、是否符合任务**，而不是把"一切容易理解"设为唯一标准。
