# 问题
常见无效试听：十个人从不同角度提意见，最后改得最多的版本成了"大家都能接受"的版本。

# 四种轮次
| 轮次 | 判断什么 | 方法要点 |
|---|---|---|
| 方向轮 | 声音世界与声画立场是否合适 | 比较完整方向合理，不必假装只改一个变量 |
| 实现轮 | 已选方向怎样执行更好 | 尽量控制其他因素，比较入点、配器活动、声效密度等具体变化 |
| 问题定位轮 | 已发现的困难由什么造成 | 拆分可能原因，而非继续找"整体更好听"的替代素材 |
| 交付轮 | 约定版本是否满足发布条件 | 不以未讨论过的审美偏好推翻上游决策；也不因临近交付忽略新的事实或技术阻断项 |

# 原则
实验设计由**目的、因素和需要获得的结论**驱动，而不是先选熟悉的检验形式[2]。每轮开始前写一句 [本轮决策句](/templates/review-round-decision-sentence.md)。
