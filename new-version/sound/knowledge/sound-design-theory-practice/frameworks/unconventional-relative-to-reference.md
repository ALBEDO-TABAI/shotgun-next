# 核心区分
素材奇特 ≠ 非常规。某声音对某类型片常见、对日常生活不常见；某合成音对一群人熟悉、对另一群人难以识别。**判断非常规必须指出被偏离的参照。**

# 五类参照
| 参照来源 | 示例问题 |
|---|---|
| 现实因果 | 薄纸为什么听起来像重型机械？ |
| 故事常态 | 平时规律运转的机器，现在为何像在呼吸？ |
| 形式规则 | 一直完整的音乐短句，最后为何少了结尾？ |
| 文化语境 | 庆祝音乐为何持续在失败场景中？ |
| 媒介约定 | 作品为何突然撤去本应持续的全部声音？ |

# 设计问题的标准写法
> 观众原本有理由期待什么？我们改变哪一项、保留哪一项，以便形成什么关系？

- 没有已建立或可合理借用的预期，就不能假设观众一定体验到"预期被打破"。
- **非常规不一定令人不安**：它也可以让对象更轻盈、更有生命感、更幽默，或给抽象画面以触觉联想。把所有非写实声音都导向恐怖，会大幅缩窄创作空间。

证据身份：本包综合（工作定义）。
