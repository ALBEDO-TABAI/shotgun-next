# 五种变化
| 维度 | 方向示例 |
|---|---|
| 数量 | 少 → 多 |
| 频谱 | 集中 → 扩散 |
| 时间 | 孤立 → 连续 |
| 空间 | 贴近 → 展开 |
| 来源 | 可辨认 → 模糊 |

每一种都应说明**起止和触发条件**。

# Examples
```text
开始只有一颗可辨认的水滴；第二次开始出现类似的短音回应；
第三段不再要求辨认每一颗，而让它们形成轻量节奏；
到头发舒展时撤去大部分颗粒，保留连续运动。
```
同时规定了听法、结构与材料变化。

# 解开矛盾词
- ✗ "稀疏但密集、轻柔但强烈、克制但炸裂"
- ✓ "整体事件稀疏，但唯一关键接触的音头清楚；持续层柔和，转折时短暂有力。"——分到不同**层**或不同**时间**。
- 若矛盾无法解开，回到**目标取舍**，而不是无限增加提示词权重。**语言的任务是暴露冲突，不是掩盖冲突。**
