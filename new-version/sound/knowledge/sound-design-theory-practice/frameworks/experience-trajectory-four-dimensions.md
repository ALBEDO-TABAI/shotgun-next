# 从方向词到轨迹
"梦幻、轻快、清爽、愉悦"只是方向词。至少补出：**起点、过程、转变条件、终点**。
例："开始是日常里细小的杂乱；注意被一片叶子的水滴收拢；进入微观世界后出现轻盈秩序；最后回到舒展的使用体验。"→ 决定音乐是否一开始就完整、何时形成拍点、何时减少颗粒、结尾是否需要强高潮。

# 四个并行维度（本包综合）
| 维度 | 问题 |
|---|---|
| 信息 | 观众知道了什么？ |
| 情绪 | 他们可能怎样感受？ |
| 关系 | 靠近或疏离谁？ |
| 身体与形式 | 节奏、空间、动作怎样变化？ |

四维可以不同步：人物刚获得信息时情绪尚未跟上；画面已开阔，声音仍可暂时贴近。

# 商业 vs 非商业
- 商业：追问"这段体验最终与什么具体品牌/产品意义相连？"——观众喜欢奇幻场景却不知产品是什么 = 体验与信息目标未连接。
- 非商业：不强加购买/记忆目标；可以规定保持开放问题、让重复被身体感知、不替人物下结论。
