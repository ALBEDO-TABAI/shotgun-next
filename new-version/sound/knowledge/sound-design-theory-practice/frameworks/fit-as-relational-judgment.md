# 工作定义（本包综合，非已验证单一量表）
> 在约定表达目标、观众情境和生产约束下，一个声音方案能够完成重要任务，同时其代价、误读与限制可被接受。

# 候选 = 用法，不是文件
我们选择的是**某段音乐以某种用法进入某个视听系统的方案**，至少包括：
1. 音乐材料
2. 使用片段
3. 时间安排
4. 与其他声音的关系

只比较曲名不比较用法 → 把可修复的入点问题误判为"根本不合适"，或把恰好剪顺误认为曲子有普遍优势。

# 没有永远有效的总评分
一个方案更有辨识度，另一个更易剪辑，第三个更适合对白，第四个更诚实地保留事实。决策需明确**当前最重要的矛盾**，而不是把形容词加总。
