# Schema
> **创作目标 → 要判断的概念 → 可观察表现 → 测量或提问方式 → 决策规则**

# Examples
目标"让品牌在结尾被认出"至少分出三个问题：
1. 听众是否**注意到**结尾声；
2. 重复播放时是否**认出**它；
3. 能否把它与目标品牌**正确关联**。

第一项不等于第三项。

"这段显得清爽"可以指：音乐本身听起来轻盈／产品触感被想象为清爽／观众当下感到舒适。研究区分**音乐所表达或被识别的情绪**与**听众自身产生的情绪**[2]；项目评价也不应混写。

# 边界
指标之间可以相关，但**需要具体研究设计来建立关联**，不能在汇报时自动升级。广告音乐契合与涉入的研究能帮助提出待测变量，却不能把某个音乐特征换算成广告转化[3]。
