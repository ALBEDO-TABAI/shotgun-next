# 概念（来源支持）
Albert Bregman 的 **Auditory Scene Analysis** 研究听觉系统如何把混合的声音输入组织成可感知的声音结构；相关研究讨论**共同起始、相似性、随时间共同变化**等组织线索。不同来源可以形成一个知觉整体，同一来源也可能被听成不同的流。

> **轨道是工程组织单位，听觉流是知觉组织单位，二者不一一对应。**

# “统一”的两种意思（假设示例）
产品展开镜头：机械动作声 + 音乐短音 + 空气流动声 + 低频变化 = 制作上四层。
- 方案一：设计为**同一次运动的不同侧面**，观众主要感知“产品展开了”；
- 方案二：音乐维持连续背景，只让机械动作**清楚独立**。

设计问题：**这些声音应该被听成“一件事”，还是“几件彼此有关系的事”？**
不是所有重叠都叫拥挤，也不是所有融合都叫高级。

# 边界
不能由此推出固定“最多几层声音”的制作法则（“同时最多三个声音”之类经验说法不是普遍听觉定律）。
