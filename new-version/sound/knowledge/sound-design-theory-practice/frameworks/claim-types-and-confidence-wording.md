# Schema
| 声明类型 | 合适依据 | 可用表述 |
|---|---|---|
| 可听事实 | 同一版本可复查位置 | "在该区间可辨认到……" |
| 制作事实 | 原始资产、作者资料、可靠制作记录 | "制作人员在文中说明……" |
| 形式规律 | 多位置比较与反例检查 | "这些段落共享……；另有例外……" |
| 功能解释 | 声画证据、上下文、替代解释 | "这支持一种理解……但不能排除……" |
| 观众结果 | 实际测试设计、样本与反馈 | "在本次条件下，参与者报告……" |
| 未执行构想 | 清楚的设计假设 | "可测试的方案是……" |

# 置信规则
- 不随手给每行加"高／中／低"。若用等级，**附原因**：
  > "声源身份低确定，因为只有最终混音且未找到制作资料；进入时机高确定，因为有可复查波形和完整片段。"
- 同一事件的不同字段可以有不同确定程度。
- 不用虚构百分比制造精确感。

# 引用 ≠ 直接证据
- 论文证明某现象**可以**发生，不代表它已在当前作品发生。
- 十篇二手评论重复一种解释，不一定比一个可核查的声画观察更能支持作者意图。
