# 核心问题

理论包（《一.md》及第二至第十篇）建立了声音任务、声画关系、时间线、分析与评价框架；实践包补上中间缺失的一层：**怎样把需求变成可以演奏、试听、编辑、局部返修的声音材料。**

"想要轻盈、亲密、有张力"是创作目标；"写下哪几个音、怎样发声、在何处停止"才开始成为音乐本身（见 [音乐中的想法 vs 关于音乐的想法](/principles/musical-ideas-vs-ideas-about-music.md)）。

# 主线（本包综合）

**需求翻译 → 小型声音实验 → 可发展材料 → 作曲与编配 → 演奏／录音／合成与编辑 → 视听混音 → 有针对性的修改**

- 可往返，不是瀑布：音色先行的作品可从采样开始；主题鲜明的作品可从哼唱开始；时间严格的广告可先写结尾和关键落点。
- 旁证：Berklee 影视配乐课程纲要把主题写作、主题改编、配画面、声音设计型音乐、对白下配乐、MIDI 模拟制作放在同一能力链（仅查公开纲要）。

# 七个模块与产物

| 模块 | 核心工作 | 交给下一步的产物 |
|---|---|---|
| 1 翻译需求 | 体验、任务、限制 → 创作问题 | 一页 brief、关键窗口、少量明确假设 |
| 2 构想方案 | 用真正不同的声音策略探索 | 2–3 个短草稿及其可编辑来源 |
| 3 作曲编配 | 材料发展成段落与声部关系 | 音符／节奏／纹理、编配图、完整音乐草稿 |
| 4 演奏录音 | 乐谱与动作 → 有意图的发声 | 选定 take、MIDI 表情、可复用干声与尾部 |
| 5 声音制作 | 为物体、空间、主观体验造材料 | 单体音效、变体、编辑好的对白与环境 |
| 6 混音完成 | 组织声音之间的可听关系 | 视听混音、分组输出、目标媒介版本 |
| 7 优化迭代 | 定位原因并改对应层级 | 局部修订、对照依据、可回退版本 |
