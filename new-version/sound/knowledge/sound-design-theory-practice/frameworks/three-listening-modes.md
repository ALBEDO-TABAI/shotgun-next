# 三种模式（来源支持；还原聆听承接 Pierre Schaeffer）
| 模式 | 核心问题 | 工作用法 |
|---|---|---|
| 因果聆听 Causal | 什么正在发声？发生了什么？ | 判断材料、动作、距离、可能声源 |
| 语义聆听 Semantic | 按某种语言或编码表达了什么？ | 理解对白、广播、约定信号与提示 |
| 还原聆听 Reduced | 暂不考虑来源与意义，声音本身是什么样？ | 观察音高、颗粒、起伏、持续、断裂、音色变化 |

- 三者**可以交叠**，不是从低级到高级的排序。
- “还原”不是降低音量，也不是还原真实录音，而是**暂时搁置“谁发出来的”“意味着什么”**。

# 同一声音可承担不同任务
设计改变的是**观众被邀请采取的聆听方式**，而不是给素材换分类。示例见 [敲门声的三次聆听](/cases/knock-three-listening-modes.md)。

# Skill 字段
> **预期主导聆听模式**：此刻希望观众辨认来源、理解信息，还是感受声音形态？是否需要发生切换？

这比“它是音效还是音乐”更接近表达任务。

# 边界
隐藏声源不会自动把观众推入还原聆听，见 [隐藏声源不等于抽象](/principles/hidden-source-is-not-abstraction.md)。
