# 四段
| 段 | 作用 |
|---|---|
| 建立 | 给观众一个可理解的联系 |
| 承受 | 维持一定偏离，让体验展开 |
| 转化 | 逐渐放松现实约束（或改变听法） |
| 回收 | 决定是否返回现实锚点 |

# Examples
- **正向**：水滴起初严格对应画面 → 尾部变短动机 → 进入不再逐滴同步的音乐纹理 → 回到产品实体时一个清楚接触声重新建立现实锚点。这是段落设计，不只是音效加工。
- **反向**：先出现无法识别的声音 → 揭示它来自普通物体。价值在重新理解，而非持续陌生。揭示后观众已知来源，原悬念任务可能结束 → 声音应获得新工作或退出。

# 强度轨迹
