# 四级（项目管理建议）
| 等级 | 含义 | 示例 |
|---|---|---|
| 阻断问题 | 必要条件不能满足 | 错误剪辑版本；关键素材权利未确认；约定的重要信息无法被理解 |
| 实质问题 | 削弱主要任务，可通过限定修改解决 | 入点过早泄露转折；声效与音乐争夺同一事件 |
| 局部问题 | 影响细节完成度 | 单次接缝；尾音截断 |
| 偏好差异 | 多个可成立方案之间的选择 | 不应伪装成客观缺陷 |

# 要点
- 按**对已批准任务的影响**判断，不按提出者声音大小。
- 严重性仍取决于作品：一个极短接缝若破坏关键寂静，也可能是实质问题。
- **停止修改**的依据不是"再也没有人能提意见"，而是：必要条件通过、主要任务有足够支持、剩余差异已被明确接受，并保留决策记录。
