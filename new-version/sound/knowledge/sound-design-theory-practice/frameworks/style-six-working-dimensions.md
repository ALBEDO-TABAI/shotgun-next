# 六个维度（便于制作的工作拆分，非完整音乐学分类）
1. 音乐语汇
2. 节奏组织
3. 音色材料
4. 演奏方式
5. 录音空间
6. 声画用法

# 为什么要拆
两条都叫"电子"：一条拍点精确、音头锋利、空间集中；另一条无稳定脉冲、起音缓慢、空间弥散。都放进"科技音乐"会掩盖真正决定适配的差异。

# 融合规则
- 先选**一个组织核心**：如节奏规则稳定、音色在木质与合成之间变化；或动机轮廓一致、演奏空间由近到远。
- "一个组织原则＋有限的异质材料"是构想，**不是数量定律**；关键是异质性被赋予关系（现实 vs 记忆？一种材料逐渐转化为另一种？）。观众不必知道材料名，但要能经历其关系。

# 风格名的弹性
"极简""氛围""有机电子"可作检索入口；委托与验收须落到可听行为。标签正确不能掩盖"音乐在旁白区不断提出新旋律"的问题。
