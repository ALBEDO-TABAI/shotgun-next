# 四种触发（本包工作分类）
| 类型 | 例 | 要点 |
|---|---|---|
| 事件触发 | 碰撞、门开、人物出现、装置启动 | 动作与声音关系明确，但不是每个动作都要额外强调 |
| 理解触发 | 观众刚意识到物体的意义；表情被重新理解 | 需要强调的可能在动作**之后** |
| 状态触发 | 日常→主观；散乱→稳定；共同活动→独处 | 是一段过程，可能没有唯一帧 |
| 形式触发 | 重复完成、断裂、回收 | 适合非剧情中心内容，但需可感知规则 |

# 为什么要命名
- 锚点是"人物意识到对方不会回来" → 镜头延长后不能让音乐固定在旧时间码。
- 锚点是"瓶盖脱离" → 跟随动作帧，而非旁白段落移动。
