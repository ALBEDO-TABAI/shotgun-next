# 模板（本包综合）
**接近 → 接触 → 受力／变形 → 运动 → 停止／余振**

描述感知重点，而非物理模拟。分析不只记"用了水声"，而问：水被理解为细小、连绵、黏稠、脆弱、充沛，还是人工装置的一部分？

# 例
- 瓶盖开启：只强调**阻力解除**瞬间，或保留开启前的**犹豫**——操作体验不同。
- 头发掠过镜头要柔软流动：优先构想动作连续、摩擦细度、空间让位；加厚重冲击会把同一运动解释成强力甩动。
- "身体感"不能只写成低频数量；问题是音效、音乐与画面共同呈现了什么动作，不是某频段天然属于什么产品。

# 非商业用法
可故意解除稳定来源（皮肤？布料？空气？）；需确认不确定性本身是目标，而非制作不清造成的事故。
