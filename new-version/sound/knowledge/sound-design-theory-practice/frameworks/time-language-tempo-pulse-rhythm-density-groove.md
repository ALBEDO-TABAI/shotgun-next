# 六个概念
| 概念 | 定义要点 | 常见误用 |
|---|---|---|
| 速度（tempo） | 参考拍单位进行多快；**必须说明一拍是什么**（四分音符 vs 附点四分音符同数值不是同一组织） | 只写一个数字 |
| 脉冲／拍点 | 可被跟随的周期参照；可以存在而无明显鼓组 | "没有鼓 = 没有节奏"；"有拍点 = 每拍都要打出来" |
| 节拍与拍号 | 拍的分组与强弱组织 | 先用记谱术语阻塞非专业沟通；应先说听觉行为（"每四拍一个循环，第三拍不强调"） |
| 节奏 | 实际事件怎样分布：长短、重音、休止、切分 | 与速度混为一谈 |
| 事件密度 | 单位时间内可辨认变化的数量；速度不变密度可增减，慢拍也可有密集细分 | 用降 BPM 解决"太忙" |
| 律动（groove） | 人如何体验声音的运动与可跟随性 | 缩成"量化不齐"；轻微时值差不自动自然，完全精确不自动僵硬 |

# 写法
描述**哪一层稳定、哪一层松动**，以及动作如何与之建立关系。

# Examples
```text
✗ 慢一点但又更有节奏
✓ 参考拍速保持不变；先减少高频连续细分，让主要拍点仍可跟随。
  只在体验释放段增加短音回应，不把所有动作都做成重拍。
```
