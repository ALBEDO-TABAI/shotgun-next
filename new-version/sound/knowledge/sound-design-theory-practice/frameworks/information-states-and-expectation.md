# 三份信息状态（本包综合）
| 状态 | 例 |
|---|---|
| 人物知道什么 | 人物没听见门外脚步 |
| 观众知道什么 | 观众听见了，但不知道是谁 |
| 作品目前允许确认什么 | 暂不揭示身份 |

声音要保护哪一种差距，应在选曲前明确。线索不一定是明确消息，也可以是尚未解释、逐渐获得含义的规律。

# 期待（来源支持 + 局部假设）
- Huron 的音乐期待研究提供理论方向（仅查出版社介绍），不据此宣称某种不协和或延迟必然引起惊恐。[2]
- 局部假设写法：某短句两次完整出现，第三次停在惯常结束之前——观众会注意到未完成吗？前提是前文**真的建立了规律**，而不只是说明书里写了。

# 自拟例：钥匙声的缺席
人物每次安全回家都把钥匙放桌上，伴随普通金属接触声；最后一次没有。缺席是否成为线索取决于前面展示是否自然可辨认——**不能把创作者脑中的符号系统当成观众已学会的系统**。

# 风险：过早替故事下结论
陌生人尚未行动时用极端威胁性配乐，会把"他是谁"提前转成"他何时作恶"。可以这样做，但必须是叙述决策，而非按面孔套类型音乐。
