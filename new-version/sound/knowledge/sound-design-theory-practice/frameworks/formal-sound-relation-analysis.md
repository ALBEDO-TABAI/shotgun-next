# 基本维度（来源支持）
Yale 声音分析材料分别处理**叙事归属、画内画外、时间、声音透视**等维度[2]。它们帮助描述，但**术语本身不能说明当前作品中的作用**。

# 术语后必须追问的问题
| 术语 | 还需追问 |
|---|---|
| 画外声 | 来源是否已知？是否被人物听见？是否改变空间预期？ |
| 非叙事内音乐 | 怎样进入？与谁共情？是否跨场形成结构？ |
| 主观声音 | 作品中有何感知依据？（看到低通处理不自动成立） |

# 形态描述
Smalley 的频谱形态学适合在**声源模糊**时分析起势、持续、纹理与变化[3]。本篇建议：先以可听变化组织事实，再讨论象征。听到"由稳定转为碎裂"，可以先说"结构破碎"；解释为"记忆崩解"需要额外语境。

# 单次事件 vs 规律
- 两个相似声音未必构成主题；一个节奏短暂与剪辑对齐不等于全片组织原则。
- 规律需要**跨位置比较**，并记录其变体和例外。
