# 四步（本包综合）
| 步骤 | 作用 | 失败样态 |
|---|---|---|
| 唤起 | 说明此刻有变化 | 冲击音只唤起未指向 → "吓了一下但没看清信息" |
| 指向 | 说明应关注哪里／什么 | 指错对象（停在转场而非产品名） |
| 保持 | 让未解决事件继续占据心理位置 | 过早释放，悬置消失 |
| 释放 | 允许注意转向下一件事 | 连续强调不释放 → 每个动作同样重要 |

设计问题：要让观众寻找来源、注意细节、等待动作完成，还是从主体移向画面边缘？

# 教学例（自拟）
人物翻找抽屉。
- A：每次翻动都有清晰声音；B：大部分动作普通，仅触碰旧照片时改变近距离细节。
- B 的假设不是"声音少所以高级"，而是让照片从搜索背景中脱离。若剧情要表现**混乱而非发现**，A 反而更合适。

# 记录与修改
- 记录**被强调的对象**，不只是强调手段："这个音头使注意停在转场，而我们希望观众读完产品名。"
- 修改不必立刻换音效：可延后音头、延长信息停留，或把强调交给画面。
