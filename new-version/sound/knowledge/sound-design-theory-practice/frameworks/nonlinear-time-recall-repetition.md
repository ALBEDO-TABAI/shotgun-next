# 三种时间要分开记录
事件时间｜呈现时间｜声音何时获得新意义。

# 重复场景
第二次展示同一场景，声音不必照搬第一次：
- 补充首次没有听到的内容；或
- 维持声音不变，让新画面改变其解释。

例（自拟）：第一次只听见关门声，人物无反应；第二次回看时让观众注意到关门前的一次迟疑——重点不是把关门做得更响，而是决定**哪部分先前被保留、哪部分现在成为前景**。

# 点位表补充字段
- **所属事件**
- **本次呈现用途**

同一声音资产可在多处出现，但**文件相同不代表意义相同**。

# 回忆 ↔ 现实的返回策略
突然中断｜与现实声重合｜保留一层继续影响人物——这些选择决定观众何时理解已回到当下。

# 抽象作品
标记材料在形式中的**第几次出现**、哪些属性变化；"事件"是形式单位，不必虚构角色记忆。
