# 设计问题
**什么保持不变、什么允许变化、变化怎样被认作同一个东西**——而不是复制同一段素材。

# 候选身份特征（本包综合）
旋律之外：节奏轮廓、发音方式、材料组合、停顿习惯。"可能成为身份" ≠ "已形成识别"，要检查前后出现是否真的建立了关系。Berklee 影视作曲课程把主题发展、角色与场景表达纳入训练范围。[2]

# 三种记忆要分开
Boltz 实验摘要：研究条件下情绪一致与不一致的音乐／影片配对呈现不同编码与回忆模式。[3]
→ 分开 **记住曲子 / 记住场景 / 记住二者关联**；"朗朗上口"不能替代品牌记忆或人物理解。

# 自拟例：品牌结尾三个短音
容易被记住，却可能与产品无关。改进：在产品关键动作中建立同一节奏关系，结尾回收——需比较"听过曲子"与"认出品牌"两个结果。

# 防止主题泛滥
人物、地点、道具、每种情绪各有提示 = 大量待学习编码。是否建立声音身份，取决于作品是否会用到其辨认、变化与回忆收益。
