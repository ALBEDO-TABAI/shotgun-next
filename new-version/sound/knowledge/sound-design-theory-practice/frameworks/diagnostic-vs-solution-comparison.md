# 两种比较
| | 诊断比较 | 方案比较 |
|---|---|---|
| 目的 | 定位原因 | 比较完整方案 |
| 变量 | 只改一个，其余（音符、节奏、时间线、近似响度）保持 | 多个变量协同改变 |
| 例 | 判断"铃状音色是否导致幼稚感"：只换发音 | 换成弓弦类声源后，发音、音长、表情都要重写 |
| 能证明什么 | 该变量是否相关 | 哪个整体方案更好，**不**隔离单一原因 |

# 规则
- "一次只改一个"**不是永久规则**。关键是清楚这一轮是**定位原因**还是**比较完整方案**。
- 诊断有帮助后，再根据新音色重新调整演奏。
