# 拆分表
| 模糊目标 | 更明确的待评估问题 | 不足以单独证明的指标 |
|---|---|---|
| 更有记忆点 | 记住旋律、声音形态、产品，还是品牌归属？ | 当场说出"刚才有个声音" |
| 更感人 | 认为人物悲伤、对人物共情，还是自身悲伤？ | 给音乐贴"悲伤"标签 |
| 信息更清楚 | 听清字词、理解句意，还是记住产品要点？ | 对白峰值高于音乐峰值 |
| 更沉浸 | 注意持续、空间可信、叙事投入，还是设备包围感？ | 声道更多、混响更长 |
| 更有购买欲 | 自述意愿、点击行为，还是实际购买？ | 音乐喜欢程度较高 |

# 使用
- 反馈会上出现模糊词时，先用本表把它拆成一个或几个可检查问题，再选方法。
- 右列指标可以作为线索，但不能在汇报中自动升级为左列结论（见 [评价链](/frameworks/evaluation-chain-goal-to-decision.md)）。
