# 五个相关但不同的量
| 量 | 说明 |
|---|---|
| 瞬时峰值 | 一个音的峰 |
| 整体响度 | 一个片段的节目响度（BS.1770 定义测量算法）[2] |
| 前后强弱关系 | 段落对比 |
| 演奏力度 | 音乐表现上的强弱 |
| 体验能量 | 听者感受到的能量 |

- BS.1770 是测量算法范围，**不是审美评分**，也不直接给出观众耳边声压（还受设备、音量、环境影响）。
- 归一到同样峰值 ≠ 主观响度匹配。

# "高潮不够"的五种可能
1. 前面没有留空间
2. 和声与乐句没有完成
3. 动作缺少关键对应
4. 配器没有形成对比
5. 确实需要更大响度变化

先确定缺哪一种，避免直接压缩或限幅把整段做得更响。

# Examples
```text
从第一个段落到体验段，优先通过音区、材料和事件关系展开；
终混后再检查是否需要小幅响度变化。不要让片尾标识成为整个片子最突兀的声音。
```
规定的是**发展策略**，不是未经听音的数值处方。

# 边界
具体响度、真峰值、声道与文件规格应来自**交付要求**；不在风格 brief 里混入一个声称适用于所有平台的目标值。
