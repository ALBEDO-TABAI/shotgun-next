# 七种关系（创作选项，非互斥流派，无默认优先级）
| 关系 | 核心任务 | 最需要检查的风险 |
|---|---|---|
| 支持 | 声画共同集中一个意义 | 重复注释，过早替观众下结论 |
| 补充 | 提供画面未明确表达的一层 | 无依据补出人物心理或事实 |
| 预示 | 在事件前建立等待或方向 | 把开放悬念提前泄露 |
| 延迟回应 | 先看到，再处理后果 | 被误认为音乐错位或缺支撑 |
| 冷漠持续 | 音乐不随人物事件改变 | 被理解为嘲笑，而非世界继续 |
| 对照／反讽 | 声画产生可解释矛盾 | 只剩猎奇、轻浮或道德误导 |
| 形式并行 | 声画各有结构，时合时分 | 两者没有可追踪的关系 |

# 使用规则
- 补一个**因果句**："因为这段要让观众先相信人物的平静、再发现其不稳，所以音乐暂不直接表达悲伤。"——把审美口味转成叙述策略。
- "音乐站在人物一边"要具体化：分享人物当下感受，或保持关切却不接受人物对现实的解释——导向不同音乐行为。共情 ≠ 无条件复制人物情绪。
- 抽象影像：先比较声音与画面的**运动规则**（画面渐密，音乐可同样增加事件，也可保持简单，让复杂度差异成为结构），不虚构人物心理。
