# 入口问题
- 有没有明确中心？多久变化？是否回到某处？哪些声音持续不动？
- 非调性、噪声或纹理音乐：**不强行套传统功能和声语言**。

# 目标写法（不预设手段）
| 目标 | 描述 | 不要自动等同为 |
|---|---|---|
| 悬置 | 前段避免强烈结束感，保留尚未完成的关系，转折后再出现清楚落点 | 必用不协和音／小调 |
| 温暖 | 同时考虑演奏、音区、空间与文化关联 | 立即要求大调 |

# "和声更复杂"的四种含义
音更多／变化更快／调性更模糊／声部运动更独立。一个和弦延续很久但内部色彩缓慢变化，与每拍换和弦的忙碌感不是一回事。

# 确定程度
- 可确定：写"低音持续不变，上方短音交替"。
- 不能确定调式：写"**未判定**"。
- "需要更少落地感"是**目标建议**，不应伪装成对原曲和声的分析。
