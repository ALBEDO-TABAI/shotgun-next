# 核心
短促敲击、柔和连奏、带机械细节的近距离录音、远处空间中的零散音，都可能来自钢琴，却建立不同关系。**乐器名不是声音描述。**

# 可描述的演奏维度
- 音与音之间的连接（连／断）
- 每次力度差异；重音位置
- 呼吸；停顿是否有主动感
- 重复是否完全一致

不必自动美化所有不稳定：节奏游移可能表达犹豫，也可能只是与画面失配；机械重复可以是错误，也可以是作品主题。

# Examples
```text
✗ 自然一点
✓ 保持整体拍速；同一短音重复时允许轻微力度差异，但关键动作对应的音头不要漂移。
✓ 保留句末呼吸，不把每次空隙填满。
```
这样能区分**有意变化**与**需修正的技术误差**。

# 生成与来源边界
- 提示中写"真实演奏""人性化"只是方向，**不能据此声明输出确由真人演奏**。
- 素材来源与听感分开记录；类似呼吸的声音不证明真实录音中有人呼吸。
