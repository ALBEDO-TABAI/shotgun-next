# 诊断"太满"的五项
1. 声部数量
2. 事件密度
3. 同时变化的内容
4. 持续时长
5. 频谱覆盖

同样十条轨道，可以被听成一个稳定和声，也可以像十个独立事件——**工程轨道总数不是指标**。

# 减少新事件，而非一起关小
```text
保留当前和声支撑，旁白出现时不再引入新的上行旋律；
持续层延续，但每句之间只保留一个短回应。
```

# 配器 ≠ 不断加乐器
段落发展可通过同一材料的位置、音区、奏法、间隙改变完成。短广告中材料加入过快，后面只能继续堆叠；但**少层数也不是美学义务**。

# 层的任务角色（非固定乐器分组）
| 角色 | 作用 |
|---|---|
| 持续参照 | 提供和声／空间底 |
| 节奏组织 | 提供可跟随的时间 |
| 旋律前景 | 承担需要跟随的音高线 |
| 动作连接 | 与画面动作对应 |
| 空间尾部 | 延展与归属 |

没有任务不一定要删，但应知道它的存在如何改变整体。
