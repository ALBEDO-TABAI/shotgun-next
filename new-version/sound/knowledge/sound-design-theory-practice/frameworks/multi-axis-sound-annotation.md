# 为什么要多轴
“音乐／音效”“故事内／故事外”“前景／背景”属于**不同维度**。Yale 电影分析教学材料也分别讨论声源、画内外、故事内外、声音时间与声音透视，并区分现场录制与后期添加——它们不能合并成一条分类轴。

# Schema
| 分析轴 | 问题 | 可用描述 |
|---|---|---|
| 材料形态 | 听起来是什么类型的材料？ | 语言、非语言人声、环境、动作事件、音乐、复合声音 |
| 故事归属 | 呈现为故事中的声音，还是故事之外的表达？ | 现场声、人物记忆、内部想象、外部配乐、归属暂不明确 |
| 可见性与揭示状态 | 声源是否可见？观众是否知道它是什么？ | 当前可见、已知但画外、尚未揭示、刻意保持模糊 |
| 时间关系 | 属于当下、过去、未来或不指向时间？ | 同时发生、回忆侵入、提前出现、跨场延续 |
| 听觉位置 | 观众仿佛在哪里听？ | 贴近身体、房间一角、隔墙、远处、超现实微观距离 |
| 注意力地位 | 此刻被怎样组织？ | 主体、支撑、背景、等待被注意的线索 |
| 表达立场 | 与人物、叙述者或品牌的态度关系？ | 共情、旁观、讽刺、疏离、尚不能确定 |
| 制作来源 | 实际怎样被制作？ | 现场录音、拟音、采样、合成、混合、未知 |

# 使用规则
- 每个声音可在每条轴上取值，**不要求归入唯一类别**；
- 允许“不确定／刻意模糊”作为合法取值（见 [分类四个易错点](/principles/sound-classification-pitfalls.md)）；
- 听觉位置与表达立场的细分见 [听觉立场三轴](/frameworks/three-axes-of-auditory-stance.md)。
