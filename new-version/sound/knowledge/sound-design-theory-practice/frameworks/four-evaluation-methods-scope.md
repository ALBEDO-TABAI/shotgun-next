# 对照表
| 方法 | 适合回答 | 不能替代 |
|---|---|---|
| 专业评审 | 结构、声画关系、可执行性、制作问题；能提出修改路径 | 代表所有受众 |
| 探索性受众反馈 | 发现意外联想、理解困难、未预料的观看方式 | 准确的发生率 |
| 有计划的对照测试 | 预先定义的条件差异；控制、样本、分析与问题匹配时可作更明确判断 | 未设计的问题 |
| 技术测量与标准化听测 | 相应的技术对象 | 叙事价值或音乐适配的认证 |

# 标准的适用范围（来源支持）
- ITU-R **BS.1116**：音频系统**小损伤**的主观评价[2]。
- ITU-R **BS.1534**：音频系统**中等质量水平**的主观评价[3]。
- 不能把这些标准名称或技术听音得分当成影片叙事价值或音乐适配的认证。

# Examples
- 混音师发现对白被音乐遮盖 → 有效的专业线索，≠ 已测得目标受众理解率。
- 观众说"听着像恐怖片" → 重要探索反馈，≠ 所有观众都会这样理解。
