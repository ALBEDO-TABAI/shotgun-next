# 定义
分析现成作品的声音时，首要任务是**建立依据**，而不是展示解释能力。一句"音乐象征人物的内心崩塌"很有感染力，但没有说明听到了什么、在何处、与什么画面相连，也没有排除其他解释。

本包综合的**五层证据结构**：

| 层 | 声明示例 | 需要的依据 |
|---|---|---|
| 观察事实 | "人物坐下后，节奏层停止，只剩持续声与环境" | 同一版本可复查的位置 |
| 形式关系 | "声音从推动转为持续" | 可听变化的描述与比较 |
| 功能假设 | "可能使注意转向人物迟疑" | 声画证据＋上下文＋替代解释 |
| 创作者意图 | "导演想表现迟疑" | 一手资料（访谈、制作记录） |
| 受众结果 | "初看者把它理解为迟疑" | 真实受众证据 |

# 要点
- 五层**不是深浅阶梯**，而是不同的声明类型，各自承担不同举证责任。
- 再有洞察的解释也不能直接升格为意图；再明确的导演访谈也不能证明所有观众产生相同反应。
- 严谨分析**可以停在形式层**，也可以提出多个并存假设；不能因为意图未证实就否定分析价值，也不能为了故事完整而补足不存在的证据。
