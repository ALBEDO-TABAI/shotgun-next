# 四层（本包工作模型）
| 层面 | 关心什么 | 例子 |
|---|---|---|
| 故事中的声音世界 | 设定里哪些人、物、空间、事件能发声 | 隔壁练琴、走廊电梯、房间冰箱 |
| 作品呈现的声音世界 | 作品实际让观众听到什么、怎样处理 | 练琴清楚，电梯被省略，冰箱在关键时刻异常突出 |
| 观众组织出的听觉经验 | 观众听成什么、关注什么、建立什么联系 | 练琴=日常生活；冰箱=令人不安的持续压力 |
| 实际播放的声音条件 | 经过什么设备、空间、观看方式到达观众 | 耳机、手机外放、影院、嘈杂展厅 |

# 三个不等式
- “故事里应该存在” ≠ “作品里必须突出”；
- “素材里存在” ≠ “观众实际听见”；
- “创作者想表达” ≠ “观众已经理解”。

# 推论
整体设计不是尽可能完整地模拟现实，而是**决定现实中哪些关系值得被呈现，以及哪些非现实关系值得被创造**。播放条件是设计约束的一部分（见 [声音世界规则](/templates/sound-world-rules.md) 的“播放约束”）。
