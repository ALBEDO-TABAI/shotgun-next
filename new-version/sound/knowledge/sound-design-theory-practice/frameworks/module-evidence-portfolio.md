# 模块—问题—证据

| 模块 | 重点研究问题 | 主要证据类型 |
|---|---|---|
| [02 功能](/topics/02-music-sound-functions.md) | 音乐怎样参与情绪、注意、记忆和广告任务？ | 原始研究、机制论文、历史分析框架、一手实践 |
| [03 适配](/topics/03-music-fit-judgment.md) | 契合是什么，为什么不能只按流派或情绪选曲？ | 广告研究、跨文化体验研究、视听模型、委托方法综合 |
| [04 描述](/topics/04-sound-description-language.md) | 形容词如何落到可听维度，参数研究有什么边界？ | 音乐线索实验、跨语言音色研究、节奏研究、基础教学 |
| [05 时间线](/topics/05-sound-timeline.md) | 声音时序如何影响解释，怎样落实到制作点位？ | 时序实验、职业实践、声音时间教学、本文计算 |
| [06 非常规](/topics/06-unconventional-sound.md) | 声音怎样被重新关联，陌生感怎样有表达理由？ | 作者实践、声音形态理论、粗糙度研究、对照方法 |
| [07 案例](/topics/07-shampoo-ad-case.md) | 多个理论如何在同一条广告时间线上共同成立？ | 前述理论的假设性应用、精确时间计算、实施规划 |
| [08 分析](/topics/08-work-sound-analysis.md) | 怎样区分观察、解释、意图和效果？ | 形式分析教学、一手来源判断、实验设计思路 |
| [09 评价](/topics/09-sound-evaluation-acceptance.md) | 怎样测量适配而不滥用技术分数或小样本？ | 官方实验设计、测量范围、可访问性、任务化验收 |
| [10 协作](/topics/10-ai-team-sound-collaboration.md) | 谁消费什么，怎样避免计划、素材、批准互相矛盾？ | 专业职责、官方工程经验、溯源模型、风险框架、权利对象说明 |

# 跨篇一致逻辑
各篇保持 **目标 → 关系 → 实现 → 证据 → 决策** 的同一条链：先写观众要经历的变化，再定声画／声部关系，再落到可执行的材料与时间，再用合适等级的证据检验，最后形成可返修的决策记录。
