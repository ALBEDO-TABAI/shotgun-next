# 概念（来源支持）
Michel Chion 的 **added value**：声音为画面带来表达性或信息性，但观众可能把这些贡献当作画面本身已有的性质。

# 分析含义
- 不只找“声音补充了什么没拍到的信息”；
- 还要问“**声音改变了画面本身的哪一种性质**”：物体重量感、脆度、尺度、动作意图、空间性质……

# 转为 skill 判断
| 不要只写 | 应继续记录 |
|---|---|
| “这里有一个瓶子落桌音效。” | “这个声音正在改变物体的重量感、脆度、尺度、动作意图，还是空间性质？” |

# 边界
附加价值是分析语言，**不是情绪效果公式**；具体方向需要在作品中作为视听假设验证。示例见 [玻璃瓶落桌：三种声音假设](/cases/glass-bottle-three-sound-hypotheses.md)。
