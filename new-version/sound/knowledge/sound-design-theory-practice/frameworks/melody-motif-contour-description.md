# 音高材料的形态谱
完整歌唱性旋律 → 短动机 → 音高轮廓 → 重复音 → 几乎不稳定的音高纹理。形态不同，对注意力与时间组织的要求不同；**没有哪种天然更高级**。

# 记录维度
- 长度；是否重复
- 大致上行／下行；跳进还是连续
- 何时完成；是否由不同材料接力
- 无法确认音程时用**相对轮廓**；听到模糊持续层时**不要虚构调性与和弦**

# 动机描述 = 身份 + 变体
```text
保留"短—短—长"的节奏轮廓，前段只出现前两个动作，结尾再完成；
音色可以变化，但不要同时改掉节奏和轮廓。
```

# 旁白场景
"不要旋律"可能过度。真正需要的往往是：**旁白区没有新的、需要跟随的旋律事件**，而非完全没有音高——短动机可在句间回应，持续层保持。

# 分析边界
- "听到一个反复形态" ≠ "它是全片主题"，后者需更多位置的证据。
- 生成系统输出了可唱片段，不代表跨版本能稳定保留同一动机。
