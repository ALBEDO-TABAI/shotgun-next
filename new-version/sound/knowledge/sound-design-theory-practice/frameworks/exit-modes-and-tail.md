# 四种退出
| 方式 | 适用 | 前提／风险 |
|---|---|---|
| 完成后退出 | 需要确认或收束 | "完成"可以是动作得到回应，不必总有和弦落地 |
| 未完成时退出 | 保留不确定或制造断裂 | 前文须建立足以被感受的延续，否则像剪辑突兀 |
| 转换身份后退出 | 音乐留下与空间同源的部分（持续层被听成房间设备声） | 需建立材料与空间逻辑；频率相近不等于完成叙事转换 |
| 被其他声音接管 | 人声、动作或环境获得前景 | 设计谁先退、谁后进、是否短暂重叠及其必要性 |

# 尾部的四个检查点
1. 最后音头
2. 主体结束
3. 尾部结束
4. 文件结束

尾部有戏剧属性：长尾可继续维持空间和情绪；在广告时长内被硬截断可能破坏收束。
