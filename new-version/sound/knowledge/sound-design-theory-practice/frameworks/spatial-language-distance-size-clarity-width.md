# 分项描述
主体距离｜空间范围｜反射／尾声｜遮挡｜方向｜横向展开。声音透视涉及声音与听者位置的呈现，**不必机械跟随摄影机**。[2]

# 多义词拆解
| 词 | 可能对应的不同操作 |
|---|---|
| 更大 | 更大的声源／更大的房间／更宽的立体声／更强的声音／更多层同时存在 |
| 更远 | 不只降音量：声源细节、空间与遮挡关系也需变化 |
| 干净 | 不总是无混响：适度共同空间帮助材料归属同一场景；过干的每个声源可能像剪贴 |

# Examples
- 产品微观特写"近而有空间"：关键音头清晰贴近，尾部在动作结束后向周围展开；不把主体和尾部一起推远（制作方案，需实际音频验证）。
- "干净"的可执行版：主体之间有共同空间依据，但旁白区不被长尾持续覆盖。

# 播放边界
- 不假设所有播放环境保留立体声宽度或环绕位置。
- 核心信息仅依赖极端左右差异时，需另查单声道／实际设备；未验证前记为**未验证**——耳机清楚不等于外放成立。
