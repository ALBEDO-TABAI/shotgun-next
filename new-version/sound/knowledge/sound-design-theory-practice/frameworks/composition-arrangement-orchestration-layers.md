# 三层（本包工作区分，非行业职责划界）

| 层 | 决定什么 |
|---|---|
| 作曲 | 材料、音高、节奏及发展 |
| 编曲 | 声部、伴奏、密度与段落组织 |
| 配器 | 由什么声源、在什么音区、以什么演奏方式实现 |

电子音乐中三者常同时发生；区分的目的是让每层都**可单独修改**。

# 诊断例

| 症状 | 首先怀疑的层 |
|---|---|
| "这句没有去向" | 作曲 |
| "旁白时太忙" | 编曲 |
| "旋律听起来幼稚" | 旋律 + 配器 + 发音共同作用 |

不能把它们都归入混音。
