# 四种留白（制作层分类）
| 类型 | 操作对象 | 需要检查的问题 |
|---|---|---|
| 无配乐 | 音乐退出，故事世界继续 | 环境与动作是否足以维持空间和任务？ |
| 局部稀疏 | 减少竞争，只保留少数事件 | 留下的声音是否因此承担了过多意义？ |
| 主观收缩 | 改变人物注意对应的可听范围 | 是否有叙事依据，而非模板化滤镜？ |
| 近乎全面撤除 | 大量作品声音共同消失 | 断裂是否有意，播放时是否像故障？ |

# 研究边界
Goh、Phillips、Firestone 2023 研究了"静默的知觉"并提供演示材料 [2]；这**不等同于**"电影静音会让大脑重置"之类推论。本表也不主张完全无声是稳定的现实聆听条件。

# 设计要点
- 留白强度**取决于前文**：一直稀疏与一直密集的作品，撤去同一条音乐形成的变化不同；不用固定秒数判断"够长"。
- **不要在每个重要台词前机械抽空所有声音**——反复出现会变成提示，让人物每次说话都像发布结论。是否需要这种仪式性是创作选择。
