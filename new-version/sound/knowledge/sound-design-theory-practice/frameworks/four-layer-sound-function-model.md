# 定义
功能问题 = **相对于什么情境，声音改变了哪一种关系，使作品得以怎样被理解或经历。**
"这里有弦乐""这里变响了""这里很悲伤"分别在谈材料、操作和感受，都没有回答功能问题。

# 四层（本包综合）
| 层 | 回答 | 典型证据来源 |
|---|---|---|
| 材料 | 声音是什么 | 素材、配器、音色 |
| 形式变化 | 声音做了什么变化 | 进入、退出、重复、打断、电平 |
| 任务（意图） | 创作上希望完成什么 | 创作者陈述、brief |
| 结果 | 实际观看中出现了什么 | 观众反馈、对照测试 |

- 四层可以互相支持，也可能冲突：创作者说"表现孤独"（意图）、观众说"压抑"（体验）、波形显示电平下降（技术变化）是三种不同证据。
- 同一条持续音：追逐前可建立等待，对白后可延长未完成感，跨空间可维持连续性——**不能从音色名反推任务，也不能从任务名锁定配器**。

# 最小分析单位
不是"这首歌很适合"，而是**有上下文的变化**。例：
> 人物说出否认后，音乐才出现未完成短句，拟把注意力从语言内容转向他迟迟没有离开的动作。

这句话是可被推翻的假设：若观众没注意到迟疑，或把音乐听成胜利，任务就需重审。
