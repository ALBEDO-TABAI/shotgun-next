# 因果链模型（本包综合）
> 音乐中的某种变化 → 在当前视听关系中改变一个**局部条件** → 观众可能据此形成某种**理解** → 这种理解可能参与更远端的**项目结果**。

例：短句在人物停顿后出现 → 停顿得到注意 → 支持"人物还在犹豫" → 人物关系更易理解。各环节需分别确认；**不能因为最后有人喜欢影片就声称整条链已验证**。

# 链条中断条件（须写出）
- 画面已明显说明犹豫 → 音乐只是重复。
- 对白太复杂 → 观众没注意到音乐变化。
- 前文建立了另一种动机意义 → 同样短句指向完全不同的关系。

写出这些条件，才能判断什么时候值得用这种方法。
