# 问题
两个人都说"清爽"，一个想要稀疏、快速消散的短音，另一个想要持续、明亮、开阔的空间。分歧不是谁不懂音乐，而是**体验词尚未规定实现方式**。

# 五层结构（本包综合）
| 层 | 回答的问题 | 示例（"更亲密"） |
|---|---|---|
| 1 表达目的 | 希望观众经历什么 | 更亲密 |
| 2 听觉现象 | 听上去是什么样 | 人物声音靠近，周围较少竞争 |
| 3 可操作参数 | 候选操作是什么 | 减少远处持续层，保留呼吸与轻微衣物动作 |
| 4 时间与关系 | 在哪里、对谁成立 | 只在独处段这样处理 |
| 5 验收及边界 | 什么算成功、什么不允许 | 不把贴近变成刻意的口腔细节 |

# 要点
- **技术词不天然更清晰**："把中高频削一点"没说削哪层、为何、会损失什么；"混响少一点"可能指尾巴太长、空间太大、反射太密或主体不够近。
- 有效沟通不是消灭感性词，而是给感性词**建立可以试听和修改的对应物**。
- 描述**不应过度锁死实现**：导演规定"保留轻盈运动感"即可，不必决定滤波器数值；声音设计师可提两种做法并展示代价。接口让目标与操作互相看见，不让上游承担全部工程细节。
