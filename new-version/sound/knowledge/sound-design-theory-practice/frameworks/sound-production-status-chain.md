# 状态链
> **计划 → 候选已取得 → 已审查 → 选定方案 → 已整合导出 → 已验证 → 已授权交付**

名称可替换，含义要清晰（本包综合）。

| 状态 | 进入条件 |
|---|---|
| 候选已取得 | 有真实文件或可访问素材 |
| 已整合导出 | 有指定版本的实际输出 |
| 已验证 | 有绑定**该文件**的证据 |
| 已授权交付 | 另需正确的用途和批准 |

# 分维度记录，不塞进一个布尔值
分别记录 **艺术 / 技术 / 权利** 状态，再按项目规则计算是否允许下一动作：
- 艺术通过 + 技术待测 + 权利已确认 → 可以继续技术验证，**不**意味着立即发布。
- 艺术待改 + 技术通过 → 旧的"技术通过"**不能**污染改动后的新文件。

# 非正常状态也要显式
错误、等待输入、主动放弃候选都应是明确状态；不能统一记成"失败后自动重试"，否则系统可能在缺少必要信息时不断生成。
