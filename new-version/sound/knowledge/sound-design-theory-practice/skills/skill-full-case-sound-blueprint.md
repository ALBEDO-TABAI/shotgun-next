# 核心知识段（精炼）
在完整案例中，先分开用户给定方向、教学假设和真实未知，再建立任务轨迹与声音命题。把音乐、动作声、环境和人声放进同一张时间线，明确材料如何建立、转化、让位和回收。固定拍速时用精确计算连接秒、小节和片长，但不强制所有镜头卡拍；真实动作和语言到位后再确认硬锚点。每段给出表达目标、声音行为、禁区、素材依赖与检查方法。生成请求、计划文件、实际资产、技术合规、艺术批准和权利许可分别记录。长短版本共享规则但重新设计任务与收束，不直接继承批准。未制作或未测试时只能称为可实施蓝图。

# 触发
广告／品牌短片／叙事短片需要从方向词推演到声音时间线、brief 与交付计划。

# 最小输入
| 字段 | 必需性 |
|---|---|
| 方向词与参考 | 必需 |
| 片长、拍速／拍号或"待定" | 必需（可为假设，须标注） |
| 画面段落或分镜 | 有则用，无则写为假设 |
| 必要语言（文案、时长） | 有则用 |
| 品牌已有声音标识、权利约束、投放目的地 | 有则用 |

# 输出
信息边界表、命题与规则、段落表（含精确时间）、作曲与资产蓝图、三份 brief、混音策略、测试与交付计划、失败模式诊断表。

# 质量门禁
- [ ] 每项内容标有证据身份（给定／假设／未知）
- [ ] 时间由单一权威基准派生（[帧与拍点原则](/principles/frame-quantization-vs-beat-sync.md)）
- [ ] 信息段先靠编配让位（[原则](/principles/vo-space-by-arrangement-before-dynamics.md)）
- [ ] 未暗示未证实功效或成分
- [ ] 计划资产不写成已交付；批准绑定版本
- [ ] 不声称未测试的效果（[蓝图原则](/principles/blueprint-not-verified-result.md)）
- [ ] 规则附反例与适用条件（[可迁移规则](/principles/shampoo-ad-transferable-rules.md)）
