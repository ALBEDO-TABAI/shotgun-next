# 触发
- 需要说明"这段音乐/声音在做什么"、把"更感人/更高级"改写成可执行任务、或给已有声轨做功能诊断时。

# 最小输入
- 目标；段落上下文（前后文）；可用材料（文字 / 音视频）。
- 只有文字 → 输出**构想**；有音视频 → 才输出**观察**。

# 处理
1. 记录画面与语言已表达的内容。
2. 记录声音实际变化（进入、退出、关系）。
3. 用[七个工作方向](/frameworks/seven-sound-function-directions.md)提问；分开[被感知情绪／听者感受](/frameworks/emotion-perceived-vs-felt.md)与[情绪立场四问](/frameworks/emotional-stance-four-questions.md)。
4. [分配首要／次要任务与不可破坏条件](/methods/primary-secondary-task-assignment.md)；标注[层间关系](/frameworks/inter-layer-task-relations.md)。
5. 写[可执行功能句](/methods/executable-sound-function-sentence.md)与[保护任务](/principles/protective-function-design.md)。
6. 列替代解释、最小对照、可推翻现象。

# 输出
[声音功能卡](/templates/sound-function-card.md)（可多张），附当前结论与未决项。

# 质量门禁
- 通过[质量门槛清单](/checklists/sound-function-analysis-quality-gates.md)。
- 结论强度不超过[三种证据强度](/principles/function-claim-evidence-strength.md)中实际达到的一级。

# 核心知识段（精炼）
> 声音功能分析以"声音在上下文中改变了什么关系"为对象，区分材料、形式操作、表达任务、预期效果与实际证据；七个方向用于提问而不要求全覆盖；为每段指定首要任务、次要任务与不可破坏条件，记录层间互补、交接、冗余、竞争或抵牾；分开被感知情绪、听者情绪、人物情绪归因与作品立场；结论须连到实际声画证据、一手资料或标注的假设，并以替代解释与最小对照保持可修正。
