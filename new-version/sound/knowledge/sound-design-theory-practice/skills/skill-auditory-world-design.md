# 触发
- 需要为影片／广告／短片建立整体声音方向，而不只是“配一首乐”；
- 需要分析现成作品的声音关系；
- 反馈是“声音太多／太乱／不真实／主观感不对”等需要拆解的问题。

# 最小输入
作品目标；剧本或剪辑版本（注明版本）；关键人物与空间；已有声音素材；传播／播放条件；事实边界。输入能力决定可作结论（见 [输入能力边界](/principles/input-capability-boundaries.md)）。

# 处理
1. **A 确认依据** → 已知条件、未定问题、允许假设。
2. **B 声音世界规则** → [八项规则](/templates/sound-world-rules.md)，每条带边界。
3. **C 事件表 + 关系表** → [两张表](/templates/event-table-and-relation-table.md)。
4. **D 关系原型** → [粗材料验证](/methods/relation-prototype-before-asset-fidelity.md)，向上游提建议（由决策者确认）。
5. **E 分层验收** → [事实／技术／艺术](/methods/fact-technical-artistic-acceptance.md)。
分析现成作品时逐段填写 [声音分析卡](/templates/sound-analysis-card.md)，按 [多轴标注](/frameworks/multi-axis-sound-annotation.md) 记录。

# 输出
- 声音世界规则表；事件表与关系表；关键段落分析卡；原型对照计划与上游建议；分层验收记录。

# 质量门禁
- [ ] 区分四个世界：故事中／作品呈现／观众组织／播放条件（[四个世界](/frameworks/four-sound-worlds.md)）。
- [ ] 每个关键声音标注预期主导聆听模式（[三种聆听](/frameworks/three-listening-modes.md)）与“一件事还是几件事”（[听觉场景分析](/frameworks/auditory-scene-analysis-tracks-vs-streams.md)）。
- [ ] 写出“明确不出现什么及原因”（[三种留白](/frameworks/three-silence-operations.md)）。
- [ ] 真实性按四维分别评价，纪实／产品事实不得风格化造假（[真实四维](/frameworks/four-dimensions-of-realism.md)）。
- [ ] 观察、推断、制作事实、设计建议、测试结果分开；理论解释、作者意图、制作事实、观众反馈不互相冒充。
- [ ] 不写“同时最多 N 个声音”“用了 X 观众必然 Y”之类公式（[证据边界](/principles/theory-experiment-practice-are-not-formulas.md)）。

# 核心知识段（精炼）
整体听觉世界设计以声画共同形成的经验为对象，而不是分别最大化音乐、人声、环境声与音效；声音与画面的关系可以写实、补充、替代、冲突或跨越时空，但每种关系都需在具体作品中验证。

> **不是先问“这个画面配什么声音”，而是先问“这部作品允许我们怎样听见它的世界”。**
