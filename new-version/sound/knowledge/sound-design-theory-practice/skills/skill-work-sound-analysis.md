# 触发
需要分析现成作品（影片、广告、片段、音频）的声音组织、功能或意图；需要比较作品；需要为 agent 生成可复查的声音分析报告。

# 最小输入
- 待分析材料（注明是完整音视频、只有音频、只有画面、只有字幕／转录、工程分组还是源分离估计）；
- 版本与范围信息；
- 分析目的（学习迁移／评价／比较／争议解释）。

# 处理步骤
1. 确认素材、版本、范围与播放条件 → [素材与版本记录](/templates/analysis-material-version-record.md)
2. 按输入能力锁定不可作出的结论 → [能力边界](/principles/analysis-input-capability-boundaries.md)
3. 整体经验 → 结构观察 → 解释验证 → [三阶段](/methods/analysis-three-phase-viewing.md)
4. 用位置与变化记录可听事实；声源不明描述形态 → [观察记录](/templates/sound-observation-record.md)
5. 形式命名＋区分单次与规律 → [形式分析](/frameworks/formal-sound-relation-analysis.md)
6. 功能假设＋至少一个替代解释＋可推翻条件 → [形式到功能](/methods/form-to-function-hypothesis.md)
7. 需要时检索一手资料、做反事实或拆解比较 → [资料检索](/methods/sound-claim-source-search.md)、[反事实](/methods/counterfactual-sound-analysis.md)、[拆解比较](/frameworks/audio-only-mute-stem-comparison-modes.md)
8. 提炼任务、关系、成立条件、失效边界 → [可迁移提炼](/methods/extract-transferable-sound-method.md)

# 输出
[可复查的声音分析报告](/templates/sound-analysis-report.md)，每条结论带 [声明类型与置信理由](/frameworks/claim-types-and-confidence-wording.md)。

# 质量门禁（失败条件）
- 没有音视频却写成"已观察"；听感猜测写成制作事实；
- 功能解释没有替代解释；意图句没有一手来源；
- 测量结果越出适用范围（[测量边界](/principles/measurement-locates-not-judges.md)）；
- 局部结论被扩大为全片／流派规律（[颗粒度](/principles/analysis-claim-scope-granularity.md)）；
- 未通过 [反向审查清单](/checklists/analysis-storytelling-reverse-audit.md)。

# 核心知识段（精炼）
作品声音分析先确认素材、版本、范围和能力边界，再分别记录可听事实、形式关系、功能假设、创作者意图和受众结果；声源不明时描述形态；局部放回前后文，区分单次与规律，为主要解释保留替代解释和可推翻条件；一手资料与实验各有支持范围；各类拆解比较须说明改变了什么；测量只用于其适用范围；最后提炼任务、关系、条件与边界，而非固化表面材料。
