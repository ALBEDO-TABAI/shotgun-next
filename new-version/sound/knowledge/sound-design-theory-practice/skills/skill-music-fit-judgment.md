# 触发
需要判断"这部片／这段适合什么音乐"、比较候选曲、写原创委托或生成探索方向、或决定是否无配乐时。

# 输入
- 项目目标与不可违背条件
- 剧本／当前剪辑版本／预期时长
- 观众观看情境与需要理解的信息
- 已有声音、参考及来源状态
- 可以验证和不能验证的条件

# 步骤
1. 分开事实、偏好、假设与硬限制 → [目标分层](/frameworks/goal-tiers-must-worth-drop.md)
2. 写观众体验轨迹，不先指定流派 → [体验轨迹四维](/frameworks/experience-trajectory-four-dimensions.md)
3. 选择声画关系与听觉立场 → [七种声画关系](/frameworks/seven-audio-visual-relations.md)
4. 写声音命题和排除项 → [声音命题三测试](/frameworks/sound-proposition-three-tests.md)
5. 提出至少两种真正不同的实现方向 → [风格六维度](/frameworks/style-six-working-dimensions.md)、[四种路径](/frameworks/four-music-sourcing-paths.md)
6. 逐轴检查适配、竞争、误读与可制作性 → [多轴适配矩阵](/frameworks/multi-axis-fit-matrix.md)、[文化关联核查](/templates/cultural-association-check.md)、[权利对象](/principles/music-work-vs-recording-rights.md)
7. 用代表段落和完整上下文比较 → [两轮候选比较](/methods/two-round-candidate-comparison.md)、[参考拆解](/templates/reference-breakdown-record.md)
8. 记录选择理由、未决证据、允许变化范围 → [条件化决策记录](/templates/conditional-music-decision-record.md)

# 输出
方向说明；候选差异；任务与声音关系；风格维度；参考拆解；制作／权利依赖；对照计划；暂定决定与重评触发条件。

# 质量门禁
- [不附虚构分数、局部未知不被整体通过掩盖](/principles/no-fabricated-fit-scores.md)。
- 返修时先[定位问题层级](/checklists/fit-revision-problem-layers.md)。

# 核心知识段（精炼）
> 适配以"某段音乐的具体用法与作品任务之间的关系"为单位；先分硬条件、目标与偏好，建立信息/情绪/关系/身体形式的体验轨迹，再定声画关系、听觉立场与能约束选择的声音命题；风格拆为六维；候选按八轴逐轴比较，先定方向再优化实现；参考只借明确维度；决策记录证据、取舍、未决项与重评触发条件；无试听、授权或观众数据时不把适配假设写成已验证。
