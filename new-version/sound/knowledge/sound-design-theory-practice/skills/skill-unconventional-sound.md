# 核心知识段（精炼）
非常规声音设计以相对于项目常态的**有意偏离**为对象：先确定观众有理由期待什么，再决定保留哪种联系、改变哪种预期、建立什么新关系。可从动作形态替代、尺度变化、现实声音乐化、声源归属转移、对象行为、情绪不响应、局部规律破坏、时间形态变形构想方案。研究中的粗糙度、期待或视听关系不能被改写为万能情绪开关；新奇不等于有效。让观众经历到目标关系比识别素材来源更重要；技术缺陷、事实误导与不必要的听觉不适不能事后包装成创意成功。

# 触发
- 需求含"梦幻／奇幻／拟人／反讽／陌生感／不要写实"等；
- 已有写实方案但表达不足；
- 需要解释或返修一个"怪"的声音。

# 最小输入
| 字段 | 说明 |
|---|---|
| 段落与画面动作 | 事件、时长、关键动作 |
| 创作目标 | 希望的新关系 |
| 当前常态／参照 | 常规方案是什么 |
| 项目边界 | 事实展示、品牌、纪实责任、权利限制 |
| 素材能力 | 实录／授权库／生成／合成 |

# 处理
1. 写出参照与观众依据（[参照](/frameworks/unconventional-relative-to-reference.md)）。
2. 选保留项、偏离项、新关系；首轮只显著改一个维度（[三元模板](/frameworks/keep-one-link-change-one-expectation.md)）。
3. 从八种方法中选择实现路径（见 [枢纽](/topics/06-unconventional-sound.md)）。
4. 设计强度轨迹（[陌生感的段落](/frameworks/strangeness-arc-establish-sustain-transform-return.md)）。
5. 对照风险矩阵写出可接受／不可接受误读（[风险矩阵](/checklists/unconventional-sound-risk-matrix.md)）。
6. 做常规／轻度／明显三候选并按 [最小实验流程](/methods/unconventional-sound-minimal-experiment.md) 检验。

# 输出
- 一张或多张 [非常规声音卡](/templates/unconventional-sound-card.md)；
- 候选版本及其来源记录；
- 测试计划或结果（未执行明确标注）。

# 质量门禁
- [ ] 能指出被偏离的参照与规则证据
- [ ] 能说出收益（[新奇须有收益](/principles/novelty-must-yield-benefit.md)）
- [ ] 分开关联／来源／表达三判断（[三种判断](/frameworks/association-source-endorsement-three-judgments.md)）
- [ ] 没把粗糙度、频率等写成情绪开关（[粗糙度原则](/principles/roughness-harshness-loudness-fear-distinct.md)）
- [ ] 未暗示虚假性能或事实；纪实素材负责
- [ ] 原始素材与处理可追溯（[溯源原则](/principles/keep-raw-and-trace-transformed-sound.md)）
