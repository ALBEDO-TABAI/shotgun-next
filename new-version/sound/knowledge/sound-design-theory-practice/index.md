# 声音设计理论与创作制作知识包 · Overview

母题：**影视／广告声音设计的理论、方法与制作实践**——从"整个听觉世界"总纲出发，经声音功能、音乐适配、描述语言、时间线（入点出点留白交接）、非常规声音、完整广告案例、作品分析、评价验收、AI 团队协作交付，再到制作层的需求翻译、构想、作曲编配、演奏录音、音效合成、混音与返修。来源为 `new-version/sound/声音设计理论与方法_二至十/`（《一.md》+ 02–10 九篇 + 研究方法与来源索引）与 `new-version/sound/声音创作与制作_实践知识包/`（主文 + 四小节 MIDI 练习），均整理于 2026-09-18。

全包共用一套证据约定：学术研究、一手创作／工程经验、官方标准／手册、本包综合、自拟教学案例各自只能支持特定强度的论断；本包没有真实影片、音频渲染、混音或受众数据。见 [来源使用与证据边界总原则](principles/source-use-and-evidence-boundaries.md) 与 [实践包的四种内容身份](principles/practice-four-content-identities.md)。

# 主题枢纽 · Topics

* [00 研究方法、来源与证据边界](topics/00-research-method-evidence.md) - 两套源材料怎样检索与综合、各模块依赖什么证据、来源各能支持到什么程度，以及哪些结果只能靠实践回答。
* [01 先明确：你要设计的不是“一首配乐”，而是整个听觉世界](topics/01-auditory-world.md) - 整体听觉世界设计：四个世界、多轴标注、七个理论基础（附加价值／同步融合、三种聆听、生态事件、听觉场景、声景、听觉立场、频谱形态）、真实四维、留白与交接、A–E 流程、分析卡与案例。
* [02 音乐与声音的功能：叙事与感知任务](topics/02-music-sound-functions.md) - 把“烘托气氛”展开为可分析、可分工、可验证的声音任务系统：四层模型、七个工作方向、任务分配、功能句、功能卡与证据强度。
* [03 音乐适配判断：目标、立场与声画策略](topics/03-music-fit-judgment.md) - 判断一部影片适合什么音乐：四个入口（体验轨迹、声画关系、声音命题、风格维度）、八轴适配矩阵、路径选择、参考拆解、两轮比较与条件化决策记录。
* [04 声音描述语言：从感觉到执行](topics/04-sound-description-language.md) - 把体验目标翻译为可听特征、可操作参数、时间关系与验收条件；节奏、动机、和声、音色、空间、动态，以及导演／制作／生成三种描述接口。
* [05 声音时间线：入点、出点、留白与交接](topics/05-sound-timeline.md) - 把声音的出场与退场当作戏剧设计：spotting、三个时钟、触发、入点与出点、留白、桥接、同步分级、人声交接、时间表示、剪辑变更与音乐先行。
* [06 非常规声音：预期、隐喻与重组](topics/06-unconventional-sound.md) - 把非常规声音理解为对来源、动作、时间、空间、情绪或声画归属的有意重组，研究如何产生可解释的陌生感、亲密感、荒诞、张力或幻想，而不把“怪异”本身当成价值。
* [07 洗发水广告：完整声音设计案例](topics/07-shampoo-ad-case.md) - 以 30 秒、118 BPM 的假设洗发水广告，把前六篇的判断整合为可供导演、作曲、声音设计、剪辑、混音与 agent 共用的可实施蓝图：信息边界、命题、段落表、资产规划、brief、混音、短版、测试与交付。
* [08 作品声音分析：观察、证据与解释](topics/08-work-sound-analysis.md) - 分析现成作品时避免'听起来像这么回事'的解读：确认版本与能力边界，分层记录观察、形式、功能、意图与受众结果，保留替代解释，提炼可迁移的关系与条件。
* [09 声音评价：适配测试与分层验收](topics/09-sound-evaluation-acceptance.md) - 什么才算'适合'和'做得好'：拆开六种判断，建立目标到决策的评价链，按轮次选方法，控制对照条件，分级表述小样本结论，把反馈写成可复验的最小修改，并把批准绑定到版本与使用范围。
* [10 AI 影视团队：声音职责、协作合同与可验证交付](topics/10-ai-team-sound-collaboration.md) - 把前九篇转成可分工、可消费、可返修的工作体系：按职责与真实能力分工，共享权威记录，分离意图/素材/批准，显式状态，依赖驱动的版本更新，绑定文件的验收。
* [实践包：声音创作与制作——从需求到可听方案、成片与迭代](topics/p-sound-creation-production.md) - 补上理论 01–10 与实际制作之间的一层：需求翻译→小型实验→可发展材料→作曲编配→演奏录音／声音制作→混音→针对性修改，附 30 秒广告贯穿案例、跨体裁迁移、创作卡与返修卡、四小节 MIDI 练习。
