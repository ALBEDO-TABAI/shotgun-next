# 三个决定（每个都放弃了一些东西）
| 决定 | 放弃 |
|---|---|
| 材料与音乐**相互生长** | 完整歌曲、强烈鼓组为主 |
| 只保留**一个短动机**作记忆线 | 每个画面元素各自获得主题 |
| 释放段靠**连续性与空间展开** | 夸张的低频落点 |

# 三个可独立修改的核心对象
1. 叶片摩擦做成的**节奏家族** → [配方 A](/recipes/leaf-paper-rub-light-percussion.md)
2. 有明确起点的**水滴与短音过渡** → [配方 B](/recipes/water-drop-to-musical-note.md)
3. 一个**四小节旋律及伴奏骨架** → [MIDI 四小节对照练习](/exercises/midi-four-bar-motif-comparison.md)（配套 MIDI 只演示第 3 项，不含前两项的实录或合成音频）
