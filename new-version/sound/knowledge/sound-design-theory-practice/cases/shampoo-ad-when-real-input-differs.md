> 证据身份：**教学假设案例**。方向词来自对话；30 秒、4/4、118 BPM、旁白窗口等均为本篇假设；无真实影片、音频、试听或授权。

# 情形一：旁白延续到 18 秒
12–16 秒旁白窗口只是假设（不是合同，也不是按平均语速推定的必然值）。实际延到 18 秒会与 C05 释放重叠。三条路径：
1. 经批准调整文案或表达；
2. 延后释放但保留片尾任务；
3. 让释放先通过画面和稳定音乐发生，等语言结束再加新的音乐事件。

三条路径改变的对象不同，**不能由声音 agent 默默选一条后通知其他部门"已解决"**：比较所需修改、保留目标和代价，再更新受影响点位。

# 情形二：最终画面没有茶叶近景
S01 等材料不必因蓝图曾列出而强行保留；把"细小现实事件逐渐音乐化"的规则转移到水、瓶身或其他实际存在的动作，而不是让声音暗示不存在的配方成分。

# 情形三：画面更接近日常人物生活
重评是否仍采用 B 方向。可复用的是材料联系、前景交接与身份回收；微观幻想不是必须保留的教条。
