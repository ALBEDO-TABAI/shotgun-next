> 证据身份：**自拟教学案例**，无实际影片，全部为构想。

# 设定
成年人独自收拾父亲留下的工具箱，最后把一枚螺丝放回原来的格子。

# 六步
1. **明确事实**：画面表达整理与归位；无台词说明父亲是否去世、关系历史。→ 不在音乐描述中擅自写入丧亲事实。
2. **三种任务假设**（方向不同，不是悲伤程度高低）：
   - A 珍惜一种生活习惯；B 人物在控制情绪；C 关注物体排列的形式秩序。
3. **配置关系**：
   | 方向 | 声音关系 |
   |---|---|
   | A | 日常环境继续，保留工具具体接触，仅归位后很短的音乐回应 |
   | B | 持续层贯穿整理，关键动作时退出，留给一次呼吸 |
   | C | 从工具接触提取节奏，画面排列与声音重复形成形式，不先给亲情判断 |
4. **失败信号（预先声明的风险）**：A 太平淡没注意归位；B 把平静动作夸大成创伤；C 把人物工具化为图形、失去温度。
5. **最小对照**：素材相近，只比较音乐在归位**前／后**进入。问："哪个动作对你最重要？""你认为他在做什么？""是否认为片段已明确某人去世？"——若最后一项被无依据强化，追查是音乐、画面还是提问造成。
6. **有边界的结论**：受测者普遍注意归位 → 支持注意力任务；**不能**宣布"观众理解了完整父子关系"。证据尺度 = 声明尺度。
