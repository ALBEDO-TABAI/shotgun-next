> **证据身份**：自拟教学案例，非实际影片。

# 设定
人物独自在厨房，冰箱可见；阅读一封信时出现一条低沉持续声；他离开后，该声延续到空房间镜头。

# 逐层分析
| 层 | 做法 |
|---|---|
| 观察层 | 记录何时可辨、是否随其他层退出而突出、是否与人物动作同步；**不**直接命名为"低音合成器"或"冰箱录音" |
| 形式层 | 它跨人物与空房间延续，建立连续关系；若后面有声源揭示，再更新来源判断，而不改写当时能知道的内容 |
| 假设 A：人物主观压力 | 查看是否与人物注意、记忆或其他主观处理相关；空房间中继续存在不一定推翻，但要求更复杂解释 |
| 假设 B：空间持续 | 若在其他无人物场景也出现，或与设备状态相连，则获支持；画面有冰箱≠声音一定来自冰箱 |
| 假设 C：剪辑连接 | 可能主要连接离开与空房间；比较在切镜处终止与延续的版本 |
| 一手资料层 | 若混音师说明由设备录音与音乐共同构成，可支持制作来源；仍不能证明观众都理解为压迫 |

# 结论写法
> "制作来源是复合材料；形式上跨镜延续；其作用可能兼有空间持续与人物情绪余留，当前资料不足以确定唯一解释。"

这比"冰箱声象征精神崩溃"更扎实。
