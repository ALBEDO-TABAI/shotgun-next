> 证据身份：**自拟教学案例**。音频事实为教学设定，真实项目必须听后确认。

# 原始反馈
"这段音乐太厚了，不够清爽，泡沫要更梦幻，结尾不够高级。"——几乎没有明确改动对象。

# 步骤
| 步骤 | 做法 |
|---|---|
| 1 回到事实 | 假设信息段：低音持续、颗粒打击频繁、旋律每两拍变化，泡沫音效在每个动作上落点 |
| 2 解释"厚" | 不立刻认定低频过多；检查持续层与高事件密度是否共同覆盖语言；也可能真正拥挤的是连续上行旋律 |
| 3 最小修改 | 信息段撤掉新的旋律事件，保留低音与较稀疏的颗粒；**不同时改和声、速度与音色**。若清楚度改善，说明问题至少部分来自活动竞争而非频谱 |
| 4 解释"梦幻" | 选定为"现实起点与非现实尾部的转化"，不自动加全局混响；只为少数主泡沫设计尾部延伸，检查小尺度是否保留 |
| 5 解释"高级" | 暂定为"收束有控制、身份清楚、不过量强调"；片尾保留短动机、撤去多余转场音，而非加更厚重的标识冲击。若品牌要张扬庆祝，此解释须重选 |
| 6 重写反馈 | 见下 |

# 改写后的反馈
```text
信息段先减少新事件；微观段采用可辨起点到抽象尾部的转化；片尾通过材料回收而非加响完成。
保留速度与总体方向。验收时分别看语言是否清楚、微观尺度是否成立、结尾是否与开头形成联系。
```
