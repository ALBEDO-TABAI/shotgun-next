# 背景
最小修改适合定位具体问题，但并非所有问题都能靠单因素测试解决：音乐密度的影响可能取决于**何时进入**；某音色在稀疏混音里合适，在密集混音里可能产生不同关系。

# 无效初稿
| 条件 | 音乐进入 | 旁白区音乐活动 |
|---|---|---|
| A | 旁白开始前 | 较少新事件 |
| B | 旁白开始前 | 较多新事件 |
| C | 旁白结束后 | 较少新事件 |
| D | 旁白结束后 | 较多新事件 |

**问题**：若"旁白结束后才进入"意味着旁白区完全没有音乐，那么第二个因素在 C、D 中**并未真正变化**——这个表只是长得像四格实验。

# 修正方向
- 两个入口都放在旁白前，只改变**相对画面动作的早晚**；再在两种入口下实现可比较的旁白区活动水平；
- 或放弃这一设计，重新提出更合适的问题。

# 检查清单
- 因素能否独立改变？
- 组合是否实际存在？
- 其他条件是否可比？
