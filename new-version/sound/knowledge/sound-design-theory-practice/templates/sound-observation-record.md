# 写法原则
- 好的观察："角色抬头之后，连续打击停止；较长的音高层保留到下一镜头；人声没有同时出现。"
- 不好的观察："音乐终于表现了孤独。"（直接跳到解释）
- 声源不明时**描述形态**："短促、带金属般余振的声音"，不写"用水琴录制"，除非有来源证据。调性、拍速、声道、处理方式同理：听出的与未判定的分开写。
- **"不存在"的观察要谨慎**：说"没有音乐"前，先检查是否有低调音高层、环境化音乐或被掩盖的持续材料；只能确认"没有明显旋律"时不要扩大为"完全无配乐"。

# Schema
| 字段 | 填写说明 |
|---|---|
| 位置 | 时间码／区间（按版本记录的时间码规则） |
| 可听事件 | 听到了什么；声源不明写形态 |
| 持续／变化 | 起势、持续、终止、材料变化 |
| 可见对应 | 同时可见的动作、剪切、文字 |
| 与其他声音关系 | 前后景、遮蔽、交接、共存 |
| 确定程度 | **用证据说明**，如"起点清楚，但声源不明"；不写凭感觉的"96% 置信度" |
| 复查方式 | 他人如何复听／复看验证 |

# Examples
```text
位置：00:41–00:47
可听事件：一条低沉持续声（声源未确认）
持续／变化：人物停顿时相对突出，切镜后延续
可见对应：人物读信；随后空房间镜头
与其他声音关系：其余环境层同时减弱
确定程度：进入时机清楚（可复查）；声源身份低确定（无制作资料）
复查方式：同一版本 00:40 起完整回放
```
（示例为自拟，承接 [低沉持续声分析案例](/cases/kitchen-drone-analysis.md)）
