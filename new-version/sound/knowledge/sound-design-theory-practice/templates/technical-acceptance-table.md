# Schema
| 检查对象 | 应先确认的条件 | 典型检查方式 |
|---|---|---|
| 长度与同步 | 画面版本、帧率、时间原点、允许误差 | 对照指定时间线与关键动作，完整回放 |
| 编码与容器 | 目的地要求的格式、采样率、位深或编码方式 | 读取文件元数据并验证可正常解码 |
| 声道布局 | 单声道／立体声／指定多声道，轨道顺序与标签 | 检查路由、声道标识及实际声音 |
| 响度与峰值 | 约定规范、测量方法、整片或片段范围 | 使用对应仪表并保存报告 |
| 接缝与尾部 | 是否包含混响尾部、导出范围是否正确 | 检查开头、剪接、停顿与结束 |
| 可理解性 | 哪些信息必须在什么播放条件下被理解 | 目标条件试听，按任务提问 |
| 派生版本 | 不同片长、语言、比例或渠道是否改变声音任务 | 各自验收，不以主版本通过代替全部通过 |

# 规则
- 写成**项目表**，不复制一组"通用最佳参数"。
- **EBU R 128** 是特定广播响度规范体系的一部分[2]；是否采用应与实际目的地及约定版本核对，不是所有社交平台、影院和展陈的统一答案。
- 文件响度读数不告诉你手机扬声器频响、用户音量设置或周围噪声——技术表必须与**实际播放检查**共同使用。
