# Schema
~~~text
当前问题：
这一轮不变的内容：
声音／音乐种子：
展开办法：
具体音乐对象：音符、节奏、声部或声音过程
实现办法：演奏、录音、合成、采样、编辑
需要的素材与工具：
可听或可编辑的产物：
放回画面要检查的关系：
失败信号与第一返修动作：
~~~

# 字段说明
| 字段 | 目的 |
|---|---|
| 这一轮不变的内容 | 防止每轮全部重做，保护已通过部分 |
| 具体音乐对象 | 把"想法"落到可发声、可编辑的对象 |
| 可听或可编辑的产物 | 每轮必须产出一个对象，而非更多描述 |
| 失败信号与第一返修动作 | 让规则可证伪（见[最小行动单元](/principles/minimum-action-unit-rule.md)） |
