# Schema
```text
对象／段落 ID：
目标：观众要注意、理解或体验什么
声音事实或待生成的材料：
时间：开始、关键变化、结束、尾部
节奏：拍单位、速度、重音、密度、停顿
音高组织：动机／旋律／持续音／未判定
音色形态：音头、主体、颗粒／连续、终止
空间：主体距离、方向、尾部范围、遮挡
动态：段落对比；是否有约定测量指标
与其他声音关系：前景、支撑、交接、融合／分离
允许变化：
禁止项：具体不需要的特征及其原因
参考：准确段落、借用维度、排除维度
实际工具能力：已确认／未确认
验收：可听结果、技术条件、非预期联想
```

# 检查顺序
1. 目标是否清楚
2. 描述是否自相矛盾
3. 工具是否能执行
4. 实际音频

# 填写纪律
- **分析任务**：无法确认的字段留"未判定"，不为模板完整而猜测音高、调性、音源或录音方式。
- **创作任务**：可提建议值，但须标为建议，而非对原片的观测。
