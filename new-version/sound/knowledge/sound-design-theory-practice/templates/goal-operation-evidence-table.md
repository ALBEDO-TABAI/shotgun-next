# Schema

| 字段 | 填什么 |
|---|---|
| 原话 | 客户／导演的形容词原话 |
| 更具体的目标假设 | 体验上真正要的是什么、不要什么 |
| 第一轮尝试 | 可听、可比较的具体操作 |
| 不能忽略的反证 | 该操作仍可能失败的方式 |
| 失败判据 | 听到什么就算这条路不成立 |

# Examples（本包提出的实验方向，非科学处方）

| 原话 | 目标假设 | 第一轮尝试 | 反证 |
|---|---|---|---|
| 轻快但不幼稚 | 有运动感，不靠蹦跳式可爱 | 保留中速脉冲；改重音与音长；先不加高音铃铛 | 去掉铃铛后旋律和演奏仍可能像儿歌 |
| 梦幻但不糊 | 现实边界松动，重要动作仍清楚 | 近距离主体 + 处理过的尾部，而非整轨长混响 | 尾部仍可能遮掉下一个动作 |
| 温暖但不煽情 | 接近人物，不替他宣布情绪 | 小音域、有限和声运动、克制句末；与无音乐版比较 | 稀疏慢钢琴同样可能很煽情 |
| 有力量但不压迫 | 动作有决心，信息不过载 | 明确起音与停止、低音节律简化、关键处才加厚 | 更短的声音也可能变尖硬 |
| 紧张但不提前剧透 | 维持不确定，不宣布危险 | 延迟完成短句、保留少量不稳定纹理 | 惯用悬疑音色可能已经剧透 |

# 使用要点

- 每行都要有"反证"与"失败判据"，否则无法收敛。
- 不要把表格反向当作情绪→乐器字典。
