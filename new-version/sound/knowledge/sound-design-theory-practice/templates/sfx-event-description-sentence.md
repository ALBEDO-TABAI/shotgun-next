# 句式
> 在**什么上下文和时刻**，一个**什么性质的对象**，以**怎样的动作**与另一对象或空间发生关系；声音怎样**起势、持续、变化和终止**；观众**应辨认什么**，又**不应被引向什么**。

# Examples
| 原需求 | 改写 |
|---|---|
| 加一个水声 | 液滴脱离叶尖时出现一个小而清楚的起点，接触后有极短、细密的尾部；保持轻微尺度，不加大水体的低沉冲击。希望引导注意到脱离与落下，而不是强调冲洗力量。 |
| 加一个科技音效 | 装置启动前出现两次不完全稳定的内部脉冲，成功时杂乱细节逐渐收束为连续运转；不要用爆炸式落点，重点是状态被稳定下来。 |
| 加一个转场 whoosh | 镜头开始穿越泡沫时，细密空气摩擦逐渐形成；最密的部分对应穿越过程，而不是切镜本身；抵达后迅速退出，为下一句语言让位。 |

# 边界
- 允许非真实声源参与制作。**来源替代不自动等于虚假**；关键在项目允许何种风格化、支持哪种动作感、是否制造不该有的事实印象。
