# Schema
```text
一、材料与范围
作品、版本、来源、分析区间、播放条件、缺失信息。

二、可复查观察
按时间记录声音事件、变化、可见对应和不确定部分。

三、形式组织
叙事归属、听觉位置、前后景、时间关系、重复与例外。

四、功能解释
主要假设、支持依据、替代解释、可推翻条件。

五、制作与作者资料
一手来源、具体陈述、对应版本、与实际声轨的关系。

六、对照与测量
实际执行了什么；只建议了什么；每种方法的限制。

七、评价与迁移
与明确目标的关系；可复用规则；不宜照搬的条件。

八、结论状态
已证实、较有支持、仍未确定、需要什么下一步依据。
```

# 使用规则
- 局部分析可以缩短，但**不可删除材料范围与证据状态**。
- 无音视频输入时，报告名称改为"声音设计假设"或"分析计划"，避免标题制造"已完成观察"的假象。
