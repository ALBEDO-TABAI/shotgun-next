# 为什么需要
同名作品可能存在不同剪辑、预告、地区版、修复版或平台版本。版本差异可能改变结论时，分析者必须核查所用材料。目标不是无限技术记录，而是**保存足以让别人找到同一段、听到同一版本并检查结论的信息**。

# Schema
| 字段 | 说明 |
|---|---|
| 作品名称 | 正式名称 |
| 获取来源 | 平台、发行介质、链接等 |
| 版本／文件标识 | 当前版本或文件 ID；未知则写"未知"，不从文件名推断 |
| 时长 | 实际文件时长 |
| 音轨语言 | |
| 声道 | 单声道／立体声／多声道 |
| 可确认的技术参数 | 仅写可确认的 |
| 时间码规则 | 用于定位的计时方式 |
| 播放条件 | 设备、耳机／扬声器、房间、自动音量等 |
| 分析范围 | 全片／片段区间 |

# 边界提醒
- 只有线上片段 → 分析范围写"该片段"，不是全片。
- 只有一个压缩混音 → 不能描述原始分轨。
- 只有带字幕视频 → 字幕中的音效标注不等于实际可听细节。
- 区分**作品声轨**与**播放环境**：房间噪声、耳机处理、自动音量、声道转换都会影响观察，不要把无法排除的播放问题归咎于创作者。
