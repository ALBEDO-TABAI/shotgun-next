# Schema
~~~text
旁白／对白 → DX 人声组 ──────────────┐
音乐：领奏／和声／低音／节奏 → MX 音乐组 ─┼→ 视听总混音 → 指定交付版本
物体动作／环境／设计声音 → FX 声音组 ────┘
需要共享的空间 → 发送／返回轨（按实际空间和交付需要设置）
~~~

# 使用说明
- DX／MX／FX 是讲解用标签，**不要求**工程使用同一命名。
- 轨道数和总线数由**可编辑性**决定，不为"专业感"制造复杂层级。
- **前／后推子发送**：调整主轨音量后，空间尾部是否应跟随？按需要听到的行为选择。
- **并行 ≠ 串联**：并行处理把原声与处理声混合；iZotope 教程给出过辅助总线路由示例。[2]
- 分组方式会影响后续分轨交付：见 [分轨相加不等于总混](/principles/stems-sum-not-equal-mix.md)。
