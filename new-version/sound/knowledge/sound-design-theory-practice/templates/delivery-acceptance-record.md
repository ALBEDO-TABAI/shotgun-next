# Schema
| 字段 | 说明 |
|---|---|
| 文件身份 | 文件名 + 可选校验值（SHA-256 仅证明字节同一，不证明质量） |
| 对应画面与声音版本 | 绑定时间线版本 |
| 导出时间 | |
| 测量工具及范围 | 工具版本、所用标准版本（如 BS.1770 的约定版本） |
| 检查结果 | 技术、艺术、权利、无障碍分列 |
| 试听环境 | 监听设备与条件 |
| 审核者 | 谁做的判断 |
| 保留问题 | 未解决项与例外批准 |

# 规则
- 目标值（响度等）来自**目的地规范与合同**，不来自网络口诀。
- 无障碍检查与成片共同进行（字幕、重要声音信息、音频描述）。
- "可交付"= 各条件的明确合取或已批准例外。
