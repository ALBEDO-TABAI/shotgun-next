# Schema
| 规则对象 | 需要确定的内容 | 相关概念 |
|---|---|---|
| 现实边界 | 哪些声音保持写实，哪些允许夸张、抽象或替代？ | [真实四维](/frameworks/four-dimensions-of-realism.md) |
| 世界常态 | 没有重要事件时，各空间怎样运转？ | [地点声音三问](/methods/place-sound-three-questions.md) |
| 听觉立场 | 默认从哪里听？何时转入某个人物的感知？ | [听觉立场三轴](/frameworks/three-axes-of-auditory-stance.md) |
| 材料关系 | 音乐、环境、物体声、人声是否共享材料或行为特征？ | [整体性不是同质性](/principles/unity-is-intentional-relation-not-sameness.md) |
| 注意力规则 | 关键时刻由谁承担表达，其他声音怎样支撑？ | [协调强调](/principles/coordinated-emphasis-not-stacking.md) |
| 变化规则 | 哪些声音可以变形、跨场或改变叙事归属？ | [多轴标注](/frameworks/multi-axis-sound-annotation.md) |
| 省略规则 | 哪些可见动作不必发声？哪些时刻不使用音乐？ | [三种留白](/frameworks/three-silence-operations.md) |
| 播放约束 | 哪些关系必须在目标播放方式中保留下来？ | [四个声音世界](/frameworks/four-sound-worlds.md) |

# 写法：规则要带边界
```text
可以微观化，但不把细小动作做成巨大撞击；
可以梦幻化，但关键产品动作仍需容易理解；
可以存在两个风格，但二者的切换必须有明确依据。
```
