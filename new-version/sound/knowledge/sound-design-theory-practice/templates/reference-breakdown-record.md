# 模板
| 参考记录项 | 应写的内容 |
|---|---|
| 来源与段落 | 作品、版本、准确区间，取得途径 |
| 可听事实 | 前段稀疏、某时刻撤去打击等，不先写"高级" |
| 借用维度 | 结构、节奏行为、空间关系或表达距离 |
| 排除维度 | 不复制旋律、歌词、标识或不合项目的特征 |
| 转化问题 | 这一特征怎样与本项目的画面任务发生关系？ |
| 验收依据 | 新方案怎样在不相似的表面下仍完成相同任务？ |

# 使用规则（工作方法，非量化心理效应）
- 引用参考的**具体段落**，而不只给全曲链接。
- 例：借其前景稀疏、弱起进入、结尾收束；不借旋律、特定演唱方式或其已知品牌联想。
- 准备**功能相同但风格不同**的参考，让团队看到任务与音色的区别；参考都几乎相同 → 讨论只能在细微仿制中移动。
- 参考是讨论证据，不是隐形命令；不作为要求生成系统复刻某位创作者身份的捷径——写可听特征、使用方法和禁止项。
