# Schema
| 字段 | 内容 |
|---|---|
| 作品任务 | 商业或非商业目的、主要信息、人物或产品关系、观众体验轨迹 |
| 声音命题 | 整体如何被听见、默认听觉立场、哪些声音材料形成联系 |
| 已批准边界 | 事实约束、不能提前揭示的内容、应避免的联想、音乐与人声优先关系 |
| 传播条件 | 片长、语言、目标播放环境、是否需静音或无障碍版本 |
| 未决问题 | 如音乐是否原创、最终旁白未定、发行规范待核对 |
| 工作阶段 | 选方向／关系原型／精修／交付验收 |

# 规则
- 未决项**不应自动补成事实**。
- 合理默认值可作建议，但须**标记为暂定**，并写明哪些后续决定依赖它。
