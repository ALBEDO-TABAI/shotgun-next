# Schema
```text
一、当前可以确认的事实
二、对主要任务的判断及依据
三、仍有不确定性的地方
四、已经决定的修改或接受条件
   —— 每项：责任人／产物／复验范围
```

# 写作规则
- **不并列罗列冲突意见**：一条要"音乐更明显"、一条要"旁白更清楚"，可能是两位听者在评价不同时间窗口。先定位具体位置，可能只需改变交接，而不是重新选曲。
- **不为全体同意削平作品**：若某特征服务于已批准目标，争议应被记录并由决策者权衡；只有违反必要条件或造成不可接受后果才按问题处理。
- **记录选择所依赖的约束**：多个方案都可成立时，不必宣称其他方案错误；条件变化后团队知道此前为何选择、什么新信息值得重开决定。

# 最终产物
不是"百分之百完美"的声明，而是**与证据相称、对当前版本有效、可执行和可复查**的决定。
