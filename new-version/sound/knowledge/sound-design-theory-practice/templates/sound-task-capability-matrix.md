# 用途
"多模态模型""音乐 agent"等名称**不构成能力证据**。派发前为每个执行单元填写此表。

# Schema
| 能力 | 必须验证的内容 | 不能替代的内容 | 本单元实测结果 |
|---|---|---|---|
| 读取剧本与资料 | 实际可访问哪些文件、是否完整、对应何版本 | 不等于听过影片 | |
| 观看与听音 | 支持的容器、时长、声道，是否能获得真实音轨 | 文本转录 ≠ 音色和混音分析 | |
| 生成音乐或音效 | 是否有实际服务、输入约束、输出形式、费用和权限 | 写出提示词 ≠ 音频已生成 | |
| 编辑与混音 | 能否对真实素材剪切、自动化、路由和导出 | 描述修改 ≠ 修改已执行 | |
| 技术测量 | 工具版本、测量范围、报告与实际文件的绑定 | 模型自评 ≠ 仪表结果 | |
| 检索与权利核查 | 可获得哪些条款、合同或权属证明 | 网页上有试听 ≠ 可以使用 | |
| 发布与交付 | 是否有目标位置、访问权限与用户批准 | 本地导出 ≠ 上线成功 | |

# 降级规则
能力不足时，任务可降级为"提出方案"或"准备交接"，但**状态必须同步降级**，报告中不能保留"制作完成"。
