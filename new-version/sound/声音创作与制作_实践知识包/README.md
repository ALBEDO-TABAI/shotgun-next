# 声音创作与制作｜实践知识包

本包补充原十篇理论中的制作层，不覆盖原文件。重点是需求翻译、构想、作曲与编配、演奏与录音、音效制作、混音和有针对性的修改，不再重复扩展分析分类。

## 入口

**[主文：声音创作与制作——从需求到可听方案、成片与迭代](声音创作与制作_实践知识包.md)**

主文包含七个生产模块、完整的假设洗发水广告工作过程、跨体裁迁移、小型练习、创作卡和返修卡；末尾保留 27 项来源条目与各自查阅范围。来源包括一手作曲教学、开放教材、原始实验、官方手册与官方规范介绍。示例音符、制作试验和案例返修属于原创教学构造。

**[练习说明与三个 MIDI 文件](exercises/README.md)**

MIDI 是四小节可编辑音符材料，用于比较“保持原句”“撤掉中段领奏”“改变句末音”。它们不是本文三个创意方向的完整配乐，也不是 30 秒成片音轨。

## 建议阅读路径

要从需求开始做一段新音乐，读第一、二模块，再进入第三模块的音符与编配练习。

已经有乐谱或 MIDI 但声音机械，读第四模块；需要物体音效或非常规材料，读第五模块。

已有声音但放入画面不成立，读第六、七模块，并回到对应的作曲、演奏或素材层局部修订，不默认所有问题由插件解决。
