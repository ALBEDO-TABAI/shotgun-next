# 空间与物件

用于从故事动作走向布景/场景卡。基本原则来自美术职业对功能、连续性与制作需求的要求，具体表单是本包工作约定，见[来源](sources.md)。

## 先排功能，再装饰

把场景分成动作区、等待/观察区、通行区、遮挡区、画外延伸。实际尺寸未测时可用相对关系，不写虚假的精确平面图。导演需要的两人关系决定视线和动线；美术提供可见空间，不接管镜头。

| 空间类型 | 首要判断 | 常见选择 | 容易漏的检查 |
|---|---|---|---|
| 住宅/小店 | 人如何使用、存放与维护 | 动作面集中，生活区与工作区交叠 | 门打开后是否挡主动作、家具是否能真实取物 |
| 制度性空间 | 谁等候、谁被看见、谁有权限 | 柜台/门禁/动线形成关系 | 标识、透明隔断、声音泄露是否与情节一致 |
| 交通/狭窄空间 | 乘坐与进出、手可伸向哪里 | 限定通道、窗景与支撑点 | 假装无限退机位、人物穿过座椅 |
| 公共/人群空间 | 主行动线与群体流向 | 一条清楚路线，局部障碍 | 群众是否挡住主动作、密度是否可复位、每个可见人物是否有自己的任务与时点而非同步反应 |
| 自然/户外 | 地形、天气、水与脚印的作用 | 地貌与活动相关，允许空旷 | 地面湿干、方向、季节与声音变化 |
| 产品/抽象舞台 | 产品尺度和被证明的属性 | 接触面、支撑、留白、界面 | 底座不稳、反射吞字、效果伪造功能 |
| 幻想/数字世界 | 空间可读规则与动作路径 | 重复地标、局部例外、尺度锚 | 美术漂亮但人物无法执行动作 |

## 场景卡

核心信息：`场景ID/本次版本 → 叙事用途 → 关键区域及关系 → 空间锚点与主视角 → 出入/接触/视线 → 视觉语法 → 关键道具 → 变化状态 → 实现与未定项`。

如需要平面关系，给方向约定：以上方为窗面，入口在下方；再标人物从入口到工作台的路径。不要混用画面左/角色左/房间左。位置用唯一语义锚点写，如“收银台与冰柜之间的通道”“电视右侧、正对窗的沙发”，不写“右边的架子”；交给生成或多人调度时标明主视角从哪个方向看，近景沿用同一锚点。转反打后屏幕左右会变，固定的是场景锚点关系。美术层只锁定场景几何；摄影可在明确条件下使用不同机位。

场景画面至少能回答：看到哪个界面、画面外是否有出路、人物与道具如何接触。只做概念立面时明确“未定义背面/动线”；不可把一张正面概念图当已完成360°空间。

## 物件层级按工作用途分

| 类型 | 设计重心 | 输出深度 |
|---|---|---|
| 叙事关键物件 | 观众须辨认、谁拥有、怎样开合/转交/损坏 | 多面形态、尺寸依据、状态和可替代件 |
| 人物操作道具 | 可抓握、容量、重量感、声音 | 操作步骤、接触点、材料或数字行为 |
| 陈设 | 世界习惯与背景秩序 | 所在区域、密度、颜色关系；不用每件传记 |
| 消耗/变化道具 | 破损、液位、折痕、燃烧/湿度状态 | 剧情时间状态、复位方法、复制需求 |
| 屏幕/印刷/文字道具 | 信息何时可读、字句与时代一致 | 精确文字、阅读方向、所需清晰度 |
| 特效/危险替代物 | 看起来像什么、实际由谁确认如何做 | 效果目标与交接问题；不冒充安全方案 |

关键道具卡：`ID | 来源剧情 | 外观可辨点 | 使用动作 | 所有者/位置 | 状态变化 | 实拍/数字实现 | 保留/可替代 | 验证项`。

## 让美术产生戏，而非添加故事

- 想让物件被隐藏：选择柜门、袖口、遮挡或光影条件；不新增“密室”改变剧情。
- 想让递物有犹豫：提供足够的台面距离与能短暂停放的位置；动作决定仍交导演。
- 想让世界显得拥挤：可以压窄视线、增加近侧遮挡；不必真的把通行口塞满。
- 想让产品成为中心：控制轮廓和邻近反射；不必把一切都染成品牌色。

## 反向验证

从三个时刻回看场景：动作前东西在哪 → 动作怎样发生 → 动作后什么改变。若角色在前镜把钥匙放抽屉，后镜从口袋拿出，先找是否缺转移动作，不能只通过“画面更美”解释。

能否制作到所需镜头尺度？大远景只见轮廓的招牌不必制造密密麻麻的小字；特写要展示铰链就不能只有没有结构的封闭外壳。先确定观看需求，再分配细节与工时。
