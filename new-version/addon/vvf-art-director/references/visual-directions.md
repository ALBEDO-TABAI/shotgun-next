# 美术视觉方向选择

用在方向未定或方案看起来都一样时。下表是本包可组合的设计路线，不是风格史分类，也不是互斥桶。每个项目选择真正改变画面的轴，毋须填满。

| 路线 | 画面构造与适用任务 | 常用实现 | 失效反例 |
|---|---|---|---|
| 生活观察 | 使用痕迹集中、非对称但有功能秩序；让人物生活可信 | 搜集操作细节，保留普通物件之间的关系 | 每面刷旧、每角堆杂物等于“穷” |
| 日常秩序 | 整洁、维护、有限差异；家庭、机构、克制剧情 | 重复柜体/桌面系统，以一件变动读人物选择 | 只有样板间，找不到居住动作 |
| 工业过程 | 接口、传输、磨损、工具尺度；劳动、科技与流程 | 功能线连通，材料按用途分区 | 空管道和齿轮只作装饰 |
| 仪式/纪念 | 明确中心、门槛、重复、观看方向；关系与权力 | 局部对称，留空与进入顺序 | 无差别宏大、所有角色都同样重要 |
| 亲密手工 | 可触表面、修补、纤维、局部不齐；记忆与人物手艺 | 手工材料与使用处细节 | 只加纸纹滤镜，形状仍像塑料 |
| 商业几何 | 功能中心、清楚支撑、反射受控；产品与信息展示 | 模块台面、限定颜色关系、准确标识 | 材料炫技盖过产品，误表现功效 |
| 编辑式平面 | 图形层、尺度对比、文字与物体关系；概念广告/片头 | 有意压平空间，清楚分层规则 | 被硬要求三层纵深破坏版式 |
| 舞台表现 | 空间以心理/关系组织；寓言、MV、夸张喜剧 | 假透视、可见布景、色块与变形 | 一会写实一会抽象却无转换线索 |
| 低密度陌生 | 少量形体、空白、异常尺度；悬念或孤立感 | 控制可见信息与背景秩序 | 所有惊悚都改成脏暗房间 |
| 高密度拼合 | 物件聚集形成时间/身份层；喜剧、混杂城市、私人收藏 | 分组、重复、主次密度，保留操作面 | 所有风格平均拼贴，无视觉中心 |
| 历史再现 | 特定时地的建造与使用规律；历史叙事 | 实物证据与地区资料，具体时代层 | 用同类影视作品代替历史资料 |
| 历史转译 | 明确借用结构并重组；幻想、架空世界 | 保留选定工艺逻辑，说明哪些已虚构 | 把混搭称为考据准确 |
| 生物/生态 | 生长、栖息、循环和尺度关系；自然/幻想环境 | 生长方向和资源限制影响形状 | 到处长藤蔓却没光水来源或自定规则 |
| 轻盈/悬浮 | 轻接触、透光、缓慢形变；诗性与幻想 | 显式定义支撑/失重/影子规则 | 实拍稿中无说明要求承重物凭空悬浮 |
| 机械/纸偶/定格 | 接缝、部件、材质与动作方式共同可读 | 角色/场景共享颗粒与尺度 | 用实拍皮肤毛孔要求抹掉手工痕迹 |
| 数字抽象 | 粒子、体积、线条或UI形成可行动世界 | 定义边界、交互、变化和层次 | 只写“赛博”，每镜效果随机 |

## 组合规则

优先说明主路线决定什么、辅路线只作用在哪个层。例如“生活观察决定空间与工具；商业几何只决定产品陈列台”。相冲突的层给明确归属，不能同时要求全部写实与全部平面。参考一个作者时，描述选中的可见关系，不靠名字代替规格。

## 两种方案如何真的不同

选一个核心轴做分叉：空间关系、材料响应、密度、时间痕迹、抽象程度或制作工艺。两方案使用同样剧情、同样镜头需求，比较谁更能完成任务。

示例目标“让修理店体现与旧物共处”：

- 方案A：多次修补的材料叠层，工作台整洁；人物的修复劳动可见。
- 方案B：近乎空白的店，只保留顾客留下的旧物墙；缺席者通过物件位置可读。

差异不在冷暖调，而在观众从“使用过程”还是“物件关系”认识空间。若故事重手艺选A；若重记忆选B。镜头不能展示旧物墙，B的优势就不存在，应改选。

## 方向验收

暂时去掉风格名称，仍能据描述构造明显不同的画面吗？同一方向能否在日/夜、大全景/特写、人物/无人场景保持关系而不机械重复？只在一张氛围图成立的方案还不够，至少检验当前故事必需的另一个条件。

证据边界：非写实形态、材质和光影可以跨制作阶段共同设计，有主创实例支持；本页路线与推荐为本包归纳，不声称观众效应已实证。见[来源](sources.md)。
