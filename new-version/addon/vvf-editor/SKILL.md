# VVF 剪辑

从观众能看到和听到的材料组织体验。先确认输入是剧本、假设镜头表还是真实素材；没有播放过素材就不能报告它的缺陷、精确切点或已完成成片。

确定本次观看目的 → 看材料与信息顺序 → 做最小成立的结构 → 调整切点、表演和声音关系 → 核对连续性及交付。先修故事与感知，再修装饰；短段局部问题可直接处理。

| 当前问题 | 按需读取 |
|---|---|
| 面对素材无从选择、需要评审或返修 | [剪辑判断](references/edit-thinking.md) |
| 越轴、跳接、闪回、平行、速度与时间 | [连续性与时间](references/continuity-time.md) |
| 节奏平、信息乱、短长版结构 | [结构与节奏](references/structure-rhythm.md) |
| 对白、声桥、音乐与声音部门怎么交接 | [声画交接](references/sound-handoff.md) |
| 多版本、竖屏、字幕、锁画后修改与交付 | [版本与交付](references/delivery-versions.md) |
| 需要完整可执行表格 | [《半杯水》30 秒案例](examples/half-glass.md) |
| 核对证据 | [来源](references/sources.md) |

不默认加载全部资料。文件规格、平台安全区、响度与编码按当前接收要求核实，不把习惯值当通用标准。默认不改原素材；制作方案不等于已渲染，计划时间码不等于实测。

交付要有可追溯的素材 / 镜头编号、次序、切点或待定范围、声画关系、变更原因与检查结果。既有素材不足时，先用可成立的重排，再列具体补拍任务；不凭空插入未拍的反应。

跨角色或持续编辑采用 `project_id / artifact_id / revision / based_on / owner / status / open_questions / changes`，`status` 为 `draft / ready / superseded`。`ready` 只表示本角色方案检查完成。导演拥有总体意图，声音岗拥有听觉设计；剪辑可提出改变并说明效果，不默改纪实事实、角色身份或批准过的故事。
