# 声画关系与声音交接

剪辑决定声画在时间上怎样相遇；声音岗位决定听觉视点、材质和混音。没有独立声音人员时可给临时方案，但标清临时和正式。

## 先分声音职责

对白 / 旁白负责语言信息；环境声建立地点与连续；动作声使事件可感；音乐可组织情绪或形式；静默可改变注意关系。不是每种声音都要出现，也不是画面每个动作都要夸张配声。

| 手法 | 适用任务 | 容易造成的问题 |
|---|---|---|
| 下一场声音提前（J-cut） | 先引起注意、带入空间或话题 | 误以为当前人物听见未来场景的声源 |
| 上一场声音延后（L-cut） | 保留余韵、反应或语意 | 误以为人物仍在同一时空 |
| 声音桥 | 跨地点 / 时间形成关系 | 把非同时事件伪装成真实因果 |
| 留反应时声在画外 | 强调听者的选择与变化 | 反应素材并非该句发生时，纪实尤其敏感 |
| 反差声画 | 讽刺、主观疏离、非写实 | 没有清晰意图，只是音乐风格不搭 |
| 刻意降声或静默 | 注意某行动、主观变化 | 被误做成技术断音或删掉必要信息 |

## 对白剪辑

检查句子完整意义、呼吸、口型、表演的思考停顿与环境连续。删除口误可以合理，但不能拼接出说话者没表达的主张。具体需要另一条录音时记录来源与替换范围，不让近义句悄悄改变事实。

## 音乐不是节奏拐杖

先看无临时音乐的结构是否有明确作用；这不是要求每片都无声成立。舞蹈、MV、音乐叙事当然可以以音乐为骨架。临时音乐需标用途与未获正式使用条件，不能混入最终交付后忘记替换。

## 交给声音岗位的最小包

当前画面版本、总时长与时间基准；可播放参考；对白与源音对应关系；有意义的动作 / 事件时间；声桥、静默与临时音乐意图；哪些已锁、哪些可能改；需要的输出种类与接收要求。

如确需分轨或工程交换文件，使用制作工具真实能导出的格式，并附参考视频与同步参考。不要仅凭文档声称音频工程可重开。[E3](sources.md#e3)

## 画面更新后

以事件和镜头编号说明插入 / 删除 / 移动及新旧时间，不只写“总长少两秒”。声音、字幕、合成、调色都需要受影响范围；只更新真正改变的段。锁画是协作约定，不是阻止必要修正的法律。
