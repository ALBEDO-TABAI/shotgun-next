# 连续性、断裂与叙事时间

本页是条件化剪辑启发，不规定每片都必须隐形剪辑。判断标准是观众是否获得本作品需要的空间、时间与事件关系。

## 连续性按关系检查

| 关系 | 检查 | 出错时先试 |
|---|---|---|
| 银幕方向 | 人物 / 物体进出方向、相对位置 | 换可用角度、过渡到中性关系或保留实际转向 |
| 视线 | 看向谁、眼高、画内外位置 | 用同框或目标镜建立关系；不能随意翻转品牌 / 手性 |
| 动作 | 接触、起落、持有、速度与阶段 | 以真实动作相位选切点，保留必要先后 |
| 道具 / 服装 / 身体状态 | 湿干、损伤、杯中量、左右手 | 换素材或承认时间经过；不要只裁掉一次后又露出 |
| 空间 | 地标、出入口、移动路径 | 补真实空间信息；没有素材就列补拍 |
| 声音环境 | 背景、混响、动作尾音 | 连续底声与交叉过渡；不覆盖叙事上应变化的环境 |

180 度轴线是一种组织空间的惯例，跨越可以有意制造不安或改变关系。要判断转向、机位运动、重新建立关系是否足够清楚，不能见跨轴就判失败。

## 选择时间策略

- 省略：跳过可预测过程，保留行动结果可理解的入口。省掉“拿到钥匙”可能让下一场开门无来源，应看它是否关键。
- 延展：反应、不同角度或声音可延长主观体验；连续重复同一动作若无动机容易显得倒带。
- 平行：多个地点轮替可暗示同时发生；若真实材料并非同时，要避免声画和标注让人误以为实时互因。
- 闪回 / 闪前：维护事件时间与呈现时间两列；用人物状态、场景或明确标记帮助定向，不一定靠统一滤镜。
- 跳接：可表达省时、焦躁、断裂、幽默或自觉媒介感；留意是否意外跳过了理解所需的步骤。
- 重复 / 循环：同一事件可随新信息改变意义；记录重复是有意设计，防止被当坏素材自动删除。
- 速度变化：检查声音、动作辨识、帧表现和意义变化；无法在原素材支持下凭空补足细节。

## 边界不是一个时间点

在切点两侧连看足够的动作和声音，检查进出姿势、反应、接触、尾音、转场残影。静态并排只能检查部分位置状态，不能证明动作过程连续。

真实切点以实际媒体的帧 / 时间基准表达；不要把可变帧率素材的平均帧率当精确帧号。未打开媒体时只给估时与事件锚点。

## 纪实的特殊约束

来源相邻不保证事件相邻。不要把来自别时别地的反应拼成当前人的反应，也不要用音效暗示未发生的暴力、事故或说话。需要时间压缩、重演、档案画面时保存出处并明确其表达性质。
