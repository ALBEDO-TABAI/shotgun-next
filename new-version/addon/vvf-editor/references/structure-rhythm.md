# 信息结构与节奏

节奏不是平均镜长或切换频率。它由信息进入、行动、表演变化、声音和观众理解时间共同构成；以下为本包创作判断，不是心理实验定律。

## 四种整理方式

| 当前目标 | 起步方法 | 调整方向 |
|---|---|---|
| 剧情关系清楚 | 按人物行动和反应建立最小连续场景 | 哪个人的变化决定切走或停留 |
| 纪实问题推进 | 材料证据与人物处境分组 | 观众的疑问是否由真实材料逐步回答 |
| 商业产品可懂 | 使用处境、产品出现、动作结果 | 不为炫技删去必要使用步骤 |
| 诗性 / 实验 | 建立重复、差异、并置或感知变化 | 形式是否持续产生新关系，而非同类美图堆叠 |

## 一遍只看一种问题

先以完整结构看信息和情感是否成立，再看切点与表演。必要时单独听声音、静音看信息或用纸卡重排；这些是诊断，不是所有片都必须做的固定检查。

“慢”的可能原因：内容重复、动作没有压力、信息早已知道、视线没有目标、声音不发展。应先删除重复或改变信息位置，不立刻倍速。

“快”的可能原因：字幕来不及读、动作结果未显露、连续新空间无定向、音乐与画面争抢、情感反应被切掉。应保留必要停留或减信息，不只是降音乐节拍。

## 切换密度与变化

连续长镜可借演员和画面内部关系变化推进；短镜群可以在一句观点、一项动作或一个声场中形成整体。是否变奏取决于目的，没有“三个同景别自动不合格”的规则。

音乐拍点可以强化转折，也可故意错开让人物行动成为主导。先确定为什么切，再决定是否踩拍；不能让素材仅成为拍点填充物。

## 从长版得到短版

短版先重新定义它必须独立完成的任务，列不可缺的信息依赖，再重建最小结构。不要把长版每镜按比例缩短。

可删除：重复证明、次要支线、观众已理解的过程。优先保留：触发、关键操作、结果、必要限制、人物选择和结尾接续。短版改了主张就成为新创作版本，不能仍宣称与长版表达完全相同。

## 完整性判据

开头建立观看方式，或有意让观众处于明确的疑问；中段每次新增画面有信息 / 情感 / 形式作用；结尾兑现本版本承诺或明确开放问题。商业片可以有行动号召，观察纪录片不必有总结口号。

给评审者的提问应具体，例如“你认为他为什么没有接杯子？”而非“好不好看”。观众回答是本次反馈，不能据一次测试推导普遍观看规律。
