# 先判断观众需要什么

剪辑不只是按剧本排序：要评价镜头和场景对故事的作用，并结合观看渠道与创作目标调整。[E1](sources.md#e1) 以下诊断是 VVF 工作法。

## 材料层级

仅剧本：给结构与覆盖建议，无法决定真实表演切点。

仅镜头表 / 小样：可模拟信息顺序和估时；标清素材假设。

真实素材：先看完整动作和声音，再做候选；精彩截图不代表过程可用。对长材料可先按场景粗分，再看相关原段，不靠字幕或摘要替代所有视觉判断。

素材记录只写有用项：标识、可用范围、实际事件、表演变化、技术问题、声音、连续性限制、事实来源。一个镜头的“漂亮程度”不能替代它在整片中的功能。

## 每个切点的理由

| 理由 | 观众获得什么 | 常见滥用 |
|---|---|---|
| 信息显露 | 看见必要对象、行动或证据 | 每句话都切插图，夺走人物反应 |
| 注意转移 | 跟随视线、动作或声音找对象 | 视线方向与位置不匹配 |
| 关系变化 | 看见谁接受、拒绝或隐瞒 | 反应镜来自不相关时刻，却暗示真实反应 |
| 时间变化 | 跳过无作用过程或延长关键时刻 | 跳过导致因果不明的必要动作 |
| 节奏 / 形式 | 形成重复、打断、碰撞或呼吸 | 每拍必切、无变化也强行快剪 |
| 空间重定向 | 建立新区域或关系 | 只因素材够多而反复给全景 |

不切同样是选择：让观众检查一段真实过程、观看无法躲避的反应或在同框中比较人物。不要把“多样”写成每几镜必须换景别。

## 返修顺序

明确观众在哪一刻误解或失去兴趣，再检查：缺信息、重复信息、表演变化被切掉、镜头无法衔接、声音抢注意、技术残帧。把缺陷绑定真实素材与时间，不用“全片不高级”作为可执行意见。

生成素材的返修先看剪辑能否解决：删减、换序、延长反应、声音先入或延续、裁切、现有覆盖；再考虑只补生成一个反应、过渡或关键状态；只有一个节拍的空间或表演整体错了才重做小节。好表演比小连续性难重现，优先保护。

若只凭导演原意读得懂，先补观众能看到的线索；若原意与素材矛盾，说明两者并提出素材成立的新方案。纪录剪辑需要重新发现材料的可能性，但不能因此虚构事实。[E2](sources.md#e2)

## 评审记录

“TC 00:12.2–00:13.1，手尚未碰杯便响起碰撞声，提前音效让观众误判接触；声音重对到实际接触点，画面不改。”优于“这里节奏差”。

没有真实播放条件时写“拟检验点：接触声同步”，不要填写貌似实测的 TC。
