# 完整案例：45 秒桌面产品片

虚构练习输入：三天内做一条 45 秒横版产品片和 15 秒竖版；现金上限人民币 12,000 元；一件真实瓶装产品，包装外观必须准确；两位创作者这三天各可投入每天 8 小时工作，无需演员露脸；不能进行付费 AI 试错。下列费用为练习估算，未询价、未预订、未制作。

`project_id: tabletop-demo`；`artifact_id: production-plan`；`revision: 1`；`based_on: brief-v1`；`owner: producer`；`status: ready`；`open_questions: 报价、实物及场地窗口、接收规格`；`changes: 首版制作方案`。

## 决策

采用同一桌面空间的实拍产品与手部动作，用两个灯光状态形成变化。保留“打开—使用—收回”的完整动作，取消原设想的水下与外景；这个形式变化须在开始制作前由导演接受。竖版从设计时保留手、瓶和动作接触点，不能等横版完成后盲裁。

未选方案：三地点加水下段需要额外转场、道具防护和特殊工艺，当前三天 / 两人的容量无依据支持；不以未核查的“AI 很快”作为替代。

## 资源

场景 SET01，一张桌；产品 PROP01，两件同款实物作为展示 / 使用备用；一位创作者兼摄影和剪辑，另一位负责灯光 / 道具并在镜头中伸手。手部镜拍摄时不能同时要求第二人移动灯具，灯位预先固定。

声音：开合、触碰和衣袖同期素材；无配音，不默认购买音乐。包装小字以真实物品出现，不重新生成。关键工艺未知是反光控制与竖版动作空间。

## 三天排期与容量

| 时间 | 工作 | 依赖与产物 |
|---|---|---|
| D1 上午 | 核定文案、实物、桌面与两种画幅 | 文字定稿、资源可用；未到实物不定反光方案 |
| D1 下午 | 反光测试、手部预演、两种画幅草剪 | 同一瓶和动作；通过才锁灯位 / 构图 |
| D2 上午 | 干净展示镜、开盖前状态 | 先记录完整包装与道具状态 |
| D2 下午 | 开合 / 使用动作、备用与同期声、素材备份 | 不可逆消耗后不回拍干净状态，除非换备用 |
| D3 上午 | 45 秒粗剪与 15 秒竖版 | 完整动作可读；出当前版本给声音与修订 |
| D3 下午 | 汇总修订、声音、调色、双版导出和完整回看 | 最后留出导出失败修正窗口 |

关键路径：实物到位 → 反光 / 动作测试 → 拍摄 → 双版剪辑 → 整合与检查。D3 第一人按 3 小时双版粗剪、1 小时汇总修订、1 小时调色、1 小时整合声音、1 小时导出检查、1 小时返修余量排列，共 8 小时；第二人整理声音可与粗剪并行，但第一人的剪辑、调色和整合串行。此为练习工时假设，接收方须能在粗剪后给出一次汇总反馈；窗口不成立则重排，不能保证三天必过。

## 试验和变更

测试问题：瓶主标在预定两个角度是否可辨、手是否遮挡、竖版是否保留接触点。只改灯角 / 遮光位置，不在同一轮改瓶型和文案。若不可用，改为固定产品展示加独立手部近景，保住真实产品与因果动作；导演确认改变的视听形式。

若 D2 产品未到：禁止凭类似瓶替代后宣称准确；可继续桌面布置、排期与已授权素材整理，交付日期或范围必须重算。
