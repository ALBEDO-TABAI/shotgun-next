# 预算区间与降本选择

费用计划应反映创意需求、可核查证据、最低可行资源与应急安排。[P1](sources.md#p1) 本页不是实时价目表；示例数字均需被项目报价替换。

## 计算口径

按币种分别计算：`项目费用 = 数量 × 单位费用 + 固定费用`。记录费用来源与日期、含税 / 未税、单位（人日 / 项 / 张 / 秒等）、是否含准备、修订和交付。不要把人日费用再乘团队总人数，除非原报价明确是单人日价。

区间不是把所有项随便加减百分比。数量不确定与单价不确定分别写：例如“需 2–3 个布光配置，单配置准备 40–70 分钟”，先验证配置数或实测准备时长。

至少分清：

- 已发生：有当前实际依据；退款和冲销单列。
- 已承诺：已下单但未完成支付或交付，不可当作还能自由删减。
- 待发生：计划中的必要工作。
- 预留：针对具体不确定性的可动用空间，不是已经花费。
- 未知：尚无依据；以未知清单和影响范围呈现，不能填 0。

现金支出与总经济成本可以不同。借来的场地或自有人力若现金为 0，应写“已确认免付现金 / 自有投入”，仍记占用时间与条件。

## 比较方案时保持同一目标

| 方案变化 | 可能减少 | 可能增加 / 失去 | 先验证 |
|---|---|---|---|
| 合并地点 | 转场、租用、布置 | 视觉区分与空间可信度 | 是否可由区域 / 光线改变建立差异 |
| 缩减镜头数 | 机位与布光次数 | 信息清楚度、后期选择 | 必要动作与反应是否仍可读 |
| 替复杂运动为固定机位 | 设备、排练 | 临场感或主观性 | 演员调度是否能承担原来的功能 |
| 复用资产 | 设计 / 制作 | 适配、维护与一致性管理 | 后续是否真的重复使用 |
| 提前锁台词与文字 | 重录、字幕和剪辑返工 | 前期校对时间 | 信息是否已核实，客户是否提供最终文案 |
| 实拍精确物件 + 生成环境 | 实景投入 | 合成与接缝风险 | 代表镜头试合成是否成立 |

不要把“全降画质”当第一方案。优先删低价值变化、重复工序或错误接口，保留最重要的表演、产品真值、因果动作和声音可懂度。

## 硬预算检查

已发生 + 已承诺 + 待发生的较高估值 + 计划预留，不得在报告里被包装成预算内而实际上超上限。若超限，列出可撤销项、影响目标、最迟决策点。不能只给一个乐观平均值。

敏感性先看最能改变结论的一两项：增加一个拍摄日、多一轮复杂返工、另一种交付格式。没有概率数据不伪装成精确成功率；有数据时也说明样本和适用范围。
