# 从创作拆出资源

职业依据要求从创意需求识别费用、资源、时长及部门协作，而不是只按成片分钟估价。[P1](sources.md#p1)、[P2](sources.md#p2) 以下是 VVF 的轻量拆解法。

## 分清三个计数

故事里有几个场景、实际拍几个布景 / 机位、交付几份成片是不同数量。一个场景可需多次布光；一个布景可扮演多个地点；一条片的横竖版本可能需要重新构图和剪辑。

逐场或逐镜记：叙事任务、人物 / 群体、地点与日夜、关键道具和状态、动作、声音、特殊工艺、连续性、可复用项。只有会改变资源决策的特征才记，不复制整篇剧本。

| 特征 | 隐含资源 | 低成本替代与代价 |
|---|---|---|
| 多角色对话 | 排练、收音、覆盖、服装与视线连续 | 两人分时拍需严密匹配；可能牺牲即兴反应 |
| 多地点 / 昼夜 | 转场、运输、布置、控光、等待 | 同一地点分区使用；空间差异需要美术与镜头支持 |
| 湿润 / 破损 / 消耗 | 备份道具、复位、清洁、状态顺序 | 先拍干净状态；不可逆动作安排在对应资产最后使用 |
| 精确产品 / 小字 | 真值资产、控反光、局部补拍、后期 | 独立实拍产品层；需要匹配角度光影，不能假定容易合成 |
| 大运动 / 一镜到底 | 走位、设备空间、重复排练 | 分段或遮挡连接；须保留原意图并说明形式变化 |
| 多交付版本 | 重排信息、安全区域、字幕与声音版本 | 早期共同设计；硬裁切可能丢人物关系 |

## 制作媒介选择

- 真人实拍：表演互动、真实产品和连续物理动作是优势；场地、人员、天气和复位构成约束。
- 动画：允许形变与不可实拍世界；设计、绑定、动作资产、渲染和镜头变更会形成前期投入。复用价值取决于后续镜头真实使用，不等于所有资产都值得造全。
- AI 生成：适合可容忍细节变化的视觉探索和某些短段；精确身份、动作因果、文字、长时一致性必须验证。生成成功不等于可用，不能把随机重试当计划。
- 混合：把需要真实的部分与可生成部分按可见依赖拆开。提前试合成接缝，明确透视、光影、运动、遮挡、音画同步和授权素材的接口。

这不是工具排行榜；能力随工具变化，选定工具时核查当时可用限制。规划本身不要求立即调用服务。

## 输出示例

“SH04 需要一只手将瓶放到水面，瓶型与标签需准确。方案 A 实拍浅水盘，费用含防护与复位；方案 B 实拍手瓶层加水面背景，先试接触阴影与水纹；不选全生成，因为当前没有可靠身份和接触测试。”

下一岗收到的是明确任务、边界与需验证的接口，不只是“美术负责画面、后期负责合成”。
