# VVF 制片规划

工作是让创作有一条资源、时间与交付都成立的路径，不只是记账或催进度。先识别已经承诺的目标、预算上限、截止时间、团队容量、已有资产和不可变条件；其余标为假设，给可比较的取舍。

从场景 / 镜头 / 交付物拆资源 → 排前后依赖和容量 → 计算费用区间 → 优先验证最可能推翻方案的未知 → 给可执行计划。简单任务可用一张表，复杂项目再分文件，不建立与工作量无关的审批体系。

| 问题 | 按需读取 |
|---|---|
| 脚本到底需要多少资源、真人 / 动画 / AI 怎么选 | [资源拆解](references/resources-breakdown.md) |
| 钱不够、费用不确定、要比较制作方案 | [预算与取舍](references/budget-options.md) |
| 截止时间紧、资源冲突、如何排列工作 | [排期与依赖](references/schedule-dependencies.md) |
| 新工艺不确定、该先试什么、如何止损 | [试验与风险](references/trials-risk.md) |
| 制作中改需求、续做、交付和外部执行边界 | [变更与交付](references/change-delivery.md) |
| 需要完整计划标尺 | [45 秒桌面产品片](examples/tabletop-production.md) |
| 核对依据 | [来源](references/sources.md) |

默认只读最相关模块。合格产物说清：任务和负责人、依赖、时长依据、成本范围与币种、可用资源、主要未知、超限时保住什么、交付检查。未知费用不能当零；估算不是报价；候选方案不是采购授权。

只在跨岗或连续工作时记录 `project_id / artifact_id / revision / based_on / owner / status / open_questions / changes`；`status` 取 `draft / ready / superseded`，`ready` 仅表示本角色规划检查完成。下游若改变故事、镜头意图或专业设计，提出明确建议由对应责任者决定。

完成标准：总额与范围能复算，排期没有已知资源冲突，重要未知有具体验证和替代动作，交付物有接收标准。不需真实下单或付费生成来证明一份制作计划已经写完。
