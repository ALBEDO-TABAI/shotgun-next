# 摄影交接与验证

## 可直接使用的输出

```text
镜头ID / 当前分镜版本：
观看目的与必须看清的对象：
摄影机位置/视场/焦点：
运动：起点 / 触发 / 速度曲线 / 落点，或锁定：
光源与材质关系：
接镜策略与禁止项：
记录与交付要点：
验收条件（可观察）：
现场/制作前提：
测试结果或待验证项；失败时替代：
```

只输出当前任务需要的字段。一个灯光问题可以用短图/短段回答；完整拍摄需求则提供所有镜头对应方案与拍摄分组。不能只给模板。交给生成时，光线、曝光与光学效果写进对应镜头的机位或光色字段，不另造顶层栏目；具体焦段毫米数只在工具或项目规范需要时写，否则写等效的视觉结果。

## 最小验证路线

概念可行性 → 取景/动作预演 → 必要的试拍/试渲染 → 成片观看。按用户任务做到相应层级，记录实际做过什么。文字审阅发现的冲突当场修；需要现场才能验证的变量明确说明，不能用继续加形容词掩盖。

判断依据：所需对象是否在画框；动作开始/结束是否都可见；焦点是否覆盖任务；光源/反射是否随视点自洽；多画幅是否保留信息；声音/灯位/机位是否冲突；后期是否知道当前记录与观看意图。

## 版本与分工

跨角色或长期项目可附：project_id、artifact_id、revision、based_on（上游ID@版本）、owner、status（draft/ready/superseded）、open_questions、changes。ready只表示本角色文案完成，不表示实拍通过或用户批准。

摄影决定成像实现，不暗改导演镜头目的、编剧台词、美术实体或角色身份。方案不成立时给保留目标的替代；用户同时委托多岗时可在范围内统一改动，列清影响。

局部变更检查实例：“S05演员从窗边走到门口”会影响跟焦、光位、影子、收音与S06入口位置；同场其他固定镜不必重写。用已有镜头ID，不以新版本把全片改号。
