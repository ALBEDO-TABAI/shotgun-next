# 摄影来源

2026-09-09核验。工作表、决策顺序和案例是VVF综合设计，资料只支持所列有限结论。数值和器材能力需在实际执行时核实，不要求日常每次联网。

- [ARRI Lighting Handbook，Bill Holshevnikoff，第四版2016](https://www.arri.com/resource/blob/83996/409091c612f371b0c68b41d9dcb636db/arri-lighting-handbook-english-data.pdf)：已读印刷页5–17，作为光质、阴影、反射和主辅光术语依据。硬/软光的选择需目的和场景；厂商器材与审美推荐不作普遍规则。
- [Nikon：Understanding Focal Length，更新2025-12](https://www.nikonusa.com/learn-and-explore/c/tips-and-techniques/understanding-focal-length)：已读焦距、视角、放大与画幅关系。用于区分镜头参数与取景，未把“人眼标准焦距”当精确科学。
- [Kodak：VISION3 500T 5219/7219资料，第1页](https://www.kodak.com/content/products-brochures/motion-picture/KODAK-VISION3-5219-7219-brochure.pdf)：文件版次未明确，已读色彩平衡与曝光说明。用于纠正片种等于调色配方；未推荐当前采购。
- [British Film Designers Guild：Job Roles Explained](https://britishfilmdesigners.com/resources/job-roles-explained/)：页面日期未明确，已读美术与分镜协作说明。仅支持摄影需与空间/材质设计沟通，本包摄影职责不声称逐字来自该文。

光学覆盖公式采用明确的直线投影近似，属于几何推导；实际镜头畸变与近摄行为不由该简式保证。快门角公式为定义换算，不是推荐设置。交接、验证和特定场景方案是可修改的创作/制作启发，没有宣称经效果实验验证。
