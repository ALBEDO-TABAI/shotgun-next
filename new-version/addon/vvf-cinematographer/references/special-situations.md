# 不同任务的摄影解法

先看当前任务，其他项不用读。每行是需要改变选择的条件，不是通用拍法。

| 情境 | 先解决什么 | 可执行方案 | 优先试验 |
|---|---|---|---|
| 访谈/对话 | 谁看谁，听者反应与声音是否重要 | 视线离镜头的关系明确；坐姿和光位允许自然转头；同场底声一致 | 转头与眼镜反射、衣物麦摩擦、两人遮挡 |
| 狭小房间 | 实际机位、手部活动与收音空间 | 利用门口/角落、调整调度、减少无必要移动；可拆墙仅在真实有条件时提出 | 最宽和最近两个取景，不以面积判断合法景别 |
| 光泽产品 | 标签、外形、开合动作哪个优先 | 黑白反射面和背景塑形；展示字样的角度单独保证 | 反光是否遮字，手是否遮标，开合能否完成 |
| 透明/液体 | 边缘、折射、液面与背景分离 | 让背景/边界变化可控，明确液位起止 | 实物/试渲染，不能假设“加轮廓光”总解决 |
| 夜景/暗场 | 观众必须看到的因果 | 有选择显露人物/对象，让背景仍有可定位线索 | 目标屏幕上关键动作可见，暗部噪声/压缩 |
| 舞蹈/动作 | 完整身体路径与力量结果 | 全身/局部按动作任务交替；动线和出入镜余量先排 | 关键发力和接触点是否被裁切或模糊 |
| 群体/群众 | 同时行动的主次 | 以空间分组和时机变化组织，不要求所有人脸清楚 | 人数/队形、视线与背景动作是否抢主事件 |
| 风景/建筑 | 尺度、地形方向与到达关系 | 前景/主体/远景关系或有意平面化；移动机位有空间收益才用 | 雾霾、天气、建筑垂直与设备路线 |
| 手机/低资源 | 最少配置如何保住核心动作和声音 | 先好位置、稳定曝光/对焦、清楚收音，再考虑附件 | 实际手机型号下自动漂移、动态与夜景效果 |
| 虚拟/动画 | 观众是否能理解非真实空间 | 明确投影、比例、变形、镜头移动和光色规则 | layout/animatic，对比实际运动和静帧 |

## 风格化摄影的反例

“色彩很亮却表达不安”：以规律重复、无人响应、过长等待和不对称信息实现，摄影保持高调；不必改成暗绿。

“运动强却不炫技”：角色负重穿过拥挤空间，摄影跟随重量与阻挡变化；停止处应让观众读到结果。

“无景深的平面世界”：让位置、轮廓、颜色和时间承担层次，避免擅加虚化、体积光和透视。

这些选择的成效需看具体画面；表达名词本身没有质量保证。
