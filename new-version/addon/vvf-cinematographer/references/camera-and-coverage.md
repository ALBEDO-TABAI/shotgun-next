# 机位、动作与覆盖

摄影方案消费导演确定的观看任务。发现叙事冲突时指出原因并给建议，不另写剧情。

## 机位计划

把摄影机、人物、关键物件、灯、收音与移动通道放在同一空间里想。场地未知时给相对方案；场勘后再定位置。拍摄顺序按布光/设备/演员/场地组织，成片顺序另列，两者不要混号。

移动镜头写起点、终点、看向、跟随对象、速度变化触发、对焦任务、谁先进入/离开画面。例如“从桌端沿走廊跟到门口，人物停时摄影机再前进半步让门外出现”，比“史诗稳定器长镜头”可执行。

## 承托与速度曲线

先问静止是否更有力量。要动就写起点、触发、速度曲线、落点（结束构图），不只写“流畅运镜”。承托系统按结果选，不按档次选：

| 系统 | 适用结果 | 必须写清 |
|---|---|---|
| 锁定机位 | 克制、观察、几何秩序 | 主体如何在固定画框内调度 |
| 三脚架摇移 | 观察空间或跟随有限动作 | 方向、触发点、停止构图 |
| 轨道/滑轨 | 稳定推进、揭示、距离变化 | 路径、总距离、速度曲线、终点 |
| 稳定器 | 流动伴随、穿越空间 | 跟随对象、距离、转向与避障 |
| 肩扛/手持 | 身体在场、压迫、不确定 | 抖动幅度、频率、是否保持可读 |
| 运动控制 | 精确重复、合成、机械节奏 | 可复现路径、节点、同步事件 |
| 穿越机 | 高速穿越、强主观 | 飞行路线、转弯半径、贴近物与可读性 |
| 摇臂/升降/航拍 | 尺度揭示、地理变化 | 起止高度、弧线、揭示的信息 |

快慢速写正常速度、加减速触发、持续阶段和回到正常的时机；速度变化服务感知（冲击、延长决定、压缩路程、失衡），不做无动机的变速。帧率、快门角、运动模糊只在目标设备或工具需要时给数值，并同时写期望的清晰或拖影结果。生成工具可用的运镜与速度控制是当期能力，写方案时标待验证。

## 为什么需要覆盖

覆盖为关键叙事和剪接提供选择，不意味着每场都拍全景/中景/特写套餐。

| 风险 | 有价值的补充 | 不值得的堆叠 |
|---|---|---|
| 动作连接不稳 | 同一动作关键相位的进入/离开余量 | 无动作意义的随机物件近景 |
| 双人关系变化 | 同框或能重新定位的角度 | 每一句机械正反打 |
| 操作看不清 | 手与接触面的可读角度、结果状态 | 漂亮人脸但看不见操作 |
| 不可重复现场 | 提前确定关键机位、备用录制/声音 | 事后让当事人重演却称现场记录 |
| 运动容易遮挡 | 验证路径、调整调度或安全的替代视角 | 追加更复杂运动掩盖问题 |
| 后期需重组 | 拍够必要起止状态和空间声音 | 无限制拍素材而没有取舍 |

## 方向与切点

连续剪辑时记录人物画面左右、视线、行进方向及主要轴；人物移动会改变轴。换侧可由可见运动或清楚的新关系建立，不把180°当物理法则。摄影给剪辑可接的材料，导演/剪辑可选择故意跳切或方向失衡。

跟拍始终要有观看目标；“手持自然”不意味着随机抖动。固定摄影机允许人物穿越不同构图区域，长镜头也可以通过调度改变景别与信息。

## 多画幅

先确定主画幅和必需兼容画幅，逐个检查主体、接触动作、视线空间、字幕/图形位置和上下留白。一个横向双人构图裁成竖屏可能只剩一人；需要不同调度或另拍，不能保证后期总能修。

机位保护范围与最终画框分开；留裁切空间会影响现场看图和美术摆设。未知平台时用实际示意画框检查，不写一套全球通用按钮安全区。

## 现场试验

优先试最难一镜：最长动作路径、多人遮挡、复杂反射、焦点变化或关键文字。用最低成本预演确认问题在哪；成功后扩展同类镜头。测试记录写具体画面/器材与条件，不把手机预演等同最终摄影质量。
