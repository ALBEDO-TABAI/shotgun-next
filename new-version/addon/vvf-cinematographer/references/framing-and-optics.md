# 取景、透视与焦点

## 决定顺序

观看任务 → 主体/环境关系 → 可用机位距离与高度 → 画幅与视场 → 焦距/镜头类型 → 焦点范围。可以来回调整，但不能先固定“电影35mm”再逼场景迁就。

景别是主体在画面中的尺度。视角取决于焦距与有效成像尺寸。透视关系主要由观察位置决定；保持同机位改变焦距相当于改变取景范围，保持主体大小而换焦距往往需要移动机位，后者才改变前后相对比例。镜头畸变、呼吸、移轴等另行考虑，别与透视混称。[技术来源](sources.md)

## 有数据才计算

普通直线投影、远离近摄条件时，可用 `水平视角≈2×atan(有效宽度/(2×焦距))`、`目标距离处覆盖宽度≈距离×有效宽度/焦距` 做初估。宽度与焦距用同单位。实际裁切、对焦呼吸、畸变、最近对焦、近摄放大和有效画幅会使结果不同；仍要取景试验。

例：有效宽度24mm、焦距24mm、距离2m，初估覆盖约2m宽。这不证明两米房间一定能拍下两个人：机身、演员、布景、手臂动作、收音和安全通道都占空间。未知有效画幅时不输出毫米级结论。

## 焦距与位置的取舍

| 需求 | 可行路径 | 代价 |
|---|---|---|
| 人物与背景比例更接近 | 拉远机位，再以较窄视场维持主体尺度 | 工作距离增加、背景选择变窄 |
| 强调前后距离 | 靠近前景，用较广视场容纳环境 | 近距离身体比例可能夸张 |
| 狭小空间多人同框 | 调整人物深度/机位开口，选合适视场 | 边缘形变、收音和灯位需试 |
| 操作步骤清楚 | 控制机位到手和物件的距离，让焦点范围覆盖接触 | 不一定需要人脸清楚 |
| 保留观察距离 | 较远机位、适合视场、提前考虑收音 | 远拍画面不自动获得近距离声音 |
| 精密几何 | 检查水平/垂直与投影，必要时布景或后期纠正 | 不能靠“超广角”自动解决所有建筑问题 |

## 景深不是“越浅越高级”

先列必须同时清楚的物体以及运动范围。光圈、焦距、对焦距离、画幅/最终放大与清晰标准共同影响景深；不从镜头型号猜绝对范围。

多人可排在近似同一焦平面；主体与背景都重要时可加深景深、改变站位或分镜。拉焦写触发与落点，例如“听到门响，从手中的信转到门口来人”；避免每镜都拉焦。

微距描述放大与工作距离，不能把“微距”当固定焦段。极近摄需要关注薄景深、遮光、反射与物体运动；生成画面同样要描述可读结果。

## 交付字段

机位/高度（测量或相对）；目标视场；焦距与画幅口径（有可靠数据才填）；关键对象距机位的大致关系；焦点起止和必须清楚的范围；无法实现时的替代。省掉与结果无关的设备名。
