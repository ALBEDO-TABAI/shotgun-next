# 听觉视点与叙事

## 先选谁在听

观众可以贴近角色身体，也可以听到角色不知道的远处；听觉视点不必与镜头视点完全相同。将差异作为有意识的选择。

| 目标 | 选择 | 边界 |
|---|---|---|
| 建立真实活动空间 | 持续环境底、明确声源远近、动作接触 | “真实”不等于所有现场杂音同样响 |
| 提前揭示/悬念 | 画外脚步、门外争执、机械异常 | 提示多少信息要与导演一致 |
| 主观注意 | 在触发事件后压低无关声、突出呼吸/物件 | 不把主观处理误标为物理真实录音 |
| 记忆与联想 | 某声响作为前后场连接、重复但改变环境 | 需有可识别锚点，不能任意回声代表回忆 |
| 关系冲突 | 一人声音靠近，另一人被空间阻隔；说与听错开 | 不用音色自动定义好坏/阶层 |
| 形式/实验 | 音高、节拍、音色与形状/密度建立规则 | 没有拟真声源也可成立 |
| 喜剧/反讽 | 预期声缺席、延迟或与庄重画面错位 | 观众需知道预期，否则只是不同步错误 |

## 声音事件而非形容词堆

“紧张、史诗、沉浸”要改成声源与变化：“门外脚步在走廊停住，屋内工具声突然停下，留空调低声；门没开之前不出现音乐冲击。”每层有进入、延续、变化与退出。

声画同向可以清楚，反向可以复杂；没有统一的高级优先级。用声音补画面看不见的信息时，检查是否改变事实。例如画面只见一辆车，添加枪声会引入新事件，须有创作依据。

## 远近与空间

位置、声源动作、遮挡、距离、反射和听者方向共同影响听感。靠近录制后可在后期构造远近，但需保留足够干净素材和明确世界关系；“加混响”不能自动匹配任何房间。

多声源不必等响，注意谁在承担事实、谁在维持空间、谁是节拍。减去抢话的音乐或装饰效果，往往比继续加层更有用。

## 提交一个可听的选择

为关键转折写短声景：之前有什么；什么触发变化；此刻谁主导；变化后还剩什么。需要比较时提供两个真正不同的听觉视点，并说明对观众知道/感到什么的影响。声音早期参与的职业实践依据见[来源](sources.md)，不将厂商技术宣传当艺术必要条件。
