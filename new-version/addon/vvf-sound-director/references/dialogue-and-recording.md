# 人声、对白与录音

## 文本和表演

保留说话者、原文和可改范围。给可演目标，如试探、安抚、拖延，以及句子的对象和转折；“低沉男声/温柔女声”不足以构成人物。语言、口音、语域依角色与语境，不用它们暗示智力、道德或社会价值。

配音方案区分身份特征、当下行动和情绪变化。真实人物声音的克隆/模仿需要相应授权与可用工具，不因有录音链接就视为许可。普通虚构配音可直接描述音色和表演，不捏造演员同意。

## 对白时间

1. 以实际录音或朗读为优先证据。
2. 未录音时给估计区间，包含呼吸、停顿、动作和打断；字数只是粗估。
3. 重叠说话应说明哪句必须可懂、哪句可以部分被盖住。
4. 台词跨镜是一条声音事件，注明覆盖镜头和位置，不重复计算时长。

太长时先保护不可删内容，再提出延长、获准压缩或改声画组织。加快到失去人物语气不算解决。口型同步任务需以实际声音/画面校准，不凭文字宣称帧级同步。

## 现场条件

先听空间：背景机械、交通、人群、反射、风、衣物与道具。调整位置、录音时机与收音距离可比后期更有效。枪式麦不是声音长焦，不保证远距离对话像贴近录制；硬反射面也会影响其拾音。[Shure资料](sources.md)

| 条件 | 方案思路 | 检查 |
|---|---|---|
| 双人固定对话 | 麦克风位置跟随说话任务或分别记录 | 转头、距离变化、遮挡与相位/串音 |
| 走动 | 选择能跟随的收音与备用方案，保留动作自然 | 衣服摩擦、脚步、无线状态、出画与影子 |
| 纪录不可重来 | 先保住关键说话和同步参考 | 不假定后期可从严重噪声中恢复全部台词 |
| 旁白/配音 | 稳定口麦关系与环境，给实际画面/语境 | 爆破音、口水音、呼吸、房间染色 |
| 多语言版本 | 保存文字版本和实际时长 | 翻译不等于同长；专有名词与语气回核 |

不在没有设备/场地事实时发“万能距离、增益和降噪数值”。预留峰值空间并监听，具体设置按设备和测试。

## 给后期的素材

保留原始录音与清晰命名、场次/镜头/条次、同步信息、轨道对应说话者、实际录音参数、问题和备用句。采集可用环境底、关键动作和必要的单独台词，说明对应场景状态。未经录制不能勾选“已收集”。

降噪、修复和补录先解决可懂度，但保留表演与音色；过度处理后的金属感、抽吸和呼吸断裂应回听原始素材，必要时选更好条次或补录，不无限叠插件。
