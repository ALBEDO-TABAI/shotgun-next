# 声音世界、环境与效果

## 分层以便选择，不要求全部出现

持续空间底；可定位的远近事件；关键同步动作；身体/衣物细节；设计性声音。每层说明任务，用户只要干净说明片时不强加复杂声景。

| 声源/任务 | 应记录的变化 | 常见误区 |
|---|---|---|
| 房间/城市/自然 | 场景、时间、开门/移位前后 | 一个循环环境适配所有地点 |
| 手与物件 | 接触材料、力度、速度、摩擦/撞击/分离 | 每次触摸都配夸张点击 |
| 服装/身体 | 动作幅度、材质、负重、呼吸位置 | 以统一“皮革声”覆盖所有衣服 |
| 机械/车辆 | 启动、负荷、转速、异常、停止 | 画面停了声音仍按旧转速跑 |
| 动物/非人角色 | 行为意图、身体尺度、世界声学 | 凭外表编造真实物种行为事实 |
| 未来/魔法 | 声音产生/传播规则、角色如何感知 | 每种能力都用同一种科幻冲击 |
| 抽象动画 | 形态/节拍/密度与音色的对应 | 强迫给无实体图形补真实物理声源 |

## 风格与材料的对应

同一木盒可突出空腔、铰链、指腹摩擦或轻敲节拍。选择由画面尺度、动作与观看任务决定，不是材料名自动生成唯一声音。实录、拟音、合成或素材库都可以使用；来源与权利状态另记。

“小物体有巨大低频”可作为主观/喜剧/怪异选择；如果声称写实，则应验证尺度与环境是否可信。写清设计偏离，避免混音者把有意设计当录音错误。

## 连续性

环境底跟随故事空间，不跟随每一次切镜重启。门开后远声变清楚、角色进入室内后反射改变、机器断电后留转子停止声，都应与动作状态同步。

对跨时空声音桥区分“上一场继续”“下一场先入”“记忆/非叙事层”；声音表写它属于哪个世界及开始/结束触发。音响一致不等于必须持续铺满，突然消失也可成为信息。

## 素材采集/生成说明

用“动作＋材质＋力度/速度＋空间/距离＋长度/可循环范围＋干净程度”描述所需素材，附具体镜头ID。生成声音如果要同步，提供实际时间与参考动作；未有画面只能作计划时标。

不要写“已取得正版音效”而无来源记录。检索到素材与已下载、已获许可、已剪入、已回听是不同状态。
