# 服装、妆发、道具与穿用

用于服化深化、定妆和执行。职业来源见[来源](sources.md)。这里将服装/妆发合并为协调入口，实际制作仍按团队分工交接，不假称一人负责全部工种。

## 人为何这样穿

从场合、工作、气候、可获得资源、个人选择和维护习惯推导，而非“皮革=危险、丝绸=欲望”。相同布料可以是制服、礼物、借来的正式服或日常耐用品，意义不同。

角色可穿与自我不一致的衣服：为融入、伪装、纪念、遵守规定或没有选择。需要说明这种不一致服务什么故事，不自动判设计冲突。

## 穿用卡

| 层 | 需决定的内容 | 功能检查 |
|---|---|---|
| 基础衣装 | 层次、廓形、开合、尺寸关系 | 是否能完成坐/蹲/跑/抬手和脱穿 |
| 面料 | 厚薄、垂坠、伸展、光泽、透光 | 运动形态、风雨后改变、反射与声音 |
| 穿法 | 扣法、卷袖、领口、扎/不扎、携带方式 | 每镜是否保持；变化是否有事件 |
| 色彩 | 与自身肤发、其他角色、场景的关系 | 小尺寸识别；明度/轮廓是否足够 |
| 鞋与附件 | 接触面、步态、携物、快换 | 动作稳定、声音、实际/动画接地 |
| 妆发 | 分区、梳理、固定方式、湿度、前后状态 | 运动后是否维持或按剧情改变 |
| 化妆变化 | 泪痕/汗/灰/伤痕等已授权情节 | 位置、程度、变化时间；不凭外貌诊断疾病 |
| 功能道具 | 角色如何获得、携带、放置与操作 | 不与服装/手部动作互相占位 |

色彩和比例用描述性语言即可；必要时给色板作为沟通参考，实拍/材质条件需试样。不强制60/30/10，也不禁止简单色名。说“深蓝哑光短外套，袖口浅色修补”比堆五种诗性色名更可执行。

## 设计路线不是人格分类

| 路线 | 可见结构 | 适用 | 需要避免 |
|---|---|---|---|
| 功能维护 | 动作余量、可达口袋、反复修补 | 劳动/工作/日常 | 所有人都脏旧、工具满身 |
| 制服中的个体 | 保留制度轮廓，穿法/维护/附属物区别 | 群像、机构、学校 | 为区分角色擅改真实制服身份 |
| 社交呈现 | 特定场合的完整外观与不习惯动作 | 聚会、面试、伪装 | 精致外观等于虚伪 |
| 私人叠层 | 新旧衣物混用、来自不同关系的物件 | 记忆、家庭、成长 | 每件都写象征传记 |
| 图形角色 | 简化色块、明确轮廓、可重复画 | 二维/广告/吉祥物 | 删除使角色有文化身份的关键结构 |
| 材料角色 | 纸、布、木、金属等直接形成身体/衣装 | 定格、非人角色 | 强加真人毛孔和真实皮肤 |
| 历史/幻想 | 依据或明确虚构的结构、穿用与装饰逻辑 | 历史/架空 | 混年代还称精准复原 |

## 做旧、妆发与变化

每处痕迹写来源：袖口长期摩擦、膝部跪地、雨水沿肩线进入、手掌沾污后转移到衣襟。干净与有生活感可以并存。年代剧不代表所有服装都旧。

变化线要来自事件：角色挽袖开始工作、进门脱雨衣、冲突中扣子脱落、结束时重新整理。不要用“堕落变黑、成长变白”替代人物。一次换装不一定是心理弧线；它可能只是第二天上班。

## 实拍、替身与备份

计划衣装时记录能否购买/租借/改装/制作，及数量为何需要：湿版、破损版、替身动作、连续重拍、快换。未经现场安排不编固定数量和预算。涉及动作、安全装备或接触皮肤的材料，给专业人员验证需求；概念图不能取代试穿/试妆/动作检查。

日常服装测试也要看：坐下袖口是否改变、背包是否遮标志、衣料摩擦是否影响收音、背景是否吞衣服轮廓。发现问题可调整穿法、材质、道具位置或画面关系，不总靠换颜色。

## 交付组合

- 只要造型：角色服化卡+一个必要变化；无需采购表。
- 多镜制作：服装身份卡+按剧情时间的状态表+关键动作测试要求。
- 真实执行：在前两者上补获取方式、尺寸依据、试穿/备份与部门交接；预算与安排仍需实际团队确认。

连续变更规则见[连续性与交接](continuity-and-handoff.md)，历史研究见[文化与证据](culture-and-evidence.md)。
