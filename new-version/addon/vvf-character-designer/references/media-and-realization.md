# 媒介、设定图与制作

用于把角色卡转成实拍/动画/AI可继续使用的材料。依据及图像观察见[来源](sources.md)。本页不承诺特定模型能力。

## 按动作与观看需要准备参考

| 媒介 | 有用的交付 | 核验重点 | 不必默认做 |
|---|---|---|---|
| 真人拍摄 | 服化方向、试穿/试妆条件、穿用状态、动作需求 | 演员实际动作、材料、发型/妆容连续性 | 为演员虚构精确骨骼比例 |
| 手绘二维 | 主要角度、比例关系、色块、表情/姿态、简化规则 | 不同角度体量、遮挡、重复绘制稳定 | 一张高精度画好所有毛孔 |
| 绑定二维 | 分件结构、关节/遮挡、可转角度、替换手/口型 | 极端姿态是否露缝或穿插 | 无限制旋转、任意透视 |
| 三维角色 | 多角度结构、材质区、变形要求、衣物/毛发与接触 | 体量、关节、抓握、穿透、轮廓保持 | 写实纹理等于角色可信 |
| 定格/偶 | 尺度、关节、可换表情/手、衣料与固定点 | 可操作性、连续复位、灯下材料稳定 | 精美静态偶就能完整表演 |
| AI图像/视频 | 清楚角色母版、已需视角、镜头状态、参考用途 | 真正生成结果是否同一人/同衣装/同道具 | 文字Identity Lock就是保证 |
| 图形/抽象 | 稳定形态信号、可变形部位、材质/运动规则 | 变形仍可辨身份、关系可读 | 强制人脸/真人皮肤 |
| 混合 | 哪些由真人/二维/三维/AI完成、重合/交互界面 | 接触、比例、视线、遮挡和光色 | “后期统一”替代接口约定 |

## 设定图需求书

只生成当前任务需要的视图，例：正面/侧面/背面/四分之三侧视中必要角度；保留头顶、肩、腰、足底等比例参照；另给必须执行的动作和当前衣装。各视图应是同一版角色，别把四个变体拼成“旋转图”。

需要制作时加：哪处会变形、哪处有硬结构、衣物开合、道具接触、看不见但动作要用的部位。给模型的人审标签可分开：注释版用于决策，干净版用于避免编号文字混入生成参考。是否需要分版由实际工具与任务决定。

一张设定图不是整套角色：未给背面就不声称背面锁定，未画动作就不声称能完成动作。图像未实际生成时交付“设定图说明”而非假图片链接。

## 提示词按功能组织

保持用户语言；仅在指定工具或已验证需要时翻译。生成目标是角色参考、单帧插图或带动作视频，不能混成一段：

- **参考图**：同一角色的稳定形态、衣装、视图、背景分离与不可改变项。
- **关键帧**：引用稳定身份，加当前场景/姿态/道具/服化状态与可见范围；写主体占画面多大、落在哪（九宫格）、被什么遮挡。图已负责外貌与构图时，文字不再复述，只写差异。
- **视频**：引用稳定身份，加动作开始→过程→结束、接触对象和当前状态变化。

描述优先顺序：`身份识别 → 本次任务/视图 → 关键衣装与材料 → 当前动作/表情 → 状态 → 具体需防偏差`。不复制全包红线；只在发生过或预计会破坏本次任务的偏差上加约束。

## 一致性失败如何处理

| 现象 | 先查 | 针对性处理 |
|---|---|---|
| 同人换脸 | 输入是否同版参考、角色是否被复杂风格描述覆盖 | 明确身份母版与必要脸部视图，减少争抢身份的描述 |
| 衣服换款 | 穿用结构是否写清、参考是否遮住关键部件 | 补开合/领口/下摆视图，锁定服装身份而非只锁颜色 |
| 动作后道具失踪 | 起止状态、携带位置、双手是否同时被占用 | 明确转移步骤或简化并行动作 |
| 多人融成一个 | 角色命名、参考分配、相互遮挡与相似外形 | 明确各自空间和动作，可拆生成/合成；不承诺一定修复 |
| 表情夸张/僵硬 | 是否叠了多个情绪词、是否要“每秒变化” | 改写可见动作过程，用静止与节奏承载 |
| 2D/3D转译失形 | 轮廓体量是否仅靠单角度成立 | 补必要视图和可变形范围，不只提高贴图精度 |
| 越改越脏、塑料感、碎噪 | 低质图多代传递、每张参考职责混杂 | 回到原图或线稿重生再合成局部；每张参考只承担一件事（身份、空间、构图或风格） |

实际失败归因要基于结果；未尝试的建议叫“下一步测试”，不能说已解决。

## 成果状态

文本角色卡完成→参考图生成→必要角度核验→动作/衣装测试→实际镜头复核，是不同证据。只做当前授权范围；完成文本设计时不自动调用付费生成或采购。
