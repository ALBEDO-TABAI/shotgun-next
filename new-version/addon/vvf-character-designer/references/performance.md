# 身体行动与表演

用于角色动作基调、表情/姿态参考和视频状态。不是读心、测谎或医学诊断。研究依据见[来源](sources.md)中的Barrett等综述；本文动作选择是创作，不是心理测量。

## 先写行动关系

问角色想对谁做什么：拖延回答、争取信任、确认对方是否留下、掩饰失误、完成任务、拒绝接近。再决定外在动作，不从“悲伤”直接生成哭脸。

可用短结构：`触发 → 注意转移 → 尝试行动 → 对方/环境反馈 → 下一状态`。一个镜头未必包含全部阶段；需要哪一段就写哪一段。

例：“听见熟悉称呼 → 手停在扣子上 → 继续扣却错过扣眼 → 发现对方仍在等 → 重新对上扣眼。”这是可演选择；不能宣称扣错扣子代表真实人一定悲伤。

## 身体动作语言

| 控制轴 | 可写描述 | 适配问题 | 常见误用 |
|---|---|---|---|
| 重量与用力 | 搬起前先压稳脚、轻触后撤 | 物体重量、角色体力、行动难度 | 用“强壮”替代实际承重 |
| 时间 | 立即反应、迟半拍、动作中停住 | 角色是否犹豫/预期已知 | 紧张必快、悲伤必慢 |
| 路径 | 直达目标、绕开接触、边做边看 | 人物对空间与人的关系 | 所有反派直线、好人曲线 |
| 连续与控制 | 一口气完成、分段重新确认 | 熟练程度、任务风险 | 所有动作都流畅或都颤抖 |
| 支撑与重心 | 双脚均重、坐前沿、靠台借力 | 站姿、疲劳、接触关系 | 把姿态当固定性格证据 |
| 幅度与可见性 | 小动作只供近景读，大动作供远景读 | 最终画面能否看见 | 远景安排一帧嘴角变化 |
| 视线 | 先看工具再看人，保持眼神但手移开 | 注意对象、信息/权力关系 | 回避视线等于撒谎 |

可借拉班的重量/时间/空间/流动维度组织动作，不必强制每人只用一种Effort。角色有习惯，也会因目标、关系、疲劳和环境改变。

## 同一情绪的不同可见路径

| 戏剧情境 | 路线A | 路线B | 选择依据 |
|---|---|---|---|
| 努力控制愤怒 | 把手边物件摆得更整齐 | 暂时不动作，听完才回复 | 原故事是用秩序控制还是拒绝参与 |
| 得到好消息 | 立刻转向伙伴分享 | 继续工作，过一会才放松肩部 | 关系与场合允许多大表达 |
| 想留下对方 | 伸手后撤回 | 找一项还没完成的共同小事 | 直接请求还是掩饰需求 |
| 害怕被发现 | 持续做日常动作但节奏错位 | 完全停住，观察环境 | 可见风险与人物训练/经验 |
| 痛失重要东西 | 快速收拾表面秩序 | 长时间处理一个无关小物 | 片段具体目标，不按情绪标签套动作 |

别把每行都塞进一镜；先锁定当前戏的行动。表演不必每秒变化，静止也可以是明确选择。

## 面部动作、FACS与微表情

优先用可观察语言：内侧眉抬起、嘴角收紧、下颌放松、眼睑收窄、短暂闭眼。需要专业编码时核对对应动作单元，别编AU编号；一般创作不必使用FACS。

AU组合描述肌肉动作，不直接证明内心情绪、真假笑或道德品质。一个笑可以来自愉悦、礼貌、紧张或关系调节；意义来自故事和前后关系。不能把“嘴笑眼不笑”当真实人作假的诊断。

微小快速动作只在拍摄/生成媒介、景别与播放尺度能承载时设计。没有可控帧率/表演条件时不要要求精确0.04秒或“一帧揭露谎言”；改为能辨认的反应过程。真要极短动作，则记录预计可见窗口并以实际片段检查。

## 姿态/表情库的任务版本

不要所有角色固定交开心、愤怒、悲伤等七宫格。根据本片实际镜头选择：工作常态、与特定人交流、受阻、反应、恢复。每格包含姿态/视线/手部/可见变化以及衣装状态。

对3D/二维制作可以另列必要的极端姿态、抓握、蹲坐、口型、遮挡测试；先解决本片动作，避免做完整表情库却不能拿起道具。

## 交付与核验

动作卡：`角色/镜号 → 行动目的（创作解释） → 可见动作 → 起止状态 → 对象/接触 → 节拍 → 不宜的夸张 → 验证方式`。

文本检查：动作有物理/作品规则支撑、没有互相冲突的同时动作、眼神落点明确、衣物/道具状态连贯。真人排练、动画预览和AI成片测试分别给真实结果；不把文字上的“自然”当验证。
