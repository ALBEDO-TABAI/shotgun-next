# VVF 角色与服化设计

把角色的故事处境转成能被看见、表演和制作的身份。区分“这个人是谁”“当前怎样行动”“衣物/妆发发生什么变化”；三者有关联，但不必表里一致。本包独立使用，不依赖其他技能。

## 开始

判断用户需要概念探索、既有角色深化、服化设计、参考图说明还是连续性改稿。提取故事事实、角色范围、媒介、时代地域与已指定外观；不确定部分标为设计假设。只有影响关键故事事实、真实文化归属或已指定人物身份的矛盾才先问。单个人物点子可以开始设计，无需先有完整分镜。

| 角色辨识、身体形态、跨角色差异 | [身份与形态](references/identity-and-form.md) |

| 服装、妆发、材料、道具、变化线 | [服化与穿用](references/costume-and-grooming.md) |

按需打开，通常先一份；不把全部资源和样例重复放入每次对话。

## 工作方法

1. 提取角色本次要做什么、面对谁及与当前设计有关的处境。隐瞒或伪装只有故事需要时才分析，不给普通服化任务强加秘密动机。区分原文事实与本次设计。
2. 选择能改变读法的少数变量：轮廓、穿用方式、动作习惯、材质、维护痕迹或社会场合。探索时给有实质差异的方案及取舍；用户已有方向时直接深化。
3. 根据媒介落实为角色卡、服装状态、动作示例或参考图制作说明。稳定身份写一次；每镜只记录变化和关键保留项。
4. 检验角色在当前必要角度、动作、角色组合与尺寸下仍可辨，衣装能完成动作，前后状态有原因。没有真实图像或试穿时只能报告文本层检查。
5. 改稿保留角色/资产ID，找到受影响镜头与参考版本再修；不要因换一件外套重建整套人物。

## 底线

- 外貌、体型、肤色、年龄、残障、眼距或鼻型不能证明善恶、智力、阶层或人格。可用虚构造型符号，但说明是作品选择，并检验是否被刻板印象替代了人物设计。
- 表情是可见动作；情绪意义依赖情境。微表情、回避视线或笑纹不能作为真实人物测谎、诊断与“真心”的证据。
- 服装可以伪装、反抗、习惯性穿用，也可以与内心矛盾；不强制外貌/欲望/行动一一对应。
- 不强制头身比例、60/30/10色比、全角色三角形/圆形分类、双语或每人必有标志道具。只保留当前用途需要的信息。
- “身份已描述”不等于生成结果一致；参考图、动画姿态、试穿、真实成片分别核验。
- 已授权设计范围内自主完成；外部生成、采购、演员安排不由文案任务自动授权。

交付前确认：原故事与指定外观未漂移；方案差异有作用；可见动作与衣装兼容；必需连续状态覆盖；事实与假设分明。本角色`ready`只指文案检查完成，不表示用户批准或素材已生成。
