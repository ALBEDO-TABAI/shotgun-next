# 完整案例：《先别关灯》

输入：写一个约 60 秒的双人短片；一间公共阅览室；不靠煽情身世反转；结尾要有一点温柔。以下为原创虚构示例，尚未实际试读或拍摄。

选择：两个人最初对“按时结束”的理解不同，最终共同保留一小块未结束的时间。以行动表达，不补旁白。夜班管理员想准时闭馆，读者想抄完书上的一句话；二者都不是坏人。

## SC01 内景 阅览室 夜

墙钟指向闭馆前一分钟。管理员林把桌上的椅子逐一推回，只剩最里面一桌亮着台灯。

读者夏伏在摊开的书前，用铅笔写字。笔尖突然断了。

林站在桌边，拿着总开关的钥匙。

林：闭馆了。

夏把断尖捏在指间，没有抬头。

夏：就差一行。

林看她本子。最后一行空着，前面的字密密麻麻。他看向墙钟，又看向门口。

林：明天还在。

夏：我明天不在。

林没有追问。他从前台拿来一支笔，放在空行旁。

林：写完放这儿。

夏握笔，迟疑一下。

夏：灯呢？

林走到总开关前。顶灯一排排熄灭，只剩她桌上的台灯。

林把那把钥匙放回口袋，坐到门边，重新翻开自己没看完的报纸。

夏开始写。安静里，笔尖刮过纸面。

结束。

## 估时与交接

| 段落 | 估时 | 必要变化 |
|---|---:|---|
| 收椅、断笔、来到桌边 | 0–12 秒 | 两人的任务发生碰撞 |
| “闭馆了”至“我明天不在” | 12–29 秒 | 读者的期限被看见，但原因保留 |
| 取笔、递笔 | 29–41 秒 | 管理员改变策略 |
| “灯呢”至关顶灯 | 41–50 秒 | 形成暂时疑问并给出行动回答 |
| 坐下、写字 | 50–60 秒 | 等待从对立变成共同处境 |

台词短不代表 60 秒已被验证；实际排练须留给取笔、沉默和反应，过长先压收椅与来回走动，不压最后两人的共处。

导演必须保留：断笔导致停顿；管理员看见空行；递笔在关灯前；台灯有独立供电的可信条件。机位与景别开放。夏为何明天不来有意不解释，不能私自添加死亡、疾病或灾难。

制片待确认：可控制的顶灯与独立台灯、桌到前台距离、环境噪声。声音只需实际动作与房间底声，可不配乐。

## 局部修订示例

用户说：“不要‘我明天不在’，太像身世悬念。”

改为夏把借阅小票转向林：上面写着“今日归还”。夏说：“这本明天要还。”其他动机仍成立。SC01 的该处台词与道具变，角色身份不变，结尾不变；通知美术增加小票，导演决定是否需要让字可读，声音重估该句读时。`revision: 2`，`changes: SC01 中段台词与小票道具`。
