# 修订与导演交接

编剧通常需要根据反馈多次改写，重写是职业工作的一部分；反复润色不等于质量自动提高。[S4](sources.md#s4)

## 先把反馈翻译成可验证目标

“更有情绪”可能是人物代价不清、观众不知道其期待、反应时间不足或只是对白音色。先找当前文本证据。若反馈同时有不同含义，说明采用哪种解释；关键方向不明才问。

| 问题层 | 优先检查 | 最小修法 |
|---|---|---|
| 命题 / 视点 | 谁的故事、观众最终理解什么 | 改核心选择或信息位置，不先堆金句 |
| 因果 / 动机 | 行动有无来源、代价是否可信 | 补或改触发事件，删除冲突动机 |
| 场景 | 入场与离场是否有变化 | 改策略、信息或关系作用 |
| 台词 | 是否说给具体对象、是否重复画面 | 缩句、换行动、保留必要直接表达 |
| 时长 / 可执行性 | 实际读时、动作、资源 | 删除支线或换表达方案，不一律加速 |
| 事实 / 使用边界 | 材料出处和实际许可 | 改相应表述、标注或改用可用素材 |

## 连续编辑

保留稳定场景和人物编号。局部新增可用 SC03A，不因插一场重编号全篇。每次记录本轮改变、保留的约束和受影响下游，例如 SC03 台词缩短影响 SH08–SH10 与声音计时；不自动重做无关角色外观。

旧版本保留为旧版本；当前交付不要混有已删除台词。只有用户要求比较时附前后差异，默认给可直接使用的完整修订片段和明确接续位置。

## 按接收者交付

- 导演：分场正文、人物此刻的目标与转折、必须保留的因果、关键声音或画外信息；摄影方案可作建议，不能以技术词掩盖空剧情。
- 制片：出场人物、地点 / 日夜、关键动作、道具与不确定资源；不承诺未询价预算。
- 角色 / 美术：故事功能、社会处境、状态变化、必须可见的叙事特征；外观开放项明确保留。
- 剪辑：必要信息顺序、可删 / 可移与不可改变事实、已有材料出处。

跨角色头部采用 VVF 局部约定：`project_id, artifact_id, revision, based_on, owner, status, open_questions, changes`。正文仍可自然语言。`ready` 只表示文案自检完成，不表示拍摄、授权或用户批准。

## 交付前读一遍

人物名和指代一致；动作顺序可表演；台词不需要观众读作者注释；时间 / 地点变化可理解；未定项有具体影响；时长区分估算与实测；没有把创作偏好写成硬规则。找不到新增修改能改善这些目标时停止，不为“再高级一点”无限扩写。
