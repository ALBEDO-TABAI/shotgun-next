# 改编、纪实与证据

本页提供创作工作边界，不给法律结论。若任务要求判断具体使用权，需读取授权范围和相应现行依据；不知道不能写成已获得授权。

## 三张小表解决三类问题

只在材料复杂时使用，简单改编用几句文字即可。

| 层 | 记录什么 | 典型问题 |
|---|---|---|
| 来源事实 | 原作片段 / 采访时间码 / 文件版本、可确认事件、原话 | 原文到底说了什么？ |
| 改编选择 | 保留、合并、移时、改视点、外化、虚构补写及原因 | 为什么改变？改了会影响谁的动机？ |
| 使用条件 | 用户说明的权利范围、署名、保留项、公开与否、待确认事项 | 目前可交付何种用途的文本？ |

引用不是授权；公开可读也不自动允许复制。用户拥有或允许处理的材料可直接开展范围内改编，不因为“是改编”反复要求确认。只有用途或授权缺失实际阻断目标时再指出具体需要。

## 把小说变成视听事件

- 内心判断 → 选择、行为痕迹、注意对象、回避或有意旁白；不要强迫每段心理都表演成夸张表情。
- 长背景 → 现在时行动的障碍或可见后果；确有叙事价值的回忆可保留。
- 多人物 → 只有功能与关系可以合并时才合并；同时标明被改变的事件责任，纪实尤其不能随意合成人物。
- 时间压缩 → 保留因果与必要间隔的提示；不能让本需数月的过程看成同日发生而仍声称纪实。
- 视点变化 → 检查新视点能知道什么，观众会失去什么，是否破坏原作核心张力。

## 参考借鉴与复刻

先描述参考真正可见的事件与形式，再提炼有条件的机制，再写新作品选择。机制如“观众先听见结果，再看到起因”可迁移；具体肖像、独特角色、整段对白、音乐与完整画面序列不因叫“机制”就变得可任意复制。

对比表应包含：保留的功能、改变的表达载体、目标作品的新动机、仍需确认的使用条件。不要只替换产品名或人物名便称原创。

## 纪实检查

事实、转述、观点、重演与推测分别标识。避免把不同时间的提问和回答拼成新主张、用别处反应镜暗示现场反应、把相关性剪成因果。允许复杂、多义和没有结论；不要为满足“三幕式”制造阻碍。

来源缺口不等于全片停工：可继续写场景安排、采访问题、已核实段落。将缺口绑定到具体句子和使用影响，而非笼统“待核实全部”。
