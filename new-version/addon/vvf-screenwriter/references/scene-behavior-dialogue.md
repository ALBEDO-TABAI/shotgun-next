# 可表演的场景、行为与对白

人物复杂性不是填满性格标签，而是让具体行为同时受欲望、处境和关系影响。来源支持重视行为观察；以下动作表与检查是本包设计。[S2](sources.md#s2)

## 场景发动机

确认当前视点人物、对手或环境压力、入场目标、可用策略、信息不对称与离场变化。允许一人独处：压力可来自物件、时间、制度、身体或记忆，但必须有可感知载体。

行动动词比抽象情绪更能指导表演：试探、拖延、遮掩、邀请、转移、讨价还价、设界限、安抚、拒绝。它们不是表演指令全集；选择与当前对象发生作用的一项，后续策略可变。

| 抽象写法 | 可表演改写 | 不应附加的推断 |
|---|---|---|
| 她很生气 | 她把已经递出的钥匙收回，放进自己口袋 | 不能因此认定她“天性控制欲强” |
| 他后悔了 | 门快合上时，他伸手挡住；准备好的道歉没有说出口 | 不必马上用旁白解释原因 |
| 两人很亲密 | 她没回头便把杯子递向身后，对方正好接住 | 熟练动作也可能来自工作习惯 |
| 他有权力 | 对话暂停，其他人等他翻完那页纸 | 不必依靠豪车或西装符号 |

## 台词作为行动

每句关键台词问：说给谁、想让对方怎样、为什么此刻说、为什么不用别的说法。保留角色间的知识差、称呼变化、绕行和修正。潜台词不是人人故弄玄虚；事实询问、教学、无障碍说明可以直接。

诊断一段对白：

1. 若人物把双方都知道的背景讲给彼此听，换成行动痕迹、第三方冲突或确实需要的信息交流。
2. 若每人都能说出作者的漂亮金句，按职业经验、关系、词汇范围、逃避方式做差异；不要用口音嘲讽社会群体。
3. 若台词和动作重复表达同一信息，保留最有效载体；若重复具有否认、讽刺或反差功能则保留。
4. 若场景没有变化，先换策略或代价，再润色句子。

喜剧看预期、错位和反应的时机；恐惧看不知道什么与能否行动；亲密看是否允许对方进入自己的空间。它们是检查方向，不是情绪按键。

## 可拍文本与计时

动作栏写可以看见或听见的事实；必要的心理说明可放角色说明或场景目的，不把整段内心独白藏在动作栏。传统剧本的场景标题、人物名和动作 / 台词区分可参考 BBC 格式，用户已有格式优先。[S1](sources.md#s1)

不要把“一页约一分钟”或固定字速当精确时长。初稿标估时；对白读时、沉默、动作完成、反应与转场都占时间。没有实际试读时写“待试读”，不虚构读秒证据。

非人角色和动画也需要行动限制：它能感知什么、怎样移动、为何选择。造型夸张不等于情绪只能夸张。即兴开发可以先设计情境、关系和边界，再由排练形成文本；不要冒充已经发生的排练结果。[S3](sources.md#s3)
