# 从命题到故事结构

本页是 VVF 的可反驳工作法，不是叙事公式。先从具体人物、处境或行动矛盾建立故事，再决定需要多少结构工具。[S2](sources.md#s2)

## 让一个想法可持续

用一句话区分：人物想得到什么；什么力量阻止；他采取什么行动；行动怎样改变局面；观众最终重新理解什么。并非所有作品都要人物成长，拒绝改变、循环、观察与悬置也可以成立。

“一个孤独的人学会爱”还不能执行；“夜班保安想按时关灯，却发现最后一位读者每晚都把同一本书翻回第一页”提供了可观察行动、疑问和限制。不要立刻给读者加悲惨身世，先看什么选择最能承载命题。

## 按任务选结构，不按时长套比例

| 结构路径 | 最适合 | 关键设计 | 失效征兆 |
|---|---|---|---|
| 目标—阻碍—选择—后果 | 行动清楚的剧情 | 每次尝试改变代价或关系 | 只是不断增加障碍，人物不做选择 |
| 欲望与责任冲突 | 人物戏、伦理困境 | 两边都有真实损失 | 反方被写成明显错误，选择无重量 |
| 问题—线索—重释 | 悬疑、调查、解释 | 观众知道什么、何时改变理解 | 靠最后突然出现的事实解谜 |
| 平行 / 交叉 | 群像、对照、同时事件 | 每次切换增加比较或时间压力 | 两条线互不改变理解，只轮流出现 |
| 情境累积 / 观察 | 日常、纪录、抒情 | 细小差异逐步改变体验 | 只有相似漂亮片段，没有新的观察 |
| 循环 / 回声 | 超短、实验、荒诞 | 结尾返回同一形式但意义改变 | 只为无缝播放倒带，破坏事件逻辑 |
| 非线性 / 记忆 | 主观叙事、创伤、谜题 | 事件顺序与呈现顺序分开维护 | 作者知道年代，观众没有可辨线索 |

只有结构比较真能影响决策时才给两个候选；不要机械给三套方案。

## 长短与系列的差异

- 超短内容选一个能在现有时长被感知的变化，删背景解释而保留必要因果；反转不是必选。
- 叙事短片可围绕一次有后果的行动或视角变化，支线要有明确贡献；观察、散文、实验短片也可围绕持续状态、感知或形式关系组织，不强加不可逆事件。
- 长篇先建立序列目标及局部结果，再写场景。每条支线写清它何时改变主线压力、信息或情感，不靠平均分配戏份。
- 系列区分本集问题与跨集动力。每集要提供有价值的阶段结果；不以截断一句话冒充悬念。人物和世界状态保留至下一集。

## 检查因果与信息

把每场压成“入场状态 → 行动 → 出场变化”。场景可以改变关系、知识、计划、资源或情绪温度；不是每场都必须吵架或反转。

另查三种缺口：人物知道了他不可能知道的信息；关键结果没有行动来源；观众必须理解的事实只存在于作者注释。真正悬置的问题可以保留，但应区分“有意不回答”与“漏写”。

交付可含一句故事主张、必要人物关系、分场文本与未定项。不要把结构分析本身当剧本交付。
