# 内容模式与成功条件

这些是可组合的功能路径，不是互斥类型或平台算法承诺。形式应帮助目标观众完成本次理解与体验。

| 模式 | 写作核心 | 常见结构选择 | 需要守住 |
|---|---|---|---|
| 剧情 / 关系 | 欲望、选择、代价、关系变化 | 行动因果、平行、非线性 | 不把人物当观点传声筒 |
| 商业 / 品牌 | 具体使用处境与可相信的价值 | 问题—使用—结果、感官体验、身份认同、轻喜剧 | 画面支持的承诺与需要证据的产品说法分开 |
| 产品演示 | 观众理解怎样用、哪里有差别 | 输入—操作—反馈—限制 | 步骤、条件、结果不能跳过关键因果 |
| 教学 / 科普 | 纠正误解或形成可操作理解 | 现象—解释—演示—迁移 | 把比喻与事实边界说明白；专业断言有证据 |
| 纪实 / 采访 | 材料中的问题、人物处境与复杂性 | 观察累积、证据推进、人物行动 | 不伪造引语、重演或同期关系 |
| 社会倡议 | 看见处境及行动可能 | 多视点、具体日常、行动后果 | 避免把真实人物简化成苦难工具 |
| 喜剧 / 荒诞 | 预期、规则、误解与反应 | 升级、回声、错误策略 | 笑点由处境和选择成立，不只靠身份羞辱 |
| 悬疑 / 惊悚 | 信息分配与行动压力 | 限知、线索、延迟、重释 | 伏笔可复查，不能拿漏写冒充神秘 |
| 动画 / 幻想 | 世界规则与行动可能 | 变形、尺度差、物体关系 | 规则变化要有叙事原因或明确实验约定 |
| 诗性 / 实验 | 感知、意象、节奏或概念关系 | 并置、循环、递变、间断 | 不强塞戏剧冲突；仍能解释选择为何服务作品 |

## 商业短内容的条件分流

需要快速建立相关性时，开头可以直接进入任务、矛盾、异常、结果证据或具体体验；并非必须在两秒内反转。观众是否愿意看下去由内容与观看情境共同决定，不能保证转化或播放量。

把每个卖点译为“谁在什么情况下能看出什么差异”。无法在画面证明的性能、医疗或比较说法列为待核实，不为冲击力编造实验。品牌片可以追求情绪与记忆，不强迫每镜展示产品；演示片必须保持操作与结果可读。

## 纪实和虚构的分界

采访脚本是问题与观察计划，不是预写被访者答案。已有采访可编纸面结构，但保留出处与上下文。重演、合成人物、动画说明、推测场面要分别标注其性质。

## 不同长度的压缩方法

- 15 秒：保留一个明确变化、一个主要信息任务；删除分支，不删除观众理解结果所必需的动作。
- 60–90 秒：容纳一次策略变化或多个证据点，但是否需要反转由任务决定。
- 数分钟以上：给人物选择与后果相处的时间；用场景变化推进，避免只加旁白。

以上是尺度示例，不是固定镜头数或字数配额。先写必要内容，再用试读与预演校时；素材不足时如实标缺，不虚构画面已存在。
