# 案例：30 秒洗发水品牌片《留一点空隙》

设计样稿，品牌产品虚构，没有实际生成。"参考 A""瓶身 V2"是制作时要建立的代称。

## 任务

30 秒品牌片。青绿色洗发水。客户原话："清爽、治愈、有温度、轻快。"

## 大多数人的第一稿

> 一个美女在浴室洗头，泡沫丰富，水花飞溅，阳光透过窗户，清爽治愈，产品特写，电影感。

问题：这是洗发水广告的**模板**，不是**这个**广告。"清爽治愈"是结论没过程。

## 第一步：形容词翻译成体验

观众看完到底要有什么感觉？定为：**忙完一天后，终于可以把注意力还给自己。** 清爽是"不挤"，治愈是"从被催促到可以慢一点"，温度是"不冷"。

划一条线：不把产品宣传成能解决情绪或人生问题。

## 第二步：感受稿

> 一整天，声音都挤在她身上。回到家，水先替她把这些声音隔远。等她再走到窗边，风并没有变大，只是她终于给它留了位置。

两个通感：**"水隔远声音"** → 声音设计（嘈杂退远，水声占前景）+ 空间切换，不拍通知图标被冲走。**"给风留位置"** → 身体放松 + 构图开阔，不让墙壁变形。

## 第三步：三个方案

- **身体方案**：肩颈收紧到舒展。直接，但容易演成广告笑容。
- **材质方案**：泡沫从密到薄，水纹由乱到稳。精致，但人的体验弱。
- **声音方案**：密集近处声 → 水声主导 → 有间隔的音乐。最能表达"空隙"，要考虑静音观看。

**决定**：声音当结构，身体当看得见的支撑，材质当中段愉悦。静音时靠取景从紧凑到开阔、动作速度、停留时间读到变化。

## 第四步：美术和连续性

人物身份不变，三个状态：回家、洗护中、洗护后。剪辑表现时间过去，不把湿发瞬间变干当产品效果。室内同一个家，窗的方向、台面、产品位置稳定。产品按压瓶，字标来自批准参考，探索用占位包装。茶叶只作一处植物联想，不暗示成分功效。

## 第五步：30 秒剪辑设计

**这是剪辑规划，不是一次生成的指令。**

| 时间 | 画面和主动作 | 声音和表达任务 | 优先检查 |
| --- | --- | --- | --- |
| 0–4 | 门内侧固定中景。进门放包，手短暂搭着包带 | 车声、零碎室内声，音乐稀疏。"人回来了，节奏还没回来" | 放包接触、门和包的去向 |
| 4–7 | 桌面近景。手机屏幕朝下落台面，手离开 | 一声短接触，之后少一点信息噪声 | 手机不分裂，手离开后留半拍 |
| 7–11 | 水流和湿发局部 | 水声占前景，音乐开始轻律动 | 水的方向、湿态 |
| 11–15 | 按压瓶和手掌。一次按压，少量产品落掌心 | 泵头和液体细声 | 泵头结构、出液位置、标签、手部 |
| 15–20 | 洗护中的手和发丝，泡沫被慢慢带开 | 音乐略展开，水声不消失 | 手和发丝、泡沫一致 |
| 20–25 | 时间跳切到洗护后。窗边把头发拨到肩后，停着感受风 | 音乐更通透，室内声回来。不要求大笑 | 干发、光源连续、不过度展示 |
| 25–30 | 产品静物，背景留空。一道轻反光经过墙面后停稳 | 配乐收束。旁白可以是"给今天，留一点空隙。" | 包装正确，反光不盖字标 |

## 第六步：两段执行稿

**S04 产品按压——第一个风险测试**
```text
保留首帧的按压瓶、台面和双手位置。右手食指完成一次平稳按压，少量产品从出液口落入下方的左手掌心。松开后泵头回到起始高度。镜头固定，能看清泵头、出液口和手掌的关系。光线清楚柔和，玻璃和塑料结构保持真实，不突出夸张的飞溅。
```
接触不稳 → 改成"泵头近景"和"掌心已有产品"两镜，用声音连接。

**S06 舒展——不是摆出开心**
```text
以洗护后的干发首帧开始。她站在窗边，把落在脸侧的一缕头发拨到肩后，手自然落下，之后不再忙着做下一件事。窗边微风只带动少量发梢。镜头安静留在原处，人物一侧有干净的空间。她的状态轻松、清醒，不需要对镜头微笑，也不刻意闭眼陶醉。
```

## 第七步：音乐

约 118BPM，轻而有弹性的低音、清亮短音、稀疏打击乐。中段展开，结尾减少声部。开头不铺满旋律，给门、包、手机的接触留位置。118BPM 每拍约 0.51 秒——剪辑参考，不是生成音频精确符合。别为整齐把所有切点放重拍上。

## 制作顺序

1. 先试泵头接触、湿发泡沫（高风险）
2. 再试结尾轻松状态
3. 选定音乐方向后排粗剪
4. 最后补开篇和产品静帧

## 验收

- 去掉音乐，还能看出忙和松的变化吗？
- 只听声音，有从挤到开阔的方向吗？
- 产品结构和使用方式可信吗？
- 干湿切换有时间跳跃线索吗？
- 收尾能承载字标吗？

## 如果失败

观众只看到"表演放松"的模特 → 减少结尾动作，不是加强微表情。中段像实验室特效 → 收回正常洗护尺度。画面已够柔和 → 别再叠梦幻辉光。
