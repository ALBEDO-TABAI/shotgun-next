# 改写对照：12 组"写成这样 → 改成这样"

三种常见病：**只有标签**（结论没过程）/ **写成散文**（有感觉但不知画什么）/ **控制过度**（AI 做不到，做到了像机器人）。

"改成这样"不是唯一正确答案。

## 1 "悲伤"缺的是这一次的悲伤
- ✗ `女人悲伤地坐着，电影感。` / ✗ `眼角、鼻翼、下巴依次颤抖，三秒内落泪。`
- ✓ 她坐在已经收拾好的房间里，手还搭在椅背上。有人叫她走，她应了一声，却没有马上站起来。
- **改了什么**：悲伤有了时间和阻力，落在"没完成的起身"上。

## 2 "快乐"不该被修成不敢快乐
- ✗ `女孩开心，自然微笑。` / ✗ `极其克制，不能大笑，不能有明显动作。`
- ✓ 她认出人群里的朋友，边挥手边快步跑过去，笑声先到了。最后几步明显收住，怕撞到对方，但拥抱时还是带着一点冲劲。
- **改了什么**：喜悦有强度，也有接触前后的动作逻辑。

## 3 "愤怒"不只是音量
- ✗ `男人愤怒地说："你早就知道。"`
- ✓ "你"字说得很清楚，像在确认对象。"早就"加重，后面的"知道"落下来。不是喊给全屋听，而是让面前这个人没法再躲开这句话。
- **改了什么**：重音和对象明确了。实际效果需试听。

## 4 "自然"不等于必须加瑕疵
- ✗ `真实自然，皮肤细腻，活人感。` / ✗ `大量毛孔、颗粒、手持乱晃、曝光失误。`
- ✓ 她顺手把滑到手背的袖口挽回去，继续刚才没说完的话。保留原来干净的光，不加额外颗粒。
- **改了什么**：自然来自动作连续性，不是瑕疵数量。

## 5 "梦幻"不是平均起雾
- ✗ `梦幻唯美的香水广告。`
- ✓ 瓶身保持清楚。背景的花影像隔着浅水被轻轻推开，只有影子在变，花和台面都安静不动。梦意停在背景，不吞掉产品。
- **改了什么**：明确了现实和非现实各落在哪一层。

## 6 "高级"不是写满设备名
- ✗ `ARRI、电影大师、8K、奢华。`
- ✓ 深色瓶身只保留两条窄而连续的高光，标签正面清晰，瓶盖的金属边不泛成一大片白。背景有距离，但不抢主体。
- **改了什么**：审美落到比例和材料关系。

## 7 "轻轻"不是整条慢放
- ✗ `轻轻把盒子放下。`
- ✓ 他把盒子移到桌上，接近桌面时才收慢。指尖多扶了一下，确认它站稳后离开。
- **改了什么**：只在关键接触处控制速度。

## 8 "现场感"不是永远在抖
- ✗ `手持拍摄，真实电影感。`
- ✓ 镜头在她身后半步跟着走，转角时稍晚一点跟上，让门框短暂经过前景。整体稳定，只有走路带来的轻微起伏。
- **改了什么**：抖动有来源、幅度、观看理由。

## 9 "紧张地等待"不一定要拍脸
- ✗ `面部紧张，焦虑，不安。`
- ✓ 电梯数字迟迟不变。她手里的钥匙碰了一声，之后被握住，不再响。镜头只拍手和关闭的电梯门。
- **改了什么**：手、道具、声音一起承担，脸不必进画面。

## 10 "同一人物"先解决参考图冲突
- ✗ `千万别换脸，绝对一致，一模一样。`
- ✓ 人物身份用参考 A。本场服装用参考 B。A 里的旧外套不延续到这一场。其余姿态以当前首帧为起点。
- **改了什么**：先说清谁提供什么。前提是参考图真的上传了。

## 11 "移过去"要区分复制和搬动
- ✗ `把标 1 的花瓶移到标 2。`
- ✓ 把标 1 指的这只花瓶移到标 2 的桌面区域，原来的位置恢复成空桌面。保持同一个瓶身和花枝，按新位置调整接触阴影，最后去掉辅助标记。
- **改了什么**：补齐移动前后状态，避免两只花瓶。

## 12 删掉一半，反而更完整
- ✗ `极度细腻自然真实的年轻女孩，优雅而灵动，慢慢轻轻转过脸，带着五味杂陈的心情，镜头缓缓平稳推近又轻微环绕……`
- ✓（针对已确定首帧）她听见自己的名字，转向声音来的方向，认出对方后笑了。镜头留在原地。
- **改了什么**：一个刺激、一个反应、一个镜头选择。这条任务不需要更多。

## 改完别只比文字

提示词读起来更像文学、教科书或工程规范，都不能代替**成片有没有表达对**。
