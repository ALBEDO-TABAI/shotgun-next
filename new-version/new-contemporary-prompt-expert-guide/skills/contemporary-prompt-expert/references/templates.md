# 六张模板

给人或 AI 助手的工作文本，不是某个模型的固定接口。方括号是要填的。已知信息不重复问；缺关键信息明确说"缺这个"；低风险假设可以先做但标注。

## 模板一：先长出几个方向

```text
我要做[用途和媒介]，希望观众首先感到/理解[主要体验]。
现有材料：[实际有的]。必须保留：[关键事实]。

请给出三个在"怎么让人感到"这件事上真正不同的方向，不是同一画面换配色。每个方向写：
- 一段有画面感的感受描述
- 它怎么落到人物 / 物件 / 空间 / 声音
- 一个最值得保留的细节
- 一个可能失败的地方

直接和间接表达都可以，不默认"含蓄""写实""三幕"更高级。
不编造已存在的参考素材或模型测试结果。
```

## 模板二：感受稿变一张图

```text
感受稿：[一句感受或一小段联想]
用途：[概念图 / 角色资产 / 场景资产 / 主视觉 / 最终静帧]

把感受里真正有用的"关系"提取出来，再选两三个可见的东西承载。不把所有比喻字面画出来。
生成说明交代：视觉中心、空间关系、材料或光或绘画语言、必要留白。
没有叙事需求不强加故事。已有产品或角色按实际参考保持。

最后给一版自然语言提示词，再用一句话说明本版最重要的视觉选择。
```

## 模板三：让首帧继续发生

```text
这是[首帧 / 身份参考 / 布局参考]，先按实际任务区分它的作用。

本镜头要完成：[一件事，或一次感受变化]
起点：[看得见的姿势、视线、手和道具位置]
终点：[要延续到后面镜头的状态]
观看方式：[机位 / 取景 / 一项主要运动，或"保持原图"]
声音：[对白 / 环境 / 音乐，注明谁听见、谁发声]

写一版适合当前工具的执行稿。只细化关键接触和情绪转折，自然过渡留给模型。
不追加新人物、新剧情，不给一串表情词。
```

## 模板四：声音不是情绪标签

```text
台词正文：[准确台词，不混入备注]
角色长期声音：[语言、口音、音区、声音质地]
当场关系：[对谁说，想怎样影响对方，身体正在做什么]
变化：[哪几个词要强调，哪里改变节奏或收住]
空间：[耳边 / 正常距离 / 电话 / 门后]

给出自然的表演说明，保留台词可读性。
不把标点换算成"保证执行的秒数"。需精确时长的地方列为试听后再调。
```

## 模板五：参考素材分工

```text
本次实际可用的素材和用途：
[列表，例：A_身份.png（角色身份）；厨房_布局.png（场景布局）；首帧.png（起点）]

先检查角色、服装、场景布局、光向、时间状态有没有互相冲突。
区分：首帧 / 身份 / 风格 / 运动 / 声音参考。

冲突能用"已批准版本"解决的直接用；不能确定的指出影响，不默默混合。
只保留当前镜头需要的输入，输出精简的引用分工和执行稿。
```

## 模板六：看结果，再修提示

```text
本次任务和必须项：[目标]
实际输出：[可读取的媒体，或我看到的具体现象]

区分三类：内容对不对、表达好不好、后面能不能用。
先描述实际能看见 / 听见的，不从提示词推断"应该已完成"。

找出最影响任务的一处问题，提一个最小修改和一个备选路线。
不一次换掉角色、风格、机位和模型，除非问题本身需要连带改。
没有可读取媒体时只做文本和条件审查，不宣称"验片通过"。
```

## 模板不是最终格式

要交纯文本给模型时，从模板编出一段自然说明；参考引用和参数放进有效接口；过程解释不一起提交。用完做一次删减检查：只有标签就补过程，写成散文就找落点，控制过度就删到只剩关键接触。
