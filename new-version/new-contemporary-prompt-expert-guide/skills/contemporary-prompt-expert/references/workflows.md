# 按任务的流程：出方向 / 文生图 / 改图 / 图生视频 / 多镜头 / 预演 / 评价修复 / 换工具

---

## 1. 从一句需求到几个真正不同的方向

**第一步：把形容词翻译成问题**。"梦幻"是要世界规则偏一点还是只要柔和？"高级"是材质精确、留白、文化气质还是价格信号？品牌名、必须保留的内容、授权范围、输出规格——不能猜。

六行创作简报：
```text
作品用途：30 秒情绪品牌片，之后另做竖屏版。
核心体验：从被催促变成可以慢一点。清爽，但不是冷。
必须让观众读懂：产品是什么、什么时候用。不添加没确认的功效。
已有素材：包装主图、一个人物参考、一张室内场景参考。
形式空间：允许少量非写实转场，人物和产品保持可辨认。
待选择：音乐主导还是环境声主导？先比较两种。
```

**第二步：用不同"机制"发展方向**。一个由身体状态推动，一个由空间开合推动，一个由声音密度推动。每个方向写：感受稿、画面解释、最大风险。风险不是否定理由，是决定先试哪点。

**第三步：选方向看四件事**：贴近任务？有辨识度？核心信息容易接收？现有条件能完成？别把"最容易生成"当最好，也别把"最奇怪"当最有创意。

**第四步：先试最可能推翻方案的那一点**。全片靠一处玻璃折射就先做它；靠一句台词就先试听；靠道具交接就先试接触。不是所有验证都要付费调用——文字读稿、草图、已有素材剪节拍都行。

**第五步：冻结到恰当程度**。确定表达方向、关键人物物件、每段结果；留开放自然小动作和非关键装饰。交给生成环节的是：选定方向、实际素材清单、当前镜头任务、重要约束、这次要比较的点。不附所有聊天记录和被否决方案。

## 2. 文字生图

**先判断做哪种图**：概念探索 / 角色资产 / 场景资产 / 最终静帧 / 版式海报。角色资产要身份结构清楚；成片静帧重气氛视点；海报要给信息留空间。同一产品新角度不是从零想象，用参考图或改图。

**起草顺序**：一句话定观看任务 → 主要对象和关系 → 构图和环境 → 最后少量光、材料、风格。抽象感觉放开头或结尾一次就够。

```text
一张明亮、安静的生活方式产品静帧。浅色洗手台右侧放着一只半透明青绿色按压瓶，左侧留出干净空间。镜头与台面略成俯角，能看清瓶身正面和少量顶部结构。午后柔光从侧窗进入，在墙上留很淡的窗影。台面只有一小片尚未干透的水迹，没有铺满装饰叶片。画面轻盈、清爽，但保留生活的温度。
```
已有真实包装时改成"使用包装参考"。

**按层比较**：第一轮看结构（主体突出？空白有用？机位能看清目标？）→ 第二轮看关系（比例、距离、同一世界？）→ 第三轮看材料细节。构图错了别用高分辨率把错误做精细。

**修改只说需要变的那一层**："左上更空，瓶子不动"。多轮漂移就回最后可靠版本。

**风格化不必向摄影靠**：插画用轮廓色面纹理；黏土保留压痕；图形海报可以没有实体光源。给媒介写它自己的规则。

**输出前**：画幅、像素、颜色、信息区、字标结构。**如果之后要变视频**：起始姿势能接着动吗？双手在哪？头朝哪？道具被挡了吗？漂亮的静帧不一定是好首帧。

## 3. 改图

**核心结构**：原图 + 目标区域 + 操作 + 预期结果 + 重要保留项。

**指出"是哪一个"**：只有一只杯子就说"桌上的杯子"；东西多用框、箭头、编号、局部裁切或蒙版。别不分任务画满标记。

**红箭头是看得见的提示，蒙版是接口里的编辑范围**——不同机制。即使给了蒙版也别假设外面像素绝对不变（OpenAI 官方文档说蒙版是"指导"）。

| 操作 | 说清 | 检查 |
| --- | --- | --- |
| 删除 | 只删对象还是连影子倒影？ | 背景修复、残影、纹理重复 |
| 替换 | 继承尺寸姿态还是连结构改？ | 接触点、材质、身份 |
| 移动 | 原位不留副本，新位怎么落地？ | 透视、比例、阴影遮挡 |
| 重打光 | 哪个光源哪个区域变？造型保持？ | 光影合理、脸和产品被重生成了吗 |

**移动说明范例**：
```text
用没打标的原图作为画面基础，打标图只帮助定位。把标 1 的这只花瓶移到标 2 的桌面空位，原位置修复成同一张桌面的连续纹理，不保留第二只花瓶。保持瓶型、花枝数量和主要朝向，按新位置匹配透视和接触阴影。人物、桌子结构和画幅不变，最终画面没有任何定位标记。
```
只有工具能理解两张输入且分工清楚时才这样提交。

**用保留项保护任务，别堆无关禁令**。要保字标就列字标为重点。要逐像素保留非编辑区，在后期把通过的局部合成回原图，不依赖"其他地方绝对不动"。标记别盖住要保留的结构。

**完成后两次比较**：目标对不对 → 原本正确的区域被连带改了吗。漂移就退回最后通过版本，分区域分步。别把每张中间结果叫"最终图"。

## 4. 图生视频

**上传前先想这张图扮演什么**：
- **首帧**：视频从这里开始。姿势、构图、光都是起点。
- **身份参考**：告诉 AI "这个人长这样"，不一定从图里的姿态开始。
- **风格参考**：外观方向，不规定空间。

不同工具叫法和能力不同，按实际模式确认。强首帧任务里不能一边要求严格保留第一帧，一边要求第一秒变成完全不同的站姿。

**只写变化，不重复图里已有的**：
```text
她听见窗外有人叫她，视线先移向窗外，随后身体稍稍转过去。右手仍稳稳拿着杯子，没有端起来喝。窗帘在她转身后轻碰一下肩侧。镜头保持原来的中景和位置，安静地等她看清来人。
```

**给一个结尾状态**："她走到门边停住，仍没有打开门"——限定进度，也给下一镜起点。要产品定帧就让末尾稳定。

**用时间表达关系，别迷信小数秒**："先停一下，再回头"；"前半段听见，后半段认出"。关键节拍用输出音视频确认。

**多种运动同时存在时先测主动作**。人物转身 + 镜头环绕 + 窗帘飘 + 光闪 + 焦点切换会竞争注意力，也让你找不到是哪个坏了。

| 症状 | 修 | 别 |
| --- | --- | --- |
| 动作从奇怪姿态起步 | 修首帧或调动作 | 加"自然"两个字 |
| 身份在运动中漂移 | 检查人脸信息、转头幅度、遮挡、工具参考能力；缩小动作或分镜 | 无限强调"不变脸" |
| 动作完成情绪没读出 | 镜头能看到反应吗？刺激明确吗？剪辑给停留了吗？ | 改表演句 |

**选择和剪辑是流程一部分**。从候选选可用区间，可以剪掉破绽，但不能剪掉必需因果再宣称完成。看实际片段，不看任务状态"成功"。

## 5. 多镜头与资产

**库可以全，一次只拿需要的**。桌边近景只需要脸、当前上装、桌面环境。

**四类分开，别混成"角色包"**：
- 身份：跨造型不变（脸、体型）
- 造型：一场戏内保持（发型、服装、妆）
- 状态：随剧情变（湿了、破了、拿着什么）
- 本镜姿态：这个镜头从哪个姿势开始

声音同理：稳定声线和这次表演分开。

**每个镜头一张薄任务卡**（给团队看，给 AI 只编入它支持并需要的）：
```text
镜头：S04，接 S03。
本镜任务：她从桌上拿起产品，停在能看清标签的位置。
引用：人物 A 已批准身份；造型 A-室内；产品瓶身 V2；桌边首帧 S04-V1。
起点：瓶子在桌上，盖子关着；她双手空着。
终点：瓶子在右手，盖子仍关着；人物仍坐着。
本次开放：自然的手指调整和衣袖跟随。
本次必查：瓶型、字标、拿瓶的手、起终状态。
```

**交接记"实际发生了什么"**。生成出来她把瓶子放回了桌上——不能因为提示词要求"拿着"就让下一镜按"右手持瓶"生成。要么接受改动，要么修当前镜头。**已批准的画面状态才是接续依据。**

**场景参考先检查是不是同一间房**：门窗大件家具相对位置一致。反打不是生成一间风格相近的新房间。

**声画和后期共享同一个决定**：S04 做了决定，音乐转折不按旧版 S05。台词删了，字幕口型也查。

**交付前看整个序列**：先放下提示词像普通观众看一遍，再技术检查。视线方向、空间地标、声音连续、道具状态、节奏起落。

## 6. 预演

**什么时候需要**：多人同步、复杂遮挡、长路线、关键交接、严格运动节拍。一个人抬头、产品转台、固定对话镜头不需要。

**先写观众必须看懂的顺序**。30 秒长镜头表现文件调换：原件 → 谁接近了 → 交换发生 → 谁拿着哪份。镜头路线服务这些信息，不是先画漂亮曲线再塞剧情。

**先做最便宜的预演**：桌面小物代替人物手机拍；平面草图画站位读台词计时。时间不能按路径长度推算——接触、停顿、读信息都耗时。

**粗模粗在外观，不粗在关键关系**。人物可以是方块，但关键道具能否看见、路线、机位高度、遮挡、时间要准。手部交换靠躯干方块证明不了，需要代理物。

给制作助手的说明：
```text
按已确认的镜头说明建立简化预演，不重新改剧情。人物用不同颜色的简单体块区分，关键道具单独建代理物。先输出俯视布局和三个信息关键时刻的机位，再输出连续的相机运动。如果现有空间看不清道具交接，提出最小改动方案，而不是偷偷移动门窗或省略动作。
```

**三种预演输出**：给人审查的说明版（带名字箭头轨迹）/ 给模型的运动参考（去掉辅助标记）/ 可编辑工程文件。

**交给生成器时说清每个参考的职责**：运动视频管相机人物位置节奏；外观资产管人物场景外貌；提示词管情绪材料细节。能否分离必须实测。

**预演通过了最终片仍要验**：几何连续≠身份连续；路线正确≠道具没漂移。

## 7. 评价与修复

**看成片前先写两个判断点**："观众能认出同一瓶产品""结尾感到松开而不是虚弱"。第一次看不读提示词，只写看到听到什么；第二次再对照任务。

**失败分层**：

| 看起来 | 先检查 | 往哪改 |
| --- | --- | --- |
| 画面漂亮但没说清 | 感受和信息任务 | 重选落点或观看方式 |
| 人物像示范表情 | 情境、对象、主动作 | 减表情清单，补真实任务 |
| 手和东西乱 | 首帧、拿着什么、接触复杂度 | 简化动作或拆镜，补参考 |
| 场景变了 | 多图布局一致吗 | 先修场景事实，不先调色 |
| 底图像贴上去 | 光、尺度、边缘、透视 | 回图像关系，不加颗粒 |
| 配音机械 | 台词、角色差异、节奏、声音模式 | 判断哪层错，试听修 |
| 切起来突然 | 起终状态、声音桥、节拍 | 改选片区间或补接头 |

**一次改一件主要的事**。"紧张不明显"→两个候选：加一处手部停顿，或改景别让反应被看见。不同时换演员灯光模型运镜。互相依赖的小东西可以一起改（移花瓶需同时改旧位背景和新阴影）。

**保持比较条件相近**：记工具版本、输入、设置、提示词、选取区间。相同设置也可能不同结果。不只展示最成功样本。

**用失败改变假设**。加了手部动作还是僵硬→检查机位看不到反应？声音太规整？首帧姿态不合适？不要解释为"提示词不够长"然后继续添。

**停止条件**：
- **停**：关键任务通过，局部缺陷后期低成本修
- **回头**：核心表达仍错，局部精修无意义，返回方案
- **换路**：工具不适合所需控制

三档：**可用 / 可用但需指定修补 / 需重做**。

**复盘记能迁移的**：什么输入、什么动作、什么画幅下哪些关系有效、哪些控制不可靠。不记"这条提示很神"。

## 8. 换工具

**创意不变，输入随工具变。** 同一个"她听见门锁声杯子停在半空"，在偏好短句的工具里是两句话，在支持分段的工具里可以拆人物 / 镜头 / 声音。

**换工具查六项**：
1. 输入角色：首帧、尾帧、身份、风格、运动、布局——分得清吗？
2. 参考限制：数量、格式、长度、分辨率、怎么引用
3. 文字偏好：简洁自然句、分段、参数词、专用标签？
4. 声音：能生成？能关？台词和说明能分开？
5. 时长和镜头：实际多长？多镜头怎么处理？能续接？
6. 负向约束：有单独负向栏？普通否定推荐吗？

按实际入口确认，不从教程截图、营销标题、转售接口推断。

**否定句**：创作说明里可以写"不要夸张惊吓"。偏好正向的工具里转成"反应小，先停一下，再自然回头"。安全边界不因"正向更好"被抹掉。"固定机位"比"不摇不推不绕"好读，但也不保证不动。

**防三个假精确**：设备名（ARRI）是外观联想不是调用相机；秒数是节奏意图不是逐帧回执；角色编号是指认方式不是无需上传的永久记忆。

**不提供"哪个模型永远最好"**。工具变，表演美术通感的方法不用随发布重写。
