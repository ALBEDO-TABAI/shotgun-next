# 评价表：做对了吗，还能往下做吗

## 不打总分

"整体 8.5 分"会把严重问题（字标错了）被漂亮部分平均掉。先分两类：

- **硬任务**：产品必须能认出；角色不能换人；关键台词不能错。做不到就不合格。
- **审美选择**：背景偏蓝还是偏暖；镜头静止还是慢推。是方案不是对错，除非品牌已限定。

不能用漂亮弥补错误字标，也不能拿个人偏好否定项目需要的形式。

## 七个维度，按需用

| 维度 | 看或听什么 | 过了的样子 | 要改的样子 |
| --- | --- | --- | --- |
| 任务 | 必须让观众知道或感到什么 | 重要信息看得见，核心体验有东西托着 | 只有看提示词才懂 |
| 表达 | 形式服务目标吗 | 有主有次，风格相容 | 每个部门都在同一处用力 |
| 行为 | 动作、反应、关系 | 刺激和回应接得上 | 对着空气演，动作空转 |
| 空间 | 人物、道具、光、机位 | 关键位置和持有状态清楚 | 突然换房、穿物、道具消失 |
| 质感 | 表面、重量、声音材料 | 作品自己的规则稳定 | 结构错误被柔光颗粒遮住 |
| 声音 | 台词、空间、情绪、画面 | 谁发声清楚，有需要的间隔 | 错人说话、抢信息、时序错 |
| 制作 | 片段长度、接头、能不能剪 | 可用区间明确，后面能接 | 没剪辑余量，改动无法追踪 |

写实看写实规则，超现实看它自己设的规则。

## 三轮观看

1. **像观众**：不读提示词。最先注意到什么？最直接的感受？
2. **像专业同事**：动作接触、声画归属、光和材质、信息来得及接收吗？
3. **像剪辑师**：和前后镜头接得上吗？哪一段能用？剩余问题怎么处理？

时间紧可以合并，但**不要只看静帧截图**。声音和运动的问题一张图看不出。

## 结论格式

```text
对象：实际候选文件 + 可用时间范围
本镜任务：……
观察到的：……（只写媒体能支持的）
结论：可用 / 可用但需修补 / 需重做
最重要的问题：……
下一步：保留 / 局部修 / 改音 / 换区间 / 重生成 / 回方案
交接状态：谁在哪里，关键物件在哪，声音和造型用哪版
```

"更自然一点""再高级一点"不能单独当返工单。说出**哪里**让你这样感觉，**先改哪一层**。

## 例子

候选：角色身份对，拿杯子完成了，但原本希望松弛的结尾变成对镜头的广告微笑。

**没用**："整体 8.5 分，可以。"
**有用**：内容任务通过；结尾表达偏展示。保留前半段拿杯，后半段改成看向窗外的停留，或重选一段没看镜头的区间。

如果项目本来就要广告展示，这个表现反而合适。**判断跟着目标变。**

## 哪些缺陷可以放过

远处背景一片非关键叶子形状变了，未必值得重做。产品标签、关键道具归属、决定性台词的错误更重要。比例按**伤不伤任务**算，不按错误像素面积。

## 没有媒体时

可以检查语义矛盾、时间预算、引用分工、风险——叫**文本预审**。不能说"配音自然""没有变脸""动作流畅"。
