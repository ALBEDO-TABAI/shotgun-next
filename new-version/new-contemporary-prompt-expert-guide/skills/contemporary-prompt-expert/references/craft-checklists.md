# 各部门卡片：先问什么、写什么、别写什么

九个部门。每张卡片：先问 / 写 / 别写 / 失败了先修什么。

---

## 表演

**先问**：他在做什么？想让谁怎么样？
**够用的表演说明** = 当下在做的事 + 一个刺激 + 反应的变化 + 从哪里看得出来。

**一次反应三个节拍**：先维持原来的事（还在整理桌面）→ 刺激进来（听到名字，停住）→ 新选择（把杯子放回，转身开门）。

**主动作 / 跟随动作 / 细微反应要互相引起**：接到盒子 → 感到没重量 → 再看对方。不是三条互不相关的循环。

**按景别写尺度**：

| 镜头给了什么 | 优先写 | 白写 |
| --- | --- | --- |
| 远景 | 站位、走停、转身、距离 | 眼角变化承载剧情 |
| 中景 | 手部任务、重心、朝向、听者反应 | 面部手部同时塞满 |
| 近景 | 看向谁、反应延迟、嘴角下颌 | 没对象的一串"微表情" |
| 手部特写 | 触碰、迟疑、松开、使用痕迹 | 全身表演 |

**别忘了听的人**：打断、后退、继续手头的事、把东西接过来——都改变关系。"她说'我没事'，对方没劝，只把要收走的椅子放回原处。"

**别**：表情清单（眉头紧锁、眼神凌厉、嘴角下压）；"0.2 秒眉毛动、0.4 秒瞳孔放大"；把"没表情"当"内心丰富"、把跺脚当"演过了"——内外不一致是选项不是唯一正确。

**失败修法**：太满像表情包 → 减少同时发生的表情，留任务和一次关键反应。太空像木头 → 补刺激和后果，不加"更有演技"。像摆拍 → 检查是否无缘无故看镜头。动作奇怪 → 回到首帧的手、姿势、道具，别只改情绪词。

## 台词与配音

**声音四层，分开写**：
1. 这个人一直什么声音（音区、厚薄、气息、口音——只留跨镜头能用的）
2. 这次想干什么（安抚 / 催促 / 试探 / 掩饰 / 说绝；对谁；多近；身体在不在动）
3. 句子怎么走（哪个词加重、哪里停、何时压低加快拖住突然结束）
4. 在什么空间（干声 / 隔门 / 电话 / 空房间 / 街上）

**同一句"我知道了"三种说法**：接受 = 句子完整落下，呼吸松开，继续手上的事；敷衍 = 比平常快，不看对方，手没停；受伤收住 = 先停一下，"知道"说清楚，末尾不上挑，放下东西再抬眼。

**台词、导演备注、时间表分开放**。只有支持"指令和台词分开输入"的工具才能直接提交，否则备注会被念出来。

```text
台词正文：你终于来了。先坐，我给你倒水。
说话对象：刚进门的老朋友。
声音方向：成年女性，温和中音，不用播报腔。
当场状态：原本有点担心，开口时放松下来。
空间：安静住宅内，距离近，少量自然反射。
```

**别**："深沉悲伤地说"两个标签；每句都改成省略号口吃碎句（统一出现就是另一种模板腔）；省略号当固定 0.3 秒（不同工具处理不同，要试听）；一边锁死已生成的口型一边改台词。

**先试听再对口型**：台词顺不顺、音色像不像同一人、时长装得下吗。不够就删句或延长镜头，不把人压成高速朗读。

## 动作与调度

**动作不是动词的数量，是状态真的改变了。** "她把盒盖抬起，看到里面后没有再往上打开"胜过六个动词。

**写起点 → 关键接触 → 终点**。碰撞、握手、交接、拿取、开盖要交代对象和前后状态；走路怎么走交给 AI。

> A 先伸出右手，B 把钥匙落进她掌心。A 合上手指后，B 才松开。两人的手短暂同框。

接触做不稳 → 拆成"接近、遮挡、结果"三镜，只要观众能理解且不假装一镜到底。

**随身道具记"手位账"**：

| 时刻 | 左手 | 右手 | 其他 |
| --- | --- | --- | --- |
| 门口 | 推门 | 拿手机拍摄 | 相机挂脖子，咖啡未出现 |
| 桌边 | 空 | 手机放稳后松开 | 咖啡在桌上 |

**调度是关系的变化**：从屏风后走到对方面前是空间移动；从不敢打扰到主动开口是关系移动。两者互相解释。对方有没有让座、后退、继续手上的事，决定走近有没有改变场面。

**用固定地标定方向**（门、窗、桌），少用跨镜头的"左右"。

**让重量留下后果**：包碰腿、水洒出湿迹、椅子没马上回位。后果比"物理真实"四个字更好检查。

## 镜头

**先问观众站在哪里、能看见什么。**

**六个要素别混叫"运镜"**：位置和高度 / 朝向 / 取景范围 / 前后关系 / 运动 / 焦点。

"推近"有两种：镜头前移 vs 变焦放大——要看遮挡物后面必须前移或横移。"摇镜"是改方向，不是绕主体换位置。

**一条镜头先选一件主要的活**：跟随 / 揭示 / 逼近 / 撤离 / 等待。可组合，不必八秒内全做。

**镜头和人物可以不同步**：跟太准像展示，略晚像发现。但剧情要看清关键动作时不能晚到。

**现场感来自"可以解释的限制"**：走路起伏、前景擦过、对焦调整。干净稳定也可以很真实。水滴、眩光、剧烈晃动是强表达，不是默认修补剂。

**检验法**：给不知道提示词的人看，只问"你先看到了什么"。

**别**：一串"流畅电影感"；文字说不清机位时堆形容词——画草图或做预演。

## 光与材质

**光不是亮度总开关。** 说明顺序：来源 → 方向 → 软硬 → 影响区域 → 明暗关系 → 颜色关系。选需要的写。

> 左后方窗光在瓶肩留一道窄亮边。正面标签由较柔的反射光照清。背景稍暗但不全黑。玻璃看得出厚度。

**三组别搞混**：
- 方向 vs 效果："侧逆光"是光从哪来，"轮廓光"是边缘被强调的效果。
- 亮度 vs 软硬：**光源相对主体的大小**决定软硬——大窗软，小灯泡硬。亮不亮不决定。
- 光的颜色 vs 物体颜色：蓝瓶子不等于蓝灯照。

**硬光不需要百叶窗**。百叶窗、树叶只是让阴影有图案。"光从左上斜照，瓶子在桌面投一道边缘清楚的影子，影子不经过标签"——不写"极致硬光、爆亮"。

**材质四种线索**：表面（哑光 / 细纹 / 抛光）、透光反射（透 / 半透 / 镜面 / 散开）、变形（硬挺 / 柔韧 / 可压扁）、接触后果（水迹 / 指痕 / 压痕 / 滑动阻力）。

"高级丝绸" → "布料薄但有重量。折面亮光沿褶皱移动，落到肩上先滑一点再停住。"

**连续性**：镜头换侧，窗的位置不变。袖口刚湿，下一镜不能无故变干。

**交给后期**：品牌色、字标、精确局部亮度、统一颗粒。加颗粒掩盖不了错误阴影。风格化可以让影子不服从光源，但要明确说是这个世界的规则。

## 美术与妆造

**问"这个人怎么生活、这个东西怎么被用过"，别问"什么风格"。** 风格是选择、使用、维护留下的关系。

> 房间不脏，桌面有长期工作磨亮的边。两把椅子不成套，常坐的靠窗。

**角色三件事分开管**：
- 是谁：脸、比例、辨识特点——全程不变
- 现在什么造型：发型服装妆容配饰——可变但要批准
- 这一刻什么状态：干湿、完整破损、妆新旧、道具怎么拿——随剧情变，**变化要有时间和行为理由**

**别把性别当妆造硬规则**。问：这个世界怎么表达阶层、职业、仪式、偏好、处境？再定发型妆衣配饰各承担多少。

**用材质和维护状态代替身份名**："失意贵族"不必破衣——衣服依然昂贵，领口不再像从前那样整理妥当。

**场景固定结构，氛围不同版本**：门窗桌通道不变；清晨深夜是光的版本，宴会散场是陈设的状态。九张好看的房间图不等于场景资产，除非真是同一空间。

**重要道具必须能用**：要开盖的瓶子要知道盖和瓶怎么分开。一张正面美图不够。

**资产"本色"和拍摄"氛围"分开**：中性参考图看清身份结构；最终画面可以浓烈。资产不应把下游场景锁进同一种灯光表情。

## 音乐与声音

**先决定声音在干哪件事**：撑空间 / 给重量 / 引注意 / 改理解 / 连段落 / 给质感。别只填流派和 BPM。

**三层别抢同一件事**：环境底（风水电器街道）/ 动作声点声（布料脚步杯子门）/ 音乐或声音设计（持续脉冲上升悬住松开）。

**安静不等于所有轨归零**。留很小的室内声，拿掉占注意的声音，靠对比感到静。

**音乐说明写五件事**：开头怎么进入 / 什么材料 / 节奏怎么呼吸 / 哪里变化 / 结尾怎么留余味。目标 BPM 是剪辑参考，不是已执行事实。

**音乐不一定跟表情走**，但用反差前先说清想产生什么（甜蜜藏不安？安静承托喜悦？）。别把反差本身当高级。

**声音的通感到起落**："锋利" = 起音快尾音短；"温润" = 圆起音持续平滑；"像远处玻璃反光" = 减少音符、拉开间隔、少数清亮音色在远处。不必真录玻璃。

**写清哪些是场内真实来源、哪些是配乐或主观处理**。否则 AI 可能把旁白变成画面里新增的说话人。

**验三遍**：只听音频有结构吗？静音看画面必须信息能读吗？合起来是支持还是重复喊同一句？

## 静态图、平面、风格化

**四件事**：视觉中心（第一眼看哪）/ 空间关系（谁前谁后）/ 材料语言（摄影 / 手绘 / 印刷质感）/ 阅读路径（第二眼去哪）。故事只是组织方式之一，别给每只瓶子安排动机。

**把"风格"拆成可选构成**：线条工整还是松动？色块平涂还是渗染？形体准确还是夸张？空间平面叠置还是透视深入？保留哪种手工痕迹？

**风格融合决定谁提供骨架**：几何版式提供秩序，水墨边缘提供材质，局部金属反光提供产品属性。不要四种风格同时改造每一处。检查：第一眼属于什么，第二眼发现什么不同？答不出就是元素拼盘。

**版式和字标有硬任务**：先定画幅和发布尺寸，再定主体占比、标题区、安全边界。"主体位于右下。左上留出连续、低细节的浅色区域供后期放标题。不生成占位文字。" 长文案、精确商标保留可编辑步骤。

**静态图的"动作感"是一个状态**："正在转身的一瞬"可以；"先转身然后走出房间"放一张图会变拼贴。

## 时间与剪辑

**三种时间一起算**：事情做完的时间 / 观众看懂的时间 / 感受形成的时间。没有"每个动作固定两秒"。

**先给段落功能，再给秒数**："进入、触感、展开、留味"；"试探、接住、错过、停留"；"建立预期、重复、偏差、反应"。写下每段结束时观众多知道了什么、多感到了什么。

**一镜到底和多镜头没有高低**。前者强调连续过程，后者允许压缩时间、改变视点。困难动作不必全靠长镜头。

**切镜理由不只有"动作做完"**：看见关键物之前切让声音带过去；动作没结束切到反应；保留动作后的余量让空白成内容。

**声音可以比画面更连续**：长音跨两镜、环境声提前进、最后半句留在对方反应上。别让每个 AI 片段都带自己的音乐开头结尾。

**交接点比中段更容易出问题**：右手拿杯下一镜变左手；门外直接坐下没有跳跃线索；光源反了；结尾意外慢动作。判断影不影响理解，不是任何差异都返工。

**记录每条候选**：可用区间、开始结束状态、主要缺陷。"生成成功"≠"成片通过"。

**时间不够**：减少必须事件、改剪辑形式、重新分配时长——比要求"更自然地完成全部动作"管用。
