# III · 视听专业

分别学习表演、声音、动作、镜头、光线、美术、音乐、平面和剪辑，在提示词里各自该怎么写。按需读，不用全看。

- [12｜表演：先问"他想让谁怎么样"，再写表情](/craft/01-acting.md) — 情绪不是表情包。一个刺激、一次反应、一处看得见的变化。

- [13｜台词与配音：不是换一副嗓子，是换一种说话的关系](/craft/02-dialogue-voice.md) — 声音分四层，分开写。

- [14｜动作与调度：东西从哪来、到哪去，手上拿着什么](/craft/03-action-blocking.md) — 关键接触写清，走路怎么走交给 AI。

- [15｜镜头：先决定观众站在哪里，再决定镜头怎么动](/craft/04-camera-attention.md) — 一条镜头只干一件主要的活。

- [16｜光与材质：光从哪来、落在哪、什么东西怎么反应](/craft/05-light-material.md) — "高级质感"什么都没说。

- [17｜美术与妆造：世界不是背景板，身份不只是一张脸](/craft/06-world-art-costume.md) — 问"这个人怎么生活"，别问"什么风格"。

- [18｜音乐与声音：先决定声音在干哪件事](/craft/07-sound-music.md) — 撑空间、给重量、引注意、改理解、连段落。

- [19｜静态图、平面设计与风格化：一张图不必写成电影](/craft/08-still-graphic-style.md) — 允许没有故事，不允许没有选择。

- [20｜时间与剪辑：提示词里发生了，不代表观众来得及看懂](/craft/09-time-montage.md) — 算三种时间，先定功能再填秒数。
