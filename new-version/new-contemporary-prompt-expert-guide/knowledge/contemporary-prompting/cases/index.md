# V · 完整案例

八个从头走到尾的例子。每个都先给"大多数人的第一稿"，再说问题在哪、怎么想、最后写成什么样。全是设计样稿，没有实际生成过。

- [29｜完整案例：30 秒洗发水品牌片《留一点空隙》](/cases/01-brand-film.md) — 最完整的一个。从一句"清爽治愈"到 30 秒镜头表。先读这个。

- [30｜完整案例：餐桌上，一句没问出口的话](/cases/02-relationship.md) — 一只杯子和听者的反应。直接问的版本也不低级。

- [31｜完整案例：喜悦真的可以冲出来](/cases/03-big-emotion.md) — 大笑、奔跑、拥抱同样可以写得好。

- [32｜完整案例：谁在拍谁——12 秒咖啡馆 Vlog](/cases/04-vlog.md) — 镜头是一个物件：谁拿着、朝哪拍、什么时候放下。

- [33｜完整案例：空走廊为什么会让人等下去](/cases/05-empty-corridor.md) — 不用人脸、不用重型音乐的悬念。

- [34｜完整案例：不追求实拍的香水图与短动效](/cases/06-surreal-perfume.md) — 只偏离一条规则，其余保持稳定。

- [35｜完整案例：安静自习室里的零食袋](/cases/07-comedy.md) — 喜剧来自目标、阻力和反应。

- [36｜完整案例：两份文件，谁最后拿着哪一份](/cases/08-object-exchange.md) — 状态表先于相机路线。
