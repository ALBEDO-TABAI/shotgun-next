# 39｜评价表：做对了吗，还能往下做吗

## 为什么不打总分

"整体 8.5 分"会把一个严重问题（字标错了）被其他漂亮部分平均掉。

先分两类：

- **硬任务**：客户的产品必须能认出来；角色不能换人；关键台词不能错。做不到就是不合格，多漂亮都不行。
- **审美选择**：背景偏蓝还是偏暖；镜头静止还是慢推。这是方案，不是对错，除非品牌已经限定。

不能用漂亮弥补错误字标，也不能拿个人偏好否定项目明确需要的形式。

## 七个维度，按需用

不必每项打分。用的时候看这一栏。

| 维度 | 看或听什么 | 过了的样子 | 要改的样子 |
| --- | --- | --- | --- |
| 任务 | 必须让观众知道或感到什么 | 重要信息看得见，核心体验有东西托着 | 只有看提示词才懂 |
| 表达 | 形式有没有服务目标 | 有主有次，风格相容 | 每个部门都在同一处用力 |
| 行为 | 动作、反应和关系 | 刺激和回应能接上 | 对着空气演，动作空转 |
| 空间 | 人物、道具、光和机位 | 关键位置和持有状态清楚 | 突然换房、穿物、道具消失 |
| 质感 | 表面、重量、声音材料 | 作品自己的规则稳定 | 结构错误被柔光或颗粒遮住 |
| 声音 | 台词、空间、情绪和画面 | 谁发声清楚，有需要的间隔 | 错人说话、抢信息、时序错 |
| 制作 | 片段长度、接头、能不能剪 | 可用区间明确，后面能接 | 没有剪辑余量，改动无法追踪 |

写实作品看写实规则，超现实作品看它自己设的规则。不能用一套"自然"统一判所有作品。

## 三轮观看

**第一轮像观众**：不读提示词。说最先注意到的东西和最直接的感受。

**第二轮像专业同事**：看动作接触、声画归属、光和材质、信息来得及接收吗。

**第三轮像剪辑师**：看和前后镜头接不接得上，具体哪一段能用，剩余问题怎么处理。

时间紧可以合并，但**不要只看静帧截图**。声音和运动中的问题，一张图看不出来。

## 留一份明确的结论

```text
对象：实际候选文件 + 可用时间范围
本镜任务：……
观察到的：……（只写媒体能支持的观察）
结论：可用 / 可用但需修补 / 需重做
最重要的问题：……
下一步：保留 / 局部修 / 改音 / 换区间 / 重生成 / 回方案
交接状态：谁在哪里，关键物件在哪，声音和造型用哪版
```

"更自然一点""再高级一点"不能单独当返工单。要说出**哪里**让你这样感觉，**先改哪一层**。

## 一个纸上例子

假设一条候选：角色身份对，拿杯子也完成了，但原本希望松弛的结尾变成了对着镜头的广告微笑。

**没用的结论**："整体 8.5 分，可以。"

**有用的结论**：内容任务通过；结尾表达偏展示。保留前半段拿杯，后半段改成看向窗外的停留，或重新选一段没看镜头的区间。

如果项目本来就需要广告展示，这个表现反而合适。**判断跟着目标变。**

## 哪些缺陷可以放过

远处背景一片非关键叶子的形状变了，未必值得重做。产品标签、关键道具归属、决定性台词的错误通常更重要。

比例不按"错误像素面积"算，按**它伤不伤任务**。

## 没有媒体时能做什么

可以检查：语义矛盾、时间预算、引用分工、风险。这叫**文本预审**。

不能说："配音自然""没有变脸""动作流畅"。

这本书所有案例都停在设计和文本审查层，没有装成媒体验收。
