# 术语表：书里反复出现的词，一句话解释

按四组排。每个词一句话，后面标注在哪一章讲得最细。

## 一、这本书自创的词

**六个问题**：写提示词前问自己的六件事——想让人感到什么、靠什么承载、谁在做什么、观众从哪看、给哪个工具、怎么判断成不成。→ [02](/foundations/02-six-layer-method.md)

**感受稿**：给自己看的那一稿。可以很抽象，"像一封没封口的信"也行。→ [03](/foundations/03-three-drafts.md)

**创作说明**：给团队看的那一稿。说清楚要什么、不要什么、为什么。→ [03](/foundations/03-three-drafts.md)

**执行稿**：给 AI 看的那一稿。具体、可见、按工具的习惯写。→ [03](/foundations/03-three-drafts.md)

**通感**：借一种感觉的形状去描述另一种感觉。关键是转移"关系"，不是搬"物件"。→ [06](/language/01-sensory-translation.md)

**情绪图谱 / 氛围图谱**：两张查表。同一个情绪词，列出它可以落在哪些不同的身体动作或材料上。→ [09](/language/04-emotion-atlas.md)、[10](/language/05-atmosphere-atlas.md)

**改写诊所**：12 组"写成这样 → 改成这样"的对照。→ [11](/language/06-rewrite-clinic.md)

**状态表**：一张表，记录每个时段里每个关键物件在谁手上、在哪。用于多镜头和复杂调度。→ [36](/cases/08-object-exchange.md)

**交接状态**：一个镜头结束时，谁在哪、拿着什么、光和声音是什么样。下一个镜头从这里接。→ [25](/workflows/05-assets-multishot.md)

**文本预审 vs 媒体验收**：没看到生成结果时只能检查文字有没有矛盾，叫文本预审。看到了实际画面和声音才叫验收。这本书全部停在前者。→ [39](/practice/03-review-rubric.md)

## 二、写提示词会碰到的词

**提示词**：你交给 AI 的那段话。当代写法更像说明书 + 短剧本，不是关键词清单。→ [01](/foundations/01-what-this-field-is.md)

**首帧**：图生视频时给的那张图。它定下了姿势、构图、光。视频从它开始发生。→ [24](/workflows/04-image-to-video.md)

**身份参考**：用来告诉 AI "这个人长这样"的图。它不是首帧，不决定动作起点。→ [24](/workflows/04-image-to-video.md)

**布局参考 / 风格参考**：分别告诉 AI "空间怎么摆"和"画面什么味道"的图。角色分开，不要混。→ [25](/workflows/05-assets-multishot.md)

**蒙版**：改图时画出来的"只改这里"的区域。官方文档说它的形状不一定被精确遵循。→ [23](/workflows/03-image-edit.md)

**负向提示**：告诉 AI "不要什么"的字段。有的工具支持，有的不支持，有的只接受正向表述。→ [28](/workflows/08-model-adaptation.md)

**底图**：生成时作为基础的那张图。改图、图生视频都从底图出发。→ [23](/workflows/03-image-edit.md)

**资产 / 资产库**：角色、场景、道具的参考图和说明，做多镜头时反复用。库可以丰富，每次提交要精选。→ [25](/workflows/05-assets-multishot.md)

**AI 味**：一个模糊的抱怨词，通常指底图、运动、光照、剪辑里的某一个具体问题。要拆开找。→ [27](/workflows/07-evaluate-repair.md)

**留白**：画面里故意空着的地方。给字、给呼吸、给注意力。→ [19](/craft/08-still-graphic-style.md)

**视觉中心**：观众第一眼看的地方。一张图通常只能有一个。→ [22](/workflows/02-text-to-image.md)

## 三、影视的词

**机位**：摄影机放在哪。高度、距离、朝向。→ [15](/craft/04-camera-attention.md)

**取景**：画面里框进来多大范围。全景（看到整个空间）、中景（腰以上）、近景（胸以上）、特写（脸或手）。→ [15](/craft/04-camera-attention.md)

**运镜**：摄影机怎么动。推、拉、摇、移、跟。不动也是一种选择。→ [15](/craft/04-camera-attention.md)

**平视 / 俯视 / 低角度**：摄影机和被拍对象等高 / 从上往下 / 从下往上。→ [15](/craft/04-camera-attention.md)

**调度**：安排人和东西在空间里怎么走、怎么站、什么时候动。→ [14](/craft/03-action-blocking.md)

**一镜到底**：不剪，一个镜头拍完整段。对 AI 生成来说难度很高。→ [26](/workflows/06-previs.md)

**空镜**：画面里没有人的镜头。走廊、桌面、窗外。→ [33](/cases/05-empty-corridor.md)

**遮挡**：一个东西挡住另一个东西。会影响观众能不能看到关键动作。→ [15](/craft/04-camera-attention.md)

**同框**：两个东西在同一画面里。同框时物件够不够大能看清，是常见问题。→ [15](/craft/04-camera-attention.md)

**连续性**：镜头之间接得上——同一个人、同一件衣服、杯子还在同一边。→ [25](/workflows/05-assets-multishot.md)

**硬光 / 软光**：影子边缘清晰 = 硬光（小光源、直射太阳）；影子边缘模糊 = 软光（大光源、阴天、柔光箱）。硬光不等于亮。→ [16](/craft/05-light-material.md)

**逆光 / 侧光 / 顺光**：光从对象后面来 / 从侧面来 / 从摄影机方向来。→ [16](/craft/05-light-material.md)

**场内声 / 配乐**：场内声是画面里那个世界有的声音（脚步、碗筷）；配乐是加上去的音乐，角色听不到。→ [18](/craft/07-sound-music.md)

**环境音 / 底噪**：一个空间本身就有的持续声音。冰箱嗡嗡、远处车流。→ [18](/craft/07-sound-music.md)

**跟随动态**：主动作带起来的次级运动。人转身，头发和衣角跟着甩。→ [14](/craft/03-action-blocking.md)

**节拍**：一段内容里的时间划分。哪几秒干什么。→ [20](/craft/09-time-montage.md)

**主视觉**：一个项目最核心的那张图。海报、封面、广告主图。→ [34](/cases/06-surreal-perfume.md)

## 四、工具和流程的词

**文生图 / 图生视频 / 改图**：三种基本任务——从文字造一张图、从一张图生成视频、改一张已有的图。→ [22](/workflows/02-text-to-image.md)、[24](/workflows/04-image-to-video.md)、[23](/workflows/03-image-edit.md)

**预演**：正式生成之前，先用简化模型或草图检查空间、路线、遮挡。→ [26](/workflows/06-previs.md)

**分层合成**：把画面拆成几层分别生成，最后在后期软件里叠起来。→ [34](/cases/06-surreal-perfume.md)

**工具适配**：同一个创意，给不同工具写不同的执行稿。→ [28](/workflows/08-model-adaptation.md)

**OKF**：Open Knowledge Format，这个知识包用的文件组织格式。→ [OKF 封装说明](/references/okf.md)

**skill**：给 AI 助手用的一个文件夹，告诉它什么时候用这本书、怎么用。→ [40](/practice/04-agent-use.md)
