# 门边｜标准视听剧本

版本：v003
用途：虚构教学短场景。
目标时长：约 18 秒，未试读与排练实测。
人物：阿宁、阿川。关系史不明示。
硬约束：只出现两人、门、边桌和钥匙；阿宁主动放钥匙，阿川不接收；阿宁不离开；不解释钥匙权属与提议事项。
执行自由：在不改变人物/物件状态和信息顺序的前提下，允许调整局部观看距离、表演停顿和必要剪辑。门厅光线不承担新增剧情。没有一镜到底硬要求。

## SC001｜内景·门厅·时间未明

预算：约 0–9 秒。
阿宁站在门边，手里握着钥匙。阿川在屋内，两人间有一张边桌。
阿川将一只手掌摊开放在桌上，掌心向上。阿宁看一眼他的手，没有伸手。

**对白 D001｜阿川**：今天就定下来？

声音：保留说话声与动作声；不增加解释性旁白、屏幕文字或有叙事含义的场外事件。

## SC002｜内景·同一门厅·连续

预算：约 9–18 秒；与上一单元处于同一空间和连续时间，因行动阶段变化分为第二段。
阿宁把钥匙放在边桌另一端，与阿川的掌心留出一段距离。

**对白 D002｜阿宁**：明早我再答复你。

阿川收回手。阿宁仍在门边。画面切黑。
声音：钥匙落在桌面的轻响。无旁白，无屏幕文字。对白后的停顿长短留待排练，不额外加入门铃或敲门声。
