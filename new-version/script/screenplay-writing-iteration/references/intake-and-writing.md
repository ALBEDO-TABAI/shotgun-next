# 从需求或原稿进入创作

## 1. 建立最小任务卡，不做审问

先从用户已给材料提取：作品要做什么、给谁在何种条件下看、篇幅/时长、当前材料与版本、核心体验或问题、不可改项、可改范围、事实来源、当前最想解决的一件事。必要时用一段话回述；不要把不知道的项目全部问一遍。

四类输入分别处理：**事实**依来源核验，**要求**依用户权限变更，**假设**允许试验但应可见，**偏好**用于比较不伪装客观定律。“年轻人都讨厌说教”不是自动成为事实的 brief；“不要旁白”是要求；“轻盈”是待翻译的方向。

缺时长而任务可写时，明确暂定一个适合任务的长度或先写无秒数场景，不能声称用户要求了它。缺品牌资料时用中性产品/占位并标记未核实，不补功效。非虚构缺关键材料则先组织可证实内容，未证实部分不写作实际经历。

## 2. 原稿润色先做保留表

在读到全文后提炼：核心问题、当前组织、最有效选择、人物声音、必须保留的情节/信息、允许变动的层级。若只给一段，只对该段负责，不推断未读全稿。

| 用户授权 | 可以做 | 不能静默做 |
|---|---|---|
| 校对 | 错字、标点、显然的重复，保持语言意图 | 重写对白、补人物背景 |
| 润色 | 语序、词汇、可表演性、局部冗余，在已知意图内澄清 | 改行动发起者、改变结局、删必要事实 |
| 局部改写 | 指定场景/功能内调整动作与对白，复核依赖 | 为解决一场戏而重构全片 |
| 结构改稿 | 经授权重排/合并场景、改变信息安排，说明代价 | 宣称原有揭示/情绪完全不受影响 |
| 重新创作 | 以用户保留的约束发展新方案 | 把新构造当原稿真实内容 |

原稿确实有问题不代表可以越权。提出修正建议并说明收益，范围外的方案放“待决”，不混进当前稿。也允许结论是“这句不改更好”。

## 3. 让创意改变关系，而非换形容词

把题材、主题词、暂定命题、具体问题、前提与构想、形式假设分开。例：“回家”是题材；“归属”是主题词；“她要在不道歉的情况下进门吗”才是可写问题之一。

方向未定时提供二至三个**实质不同**的方案，比较观看入口、组织原则、人物关系/材料连接、关键桥段、收益与风险。蓝色改青色不是新方向；同一反转换道具也未必是新结构。

用户已给明确方向或要求直接写时，不先布置选题会。可在结果后简短说明采用的假设，给当前最优完整稿。

## 4. 先骨架后词句，但不强制先开会

叙事作品检查人物在当下想让谁怎样、他知道/误以为什么、选择有哪些、世界如何回应。关系需要双向作用，配角不是主角主题的工具。人物改变可以是行为、关系、认识、条件或观众理解，不必须成长成更好的人。

场景建立“进入—作用—离开”，连接明确因果/时间/对照/类比/论证/形式关系。桥段用具体处境和选择承载，不靠主题台词讲义。世界规则只补实际会影响事件的条目，不写无人使用的百科。

非叙事作品用意象、材质、形状、声音、论点、知识分类建立结构；保留强烈、装饰性、超现实、实验或外放表达的权利。不能因为没有人物目标而强行加一个人进来。

## 5. 联合检查信息与对白

只为关键命题记录：世界状态、人物之前/之后知道什么、观众最早何时可知、由什么画面/声音/文字给出、之后哪件事依赖它。反转之前允许的线索与不能提前暴露的信息分开。

对白按三轮处理：先交流流动与回应；再共同知识、关系和说明任务；最后节奏、选词、停顿与动作。没有上下文依据的潜台词是分析者编出来的；无声不自动含蓄，直说也可以精准。

“消息发送”与“对方收到/理解/答应”分开。旁白、字幕、手机显示、画外声各有归属。角色不能因为观众听到了旁白就拥有那条知识。

## 6. 对抽象感受做表达设计

使用“体验—变化—落点—可见可听—注意/时序—执行”六问，但创作阶段可以从任何一层进入。为“清爽、亲密、紧张”寻找具体的动作、空间、材料或声音，不直接堆标签。

同一体验可以走不同机制。例如清爽来自水流、信息密度变疏、声音间隔或人物动作变轻；选与题目真正有关系的一种，必要时一个辅助通道。写实/克制不是默认答案，欢跃可以真的跳起来，喜剧可以故意放大。

## 7. 写作自检与交付

先修关键事实、任务及锁定要求，再修人物/结构/信息的上游依赖，最后才是语言、局部节奏与提示词措辞。报告有效部分，防止每轮反馈把原本优点磨掉。

给用户的主体是完整剧本。方法卡只在它改变用户判断时出现；未经要求不输出内部长篇推演。可以给简短决策依据与取舍，不展示隐藏推理过程。
