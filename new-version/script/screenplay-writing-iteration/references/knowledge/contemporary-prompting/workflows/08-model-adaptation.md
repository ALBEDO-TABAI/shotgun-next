# 28｜工具适配：同一个创意，不必用同一段提示词

## 先保留共同的创意，再改变输入方式

**共同创意**：一个人听见有人叫自己，回头认出朋友，笑容展开。镜头安静不动。

**文字生图探索**——需要先建立一个瞬间：
> 午后车站，一个年轻人刚认出镜头外的朋友。身体仍朝着站台，脸已经转向声音来的方向，笑意刚开始展开。平视中景，环境明亮，人物旁保留少量人流空间。

**有确定首帧的图生视频**——重点是接续：
> 他听到画面右侧有人叫自己，转头看过去，认出对方后笑了。镜头保持原位。

**多模态参考生成**——还要说清哪张图管什么：
> 人物外观采用已绑定的人物参考，站台布局采用场景参考。本镜从人物侧身站立开始，按上述反应生成。不继承人物参考里的棚拍背景。

**对话式图像编辑**——只改当前帧需要的事：
> 保留人物身份、衣服和站台。只把表情调整到刚认出熟人的自然笑意，头部朝向不变。

这四段不是四种审美，而是**四种任务**。

## 换工具时，查六项能力

1. **输入角色**：首帧、尾帧、身份、风格、运动、布局参考——它分得清吗？
2. **参考限制**：数量、格式、长度、分辨率、怎么引用。
3. **文字偏好**：简洁自然句、分段描述、参数词，还是专用标签？
4. **声音**：能生成吗？能关闭吗？台词和说明能分开输入吗？
5. **时长和镜头**：实际输出多长？多镜头怎么处理？能编辑和续接吗？
6. **负向约束**：有单独的负向栏吗？普通否定推荐吗？冲突时怎么表现？

**这些必须按你实际用的入口确认**，不从教程截图、营销标题、或另一家转售接口推断。

## 官方资料能支持到哪里

Midjourney 的基础指南仍然重视短而清楚的表达。Runway 的图生视频指南区分"图像提供的静态信息"和"提示词提供的运动"。Google 的视频指南允许按主体、动作、环境、机位等维度组织，同时提醒部分高级镜头效果的可靠性会变化。

**这些是工具自己的指导，不是跨模型的统一定律。** Runway Gen-4 建议正向表述，不等于所有生成系统都禁止负向提示。详见[图像工具的官方说法](../references/official-image.md)和[视频工具的官方说法](../references/official-video.md)。

## 否定句怎么处理

创作说明里可以写"不要夸张惊吓"，用来区分目标。

在更偏好正向描述的工具里，可以转成"反应小，先停一下，再自然回头"。

必要的内容边界和安全要求，不能因为"正向提示更好"就被抹掉。用工具支持的实际控制方式。

"固定机位"通常比一串"不摇、不推、不绕"更容易读，但也不能保证工具真的不动。检查结果，必要时改路线。

## 防三个假精确

**设备名**：写"ARRI Alexa"是外观和拍摄的联想，不是已经调用了物理相机。
**秒数**：提示里的秒数是节奏意图，不是逐帧执行的回执。
**角色编号**：编号是指认方式，不是无需上传的永久记忆。

参数真的能在界面或 API 里落实时，才把它当实际配置。没有专用控制时，把效果写成**观众能看到的结果**，并承认仍需要挑选。

## 维护，不追新清单

这本书不提供"哪个模型永远最好"的排名。工具会变，但表演、美术、通感的方法不用随每次发布重写。

只更新这一层：工具接口和第一方来源。已归档的旧指南（比如 Sora2 的提示指南）只用于回顾创作原则，不当作当前产品的能力表。

## 一句话记住

**创意不变，输入随工具变。换工具先查六项能力。设备名、秒数、编号都不是锁。**

## 动手试试

拿一个你熟悉的工具，用上面六项能力逐一回答。哪几项你其实不确定？去官方文档查一下，而不是凭印象。
