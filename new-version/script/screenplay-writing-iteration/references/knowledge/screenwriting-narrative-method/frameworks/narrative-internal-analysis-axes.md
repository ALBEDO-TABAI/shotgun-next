# 要点

## 1. 叙事动力：作品让人持续关心哪个尚未完成的问题？

用功能性描述而非固定故事物种，可以共存：

| 动力类型 | 问题 |
|---|---|
| 目标与后果 | 事情能否做到？做到之后会怎样？ |
| 解释与发现 | 已经发生的事究竟意味着什么？ |
| 关系与承认 | 两个人会不会接近、分离或重新理解彼此？ |
| 选择与代价 | 人物会选择什么，愿意承担什么？ |
| 经验与过程 | 时间、劳动、等待或某种感知正在如何被经历？ |

写成"作品建立了何种期待的线索"，不是"所有观众都会被它吸引"：认知叙事研究强调观众用线索与已有知识推断，推断需要接收者参与。

## 2. 情节结构：哪些线索以什么关系连接？

优先描述可观察的连接方式：单一行动链、多个相互影响的行动链、相对独立的段落、人物群像网络、故事中再讲另一个故事。"故事套故事"须与普通场景切换区分：叙事层级讨论的是讲述行为与被讲述世界的关系。

> 多人物不自动等于多视角；多地点不自动等于多线叙事；插入一段梦境不自动等于倒叙或故事套故事。

## 3. 时间组织：顺序、时长、频率

| 时间维度 | 要检查的问题 | 自拟例子 |
|---|---|---|
| 顺序 | 得知事件的次序与发生次序有什么差异？ | 先展示修好的伞，再回到送修时 |
| 时长 | 哪些过程被展开、压缩、跳过或停留？ | 三天维修压缩为十秒，最后一次交接展开成整场戏 |
| 频率 | 同一事件讲了几次？一次呈现是否概括多次发生？ | 同一次送伞从不同人的记忆中呈现；一个段落概括她每年都来修伞 |

两个误判要防：**重复出现类似动作不一定是重复讲述同一次事件；节奏快慢不只由镜头长短决定。** 可另记"多久发生一次足以改变理解的信息更新"，但不与剪辑频率等同。作品明确提供矛盾时间或不可唯一重建的时间关系时，不强制整理出"正确时间线"。

## 4. 信息组织：发声者、知识限制、主观经验、可靠性分别判断

最易被"第一／第三人称"过度简化的一层。聚焦（Niederhoff）关注叙事信息如何相对人物经验与知识被选择或限制，与"谁在说话"有关但不是同一问题。分别问：

- 谁在发声？有没有旁白？是谁的文字或语言？
- 信息主要受谁的知识限制？观众是否知道人物不知道的事？
- 我们被允许进入怎样的主观经验？只见外在行为，还是记忆、想象、内心语言、感官变形？
- 已提供的信息在哪个方面值得怀疑？事实报告、事件解释、价值评价可靠性不同（Shen）。人物判断错误、人物说谎、作品延迟信息，不能全部叫"不可靠叙事"。

电影额外注意：摄像机角度不等于完整叙述视角；声音、剪辑、字幕、表演都参与信息传递；电影是否必须假设一个类人"叙述者"在理论上有争论（Kuhn & Schmidt）。

## 5. 结尾：结束了哪种问题，又保留了哪种问题？

不只标"开放／封闭"，而是分别检查：任务是否完成、关系是否改变、事实是否解释清楚、价值问题是否得到确定回答。作品可以任务闭合、关系开放；真相明确、道德判断开放。"结局没解释完"不自动是结构缺陷。

# 适用边界 / 不应自动做什么

- 五项彼此相关但不能互相替代；不用其中一项的结论代替另一项。
- 不把形式变化（多人物、多地点、梦境）自动套上术语（多视角、多线、倒叙）。
- 不把"人物错／人物撒谎／作品延迟信息"统称不可靠叙述。
