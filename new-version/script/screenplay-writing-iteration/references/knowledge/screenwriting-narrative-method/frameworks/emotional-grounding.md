# 要点

共情、认同、理解与喜欢可以分离，叙事共情研究也强调接收者差异。[2]

| 检查 | 内容 |
|---|---|
| 1. 情感对象 | 观众为人物处境、自己的记忆或视听形式所触动，可能都成立；不能把所有泪点归为人物塑造成功 |
| 2. 情感依据 | 巨大转折是否有关系、风险和经验支撑？人物流泪不意味着编剧已完成动机工作，铺垫时间长也不保证有效，要找具体联系 |
| 3. 强度与尺度 | 小边界决定可以重要，却未必需要世界突然明亮的高潮；比较轻重不同的音乐与表演，检查是否超出已建立的变化 |
| 4. 余味与即时反应 | 即时喜欢、随后回想、迟来的不适各有意义；可分阶段询问，但一次访谈不是普遍规律 |
| 5. 声音分离的正确用途 | 去掉音乐可定位它承担什么，不证明依赖音乐就是剧本失败；需警惕的是声音独自宣布一项没有行动根据的巨大意义 |

# 适用边界 / 不应自动做什么

- 克制不永远优于煽情：夸张与情绪过量也可以是形式，评价应与整体约定相称。
- 完整作品本来包含声音，“无声测试”是定位工具而不是判决。
