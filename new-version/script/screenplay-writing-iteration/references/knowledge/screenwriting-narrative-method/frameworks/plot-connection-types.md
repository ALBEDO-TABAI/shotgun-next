# 要点

| 连接类型 | 含义 | 例 / 注意 |
|---|---|---|
| 因果 | 前一选择改变后续条件 | 为弥补迟到而撒谎，谎言迫使人物参加原想逃开的聚会。不只是先发生，还改变了可能性。 |
| 促成与限制 | 条件允许或阻碍，但不是动机 | 钥匙允许进入却未必是进入的动机；雨让出行困难却未必直接造成争吵。把所有连接都叫因果，会抹掉条件、理由与偶然的区别。 |
| 人物动机 | 人物因相信某事而行动，即使该信念不真实 | 以当时可用的知识理解行为，不用作者后来揭示的真相替代人物理由。 |
| 对照、相似与等价 | 互不影响的两段通过并置形成意义 | 两个饭桌通过空位和礼仪形成联系。Schmid 的非时间性联系研究提供概念：找不到因果不等于没有结构。 |
| 重复与变奏 | 同一动作再出现时执行者、观看者、结果、节奏是否变化 | 重复可积累意义；变化不必是戏剧性大翻转。 |
| 分类或论证 | 并列的几种处理办法是在比较，不是成长阶段 | 检查分类和比较条件，不强迫每段有目标与障碍。 |

**操作要求**：为场景之间的箭头写一句关系说明——"A 使 B 变得必要""A 使观众误判 B""A 与 B 形成价值对照"。没有说明的连线不能替代分析。

# 适用边界 / 不应自动做什么

- 不把全部连接称为因果；不因缺少因果就判定"没有结构"。
- 动机分析以人物当时的信念为准（信念不是事实）。
