# 要点

观众可以理解人物理由但反对行动，可以为处境难过但不喜欢人物，也可以在保持批判距离时持续关注。共情研究提醒这些概念不能混用，也不存在对所有接收者都保证同一共情效果的形式。

因此"让他更讨喜"不是通用修复：缺的可能是行动依据而不是多一个善举；也可能作品本来追求疏离和审视。

分别提问：

| 问题 | 对应概念 |
|---|---|
| 观众知道他的处境吗？ | 理解（处境） |
| 能描述他的理由吗？ | 理解（理由） |
| 认同做法吗？ | 认同 |
| 愿意继续看吗？ | 持续关注 |
| 产生了什么感受？ | 共情 / 好恶 |

自拟例：家长偷看子女邮件，作品可以让担忧截止日期的动机可理解，却不必因此取消越界后果。让人性复杂可见，不等于让每种做法都被合理化。

# 适用边界 / 不应自动做什么

- 不用一次"善举"修补缺乏行动依据的人物。
- 不假定某种形式对所有观众产生同一共情效果；共情研究是理论综述，不是观众效果实验。
