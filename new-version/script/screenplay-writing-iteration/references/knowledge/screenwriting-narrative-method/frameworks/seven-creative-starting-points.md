# 要点

| 起点 | 需要完成的转化 | 常见误区 |
|---|---|---|
| 1. 人物或关系 | 先观察他不断做什么，保留多个解释（"总是提前到"可以是负责、需要独处适应、或用等待表达不满），再找能在不同场景中支持或反驳各解释的行为 | 先决定人格类型；用一个习惯诊断整个人 |
| 2. 一个时刻 | 追问：为什么这个细节停留在记忆里？暗示什么前后关系？哪些关系来自材料、哪些是新构造？哪一种最需要继续研究？ | 把创作者的工作顺序当成所有人必须遵守的顺序（Gilroy 的讲座可借鉴的是观察尺度与对具体知识的重视） |
| 3. 一种感受 | 寻找感受的可感知条件：一直没收起的工作物、反复被中断的动作、室内外声音没有分界 | 只把情绪词变成滤镜。检验：换人物和场所后内容完全不变，要么补具体条件，要么明确采用抽象感受的形式，而非假装有完整人物故事 |
| 4. 事实与现实矛盾 | 寻找能进入场景的行动条件，也寻找推翻初始判断的反例；用"最后一班车之后工作人员怎样回家"代替"这个行业辛苦吗" | 一个受访者的经历推出全部从业者；出现一次当作普遍模式或既定因果 |
| 5. 物件、工艺或空间 | 先理解物件怎样被握持、维护、交换、舍弃；空间条件本身生成互动（桌子宽于门框要求合作、拆卸或改计划） | 跳过功能、成本和时间条件，直接把保留旧物写成道德优越 |
| 6. 商业 brief | 把事实、要求、假设、审美偏好分开："包装必须出现"是要求，"希望体现专业"是意向，"专业就要实验室镜头"是形式假设，"实验室看起来更酷"是偏好 | 不拆开，导致更换镜头被误认为违背策略 |
| 7. 形式限制 | 检验限制带来了什么（"只拍门外"可能建立距离，也可能把必要行动隐藏得无法理解），说明它如何改变观看 | 把限制本身视为创意成功；主动选择不等于免于评价 |

# 适用边界 / 不应自动做什么

- 起点类型不决定作品优劣，只决定第一步要做的转化。
- 不要把 brief 的意向层与偏好层写成策略层；不要把个人时刻直接升级为人群洞察。
