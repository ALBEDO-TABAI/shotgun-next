# 要点

可能世界理论讨论可能性、义务、价值与知识等模态，也区分作品确立的状态和人物相信、希望、想象的状态；虚构世界是否具有完整未写出的事实存在理论争论。转成实践，用四个问题建立最小世界：

| 维度 | 问题 | 自拟"记忆寄存所"例子 |
|---|---|---|
| 可能性 | 什么能够发生，能力有什么边界 | 可以寄存回忆，但不能改变外部事件 |
| 允许与义务 | 谁被允许做，谁必须同意 | 取回需要本人确认，工作人员不能代选 |
| 价值秩序 | 什么被看重、羞耻或视为代价 | 有人把保留痛苦看成忠诚，也有人不同意 |
| 知识分布 | 谁知道规则和事实 | 来访者不知道此前留下过纸质记录 |

例子是幻想设定，价值在于区分规则，不在于证明某种技术可行。

## 四条检查

1. **规则应当产生生活后果**。从不影响选择的规则只是背景；故事一旦依赖规则解决问题，就要适当建立它。"禁止夜间出门"应影响交通、劳动、约会或照护，而不只是让海报看起来危险。
2. **例外需要范围，不是永久免责**。例外可来自代价、特殊条件、权限或此前误解；结尾突然出现无边界的新能力会抹掉前面的困难。新信息改变的是世界规则、人物知识还是观众理解，三者不同，不应笼统说"反转解释了一切"。
3. **现实题材同样有世界规则**。谁保管备用钥匙、谁可临时来访、工作消息是否要求即时回应、旧物归谁，都决定动作意义。不熟悉的职业、地区或时代要研究具体条件，不能把创作者的生活常识当成全体人物共享的世界事实。
4. **不稳定世界也可以分析**。梦境、荒诞与寓言不必服从日常物理，但可检查变形、重复、语调和信息关系怎样组织观看。不能一律指出不现实就是失败，也不能因为标了荒诞就免除一致性问题。

# 适用边界 / 不应自动做什么

- "世界观"指故事世界的存在条件、规则与价值关系，不等同创作者本人的哲学立场。
- 人物与世界需共同分析，不能分别写完设定再期待自动协调。
