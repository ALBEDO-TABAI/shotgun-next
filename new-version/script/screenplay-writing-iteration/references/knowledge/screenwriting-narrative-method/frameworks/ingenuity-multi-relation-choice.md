# 要点

以下是**观察入口，不是优劣等级**。

| 入口 | 自拟例子 | 前提检查 |
|---|---|---|
| 1. 同一动作完成不同层面 | 父亲让出门内位置，既允许箱子通行，也允许女儿进入 | 动作实际可读，不是评论者任意加义 |
| 2. 事实不变，意义更新 | 旧标签第一次被看作杂乱，后来成为保存证据 | 说清旧解释与新解释各依赖什么；物件出现两次不等于伏笔 |
| 3. 表面事务承载关系 | 修伞、搬桌、归还钥匙承载协商与距离 | 事务需真实影响行动，不是随便拿道具装饰谈话 |
| 4. 通道间保留差异 | 语言承认事实，动作仍犹豫；画面重复，声音变化 | 可互补也可有距离，不必全部重复，也不必刻意互相否定 |
| 5. 观众完成有依据的最后一步 | 不总结“他们终于理解”，而给出与此前不同的回应 | 提供足够条件，同时允许情感解释不统一 |

非时间性的相似、对照与等价也是意义来源，不能只有因果伏笔才算结构。[2]

## 巧妙的代价

- 需要多少背景知识？
- 是否让人物变笨？
- 是否只能在作者解释后才理解？
- 是否造成产品或事实误认？
- 执行能否稳定实现？

这些成本可以值得，但应被说明。

# 适用边界 / 不应自动做什么

- 不把入口当评分项；不因“留白多、需要思考”就判为高级（见 [反向练习](../exercises/08-evaluation.md)）。
