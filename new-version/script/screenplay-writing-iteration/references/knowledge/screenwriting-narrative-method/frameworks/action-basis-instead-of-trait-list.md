# 要点

"独立、温柔、坚强、敏感"是概括，不是具体行动的充分依据。本篇的问题链是：**人物注意什么、相信什么、希望什么、能做什么、选择怎样做、承担什么；别人和世界又怎样回应？**

| 项 | 工作定义 | 检查要点 |
|---|---|---|
| 欲望 / 目标 / 任务 | 欲望＝趋向的状态或关系（被理解）；目标＝较具体结果（拿回钥匙）；任务＝此刻尝试的行动（说服对方结束争论） | 三者可冲突：想保住关系，却当场努力证明自己没错。这种张力比"她很矛盾"更可写。短暂配角只需职业判断、当前任务与拒绝理由 |
| 信念不是事实 | 人物相信"拒绝一次就会失去认可"是人物判断，作品可支持、部分支持或反驳 | 关键是信念怎样进入行动；人物不得使用尚未获得的信息（观众知道危险≠人物知道） |
| 策略比标签更能生成场景 | "讨好"可细化为先答应再问条件、用长解释代替拒绝、拒绝后立刻给替代方案、只对某些对象如此 | 策略应受反馈影响：对方误解是否改说法，拒绝是否换条件，场合变化是否转为事务性语言 |
| 能力、资源和机会 | 不行动未必因为不勇敢，可能缺信息、时间、钱、权限、交通或同时要照顾别的任务 | 先列实际可行选项再评价选择；世界没提供机会，就不能用"终于愿意努力"解释全部改变 |
| 情绪与行为 | 愤怒不总是提高音量，悲伤不总是流泪 | 观察情绪如何改变注意、判断与策略；给演员行动任务（"努力让对方听完这句话"）而非锁定表情 |
| 代价与分量 | 代价可以是时间、承诺、物件、体面、关系或不可兼得之物，不必生死攸关 | "我明早看"只有在建立了原先应对方式与当前条件后才有分量，宏大配乐不能替代依据 |

# 适用边界 / 不应自动做什么

- 不必给每个短暂配角都设终极欲望；长篇主要人物则要检查愿望在不同阶段的变化。
- 文学化的动作描述不是一律禁止，关键是执行者能否理解其作用。
- 模型用于寻找依据与漏洞，不把人物变成可准确预测的机器。
