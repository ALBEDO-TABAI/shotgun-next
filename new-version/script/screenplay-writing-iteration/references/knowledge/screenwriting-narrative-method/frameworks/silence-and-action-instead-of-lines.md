# 要点

Straughan 的讲座强调说出与未说出、语言、图像和声音之间的关系。由此看对白，不只在纸上找句子，而要看它怎样与其他通道合作。

## 1. 沉默需要正在等待的条件

- 回答"你也觉得是我的错？"之前的沉默有未完成回应；独自坐在房间里的沉默主要建立状态与时间。两者不同。
- 沉默可能是不愿说、不能说、在想、没听见或无须再说。**作品支持到哪一步，就分析到哪一步**；不把所有静默都解释成创伤或压抑。

## 2. 动作可以确定事实，保留原因

把第二只碗放回柜子可以明确不再为两人准备饭，却不能单独证明已放下感情。交接时写必须看清的动作，不只写抽象心理结论。

## 3. 语言和动作可以有距离

- 口中说"不急"，手已收好东西：可能是礼貌、矛盾或隐瞒，不自动等于虚伪。应查当前关系和后续回应。
- 语言足够时，动作不必重复同一解释。"明早接你"后晃车钥匙可能有用也可能多余，取决于本段任务。

## 4. 物件不能替人物承担所有情绪

钥匙、杯子、旧照片容易被当作万能情感符号。先让物件具有真实使用关系，再讨论它如何产生额外意义。没有关系依据，再精美的特写也可能只是一件物品。

# 适用边界 / 不应自动做什么

- 不崇拜省字：删词后必要信息若无动作承接，观众会看不懂。
- 不强迫演员用固定动作"证明"心理。
