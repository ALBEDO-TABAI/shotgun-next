# 要点

- **可用的出口**：行动完成、决定作出、问题刚被提出、认知刚改变、某种体验达到阶段。不同出口会把不同任务交给下一段。
- **区分两种"没说完"**：有意留下问题 vs. 必要过程被截断。若下一场依赖观众知道桌子是否成功搬走，就要确认省略是否仍允许推断。
- **试着挪动结束点**：提前或延后一点结束，比较获得或失去什么。多停留不必总新增信息，也可以保留时间与感受——但这应是可讨论的选择，而非"高级镜头必须慢"的规则。
- **分层描述闭合**：结尾可以任务闭合、关系开放、价值未定。说明具体闭合哪一层，比简单贴"开放式结尾"更有用。

# 适用边界 / 不应自动做什么

- 不默认每场以金句或反转收尾。
- 不把"停留更久"当作自动更高级。
