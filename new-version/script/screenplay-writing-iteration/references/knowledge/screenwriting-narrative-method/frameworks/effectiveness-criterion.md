# 要点

一个完整的“有效”陈述：**对哪些人，在什么条件下，哪项选择支持哪种结果；有什么证据，还有什么其他解释。**

| 检查 | 含义 | 反例 / 提醒 |
|---|---|---|
| 1. 结构存在 ≠ 接收发生 | 剧本有铺垫与回收只证明两处对应存在；观众察觉并在意需要观看证据 | 没有实测可以说“提供重新理解的依据”，不要说“一定感动” |
| 2. 经济性 ≠ 最短 | 一起考虑篇幅、制作成本、理解负担、误读修复 | 直接说“明天下午取”可能比复杂时间蒙太奇更恰当；若等待是主题，展开过程不是低效 |
| 3. 艺术体验不必服从单一行为目标 | 观察片段可让熟悉生活重新可注意，不一定说服观众认同一句命题 | 仍可分析持续、重复、声画关系，但不强造商业式转化目标 |
| 4. 功能多 ≠ 更好 | 各功能是否兼容比数量重要 | 一个道具兼具剧情、人物、品牌、创伤、反转，可能过于算计；不被主线耗尽的生活质感也有价值 |
| 5. 反应快 ≠ 影响深 | 即时刺激、延迟回想、信息记忆、实际行为是不同结果 | 不能由“首看喜欢”推导所有层面成功，也不必每个项目都做长期研究 |

# 适用边界 / 不应自动做什么

- 结果类型之间不构成必然顺序，不能互相代替。
- 测试关注什么由问题决定，而不是默认测全部。
