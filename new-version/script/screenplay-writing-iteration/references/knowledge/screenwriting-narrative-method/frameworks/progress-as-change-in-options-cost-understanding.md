# 要点

在目标导向叙事中，进度可从三处检查，它们不必一起上升，也不必持续加码：

| 检查项 | 问题 |
|---|---|
| 可用选项 | 人物能做的事是否改变？ |
| 行动代价 | 做这件事的代价是否变化？ |
| 对结果的理解 | 人物或观众对结果的认识是否更新？ |

- 增加事故可能只是打断；一条新信息让原目标不再值得追求，即使没人跑动，也可能显著推进。
- 例：女儿以为母亲不愿搬家，看到她为桌腿做拆卸标记后才意识到她想保留桌子而非拖延；女儿的任务从催促清空变为共同搬运。无需增加争吵来证明关系变化。

## 整合后果也是进度

人物需要停下来理解刚发生的事，观众也可能需要时间重新排列信息。若每场都增加新目标而不给后果落地，整体可能很忙却缺分量。

## 任务成功不等于所有层面都向前

人物得到想要的东西可能损害关系；真相查清可能使价值判断更难。写进度时说明是**哪一层**变化，不把所有更新都当成"更好"。

# 适用边界 / 不应自动做什么

- 仅适用于目标导向段落；非叙事或诗性段落改用形式变化描述（见 [进入—作用—离开模型](scene-entry-process-exit-model.md) 的边界）。
- 不把"事件更多"当作"更推进"。
