# 要点

"自由""爱""可靠"划出意义领域，却不决定选谁、发生什么、按什么顺序呈现、哪种结论不能轻易推出。创作起点需要经过六个层面，各回答不同的问题：

| 层面 | 回答什么 | 自拟示例 | 仍待解决 |
|---|---|---|---|
| 1. 题材 | 接近哪个生活领域（照护、劳动、迁居、消费、亲密关系） | 家庭照护 | 接近哪个具体处境 |
| 2. 主题词 | 抽象关注，便于检索材料 | 尊重 | 尊重体现为哪种行动差异 |
| 3. 暂定命题 | 一个可被材料挑战的判断 | 关心有时意味着克制干预 | 何时成立、何时不成立 |
| 4. 戏剧或体验问题 | 具体对象、行动与代价 | 他会不会帮她搬走最后一箱东西 | 选择为何困难 |
| 5. 前提与构想 | 使经历成为可能的条件组合，及其可能发展 | 她只回来一天，搬完后将很少再回 | 哪些事实要让观众知道 |
| 6. 形式假设 | 观众怎样进入问题 | 不回顾争吵，通过共同搬运展开 | 行为是否足够承载关系 |

补充说明：
- 同一题材可有完全不同的角度（三部拍夜班的作品分别关注工作过程、个人时间、城市声音）。
- 主题词不能直接充当人物行为的充分解释："因为主题是自由，所以人物必须离开"是过早给出答案。
- "暂定"意味着材料可以让命题变得更有条件，而不是把所有人物写成支持口号的证人。
- 戏剧问题不必是"能否成功"：注意力如何改变、两个人如何开始共同沉默、空间消失后哪些动作习惯留下，都可以是体验问题。经验性叙事研究提供了重视时间、身体与经历的路径，但这里只是借用理论入口，不是新的唯一叙事定义。
- 前提（如"即将离开城市的修伞人收到一把多年前修过的伞"）有角色、时点、物件和潜在关系，但不等于故事已成立；构想才进一步提出是谁送来、修理是任务还是借口。
- 形式假设决定观看组织：观众先知道送伞者等待修伞人认出，与始终跟着修伞人共同发现，是不同方案；画面色调相同，观看组织仍可完全不同。

# 适用边界 / 不应自动做什么

- 这些是工作定义，团队可以调整，但同一项目内必须保持一致；不能一处用"主题"指题材，一处指结论，再声称所有方案都没有主题。
- 不要求每个作品预先拥有唯一答案，也不把商业 brief 与作者私人表达混为一谈。
