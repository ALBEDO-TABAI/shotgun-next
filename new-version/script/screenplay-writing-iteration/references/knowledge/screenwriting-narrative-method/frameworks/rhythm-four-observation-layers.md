# 要点

以下是本包的**工作性划分**，不是四个可精确测量的人脑时钟。

| 层面 | 观察对象 |
|---|---|
| 事件节奏 | 行动及后果更新 |
| 认知节奏 | 疑问、预期和解释更新 |
| 情绪节奏 | 设计所支持的感受变化；**实际效果另需观看证据** |
| 视听节奏 | 镜头、动作、运动、声音节拍与停顿 |

缓慢动作可以伴随快速理解更新，快剪也可能始终重复同一判断。**诊断"慢"必须指出哪一层。**

## 电影观看研究提供的有限支持

- Magliano 与 Zacks 围绕《红气球》及大学样本的既有数据，分析连续性剪辑与事件分段，发现动作中断与事件边界的联系比单纯时空变化更突出。研究对象是**分段判断**，不是哪个剪法更好看。
- 可借此区分剪切点与事件边界；不能推出动作连续就一定流畅，也不能把特定影片结论变成所有广告的节奏规则。

## 语料平均不能变成最佳创作处方

- Cutting 分析英语流行电影的形式分布，其样本选择、时长处理和结构假设都有范围。统计模式是描述，不是"每部作品应在某一百分比处转折"的证明。
- 可取的做法是借鉴其**分层记录方法**检查自身作品的变化分布；不凭平均曲线制造"每五秒必须一个爆点"的伪科学要求。

# 适用边界 / 不应自动做什么

- 情绪层只记录设计假设或实际反馈，不记为已成立的效果。
- 不由语料平均推导最佳转折秒数；不由事件分段研究推导"所有快剪更有效"（见 [来源使用总原则](../principles/source-use-and-evidence-boundaries.md)）。
