# 要点

## 先确定证据对象

不同材料提供不同证据，不能互相代替：

| 材料 | 能证明什么 | 不能证明什么 |
|---|---|---|
| 故事设想 | 意图、任务 | 表演是否成立 |
| 剧本文本 | 线索存在 | 镜头里是否可见 |
| 试拍 / 剪辑版本 | 机制是否在成片中运作 | 每类观众的实际反应 |
| 真实观看 | 特定参与者发生了什么 | 普遍反应规律 |

因此评价先补主语：“这份剧本尚未建立……”“这个版本在此处……”“本次参与者中……”“我的首次观看感受是……”，不要全部缩成“观众觉得”。

## 五类陈述

| 陈述类型 | 说什么 | 需要什么证据 |
|---|---|---|
| 描述 | 材料里有什么 | 可回看的材料 |
| 解释 | 这些选择可能怎样运作 | 形式分析与前后文 |
| 意图判断 | 创作者为什么这样选 | 可靠创作材料 |
| 效果判断 | 特定观看者实际发生什么 | 相应接收证据 |
| 规范判断 | 在某目标或价值标准下值得怎样取舍 | 明确的目标与责任方 |

从“蓝色画面”到“导演想表现孤独”再到“观众被打动”，跨越了多种陈述，不能只靠一句流畅评价完成。

# 适用边界 / 不应自动做什么

- “好看”“感人”“很高级”可以是诚实反应，但不足以指导修改；统计冲突、台词和反转也不能自动给出艺术判断。
- 本篇的操作定义不是这些词在全部学术传统中的唯一含义。
