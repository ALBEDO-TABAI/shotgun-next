# 要点

叙事时间研究（Scheffel 等）以顺序、时长、频率区分事件发生与呈现的关系，可把倒叙、压缩、重复等操作分开检查。

| 维度 | 问什么 | 作用示例 |
|---|---|---|
| 顺序 | 观众得知的次序与事件发生次序怎样不同 | 提前结局把结果问题转为过程问题；延迟往事修正人物理解 |
| 时长 | 哪里展开、哪里概括或跳过 | 一段等待可以很长，数年生活可以很短；关键是作品要求观众在哪里停留 |
| 频率 | 一件事发生几次、被讲几次 | 一场见面被三个视角重述，与每年重复相似见面，是不同结构 |

## 省略不一定是缺场

装箱直接切到空房，可合理省略可推知的搬运；但若关系变化恰恰发生在共同搬运，删掉过程就只剩未经经历的结果。

## 换序需要重查信息，不只是时间线

同一段行动移到秘密揭示之后，意义可能完全不同。修改后要重看**观众当时知道什么**，而不是确认事件仍能拼回原顺序就算完成。

# 适用边界 / 不应自动做什么

- 三个维度分别检查，不合并为"时间线是否通顺"。
- 不把"能推知"等同"不需要经历"。
