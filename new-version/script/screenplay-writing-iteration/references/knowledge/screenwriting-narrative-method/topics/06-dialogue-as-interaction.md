# 本篇回答什么问题

**谁对谁，在什么共同处境中，试图通过说、问、改口、回避或不回应，改变什么？** 研究对白、沉默、动作、转述、旁白和手机文字的配合；不把对白质量等同金句数量、字数多少或口语相似程度。适用于写实，也适用于文学化、舞台化、诗性或荒诞表达。

# 核心主张

1. 分析先字面、再行动、再关系、最后作品作用，不从主题倒推每句都藏深意。
2. 潜台词需要可用语境、可理解关联和后续接收；间接表达、隐瞒欺骗、意义开放是三种不同状态。
3. 听见、理解、同意、照做是四件事；消息发出不等于交流完成；人物共同知识不等于观众共同知识。
4. 对话是策略随反馈变化：先修互动，再修词句；合作也能推进。
5. 人物声音来自选择（注意对象、组织方式、不确定性、关系风险、回避对象），不是配置口头禅。
6. 不禁止说明性对白，而是解决为什么此刻需要它；隐藏得深不等于好。
7. 删掉台词，意义不会自动进入目光：沉默需要等待条件，动作确定事实但保留原因，物件先有使用关系。
8. 旁白、字幕、手机文字不是次等对白，各有事件状态与信息关系。

# 来源与边界

具名理论用于区分概念；互动流程、分析表与对白样例是本包的综合和自拟，不是实际会话研究结果；案例未做实际受众验证。

- [H. P. Grice：Logic and Conversation](../references/grice-logic-and-conversation-1975.md) - 会话含义与合作原则；不将合作原则理解为道德要求
- [Clark、Brennan：Grounding in Communication](../references/clark-brennan-grounding-1991.md) - 共同理解、反馈与媒介约束；向创作交接迁移是本包综合
- [John August：How to write dialogue](../references/august-how-to-write-dialogue.md) - 个人实践方法，不是硬性规则
- [Peter Straughan / BAFTA 讲座](../references/straughan-bafta-lecture-2012.md) - 创作者立场，不是效果实验
- [Brian McHale：Speech Representation](../references/mchale-speech-representation.md) - 话语呈现方式；迁移到电影需额外条件

总的来源使用原则见 [来源使用与证据边界](../principles/source-use-and-evidence-boundaries.md)。
