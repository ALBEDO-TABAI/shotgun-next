# 本篇回答什么问题

"你说的'故事形式'到底在说哪一层？"——不是补更多"故事类型"的名字，而是建立一套能区分不同命名依据、不同分析尺度、不同证据强度的模型，把"给作品贴标签"变成"建立有证据的形式档案"。

本篇由用户提供，与上传文件一致；后续 02–12 篇扩展的是原体系第②–⑫点，不改写本篇内部小节。本篇脚注是历史引用占位符，本包不冒名重建其来源。

# 核心主张

1. 作品**为了什么被使用**与作品内部**怎样组织内容**不是同一个问题；商业用途不推出论证形式。
2. 故事世界、情节组织、叙述过程是三个对象；术语要带"所属理论 + 本次定义 + 与相邻概念区别"存储。
3. "有故事""有叙事性""故事很好"分开；事件性取决于情境而非动作规模。
4. 先判断主导组织原则（叙事／分类／修辞论证／联想／抽象形式），整体与局部分别记录；用"改变连接看什么被破坏"定位结构依赖。
5. 类型看元素、关系与使用惯例三层，保留"类型命名来源"字段；题材、核心问题、表达命题分开。
6. 事实性约定（自我声明／材料制作／独立核验）、现实感（表达惯例）、世界规则（能发生／被允许／被看重／谁知道）拆开。
7. 叙事内部再拆动力、结构、时间（顺序／时长／频率）、信息（发声／知识限制／主观经验／可靠性）、结尾。
8. 非因果也能组织作品；非线性与非因果分开；媒介通道分工要记"信息载体"和"通道关系"；风格／语调／情绪氛围／实际反应用不同操作定义。
