# 要点

## 三种陈述分开
作者理论区分现实创作者与文本解释中不同的作者概念：由作品读出某种意味，不等于知道现实作者的心理目的。

| 陈述 | 例句 | 需要什么证据 |
|---|---|---|
| 观察 | "这段出现了……" | 作品本身 |
| 机制假设 | "这样的安排可能使……" | 分析推理 |
| 意图自述 | "某创作者在访谈中说……" | 真实访谈或制作记录，**不能**由前两种自动推导 |

## 1. 导演、演员、摄影与剪辑不只是下游包装
- 同一句"往里放"，语气、身体位置、女儿是否先误拉箱子、镜头是否展示门内空间、音乐是否提前宣布温柔，都改变关系的可读性。
- 保护编剧意图不意味着消除其他人的创作。更可用的讨论：改动后，原来需要成立的关系还在吗？若不在，新方案是否明确选择了另一种更适合的关系？
- August 与 Mazin 关于导演合作的对谈强调意图沟通、制作约束与可操作反馈——采用的是实践启发，不是要求编剧拥有所有执行决定。

## 2. 交接应允许执行者回述
接收者能说明："我理解这里不是拒绝而是邀请；我准备通过某个动作完成；某原动作因空间条件要改；我会保留某个信息顺序。"
- 比一句"收到"更能发现双方是否在谈同一件事。
- 回述不是表演忠诚，也不是每个普通镜头都要复杂审批，只用于**对意义有影响的关键交接**。

## 3. 不把"大家同意了"误当成观众证据
- 制作会议的共同理解证明团队当前对方案的认识，不能证明首看观众获得同一解释。
- 越熟悉素材的人越可能依赖未被实际表达的背景，因此**内部共识与外部首看应分别记录**。

# 适用边界 / 不应自动做什么
- 不得从作品效果反推创作者心理并写成事实。
- 不要求编剧控制所有部门，也不要求所有人同意一种艺术解释。
