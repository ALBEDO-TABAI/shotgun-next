# 五种修改

| 修改 | 可能后果 | 正确处理 |
|---|---|---|
| 1. 为快节奏删掉期限 | 她可能被读成忽视紧急请求 | 先检查是否有其他依据，不直接增加一段同事解释；若真实场景无期限约束，应改变核心问题 |
| 2. 只显示最终短句，不显示草稿 | 安排仍清楚，但不再充分建立"策略从解释转为直接" | 片子可能仍成立，只是人物变化范围需要缩小 |
| 3. 不显示发送，把手机放下 | 可能变成尚未回应的暂放 | 可作为另一种选择，但**不能沿用**"已明确安排"的分析、字幕与验收 |
| 4. 使用产品之后才删除道歉 | 增加"产品带来内在转变"的归因 | 需比较顺序和声音，不只在文案里加免责声明 |
| 5. 结尾加上对方赞赏 | "你终于学会爱自己了"让对方替作者评述，关系变奇怪；"好，明早见"确认安排被接收，但改变闭合与注意重点 | 若加入，要重新比较结构 |

# 原则

修改不是绝对禁止。每一项都需说明：**新版本选了什么**，以及**旧版本哪些结论不再适用**。
