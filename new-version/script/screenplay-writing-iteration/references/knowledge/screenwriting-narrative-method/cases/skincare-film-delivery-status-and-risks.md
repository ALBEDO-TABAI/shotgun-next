文本完成和生产通过是不同状态。

# 哪些替代仍是这条片，哪些已经换了问题

| 仍是执行探索 | 已经换了前提 |
|---|---|
| 手机放到桌边而非洗手台 | 改成必须立刻处理的工作（责任结构改变） |
| 换另一种已核验的护理动作 | 对方是需要帮助的家人（关系风险不同） |
| 改变拍摄角度 | 发完消息转身彻底离开（不再是恢复被中断的动作） |

判断标准：核心关系是否仍成立。换前提不是换道具。

# 三组候选比较（均未验证）

**三个可比较的回复**（都短，但不是同义润色；界面、人物反应和结尾意义要随之复查）：

| 回复 | 含义变化 |
|---|---|
| "我明早看。" | 明确安排开始处理 |
| "明早给你结果。" | 增加完成承诺，需要真实任务支持 |
| "有空再说吧。" | 降低时间明确性，可能变成回避 |

**两个声音候选**：候选一发送后先保留生活声音再轻微进入旋律，尝试让行为本身成为重心；候选二从开始就有稳定音乐，消息只短暂打断，可能减少胜利式转调，但也可能削弱选择的可察觉性。应在实际视听草稿中比较，不靠文字说明确定哪版更克制。

**品牌介入的三个时间位置**：开头建立"产品已属于生活"可减少外来解决方案感；中段特写可能抢走选择过程的注意；结尾落版署名清楚但可能缺少独特联系。不规定开头必好或结尾必差，要结合镜头强度、已有品牌认知和任务检查。

# 这条片的最小完成证明

| 层 | 只能证明 |
|---|---|
| 文本 | 完整候选与必要关系已写出 |
| 原型 | 界面和动作能在时间内清楚出现 |
| 成片 | 前后关系未被执行改变 |
| 效果 | 需要真实观看反馈 |

任何一层未做，保留状态即可。不能因为推演得很细，就把它当成实际制作或传播结果。
