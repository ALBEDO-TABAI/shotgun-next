# topic-10
* [护肤短片案例 · 十五秒版与平面版：缩小任务，不硬塞完整 45 秒](skincare-film-15s-and-print.md) - 15 秒版把任务缩小为"清楚表现一次回应安排与护理继续"，平面版只保留一个关系瞬间；两者各自验证，不继承长版结论，也不假定观众看过长版。
* [护肤短片案例 · 45 秒时间草案：八段预算，不是节奏处方](skincare-film-45s-time-draft.md) - 把原对话五个时段展开为八段 45 秒时间预算，每段标明画面动作、声音文字与当前作用，并声明输入速度、阅读速度、镜头停留和产品用法均未实测。
* [护肤短片案例 · 五种对抗性修改及其后果](skincare-film-adversarial-modifications.md) - 逐一推演删期限、只显示最终短句、不显示发送、产品后才删道歉、结尾加对方赞赏五种修改会改变什么结论，说明修改不是禁止，但每项都要写明新版本选了什么、旧结论哪些失效。
* [护肤短片案例 · 品牌独特性尚未解决：案例完整度不能掩盖的缺口](skincare-film-brand-uniqueness-gap.md) - 承认当前方案只在品类层面成立、替换包装后多数叙事仍可能成立，说明真实品牌资料可能怎样进入，并区分情绪品牌片与产品功能说明两类任务不能合并宣称。
* [护肤短片案例 · 拆解 brief 与缩小命题：给定、假设、未知、非目标](skincare-film-brief-decomposition.md) - 把"留一点时间给自己"的抽象情绪拆成给定任务、工作假设、待补材料与非目标四栏，并诊断"忙碌—自白—产品—自信笑容"初稿的四条风险，最终缩小为一个可被经历的具体问题。
* [护肤短片案例 · 当前交付状态、风险与「哪些替代仍是这条片」](skincare-film-delivery-status-and-risks.md) - 用状态表列出文本、产品事实、可执行性、声画、短版、观众效果与合规八项的当前状态与下一步；区分执行探索与换前提，比较三个回复、两个声音候选、三个品牌介入位置，并给出各层的最小完成证明。
* [护肤短片案例 · 表演、摄影、美术、声音、剪辑与文案怎样共同承担](skincare-film-department-division.md) - 逐部门列出这条片的具体职责与禁区：表演只表现选择而非症状，摄影保住指称，界面区分草稿与已发送，声音不放胜利音乐，剪辑改序要重查因果，文案不超出已建立的事实。
* [护肤短片案例 · 保护的不是镜头列表，而是五个关键关系](skincare-film-five-protected-relations.md) - 列出这条片必须在任何执行方案中保住的五个关系，给出一条决定记录（SKIN-INFO-03）的 YAML 示例，并说明只追踪会影响多人理解与执行的关键点。
* [护肤短片案例 · 三种形式比较：单一微事件、多夜变奏、诗性声画](skincare-film-form-comparison.md) - 在写场景稿前先比较三条形式路线各自的优势假设与风险，选择"单一微事件"用于完整推演，并声明该选择不是普遍最优。
* [护肤短片案例 · 信息安排表：必须清楚、可以开放、本版不需要](skincare-film-information-plan.md) - 以一张信息表列出这条 45 秒片必须清楚建立、可以开放和本版不需要的信息及其候选载体，并说明为何新增"期限信息"以及它带来的读取负担。
* [护肤短片案例 · 完整场景稿候选 A-01（内景／晚间／洗手台附近）](skincare-film-scene-script-a01.md) - 45 秒护肤短片的完整场景稿候选 A-01，含手机界面文字、动作连续性、品牌落版候选文案，以及"为何暂不写旁白""为何不加对方回复"的两条设计说明。
* [护肤短片案例 · 五阶段验证计划：先验证是否读到，再讨论是否喜欢](skincare-film-validation-plan.md) - 从材料核实、低成本时间草稿、不提示主题的首看、分开记录到单变量比较的五阶段测试设计，并说明假设性反馈只能用作模拟诊断，不填样本数与百分比。
