# 检查项

以下五项是本包的实用检查，不是已验证的固定心理阶段模型。

| # | 检查 | 问题 |
|---|---|---|
| 1 | 存在 | 当前版本真的保留了道具、声音或字句吗？ |
| 2 | 可察觉 | 画幅、清晰度、音量与停留时间允许辨认吗？ |
| 3 | 可能被注意 | 同一时刻有没有更强任务争抢？需实际查看，不能凭作者熟悉度判断 |
| 4 | 可被理解 | 看见后知道它与当前问题有什么关系吗？ |
| 5 | 可被后续唤回 | 后文是否提供重新联系，还是默认出现一次就永远有效？ |

# 三条补充

- **重复不一定冗余**：先建立物件、再改变使用、最后产生后果，承担的是不同任务。可以重复关系而非逐字复述；原样重复既有解释则需要说明新增作用。
- **强调不等于揭底**：可以让观众记住木柄重要，而不解释为何重要。分层建立比把整个线索藏到几乎不可见更可控。
- **注意分配属于整个段落**：关键对白、小字屏幕与细微动作同时出现，可能需要错开、换载体或减任务。不要编造"每秒最多处理几条信息"的科学门槛。

# 适用边界

- 每一项都要对实际版本（含裁切、字幕、音量）检查，写了不等于生效。
