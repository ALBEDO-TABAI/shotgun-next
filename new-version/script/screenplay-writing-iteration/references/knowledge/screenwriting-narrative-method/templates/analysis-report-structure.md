# 写作规则
- 摘要只放最重要的发现；报告长度不等于分析深度。只有一个关键问题就只给一个，不为显得全面制造十项批评。
- 用"当前版本在此处缺少……"替代"编剧没有能力……"。对作品作有依据评价，不从文本推测现实创作者的智力、人格或经历。

# Examples：反馈句式

> 在某位置，作品呈现了某事实。它支持某种理解，但还不足以支持某结论。另一解释是……。如果目标确实为……，可比较某项最小修改；代价为……；验证方式为……。

这个格式帮助清楚，不要求每条意见机械同句式。分析是说明关系，不是填满固定语法。
