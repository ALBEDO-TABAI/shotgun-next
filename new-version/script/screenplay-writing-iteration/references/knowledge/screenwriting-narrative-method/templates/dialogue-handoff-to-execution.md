# 输入依赖（本篇不能自行更改）

| 项目 | 来自 |
|---|---|
| 人物为何采用某策略 | 第四篇 人物模型 |
| 场景要经历什么 | 第五篇 场景设计 |
| 什么时候交代什么 | 第七篇 信息设计 |

本篇不能自行更改人物已知信息或场景目标。

# 交接清单

```markdown
- 场景任务与进入/离开状态：
- 关键轮次（每轮：话语行动 / 期望回应 / 实际回应 / 观众须获得）：
- 必须看清的动作（确定事实的动作，不写心理结论）：
- 必要信息及其载体（对白 / 动作 / 字幕 / 前场）：
- 保护项：行动关系、指称、许可、承诺的时间与范围
- 可变项：措辞、重音、停顿、视线、次要动作
- 改词红线：改变承诺（"明天下午"→"很快"）、改变方案（"这个别换"→"都别换"）须回到条件检查
- 试读问题：
- 验证状态：自拟稿 / 已试读 / 已排练
```

# 原则

- 保护行动关系而非固定每个停顿。
- 改词可以接受，但把"明天下午"改为"很快"会改变承诺，把"这个别换"改为"都别换"会改变方案；这类变化必须回到相关条件检查。

> 对白的扎实，不是作者藏了多少答案，而是人物此刻确实需要这样相互作用，观众也有依据从作用过程中形成理解。
