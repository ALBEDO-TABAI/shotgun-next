# 操作

| 轮次 | 任务 | 不做什么 |
|---|---|---|
| 第一轮：交流流动 | 人物想让对方怎样回应，实际得到了什么，下一步如何改变 | 不追求漂亮 |
| 第二轮：信息与关系 | 双方共同知道什么，观众还缺什么，哪句是人物在说、哪句只是作者急着说明 | 不用润色掩盖任务不足 |
| 第三轮：语言与声画 | 词汇、节奏、改口、停顿、动作、声音和文字如何配合 | 此时才做精细润色 |

# 试读后回到问题层

演员读不顺，可能是措辞，也可能是人物根本没有行动目标；不要只要求"再生活一点"。

# 改写也可以选择不改

风格化对白被误当成不自然时，应先确认作品是否有稳定语言约定，而非一律口语化。

# 适用边界 / 不应自动做什么

- 不用词句打磨掩盖场景任务不足。
- 本篇不能自行更改人物已知信息或场景目标；这两项分别属于人物层与场景层。
