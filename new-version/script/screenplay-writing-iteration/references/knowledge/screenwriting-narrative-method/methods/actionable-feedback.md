# 步骤

1. **位置与材料**：指出版本、场次、片段。
2. **可见事实**：材料里实际有什么。
3. **作用假设**：这些材料可能被怎样读。
4. **其他解释或条件**：什么前提下另一种读法成立。
5. **最小修改及验证**：针对真实问题的小范围改动，附代价与验证方式。

## 自拟示例

> 当前结尾没有显示女儿能否拒绝钥匙，因此父亲的动作既可读成许可，也可读成继续代她决定。若目标是协商，可让女儿先提出来访条件，再由父亲接受。代价是增加对白、减少动作留白，应比较试演。

# 三条规则

| 规则 | 说明 |
|---|---|
| 问题不等于方案 | “我不理解她为什么留下”是体验报告；“必须加童年回忆”是解决方案。前者可能准确，后者未必必要，可用更小线索或调整任务解决 |
| 允许不修改 | 合理的复杂性不是每次都需消除；某意见可能是审美偏好而非错误，可记录理由暂不执行。不是收到一条意见就必加一个解释镜头 |
| 说明值得保护的部分 | 只列问题可能导致修稿者删掉最有效的关系；要明确什么机制已成立、依赖什么、哪些改动会损坏它 |

# 适用边界 / 不应自动做什么

- 不把体验报告直接翻译成改法；不把偏好包装成错误。
