# 要点

## 两步

| 步骤 | 问题 |
|---|---|
| 第一步：形式描述 | 这部作品采用什么关系来组织内容？证据是什么？ |
| 第二步：价值评价 | 在已知任务或可辨认的艺术追求下，这些关系完成了什么，又付出了什么代价？ |

## 按组织原则的对应检查方向

| 作品组织 | 检查方向 |
|---|---|
| 因果叙事 | 行动依据、后果连接与信息安排 |
| 分类性作品 | 分类依据、层次与遗漏 |
| 论证性作品 | 主张、支持材料与推理之间的关系 |
| 联想性作品 | 对应、变化与解释空间 |
| 抽象形式作品 | 形式规律、变奏、节奏及整体发展 |

这些是对应检查方向，**不是给各类作品制定统一优劣榜**。

## 两个保留

- 作品可能**有意让某个期待落空**，借此改变观看方式。但"有意"不是免检理由：分析仍应指出期待怎样建立、怎样被改变、改变之后产生了什么新的组织依据。
- 删减、换序、提前揭示等**反事实测试只能帮助辨认依赖关系**，不能单独证明观众效果，也不能证明作者的真实构想。

# 适用边界 / 不应自动做什么

- 不在形式描述完成前评价；不用一套标准评所有组织形式。
- 不以"作者有意"跳过分析。
- 不把反事实测试结果写成效果证明或意图证明。
