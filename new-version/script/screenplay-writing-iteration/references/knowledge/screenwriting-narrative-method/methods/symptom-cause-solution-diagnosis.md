# 要点

| 层 | 示例 | 说明 |
|---|---|---|
| 症状报告 | "读不懂为什么留下" | 可以成立 |
| 原因假设 | "缺少改变选择的依据" | 需要证据支持 |
| 方案 | "增加童年闪回" | 症状成立，方案仍可能过度 |

连贯研究提醒：表面衔接与语境中的意义关系不同。所以加连接词、加反应特写、加旁白，不保证解决真正的因果与动机问题。

## 先查结构依赖，再查局部装饰
- 若"请求是否紧急"不清，会连带影响人物是否负责、对白是否自然、结尾是否可信——先修条件可能同时解决多个问题。
- 若只是字幕遮挡了关键按钮，就不必重写人物弧。**修改范围要与证据相称。**

## 优先级不用艺术总分
按后果与依赖排序：
1. 重要事实错误；
2. 核心任务无法理解；
3. 跨场冲突；
4. 局部表达不顺；
5. 偏好差异。

此排序用于分配修订资源，不给作品或创作者评等级。非商业作品的核心任务也可以是形式体验，不自动以商业标准优先。

# 适用边界 / 不应自动做什么
- 不把症状直接写成方案。
- 不用"意见条数"衡量分析深度。
