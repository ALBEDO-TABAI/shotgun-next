# 要点

演员、场地、天气、技术和剪辑会带来新发现。编剧与导演对谈中，意图沟通和制作约束是重要议题；执行不是逐字搬运。

| 规则 | 内容 | 例子 |
|---|---|---|
| 冻结的范围要明确 | 冻结拍摄所需的当前稿，同时保留正式变更通道；冻结不是永不改变，而是不让不同部门悄悄执行不同版本 | — |
| 变更回到影响层级 | 换词不影响承诺，可局部处理；改变行动意义或事实的修改要通知相关消费者，而不是只改一个文件 | "明早看"改"有空再说"改变行动意义；删除已发送状态改变事实 |
| 无法执行要有替代与损失说明 | 保住镜头数量不是目标，保持角色行为关系才是 | 拍不到门内空位可换动作，但要检查邀请是否仍可读 |
| 成片重新评估 | 文字成立不保证成片成立；成片中的新效果不必假装全由初稿预设 | 按第十一篇检查实际版本再决定是否修订 |

# 适用边界 / 不应自动做什么

- 不把执行理解为纯粹逐字搬运，也不允许各部门保留各自喜欢的版本。
- 本阶段建议未在真实团队运行测试。
