# 操作

1. **保留五种信息状态**：已明确建立 / 当前可推断 / 有意开放 / 待研究 / 不适用。短片不需要人物学历时不必虚构学历填空；世界没有说明某件事时，不自动当作不存在。
2. **行为倾向不是预测公式**。"在公开场合她倾向先笑着接过话题，在私下能够提出异议"有助于写场景，但新信息、新关系和身体状态仍会改变反应。人物可以出人意料，只要回看有依据。
3. **同一事实维护一个适用时点**。"钥匙归还了""父亲仍有钥匙""女儿以为钥匙丢了"可能分别属于不同时间和信念；加上对象、时点与来源后才知道是真矛盾还是多视角。
4. **设定与执行互相检查**。门禁规则变了，动作、道具、字幕、对白可能都要更新，不是只改设定文档就算完成；执行中发现某条件不可行，也应回到规则和场景重新选择，不靠下游自行补故事。

# 适用边界 / 不应自动做什么

- 人物小传、策略表和规则表都是工具，不是所有作品必须填满的表格。
- 不用永久记录所有细小心理状态；只维护真正影响作品和后续执行的关系。
