# 设定（自拟）

女儿希望父亲来访前联系；父亲要确认自己仍受欢迎。事实与关系目标保持一致，只比较语言组织。

# 四种形式

| 形式 | 片段 | 成立条件 | 风险 |
|---|---|---|---|
| 直接协商 | "你来之前给我发条消息。"／"怕我赶上你不在？"／"我想自己安排时间。"／"好。" | 关系已能正面谈论 | 不是直白本身，而是是否过早拥有这种交流能力 |
| 事务性间接 | "楼下门禁换了。"／"那我到了给你打电话。"／"来之前说吧。"／"提前多久？" | 门禁有事实依据 | 不能只为自然发明事实；始终只谈技术可能没完成关系上的明确约定 |
| 回避被轻轻揭开 | "你别每次都买那么多菜。"／"不买就空手来？"／"不是不能来。" | 突出双方在谈不同问题 | 当前还没完成来访安排；不能因潜台词丰富就假装事实已讲清 |
| 高度风格化 | "把这扇门留给我开，好吗？" | 整体语言、人物和空间支持 | 可能像作者在说；不单凭句子优美 |

# 比较维度

每版分别检查：事实确定性、人物当前能力、所需语境、情绪空间、表演条件、篇幅。没有一版同时免费获得全部好处。

# 从可说到可演

- 为关键句写下具体行动：提出条件、试探、澄清或争取承认。演员可改变重音、停顿和视线，比较不同回应，而不是服从唯一"真正含义"。
- 演员多种尝试仍难建立关系，回到场景任务和前文，不只改形容词。
- 试演发现新的有效关系，也可回写剧本，记录它改变了什么。

# 对白修订的语义检查

| 改动 | 含义变化 |
|---|---|
| "明早看"→"明早弄好" | 从开始处理变成完成承诺 |
| "这个别换"→"别换" | 指称范围可能扩大 |
| "我知道"→"我同意" | 从理解变成接受 |

这些不是纯口语润色。交接时应区分**保持事实与行动的改词**与**真正改变人物承诺的修改**；后者需重新检查前后关系。
