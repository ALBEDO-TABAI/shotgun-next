# 要点

## 先定义观察依据
以"人物情绪改变"为标记时，先定义依据：语言明确改变、行动策略改变，还是表情被解释为不同？三者混在同一栏，分析者之间的分歧就难以定位。可先为少量片段试编码，再讨论分歧来自漏看、术语不同还是合理解释——不必为统一抹掉后者，也不能因一致就宣称判断客观正确。

## 一项判断至少保留三个位置
| 位置 | 示例 |
|---|---|
| 证据在哪里 | 本场女儿接受邀请的动作 |
| 结论适用范围 | 只到"接受邀请"，不延伸到"决定长期居住" |
| 反证可能在哪里 | 后场若显示只进屋取物，应修订解释 |

## 不确定性要具体
"可能不太自然"仍含糊。可写："未知真实口语是否这样使用""不知道人物是否已听过这段说明""缺后场，无法判断此刻重复是否回收"。具体未知指向不同的取证任务。

## 分析中的负例
发现潜在问题后，主动找能让它不成为问题的条件：前文已建立权限、此处是记忆、局部违反写实是稳定形式的一部分。没有材料就保留问题；确实存在就修改自己的判断。对抗性复查不是挑出更多错误，而是同时降低假问题与遗漏。

## 报告应能承受脱离作者解释的检查
- 另一位读者能否凭报告中的位置和引文找到同一事实？
- 能否看出哪句是分析者推测？
- 建议是否依赖报告没有说明的背景？
若只能在口头解释后才理解报告，报告自身可能出现了和剧本相同的信息问题。

## 不将审稿变成统一风格
读者不喜欢长停顿可以是偏好；若停顿破坏明确的任务时间条件，则是另一类问题。分析帮助作品完成自身选择，不把全部作品改成评审者最熟悉的类型。改稿后要再次检查原来有效的机制，而不只确认意见逐条执行——执行全部建议仍可能使作品更平、更冗余或彼此矛盾。
