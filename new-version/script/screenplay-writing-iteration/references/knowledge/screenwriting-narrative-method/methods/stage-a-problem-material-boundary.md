# 要点

| 项 | 内容 |
|---|---|
| 输入 | brief 或创作冲动、实际资料、媒介与资源条件、已有构想 |
| 工作 | 按第三篇区分题材、命题、具体问题、前提与形式假设；按来源区分观察、自述、公开资料与构造；主动寻找会推翻初始想法的材料 |
| 交付 | 一页任务说明、材料地图、未知项及其影响、可比较的方向 |
| 进入下一阶段的条件 | 知道当前探索的具体问题、必须尊重的事实、哪些仍在假设 |
| 回退触发 | 新事实否定前提；使用范围不允许；品牌能力不支持；素材无法取得 |

- 交付物不是先写完整剧本再证明它合理。
- 若手头只有"高级、温暖、真实"这类抽象词，可以继续生成小样帮助具体化，不必无限讨论抽象词。
- 触发回退时应改问题或规模，而不是隐藏限制。

# 适用边界 / 不应自动做什么

- 不把个人经验升级成人群洞察；材料状态要按来源标记。
- 小项目可以把四项交付合并为一页。
