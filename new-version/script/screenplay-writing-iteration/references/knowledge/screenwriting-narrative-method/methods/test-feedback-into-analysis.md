# 要点

| 规则 | 做法 | 不做 |
|---|---|---|
| 1. 先开放，再具体 | 先问发生什么、何处开始这样理解，再针对关键事实追问 | 一开始就问"是否看懂某个主题" |
| 2. 编码也需要定义 | "看懂"是认出发送成功、理解次日安排，还是接受自我照顾主题？分开记录 | 把合理多解编码成错误 |
| 3. 小样本用于发现 | 数位受访者可定位问题 | 冒充整体观众分布；把熟悉素材的同事当目标群体 |
| 4. 版本比较注意顺序 | 使用独立首看，或明确分析顺序影响 | 把已看过一版的人当作同样首看；没有数据时填统计结论 |
| 5. 作者解释后的同意不是原版理解 | 可以研究解释带来的改变，但区分条件 | 被告知"木柄来自父亲"后说"很感人"，当作图像独立传达了这项事实 |
| 6. 反馈冲突不一定要消除 | 先找共同事实和分歧来源，再决定保留开放或调整 | 把多数意见当唯一艺术标准 |

# 适用边界 / 不应自动做什么
- 没有接收数据时不输出观众效果结论。
- 模拟观众（同事、模型）不是受众数据。
