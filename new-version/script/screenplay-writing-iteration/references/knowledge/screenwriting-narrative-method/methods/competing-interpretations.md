# 要点

同一个沉默可以是思考、拒绝或无法开口。分析不是选"最容易讲圆"的解释，而是列出竞争方案后比较**材料支持**。

## 比较三项
1. 各自解释了哪些材料；
2. 各自需要补多少假设；
3. 各自在哪些地方被反证。

多视角研究提醒：作品可以让不同观点进入组织，但不是出现多个人物就自动形成同等充分的视角。

# Examples

自拟片段：父亲抓住女儿的箱子，随后主动让出位置。

| 解释 | 支持材料 | 削弱材料 / 所需补充 |
|---|---|---|
| A：父亲想阻止女儿离开 | 抓住箱子 | 后续主动让出位置削弱此读法 |
| B：避免箱子碰到门框 | 若画面有碰撞风险且之后立即让行，支持更强 | 需要画面确认碰撞风险 |
| C：他心里矛盾 | 可兼容 A 与 B | 更难由单一动作确定，需要其他材料 |

承认开放，也不能把每种私人联想写成同样充分。

## 主题与意图分开
- "作品可以被理解为边界协商"是**解释**；
- "作者想纠正现代家庭观念"是**意图和社会判断**，需要额外证据。
不能因为主题分析精彩就越过范围。

# 适用边界 / 不应自动做什么
- 不因某解释更完整、更动人就默认它正确。
- 不用多个解释的存在证明作品"多义"，仍要比较支持强度。
