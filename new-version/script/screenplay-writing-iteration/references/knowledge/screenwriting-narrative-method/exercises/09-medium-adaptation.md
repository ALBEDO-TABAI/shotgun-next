# 练习

| # | 练习 | 记录什么 |
|---|---|---|
| 1 | 把同一素材分别做成说明片和关系短片，保持事实一致 | 比较顺序、人物与文本承担的任务 |
| 2 | 把四十五秒改为十五秒，明确宣布不再保留的一项叙事任务 | 检查剩余任务是否真正完成 |
| 3 | 为同一张图写说明、开放提问、关系限定三种标题 | 图像意义怎样改变，不只比较文案是否优美 |
| 4 | 把一段拟纪录感广告列成材料清单，区分现场、表演、合成、推断和真实声明 | 找到容易误认的地方 |
| 5 | 去掉品牌 | 既记录仍成立的部分，也记录失去的实际联系；故事独立并非自动失败，品牌缺位也不被动人故事自动豁免 |

# 工作原则

> 媒介适配不是把故事挤进尺寸，而是重新确认这个版本能够、需要并且有依据让观众经历什么。
