## 内容与使用范围

正文共11篇，均为独立Markdown文档。每篇包含概念与理论、适用边界、具体分析或创作方法、自拟案例、反例与诊断、skill输入输出和验证问题。文档不是只有提纲，也不是已安装或运行的Agent技能。

各篇按任务展开，篇幅不机械相等。全包正文合计约70,094个汉字，104,174个字符；统计包括各篇脚注和导航。汉字数按Unicode基本中日韩汉字范围计算，不等同严格字数或词数。

## 三种阅读路线

**建立理论基础**：先读[第一篇参考原文](参考原文/一.md)，再依编号阅读。篇与篇互相引用，但不要求为理解某一篇先读完全部。

**分析现有作品**：第一篇做形式定位，第十一篇建立分析过程，再按具体问题调用第四至九篇；第二篇用于分析工作与贡献。

**从零创作或组织团队**：第三篇建立问题，第十二篇安排探索与迭代，再调用人物、场景、对白和信息模块。第十篇提供完整推演，不是唯一正确范本。

## 研究与证据声明

整理日期为2026-09-18。检索围绕原十二点主题展开，优先采用理论作者或创作者原文、署名学术词条、研究论文、大学或行业机构材料。它是面向方法建设的主题性研究与综合，**不是具有预注册检索式和全量筛选流程的系统综述**。

学术理论用来建立概念，不自动证明效果；实证研究仅支持其样本、材料、任务和模型范围；创作者讲座提供实践立场，不被改写成普遍规则。工作表、流程、接口、诊断练习和虚构案例为本包综合。

Macdonald专著仅取得出版简介与目录；Escalas论文仅取得摘要和元数据；DAWG使用机构和框架介绍。相应限制在脚注中保留，没有把未读全文写成完整原典分析。被来源间接引介的论文不计入本包直接读过的原文。

所有案例均为自拟或对原对话虚构案例的扩展。没有进行受众实验、真实拍摄、产品功效核验或本地法律合规审查。测试表描述要怎样测试，不是测试已通过。AI研究不用于宣称当前所有模型表现或自动创作收益。
