# 非人物初步剧本｜六专题深化知识包 V2

**研究查验日期：2026-09-18　｜　语言：简体中文　｜　交付：六篇独立 Markdown＋阅读索引、来源记录、结构校验记录**

> 把创意写成能够被设计的内容：先决定产品、对象、材料、空间、信息和感受如何在时间中展开，再进入设计与分镜；不以人物冲突为唯一结构，也不把剧本直接降成生成提示词。

## 这次扩写对应什么

本包严格对应上一轮回答的六个大点，而不是把旧包十二个模块简单改名。旧稿作为问题与结构基线；本轮补充新检索，并将研究转成选择方法、内容推演、写作示范和实际交接。它可以独立阅读，不需要先复制旧压缩包，也没有覆盖旧知识文件。

六篇都以“要解决的创作问题—相关依据—方法转译—选择与实施—示范与回修—工作模板／退出条件”展开。篇幅不机械相同：机制篇需要多路线，案例篇需要事实与迁移分离，交接篇需要完整正文与双向引用。

## 三种读法

**按完整流程读：** 01 确定任务与路线 → 03 构想内容 → 02 编排状态与时间 → 05 写出初稿与设计需求 → 06 优化与回修。04 在需要案例支撑或替代机制时查用。

**先看怎么做：** 直接读 05 的“一页”阅读灯 V1，再读 06 的 V2 与长短版本。然后返回 01／03，检查这些内容是怎样从需求中选出来的，而不是只复制示例外观。

**给 agent 按问题调用：** 需求模糊用 01；“只有形容词、想不出内容”用 03；先后与时长不清用 02；参考只能模仿外观用 04；美术不知道要做什么用 05；改稿、版本与下游消费失配用 06。不需要每次全量输出六篇。

## 贯穿案例与版本关系

“一页”折叠阅读灯是原创虚构教学项目，底座、立柱、唯一铰链、手动按钮、固定暖白光、名称与所有时长均为教学条件，并非用户真实商品资料。允许一只局部操作手，但不讲人物目标、冲突或经历；完全无人写法另在三色杯、香氛、材料、系统和循环示例中展开。

01—03 展示选择与构思，05 的 V1 是初稿，06 的 V2 是内容升级示范。两者是教学演进，不是同时生效的两份生产“最终版”。06 的 V2 消费表显式更新设计需求用途；15 秒与 6 秒分别声明本版任务及放弃项。候选标题不能替代未批准的实际产品文字。

## 本包怎样使用证据

文献与方法来源使用 S01—S17；真实案例使用 C01—C09。每篇保留独立可用的来源链接；[来源与研究记录](来源与研究记录.md)提供 26 项来源的查验范围、可支持结论和不能外推之处。S 类也包括机构流程与工程手册，不能统称为十七项实证研究。

研究结论、创作者公开自述、本包的工作建议和原创教学内容分别标明。九个案例研究以公开文字为依据，未伪装成逐帧观看或内部流程还原；其中 Spline 含角色元素，Procreate 明确作为角色动画边界对照，不能把九例都当纯非人物成片。

部分论文仅能核到摘要与题录，已标范围；部分从作者公开副本阅读。包内不再分发第三方论文、影片、图片或品牌资产。素材公开可见，不表示获得商业使用权。

## 适用边界

本包是一份可继续用于 skill 开发的知识资料，不是已经安装或跑通的 agent。没有执行实际视频生成、材质实测、受众访谈或商业投放。初步剧本的完成与最终生产、用户确认、受众效果是不同状态。

不要把审慎变成流程负担：只阻塞依赖未知事实的部分；只给必要变化提取状态与关系；只在确有问题时做针对性验证。超现实与抽象表达仍然可用，只需明确其与真实商品的联系及边界。
