# 要点

## 候选关系表

| 意图词 | 候选关系一 | 候选关系二 | 需要警惕的相反感受 |
|---|---|---|---|
| 清透 | 重叠减少，层次可辨 | 单一表面中出现连续的透见路径 | 稀薄、空洞、清洁功效暗示 |
| 轻盈 | 明确支撑下的从容移动 | 质量感不大的短促响应与稳定 | 失控、塑料感、无重量 |
| 精密 | 微小动作带来准确配合 | 多部分维持明确相位关系 | 繁琐、僵硬、过度机械化 |
| 柔和 | 接触边界逐渐形成 | 变化结束时没有突兀跳变 | 软塌、拖沓、辨认不足 |
| 舒展 | 固定支点周围的关系打开 | 可用间距逐步明确 | 无边界膨胀、散乱 |
| 清爽 | 附着与分离之间清楚 | 密集运动后出现稳定空隙 | 排污、清洁、产品作用夸大 |
| 包裹 | 周边形成有空隙的整体 | 局部接触向周围连续延展 | 束缚、吞没、黏腻 |
| 活力 | 相同规则产生差异响应 | 稳定预期中出现轻微偏离 | 乱动、躁动、节奏疲劳 |
| 温润 | 接触与表面变化缓慢过渡 | 明暗或声音的边缘不尖锐 | 不清楚、迟缓、过暖 |
| 秩序 | 不同元素可辨且关系一致 | 变化后仍能找到不变量 | 单调、无个性、过度控制 |

## 使用步骤
1. 为每个体验词至少写两种解释，挑**一个**关系；
2. 写一次具体过程；
3. 主动提出一个可能的反向解读；
4. 用转译句式收束。

## 转译句式

```text
为了尝试建立【体验】，让【对象】从【关系 A】经过【动作／规则】进入【关系 B】；
保留【锚点】，使变化可被追踪；用【产品联系】把它接回任务。
```

示范：为了尝试建立精密，让两个具有已知接口的模块从错开进入准确配合；保留一个稳定基准，不同时改变轮廓；连接后的完整使用形态负责把动作接回产品。

# 适用边界

- 表中内容是**原创构思候选，不是心理学映射表**，不宣称固定对应。
- 自检：若只能回答“因为大家都觉得蓝色清爽”，说明还没有完成本项目的转译。
- “清透”“清爽”等词的某些画面会带出清洁或功效暗示，属于可能承担产品主张的表达，应回到 [四种真实性层级](/frameworks/authenticity-levels.md) 与事实依据处理。
- 句式里的“尝试建立”是设计意图；观众是否获得该体验仍待检验，见 [按问题类型选择验证](/frameworks/validation-by-question-type.md)。
