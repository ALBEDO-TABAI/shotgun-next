# 要点

## 1. 改写示范

| | 句子 |
|---|---|
| 原句 | 「清透质感出现，产品高级展现。」 |
| 可写版 | 「产品保持在中心。前方两片半透明板向两侧错开，重叠面积减少，瓶肩与标签区逐渐可辨。板片停止后，完整瓶体在层次清楚的空间中保持。」 |

可写版增加的是**对象身份、动作方向、空间关系、披露与结果**；没有把美术自由写死——板片形状、表面细节、环境色彩仍可发展。

## 2. 用动词暴露设计任务

| 动词 | 隐含的设计条件 |
|---|---|
| 打开 | 内侧和连接 |
| 折叠 | 固定点、折线或关节 |
| 穿过 | 入口、厚度和出口 |
| 反射 | 被反射对象与环境 |
| 盛放 | 接触、承托和容量关系 |
| 替换 | 身份与状态变化规则 |

同一动词可能有不同层级：「展开盒内世界」可以指实际纸艺机构，也可以是观看者进入不可能空间。**先明确层级，再提取资产**；不能因为都是「展开」，就让美术同时建真实折叠机构和无穷大内部空间。

## 3. 用限制保护关系，不用限制替代创作

| 写法 | 效果 |
|---|---|
| 「不要任何多余元素」 | 封锁范围却不解释原因，通常不能提供充分指导 |
| 「关键转动期间保持固定立柱可辨，手不得持续遮挡唯一铰链；其余环境细节不承担新动作」 | 保护本段内容并留下自由 |

需求越具体不一定越死板；重要的是**具体到关系**，还是具体到不必要的唯一实现。

# 适用边界

- 这是本包的写作工作法，没有被来源验证为标准句法。
- 动词层级的判断依赖第 01 篇的 [四种真实性层级](/frameworks/authenticity-levels.md)；层级未定时不应直接进入资产提取。
