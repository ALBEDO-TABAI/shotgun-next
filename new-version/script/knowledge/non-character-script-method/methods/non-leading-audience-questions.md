# 要点

## 提问顺序

1. **先开放询问**
   - 你看到哪些东西发生了变化？
   - 你认为哪个动作导致了哪个结果？
   - 能描述一下产品是什么吗？
2. **再问不确定点**
   - 有没有地方不知道属于哪里？
3. **最后才讨论体验**
   - 哪些部分让你想到柔软、精确或别的感觉？依据是什么？

## 不要做

- 不要开场就问「你是不是觉得很柔软、很高级」。
- 不要在测试前讲解隐喻，再把回答当作自然理解。
- 不要把每个不同联想都判为错误：可以记录联想与事实误读，但开放艺术任务本来可能允许多个解释。

## 样本

- 探索性小样本能暴露问题，却不适合精确估计总体比例。
- 具体样本量应由任务、目标人群、比较设计与资源决定。
- 本包**不规定**「问五个人达到某百分比即可上线」。

# 适用边界

- 这是本包的工作建议，不是心理测量或市场研究规范；本包未执行任何访谈。
- 区分「事实误读」（例如把手动开灯理解成感应）与「不同联想」很重要：前者可能触及产品主张，应优先处理。
