# 要点

**只写起止状态会漏掉什么。**

| 起止写法 | 可能遗漏的中间内容 |
|---|---|
| 闭合—打开 | 铰链、运动路径与内侧 |
| 接触—恢复 | 作用点、最大形变和卸载 |
| 断开—连接 | 接口对准与身份保持 |

**判断步骤。**

1. 写出本段的起始状态与结束状态。
2. 假设删去中间态，只留两端。
3. 问：剩余信息能否区分「同一对象变化」与「换了一件东西」？
4. 问：剩余信息能否区分「真实作用」与「无依据结果」？
5. 任何一问答「不能」，且本段承担相应的解释任务，则该中间态必要，应写入节拍的「必须看见的中间态或参照」。
6. 若选择省略，标明本版因此**不承担**哪项任务。

**省略不是错误。** 「盖子移到一旁，盒内空间已经展开」可以是有意省略动作的写法；但不能同时宣称这段完整解释了展开机构。未标明省略承担不了的任务，才是问题。

# 适用边界

- 判断标准是任务，不是动作长短：短动作也可能有必须看见的中间态，长动作也可能可省。
- 中间态是内容条件，不是要求美术必须出一张参考图。
