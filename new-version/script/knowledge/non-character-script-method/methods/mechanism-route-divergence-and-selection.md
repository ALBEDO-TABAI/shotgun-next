# 要点

本概念细化七步法的步骤三、四，并吸收教学项目 §7.4–7.5 的示范。

## 1. 路线卡：每条路线回答同样五问

1. 对象是什么；
2. 核心变化是什么；
3. 观众要做哪种理解；
4. 产品如何参与；
5. 最困难的设计条件是什么。

每条约一段正文，不在这个阶段展开几十镜。

## 2. 判断「真正不同」

- 三条颜色不同的路线**不是**三个机制。
- 直接演示、累积揭示、跨对象类比，才是结构性不同。
- 路线数按项目需要决定；少量可比较方向比大量同义方案更有价值。

## 3. 六个比较维度

任务贴合 ｜ 表达特异性 ｜ 理解负担 ｜ 设计负担 ｜ 短版可保留性 ｜ 核心不确定性

写理由，不用没有测量依据的「创意 92 分」。

## 4. 把取舍写成创作决定

- 两条路线各有优势时，明确这是一项创作取舍：直接演示更容易解释操作；披露路线更有发现过程，但可能需要更多阅读时间。
- 分工：导演决定本版值得追求什么，编剧将决定落实为内容。

## 5. 选定后的三项记录

| 记录 | 教学项目示范 |
|---|---|
| 已选路线与理由 | 选 A（真实操作）为主干：教学目标同时包含操作理解与非人物写作，A 的事实依赖更可控。不是宣布 A 对所有片子更好 |
| 保留的辅助机制 | 保留 B 的「先看光面、后理解书页」局部披露方法，而不保留一整套延迟产品揭示 |
| 本版的牺牲 | 不展示内部电路；不做大型液体世界；不介绍全部参数；不将「安静」转成失眠人物的情绪困境。它们不是永久禁用项，而是本版为把一个关系讲清楚所作的取舍 |

# 适用边界

- 并行原型研究提供比较思路，但**没有给出通用最佳数量**；不能推出每个项目一定要三条路线、一定提高转化率，或多 agent 同时调用即等于该实验 [2]。
- 用相同细化程度比较，避免只精修第一个方向。
