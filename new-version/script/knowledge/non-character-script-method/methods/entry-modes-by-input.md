# 要点

| 入口 | 先做什么 | 关键规则 | 输出 |
|---|---|---|---|
| 用户只有一句需求 | 任务解包与有限发散 | 缺少产品内部资料时，从外观与已知操作写，不把未知当成阻塞整条片子的理由；关键不确定性明确留出条件分支 | 任务卡 + 少量路线 |
| 用户已有创意或初稿 | 先找其有效内容，再诊断断点 | 已有「杯中气泡与产品字母构成呼应」的创意，不应被默认推翻成完整人物故事；可以补：气泡何时出现、字母如何被辨认、产品与类比的边界 | 「保留什么 / 需要补什么 / 局部修订 / 可选结构升级」；局部润色与结构重写分开，让用户知道改动性质 |
| 用户提供参考片让你反推 | 先记录可观察内容与证据位置 | 创作者意图、商业目标和不可见因果须标为推断。推得出的可能是「局部—整体揭示」；推不出的是「创作者一定采用某理论」或「这支广告因此卖得好」 | 可作为创作输入的关系，而不是被复制的标志性设计 |

# 适用边界

- 反推的产物应抽出关系，不复制标志性设计；详细方法在第 04 篇。
- 三种入口共享同一工作逻辑，区别只在从哪一步进入、展开到什么深度。
