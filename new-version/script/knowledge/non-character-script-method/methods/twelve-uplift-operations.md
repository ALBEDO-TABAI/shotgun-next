# 要点

每项操作都改变内容关系，而不是追加形容词或特效。每项都附带来源给出的限制。

| # | 操作 | 怎么做 | 来源给出的限制 |
|---|---|---|---|
| 4.1 | **建立母题** | 把多个片段收束到一个可反复辨认的关系（固定与转动、接触与分离、局部与整体、独立与协作）；例：水花、金属、产品旋转三段改成三次不同条件下的「边界变清楚」 | 母题不是把同一标志到处贴；不能为统一而消除必要差异，是否值得取决于任务 |
| 4.2 | **增加一次重新理解** | 让后段提供一条有用线索，使前段获得新位置或新意义（抽象表面后来成为真实纸页） | 关键是后段能解释前文，不是突然出现意外物体；惊讶与理解不必总绑定 |
| 4.3 | **提升产品参与度** | 产品可以是作用者、承载者、被理解对象、比较基准或形式源；让一个真实关系提前参与 | 不是无条件增加露脸次数，也不是计算占屏百分比；品牌艺术片可以有意不持续露脸 |
| 4.4 | **改变时间性格** | 先稳定后变化、先密集后澄清、重复中偏离、动作后留出响应 | 「更快」解决不了身份缺失，「更慢」解决不了没有共同规则 |
| 4.5 | **改善作用来源** | 明确接触、作用点、固定边界与留得住的结果 | 真实功能无依据时，可把作用移到独立艺术装置，但需显式更新内容关系 |
| 4.6 | **增加可辨认的对照** | 给变化一个起点、共同基准或同时存在的参照 | 对照不等于竞争，不必宣称哪个更好；多维对照看不清时先减少维度 |
| 4.7 | **将装饰改为有任务的事件** | 问每个元素承担识别、感受、连接还是层级 | 无任务但审美确有价值可作为开放项保留；装饰不得获得改变主内容的权力，尤其不能为转场自动长成产品内部 |
| 4.8 | **让声画各自承担适合的职责** | 声音支持接触与空间，图像承担结构与身份，文字负责准确命名 | 不必每条信息重复三遍；有意反差可以成立，没看过完整视听代理前不要仅凭文本判矛盾 |
| 4.9 | **把复杂度放在值得理解的位置** | 在一个关键结构上复杂、其它位置稳定 | 每秒同时出现新主体、新空间、新材质、新文字时，问题可能是竞争而非观众不够懂 |
| 4.10 | **用有理由的缺省代替解释过量** | 熟悉操作可省略、留下关键状态；艺术作品可保留开放联想 | 省略后不能继续要求它承担被删去的信息任务 |
| 4.11 | **设计结尾的回响** | 结尾回到开头的对象、规则或关系，不一定回到完全相同状态 | 并非每片都需要闭环；品牌名与稳定停留可能已是恰当结束 |
| 4.12 | **给路线保留真正的替代方案** | 机制始终不成立时，保留一条组织依据不同的候选 | 替代路线用来重新选择，不是把所有候选拼成一条片；无需为多 agent 生成十个相似答案 |

# 适用边界

- 十二种操作是本包的原创综合，不是经过验证的「有效提升清单」；每次使用的增益都是待比较的创作假设。
- 提升发生在修错与澄清之后；事实未核实或关系看不懂时，先处理前两种工作。
- 任何操作都不得以改变产品事实为代价（V2 完整保留单铰链与手动开关）。
