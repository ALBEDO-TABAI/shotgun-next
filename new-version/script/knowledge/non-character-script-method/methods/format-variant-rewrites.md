# 要点

| 版本 | 真正改变的是 | 怎么做 | 不应该 |
|---|---|---|---|
| **竖版** | 可见关系 | 横版的横向并置可改为前后或上下层次；保留真实照明与支撑关系；关键铰链与按钮不能被裁掉；若改为先局部后整体，同步更新披露关系与时间 | 让书为了入框而漂浮；只检查最终安全框，不检查动作中间态和文字出现时的关系 |
| **静音版** | 信息职责 | 主版本若靠按钮声确认接触，静音版由画面补足接触；核心名称若只在旁白出现，需增加准确文字 | 因为脚本写了「可静音」就判完成——仍应实际查看 |
| **无手版** | 可能是表达性质 | 改为明确的展陈状态对照（收拢态、工作态、亮灯使用态分别出现），承认省略了作用过程；或采用用户许可的舞台装置承担作用 | 直接删除手，却保留「灯自主展开、自动亮起」的写法 |

补充要点：

- 正文未改变的版本也需要对应的设计布局，但这不等于重复建立产品事实。
- 抽象声画作品的静音版可能是另一件作品，不能自动承诺情绪与内容完全等价。
- 一页阅读灯一例已要求视觉理解主任务，故静音主要影响体验，而非操作事实。
- 若无手版使用无作用源的艺术运动，应清楚选择其表达性质并检查实际误读；它不再等同真实操作演示。

# 适用边界

- 三种改写的判断都是内容层的工作建议，没有经过观看测试；「是否仍能看懂」需按 [不同问题需要不同证据](/frameworks/validation-by-question-type.md) 另行检验。
- 无手版改为自主运动时，[真实性层级](/frameworks/authenticity-levels.md) 已从真实行为变为其它层级，属于内容关系变化甚至任务变化，不是实现调整。
