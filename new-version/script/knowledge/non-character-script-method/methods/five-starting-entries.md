# 要点

| 入口 | 先问什么 | 来源中的示例 | 限制与提醒 |
|---|---|---|---|
| 真实产品关系 | 产品如何接触、开合、连接、承载、被操作或被收纳 | “灯头绕固定轴从竖向进入横向工作姿态。”先写成没有风格词的动作，再决定它克制、连续、分段、对照还是有发现感 | 不能把不存在的结构当创意自由；动作不够独特时，用观看关系与时间体验深化，而不是发明新功能 |
| 材料行为 | 接触时发生什么，离开时留下什么，速度改变时如何响应，与什么表面形成差异 | 柔顺可以是沿曲面连续贴合，也可以是受扰动后平稳恢复；两者动作、材料与情绪方向不同 | 只列“玻璃、凝胶、丝绸”不算构思；还要决定行为由真实产品还是独立代理材料承担 |
| 空间关系 | 物体怎样被包围、分隔、支撑、遮挡、容纳；何时意识到空间更大或更有层次 | 产品始终不动，外部几层框架逐次错开，使它从拥挤关系进入明确中心 | 空间不是背景库；这可以是感受类比，不必假装产品具有整理房间的功能 |
| 品牌或文字的形式 | 某个形式特征（折角、字母间距、网格、包装比例）能否产生有意义的动作，在哪里与产品或任务会合 | “间距”成为排布、遮挡与揭示的变量；“闭合轮廓”变成包围与容纳 | 不是把标志变成一切；精确字形不可修改时，让辅助图形承担变化，标志保持准确 |
| 不可直接拍到的关系 | 协作、权限、连续性、选择、连接、独立又成整体——先写关系，再找可视载体 | “同一对象被不同权限的人接触”由同一编号的资料卡、两个视图和清楚权限标签表达 | 不要一开始就选星球、云端、神经网络等品类惯用图像 |

## 使用方式
- 入口决定的是“从哪里找到关系”，不是风格。选定入口后仍要写出对象、变化、关系与结束状态。
- 从产品关系起笔的好处是产品不会到最后才被硬插入。

# 适用边界

- 五个入口是本包的原创工作工具，不是穷尽分类；来源未声称其完备。
- 代理材料的表现不等于产品真实属性，参见 [四种真实性层级](/frameworks/authenticity-levels.md)。
