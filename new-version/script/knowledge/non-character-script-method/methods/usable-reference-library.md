# 要点

## 每条记录存什么

案例库不应只存品牌、链接与风格词。建议每条记录八项：

1. 任务；
2. 可确认内容；
3. 证据类型；
4. 可迁移操作；
5. 必要前提；
6. 不能迁移项；
7. 一个原创适配胚；
8. 当前查验范围。

可直接填写的文本模板见 [案例库记录模板](/templates/case-library-record.md)。

## 怎么检索

- 优先问关系型问题：「哪里有通过接触表达顺应的案例」「哪里有局部到整体的身份揭示」。
- 之后再查品牌和风格。
- 这样案例库才帮助生成内容，而不是把每个新项目拉回同一批漂亮影片。

## 存什么形态

- 保存一手链接，而不是大量复制原片素材。
- 需要素材用于实际制作时，再处理版权和授权。
- 本包不包含第三方图片、视频或论文全文。

# 适用边界

- 参考库回答「可以怎样表达」；产品事实要另找准确资料，见 [案例证据的限度](/principles/case-evidence-limits.md)。
- 参考不断增加却没有改变当前 brief 的关系判断时，研究可能已失去边际价值，见 [案例研究与迁移的 skill 接口](/skills/case-research-and-transfer.md) 的退出条件。
