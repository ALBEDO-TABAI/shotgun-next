# 要点

| 来源 | 含义 | 例子 |
|---|---|---|
| 对象自身变化 | 对象的形态或材料状态真的变了 | 灯头转动、液体铺展、纸张折起 |
| 对象间关系变化 | 对象本身未变，彼此关系变了 | 两个分离部件相接；遮挡物移开；一个容器开始承托另一个对象 |
| 呈现范围变化 | 世界未变，被看见的范围变了 | 从局部扩到整体；不同表面依次被看见；观众从外部进入一个约定的艺术空间 |
| 符号或解释变化 | 同一对象被赋予新的理解 | 同一图形被重新标注为某种模块；数个局部最后被归入同一系统 |

**最常见的写错方式。** 后两类尤其容易被写成「世界发生魔法变形」。脚本应说明它们是**认知与披露变化**，除非确实希望对象进行超现实变形。

**为什么必须区分。** 同一句含糊动作（例如「方块拉远，最后变成包装」）在四种来源下需要不同的身份延续、资产准确性和中间态，不能共用一句话交给下游，见 [编排练习](/exercises/orchestration-exercises.md)。

# 适用边界

- 超现实变形并未被禁用；要求的只是作者明确选了哪一种，并让下游知道。
- 分类用于写作判断，不是对观众知觉过程的科学划分。
