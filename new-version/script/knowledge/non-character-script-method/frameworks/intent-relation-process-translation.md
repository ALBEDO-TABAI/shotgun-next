# 要点

## 缺口在哪里
“清爽”不是水，“精密”不是齿轮，“轻盈”不是漂浮，“科技”不是发光线。素材可以有用，但它们不能自动回答四个问题：

| 素材回答不了的问题 | 需要由谁回答 |
|---|---|
| 发生什么 | 作用或规则 |
| 为什么如此 | 关系与连接依据 |
| 产品如何参与 | 承载者与产品联系 |
| 前后有什么变化 | 状态差异与披露 |

## 核心转换
**抽象意图 → 可以感知的关系 → 让关系被看见的过程。** 起点可以是产品、材料、空间、文字、声音、使用或系统关系，不必永远先写一个人物故事。

## 本包综合的五步创作操作
1. 先定义想让人接触的关系；
2. 选择承载对象；
3. 设计作用或规则；
4. 安排披露；
5. 检查有无相反解读。

## 「机制」一词的用法
只表示某条内容如何成立。例如“局部线索累积到整体辨认”是一种表达机制，**不是**对观众大脑提出的新科学机制。

# 适用边界

- 研究入口与本包应用要分开：材料体验设计研究把材料放在感官、意义、情感和行动的整体关系中 [2]；关系类比理论强调对象间关系的映射而非表面相似 [3]；广告视觉修辞理论提出复杂度与歧义等分析维度 [4]；材料知觉研究提示作用过程、形状、外观与场景共同影响判断 [5][6]。
- 上述五步流程**是本包综合，不是这些论文直接提供的广告配方**。
- 材料体验不能保证审美效果，类比成立也不保证观众必然理解。这里的“科学性”主要指：把依据、推演和待检验的创作假设分开，而不是给每个“高级感”套一个学术名词。
- S06、S15 仅核到摘要与题录，不用于复刻其完整分类，见 [证据分层与使用边界](/principles/evidence-and-use-boundaries.md)。
