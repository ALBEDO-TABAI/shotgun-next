# 要点

| 时间类型 | 职责 |
|---|---|
| 建立时间 | 让观众有机会接触参照和规则 |
| 变化时间 | 让过程发生 |
| 辨认时间 | 使结果可被读取 |
| 停留时间 | 允许体验持续、比较完成或形成余韵 |

**重叠但不自动同时完成。** 四类可以部分重叠，但不能假定全部同时完成：

- 一个五秒动作并不必然需要再加五秒阅读；
- 反过来，按钮按下只需很短动作，也不表示产品身份和字卡可以在同一瞬间完成。

**检查方法。** 作者要检查各项任务**是否竞争同一注意对象**，而不是把时间机械相加或机械压缩。

# 适用边界

- 这是写作用的职责划分，不是测得的注意或阅读时长模型；本包不提供任何固定秒数阈值。
- 停留不是「没有新信息」的同义词：它承担体验、比较与余韵职责，是否删减由任务决定。
