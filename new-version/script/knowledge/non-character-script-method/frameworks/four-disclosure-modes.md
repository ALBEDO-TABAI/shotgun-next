# 要点

| 披露写法 | 核心问题 | 内容胚 | 应避免 |
|---|---|---|---|
| 累积 | 下一条线索是否帮助理解前一条 | 弧边、接口、主体轮廓依次组成同一产品 | 多个无法互相解释的微距 |
| 修正 | 新线索是否合理改变先前判断 | 看似独立薄片，后来被理解为折叠部件 | 无前文依据的突然替换 |
| 定位 | 已见局部属于哪里 | 某个纹路再次出现在成品的同一区域 | 只用相似颜色声称同一对象 |
| 重新分类 | 相同对象在新规则下怎样理解 | 数个图块原来是同一工具的不同状态 | 最后用旁白硬说它们相关 |

**披露位置不是审美等级。** 披露机制可以在开头、途中或结尾发生，不应默认把品牌全部藏到最后。六秒版本常需要一开始就出现身份；这改变的是任务分配，而不是审美高低。

# 适用边界

- 四种写法是编排候选，可以组合；表中的内容胚是原创示意，不是任何真实影片的镜头记录。
- 披露延迟会占用辨认时间，短版通常需要改写而非原样缩速。
