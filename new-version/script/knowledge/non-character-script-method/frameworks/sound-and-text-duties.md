# 要点

## 声音先分职责

可分配的职责：接触提示、空间延续、规则计时、关系对照、信息传达、情绪方向。不要一开始就把「高级」写成固定乐器套装。

- 灯的按钮声可以帮助辨认接触，但**不得代替画面中必须理解的操作**。
- 抽象图形按固定节律变化时，声音可以参与组织；若作品本体是声画对应，前期就需要共同设计规则。NFB 对《Synchromy》的说明是这种做法的实践参照，不是所有产品片必须先完成音乐的依据 [2]。
- 跨感官研究提供「不同感官特征之间可能存在对应」的研究入口，但不能据此规定某种高音必然代表清爽、某种低频必然代表高级 [3]。
- 更可执行的写法：选一个主要变化，由声音**跟随、先行、滞后或保持独立**，并写明该选择为何服务本段。

## 四种声画关系（原创操作例）

| 关系 | 操作例 | 职责 |
|---|---|---|
| 同步 | 模块接触时出现短促声点 | 帮助定位事件 |
| 先行 | 下一空间的环境声提前进入 | 为空间延续提供线索 |
| 滞后 | 动作停止后仍留一段衰减 | 让观众接触空间尾声 |
| 独立 | 图形缓慢变奏，声音保持另一层节律 | 形成有意张力；不能因独立而自动判为不同步错误 |

## 文字也分职责

类别标签、准确名称、必要限制、诗性表达、结构分段。可以让图像解释操作、让文字准确命名；也可以让文字参与形式变奏。必须清楚哪些内容必须精确校对，哪些允许开放阅读。

## 文字加入时，重新检查谁是观看中心

原创反例：「模块在两秒内连接，同时出现产品名称、三个功能和一行活动说明。」文本未必有错，但初稿没有决定谁先被接触。先问：模块连接是必须看懂的操作，还是字卡背后的形式活动？

| 版本 | 处理 |
|---|---|
| 操作优先 | 连接发生时只保留对象身份，连接稳定后再命名 |
| 选择优先 | 先建立类别标签，让后续相同结构依次展示各选项 |
| 品牌识别优先 | 保留稳定产品与名称，取消复杂连接过程 |

三者不是字体大小不同，而是内容职责不同。最终写法要有「何时允许出现」和「出现时哪些其他变化应让位」。

# 适用边界

- 准确文字仍交给排版与校对；但让文字承担哪一段的信息，不能全部留到后期临时决定。
- 多语言字数变化时先检查原有窗口，不用不经检验的固定阅读速度保证所有语言都能读完。
- S08 本次仅核到摘要与公开备注；不建立适用于所有文化、品类和个体的声音—材质万能字典。
- 《Synchromy》未逐帧转录，不推出所有广告必须逐拍同步。
