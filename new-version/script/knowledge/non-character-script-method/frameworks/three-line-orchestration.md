# 要点

**问题起点。** 同一句「瓶子出现，薄片打开，瓶子完整出现」至少对应三种完全不同的内容：

| 读法 | 实际发生的事 | 牵动的下游条件 |
|---|---|---|
| 产品自身改变形状 | 世界状态变化 | 资产、动作、事实依据 |
| 周围物体移位，使一直存在的产品显露 | 对象间关系变化 | 遮挡物、运动路径 |
| 观众观察位置改变，产品与薄片都没动 | 呈现范围变化 | 镜头方案 |

三者可能得到相近的单帧，但需要的资产、动作、事实依据和镜头方案不同。因此编排不能只回答「下一段放什么」。

**三条线。**

| 线 | 回答的问题 | 展开位置 |
|---|---|---|
| 世界线 | 世界里发生什么 | [对象状态类型](/frameworks/object-state-types.md)、[状态变化的四种来源](/frameworks/four-sources-of-state-change.md)、[关键中间态判断](/methods/key-intermediate-state-test.md) |
| 信息线 | 观众获得什么 | [信息增量与身份锚点](/frameworks/information-gain-and-identity-anchors.md)、[披露的四种写法](/frameworks/four-disclosure-modes.md) |
| 时间体验线 | 这一段如何占用时间 | [四类时间](/frameworks/four-kinds-of-time.md)、[四种时间性格](/frameworks/four-temporal-characters.md)、[时间预算工作法](/methods/time-budgeting.md) |

**同一版本约束。** 三条线必须放在同一内容版本中，不能变成三个 agent 各自保留的剧情解释。

**「观众获得」是设计目标，不是已观测结果。** 「观众终于感到安心」要改写成：「此处希望通过关系稳定与足够停留建立安定感；后续检验是否如此」。

# 适用边界

- 状态表、连接标记和时间工作法是本包的原创综合，不是心理学量表。
- 本篇输入是已选表达命题，输出是有职责、有连接依据、有暂定时间的内容节拍；它不替代路线选择，也不产出分镜。
