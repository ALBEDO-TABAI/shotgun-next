# 要点

| 任务 | 适合写成的终点 | 常见误置 |
|---|---|---|
| 识别 | 认出类别、具体产品、名称或系列差异 | 只记住漂亮环境，不知道在展示什么 |
| 理解 | 能说清一个操作、结构或系统关系 | 同时解释全部功能，导致每个都模糊 |
| 感受 | 得到某种有内容依据的触感、空间感或时间经验 | 直接宣布「观众感到治愈」，却没有承载过程 |
| 联结 | 将某个形式、体验或价值与品牌联系 | 片尾突然贴标志，前文可以任意换品牌 |
| 选择 | 区分变体、适用关系或组合方式 | 用独立美图替代可比较信息 |
| 持续观看 | 任意进入时仍能接触作品的规则或氛围 | 强迫展厅循环等待一个唯一开头 |

## 主任务与可让位任务

- 一条片可以有复合任务，但初稿最好能指出**主任务**与**可让位任务**。
- 目的不是机械限制创作，而是在时长、资源或事实变化时知道优先保护什么。

# 适用边界

- 这是「工作地图」三条轴之一（另两条是组织依据与真实性层级），属于本包的方法综合。
- 「感受」类终点是设计目标，不是已观测的受众结果。
