# 要点

本概念合并来源 §3.1 与 §3.3 的两条修正，它们共同回答「没有人物情节时，初步剧本到底在写什么」。

## 修正一：没有人物，不等于没有事件

| 可以写的变化 | 为什么算事件 |
|---|---|
| 一只容器受压、变形、恢复 | 对象自身状态改变 |
| 两个模块由分离变为连接 | 对象间关系改变 |
| 一个图形在持续重复中改变相位 | 形式规则下的可辨变化 |

- 是否构成**人物叙事**，取决于内容是否主要围绕人的目标、行动与关系展开，而不是画面里是否出现一只手。
- 反向陷阱：片中只有产品，也可能暗中沿用完整人物故事，把产品拟人化成「受挫—奋斗—胜利」的主人公。这不是禁用方法，但不是所有产品片的默认答案；需要证明它服务什么，不能为了填满剧本模板而强行使用。

## 修正二：初步剧本不是缩小版最终分镜

| 初步剧本应规定 | 初步剧本不必规定 |
|---|---|
| 必须看清同一铰链连接着哪两部分 | 第 3 镜头使用某焦段 |
| 产品在操作前后保持同一身份 | 只能用长镜头完成 |
| 必须让观众同时比较两个对象；必须暂缓揭示产品身份（这已是内容机制的一部分） | 每一镜的相机轨迹与全部技术参数 |

核心句：**前置的是使表达成立的关系，不是无差别前置所有技术参数。** 但也不能把所有观看问题都推迟给下游。

# 适用边界

- 这是本包为当前团队需求提出的方法综合，不是文献结论；来源明确说明七步流程等并未被验证为「最优 AI 影视流程」。
- 「不讲人物故事」与「不出现任何人体」需要区分：教学项目允许一只局部操作手作为作用来源，但不承担角色经历。
- 含角色的作品不应被一律排除，边界对照见第 04 篇的 Procreate Dreams 案例。
