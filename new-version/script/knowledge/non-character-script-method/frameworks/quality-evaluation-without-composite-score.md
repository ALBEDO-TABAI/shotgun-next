# 要点

## 七个分开记录的维度

1. 事实与关系完整性
2. 理解可接触性
3. 表达集中度
4. 产品联系
5. 时间性格
6. 设计可交接性
7. 候选多样性

**记录方式**：每个维度用「明确／待改／待验证」配理由，不需要发明精确分数。

## 为什么不加权

一条高新颖度方案可能设计依赖很强；一条易制作方案可能不够特异。创作选择应该**展示这些取舍**，而不是把它们加权成一个看似科学的 87.4 分。项目确实要量化时，需说明尺度、评价者、依据与不确定性。

## 「产品替换测试」不是简单通过／失败

- 若换成任何品牌完全不影响内容，可检查产品联系是否过弱。
- 但某些系列模板本来就为多个 SKU 设计，替换能力恰恰是目标。
- 评价必须回到任务。

# 适用边界

- 七个维度是本包的工作维度，不是经过验证的量表；「待验证」不得在没有证据时改写为「明确」。
- 第 01 篇同样反对没有测量依据的「创意 92 分」；评价理由可以是创作判断，但要可被行动。
