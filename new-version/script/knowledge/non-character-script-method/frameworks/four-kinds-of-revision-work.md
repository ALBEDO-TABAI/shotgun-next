# 要点

| 工作 | 处理什么 | 来源举例 |
|---|---|---|
| **修错** | 事实、结构、文字与状态矛盾 | 产品只有一个铰链却被写成两个 |
| **澄清** | 本来有效但难以接触的关系 | 观众不知道微距属于哪个部位 |
| **提升** | 内容已正确且清楚之后，再增加集中度、发现感、材料经验、形式回响或时间性格 | 见 [十二种提升操作](/methods/twelve-uplift-operations.md) |
| **改任务** | 用户改变主任务、受众、时长或版本 | 从「解释操作」转为「主要建立感受」 |

四者可能同时发生，但**应分开记录**：

- 只做修错，会得到无聊但正确的片子。
- 只做提升，可能把事实改掉。
- 把改任务当纠错，会导致无休止返工。

改任务不代表原稿一定很差，也不能伪装成小幅润色。

# 适用边界

- 这是本包为回修工作提出的分类（原创综合），不是文献中的既有分类法。
- 分类的目的是让每次改动知道自己的性质与该回到哪一层，不是增加文书；同一轮可以同时包含多种工作，只要记录分开。
