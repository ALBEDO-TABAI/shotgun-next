# 要点

| 连接 | 何时使用 | 作者应写清什么 | 典型修复 |
|---|---|---|---|
| 因果 | 解释作用和结果 | 谁作用于谁、条件是什么 | 补原因或限定表达，不凭结果倒推功能 |
| 理解前提 | 后段依赖前段信息 | 哪个对象或规则必须先被认识 | 提前锚点或合并解释 |
| 时间相继 | 同一世界继续发展 | 是否省略动作或经过时间 | 不让纯「之后」误变「因此」 |
| 对照 | 展示某维度差异 | 同尺度、同条件或明确条件差异 | 恢复可比较的参照 |
| 类比 | 用一个关系理解另一个 | 共享关系与不对应项 | 减少表面装饰，补共同关系 |
| 形式延续 | 保持运动、形状或节律 | 哪个变量延续，哪个改变 | 不靠万能形变转场掩盖无联系 |
| 分类 | 展示系列、模块和层级 | 总类、成员、合法组合 | 增加总图或明确标签 |
| 有意断裂 | 引入突变、并置或开放经验 | 为什么此处需要断裂 | 让新规则可辨认，而非自动补因果 |

这张表不要求每个转场出现文字解释，而是要求作者**在内部知道连接负责什么**。下游可以选择匹配剪辑、硬切、持续运动或声音桥，但不能因为某个转场好做而改变连接含义。

## 特别检查：共享方向不等于共享因果

叶片向下落，随后液体向下进入瓶子——两个动作方向相同，可能形成形式延续，也可能让人认为叶片就是配方原料。**仅标「形式连接」不能消除实际误读。**

可尝试的改法：

1. 把叶片置于独立展陈空间；
2. 不让它穿过瓶口；
3. 让真实产品动作有自己的清楚起点；
4. 用不同的并置关系而非变形替换。

若仍会形成具体成分含义，回到任务与事实层处理。

# 适用边界

- 八种连接是写作标记，不是叙事学的正式分类；相似、对照等非时间性联系的学术依据在第 01 篇讨论。
- 连接可以混合，但每个转场应能说出主要负责的一种。
