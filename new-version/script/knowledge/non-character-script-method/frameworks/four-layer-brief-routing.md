# 要点

## 四层描述各回答不同问题

| 层 | 典型说法 | 它实际描述什么 |
|---|---|---|
| 用途 | 品牌片、产品 TVC、电商片 | 这条片被拿来做什么 |
| 生产方式 | 3D、实拍、AI 生成 | 怎样被制作出来 |
| 体验或风格 | 清透、极简 | 希望呈现的感受或外观 |
| 组织方式 | 演示、分类、关系类比 | **内容怎样被组织起来** |

四层混在一起时，agent 容易把「做高级 3D 产品片」误解成已经有了一条创意。只有第四层才开始描述内容结构。

## 一句带主次的判断

> 本版本以【传播任务】为主，用【组织依据】组织内容，尝试【体验方向】，在【接收条件】下工作。

示例（教学项目）：「本版本以认出产品并看懂折叠为主，用真实操作与空间关系组织内容，尝试安静、精确的体验，在 30 秒、可静音的条件下工作。」

这句话没有解决全部创意，却排除了许多无关探索。

# 适用边界

- 判断句是路由工具，不是创意本身；填完之后仍需进入机制发散。
- 四个槽位分别由其它概念提供候选值，不要凭「广告」二字推断结构，也不要以「高级」直接推断材质。
