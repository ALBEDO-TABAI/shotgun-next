# 要点

## 六种组织依据

| 组织依据 | 依赖什么 |
|---|---|
| 事件 | 变化 |
| 演示 | 条件与作用 |
| 分类 | 共同准则 |
| 比较 | 可辨认差异 |
| 类比 | 关系映射 |
| 形式作品 | 不变量、变化和时间 |

它们可以混合，但混合不等于把所有方法同时塞进片子。

## 连接词测试

> 删去「然后」，能否用一个更明确的连接词说明两段关系？

| 能替换成的连接词 | 暴露出的组织依据 |
|---|---|
| 因为 | 因果 / 演示 |
| 与之相比 | 比较 |
| 同样的关系 | 类比 |
| 这是其中一种 | 分类 |
| 先前的局部原来属于…… | 披露 / 重新定位 |

也允许答案是「有意断裂」或「开放并置」，但这时要说明作品为何需要该选择。

# 适用边界

- 文献依据有限：Schmid 关于非时间性联系的讨论只支持「相似、对照等联系不必依赖事件的时间或因果链」[2]；把事件、比较、分类、类比、形式分别作为写作入口，是本包进一步提出的做法。
- 该来源不能被用来把所有抽象视频归为叙事，也不代表任意拼接都会有意义。
