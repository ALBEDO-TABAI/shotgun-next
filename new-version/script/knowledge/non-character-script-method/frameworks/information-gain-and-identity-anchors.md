# 要点

## 一段的信息贡献

一段结束后，观众可以新增：

- 对象身份；
- 部分与整体关系；
- 动作原因；
- 比较基准；
- 类别层级；
- 或者只是让已知关系变得更清晰。

不必每段新增事实，但应知道本段的贡献。「又看到一次产品」不必删——它可以承担重定位、名称识别或感官停留；只有当这些职责都已充分完成，才考虑它是否只是重复占时。

## 身份锚点—变化变量

| 项 | 写法 |
|---|---|
| 身份锚点 | 在变化中保持、供观众追踪的特征 |
| 变化变量 | 本段允许改变的特征 |

- 不必让所有特征都固定，只需明确观众追踪什么。
- 真实产品可保持瓶肩、盖体、标签区；抽象系统可保持图标、编号、特定形状或相对位置。
- **不能只靠颜色保持身份**，尤其当版本需要改配色、转为单色或压缩到小画面时。
- 可以设计「颜色＋轮廓」或「编号＋稳定位置」的冗余锚点。这里的冗余是有目的的识别支持，不是多写一份事实清单。

# 适用边界

- 「观众多了什么依据」是设计目标的表述，不是已测得的理解结果。
- 锚点设计属于内容条件；具体造型仍由美术提案。
