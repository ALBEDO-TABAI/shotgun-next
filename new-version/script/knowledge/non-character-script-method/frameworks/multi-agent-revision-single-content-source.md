# 要点

**核心约定**：当前剧本承担内容源；美术、镜头与声音可以保留各自工作文件，但引用**同一内容版本**。专业判断不同不等于多重事实真相；关键在于最终采用的改变在哪里确定，下游实际消费哪个版本。

| 角色 | 在回修中的职责 |
|---|---|
| **编剧 agent** | 接收变更，判断内容关系与职责变化，维护正文及其工作视图 |
| **导演 agent** | 对重要表达取舍、机制选择与版本任务进行判断 |
| **美术 agent** | 提出载体、材质、空间与对象方案，并指出会影响内容的部分 |
| **镜头与时序设计 agent** | 提出观察、连接和时间方案，标明是否改变披露与任务 |
| **用户** | 确认重要需求、方向与需授权事项；最终稿确认独立于内部自检 |

**升级规则**：无需让所有角色对每个小改都重复审批。只将改变内容含义、事实或用户选择的项提升处理。

# 适用边界

- 这是本包提出的协作约定（原创综合），本包不是已经安装或跑通的 agent，上述分工没有经过实际运行验证。
- 角色名沿用来源；来源未列声音 agent 的独立职责条目，只说明声音可保留自己的工作文件并引用同一内容版本。

> 待确认：各 agent 的实际权限边界与审批入口（谁可以直接执行实现内调整、谁有权接受内容关系变化）需由团队按真实系统确定；来源只给出原则。
