# 要点

## 四种工作标记

| 标记 | 含义（按来源用词理解） |
|---|---|
| 真实行为 | 呈现产品或对象实际会发生的行为 |
| 机制简化 | 对真实机制作省略或简化的呈现，例如省略复杂零件的结构图 |
| 感官类比 | 用另一对象或材料的经验来类比某种感受 |
| 自主抽象 | 不承担产品事实的独立艺术或形式世界 |

> 待确认：来源只列出四个标记名并给出例子，未给逐条定义；上表「含义」一列是按上下文的归纳，是否作为团队正式口径需人审。

标记**不是强制打在画面上的字幕**，而是作者与下游要共享的内容判断。

## 判断方式：按表达本身寻找依据

| 表达 | 处理 |
|---|---|
| 产品在艺术展陈中悬浮 | 不必成为重力研究 |
| 简化结构图省略复杂零件 | 可以成立 |
| 「产品的实际包装可展开为建筑」 | 可能承担具体产品主张，需要依据 |
| 「某成分进入皮肤后立即形成保护层」 | 可能承担具体产品主张，需要依据 |

两种都要避免：把所有美术世界锁成现实；把所有问题都用「艺术表达」抹掉。

# 适用边界

- 对图像与整体语境的重视可参照 FTC 的美国广告指导 [2]；它只提供美国机构的判断入口，**不是具体产品或目标市场的法律意见**，具体发布判断必须另按市场与品类处理。
- 超现实与抽象表达仍然可用，只需明确其与真实商品的联系及边界。
