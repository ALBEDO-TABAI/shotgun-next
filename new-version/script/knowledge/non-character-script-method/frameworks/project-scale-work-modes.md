# 要点

| 模式 | 包含什么 | 适用 | 不应声称 |
|---|---|---|---|
| 快速草案模式 | 一页 brief、两条短路线、一版内容骨架、少量设计问题 | 方向探索 | 资产已经可用 |
| 标准初稿模式 | 需求与事实卡、已选命题、正文、节拍、设计需求以及一次跨专业回修 | 初步剧本终点（本包所要求的交付） | — |
| 高依赖模式 | 在标准初稿之上，增加**一项**针对性资料核验或低成本代理试验 | 真实机构、科学机制、复杂空间变换或多版本依赖决定内容时 | 不是因为片子高端，就必须给所有动作做完整动态预演 |

- 三个模式共享同一工作逻辑，改变的是证据和展开程度。
- 反例：让一个只需六秒循环的任务，负担与完整系统说明片相同的流程。

# 适用边界

- 模式划分是本包的工作建议，没有对应的实证研究。
- 包 README 的适用边界另有同向提醒：不要把审慎变成流程负担，只阻塞依赖未知事实的部分，只在确有问题时做针对性验证（见 [证据分层与使用边界](/principles/evidence-and-use-boundaries.md)）。
