# 要点

| 时间性格 | 做法 | 适合 | 注意 |
|---|---|---|---|
| 先稳定再改变 | 让观众掌握规则后看出一次偏离 | 精确的形态或材料关系 | — |
| 先密集再澄清 | 从复杂的局部进入稳定全貌 | 发现与系统归类 | 前段不能只是无法恢复的噪声 |
| 均匀变奏 | 以共同规则承载长期观看 | 循环、陈列或节律作品 | 不必强加高潮 |
| 停顿与响应 | 动作之后留出明确响应，形成接触、弹性、到位等时间质感 | 动作经验 | 不意味着所有物体都要弹跳 |

同一动作采用不同时间性格时，**含义和设计要求都可能变化**，因此时间性格属于内容决定，不只是剪辑口味。

# 适用边界

- 四种是编排候选，不是情绪效果定律；来源没有提供任何受众实验支持「某性格必然产生某感受」。
- 可以在一条片内分段使用不同性格，但需知道每段为何如此。
