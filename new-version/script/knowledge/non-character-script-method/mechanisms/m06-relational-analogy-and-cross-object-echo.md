# 选择时机

目标概念难以直接拍出，但能找到另一个关系清楚的载体。

# 怎么生成

1. 把目标写成关系句；
2. 找三个不同领域的候选；
3. 列对应项与不对应项；
4. 选择映射最清楚且不过度解释的一个；
5. 让观众看到共同关系，再决定产品何时进入。

# 原创片段

要表达“不同部分保持独立而形成协作”，用几片各自沿固定轨道运动的叶状构件，在一处时刻对齐成连续通道；再由真实模块系统展示相应连接关系。不是因为叶片和模块同色，而是共同承担独立与协作。

> 该片段为本包原创虚构示例，不对应任何真实商品或已发布影片。

# 变体

不做形变转场，采用并置和重复动作；比直接将叶片变成产品更容易保留“类比而非组成”的边界。

# 设计条件

共享关系；身份锚点；过渡规则；不对应项。

# 故障修复

类比只能靠长旁白解释时，减少映射层数；完全移除产品就毫无损失时，重新寻找其参与位置。

关系类比理论（强调关系映射而非表面属性匹配）是本卡的研究入口，但来源仅核到摘要，本卡是原创应用而非该理论的逐项重建，见 [意图—关系—可见过程](/frameworks/intent-relation-process-translation.md)。
