# 选择时机

多系列、配件、软件状态或服务关系需要保持清楚；顺序可交换可能是优点。

# 怎么生成

1. 先给总类；
2. 制定一个稳定分组准则；
3. 以相同展示语法呈现差异；
4. 显示必要组合；
5. 回到总图或选择入口。

不要把颜色、用途、价格、形状混成同一层分类。

# 原创片段

一个底座先确立共同身份；三种真实配件分别接入同一位置；每个配件用同一节拍结构展示区别；最后只出现实际允许的组合。多个片段可以独立形成短版。

> 该片段为本包原创虚构示例，不对应任何真实商品或已发布影片。

# 变体

先展示不同结果，再揭示其共用的核心平台。这改变披露结构，但保持分类关系。

# 设计条件

类别；成员；配对；标签规则。

# 故障修复

片子像目录时，可增加一次能体现组合意义的关系变化；但不必为解决“像目录”而强行增加人物冲突。
