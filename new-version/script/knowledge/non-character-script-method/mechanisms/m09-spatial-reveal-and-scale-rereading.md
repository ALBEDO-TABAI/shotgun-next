# 选择时机

局部与整体、内与外、容纳与被容纳的关系能提供发现价值。

# 怎么生成

1. 建立局部参照；
2. 明确当前边界；
3. 扩大或改变观看范围；
4. 让先前内容在新层级中重新定位；
5. 最后决定落到真实空间还是艺术世界。

# 原创片段

一个浅色弧面先作为抽象表面被接触；范围扩展后，弧面被认作杯口内缘；再出现完整杯子与桌面。物体不变，观看者重新定位。

> 该片段为本包原创虚构示例，不对应任何真实商品或已发布影片。

# 变体

从盒内进入一个刻意不可能的展陈空间。此时不是宏观实拍放大，而是艺术世界切换，需要另写内外边界与产品身份保持方式。

# 设计条件

内外表面；尺度参照；局部对应；转换规则。

# 故障修复

连续穿越难实现时可分开观察，但保留入口和对应线索；不能让工具方便性决定出现一套无关空间。
