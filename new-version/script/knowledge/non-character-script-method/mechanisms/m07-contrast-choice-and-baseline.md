# 选择时机

要让人分清变体、前后状态、材料表现或合法组合。诗性对照与性能证明应分别处理。

# 怎么生成

1. 只选本段要比较的维度；
2. 固定必要参照；
3. 决定同时并置还是先后呈现；
4. 写出标签与辨认窗口；
5. 检查对照是否暗含“哪一个更好”。

# 原创片段

三种杯型按相同姿态与尺度依次放在同一展示位置，再并列出现；每种名称和对应口沿清楚。任务是帮助选择，不必为其编出优劣等级。

> 该片段为本包原创虚构示例，不对应任何真实商品或已发布影片。

# 变体

先建立一种杯型，再只改变色彩，使“同型不同色”的关系更直接。若同时改形状和颜色，则需要承认比较维度增加。

# 设计条件

基准；变体；标签；组合合法性。

# 故障修复

横版并置在竖版看不清时，可改成先后对照，但应补身份和稳定位置，不是简单裁掉一边。
