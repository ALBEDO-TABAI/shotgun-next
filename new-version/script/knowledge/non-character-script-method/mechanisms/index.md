# 机制卡 · Mechanism Cards

十二张内容机制卡 M01–M12：选择时机、怎么生成、原创片段、变体、设计条件、故障修复。

* [M01｜累积揭示与身份重构](m01-cumulative-reveal-and-identity-reframing.md) - 用能互相补充的局部线索累积到整体辨认；重要的不是露出得晚，而是前文不白看。适合辨认、发现或展示结构的任务。
* [M02｜条件—作用—结果的演示](m02-condition-action-result-demonstration.md) - 围绕唯一要解释的关系，写清初始条件、作用者与作用位置、关键中间态和结果；先分清是说明怎么发生，还是证明性能达到多少。
* [M03｜结构展开与部件层级](m03-structural-unfolding-and-part-hierarchy.md) - 给出整体锚点后，按内容需要而非零件数量分组，每次只展开一个有信息价值的层级，最后回到可辨识整体。前提是有准确结构资料，或明确是非真实艺术装置。
* [M04｜接触、顺应、恢复与痕迹](m04-contact-compliance-recovery-trace.md) - 以作用对象、接触区域、固定边界、形变传播和卸载后的去向组织触感内容；先分清真实产品与代理材料。
* [M05｜流动、汇聚、分离与路径](m05-flow-convergence-separation-path.md) - 指定源与终点、边界、相遇规则和末态来组织流动内容；不默认高速飞溅，不把流速直接当黏度，警惕汇入包装被读成原料组成。
* [M06｜关系类比与跨对象呼应](m06-relational-analogy-and-cross-object-echo.md) - 把难以直接拍出的目标写成关系句，跨领域找载体，列出对应项与不对应项，让观众先看到共同关系，再决定产品何时进入。
* [M07｜对照、选择与保持基准](m07-contrast-choice-and-baseline.md) - 只选本段要比较的维度，固定必要参照，决定并置还是先后，写出标签与辨认窗口，并检查对照是否暗含优劣。诗性对照与性能证明分开处理。
* [M08｜重复、变奏与规则偏离](m08-repetition-variation-and-rule-deviation.md) - 确定一条不变量并先让它被认识，每次只改一个主要变量，再决定是否偏离以及回归、重组或继续。没有新卖点也可以有有效变化。
* [M09｜空间揭示与尺度重读](m09-spatial-reveal-and-scale-rereading.md) - 建立局部参照与当前边界，扩大或改变观看范围，让先前内容在新层级中重新定位，再决定落到真实空间还是艺术世界。物体不变，变的是观看者的定位。
* [M10｜分类系统与模块组合](m10-classification-system-and-modular-combination.md) - 先给总类和一个稳定分组准则，以相同展示语法呈现差异，只显示必要且合法的组合，再回到总图或选择入口。顺序可交换可以是优点。
* [M11｜过程痕迹与来源联系](m11-process-trace-and-origin-link.md) - 选一个可持续追踪的痕迹，明确它如何形成，保留前后同一部位，用成品回应，并标明是实际过程、代表过程还是艺术演绎。前提是事实资料足够。
* [M12｜循环、任意进入与持续空间](m12-loop-any-entry-and-continuous-space.md) - 为展厅、门店、舞台或直播背景选可持续规则与变化范围，决定常驻信息，检查任意进入能否接触主任务，并设计周期边界或有意重启。
