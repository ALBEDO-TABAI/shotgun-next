# 选择时机

制造、时间、工艺、使用痕迹或来源是核心，而且事实资料足够。

# 怎么生成

1. 选择一个能够持续追踪的痕迹；
2. 明确它如何形成；
3. 保留前后同一部位；
4. 用成品再次回应；
5. 标明实际过程、代表过程或艺术演绎的性质。

# 原创片段

真实加工资料中，一处表面纹路随工序出现；随后成品同一区域被看见；整体展示使纹路成为身份细节。无需加入没有依据的工匠传承故事。

> 该片段为本包原创虚构示例，不对应任何真实商品或已发布影片。

# 变体

只展示已确认表面的不同状态，不声称还原制造过程；或者采用明确的艺术装置表现“时间留下关系”，不冒充该 SKU 的来源记录。

# 设计条件

来源依据；对应部位；过程状态；身份连续。

# 故障修复

漂亮木屑不能自动证明手工制造，植物和产地风光也不能自动证明成分；资料不足就换表达任务，而非补造来源。
