# 选择时机

形式、节律、系列感或运动性格是主要内容。没有新卖点也可以有有效变化。

# 怎么生成

1. 确定一条不变量；
2. 先让它被认识；
3. 每次挑一个主要变量变化；
4. 决定是否出现偏离；
5. 最后选择回归、重组或继续。

不要把三种完全无关素材称作变奏。

# 原创片段

六枚圆角图块按共同轴翻转；第二轮仍翻转，但相位逐次延后，形成响应；第三轮停在不同角度，得到空间层次。对象与规则保持，时间关系变了。

> 该片段为本包原创虚构示例，不对应任何真实商品或已发布影片。

# 变体

取消明显高潮，让每轮只产生细微差异，适合环境视觉；或者将一次偏离对应某个真实系列差异，适合产品陈列。

# 设计条件

参数化变体；相位；停止条件；身份数量。

# 故障修复

单调时先改变量或段落职责，不必不断引入新材质；嘈杂时减少同时改变的维度。
