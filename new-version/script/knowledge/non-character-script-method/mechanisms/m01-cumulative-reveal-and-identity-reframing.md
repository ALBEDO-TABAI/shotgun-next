# 选择时机

目标是辨认、发现或展示某个结构；产品有足以建立联系的局部，且时长允许一定阅读过程。

# 怎么生成

1. 先列三条可确认的身份线索；
2. 写出每条线索单独能让人知道什么；
3. 挑能**互相补充**的两条，而非最漂亮的两条；
4. 最后让完整对象回应它们。

重要的不是“露出得晚”，而是前文不白看。

# 原创片段

一道可转动的弧形边缘先被看见；下一条线索显示它与固定基座相连；第三段给出完整桌面镜，前两条线索变成镜体支撑结构。产品始终完整，改变的是披露。

> 该片段为本包原创虚构示例，不对应任何真实商品或已发布影片。

# 变体

开头就认出镜子，随后逐步揭示其调节关系——从身份悬念改成结构发现，适合更短或更说明性的版本。

# 设计条件

准确整体；局部对应；遮挡或观察范围；不能提前泄露的信息；最终识别窗口。

# 故障修复

若局部像无关首饰，添加关系线索或提前给出类别，不要只增加更多微距。
