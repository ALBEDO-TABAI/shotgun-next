# 选择时机

必须让人知道如何操作、连接、开合或发生变化，并有相应事实依据。

# 怎么生成

1. 写出要解释的**唯一**关系；
2. 选择能显示初始条件的参照；
3. 将作用者和作用位置写清；
4. 保留关键中间态；
5. 最后给出结果。

先决定这是“说明怎么发生”，还是“证明性能达到多少”；后者不能仅靠精美模拟。

# 原创片段

一只真实可折叠支架处于平放状态；局部操作手抬起活动面；支撑件卡入已确认的位置；设备放上后关系稳定。内容是展开与支撑，不是夸大的承重测试。

> 该片段为本包原创虚构示例，不对应任何真实商品或已发布影片。

# 变体

在明确展陈语境中并列三个姿态，不呈现操作过程。这样降低动作需求，却不能声称完整解释了操作方法。

# 设计条件

作用界面；固定参照；起、中、终状态；接触与遮挡；结果承托。

# 故障修复

如果只看见物体变好了，优先补作用，或降低该段承担的解释任务。
