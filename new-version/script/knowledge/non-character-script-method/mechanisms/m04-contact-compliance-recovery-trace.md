# 选择时机

触感、柔软、弹性、承托、脆性或表面接触是核心。首先明确真实产品与代理材料的区别。

# 怎么生成

1. 选择作用对象；
2. 指定接触区域与固定边界；
3. 决定变形如何传播；
4. 决定卸载后是恢复、保持还是留下痕迹；
5. 选择一条能帮助观看者追踪过程的稳定参照。

# 原创片段

独立织物跨在两个固定点之间；一件圆润物体接触中部，织物形成连续包围但不完全吞没；物体离开后，织物回到悬置状态。希望建立的是顺应与支撑的并存，而不是无条件“越软越好”。

> 该片段为本包原创虚构示例，不对应任何真实商品或已发布影片。

# 变体

将织物改为薄硬片，其弯曲与恢复更克制，表达方向可能转为韧性——关系相似、体验不同的候选。

# 设计条件

作用源；接触；形变边界；基态和恢复态。

# 故障修复

感觉黏腻时，可改离开方式、接触面积或时间尾部；不要只换成浅色。真实产品的材料属性不能因更好看而被改写。

来源提示材料知觉涉及光学、形状与运动多种线索且权重随条件改变；该研究入口见 [意图—关系—可见过程](/frameworks/intent-relation-process-translation.md) 的证据说明，本卡本身是原创工作工具。
