# 选择时机

部件关系本身值得理解，且有准确结构资料；或明确是非真实的艺术装置。

# 怎么生成

1. 给出整体锚点；
2. 按内容需要而不是零件数量分组；
3. 每次只展开一个有信息价值的层级；
4. 保持连接方向或相应标签；
5. 最后回到可辨识整体或清楚的分组图。

# 原创片段

虚构模块音箱的外壳与两件获确认可替换模块分层移开；接口位置保持一致；只解释其中一个模块的装配关系；其余部分回归整体。不凭空补入复杂芯片和声学结构。

> 该片段为本包原创虚构示例，不对应任何真实商品或已发布影片。

# 变体

不拆内部，改为外部配件依次与同一主体组成不同用途。这样仍能讲层级和组合，减少对未知内部的依赖。

# 设计条件

零件身份；接口；内部可见面；数量与组合规则。

# 故障修复

“全部炸开”难读时先改分组与顺序，再考虑速度；慢放一团零件不一定能解释层级。
