# 选择时机

内容涉及流动方向、覆盖、相遇、分配或物质体验。不得默认所有液体都该高速飞溅。

# 怎么生成

1. 指定源与终点；
2. 决定边界是否存在；
3. 选择相遇时混合、并行、绕行还是排斥；
4. 明确最终状态承接什么任务。

选择行为参照时同时考虑作用力，不把流速直接当黏度。

# 原创片段

两股独立色液在透明的平行槽中流动，经过相同曲线后到达并列容器；两者始终不混合。若用于两款产品陈列，内容可为共同系列与差异，而不是配方融合。

> 该片段为本包原创虚构示例，不对应任何真实商品或已发布影片。

# 变体

改用颗粒、纸片或图形沿路径运动，保持“并行而不混合”的关系；可能减少真实成分含义，也可能损失液体体验。

# 设计条件

来源；容器；接触表面；路径；混合规则；末态。

# 故障修复

结尾汇入包装容易讲成原料组成；改成独立并置或明确真实依据，而非只加内部注释。

来源 §2 引用的液体黏度视觉研究提示外力与材料因素需区分（“不把流速直接当黏度”与之呼应）；证据范围见 [意图—关系—可见过程](/frameworks/intent-relation-process-translation.md)。
