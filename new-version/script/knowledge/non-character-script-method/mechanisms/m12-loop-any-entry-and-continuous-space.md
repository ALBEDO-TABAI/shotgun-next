# 选择时机

展厅、门店、舞台或直播背景；主要任务不是从零讲完一个结论。

# 怎么生成

1. 选可持续规则；
2. 确定变化范围；
3. 决定哪些信息常驻；
4. 检查任意进入能否接触主任务；
5. 设计周期边界或有意重启方式。

# 原创片段

三个不同厚度的弧环在独立层级中缓慢错位，偶尔构成共同轮廓；标识在不干扰运动的区域常驻。观看者无需等开头，主要经验是关系不断重组。

> 该片段为本包原创虚构示例，不对应任何真实商品或已发布影片。

# 变体

用同一循环模板容纳真实产品配色，每个周期仅更换一个系列成员；但要保证变体身份清楚且循环不制造虚假产品组合。

# 设计条件

首尾状态；运动方向；对象数量；持续识别；文字层。

# 故障修复

只接上两张首尾图却出现速度跳变时，检查变化趋势；内容本来无需无缝，不必为炫技强制无缝。
