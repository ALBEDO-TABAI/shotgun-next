# 本篇回答什么问题

现实创作案例支持了哪些方向？怎样研究案例，而不是只收集好看的作品；怎样把一个真实项目读成可用的创作操作，又不把它写成成片逆向工程或成功学结论。

研究对象是创作者／出品机构的公开文字、项目说明和署名，不是其未公开的原始剧本。原创内容胚不是原片镜头转录。

# 输入与产物

- **输入**：当前 brief 与事实卡；需要案例支撑、替代机制，或「参考只能模仿外观」的情形。
- **产物**：每例一张事实卡与一张迁移卡；一段适配本项目的原创内容胚；必要设计条件；下一步最值得检验的问题。

# 核心主张

1. 每例明确分开「公开依据」「方法提取」「原创练习」；第三层以后是方法综合，不能写成原导演就是这样创作的。
2. 「不知道内部流程」不妨碍提出有用的新方案：未知的是历史还原，不是今天的创作能力。
3. 研究单位可以小于一支片：一个触觉实验、一种披露策略、一条声画规则都可迁移。
4. 借的是操作与关系，不是品牌外观、IP、旧事实或夸大表述；每例都有「最容易误借的东西」。
5. 多个参考同时借用时，先检查机制冲突；减少一个世界往往比再找一个更好看的参考有效。
6. 补非叙事能力不等于放弃叙事：路由写「本段由什么组织」，而不是「本片有没有人」。
7. 创作参考回答「可以怎样表达」，事实资料回答「这个产品实际是什么」，二者不能互相代替。
8. 研究提供一种可写操作、一个必要条件和一个可迁移方向后，就该去写自己的内容。
