# 本篇回答什么问题

初步剧本应该组织什么？不只是「下一段放什么」，而是三件事同时成立：**世界里发生什么、观众获得什么、这一段如何占用时间**。同一句含糊动作可能是对象变形、遮挡移开或观察位置改变，三者需要的资产、事实依据与镜头方案都不同。

# 输入与产物

| 项 | 内容 |
|---|---|
| 输入 | 已选表达命题（来自 [01 能力定位与连续创作路径](/topics/01-capability-and-creative-path.md) 或 [03 创意生成与可见过程构造](/topics/03-idea-generation-and-visible-process.md)） |
| 产物 | 有职责、有连接依据、有暂定时间的内容节拍 |
| 性质 | 状态表、连接标记和时间工作法为原创综合，不是心理学量表 |

# 核心主张

1. 编排拆成世界线、信息线、时间体验线三条线，并留在同一内容版本里，不由三个 agent 各自保留剧情解释。
2. 「观众获得」是设计目标，不是已观测结果。
3. 状态变化有四种来源；呈现范围变化与解释变化是披露，不应被写成世界里的魔法变形。
4. 中间态是否必要，看删去后能否区分「同一对象变化」与「换了一件东西」；省略可以，但要标明因此不承担的任务。
5. 节拍按主要内容职责划分，节拍编号是内容引用，不是镜头订单。
6. 作者在内部要知道每个段落连接负责什么；共享方向不等于共享因果，标注「形式连接」不能消除实际误读。
7. 顺序由理解依赖决定；演示顺序不等于产品技术依赖，不得据此补造规格。
8. 时间是给不同关系分配出现机会；超时先减任务竞争再动速度，交付版本的预算必须可加总。

# 证据骨架与边界

| 依据 | 可以据此说什么 | 本包进一步提出什么 |
|---|---|---|
| 事件分割研究 [2]、电影叙事学条目 [3] | 事件边界不等同于剪切点；变化可在镜头内或镜头间呈现 | 以内容职责划分节拍，镜头划分留给时序设计 |
| 动画理解研究综述 [4] | 动画不会自动让复杂关系易懂；太快、太复杂或不匹配会出问题 | 用观察任务决定时间预算 |
| 材料知觉研究 [5][6] | 材料判断依赖外观、形状、动态与作用场景 | 写清作用与场景，而非只写材质名 |
| 跨感官对应综述 [7] | 不同感官特征之间可能存在对应 | 选一个主要变化，让声音跟随、先行、滞后或独立 |
| NFB《Synchromy》说明 [8] | 声画可以有直接组织关系 | 作品本体是声画对应时，前期共同设计规则 |

- 这些研究不是广告最佳秒数的来源，也没有证明所有变化越慢越好；本篇字段、阈值与例子均需在项目中检验。
- S08、S14 本次仅核到摘要；《Synchromy》未逐帧转录。
- 全包证据分层见 [证据分层与使用边界](/principles/evidence-and-use-boundaries.md)；贯穿项目见 [「一页」教学项目总览](/examples/yiye-lamp-project-overview.md)。
