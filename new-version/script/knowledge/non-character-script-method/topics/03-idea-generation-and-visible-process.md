# 本篇回答什么问题

当需求只有“清透、精密、舒展”这类形容词时，怎样构想出**具体发生的内容**——而不是再给一份素材词典、一篇非叙事理论或一串生成提示词。

# 输入与产物

| | 内容 |
|---|---|
| 输入 | 任务、产品事实与体验意图（通常来自 [01 能力定位与连续创作路径](/topics/01-capability-and-creative-path.md)） |
| 输出 | 可比较的创意路线，以及可继续写作的片段 |
| 性质 | 本篇所有机制卡、操作算子和虚构片段都是**原创工作工具** |

# 核心主张

1. 素材（水、齿轮、漂浮、发光线）不能自动决定发生什么、为什么、产品如何参与、前后有何变化；缺的是“意图 → 关系 → 可见过程”这一中间层。
2. 起笔不必从形容词或人物故事开始，可以从产品关系、材料行为、空间关系、形式、不可直接拍到的关系出发。
3. 体验词只产生**候选关系**，不宣称固定对应；每次都要主动写出一个可能的相反解读。
4. 发散靠改变关系（承载者、披露、变量、尺度、关系类型、规则扰动），不是换颜色；组合必须过“服务主任务／产品联系／可写过程”三问。
5. 机制卡不是任意菜单：主机制完成主任务，辅助机制必须解决一个具体问题，说不清贡献就先移除。
6. 对多条路线施加同一限制，是为了看清各自依赖什么，不是证明对象越少越好。
7. 不够有个性时升级内容（母题、前后回响），而不是升级形容词。
8. 参考作品只借一个操作，不借整套外观、产品事实与 IP。

# 证据骨架与边界

| 依据 | 可以据此说什么 | 本包进一步提出什么（原创综合） |
|---|---|---|
| [S02 Material Driven Design](/references/s02-karana-material-driven-design.md) | 材料要放在感官、意义、情感和行动的整体关系中看，而不是只看表面 | 从材料行为起笔；M04／M05 |
| [S06 Structure-Mapping](/references/s06-gentner-structure-mapping.md)（仅摘要） | 类比关注对象间关系的映射，区别于表面相似 | M06 类比工作卡——原创应用，未逐项重建该理论 |
| [S15 视觉修辞类型学](/references/s15-phillips-mcquarrie-visual-rhetoric.md)（仅摘要、题录） | 视觉修辞可按复杂度与歧义等维度分析 | 本包机制分类**不是**论文原表 |
| [S16 软硬推断线索](/references/s16-schmidt-stiffness-cues.md)、[S07 液体视觉知觉](/references/s07-van-assen-liquid-perception.md) | 作用过程、形状、外观和场景共同影响材料判断 | 机制卡要求写清作用源、边界与参照 |
| [C01 Purple](/references/c01-manvsmachine-purple.md)、[C02 Hublot](/references/c02-tendril-hublot-mp10.md)、[C06 Synchromy](/references/c06-nfb-synchromy.md) | 创作者公开的任务与做法 | “借操作，不借外观”的三个示例 |

- “定义关系 → 选承载对象 → 设计作用或规则 → 安排披露 → 检查相反解读”是本包综合，**不是上述论文直接提供的广告配方**。
- 材料体验不能保证审美效果，类比成立也不保证观众必然理解；尚无证据的感受一律标为意图。
- 不能据本篇推出“材质与情绪一一对应”等结论，总体边界见 [证据分层与使用边界](/principles/evidence-and-use-boundaries.md)。
