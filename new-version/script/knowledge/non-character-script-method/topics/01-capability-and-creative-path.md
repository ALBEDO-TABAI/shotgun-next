# 本篇回答什么问题

已有知识知道怎样「理解非叙事」，真正的缺口是一条**连续的创作路径**。本篇以三个问题组织：

1. 没有人物情节时，哪些东西可以承担组织力？
2. 从模糊 brief 到初稿，中间必须发生哪些创作决定？
3. 怎样允许设计反过来改善内容，同时不把职责分成更多彼此重判的 agent？

定位：初步剧本阶段的创作知识，不是安装完成的 skill。文中的工作分类、流程、表格与教学项目属于方法综合；文献所支持的有限结论另行注明。

# 输入与产物

- **输入**：一条 brief（一句需求、已有创意或初稿、或参考片）及已有产品事实。
- **产物**：一页任务定义、一个可写的表达命题、机制不同的候选路线、选定路线的内容骨架及设计问题。
- 完整正文与设计清单在第 05 篇展开；本篇不重复生成另一份「最终稿」。

# 核心主张

1. 没有人物不等于没有事件；是否人物叙事取决于内容是否围绕人的目标、行动与关系展开，而不是画面里是否出现一只手。
2. 「什么类型的广告」不是足够精确的路由条件：用途、生产方式、体验风格、组织方式是四层不同描述，只有最后一层才开始描述内容结构。
3. 初步剧本不是缩小版分镜：前置的是使表达成立的关系，不是无差别前置所有技术参数。
4. 工作地图有三条轴：传播任务（本版结束时得到什么）、组织依据（推进力来自哪里）、真实性层级（正在呈现哪一种世界）。
5. 收到 brief 先拆成事实、意图、偏好、交付条件，只追问会改变路线的问题。
6. 先生成机制不同的少量路线，用相同细化程度比较，以关系选择并写出牺牲；不用没有测量依据的分数。
7. 只回退到必要层级；三种输入入口、三种规模模式共享同一逻辑，不必每次重跑全流程。
8. 按决策类型分主责：改变内容的提议必须回到内容源，不因只多写几个字而算小改。

# 证据骨架与边界

| 调研问题 | 搜集到的依据 | 可以据此说什么 | 本包进一步提出什么 |
|---|---|---|---|
| 是否只有因果情节才能组织内容 | Schmid 的非时间性联系讨论 [2] | 相似与对照也是组织联系 | 将事件、比较、分类、类比、形式分别作为写作入口 |
| 问题理解与方案形成能否分开工作 | Design Council 的过程框架 [3] | 可以区分理解问题、定义问题和发展方案，并允许迭代 | 为轻量 AI 项目设计可回退但不重复审批的工作路径 |
| 动态品牌项目是否存在脚本职责 | Ordinary Folk 的流程及 Webflow 署名 [4][5] | 该机构的实践明确包含脚本与设计等不同职能 | 在现有编剧 agent 中补能力，而不是按片型再建角色 |
| 方案是否值得先并列再精修 | Dow 等人的原型实验 [6] | 在图形网页广告设计任务中，并行原型有积极结果 | 用相同细化程度比较少量不同机制，避免只精修第一个方向 |

- 这些来源来自叙事学、设计实践、设计实验和真实项目，证据类型不同；它们共同提供工作入口，**并没有直接验证「本包的七步流程是最优 AI 影视流程」**。
- 真实性层级中对图像与整体语境的重视参照 FTC 的美国广告指导 [7]，它不是具体产品或目标市场的法律意见。
- 全包的证据分层见 [证据分层与使用边界](/principles/evidence-and-use-boundaries.md)。
