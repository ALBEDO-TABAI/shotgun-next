# 主题枢纽 · Topic Guides

每篇来源文档一个入口：回答什么问题、输入与产物、核心主张、本篇概念清单、与其它篇的交接、证据骨架。

* [01 能力定位与连续创作路径](01-capability-and-creative-path.md) - 从「理解非叙事」到「能够写出来」：没有人物情节时什么承担组织力，从模糊 brief 到初稿之间必须发生哪些创作决定，以及设计如何反过来改善内容。
* [02｜对象、信息与时间体验的联合编排](02-object-information-time-orchestration.md) - 第 02 篇枢纽：初步剧本组织的不只是事件，还有观看和感受——把已选表达命题编排成有职责、有连接依据、有暂定时间的内容节拍。
* [03｜怎样真正构想内容：从体验词到关系，再到可见过程](03-idea-generation-and-visible-process.md) - 第 03 篇枢纽：五个起笔入口、体验词转译、六个创意操作、十二张机制卡与选择矩阵，以及阅读灯、香氛、抽象循环三个原创推演。输入任务与事实，输出可比较的创意路线与可写片段。
* [04｜一手案例研究与方法迁移](04-primary-case-research-and-transfer.md) - 第 04 篇枢纽：九个创作者一手项目怎样成为可用方法。逐例分开公开依据、方法提取与原创迁移，并给出横向比较、完整迁移演练、参考库与退出条件。
* [05 初步剧本写作与设计需求交接](05-script-writing-and-design-handoff.md) - 把创意写成能被设计的内容：在印象过粗与实现过细之间建立中间层，产出一版可阅读初稿、一张内容节拍表、一份有消费位置的设计需求。
* [06｜创意优化、验证与多 Agent 回修](06-optimization-validation-and-multi-agent-revision.md) - 第 06 篇枢纽：优化不只是纠错。区分四种回修工作，用十二种操作提升表达，示范一页阅读灯 V0→V1→V2 与 30／15／6 秒改写，并给出验证方法、变更消费流程、skill 执行契约与十四项待运行评估情境。
