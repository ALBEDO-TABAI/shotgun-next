# 非人物初步剧本方法知识包 · Overview

母题：**非人物初步剧本**——没有人物冲突时，怎样把产品、对象、材料、空间、信息和感受在时间中的展开写成可被设计的内容：从任务路由与路线选择，到状态／信息／时间编排、机制构想、一手案例迁移、初稿与设计需求交接，再到升级、验证、版本改写与多 agent 回修。来源为《非人物初步剧本｜六专题深化知识包 V2》（研究查验 2026-09-18）。

使用前先读 [证据分层与使用边界](principles/evidence-and-use-boundaries.md)：研究结论、创作者自述、本包建议与原创教学内容分层标识；本包是知识资料，不是已跑通的 agent，未做视频生成、材质实测或受众测试。

# 主题枢纽 · Topics

* [01 能力定位与连续创作路径](topics/01-capability-and-creative-path.md) - 从「理解非叙事」到「能够写出来」：没有人物情节时什么承担组织力，从模糊 brief 到初稿之间必须发生哪些创作决定，以及设计如何反过来改善内容。
* [02｜对象、信息与时间体验的联合编排](topics/02-object-information-time-orchestration.md) - 第 02 篇枢纽：初步剧本组织的不只是事件，还有观看和感受——把已选表达命题编排成有职责、有连接依据、有暂定时间的内容节拍。
* [03｜怎样真正构想内容：从体验词到关系，再到可见过程](topics/03-idea-generation-and-visible-process.md) - 第 03 篇枢纽：五个起笔入口、体验词转译、六个创意操作、十二张机制卡与选择矩阵，以及阅读灯、香氛、抽象循环三个原创推演。输入任务与事实，输出可比较的创意路线与可写片段。
* [04｜一手案例研究与方法迁移](topics/04-primary-case-research-and-transfer.md) - 第 04 篇枢纽：九个创作者一手项目怎样成为可用方法。逐例分开公开依据、方法提取与原创迁移，并给出横向比较、完整迁移演练、参考库与退出条件。
* [05 初步剧本写作与设计需求交接](topics/05-script-writing-and-design-handoff.md) - 把创意写成能被设计的内容：在印象过粗与实现过细之间建立中间层，产出一版可阅读初稿、一张内容节拍表、一份有消费位置的设计需求。
* [06｜创意优化、验证与多 Agent 回修](topics/06-optimization-validation-and-multi-agent-revision.md) - 第 06 篇枢纽：优化不只是纠错。区分四种回修工作，用十二种操作提升表达，示范一页阅读灯 V0→V1→V2 与 30／15／6 秒改写，并给出验证方法、变更消费流程、skill 执行契约与十四项待运行评估情境。

* [框架 · Frameworks](frameworks/) - 概念区分、分层模型、分类轴与对照表：传播任务、真实性层级、三线编排、披露、时间、连接、变更分类等。（27 个）

* [一手案例研究 · Case Studies](cases/) - 九个真实项目（C01–C09）：公开依据与本包提取的方法、原创迁移分开写；不是成片逆向工程。（9 个）
* [原创教学推演 · Worked Examples](examples/) - 原创虚构项目：“一页”阅读灯 V0／V1／V2／15s／6s、三色杯、香氛、材料片段、系统片、循环装置等。（24 个）
* [检查清单 · Checklists](checklists/) - 症状—修复表、诊断树、失败模式、评估情境与完成标准。（8 个）
* [模板 · Templates](templates/) - 可直接填写的任务卡、编排工作表、路线比较卡、案例记录、初稿与需求模板、测试记录。（8 个）
* [Skill 接口 · Skill Interfaces](skills/) - 各篇给 agent 的执行指令、输入输出、停止／退出条件与执行契约。（6 个）
* [练习 · Exercises](exercises/) - 各篇练习与示范判断。（4 个）
* [原则与边界 · Principles](principles/) - 证据分层、案例证据限度、决策归属、借操作不借外观、版本与检查结果不互相冒充。（7 个）
* [外部来源镜像 · References](references/) - 26 项来源（S01–S17 文献与方法，C01–C09 案例一手页面），含查验范围、支持的有限要点与不能外推之处。（26 个）
