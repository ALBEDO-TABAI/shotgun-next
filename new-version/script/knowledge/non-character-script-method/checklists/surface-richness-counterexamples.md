# 要点

| 反例 | 症状 | 先问 / 先做 | 不应做 |
|---|---|---|---|
| 一、十个世界，十次产品出现 | 可能是分类陈列，也可能是任意拼贴 | 每个世界是否同属一条分类规则，还是分别承担不同感受？若没有关系，用**一个更具体的变化**替代三个无关环境 | 只改转场 |
| 二、过早指定导演风格 | 「像某导演」被当成内容 | 把参考翻译成可行动选择：倾向持续观察、空间揭示、物体接触、对称破坏还是声音反差；再判断哪些适合本任务 | 让参考替代内容 |
| 三、所有未知都问用户 | 创作责任被包装成几十个问卷 | 向用户询问**事实与重要意图**；将审美实现作为有理由的提案 | 假定用户不期待 agent 帮忙构想 |
| 四、为了稳定，把创意全部删掉 | 难实现就退回静态产品图 | 先区分核心关系与实现形式；改变接触方式、减少同时运动、保留关键中间态 | 用工具失败证明用户只能接受静态产品图 |

# 适用边界

- 这是诊断启发，不是验收标准；每条都需要回到具体任务判断。
- 反例一中「分类陈列」本身是合法的组织依据，问题只在于是否存在共同准则。
