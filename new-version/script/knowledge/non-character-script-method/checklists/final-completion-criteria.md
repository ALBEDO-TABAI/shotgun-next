# 要点

## 三件产物各自的标准

| 产物 | 不只是 | 还应该 |
|---|---|---|
| 初步剧本 | 没有明显错误 | 知道自己为什么值得这样展开 |
| 设计需求 | 列出对象 | 让专业能提出方案 |
| 一轮回修 | 生成新文件 | 让下游真的消费新的内容关系 |

## 每轮结束时的五问

- [ ] 本轮**改善了什么**？
- [ ] **牺牲了什么**？
- [ ] **证据支持到哪里**？
- [ ] 哪些**决定已经生效**？
- [ ] 接下来**由谁做什么**？

终点不是把创意锁死，而是建立可前进的秩序。

# 适用边界

- 初步剧本的完成，与最终生产、用户确认、受众效果是不同状态；达到本标准不代表后三者成立。
- 五问是记录要求，不是审批关卡；不要把审慎变成流程负担，只阻塞依赖未知事实的部分。
