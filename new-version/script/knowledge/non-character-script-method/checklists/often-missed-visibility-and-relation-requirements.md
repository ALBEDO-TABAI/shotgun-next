# 要点

## 七个常漏问题

- [ ] **反射**：产品需要形成什么反射边界？
- [ ] **透明**：透明容器需要哪些前后层次可辨？
- [ ] **开合**：开合动作会露出哪一侧？
- [ ] **薄片**：薄片之间会不会穿插？
- [ ] **表面运动**：表面上发生的运动是否需要厚度？
- [ ] **局部回整体**：局部回到整体时靠什么定位？
- [ ] **字卡**：是否需要精确语言版本？

## 写成结果要求，而不是唯一实现

| 写法 | 例子 |
|---|---|
| 结果要求（推荐） | 「瓶身右侧边缘需与背景分离，标签不能被主要反射完全遮住」 |
| 唯一实现（不必由编剧给出） | 先安排具体反光板尺寸 |

## 判断

对于初步剧本，**够用的几何、关系和可见条件**通常比一份极细的审美形容词列表更接近下游需求。

# 适用边界

- 这不是否定美术探索；美术仍需在这些条件下寻找更有表现力的结果。
- 清单只列常见遗漏，不是穷尽的需求分类。
