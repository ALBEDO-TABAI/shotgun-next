# 一手案例研究 · Case Studies

九个真实项目（C01–C09）：公开依据与本包提取的方法、原创迁移分开写；不是成片逆向工程。

* [C01｜ManvsMachine × Purple：把体验意图变成材料事件](c01-purple-material-event.md) - 从官方项目说明提取「什么接触揭示什么行为」的写法：先选身体经验，再选作用；含软包耳机触感片的原创迁移与回修。
* [C02｜Tendril × Hublot MP-10：把披露与技术信息编成两种职责](c02-hublot-disclosure-and-technical-duties.md) - 「吸引人发现」与「解释技术」可以合作但不是同一任务；含 24 秒精密手摇磨豆器的原创迁移、路线分叉与 R&D 的用法。
* [C03｜FutureDeluxe × Prada Paradoxe：同一世界可以容纳不同真实性层级](c03-prada-authenticity-levels-in-one-world.md) - 概念意象与产品操作可以共处，但要先给每段标表达性质再安排连接；含香氛补充装发布的三条原创路线与设计需求差异。
* [C04｜Tendril × Microsoft Hybrid Work：用可追踪关系承载抽象系统](c04-microsoft-trackable-relations.md) - 抽象不等于失去身份，清晰不等于全程录屏：让资料、设备、权限保持身份，让空间与过渡承担体验；含跨设备资料接续的原创迁移。
* [C05｜FutureDeluxe × Sonos Arc Ultra：把体验写成产品与周围世界的关系](c05-sonos-product-and-surrounding-world.md) - 有些体验要靠产品与周边空间的关系表达；必须区分体验可视化与技术解释。含无第三方 IP 的空间声音片原创迁移与设计交接。
* [C06｜NFB《Synchromy》：规则本身可以成为内容](c06-synchromy-rule-as-content.md) - 脚本可以直接规定声音、形状与时间的映射规则；含 18 秒声画研究短片的原创迁移、初步剧本应写的条目，以及一次升级与一次错误。
* [C07｜Ordinary Folk × Webflow：视觉系统的延续与功能内容的更新](c07-webflow-visual-continuity-and-function-update.md) - 续作可以保留既有视觉语法、重新分配新内容的职责；复用视觉系统不等于重复旧剧本。含季度更新片原创迁移与新旧关系卡。
* [C08｜Ordinary Folk × Spline：制作材料与表达对象可以相互支撑](c08-spline-tool-as-material.md) - 产品是创作工具时，作品可以展示由该工具支持的结果，但贡献与能力描述必须准确；含虚构排版工具介绍的三条原创路线。
* [C09｜Ordinary Folk × Procreate Dreams：防止过度纠偏的边界案例](c09-procreate-dreams-character-boundary.md) - 官方标为角色动画；放进本包是为了区分「角色存在」与「传统戏剧结构是否必要」。含同一命题三种承载者的原创迁移与对 agent 路由的意义。
