# 公开依据

- NFB 介绍作品通过光学方式建立声轨节律，并将相关图形以颜色形式呈现，形成听见与看见的直接关系。来源镜像见 [C06 参考条目](/references/c06-nfb-synchromy.md)。
- 查验范围：光学声画关系介绍及教育备注。**不进行逐帧结构转录**，也不将作品内容归纳成某种人物寓言。

# 可提取的方法（本包提取，不是原团队用语）

- 启发不是「抽象动画也很好看」，而是脚本可以规定**映射**：什么图形变量对应什么声音变量，什么保持一致，什么发生变化，如何产生时间段落。作品不必等待一个产品或人物来证明其结构存在。
- 用于新项目时，先选一条主要映射，再决定是否加入偏离。多个变量同时随意变化，会使映射难以被接触。
- 但作品也可以有意追求复杂或不透明，不能用单一教学标准限制艺术任务。

# 原创迁移：18 秒声画研究短片（虚构项目）

教学规则：一个图形单元对应一个声点；图形持续时间与声点延续相关；三个层级依次进入，而不是同时出现。

| 时间 | 内容 |
|---|---|
| 0–6 秒 | 建立单一层级 |
| 6–12 秒 | 加入第二层级，以错位形成关系 |
| 12–18 秒 | 第三层级短暂加入，再回到可继续的稳定结构 |

这是原创教学预算，不是原片时间表。

初步剧本该写什么：

- 不需要传统场景对白，但要写图形集合、变化维度、声音分层、映射关系、例外规则和周期条件。音响设计因此是**内容协作**，而不是全部画面完成后再任意配乐。
- 若作为品牌展厅内容：还要决定标识是否参与变形、准确字形如何保持、随时进入能否认出品牌。若品牌标识不得变形，就让独立形式系统运动，标识单独存在。

# 回修与分叉

- **一次升级**：将所有图形同时响应同一个鼓点，改为两个清楚层级轮流进入，让形式关系可被接触。
- **一次错误**：为了使抽象片「有故事」，追加一个小人战胜混乱世界。这可以是新路线，但不是必需修复，更不是原本抽象结构不成立的证据。

# 迁移要点

声音、形状与时间规则可以直接成为初步剧本对象。

# 最容易误借的东西

「每拍必同步」的万能规则。
