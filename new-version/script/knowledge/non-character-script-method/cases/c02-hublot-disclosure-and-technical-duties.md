# 公开依据

- Tendril 的项目文字强调纹理、构件的逐步呈现和**暂缓完整揭示**，同时用图形方式表现技术特征；官方另提供 R&D 延伸入口。来源镜像见 [C02 参考条目](/references/c02-tendril-hublot-mp10.md)。
- 查验范围：Approach & Aesthetic、Precision & Complexity 等公开文字；跟随官方 R&D 入口核读 Behance 公开文字，**未逐项观看动态图像**。
- 本包不复述或核验手表参数，也不把公开页面的排序当作影片时间线。

# 可提取的方法（本包提取，不是原团队用语）

- 初步剧本应分清三件事：哪些局部为**识别**积累线索；哪些局部负责**说明结构**；什么时候观众需要**完整对象重新定位**。没有必要让每个微距同时承担所有任务。
- 迁移时先画内容依赖：`整体身份线索 → 关键关系 → 完整理解`，再决定是否延迟全貌。
- 延迟本身不是高端风格公式，它需要可累积的前文与足够观看时间。

# 原创迁移：24 秒精密手摇磨豆器（虚构项目）

教学设定仅确认外部调节环、手柄和主体，**不具备内部剖面资料**。

| 时间 | 内容 |
|---|---|
| 0–5 秒 | 完整主体已有识别线索，调节环细节先承担注意入口 |
| 5–11 秒 | 局部操作让调节环与固定标记形成清楚关系 |
| 11–18 秒 | 手柄和环体在同一产品上重新定位 |
| 18–24 秒 | 完整产品与准确名称稳定呈现 |

时长仅为原创练习预算（已通过包内算术检查，不代表实测）。借的是「局部信息需要被整体收回」，没有复制手表外观，也没有因为品类叫精密就补刀盘、电机或内部齿轮动画。

# 回修与分叉

- **身份优先版**：从完整磨豆器开始，再探索局部。**发现优先版**：先见调节关系，稍后辨认主体。选择取决于观众是否已认识产品、是否必须很早识别品牌，以及版本长度。
- 美术需要准确的局部与整体对应；镜头端需要能定位「这个环属于哪里」，而不是任意旋转的金属圆环。
- 若最终只能记住材质：优先修线索关联，不是延长片尾标志。
- **R&D 对初稿的意义**：公开存在 R&D，不等于知道每次试验如何决定原片。用于新项目时把试验限定为一个问题，例如「同一固定标记是否足以看清调节关系」，先用代理或准确局部检验，不必先做完整高保真成片。

# 迁移要点

揭示需要线索累积；技术说明需要定位和参照。它们能共享素材，但应分别管理职责。

# 最容易误借的东西

黑色金属风格。
