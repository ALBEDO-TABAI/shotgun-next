# 公开依据

- 工作室把项目描述为：可视化躺在 Purple Grid 床垫与枕头上的感受，并用触感鲜明的「测试式」创作传达产品特征与舒适意图。来源镜像见 [C01 参考条目](/references/c01-manvsmachine-purple.md)。
- 查验范围：公开 brief 与创意说明；**未逐帧观看影片**，没有客户 brief、内部脚本或投放数据。
- 这只支持「创作任务与表达取向」，不是舒适、健康或销量的独立验证。

# 可提取的方法（本包提取，不是原团队用语）

- 有用的不是紫色或软物体，而是把「想让人接触的身体经验」变成具体关系：材料要遇到某种作用，观众才有机会看到顺应、承托、恢复等差异。
- 初步剧本因此先问「什么接触揭示什么行为」，而不是「主人公为什么压力大」。
- 迁移时区分三个对象，它们可以重合也可以分离：
  1. 被展示的真实产品；
  2. 用于作用的对象；
  3. 允许艺术自由的代理材料。
- 不能默认代理材料的所有表现都是产品真实属性。

# 原创迁移：软包耳机触感片（虚构项目）

设定：任务是感官展示，不证明隔音或人体舒适效果；真实耳罩外形已确认，压缩参数未知。

| 路线 | 内容 | 借的是什么 |
|---|---|---|
| 甲：真实外观与接触位置 | 软垫表面局部被看见；一次已授权的轻触使接触关系明确；随后完整耳机与稳定表面并置 | 真实接触关系 |
| 乙：独立织物装置 | 织物顺应圆润对象，离开后恢复；耳机在另一层展陈中保持真实形态 | 接触与顺应，不假装展示耳罩工程性能 |

从草句到可写内容：

- 草句：「耳罩很柔软，丝绸包裹产品。」
- 改写要点：独立织物从两个固定边缘下垂；圆润形体与中部接触，织物沿接触区形成包围但边缘仍可辨；形体离开后织物回落；随后真实耳机与织物空间并置，耳罩外形不发生未经确认的压缩。
- 增加的不是文采，而是**作用、边界、结束状态和真实产品的位置**。美术需要织物固定点、接触三态、耳机身份、两层空间；时序需要决定两段类比怎样被读取。

# 回修与分叉

- 代理装置太强、产品沦为片尾附件：减少装置段，提前耳机的形状锚点。
- 受压引发不适：改成沿曲面贴合或轻触响应。
- 修订对象是体验关系，而不是把「柔软」换成「极致柔软」。

# 迁移要点

先选身体经验，再选作用；材料行为比材料名更接近剧本内容。

# 最容易误借的东西

把代理材料当成产品性能证据（见 [九例横向比较](/frameworks/nine-case-operation-comparison.md)）。
