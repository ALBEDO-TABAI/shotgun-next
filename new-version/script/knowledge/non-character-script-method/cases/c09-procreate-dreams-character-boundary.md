# 公开依据

- 官方把项目标为**角色动画**，以创作过程中的受限、转动与突破描述创意，并说明希望展示动画软件能力。来源镜像见 [C09 参考条目](/references/c09-ordinary-folk-procreate-dreams.md)。
- 查验范围：项目文字、类型与署名。本例**不是「没有人物」的证据**，也不冒充完整剧情还原。

# 可提取的方法（本包提取，不是原团队用语）

- 补上非人物能力之后，agent 可能走向另一个极端：看见人物就判不适用，或将所有形式片里的行动都改成物体。需要的是更完整的路由，而不是从「所有片子都要故事」改成「所有片子都不要人」。
- 一个角色可以只承担动作、尺度或形式关系；也可以发展完整目标与关系。初步剧本应**按段落职责判断**，而非用人脸或身体作为结构分类的唯一依据。

# 原创迁移：同一命题的三种承载者

命题：「一个既定边界被重新组织，新的表达空间出现。」

| 版本 | 内容 | 性质 |
|---|---|---|
| 无角色 | 独立框架转向，先前封闭的区域形成可进入的路径 | 形式与空间关系 |
| 局部行动 | 一只操作手调整框架，作用关系明确，不描写人物愿望或经历 | 手是作用来源，不是角色 |
| 角色 | 简化角色不断尝试新位置，最终参与改变框架关系 | 可能开始出现目标行动；需要时调用已有戏剧知识 |

三个版本不是优劣顺序。选择取决于用户是否要求人物、产品如何参与，以及哪种承载者更能形成希望的观看经验。

# 回修与分叉（对 agent 的直接意义）

- 将任务路由写为「**本段由什么组织**」，而不是「本片有没有人」。
- 一条剧情广告中可能有材料桥段；一条非人物产品片中可能有操作手；一条抽象片中可能有短暂角色动作。共享的初步剧本方法应能处理这些混合，而不是强迫整片只能选一个标签。

# 迁移要点

补非叙事能力，不等于放弃叙事；应该增加选择能力，而不是更换一种偏见。

# 最容易误借的东西

「有人就必须三幕式」。
