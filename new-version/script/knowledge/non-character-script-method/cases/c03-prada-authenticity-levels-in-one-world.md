# 公开依据

- FutureDeluxe 说明其延展了 McCann Paris 的创意，制作虚拟花朵绽放和品牌实验室语境下的瓶体补充灌装等动态资产。来源镜像见 [C03 参考条目](/references/c03-futuredeluxe-prada-paradoxe.md)。
- 查验范围：项目及动态资产说明。官方文字支持这些**内容类别**，不支持自行推定配方来源、真实工艺、完整先后顺序或功效。

# 可提取的方法（本包提取，不是原团队用语）

- 一个项目可以同时有概念意象与产品操作；但只写「花变成液体，进入瓶中」就假定两者自然连接，可能把开放意象写成具体来源或制造过程。
- 先给每段标**表达性质**，再安排连接：花朵可以承担概念、感受或形式；灌装可以承担真实操作。
- 二者可以共享颜色、节律或空间身份，**不必共享物理因果**。

# 原创迁移：香氛补充装发布（虚构项目）

教学资料只确认瓶体可补充、接口与补充操作，允许一个独立艺术花形；不提供花朵与配方的关系。

| 路线 | 做法 | 取舍 |
|---|---|---|
| 甲 | 「花形展开」与「补充灌装」并置，用相近的展开—稳定时间关系呼应 | 保留意象，靠时间关系而非因果连接 |
| 乙 | 取消花形，以瓶体内外和液体表面的观察组织体验 | 操作更清晰，放弃概念意象 |
| 丙 | 花形只在独立品牌空间出现，产品操作在准确展台完成，用同一视觉秩序统一 | 空间区隔更强，可能增加设计资源 |

一段可写的原创建议（要点）：独立花形由紧凑层片进入开放状态，**中心不产生液体**；随后进入真实容器操作段，瓶盖移开、补充装与已确认接口对应、液体按许可动作进入容器；操作结束回到完整产品，艺术花形在独立背景层保持展开。

# 回修与分叉

- 上述写法保留了艺术与产品动作，但**没有声称观众必然不会误读**。若两段仍被看作配方制造，需改变连接或移除有争议意象，而不是依赖内部脚本注释。
- 设计需求因此不同：花形需要开合状态与艺术自由；产品需要准确瓶口、盖体、接口和操作状态；空间需要区分实体接触与背景并置；液体的起点、终点、接触与结束状态必须写清。真实灌装和抽象流动**不应共用一个泛化「液体素材」需求**。

# 迁移要点

世界可以统一，语义责任必须分开；连接方式本身是内容决定。

# 最容易误借的东西

成分或工艺因果。
