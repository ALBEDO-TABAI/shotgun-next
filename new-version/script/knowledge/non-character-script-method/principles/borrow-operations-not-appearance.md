# 要点

## 四句参考记录
每次使用参考作品，写四句：

1. 原项目公开任务是什么；
2. 可确认的表达关系是什么；
3. 本项目要借哪**一个**操作；
4. 哪些视觉身份、产品事实与 IP 不可移植。

## 来源给出的三个例子

| 参考 | 可以借的操作 | 不意味着 |
|---|---|---|
| Hublot MP-10 [2] | 局部线索累积 | 照搬其黑色机械世界 |
| Purple [3] | 以材料事件接触体验 | 任何护肤品都应该做床垫式受压 |
| 《Synchromy》[4] | 声画规则本体 | 每个转场都要踩鼓点 |

# 适用边界

- 案例页面只能确认创作者公开的任务与做法，不提供独立的效果因果；未逐帧观看影片，见 [案例证据的限度](/principles/case-evidence-limits.md) 与 [证据分层与使用边界](/principles/evidence-and-use-boundaries.md)。
- 素材公开可见不表示获得商业使用权；IP 与品牌身份不可移植。
- “借的操作”是本包提取的方法综合，不表示原团队公开使用了这些名词。
