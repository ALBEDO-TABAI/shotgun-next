# 要点

| 依据 | 来源可以支持什么 | 本包据此作出的工作选择 |
|---|---|---|
| 叙事电影事件分割研究 [2] | 区分镜头切换、动作变化与时空变化；有意义的事件边界不能简单等同于剪切点 | 以内容职责划分节拍，再让时序设计决定镜头划分，而不是按「六个镜头」倒填六个卖点 |
| 电影叙事学条目 [3] | 状态变化可在镜头内部或镜头之间呈现 | 同上；节拍编号是内容引用，不是镜头订单 |
| 动画理解研究综述 [4] | 动画不会自动使复杂关系容易理解；呈现与内容不匹配、变化太快或过于复杂都可能出问题 | 用观察任务决定时间预算 |
| 材料知觉研究 [5][6] | 判断材料要同时考虑外观、形状、动态与作用场景 | 写材料事件时写清作用与场景，而不是只写材质名 |

由此提出三项实务方法：

1. 用**状态差异**判断到底发生了什么，见 [状态变化的四种来源](/frameworks/four-sources-of-state-change.md)。
2. 用**理解依赖**决定信息先后，见 [依赖排序](/methods/dependency-ordering.md)。
3. 用**观察任务**决定时间预算，见 [时间预算工作法](/methods/time-budgeting.md)。

# 适用边界

- 这些研究**不是广告最佳秒数的来源**，也没有证明所有变化越慢越好。
- 事件分割研究使用叙事电影和具体样本，不能外推固定的广告节拍频率或受众效果。
- 三项实务方法的具体字段、阈值与例子均需在项目中检验；它们是本包综合，不是论文结论。
- S14 本次仅核到摘要与题录，不据此复刻未读到的细节。
