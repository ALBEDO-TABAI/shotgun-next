# 原则与边界 · Principles

证据分层、案例证据限度、决策归属、借操作不借外观、版本与检查结果不互相冒充。

# 全包通用

* [证据分层与使用边界](evidence-and-use-boundaries.md) - 全包总原则：研究结论、创作者公开自述、本包工作建议、原创教学内容四层分开标识；列出不可从本包推出的结论与继续研究时的选择标准。

# 01 能力定位与连续创作路径

* [主责与协作：按决策类型分责，而不是按素材归属](decision-ownership-and-content-source.md) - 编剧、导演、美术、镜头与时序各自对哪类决定负责；哪些决定可以下放，哪些必须回到内容源。改变内容的提议不因字数少而算小改。

# 02 对象、信息与时间体验编排

* [切镜头、事件与知觉不是同一件事](cut-event-perception-are-distinct.md) - 本篇的证据边界：事件边界不等于剪切点，动画不会自动更易懂，材料判断依赖多种线索；这些研究都不是广告最佳秒数的来源。

# 03 创意生成与可见过程构造

* [参考作品的使用方式：借操作，不借整套外观](borrow-operations-not-appearance.md) - 每次参考只写四句：原项目公开任务、可确认的表达关系、本项目要借的一个操作、不可移植的视觉身份／产品事实／IP。

# 04 一手案例研究与方法迁移

* [案例证据的限度：创作参考与事实资料不能互相代替](case-evidence-limits.md) - 九个案例只依据公开文字：未逐帧观看、没有内部资料与投放数据；创作参考回答「可以怎样表达」，事实资料回答「这个产品实际是什么」。

# 06 创意优化、验证与多 Agent 回修

* [内容 ID、版本与检查结果不要互相冒充](content-id-version-check-separation.md) - 同一个引用必须能确定其内容与版本；自检通过、导演认可、用户确认、资产可用、生成成功各是不同状态，都不能替代传播效果已验证；变更后只复核受影响的检查。
* [调研为回修提供了什么，而不是保证了什么](what-research-supports-for-revision.md) - 并行原型、迭代框架、配置管理与 AI 创意实验只为回修提供工作入口；本篇把它们转成三个工作习惯，而不把它们当作效果保证。
