# 要点

本包的调研是**围绕创作缺口的定向研究**，不是穷尽性或预注册的系统综述。26 项来源（S01–S17 文献与方法来源，C01–C09 真实案例一手来源）只是本次实际用于构建六篇内容的来源，不是“全部最新研究”。S 类还包含机构流程与工程手册，**不能统称为十七项实证研究**。

## 四层内容必须分开标识

| 层 | 在本包中的说法 | 能支持什么 | 不能当成什么 |
|---|---|---|---|
| 研究发现／论文讨论 | 「研究发现」「论文讨论」 | 仅限来源可支持的范围与核读位置 | 广告最佳秒数、受众效果、通用定律 |
| 创作者公开自述 | 「官方说明」 | 公开的创作任务与做法 | 独立效果因果、内部流程还原、逐帧镜头表 |
| 本包工作建议 | 「本包建议」「可提取的方法」 | 跨领域应用或作者综合，可在项目中检验 | 原论文结论、原团队用语、已验证最优流程 |
| 原创教学内容 | 「原创练习」「教学项目」 | 演示方法如何落到内容 | 现实产品事实、原案例内部脚本、真实商品资料 |

## 访问范围的如实标注

- 仅核到摘要与题录：[S06](/references/s06-gentner-structure-mapping.md)、[S08](/references/s08-spence-crossmodal-correspondences.md)、[S14](/references/s14-tversky-animation-facilitate.md)、[S15](/references/s15-phillips-mcquarrie-visual-rhetoric.md)——不用于复刻未读到的完整分类或细节。
- 出版入口受限：[S09](/references/s09-dow-parallel-prototyping.md) 采用出版摘要与可确认任务范围；[S13](/references/s13-doshi-hauser-generative-ai-creativity.md) 出版站直开失败，实际阅读原论文公开副本。
- 真实案例页面只能确认公开创作任务与做法；**未完成影片的逐帧观看**，没有据页面图像重建原片镜头表。Hublot 官方延伸页只作同一项目的补充入口，不另算独立案例。
- 九个案例并非都是纯非人物成片：Spline 含角色元素，Procreate Dreams 明确作为角色动画的边界对照。
- 包内不分发第三方论文、影片、图片或品牌资产；素材公开可见不表示获得商业使用权。

## 不要从本包推出

1. 固定三秒注意阈值；
2. 万能高潮比例；
3. 材质与情绪一一对应；
4. 模拟可以证明商品性能；
5. 所有 AI 创作必然同质化；
6. 某个流程已经验证为最优。

## 本包是什么、不是什么

- 是一份可继续用于 skill 开发的**知识资料**，不是已经安装或跑通的 agent。
- 没有执行实际视频生成、材质实测、受众访谈或商业投放。
- 初步剧本的完成、最终生产、用户确认、受众效果是**不同状态**，不得互相冒充。
- 不把审慎变成流程负担：只阻塞依赖未知事实的部分；只给必要变化提取状态与关系；只在确有问题时做针对性验证。超现实与抽象表达仍然可用，只需明确其与真实商品的联系及边界。

## 继续研究时的选择标准

| 遇到的情况 | 优先动作 | 不要做 |
|---|---|---|
| 真实商品结构或功效未知 | 补该商品的准确资料 | 以更多审美案例填补事实空白 |
| 创意路线同质 | 扩展组织机制与不同领域关系 | 多搜相同视觉风格 |
| 理解问题 | 先明确要检验的对象、动作或信息，再选合适保真的材料 | 直接做高保真成片 |
| 继续做镜头级案例研究 | 记录片源、版本、时间码、可观察内容及推断层级 | 把原创迁移练习回填为历史作品的真实流程 |
