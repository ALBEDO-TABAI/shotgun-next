# 要点

## 谁对什么决定负责

| 角色 | 负责的决定 |
|---|---|
| 编剧 | 内容关系与可读初稿 |
| 导演 | 整片表达判断及重要取舍 |
| 美术 | 载体、对象与空间方案 |
| 镜头与时序设计 | 观看路径、衔接与时间落实 |

某个材质运动既可能涉及美术，也可能涉及内容；因此问题应交给**对该决定负责的人**，而不是所有相关 agent 都另写一个最终答案。

## 可下放与需回到内容源

| 可直接下放的决定 | 需要回到内容源的决定 |
|---|---|
| 不影响身份和信息的细部风格 | 产品由旁观者变成触发者 |
| 合乎内容关系的载体替换 | 先比较后解释变成先解释后比较 |
| 未改变语义的镜头拆分 | 抽象图形变成产品真实内部 |
| | 操作演示变成感应自动响应 |

## 判例

- 设计端提出「让铰链转动与页边弧线产生呼应」：可以是有效增益。
- 设计端提出「灯一亮，整本书自动翻开」：改变了内容。**不要因后者只多写六个字而把它当成小改。**

# 适用边界

- 来源 §2 的证据骨架指出：真实动态品牌项目中存在脚本与设计等不同职能，有 Ordinary Folk 的公开流程及 Webflow 项目署名为依据 [2][3]；但那只是该机构的实践自述，不是全行业唯一分工或纯 AI 流程标准。
- 本包的主张是在现有编剧 agent 中补能力，而不是按片型再建角色；角色划分与实际权限仍需团队确认。

> 待确认：四个角色的决策边界是本包的工作建议，是否作为团队 agent 分工的正式口径、由谁裁定「是否改变内容」，需人审。
