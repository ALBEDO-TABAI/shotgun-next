# 要点

## 本次研究没有做什么

- 没有逐帧观看完整影片。
- 没有取得客户 brief、导演原始 treatment、内部资产或投放数据。
- 部分页面的图片链接未成功读取，不能依据图片标题推断其可见细节。
- Hublot 的官方延伸 Behance 页面已核读公开文字，但不宣称完成全部 R&D 动态素材分析。

因此本篇的价值是「**有一手创作意图依据的机制研究与迁移练习**」，不是冒充完整的成片逆向工程。

## 由此得到的约束

| 不应做 | 应当做 |
|---|---|
| 把页面排序当作影片时间线，或据文字编造镜头顺序 | 要做镜头级分析时，取得可访问视频，记录版本、时间码、可观察内容与推断层级 |
| 把创作者自述当作舒适、性能、销量等效果证据 | 只用来确认公开创作任务与做法 |
| 把九例都当作纯非人物成片 | Spline 含角色元素；Procreate Dreams 明确是角色动画的边界对照 |
| 把本篇的原创迁移练习回填为历史作品的真实流程 | 「本包提取」不表示原团队公开使用了这些名词 |
| 用案例创作说明替代产品资料 | 涉及真实接口、产品特征或素材权利的新问题，继续针对性查验 |

**创作参考回答「可以怎样表达」，事实资料回答「这个产品实际是什么」，二者不能互相代替。**

合格成果是九种可以被使用、比较与拒绝的创作操作，而不是九条「照着做就有效」的成功学结论。

# 适用边界

- 素材公开可见，不表示获得商业使用权；包内不分发第三方影片、图片或品牌资产。
- 上述限制描述的是 2026-09-18 这一次查验的范围。
