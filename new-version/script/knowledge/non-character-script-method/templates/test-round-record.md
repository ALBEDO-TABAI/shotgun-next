# Schema

```text
问题：我们要判断哪一项不确定性？
版本：使用哪个脚本、资产与时序版本？
材料：正文／状态图／动态代理／完整视听？
参与者与条件：实际记录，不补造目标人群。
比较：改变哪个主要因素，保留哪些条件？
提问：先开放，再针对。
观察：逐条记录真实回答或可观察问题。
解释：哪些是证据，哪些仍是作者假设？
决定：保留／局部改／换路线／补证据。
边界：本轮无法判断什么？
```

# 要点

- **只有 agent 自检时**：「参与者」写「未进行人类观看测试」，「观察」写文本中找到的问题，不虚构访谈口吻。
- **多个 agent 同意，不等于代表多个真实受众。**
- 「版本」一行必须能唯一确定被测内容，否则结果无法回到正确的稿件。
- 「解释」一行强制把证据与作者假设分开；「边界」一行防止把本轮结果外推。

# 适用边界

- 模板是记录约定，不是实验设计规范；样本量与比较设计仍由任务决定。
- 字段不必每项写满，但「版本」「参与者与条件」「边界」三项不应省略。
