# 要点

模板分三段：**任务定义**（每个项目一份）、**路线卡**（每条候选路线一份）、**选定与交接**（选择后一份）。

# Schema

```text
项目与本轮范围：
主任务／次任务／本版不做：
已有事实及出处：
创意假设：
阻塞性未知（只写影响核心内容的项）：
必须让观众得到：
允许联想到：
不能误认为：

路线名称：
对象与核心关系：
主要变化或组织规则：
观看者先接触什么、后接触什么：
产品为什么属于这条表达：
最小设计条件：
最需要检验的问题：
与其他路线的结构性差异：

选定路线及理由：
可保留的辅助机制：
暂不细化的决定：
交给下一环节的具体任务：
```

## 字段说明

| 字段 | 填写依据 |
|---|---|
| 主任务／次任务／本版不做 | 从六种传播任务中指出主任务与可让位任务 |
| 已有事实及出处／创意假设 | brief 解包的「事实」与「意图、偏好」分开写；事实写出处或「用户提供」 |
| 阻塞性未知 | 只写影响核心内容的项；其余留作条件分支或交给下游 |
| 必须让观众得到／允许联想到／不能误认为 | 七步法步骤一的三句 |
| 与其他路线的结构性差异 | 防止三条路线只是换色的同义方案 |
| 选定路线及理由／可保留的辅助机制 | 写理由而不是打分；舍弃项与牺牲一并记录 |

# Examples

教学项目的填写示意（摘自「一页」阅读灯走查）：

```text
主任务／次任务／本版不做：认出产品并看懂折叠 ／ 记住名称 ／ 不展示内部电路、不介绍全部参数
不能误认为：感应或自动开灯、调色、护眼或性能领先
路线名称：A 真实操作
对象与核心关系：灯头绕立柱顶端唯一铰链，从收拢进入横向工作姿态
最小设计条件：转动时看清固定点；手不遮住接口
可保留的辅助机制：路线 B 的「先看光面、后理解书页」局部披露
```

# 适用边界

- 模板不是让每个字段都写一页；没有真实调研时，不在任何字段里虚构受众画像。
- 它只覆盖第 01 篇的产物（任务定义、路线、交接任务）；节拍、正文与设计需求另有模板。
