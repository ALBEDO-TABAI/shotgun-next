# 要点

## 回传应包含的四项

| 项 | 说明 |
|---|---|
| 提案 | 针对哪条需求（D 编号）提出什么载体、观察或接触方案 |
| 理由 | 它解决了哪一个可见性、关系或遮挡问题 |
| 消费位置 | 方案被哪个节拍或哪条其他需求使用 |
| 未改变项 | 明确哪些事实与内容没有被改动；哪些判断交回编剧与导演 |

## 可套用骨架

```text
针对需求（D 编号）：
提案：
理由（解决哪一个关系／可见性问题）：
被谁消费（节拍／其他需求）：
未改变的事实与内容：
需要编剧／导演判断的事项：
```

## 美术响应示范（来源原例，「一页」V1）

> D02 建议保留单一清楚的转动平面；从侧前方能同时看到固定立柱与灯头接口。D04 的手改从灯头末端接触，以减少关节遮挡。D05 建议使用有一条稳定页边折线的纸面，供 D09 回到整体。灯体事实不改；是否保留 B04 的长停留，请编剧与导演根据粗排判断。

它不是仅交一张漂亮主视觉后，让分镜 agent 自己推断整套空间。

## 镜头与时序响应示范

B02 用连续观察，B03 单独建立按钮接触，B04／B05 合成一段局部到整体的观察。该提案**改变了两个节拍的时间组合，但不改产品事实**。是否合并内容职责，应回到当前剧本记录，而不是让表格仍保留旧时间。

# 适用边界

- 骨架是对来源示范的归纳（来源给的是示范文字，不是固定表单）。
- 回传不是再抄一遍剧本，也不是让下游补全自己认为缺少的剧情。
