# 要点

```text
案例名称／一手来源：
可确认的任务：
可确认的做法：
尚未知的内容：
本包提取的关系：
迁移需要的前提：
不能直接移植的事实／身份／IP：
适配本项目的三句内容胚：
与参考不同之处：
下一步最值得检验的问题：
```

## 填写提示

- 前四行是事实层：只写官方材料可确认的内容，并如实写「尚未知」。
- 「本包提取的关系」以后是方法综合与原创内容，不能回填成原作的真实流程。
- 「不能直接移植的事实／身份／IP」要具体，例如第三方电影 IP、原品牌外观、旧版本功能。
- 「三句内容胚」必须写自己的对象、动作与结束状态。

# 适用边界

- 保存一手链接，不复制原片素材；素材公开可见不等于可商用。
- 模板字段是本包的工作建议，不是行业标准。
