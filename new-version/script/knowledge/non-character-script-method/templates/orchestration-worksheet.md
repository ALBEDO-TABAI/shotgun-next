# 要点

本模板把第 02 篇的全部判断收进一张表：先写整体，再逐节拍，最后做联合检查。它是本包自有工具，可整段复制使用。

# Schema

```text
最终要得到的理解／体验：
关键对象及身份锚点：
世界中真正改变的变量：
只改变观看范围的部分：
关键理解依赖：
允许交换顺序的部分：

节拍：
- 进入条件：
- 动作／披露／比较／停留：
- 离开状态：
- 本段主要职责：
- 与前段的连接：
- 必须看见的中间态或参照：
- 声音与文字的责任：
- 暂定时间及不确定处：

联合检查：
- 总时长是否匹配？
- 是内容重复，还是有意义的辨认与停留？
- 是否无意把「之后」讲成「因此」？
- 一个静音／短版／竖版是否需要重分任务？
```

# 适用边界

- 静态陈列或纯形式片可以没有实体动作，相应字段填披露、比较、停留或规则与变化变量。
- 模板用来让关键决定有位置，不要求每个字段写满；不把它当分镜表使用。
