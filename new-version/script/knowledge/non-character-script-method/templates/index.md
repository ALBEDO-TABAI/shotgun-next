# 模板 · Templates

可直接填写的任务卡、编排工作表、路线比较卡、案例记录、初稿与需求模板、测试记录。

# 01 能力定位与连续创作路径

* [任务与路线卡模板](task-and-route-card.md) - 可直接填写的三段式模板：任务定义、单条路线卡、选定与交接。作用是让每个关键创作决定有位置，而不是增加文书量。

# 02 对象、信息与时间体验编排

* [编排工作表：对象、依赖、节拍与联合检查](orchestration-worksheet.md) - 可直接填写的编排模板：最终理解、身份锚点、真正改变的变量、理解依赖、逐节拍字段，以及总时长、重复、因果误读与版本重分四项联合检查。

# 03 创意生成与可见过程构造

* [路线比较卡（创意路线模板）](route-comparison-card.md) - 第 03 篇的可填写模板：从创作任务、体验词两种解释、选定关系、承载者、主机制，到内容胚、设计条件、相反解读、机制不同的备选与选择理由。

# 04 一手案例研究与方法迁移

* [案例库记录模板](case-library-record.md) - 一条参考案例入库时填写的十个字段：一手来源、可确认任务与做法、未知内容、提取的关系、迁移前提、不能移植项、三句内容胚、与参考的不同、下一步检验问题。
* [事实卡与迁移卡](fact-card-and-transfer-card.md) - 每个案例做两张卡：事实卡只写官方材料能确认的事；迁移卡写自己的对象、动作、条件和风险，不拿原品牌外观当方法。

# 05 初步剧本写作与设计需求交接

* [美术与镜头时序的回传格式：提案、理由、消费位置、未改变项](art-department-return.md) - 有效的下游响应可以很短，但要有提案、理由、消费位置，并明确什么没有改变；改变节拍时间组合的提案要回到当前剧本记录。
* [可复制的初稿与设计需求模板](draft-and-requirement-template.md) - 一份覆盖项目状态、任务与事实、初步剧本正文、节拍表、设计需求、待回修事项与交付说明的文本模板。

# 06 创意优化、验证与多 Agent 回修

* [一轮有效测试的记录格式](test-round-record.md) - 十行测试记录模板：问题、版本、材料、参与者与条件、比较、提问、观察、解释、决定、边界；只有 agent 自检时如实填写未进行人类观看测试。
