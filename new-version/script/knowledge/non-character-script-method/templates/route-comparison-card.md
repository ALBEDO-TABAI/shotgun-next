# Schema

```text
创作任务：
体验词及两种解释：
选定的关系：
承载者：真实产品／代理材料／空间／图形／系统
主机制：
不变量与主要变量：
三至五句内容胚：
与产品或作品任务的联系：
一项最重要的设计条件：
可能的相反解读：
一个机制不同的备选：
为什么选当前路线：
```

# 填写说明

| 字段 | 从哪里来 |
|---|---|
| 创作任务 | [任务与路线卡](/templates/task-and-route-card.md) 的主任务，分类见 [六种传播任务](/frameworks/communication-tasks.md) |
| 体验词及两种解释／可能的相反解读 | [体验词转译](/methods/experience-word-translation.md) 的候选关系与“需要警惕的相反感受” |
| 选定的关系／承载者 | [五个起笔入口](/methods/five-starting-entries.md)；承载者的真实性标记见 [四种真实性层级](/frameworks/authenticity-levels.md) |
| 主机制 | 十二张机制卡，按 [机制选择矩阵](/frameworks/mechanism-selection-matrix.md) 选 |
| 不变量与主要变量 | 机制卡的“设计条件”与 [身份锚点—变化变量配对](/frameworks/information-gain-and-identity-anchors.md) |
| 一个机制不同的备选 | 用 [六个创意操作](/methods/six-creative-operations.md) 生成；必须是结构差异，不是同义改写 |
| 为什么选当前路线 | [机制路线的发散与选择](/methods/mechanism-route-divergence-and-selection.md)：写理由，不写无测量依据的分数 |

# Examples

按来源 §19 的“一页”阅读灯推演回填（内容均出自来源，字段归位为本知识包整理）：

```text
创作任务：30 秒，认出产品并看懂折叠与手动启动，最后记住名称（教学设定）
体验词及两种解释：精密＝固定点清楚、转动边界明确／到位姿态稳定；舒展＝灯头从并行进入横向工作关系
选定的关系：固定与转动；收拢与横向；未亮与书页被照亮
承载者：真实产品（加一次局部操作手与一本书）
主机制：M02，辅以 M09 的局部重新定位
不变量与主要变量：底座与立柱固定；灯头角度、亮灭、观看范围改变
三至五句内容胚：见 “一页”灯三次发散 §4
与产品或作品任务的联系：主动作来自唯一铰链这一真实关系
一项最重要的设计条件：转动时看清固定枢点，手不遮住接口
可能的相反解读：成为说明书；光被读成能推动纸张的物质
一个机制不同的备选：M01 身份揭示（依靠真实局部）
为什么选当前路线：教学目标含操作理解，事实依赖更可控
```

# 适用边界

- 模板用于让关键创作决定有位置，不是增加文书量；字段不必都写满。
- 与第 01 篇的 [任务与路线卡](/templates/task-and-route-card.md) 分工：那张卡侧重任务定义与路线间结构差异，本卡侧重“体验词 → 关系 → 机制”的转译链条。
