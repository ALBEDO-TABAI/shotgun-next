# 要点

> **声明：** 以下为**原创虚构商品**的教学示例。名称、结构与操作仅是教学给定条件，不代表用户真实商品；「已有资料」也是教学前提，不表示确实获得了 CAD 或实物样机。V1 是内容发展示例，**未代表用户确认进入真实生产**。

## 任务卡

| 项 | 内容 |
|---|---|
| 主任务 | 认出产品，看懂由收拢进入工作姿态，并将这一动作与阅读空间联系起来 |
| 体验意图 | 克制、精确、舒展 |
| 不承担 | 护眼功效、性能领先、照度数字、自动化能力或人物经历 |
| 交付 | 30 秒，横向主版本，可静音理解；15 秒和 6 秒版本见第 06 篇 |

## 事实与开放项

- **事实：** 扁椭圆底座、固定立柱、细长灯头，硬质深灰外观；唯一铰链位于立柱顶部，灯头经该处转动；收拢时近似与立柱平行，工作时横向展开；底座按钮手动开关，固定暖白光；允许一只局部操作手，不涉及人物身份；准确文字为「一页／折叠阅读灯」。
- **开放项：** 桌面材质、书页图像风格、镜头数量、观察路径、具体照明表现、局部声响及音乐。
- **开放不等于任意：** 这些决定不能让铰链数量变化、按钮变成感应器，或把纸页写成灯自动控制的装置。

## 六个节拍（总长 30 秒）

| ID／时间 | 小标题 | 发生什么 | 保持 / 明确不做 |
|---|---|---|---|
| B01／0–4 秒 | 收拢的形态 | 灯立在桌面，灯头沿固定立柱收拢，完整轮廓可辨；灯未亮；一本打开的书处在工作范围中，但不急于强调书上细节 | 底座与桌面接触稳定，周围没有抢先启动的动作；建立「一件完整、收拢的产品」这一参照，而非一组待组合零件；可有安静环境声或无声，不由旁白替画面解释身份 |
| B02／4–10 秒 | 只改变一个关系 | 局部操作手扶住灯头，绕立柱顶端唯一铰链抬起；经过一个可辨认的中间姿态，停在横向展开的工作姿态 | 立柱与底座不动，灯头不拉长、不弯折；手只提供作用来源，不承担心情、身份或前史；到位后关系保持片刻，不被另一个大动作覆盖 |
| B03／10–14 秒 | 启动的原因 | 同一只手移向底座按钮，接触并按下；灯头亮起，暖白光落在打开的书上；手退出 | 产品与书保持原有身份和位置；可有短而克制的操作声，但不能用声音弥补画面中不可见的关键接触；环境不因灯亮而自动打开、变形或长出新物体 |
| B04／14–21 秒 | 接触一页上的光 | 观看转向已稳定的纸面：先接触纸张局部、页边或折线与光的关系，再逐渐知道这是刚才同一本书的书页 | 纸没有魔法展开，光没有被表现成进入纸内的液体；不增加新功能；持续观察还是局部—整体衔接，由镜头与时序设计提出 |
| B05／21–26 秒 | 产品与阅读关系会合 | 同一灯与同一书页在清楚的整体关系中出现；工作姿态、底座稳定和书页上的光同时得到定位 | 此前的局部不是另一个独立世界；不重复开灯，不追加功能标签；内容从「怎么展开、怎样启动」回到「这一转动让产品进入何种工作关系」 |
| B06／26–30 秒 | 准确地留下名称 | 产品保持工作姿态，名称「一页」与类别「折叠阅读灯」以独立字卡出现 | 图形与产品不争抢最后的识别时间；允许光与空间保持稳定，不强迫所有对象同时收回；不出现功效口号、价格或参数——确需新增时另行分配时间与资料责任 |

# 适用边界

- 时间分配是教学预算，不是实验得出的比例；算术一致性已在来源包的结构校验中核对（与第 02 篇表格、第 05 篇节拍表一致），但这不代表实际动画或阅读能在同样时长内达成目标。
- V1 与第 06 篇的 V2 是教学演进，不是同时生效的两份生产「最终版」。
- 本概念是要点提炼；完整文学正文以来源文档 §6 为准。
