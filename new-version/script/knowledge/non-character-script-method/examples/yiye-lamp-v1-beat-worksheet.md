# 要点

> 原创虚构教学项目，设定见 [V1 阅读正文](/examples/yiye-lamp-v1-script.md)。

| ID／秒数 | 主职责 | 状态与连接 | 必须看清 | 设计需求 |
|---|---|---|---|---|
| B01／0–4 | 建立身份与收拢参照 | 产品闭合、未亮；书已打开 | 完整轮廓与稳定支撑 | D01、D02、D03、D05、D06 |
| B02／4–10 | 理解折叠关系 | 同一产品由收拢进入工作姿态 | 唯一铰链、固定件、中间态 | D01、D02、D04、D06 |
| B03／10–14 | 理解手动启动 | 按键后亮灯；接触提供作用依据 | 按钮、手、亮灯结果 | D01、D03、D04、D05、D06、D07、D10 |
| B04／14–21 | 感官停留与纸面定位 | 物体稳定，主要改变观看范围 | 同一书页、局部与整体线索 | D01、D05、D06、D07、D09、D10 |
| B05／21–26 | 汇合使用关系 | 从局部回到产品与书的整体 | 工作姿态与照亮位置的关系 | D01、D02、D05、D06、D07、D09 |
| B06／26–30 | 准确识别 | 同一稳定关系加独立字卡 | 名称、类别与产品 | D01、D05、D06、D07、D08、D10 |

- 总长 30 秒；六段首尾相接（0–4–10–14–21–26–30）。
- 表格是正文的**工作视图**，不产生新的情节。
- B04 的纸面是 D05 所定义的同一页，不能由下游随意替换成液体、皮肤或一块自发光面板。

## 怎样读这张表

- 「状态与连接」列区分了**世界变化**（B02、B03）与**主要改变观看范围**（B04、B05）——后者不是对象发生了魔法变化。
- 「设计需求」列是正向引用；反向（每条需求在哪里被消费）见 [V1 设计需求清单](/examples/yiye-lamp-v1-design-requirements.md)。来源包的结构校验确认正反向完全对应，没有未定义或孤立需求。

# 适用边界

- 节拍编号是内容引用，不是镜头订单：B02 可一镜完成，也可由两个连贯观察完成。
- 校验的是文档内的一致性，不是受众理解或生成可行性。
