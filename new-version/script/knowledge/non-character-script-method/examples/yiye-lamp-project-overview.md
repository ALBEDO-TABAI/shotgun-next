# 要点

**声明：** “一页”折叠阅读灯是**原创虚构教学项目**。底座、立柱、唯一铰链、手动按钮、固定暖白光、名称与所有时长均为教学条件，不是用户真实商品资料。允许一只局部操作手，但不讲人物目标、冲突或经历。

## 模糊需求（起点）

30 秒；安静、精密、舒展，有产品吸引力；不要人物故事，也不要单纯旋转；最后要记住名称；后续还会做 15 秒和 6 秒。

## 教学事实卡

| 编号 | 设定 | 创作含义 |
|---|---|---|
| F01 | 扁椭圆底座、固定立柱、细长灯头；深灰硬质表面 | 产品身份要保持，不随风格变成柔性带 |
| F02 | 灯头通过立柱顶端唯一铰链转动；收拢时与立柱近似平行，工作时横向展开 | 主动作来自真实关系；不得拉长、增生关节 |
| F03 | 底座按钮手动开关，固定暖白光 | 不表达感应、自主开灯或调色 |
| F04 | 可照亮桌上书页；无功效及照度数字资料 | 可呈现使用关系，不讲护眼、无影或性能领先 |
| F05 | 名称「一页」，类别「折叠阅读灯」 | 文字由独立字卡承载，不交给图像模型自由编写 |
| F06 | 不讲人物；允许局部操作手 | 操作手是作用来源，不承担角色经历 |

**关系命题：** 在一个稳定枢点周围，让形态从收拢进入工作；再让这次转动与一页被照亮的空间联系起来。

## 版本关系

- 01–03 展示选择与构思；05 的 V1 是初稿；06 的 V2 是内容升级示范。**二者是教学演进，不是同时生效的两份生产「最终版」。**
- 06 的 V2 消费表显式更新设计需求用途；15 秒与 6 秒分别声明本版任务及放弃项，不宣称无损压缩。
- 候选标题不能替代未批准的实际产品文字。

# 适用边界

- 该项目只覆盖「允许局部操作手」的写法。完全无人的写法另见 [三色杯系列](/examples/three-color-cup-series.md)、[香氛框架错开](/examples/fragrance-frame-offset.md)、[18 秒材料片段](/examples/eighteen-second-material-piece.md)、[权限系统片](/examples/permission-system-piece.md) 与 [三弧线循环装置](/examples/three-arc-loop-installation.md)。
- 所有秒数是教学预算，经过算术检查而非受众或制作验证，见 [包结构检查记录](/checklists/package-structure-checks.md)。
- 先读 V1／V2 外观再回头读 01／03 的人，应检查这些内容是怎样从需求中选出来的，而不是只复制示例外观。
