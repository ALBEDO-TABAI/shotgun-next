# 要点

> 原创虚构教学项目，设定见 [V1 阅读正文](/examples/yiye-lamp-v1-script.md)。以下 ID、消费位置与来源表格一致。

| ID／类型 | 内容与可用状态 | 不变量及开放项 | 消费位置／最小验证 |
|---|---|---|---|
| D01／对象主规格 | LAMP-01 整灯及部件从属关系；准确轮廓与外观 | 唯一铰链、底座／立柱／灯头身份固定；环境自由 | B01–B06；各关键状态仍是同一产品，无增生或混用版本 |
| D02／动作与姿态 | 同一灯收拢、中间、工作状态及连接关系 | 单轴关系、固定立柱与底座、灯头不拉伸；允许不同观察方式 | B01、B02、B05；状态图或代理能区分固定与运动部分 |
| D03／操作状态 | 底座按钮可接触；未亮／亮起／稳定发光状态 | 手动开关、固定暖白光；不添加感应含义 | B01、B03；按钮接触能与亮灯建立清楚对应 |
| D04／作用对象 | 一只局部操作手，包含扶起、按键、退出条件 | 不新增角色经历；关键接口不能持续被遮挡 | B02、B03；粗略关系图或动作代理能完成接触而不改产品 |
| D05／书页对象 | 同一本打开的书与可追踪纸页；局部、整体均可使用 | 页边／折线等至少一项定位线索一致；精确正文非本版必需 | B01、B03–B06；局部能回到该书页，不任意换纸面 |
| D06／空间关系 | 桌面支撑、灯与书的相对位置、必要观察范围 | 底座稳定；书位于许可工作关系内；材质与细节开放 | B01–B06；各观察能对应同一布局，无无故穿插与漂移 |
| D07／光与表面关系 | 亮灯前后以及稳定光落在书页上的表现 | 不当成量化性能证明；不新增光推动实体动作 | B03–B06；能分清灯体发光与纸面受光，产品关系正确 |
| D08／准确文字 | 「一页」「折叠阅读灯」独立字卡 | 内容精确，不让图像生成自由改字；版式开放 | B06；在交付尺寸和时间中检查文字及产品识别机会 |
| D09／局部重新定位 | 纸面局部与整体书页的对应方案 | 同一页；不变成产品表面或新空间；可持续观察或切换 | B04、B05；两种观察之间有明确共同线索 |
| D10／声音职责 | B03 可选操作声；B04 空间延续；B06 可选结束处理 | 不靠声音替代必要视觉；无声版仍能理解主任务 | B03、B04、B06；只定义职责，最终音乐与混音另行发展 |

## 反向对应（需求 → 节拍）

D01：B01–B06｜D02：B01、B02、B05｜D03：B01、B03｜D04：B02、B03｜D05：B01、B03–B06｜D06：B01–B06｜D07：B03–B06｜D08：B06｜D09：B04、B05｜D10：B03、B04、B06。与 [节拍工作表](/examples/yiye-lamp-v1-beat-worksheet.md) 的正向引用逐项一致。

## 数量不是工作量

这十条不是十个必须单独生成的文件：D02、D03 可以由同一主资产与状态方案解决；D07、D09 可能属于照明和观察方案；D10 是声音协作需求。**设计需求数量不能被直接当资产数量或生成调用次数。**

# 适用边界

- 「最小验证」是交接用的可用性判断，不是受众测试，也不证明生成模型能完成。
- 来源包校验的是文档内正反向对应；没有声称真实下游 agent 已读取。
