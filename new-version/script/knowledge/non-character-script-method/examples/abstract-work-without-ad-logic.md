# 要点

> 原创虚构任务。来源未给出分段秒数，不应把它当作已完成时序验证的片段。

## 任务
12 秒展厅循环，主要展示“同一规则能产生多种空间关系”；**不含产品与行动引导**。

## 机制与结构
选 [M08 重复、变奏与规则偏离](/mechanisms/m08-repetition-variation-and-rule-deviation.md) ＋ [M12 循环、任意进入与持续空间](/mechanisms/m12-loop-any-entry-and-continuous-space.md)：

| 阶段 | 同一组条带沿共同轴翻转 |
|---|---|
| 第一阶段 | 同相 |
| 第二阶段 | 逐次延后 |
| 第三阶段 | 恢复到可接续状态 |

作品的贡献是**可追踪的规则与变化**，不是新卖点。

## 声音
可以由声音建立另一个稳定层，也可以无声。

## 判定标准
- 规则是否可被接触；
- 变化是否有意义；
- 循环条件是否实现；
- **不是**能否复述一个人物目标。

抽象作品也可以有意含混；需要作者知道含混在哪里，而非让下游误以为缺少脚本。

# 适用边界

- 本例不承担识别、理解产品或促成选择的任务；不要用广告任务的完成标准评价它。
- “有意含混”需要作者显式记录，否则下游会按缺失处理。
