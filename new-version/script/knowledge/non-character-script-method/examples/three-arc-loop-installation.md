# 要点

> 原创虚构展厅作品：三条独立弧线围绕同一中心逐步改变相位，周期中偶尔对齐，再缓慢分开。职责是**持续建立层次**，不传达操作知识。

## 脚本应写的规则

- 对象数量固定；
- 轨道不互换；
- 相位变化连续；
- 某些时刻对齐，但对齐不是必须等到的唯一信息；
- 名称可以常驻于独立层。

## 接缝

首尾相接只是技术条件，还需检查运动方向和变化速度的接续。可用周期记法：

```text
状态(t + 周期) = 状态(t)
```

这只是周期设计记法。若只匹配首尾图像，运动方向在接缝处反转，仍可能有可见顿挫。反过来，作品也可以选择**有意重启**；只有需求要求无缝时，才把无缝当验收条件。

## 随机进入检查

分别从周期的不同位置开始，看是否仍能认出对象、规则和必要品牌信息。无需等完整故事，也不应因段落可交换而判它没有结构。

# 适用边界

- 循环作品的评价不套用「开头—高潮—结尾」；也不把「任意进入可读」当成所有广告的要求。
- 本例是教学设定，没有运行任何展厅观看测试。
