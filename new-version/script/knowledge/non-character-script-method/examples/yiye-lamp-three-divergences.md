# 要点

> “一页”折叠阅读灯是**原创虚构教学项目**，唯一铰链、固定立柱、手动按钮等规格均为教学设定，不是真实商品资料。总览见 [“一页”项目总览](/examples/yiye-lamp-project-overview.md)。

## 1. 先写关系，不写色调
从“安静、精密、舒展”出发，沿用教学事实，得到三组关系：

- 固定与转动；
- 收拢与横向；
- 未亮与书页被照亮。

## 2. 第一轮候选：三张机制卡，三种重点

| 候选 | 机制卡 | 重点 |
|---|---|---|
| 真实操作 | [M02](/mechanisms/m02-condition-action-result-demonstration.md) | 作用 |
| 身份揭示 | [M01](/mechanisms/m01-cumulative-reveal-and-identity-reframing.md) | 发现 |
| 灯头展开与独立图形展开的类比 | [M06](/mechanisms/m06-relational-analogy-and-cross-object-echo.md) | 关系联想 |

## 3. 对三条路线施加同一限制
限制：“只允许产品、书与一次必要操作，不增加大型幻想空间。”

| 路线 | 受限后的情况 |
|---|---|
| 操作 | 仍成立：展开、按键、书页亮起 |
| 揭示 | 需要依靠真实局部，而非外部遮挡装置 |
| 类比 | 失去独立图形，但可转向灯的转动与书页空间关系，不一定需要纸艺宇宙 |

限制的作用是**看清每条路线依赖什么**，不是证明对象越少越好。若额外载体能显著增强表达，可以恢复，但需说明新增价值与设计条件。

## 4. 选主机制，写出片段胚
选择 M02，辅以 [M09](/mechanisms/m09-spatial-reveal-and-scale-rereading.md) 的局部重新定位。片段胚的内容次序：

1. 收拢的灯与打开的书先建立同一桌面；
2. 操作手抬起灯头，固定枢点始终明确，灯头停在工作姿态；
3. 按钮接触后，暖白光落到纸面；
4. 不是再一次产品旋转，而是从纸面局部进入完整书页，让此前的光被理解为一个具体阅读关系；
5. 产品名在这一关系稳定后出现。

这段已经可以写成初稿：它没有要求具体焦距、渲染器或音乐风格，也没有把“光”描写成一股能自动推动纸张的物质。

## 5. 不够有个性时，升级内容而非形容词

| 升级方向 | 做法 | 强化的是 |
|---|---|---|
| 形式母题 | 让“固定枢点”贯穿，相关线与空间始终围绕这个稳定关系组织 | 规则 |
| 前后回响 | 让开头的纸面局部在结尾被重新理解 | 观看结构 |

两者都值得提出，但不应直接同时采用：各写成一个同样长度的段落，再比较是否帮助主任务。

# 适用边界

- 选 M02 不是宣布演示路线对所有片子更好；本例的教学目标同时包含操作理解与非人物写作。
- 片段胚不是分镜，也不是生成提示词；时长与镜头由后续环节决定。
