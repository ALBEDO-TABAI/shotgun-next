> **声明**：「一页」折叠阅读灯是原创虚构教学项目，规格、名称、时长与段落均为教学设定，不是真实商品资料。V1 与 V2 是教学演进，不是同时生效的两份生产最终版；V2 不代表用户已批准真实项目。

# 要点

**本版任务**：尽早认出产品，理解展开与手动启动，记住名称。**主动放弃**：V2 的较长感官回响。

| ID／时间 | 内容 | 保留／放弃 |
|---|---|---|
| **V15-01**／0–2 秒 | 收拢产品与书同处一桌，完整身份明确 | 保留类别与参照，不做长谜面 |
| **V15-02**／2–7 秒 | 操作手扶起灯头，唯一铰链与固定立柱清楚 | 保留关键中间态，不要求完整慢动作欣赏 |
| **V15-03**／7–10 秒 | 按钮接触，灯亮，手退出 | 保留手动启动关系 |
| **V15-04**／10–15 秒 | 工作产品与书页关系稳定，名称及类别出现 | 合并使用关系与识别；不保留独立 B04 式感官段 |

总长 15 秒（2＋5＋3＋5）。

**若五秒仍不足以理解动作**：应减少其他任务或改用更清楚的观察，而不是要求生成模型任意加速且保证理解不变。

节拍使用 V15 前缀，是为了避免与 S 类来源、C 类案例编号混淆。

# 适用边界

- 15 秒版是**重分任务**，不是 30 秒版的无损压缩；它不再承担独立的纸面感官体验。
- 时间分配是可核算的写作预算，通过的是算术检查，不代表实际动画、文字阅读一定能在该时长内达成目标。
