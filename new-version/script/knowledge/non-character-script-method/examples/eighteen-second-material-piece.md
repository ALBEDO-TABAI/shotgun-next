# 要点

> **虚构任务：** 展示护肤品的包装与一种「铺展、停留」的感官方向。没有人体、吸收、修复或真实配方流变数据；代理材料明确独立于实际商品。

| 时间 | 原创内容 | 设计问题 |
|---|---|---|
| 0–4 秒 | 已确认产品站在独立台面，名称类别可辨 | 真实包装、稳定身份、与代理舞台分区 |
| 4–10 秒 | 另一独立表面上，代理凝胶在明确作用下沿浅槽缓慢铺展 | 源、接触表面、边界、结束状态；不进入皮肤 |
| 10–14 秒 | 凝胶停留，表面与厚薄关系得到接触；产品不发生材质变形 | 感官停留、代理与真实产品关系 |
| 14–18 秒 | 回到完整产品与准确字卡，代理材料只保持背景关系 | 身份与类别，不追加功效结论 |

总长 18 秒（四段首尾相接）。

## 关键提醒

- 这仍可能被观众解读为实际配方展示，所以**内部「代理」标记不是免责保证**。
- 实际项目可以：改用更清楚的独立艺术装置；降低真实流体模拟倾向；或取得真实材料依据。
- 关键是**保留创意可用路径**，而不是因为缺少功效资料就只能放产品静帧。

# 适用边界

- 时间分配是可核算的写作预算（来源包校验中列为「包装与材料（05 原创）」18 秒 4 段，算术通过），不代表材料体验一定能在该时长内达成。
- 是否构成需要依据的产品主张，须按目标市场与品类另行判断；本包不提供法律意见。
