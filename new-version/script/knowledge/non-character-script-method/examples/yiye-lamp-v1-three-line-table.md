# 要点

> 原创虚构教学项目。「一页」折叠阅读灯的规格、名称与全部时长均为教学设定，不对应真实商品。设定：唯一铰链、手动按钮、固定暖白光，允许局部操作手，不承担人物故事。

## V1 三线对齐

| ID／时间 | 世界线 | 信息线 | 时间与体验职责 |
|---|---|---|---|
| B01／0–4 秒 | 收拢产品立于桌面，未亮；书保持打开 | 尽早建立类别与完整身份 | 给稳定参照，不以巨大谜面开场 |
| B02／4–10 秒 | 手扶灯头，绕唯一铰链展开；底座和立柱固定 | 看清哪里转动、哪里不动 | 过程优先；关键中间态不被手遮住 |
| B03／10–14 秒 | 手按底座按钮，灯亮，手退出 | 手动启动关系明确 | 短动作后保留结果，不让环境同时起舞 |
| B04／14–21 秒 | 产品和书都稳定；光在纸面上 | 先接触纸面局部，再知道光落在哪里 | 触感、明暗与停留，而非新增功能 |
| B05／21–26 秒 | 同一产品与书页以整体关系被呈现 | 将折叠、灯光和阅读联系起来 | 从局部回到用途，恢复空间定位 |
| B06／26–30 秒 | 工作姿态保持，准确名称字卡出现 | 「一页／折叠阅读灯」被读取 | 辨认与结束，不追加全新卖点 |

**时间解释。** 总长 30 秒，分配是**教学预算，不是实验得出的比例**。B02 较长，因为本例必须看懂转动关系；B04 较长，是为了给感官停留空间。实际发现 B04 重复时可以合并，而不是因它「没有新信息」自动删除。

## 这张表还不是分镜

- B02 可以一镜完成，也可以用两个连贯观察完成。
- B04 可以由观看范围变化完成局部到书页的定位，也可以用明确的局部—整体连接完成。
- 初稿要求的是：同一页、同一光区、产品没有凭空改变——而不是唯一相机轨迹。

## 两次改排实验

| 改排 | 做法 | 得到 | 代价 |
|---|---|---|---|
| 甲 | 先亮灯工作，再回到收拢并解释操作 | 由「理解动作后看到结果」变成「先见结果再获得解释」，可以成立 | 需要清楚区分演示段与当前使用段 |
| 乙 | 产品从头到尾亮着，只展示形态变化 | 减少一次开关动作，获得更多感官时间 | 放弃手动启动的解释任务；这不是剪辑层的无损替换，而是任务取舍，需要内容负责人同意 |

# 适用边界

- 仅为教学示范；时间段经过算术检查（起点、终点、相邻连续、总长），并与第 05 篇正文及表格一致，但不代表实际动画、文字阅读或材料体验一定能在相同时长内达到目标。
- V1 是初稿，不是与 V2 同时生效的生产基线。
