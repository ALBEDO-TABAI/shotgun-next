# 要点

## 1. 一句话，三种可成立版本

| 版本 | 内容 | 需要的依据 / 条件 |
|---|---|---|
| 真实包装机构 | 盒盖开启，已有折叠机构随之展开 | 真实结构、连接、内侧、干涉与产品承托依据 |
| 独立纸艺舞台 | 盒盖打开后，盒内展陈纸艺依舞台规则展开；纸艺**并非产品销售包装的一部分** | 区分包装事实与艺术装置 |
| 艺术空间入口 | 开盖提供进入不可能空间的入口，实际盒体不扩大；观看者在艺术规则下进入内部世界 | 内外边界、入口线索与产品身份保持 |

三个版本都可以有创作价值，没有必要只允许现实机构；但它们**不能共用同一份没有区别的需求清单**。

## 2. 选独立舞台版本写正文（原创示范，要点）

盒子先闭合、产品不可见 → 盒盖绕已确认的连接打开，露出内部纸艺舞台和固定承托 → 纸艺由中央向两侧分层展开；产品始终位于承托上，不被纸片吞没，也不从材料中生成 → 展开后盒体尺寸保持，内部层次来自纸艺间距 → 产品与盒体共同出现，字卡说明当前产品名称，**不暗示售卖包装自动展开成舞台**。

## 3. 提取结果

- **需要：** 盒体闭合／半开／全开；盖体内侧；纸艺折叠／中间／展开；产品承托；产品与纸片接触边界；内外空间对应；开启时的可见性；准确文字。
- **不一定需要：** 全尺寸三维建筑、无穷空间、每一页纸纹、所有未见背面的高精细制作。后续观察需要新增背面时再更新需求；不要把未来所有可能镜头都当当前工作范围。

## 4. 一次美术提案如何反馈

美术发现多层纸艺会遮住产品，提出把产品抬高到独立中心台：

- 若原内容只要求产品始终可见且被承托 → 这是**载体改进**；
- 若原内容恰恰需要产品由层片中逐渐被发现 → 提案**改变了披露**，编剧要重新组织。

「加一个台子」是否是内容变更，取决于它**改变什么关系**，不取决于这项建模工作看起来有多小。

# 适用边界

- 三种版本与示范正文均为教学用的原创设定，不对应任何真实包装。
- 真实机构版本需要真实结构依据；没有依据时不应以该版本承担产品主张。
