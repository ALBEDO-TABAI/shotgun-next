# 要点

> **声明**：「一页」折叠阅读灯是原创虚构教学项目，全部规格仅用于教学，不对应用户真实商品。第 01—03 篇是发展过程，第 05 篇给出 V1 全稿，第 06 篇给出 V2 改稿；它们不是相互竞争的生产基线。

## 1. 模糊需求

「30 秒，安静、精密、舒展，有产品吸引力；不要人物故事，也不要单纯旋转。最后要记住名称，后续还会做 15 秒和 6 秒。」

## 2. 教学事实卡

| 编号 | 本例设定 | 创作含义 |
|---|---|---|
| F01 | 扁椭圆底座、固定立柱、细长灯头；深灰硬质表面 | 产品身份要保持，不随风格变成柔性带 |
| F02 | 灯头通过立柱顶端唯一铰链转动；收拢时与立柱近似平行，工作时横向展开 | 主动作来自真实关系；不得拉长、增生关节 |
| F03 | 底座按钮手动开关，固定暖白光 | 本例不表达感应、自主开灯或调色功能 |
| F04 | 可以照亮桌上书页；没有功效及照度数字资料 | 可以呈现使用关系，不讲护眼、无影或性能领先 |
| F05 | 名称「一页」，类别「折叠阅读灯」 | 文字由独立字卡承载，不交给图像模型自由编写 |
| F06 | 不讲人物；允许局部操作手出现 | 操作手是作用来源，不承担角色经历 |

## 3. 把体验词变成待探索关系

| 体验词 | 不直接等于 | 可以是 |
|---|---|---|
| 安静 | 慢 | 动作停止后保留阅读机会；没有多余响应的清楚控制 |
| 精密 | 齿轮 | 固定点清楚、转动边界明确、到位姿态稳定 |
| 舒展 | 无限变大 | 灯头从并行关系进入横向工作关系 |

收束成的**关系命题**：在一个稳定枢点周围，让形态从收拢进入工作；再让这次转动与一页被照亮的空间联系起来。

## 4. 三条真正不同的路线

| 路线 | 内容胚 | 主要体验 | 代价与需验证处 |
|---|---|---|---|
| A：真实操作 | 看见收拢产品；操作手展开灯头、按下按钮；最后理解灯与书页的关系 | 清楚、克制、具体 | 手可能带来新的制作条件；整体创意需避免成为说明书 |
| B：识别重构 | 先看一段线与折角；增加连接线索；最后发现它们属于同一阅读灯 | 发现、精确、辨认 | 产品认知延迟；短版需要改写而非原样缩速 |
| C：空间类比 | 独立图形绕固定点打开；随后同样关系由真实灯头完成；最后落到阅读空间 | 形式、舒展、关联 | 类比容易抢走产品；需避免图形被误读成内部机构 |

**选择**：A 为主干（教学目标同时包含操作理解与非人物写作，A 的事实依赖更可控），不是宣布 A 对所有片子更好；保留 B 的「先看光面、后理解书页」局部披露方法作为辅助。

## 5. 写出选择后的牺牲

不展示内部电路；不做大型液体世界；不介绍全部参数；不将「安静」转成失眠人物的情绪困境。它们不是永久禁用项，而是本版的取舍。

## 6. 骨架与设计问题

骨架：认出收拢状态 → 看清唯一枢点的转动 → 看见手动启动 → 接触书页上的光 → 将局部光面理解为具体阅读关系 → 名称落版。

设计问题（不是「还有什么更高级的素材」）：

- 需要在转动时看清固定点；
- 手要能完成操作且不遮住接口；
- 发光前后保留同一书页与产品；
- 局部光面不能被误读成产品表面；
- 结尾文字与产品识别都要有时间。

这已经可以交给美术与时序提出方案，而无需先决定每一镜的焦距。

# 适用边界

- 所有规格、名称与时长都是教学条件；不得当作真实商品资料或受众结论。
- 路线 A 的胜出只在本例的教学目标下成立。
