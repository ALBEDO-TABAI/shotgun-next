> **声明**：「一页」折叠阅读灯是原创虚构教学项目，规格、名称、时长与段落均为教学设定，不是真实商品资料。V1 与 V2 是教学演进，不是同时生效的两份生产最终版；V2 不代表用户已批准真实项目。

> 这是教学变更**已经如何写入文本**的示范，不是实际 agent 已接收任务的回执。实际执行时由各消费者报告已采用的版本，本包不代他们填写「已确认」。

# 要点

D01—D10 的定义来自第 05 篇；V2 中保留定义，仅更新明确变化的职责与引用。

## 正向：V2 节拍 → 实际消费的需求

| V2 节拍 | 对应原内容 | V2 实际消费需求 | 本轮需要更新什么 |
|---|---|---|---|
| R01 | B01 | D01、D02、D03、D05、D06、D09 | D05/D09 的页边定位线索提前进入建立段 |
| R02 | B02 | D01、D02、D04、D06 | 时间改为 5–12 秒；单铰链与手部条件不变 |
| R03 | B03 | D01、D03、D04、D05、D06、D07、D10 | 时间改为 12–16 秒，操作声位置随当前内容移动 |
| R04 | B04＋B05 | D01、D02、D05、D06、D07、D09、D10 | 合并感官与整体回收，D09 不再派生两个独立段落任务 |
| R05 | B06 | D01、D05、D06、D07、D08、D10 | 落版改为 25–30 秒；候选标题未批准前不加入 D08 |

## 反向：需求 → 在 V2 中的用途

| 需求 | V2 使用节拍 |
|---|---|
| D01、D06 | R01—R05 |
| D02 | R01、R02、R04 |
| D03 | R01、R03 |
| D04 | R02、R03 |
| D05 | R01、R03、R04、R05 |
| D07 | R03—R05 |
| D08 | 仅 R05 |
| D09 | R01、R04（V1 中用于 B04/B05） |
| D10 | R03、R04、R05 |

这样既没有消失的需求，也没有只写在新正文而未交给设计端的定位条件。

## 旧素材怎么办

若旧 B04/B05 已有素材，不自动丢弃：先检查它们是否仍能组成 R04 的同页回收；能复用的保留，不能满足的部分重新设计。当前变化影响的是**组合与时间**，并不授权改造真实灯体。

# 适用边界

- 来源的结构校验确认过：V2 五个节拍与十项需求用途的正反向说明逐项一致；该检查针对的是文档交接合同，不声称真实下游 agent 已读取新版本。
- 是否沿用 B 编号或改为 R 编号不是核心，见 [内容 ID、版本与检查结果不要互相冒充](/principles/content-id-version-check-separation.md)。
