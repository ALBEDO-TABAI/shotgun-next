> **声明**：「一页」折叠阅读灯是原创虚构教学项目，规格、名称、时长与段落均为教学设定，不是真实商品资料。V1 与 V2 是教学演进，不是同时生效的两份生产最终版；V2 不代表用户已批准真实项目。

# 要点

**本版任务**：认出工作状态的产品及名称，建立与书页的关系。**明确不承担**：完整展开和手动启动过程的解释。

| ID／时间 | 内容 | 说明 |
|---|---|---|
| **V6-01**／0–2 秒 | 产品已处于展开、亮灯的工作姿态，完整轮廓与书页关系可见 | 这是初始状态，不是自动开灯事件 |
| **V6-02**／2–6 秒 | 同一稳定关系保持，名称「一页／折叠阅读灯」出现 | 只保留必要识别和体验；不叠加全新功能 |

总长 6 秒（2＋4）。

**评价口径**：六秒版的合格不能用「是否看懂全部操作」评价，因为该任务已明确不承担。若用户必须解释操作，应讨论更长版本或减少其他内容，不伪称无损压缩。

# 适用边界

- 开场即亮灯只是初始状态的选择；不得由此推出「自动亮灯」「感应启动」等产品功能（教学事实为手动按钮）。
- 这是提升操作中「用有理由的缺省代替解释过量」的极端情形：省略之后，不能继续要求它承担被删去的信息任务。
