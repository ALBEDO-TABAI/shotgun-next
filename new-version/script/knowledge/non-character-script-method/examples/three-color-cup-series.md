# 要点

> **声明**：原创虚构教学需求。教学事实只包含杯型、配色和类别，不包含保温、耐摔或工艺性能；颜色名称是本例的命名设定，实际项目需换成已批准名称。

需求：「三只相同杯型，分别为雾白、青灰和赭红；十八秒，清楚展示选择，又不要像静态商品目录。」

## 第一步：任务卡（不是替三只杯子安排性格）

- 必须得到：同一系列中的三个颜色选项；
- 允许联想到：有秩序而不呆板；
- 本版不做：不证明哪一色更好，不解释制作工艺。

## 第二步：从「相同与不同」找锚点，生成三条机制不同的路线

保持：杯型和展示尺度。可变：颜色与出场位置。

| 路线 | 机制 | 侧重 |
|---|---|---|
| A | 同一比较位置依次换入变体 | 更直接承担选择 |
| B | 同一套转动规则由三只杯子以不同相位响应 | 更侧重形式 |
| C | 先看局部色面，最后发现三者属于同一杯型 | 更侧重发现 |

若「清楚展示选择」是主任务：选 A 为主、借 B 的轻微节律变化，而不是先精修最神秘的 C。

## 第三步：写成普通正文（要点转述）

雾白杯先进入固定展位，杯口与把手关系被看清；它移到一侧，青灰杯沿同一方向来到同一展位，保持相同尺度和姿态；随后赭红杯接替。三只杯**没有相互变形，也不是同一只杯子变色**。最后三者并列，名称分别对应各自颜色，完整系列保持。

## 第四步：当前预算

| 时间 | 内容 |
|---|---|
| 0–4 秒 | 雾白与共同杯型 |
| 4–8 秒 | 青灰 |
| 8–12 秒 | 赭红 |
| 12–18 秒 | 三者并列与准确名称 |

这是一个可核算的候选，**不声称四秒是颜色识别的科学阈值**。若只需要两色，直接删去一个成员并重分时间，无需重建整条人物因果链。

## 第五步：设计问题

- 只需要一套杯型身份及三个配色定义，不是三套自由设计；
- 需要统一观察条件、换入换出路径、最终并列空间与标签对应；
- 美术可以发展台面或背景，但不能让某只杯子明显更大来暗示容量差异；
- 时序可以改变节律，但不能让颜色切换看起来像真实变色功能。

## 结论

这条片的次序大体可交换，恰好因为它采用分类与比较。优化目标不是强造「必须先雾白后青灰」的剧情理由，而是让每个变体可比较、每次出现有轻微节律差异、结尾能回收系列关系。**连续创作路径负责完成内容决定，不负责把所有任务改造成同一种结构。**

# 适用边界

- 时间表通过了包内的算术检查（18 秒、4 段），这只代表写作预算可加总，不代表实际动画或文字阅读一定能在相同时长内达到目标。
- 本例不含任何产品性能主张。
