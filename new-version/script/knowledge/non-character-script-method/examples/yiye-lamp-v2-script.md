> **声明**：「一页」折叠阅读灯是原创虚构教学项目，规格、名称、时长与段落均为教学设定，不是真实商品资料。V1 与 V2 是教学演进，不是同时生效的两份生产最终版；V2 不代表用户已批准真实项目。

# 要点

以下为逐节拍提炼，ID 与时间与来源一致；当前预算 5＋7＋4＋9＋5＝30 秒。

| ID／时间 | 小标题 | 发生什么 | 明确不做 |
|---|---|---|---|
| **R01**／0–5 秒 | 关系尚未展开 | 灯以收拢姿态立在打开的书旁；固定立柱与贴近它的灯头形成两条相邻的竖向关系；书页边缘或折线提供另一处稳定参照；完整产品已能被辨认 | 不把书页写成「等待拯救」的角色，不让环境刻意受难；只建立两件东西尚未进入工作的关系 |
| **R02**／5–12 秒 | 只围绕一个点改变 | 局部操作手扶起灯头；立柱和底座不动，灯头绕唯一铰链进入横向姿态；观看重点是两条相邻的线如何成为支撑与展开关系；关键中间态被保留，手让出观察空间；到位后动作停止 | 没有额外结构跟着弹出，没有第二个环境动作迫使观看者转移；重点不在金属飞掠 |
| **R03**／12–16 秒 | 让工作关系成立 | 同一只手按下底座按钮，暖白光亮起并落到书页；手离开，灯和书保持原位；光是这次操作的结果 | 不是未交代的自主响应；此处不追加参数 |
| **R04**／16–25 秒 | 同一页上的重新理解 | 观看从书页的局部纹理与明暗边界进入更完整的阅读关系；先前看见的页边或折线再次出现，确认是开头同一页；固定点没变，灯头已展开，光停留在这页上 | 感官停留与空间回收合并，不再单独追加一段重复整体旋转；不进入另一个抽象世界 |
| **R05**／25–30 秒 | 把表达留给准确名称 | 工作状态保持；名称「一页」和类别「折叠阅读灯」出现 | 不在名称刚出现时同时收拢灯、翻合书并离开空间；结束的职责是辨认与回味 |

**关于标题**：「一处转动，一页有光」在本例中只是候选创意标题，可以讨论，但不替代必须准确的名称与类别；未批准前不进入字卡需求（见消费表对 D08 的处理）。

**母题如何落到节拍**：R01 建立「两条相邻的线＋同一页的定位线索」→ R02 围绕唯一枢点改变 → R03 转动关系与这一页会合 → R04 页边线索再次出现，完成一次重新理解 → R05 让关系保持。

# 适用边界

- 这是初步剧本，不是分镜：节拍编号是内容引用，不是镜头订单；每段可由一个或多个观察完成，只要同一页、同一光区、同一产品身份保持。
- 产品事实与 V1 完全相同（单铰链、手动开关、固定暖白光）；动作代理仍需核验，没有实际生成或观看测试。
- 另一可比较预算 3＋9＋4＋10＋4 是待比较候选，不是同时存在的第二份当前时间表（见改动说明）。
