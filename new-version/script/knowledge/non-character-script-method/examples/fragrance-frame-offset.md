# 要点

> 原创虚构任务，时间为**教学预算**，不是实验比例。

## 任务与事实
- 20 秒；识别瓶型与名称；尝试清透、层次、轻快；
- 没有配方与功效说明需求；
- 产品是一只**不可变形的硬质瓶**，外观已确认。

## 关系候选
层叠到分开；接触后分离；明暗边界逐渐清楚。

若选择“流体穿过瓶体”，就新增了可能的成分或功能含义；没有必要时暂不采用。

## 三条路线

| 路线 | 内容胚 | 主机制／辅助 | 判断 |
|---|---|---|---|
| 甲 空间间距 | 一组独立框架从重叠变为错开，产品一直保持完整；层次逐渐清楚后，产品名稳定出现 | [M09](/mechanisms/m09-spatial-reveal-and-scale-rereading.md)，辅 [M08](/mechanisms/m08-repetition-variation-and-rule-deviation.md) | 本例选用 |
| 乙 短促触点 | 几枚独立圆润物体轻触悬置薄片，薄片短暂响应，离开后恢复；最后瓶体与这一空间并置 | [M04](/mechanisms/m04-contact-compliance-recovery-trace.md) | 可能更轻快，也可能更像玩具，需要小样判断 |
| 丙 身份重构 | 先看已知瓶肩弧线与瓶盖接缝，再用完整轮廓回应 | [M01](/mechanisms/m01-cumulative-reveal-and-identity-reframing.md) | 更贴近产品，但感官层次较弱 |

## 选定路线甲的时间预算

| 时间 | 内容 |
|---|---|
| 0–4 秒 | 产品身份与层叠关系 |
| 4–11 秒 | 框架依次错开 |
| 11–16 秒 | 产品与间距稳定 |
| 16–20 秒 | 名称与完整识别 |

## 设计重点
框架独立性、前后关系、产品轮廓与不变标签——而不是替瓶子发明柔软外壳。

## 一次创意优化
把“框架不断飞散”改为“每次错开都让同一瓶型多一处可辨”，使运动与识别共同工作。这是**内容升级**，不只是更安全。

# 适用边界

- 框架是独立代理装置，属于感受类比，不表示产品具有任何分层、清洁或功效属性，见 [四种真实性层级](/frameworks/authenticity-levels.md)。
- 路线乙是否“像玩具”是待小样判断的假设，来源没有给出结论。
- 时间分段已通过来源的算术检查（总长 20 秒、4 段），不代表实际动画或文字阅读一定能在同样时长内达到目标，见 [包结构检查](/checklists/package-structure-checks.md)。
