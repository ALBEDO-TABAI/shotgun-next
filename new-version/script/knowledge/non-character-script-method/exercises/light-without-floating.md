# 题目

给“轻”写三个**不含漂浮**的片段。

# 示范方向

| 方向 | 片段思路 | 性质 | 约束 |
|---|---|---|---|
| 实用行为 | 明确支撑下的单手搬移 | 真实产品行为 | **只能在产品资料允许时使用** |
| 触感类比 | 独立薄片受扰后的短响应 | 代理材料经验 | 只表达代理材料经验，不代表产品属性 |
| 空间组织 | 复杂关系整理后留下可辨间距 | 视觉轻简 | 表达的是视觉上的轻，不是重量 |

# 判断要点

- 三个方向分别是实用行为、触感类比、空间组织，**不能混成“产品真实重量很轻”**。
- 每个片段都应写出对象、变化、关系与结束状态，而不是再换一个形容词。
- 自检：三个片段是否机制不同，还是同一画面的同义改写。
