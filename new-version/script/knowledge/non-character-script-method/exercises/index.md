# 练习 · Exercises

各篇练习与示范判断。

# 01 能力定位与连续创作路径

* [练习：给同一支香氛写三条任务定义](fragrance-three-task-definitions.md) - 为同一支香氛分别写「识别优先」「感受优先」「系列选择优先」三条任务定义，每条四句、禁止新增人物困境，检查是否真的产生三种不同组织关系。

# 02 对象、信息与时间体验编排

* [编排练习三则：方块变包装、泡沫退去、30 秒压 15 秒](orchestration-exercises.md) - 三个带示范判断的练习：区分真实变形、披露与图形替换；区分遮挡、清洁主张与相机任务；压缩时先决定删哪个职责。

# 03 创意生成与可见过程构造

* [练习：给“轻”写三个不含漂浮的片段](light-without-floating.md) - 用实用行为、触感类比、空间组织三个方向各写一个“轻”的片段，并保持三者的事实层级不混成“产品真实重量很轻”。

# 05 初步剧本写作与设计需求交接

* [练习：三个真实层级的「水中诞生」与过度需求检查](script-handoff-exercises.md) - 练习一把「产品在水中诞生」改写成三种真实层级并分别提取需求；练习二判断一份为五秒开盖要求全套内部零件与 360 度模型的需求是否过度。
