# 要点

## 练习一：「产品在水中诞生」的三个真实层级

**任务：** 把这句话改成三个不同真实层级的版本，并分别提取需求。

**示范：**

| 版本 | 内容 |
|---|---|
| 真实行为 | 真实产品从水下被提出 |
| 并置 | 独立水形与产品并置 |
| 明确超现实 | 水形变为产品的明确超现实变形 |

分别提取：**接触、成分含义、身份变化和中间态**需求。**不能给三者同一份资产单。**

## 练习二：检查一份需求是否过度

**待检需求：** 「为了五秒盒盖开启，要求盒子的所有内部零件、全部历史包装、360 度高精度模型与十种场景。」

**示范判断：** 保留开启与当前观察需要的部分；其余只有在有明确使用或验证需求时才进入范围。

# 适用边界

- 示范不是唯一答案；关键在于三个版本得到**不同**的需求，而过度需求能说出每一项的消费位置或被删去。
