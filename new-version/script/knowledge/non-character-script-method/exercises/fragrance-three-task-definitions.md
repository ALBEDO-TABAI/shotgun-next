# 要点

## 题目

给同一支香氛写三条任务定义：

1. 识别优先；
2. 感受优先；
3. 系列选择优先。

**限制**：每条只写四句内容；禁止新增人物困境。

## 检查标准

是否真的产生**三种不同的组织关系**，而不是同一条内容换三种形容词。

## 示范解法

| 任务定义 | 示范方向 |
|---|---|
| 识别优先 | 建立瓶型线索 |
| 感受优先 | 组织一种可辨认的材料经验 |
| 系列选择优先 | 使三种变体保持相同比较条件 |

它们无需共享相同开头，也无需都以高潮结束。

# 适用边界

- 示范解法只给方向，不是唯一答案。
- 香氛是虚构练习对象，不含任何成分、功效或配方事实；感受类内容不得暗示成分因果。
