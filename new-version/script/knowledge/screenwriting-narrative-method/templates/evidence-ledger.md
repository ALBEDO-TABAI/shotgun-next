# 要点

分析中的观察、人物判断、机制推测、创作者意图与实际效果**分别记录**，不共用一个"可信"标签。

# Schema

| 层次 | 示例 | 所需依据 |
|---|---|---|
| 可见事实 | 角色删掉一段未发送文字 | 当前画面或文本 |
| 人物理解 | 她认为需要道歉 | 行为、语言及语境；可能仍是推断 |
| 机制假设 | 删改突出回应策略变化 | 前后材料对照 |
| 意图自述 | 创作者说想表达一次小选择 | 可靠访谈或记录 |
| 实际效果 | 某些测试者读出明确安排 | 真实测试过程与反馈 |

# 三条使用规则
- **证据要小范围而完整**：只有一句台词可能不足，需要前一回应与后一个动作；引文越多不自动越强，选能支持结论的最小完整范围。
- **来源不同，不用一个"可信"包办**：画面直接证明门关闭，不证明谁想断绝关系；访谈证明某人这样解释创作，不证明所有观众如此体验。
- **未知不是空白待补**：人物没有说明动机，可以保持未知；若后场需要唯一动机，标记为待验证关系。分析者不能通过合理想象把缺口自动修好。

# Examples

```text
证据ID：E12
版本／位置：本次片段，开箱之后
直接可见：旧物完整，外包装有此前出现过的标签
支持判断：物件被保留，并有整理的线索
不充分支持：一定由父亲独自整理；所有矛盾已解决
需要补查：前文谁使用过标签；后文有无明确归因
```
