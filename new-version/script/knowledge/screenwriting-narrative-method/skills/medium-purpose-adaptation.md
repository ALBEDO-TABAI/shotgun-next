# 启动条件

媒介或用途改变（来自 [模块边界总表](/methods/call-modules-by-problem.md)）。

# 输入

实际媒介、用途、目标条件、事实性约定、品牌材料、当前作品。未知字段允许保留，不自动补品牌策略或群体偏好。

# 步骤

1. 完成 [四轴定位](/frameworks/four-axes-purpose-medium-factuality-context.md)；
2. 判断主导组织（[整体组织原则判断法](/methods/dominant-organizing-principle-test.md)）；
3. 识别可迁移与不可迁移关系（[跨版本交接的四类内容](/templates/cross-version-handoff.md)）；
4. 为每版明确任务；
5. 调整载体而非机械裁切（[裁切、短版与跨媒介的损失](/frameworks/crop-short-version-cross-media-losses.md)）；
6. 核对事实、关系和识别（[品牌与故事的连接](/frameworks/brand-story-connection.md)、[产品因果谨慎](/principles/product-causality-caution.md)）；
7. 制定对应测试（[测试矩阵](/checklists/09-test-matrix.md)）。

# 输出

适配档案、版本任务表、关键损失说明、待验证条件、具体样稿。不只是一列尺寸。输出遵循 [统一 skill 接口](/skills/unified-skill-interface.md) 的 result 结构，状态为 proposal。

# 通过条件

- 用途与形式不混淆；
- 虚构与证据不混淆；
- 单幅推断不扩成完整事实；
- 产品意义不冒充功能；
- 缩短或裁切后的版本重新检查。

# 不应自动做什么

声称短版完整保留全部长版作用。
