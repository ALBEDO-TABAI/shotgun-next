# 输入

- 实际作品版本（含声音、结尾、字幕；缺哪一项就声明哪些结论不能确认）
- 分析范围
- 世界条件
- 人物知识依据
- 当前任务

# 流程

1. 先无解释地记录材料
2. 建立关键事实和来源
3. 区分人物与观众的知识变化
4. 识别观看问题（好奇 / 悬念 / 惊讶）
5. 把信息分类为必要、延迟、开放、可删
6. 检查载体
7. 提出单变量替代
8. 安排验证

# 交付

- 关键理解图
- 简化信息表
- 主要误读风险
- 需保护的揭示关系
- 可测试修改

不只交"悬念不足""留白高级"等标签。

# 通过条件

- 事实与信念分开
- 知识变化有路径
- 必要信息可获得
- 开放范围明确
- 反转不靠临时规则免责
- 判断符合实际材料范围

# 启动条件与不应自动做什么

- 启动：误读、留白、揭示问题。
- 不应自动做：以"作者知道"代替"观众可获得"。
