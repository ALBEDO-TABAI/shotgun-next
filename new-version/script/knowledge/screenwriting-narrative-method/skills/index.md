# Skill 接口 · Skill Interfaces

各篇模块的输入、步骤、输出结构与启动/停止条件，以及统一接口。


# topic-01
* [skill：narrative-form-identification（叙事形式识别与建模）](narrative-form-identification.md) - 基于作品及可核验语境识别不同层面的形式属性、解释属性之间的关系、建立允许不确定性的证据化形式档案：任务边界、四类输入、六步流程、判断记录格式与六项通过条件。

# topic-02
* [skill：screenwriting-work-and-contribution-map](screenwriting-work-and-contribution-map.md) - 编剧工作与贡献地图模块的输入、步骤与输出结构：按六类工作识别关键选择，追踪来源、载体、依赖与实现状态，输出可行动的问题与验证办法；无证据不裁定署名。

# topic-03
* [skill：creative-origin-and-question-framing](creative-origin-and-question-framing.md) - 起点抽象或方向未定时启动；输入 brief、感受、细节、人物、事实、物件或形式兴趣，输出材料地图、暂定问题、候选形式、代表性段落、未知与测试。

# topic-04
* [skill：character-relation-world-model](character-relation-world-model.md) - 人物—关系—世界联合模型的接口：输入材料与模式边界、六步工作流程、YAML 输出模板；只维护真正影响作品和后续执行的关系。

# topic-05
* [skill：scene-plot-and-rhythm-design](scene-plot-and-rhythm-design.md) - 场景、情节与节奏模块的输入、分析流程、创作流程与场景记录 YAML；非叙事段落允许不适用因果字段，不为填表而虚构剧情。

# topic-06
* [skill：dialogue-as-interaction](dialogue-as-interaction.md) - 对白模块的输入（前后文、人物知识、关系与任务、必要信息、语言风格、目标媒介）、八步操作与关键轮次 YAML 输出模板；只标对理解和执行有影响的轮次。

# topic-07
* [skill：信息设计与揭示（information-design-and-reveal）](information-design-and-reveal.md) - 第07篇的模块接口：输入实际版本与知识依据，八步流程输出关键理解图、信息表、误读风险、需保护的揭示关系与可测试修改；六项通过条件。

# topic-08
* [skill：evidence-based-expression-review](evidence-based-expression-review.md) - 第 08 模块接口：输入实际版本、任务、创作材料、接收反馈与约束；流程为记录反应与证据→辨认形式→选择标准→分别检查四种品质→列取舍与反证→按影响排序→提出可验证小修改；输出 J 编号判断记录。

# topic-09
* [skill：medium-purpose-adaptation（媒介与用途适配）](medium-purpose-adaptation.md) - 输入媒介、用途、目标条件、事实性约定、品牌材料与当前作品，经四轴定位、主导组织判断、关系迁移与版本任务设定，输出适配档案、版本任务表、关键损失说明、待验证条件与样稿。

# topic-10
* [护肤短片案例 · skill 调用与教学使用](skincare-case-teaching-use.md) - 以真实 brief、产品与品牌材料、观看条件为输入，按当前风险调用第一至十二篇对应模块，输出场景稿、信息表、时间草案、关键关系记录、品牌待补项、版本任务与测试计划；附四个练习。

# topic-11
* [skill：close-reading-and-diagnostic-review](close-reading-and-diagnostic-review.md) - 作品细读与诊断审查模块的输入、默认流程、完成条件与自检反例；启动条件是分析现成材料，核心输出是证据报告、竞争解释与最小修改，不应默默从分析跳到重写。

# topic-12
* [统一 skill 接口：iterative-screenwriting-workflow 与全包统一输入／输出](unified-skill-interface.md) - 本包各模块共用的输入结构（material/request/context）、输出结构（result 十二字段）、状态词含义（proposal/current/consumed/checked）与限制声明；是知识接口示例，不是可安装的 skill 包。
