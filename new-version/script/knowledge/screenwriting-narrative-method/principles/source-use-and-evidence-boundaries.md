# 要点

本包（编剧与叙事研究包，原体系第②–⑫篇）是**面向方法建设的主题性研究与综合**，不是具有预注册检索式和全量筛选流程的系统综述。整理日期 2026-09-18。

## 来源类型决定论断强度

| 来源类型 | 能支持什么 | 不能支持什么 |
|---|---|---|
| 署名学术理论综述（Living Handbook of Narratology 等） | 建立概念、呈现学术争论 | 不是观众效果实验，不自动证明创作效果 |
| 创作者第一人称讲座 / 编剧本人文章与对谈 | 提供实践立场与提问方式 | 不能改写为所有作品的普遍规则 |
| 同行评审实证研究 / 语料研究 | 仅支持其样本、材料、任务与模型范围 | 不能外推为最佳创作处方 |
| 行业制度原文 / 专业协会原则 | 说明该机构的定义与原则 | 不是全球统一职业规则或法律判断 |
| 出版简介、摘要、框架介绍 | 作为研究方向与延伸阅读 | 不声称已读全文，不做完整原典分析 |

被来源间接引介的论文**不计入**本包直接读过的原文。

## 访问范围受限的来源（须保留限制）

- [Macdonald 专著](/references/macdonald-screenwriting-poetics-2013.md)：仅取得出版简介与目录。
- [Escalas 论文](/references/escalas-narrative-processing-2004.md)：仅取得摘要和元数据。
- [DAWG 框架](/references/dawg-from-reflection-to-release.md)：使用机构和框架介绍，未逐页阅读下载版。

## 不允许的推论（来源索引明列）

- 不能由电影语料平均推导最佳转折秒数（见 [Cutting 2016](/references/cutting-dynamics-of-popular-movies-2016.md)）。
- 不能由事件分段研究推导"所有快剪更有效"（见 [Magliano & Zacks 2011](/references/magliano-zacks-continuity-editing-2011.md)）。
- 不能由英语短篇和特定旧模型的结果推断当前中文影视反馈性能（见 [Rashkin 等 2025](/references/rashkin-help-me-write-a-story-2025.md)）。
- 不能由十四位专业编剧的系统研究证明最终影片普遍更好（见 [DuoDrama 2026](/references/tang-duodrama-2026.md)）。
- 不能由品牌态度或联系研究直接推断本案销售（见 [Escalas 2004](/references/escalas-narrative-processing-2004.md)）。

## 关于案例与测试

- 所有案例均为**自拟**，或对原对话虚构案例的扩展；没有进行受众实验、真实拍摄、产品功效核验或本地法律合规审查。
- 测试表描述**要怎样测试**，不是测试已通过。
- AI 研究不用于宣称当前所有模型表现或自动创作收益。
- 工作表、流程、接口、诊断练习为本包综合，不是任何单一学者的完整学说，也不是经部署认证的软件系统。

# 适用边界

- 学术术语之间存在差异，各篇采用的**工作定义**已在正文注明；跨篇引用同一术语时以该篇定义为准。
- 第一篇（[叙事形式识别](/topics/01-narrative-form-identification.md)）为用户原文，其历史引用占位符按原样保留，不冒名重建来源。
