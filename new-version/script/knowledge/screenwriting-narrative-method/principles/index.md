# 原则与边界 · Principles

伦理、责任、证据边界与协作保留条件。


# topic-00
* [来源使用与证据边界总原则](source-use-and-evidence-boundaries.md) - 本包所有论断的证据强度由来源类型决定：理论建立概念、创作者讲座提供立场、实证研究只支持其样本范围；案例均为自拟，测试表描述"要怎样测"而非"已通过"。

# topic-01
* [工作原则：故事形式是一组在不同层面上相互配合的选择](form-first-working-principle.md) - 整个形式识别模块的压缩原则：知道自己正在分析哪一层、结论依据什么、尚不能证明什么；附「按问题而不是按名气」组织核心来源的对照表。

# topic-02
* [合作与作者意图：先谈可见选择，再谈谁为何选择](collaboration-and-author-intent.md) - 区分"作品出现了什么""这样安排可能使什么"与"创作者自述为何如此"三种陈述；把导演、演员、摄影、剪辑视为共同创作而非下游包装；交接允许回述；内部共识不是观众证据。

# topic-03
* [新意来自改变关系，不是叠加奇观](novelty-by-changing-relations.md) - 每次只改一个关键关系来检验作用；元素多不等于组合有根据；具体性不等于消费私人痛苦；新意不必以难懂为代价；转换形式可能比增加剧情更有效。

# topic-07
* [误导与反转：改变认识，不要无说明改写规则](misdirection-and-reversal-rules.md) - 区分范围限制、观众推断与信息冲突；反转要过回看检验，有伏笔不等于有必要，人物隐瞒需要行动依据。

# topic-08
* [四种标准会冲突，不适合无理由相加](criteria-conflict-no-summation.md) - 精准、有效、不出戏、巧妙没有天然共同单位，不宜算艺术总分；每项改动都有可能获得与可能失去，应为必要事实设通过条件、为艺术偏好保留论证，优先修结构性缺口。
* [叙事有力，不代表陈述正当](narrative-force-vs-statement-legitimacy.md) - 叙事伦理关注人物行为、讲述方式与制作及接收关系；真实人物经历、职业形象、产品功效不能因能制造情绪就免于核查，虚构人物也不必都成为榜样。

# topic-09
* [非商业影片：不把每一段都压成效率工具](non-commercial-film-not-efficiency-tool.md) - 非商业作品可以不给唯一结论、以时间为材料、保留不可通约的优先级，但制作条件仍然真实，表达选择与实施不足要分开。
* [非虚构：能组织材料，不等于可以补造现实](nonfiction-material-responsibility.md) - 事件、说法与演示分别标记；剪辑可改变指向；真实人物不是可随意重写的角色；不必伪装无立场；AI 材料需要来源状态。
* [谨慎处理产品因果：不把参与生活写成解决人生](product-causality-caution.md) - 分开实际功能、使用情境、心理或象征意义三层陈述；不用反派化普通他人制造需求；有展示不等于有证据。

# topic-11
* [AI 辅助审稿：有条理的意见仍可能漏掉主要问题](ai-assisted-review-boundaries.md) - 使用模型审稿的五条边界：先取证再评价、多角度优于重复问好不好、人保留问题与方向的决定、生成的内心独白只是解释候选、反馈要进入版本状态。

# topic-12
* [决定粒度、返工成本和停止权](decision-granularity-rework-stop.md) - 用"是否改变事实、行动、信息时机、重要表达或多人交接"定粒度；不把所有决定交给同一审批入口；变更闭环要检查实际结果；回退不是删除历史；停止范围与问题范围相称；三种节省分别观察。
* [人工与 AI 协作的保留条件](human-ai-collaboration-conditions.md) - 事实检索回来源、模型补写要标构造、角色模拟不是内心真相、模拟观众不是受众数据、多模型一致不是独立证明；最终方向、事实性承诺与发布责任由人类决策。
* [三类不可合并的信息](three-non-mergeable-information-classes.md) - 世界／产品事实与人物信念；作者意图、形式机制与实际效果；必须一致的执行状态与允许多解的艺术意义——三组信息各自分开记录，不互相冒充。
* [两项 AI 研究提供什么，又不能证明什么](what-two-ai-studies-show.md) - Rashkin 等的 LLM 写作反馈评估与 DuoDrama 的剧本反思支持研究对本流程的启发与不能外推的范围；本包未运行这些系统。
