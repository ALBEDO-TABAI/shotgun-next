# 练习

| 练习 | 任务 | 禁止 / 注意 |
|---|---|---|
| 动作替代 | 为门口场景写三种不同的邀请动作，分别说明更强调许可、照顾还是迟疑 | 检查实际空间条件，不只更换象征物 |
| 版本审计 | 对一段场景分别删解释、换顺序、合并人物；描述观众理解与人物行动怎样改变 | 不只比较字数 |
| 交接复盘 | 假设信封在旧版没有署名，新版才在结尾揭示寄件人，美术却按旧资料加上姓名；设计修复 | 修复要同时检查版本、可读范围和揭示点，不只加一个笼统的"加强审核" |
| 贡献边界 | 拿一段最终成片与一个早期稿，列出哪些相似支持继承关系、哪些不足以判断具体贡献 | 禁止由自己的审美偏好推定谁真正完成了创作 |

# 验收标准
- 结论与材料范围对应；
- 事实、意图、效果没有混写；
- 执行者能回述关键关系；
- 当前版本明确；
- 修改能指出具体对象、影响与验证方法。

# 本篇的要求与不要求
- 不要求所有人同意一种艺术解释，也不要求每项效果归到唯一作者。
- 要求：工作和证据能够相互对应。

> 编剧工作的价值，不是最后留下多少文字，而是对材料、人物、事件和理解作了哪些有根据的选择，以及这些选择是否真正进入作品。
