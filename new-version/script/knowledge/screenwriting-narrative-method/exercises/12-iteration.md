# 练习

1. **跨原型追踪**：让同一概念从文字到走位再到声画草稿，记录每阶段发现的问题归属；不总把最后看到的问题当成最后一环的责任。
2. **制造版本冲突**：故意造一个版本冲突，检查当前事实、执行者与验证怎样协同修复，不靠重复审查或多份摘要。
3. **写出未改变什么**：对一次修改写出未改变什么，保护作品的有效部分；对一项不接受的意见说明理由，而非以作者权威结束讨论。
4. **缩放流程**：为一个十秒平面动态与一个长篇影片分别缩放流程，保留必要关系，删除没人使用的仪式。

# 体系的落点

十二点体系不是十二套互相竞争的理论，而是从形式识别，到人物、事件、语言、信息、媒介，再到分析与协作的一组相互连接的工具。

> 好的创作流程，既允许新的发现改变作品，也能把当前已经决定的关系可靠传到执行中；它减少无意义返工，而不是减少作品本应保留的复杂性。
