# 方法 · Methods

可执行的步骤与流程：转化、观察、诊断、阶段 A–G。


# topic-01
* [主导组织原则判断法：这部作品究竟靠什么连接起来](dominant-organizing-principle-test.md) - 先问作品主要在讲述变化、组织知识、建立判断、连接意象还是展开形式变化（叙事／分类／修辞论证／联想／抽象形式），再用「改变某种连接关系是否破坏作品成立方式」做分析性试验定位结构依赖。
* [双重尺度评价：先描述结构，再判断它完成了什么](dual-scale-evaluation.md) - 把形式描述与价值评价分成两步：先问作品用什么关系组织内容、证据是什么；再在已知任务或可辨认的艺术追求下问这些关系完成了什么、付出什么代价；按组织原则给出对应检查方向，不制定统一优劣榜。
* [融合重组作品的组合关系分析：四种情况，不只增加形容词](hybrid-work-combination-analysis.md) - 面对混合形式，至少区分元素借用、局部嵌入、不同通道形成对照、组织原则发生转变四种组合关系，并写出「各属性位于哪里、怎样合作」的形式档案句。

# topic-02
* [跨抽象层等价检查：避免"意思没变"的假等价](cross-abstraction-equivalence-check.md) - 把替代方案的等价分为事实、行动关系、信息时机、经验四种分别核对，用"保留 / 改变"对照表把损失放到桌面上；并识别无人消费的工作。

# topic-03
* [从材料到可写问题的五次转化](five-transformations-material-to-question.md) - 价值词转成可观察差异 → 找到不只是对错口号的选择 → 让问题在具体时刻发生 → 选择观众的进入位置 → 决定哪些不展开。
* [把创作调研设计成能改变判断的提问](research-as-judgment-changing-questions.md) - 调研问题分事件、过程、差异、边界四类；材料—解释—转化三栏不合并；资料不足时三种诚实推进；为抽象起点设置退出条件。

# topic-04
* [行动依据不被模型决定：竞争假设与区分力](action-basis-without-model-determinism.md) - 给关键人物解释配一个竞争假设，让设定从"能解释一切"变成"有区分力"；通过资源与时间让价值进入行动；稳定人物也可成为变化中心；规则修订要查新增了哪些可能动作。
* [最小人物—世界模型：不建无人使用的设定仓库](minimal-character-world-model.md) - 只维护影响作品与执行的信息：保留五种信息状态、把行为倾向当倾向而非预测公式、同一事实附带对象／时点／来源、设定与执行互相检查。

# topic-05
* [从单场进入序列：承诺、发展与回应](sequence-promise-payoff-rewrite.md) - 用"承诺—发展—回应"描述序列功能，区分累积、升级、转向三种关系，分配高潮与后果，选择过渡方式，并用分层反事实替代笼统的"加快节奏"。

# topic-06
* [从分析进入改写：三轮不同任务](dialogue-rewrite-three-rounds.md) - 对白改写分三轮：先只写交流流动，再检查信息与关系，最后处理语言与声画；试读后回到问题层，改写也可以选择不改。
* [说明性对白的三个决定](exposition-dialogue-decisions.md) - 不禁止解释，而是解决"为什么此刻需要它"：决定观众此刻只需知道哪部分、谁合理地知道又有理由说、接收后改变什么；并检查多通道说明是否争抢。
* [同一任务的四种语言形式比较，不存在自动赢家](four-language-forms-comparison.md) - 保持事实与关系目标一致，比较直接协商、事务性间接、回避被轻轻揭开、高度风格化四种语言组织；按事实确定性、人物能力、语境、情绪空间、表演条件、篇幅逐项检查，并做改词的语义检查。

# topic-07
* [验证：发现作者知道得太多](detect-author-knows-too-much.md) - 用不提示主题的首看复述检验观众实际获得了什么，并分开逐段提问与完整体验、事实错误与解释差异、回看与首看、理解与情绪。
* [讲还是不讲：按当前任务给信息分类](tell-or-withhold-by-task.md) - 用"必要理解条件／可以延迟／可以开放／无当前作用"四类决定每条信息的处理方式，并要求为省略写出作用说明。

# topic-08
* [把反馈写成可以行动的判断](actionable-feedback.md) - 反馈结构：位置与材料 → 可见事实 → 作用假设 → 其他解释或条件 → 最小修改及验证；问题不等于方案，允许不修改，反馈也要说明值得保护的部分。
* [评审分歧怎样形成可推进的讨论](review-disagreement-to-decision.md) - 先判定分歧属于事实、机制、标准、偏好还是执行层，一次讨论只解决相应层级；把意见列表变成决策记录；对表达力与陈述责任分别检查；好评价应写明哪项新证据会推翻自己。

# topic-09
* [设计一组物料：不让每张图都重复同一个小电影](asset-set-design.md) - 一组传播物料按媒介分工（影片给经历、单图给关系瞬间、说明页给事实），每个入口自足、统一事实而允许组织方式不同，传播情境未知时给条件化方案，素材复用要连同事实指向检查。

# topic-11
* [分析开始前：建立材料边界](analysis-material-boundary.md) - 在分析一部现成作品前，先确定实际对象、把外部资料单独放置、明确委托任务并记录第一反应的条件，避免把未知记成失败。
* [解释需要竞争方案，不是所有可能性都等价](competing-interpretations.md) - 对同一材料提出多个解释，比较各自解释了哪些材料、需要补多少假设、在哪里被反证；主题解释与作者意图分开，不把每种私人联想写成同样充分。
* [第一遍：记录观看经历，不急着归因](first-pass-viewing-record.md) - 第一次完整观看时记录兴趣、困惑、期待、情绪与注意转移的位置，把理解状态、观看问题和意图推断三种记录分开，并同时记录有效部分。
* [让分析编码能够被另一位分析者复查](reviewable-analysis-coding.md) - 定义标记的观察依据、为一项判断保留证据／适用范围／反证三个位置、把不确定性写具体、主动寻找负例、让报告脱离口头解释仍可检查，并避免把审稿变成统一风格。
* [第二遍：重建事实、呈现与问题变化](second-pass-structure-reconstruction.md) - 第二次观看时识别主导组织原则、分开故事世界顺序与观众得知顺序、选择分析单位、描述进入与离开状态，并为每项结论指出材料通道。
* [诊断：把症状、原因和方案分开](symptom-cause-solution-diagnosis.md) - 把症状报告、原因假设与修改方案分成三件事，先查结构依赖再查局部装饰，按后果与依赖排定修订优先级，而不给作品打艺术总分。
* [测试反馈怎样进入分析](test-feedback-into-analysis.md) - 收集与使用观众或同事反馈的六条规则：先开放再具体、编码需定义、小样本只用于发现、版本比较注意顺序、作者解释后的同意不是原版理解、反馈冲突不一定要消除。
* [第三遍：用反事实检验定位作用](third-pass-counterfactual-tests.md) - 在脑中或低成本草稿中做删除、换序、换载体、换条件、分离通道、改结束点六种反事实比较，定位某个选择实际承担的作用，而不自动改动原作品。

# topic-12
* [按问题调用模块，不把十二篇串成冗长审批](call-modules-by-problem.md) - 当前问题→优先调用的篇目与所需结果的对照表，各篇的启动条件、核心输出与禁区，以及最小运行闭环；流程按任务缩放。
* [发散与收敛：把双钻石借用到编剧流程](double-diamond-for-screenwriting.md) - 借用 Design Council 双钻石区分理解问题与生产方案；发散要改变实质变量，收敛要说明理由，返回要具体到层级。
* [从想拍的场景与需要的连接组织内容](organize-content-from-desired-scenes.md) - 让"值得经历的片段"与"理解作品需要的条件"两组材料保持对话；连接不一定加场景，喜欢也要说明作用，大纲与场景可往返。
* [阶段A：建立问题、材料与边界](stage-a-problem-material-boundary.md) - 从 brief 或创作冲动出发，区分题材、命题、具体问题与形式假设，按来源区分材料，交付一页任务说明、材料地图与未知项。
* [阶段B：比较形式和代表性片段](stage-b-form-and-representative-fragment.md) - 建立少量真正不同的方案，每个至少有一段具体样稿，按六个维度比较后形成暂定方向；没有方案能承担真实要求时回到任务。
* [阶段C：建立人物、世界、场景与信息的联合骨架](stage-c-joint-skeleton.md) - 用第四、五、七篇分别检查人物与规则、场景序列、信息分配，再做结构比较；交付当前大纲、关键场景草稿、简化人物规则说明与信息关系。
* [阶段D：从场景到可表演、可呈现的稿件](stage-d-performable-draft.md) - 对白先写互动后写声音，场所与动作接受现实检验，明确声画分工，制作说明分开"必须成立的关系"与"候选执行"。
* [阶段E：原型测试](stage-e-prototype-testing.md) - 不同原型回答不同问题，最先测试高影响、低成本的未知，定义任务而不诱导答案，状态记录必须诚实。
* [阶段F：反馈诊断与修订](stage-f-feedback-and-revision.md) - 分开体验报告、问题假设与方案；按事实→依赖→局部→打磨的顺序修订；小改优先但不拒绝重构；修改要有反证；有明确停止条件。
* [阶段G：进入制作后保护关系并有依据地调整](stage-g-production-protection.md) - 冻结范围要明确、变更回到影响层级、无法执行要给替代与损失说明、成片重新评估；执行不是逐字搬运。
