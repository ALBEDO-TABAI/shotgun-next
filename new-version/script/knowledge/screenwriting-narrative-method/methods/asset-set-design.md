# 操作

1. **按媒介分工**：影片提供经历，单图呈现关系瞬间，说明页解释事实，工艺片展示真实过程。是否采用取决于实际任务与发布条件，不默认用户按设计顺序全部接触。
2. **每个入口自足**：短版不能依赖观看者看过长版才理解关键事实；单图可以开放，但不该用只有系列末尾才解释的指称承担必要任务。自足 ≠ 每份资料完整重复：明确本物料的最低理解范围，把更深内容作为额外层次。
3. **统一不是全部长得一样**：统一真实事实、品牌识别、人物关系与基本语调，允许不同媒介采用不同组织方式。统一过度 → 每个媒介只剩同一画面改尺寸；变化过度 → 事实与意义互相冲突。说明哪一层统一、哪一层变化。
4. **传播情境未知时**：提供条件化方案（有声／静音、顺序受控／独立入口、大尺寸／小尺寸）；不编造某平台"现在流行"的观看规律替代实际 brief。上线规范、时长限制、平台功能需另外核查当前官方资料。
5. **素材复用有语义成本**：同一张表情在不同文案下指向不同事件；反应镜头从非虚构素材移到新问题后可能制造未发生的回应。复用不是纯粹节省，要连同事实指向一起检查。

# Examples（自拟物料矩阵）

| 物料 | 独立任务 | 不承担 | 需要共同核对 |
|---|---|---|---|
| 45 秒护肤片 | 一次回应安排与护理继续 | 完整功能教育 | 使用动作、品牌事实 |
| 15 秒版 | 明确生活片段与归属 | 长期人格改变 | 可延期条件和发送状态 |
| 平面 | 一个关系瞬间与标题 | 全部前史 | 手机、手和产品之间关系 |
| 产品说明 | 准确解释真实信息 | 虚构人格转变 | 声称与证据范围 |

# 适用边界

本篇只提供叙事适配方法，不声称覆盖所有平台的现行技术规范。
