# 要点

分析的第一步不是评价，而是说清"我到底在看什么、还知道什么、被要求做什么"。四项工作：

## 1. 明确实际对象
记录作品名称、版本、时长、语言、字幕、声道、画幅、所见范围、是否完整。剧本与成片、预告片与正片、删减版与原版都是不同对象。

| 材料缺失 | 不能断言的事 | 可以做的事 |
|---|---|---|
| 没有结尾 | 伏笔未回收 | 列为待检查项 |
| 没有声音 | 完整的声画关系评价 | 限定结论到画面 |
| 只有截图 | 节奏与动作先后 | 提出需要补看的位置 |

原则：可以提出待检查项，**不把未知记成失败**。

## 2. 外部资料单独放置
brief、创作者访谈、剧本、制作记录、发行文案、评论各有不同身份。访谈可以支持"某人这样自述"，不能替作品补出未呈现的线索。由文本推测的意图，不能自动当作现实作者的心理事实（作者理论区分现实创作者与分析中的作者概念）。

## 3. 明确委托任务
任务可能是：了解形式、评价当前版本、找理解障碍、比较改编、提出修改、核查执行。任务不同，报告不同。只要求分析时，不应未经说明替作品改结尾、加角色、修正作者立场；可以提出候选调整，但要标明"已从解释进入创作"。

## 4. 保存第一反应的条件
是完整首看，还是已读过剧情介绍？是否暂停、快进、同时读评论？这些条件改变可用知识，记录它们比假装完全客观更有用。

# 适用边界 / 不应自动做什么
- 完整作品、片段、剧本与二手摘要支持不同范围的结论；材料不全时保留限制，不补造内容。
- 不因为分析者知道了访谈内容，就把它当作首看观众已知的信息。
- 不默默从"分析"跳到"重写"。
