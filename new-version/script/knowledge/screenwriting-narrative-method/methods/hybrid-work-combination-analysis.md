# 要点

混合形式中至少区分四种情况：

| 情况 | 含义 | 需要记录什么 |
|---|---|---|
| 1. 元素借用 | 借用某类型的道具、空间、服装或场面，但没有采用相应的整体情节关系 | 借了什么；是否真正影响人物和事件（不能只统计视觉符号） |
| 2. 局部嵌入 | 整体由一种方式组织，内部包含另一种方式 | 例：故事中插入工艺分类说明；论证中嵌入一个人物经历 |
| 3. 不同通道形成对照 | 画面与旁白态度不同，音乐与人物行动形成距离 | 混合发生在表达通道之间，不一定是两种故事类型的混合 |
| 4. 组织原则发生转变 | 开头建立谜题随后转向关系观察；前半按产品类别、后半变成人物行动过程 | 转变的**位置、触发条件和后果** |

理论基础：类型元素与结构可以交叉组合；作品整体与局部的形式关系可以不同。这四项是来源建议的工作性划分。

## 操作步骤

1. 先用 [主导组织原则判断法](/methods/dominant-organizing-principle-test.md) 定整体，再逐段标局部。
2. 对每处"混合感"归入上表四种之一；若是通道对照，改用信息载体／通道关系字段描述。
3. 若组织原则转变，标出转变位置、触发条件、后果。
4. 输出一句形式档案，说明各属性位于哪里、怎样合作。

## 形式档案示例（自拟，不对应真实作品）

> 这是一条虚构的维修品牌短片。整体以修复旧伞的行动过程组织，中段按部件展开工艺描写，局部通过缝线与旧照片建立联想。事件大体顺时呈现，但旧伞的关系意义被延迟交代。画面偏外部观察，较少直接解释人物内心。它可能将修复行为与保存关系记忆联系起来，但这种联系是否被目标观众读出，仍需验证。

它比"温情、诗意、治愈、纪录感、高级"多做的一件事：**说明各个属性位于哪里，以及它们怎样合作。**

# 适用边界 / 不应自动做什么

- 不用叠加形容词代替组合关系描述。
- 通道间对照不自动升级为"类型混合"。
- 组织原则转变需要位置与触发条件证据，不凭感觉标"前后风格不同"。
