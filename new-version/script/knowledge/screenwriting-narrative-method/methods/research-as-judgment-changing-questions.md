# 要点

调研最容易滑向两个极端：只有宽泛聊天而没有可用材料；或只问确认初稿的问题，把回答剪成支持概念的证词。

## 四类问题

| 类型 | 问什么 |
|---|---|
| 事件 | 具体发生过什么 |
| 过程 | 先后、工具与参与者 |
| 差异 | 什么情况下会不同 |
| 边界 | 哪些经历不能被当前概括代表 |

与其问"你是不是总被工作打扰"，可以问："最近一次在准备结束一天时收到请求，实际怎样处理？当时截止时间是什么？有没有不一样的情况？"这不保证代表性，但比把答案嵌入问题更能保留反例。

## 从材料到构想的可见桥梁：三栏不合并

1. 原话或观察；2. 解释候选；3. 创作转化。

自拟示例：原材料"我通常第二天才处理这类文件" → 解释可能是任务本来不急、工作习惯明确、或当事人自主权较高 → 创作转化可以是直接协商，不必硬写长时间挣扎。若原想讲"不敢拒绝"，资料可能正在否定该方向。

## 资料不足时的三种诚实推进

- 缩小为一个虚构人物，不声称普遍洞察；
- 保留多个候选，先做便宜的形式原型；
- 暂停依赖未知事实的部分，先发展不依赖它的内容。

不能用"艺术允许想象"混淆虚构与事实性声明，也不必因研究未穷尽就停止全部创作。关键是构造与承诺的范围匹配。

## 为抽象起点设置退出条件

- 概念经过具体场景尝试仍只能依赖主题宣告 → 换组织方式或缩小问题。退出不是承认主题没价值，而是当前前提尚未生成作品。
- 反过来，一段强烈场景若只能依靠不真实的职业规则成立 → 先修规则，而不是继续投入画面细化。越早检验高影响假设，越少需要用后续包装维护脆弱前提。
