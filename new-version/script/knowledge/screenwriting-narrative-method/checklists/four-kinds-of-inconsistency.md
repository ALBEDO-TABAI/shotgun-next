# 检查表

| 类别 | 判定条件 | 处理 |
|---|---|---|
| 真实矛盾 | 同一时点同一钥匙已经归还，却又在原持有人手中使用，且无任何获取路径 | 先核查缺场与时间；不擅自补"另有钥匙" |
| 错误信念 | 父亲以为仍能进入，实际权限已失效 | 可以是正常叙事安排，不等于规则崩坏 |
| 信息不足 | 作品没说明门是否更换 | 记为未知；不要同时确定换过和没换 |
| 有意的不稳定 | 作品在不同记忆或不可能世界间切换 | 检查其组织原则，不强迫唯一现实版本 |

# 使用要点

- 复查前先给每条事实加上对象、时点与来源（见 [最小人物—世界模型](/methods/minimal-character-world-model.md)），否则多视角会被误判为矛盾。
- 这张分类同时防止两种偏差："所有疑问都是漏洞"与"所有漏洞都是留白"。
