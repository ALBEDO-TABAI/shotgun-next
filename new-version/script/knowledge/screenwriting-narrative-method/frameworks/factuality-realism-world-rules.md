# 要点

## 1. 事实性约定：作品要求我们怎样对待它与现实的关系？

问题是"它是否要求我们相信这些人物、事件或证据对应现实世界"，与"看起来像不像真的"不同。来源引 Schaeffer 对事实／虚构叙述的讨论：语义、形式与语用判据并存，关键是作品对现实指涉承担什么承诺；仅凭文体或制作手段不能决定事实性身份。

工作流中记录三个不同字段：

| 字段 | 例 |
|---|---|
| 作品如何自我声明 | 虚构故事、真实人物访谈、事件重演 |
| 材料如何制作 | 现场记录、演员重演、动画说明、合成画面 |
| 哪些内容已得到独立核验 | 事件发生过，还是目前只知道作品声称发生过 |

这样不会把"采用纪录感拍摄"写成"记录了真实事件"，也不会把"使用动画"写成"内容必然虚构"。

## 2. 现实感：作品用什么惯例让某种生活显得可信？

把现实感作为**表达关系**分析，不当成事实认证。检查语言、行为、时间、空间、行动后果是否共同支持某种生活经验。比"很真实／不真实"更精确的写法："空间质感具有写实取向，但人物行为的因果依据较弱。"

## 3. 世界规则：可能、允许、重视、知道是四种不同问题

来源引 Ryan 可能世界讨论：关于可能性、义务、价值和知识的世界组织方式，并区分故事中被确立的状态与人物相信、希望或想象的状态。

| 问题 | 内容 | 例（删除记忆的世界） |
|---|---|---|
| 什么能发生？ | 自然、技术或超自然的可能性 | 一个人可以删除记忆 |
| 什么被允许？ | 法律、习俗、组织与关系中的规则 | 删除伴侣的记忆需要双方同意 |
| 什么被看重？ | 这个世界里的价值秩序 | 保留痛苦被视为忠诚 |
| 谁知道什么？ | 事实、信念、误解与秘密的分布 | 某人不知道自己的记忆已被删过 |

这些维度共同生成剧情，不应全部塞进一段"世界观背景说明"。

> 作品没有说明，不等于事情不存在；人物相信，不等于世界事实。

但也不能为了填满设定表就替作品补出不存在的答案。

# 适用边界 / 不应自动做什么

- 不由制作手段（纪录感、动画）推断事实性身份。
- 不把"未核验的作品声称"记为已核验事实。
- 不为填表补造世界设定；未说明保持未说明。
