# 要点

"这里太慢""不够有戏"这类反馈，可能分别指行动停滞、信息重复、目标不清、关系没变、关键动作不可读，或把需要持续体验的段落按快节奏广告评价。要先统一分析尺度，才能把这些问题拆开。

| 尺度 | 定义与注意点 |
|---|---|
| 镜头 | 一个动作可以分多个镜头呈现，一个长镜头也可含数次任务、信息与关系变化。平均镜头长度只描述一类视听参数，不能独自说明剧情是否推进。 |
| 动作 | 可观察的行为，如拿杯子。 |
| 事件 / 事件性 | 发现杯子空了可能改变下一步任务；第一次不替对方添水，在特定关系里可能是重要变化。Hühn 区分"一般状态变化"与"在特定情境下更有分量的事件性"，用于避免把动作规模或事故数量等同戏剧强度。 |
| 节拍（场内） | 本包约定：场景内一次可识别的策略、信息或关系更新。 |
| 节拍（大纲） | 规划中标出的时刻或内容块。与场内节拍尺度不同，不要求一张卡等于一场戏。August 与 Goddard 的对谈讨论大纲时刻怎样转成可表演场景，并承认"大纲先行"与"写场景中发现结构"可并存，属实践启发，不是篇幅换算标准。 |
| 场景（叙事） | 一段谈判从室内移到门外可仍是连续行动；同一房间跨过数天可进入新场景。 |
| 场号（制作） | 与叙事场景可能不重合。建议同时保留制作场号和分析段落，不混用两套切分。 |
| 序列 | 围绕某种关系聚合：可以是一个任务（"搬家序列"），也可以是声音与意象的并置（"城市夜晚"）。 |

最外层如何分幕是对整体组织的进一步解释，不应反过来迫使每个局部采用相同节奏。

# 适用边界 / 不应自动做什么

- 不把镜头数当作剧情数；不把三幕、四幕或固定秒数当作所有作品的法则。
- 分析尺度是本包的工作性约定，用于场景、序列和整体分析；具名理论提供概念，不提供篇幅换算。
