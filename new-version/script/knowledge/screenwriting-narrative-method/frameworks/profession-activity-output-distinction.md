# 要点

## 1. 职业角色 ≠ 全部实际活动
- "编剧"既可以指项目职位，也可以指选材、构造事件、写场景等**活动**。编导合一、小型制作、广告团队、纪录项目组织方式各异。
- 没有独立编剧职位 ≠ 没有叙事建构；有编剧署名 ≠ 成片每项细节由其独自设计。
- 分析成片的正确顺序：先说"这里完成了信息延迟 / 人物关系建构"，再找谁贡献了它的证据。**不要从职务名称推定实际劳动。**
- WGA 电影署名手册把戏剧构造、原创或不同场景、人物塑造及关系、对白等纳入贡献判断，不只计算改了多少文字。这是一个制度实例，只适用于该协会，不能冒充全球统一职业定义。

## 2. 写作成果有不同读者与任务
| 成果 | 主要任务 |
|---|---|
| 概念说明 | 了解项目 |
| 梗概 | 理解整体 |
| 大纲 | 比较结构 |
| 剧本 | 想象可经历的过程 |
| 制作说明 | 保护关键条件 |
| 改稿记录 | 理解版本改变 |

一份材料适合某一任务，不代表能承担其余全部。"一段克制的重逢"能记录创作愿望，却不足以指示演员当场做什么；逐镜技术表再完整，也可能没说清人物为什么留下。

## 3. 剧本既是作品，也是协作中的工作材料
剧本在不同阶段帮助探索、比较、沟通和执行，不只是等待转成画面的文字。由此保留三个问题，互相联系但不能互相替代：
1. 文本已经建立什么；
2. 文本怎样在协作中被理解；
3. 实际成片保留了什么。

# 适用边界 / 不应自动做什么
- 这是分析与协作框架，不是法律署名裁决，也不要求编剧独自控制所有部门。
- Macdonald 的专著在本包只取得出版简介与目录，仅作研究入口，不承担全书细节的证据。
