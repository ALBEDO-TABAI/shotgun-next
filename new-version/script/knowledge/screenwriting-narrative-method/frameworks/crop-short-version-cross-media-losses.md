# 要点

| 改版 | 会丢什么 | 应做什么 |
|---|---|---|
| 裁切 | 去掉回应者、手上物件或门内空位，即使主角脸保留也可能丢失关系 | 保护关键行为的可见部分，而不只确保人脸居中 |
| 静音 | 原靠环境声识别地点或画外回应的信息途径 | 另找载体；字幕可补词，却未必恢复来源与空间关系 |
| 缩短时长 | 四十五秒的微小选择在十五秒可能只剩一个清楚的生活瞬间，认知弧未必保住 | 声明短版做什么、不再承诺什么，不只是剪掉铺垫保留高潮 |
| 跨媒介扩展 | — | 区分"不同媒介各自对较大叙事作出贡献"与"同一内容换包装"；只有确实新增相关世界内容，才谈更强意义的跨媒介叙事 |

同一品牌可以让影片讲一个经历，平面表现一个动作，说明页提供事实；彼此相关但各自完成任务。Jenkins 的跨媒介区分有启发，但不意味着每条广告都需要世界观宇宙。
