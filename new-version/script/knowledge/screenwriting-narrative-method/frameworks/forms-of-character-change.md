# 要点

先区分变化到底发生在哪里：

| 变化形式 | 含义 | 不应夸大为 |
|---|---|---|
| 行为改变 | 一次换了做法 | 长期习惯已改变 |
| 信念改变 | 重新认识某事 | 立刻有能力行动 |
| 关系改变 | 许可、信任、依赖或距离改变 | 双方性格重塑 |
| 观众认识改变 | 新信息修正了观看者 | 人物突然变了 |
| 维持与抵抗 | 人物坚持某选择，周围条件或他人判断变化 | 没有变化 |
| 反复或未能改变 | 可以是作品真正关注的经历 | 尚未完成的励志弧 |

这些分类不互斥。最重要的是不把一次动作、一项秘密或一个镜头夸大成作品尚未证明的整个人生转折。

Sciamma 在讲座中描述不依赖完整人物履历、从当下欲望和经验组织创作的做法：这证明小传不是唯一道路，不意味着研究背景在其他作品里没有价值。

## 人物"立体"不是优缺点的数量

一个角色可以很少被直接说明却在不同关系中呈现复杂性；也可以拥有一串秘密和反常爱好而行动单调。更值得检查的是：

- 同一策略在不同处境中是否暴露不同代价；
- 人物对自己的解释是否与行动有张力；
- 新证据是否允许重新理解他；
- 作品有没有把他全部化约为一个功能。

# 适用边界 / 不应自动做什么

- 类型化配角、寓言人物和喜剧角色可采用有限塑造；评价要尊重篇幅与形式，不要求一张广告照片具备长篇小说的人物展开。
- 创作者讲座是实践立场，不是普遍效果的实验证明。
