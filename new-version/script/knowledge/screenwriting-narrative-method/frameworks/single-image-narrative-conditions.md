# 要点

1. **一个瞬间可以包含时间方向**：半收起的箱子、刚松开的手、尚未合上的门可暗示前后，但静态姿态未必唯一确定方向（到达或离开）。要区分 *已可见* / *受支持推断* / *创作者补充*：旧照片与伞并置可支持记忆联系，未必证明亲属关系、死亡或继承。
2. **找临界瞬间**：两人共同托住桌面比各站一旁微笑更能表现合作；但若关键是"从不合作到合作"的转变，单张图通常无法完整建立，需要系列或图文配合。
3. **图文共同组织意义**：标题可以提出问题、限定语境、评论或反转图像；不能默认文字越少越高级。文本与图像各承担什么应分别说明。标题声称"她终于选择自己"而图里只是使用产品，结论超过图像依据，可缩小文案或改变可见行动。
4. **图中有人不等于必须讲故事**：人物可提供尺度、使用关系、动作和形式节奏；作品也可主要组织材质、颜色或观点。为每张图写完整人物弧会增加无人使用的设定。
5. **系列增加顺序，也增加不确定性**：多张可通过动作阶段、重复或对照建立变化，但要确认展示顺序是否受控、单张是否会独立传播；序列关键线索不能假设所有人都看到。
