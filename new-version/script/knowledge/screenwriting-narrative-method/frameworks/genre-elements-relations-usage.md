# 要点

"发生在太空"不够说明作品怎样使用科幻；"有一对恋人"不够说明它怎样使用爱情类型。来源引用 Altman 的语义／句法方法：**语义层面**关注人物、地点、道具、场面等构成元素；**句法层面**关注这些元素之间的组织关系。两者结合，而不是只凭出现了什么符号判断类型。

| 层面 | 分析问题 | 例 |
|---|---|---|
| 元素（语义） | 作品调用了哪些容易被识别的类型材料？ | 未来城市、人工智能、实验室 |
| 关系（句法） | 这些材料如何形成矛盾、任务、关系变化与结局？ | 主要结构建立在家庭照护关系上 |
| 使用（语用） | 谁在怎样使用这个类型名？ | 发行方自我定位／创作者自述／评论界分类／本次分析者判断 |

比"科幻＋亲情"更有分析价值的说法："它调用科幻世界的设定元素，但主要通过家庭关系中的义务与选择组织剧情。"这仍需作品证据，不是几个道具自动得出的结论。

第三层来自 Altman《Film/Genre》：产业、评论者和观众如何建构与使用类型；类型不是永远不变的自然物种。skill 应保留**"类型命名来源"字段**，避免把"海报上写着悬疑片"与"作品内部主要依靠谜题组织"当成同一项证据。

## 题材、核心问题、表达命题分开

| 项 | 含义 | 例 |
|---|---|---|
| 题材 | 作品涉及哪个生活领域 | 家庭、劳动、消费、迁徙 |
| 核心问题 | 作品具体在追问什么 | "照顾一个人，是否意味着替他决定？" |
| 表达命题 | 作品似乎建立了什么判断 | "尊重也可能体现为克制干预。" |

表达命题往往是解释，**不应自动写成作者的真实意图**；作品也可以保持问题开放，不提供唯一命题。

# 适用边界 / 不应自动做什么

- 不凭道具、场景符号统计判定类型。
- 不把外部分类标签（海报、发行分类）与作品内部组织方式混为一项证据。
- 不把分析者读出的命题写成作者意图。
