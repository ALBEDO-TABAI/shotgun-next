# 要点

聚焦理论关注叙事信息怎样相对于人物知识和经验受到限制，不能只用"第一人称／第三人称"概括：
- 人物旁白可以讲后来才知道的事；没有旁白的影片也能严格限制在某人所知。
- 一个主观镜头只说明局部视觉，不足以证明全片遵循这个人的信息范围。

## 1. 范围与深度分别看

| 维度 | 问题 | 例子 |
|---|---|---|
| 范围 | 我们接触哪些人的哪些事情 | 知道多个角色的行动，不一定了解其内心 |
| 深度 | 通过什么方式接近记忆、想象或感知 | 深入一个人的感受，不一定知道他对关键事实的认识 |

不要把所有内心画面都归为事实闪回。

## 2. 知识获取必须有路径

前场人物无法看到屏幕，后场却准确引用内容——需要查：是否另有获取路径、前场是否为主观叙述、是否只是在猜、还是确实有连续性问题。
- 分析不能替作品发明"偷看"。
- 创作可以新增路径，但应标为修改，并评估它是否比改掉后场那句话更必要。

## 3. 信息限制可以改变，但要处理过渡

单一视角转向全知不是绝对禁止，可能有明确结构作用；但要说明新的信息位置怎样进入，而不是仅为解决当前难题临时获得作者视角。

# 适用边界

- 聚焦理论是理论综述，不是观众效果实验。
- "谁在说"与"我们知道多少"是两个变量，分析时分别判断。
