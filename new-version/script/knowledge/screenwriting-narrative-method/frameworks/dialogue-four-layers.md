# 要点

一句对白同时在几个层面工作，分析应按下面的顺序展开，而不是一上来寻找隐藏深意。

| 层 | 问什么 | 例子（"门还开着"） | 注意 |
|---|---|---|---|
| 1. 字面内容 | 这句陈述了什么对象与事实 | 一个门的状态 | 先确定对象与事实，不把任何门都读成人生出口 |
| 2. 当下行动 | 说话者试图达成什么（本包称"话语行动"） | 提醒关门、邀请留下、暗示允许回来、回答是否上锁 | 句型不自动决定唯一行动；"你要走？"可核实、挽留、质问或要对方承认，须结合前后回应判断 |
| 3. 关系位置 | 说话者是否有权要求、是否怕拒绝、是否想保全体面、是否刚发生误会 | 这些条件影响说法 | 不能从年龄、性别或地域直接推定固定语言性格 |
| 4. 作品作用 | 观众由此获得什么：空间、习惯、关系、新期待 | 一句问候也可能通过变化建立关系 | 对观众有用不证明人物有理由说 |

核心问题：**谁对谁，在什么共同处境中，试图通过说、问、改口、回避或不回应，改变什么？**

# 适用边界 / 不应自动做什么

- 适用于写实，也适用于文学化、舞台化、诗性或荒诞表达；不同作品有不同语言约定，不必统一改成自然主义口语。
- 不要把对白质量等同于金句数量、字数多少或口语相似程度。
- 常见失败不是句子不漂亮，而是人物没有理由此刻这样说、上一句没有改变下一句、人物只是替作者交代材料。
