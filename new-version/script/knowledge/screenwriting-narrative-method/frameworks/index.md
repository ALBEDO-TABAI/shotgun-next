# 框架 · Frameworks

概念区分、分层模型与分类轴：先把容易混用的东西分开。


# topic-01
* [事实性、现实感与世界规则：三个容易互相冒充的问题](factuality-realism-world-rules.md) - 分开「作品对现实指涉承担什么承诺（自我声明／材料制作／独立核验）」「哪些惯例让生活显得可信」「世界里什么能发生、被允许、被看重、谁知道什么」，防止把纪录感写成真实、把动画写成必然虚构。
* [类型不是题材清单：元素、关系与使用惯例三层面](genre-elements-relations-usage.md) - 借 Altman 语义／句法／语用框架，把类型判断拆成「调用了哪些元素」「元素怎样组织成矛盾与结局」「谁在怎样使用这个类型名」，并把题材、核心问题、表达命题分开记录。
* [媒介与风格的操作定义：单幅图像的叙事条件、电影通道分工、风格／语调／情绪／反应](medium-and-style-operational-definitions.md) - 不把文学叙事模型直接搬到所有图像上：单幅图像只记录已呈现关系、可支持的推断与不能确定的前因后果；电影意义在多通道间分工，需记「信息载体」与「通道关系」字段；风格、语调、情绪氛围、实际反应采用不同操作定义。
* [叙事内部分析轴：动力、结构、时间、信息与结尾](narrative-internal-analysis-axes.md) - 进入叙事内部后分别检查：作品让人关心哪个未完成问题（动力）、线索以什么关系连接（结构）、顺序／时长／频率（时间）、谁发声／谁的知识限制／主观经验／可靠性（信息）、结尾闭合了哪种问题。五项相关但不能互相替代。
* [非因果关系同样能组织作品：找到它的连接依据](non-causal-organization.md) - 分析诗性、散文性、实验性作品时，不因缺少强因果就判定「没有结构」；用相似、对照、等价等非时间性联系（Schmid）追问哪些可见可听特征建立了联系、发生在哪一层、有无同样合理的其他解释，并把非线性与非因果分开。
* [故事形式的层面分流：不要把不同层面的概念装进同一个抽屉](story-form-layers.md) - 把「品牌片、家庭故事、悬疑、碎片化、写实、诗性、感人」等常见描述拆成「它在谈哪一层」的追问，用一张概念分流表代替笼统的风格分类表。
* [故事世界、情节组织、叙述过程：三个必须分开的对象](storyworld-plot-narration-distinction.md) - 以 Bordwell 三维度为基础，区分「世界里发生了什么／作品选了哪些怎样排列／观众何时通过什么得知」，并附术语不可逐字互换、「有故事／有叙事性／故事好」必须分开两条配套约定。

# topic-02
* [贡献追溯的三层证据](contribution-evidence-three-layers.md) - 用材料证据、转化证据、实现证据三层追溯谁在何时提出了什么、提议如何进入下一版、成片是否保留，替代虚构的"创意占比"；缺证据时报告不可确认，分歧时保留分歧。
* [职业、活动与成果的三分](profession-activity-output-distinction.md) - 把"编剧"这一职位、实际进行的叙事建构活动、以及不同用途的写作成果分开，避免从职务名称倒推劳动内容或从署名推定成片细节。
* [六类核心编剧工作](six-screenwriting-work-types.md) - 按"改变的对象"把编剧工作分为选材、建构、组织、分配、转译、修订六类，各配对象、常见成果与应防止的替代性指标，而不是按文件名称区分。
* [不同项目的工作颗粒度](work-granularity-by-project.md) - 广告、非商业影片、平面拍摄、非虚构、AI 辅助项目各自对编剧工作的要求与禁区，以及项目规模决定的文件分层：小项目一份当前剧本、一份关键决定记录、一份反馈即可。

# topic-03
* [研究材料的四种状态](four-states-of-research-material.md) - 把直接观察、当事人自述、可核验公开资料、创作构造分开记录，并为每条材料写明"能支持 / 不能支持 / 创作转化 / 待确认"，让资料真正改变创作而非装饰初稿。
* [七种创作起点及各自需要的转化](seven-creative-starting-points.md) - 从人物或关系、一个时刻、一种感受、事实与现实矛盾、物件工艺或空间、商业 brief、形式限制出发，每种起点都要完成特定转化才能成为可写的问题。
* [题材到形式假设的六层区分](six-levels-subject-to-form.md) - 把题材、主题词、暂定命题、戏剧或体验问题、前提与构想、形式假设分开，避免用一个"主题"字混指不同层面并过早把创作问题替换成答案。
* [可讲述性的三个层面与可制作性的分离](tellability-and-producibility.md) - 材料值得讲不只看事件是否罕见，要分事件、经验、表达三个层面检查；值得关心的素材与当前条件能否恰当表达是两回事。
* [命题驱动与发现驱动](thesis-driven-vs-discovery-driven.md) - 两条路径各有价值与风险；本包建议用"暂定问题"折中——方向明确，但说明什么证据会让它改变，并且开放探索不等于交接含糊。

# topic-04
* [把性格清单改成行动依据](action-basis-instead-of-trait-list.md) - 用欲望／目标／任务、信念、策略、能力与资源、情绪与行为、代价与分量六项替代形容词式性格标签，使人物在互动中生成可写的场景。
* [观众背景知识：既能帮助理解，也能造成错位](audience-background-knowledge.md) - 图式帮助观众补足未说明的情境但不保证补出作者版本；用"常识移除"检查作品依赖哪些常识；多视角需由作品证明观众实际获得了什么。
* [人物的三个层面：世界状态、呈现方式、接收解释](character-three-levels.md) - 分析人物时先分开作品确立的事实、我们借以接近人物的呈现途径、以及观众形成的解释，直接描述要查来源，间接塑造不得任意补完。
* [人物变化的多种形式：不必统一写成成长](forms-of-character-change.md) - 区分行为改变、信念改变、关系改变、观众认识改变、维持与抵抗、反复或未能改变六种变化位置，并把"立体"定义为策略在不同处境中暴露不同代价。
* [关系是双向过程，不是两份小传的相加](relationship-as-bidirectional-process.md) - 同一人面对不同对象可以不同；双方理解可不对称但客观动作不随解释变化；权力通过行动条件显示；配角需要合理任务而非额外支线。
* [理解、共情、认同与喜欢并不相同](understanding-empathy-identification-liking.md) - 观众可以理解理由却反对行动、为处境难过却不喜欢人物；"让他更讨喜"不是通用修复，应分别问处境、理由、认同、持续观看与感受五个问题。
* [世界规则的四种问题：可能、允许、价值、知识](world-rules-four-questions.md) - 借可能世界理论把世界规则拆成可能性、允许与义务、价值秩序、知识分布四个维度，并要求规则产生生活后果、例外有范围、现实题材同样有规则、不稳定世界也可分析。

# topic-05
* [统一分析尺度：镜头、动作、事件、节拍、场景与序列](analysis-units-shot-to-sequence.md) - 分析场景与情节前先约定切分尺度：镜头不等于事件，动作不等于事件性，节拍分场内与大纲两种，制作场号与叙事场景可以不重合，序列围绕关系聚合。
* [情节连接的六种类型：不只有"然后"与"因此"](plot-connection-types.md) - 区分因果、促成与限制、人物动机、对照相似等价、重复与变奏、分类或论证六种段间连接，并要求为每条连线写一句关系说明。
* [进度：可用选项、代价与理解怎样变化](progress-as-change-in-options-cost-understanding.md) - 剧情进度看的是人物可用选项、行动代价与对结果的理解是否变化，三者不必一起上升；整合后果也是进度；任务成功不等于所有层面都向前。
* [节奏的四个观察层面与实证研究的限度](rhythm-four-observation-layers.md) - 把节奏拆为事件、认知、情绪、视听四个观察层面，诊断"慢"必须指出哪一层；事件分段研究与电影语料统计只提供有限支持，不能变成创作处方。
* [场景如何结束：不必都靠金句或反转](scene-endings.md) - 场景可在行动完成、决定作出、问题刚提出、认知刚改变或体验达到阶段时结束；区分有意留下问题与必要过程被截断；描述具体闭合哪一层比贴"开放式结尾"更有用。
* [进入状态—作用过程—离开状态](scene-entry-process-exit-model.md) - 用进入状态、作用过程、离开状态三段描述一场戏发生了什么变化；作用不只有争吵，离开状态的变化可以很小；抽象或不可能叙事改记形式初态与变奏规则。
* [场景的第一问：为什么要让观众经历这一段](scene-purpose-and-functions.md) - 场景职责不等于"交代什么信息"；应写成一句具体的认知或体验任务，场景可承担多个功能但不必样样俱全，功能兼容性比数量重要。
* [空间与物件：让场景条件参与表达](space-and-objects-in-scene.md) - 检查场所的可见、可听、可达、可进入、可退出条件如何限制表达；物件先有实际任务再谈象征；空间同时向人物与观众分配知识。
* [时间组织：顺序、时长与频率分别检查](time-order-duration-frequency.md) - 按顺序、时长、频率三个维度分别检查事件发生与呈现的关系；省略不一定是缺场，换序后必须重查观众当时知道什么。

# topic-06
* [人物声音：从选择形成差异，而不是配置口头禅](character-voice-from-choices.md) - 用注意对象、组织方式、不确定性处理、关系风险处理、回避对象五个维度观察人物声音；声音应有弹性，方言与职业术语需研究。
* [对话是策略随反馈变化，不是两份独白交错](dialogue-as-strategy-under-feedback.md) - 用"当前需要→尝试说法→对方接收→策略是否奏效→继续/修改/升级/放弃"链条写对话；先修互动再修词句，停顿要有可演条件，合作也能推进。
* [对白的四层分析：字面、行动、关系、作品作用](dialogue-four-layers.md) - 分析一句台词时按字面内容、当下行动、关系位置、作品作用的顺序推进，不从主题倒推每句都藏深意。
* [共同理解：听见、理解、同意、照做是四件事](grounding-hear-understand-agree-comply.md) - 借 Clark 与 Brennan 的 grounding 概念把"消息发出"与"交流完成"分开，检查人物各自的已知假设、反馈强度，以及人物共同知识与观众共同知识的差别。
* [沉默与动作：删掉台词，意义不会自动进入目光](silence-and-action-instead-of-lines.md) - 沉默需要"正在等待回应"的条件；动作可确定事实但保留原因；语言与动作可以有距离；物件先有真实使用关系才谈象征。
* [潜台词与会话含义：三个推断条件与三种不可混用的状态](subtext-and-conversational-implicature.md) - 借 Grice 会话含义区分潜台词成立的条件（可用语境、可理解关联、后续接收），并把间接表达、隐瞒欺骗、意义开放分开。
* [旁白、转述、字幕和手机文字不是次等对白](voiceover-captions-and-phone-text.md) - 用"保留谁的原话、谁选择或改写、来源是否可辨认、与可见事件的关系"四问检查旁白、转述、字幕与手机文字；手机文字有输入、删除、发送、撤回、已读、未回等不同事件状态。

# topic-07
* [好奇、悬念与惊讶：三种可共存的观看问题](curiosity-suspense-surprise.md) - 把好奇／悬念／惊讶转成三个工作问题（结果由何导致、行动将有何后果、新信息改变了什么认识），并纠正"知道更多＝悬念、知道更少＝好奇"的误解。
* [聚焦：范围、深度与知识获取路径](focalization-range-depth-path.md) - 谁发声不等于我们知道多少；分别记录信息范围与深度，要求每次人物知识都有获取路径，并处理信息限制变化时的过渡。
* [留白、歧义、延迟与缺漏不能互相替代](gap-ambiguity-delay-omission.md) - 四种"没讲"各有不同性质：留白是给足关系不穷尽、歧义是材料支持多读、延迟是后续更新、缺漏是必要条件缺失；"有人不懂"与"作者说留白"都不是判决。
* [最小信息模型：世界状态、人物信念、实际呈现、观众理解](minimal-information-model.md) - 把"世界中发生过、人物相信发生过、作品声称发生过、观众推测发生过"分成四种状态，用五档理解状态替代粗糙的"交代过／没交代"。
* [展示与讲述：选择适当载体，而非排高低](showing-and-telling-as-carriers.md) - 展示／讲述没有统一定义与优劣排序；比较直接说明、行动演示、反应与关系、痕迹与并置四类载体，按清楚程度、形式约定、成本和风险选择。
* [不可靠性：分开报告、解释与评价](unreliability-report-interpretation-evaluation.md) - 说谎、误判原因与不被接受的价值立场不是同一个问题；范围限制不等于不可靠，也不能用"叙述者不可靠"给所有矛盾免责。

# topic-08
* [连贯不等于表面顺滑](coherence-vs-surface-smoothness.md) - 区分语言衔接与依赖语境的连贯；分别检查事件、人物、主题与形式、接收可追踪性四种连贯，并区分“人物真的变了、观众认识被修正、同一层事实冲突”三类变化。
* [有效：先说结果类型，再讨论效率](effectiveness-criterion.md) - 有效可以指理解、体验、观点建立、品牌辨认或现实行动，彼此不可替代；结构存在与接收发生分开，经济性不等于最短，功能多不自动更好，反应快不等于影响深。
* [情感成立：不用表情与音乐替代依据](emotional-grounding.md) - 分开情感对象、情感依据、强度与尺度、余味与即时反应，并说明“去掉音乐”测试的正确用途；人物流泪不等于动机工作已完成。
* [评价前先补主语：五类陈述分开](five-statement-types-in-evaluation.md) - 评价作品前先确定证据对象（设想、剧本、试拍、剪辑版、真实观看），并把描述、解释、意图判断、效果判断、规范判断分开，不用一句流畅评价跨越多层。
* [不出戏：维持可辨认的观看约定，而非误信现实](immersion-as-viewing-conventions.md) - 沉浸不是把虚构误当现实；“不出戏”检查世界、人物、语言与表演、信息、传播框架五种约定是否被有意识地维持或转换，并区分有意距离与意外破坏。
* [巧妙：多个关系在一个选择中合作](ingenuity-multi-relation-choice.md) - 巧妙的五个观察入口——同一动作完成不同层面、事实不变意义更新、表面事务承载关系、通道间保留差异、观众完成有依据的最后一步——以及巧妙的代价清单。
* [精准：分配确定与开放，而不是压成唯一答案](precision-criterion.md) - 精准指作品提供的条件与具体理解任务相称——必须清楚、可以开放、不应误导三个区域分开；局部清楚不等于整体清楚，分析者也要限定自己的结论。

# topic-09
* [品牌与故事的连接：四类结果、产品叙事角色与三层检查](brand-story-connection.md) - 把品牌联系当成需要建立的关系：区分认出、理解、联系、行动四类结果，列出产品可承担的六种叙事角色，并用内容关联、事实身份依据、可感知归属三层检查连接。
* [裁切、短版与跨媒介不是简单复制](crop-short-version-cross-media-losses.md) - 裁切会删除关系，静音改变信息途径，缩短时长可能需要换任务，跨媒介扩展不同于格式重复；每种改版都要写出损失。
* [四轴定位：传播用途、媒介条件、事实性承诺、观看情境](four-axes-purpose-medium-factuality-context.md) - 用四个相互影响但不能互相代替的轴替代"广告／电影／平面"的粗略分类，先确定任务与媒介，再检查内容怎样适配。
* [单幅平面：设计事件线索，不替图像虚构完整故事](single-image-narrative-conditions.md) - 单张图像可包含时间方向但不唯一确定；找临界瞬间而非平均浓缩剧情；图文共同组织意义；图中有人不必讲故事；系列增加顺序也增加不确定性。

# topic-12
* [Agent 和人怎样分工，不让建议变成事实](agent-human-role-division.md) - 五个可实现的 Agent 角色（研究与证据、创作、剧作分析、制作可行性、版本协调）各自的职责与禁区，以及人的决策位置。
* [四类输入与不确定性的位置](four-input-types-and-uncertainty.md) - 把创作输入分成事实、要求、假设、偏好四类，各自改变权限与证据要求不同；未知项要有明确位置，并控制过早承诺。
* [最小协作架构：一份当前依据，而不是一个解释暴君](minimal-collaboration-architecture.md) - 单一事实只用于该统一的事项；三类文件足以启动；一项决定需要提议、当前、已消费、已检查四个状态；交接允许回述；旧版本可保存但不再自动生效。
