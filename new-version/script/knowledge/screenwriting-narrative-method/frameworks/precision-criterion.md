# 要点

## 1. 确定具体理解任务

事实清楚与情感复杂可以共存。一场戏可以要求观众知道女儿主动改签，却允许不知道她主要出于兴奋、害怕还是体贴。

| 区域 | 要求 | 自拟例子 |
|---|---|---|
| 必须清楚 | 后续理解依赖它 | 是主动改签，不是车次取消 |
| 可以开放 | 多种解释有材料支持 | 改签的情感动机 |
| 不应误导 | 这种理解无依据且有重要后果 | 不能误认有人强迫她留下 |

精准 = 作品提供的条件与这些要求相称，不是每个观众复述同一句主题。

## 2. 局部准确不等于整体准确

- “我明天走”单句明确，若紧接昨天的打包镜头却无时序线索，整体仍可能混乱。信息所处位置与单句是否清楚同样重要。
- 产品使用后接自信笑容，未必明说产品改变人生，但组合可能邀请过度归因。评价对象是完整关系，不只检查文字里有没有某句宣称。

## 3. 限定分析者自己的结论

暂时不回消息 ≠ 重建自我边界；保存旧物 ≠ 亲密关系已修复。可写成可能方向，不能当成作品已充分证明的稳定变化。精准的报告同时说明现有材料支持什么、还不能证明什么。

## 4. 清楚程度与形式相称

操作说明、关系揭示、诗性体验不需要相同确定性。增加解释可能解决误读，也可能消除有价值的余味。先明确哪里需要确定，再决定是否补充。

# 适用边界 / 不应自动做什么

- 不把“所有观众读成同一意思”当作精准的证明。
- 不因单句清楚就判定整体清楚；不因组合没有明说就判定没有误导。
