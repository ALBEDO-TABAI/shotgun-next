# 要点

McHale 区分直接、间接和自由间接话语等呈现方式，提示原话、视角和转述者并非总重合。文学概念迁移到电影时需要明确额外条件。

## 四个检查问题

1. 保留了谁的原话？
2. 谁选择或改写？
3. 来源是否可辨认？
4. 与可见事件是什么关系？

## 1. 旁白可以承担独特工作

- 可以压缩时间、引入后来理解、表现语言节奏或与画面保持距离。
- 不能仅因某事"能拍"就删旁白，也不能让旁白只把动作含义再说一遍。
- "当时我以为他在生气"限定过去理解；"他在生气"更像事实判断。一个词就可能改变叙述承诺。

## 2. 手机文字有不同事件状态

| 状态 | 后果 |
|---|---|
| 输入、删除、发送、撤回、已读、未回 | 各不相同，不可混写 |
| 未发送草稿 | 不能成为收件人的后场知识 |
| 最终回复用词改变 | 可能改变承诺 |

若关键是"长解释改为明确安排"，不必让观众逐字读完全部草稿，但需要知道发生了改写。可读性要用真实界面、字号和时长检查，不能由剧本"观众看到"保证。

## 3. 字幕会改变信息关系

- 画外说话者身份被隐藏时，字幕提前写姓名可能揭露。
- 关键在改口时，只保留整理后的完整句可能抹掉过程。
- 不同版本应检查叙事功能，而非只转录字面。这是一项编辑检查，不替代实际发行平台或无障碍交付规范。

# 适用边界 / 不应自动做什么

- 不把旁白当作可拍则删的次等手段。
- 未发送草稿、撤回消息不得被其他人物"知道"。
