# 本篇回答什么问题

反过来用于创作时，最值得建立什么流程？默认路径是：表达任务或创作欲望 → 具体问题 → 不同形式方案 → 场景与段落 → 信息分配 → 对白与声画 → 试读或视听草稿 → 修订。但任何一步都可能发现原问题不对。流程的价值是让发现进入决策、让决定进入执行、让反馈回到适当层级，而不是制造越来越多等待确认的材料。

# 核心主张

1. 先把输入分成事实、要求、假设、偏好，改变权限各不相同；未知要有位置，不能无标记进入交付。
2. 发散要改变实质变量，收敛要说明理由，返回要具体到层级。
3. 阶段 A–G 各有输入、交付、进入条件与回退触发，但按任务缩放，不要求每个项目依次填写全部文档。
4. 原型只回答它能回答的问题；状态必须诚实（未测就写未测）。
5. 一份当前依据只统一该统一的事项；一项决定有提议、当前、已消费、已检查四个状态。
6. Agent 角色可实现但未验证；最终方向、事实性承诺与发布责任由人决定。
7. 两项 AI 研究支持保留取证与人工判断，不证明中文影视或当前模型的表现。
8. 按问题调用模块，不把十二篇串成冗长审批。

# 来源与边界

本篇的流程、职责与交接字段是本包的综合设计，不是已部署的 Agent 系统，也未在真实团队运行测试。具名来源分别提供方法类比、创作者经验、协作理论与研究结果，不混写为普遍科学定律：
- [Design Council：The Double Diamond](/references/design-council-double-diamond.md) — 方法类比
- [Céline Sciamma / BAFTA 讲座](/references/sciamma-bafta-lecture-2019.md) — 创作者个人方法
- [Scriptnotes 728：Beats to Scenes](/references/scriptnotes-728-beats-to-scenes.md)、[John August：How to write a scene](/references/august-how-to-write-a-scene.md)、[Scriptnotes 696：Guide to Directors](/references/scriptnotes-696-guide-to-directors.md) — 实践提问，非硬规则
- [Clark & Brennan：Grounding in Communication](/references/clark-brennan-grounding-1991.md) — 共同理解理论，迁移为交接检查
- [Rashkin 等 2025](/references/rashkin-help-me-write-a-story-2025.md)、[Tang 等 DuoDrama 2026](/references/tang-duodrama-2026.md) — 仅支持其任务与模型范围
