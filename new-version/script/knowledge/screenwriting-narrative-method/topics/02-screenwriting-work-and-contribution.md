# 本篇回答什么问题
"这句台词是谁写的"容易追问，"为什么不用台词""为什么这件事必须晚一点出现""为什么合并两个人物"却容易从工作记录里消失。本篇对应原十二点体系的第②点，承接第一篇的形式档案，处理**工作分解、成果形态、表达转译与贡献证据**；不替代第 12 篇的整体制作流程。

# 核心主张
1. 分开职业、活动与成果：不从职务名称推定劳动，不从署名推定成片细节。
2. 编剧工作按**改变的对象**分六类：选材、建构、组织、分配、转译、修订；每类有各自的替代性指标陷阱。
3. 每种交付物有自己的读者与任务，"完成"要按任务检查；制作说明保护意义关系而非锁死手段。
4. 作品出现了什么、可能造成什么、创作者自述为何，是三种陈述，后者需要真实记录。
5. 贡献用材料、转化、实现三层证据追溯，写成叙述链而非虚构占比；缺证据就报告不可确认。
6. 替代方案的等价分事实、行动关系、信息时机、经验四层，终态相同不等于全部等价。
7. 内部共识不是观众证据；交接允许执行者回述。
8. 规模决定文件分层，不制造无人消费的报告。
