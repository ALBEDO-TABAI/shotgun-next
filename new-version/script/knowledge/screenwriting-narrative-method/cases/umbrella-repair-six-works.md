# 案例声明

全部为自拟形式练习，非真实品牌项目或维修研究。

# 六种版本

| 版本 | 内容 | 重点 / 品牌角色 | 风险与要求 |
|---|---|---|---|
| A 服务广告 | 顾客要当天取伞，维修者明确实际时限并提供临时借伞 | 承诺、限制与替代；品牌是服务提供者 | 须核实流程与服务，不为表达可靠编造业务；结尾安心由行动支持，不宣告人生被修复 |
| B 工艺说明片 | 依部件和工序组织检查、拆卸、替换与复核 | 工作如何判断；未必需要误会与成长 | 镜头顺序应尊重所解释的过程，不能混剪成错误因果 |
| C 剧情短片 | 修伞成为两个人重新见面的具体任务：为何必须来、为何保留木柄、能否直接谈关系 | 人物选择 | 保护物件与前史的关系，不把所有价值归到品牌；品牌只落版时其联系需另行说明 |
| D 观察性非虚构短片 | 跟随真实修伞人的一段工作，记录实际条件与交谈 | 实际观察 | 未出现戏剧性客人不等于要安排偶遇；可剪辑选择，但保存来源、时间和语境，不给停顿强加心理 |
| E 单幅平面 | 一只手稳住木柄，另一只手更换伞面，旁边放着用旧的部件 | 修复与保留；未必交代主人和木柄来历 | 标题可限定"保留想留下的部分"，仍需防止修复能力宣称超出真实范围 |
| F 诗性视听短片 | 伞骨与树枝、缝线与布纹、雨点与轻敲构成联想 | 形式关系和意义变化，不伪装完整事件链 | 若同时承担品牌识别，需真实资产进入组织，不只在结尾补一个陌生名字 |

# 比较表

| 版本 | 主要推进 | 关键检查 | 不应强加 |
|---|---|---|---|
| A | 服务问题与安排 | 承诺真实、选择清楚 | 产品解决全部情绪 |
| B | 分类与过程 | 工艺准确、步骤可读 | 人物成长弧 |
| C | 行动与关系 | 动机、信息与后果 | 每秒卖点 |
| D | 实际观察 | 来源、语境、参与关系 | 必须发生预定故事 |
| E | 关系瞬间与图文 | 推断边界、裁切 | 完整前后史 |
| F | 联想和形式变奏 | 对应、节奏、归属 | 强因果解释全部画面 |

它们不是质量排名；差别是材料被组织来完成什么，以及需要什么证据。
