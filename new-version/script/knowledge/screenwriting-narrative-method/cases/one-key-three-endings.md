# 案例声明

本案例为自拟，未做受众验证。此前条件（父亲常替女儿安排、本场希望她的选择被尊重且关系不中断）必须在作品中建立，不能靠案例说明代替。

# 三个候选结尾

## A：主题总结

父亲：“爱不是控制，是尊重你的自由。”他把钥匙推回，女儿拥抱他。

- 命题明确，但人物为何此刻做出如此完整的总结需要依据。
- 推回钥匙也可能被读成不接受离开而非许可；台词不能自动修复动作歧义。

## B：只有动作

父亲推回钥匙。女儿拿起，离开。

- 更短、更开放，却可能无法区分许可、控制或回避。
- 前文若已有钥匙约定可以成立；没有则不能仅因无对白就赞美精准。

## C：协商条件

父亲：“这把你留着。”女儿没有立刻接，问：“我来之前，给你发消息？”父亲：“好。”她收起钥匙。

- 让使用方式进入协商，尝试把主动选择交给女儿。
- 效果仍取决于前文与表演，不是标准正确答案。

# 四维度检查

| 维度 | 可检查 | 不能自动推出 |
|---|---|---|
| 精准 | 权限与条件由谁提出是否可见 | 所有人都读成尊重 |
| 有效 | 是否回应先前具体问题 | 人生观已彻底改变 |
| 不出戏 | 语言属于人物和处境吗 | 日常口语必然更好 |
| 巧妙 | 实际进入权与关系边界是否合作 | 钥匙天然是高明象征 |

选择可以是任一版，也可以重写。**比较的价值是理解条件与代价，而不是给所有作品固定赢家。**
