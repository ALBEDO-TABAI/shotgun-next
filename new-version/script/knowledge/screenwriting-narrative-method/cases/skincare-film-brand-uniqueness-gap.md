# 现状判断

当前方案在品类层面讲"晚间护理与个人时间"。若只替换包装，多数叙事仍可能成立。这不自动使它失败，但说明**没有足够理由宣称品牌独有**。

# 真实品牌资料可能怎样进入

| 资料 | 可能改变什么 |
|---|---|
| 具体而真实的使用动作 | 动作节奏 |
| 可辨认的包装结构 | 成为生活声音的一部分 |
| 既有品牌语言 | 文案 |
| 真实研究 | 确认或否定该生活处境 |

这些必须来自资料，**不因为"需要独特"就发明**。"肤感""清爽""舒缓"等词可能具有不同事实与监管含义，应由真实证据和专业审核确定。

# 两类任务不要合并宣称

- **情绪品牌片**：需要建立可信联系和归属。
- **解释具体产品功能**：当前版本可能不足，需增加合适信息或重做形式。
- 不能让一条 45 秒片同时承担全套品牌哲学、所有卖点、人物弧和世界观，再用"节奏快"解决冲突。

# 产品可替代性测试的用法

替换同品类包装，记录失去什么。若没有重要损失：继续研究专属素材，或接受它是当前的品类构想。**不要把测试变成"凡故事独立成立必不合格"。**

> 待确认：品牌是否接受"品类层面的构想"作为当前交付，还是要求在文本阶段就建立品牌独有联系——这决定是否需要重做形式，只能由品牌方拍板。
