# 前提

自拟的虚构维修服务项目，未取得真实品牌资料和工艺验证。初始要求："表达可靠，不只说技术好"。

# 三条路线

## 路线 A：承诺如何被兑现
修理者面对顾客当天取伞的要求，检查后发现无法按原样及时修复；他说明限制、提供替代方案、让顾客选择。可靠 = 明确能力与承诺，而非魔法赶工。需核验真实维修流程、可替换部分与合理时间；服务实际做不到就不能为故事编造。

## 路线 B：不擅自替人决定
顾客想修得像新的一样；修理者发现某块旧补丁可能重要，不替他编解释，只问"这块也换掉吗"，顾客选择保留。关注协商与权限。无需立刻揭晓亡亲往事，也不必把"保留旧物"写成唯一正确态度。风险：暗示过重，诱导观众补出不存在的悲剧。

## 路线 C：让工作过程被看见
按检查、拆解、试撑、返回复核组织。没有人物成长，也没有交付时拥抱，重点是质量如何体现在实际过程。需要工艺准确、动作可读；实际没有某道工序，不应因为拍起来漂亮而加入并伪装成真实工作。

# 比较什么

比较每条路线把"可靠"定义成什么；依赖哪些事实；与品牌有什么关系；需要怎样的篇幅和材料；最大的未证实假设是什么。

| 路线 | 主要组织 | 核心证据 | 最大风险 |
|---|---|---|---|
| A | 行动与后果 | 实际限制、说明与替代 | 编造不存在的承诺 |
| B | 关系协商 | 顾客表达偏好且被尊重 | 把有限偏好解读为完整人生 |
| C | 过程观察／说明 | 可核验的工序及判断 | 用漂亮动作冒充专业证明 |

若品牌确实以透明沟通见长，A 有研究基础；若只有工艺素材可用，C 可能更适配，但仍需检查传播任务。没有一种路线因为更像故事就自动更好。

# 适用边界

- 案例为自拟，不是真实消费者研究，不能当作已验证方案。
- 比较项本身是本包综合方法，不是行业标准。
