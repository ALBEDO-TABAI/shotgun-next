# 全面评价与可行动诊断

## 评价如何不空泛

先明确标准来源：用户明确要求、作品已建立的观看约定、媒介限制，或分析者暂定标准。未知 brief 不妨碍分析作品内部关系，但不能直接判“完成品牌目标”。

“全面”是覆盖适用维度与限制，不是十二栏全写批评。每项标为“有支持 / 条件性成立 / 存在风险 / 材料不足 / 不适用”；结论不是客观量表分数。综合评价应说明最重要的成就、代价、核心弱点及结论适用范围。

## 覆盖矩阵

| 维度 | 核心检查 | 不允许的捷径 |
|---|---|---|
| 1 任务与观看情境 | 作品服务什么任务，用户已给什么目标，首次/静音/移动端有什么约束 | 广告一律等于卖点论证；艺术片一律免评 |
| 2 形式与主题问题 | 整体如何连接，局部是否协作；题材、问题、命题是否被混淆 | 只有贴“悬疑/治愈/高级”标签 |
| 3 人物与关系 | 行动对象、依据、策略、选择、代价和他者回应 | 用标签/讨喜程度代替行为判断 |
| 4 世界、空间与物件 | 规则、知识权限、空间关系、物件持有和行动可能性 | 把角色误信当作世界自相矛盾 |
| 5 场景与结构进度 | 进入—作用—离开；连接理由、选择变化、铺垫回收 | 用镜头多、冲突多、反转多等于推进 |
| 6 对白与文字 | 对谁做什么、对方怎么回应、语体/共同知识；旁白与文字有无任务 | 所有直白对白都差，所有省略都高级 |
| 7 信息分配 | 必要/延迟/开放/无作用；观众、人物和叙述者各知道什么 | 以作者解释补足观众看不到的线索 |
| 8 精准与连贯 | 哪些需要明确、哪些可开放；观看约定是否被意外破坏 | 表面顺滑等于有逻辑；刻意疏离等于失败 |
| 9 情感与巧妙 | 情感有什么行为/形式依据；一个选择服务哪些关系及其代价 | 音乐/哭泣必然感动；双关必然巧妙 |
| 10 声画与节奏 | 事件、认知、情绪、视听四种节奏；通道是互补、反差还是冗余 | 单张截图证明运动/声音表现；快等于有效 |
| 11 媒介、品牌与陈述责任 | 品牌联系和必要识别；功能/情境/象征分开；非虚构来源 | 使用产品就证明功效；想象用户反应就是销售数据 |
| 12 创作转译与可制作性 | 关键动作、读字、空间、接头和时长能否被实现；原创关系能否迁移 | 剧本写了就已拍成；模仿名词就是学到方法 |

非人物作品的第 3 项可以不适用，第 4 项改看物件/视觉世界规则，第 5、7、9 项改看形式和经验的组织。若未看成片，第 10、12 项只给文本风险判断，不说“表演自然、配乐恰到好处”。

## 有效机制卡

`位置与证据 → 具体选择 → 改变了什么关系/知识/体验条件 → 成立所需条件 → 本来可能付出的代价 → 改稿必须保护什么`。

示例：父亲先移开鞋架再回答，许可先以动作成立，台词不必解释全部关系；但其作用依赖观众看懂鞋架挡住入口。此为机制判断，不证明所有观众已经读到。

## 问题卡

每个关键问题包含：ID、范围、材料事实、症状、原因假设、竞争解释、标准/目标、严重后果、需保护机制、最小改动、替代路线、代价、验证。未发现有意义的竞争解释时写清排查范围，不虚构平衡。

优先级按后果与依赖：
- **P0 阻断**：关键事实错误、根本逻辑/材料冲突，或明确要求不能成立。
- **P1 重要**：关键选择/信息不成立，导致后续理解偏离。
- **P2 改善**：局部节奏、语言、重复、清晰度与可执行性问题。
- **P3 取舍**：成立的替代审美，不能冒充必须返工。

不要用很多 P2 抵消一个 P0，也不要为了显得严格硬造 P0。先问小改能不能解决，最后才建议新增场景或重写全片。

## 反事实与竞争解释

可做删除、换序、换载体、改变前提、分离声画、改变结束点。每次写“保持什么，只改什么，会影响哪条关系”。例如把主动递钥匙改成对方拿走，终态相同但选择权不同；不能叫等价润色。

合理反证可能是：缺的是材料而不是作品；用户目标并不要求那种效果；下一场已解决；诗性开放本身是观看约定；所建议修改会破坏更重要的误判过程。验证这些情况，避免假问题。

## 评价与预测分开

允许给出有立场的专业判断：“在现有文本中，时间承诺比情感宣言更有依据；建议保留前者。”不能说“观众必然共鸣”“转化率更高”。有真实反馈时注明参与者、材料版本、提问和观看条件；模拟角色或模型多视角审稿只叫纸面检查。

用户要求打分时先给定义清楚的分项诊断锚点和证据，不将它包装成科学测量或跨作品统一艺术排名；关键失败项仍单列，不被平均掉。

## 借鉴方法不是复制表面

输出“目标/问题 → 决策机制 → 所需前提 → 可换的载体 → 不该照搬的条件 → 一个新情境的简短迁移”。不把特定台词、颜色或作品名当万能配方。新情境必须标“示例”，不能混入重建稿。
