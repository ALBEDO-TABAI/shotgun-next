# 取证、对齐与剧本重建

## 1. 对象先于解释

先给一句对象声明，例如：“本次依据 storyboard-v2.csv 的 18 行及 transcript-v1.srt；未提供视频；结论指向这些材料描述的视频版本，不能确认成片实现。”若表格是拍摄前设计，则称“计划版本重建”，而非“成片复原”。

建立来源小表：来源 ID、文件/版本、性质、覆盖范围、已读范围、定位单位、限制。保留来源的实际粒度：表格用工作表/行或镜号，字幕用条目和原时间码，文字用实际段落，视频用实际可读取区间。没有时间码就用材料位置；不能给估出来的 00:13.240 伪精度。

来源可靠性按陈述判定：画面能证明门关了，不能证明绝交；对白能证明角色说过某事，不必证明世界里真发生；故事板能证明设计要求，不证明拍摄成功；模型逐镜描述是二手记录，不能当已亲眼查看。

## 2. 对齐不强迫一一对应

先在原顺序建立镜头/文本单元。每单元写视觉、对白、旁白、场内/场外声音、屏幕文字及载体，再建立跨来源对应关系。

| 情况 | 处理 |
|---|---|
| 一句旁白跨三镜 | 保留一条话语及其覆盖范围，不每镜复制为三次发声 |
| 字幕跨切点 | 注明覆盖区间，不自动当作新镜头对白 |
| 两人同时说话 | 保留重叠；不强行串成自然接话 |
| 文字稿没有说话人 | 标“说话者未确定”，不按语气猜身份后写死 |
| 时间码缺失/镜号跳号 | 保留缺口；有局部可核对则先完成局部 |
| 两份材料事件顺序不同 | 查版本、拍摄顺序与成片顺序；未解决时保留竞争重建 |
| 转录可能误字 | 保留原文，另记“疑似应为…”，有实际音频才进一步核对 |

重复不是删除依据：同一句字幕可能是两次真实重复，也可能是导出重复。先查上下文。音画时长重叠不能简单相加为全片时长。

## 3. 证据标签和置信度

使用自然标签，不必给每句话建 JSON：

- **材料明示**：来源的直接记录；同时说明它是原媒体还是二手记录。
- **推断**：说明可见线索、竞争解释和适用范围；高置信度不把它变成事实。
- **未知/冲突**：没有足够依据，或材料相互冲突。
- **有意开放（判断）**：仅在存在形式依据时使用；不能把所有没解释的地方美化成留白。
- **外部意图自述 / 真实接收证据**：独立记录来源和条件，不能灌进首看观众知识。

置信度可用高/中/低，必须有理由，如“两份同版本材料相互支持”或“仅来自不完整镜头描述”。不给未经校准的百分比。

## 4. 从镜头到场景

一个场景由连续处境和主要作用关系定义；一个长镜头可含多个节拍，多个快切可同属一个段落。工作单位建议：`SH01` 为源镜头，`SC001` 为重建场景，`B01` 为必要节拍；这些 ID 不是来源原有镜号时要说明。

对每场回答：进入时发生了什么？谁知道什么？这场让什么变化？离开时世界、关系、知识或形式规律如何变化？用一句话说明与下一场是因果、时间、对照、类比、论证还是形式连接。只在适用时建立人物目标。

同时维护两条简图：故事世界时间线和呈现/获知时间线。回忆、梦境、主观想象、屏幕内影像要分层；未确定是闪回还是想象，不擅自选一个。

## 5. 重建稿的书写纪律

正文用场景标题、可呈现动作和来源中确有的语言。少量中性整理可以改善可读性，但不得改变事件发生方式。可用“人物 A”“门内的人”等描述性称呼；未知姓名、年龄、职业不得发明成确切设定。

不要把“她痛苦地意识到父亲从未爱过自己”写进画面只提供低头动作的场景。可写：“她低头，手停在杯沿。[材料明示 E004]”；另注：“可能承托犹疑或失落，具体原因未定。[推断 E004]”。

剧本后可附解释性梗概和主题假设，但使用同样的证据边界。标题不明时用“分析用暂名”，原结局不明时停在材料结束处。

## 6. 覆盖与冲突复核

逐个源单元标注去向：已并入哪个 SC、重复待核、与另一版本冲突、非剧本信息、未能读取。重要单元不能无声消失；无关拍摄管理信息无需搬入正文。

以实际目标决定主文：用户指定成片而只给计划稿时，先交计划层重建并标界限；用户指定某版文字稿时，不用另一版分镜的内容暗中纠正它。无法选主版本就给最小共同部分与差异分支，不拼出不存在的“最合理成片”。
