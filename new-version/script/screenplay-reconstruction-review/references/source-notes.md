# 来源、封装变更与验证边界

## 用户提供的主要资料

本技能基于本次上传的 `封存.zip`，内含 `screenwriting-narrative-method`（245 份 Markdown）与 `contemporary-prompting`（58 份 Markdown），共 303 份。本包各自完整内置两套资料，独立安装不依赖另一技能或外部知识路径。

`references/knowledge/` 是随附研究资料；外层 `SKILL.md` 与本目录的操作规程是这次为两个具体任务设计的运行入口。原资料的小写 `skills/` 只是知识接口示例。相同来源在两个独立包重复内置是为了离线独立使用，不意味着运行时把它们同时灌入上下文。

## 本次做了什么、没有做什么

做了输入/输出与任务边界、按问题阅读路由、证据重建流程、写作/修订/确认流程、双版本保护关系、模板、案例、评测用例和必要的只读检查工具。它们是本次综合设计，不冒称原作者或某个理论家的原始分类。

没有重新进行全量学术系统综述，没有重新核验原包每一条外部链接，没有重看教程原视频，没有运行生成实验或真实受众测试，也没有宣称在用户的应用内完成安装和长周期运行。

## 导航修复与来源保真

移除了 macOS 元数据。可定位的包内绝对链接改为文件相对链接，保持搬移后可读。指向未随上传包提供的历史原稿/README/阅读器等位置，保留为有说明的历史定位文本，不造假补写其内容。涉及旧 Skill 和离线阅读器的历史包装说明加了存档提示。

[来源清单](source-manifest.json) 记录每份文件的原始 SHA-256、包内路径和转换后 SHA-256；[未随包提供的历史定位](unavailable-source-locators.json) 保留每处缺失来源的位置。正文中的知识观点、案例身份与研究限制没有被抬高为已验证事实。原包自己的数量、发布日期和安装描述属于历史陈述；实际交付以文件清单与本次验证报告为准。

## 官方 Skill 结构依据

2026-09-18 查阅用户指定的 OpenAI “Build skills” 页面。采用单技能目录、带 `name`/`description` 的 `SKILL.md`、按需引用资料、模板和可选工具，并提供 `agents/openai.yaml`。本次是两个独立本地 Skill ZIP，不是插件目录发布或安装回执。

官方来源：`https://learn.chatgpt.com/docs/build-skills`

## 研究与运行结果分开

编剧资料中的理论、作者经验和实证研究各有限定范围；提示词六问与示例没有生成效果保证。查看 [编剧证据边界](knowledge/screenwriting-narrative-method/principles/source-use-and-evidence-boundaries.md) 和 [提示词证据边界](knowledge/contemporary-prompting/foundations/05-how-to-know.md)。当前产品能力、接口与规格需执行时查第一方资料，历史指南不是当下能力表。

封装检查与单元测试只证明明确列出的静态合同；不能证明模型总会正确触发、推理、遵守审批或写出好作品。人工/宿主行为用例与真实媒体/受众验证单独标记是否运行，不混用“通过”。
