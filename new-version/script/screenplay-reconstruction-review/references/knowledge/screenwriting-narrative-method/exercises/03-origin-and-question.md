# 练习

| # | 任务 | 约束 |
|---|---|---|
| 一 | 以"关心"为主题，分别写行动问题、关系问题、观察问题 | 不得只换人物姓名，需说明观众在等待什么不同东西 |
| 二 | 给"可靠的维修服务"加上无法当天完成的限制，重新设计表达 | 不能凭空增加加急服务逃避限制 |
| 三 | 选一个自己尚无答案的问题，写出事实可跟随、价值判断开放的场景 | 开放不是人物和任务全部模糊 |
| 四 | 从研究中找一条不利于原概念的材料，说明方案因此改变了什么 | 若不改变，也应给出有依据的理由 |
| 五 | 把一个昂贵场景换成低成本载体，分别记录保留的关系和损失的体验 | 避免只比较制作价格 |

# 完成条件

完成本篇不要求已有完整剧情，但应知道：自己在研究什么、哪些来自证据、哪些正在构造、为什么选择当前形式、下一步怎样让方案面对实际材料。

> 好的起点不是听起来足够宏大，而是能够不断生成具体关系，并允许新的发现修订最初的想法。
