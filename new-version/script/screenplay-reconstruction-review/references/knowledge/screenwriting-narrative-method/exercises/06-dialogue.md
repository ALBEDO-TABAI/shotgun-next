# 六项测试

| 测试 | 做法 | 注意 |
|---|---|---|
| 无背景首读 | 先问发生什么，再问关系理解 | 不提示"父亲隐忍的爱"；事实误读与情感差异分别记录 |
| 回应扰动 | 把一句回答改成明确拒绝，检查下一句是否完全不变 | 不变可能是预制独白，也可能人物有意不听，需证据区分 |
| 直接／间接双写 | 用三种语言风格完成同一任务 | 比较所需语境、时间和解释空间，不预设含蓄版本胜出 |
| 声画分离 | 分别读台词、看无声动作、看完整版本 | 定位各通道；不要求每个通道独自完成作品 |
| 关系迁移 | 把同一事实分别告诉朋友、顾客和长期合作者 | 事实不变，观察顺序、解释量和请求方式的变化 |
| 专业词核验 | 对职业、方言和历史用语找真实材料 | 听起来专业不是已经正确；未经查证须标注 |

# 通过条件

不是每句藏答案，而是：

- 关键表达有当前依据
- 回应参与过程
- 必要信息可获得
- 语言风格与作品约定相称
- 开放解释没有被误报为确定事实
