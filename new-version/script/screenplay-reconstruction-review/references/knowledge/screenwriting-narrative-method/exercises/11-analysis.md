# 练习

| 练习 | 检查什么 |
|---|---|
| 1. 分别用十句复述事件、十句说明信息安排 | 两者是否被混写 |
| 2. 为一个片段写两种有证据的主题解读 | 各自注明解释不了的材料 |
| 3. 选一个评价词，改写成可回看的具体关系 | 找不到证据就保留为个人反应，不写成机制结论 |
| 4. 比较修订前后版本 | 列出解决的问题、新增的问题、未受影响的部分；修改多不等于更好 |

# 交接清单
将报告交给修改者时，提供：
- 当前版本；
- 关键事实；
- 需保护机制；
- 建议的可替换性；
- 重新验证条件。

不要让下游自己猜哪条意见必须执行、哪条只是讨论。

# 本篇原则
> 分析的终点不是替作品说出一个更漂亮的主题，而是说明它怎样成立、哪里尚无依据，以及怎样通过具体变化来检验理解。
