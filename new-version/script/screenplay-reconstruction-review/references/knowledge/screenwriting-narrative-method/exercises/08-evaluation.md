# 测试设计要点

| 测试 | 要点 |
|---|---|
| 理解测试 | 先问事实和关系 |
| 体验访谈 | 问感受出现的时刻 |
| 版本比较 | 尽量明确变量；观看顺序要考虑前一版带来的知识 |

- 熟悉素材的内部人员适合检查执行，不一定代表首看。
- 小样本可以发现问题，但不能推断全体观众比例；量化复述正确率不等于艺术质量。
- 可以记录赞成、理解、记忆、喜欢和行动意向，但不能互相替换。
- 本包没有运行实际受众实验，所有测试都为建议方案。

# 反向练习

1. **拖或直白的段落**：先写它可能承担的另一种任务，再找证据，最后才决定删改。
2. **觉得“高级”的处理**：去掉这个词，只解释具体关系。如果只能说“留白多、需要思考”，还没有完成分析。
3. **两份有证据但优先级不同的评价**：区分分歧来自事实还是取舍，不把后者伪装成对方不懂作品。

> 成熟评价不是消灭审美差异，而是让依据可讨论、让修改有对象，使作品不因一句含糊意见而失去自己真正成立的部分。
