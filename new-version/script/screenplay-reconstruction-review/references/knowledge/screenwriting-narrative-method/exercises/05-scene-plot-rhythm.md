# 反证

- **观看者没有读出母亲已准备搬走**：先查证据可见性、前文是否过度定义她的拒绝、后续动作是否真支持新理解。不能直接责怪"不懂留白"。
- **删一场仍能复述故事**：不证明它无用。还应比较关系、空间、节奏和经验损失。反事实测试必须覆盖作品实际追求的功能。

# 练习

| # | 练习 | 要求 |
|---|---|---|
| 一 | 同一地点分别写合作场景与冲突场景 | 两者都需明确过程，不把合作版写成寒暄 |
| 二 | 重排三场戏 | 保持世界事实不变，记录观众问题怎样变化 |
| 三 | 对一个长段落分别标注动作、理解和声画强调 | 观察三者不同步的作用 |
| 四 | 删除自己喜欢的场景，再写出具体损失 | 可以恢复，但不能只用"很美"作理由 |

# 交付

场景表、连接关系、分层节奏诊断、可测试修改。它不是标准结构合格证，而是关于作品怎样推进的证据化说明。

> 进度不是事情越来越多，而是行动、理解、关系或经验发生有根据的变化；节奏是怎样分配经历这些变化的时间。
