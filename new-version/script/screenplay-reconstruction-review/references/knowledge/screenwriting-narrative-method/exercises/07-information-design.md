# 练习

| # | 练习 | 要求 |
|---|---|---|
| 1 | 同一故事写三种信息顺序 | 说明每版观众在等待什么，而非只倒放镜头 |
| 2 | 删除一条解释 | 列出剩余证据支持到哪一步；达不到要求就保留说明或调整任务，不靠作者补充 |
| 3 | 审查假线索 | 分别写作品实际给了什么与观众可能推断什么，找出在改写事实而非引导推断的地方 |
| 4 | 写一个原因始终未明、但当下行动可理解的结尾 | 说明未知不妨碍什么，又保留了什么 |
| 5 | 横屏有声版改静音竖屏版 | 检查字幕、画幅与声音缺失怎样改变知识；形式变了，不能自动继承原版理解状态 |

# 本篇工作原则

> 信息设计不是让观众尽量晚才明白，而是让他们在适当时刻，凭作品实际提供的依据，知道必要的部分，并对值得保留的部分继续思考。
