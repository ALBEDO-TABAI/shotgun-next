# 要点

| 状态 | 记录什么 | 限制 |
|---|---|---|
| 1. 直接观察 | 动作、空间、时间、可见语言（"她发送前删改三次"比"她没有安全感"更接近观察） | 仍受立场与范围限制，不是全知事实 |
| 2. 当事人自述 | 谁在什么情境下说了什么，以及允许怎样使用 | 既是关于事件的材料，也是当下的自我呈现；不能无条件当作全部事实的最终版本 |
| 3. 可核验公开资料 | 区分原始记录、专业研究、机构说明、新闻转述、无来源总结 | 多个转载不等于多个独立证据；术语专业不代表适用于当前年代、地区或产品 |
| 4. 创作构造 | 合并人物、虚构对白、改变时序、新增关系 | 都是合法手段，但应在内部材料中注明；事实性作品不能把构造改写成已核实的现实 |

口述史协会（OHA）的原则强调知情参与、语境与材料使用；迁移到创作研究时应说明采访目的、记录方式与引用范围，但这不替代具体权利问题的专业核查。

## 材料条目示例（自拟）

```text
材料ID：R-014
内容：一名受访者说自己习惯先回消息，再完成睡前动作。
来源状态：该人的自述；不是整个人群的调查。
能支持：这一行为值得围绕该人物继续研究。
不能支持：同类职业或年龄的人普遍如此。
创作转化：拟用一次动作被中断与恢复表现当下选择。
待确认：实际回应要求、职业条件、公开使用的同意。
```

## 研究也需要反向提问
- 什么材料会让目前喜欢的构想不成立？
- 是否把个体的自由选择写成了事实上不能拒绝的任务？
- 是否遗漏了决定行为的资源条件？有无与常见叙事相反的经验？
- 若所有资料只用于证明初稿，研究正在承担装饰功能。保留一栏"这项发现会改变哪一处创作"，使调研进入决策。

# 适用边界 / 不应自动做什么

- 不把一条自述当作人群结论；不把转载数量当作证据数量。
- 不用"艺术允许想象"混淆虚构与事实性声明。
