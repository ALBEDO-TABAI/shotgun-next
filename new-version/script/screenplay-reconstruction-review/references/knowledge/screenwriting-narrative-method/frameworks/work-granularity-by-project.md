# 要点

| 项目类型 | 编剧工作的特点 | 不能做什么 |
|---|---|---|
| 广告 | 需要真实品牌与产品条件；可以重构表达 | 不默认由编剧独自决定策略；不悄悄改造事实性卖点 |
| 非商业影片 | 可在写作中发现问题；尚未决定的结尾是合法状态 | 不把早期命题伪装成从未改变；要记录方向如何变化 |
| 平面拍摄 | 可能只需设计一个动作阶段、关系瞬间与标题配合 | 不必补出完整人物人生 |
| 非虚构 | 在研究和剪辑中组织材料 | 不把未知事实自动补成确定事件；叙事建构与现实指涉责任并行检查 |
| AI 辅助项目 | 模型可提供背景、动机等建议 | "符合提示词""模型解释得通""几位 Agent 都同意"都不等于作品任务完成；模型生成内容必须标为建议，不进入原始证据栏 |

## 规模决定分层
- 小项目：只维护**一份当前剧本、一份关键决定记录、一份反馈**。
- 复杂项目才进一步分层。
- 不应为了调用更多角色而制造无人消费的报告。

# 适用边界
- 表中类型不是互斥分类，同一项目可以兼有多种属性（如商业非虚构短片）。
