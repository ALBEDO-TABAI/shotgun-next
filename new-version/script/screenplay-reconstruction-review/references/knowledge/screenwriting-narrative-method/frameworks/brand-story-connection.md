# 要点

## 1. 至少区分四类结果
品牌认出、信息理解、情感或意义联系、现实行动。它们可以相互影响，但不保证按固定漏斗发生：喜欢故事 ≠ 认出品牌；认出品牌 ≠ 相信卖点；表达赞同 ≠ 购买。没有对应数据，不能由一项结果推出另一项。

Escalas 关于叙事加工与消费者—品牌联系的研究，本包只取得摘要与元数据：它支持把这种关系作为研究问题，不支持"任何故事广告都提高销售"，也不提供本案结果。

## 2. 产品可以有不同叙事角色

| 角色 | 主要关系 | 审查重点 |
|---|---|---|
| 实际工具 | 帮助完成某项任务 | 能力和效果是否真实 |
| 日常行为的一部分 | 在具体生活中被使用 | 使用是否自然、真实、可识别 |
| 解释或演示对象 | 观众理解它是什么 | 证据与结论是否匹配 |
| 关系中的物件 | 赠送、保留、修复、传递 | 人物关系是否有依据 |
| 品牌价值的署名者 | 品牌选择讲某种生活经验 | 联系是否可信，是否空泛占有价值 |
| 形式来源 | 包装、质地、结构组织声画 | 形式联想是否仍可归属品牌 |

角色不互斥，一件产品不必解决全部故事。生活片段可以独立成立，品牌通过真实用途、资产或长期主题与其发生关系。

## 3. 三层连接检查
1. **内容关联**：为什么是这个题材，而非任何情绪故事？
2. **事实与身份依据**：品牌有什么资格、能力或历史讲它？资料必须真实，不由编剧临时补造。
3. **可感知归属**：实际呈现什么使观众把作品与品牌联系起来？只在内部提案里解释不够。

# 适用边界

- 品牌片不必每秒露出；去掉所有名字后毫无特定联系，只提示需要讨论可替代性，是诊断，不是自动判死刑。
- 不由品牌态度或联系研究直接推断本案销售。
