# 要点

Toolan 区分**语言衔接**与**依赖语境的连贯**：连接词与顺滑剪辑不保证意义完整，打乱日常顺序也不自动失去组织。[2]

## 四种连贯分别检查

| 连贯 | 检查什么 |
|---|---|
| 事件连贯 | 行动、条件和后果能否在作品规则中联系 |
| 人物连贯 | 选择是否符合当前知识、资源、关系与压力，或变化是否得到表达 |
| 主题与形式连贯 | 重复、对照、语调与意象是否形成可说明的关系 |
| 接收可追踪性 | 观众是否有足够线索跟随作品实际要求的内容 |

一部非因果作品可以有形式连贯；一条剪得很顺的广告也可能在产品与结论之间缺桥梁。

## 三类不同变化，不能统称“崩人设”

1. 人物确实改变；
2. 观众对人物的认识被修正；
3. 同一层事实无解释地冲突。

前两种不能都说成“崩人设”，第三种也不能被说成“精巧反转”。判断前先检查时间、来源与视角。

# 适用边界 / 不应自动做什么

- 复杂作品不免于具体事实核查；清楚作品也不必只有一种解释。
