# 要点

August 的对白文章重视对话流动、对反应的预期以及人物真正听取回应，而不是轮到自己就完成说明段落。这是个人实践方法，不是某种措辞保证效果的实验结论。

## 互动链

> 当前需要 → 尝试说法 → 对方接收 → 原策略是否奏效 → 继续、修改、升级或放弃。

## 1. 先修互动，再修词句

甲想借车，先夸乙保养得好；乙直接问"你要借多久"。甲若仍按原稿继续三句赞美，就像没有听见。可让甲被识破后直接谈条件，或否认后被钥匙位置暴露。乙的回应应对甲产生作用，哪怕甲有意装没听见。

## 2. 打断和语气词不是自然感插件

- 加入"那个""就是"不自动真实。
- 停顿是在找词、等许可、决定是否说真话，还是对方动作改变了判断？**关键停顿至少要有可演的条件**，不只写"意味深长"。
- 其他停顿可由表演发现，不必精确规定每一秒；目的不是把对白变成微操脚本。

## 3. 合作也有推进

- 一起回忆、共同寻找说法、确认陌生规则，都可形成变化。修理者解释限制、顾客补充物件的重要部分、双方重设修理目标，是共同解决问题，不必强行改成争胜。
- 亲密可通过无需补全的句子表现；疏离也可通过完整却互不承接的礼貌话表现。不能把协调一律视为没有戏。

# 适用边界 / 不应自动做什么

- 不把"人物有意不听"与"作者预制独白"混为一谈：两者都表现为回应不变，需要证据区分（见练习"回应扰动"）。
- 不用打断、语气词、停顿的数量衡量自然感。
