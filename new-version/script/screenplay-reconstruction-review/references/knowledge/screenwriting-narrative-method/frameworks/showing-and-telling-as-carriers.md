# 要点

- "展示／讲述"在理论中有多种定义：不等于有画面就是展示、有语言就是讲述，更不能由此统一排序。
- 关于说明性信息的编剧对谈同时警惕两端：灌输过量，以及因害怕解释而删掉必要内容；承认直接说明可以有效。

## 四类载体比较

| 载体 | 适合 | 代价 / 风险 |
|---|---|---|
| 直接说明 | 事实必须明确；解释本来属于场景；作品采用说明形式 | 可能灌输过量 |
| 行动演示 | 把规则与后果联系起来 | 需要时间；虚构演示不等于真实功效证明 |
| 反应与关系 | 表现信息的影响 | 未必能交代精确复杂的事实 |
| 痕迹与并置 | 提供推断空间 | 承担更多误读可能 |

选择取决于清楚程度、形式约定、成本和风险，而不是一律去掉对白。

## 无声测试的用途

无声测试只能定位语言承担了什么，不能证明"依赖语言就不够电影化"。

# 适用边界

- 理论综述与创作者对谈都不是观众效果实验；创作者建议不改写为所有作品的硬性规则。
