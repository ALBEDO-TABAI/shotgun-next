# 要点

Grice 的会话理论说明：接收者可借助语境、谈话目的和对相关性的预期，推断未直接说出的意思。合作原则**不等于**友善、诚实或意见一致，也不意味着每句都存在唯一的秘密答案。潜台词不是把字面全反过来。

## 潜台词成立的三个条件

| 条件 | 含义 | 反例 |
|---|---|---|
| 有可用语境 | 没有上下文，"雨停了"可以是出门、结束等待或只是观察 | 不能因作者想写告别就断言它必然是逐客 |
| 有可理解的关联 | 回答"今晚留下吗"时提到早班车，观众有理由联系到离开安排 | 关联只存在于作者私人记忆时，需另给依据 |
| 有后续接收 | 对方收被子、问几点走、换话题，会进一步确定这句如何被理解 | 潜台词形成于互动，不是孤立句子的密码 |

## 自拟小对话

甲："今晚留下吗？"／乙："明早五点的车。"／甲："我送你。"

这并不必然证明乙不想留下：可能在说明不便、争取照顾或强调很早离开。甲接受了车次事实，未必完成了留宿问题。作品需要明确就再用行为或回应解决；作品关注两人绕开决定，则可保留这项未完成。

## 三种状态不能混用

| 状态 | 含义 |
|---|---|
| 间接表达 | 需要从语境推断行动 |
| 隐瞒或欺骗 | 涉及人物怎样控制信息 |
| 意义开放 | 作品没有完全确定动机 |

三者可并存，却不是同一个标签。反讽、客套与试探也不同：不是所有不直说都叫反讽，直白也不一定缺乏关系作用（"我不答应"可以很有行动分量）。

## 潜台词最好先写成假设

记录"可能在试探是否仍被欢迎"，并注明支持它的停顿与动作；不给演员一张"真正意思唯一对照表"。排练可比较不同读法，有时保留竞争解释更有价值。

# 适用边界 / 不应自动做什么

- 不把每句都改成潜台词；不把合作原则理解为道德要求。
- 隐瞒与欺骗属于信息控制问题，应回到信息设计层处理。
