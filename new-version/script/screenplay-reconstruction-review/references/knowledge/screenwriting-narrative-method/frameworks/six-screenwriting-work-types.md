# 要点

> 本分类是本知识包的应用综合，不是某位学者的原始完整分类。

| 工作 | 主要对象 | 常见成果 | 应防止的替代性指标 |
|---|---|---|---|
| 选材 | 经验范围与视角 | 材料地图、取舍说明 | 资料数量代替相关性 |
| 建构 | 行动依据与世界条件 | 人物关系、规则记录 | 设定页数代替可用性 |
| 组织 | 部分连接 | 大纲、场景序列 | 幕结构标签代替实际关系 |
| 分配 | 知识与预期 | 信息表、揭示说明 | 写过代替已被呈现 |
| 转译 | 意图与声画行为 | 场景稿、执行说明 | 参数细度代替叙事清楚 |
| 修订 | 方案与新证据 | 改稿、影响记录 | 改字数量代替解决问题 |

## 1. 选材：决定哪些经验进入作品
- 同一次家庭搬迁可围绕亲子、劳动、财产或孩子的空间记忆展开；选谁、哪个时段、什么事件作中心已是创作，不是中性准备。
- 选材也包括**不使用**：不服务当前问题、篇幅无法承载、事实未核实、可能伤害现实人物、会引向更大线索。
- 分析问：哪些经验被直接呈现、哪些只由转述、哪些被省略；取舍改变了观众判断什么的条件。缺席不必都补足，但不应被当作不存在。
- 商业项目要区分**真实 brief** 与**创作假设**："品牌要求产品出现"与"我们猜年轻观众喜欢独白"不是同类输入，后者需研究或测试，不能默默升级成要求。

## 2. 建构：让人物、关系与规则生成选择
- "父亲不善表达"是概括；"他会先把东西修好再找理由送去，却不直接问女儿何时回来"才是可用的行为倾向。
- 不要求十页小传，要求关键动作有依据：想获得什么、相信什么、能做什么、担心哪种代价、面对不同对象怎样换策略。
- 世界建构不只是年代服装："住户可随时取消访客权限"会改变钥匙、来访与亲密关系的意义。
- 交付物应说明已确立事实、规则适用范围、人物知识、故意未定项。不把人物误信写成世界事实，不让结尾突然出现未建立的万能例外。

## 3. 组织：改变部分之间的关系
- 合并角色、删前史、交换两场、让物件再现、把单一经历改为反复过程都属组织，不只是套三幕四幕。
- 同一事件提前出现可能让共同发现变成等待人物追上观众；删一段文字可能比新增十页更大改变重心。
- 比较版本应描述**关系**：新增什么因果、改变谁的理解、把哪项选择留到何时，而不是"新增 500 字、删 300 字"。

## 4. 分配：安排知识、注意力和预期
- 重要信息可能只在小传里、放进画面却无法辨认、可读却与更强动作争抢注意。
- 便条在美术文件里完整存在 ≠ 观众知道内容。载体由编剧与执行者共同决定。
- 人物信息也有获取路径：没读过信就不能准确回应信中秘密。分配要保护路径，不只管理揭晓时间。

## 5. 转译：把意图变成可感知过程
- "她终于放下了"是意图；她归还了什么、停止了什么、允许了什么才让观众基于动作形成理解。转译不等于给情绪配固定身体符号。
- 电影叙事是影像、表演、声音、剪辑、文字的配合，不能缩减为语言故事加插图；电影是否必须假设类人叙述者存在理论分歧。
- 通道分工示例：动作建立事实，声音提供画外压力，文字承担精确信息，构图保留关系距离。各通道不必重复同一结论，也不必为复杂而互相反对。

## 6. 修订：根据新材料改变方案
- 修改来源：研究、读稿、表演、场地、预算、片长、观看反馈。先明确问题，不立即重写全部。
- "自然一点"可能指没有说话动机、句子太完整、表演太强调、品牌语言突入日常谈话——不同原因要求不同干预。先诊断含糊意见，比快速交一版全新稿更省返工。
- 记录影响范围：删铺垫影响后面理解，提前道具可能让反转失效。修订不以保存文件为终点，还要检查下游关系。

# 适用边界 / 不应自动做什么
- 六类是按改变对象划分的分析尺度，不是岗位分工表；同一人可做多类，同一类可多人协作。
- 无证据时不得据此裁定署名或占比（见 [贡献追溯](contribution-evidence-three-layers.md)）。
