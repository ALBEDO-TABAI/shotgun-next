# 要点

| 术语（本包工作定义） | 含义 | 检查 |
|---|---|---|
| 留白 | 作品已给出当前理解所需的关系，但不穷尽某些可推断或开放的部分 | 它不是普遍优于解释的等级 |
| 歧义 | 现有材料支持多种读法 | 若后文只能按一种理解成立，就要决定是否补线索；不能一面宣称开放，一面要求所有人选同一答案 |
| 延迟 | 信息在后续被更新 | 关键问题可以回答、重写、转移或明确放弃，未必逐项揭底；但不能无意识遗忘前面建立的期待 |
| 缺漏 | 作品要求的理解缺少必要条件 | 来源可能是写作、剪辑、裁切、字幕或音量，必须针对实际版本判断 |

判定原则：
- "有人不懂"不自动证明错误。
- "作者说留白"不自动证明有效。
- 要区分：目标观看条件、误读的具体内容、作品愿意保留的风险。

# 适用边界

- 这些是本包的工作定义，理论术语之间存在差异。
- 缺漏必须对实际版本判断（横屏有声版与静音竖屏版可能得出不同结论）。
