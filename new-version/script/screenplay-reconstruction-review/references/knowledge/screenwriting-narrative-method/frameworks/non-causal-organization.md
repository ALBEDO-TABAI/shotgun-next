# 要点

常见错误：**找不到强因果，所以认为作品没有结构。** 来源引 Schmid 对"叙事中的非时间性联系"的讨论：人物、动作、情境和表达形式可以跨越事件先后，通过主题或形式上的相似、对照、等价被连接。

## 分析问题

- 同一个动作重复时，什么发生了改变？
- 两个空间被并置，是因为故事上互相影响，还是因为形成了价值对照？
- 某种声音反复回来时，是标记时间，还是把不同时刻的经验联系起来？
- 结尾重新出现的物件，是否改变了开头的意义？

自拟例：旧伞作品中第一次出现的缝线可能只是修复工艺；随后与衣物补丁、手上的伤痕并置，它就可能进入"修补与保留"的联想网络。

## 不能只写"运用了隐喻"，还应说明

| 追问 | 内容 |
|---|---|
| 依据 | 哪些可见或可听的特征建立了联系？ |
| 层面 | 联系发生在形式、内容还是价值层面？ |
| 竞争解释 | 还有没有同样合理的其他解释？ |

## 非线性与非因果必须分开

- 非线性主要涉及**时间呈现**；非因果涉及**材料的连接方式**。
- 顺时展开的作品同样可以包含复杂的意象对应；打乱时间的作品也仍可能依赖很强的因果链。

# 适用边界 / 不应自动做什么

- 不把"有隐喻""有意象"当成完整分析；必须指出联系的具体特征与层面。
- 不把非线性等同于非因果，也不把顺时等同于因果主导。
- 联想解释须与其他合理解释并列，不独占。
