# 要点

"广告"描述用途与传播关系，"影片"说明媒介，"平面拍摄"可能只是制作活动。三者不在同一分类轴上：品牌可以做非虚构短片，一张照片可用于商业或个人表达，同一作品会进入不同发布情境。因此不用三个盒子，而用四个轴分别定位。

| 轴 | 问什么 | 记录要求 |
|---|---|---|
| 传播用途 | 解释事实、建立品牌联想、讲述经验、提出问题、记录过程，还是形式探索？ | 真实 brief、作者自述、分析者推测分别标记 |
| 媒介条件 | 单幅、图像系列、连续有声影片、静音播放、交互体验 | 列出实际尺寸、时长、字幕、声音与完整播放条件，而不是"平台观众没耐心" |
| 事实性承诺 | 虚构、访谈、现场记录、重演、模拟、动画说明各自与现实的关系 | 经过组织不自动虚构；看起来真实也不自动成为事实证据 |
| 观看情境 | 影院、展览、店内屏幕、手机静音、社交页面、提案会议 | 未知就记录未知，不能凭人群标签推定观看习惯 |

补充判断：
- "提高转化"若没有具体人群、行动和使用条件，只是大方向，不能直接指示剧本。非商业作品也可能有传播任务（引起讨论、传递知识）。
- 单幅图像、连续图像与影片在时间表现和推断条件上不同：单张图可支持前后想象，但不能当作已明确叙述前因后果。
- 事实与虚构的差别在于对现实的指涉承诺，而不只是外观。

# 适用边界

- 四轴相互影响但不能互相代替："它是广告"不能证明它采用论证形式；"它有电影感"不能证明它适合所需发布情境。
- 本轴只做叙事适配定位，不替代平台技术规范或合规判断。
