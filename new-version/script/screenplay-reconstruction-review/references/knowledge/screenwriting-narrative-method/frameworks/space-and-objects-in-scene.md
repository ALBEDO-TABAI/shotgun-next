# 要点

空间理论提供空间框架、场所与叙事空间等分析层次（Ryan）。用于具体场景时，本包重点检查五个条件：**可见、可听、可达、可进入、可退出**。

## 1. 场所改变人物能怎样表达

- 公共交通、空厨房、即将关门的店：同一段谈话有不同限制——能否停下来、谁会听见、能否离开、是否必须继续手头工作。
- 普通空间也可以有很强的作用：两人无法同时通过门口、一人手里拿着热碗、另一人在整理待带走的物件，都能改变语言与动作。不需要稀奇场景才"有戏"。

## 2. 物件先有实际任务，再讨论象征

- 过宽的桌子要求共同抬起、转向或拆卸；手机在手与台面之间移动会改变注意力。生活任务越具体，关系表达越不必靠总结对白。
- 并非每件物品都应成为伏笔。背景可以有余量；只有当结局依赖某个状态时，才需要特别保护它的连续性与可读性。

## 3. 空间同时分配知识

- 人物看不见的动作，观众可能通过另一个镜头知道；画外声音可以让不可见事件进入判断。
- 分别记录：人物能否察觉、观众能否察觉、差异的作用。
- 若角色正对关键动作却必须无理由地"没注意到"，先调整条件，不能补一句内心"走神"就视为解决。

# 适用边界 / 不应自动做什么

- 空间条件是行动条件，不是氛围装饰；换掉不能拆的家具就要重找证据（见 [案例](../cases/moving-a-dining-table.md) §修改的实际代价）。
- 不把所有道具升格为象征。
