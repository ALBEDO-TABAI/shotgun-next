# 要点

## 1. 单张平面图像先判断它提供了什么叙事条件

跨媒介叙事研究（Ryan）区分单一时刻的图像、同一画面容纳多个时刻的图像、连续图像系列。单幅图像可通过动作、关系与痕迹支持前后推断，但推断需观者补足，未必指向唯一故事。分析一张平面广告时记录：

| 记录项 | 例（修补过的伞与旧照片并置） |
|---|---|
| 已明确呈现的关系 | 物件与照片同在 |
| 可以得到支持的事件推断 | "物件与记忆有关" |
| 尚不能确定的前因后果 | "女儿在母亲离世后修复遗物"——添加了亲属、死亡、动机，可能超出证据 |

不必强求每张图都讲故事：它可以主要建立产品属性、视觉分类、象征关系或形式体验。

## 2. 电影中的意义可以在不同通道之间分工

影像、语言、声音、场面调度与剪辑的相互关系都参与建立信息和理解。skill 增加两个字段：

- **信息载体**：这个判断来自对白、动作、道具、构图、画外声、剪辑关系，还是几个通道共同作用？
- **通道关系**：它们在相互补充、重复强调、彼此反驳，还是有意保持错位？

例：画面展示失败的行动，旁白却宣称一切顺利——要分析的不是台词孤立的真假，而是两种信息之间的关系。

## 3. 风格、语调、情绪、反应的操作定义

| 术语 | 本 skill 内的定义 | 能否仅凭形式证据分析 |
|---|---|---|
| 风格 | 反复出现、具有组织性的表达选择 | 能 |
| 语调 | 作品对人物和事件表现出的言说态度 | 能 |
| 情绪氛围 | 声画安排可能支持的整体感受 | 能（作为假设） |
| 实际反应 | 具体观看者确实报告或表现出的感受 | 不能，需接收证据 |

Keen 关于叙事共情的研究提醒：没有一种叙事会对所有接收者产生相同的共情反应。所以写"反复延迟回应、保留环境声、减少解释，可能支持一种不确定和疏离的体验"，不写"这种形式一定让观众孤独"。

# 适用边界 / 不应自动做什么

- 不替单幅图像补出完整故事；不要求每张图讲故事。
- 不把单一通道（对白或摄像机角度）当作全部信息来源。
- 不把情绪氛围假设写成实际反应。
