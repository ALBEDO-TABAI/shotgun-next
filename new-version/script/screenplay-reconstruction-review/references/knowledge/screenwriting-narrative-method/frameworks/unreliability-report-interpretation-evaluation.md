# 要点

Shen 的梳理区分三层不可靠：

| 层 | 不可靠的表现 | 工作问题 |
|---|---|---|
| 事实报告 | 说谎、报告错误 | 作品提供了什么与这段说法冲突的证据？ |
| 事件解释 | 误判原因 | 怀疑针对哪一层？ |
| 价值评价 | 观众不接受的立场 | 是人物知识有限，还是讲述方式主动改变了信息可信度？ |

不等于不可靠的情况：
- 没有讲背景不是不可靠。
- 暂时不展示门后的人不自动等于撒谎。作品可以选择范围，关键是它建立了怎样的理解约定。

## 避免"最后一切都是假的"式免责

- 结尾宣布先前影像不可靠时，要检查观众此前被要求如何对待它们。可以有激烈的认知修订，但不能只用"叙述者不可靠"替所有无解释矛盾开通行证。
- 反向也成立：不要求每个谜底都能完全提前猜到。**合理的回看重组**与**首看预测能力**不是同一标准。

# 适用边界

- 来源为理论综述，用于区分问题层次，不是观众效果实验。
- 形式开放不能免除事实性作品对真实证据的责任（见深化应用）。
