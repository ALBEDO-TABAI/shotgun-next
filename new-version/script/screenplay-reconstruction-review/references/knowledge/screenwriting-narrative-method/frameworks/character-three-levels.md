# 要点

人物研究区分虚构人物与现实中的人，讨论直接赋性、间接推断、背景知识与信息不完备。一个人物可以被明确描述，也可以由行为和语境逐步被理解，作品不必提供完整人生档案。

| 层面 | 含义 | 自拟例子 |
|---|---|---|
| 世界状态 | 作品当前确立的事实 | 她已接受新工作，还没告诉家人 |
| 呈现方式 | 通过谁、哪些行为和评价接近她 | 家人说她"总是不守信用"，不能自动当作作品认定的事实 |
| 接收解释 | 观众依据材料与自身经验形成的理解 | 同一沉默可读为保护或回避，分析应指出各自依据 |

三条操作规则：

1. **直接描述也要查来源**。旁白说人物"从不撒谎"，可能是可靠说明，也可能是回忆、自我辩解或讽刺；要结合作品约定，不能看到形容词就入档。
2. **间接塑造不等于任意补完**。一次迟到可能与交通、任务、性格或关系有关；无证据时只提候选解释，不补出整套童年经历。分析模式不应偷偷切换成续写模式。
3. **人物可以保留未被穷尽的部分**。只要当前作品要求的理解成立，不必把所有行为归结到一个"核心创伤"或统一人格模型。

# 适用边界 / 不应自动做什么

- 不把自己的第一读法称为唯一真相；对同一材料的多种解释应各自给出依据。
- 不对人物做现实心理诊断。
- 呈现层的评价（他人说法、旁白）要先判断其可靠性，再决定是否进入"世界状态"。
