# 要点

Bordwell 在电影叙事分析中引介 Sternberg 对好奇、悬念、惊讶的区分。本包直接查阅的是 Bordwell 的文章，文中转述的原系列论文不算已全文阅读。

| 类别 | 工作问题 |
|---|---|
| 好奇 | 已发生的结果究竟由什么导致？ |
| 悬念 | 正在展开的行动将产生什么后果？ |
| 惊讶 | 新信息改变了我们对什么的认识？ |

三者可以共存，不是互斥的故事类型，更不是每一场都必须具备。

## 四条纠偏

1. **知道更多不保证悬念**：观众先看到辞职信，还需要理解它的后果或人物为何难以寄出。信息差本身不是情绪强度。
2. **知道更少不保证好奇**：人物、任务、后果全部模糊，观众可能连要问什么都不知道。可以隐藏原因却明确动作，隐藏身份却明确关系或风险，让未知有可追踪的边界。
3. **已知结果仍可以关注过程**：开头就说"她最后没有离开"，仍留下如何决定、付出什么、别人怎样理解等问题。提前结果改变动力，不一定消灭观看理由。
4. **问题需要层次和更新**：连续加谜团而旧问题无任何变化，只是积压。可以让小答案重新定义大问题，或明确事实后开放意义；并非每个解决都要马上引出更大秘密。

# 适用边界

- 来源是学者本人的分析文章，提供区分工具；不保证某种信息顺序产生固定情绪。
