- 产品与品牌材料

# 练习

1. 保留核心问题，写一个**没有手机**的版本，说明什么关系不变、哪些证据需要替换。
2. 把请求改成**确实紧急**，分析为什么原方案不能原样继续，提出不同问题而非替人物辩解。
3. 加入真实产品特征后，判断它改变了剧情、动作还是只有表面美术。禁止添加未经支持的效果。
4. 把"人生改变"改写为当前作品可证明的小变化，检查结尾所有声画是否与尺度一致。

# 完成标准

> 案例的完整，不是把未知都写成答案，而是让每个选择都有对应依据、执行条件与验证办法，同时明确哪些工作尚未完成。
