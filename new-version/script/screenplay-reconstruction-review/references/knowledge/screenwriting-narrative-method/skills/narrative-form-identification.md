# 任务边界

> 基于作品及可核验语境，识别其不同层面的形式属性，解释属性之间的关系，建立证据充分、允许不确定性的形式档案。

**不应自动承担**：替作者确定唯一主题；凭一个片段判断整部作品；把所有作品改造成标准三幕结构；仅凭形式推断实际传播效果。

# 输入

| 输入 | 内容 |
|---|---|
| 作品材料 | 完整影片、剧本、分镜、单幅图像或图像系列 |
| 分析范围 | 整部作品、某段、某场、某张图，还是某次版本修改 |
| 外部语境 | brief、发布情境、创作者自述、发行分类等（**可以未知**） |
| 证据完整度 | 是否缺声音、缺结尾、缺字幕，是否只有二手摘要 |

没有 brief 时，不能把分析者推测的目的写成已知需求。

# 六步流程

1. **不命名的观察记录**：记录人物、物件、动作、声音、文字、状态变化和重复元素；暂时少用"治愈""荒诞""电影感"等概括词。
2. **确定分析尺度与段落边界**：按行动、信息、空间、主题或形式变化分段；分段依据明确，不一定每个镜头是一个叙事单元。
3. **识别主导连接方式**：分别判断整体与局部主要通过事件、分类、理由、联想或形式变化组织；允许复合。→ [主导组织原则判断法](../methods/dominant-organizing-principle-test.md)
4. **展开相关坐标**：存在叙事时继续分析世界、动力、线索、时间和信息；以抽象形式为主时不必硬填人物成长与故事时间线。→ [叙事内部分析轴](../frameworks/narrative-internal-analysis-axes.md)
5. **建立证据、解释与竞争解释**：每项重要判断能回到具体材料。"结尾改变了对人物的理解"需指出原理解由什么建立、新理解由什么修正。
6. **输出对后续创作有用的约束**：不只交付标签，说明哪些关系不能在改编或制作中被意外破坏。例："不能提前暴露这件物品的来历，否则原本的共同发现会变成等待人物追上观众。"

# 判断记录格式

```text
分析范围：
材料状态：

判断所属维度：
具体判断：
操作定义：

直接证据：
推测的作用机制：
其他合理解释：
尚缺少的信息：

创作者意图证据：
观众效果验证状态：

对后续创作的约束：
可采用的验证方式：
```

"未知""不适用""仅对本片段成立"都是合法结果。不要为了让表格完整而补造信息。

# 通过条件（六项，不计算"高级程度"）

| 检查项 | 应当通过的标准 |
|---|---|
| 概念一致 | 同一个术语在分析中采用同一操作定义 |
| 尺度明确 | 局部判断没有未经说明升级成全片结论 |
| 证据可回看 | 关键判断对应时间码、画面位置或文本段落 |
| 层面不混淆 | 类型、目的、组织方式、事实性与风格分别说明 |
| 推断有边界 | 观察、机制推测、作者意图、实际效果没有混写 |
| 对创作有用 | 能说明具体保留什么、改变什么、怎样验证 |

"内部一致"不要求作品只能有一种形式，而是：**同一对象、同一范围、同一概念定义下，不能产生没有解释的相互冲突判断。**
