# 当前任务

女儿来帮母亲搬家，以为母亲迟迟不清空是在拒绝变化。母亲已决定搬走，但想带上旧餐桌。场景要让女儿**修正判断并开始配合**，不要求她理解母亲的一生。

> 本案例为自拟。下面的动作及 90 秒分配是写作假设，尚未以真实家具、空间和演员验证。

# 薄弱版本

母亲叹气；女儿说"过去的就让它过去"；母亲说"这里都是回忆"；两人拥抱后搬家。

问题不是直白必然错误，而是当前认知变化主要靠**宣告**，观众缺少具体证据。

# 行动版本（90 秒候选）

| 时段 | 行动 | 叙事作用 | 待验证条件 |
|---|---|---|---|
| 0—12 秒 | 女儿放下打包毯，等母亲离开桌边 | 建立任务与等待 | 能否读到在等母亲而非普通休息 |
| 12—28 秒 | 母亲在桌腿和连接处贴对应标记 | 提供实际准备的证据 | 标记用途是否可辨认 |
| 28—46 秒 | 女儿尝试抬桌，发现过不了门；母亲递工具 | 旧判断受到修正 | 桌子结构、门宽和工具须合理 |
| 46—64 秒 | 两人配合拆卸，女儿按标记收好部件 | 从催促转向接受办法 | 合作变化不必演成全面和解 |
| 64—78 秒 | 女儿主动包住桌面边缘 | 以行动参与保护 | 与单纯打包如何区分 |
| 78—90 秒 | 两人共同把桌面转过门口 | 完成任务并保留关系余味 | 声画不要夸成全部人生问题解决 |

三种依据各司其职，不是同一件事：**门宽**是行动条件，**提前准备**是认知证据，**主动保护**是关系载体。

# 同一素材的别种形式

- 去掉女儿误判前提，专注两人拆卸和搬运 → 变为劳动与关系观察。它仍有结构，但不能继续宣称已完成"重新理解母亲"的弧线。
- 单幅照片截取共同托举、跨过门槛的瞬间 → 未必交代前面的误解。形式转换时要缩小所宣称完成的任务，不以图注替作品补一整部电影。

# 修改的实际代价

- 为省时删掉标记与工具准备 → 女儿转变的依据可能消失。可换更短的证据（如母亲早已量好门宽），但它必须实际可见，不能只写进内部说明。
- 家具不能拆 → 不能假装原动作不受影响；可改成两人寻找共同转向角度，但"母亲是否已接受搬家"需要另找证据。
