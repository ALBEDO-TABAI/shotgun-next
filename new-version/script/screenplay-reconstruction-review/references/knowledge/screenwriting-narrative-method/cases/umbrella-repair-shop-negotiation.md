> 本案例为自拟，未做实际受众验证；工艺细节未经实地核验，真实制作需专业确认。

# 1. 条件与任务

- 顾客带来旧伞，希望当天取走；修理者不认识他，也不知道其家庭历史。
- 必须建立：无法当天完成原样修复；顾客最看重木柄；双方最后达成明确方案。
- 可以不解释木柄来源；**不能**让观众误以为已承诺当天修好。

# 2. 说明型草稿

顾客："这是父亲给我的，对我有感情意义，希望你修好。"／修理者："今天修不好，但木柄可以留着。"／顾客："那就换其他部分，木柄是我最珍惜的。"

可作为清楚的梗概或教学说明，直说并非错误。但作为相遇场景，观察和协商几乎被预先答案替代。

# 3. 互动型候选

顾客把湿伞放上台面。
顾客："今天能拿吗？"
修理者轻轻展开，伞骨向一边塌下。
修理者："拿得走，撑不了。"
顾客："换这根呢？"
修理者停住手，把木柄转向自己。
修理者："您要修到能用，还是修回原来的样子？"
顾客摸了一下木柄磨痕。
顾客："这个别换。"
修理者："别的可以？"
顾客点头。
修理者在单子上圈出"保留原柄"。
修理者："明天下午。今天先借您一把。"
顾客看向门外，松开一直握着的伞带。

# 4. 每一轮做了什么

| 轮次 | 行动 | 反馈 | 观众得到什么 |
|---|---|---|---|
| 今天能拿吗 | 争取时间 | 区分拿走与能用 | 当天取走不等于修复 |
| 换这根呢 | 寻找局部快速方案 | 重新问目标 | 顾客知识有限，修理者不随口保证 |
| 能用还是原样 | 明确不可兼得的条件 | 指定木柄 | 真正不可替换的部分出现 |
| 别的可以 | 核对权限 | 点头 | 不是修理者擅自决定 |
| 明天下午／借伞 | 明确承诺与替代 | 松手 | 双方建立可执行安排 |

# 5. 该版本仍可能失败

- "拿得走，撑不了"可能显得机锋，也可能像嘲讽。可换成"今天先收好，修好得等到明天"，比较语气和效率；不能为聪明牺牲人物关系。
- 摸磨痕只需支持"木柄重要"，不足以证明父亲已去世。
- 最后松伞带也可能过度设计，应在排练中检验，不强迫演员用固定动作"证明"心理。

# 6. 改为抒情形式会改变什么

可用较晚时点旁白："后来换过三次伞面，握着它的地方一直没换。"这增加未来时间和回顾框架，会缩小某些开放性。它不是给原版免费加诗意，而是另一种叙述方案；应比较完整版本，不把两者优点相加。
