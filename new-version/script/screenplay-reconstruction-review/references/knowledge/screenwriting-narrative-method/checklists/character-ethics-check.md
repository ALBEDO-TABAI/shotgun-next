# 前提

叙事伦理区分人物行为、讲述方式及制作和接收关系。角色做了不妥的事不等于作品赞同；让角色可理解也不必等于替他免责。

# 检查项

- [ ] 谁得到解释自己的空间，谁只被用来触发主角成长？
- [ ] 哪些身份被用作无证据的性格快捷方式？
- [ ] 痛苦是否仅作为反转材料？
- [ ] 真实人物的经历是否被当成随意改写的虚构资源？

# 修改方式

回到具体材料修改，例如让拒绝请求的配角有真实任务，不再只是一个无理由障碍。

# 适用边界 / 不应自动做什么

- 不要求人物全部正确，也不要求给每种身份分配相同的好坏比例。
- 不对现实人物做诊断或补人生档案。
