# 检查表

Design Council 的双钻石区分发现、定义、发展、交付，并保留返回前阶段的可能。本包借用它提醒"不要还没理解问题就只生产答案"，不声称它已证明某种编剧流程最优。

| 检查项 | 应回答什么 | 不充分的替代 |
|---|---|---|
| 具体性 | 谁处于什么条件下 | 现代人都很焦虑 |
| 生成力 | 能否生成场景或形式变化 | 只有一句漂亮口号 |
| 研究基础 | 关键事实和行为依据在哪里 | 大量转载或个人直觉 |
| 形式理由 | 为什么这样被观看 | 因为高级、有电影感 |
| 表达边界 | 哪些结论不能由它推出 | 小成功解决全部生活问题 |
| 可试验性 | 哪项低成本材料能检查关键风险 | 一定要等成片再说 |

# 使用规则

- 不把六项机械相加。抽象作品可以不强调人物，但需另外说明形式关系；研究未完成的构想可以保留，停在候选状态，不直接批准制作。
- 筛选结果可以是：继续研究 / 做原型 / 缩小范围 / 换组织方式 / 暂存。不必每次用通过／失败简化创作状态。
