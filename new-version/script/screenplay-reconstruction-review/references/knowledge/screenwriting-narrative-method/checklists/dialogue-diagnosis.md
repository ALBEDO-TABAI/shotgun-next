# 诊断表

| 表面问题 | 可能原因 | 先尝试什么 |
|---|---|---|
| 像说明书 | 没有当前接收者或接收理由 | 改交流任务，或承认采用说明形式 |
| 很顺却没生命 | 每人只完成自己的段落 | 写出反馈改变下一句的位置 |
| 所有人像作者 | 注意对象和策略相同 | 先改关心什么，再改用词 |
| 误会拖太久 | 澄清机会被无理由取消 | 给真实代价，或让澄清引出新问题 |
| 处处是金句 | 每句都在总结主题 | 恢复事务与具体对象，选择少数总结时刻 |
| 沉默很多却空 | 没有等待回应的条件 | 建立触发，或明确它是状态描写 |
| 删词就看不懂 | 动作没承接必要信息 | 保留适当说明，不崇拜省字 |
| 纸上合理难表演 | 句法、动作与读取争抢 | 试读，重排断句与动作位置 |

# 使用规则

- 这些是**候选解释**，不是按症状自动改写。
- 迟疑、重复和绕路也可能正是人物内容；删除前说明会失去什么。
- 风格化对白被误当成不自然时，先确认作品是否有稳定语言约定，而非一律口语化。
