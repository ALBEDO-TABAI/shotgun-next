# 检查清单 · Checklists

症状-修复表、失败模式、对抗性复查、测试矩阵。


# topic-02
* [交付物完成标准](deliverable-completion-criteria.md) - 概念说明、梗概、大纲与场景卡、剧本、制作说明、修改记录六种编剧交付物各自"真的完成任务"的检查标准与常见失效方式。
* [六种看似专业、实际增加返工的做法](six-practices-that-increase-rework.md) - 人物小传代替行为依据、意图说明代替表达、多文件变成多事实、事后追认原设计、为保真冻结全部执行、把交接失败全归下游——六种反模式及各自的修正方向。

# topic-03
* [创作起点的七种常见失败模式及修正](03-failure-modes-and-fixes.md) - 先有答案再找人证明、自传当人群洞察、反差标签冒充故事、研究只提供术语、保留一切叫开放、生产限制视为纯粹损失、为新颖扩大承诺——各配一条修正。
* [构想筛选：先检查问题是否值得继续发展](concept-screening.md) - 用具体性、生成力、研究基础、形式理由、表达边界、可试验性六项检查候选构想，结论可以是继续研究、做原型、缩小范围、换组织方式或暂存，而非只有通过／失败。

# topic-04
* [人物塑造的伦理检查](character-ethics-check.md) - 区分人物行为、讲述方式与制作／接收关系；检查谁有解释空间、身份是否被用作性格快捷方式、痛苦是否只是反转材料、真实人物是否被随意改写。
* [对抗性复查：四类"不一致"](four-kinds-of-inconsistency.md) - 把疑似漏洞分为真实矛盾、错误信念、信息不足、有意的不稳定四类，各有不同处理，防止"所有疑问都是漏洞"和"所有漏洞都是留白"。

# topic-05
* [场景症状与最小修复](scene-symptoms-minimal-fixes.md) - 七种常见节奏与推进症状各对应"先检查什么"和"候选修改"；这些是诊断假设，不能按表自动改稿，更不能先定删减比例再找理由。

# topic-06
* [对白常见问题诊断表](dialogue-diagnosis.md) - 八种表面问题（像说明书、很顺却没生命、所有人像作者、误会拖太久、处处是金句、沉默很多却空、删词就看不懂、纸上合理难表演）的候选原因与先尝试的修法。

# topic-07
* [线索的制作检查链：存在、可察觉、可能被注意、可被理解、可被唤回](clue-production-chain.md) - 五项针对实际版本的线索检查，并说明重复不一定冗余、强调不等于揭底、注意分配属于整个段落。
* [防止信息在其他通道提前泄露，或在版本里悄悄消失](information-leak-and-version-loss.md) - 检查海报、标题、字幕、画幅、声音等剧本之外的通道；为关键揭示写最早允许明确时点；把"观众应该知道"具体到精度；有意保持误解时保护人物常识。

# topic-09
* [媒介适配测试矩阵](09-test-matrix.md) - 完整观看、静音、目标画幅与真实尺寸分别检查；品牌认出、内容理解、情感解释与现实行动分别问；不同作品类型追加各自的专业复核。本包未执行这些测试。
* [去掉产品、换品牌、删文案：三项可替代性测试](remove-product-swap-brand-tests.md) - 三项测试用于观察删除或替换后损失了什么，标准来自项目目的而不来自测试本身；不同任务需要不同的品牌关联强度。

# topic-12
* [最终交付检查与停止条件](final-delivery-and-stop-conditions.md) - 事实与材料、作品、协作、验证、交付五组检查项，以及"停止当前阶段"的含义。
