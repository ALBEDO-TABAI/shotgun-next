# 要点

不用每次从头运行全部体系。按当前问题选择模块。

## 问题 → 模块 路由表

| 当前问题 | 优先调用 | 需要的结果 |
|---|---|---|
| 不知道作品究竟靠什么成立 | [01 形式识别](../topics/01-narrative-form-identification.md) ＋ [11 分析诊断](../topics/11-close-reading-diagnosis.md) | 形式档案与证据 |
| 创意只有抽象价值 | [03 创作起点](../topics/03-creative-origin-and-question.md) | 具体问题与候选形式 |
| 人物行为不可信 | [04 人物与世界](../topics/04-character-relation-world.md) | 条件、策略与关系修订 |
| 很忙却不推进 | [05 场景与节奏](../topics/05-scene-plot-rhythm.md) | 变化与连接诊断 |
| 台词像作者演讲 | [06 对白](../topics/06-dialogue-as-interaction.md) | 互动与说明改写 |
| 留白与缺漏难区分 | [07 信息设计](../topics/07-information-design.md) | 信息范围与载体 |
| 各方都说感觉不对 | [08 表达评价](../topics/08-expression-evaluation.md) ＋ [11 分析诊断](../topics/11-close-reading-diagnosis.md) | 标准、证据与竞争解释 |
| 长短版或平面转换 | [09 媒介适配](../topics/09-medium-purpose-adaptation.md) | 新任务、损失与验证 |
| 需要综合示例 | [10 护肤片案例](../topics/10-skincare-film-case.md) | 可讨论的完整候选 |
| 工作边界或贡献不清 | [02 编剧工作](../topics/02-screenwriting-work-and-contribution.md) | 工作与实现证据 |
| 反复返工与交接冲突 | [12 迭代与交接](../topics/12-iteration-and-handoff.md) | 当前依据、变更与使用检查 |

## 模块边界（启动条件 / 核心输出 / 不应自动做什么）

| 篇目 | 启动条件 | 核心输出 | 不应自动做什么 | skill |
|---|---|---|---|---|
| 02 | 工作或贡献不清 | 工作项、来源、转化、实现与消费者 | 无证据裁定署名或占比 | [screenwriting-work-and-contribution-map](../skills/screenwriting-work-and-contribution-map.md) |
| 03 | 起点抽象或方向未定 | 具体问题、材料状态、形式候选 | 把个人经验升级成人群洞察 | [creative-origin-and-question-framing](../skills/creative-origin-and-question-framing.md) |
| 04 | 行为或世界条件不成立 | 人物依据、双向关系、规则 | 给现实人物诊断或补人生档案 | [character-relation-world-model](../skills/character-relation-world-model.md) |
| 05 | 场景、连接或节奏问题 | 状态、连接、时间、节奏诊断 | 用固定幕结构检查所有形式 | [scene-plot-and-rhythm-design](../skills/scene-plot-and-rhythm-design.md) |
| 06 | 语言与互动不成立 | 话语行动、回应、场景稿 | 把每句都改成潜台词或金句 | [dialogue-as-interaction](../skills/dialogue-as-interaction.md) |
| 07 | 误读、留白、揭示问题 | 信息状态、路径、载体与风险 | 以作者知道代替观众可获得 | [information-design-and-reveal](../skills/information-design-and-reveal.md) |
| 08 | 评价混乱或标准冲突 | 分项判断、取舍与测试 | 生成艺术总分或统一审美 | [evidence-based-expression-review](../skills/evidence-based-expression-review.md) |
| 09 | 媒介／用途改变 | 各版任务、关键损失、适配方案 | 声称短版完整保留全部长版作用 | [medium-purpose-adaptation](../skills/medium-purpose-adaptation.md) |
| 10 | 需要综合练习 | 完整护肤片候选与检查示范 | 当作真实品牌方案或验证结果 | [skincare-case-teaching-use](../skills/skincare-case-teaching-use.md) |
| 11 | 分析现成材料 | 证据报告、竞争解释、最小修改 | 默默从分析跳到重写 | [close-reading-and-diagnostic-review](../skills/close-reading-and-diagnostic-review.md) |
| 12 | 创作迭代或交接失序 | 当前依据、阶段结果与下一验证 | 无人消费的层层报告和重复审批 | [unified-skill-interface](../skills/unified-skill-interface.md) |

第一篇（形式识别）不在总表中，其接口见 [narrative-form-identification](../skills/narrative-form-identification.md)。

## 最小运行闭环

当前问题 → 相关材料 → 适当模块 → 有证据的候选 → 明确决定 → 实际使用 → 检查结果 → 必要时回到对应层级。

回退按层级：信息读取失败回到载体，前提失实回到问题；一处界面错误不必重写整个人物，整体目的改变也不能只靠局部补丁。

## 按任务缩放

小型平面不必先写完整世界百科，短广告不必预设大型角色团队，观察作品不必生成虚构冲突。

# 适用边界 / 不应自动做什么

- 模块名称用于说明分工，不宣称存在已运行工具。
- 同一人可以使用多个模块；不要求每个物料经过全部流程。
