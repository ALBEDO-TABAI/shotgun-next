# 要点

精致程度不等于问题已解决。

## 不同原型回答不同问题

| 原型 | 适合检验 |
|---|---|
| 读稿 | 语言与结构 |
| 简易走位 | 空间与动作 |
| 分镜 | 视觉顺序 |
| 临时声画稿 | 时间和通道关系 |
| 小范围试拍 | 表演与实际可读性 |

一种通过不能替代其余：文字读得懂，不说明手机画面可读；漂亮分镜不能证明演员动作在真实场地可行。

## 三条规则

- **最先测试高影响、低成本的未知**：若期限不清会改变整个人物判断，先测一句消息；若问题是演员沉默是否可读，就需要至少简易表演，而不是反复写文字解释。
- **定义任务，不诱导答案**：先让观看者复述，再问关键事实和开放理解，最后讨论喜好。首看、暂停、解释后再看分别记录。
- **状态诚实**：写"文本已形成""走位已检查""当前版本某项理解获得支持"，不写"全链路已验证"。没有真实测试就写未测试，不用假想数据补报告。

# 适用边界 / 不应自动做什么

- 原型检查通过不等于受众效果普遍成立。
- 模拟观众不是受众数据。
