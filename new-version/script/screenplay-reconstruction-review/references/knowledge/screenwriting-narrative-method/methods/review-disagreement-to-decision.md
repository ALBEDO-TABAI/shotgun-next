# 步骤一：判定分歧层级

多方说法不一致时，先确定分歧属于哪一层，而不是要求一人说服所有人。

| 层级 | 例子 | 解决方式 |
|---|---|---|
| 事实分歧 | 手机到底发送了吗？ | 回看材料，不需要审美投票 |
| 机制分歧 | 同一动作被理解为允许还是控制？ | 比较解释，需要前后证据和必要的试演 |
| 标准分歧 | 要明确协商还是保留不确定？ | 涉及目标，需要创作任务和责任方取舍 |
| 偏好分歧 | 喜欢哪种节奏或语言 | 可以保留，不把个人习惯包装成唯一专业要求 |
| 执行分歧 | 某镜头是否拍得出、某句文字是否读得完 | 需要实际样稿和资源，而不是抽象争论 |

# 步骤二：一次讨论只解决相应层级

- 对发送事实都不一致，先不讨论人物是否成长。
- 事实一致但主题各有读法，确认是否属于允许开放。
- 业务要求与艺术方向不同，不能让剪辑师靠缩短两秒替双方解决策略冲突。

# 步骤三：从意见列表到决策记录

只有改变任务、理解或执行的决定才需要持续追踪；不必记录每个普通形容词。格式见 [决策记录](../templates/decision-record.md)。

# 步骤四：表达力与责任的双重检查

分别问“它有没有力量”和“它凭什么作这个陈述”。前者分析形式，后者核查证据与伦理。一个维度通过不能替代另一个：动人的片子可能让产品因果过度，事实准确的片子可能人物僵硬。

# 步骤五：好评价应允许被材料改变

写明哪项新证据会削弱自己的判断。例如看到完整前场后发现来访约定已建立，就应收回“缺少许可依据”的批评，而不是继续要求重复说明来维护原结论。可修订性比措辞强硬更专业，也更能减少无意义返工。
