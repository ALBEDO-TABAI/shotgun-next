# 三种不同情况

| 情况 | 例子 | 性质 |
|---|---|---|
| 范围限制 | 不知道房里有人 | 允许 |
| 观众推断 | 根据行为以为他在生气 | 允许被修正 |
| 信息冲突 | 作品明确说他已离开，又无依据让他留在屋内 | 需要解释 |

# 三条原则

1. **回看检验**：新解释能否组织前面的材料？哪些事实始终成立，哪些只是旧误解？不要求全部观众提前猜到，但要检查反转是否只靠临时补事实。
2. **有伏笔不等于有必要**：突然宣布所有关系都是实验，可能重写观众投入的经历。即使出现过仪器，也要问这种改写是丰富还是抹除，而不只确认是否埋过一个道具。
3. **隐瞒需要行动依据**：不说可能因为不确定、风险、承诺、羞耻、没有机会，或根本不知道对方误会；不能每次靠手机没电和被打断拖延。有时让秘密提早说出，转而观察知道之后怎样相处，更适合人物。初稿设了谜题，不代表必须保护到最后。

# 适用边界

- 反转的评价标准是"是否只靠临时规则免责"，不是"是否够意外"。
- 有意保持误解时仍要保护人物常识（见深化应用的"有意保持误解"）。
