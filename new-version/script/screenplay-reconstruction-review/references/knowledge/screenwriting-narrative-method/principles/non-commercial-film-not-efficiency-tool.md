# 原则

1. **可以不提供唯一结论**：作品可以把照护、等待、迁居的问题展开得更复杂而不总结普遍答案；仍需判断具体经历如何组织，不能以"艺术"免于说明。
2. **时间本身可以是材料**：长时间观察劳动、犹豫或环境不必然拖沓，可检查注意如何变化、重复有何差异、段落怎样改变前后关系。但缓慢不是天然深刻；"没有变化"和"没有作用"不是同一概念。
3. **承认不可通约的优先级**：有些作品选择保留不适、距离和困难，不追求最大即时好感。不能自动以商业传播指标否定它，也不能从"难懂"直接推导高价值。
4. **制作条件仍然真实**：材料不足、表演困难、关系未建立的问题不因非商业身份消失。应明确表达选择与实施不足的差别。
