# 本篇回答什么问题

人物注意什么、相信什么、希望什么、能做什么、选择怎样做、承担什么；别人和世界又怎样回应？"世界观"指故事世界的存在条件、规则与价值关系，不等同创作者本人的哲学立场。人物与世界需共同分析，不能分别写完设定再期待自动协调。

# 核心主张

1. 形容词（独立、温柔、坚强）和标签（未来城市、职场）都不是行动的充分依据；要改成任务、信念、策略、资源、情绪与代价。
2. 先分开世界状态、呈现方式与观众解释；直接描述要查来源，间接塑造不得任意补完。
3. 人物变化有六种位置，不必统一写成成长；"立体"不是优缺点数量。
4. 关系是双向过程：同一人对不同对象可不同，理解可不对称，权力通过行动条件显示，配角要有真实任务。
5. 理解、共情、认同、喜欢是不同的事，"更讨喜"不是通用修复。
6. 世界规则拆成可能、允许、价值、知识四问；规则要产生生活后果，例外要有范围，现实题材同样有规则。
7. 只维护影响作品和执行的最小模型；给关键解释配竞争假设，防止模型把一切讲圆。
8. 人物塑造要过伦理检查：可理解不等于免责，痛苦不只是反转材料。
