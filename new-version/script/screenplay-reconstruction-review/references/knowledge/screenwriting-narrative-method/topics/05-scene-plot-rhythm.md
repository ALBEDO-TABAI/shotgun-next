# 本篇回答什么问题

对应原体系第⑤点。"这里太慢""不够有戏""加个反转"这类反馈可能指行动停滞、信息重复、目标不清、关系没变、关键动作不可读，或把需要持续体验的段落按快节奏广告评价。本篇先拆开这些问题，再提供写作、分析与修改方法。适用于场景、序列和整体分析。

# 核心主张

1. 镜头数不是剧情数；动作不等于事件性；三幕、四幕或固定秒数不是所有作品的法则。
2. 场景的第一问是"为什么要让观众经历这一段"，职责要写成一句具体任务。
3. 用进入状态—作用过程—离开状态记录变化；作用不只有争吵，变化可以很小。
4. 空间与物件先有实际任务：可见、可听、可达、可进入、可退出。
5. 情节连接有六种，为每条连线写一句关系说明。
6. 进度看可用选项、代价与理解的变化；整合后果也是进度；任务成功不等于所有层面向前。
7. 顺序、时长、频率分别检查；换序后重查观众知道什么。
8. 节奏分事件、认知、情绪、视听四层，诊断"慢"要指出哪一层；实证研究与语料统计不是创作处方。
