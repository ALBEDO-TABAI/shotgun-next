# 本篇回答什么问题

创作不是先想一个"大主题"，而是找到值得展开的具体问题：从模糊意向进入可观察、可研究、可比较的具体处境。本篇处理材料、问题与候选构想的形成；不要求作品预先拥有唯一答案，也不把商业 brief 与作者私人表达混为一谈。所列提问、筛选表和练习是本包综合方法；案例均为自拟。

# 核心主张

1. 题材、主题词、暂定命题、具体问题、前提与构想、形式假设是六个层面，混用会把创作问题过早替换成答案。
2. 材料值得讲要看事件、经验、表达三层；罕见不是唯一尺度；可讲述性与可制作性分开。
3. 七种起点各需不同转化；brief 要拆成事实、要求、假设、偏好。
4. 命题驱动与发现驱动都有风险，用"暂定问题"折中，且开放探索不等于交接含糊。
5. 研究材料分观察、自述、公开资料、构造四种状态，每条要写"能支持 / 不能支持 / 待确认"，并保留反向提问。
6. 从价值词到可写问题要经过五次转化，包括设计观众的进入位置与决定不展开什么。
7. 新意来自改变关系而非叠加奇观；具体性不等于消费私人痛苦。
8. 构想筛选用六项检查，结论不止通过／失败；越早检验高影响假设越好。
