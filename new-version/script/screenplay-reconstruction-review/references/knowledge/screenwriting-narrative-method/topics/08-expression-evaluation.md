# 本篇回答什么问题

“好看”“感人”“很高级”是诚实反应却不足以指导修改；统计冲突和反转也不能自动给出艺术判断。本篇把**精准、有效、不出戏、巧妙**四个词分别转成可检查的对象、范围、任务与观看条件，并说明它们之间怎样取舍、评审分歧怎样推进。对应原体系第⑧点。

# 核心主张

1. 评价先补主语：设想、剧本、试拍、剪辑版、真实观看提供不同证据；描述、解释、意图、效果、规范五类陈述分开。
2. 精准是“确定与开放的分配”与理解任务相称，不是所有人复述同一主题；局部清楚不等于整体清楚。
3. 有效先说结果类型（理解、体验、观点、品牌辨认、行动），结构存在不等于接收发生，经济不等于最短。
4. 连贯不等于表面顺滑；不出戏维持的是可辨认的观看约定，而非误信现实，有意距离与意外破坏不同。
5. 情感成立要找依据，不用表情与音乐替代；巧妙是多个关系在一个选择中合作，且有代价。
6. 四种标准会冲突，没有共同单位，不算总分；为必要事实设通过条件，为艺术偏好保留论证。
7. 反馈要写成可行动的判断；分歧先分层（事实 / 机制 / 标准 / 偏好 / 执行）再讨论；评价应允许被材料改变。
8. 叙事有力不代表陈述正当，表达力与责任分别检查。
