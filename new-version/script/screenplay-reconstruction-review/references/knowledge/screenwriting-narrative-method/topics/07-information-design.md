# 本篇回答什么问题

对应原体系第⑦点。观众现在需要理解什么、可以疑惑什么、依据哪些线索形成哪些推断、何时修正或保留这些推断。讨论说明、延迟、留白、误导和揭示。

# 核心主张

1. 世界中发生过、人物相信发生过、作品声称发生过、观众推测发生过，不是同一状态。
2. 谁发声不等于我们知道多少；每次人物知识都要有获取路径。
3. 不可靠性分报告、解释、评价三层；范围限制不是不可靠，也不能用"叙述者不可靠"给所有矛盾免责。
4. 好奇、悬念、惊讶是三个可共存的工作问题；知道更多不保证悬念，知道更少不保证好奇。
5. 讲或不讲按当前任务分类（必要／延迟／开放／无作用），省略也要有作用说明。
6. 留白、歧义、延迟、缺漏性质不同，不能互相替代。
7. 线索要过制作检查链（存在、可察觉、可能被注意、可被理解、可被唤回），针对实际版本。
8. 展示与讲述是载体选择，不排高低；反转要过回看检验；验证要发现"作者知道得太多"。

# 来源与边界

本篇的状态表、工作流程和自拟案例是应用综合；理论提供区分工具，不保证某种信息顺序产生固定情绪。案例未做实际受众验证。实际调用来源：
- [Niederhoff：Focalization](../references/niederhoff-focalization.md) - 知识限制、视点与声音的区别
- [Shen：Unreliability](../references/shen-unreliability.md) - 报告、解释、评价中的不可靠
- [Bordwell：How to tell a movie story](../references/bordwell-how-to-tell-a-movie-story.md) - 好奇、悬念、惊讶；文中转述的原论文不算已读
- [Klauk、Köppe：Telling vs. Showing](../references/klauk-telling-showing.md) - 展示／讲述的多种定义
- [Scriptnotes Ep. 357：Exposition](../references/scriptnotes-357-exposition.md) - 创作者对谈，不改写为硬性规则
