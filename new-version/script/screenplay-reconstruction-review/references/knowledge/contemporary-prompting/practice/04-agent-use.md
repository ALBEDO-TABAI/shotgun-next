# 40｜给 AI 助手和团队的用法

## 先认清现在在做什么

探索、写稿、准备资产、生成、修图、验片、剪辑——这是不同任务。

用户只要一句提示词，不要输出整套制片流程。用户要做一个系列，也不能只给一句漂亮描述就结束。

**按任务取用**：检索时先看总目录，再拿当前任务相关的两三篇。需要身体表演，就读表演、动作和一个案例。不要每次把 47 篇全塞进上下文。

## 角色分工

| 谁判断 | 主要决定什么 | 提示词作者负责什么 |
| --- | --- | --- |
| 导演 / 创意负责人 | 观众体验、故事、形式选择 | 准确表达，不暗中改题 |
| 美术 / 摄影 | 造型、空间、材质、光、观看位置 | 组织有效参考，写清楚描述 |
| 表演 / 声音 | 人物行为、说话关系、听觉结构 | 声线和当场状态分开写 |
| 编辑 / 生成执行 | 片段选择、接头、参数、任务模式 | 把说明编成接口能用的输入，记录实际结果 |

一个人可以兼多项，AI 助手也能协作。关键不是人头数，是**决定有没有被准确传递**。

## 给助手的最小工作顺序

1. 读已有目标和实际素材
2. 指出影响任务的矛盾
3. 在必要范围内展开或执行
4. 给一份能用的结果
5. 说明还需要验证什么

除非任务复杂，不要求每次把这五步的过程全写出来。

探索阶段可以提多个方向。**执行阶段不擅自新增人物、换包装、改结局。** 如果已有方案不成立，提最小变更和影响，不默默换一套创意。

## 对参考、参数和工具保持诚实

- 文件名 ≠ 文件已上传
- 编号 ≠ 引用已绑定
- 文字里的时长 ≠ 真实参数
- 任务提交成功 ≠ 媒体通过

**没有读到的图像、没有听到的音频，不得宣布验收。**

本指南不会自动调用模型、安装插件或购买服务。付费生成要用户对实际请求和开销做明确决定。把创作样稿当成调用许可，是两件不同的事。

## 生产只有一份"当前决定"

当前镜头说明、批准的素材、实际通过的区间，三者应该对得上。

不把旧提示词、旧状态、旧回执当最新依据。新改动影响服装、台词或终点时，更新受影响的交接。与本镜无关的信息不用传给所有人。

## 知识怎么更新

某条方法在一个模型里有效，只记录到它的适用条件，不立刻升格为全平台原则。

模型接口变了，优先更新[工具适配](../workflows/08-model-adaptation.md)和官方来源。艺术方法不用随每次发布重写。

六层方法和两张图谱是这次综合提出的创作工具，适合用实际作品反复检验。把不同结果补充为带媒体依据的案例，不编造"已验证最佳实践"。
