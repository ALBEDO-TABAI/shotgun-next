# IV · 生成与迭代

从一句需求走到成片的具体流程。生图、改图、图生视频、多镜头、预演、评价、换工具，各有各的做法。

- [21｜从一句需求到几个真正不同的方向](01-brief-to-options.md) — 先把形容词翻译成问题，再想三个方向。

- [22｜文字生图：先造一个能看懂的画面，再谈细节](02-text-to-image.md) — 结构 → 关系 → 细节。

- [23｜改图：说清改哪里，也要说清改完之后是什么样](03-image-edit.md) — 原图、改哪、怎么改、改完什么样、什么不能动。

- [24｜图生视频：让已经存在的画面继续发生](04-image-to-video.md) — 只写变化，给一个结尾状态。

- [25｜多镜头与资产：准备时可以丰富，提交时要克制](05-assets-multishot.md) — 身份、造型、状态、本镜姿态分开管。

- [26｜复杂镜头：什么时候该放下文字，先做预演](06-previs.md) — 空间关系复杂时，先用最便宜的方式演一遍。

- [27｜评价与修复：别用"AI 味"三个字掩盖问题在哪](07-evaluate-repair.md) — 失败分层，一次改一件事。

- [28｜工具适配：同一个创意，不必用同一段提示词](08-model-adaptation.md) — 创意不变，输入随工具变。
