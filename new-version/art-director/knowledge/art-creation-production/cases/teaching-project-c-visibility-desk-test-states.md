# C4 桌面验证与扩大之前的条件

- 建立前层、网纱、后层三区，用安全的小型样件和可控普通测试光；分别试前层主导、后层主导与混合，找串光来源；用目标摄影链路查看，不只凭肉眼。
- 记录网纹、反射、层距、焦点以及相机偏移后的变化；不用模糊掩盖全部问题。
- 桌面验证只说明候选机制；扩大到正式空间需重新设计结构、照明隔离、通路与运行，不把小夹子小支撑成倍放大；安全、用电、安装由专业人员确认。

# C5 四个状态，而不只“开／关”

| 状态 | 希望发生的认识变化 | 美术与照明的任务 |
|---|---|---|
| V0 | 前层暂时被视为主要空间 | 后层信息不提前泄露，前层可读但不满 |
| V1 | 原认识开始动摇 | 部分新关系出现，不急着展示全部后层 |
| V2 | 两层同时可见却不完全重合 | 明暗和图形密度共同避免无意义拥堵 |
| V3 | 留下一个不能完全回到起点的关系 | 选择保留哪条线索，而不是自动回到全黑 |

光与图形互相影响：前层过密先减图形，后层太弱也可能调形体与距离，不只提亮。计划状态不是实际演出程序；不得为效果遮挡疏散标志或关闭应急照明。
