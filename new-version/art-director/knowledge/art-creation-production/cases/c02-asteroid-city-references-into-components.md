# 资料事实

Adam Stockhausen 谈到将不同参照汇成建造小镇的具体词汇，并通过强制透视平衡远山观感与实际搭建规模。Robert Yeoman 的访谈说明，预演和摄影需要参与空间准备，包括室内自然光的进入方式。

# 工作启发

参考研究、建造与摄影不是三个互不相干的阶段。一张历史影片的图可以只贡献一种窗的开法；一种远景需要可能通过实际距离、比例与视点共同实现，而不是把景无限做大。

# 自己的练习

为一个虚构街角分别研究开口、轮廓、地面和远景，每个来源只提取一项可操作特征；以纸模型检查从指定视点看去是否同属一个世界，再横移相机看哪些部分失效；把失效范围写进方案。

# 迁移限制

不把采访里的地域、摄影设备或工作习惯当作通用答案；**不把 Yeoman 回忆其他影片（《布达佩斯大饭店》）的服装配色例子误记成《小行星城》的制作事实**。
