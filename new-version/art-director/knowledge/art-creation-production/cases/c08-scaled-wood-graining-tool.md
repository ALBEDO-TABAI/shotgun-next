# 资料事实

Terra Writz 的具名制作说明将玩具剧场的尺度构想与放大木纹的制作联系起来，工具和纹理尺寸共同服务画面。

# 工作启发

不必先用现有工具的默认痕迹填满场景。所需关系可以反向规定工具：一次操作留下多大的形、怎样的节奏、哪些地方需要变化。

# 自己的练习

画三种尺度的抽象纹理，分别放到目标取景里，选定整体关系后才制作小型印具或手绘规则；不用工具便利代替画面判断。

# 迁移限制

不复刻原教程工具结构和粘合剂配方，也不把舞台的放大木纹照搬到超近景产品摄影。
