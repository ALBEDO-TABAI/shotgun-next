# C6 让时间也接受试验

三个节奏草案：连续缓慢变化、一次明确转换、局部先后显露。保持图形不变比较，记录观看者何时意识到第二层、是否只理解成机械切换。太快看不清时可在新关系出现处安排停留；过慢失去参照时保留一条稳定轮廓。没有通用秒数。装置需考虑中途进入，循环结构本身也是创作决定。

# C7 反馈不要求唯一答案

先问“你注意到什么变化”“原先以为是什么，后来有什么不同”，再问感受；记录观看条件与说话者。作者可保留未被解释的关系，但区分**有意歧义**与**技术未完成**——任何观看位置都提前暴露后层而命题依赖逐步发现，是制作问题，不应只说“开放性”。评价可以是观看关系是否发生、材料与人工性如何参与、变化是否值得持续观看，不改写成产品识别效率。

# C8 可能故障与替代路线

- **后层一直可见：** 先查串光和相邻亮面，再测材料与层距；保留必要场地照明下无法控制就改实现，不取消安全条件。
- **只像一盏灯被打开：** 改前后内容的对应，让显露提供新关系。
- **相机移动暴露网纱：** 固定视点、改材质、接受人工痕迹或转合成——回到作品语言决定。
- **混合状态太拥堵：** 先降某一层信息密度，再比较显露顺序；不同时加颜色、音效与粒子掩盖问题。

# C9 完成物与保留限制

命题、内容关系、三条实现路线、已选机制、状态与时间草案、材料试验、观看范围和现场运行要求；实际测试后才注明哪些状态成立。保留“不适用条件”（如仅固定相机已检查、尚未验证公众自由观看）。
