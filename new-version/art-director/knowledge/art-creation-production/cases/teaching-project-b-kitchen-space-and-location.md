# B3 空间草案：先让动作自然发生

- 采用 02 篇教学尺度：宽 4.8 m、深 3.6 m；入口约 (0.5, 0.3)，收纳／操作区约 (1.0, 2.8)，餐桌中心约 (2.4, 1.7)。只表达功能关系，桌椅尺寸、门宽、净高需实测。
- 动作分：进入、取物、端到桌边、停顿、改变安排；每段问：人物是否顺手？关键动作是否被摄影机看见？自然却永远被身体遮住，和便于摄影却很别扭，都要调整。
- 先地面贴位置标记、用安全稳定的现成家具走位；改变桌角或收纳方向比先定满精细橱柜更可逆。

# B4 现成场地与搭建的取舍

- 现成场地若已具备合适入口、操作面和就餐关系，先研究哪些可保留；用保留、移除、替换、遮挡、补充改造；现有磨损不一定要覆盖，现有图案也不一定与角色相符。
- 关键视角被固定墙阻断、动作通路不能成立、持续自然光变化影响核心镜头 → 比较搭建与调整拍法；不是每个限制都靠造景，也不是所有相机要求都能靠拆墙。
- 搭建方案把可移除面、灯光进入、演员通路和道具复位位置一起写入；工程与场地许可另行确认。
