# 四问

1. 效果发生在环境、物体表面还是画外？
2. 是否与产品接触？
3. 是否跨镜头持续？
4. 需要真实物理状态，还是只要可见变化？

回答后才去 [04 画面效果技法卡：二十种从机制、试做、调节到失效诊断的工作路径](/topics/04-effect-technique-cards.md) 选择对应技法，而不是先选最炫的技术。
