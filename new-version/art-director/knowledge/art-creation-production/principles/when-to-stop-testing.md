# 可以提交当前阶段确认

- 已确认关键任务满足
- 运行条件已检查
- 专业阻断项已处理或明确不能进入下一步
- 剩余修改主要是等价偏好交换

# 实用标准

已知未知是否阻断当前使用、谁承接、下一步怎样验证。不把全部未知写成“现场解决”，也不为不影响使用的细节无限延长测试。

# 放弃路线要留原因

“该材料的自由运动与固定显露窗口冲突，已转成固定背景加局部动作片”比“方案 B 不够高级”更能帮助后来人。

# 四种完成范围

概念完成 ≠ 样片完成 ≠ 指定镜头完成 ≠ 工程确认。每次确认只承担其实际证据支持的内容。
