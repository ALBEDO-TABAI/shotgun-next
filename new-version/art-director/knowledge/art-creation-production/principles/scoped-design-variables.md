# 好的写法

- “主产品周边不出现比标签更强的细碎反射”
- “近景必须能看见薄边而不露出支撑”
- “开启后形成一条主褶皱，不要求完全自然随机”

# 规则

- 长度、角度、时长可以测量。
- “看起来像随手扔下”需要保留参考、比较条件和判断者。
- **不要把不能可靠量化的经验伪装成数字，却也不因此拒绝记录。**
