# 保什么

主体近景面、动作件、关键开口与复位通常不能只因不显眼而先删；远处完整背面、无必要视角或重复装饰可以先比较删减。

# 费用拆项

研究／设计、模型与样片、材料与加工、采购租赁、运输、安装、现场运行、拆收与恢复。没有实际报价不写“通常几千就够”；有报价写清数量、范围、有效期和未含项。

# 时间按依赖排

材料未定不全量表面；接口未试不封死；关键镜头未定不做所有背面。并行的是相互不依赖的任务。

# 缩减示范（教学）

香水原案三种完整背景 → 共用底座与主轮廓，只换接触面和前景方向，保留“被发现”关系与精细表面。若核心是空间从封闭变开放，不能删掉活动面后只剩静态产品还声称概念完整。
