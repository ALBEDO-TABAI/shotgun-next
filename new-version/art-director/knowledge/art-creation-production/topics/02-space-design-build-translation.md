# 本篇概览

本篇解决：效果图成立但不知道怎样搭；搭好后机位不够；一改镜头就穿帮；构件各自正确却无法装配；装饰很多但动作不自然。

**主线：** [空间的四个范围：被看见／被使用／摄影与光需要／制作与运行需要](/frameworks/four-space-ranges.md) → [从动作和信息顺序生成平面：先列空间必须允许的事](/methods/action-first-floor-plan.md) → [勘景：先用任务筛场地，记录五组条件](/methods/location-scouting-by-task.md) → [用镜头几何估计搭建边界（含教学算例）](/frameworks/lens-geometry-build-bounds.md) → [镜头包络：把规定镜头姿态下的所有可见边界叠在一起](/frameworks/shot-envelope.md) → [四种空间原型：地面标位／纸模白模／关键一角原大样件／简化数字灰模](/frameworks/four-prototype-levels.md) → [制作转译：先定义基准，再把尺寸分成关键／可调／派生](/methods/datum-and-three-dimension-classes.md) → [安装与表面完成的依赖顺序](/methods/installation-and-finishing-sequence.md) → [拍摄前的空间走查：按镜头一遍，按复位和维修一遍](/checklists/pre-shoot-space-walkthrough.md)。

**使用边界：** 提供设计与制作沟通方法，不签发承重、悬吊、电气或临时结构许可；数字和比例模型验证空间关系，不验证结构安全；示范坐标、尺寸和计算都是教学假设。

# 本篇概念

## 框架 · Framework

* [对场地的五类动作：保留／移除／替换／遮挡／补充](/frameworks/five-site-actions.md) - 不做全面覆盖；每个动作附理由和恢复方式——天花板难看但会反射进瓶盖，不能简单写“不会拍到天花板”。
* [四种空间原型：地面标位／纸模白模／关键一角原大样件／简化数字灰模](/frameworks/four-prototype-levels.md) - 逐级解决空间问题，任何一种原型都不包办全部验证（Houde & Hill 的原型目的区分）：标位查行动、白模查体量与视线、原大样件查近景与接口、灰模查多机位与变更。
* [空间的四个范围：被看见／被使用／摄影与光需要／制作与运行需要](/frameworks/four-space-ranges.md) - 不是造一个世界的所有东西，而是制造规定的观看条件；只满足“被看见的范围”容易得到只能拍一张图的景。
* [空间分层发展：结构与使用→体量→表面与边缘→接口→陈设与图形→状态](/frameworks/layered-space-development.md) - 按层展开但允许依据试验返回；不在每层同时做最细，体量还变时图形用占位；关键近景面层的反射可能反过来改变灯位和开口。
* [用镜头几何估计搭建边界（含教学算例）](/frameworks/lens-geometry-build-bounds.md) - θh = 2·arctan(s/2f)，W(d) ≈ d·s/f；36mm/50mm 时 4m 主体面宽 2.88m、6m 背景面宽 4.32m，平移 ±0.4m 后联合宽 5.12m——主体空间够不代表背板够；公式只作早期预算。
* [在实体、改造、绘景、数字之间选路径](/frameworks/physical-vs-digital-path-selection.md) - 按接触、视差、反射、重复、修改与维护比较，“实拍”与“数字”不是高低排序；生成图帮助构思，但不自动提供一致几何、产品准确性或连续动作。
* [镜头包络：把规定镜头姿态下的所有可见边界叠在一起](/frameworks/shot-envelope.md) - 本包术语（非行业统一文件名）：列最宽、最低、最高、最靠近、最偏侧及移动起止与中间点，合并可见区域，告诉制作哪段墙、背面、地面必须完成；还要看变化速度，“只有几帧”不是默认放行理由。
* [画面图／空间图／制作图：三张图不互相替代](/frameworks/three-drawings.md) - 画面图回答从规定位置看到什么，空间图回答关系怎样在空间中同时成立，制作图回答怎样分件制造并安装；小项目可合一页，但不能取消它们要回答的问题。
* [三种面：直接可见面／间接可见面／运行必要面](/frameworks/three-surface-types.md) - 不简单分“入镜／不入镜”：间接可见面经镜子、玻璃、金属或投影出现；运行必要面不被看见但参与支撑、遮控或使用；不同精度不代表有用／无用。

## 方法 · Method

* [从动作和信息顺序生成平面：先列空间必须允许的事](/methods/action-first-floor-plan.md) - 先列动作不列风格（进入、接近、拿取、转身、放置、停顿、移回），逐步写物理条件、观看条件与受影响的美术；需要局促时让障碍参与动作，但必须是选择而非搭建失误。
* [横竖版不能只看安全框](/methods/aspect-ratio-crop-check.md) - 16:9（36×20.25mm）保持高度裁 9:16 只剩约 11.39mm 宽，删掉大量两侧信息；分别检查关系核心、主体邻近留白、上方压顶、文本区与动作区的争夺，并把可调整范围设计进安装方案。
* [按运输、修改和运行拆件，并从拆分阶段考虑复用](/methods/breakdown-for-transport-and-change.md) - 最可能改变、损坏、接触或受运输限制的部分优先可替换；走一次“从工坊到镜头”路线，同时画拆收后状态；复用不只看这次省材料，不凭材料名宣布更环保或更便宜。
* [制作转译：先定义基准，再把尺寸分成关键／可调／派生](/methods/datum-and-three-dimension-classes.md) - 同一套景统一基准（底面前缘、中心线、上表面或轴线标高），区分净空、外包与材料厚度；关键尺寸影响动作镜头装配，可调尺寸有预设范围，派生尺寸由基准计算；公差按材料与镜头商定。
* [数字场景也需要制造思维](/methods/digital-scene-manufacturing-thinking.md) - 先统一单位、命名、主体比例、相机与遮挡再展开细节；几何、面层、光、动作分开修改；不把材质误差全归底色，检查环境反射、方向性与法线（PBRT 微表面模型）。
* [画清边缘与接缝：五种策略并先试含接缝样件](/methods/edges-and-seams-strategy.md) - 像厚石却露薄板、像金属却露泡沫、背光时接缝成暗线——通常不是补色号能解决；每条重要接缝选择藏在遮挡中、放在合理构造处、设计成视觉语言、做连续表皮或近景单独局部。
* [首件确认：不是每个人各做一块“差不多”](/methods/first-article-confirmation.md) - 扩展重复构件前选一个含关键边缘和接口的首件，记录其与样片、图纸、镜头的对应；之后是同一方法的受控扩展，允许合理差异的区域也写清。
* [安装与表面完成的依赖顺序](/methods/installation-and-finishing-sequence.md) - 先确认关键动作和体量→试装接口→完成不易返修的面层→主要体量进场后预打光→摆动作道具与陈设→走全镜头、全动作与复位；改变顺序时要知道哪些未知被推迟。
* [实拍与数字如何交接](/methods/live-digital-handoff.md) - 明确哪些对象真实接触、哪层可后期替换、哪些反射必须现场保留、镜头参数与版本如何对应；清洁底板、参考光、色彩链路和状态记录服务具体后期需要。
* [勘景：先用任务筛场地，记录五组条件](/methods/location-scouting-by-task.md) - 选址比较的是达到目标需要改变什么，而非外观；记录固定条件、可改部分、现成优势、操作限制、尚未确认，照片带方向和位置参照。
* [先画关系图，再画几何平面](/methods/relationship-diagram-before-geometry.md) - 把门口、操作面、就餐区、藏物区和机位画成点与线：实线需相邻、虚线可看见、断线必须暂时不可见；比较后再决定用墙、转角、家具或前景实现。

## 原则 · Principle

* [相机位置与焦距分开讨论](/principles/camera-position-vs-focal-length.md) - 固定相机换焦距主要改变取景范围；为恢复主体大小而前后移动相机会改变透视。对“更有空间感”不能只交一句“换广角”。
* [每个动作至少检查起点、中间和终点](/principles/check-start-middle-end-states.md) - 门开关都好看不代表开门过程不撞摄影机，软片闭合展开都漂亮不代表中间不拉动产品；要补对角、跨越、遮挡转移等最易出问题的中间状态。
* [场地备选是另一条完成核心镜头的方法](/principles/executable-backup-location.md) - 备选不是另一张漂亮照片：主方案用真实窗边，备选可以是可控棚内窗口光；主方案依赖长通路，备选可以分成两个明确镜头；比较保留的表达与新增工作，不未经报价宣称更便宜。
* [给不可失去的关系做标记](/principles/mark-non-negotiable-relations.md) - 如包覆装置的三个核心关系：产品与运动片分离、最终瓶体可见、主褶皱不压顶；换面层、背板或裁切时都复查这三项；不锁死所有尺寸，也不让“灵活调整”变成随意改关系。
* [资源压缩时保住设计而不平均缩水](/principles/resource-cuts-protect-core-relations.md) - 先分“决定核心关系的支出”与“可替代的实现”；主体近景面、动作件、关键开口与复位通常不能先删；费用拆项、不写未报价金额；时间按依赖排；不能删掉活动面还声称概念完整。
* [2.5D 分层平面的适用边界](/principles/two-point-five-d-boundary.md) - 固定或受控小幅机位可用分层平面；侧移产生视差、旋转露薄边、交互要求接触和阴影；升级时先把最易穿帮的关键层变为体量，不必一次做满三维。

## 检查清单 · Checklist

* [预打光时美术要看什么](/checklists/pre-light-art-department-check.md) - 不只等摄影说“灯好了”：检查接缝暴露、面层失色、透明层后方泄露、人物或产品改变反射、开门转身出现新穿帮面；相机监看与现场观察各有用途。
* [拍摄前的空间走查：按镜头一遍，按复位和维修一遍](/checklists/pre-shoot-space-walkthrough.md) - 记录问题位于哪个构件、姿态、状态；用三句判断完成度：需要的能否被看见、需要发生的能否发生、发生后能否恢复或进入下一状态；安全另行确认。
* [空间模块的完成物](/checklists/space-module-completion.md) - 可以是简洁图表也可以是完整图包，但至少让制作方知道制造什么、摄影方知道怎样观看、现场知道如何改变与恢复；任何一方仍需猜关键尺寸、接口或状态时补最直接的信息。

## 模板 · Template

* [构件说明卡（PF-03 香水前方运动片示范）](/templates/component-spec-card-pf03.md) - 部件／作用／定位／可见面／接口／可替换／待确认／不能据此做的事——把制造者真正需要回答的问题聚在一起；不是采购单，也不是效果描述。
* [最小勘景记录](/templates/minimum-location-scout-record.md) - 净尺寸与高度、进出与运输、光与反射、使用与保护、声音与邻接、后场与运行六项，每项写记录方式与为什么会改变方案；电气、消防、结构由专业人员确认。
