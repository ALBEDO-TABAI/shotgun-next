# 主题枢纽 · Topics

每篇源文档（01—07）一个枢纽，列出该篇全部概念与主线。

# 01 需求转译与方案生成
* [01 需求转译与方案生成：从含混语言到有机制差异、可继续制作的视觉方案](01-requirement-translation-ideation.md) - 需求含混、参考多却想不出方案、提案只是换颜色、客户反复说“感觉不对”时的入口；交付需求译文、冲突取舍、研究材料、机制候选、选中路线、视觉命题与首项原型任务。

# 02 空间设计与搭建转译
* [02 空间设计与搭建转译：把画面意图变成能拍、能用、能安装和修改的空间](02-space-design-build-translation.md) - 效果图成立却不知怎样搭、机位不够、改镜头就穿帮、构件无法装配、装饰多动作不自然时的入口；交付动作与可见性、勘景记录、空间草案、镜头包络、关键尺寸与接口、拆件安装、数字／实体边界。

# 03 材料、置景与道具制作
* [03 材料、置景与道具制作：从材质名称到形体、面层、行为、经历和复位](03-materials-set-props.md) - 东西像塑料玩具、做旧平均而假、布上色后不能动、道具好看不好用、备用件无法连戏、小样无法放大时的入口；交付材料任务书、候选路径、分层样片、边缘接缝、制作步骤、陈设系统、道具状态与备用策略。

# 04 画面效果技法卡
* [04 画面效果技法卡：二十种从机制、试做、调节到失效诊断的工作路径](04-effect-technique-cards.md) - 只会写“水光、梦幻、发光、悬浮”、照参考搭了不成立、静帧漂亮一动就穿帮时的入口；每张卡给适用、起始布置、试做顺序、调节变量、失效分支；另含五种组合与入库格式。

# 05 测试、现场优化与回修
* [05 测试、现场优化与回修：从“这版不够好”到定位、改变、验证](05-testing-onset-optimization-revision.md) - 建立可在样片、工坊、棚内、场地和数字制作中使用的试验与回修方法：四种测试、基准、色彩链路、单变量与组合试验、区组与重复、四种判定、诊断树、故障表、回归、验收边界、反馈与停止条件。

# 06 真实案例与完整教学推演
* [06 真实制作案例与完整教学推演：看清方法怎样贯穿一个项目](06-real-cases-teaching-projects.md) - 八则真实制作案例（寄生虫、小行星城、RSC 移动床与石地、Tim Walker、云状地布、丝绸、放大木纹工具）按资料事实／启发／练习／限制拆解；三个原创教学项目（香水、餐厨、显隐）演示需求到交付的完整链条。

# 07 skill 拆解与生产模板
* [07 skill 拆解与生产模板：让知识持续产出方案、试验、制作交接与有效修改](07-skill-breakdown-production-templates.md) - 把前六篇收成可执行的能力规范与生产模板：最低行为定义、七模块职责、入口路由、分阶段输入、四种证据身份、当前依据、可转写执行规范、十张带示范的模板、变更贯穿示范、十八项反例测试与学习路径。
