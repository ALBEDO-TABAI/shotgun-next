# 本篇概览

本篇任务：把前六篇知识收成可执行的能力规范与生产模板；提供可转写为 skill 的正文和测试用例，**不声称已安装、部署或在任何生成平台完成验证**。

**设计原则：** 创作要有主动方案，制作要能继续执行，优化要有局部对象；文档只服务于画、做、买、摆、拍、复位与确认。

**入口：** [入口路由：先判断用户现在卡在哪里（六种情形）](/skills/entry-routing-six-situations.md) → [美术创作与制作 skill 执行规范（可直接转写）](/skills/art-production-execution-spec.md) → 十张模板 → [十八个反例测试总览：怎样判断这项 skill 真有用](/checklists/skill-behavior-tests-overview.md)。

# 本篇概念

## 框架 · Framework

* [四种证据身份：输入事实／方案假设／实际观察／确认决定](/frameworks/four-evidence-identities.md) - 避免方案、结果和批准混在一起；“已测试”与“已确认”不是同一条状态阶梯；每个关键对象分别写当前选择、依据、验证范围、确认范围、待办，不压成一个模糊绿灯。
* [输入信息：必须现在知道的，与可以之后验证的（按阶段）](/frameworks/input-information-by-stage.md) - 构想前、制作前、测试前、交付前各有关键信息；暂缺时可以提出假设但说明哪种回答会改路线；尺寸未确认不输出伪精确施工数据；审批与技术验证分别记录。
* [七个模块各自负责什么、在哪儿停止、交给谁](/frameworks/seven-modules-responsibilities.md) - 01 需求与构想到 07 操作与交接各有真正执行的动作、最小产出与承接者；模块不是七个必须串行运行的代理，小项目可一次完成多个，已有合适场景时不必从概念重来。

## 方法 · Method

* [一个变更贯穿示范：新增 16:9 横版，哪些要改、哪些不动](/methods/change-propagation-new-landscape-version.md) - 【教学设定】先确认新增版本是否沿用时长、动作与包装显露要求；核查 PF02 边界、PF03 开口、PF05 反射新增区域；原片不够的区域不能假装已实拍；只更新受影响构件、镜头与测试；包装变更的依赖路径不同。
* [最少但足够的当前依据：借 PROV 的关系思想让结果能回溯](/methods/minimum-current-basis-provenance.md) - 一页当前项目说明（版本、任务、核心关系、选中路线、构件入口、试验入口、未定项、下一动作）；尺寸以构件说明为依据、材料效果以样片为依据、动作以状态与试拍为依据，其他地方引用不抄写；不为结构漂亮生成空编号。

## 原则 · Principle

* [“会做美术”以可观察的工作定义，而不是角色人设](/principles/art-competence-as-observable-behavior.md) - 六种最低行为：原话转可讨论关系、给出机制不同的路线、展开为需制作的对象、为关键未知选试验、依证据局部修改、把当前决定准确交给下一位；AI 能规划不等于已做，能力边界要反映在产物状态而非结尾免责声明。
* [最后一条规则：输出应该让下一步真的发生](/principles/output-must-make-next-step-happen.md) - 好产出让接收者能回答现在要画哪种关系、做哪块样片、摆哪几个对象、验证哪个动作，什么已确定、什么不能擅自决定；模型不能用越来越长的文本替代真实空间、材料、设备、操作者与反馈。

## 检查清单 · Checklist

* [反例测试组四：动作与道具](/checklists/skill-behavior-tests-action-props.md) - 景可看但演员动作别扭→应改行动与可见关系，不应只增加陈设；同款备用件造成不同动作→应核对行为和状态，不应只看外观同款即通过
* [反例测试组二：图像、证据与未实施的结果](/checklists/skill-behavior-tests-images-evidence.md) - 用户给一张生成图要求开工→应提取已知，补空间／动作／尺寸验证，不应宣布已可施工；只有静帧却问运动是否可用→应限定证据，设计全程测试，不应编造中间镜头；金属不好看但无实拍→应有条件的诊断顺序，不应断言某个灯位就是原因；没有真实试验数据→应明确计划，保留结果空缺，不应写成功率或“已测试通过”
* [反例测试组三：材料与试验设计](/checklists/skill-behavior-tests-materials-experiments.md) - 材料 A 在一种光下失败→应判断是否需组合测试，不应永久淘汰 A 且不看目标条件；表干就要用于重复动作→应按产品体系确认状态、试样，不应一概声称已达使用性能；最后面层破坏效果→应与保留基准比较、定位该层，不应全部重新上色掩盖原因
* [反例测试组六：非商业作品与来源诚实](/checklists/skill-behavior-tests-noncommercial-sources.md) - 非商业要求不稳定→应讨论有意歧义与可控变化，不应强迫所有人读出唯一信息；引用付费课程介绍→应仅使用公开说明，不应声称掌握整门付费课程
* [十八个反例测试总览：怎样判断这项 skill 真有用](/checklists/skill-behavior-tests-overview.md) - 18 项行为验收按六组组织（需求与构想、图像与证据、材料与试验、动作与道具、版本成本批准交付、非商业与来源）；不是给艺术好坏打分，实现后应把输入、输出、失败原因与修订保存为测试记录；本包尚未执行平台级测试。
* [反例测试组一：需求与构想](/checklists/skill-behavior-tests-requirement-ideation.md) - 只说高级自然→应多种解释与机制候选、第一试验，不应一串同义风格词；三个方案仅换颜色→应指出机制相同，提出关系级变化，不应包装成三大创意；概念已批准，只问材料→应材料行为、样片与替代路线，不应重新讲完整艺术史
* [反例测试组五：版本、成本、批准与交付](/checklists/skill-behavior-tests-versions-delivery.md) - 新增横版→应查可见范围与关联对象，不应硬裁或无理由重开全案；没有供应商报价→应列成本项目和需询价对象，不应虚构精确预算；概念批准、工程未确认→应区分批准范围，保留阻断，不应把美术认可当安全许可；两份“最终版”相互矛盾→应找当前依据并解决消费关系，不应让下游自行猜测和重判

## 模板 · Template

* [模板一｜需求转译与第一项试验](/templates/t01-requirement-translation-first-test.md) - 项目与交付、原话与来源、作品任务、不可更改条件、当前与另一种体验解释、拟转成的关系、会改变路线的问题、可先采用的假设、第一项可逆试验、下一位使用者需作的决定。
* [模板二｜机制路线与取舍](/templates/t02-mechanism-route-tradeoff.md) - 路线名称、视觉命题、主体与事件、空间材料如何参与、关键画面或状态、与其他路线的本质区别、必须保留的关系、可替换实现、最早可能推翻路线的未知、第一项试验与选案依据。
* [模板三｜镜头—空间—构件交接](/templates/t03-shot-space-component-handoff.md) - 镜头标识与版本、画面让人知道什么、起中终与停留、相机主体关系、必须可见与暂时不可见、直接和反射可见构件、动作与维护空间、材料图形后期接口、极端视点与裁切、当前依据与承接方。
* [模板四｜构件、面层与运行说明](/templates/t04-component-surface-operation.md) - 构件版本与镜头、外观与行为任务、尺寸单位基准与未测项、结构可见体量面层与可替换、边缘接缝背面间接可见面、材料候选与样片入口、连接运动接口、安装操作复位拆收、检查条件与实际状态。
* [模板五｜材料与效果试验单](/templates/t05-material-effect-test-sheet.md) - 试验问题与类型、对应材料构件镜头版本、候选变量与组合、基准与保持条件、样片与动作步骤、拍摄显示条件、观察重点与不接受情况、实际结果入口（未实施保留）、解释与适用范围、下一动作与影响对象。
* [模板六｜道具状态与复位](/templates/t06-prop-state-and-reset.md) - 道具使用者镜头、开始状态、动作中改变、结束状态、复位步骤与位置参照、使用或清洁后可能变化、主体件动作件备用件的必要差异、实际检查与待确认项。
* [模板七｜局部回修与回归范围](/templates/t07-local-revision-regression-scope.md) - 当前基准版本与证据、问题位置时点、与哪项已确认要求冲突、原因候选与先排除什么、保持不变的关系、第一项与备选修改、比较方法与复查镜头、实际结果与是否采纳、受影响的下游入口。
* [模板八｜实体、数字与后期的效果分工](/templates/t08-physical-digital-post-division.md) - 效果与画面作用、必须真实接触遮挡反射的关系、实体负责对象、数字负责对象、需共同保持的相机空间时间条件、需采集的基准与干净背景、输入解释创意预览与输出要求、缺口验证方法与负责方。
* [模板九｜完成交接与仍未完成的事项](/templates/t09-completion-handoff-open-items.md) - 项目与版本、交付类型（概念／待制作／指定范围已验证）、已批准对象与范围、实际验证对象条件与证据、制作使用入口、不能据此推定完成的事项、阻断与非阻断待办、下一动作承接方与唯一依据。
* [模板十｜经验条目与来源卡](/templates/t10-experience-entry-source-card.md) - 当前问题与情境、资料事实／本次方案／实际结果分列、有效关系或操作、原材料尺度镜头使用条件、失败与改动、允许迁移的部分、不适用条件与需重测部分、来源版本与证据入口；经验库可含未验证创意但要保留身份。
