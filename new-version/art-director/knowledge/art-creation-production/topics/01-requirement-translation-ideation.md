# 本篇概览

本篇解决：需求说得含混、参考很多却想不出方案、提案只是在换颜色、客户不断说“感觉不对”。交付：需求译文、冲突取舍、研究材料、机制候选、选中路线、视觉命题、首项原型任务。

**主线：** [三种任务：作品任务／视觉任务／生产任务](/frameworks/three-task-layers.md) → [原话中的六种信息：任务／硬条件／感受目标／形式偏好／实现建议／未验证判断](/frameworks/six-information-kinds.md) → [形容词转译链：原话 → 经验候选 → 关系／事件 → 可调变量 → 最早验证](/methods/adjective-translation-chain.md) → [八种构想操作盘](/frameworks/eight-ideation-operations.md) → [组合盘与四个检验：避免随机拼贴](/methods/combination-board-four-checks.md) → [可执行概念的五种规则：比例／材料／空间／时间／例外](/frameworks/five-concept-rules.md) → [选案：避免虚假综合分，也避免只说个人偏好](/principles/route-selection-without-composite-score.md) → [从概念到下一模块的最小交付（一页）](/templates/minimum-handoff-concept-to-next-module.md)。

**内容身份：** 带来源的段落是外部研究或一手实践（S01—S07、S11—S12），其后操作方法是本包应用整合；案例 A 亲近的香水、B 第二套餐具、C 可见性改变、D 植物精华均为教学设定。

# 本篇概念

## 框架 · Framework

* [八种构想操作盘](/frameworks/eight-ideation-operations.md) - 关系替换、尺度转换、功能错置、动作移交、时间化、界面化、材料反转、删除与缺席；由本包针对美术任务编订，Design Heuristics 提供方法背景但非其卡组翻译。
* [可执行概念的五种规则：比例／材料／空间／时间／例外](/frameworks/five-concept-rules.md) - 一句命题要逐步产生五种约束；只写下游最容易误判、却会改变概念的关系——比“所有画面米色”更有迁移能力。
* [四条研究线：关系／行为／材料／世界](/frameworks/four-research-lines.md) - 研究收集能够生成方案的材料而非完整成片：关系研究交付可迁移规则，行为研究交付起止与复位，材料研究交付实际光与运动中的表现，世界研究交付使用习惯与物件经历。
* [道具进入方案前要明确它的工作](/frameworks/prop-work-roles.md) - 道具可承担行动、空间分割、尺度锚点、环境证据、光学作用或信息；不给每个词配一个道具，一个结构可同时承担多个抽象目标。
* [原话中的六种信息：任务／硬条件／感受目标／形式偏好／实现建议／未验证判断](/frameworks/six-information-kinds.md) - 分辨原话性质再进入工作：硬条件先保证，感受目标提出多个机制，实现建议问它想获得什么性质，未验证判断标为假设。
* [三种入口：只有感觉／已有概念缺执行／已有试拍要改好](/frameworks/three-entry-points.md) - 按用户实际位置决定先做什么、暂时不做什么，不让每个用户都重新填 brief；创意能力也包括知道哪些决定无需重开。
* [三种任务：作品任务／视觉任务／生产任务](/frameworks/three-task-layers.md) - 一个项目同时存在作品为什么存在、观众要经历什么、团队必须制造什么条件三种任务；三者要连接，但不能用“拍出高级感”一句包办。
* [一个词的多路翻译表（轻／清爽／科学／生命力／亲密／珍贵）](/frameworks/word-multi-translation-table.md) - 同一形容词可对应不同经验与视觉机制，各有可调变量与最早检查点；这是生成候选的设计工具，不是心理学定律，必须允许反例。

## 方法 · Method

* [形容词转译链：原话 → 经验候选 → 关系／事件 → 可调变量 → 最早验证](/methods/adjective-translation-chain.md) - 中间必须有一层“人会怎样看、怎样接近或理解”；直接把温暖翻成橙色、天然翻成叶子会得到同质化搭配。
* [问题与方案共同演变：用尝试纠正问题](/methods/co-evolution-problem-solution.md) - 提出一个小方案后记录它使原问题发生了什么变化，以可见问题说明为何修正解释（如“全场蓝绿色”暴露包装失去区分）。
* [组合盘与四个检验：避免随机拼贴](/methods/combination-board-four-checks.md) - 按观看方式—事件—空间—材料行为—现实约定各写少量候选，只组合能相互解释的选项；组合后检验能否画最小场景、说明前后变化、删元素知损失、找到第一项试验。
* [用一项会改变决定的测试，而不是全面精修](/methods/decision-changing-test.md) - 争议在“有无亲近感”就比较可触碰尺度与纪念碑尺度的简化版；争议在“能否搭”就先做构件或动作样件；不用草图喜好回答材料能否反复使用。
* [防固着检查：旧失败、旧好评与单一道具](/methods/fixation-check.md) - 固着与客户、团队、经历和设计活动条件有关；检查是否把一次失败升级为永久禁令、因某图获赞而拒绝测试，可用“不用那件关键道具还能否保持关系”或换媒介草图练习。
* [动作移交：把变化从物体转给光、镜头或观看者](/methods/ideation-action-handover.md) - “产品被发现”可由遮挡物移动、镜头绕过遮挡或只改变光完成；写三条具体实现，各有起始状态与新出现的信息，再比较节奏、空间与复位。
* [删除与缺席：让不出现的东西起作用](/methods/ideation-deletion-absence.md) - 拿掉最显眼的对象看是否留下可读关系（产品离开后的凹痕、人物离开后的使用位置）；关键是缺席怎样被知道，而非“东西少”。
* [功能错置：让熟悉东西承担新的工作](/methods/ideation-function-displacement.md) - 椅子不再供人坐而成为展示光影的框架；要说明被保留的可识别特征与被改变的功能，过度改造会让功能冲突消失。
* [界面化：把感受变成边界的行为](/methods/ideation-interfacing.md) - 保护可以是阻隔也可以是柔性跟随，疏离可以是透明但无法接近；先做两层纸片关系，再决定玻璃、纱、织物还是数字层。
* [材料反转：让外观与行为形成差异](/methods/ideation-material-inversion.md) - 看似坚硬的面轻微弯曲、看似软的布保留精准轮廓；需问差异能否被镜头看到、是否值得制作代价、是否违反使用条件，不以安全风险和复杂机关证明创意。
* [关系替换：不换物件，换它们如何相处](/methods/ideation-relation-substitution.md) - 保留产品与一张纸，分别试承托、遮挡、记录轮廓、从旁离开；先画接触、支撑和空隙再评价形式。
* [尺度转换：先选不可变的尺度锚点](/methods/ideation-scale-shift.md) - 把成分或纹理放大成环境时保留已知大小的参照（产品正常、叶片成为屋顶）；所有东西一起变大观众未必感到尺度异常。
* [时间化：为画面补“之前一分钟”和“之后一分钟”](/methods/ideation-temporalization.md) - 从前史与后果中选只需当前物件状态就能提示的变化（印迹、空缺、未完成的折叠），不给所有物件编符号。
* [材料驱动构想：让一个材料行为成为概念入口](/methods/material-driven-ideation.md) - MDD 把材料理解、体验愿景、体验模式与概念发展连接；不要等概念完成才选材——揉皱后难复原的薄片启发“痕迹”，迅速复原的启发“恢复”。
* [并行原型：候选以相近完成度出现](/methods/parallel-prototyping-equal-fidelity.md) - 避免第一张精美图锁定讨论；每案给同样数量的关键画面、同样清楚的动作、同样坦诚的风险，否则评审混入表达投入差异。
* [保存原话：原句旁写暂时解释、依据与可试操作](/methods/preserve-original-words.md) - 第一份工作记录不把原话清洗成设计师喜欢的词；解释错误时可以回到真实需求，而不是在层层转述之间争论。
* [优先澄清会改变路线的三类问题](/methods/prioritize-route-changing-questions.md) - 优先处理作品用途与观看条件、不可牺牲的关系、不可逆投入的前提；其他未知可以带假设继续推进，并用可判断的选择题向需求方提问。
* [用范围和时点化解伪冲突；真冲突公开取舍](/methods/resolve-pseudo-conflicts.md) - 先问冲突是否发生在同一对象、同一时点、同一画面尺度；“神秘”与“产品清楚”可分时成立，真正冲突则公开牺牲项，不推给现场和后期。
* [明确方案的失效条件](/methods/route-failure-conditions.md) - 一条路线应允许被放弃：写明“什么结果出现时改变路线”（如所有可用材料都无法支持指定动作与复位、机位持续暴露有限视点错觉），比无期限“再优化一下”更有生产力。
* [搜索语句从形容词转向问题](/methods/search-queries-as-questions.md) - 用机制型检索词（如 scenic painting translucent backlit／透光绘景 前后绘制），优先读作者、制作机构与技术文档，并分离可观察机制与营销、摘要与验证范围、访谈与未公开数据。
* [接手已有方案：三类标记与“最小重述”](/methods/taking-over-existing-scheme.md) - 先标记已明确认可的意图、尚未验证的实现、仅由参考图暗示的细节，只补缺口；用“我保留 X 和 Y，接下来只解决 Z”重述；原方案有结构矛盾时指出具体冲突与可保留关系。
* [从静态名词改成动词：先写动词，再选物件](/methods/verbs-before-nouns.md) - “花、石头、玻璃”只提供元素，“穿过、托住、遮住、留下、聚拢、分开”提供组织；动词还要补足主语、对象与结果，否则会成为新的空词。

## 原则 · Principle

* [画面效果要能用普通话说明机制](/principles/effect-mechanism-plain-language.md) - “薄雾”“水光”“发光”不是完成的效果方案；写清效果发生在哪、是否与产品接触、是否跨镜头持续、需要真实物理状态还是可见变化，才能去选技法。
* [选案：避免虚假综合分，也避免只说个人偏好](/principles/route-selection-without-composite-score.md) - 先过不可协商条件，再比较核心任务、视觉独特性、制作前提与可逆性；安全阻断不能被创意分抵消，未报价成本不能精确排序；用条件式选择句表述。
* [抽象目标要成为有范围的设计变量，不伪装成数字](/principles/scoped-design-variables.md) - 不用“高级度 8/10”；写“主产品周边不出现比标签更强的细碎反射”这类可执行关系；可测量的量化，观察式的保留参考、比较条件和判断者。
* [方案三张图用途必须不同：起始条件／核心事件／结束关系](/principles/three-images-different-purposes.md) - 不要用同一构图换三个颜色冒充方案发展；每张图旁写一条生产问题；效果图仍是设计表达，不是测试结果。
* [何时停止搜集：剩余未知只能靠试验回答时就开始试](/principles/when-to-stop-researching.md) - 现有资料已能产生可比较机制、剩余未知只能靠当前材料或场地试验回答时开始试；但涉及真实文化、年代和生活方式时不能以个人想象替代必要研究。

## 检查清单 · Checklist

* [需求转译与方案生成的自检与完成边界](/checklists/requirement-translation-self-check.md) - 合格结果能让另一位设计者复述核心关系、画出最低限度场景、提出首项原型并知道哪些可变；只能让对方继续搜“梦幻高级自然”说明转译未完成。

## 模板 · Template

* [从概念到下一模块的最小交付（一页）](/templates/minimum-handoff-concept-to-next-module.md) - 原需求及当前解释、一个核心命题、关键画面与事件、两三个不可失去的关系、允许替换的实现、首先需要验证的问题；交给空间与材料者的是关系而非形容词。
* [参考条目格式：来源对象／借用／不借／当前迁移／待试](/templates/reference-entry-format.md) - 合格参考条目比“很有质感，值得参考”多出下一项工作；版权与资产使用资格另行核对，研究用途不赋予成片复制权。

## 练习 · Exercise

* [构想常见卡点与针对性练习](/exercises/ideation-stuck-points.md) - 只能想到熟悉元素、每案像同一张图、方案空泛、参考越多越乱、一直推翻方向、不知何时结束——各有一次具体练习与“有用”的判断标准；卡在哪用哪，保留失败样例。

## 教学设定 · Teaching Scenario

* [教学任务 D：植物精华——从六个种子收敛到两条路线](/cases/teaching-d-plant-essence-six-seeds.md) - 【虚构教学设定】“清晰而不医疗化，天然但不要森林”：六个种子经三轮（排除功效暗示、合并同机制、保留机制差异）收敛为空间序列与材料展开两案，各做黑白关系图与一项样片。
* [需求转译会议示范：“像艺术品，离生活有点远，但别变成浴室”](/cases/teaching-requirement-translation-meeting.md) - 【虚构教学对话】美术译文→两项只改一个关系的小试→反馈“能摸到但不要手印”→删除实现、不删目标→进入制作；变化发生在可追踪的解释与实现层。
