# 方法 · Methods

可执行的步骤与流程：转译链、构想操作、动作先行平面、勘景、基准与尺寸、拆件、兼容检查、陈设四轮、做旧、试验设计、回归检查、变更贯穿等。

# 01 需求转译与方案生成
* [形容词转译链：原话 → 经验候选 → 关系／事件 → 可调变量 → 最早验证](adjective-translation-chain.md) - 中间必须有一层“人会怎样看、怎样接近或理解”；直接把温暖翻成橙色、天然翻成叶子会得到同质化搭配。
* [问题与方案共同演变：用尝试纠正问题](co-evolution-problem-solution.md) - 提出一个小方案后记录它使原问题发生了什么变化，以可见问题说明为何修正解释（如“全场蓝绿色”暴露包装失去区分）。
* [组合盘与四个检验：避免随机拼贴](combination-board-four-checks.md) - 按观看方式—事件—空间—材料行为—现实约定各写少量候选，只组合能相互解释的选项；组合后检验能否画最小场景、说明前后变化、删元素知损失、找到第一项试验。
* [用一项会改变决定的测试，而不是全面精修](decision-changing-test.md) - 争议在“有无亲近感”就比较可触碰尺度与纪念碑尺度的简化版；争议在“能否搭”就先做构件或动作样件；不用草图喜好回答材料能否反复使用。
* [防固着检查：旧失败、旧好评与单一道具](fixation-check.md) - 固着与客户、团队、经历和设计活动条件有关；检查是否把一次失败升级为永久禁令、因某图获赞而拒绝测试，可用“不用那件关键道具还能否保持关系”或换媒介草图练习。
* [动作移交：把变化从物体转给光、镜头或观看者](ideation-action-handover.md) - “产品被发现”可由遮挡物移动、镜头绕过遮挡或只改变光完成；写三条具体实现，各有起始状态与新出现的信息，再比较节奏、空间与复位。
* [删除与缺席：让不出现的东西起作用](ideation-deletion-absence.md) - 拿掉最显眼的对象看是否留下可读关系（产品离开后的凹痕、人物离开后的使用位置）；关键是缺席怎样被知道，而非“东西少”。
* [功能错置：让熟悉东西承担新的工作](ideation-function-displacement.md) - 椅子不再供人坐而成为展示光影的框架；要说明被保留的可识别特征与被改变的功能，过度改造会让功能冲突消失。
* [界面化：把感受变成边界的行为](ideation-interfacing.md) - 保护可以是阻隔也可以是柔性跟随，疏离可以是透明但无法接近；先做两层纸片关系，再决定玻璃、纱、织物还是数字层。
* [材料反转：让外观与行为形成差异](ideation-material-inversion.md) - 看似坚硬的面轻微弯曲、看似软的布保留精准轮廓；需问差异能否被镜头看到、是否值得制作代价、是否违反使用条件，不以安全风险和复杂机关证明创意。
* [关系替换：不换物件，换它们如何相处](ideation-relation-substitution.md) - 保留产品与一张纸，分别试承托、遮挡、记录轮廓、从旁离开；先画接触、支撑和空隙再评价形式。
* [尺度转换：先选不可变的尺度锚点](ideation-scale-shift.md) - 把成分或纹理放大成环境时保留已知大小的参照（产品正常、叶片成为屋顶）；所有东西一起变大观众未必感到尺度异常。
* [时间化：为画面补“之前一分钟”和“之后一分钟”](ideation-temporalization.md) - 从前史与后果中选只需当前物件状态就能提示的变化（印迹、空缺、未完成的折叠），不给所有物件编符号。
* [材料驱动构想：让一个材料行为成为概念入口](material-driven-ideation.md) - MDD 把材料理解、体验愿景、体验模式与概念发展连接；不要等概念完成才选材——揉皱后难复原的薄片启发“痕迹”，迅速复原的启发“恢复”。
* [并行原型：候选以相近完成度出现](parallel-prototyping-equal-fidelity.md) - 避免第一张精美图锁定讨论；每案给同样数量的关键画面、同样清楚的动作、同样坦诚的风险，否则评审混入表达投入差异。
* [保存原话：原句旁写暂时解释、依据与可试操作](preserve-original-words.md) - 第一份工作记录不把原话清洗成设计师喜欢的词；解释错误时可以回到真实需求，而不是在层层转述之间争论。
* [优先澄清会改变路线的三类问题](prioritize-route-changing-questions.md) - 优先处理作品用途与观看条件、不可牺牲的关系、不可逆投入的前提；其他未知可以带假设继续推进，并用可判断的选择题向需求方提问。
* [用范围和时点化解伪冲突；真冲突公开取舍](resolve-pseudo-conflicts.md) - 先问冲突是否发生在同一对象、同一时点、同一画面尺度；“神秘”与“产品清楚”可分时成立，真正冲突则公开牺牲项，不推给现场和后期。
* [明确方案的失效条件](route-failure-conditions.md) - 一条路线应允许被放弃：写明“什么结果出现时改变路线”（如所有可用材料都无法支持指定动作与复位、机位持续暴露有限视点错觉），比无期限“再优化一下”更有生产力。
* [搜索语句从形容词转向问题](search-queries-as-questions.md) - 用机制型检索词（如 scenic painting translucent backlit／透光绘景 前后绘制），优先读作者、制作机构与技术文档，并分离可观察机制与营销、摘要与验证范围、访谈与未公开数据。
* [接手已有方案：三类标记与“最小重述”](taking-over-existing-scheme.md) - 先标记已明确认可的意图、尚未验证的实现、仅由参考图暗示的细节，只补缺口；用“我保留 X 和 Y，接下来只解决 Z”重述；原方案有结构矛盾时指出具体冲突与可保留关系。
* [从静态名词改成动词：先写动词，再选物件](verbs-before-nouns.md) - “花、石头、玻璃”只提供元素，“穿过、托住、遮住、留下、聚拢、分开”提供组织；动词还要补足主语、对象与结果，否则会成为新的空词。

# 02 空间设计与搭建转译
* [从动作和信息顺序生成平面：先列空间必须允许的事](action-first-floor-plan.md) - 先列动作不列风格（进入、接近、拿取、转身、放置、停顿、移回），逐步写物理条件、观看条件与受影响的美术；需要局促时让障碍参与动作，但必须是选择而非搭建失误。
* [横竖版不能只看安全框](aspect-ratio-crop-check.md) - 16:9（36×20.25mm）保持高度裁 9:16 只剩约 11.39mm 宽，删掉大量两侧信息；分别检查关系核心、主体邻近留白、上方压顶、文本区与动作区的争夺，并把可调整范围设计进安装方案。
* [按运输、修改和运行拆件，并从拆分阶段考虑复用](breakdown-for-transport-and-change.md) - 最可能改变、损坏、接触或受运输限制的部分优先可替换；走一次“从工坊到镜头”路线，同时画拆收后状态；复用不只看这次省材料，不凭材料名宣布更环保或更便宜。
* [制作转译：先定义基准，再把尺寸分成关键／可调／派生](datum-and-three-dimension-classes.md) - 同一套景统一基准（底面前缘、中心线、上表面或轴线标高），区分净空、外包与材料厚度；关键尺寸影响动作镜头装配，可调尺寸有预设范围，派生尺寸由基准计算；公差按材料与镜头商定。
* [数字场景也需要制造思维](digital-scene-manufacturing-thinking.md) - 先统一单位、命名、主体比例、相机与遮挡再展开细节；几何、面层、光、动作分开修改；不把材质误差全归底色，检查环境反射、方向性与法线（PBRT 微表面模型）。
* [画清边缘与接缝：五种策略并先试含接缝样件](edges-and-seams-strategy.md) - 像厚石却露薄板、像金属却露泡沫、背光时接缝成暗线——通常不是补色号能解决；每条重要接缝选择藏在遮挡中、放在合理构造处、设计成视觉语言、做连续表皮或近景单独局部。
* [首件确认：不是每个人各做一块“差不多”](first-article-confirmation.md) - 扩展重复构件前选一个含关键边缘和接口的首件，记录其与样片、图纸、镜头的对应；之后是同一方法的受控扩展，允许合理差异的区域也写清。
* [安装与表面完成的依赖顺序](installation-and-finishing-sequence.md) - 先确认关键动作和体量→试装接口→完成不易返修的面层→主要体量进场后预打光→摆动作道具与陈设→走全镜头、全动作与复位；改变顺序时要知道哪些未知被推迟。
* [实拍与数字如何交接](live-digital-handoff.md) - 明确哪些对象真实接触、哪层可后期替换、哪些反射必须现场保留、镜头参数与版本如何对应；清洁底板、参考光、色彩链路和状态记录服务具体后期需要。
* [勘景：先用任务筛场地，记录五组条件](location-scouting-by-task.md) - 选址比较的是达到目标需要改变什么，而非外观；记录固定条件、可改部分、现成优势、操作限制、尚未确认，照片带方向和位置参照。
* [先画关系图，再画几何平面](relationship-diagram-before-geometry.md) - 把门口、操作面、就餐区、藏物区和机位画成点与线：实线需相邻、虚线可看见、断线必须暂时不可见；比较后再决定用墙、转角、家具或前景实现。

# 03 材料、置景与道具制作
* [做旧：先画经历的因果，再决定痕迹](aging-by-causal-history.md) - 关键物经历简写为制造—获得—使用—维护—改变—当下，只写影响可见状态的事件；按原因选痕迹并检查是否成立；先做低对比版本再在目标镜头加必要信息。
* [小样比较必须包含目标观看条件](compare-under-target-viewing.md) - 在最近使用镜头查边缘与纹理、最远镜头查大关系、动作过程中查反射与状态；准备一个普通对照，避免越看越夸张；先探索后定样。
* [布料上色后要重测动作](fabric-painting-retest-motion.md) - 上色、定形、保护可能改变刚度和恢复；保留未处理对照，比较不同覆盖范围而非只比颜色；图像必须精细区与需要自由运动区可分开，结果由当前样件判断。
* [仿钢表面：底层、覆盖与方向分开测试（三块对照）](faux-steel-surface-task.md) - 同一平整基底做均匀金属色、深底薄金属层、深底薄层加方向性三块，比较完整角度变化；需要真实镜面倒影时比较实际反射材料或数字；写清“金属感”的接受范围。
* [纸与薄片：用折线控制形，不必一味模拟织物](paper-and-thin-sheet-forms.md) - 纸建立精确转折与恢复规则，薄片形成连续曲面，织物有下垂与细褶；同尺寸做自由放置、局部支撑与开合比较，不以材料名预判哪种更高级；纸边不合适时可设计成语言或只升级关键部分。
* [铜绿／旧金属：分布需要原因](patina-old-metal-task.md) - 先画结构、雨水或接触的候选路径，再分配沉积、高点与露底；用绘景层次而非化学腐蚀；像迷彩降低无理由块状反差，像绿漆检查是否掩盖金属关系。
* [过程阶梯样片：A 基底→B 底层→C 大变化→D 细节→E 最终表层](process-ladder-sample.md) - 同一基底分区或同类小板逐级加层，问题出现时可追溯在哪一步发生；样片背面写材料、批次、顺序、层间状态和日期，影像记录相机、光、距离与显示处理。
* [复位步骤要能被另一人执行](prop-reset-procedure.md) - 以杯子为例：确认清空或补到指定状态、恢复朝向落点与接触痕迹、检查边缘污迹与反射、与复位照片对照；位置参照按精度与表面条件选择，不破坏正式包装或租赁物。
* [从小样到大面积：放大的是方法，不只是尺寸](scale-up-sample-to-large-area.md) - 先分大区、设置接续方式，再做含接续边的大样；固定总体色域与主方向、可见纹理尺度、目标光下的完成关系；工作站按状态分区；维修准备替换面层、样片与记录。
* [陈设四轮：骨架→行动物→信息密度→经历](set-dressing-four-rounds.md) - 陈设不是家具目录加“有故事的小物”，先决定这里发生哪些活动；每轮从规定机位和使用者位置各检查一次。
* [石感表面：轮廓、断面与纹理层次相互支持](stone-surface-task.md) - 先问是平整石板、自然断面还是粗糙体量；石感不只来自随机黑点，大形转折、颗粒、色差区与边缘厚度共同参与；接触或支撑时视觉外壳与使用条件分别确认。
* [三项先做的兼容小检查：基底与面层附着／层间相容／处理后承受实际动作](three-compatibility-checks.md) - 用供应方建议的方法检查剥离划伤，不在正式主体上做破坏测试；关注起泡、返溶、变色、分离；刚柔组合看弯折位置，透明片胶痕会成为光学信息。
* [木感表面：先判断是板、切面、纹理还是使用经历](wood-surface-task.md) - 先确定一块“板”的边界再组织纹理流向，不无理由镜像重复；练习路径由板块方向到光泽逐步检查；近景需要真实纹理深度时比较实材／贴面；Writz 的夸张木纹属于玩具剧场尺度。

# 05 测试、现场优化与回修
* [区组、顺序与重复：让制作差异不被环境差异掩盖](blocking-order-repetition.md) - 借用 NIST 区组设计思想：同一时段内同时包含 A、B 再在另一时段复比；用中性编号与变换顺序减少“升级版”暗示；说清重复了什么（重播≠重复动作≠拆装重建）；少量结果不支持成功率。
* [颜色不对时先查链路，再决定重刷](color-chain-troubleshooting.md) - 颜色问题可能发生在物体、照明、摄影、处理与观看；先核样片与批准对象、同光同机位比较、再查输入解释与显示路径，最后才物理修改；ACES 区分输入／Look／输出，但不要求所有项目采用 ACES。
* [获取反馈，而不逼对方说出想听的答案](eliciting-feedback.md) - 先问先看见什么、何处变化被注意、何时认出产品／空间，再请对方用自己的语言描述感受并记录观看条件；区分项目确认者、专业同事与目标观看者；非商业作品不要求唯一解释；保存分歧比平均分有用。
* [修改后的回归检查：只复查受影响的链，不全案重审](regression-check-affected-chain.md) - 改一块材料先查它本身外观与动作，再查邻接、阴影、反射、接触和跨镜头状态；变更单写“受影响的消费方”；按依赖关系而非修改面积决定复查范围；保留旧版比较但只有一个当前批准依据。
* [单变量试验：适合局部定位，不是全部优化的唯一方法](single-variable-test-and-limits.md) - 问题可隔离时（如保护层是否导致过亮）比较同批次同基底同阶段的有无样片，固定光与拍摄；但单因素法无法揭示交互作用（NIST），要警惕在一种光下淘汰材料却从未在目标光下看过。
* [哪个试验先做：看后果、牵连与可逆性](test-priority-ordering.md) - 判断错误会不会换掉核心事件、会不会推翻空间或多人接口、能否便宜局部替换；次序为可发生性→最难观看条件→跨环节组合→运行与收尾；不算虚假风险系数，工程风险另由专业评价。
* [把问题写成能被证据回答的句子：对象、条件、改变、观察、决策](testable-question-sentence.md) - 弱问题“是不是更高级”→可测试问题“最终近景中 A、B 哪种表面让瓶体边缘清楚且背景不出抢眼亮斑”；观察项写可定位的事，并写明“这次不判断什么”。
* [四格组合试验：把材料与光放在一起比较](two-by-two-factorial-test.md) - 【本包设计的试验，未获数据】面层 A1/A2 × 照明 B1/B2 做全部四种组合；先按列比材料、按行比光，若最优材料随光改变则不能脱离照明回答；不算总分，按约束顺序选择；四格全不成立时检查变量范围或目标冲突。

# 06 真实案例与完整教学推演
* [从案例变成自己的案例库：提取较窄的条件性条目](build-own-case-library.md) - 每个实际项目完成后提取“在什么条件下，哪种关系由哪种实现支撑；如何试验；出现了什么；保留与改变什么”；记录材料、尺度、镜头、动作与替代代价，否则结论会退化为僵硬套路；真实案例与教学案例互补但不能混成全部拍过的作品集。
* [怎样读一个制作案例，才不会只收获风格词](how-to-read-a-production-case.md) - 分开五件事：原项目具体问题、资料记录的解决路径、保留与替换了什么、当前还不知道什么、怎样设计自己的试验；过程未知就保留未知；迁移操作而不复制物件；每则案例区分资料事实、工作启发与练习。

# 07 skill 拆解与生产模板
