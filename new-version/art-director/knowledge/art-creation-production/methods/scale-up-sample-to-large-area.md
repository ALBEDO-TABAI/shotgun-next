# 放大

小样易一次完成，正式面需多人、不同时间和工具。先分大区、设接续方式，再做一块含接续边的大样。不把偶然漂亮的笔触作为全量要求却不提供可重复方法。

# 先固定三个东西

1. 总体色域和主要方向
2. 可见纹理尺度
3. 完成面在目标光下的关系

局部自然变化可保留；图形、标识和叙事关键痕迹需精确记录。

# 工作站

未处理／处理中／待稳定／已确认／返修件分开；工具与样片对应当前工艺；上一批剩余混合物未经确认不用于新批次；临时替换写入工艺记录并决定是否重新定样。

# 维修不是最后补一瓶漆

准备关键面层替换、样片参照、可辨识材料和操作记录。局部补色造成明显边界时可能需修整个视觉区域，但不必报废整个结构。
