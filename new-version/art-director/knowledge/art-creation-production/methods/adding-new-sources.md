# 步骤

1. **先问它补什么决策。** 教程可补“为什么近景边缘失败”；论文可补“怎样安排有解释力的比较”；直接访谈可补“某项目为什么选择这条路径”。不因作者著名就占据正文。
2. **记录六项：** 原文链接、作者、实际阅读范围、关键论点、适用条件、本项目准备怎样试。
3. **试验之后再链接真实结果。** 未验证内容可以保存为候选，但必须与已运行经验分开。
4. **不收录**第三方图片、原论文全文、付费课件或字体文件；只做重新组织的说明与原创应用方法。
