# 拆件原则

看似连续的空间可由底座、外皮、边缘条、活动面、图形贴层和遮控件组成；最可能改变、损坏、接触或运输受限的部分优先设计为可替换。

# 从工坊到镜头走一遍

部件怎样经过门、拐角或升降设备；进入后怎样暂存；谁先安装；哪些面装好后再也接触不到；何时上色或接线；拆开能否不破坏最终面。运输车装得下不等于能进场地。

# 拆收后的状态

卷收面层检查开裂或粘连；叠放构件不压易损纹理；返租物件改造必须可恢复。

# 复用

难分离的复合表皮可能制作快，却使修补、分类与再利用困难；比较通用骨架配可换面层、局部定制配租赁主体等路径，纳入运输、储存、维修和重新安装条件。Theatre Green Book 强调通用地面、景片与建筑部件复用；本包不据此报告未经计算的减碳量。
