# 推荐依赖

1. 确认关键动作和体量
2. 试装接口
3. 试装通过后完成不易返修的面层
4. 主要体量进场后预打光
5. 摆动作道具与陈设
6. 走全镜头、全动作与复位

不是固定工期表：面层决定主要反射时可先在局部体量预打光；场地不能久占时可先在工坊做关键角测试。但每次改变顺序都应知道哪些未知被推迟，不能无意识把风险留到现场。
