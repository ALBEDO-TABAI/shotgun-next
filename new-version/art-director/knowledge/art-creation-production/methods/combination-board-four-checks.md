# 五列组合盘

观看方式 — 事件 — 空间 — 材料行为 — 现实约定

- 连续的组合：“被发现—展开—近身小空间—褶皱恢复—日常尺度”。
- 刺激词堆积：“宏大城市—微距皮肤—随机碎裂—实验室器皿”未必是融合。

# 四个检验

1. 能否画出最小场景？
2. 能否说明变化之前与之后？
3. 能否删去一个元素而知道损失？
4. 能否找到第一项可执行试验？

答不出来就不要先给方案起诗意名称。
