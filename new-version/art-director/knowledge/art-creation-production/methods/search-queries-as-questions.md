# 示例检索

| 英文 | 中文 |
|---|---|
| scenic painting translucent backlit | 透光绘景 前后绘制 |
| set design movable wall camera blocking | 布景 可拆墙 机位 |
| painted fabric flexibility prototype | 柔性面层 涂层 开裂 |
| product photography reflection control | 反光包装 反射控制 |

# 读取时的分离

- 供应商教程：分离“可观察机制”和产品营销。
- 论文：区分摘要、方法和验证范围。
- 主创访谈：不补出采访没有公开的尺寸、成本和意图。

搜索词是入口，不是正确性保证。
