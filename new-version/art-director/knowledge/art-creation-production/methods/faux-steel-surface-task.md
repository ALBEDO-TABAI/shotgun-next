# 三块对照

1. 均匀金属色
2. 深底 + 薄金属层
3. 深底 + 薄层 + 方向性

比较完整角度变化，不只挑某个恰好很亮的角度。Powers 的工艺记录支持底层和方向处理思路，具体比例属于其材料体系。

需要真实镜面时，仿金属涂层未必提供足够倒影，应比较实际反射材料或数字实现。接受的“金属感”写范围：远景、固定视点、中景动作，还是产品近景。
