# 区组

A 上午由甲制作、B 下午由乙制作、在不同自然光下拍——差别混入材料、操作者、干燥时间和光。更好：同一制作／拍摄时段中都包含 A、B，并在另一时段再次比较；每组保留同一基准。借用思想，不把小型美术练习包装成统计实验。

# 观看顺序

每次先看“旧版”再看“升级版”容易混入版本暗示。改用中性编号、变换顺序，先记录看见什么再讨论倾向（减少提示，不保证消除偏差）。

# 重复要说清重复了什么

| 重复 | 检查 |
|---|---|
| 同一条素材反复播放 | 只帮助观察，不增加独立制作证据 |
| 同一设置重复动作 | 短时间运行与复位 |
| 拆掉再装、换操作者或更换备用件后运行 | 转移与重建 |

不随口规定“必须拍五遍”；未测试到的条件写成限制。少量结果不支持精确成功率，也不支持“一直不会出问题”。
