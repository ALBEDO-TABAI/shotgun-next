# 转译链

> **原话 → 所指经验的候选 → 关系／事件 → 可调变量 → 最早的验证。**

- 一个词应有多路翻译（见 [一个词的多路翻译表（轻／清爽／科学／生命力／亲密／珍贵）](/frameworks/word-multi-translation-table.md)）。
- 从名词改成动词（见 [从静态名词改成动词：先写动词，再选物件](/methods/verbs-before-nouns.md)）。
- 变量要有范围，不伪装成分数（见 [抽象目标要成为有范围的设计变量，不伪装成数字](/principles/scoped-design-variables.md)）。

# 常见错误

跳过“经验”这一层，把形容词直接映射为颜色、物件或材质：温暖→橙色、天然→叶子、科学→实验器皿堆砌。
