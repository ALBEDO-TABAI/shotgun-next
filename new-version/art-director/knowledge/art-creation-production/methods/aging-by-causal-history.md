# 经历链

制造 — 获得 — 使用 — 维护 — 改变 — 当下（只写确实影响可见状态的事件）

| 原因 | 候选痕迹 | 检查问题 |
|---|---|---|
| 手反复接触 | 局部颜色、光泽或平整变化 | 使用者实际会摸那里吗 |
| 物件移动 | 方向性擦痕、碰触区域 | 运动方向与家具布局一致吗 |
| 液体经过 | 沿重力与边界的差异 | 来源、停积和清理关系是否成立 |
| 长期遮挡 | 暴露区与被盖区差异 | 原遮挡物在哪里、是否需要被知道 |
| 修补 | 局部新旧不一致 | 修补方式符合设定的资源与工具吗 |
| 精心照料 | 大面整洁、少量难去变化 | 是否误做成全新展厅或全场污迹 |

“历史很久”不要求所有痕迹都强烈。先做低对比版本；只有放大截图才看见而作品不需要近景时，也许无需继续强化。
