# 练习 · Exercises

低风险桌面练习、构想卡点练习与学习路径。

# 01 需求转译与方案生成
* [构想常见卡点与针对性练习](ideation-stuck-points.md) - 只能想到熟悉元素、每案像同一张图、方案空泛、参考越多越乱、一直推翻方向、不知何时结束——各有一次具体练习与“有用”的判断标准；卡在哪用哪，保留失败样例。

# 05 测试、现场优化与回修
* [练习 A：一次局部诊断](exercise-a-single-local-diagnosis.md) - 用非承重桌面物件与明暗卡建立基准，只移动一张卡记录物体哪部分改变；学会把环境变化对应到外观。
* [练习 B：四格表面—光试验](exercise-b-four-cell-surface-light.md) - 用已知适合日常使用的纸或成品面材、两种表面×两个可恢复光向拍四格，写出材料选择是否依赖光；未出现明显差异也如实记录。
* [练习 C：复位不是重播](exercise-c-reset-is-not-replay.md) - 用纸片设计开启—停留—复位；一次在原设置下重复、一次拆开后恢复，比较两种重复并修改定位与操作说明；桌面方法不能扩展成大型装置。

# 07 skill 拆解与生产模板
* [学习与熟练度：一个物件、一个面层、一个动作起步](learning-progression-one-object-one-surface-one-action.md) - 初学者用 01 提出关系、03/04 做低风险小样、05 记录真实结果——链条完整胜过写无法开始的大型世界观；进阶为同一主体三条件（静态近景、完整动作、另一比例）；复杂练习才加入现成场地、多人与混合实拍；模板按消费需要压缩或拆分。
