# 适用

包覆、发现、舒展、展开、被整理或被触碰的视觉事件。材料体验研究提示行为也参与意义；这里的控制方法是本包应用。

# 起始布置

画主褶皱方向，分固定轮廓区、真实运动区和产品接触区；产品支持尽量不由会被拉动的材料承担；实际结构需根据使用确认。

# 试做顺序

用少量材料完成一条主动作 → 标起点与停点 → 拍完整过程 → 恢复再做 → 加入近景面层 → 检查反射中的控制点。只有动作成立后才扩大背景面积。

# 调节变量

材料刚度、余量、控制点、重力方向、行程、速度和停点。

# 失效分支

像被扯坏→减少同时运动的部分并改善主方向；每次不一样→改局部固定与可换片；产品被拖动→分离支撑；软感消失→检查处理层或过多控制点；需要自由随机→重新定义允许变化范围，不把随机与严格复位同时列为无条件目标。

> 身份：资料支持机制或前例；试验与诊断顺序为本包整合，未声称本次已实拍验证。不能替代安全、材料兼容和实际相机测试。
