# 适用

受控机位下的深度、图形化世界或舞台化场景，不必每个元素都做完整体量。

# 起始布置

先只用三层：前景边界、主体活动层、背景；每层写清要遮住什么、何时让出什么；不从大量装饰层开始。

# 试做顺序

固定视点看三层关系 → 逐渐加入计划移动 → 检查边缘露薄、层间空洞和投影 → 决定哪些局部升级为体量。数字预演可辅助，但比例和运动应与目标镜头一致。

# 调节变量

层距、轮廓、偏移、可见边、画幅、光方向与移动幅度。

# 失效分支

像三张贴纸→检查轮廓是否只是平行叠加、有无有效遮挡；移动后断裂→减少幅度或补关键几何；投影暴露层距→改照明或让其成为主动形式；演员需要穿过→重新设计入口和动作，不用背景层假装可使用空间。

> 身份：资料支持机制或前例；试验与诊断顺序为本包整合，未声称本次已实拍验证。不能替代安全、材料兼容和实际相机测试。
