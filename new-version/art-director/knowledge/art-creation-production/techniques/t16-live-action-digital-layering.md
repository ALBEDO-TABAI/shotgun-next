# 适用

局部实物能提供接触和表面，但环境、遮挡或特殊变化适合后期完成。核心是确定哪些关系必须一起获得，哪些可以分开。

# 起始布置

按主体、接触、阴影、反射、透明／遮挡、背景和时间分别列职责；明确每层实际需要什么素材；不笼统写“产品实拍，其余后期”，尤其当产品反射整个环境时。

# 试做顺序

拍或渲染最小组合 → 检查接触和运动 → 按后期需求补干净底板与参照 → 保存相机、灯光、主体状态和色彩链路 → 低成本阶段完成一次合成验证。ACES 的输入／Look／输出区分有助于记录观看链路，但不要求项目必须采用 ACES。

# 调节变量

拆层边界、真实接触范围、反射策略、画幅、相机与动作可重复性。

# 失效分支

像贴上去→先查接触、反射、遮挡和时序；边缘全靠模糊→检查素材条件；运动无法对齐→重估是否适合分拍；生成图改变产品→回到受控主体资产。缺素材不凭一句“后期能修”消除。

> 身份：资料支持机制或前例；试验与诊断顺序为本包整合，未声称本次已实拍验证。不能替代安全、材料兼容和实际相机测试。
