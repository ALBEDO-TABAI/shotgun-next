# 适用

需要过滤、包覆、隔层或空间深度。透明、半透明、局部遮盖应分别设计，它们对背景信息和反射的处理不同。

# 起始布置

单层、少图形、背景简单；先看材料本身与边缘，再比较两层紧邻与有距离；连接区域必须进入样片。

# 试做顺序

拍空景、单层、双层 → 逐个改变层距 → 改变光方向 → 加入主体和动作。把“透过看到的背景”与“表面反射的环境”分别记录。

# 调节变量

层数、间距、角度、厚度、局部遮盖、背景密度、光的方向。需要边缘不需要细纹时不无条件加磨砂；需要看清后层时不靠更复杂背景补层次。

# 失效分支

显浑浊→先减到单层基准；双影或接缝→辨明来自厚度、连接还是叠层；运动中露支撑→改连接位置、限制视点或升级关键层。替代路线：局部实体与受控合成，但接触、折射及遮挡要重新分工。
