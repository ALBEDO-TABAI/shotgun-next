# 规则

先指定主机制，再让辅助技法解决它留下的问题；两个机制争夺同一空间、光或时点时必须先处理冲突。

# 本组合

- 纱幕：通过两个空间的可见性变化；前后绘景：通过同一载体的图像与透光变化。
- 先单独验证，避免不知道问题来自图层还是串光。
- 没有清楚观看理由时，不必使用两个显隐系统。
