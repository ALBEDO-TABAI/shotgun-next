# 适用

需要流动的光纹或波动联想，但作品不要求真实水面和液体接触。本卡是基于反射关系的应用练习，不声称干式纹理等同真实水的全部光学现象。

# 起始布置

在经确认的工作空间中使用适合手工的小型反射纹理面，将受控光投向背景而非人员眼睛或相机敏感路径；使用稳定器具，不徒手操作尖锐金属薄片；先从简单静态反射开始。

# 试做顺序

找一块可读亮纹 → 小幅改变反射面姿态 → 拍实际速度 → 放入主体 → 限制效果是否经过标签。无必要不引入液体和湿区；真实液体镜头另做专业管理与重复性设计。

# 调节变量

表面形状、光的方向与相对大小、受影距离、运动幅度、速度和作用区域。

# 失效分支

像闪烁而非流动→降低变化频率、建立连续方向；只像杂乱亮点→简化纹理；主体被吞→分区或分时；与真实水面同框却不相容→改真实光学路径或明确抽象语言。需要准确焦散时用适当物理／数字实现并验证。
