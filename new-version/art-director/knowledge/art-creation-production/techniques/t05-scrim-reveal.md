# 适用

同一现场中从一层图像转入另一层、让空场显露形象、保留两个无法完全合一的空间。ShowTex 说明了纱幕反射与透射、前后光和环境杂光的关系；本卡不把这类效果称为真正的全息。

# 起始布置

前层、纱幕、后层分区；先只放少量轮廓；照明能分别控制层次，保持必要安全照明，把不可控环境光视为既有条件。

# 试做顺序

分别试前层主导、后层主导、两层并存 → 观察每个状态漏出的内容 → 试过渡 → 加入目标镜头和运动。不要等整张纱幕画完才发现网纹或串光不适合。

# 调节变量

网纱颜色与结构、前后光分配、背景反射、图像密度、观看角度和焦点。越透明不一定越适合投影，越能显图也不一定能隐藏后景。

# 失效分支

后层始终可见→检查串光和后景反射；纱幕始终像一层布→检查自身受光和内容密度；出现纹样干扰→换实际采样条件测试；只有亮度变化没有意义→回到前后内容关系。条件不适合则改景或改合成路径。

> 身份：资料支持机制或前例；试验与诊断顺序为本包整合，未声称本次已实拍验证。不能替代安全、材料兼容和实际相机测试。
