# 适用

同一图像从白天转入夜景，或局部纹理在背光后出现，而不需要真实移动整套场景。Scheving 相关制作说明提供前后绘制与透光区域的前例。

# 起始布置

选符合用途的透光基底，先做小范围，明确遮光、透光或只需弱变化的区域；前后信息画在同一定位系统里。

# 试做顺序

简单形状测前光、背光与混合 → 逐步增加覆盖并检查 → 做含边、接缝和固定点的样件 → 加入正式图像。覆盖使透光关系消失时，不只靠加大背光补救。

# 调节变量

前后层遮盖程度、位置、色彩、图形尺度、基底均匀性和照明分区。

# 失效分支

背光一开全变白→可能缺局部信息或前后对照；变化脏乱→先减图层；接缝显黑→重新规划分件和透光连续性；正面像普通画布而目标是深空间→与局部实体结合。不复制案例涂料次数为标准。

> 身份：资料支持机制或前例；试验与诊断顺序为本包整合，未声称本次已实拍验证。不能替代安全、材料兼容和实际相机测试。
