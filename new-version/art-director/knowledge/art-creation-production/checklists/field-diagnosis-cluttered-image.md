# 从现象出发，不从整套风格推倒

1. 划出主要信息区域：主体附近、动作经过处、必须保留的空场。
2. 暂时减少其中一项干扰，重新看完整观看顺序。
3. 不同问题需不同减法：颜色冲突不一定靠删物解决，动作冲突不一定靠静态构图解决。
4. 每个物件都声称承担一种抽象价值 → 回到 01 的概念关系；把“丰富”分配给某一区域或阶段，而非同时铺满全部空间。
