- [ ] 另一位设计者能复述核心关系
- [ ] 能画出最低限度场景
- [ ] 提出了首项原型
- [ ] 知道哪些部分允许变动
- [ ] 概念确认没有被写成制作通过
- [ ] 没有以研究量代替试验
- [ ] 艺术判断保留了创造者与需求方的选择权

若交付只能让对方继续搜“梦幻高级自然”，转译仍未完成。
