# 六种工作

行动、空间分割、尺度锚点、环境证据、光学作用、信息。

# 反例

“自然、精确、温暖”→ 植物、量杯、蜡烛同时加入，不一定相互支持。可以让一个有方向的柔性结构同时承担生长与精确控制，只在接触细节上体现温暖。
