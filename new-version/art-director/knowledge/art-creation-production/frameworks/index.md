# 框架 · Frameworks

概念区分、分层模型与分类表：三种任务、六种信息、八种构想操作、四个空间范围、镜头包络、材料任务、表面五层、四种测试、四种证据身份等。

# 01 需求转译与方案生成
* [八种构想操作盘](eight-ideation-operations.md) - 关系替换、尺度转换、功能错置、动作移交、时间化、界面化、材料反转、删除与缺席；由本包针对美术任务编订，Design Heuristics 提供方法背景但非其卡组翻译。
* [可执行概念的五种规则：比例／材料／空间／时间／例外](five-concept-rules.md) - 一句命题要逐步产生五种约束；只写下游最容易误判、却会改变概念的关系——比“所有画面米色”更有迁移能力。
* [四条研究线：关系／行为／材料／世界](four-research-lines.md) - 研究收集能够生成方案的材料而非完整成片：关系研究交付可迁移规则，行为研究交付起止与复位，材料研究交付实际光与运动中的表现，世界研究交付使用习惯与物件经历。
* [道具进入方案前要明确它的工作](prop-work-roles.md) - 道具可承担行动、空间分割、尺度锚点、环境证据、光学作用或信息；不给每个词配一个道具，一个结构可同时承担多个抽象目标。
* [原话中的六种信息：任务／硬条件／感受目标／形式偏好／实现建议／未验证判断](six-information-kinds.md) - 分辨原话性质再进入工作：硬条件先保证，感受目标提出多个机制，实现建议问它想获得什么性质，未验证判断标为假设。
* [三种入口：只有感觉／已有概念缺执行／已有试拍要改好](three-entry-points.md) - 按用户实际位置决定先做什么、暂时不做什么，不让每个用户都重新填 brief；创意能力也包括知道哪些决定无需重开。
* [三种任务：作品任务／视觉任务／生产任务](three-task-layers.md) - 一个项目同时存在作品为什么存在、观众要经历什么、团队必须制造什么条件三种任务；三者要连接，但不能用“拍出高级感”一句包办。
* [一个词的多路翻译表（轻／清爽／科学／生命力／亲密／珍贵）](word-multi-translation-table.md) - 同一形容词可对应不同经验与视觉机制，各有可调变量与最早检查点；这是生成候选的设计工具，不是心理学定律，必须允许反例。

# 02 空间设计与搭建转译
* [对场地的五类动作：保留／移除／替换／遮挡／补充](five-site-actions.md) - 不做全面覆盖；每个动作附理由和恢复方式——天花板难看但会反射进瓶盖，不能简单写“不会拍到天花板”。
* [四种空间原型：地面标位／纸模白模／关键一角原大样件／简化数字灰模](four-prototype-levels.md) - 逐级解决空间问题，任何一种原型都不包办全部验证（Houde & Hill 的原型目的区分）：标位查行动、白模查体量与视线、原大样件查近景与接口、灰模查多机位与变更。
* [空间的四个范围：被看见／被使用／摄影与光需要／制作与运行需要](four-space-ranges.md) - 不是造一个世界的所有东西，而是制造规定的观看条件；只满足“被看见的范围”容易得到只能拍一张图的景。
* [空间分层发展：结构与使用→体量→表面与边缘→接口→陈设与图形→状态](layered-space-development.md) - 按层展开但允许依据试验返回；不在每层同时做最细，体量还变时图形用占位；关键近景面层的反射可能反过来改变灯位和开口。
* [用镜头几何估计搭建边界（含教学算例）](lens-geometry-build-bounds.md) - θh = 2·arctan(s/2f)，W(d) ≈ d·s/f；36mm/50mm 时 4m 主体面宽 2.88m、6m 背景面宽 4.32m，平移 ±0.4m 后联合宽 5.12m——主体空间够不代表背板够；公式只作早期预算。
* [在实体、改造、绘景、数字之间选路径](physical-vs-digital-path-selection.md) - 按接触、视差、反射、重复、修改与维护比较，“实拍”与“数字”不是高低排序；生成图帮助构思，但不自动提供一致几何、产品准确性或连续动作。
* [镜头包络：把规定镜头姿态下的所有可见边界叠在一起](shot-envelope.md) - 本包术语（非行业统一文件名）：列最宽、最低、最高、最靠近、最偏侧及移动起止与中间点，合并可见区域，告诉制作哪段墙、背面、地面必须完成；还要看变化速度，“只有几帧”不是默认放行理由。
* [画面图／空间图／制作图：三张图不互相替代](three-drawings.md) - 画面图回答从规定位置看到什么，空间图回答关系怎样在空间中同时成立，制作图回答怎样分件制造并安装；小项目可合一页，但不能取消它们要回答的问题。
* [三种面：直接可见面／间接可见面／运行必要面](three-surface-types.md) - 不简单分“入镜／不入镜”：间接可见面经镜子、玻璃、金属或投影出现；运行必要面不被看见但参与支撑、遮控或使用；不同精度不代表有用／无用。

# 03 材料、置景与道具制作
* [五种材料实现路径：现成物／局部改造／通用骨架加面层／定制形体／数字或分层合成](five-implementation-paths.md) - 选材是多目标取舍而非档次排序；各路径有优先条件与需特别检查的项；不以“定制最多”证明美术工作最多。
* [表面制作的五层工作：基底／基色／大变化／细节／最终表面](five-surface-layers.md) - 工作分解而非要求真实涂五遍；基底问题不靠面漆，基色负责大关系不负责所有材质，大变化要有尺度与分布，最终层不是免检动作。
* [先做形体再做皮肤：四种形体策略](four-form-strategies.md) - 实体空壳与支撑分离、板片分层、可控软形、现成物作为结构或母体；非承重小样做法不能直接放大到人体尺度。
* [四类小样：材料片／工艺片／接口片／行为片](four-sample-types.md) - 小样要回答问题而非收集色卡；最常遗漏的是接口片——画面暴露的往往是薄板边、拼接、转角和支撑；只测中心面不能声称全部成立。
* [图形道具：从故事世界中的制造者出发的六个问题](graphic-props-six-questions.md) - 谁做、给谁用、用什么工具、有什么时间与技能、如何复制、怎样保存（由 Annie Atkins 的公开说明转化）；先做信息结构再做风格，按实际尺寸与镜头打样，同一世界要有生产差异。
* [材料任务四方面：看起来怎样／行为怎样／怎样制造／运行中遇到什么](material-task-four-aspects.md) - “石头、金属、玻璃”还不是材料任务；先写需要保留的性质再选实材、改造、外壳、绘景或数字；真实材料是条件时照办，但不默认真实总是最佳。
* [道具的四个状态：拍摄前／动作中／动作后／复位后](prop-four-states.md) - 道具不是采购到就完成的资产，而是被动作使用的对象；每个状态写轮廓、朝向、数量、内容物、表面、关键操作和允许变化。

# 05 测试、现场优化与回修
* [从试拍到可用：验收应覆盖的五种边界](acceptance-boundaries.md) - 观看边界、时间边界、操作边界、处理边界、专业边界；一个角度通过不代表其他角度，开头结尾截图不代表中间状态，画面验收不替代安全；艺术目标与运行目标分列。
* [四种测试：探索／诊断／适用性／运行——不共用一个“通过”](four-test-types.md) - 探索找可能、诊断找原因、适用性确认能否满足具体镜头动作交付、运行检查重复复位搬运安装；开始前先写“这次是在找可能性、找原因，还是确认能用”。
* [试验判定的四种结果：满足当前条件／局部可用／不满足／证据不足](four-test-verdicts.md) - 判定不是只有通过或失败，每种结果都带下一动作与条件范围；“不喜欢”记为具体观看者偏好而非结构失败；艺术作品中的陌生不悦可能是任务一部分。

# 06 真实案例与完整教学推演
* [横向比较：同一方法在香水、叙事餐厨、非商业显隐中必须变化的地方](three-projects-cross-comparison.md) - 先保留什么、场景由什么生成、材料主要任务、最先测试什么、不应采用的捷径、完成不能只看什么——三项目答案各异；相同流程词不代表相同答案。

# 07 skill 拆解与生产模板
* [四种证据身份：输入事实／方案假设／实际观察／确认决定](four-evidence-identities.md) - 避免方案、结果和批准混在一起；“已测试”与“已确认”不是同一条状态阶梯；每个关键对象分别写当前选择、依据、验证范围、确认范围、待办，不压成一个模糊绿灯。
* [输入信息：必须现在知道的，与可以之后验证的（按阶段）](input-information-by-stage.md) - 构想前、制作前、测试前、交付前各有关键信息；暂缺时可以提出假设但说明哪种回答会改路线；尺寸未确认不输出伪精确施工数据；审批与技术验证分别记录。
* [七个模块各自负责什么、在哪儿停止、交给谁](seven-modules-responsibilities.md) - 01 需求与构想到 07 操作与交接各有真正执行的动作、最小产出与承接者；模块不是七个必须串行运行的代理，小项目可一次完成多个，已有合适场景时不必从概念重来。
