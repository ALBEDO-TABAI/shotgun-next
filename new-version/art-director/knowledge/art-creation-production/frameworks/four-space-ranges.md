# 四个范围

1. 被看见的范围
2. 被人物或物体使用的范围
3. 摄影机与光需要的范围
4. 制作与运行需要的范围

# 为什么

故事里连续的一间房可能分成两个搭建区；镜头里有深度的山可能是有限视点的体量；镜头外的空地可能承担反射控制、人员通路和复位，不能因不入镜就删掉。
