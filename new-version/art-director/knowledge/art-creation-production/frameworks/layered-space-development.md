| 层 | 决定 |
|---|---|
| 结构与使用条件 | 哪些部位承托、接触、移动 |
| 体量 | 围合、比例与开口 |
| 表面与边缘 | 材料被怎样看见 |
| 活动与维护接口 | 能否安装、调节和修复 |
| 陈设与图形 | 环境信息 |
| 状态 | 前后镜头的连续 |

- 体量还在变时，图形先用占位；动作未通过时，精细涂层只做关键样片。
- 关键近景面层的反射可能反过来改变灯位和开口，应及时返回而非坚持线性流程。
