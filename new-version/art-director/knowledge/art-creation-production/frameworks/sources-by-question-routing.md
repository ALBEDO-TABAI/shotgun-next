| 实际问题 | 优先来源 | 本包转成什么工作 |
|---|---|---|
| 需求模糊、发散停不下来或过早锁定 | S01—S07 | 解释候选、机制路线、同等完成度比较与材料试验 |
| 有图但不知道怎么造、怎样配合摄影 | S08—S12、S16—S18、S31 | 动作先行、镜头范围、构件、样片与生产接口 |
| 材料名称正确但外观或行为不成立 | S19—S27、S32、S42—S44 | 分层试样、兼容、边缘、柔性、尺度与完成后复测 |
| 包装、刻痕或反射难看 | S28—S32 | 主体—视角—反射环境的实拍试验 |
| 显隐、透光、动态表面如何做 | S21、S23、S27、S33 | 分层、分区、完整状态与替代实现 |
| 每次修改只靠口味、说不清原因 | S04、S34—S38 | 分开测试目的、组合比较、干扰因素与查看链路 |
| 图形不像故事世界中的物件 | S13—S14 | 制作者、工具、纸面、使用与复位 |
| 交接和版本越记越乱 | S11—S12、S39 | 明确产出与消费者，保留单一当前依据 |
| 复用和专业安全被放到最后 | S40—S41 | 拆装、保存与专业确认进入制作计划 |

全部来源镜像见 [references](/references/)。
