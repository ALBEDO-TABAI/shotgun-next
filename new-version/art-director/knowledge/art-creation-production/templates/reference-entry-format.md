# 格式

```text
来源对象：
借用：
不借：
当前迁移：
待试：
```

# 示范

- **来源对象：** 某件衣物的折叠过程。
- **借用：** 从多条散乱方向收敛为一条主线的动作。
- **不借：** 颜色、服装类型和人物身份。
- **当前迁移：** 让产品前景的软片从遮挡转为一条引导线。
- **待试：** 实际材料能否用少量控制点完成，而不是每次重新揉出褶皱。

# 边界

版权与资产使用资格另外核对；研究用途不自动赋予成片复制权。
