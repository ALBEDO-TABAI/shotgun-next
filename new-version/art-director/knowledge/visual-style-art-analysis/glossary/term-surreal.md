# 首先要澄清什么

指非日常效果、某种修辞，还是 Surrealism 的历史关系？

# 不足以成立的依据

只要有怪异物体

# 说明

非现实机制属于再现或修辞分面；历史关系需资料支持。Oppenheim《Object》的“超现实主义”有馆藏记录支持，而不是看图联想。反例测试：把所有怪异设计称为超现实主义→应区分非现实机制与历史关系。

# 用法

同一个词在不同句子中可能落入不同分面；存在多个合理义项时，保留歧义而不是提前锁死（见 [六步分面描述](/methods/six-step-facet-description.md) 第三步）。
