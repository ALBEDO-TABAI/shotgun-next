# 首先要澄清什么

指具体何时、何地、哪种生活或视觉传统？

# 不足以成立的依据

木材、留白、某种植物

# 说明

宽泛地域词不能当作已完成的历史解释；需要具体地域、时期和传统。个人与文化材料进入创作时也应具体化来源，而不是以宽标签代替研究。

# 用法

同一个词在不同句子中可能落入不同分面；存在多个合理义项时，保留歧义而不是提前锁死（见 [六步分面描述](/methods/six-step-facet-description.md) 第三步）。
