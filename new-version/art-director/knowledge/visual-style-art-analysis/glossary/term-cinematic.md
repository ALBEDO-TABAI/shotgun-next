# 首先要澄清什么

指构图、空间、照明、时间组织，还是某类电影的联想？

# 不足以成立的依据

宽画幅、黑边或某套调色

# 说明

“电影感”常混合形式、媒介外观与联想；应拆到具体分面后再判断，宽画幅与调色只是外观线索。

# 用法

同一个词在不同句子中可能落入不同分面；存在多个合理义项时，保留歧义而不是提前锁死（见 [六步分面描述](/methods/six-step-facet-description.md) 第三步）。
