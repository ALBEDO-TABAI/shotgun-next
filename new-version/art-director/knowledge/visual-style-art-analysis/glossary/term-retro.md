# 首先要澄清什么

相对于何时？指哪个地区、媒介或设计领域？

# 不足以成立的依据

发黄、颗粒、旧物

# 说明

“复古”必须给出比较时点与领域；旧物出现属于题材或陈设，发黄颗粒属于影像外观，都不单独构成历史归属。

# 用法

同一个词在不同句子中可能落入不同分面；存在多个合理义项时，保留歧义而不是提前锁死（见 [六步分面描述](/methods/six-step-facet-description.md) 第三步）。
