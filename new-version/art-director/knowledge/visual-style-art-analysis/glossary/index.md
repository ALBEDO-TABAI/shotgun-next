# 术语与工作定义 · Glossary

工作定义（风格、视觉描述、混合视觉系统等）与常见风格词的消歧词条。


# 一 风格概念辨析与分面分析

* [视觉风格（工作定义）](visual-style-working-definition.md) - 视觉风格是在明确作品范围内，由一组相互关联的视觉选择及其组织方式形成的相对可识别的呈现模式；识别靠比较，归属与意义需语境证据。
* [形式／风格／类型／Look／美术设计／审美评价：协作术语约定](form-style-genre-look-terms.md) - 六个常被混用的词各自回答的问题：怎样构成、持续怎样呈现、属于哪类作品、看起来怎样、谁决定了什么、是否成立。
* [“极简”：消歧词条](term-minimal.md) - 先澄清：指元素稀少、信息控制，还是历史上的 Minimalism？ 不足以成立的依据：白底加一个物件。
* [“复古”：消歧词条](term-retro.md) - 先澄清：相对于何时？指哪个地区、媒介或设计领域？ 不足以成立的依据：发黄、颗粒、旧物。
* [“写实”：消歧词条](term-realistic.md) - 先澄清：指外观逼真、生活经验可信，还是特定艺术史概念？ 不足以成立的依据：细节多、材质精细。
* [“超现实”：消歧词条](term-surreal.md) - 先澄清：指非日常效果、某种修辞，还是 Surrealism 的历史关系？ 不足以成立的依据：只要有怪异物体。
* [“胶片感”：消歧词条](term-film-look.md) - 先澄清：指什么可见特征？是否真的知道拍摄或输出介质？ 不足以成立的依据：单独添加颗粒。
* [“电影感”：消歧词条](term-cinematic.md) - 先澄清：指构图、空间、照明、时间组织，还是某类电影的联想？ 不足以成立的依据：宽画幅、黑边或某套调色。
* [“日式／东方”：消歧词条](term-japanese-oriental.md) - 先澄清：指具体何时、何地、哪种生活或视觉传统？ 不足以成立的依据：木材、留白、某种植物。
* [“拼贴”：消歧词条](term-collage.md) - 先澄清：指实际制作、可见的碎片组合，还是观念层面的并置？ 不足以成立的依据：出现多个来源不明的元素。
* [“高级感”：消歧词条](term-premium.md) - 先澄清：谁的评价？在哪种使用情境下？具体由什么支撑？ 不足以成立的依据：价格联想或个人好恶。

# 二 视觉观察与形式证据

* [视觉描述（工作定义）](visual-description-working-definition.md) - 对明确版本、明确范围内的可见对象、属性、关系和时间变化，作出可定位、可复核、与证据相称的陈述；可复核不要求同一种感受。

# 三 混合风格与融合规则

* [混合视觉系统（工作定义）](hybrid-visual-system-definition.md) - 把不同来源、组织方式或现实约定的视觉材料经选择和变换建立关系，形成可描述的整体或有作用的异质结构；混合不一定以消除差异为目标。

# 四 美术工作与设计决策

* [美术相关工作（工作定义）](art-related-work-definition.md) - 在具体项目及分工条件下，把表达、叙事或传播要求转译为视觉世界及其物质／数字实现条件，并在制作中维持、调整这些选择的工作；物件数量不是工作量指标。
* [关键道具（英雄道具）](key-prop.md) - 会显著影响行动、理解、主体识别或镜头完成的物件，可能很便宜、画面面积很小；外观、可操作性、替代件与状态变化往往需一起测试。

# 六 从抽象需求到场景方案

* [视觉构思（工作定义）](visual-ideation-definition.md) - 在具体任务和限制下，提出能够组织场景关系的概念，并通过制作、观看和反馈逐步检验、修订这些关系的过程；概念是能帮助作选择的设定，不是事后包装文案。

# 八 分析沉淀与知识复用

* [可复用的视觉知识（工作定义）](reusable-visual-knowledge-definition.md) - 具有证据与适用范围的设计判断，以及由该判断提炼出的有条件的行动原则；它不保证复制效果，而是帮助提出更好的问题和方案。
