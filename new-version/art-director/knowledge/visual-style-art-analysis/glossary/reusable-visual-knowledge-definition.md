# 定义

> 可复用的视觉知识，是**具有证据与适用范围的设计判断**，以及由该判断提炼出的**有条件的行动原则**。

# 要点

- 几千张带“高级、自然、极简、梦幻”标签的图片，遇到“产品要轻盈，但不能失去体积感”时仍不知从哪开始——原因不是图太少，而是没有保存：某张图解决了什么问题，哪些关系产生了效果，哪些条件不可丢失，哪些部分只是偶然外观。
- 它不保证复制效果：产品、人物、媒介和目标改变后，旧原则需要重新检验。可复用的意思是能帮助提出更好的问题和方案，而不是不经思考直接套用。
