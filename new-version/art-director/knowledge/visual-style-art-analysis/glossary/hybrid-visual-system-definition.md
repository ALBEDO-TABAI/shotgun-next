# 定义

> 混合视觉系统，是在明确作品范围内，把具有不同来源、组织方式或现实约定的视觉材料，经由**选择和变换**建立关系，从而形成一个可描述的整体，或一个**有作用的异质结构**。

# 要点

保留“异质结构”，是因为混合不一定以消除差异为目标。某些作品需要整齐统一，另一些恰恰依赖接缝、断裂、错位和多重中心。不能先规定“所有东西必须自然融合”，再把作品的重要冲突修掉。
