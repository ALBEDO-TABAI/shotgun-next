# 适用触发

当用户需要保存拆片成果、整理参考库、形成可迁移方法、建立团队分析模板或为 AI 准备可靠知识时使用。不自动把所有历史作品解释升级为通用创作规则，也**不默认把用户资料上传到任何外部服务**。

# 执行过程

确认实际材料与用途；选取关键决策（[决策卡](/templates/key-design-decision-card.md)）；定位观察证据；分离资料事实与分析解释；记录竞争解释；提炼有条件的迁移规则（[规则卡句式](/templates/rule-card-sentence.md)）；加入反例和失效条件；确认权限与版本；把记录连接到实际检索、创作或评审任务。有新测试结果时，更新相应规则或适用范围。

# 输出的轻重分级

| 场景 | 输出 |
|---|---|
| 个人练习 | 一张决策卡和一句迁移规则 |
| 团队复盘 | 增加版本、职责、交接和修改依据 |
| 长期 AI 资料库 | 再增加编码说明、来源链、质量抽查与维护记录 |

这些是扩展选择，不是每次都必须完成的三重审批。

# 完成条件

关键结论能找到对应来源；不同证据身份没有混写；规则说明适用与失效条件；记录没有虚构精确定位；未知没有被自动填满；下游知道哪些内容可以使用、需要检查或不能继承。

# 核心原则

一次视觉分析的最好沉淀，不是最完整的形容词清单，而是一组能够回到证据、保留解释边界、指向设计选择的记录。让每个结论知道自己的来源、范围和用途，才能把作品研究变成创作能力，而不是把一次猜测变成长期重复的事实。
