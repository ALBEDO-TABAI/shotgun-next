# 输入

作品材料、范围信息、已确认的任务或剧本、可获得的过程记录。仅有成片时，输出必须限定为可见选择与候选工作。

# 执行过程

确认分析是成片复盘还是新方案；提取世界、空间、陈设、道具、材料、制作和连续性决定（见 [七类决策对象](/frameworks/seven-decision-objects.md)）；区分作用与真实来源；建立关键依赖；确认每个交付物的使用者和验收方式；列出不能由现有证据确定的归因。

# 输出

设计决策地图、关键道具与空间说明、实现候选、已核实工作、部门接口、未决问题。小项目可以合并为一张卡，不要求岗位数量与表格数量对应。交接见 [最小交接卡](/templates/art-design-decision-handoff-card.md)。

# 完成条件

关键选择都有作用描述；真实制作与推测没有混淆；至少识别最重要的跨部门依赖；产物有人消费；安全、使用资格或实际工艺未核实时没有被写成通过。

# 核心原则

美术工作的核心证据是设计决定及其实现关系，不是画面里的物件数量。真正完成的决定，不只被写出，还必须在下游的画面或使用中成立。
