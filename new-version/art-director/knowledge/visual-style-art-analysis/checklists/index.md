# 检查清单与反例测试 · Checklists

各篇的反例测试／对抗性检查表与失败诊断表。


# 一 风格概念辨析与分面分析

* [第一篇反例测试：风格概念辨析](p01-counterexample-tests.md) - 八个应通过的判断：古典道具、数字颗粒、明亮恐怖、超写实不可能事件、段落差异、无合适风格名、需求当结果、多观看者分歧。

# 二 视觉观察与形式证据

* [第二篇反例测试：视觉观察与形式证据](p02-counterexample-tests.md) - “肯定是胶片”、低分辨率局部截图、宽留白加碎高光、瞬间遮挡、观看者注意不同、假道具外观、要求“客观高级感”。

# 三 混合风格与融合规则

* [混合失败时的诊断表：落在关系而不是风格名上](hybrid-failure-diagnosis.md) - “不够统一”“像拼素材”“都好看但不成片”“高级与自然打架”“变化太少”“风格太杂”各自对应的可操作诊断与修订方向。
* [第三篇反例测试：混合风格与融合规则](p03-counterexample-tests.md) - 广告＋胶片＋浪漫＋对称、无单一主导中心、单只历史器皿、同色但尺度矛盾、主创否认致敬、怪异即超现实、只有特写有效、要求百分比。

# 四 美术工作与设计决策

* [第四篇反例测试：美术工作与设计决策](p04-counterexample-tests.md) - 几乎没有道具、像金属、画面统一、中英岗位相近、新增绕拍、预算下降、数字场景、只有概念陈述、下游用旧图纸。

# 五 创作出发点与解释边界

* [第五篇反例测试：创作出发点与解释边界](p05-counterexample-tests.md) - “导演一定在暗示什么”、主创陈述目的、三篇同源转载、提案与访谈不同、常见细节、未找到意图资料、巧妙但无证据、两种不相容解释、反事实当动机。

# 六 从抽象需求到场景方案

* [第六篇反例测试：从抽象需求到场景方案](p06-counterexample-tests.md) - 只说“高级一些”、三方案只是色调、参考图题材不合、原型好看没回答问题、新增运动镜头、气氛过包装错、目标冲突、非商业需含混、AI 近似图。

# 七 作品评价与反馈验证

* [第七篇对抗性检查与常见假问题](p07-adversarial-checks.md) - “高级吗”、表现压抑、一位专家不喜欢、完成度不同、无记忆研究、A/B改多项、内部讨论当市场验证、不同尺寸版本、技术错误被平均、多解释、局部问题全部重做、概念认可当全部获批。

# 八 分析沉淀与知识复用

* [第八篇对抗性测试：知识越可复用，越需要防止错误被放大](p08-adversarial-tests.md) - 只有风格描述、只有一张关键帧、同源转引、陌生物件、两种合理解释、裁切调色、旧资料制作事实、单案例原则、候选被选中、模型流畅一致、旧论文错误率、字段很多、权限不明、遇到反例。
