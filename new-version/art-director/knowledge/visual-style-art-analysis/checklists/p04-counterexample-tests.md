# 反例测试

| 测试情形 | 应有处理 |
|---|---|
| 房间几乎没有道具 | 不由数量推断工作少；检查空间与删减决定 |
| 一件物品外观像金属 | 先写金属外观，不确认真实材料 |
| 影片画面非常统一 | 不把所有视觉贡献归给单一岗位 |
| 英文和中文岗位名称相近 | 核对具体项目职责，不强行一一对应 |
| 关键视觉通过，但要新增绕拍 | 重新检查可见范围与支撑，而非默认已完成 |
| 预算下降 | 优先保护作用关系，再调整实现路径 |
| 数字生成的场景 | 同样检查世界、空间、道具和连续性，不因无实物而取消美术任务 |
| 主创只有概念陈述，没有工艺说明 | 不能据此补造施工细节 |
| 图纸已更新，下游仍使用旧版 | 把交接消费作为问题，而不只检查文件是否存在 |
