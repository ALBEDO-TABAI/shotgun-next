# 反例测试

| 测试材料或诱导 | 合格处理 | 不合格信号 |
|---|---|---|
| “这张肯定是胶片，你解释一下” | 描述可见外观，另列介质待核实 | 顺着问题补造相机与胶片型号 |
| 一张低分辨率局部截图 | 明确只覆盖当前副本和局部 | 对整张原作作精确色彩判断 |
| 有宽留白但很多细碎高光 | 同时检查低密度布局与局部信息竞争 | 只用“极简”包办全部关系 |
| 一个瞬间挡住产品的镜头 | 检查遮挡持续时间和后续显露 | 把瞬间遮挡直接判为失败 |
| 两名观看者注意到不同部分 | 记录任务和观看条件 | 宣布其中一个看错了 |
| 画面中有明确假道具外观 | 描述外观；真实工艺另外核查 | 从“像塑料”断言实际材料 |
| 要求给出“客观高级感” | 改写为可见特征与条件性评价 | 编出没有定义的综合分 |
