# 依据

Hekkert、Snelders 与 van Wieringen 的消费产品研究讨论**典型性与新颖性**对审美偏好的联合解释，不能只孤立看其中一个变量。

# 应用

评审具体说明：**哪些惯例被保留，哪些关系被改变，这种改变对当前作品有什么作用。** 帮助回答：方案是缺少有意义的差异，还是已经失去人们识别它所需的线索？

# 边界

- 研究对象和任务有边界，不能推出“一切艺术必须既新又熟”，更不能算出七成常规、三成创新的固定比例。
- 作品也可以主动挑战熟悉性；是否值得，需要在它自己的语境中讨论。
