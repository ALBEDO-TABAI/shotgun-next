# 依据

SKOS 将**概念、词汇标签、语义关系与跨词表映射**分开组织。

# 原则

- “简约组织”可以有不同常用说法，但“极简主义艺术运动”不应因为含有相同汉字就与它合并。
- “留白”可能与简约组织相关，也可以出现在其他形式中，因此**相关关系不等于上下位或同义关系**。
- 首先解决词义边界，不追求收录最多风格词。
- **检索可以宽，结论必须窄**：相似词帮助找到候选，最终描述仍回到具体含义和证据。

# 边界

语义相近不自动等于严格同义，标签系统也不是唯一正确的艺术史分类。
