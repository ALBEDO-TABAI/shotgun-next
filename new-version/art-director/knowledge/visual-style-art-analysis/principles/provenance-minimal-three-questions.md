# 依据

W3C PROV 概览以**实体、活动及相关参与者**说明来源信息，并关注派生与版本（该概览是 Working Group Note，不是 Recommendation 本身）。

# 最小三问

1. 当前结论依据什么材料？
2. 经过了怎样的处理或判断？
3. 谁作出了这一判断？

# Examples

截图、原始影片和分析报告是不同对象；裁切、调色与描述是不同活动；主创自述、研究者解释和模型输出来自不同参与者。知道这些差别，才能判断一句话能支持什么。

# 边界

不需要先部署复杂数据库或 RDF：一个写清来源与修改历史的 Markdown 文件，也可以承载最小来源链。
