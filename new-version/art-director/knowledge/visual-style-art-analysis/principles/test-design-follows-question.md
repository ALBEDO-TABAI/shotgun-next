# 依据

NIST 的实验设计说明强调研究目标、因素数量、资源和错误决策控制会影响设计选择；完全随机设计把随机分配与随机执行顺序作为明确的设计概念。

# 原则

- 只借用方法原则，不把工程试验表直接套成艺术评审标准。
- 一场内部讨论、一轮访谈、一个随机比较和一次投放测试，是不同层级的证据，**不应统一写成“用户验证通过”**。
