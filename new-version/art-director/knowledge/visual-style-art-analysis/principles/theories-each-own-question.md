# 原则

这些理论不适合拼成一个“大一统解释器”，更合适的做法是让它们**分别负责一种问题**：

| 方法 | 负责解决 |
|---|---|
| [分面分类（Getty AAT）](/frameworks/faceted-classification-aat.md) | 不同性质的词被塞进同一个篮子 |
| [沃尔夫林比较形式分析](/frameworks/wolfflin-five-comparison-axes.md) | 只认物件，不认组织方式 |
| [图像志与图像学](/frameworks/panofsky-three-levels-via-icon.md) | 看见、识别、解释被混成一句话 |
| [Bordwell 电影诗学](/frameworks/bordwell-mid-level-questions.md) | 风格名代替了作品机制 |
| [视觉符号学](/frameworks/object-meaning-vs-plastic-meaning.md) | 物象意义与造型意义混淆 |
| [Rose 视觉研究方法](/frameworks/rose-image-and-its-context.md) | 画面被从生产与使用环境中抽离 |
| [经验美学（Leder 等）](/frameworks/leder-emotion-vs-judgment.md) | 感受、喜欢与质量被当作一回事 |

# 取舍原则

- **不要因为一个理论著名，就把它变成每次分析必须经过的关卡。**
- 形式研究适合解释组织差异；图像学适合处理约定主题和文化意义；生产研究适合核查工作条件；受众研究适合检验观看结果。它们能互相补充，但不能互相代替。
