# 原则一：两类记录不可互换

- 没有制作资料时，卡片中的“关键选择”可以指对成片形式的**分析性重述**，例如“主体与背景保持同色，但通过不同反射方式区分”。这不证明主创曾用相同语言提出它。
- 应明确：是从成片分析出的设计关系，还是有资料证明的真实生产决定。两类记录都可以有价值，但不可互换。

# 原则二：抽象与具体的平衡

- **过度抽象**：任何案例都变成“通过对比突出主体”。应保留具体对比发生在哪里、通过什么属性实现、与其他关系怎样共同作用。
- **过度具体**：只剩“右边放两片叶子”。
- 有效卡片需要在具体证据与有条件的关系描述之间建立连接。
