# 原则

- 原片、压缩版、截图、局部裁切、调色参考和加注版本，不应全用同一个模糊名称。派生图可以引用原资源，但要记录发生了什么变化。
- 只拿到截图，就以截图为分析对象：不能通过一个宽画幅边框猜测真实放映格式；不能根据截取图推断完整镜头的持续时间。
- 图片重裁切后，旧坐标不能悄悄继续指向原区域；视频重新剪辑后，旧时间码应检查是否仍然有效。
- 没有对应资源时，不输出虚构的证据路径：`frame_123.jpg` 看起来像文件名，不代表文件实际存在。
- 反例测试：参考图被裁切或调色 → 检查派生版本及受影响结论，不继续沿用旧定位与颜色判断。
