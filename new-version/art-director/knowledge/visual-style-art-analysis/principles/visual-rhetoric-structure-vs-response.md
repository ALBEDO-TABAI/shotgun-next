# 依据

Phillips 与 McQuarrie 提出视觉修辞分类，把图像策略的复杂性和歧义与**可检验的受众反应预测**联系起来（本次只核对摘要，不复刻其九类结构）。

# 原则

- 拆开两件事：图像怎样安排关系；这些安排是否真的产生了预期理解。
- 类比、并置、替代、尺度错置等是描述候选机制的工作词汇，可以帮助提出测试问题。
- 可以提出“这个反差可能让观众停下来理解”的假设，但不能从“存在反差”直接推出“必然提升记忆与购买”；是否停留、理解了什么、记住的是产品还是装置，需要分别验证。
