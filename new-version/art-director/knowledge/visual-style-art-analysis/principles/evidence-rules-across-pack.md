# 五条规则

1. **不同资料负责不同问题**：研究论文支持其对象与方法范围内的结论；专业机构资料说明特定制作语境；主创陈述支持“创作者这样公开说明过”；图像本身支持可见关系。没有任何一种来源可以单独包办风格归属、真实意图、制作细节和观众效果。
2. **工作框架不是普遍规律**：观察表、融合操作、假设矩阵、评价维度和交接格式，是为广告、摄影与影片分析整合的工作建议，应在使用中根据反例修订，而不是用来否定所有不符合表格的艺术作品。
3. **教学案例不是已验证的项目**：植物庭院、三十秒护肤品品牌片、裂缝桌面、无法进入的房间等明确标为虚构或假想，没有实际拍摄、受众调查、销售结果或成本记录。《芭比》《小斧子》及 Tim Walker 展览内容限于已核对的专业机构或主创文字资料，没有声称逐帧审看完整影片或完整作品集。
4. **没有全文，不扩写全文结论**：部分论文只获得可靠的摘要、卷期或机构记录；不据此编写未核对的实验细节、效应量、全部分类或精确阈值。
5. **比较条件和未知项必须留下**：来源不确定、材料不明、未做测试、只有局部画面，都不是必须被填满的漏洞；保留限制才能让下一步知道要补什么证据。
