# 依据

Dorst 与 Cross 的设计过程研究，在其摘要所述样本（九名经验丰富的工业设计师）中讨论了问题空间与方案空间的共同演变。

# 原则

- 复盘时应允许：先有材料实验，再重新理解需求；先有场景发现，再发展故事；拍摄后通过剪辑形成更清楚的概念。
- 这是对线性叙事的提醒，不是证明所有影视项目都按同一方式工作。
- 一个最后讲得非常顺畅的创作故事，未必完整保留了过程中的往返、放弃与偶然。
