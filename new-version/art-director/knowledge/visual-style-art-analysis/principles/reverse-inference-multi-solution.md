# 原则

从需求到方案存在多种可行选择；从最终画面往回追，也就可能遇到多个不同的形成过程。

# Examples

一间房间看起来很窄。候选原因：空间本身、机位和构图、人物与家具的摆放、后期裁切，或它们的组合。即使确定物理空间很窄，仍不知道它是主动选择、场地限制还是剧情需要。

# 目标

反推不应追求“把所有可见效果都对应到一个精确幕后原因”，而应寻找**证据足够区分到什么程度**。
