# 原则

- 色号能帮助沟通，但同一色号在不同表面和观看条件中不一定形成相同的画面关系。对关键部位，应检查它与其他颜色、明暗和反射怎样共处。
- Greenwood 的访谈提到，与摄影及服装相关的测试和协调参与了《芭比》的颜色决策。本篇提炼的工作原则：**不要让美术、摄影、服装各自拿着一个“正确的颜色”，却在成片里形成彼此抵消的结果。**
- 这不要求所有颜色一致。互相对抗也可以是设计选择，但必须在同一观看条件下讨论。
