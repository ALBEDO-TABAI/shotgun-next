# 依据

Jonauskaite 等人的跨国研究发现颜色—情绪关联**既有共享模式，也受语言和地理关系塑造**；其任务针对颜色词与情绪概念，而不是对整幅广告作因果实验。

# 原则

- “蓝绿色＝清爽”“红色＝危险”不能直接写入观察层。
- 先记录色彩在画面中的**位置、面积、相邻关系、明暗和饱和度**，再提出特定语境中的感受假设。
- 同一种红色出现在救援标识、节日织物、室内灯光和抽象色块中时，分析至少应允许不同解释。
- 不能把某种颜色与词语的关联，直接写成某广告已制造相应感受。

这不是否认色彩研究，而是避免把研究中的关联误用成无条件设计指令。
