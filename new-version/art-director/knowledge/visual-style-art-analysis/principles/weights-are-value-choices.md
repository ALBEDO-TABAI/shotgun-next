# 原则

- 把包装识别放在情绪陌生感之前，是一种项目优先级；换成艺术展览时可能相反。权重应由任务讨论形成，并**明确谁作了选择**。
- 先找不可妥协的约束，再比较其他取舍。不要让一个严重的内容错误，被多个“质感不错”的分数平均掉。
- 若改变合理的优先级就改变方案选择，应如实说明方案之间存在取舍，而不是宣布有一个无条件的最佳方案。
