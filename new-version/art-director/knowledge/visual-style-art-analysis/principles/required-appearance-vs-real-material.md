# 原则

- 材料不能只在桌上观看样片时决定：镜头距离、光、角度、背景和后期会改变它如何被看见（这里强调检查这些相互关系，而不是给出唯一的物理因果配方）。
- 项目可以需要石材的视觉重量，却不一定需要真实石头；可以需要纸片的薄感，却不能让它在动作中失去形状。先明确希望保留的**视觉与使用性质**，再比较候选实现。
- 第六篇：需要的是透光、柔软、薄、反光、粗糙、可变形，还是只需要其外观？没有测试时写“候选材料”，不过早列为已确认的制作事实。

# 成片分析方向相反

只能看到石材外观，就先描述外观。没有幕后证据，不宣布使用了哪种基底、涂层或数字材质。反例测试：一件物品外观像金属 → 先写金属外观，不确认真实材料。
