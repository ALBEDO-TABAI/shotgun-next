# 依据

Bordwell 的导论将作品的形式分析与意图、工艺惯例、机构约束和社会条件等解释因素联系起来，并主张围绕具体问题核查证据。

# 原则

- 可以研究画面如何工作，也可以研究它为什么形成，但不能因为两者都重要，就把它们压成同一句因果宣告。
- “某个空间安排参与构成压迫关系”可以由作品细读支持；“它是因为某项预算决定形成的”则需要另一类材料。
- 两项研究可以相互补充，不能互相冒充。
