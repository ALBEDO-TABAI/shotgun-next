# 依据

ICON 论文把艺术内容和意义解释作为需要建模的对象，明确允许不同观察者对同一作品形成不相容解释；其研究范围不等同于物理测量或作品元数据。

# 原则

- 报告中写清“**谁提出何种解释，基于什么材料**”。解释被记录得很正式，不意味着它变成作品自带的唯一属性。
- 保留多种有证据的解释，不为了数据库只有一个字段就强行合并。
- 同时，不把没有依据的任意联想与有材料支持的解释当成同等有效，它们仍需比较证据、范围和替代解释。
- 第八篇：“这张图表达疏离”可保存为有作者、有证据的解释；另一位提出“更像仪式性展示”也可以并存。

反例测试：两种有依据的解释不相容 → 保留解释者与证据，不强行平均。
