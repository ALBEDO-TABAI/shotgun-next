# 原则

- 分析成片时，可以提出实现候选，却不能仅凭“看起来复杂”估算准确预算、工期或团队人数。相同外观可能依靠不同资源条件实现。
- 创作阶段则需要把候选路径放在同一个决策表里比较：可见区域、交互要求、镜头运动、修改频率、资源限制、复用需求和待核验风险。
- 反例测试：主创只有概念陈述，没有工艺说明 → 不能据此补造施工细节。
