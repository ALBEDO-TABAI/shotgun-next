# 原则

- 若同一配方有的画面轻盈、有的笨重，应比较尺度、支撑、遮挡、材质和动作，**而不是把不符合预期的图删掉**。
- 也可以找外观差异很大却解决相近问题的作品，判断学到的是某种视觉关系，还是仅仅熟悉了一套流行配色。
- 不要求每条规则拥有固定数量的案例才允许使用；案例不足时，明确记录探索性状态即可。
- 反例测试：规则遇到反例 → 收窄、拆分或修正规则，而不是删除反例以保持体系完整；原则只在一个案例提出 → 标记探索性，补迁移测试，不宣称普遍有效。
