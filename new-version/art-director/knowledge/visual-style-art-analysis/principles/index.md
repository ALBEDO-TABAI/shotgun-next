# 原则与边界 · Principles

证据边界、解释边界、归因边界、评价与知识复用中的防误判规则。


# 00 阅读导航与使用说明

* [贯穿全包的证据规则（五条）](evidence-rules-across-pack.md) - 不同资料负责不同问题；工作框架不是普遍规律；教学案例不是已验证项目；没有全文不扩写全文结论；比较条件和未知项必须留下。
* [本包怎样理解“科学性”与研究范围](scientific-meaning-of-this-pack.md) - 问题清楚、概念分明、证据可追溯、结论不过界、替代解释可比较、方法可被反例修正；定向跨学科调研而非系统综述；35 项来源不是“35 项实验证明本框架有效”。

# 一 风格概念辨析与分面分析

* [理论分工：每种学术方法只负责一种问题](theories-each-own-question.md) - 分面分类、比较形式、图像学、电影诗学、视觉符号学、视觉方法论、经验美学不拼成大一统解释器；著名理论也不应成为每次分析的必经关卡。
* [对象本身与对象的影像呈现分开分析](object-vs-its-image.md) - 椅子的设计传统与拍它的照片的构图、照明、色彩与观看方式是两个对象；场景中有古典建筑元素不等于影像采用古典构图组织。
* [风格的稳定不等于所有部分都长得一样](style-stability-allows-local-contrast.md) - 规范应允许“整体以某种方式为主，局部通过相反处理形成对照”，否则会把作品中最有意义的变化误判为“不一致”。
* [只分析实际获得的材料：范围限定而非补全](analyze-only-obtained-material.md) - 一张海报不能证明整个系列，一个预告片不能证明正片，一张压缩截图不足以判断原始颗粒与印刷色彩；正确输出是范围限定。
* [先排除“伪混合”：多个分面同时存在不等于风格融合](multi-facet-is-not-fusion.md) - “商业＋极简＋梦幻＋三维”很可能是使用性质＋形式组织＋预期体验＋制作方式的多分面描述；只有澄清词义后才有必要讨论融合。
* [用关系句代替百分比](relation-sentences-not-percentages.md) - “70%极简＋20%巴洛克＋10%赛博”在没有特征、计量单位与比较样本定义时，只是把感觉伪装成测量；关系句说明谁主导、谁被引用、作用在哪、怎样协调。
* [创作者自述只证明“他这样说明”，不单独证明效果已产生](creator-statement-proves-the-statement.md) - 主创陈述首先证明某人在某时某场合公开这样说明；可与制作记录互证材料使用，但不能代替受众材料证明观众感受。
* [文献收录四要素：解决的问题、已核对范围、可转化规则、适用限制](source-entry-four-fields.md) - 知识库不只存一份“推荐书单”；每份资料都应说明它解决什么问题、本次核对到哪里、转化出什么规则、不能推出什么。

# 二 视觉观察与形式证据

* [第一印象先放进“体验笔记”，不悄悄变成观察结论](first-impression-goes-to-experience-notes.md) - 不是禁止直觉：可以同时记录“我第一眼觉得沉重”和“主体轮廓宽厚、支撑面较大、向上运动很少”，但不把前者伪装成后者的客观同义词。
* [观看任务影响扫描：画面不能独自决定所有人的观看顺序](viewing-task-shapes-scanpath.md) - 没有眼动记录时，“观众先看这里”应降格为“这里提供了较强的注意线索”或“我本次观看最先注意到这里”。
* [色彩与情绪有关联，但没有通用解码词典](color-emotion-not-decoding-dictionary.md) - 颜色—情绪关联既有共享模式也受语言地理塑造，且研究针对颜色词与情绪概念；“蓝绿色＝清爽”不能写入观察层。
* [定位是证据的一部分：陈述必须绑定到对象](locator-is-part-of-evidence.md) - 借 W3C Web Annotation 的“内容与目标分离、片段定位”思想；纸上写“第三张图，产品左侧叶片”也有效，没有资源时不编造时间码或文件名。
* [光影与材质：观察到外观，不宣布灯型、灯距或表面配方](light-material-boundary.md) - 多种制作路径可能产生相似结果；先问光在当前画面里做了什么（分离、显体积、遮信息、生图案、保平面感），这仍是形式功能解释而非灯光师意图。
* [画外空间不是可以随意补画的世界](off-frame-space-not-free-to-fill.md) - 门口有人朝外看，只能说明作品设置了朝向画外的关系；“未出现生活杂物”不能直接解释成“人物没有生活”，原因可能是裁切、用途、时点或设计删减。
* [尺寸与位置测量：测的是画面，不是世界](measure-the-image-not-the-world.md) - “产品高度占画面三分之一”是图像比例，不能告诉现场有多高；裁切不同的版本不能直接比较比例；不必要的测量制造假精确。
* [灰度、缩略图和遮罩是干预，不是原作](diagnostic-derivatives-not-original.md) - 灰度删除色相与饱和度，缩略图损失细节，遮住道具只得到“可能参与竞争关系”的线索；辅助图须与原图分开标注，不能反过来成为原作特征的证据。
* [色值与直方图只回答窄问题，不输出“高级感得分”](color-stats-answer-narrow-questions.md) - 平均颜色相同的两张图分布可完全不同；工具应回答“标签附近局部明暗差异是否改变”这类问题，没有操作定义时复杂图表只是把模糊判断包装成测量。

# 三 混合风格与融合规则

* [“我认出两个来源”还不等于解释了作品](recognizing-sources-is-not-explanation.md) - 识别复杂器皿与空旷几何空间各自联想什么只完成参照定位；还要问谁是密集区、轮廓是否呼应、尺度是否改变、靠颜色连接还是靠反差、去掉后损失什么。
* [视觉修辞：图像结构与受众反应是两个研究问题](visual-rhetoric-structure-vs-response.md) - 类比、并置、替代、尺度错置是描述候选机制的词汇，能帮助提出测试问题，但不能独自证明观众理解了隐喻、记住了品牌或更愿购买。
* [相同材料也可能构成不同系统：“共同出现什么”≠“由谁组织整体”](same-materials-different-systems.md) - 相同的叶片、玻璃和水可以形成稀疏陈列，也可以形成密集包围；同色不保证同一种风格关系；形式分析描述结构，不证明历史来源。
* [混合可以来自创作问题与解决路径，而不只是流派宣言](hybrid-from-production-problems.md) - 实景无法容纳透视而引入绘景、演员需接触物体而保留实体、景深改变材料表面；不把技术妥协贬为缺陷，也不把结果美化成预先规划的观念。

# 四 美术工作与设计决策

* [看起来“自然”，不等于没有设计；也不能反推每个细节都被精密设计](natural-look-still-designed.md) - 警惕“设计越显眼工作越多”的偏见：新旧、摆放、维修痕迹与空置区域可共同建立具体生活；但旧柜子可能来自场地也可能特意租借，作用与来源分别记录。
* [职位名称只提供职业语境，不保证具体分工](job-titles-context-not-division.md) - BFDG 区分生产设计、美术指导、概念、绘图、陈设、研究等职责，但不建立中英岗位硬映射；复盘先看合同、演职员表、制作说明，没有资料就用功能词。
* [部门边界随地区与规模变化：角色图是当前项目的工作地图](department-boundaries-vary.md) - 小型静物拍摄中一人可同时设计、采购和摆放；大型制作中一件物体经研究、绘图、制作、使用和连续性管理多人交接；按功能而非人数衡量专业。
* [整体视觉是协作结果，不能通过画面自动分账](collaborative-look-not-auto-attributed.md) - 颜色涉及美术表面、服装、照明、曝光和后期；体积涉及空间、镜头与渲染；道具作用受表演和剪辑改变——可讨论形式贡献，暂缓个人署名判断。
* [“不出现什么”也可以是设计决定——但要分开“结果缺少”与“主动排除”](exclusions-are-design-decisions.md) - 没有生活杂物、真实地平线、常见比例参照会改变空间理解；前者由画面支持，后者需过程证据；创作中写下排除项，防止下游凭习惯填充空白。
* [负空间和通路也是被设计的内容](negative-space-and-paths-are-designed.md) - 空地、门槛、过道、留白和视线通道决定人物距离、产品可辨性和摄影机进入方式；为“丰富层次”加前景植物可能切断原本的观看路径。
* [做旧要有使用逻辑——除非明确选择了另一种现实约定](distressing-needs-use-logic.md) - 磨损位置、颜色变化、维修痕迹与物品变形应与设定的使用方式相容；平均涂脏只传达“旧”而非具体生活；抽象舞台可选不可能的腐蚀或洁净，但不能无意混用两套标准。
* [研究不能只依赖影视作品互相参照](research-beyond-film-references.md) - 档案照片、物件记录、地点观察、当事人生活描述与专业咨询各提供不同东西，也各有范围与记忆限制；《小斧子》座谈是研究参与制作的例子。
* [材料：把“所需外观与使用性质”与“真实材料”分开，并在目标呈现中决定](required-appearance-vs-real-material.md) - 可以需要石材的视觉重量而不需真石头；材料不能只在桌上看样片决定；成片分析只能先描述外观，没有幕后证据不宣布基底、涂层或数字材质。
* [颜色不是一个孤立色号：在同一观看条件下跨部门讨论](color-not-isolated-swatch.md) - 同一色号在不同表面与观看条件中不一定形成相同关系；《芭比》访谈提到与摄影、服装的测试和协调——不要让各部门拿着各自“正确的颜色”互相抵消。
* [画面效果不一定等于昂贵技术：各种实现路径接受同样的问题](effect-not-equal-expensive-tech.md) - 实景、布景、绘景、微缩、数字环境和合成都要回答：需要什么互动、哪些机位、如何修改、哪里必须重复、最终呈现是否成立；技术名称不替代判断。
* [不能仅凭“看起来复杂”估算预算、工期或团队人数](no-imagined-cost-from-look.md) - 相同外观可能依靠不同资源条件实现；成片分析可提出实现候选，创作阶段则把候选路径放进同一决策表比较。
* [风险不是一张独立的末尾表：未核实的安全与使用资格不能由概念图或 AI 代签](risk-is-not-an-end-table.md) - 悬挂、液体、演员接触、特殊材料等要求改变时同时影响美术、拍摄与执行；需合格专业人员确认的事项列为未完成条件；视觉像真的不代表可执行或使用无问题。
* [连续性不只是物品摆放完全相同](continuity-not-identical-placement.md) - 叙事片区分故事时间中的合理变化与拍摄顺序中的意外变化；产品片区分创意变形与包装身份改变；只记录真正影响下一镜头或复拍的内容。

# 五 创作出发点与解释边界

* [解释作品可以超出表面；声称实际发生的创作过程要承担历史证据责任](interpretation-vs-historical-claim.md) - “我认为这里形成了疏离感”与“导演故意用这里表达疏离”只差几个字，却属于不同强度的结论。
* [不要用一个模糊的“可能”包住所有问题](maybe-is-not-rigor.md) - 在所有句子前加“可能”不会自动严谨；关键是说明哪部分已知、哪部分推测、支持在哪、还有什么替代解释。
* [作品机制与生产条件分开追问，不压成同一句因果宣告](work-mechanism-vs-production-conditions.md) - “某空间安排参与构成压迫关系”可由细读支持；“它因某项预算决定形成”需要另一类材料——两项研究可互补，不能互相冒充。
* [解释是有人提出的主张：写清谁、基于什么材料；允许多重解释并存但不等量齐观](interpretation-is-an-authored-claim.md) - ICON 允许不同观察者对同一作品形成不相容解释；报告与知识库中保存“谁提出何种解释”，不把分析者解释改写成作品固有属性，也不把任意联想与有据解释当同等有效。
* [出发点不一定是一句先验主题：问题与方案可以共同演变](origin-not-a-priori-theme.md) - 复盘时允许项目先有材料实验再理解需求、先有场景发现再发展故事、拍后通过剪辑形成概念；讲得很顺的创作故事未必保留了往返、放弃与偶然。
* [资料可信不等于与当前问题相关](reliable-not-necessarily-relevant.md) - 权威机构网页可能准确记录演职员表，却不包含道具设计来源；主创访谈适合回答意图，不适合证明材料配方；来源评估要问“来自哪里”和“能支持什么”。
* [多个来源也可能只是同一条消息的回声](echo-sources-not-independent.md) - 同一采访被三个网站转载仍是一条来源链；保留最接近原始陈述的记录，转载作查找或版本线索；真正的相互印证是不同材料从不同角度限制解释。
* [反推创作是多解问题：寻找证据足够区分到什么程度](reverse-inference-multi-solution.md) - 一间看起来很窄的房间可能来自空间、机位构图、人物家具摆放、后期裁切或其组合；即使确认空间窄，仍不知道是主动选择、场地限制还是剧情需要。
* [好的补证问题要能改变判断](good-questions-change-judgment.md) - “再找些支持疏离的资料”让研究只朝一个方向；“不同场地是否仍用这一布局？”“早期方案中空白是否原本承担动作？”才对应具体不确定性。
* [团队没有义务拥有一套完全相同的内在解释](team-need-not-share-one-interpretation.md) - 导演、美术、摄影和剪辑可能各自从不同问题进入并在制作中形成共同结果；作品一致性不证明参与者从一开始共享同一套语言。
* [反事实能帮忙，但不是历史录像的替代品](counterfactual-limits.md) - 反事实帮助定位选择在解释中的重要性；三个限制：想象版本≠实际版本、局部变化不只改变一个因素、今天能这样重做不证明当时这样思考；标注分析性反事实／原型测试／已发生版本比较。
* [什么时候可以停止补证](when-to-stop-gathering-evidence.md) - 已有材料足以完成当前任务且进一步研究不太可能改变决定；关键结论依赖无法获得的材料时停在条件性结论；问题问错时转向形式功能或新方案实验。

# 六 从抽象需求到场景方案

* [需求不一定在创作开始前已经完全清楚——但每次改变要有理由、范围和新确认](brief-need-not-be-fixed-first.md) - 双钻框架区分发现、定义、发展、交付且非线性；区分哪些限制已确认、哪些概念仍在探索、哪些测试结果要求重新描述任务；不永远停留在没有标准的发散。
* [发散与聚焦是不同任务，不要混在一起](diverge-and-focus-are-different-tasks.md) - “还有哪些本质不同的方案”与“哪一个值得继续”分开进行；发散先比较组织机制，聚焦要明确任务、证据与代价；混在一起会不断推翻或过早停止。
* [原型是提问工具，不只是缩小版成品](prototype-is-a-question-tool.md) - 原型是为回答一个重要问题而制作的有限表达：粗模、材料小样、动作预演、文字场景、灰模、关系草图；验证尺度时过早追求皮肤纹理和水珠细节反而回答不了问题。
* [参考迁移应优先保存关系，而不是一起复制外观](reference-transfer-keeps-relations.md) - 一张参考可只借主体与边界的距离，另一张借材料透光方式，第三张借空间逐步揭示的顺序；把三张图全部外观一起复制不等于三种方法有效整合。
* [硬限制与软目标，不是重要与不重要](hard-constraints-vs-soft-goals.md) - “包装必须正确”可能是硬限制需明确满足与否；“保持轻盈”是软目标需比较与观看反馈但不因此不重要；也不把习惯性偏好未经讨论变成硬限制。
* [感受机制也可能相互冲突：先问优先级与作用范围，而不是让执行者“都兼顾一下”](feeling-mechanisms-may-conflict.md) - “清爽”落实成空场、“丰富”落实成大量配料、“精确”落实成严格网格，可能争夺同一画面；可以让丰富只在前段、用少量有变化的材质替代更多物件。
* [聚焦不必依赖总分：先排除冲突硬限制，再比较任务、风险与实现条件](focus-without-total-score.md) - 剩下两条各有优势时，保留权衡比强行算“创意分”更诚实；明确此阶段哪一项优先，或安排能改变选择的小测试。
* [参考资料与制作资产要分开；生成图也不因已生成就是可发布成品](reference-vs-production-asset.md) - 适合理解关系的图片不等于可直接进入成片的资产；研究、设计和使用核查是不同工作；本包不提供授权结论。
* [先测试“错了会迫使重做”的问题，并考虑可逆性](test-costly-to-redo-first.md) - 尺度关系错了会影响场景、道具、机位和后期；次要表面细纹只影响局部；可快速替换的元素不必过早锁死，牵动多部门的决定需要更明确的证据与确认。
* [一次测试尽量说清改变了什么：区分“寻找更好方案”与“判断某因素作用”](one-test-clear-change.md) - 同时换背景、材料、机位和产品大小可能找到更喜欢的版本，却不知道哪项起作用；探索阶段允许整体替换，诊断阶段应收窄变化——但不强迫永远只改一个变量。
* [失败结果也要留下](keep-failed-results.md) - “叶片在小尺寸中显得厚重”可改变材料、比例或角度；“包装被水光遮住”可改变呈现时点；只保留成功图会让后续团队重走已失败路径。

# 七 作品评价与反馈验证

* [目标是判断的上下文，不是替作品免于批评的许可证；偏好是有效信息，不是质量结论](goal-is-context-not-exemption.md) - “先判断作品在解决什么”不意味着作者说要做什么就只能按那个目标评价：需求是否合理、作品是否打开了更有价值的问题、用途是否改变都可以进入评价。
* [评价不是给描述换一个带褒贬的词：写明对象、条件、标准与证据](evaluation-states-its-conditions.md) - “道具很多”是描述，“道具太多”隐含标准；快速识别产品时密集物件需检查，表现物品积累与记忆时删空反而破坏表达；不把“少”默认等同于“好”。
* [新颖与熟悉不是零和选择：说明保留了哪些惯例、改变了哪些关系](typicality-and-novelty-jointly.md) - Hekkert 等在消费产品研究中讨论典型性与新颖性的联合解释；不能推出“一切艺术必须既新又熟”或“七成常规三成创新”的固定比例。
* [比较反馈前先保存观看条件](viewing-conditions-must-be-recorded.md) - 看了什么版本、有无声音、尺寸多大、任务如何提问、观看前是否了解产品或创作解释；没有这些条件，比较两次反馈往往比较的不是同一件事。
* [批评指向作品和目标，而不是攻击创作者](critique-the-work-not-the-person.md) - d.school 反馈教学强调善意批评、讨论目标及作品与个人的区分；友好不是只说赞美，专业也不是用难懂术语；能让对方理解判断并检验修改才是反馈价值。
* [测试设计由问题决定，不由“A/B”这个名字决定](test-design-follows-question.md) - 研究目标、因素数量、资源与错误决策控制影响设计选择；内部讨论、访谈、随机比较和投放测试是不同层级证据，不应统一写成“用户验证通过”。
* [权重是价值选择，不是科学自动算出来的](weights-are-value-choices.md) - 把包装识别放在情绪陌生感之前是项目优先级，换成展览可能相反；先找不可妥协约束，严重内容错误不能被多个“质感不错”平均掉；改变合理优先级就改变选择时如实说明取舍。
* [证据可信度与作品质量是两根不同的轴](evidence-confidence-vs-quality.md) - 某判断证据弱不等于作品差；某评审十分确定也不等于判断正确；可同时记录“我倾向认为空间关系有效”与“目前只看到单张概念图，运动表现未知”。
* [提问不要预先塞入期待的答案；观看前的解释要如实记录](questions-without-leading-answers.md) - 先问“你看到了什么”“让你想到什么”，再问团队关心的问题；不要一开始就问“是否觉得清爽高级”；解释后理解与无解释理解分开记录。
* [没有开展研究，就写测试计划，不编造结果](no-study-write-a-test-plan.md) - 不为报告完整编造“八成用户觉得更清爽”；内部几位同事意见不扩大成目标人群调查；测试前写预期、测试后写观察，不只保留支持方案的回答。
* [反馈应包含“保留什么”，且问题与方案不要强行绑定](feedback-says-what-to-keep.md) - 只写需要改变的部分容易连有效关系一起破坏；“主体不清楚”是诊断，“换白底”只是候选方案之一，还可改明暗、反射、机位、遮挡或信息密度。

# 八 分析沉淀与知识复用

* [来源记录的最小三问：依据什么材料、经过怎样的处理或判断、谁作出判断](provenance-minimal-three-questions.md) - 借 W3C PROV 的实体—活动—参与者；截图、原片和报告是不同对象，裁切调色描述是不同活动，主创自述、研究者解释、模型输出来自不同参与者；Markdown 也能承载最小来源链。
* [词语不是概念，相关也不是同义：检索可以宽，结论必须窄](words-not-concepts-related-not-synonym.md) - SKOS 将概念、词汇标签、语义关系与跨词表映射分开；“简约组织”与“极简主义艺术运动”不因含相同汉字合并；“留白”与简约组织相关但不是上下位或同义。
* [可复用不等于全部公开：记录来源、访问条件和用途限制](reusable-not-all-public.md) - FAIR 包含必要时的认证与授权访问；能在某处看见图片不代表已获所有使用许可；保存分析记录不必公开客户内部原始资产；本包不替代权限确认或法律判断。
* [资料库也应说明自己是怎样组成的：收录目的、范围、选择方式、排除规则、空缺](library-describes-its-composition.md) - 借 Datasheets for Datasets 的思路：案例为什么被选、偏向哪些媒介与预算、是否只含获奖作品、有无失败与反例；精心策划的案例库不等于具有统计代表性的样本。
* [语言流畅不保证视觉依据可靠](fluent-language-not-visual-grounding.md) - 图像描述与大型视觉语言模型的对象幻觉研究表明对象存在需要独立检查；这些研究有年代、模型与任务边界，不能给当前所有模型规定相同错误率，也不是风格理解的完整测试。
* [决策卡不等于“主创当时真的作了这个决定”；描述也不能为便于迁移而丢失原作](decision-card-not-production-fact.md) - “关键选择”可以是对成片形式的分析性重述，需标明是分析出的设计关系还是有资料证明的生产决定；过度抽象变成“通过对比突出主体”，过度具体只剩“右边放两片叶子”。
* [不变量应尽可能少，但足够维持概念](minimal-sufficient-invariants.md) - “产品进入放大的植物环境”可能需保留产品与植物的尺度关系，却不必固定某种叶片、绿值或石头；但具体植物若承担已确认的产品信息就不能随意替换。
* [反例比再找十张相似图更能修正规则](counterexamples-refine-rules.md) - 同一配方有的轻盈有的笨重时，比较尺度、支撑、遮挡、材质和动作，而不是删掉不符合预期的图；也找外观差异大却解决相近问题的作品；案例不足时标记探索性状态。
* [检索应同时支持“像什么”和“解决什么”；排序靠前不是质量证明](retrieval-wide-conclusion-narrow.md) - 风格词、题材、颜色、年代用于发现候选；任务、关系和失败条件更适合支持迁移——“同色环境中仍保持主体可辨的案例”比“找高级的绿色广告”更能连接设计决策。
* [原始资源与派生资源分开；定位精度跟随证据能力](original-vs-derived-resources.md) - 原片、压缩版、截图、裁切、调色参考和加注版本不用同一模糊名称；只拿到截图就以截图为对象；裁切后旧坐标、重剪后旧时间码要检查；不输出虚构的证据路径。
* [版本变化需要传播到依赖它的结论——精准作用于相关判断](version-change-propagates.md) - 悬浮水珠在新版中被删，基于它的“失重关系”解释要重查；后来发现材料是透明树脂而非玻璃，应更正制作事实，但“画面呈现透明光滑表面”的观察不一定失效。
* [先确认模型真正获得了什么：输出覆盖范围不应超过输入](ai-input-bounds-output.md) - 原图、低分辨率缩略图、关键帧、完整视频还是别人写的描述？没有图像时可制定观察问题、分析文字，但不能声称看到道具纹理；不能把抽样帧拼成确定的动作过程。
* [自我复述不能算独立验证](self-restatement-not-verification.md) - 让同一模型再解释一次可发现内部矛盾，但不能证明图像中确实存在所说对象；关键判断应重新绑定实际材料，由人工或独立证据检查过程核对。
* [生成候选不等于批准执行：记录批准的是概念、构图、材质还是终稿](candidate-is-not-approval.md) - 模型提出的场景、材料和动作还要经过原型问题与评价；某张概念图被选中不自动批准全部制作细节；后续工具不能因看见“通过”二字就跳过未完成检查。
* [信息写出来，还必须有人真正使用：每个重要字段应有消费目的](handoff-fields-need-consumers.md) - 卡片写“包装正面不允许遮挡”，生成阶段却只读“梦幻植物庭院”，评审再凭感觉重写目标——记录越多真相越分裂；交接缩小为几个明确问题；无人读取的字段不必长期维护。
