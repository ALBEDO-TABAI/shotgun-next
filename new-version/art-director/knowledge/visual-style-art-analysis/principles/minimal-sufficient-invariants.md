# 原则

- “产品进入放大的植物环境”可能需要保留产品与植物的尺度关系，却不一定需要固定某种叶片、某个绿值或一块石头。
- 然而，如果具体植物承担**已确认的产品信息**，就不能随意替换。
- 哪些是可变项取决于当前任务，不由风格词自动决定。
