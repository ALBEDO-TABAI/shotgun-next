# 依据

Stanford d.school 的反馈教学强调善意批评、讨论目标及作品与个人的区分。

# 原则

- 解释哪一处关系影响哪一项目标，并提出修改与复查方式。
- 友好不是只说赞美，专业也不是使用难懂术语；**能让对方理解判断并检验修改**，才是反馈的实际价值。
- 第三篇：不要以“融合能力不够”评价个人；应指出哪一条关系没有被共同理解。
