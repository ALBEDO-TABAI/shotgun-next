# 依据

Tatler 等人重新讨论 Yarbus 的研究，报告了改变观看指令的延伸实验，摘要所述结果总体支持**任务对扫描方式的影响**。

# 原则

- “观众先看这里，再看那里”需要降格处理：可以说“这里提供了较强的注意线索”，或“在我本次观看中最先注意到这里”，不把一次体验写成普遍轨迹。
- 把一张广告分别交给“寻找品牌名称”的人和“判断材质”的人，预期他们可能采用不同观看方式——这是工作假设，不等于已预测实际路径。
- 评审中：不能先要求参与者“找出产品”，再把他们看向产品当作未经提示的自然注意。
- 眼动可以帮助研究观看分配，但仅凭注视不能确定理解、赞同或购买。

# 边界

没有据此预测具体广告的眼动轨迹；未完整复核实验方法。
