# 依据

Stanford d.school 把理解、定义、构思、原型与测试作为可循环使用的工作模式；Experiment Expedition 把试验、记录与后续选择联系起来。

# 原则

- 原型定义为“**为了回答一个重要问题而制作的有限表达**”：粗糙模型、材料小样、动作预演、文字场景、灰模或几张关系草图，不必从一开始追求完整精美。
- 若要验证尺度关系，过早追求皮肤纹理和水珠细节，可能使团队被完成度吸引，反而没有回答尺度问题。原型不是越逼真越好，而是保留回答当前问题所需的性质。
- 一个原型应有明确的“待回答问题”；没有问题的精美图，容易变成大家各自解释的对象。
- 反例测试：原型很好看但没回答问题 → 不作为该问题的通过证据。
