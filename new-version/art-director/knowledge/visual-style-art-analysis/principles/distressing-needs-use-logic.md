# 原则

- 磨损的位置、颜色变化、维修痕迹和物品变形，应与被设定的使用方式相容。
- 只在显眼位置平均涂脏的场景，可能传达“旧”，却无法传达具体生活。
- 抽象舞台或表现性影片不必遵循生活磨损逻辑：可以让整个空间呈现不可能的腐蚀或洁净，**只要这是被明确选择的现实约定**，而不是无意识地混用两套标准。
