# 原则

不建议输出“70% 极简＋20% 巴洛克＋10% 赛博”。除非事先定义了特征、计量单位与比较样本，否则这种数字只是**把感觉伪装成测量**。

# Examples

> 整体以稀疏、几何化的空间关系为主；局部器物引入繁复装饰；两者通过统一的表面与色彩被连接，装饰没有扩展为整个画面的主导秩序。

这段话说明了：谁主导、谁被引用、作用在哪里、怎样协调。至于能否称为“巴洛克引用”，还要另外核查器物特征与来源。

# 延伸

- 第三篇 skill 的“不输出”项：没有定义的风格比例。反例测试：要求用百分比表示混合→无计量定义时改为作用范围与主导关系。
- 第五篇：没有统计模型时，不写“作者有87%的概率想表达孤独”。
