# 原则

- 一张海报，不能证明整个传播系列的风格。
- 一个预告片，不能证明正片全部的色彩与节奏。
- 一张经过网页压缩的截图，不足以精确判断原始颗粒、锐度与印刷色彩。

对这些情况，**正确输出是范围限定，而不是补全不存在的证据**。

# 操作

明确看到的是原作、复制图、海报、静帧、完整镜头、片段还是完整作品；没有的信息标为未知，不凭视觉“补全背景”。
