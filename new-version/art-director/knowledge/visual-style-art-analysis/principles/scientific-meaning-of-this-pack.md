# 追求什么

问题清楚、概念分明、证据可追溯、结论不过界、替代解释可比较、方法可以被反例修正。

# 不做什么

- 不把艺术简化为固定公式，不声称色彩、材料或构图能无条件决定情绪。创作选择、价值标准和受众结果之间存在差别；可以严谨讨论，而不必把每种判断伪装成测量。

# 研究范围

- 本次是围绕七个问题的**定向跨学科调研**，不是具有预注册检索方案和穷尽性纳入标准的系统综述。
- 35 项来源不是“35 项实验证明本框架有效”，其中包括理论、实证研究、专业资料、标准及访谈。
- 未实施受众实验或对真实商业项目作效果验证；未进行覆盖所有模型的现时能力评测。
- 理论与专业知识随后转化为工作表、案例、判断步骤、输入输出与反例检查——转化部分属于应用整合，不与原文研究结论混同。
