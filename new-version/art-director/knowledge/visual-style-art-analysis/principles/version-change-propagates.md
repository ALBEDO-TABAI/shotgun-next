# 原则

- 原图中的悬浮水珠被后续版本删除，基于水珠的“失重关系”解释需要重新检查。只改素材文件、不标记依赖结论，会让旧分析继续污染新方案。
- 若后来发现原材料不是玻璃而是透明树脂，应更正制作事实；但“画面呈现为透明光滑表面”的观察不一定同时失效。**更新应精准作用于相关判断**，而不是全盘重写。

# 更新的三种类型不能混成一个“最新版”

1. 修正错误事实时，标记原结论被替代；
2. 增加解释时，保留原解释；
3. 改变项目选择时，说明谁在什么范围内确认了新决定。

旧记录可以继续作为历史材料，但不应被默认当成当前执行要求。反例测试：旧资料确认了制作事实 → 核对对象和版本是否相同，不用它覆盖当前作品的未知项。
