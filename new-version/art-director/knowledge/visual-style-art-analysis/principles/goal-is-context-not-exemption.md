# 原则

> 目标是判断的上下文，不是替作品免于批评的许可证；个人偏好是有效信息，但不是其他人必须接受的质量结论。

- “先判断作品在解决什么”，并不意味着作者说自己要做什么，作品就只能按那个目标评价。
- 目标可以被讨论：需求是否合理，作品是否意外打开了更有价值的问题，实际用途是否改变，都可以进入评价。
- 非商业案例：不能用“这是艺术”结束讨论，也不能用“有人没看懂”结束讨论。
