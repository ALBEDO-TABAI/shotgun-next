# 回答什么问题

在不伪造创作者心理和幕后历史的前提下，怎样提出有解释力的创作假设，并说明什么证据能支持、削弱或改变这些假设？

# 核心主张

**解释可以超出表面，但不能越过自己的证据身份。** 形式功能、创作意图、形成原因和观看效果应分别论证；真正有力量的解释不是最宏大的故事，而是能说明具体关系、经得起替代解释、知道如何被新证据修正的主张。

# 本篇概念

## Framework

- [“为什么这样设计”里的四个问题：形成原因、创作意图、形式功能、观看效果](/frameworks/four-why-questions.md) - 四者可能相关却不能互相证明：场地限制缩小布景可能产生压迫关系，创作者后来也可能认可——效果成立不证明最初就是目的，目的明确不证明观众都感受到。
- [溯因推理：从现象提出“值得检查”的假设，而非已证明的事实](/frameworks/abduction-worth-checking.md) - 看见某种关系；若某创作问题或选择存在，这种关系便较易理解；因此该解释值得进一步检查——最能讲通故事的解释也可能只是当前想得到的最好一种。
- [证据身份（第五篇七类）：各需什么支持，不应升级成什么](/frameworks/seven-evidence-identities.md) - 可见观察、形式解释、创作者自述、制作记录、历史归因、观看记录、创作建议；一个结论可依赖多种证据，但要分别说明角色，合起来也不自动证明唯一原因。
- [三种解释强度：相容、有支持、较能区分；常见线索与独特组合](/frameworks/three-explanation-strengths.md) - 相容只是最低条件；常见线索（如居中构图）单独支持特殊动机的能力有限；没有统计模型与先验定义时不写“87%的概率”。
- [创作出发点的六种类型（候选菜单）](/frameworks/six-origin-types.md) - 任务与传播问题、叙事与人物问题、形式与媒介问题、材料与工艺发现、个人经验与文化材料、资源协作与偶然——不要只寻找宏大主题。
- [解释质量五问：覆盖、区分、约束、范围、用途](/frameworks/interpretation-quality-five-checks.md) - “作品表达现代人的复杂情绪”几乎不限制任何观察；“人物试图接近时持续保留物理阻隔，最后一次行动中移除”提供了具体结构假设——具体不等于正确。

## Method

- [过程追踪：从漂亮的终点故事回到实际决策](/methods/process-tracing.md) - 起初的具体问题、第一次可定位方案、触发修改的材料或反馈、保留与放弃、最后版本、后来如何解释；每项都可能未知；不同时间的陈述可能都真实却回答不同问题。
- [从解释走向创作时显式换轨：三种句式](/methods/explicit-track-switch-three-sentences.md) - “该资料记录了作者……”（陈述事实）／“依据这些画面，我提出……”（分析解释）／“在当前项目中，可以尝试……”（新方案建议）；防止 AI 编出的意图被存成“已验证大师方法”。

## Principle

- [创作者自述只证明“他这样说明”，不单独证明效果已产生](/principles/creator-statement-proves-the-statement.md) - 主创陈述首先证明某人在某时某场合公开这样说明；可与制作记录互证材料使用，但不能代替受众材料证明观众感受。
- [解释作品可以超出表面；声称实际发生的创作过程要承担历史证据责任](/principles/interpretation-vs-historical-claim.md) - “我认为这里形成了疏离感”与“导演故意用这里表达疏离”只差几个字，却属于不同强度的结论。
- [不要用一个模糊的“可能”包住所有问题](/principles/maybe-is-not-rigor.md) - 在所有句子前加“可能”不会自动严谨；关键是说明哪部分已知、哪部分推测、支持在哪、还有什么替代解释。
- [作品机制与生产条件分开追问，不压成同一句因果宣告](/principles/work-mechanism-vs-production-conditions.md) - “某空间安排参与构成压迫关系”可由细读支持；“它因某项预算决定形成”需要另一类材料——两项研究可互补，不能互相冒充。
- [解释是有人提出的主张：写清谁、基于什么材料；允许多重解释并存但不等量齐观](/principles/interpretation-is-an-authored-claim.md) - ICON 允许不同观察者对同一作品形成不相容解释；报告与知识库中保存“谁提出何种解释”，不把分析者解释改写成作品固有属性，也不把任意联想与有据解释当同等有效。
- [出发点不一定是一句先验主题：问题与方案可以共同演变](/principles/origin-not-a-priori-theme.md) - 复盘时允许项目先有材料实验再理解需求、先有场景发现再发展故事、拍后通过剪辑形成概念；讲得很顺的创作故事未必保留了往返、放弃与偶然。
- [资料可信不等于与当前问题相关](/principles/reliable-not-necessarily-relevant.md) - 权威机构网页可能准确记录演职员表，却不包含道具设计来源；主创访谈适合回答意图，不适合证明材料配方；来源评估要问“来自哪里”和“能支持什么”。
- [多个来源也可能只是同一条消息的回声](/principles/echo-sources-not-independent.md) - 同一采访被三个网站转载仍是一条来源链；保留最接近原始陈述的记录，转载作查找或版本线索；真正的相互印证是不同材料从不同角度限制解释。
- [反推创作是多解问题：寻找证据足够区分到什么程度](/principles/reverse-inference-multi-solution.md) - 一间看起来很窄的房间可能来自空间、机位构图、人物家具摆放、后期裁切或其组合；即使确认空间窄，仍不知道是主动选择、场地限制还是剧情需要。
- [好的补证问题要能改变判断](/principles/good-questions-change-judgment.md) - “再找些支持疏离的资料”让研究只朝一个方向；“不同场地是否仍用这一布局？”“早期方案中空白是否原本承担动作？”才对应具体不确定性。
- [团队没有义务拥有一套完全相同的内在解释](/principles/team-need-not-share-one-interpretation.md) - 导演、美术、摄影和剪辑可能各自从不同问题进入并在制作中形成共同结果；作品一致性不证明参与者从一开始共享同一套语言。
- [反事实能帮忙，但不是历史录像的替代品](/principles/counterfactual-limits.md) - 反事实帮助定位选择在解释中的重要性；三个限制：想象版本≠实际版本、局部变化不只改变一个因素、今天能这样重做不证明当时这样思考；标注分析性反事实／原型测试／已发生版本比较。
- [什么时候可以停止补证](/principles/when-to-stop-gathering-evidence.md) - 已有材料足以完成当前任务且进一步研究不太可能改变决定；关键结论依赖无法获得的材料时停在条件性结论；问题问错时转向形式功能或新方案实验。

## Checklist

- [第五篇反例测试：创作出发点与解释边界](/checklists/p05-counterexample-tests.md) - “导演一定在暗示什么”、主创陈述目的、三篇同源转载、提案与访谈不同、常见细节、未找到意图资料、巧妙但无证据、两种不相容解释、反事实当动机。

## Template

- [假设矩阵：候选解释、目前支持、可能削弱的证据、值得寻找的资料](/templates/hypothesis-matrix.md) - 对关键现象只保留少数有区分价值的候选；以“人物长期位于画面边缘”为例；候选不一定互斥，可得出“多因素共同作用”。
- [最小假设卡：claim_type、question、scope、hypothesis、支持、替代、反证、改变条件、状态](/templates/hypothesis-card.md) - 状态描述适用于某条主张而非整件作品；解释被撤回不意味原始观察被删除；原始材料错误则相关解释需回查。

## Case Study

- [《小斧子》（Small Axe）：看似自然的场景由研究与跨部门选择形成](/cases/small-axe-research-and-collaboration.md) - 依据 BAFTA 2021 主创座谈文字记录：照片、档案、记忆与具体生活经验，美术与服装持续协调；不据此声称观看者反应或每个物件来历已核实。
- [Tim Walker《Illuminations》：一束红光为什么不能被解释成通用色彩象征](/cases/tim-walker-illuminations-red-light.md) - 依据 Getty 展览页收录的创作陈述：透明色彩与彩色玻璃经验、被照亮的红色与母亲制作灯罩的童年记忆；资料让解释更具体而不是更宏大。
- [虚构案例：台面上的一道裂缝可以意味着什么？](/cases/fictional-crack-on-table.md) - 虚构教学推演：面对“裂缝象征环境崩坏、瓶子代表消费主义冷漠”，按固定观察→分开解释目标→列区分性候选→写受限制结论四步推进到证据允许的位置。
