# 回答什么问题

分清词义之后，怎样真正观察、记录和比较？怎样把一张图、一组照片或一段影片转化为别人能回到原材料核查的描述，再从描述中提取组织关系？

# 核心主张

**先把看见的东西说成可检查的关系，再讨论它可能意味着什么。** 准确观察不是消灭直觉，而是让直觉有证据、有范围、可被修正；能定位的描述优于漂亮的形容词，有边界的解释优于看似完整的猜测。

# 本篇概念

## Framework

- [描述的四种精度：指认、位置、属性、关系](/frameworks/four-precisions-of-description.md) - 指认是否超出细节支持、位置是否足够、属性指哪一种“亮”、关系是颜色相近还是被组织成一组；精度服从任务。
- [形式分析：元素与组织原则（Getty 教学资料）](/frameworks/formal-analysis-elements-principles.md) - 线条、形状与体积、空间、色彩、质感作为观察入口，再以强调、平衡、运动、节奏讨论组织；两遍工作：先找特征，再找关系。
- [知觉组织：分组与图底，而非物件数量的简单相加](/frameworks/perceptual-grouping-figure-ground.md) - 接近、相似、共同变化、连续性、封闭等线索提供观察和检验方向；不问“有几个东西”，而问哪些成组、哪些成背景、哪些边界在争夺。
- [需要分开的四个对象：被摄物、拍摄影像、后续处理版本、当前观看副本](/frameworks/four-objects-subject-image-derivative-copy.md) - 每个对象能回答的问题不同，也各有不能直接推出的东西；避免把影像性质升级成物理事实。
- [缺失有四种意思：没有、没看见、无法判断、不适用](/frameworks/four-kinds-of-absence.md) - “此帧未见文字”≠“整张海报没有文字”；“未获得声音材料”≠“作品采用静默”；静态图片的镜头运动是不适用，不是资料缺失。
- [四个基本记录单位：对象—属性—关系—变化](/frameworks/object-attribute-relation-change.md) - 对象先确定指代再提高命名精度；属性给可见限定并说明参照；关系决定画面怎样成立；变化区分影片中多种运动来源。
- [关系类型与负空间：位置、相似、对比、遮挡、支撑、尺度、方向](/frameworks/relation-types-and-negative-space.md) - “石头在产品下方”是位置关系，“石头托住产品”加入接触与支撑解释，“石头象征可靠”进入意义推测；负空间要通过边界、面积与变化描述。
- [动态变化的五种来源：物体运动、摄影机运动、光或材料变化、剪辑、文字与数字效果](/frameworks/dynamic-change-sources.md) - 同一片叶子从左移到右可能来自叶子或镜头移动；信息不足时先写“相对位置发生变化”；前半段遮挡可能是时间结构的一部分。
- [观察维度菜单（八维）：适合的描述与越界说法](/frameworks/observation-dimension-menu.md) - 空间与尺度、形态与方向、色彩与明暗、材料与表面、图底与构图、人物与物件、图文关系、时间与变化——提问菜单，不是全填表格。

## Term

- [视觉描述（工作定义）](/glossary/visual-description-working-definition.md) - 对明确版本、明确范围内的可见对象、属性、关系和时间变化，作出可定位、可复核、与证据相称的陈述；可复核不要求同一种感受。

## Method

- [把大词改写成可分别核查的中层问题](/methods/big-words-to-mid-level-questions.md) - “冷峻的现代视觉”→空间是否常空置？人物是否被门框分隔？构图是否保持正面？规则何时被打破？每问需要自己的材料。
- [分析开头的材料说明：先检查你到底拿到了什么](/methods/material-version-statement.md) - 原始照片、压缩截图、网页预览、重剪视频、局部裁切还是最终发布版？有无声音、完整镜头起止、画幅、播放速度、显示尺寸？让未知继续存在。
- [四次观看：替代“一眼定风格”](/methods/four-pass-viewing.md) - 第一遍保留自然观看 → 第二遍不带风格名的分段描述 → 第三遍提取组织规则和局部反例 → 第四遍拿着反对意见回看；可按任务压缩。
- [视频抽帧：基本覆盖＋事件补充](/methods/video-sampling-coverage-plus-events.md) - 只抽开头中间结尾会漏掉短暂关键变化，只挑最漂亮帧会伪装出统一风格；先覆盖，再为遮挡、动作、场景切换补样，判断时长回到连续播放。
- [多人与 AI 协作：先定位分歧发生在哪里，再比较用词](/methods/locate-disagreement-before-words.md) - 分歧可能是对象边界、词义、观察材料、机制解释或价值判断不同；先比较定位与证据；观察阶段可先不提供想要的风格名以减少诱导。

## Principle

- [第一印象先放进“体验笔记”，不悄悄变成观察结论](/principles/first-impression-goes-to-experience-notes.md) - 不是禁止直觉：可以同时记录“我第一眼觉得沉重”和“主体轮廓宽厚、支撑面较大、向上运动很少”，但不把前者伪装成后者的客观同义词。
- [观看任务影响扫描：画面不能独自决定所有人的观看顺序](/principles/viewing-task-shapes-scanpath.md) - 没有眼动记录时，“观众先看这里”应降格为“这里提供了较强的注意线索”或“我本次观看最先注意到这里”。
- [色彩与情绪有关联，但没有通用解码词典](/principles/color-emotion-not-decoding-dictionary.md) - 颜色—情绪关联既有共享模式也受语言地理塑造，且研究针对颜色词与情绪概念；“蓝绿色＝清爽”不能写入观察层。
- [定位是证据的一部分：陈述必须绑定到对象](/principles/locator-is-part-of-evidence.md) - 借 W3C Web Annotation 的“内容与目标分离、片段定位”思想；纸上写“第三张图，产品左侧叶片”也有效，没有资源时不编造时间码或文件名。
- [光影与材质：观察到外观，不宣布灯型、灯距或表面配方](/principles/light-material-boundary.md) - 多种制作路径可能产生相似结果；先问光在当前画面里做了什么（分离、显体积、遮信息、生图案、保平面感），这仍是形式功能解释而非灯光师意图。
- [画外空间不是可以随意补画的世界](/principles/off-frame-space-not-free-to-fill.md) - 门口有人朝外看，只能说明作品设置了朝向画外的关系；“未出现生活杂物”不能直接解释成“人物没有生活”，原因可能是裁切、用途、时点或设计删减。
- [尺寸与位置测量：测的是画面，不是世界](/principles/measure-the-image-not-the-world.md) - “产品高度占画面三分之一”是图像比例，不能告诉现场有多高；裁切不同的版本不能直接比较比例；不必要的测量制造假精确。
- [灰度、缩略图和遮罩是干预，不是原作](/principles/diagnostic-derivatives-not-original.md) - 灰度删除色相与饱和度，缩略图损失细节，遮住道具只得到“可能参与竞争关系”的线索；辅助图须与原图分开标注，不能反过来成为原作特征的证据。
- [色值与直方图只回答窄问题，不输出“高级感得分”](/principles/color-stats-answer-narrow-questions.md) - 平均颜色相同的两张图分布可完全不同；工具应回答“标签附近局部明暗差异是否改变”这类问题，没有操作定义时复杂图表只是把模糊判断包装成测量。

## Checklist

- [第二篇反例测试：视觉观察与形式证据](/checklists/p02-counterexample-tests.md) - “肯定是胶片”、低分辨率局部截图、宽留白加碎高光、瞬间遮挡、观看者注意不同、假道具外观、要求“客观高级感”。

## Template

- [单条观察记录（visual_observation）](/templates/visual-observation-record.md) - asset_version、scope、locator、observation、relation、interpretation、alternatives、not_observable、next_check；字段是表达约定，删字段不等于删证据边界。

## Case Study

- [虚构案例：把一张假想护肤海报从形容词变成证据（四层）](/cases/fictional-skincare-poster-four-layers.md) - 虚构教学推演：低质量初稿 → 可检查描述 → 关系假设 → 待检验的观看解释 → 最小补证问题；故意不写“水滴正在悬浮”。
- [虚构案例：门框分隔的叙事片段与远景模糊前景的摄影系列](/cases/fictional-doorframe-film-and-distant-photo-series.md) - 同一观察程序用于叙事片与非商业摄影：记录门框何时分隔与跨越后的朝向；远距离与遮挡如何规定观看位置，而不是评价“主体不突出”。

## Exercise

- [练习：三份文本对比与“只交换证据位置”](/exercises/p02-three-texts-and-location-exchange.md) - 同一图像写名词清单、感受段落、含定位与关系的描述三份文本；两人独立描述后只交换证据位置、不交换风格名称。
