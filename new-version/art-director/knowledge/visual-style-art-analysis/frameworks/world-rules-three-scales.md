# 世界规则要回答什么

“未来感”“复古”“天然科技”不足以规定空间和道具。世界规则回答：物体是否服从现实比例，环境是否允许磨损，哪些东西可以变形，材料是否保留制造痕迹，文字是否属于世界内部。

规则不是一串审美禁令，而是**维持关系的约定**：“所有元素使用浅色”过于表面；“主体始终依靠局部明暗差异与背景分离，而不是靠新增装饰吸引注意”开始规定设计如何工作。

# 三个尺度

| 尺度 | 含义 |
|---|---|
| 全局约定 | 整件作品共同遵守的现实和观看条件 |
| 局部系统 | 某个场景或段落特有的组织方式，例如与前一场形成对照 |
| 事件例外 | 一个特定动作或叙事节点暂时改变规则 |

# 边界

分析时寻找规则的适用范围：某个幻想段落里的悬浮物体，不能自动说明全片都不遵守重力；产品最终展示镜头对可读性的要求，也未必应倒灌到全部情绪段落。
