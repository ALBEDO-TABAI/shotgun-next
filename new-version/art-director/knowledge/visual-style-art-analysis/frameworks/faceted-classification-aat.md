# 借用什么

Getty《艺术与建筑叙词表》（AAT）将作品类型、材料、技术、风格与时期等**分面**组织，并以“巴洛克大教堂”为例，说明这类表达组合了“风格”和“作品类型”，不应当作不可分的单一概念。值得借鉴的是其组织原则：**围绕概念区分词义，再用层级、关联、同义关系连接概念**；一个概念也可能处于多个较宽的语境之下。

# 转化为 skill

- 系统不应问：“它是商业风格，还是对称风格？”
- 而应问：“用途是什么？形式组织是什么？哪些历史来源得到支持？”

# Examples

> “这是一张商业性的、复古的、极简的、超现实的、有胶片感的高级广告。”

这里的词不处于同一分类位置，也不是六种风格的叠加——它们分属用途、历史来源、形式、修辞／再现、媒介外观与评价。

# 边界

不是把 AAT 的所有术语搬过来；“用途、题材、历史来源、形式、媒介、情绪”**不是从低到高的六个层级，而是回答不同问题的多个描述维度**。
