# 借用什么

Getty 的形式分析教学把**线条、形状与体积、空间、色彩、质感**作为基本观察入口，再以**强调、平衡、运动、节奏**等讨论组织方式。

# 转化

- 两遍工作：第一遍找特征，第二遍找关系。
- 写满一张“色彩、构图、材质”表不等于读懂作品；这些组织原则不是艺术必须遵守的法条。
- “画面不平衡”可以是准确的形式描述，但尚未构成负面评价——人物即将跌落时，不稳定可能恰好是作品需要的关系；是否恰当交给第七篇。

# 边界

教学分类，不是决定观众反应的实验规律；不把设计原则变成评分规则。形式分析负责描述结构，不负责证明历史来源。
