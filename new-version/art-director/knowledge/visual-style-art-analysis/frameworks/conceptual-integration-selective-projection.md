# 依据

Fauconnier 与 Turner 把概念整合理解为来自输入空间的**选择性投射**，并讨论整合空间中出现的**新结构**；明显的不协调不是所有整合的必要条件。

# 问题

新画面是否只把两个参照摆在一起，还是产生了原来各自没有的关系？

# Examples

- 弱组合：把花盆放进房间。
- 另一种方案：叶片承担屋顶、茎承担柱子、露珠承担照明点，使“植物”与“可进入空间”共同形成一个新设定。

重要的不是后者必然更好，而是两者组织机制不同。

# 边界

不能简化成“混合得越怪越有创意”。有些整合非常自然，几乎不让人意识到来源；有些有意保留矛盾。是否有效需具体任务与作品证据。该理论不是通用神经机制定论，也不是所有混合风格的唯一解释。
