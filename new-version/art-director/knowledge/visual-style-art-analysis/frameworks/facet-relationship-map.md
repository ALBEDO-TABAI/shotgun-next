# 关系

> 情境与类型提供问题和惯例；题材提供被表现的内容；历史谱系提供可能的参照；再现方式、形式组织、修辞和媒介共同参与呈现；观看条件与观众参与体验的形成。

# 边界

- 这是一张**分析关系图**，不是一条必然的创作因果链。创作者可能先有题材，也可能先发现某种材料再形成概念；不要把一种工作顺序当成全部作品的真实起点。
- **审美评价应在这张图之外单独进行**：它依据目标、标准和观看证据判断这些关系是否成立，而不是充当第十一个“风格”。
