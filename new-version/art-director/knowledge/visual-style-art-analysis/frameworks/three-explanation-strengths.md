# 三种强度

| 强度 | 含义 |
|---|---|
| 相容 | 某假设不与当前材料冲突 |
| 有支持 | 材料中存在对这个假设有帮助的线索 |
| 较能区分 | 某项证据使这个假设相对于其他候选更有解释力 |

相容只是最低条件：一幅画面几乎总可以与许多宽泛主题相容，这并不意味着这些主题都构成有质量的分析。

# 常见与独特

- 线索若在大量不相关作品中都存在（例如居中构图），单独支持某种特殊动机的能力有限；
- 少见组合与明确过程记录同时出现，解释作用可能更强。

# 不伪造概率

可以用语言说明“这个线索并不专属于当前解释；另一个线索更能帮助区分候选”。没有统计模型、样本和先验定义时，不应写“作者有87%的概率想表达孤独”。
