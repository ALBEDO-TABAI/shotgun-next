# 区分

**可辨识的对象、人物、场景**，与**形状、色彩、纹理和空间关系**，不是同一个分析层面。

# Examples

假设画面里有一片叶子：

| 陈述 | 层面 |
|---|---|
| “植物” | 物象识别 |
| “它是一条向上延伸的细长曲线” | 造型描述 |
| “它让人联想到生长” | 解释 |
| “因此证明产品具有某种功效” | 超出这张图能证明的范围 |

# 边界

- Andersson 对相关理论的研究提醒：不同学者对视觉意义如何形成存在分歧，不能把视觉关系简化为一套普遍、固定的解码表。
- 不应内置“圆形永远温柔、直线永远理性、正面永远亲密”这样的无条件规则。
