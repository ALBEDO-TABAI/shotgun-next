# Schema

| 对象 | 可以回答的问题 | 不能直接推出的东西 |
|---|---|---|
| 被摄物或场景 | 可确认的物件、结构、布置 | 不可见的背面、真实尺寸、采购来源 |
| 拍摄所得影像 | 画面中的透视、遮挡、清晰范围 | 唯一的焦距、灯位或制作部门 |
| 后续处理版本 | 裁切、文字、颜色和合成后的呈现 | 原片一定具有相同外观 |
| 当前观看副本 | 此显示条件下可见的关系 | 所有屏幕、印刷和场景下的体验 |

# Examples

- “杯子具有镜面高光”与“杯子由金属制造”应分开；
- “背景显得非常远”与“场地实际很大”也应分开。

制作方式的多解性在第四篇展开。
