# 四种成熟度

| 成熟度 | 含义 |
|---|---|
| 资料保存 | 知道作品在哪里、是什么版本 |
| 案例理解 | 能解释某个具体关系，并指出证据和替代解释 |
| 条件性规则 | 说明某类问题下可以尝试什么机制、需保留什么、在哪些情形会失效 |
| 迁移验证 | 把规则用到不同任务，记录新方案、测试和修订 |

# 边界

这些是本篇建议的工作状态，不是文献规定的统一等级。一个资料条目可以暂时停留在保存阶段，不必为了填满字段，编出它尚不具备的深层意义。
