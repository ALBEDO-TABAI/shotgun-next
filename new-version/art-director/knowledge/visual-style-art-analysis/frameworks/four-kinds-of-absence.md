# 四种缺失

| 类型 | 例 |
|---|---|
| 没有（在可检查范围内确认没有） | 画面可检查范围中没有文字 → “此帧未见文字” |
| 没看见（材料不完整） | 只得到局部裁切 → 不能写“整张海报没有文字” |
| 无法判断（材料缺失） | 视频没有提供声音轨 → “未获得声音材料”，不是“作品采用静默” |
| 不适用 | 静态图片的镜头运动 |

四者不能混用。
