# 依据

Dorst 与 Cross 的研究摘要以经验丰富的工业设计师为对象，讨论创造过程中问题与方案空间的共同演变。

# 启发

一个具体方案可以帮助我们发现原需求中的矛盾。例如试做“全场蓝绿色”后才发现包装难以区分——真正需要的也许不是颜色完全一致，而是环境与产品具有某种连续关系。

# 边界

- 不能直接推广为所有影视团队的普遍规律（摘要样本为九名工业设计师）。
- 它提供的是检查单向需求观的理论入口，**不是替某次客户变更作正当化**。
