# 四层（操作性划分，不是新的艺术史分类）

## 1. 对象：先确定指代，再提高命名精度

对象可以是人物、产品、道具、建筑，也可以是局部光斑、文字区和没有明确物体边界的色块。命名保留不确定性：“瓶状产品”“呈叶片轮廓的放大构件”“疑似反射”可能比错误的具体名称更有用。

## 2. 属性：给对象加上可见限定

“边缘较圆”“顶部反光明显”“标签正面局部可读”比“整体很有质感”更具体。形容词需要参照：“较大”相对于什么？“柔和”指阴影边界、亮度变化、轮廓还是体验？

## 3. 关系：决定画面怎样成立

关系通常比孤立属性更能区分作品，详见 [关系类型与负空间](/frameworks/relation-types-and-negative-space.md)。

## 4. 变化：影片不是一叠互不相干的静帧

详见 [动态变化的五种来源](/frameworks/dynamic-change-sources.md)。分析结论应覆盖“何时看见”，而不仅是“是否看见”。
