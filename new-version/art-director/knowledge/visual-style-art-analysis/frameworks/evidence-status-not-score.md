# 五种状态

| 状态 | 含义 |
|---|---|
| 成立 | 在当前证据与条件下成立 |
| 存在风险 | 有关系线索提示可能出问题 |
| 未成立 | 证据表明不成立 |
| 证据不足 | 尚未检查或材料不够 |
| 不适用 | 该维度与作品任务无关 |

每个维度输出状态并附理由。这里的状态是工作判断，不是经校准的测量单位。

# 必须分开

- 尚未做记忆测试，不能把记忆效果填零；
- 艺术作品不以购买为目的，购买指标应是**不适用**，而不是低分。
