# Schema

| 判断身份 | 例子 | 主要依据 |
|---|---|---|
| 可见描述 | 主体位于中央，周围存在大面积空场 | 当前可检查的图像 |
| 资料事实 | 制作团队说明该场景使用实体模型 | 对应访谈或制作记录 |
| 分析解释 | 空场可能使主体显得孤立 | 可见关系与论证 |
| 历史关系判断 | 与某传统存在引用或影响关系 | 特征比较加历史资料 |
| 目的或体验记录 | 客户希望清爽；某位观众感到紧张 | 明确的陈述者和情境 |
| 评价 | 对包装识别任务而言区分不足 | 目标、标准和相应证据 |

# 要点

- 不用一个笼统的“置信度”统治整份报告，而是分别记录判断性质。
- ICON 对艺术解释的建模也将解释者、所作识别及支持来源纳入结构。
- 关键规则：[创作者自述只证明“他这样解释”](/principles/creator-statement-proves-the-statement.md)。
