# 框架 · Frameworks

概念区分、分类轴与分层模型：十个分面、分析范围、四记录单位、六类组织位置、七类决策对象、证据身份、评价维度等。


# 一 风格概念辨析与分面分析

* [特征 → 特征关系 → 组织模式 → 有范围的风格概括](feature-to-style-progression.md) - 区分“某种特征”与“某种风格”的四级递进；以“留白”为例说明何时才有理由概括为简约呈现，且仍不等于 Minimalism。
* [分面分类：借 Getty AAT 的组织原则](faceted-classification-aat.md) - 围绕概念区分词义，再用层级、关联、同义关系连接概念；“广告”“青铜”“印象派”“对称”可共同描述对象，但不是同一组互斥选项。
* [沃尔夫林五组比较轴（改写为看片提问）](wolfflin-five-comparison-axes.md) - 线描性／绘画性、平面／纵深、封闭／开放、多样性／统一性、绝对／相对清晰——先比较“怎么看见”，再判断“看见了什么风格”。
* [图像志与图像学：三层解释框架（经 ICON 论文整理）](panofsky-three-levels-via-icon.md) - 识别对象和动作 → 识别约定主题、故事或形象 → 解释文化意义；对现代广告最重要的用途是限制解释的跳跃。
* [Bordwell 电影诗学：用可核查的中层问题代替风格名](bordwell-mid-level-questions.md) - 传统提供哪些选项、作品如何使用、哪些证据支持解释、反例能否修正理论；风格变化与创作者面对的具体问题相连。
* [视觉符号学：物象意义与造型意义分层](object-meaning-vs-plastic-meaning.md) - 可辨识的对象、人物、场景，与形状、色彩、纹理和空间关系不是同一分析层面；不内置“圆形永远温柔”一类无条件规则。
* [Rose 视觉研究方法：图像构成与使用场合分别记录](rose-image-and-its-context.md) - 同一张照片放在展览、详情页、杂志与私人相册里，分析任务不同；不能凭精致认定商业，也不能因来自广告就取消形式分析。
* [经验美学：审美情绪与审美判断是两种输出](leder-emotion-vs-judgment.md) - Leder 等的模型把感知、分类、理解、评价联系起来并区分情绪与判断；体验报告、机制解释、条件性评价、综合判断四句话不能互相代替。
* [十个描述分面（A–J）总览](ten-facets-overview.md) - 实践情境、类型、题材、历史谱系、再现方式、形式组织、修辞、媒介外观、观看关系、情绪体验——不是层级，不必全填，审美评价在分面之外。
* [十个分面之间的关系图（分析图，不是创作因果链）](facet-relationship-map.md) - 情境与类型提供问题和惯例，题材提供内容，谱系提供参照，再现、形式、修辞、媒介共同参与呈现，观看条件与观众参与体验形成；评价在图外。
* [分析范围五级：物件、单图／镜头、段落、完整作品、系列／作品群](analysis-scope-levels.md) - 每级适合判断什么、常见越界是什么；作品群可交叉，风格的稳定不等于所有部分都长得一样。
* [混合的三种工作类型：组织规则＋局部引用／同分面异质结合／跨分面有意冲突](three-hybrid-work-types.md) - 真正值得分析的是“什么与什么发生了关系”；判断“有意”仍需区分资料事实与分析假设，无证据时先说“形成了这种冲突”。
* [判断的证据身份（第一篇六类）](evidence-identity-six-kinds.md) - 可见描述、资料事实、分析解释、历史关系判断、目的或体验记录、评价——分别记录性质，而不用一个笼统置信度统治整份报告。

# 二 视觉观察与形式证据

* [描述的四种精度：指认、位置、属性、关系](four-precisions-of-description.md) - 指认是否超出细节支持、位置是否足够、属性指哪一种“亮”、关系是颜色相近还是被组织成一组；精度服从任务。
* [形式分析：元素与组织原则（Getty 教学资料）](formal-analysis-elements-principles.md) - 线条、形状与体积、空间、色彩、质感作为观察入口，再以强调、平衡、运动、节奏讨论组织；两遍工作：先找特征，再找关系。
* [知觉组织：分组与图底，而非物件数量的简单相加](perceptual-grouping-figure-ground.md) - 接近、相似、共同变化、连续性、封闭等线索提供观察和检验方向；不问“有几个东西”，而问哪些成组、哪些成背景、哪些边界在争夺。
* [需要分开的四个对象：被摄物、拍摄影像、后续处理版本、当前观看副本](four-objects-subject-image-derivative-copy.md) - 每个对象能回答的问题不同，也各有不能直接推出的东西；避免把影像性质升级成物理事实。
* [缺失有四种意思：没有、没看见、无法判断、不适用](four-kinds-of-absence.md) - “此帧未见文字”≠“整张海报没有文字”；“未获得声音材料”≠“作品采用静默”；静态图片的镜头运动是不适用，不是资料缺失。
* [四个基本记录单位：对象—属性—关系—变化](object-attribute-relation-change.md) - 对象先确定指代再提高命名精度；属性给可见限定并说明参照；关系决定画面怎样成立；变化区分影片中多种运动来源。
* [关系类型与负空间：位置、相似、对比、遮挡、支撑、尺度、方向](relation-types-and-negative-space.md) - “石头在产品下方”是位置关系，“石头托住产品”加入接触与支撑解释，“石头象征可靠”进入意义推测；负空间要通过边界、面积与变化描述。
* [动态变化的五种来源：物体运动、摄影机运动、光或材料变化、剪辑、文字与数字效果](dynamic-change-sources.md) - 同一片叶子从左移到右可能来自叶子或镜头移动；信息不足时先写“相对位置发生变化”；前半段遮挡可能是时间结构的一部分。
* [观察维度菜单（八维）：适合的描述与越界说法](observation-dimension-menu.md) - 空间与尺度、形态与方向、色彩与明暗、材料与表面、图底与构图、人物与物件、图文关系、时间与变化——提问菜单，不是全填表格。

# 三 混合风格与融合规则

* [混合的四种情况：多分面并存、局部引用、同层面异质结合、跨媒介转译](four-hybrid-situations.md) - 每种情况实际发生的事与分析重点不同；实际作品可同时包含几种，任务是说清楚而不是选一个标签。
* [结构映射：真正值得借的是关系，而不是长相](structure-mapping-relations-over-looks.md) - Gentner 区分关系结构迁移与对象属性匹配；“借叶片形状”近于复制，“借叶片围合空场的关系”可换成织物或建筑构件后仍保留组织逻辑。
* [概念整合：组合不只是两个来源相加](conceptual-integration-selective-projection.md) - Fauconnier 与 Turner 的选择性投射与整合空间中的新结构；“植物＋建筑”弱组合只是花盆进房间，强组合让叶片成屋顶、茎成柱、露珠成照明点。
* [来源关系的证据身份：明确引用／有过程资料支持的影响／仅形式相似／来源未知](source-relation-evidence-status.md) - 给来源关系设证据身份，而不是给风格算概率；多个弱线索不自动累积成历史结论；分析旧作不能把自己的主动参照倒写成原作者的参照。
* [寻找融合规则的六类组织位置](six-organizing-positions.md) - 主导秩序、局部引用、跨对象映射、材料转译、冲突管理、时间分配——是分析位置，不是六种新流派；主导不按面积投票。
* [变换操作库：从“像什么”转向“改了什么”](transformation-operations-library.md) - 选择与删减、尺度重设、材料替换、维度转换、角色转移、程度统一、局部例外、顺序重排、接缝显露；每个操作应回答“改变了什么关系”。
* [把分析变成创作约束：核心不变量、允许变化项、有条件的例外](core-invariant-allowed-variation-exception.md) - 三类规则而非一长串同等禁令；下游能据此选择，规则也需要版本——概念从“玩具世界”改为“真实家居中的玩具异物”时应更新规则而非只换参考板标题。

# 四 美术工作与设计决策

* [美术分析的三种问题：设计选择、实现路径、实际归属](three-questions-choices-paths-attribution.md) - 有哪些设计选择（依赖作品）；可能由哪些工作实现（提出候选）；实际是谁、在什么阶段作出（需要过程资料）；“可能做了”与“实际做了”在标题上就要分开。
* [美术工作的七类决策对象](seven-decision-objects.md) - 世界规则、空间结构、陈设与生活证据、道具与图形信息、材料与表面、制作与资源、现场与版本维持；可由不同岗位共同完成，产物不是越齐全越好。
* [世界规则的三个尺度：全局约定、局部系统、事件例外](world-rules-three-scales.md) - 世界规则回答物体是否服从现实比例、是否允许磨损、哪些可变形、是否保留制造痕迹、文字是否属于世界内部；分析时寻找规则的适用范围。
* [空间工作的三张地图：故事地点关系、制作空间、镜头所见画面](three-space-maps.md) - 三者可能不一致：相连的两间房可在不同地点制作，完整立面可能只搭可见部分，很深的背景可能靠层次与透视形成；避免把银幕空间误认为完整施工实体。
* [陈设的五种生活关系：获得、使用、维护、存放、淘汰](set-dressing-five-relations.md) - 从“这里有什么”走向“这些东西为什么以这种状态共同存在”；不要让所有东西拥有同一个年龄——研究具体人物如何积累物件。
* [道具作用表：行动、叙事、人物环境、形式组织、技术辅助、连续性](prop-function-table.md) - 道具不是一个物件类别，而是一组作用；给关键道具标注作用而不是只记名称数量，每类作用都有不能混淆的判断。
* [一项美术决定的四个必要信息与“消费者视角”](decision-four-necessary-info.md) - 要实现什么关系、为什么重要、有哪些已确认限制、由谁在什么产物上确认；下一位接手者需要什么、如何判断版本正确、哪些问题不能自行重判。

# 五 创作出发点与解释边界

* [“为什么这样设计”里的四个问题：形成原因、创作意图、形式功能、观看效果](four-why-questions.md) - 四者可能相关却不能互相证明：场地限制缩小布景可能产生压迫关系，创作者后来也可能认可——效果成立不证明最初就是目的，目的明确不证明观众都感受到。
* [溯因推理：从现象提出“值得检查”的假设，而非已证明的事实](abduction-worth-checking.md) - 看见某种关系；若某创作问题或选择存在，这种关系便较易理解；因此该解释值得进一步检查——最能讲通故事的解释也可能只是当前想得到的最好一种。
* [证据身份（第五篇七类）：各需什么支持，不应升级成什么](seven-evidence-identities.md) - 可见观察、形式解释、创作者自述、制作记录、历史归因、观看记录、创作建议；一个结论可依赖多种证据，但要分别说明角色，合起来也不自动证明唯一原因。
* [三种解释强度：相容、有支持、较能区分；常见线索与独特组合](three-explanation-strengths.md) - 相容只是最低条件；常见线索（如居中构图）单独支持特殊动机的能力有限；没有统计模型与先验定义时不写“87%的概率”。
* [创作出发点的六种类型（候选菜单）](six-origin-types.md) - 任务与传播问题、叙事与人物问题、形式与媒介问题、材料与工艺发现、个人经验与文化材料、资源协作与偶然——不要只寻找宏大主题。
* [解释质量五问：覆盖、区分、约束、范围、用途](interpretation-quality-five-checks.md) - “作品表达现代人的复杂情绪”几乎不限制任何观察；“人物试图接近时持续保留物理阻隔，最后一次行动中移除”提供了具体结构假设——具体不等于正确。

# 六 从抽象需求到场景方案

* [问题—方案共同演变：具体方案帮助发现原需求中的矛盾](problem-solution-coevolution.md) - 试做“全场蓝绿色”后才发现包装难以区分，真正需要的也许是环境与产品的连续关系；研究样本是经验丰富的工业设计师，不直接推广到所有影视团队。
* [把 brief 拆成五种信息：任务、已确认限制、体验目标、偏好与排除、未证实假设](brief-five-information-types.md) - 需求记录第一步不是把客户原话变成提示词，而是判断每句话的性质并分别处理。
* [概念的三个层次：意义方向、视觉命题、执行原则](concept-three-levels.md) - “与植物亲近”是意义方向；“进入叶片构成的庭院”是视觉命题；“叶片作为空间结构而非四处撒放的配料”是执行原则；三者连接但不混成一句口号。
* [先做不同机制的概念路线，再做同一机制的变体](concept-routes-vs-variants.md) - 路线改变组织关系（生活观察、尺度幻想、材料装置），变体调整颜色、叶片角度、台座形状；三个换色版本不是三种本质不同的创意。
* [原型类型表：各适合回答什么、不足以证明什么](prototype-types-table.md) - 关系草图或文字场景、简化空间模型、材料小样、动作预演、关键视觉、目标尺寸预览——具体划分由本包提出，借鉴原型与试验的工作思想。

# 七 作品评价与反馈验证

* [拆开“好”：五种判断类型](five-judgment-types.md) - 感受与偏好、形式判断、表达与艺术判断、项目适配判断、实际效果判断——判断对象不同，可以同时成立而不矛盾。
* [建立评价上下文：先写清五件事](evaluation-context-five-items.md) - 评的是哪个版本与范围、当前阶段应回答什么、用途与观看情境、哪些是硬要求哪些是可协商价值、谁在评价及其经验与利益位置。
* [不强求总分的七个评价维度](seven-evaluation-dimensions.md) - 目标适配、形式组织、概念具体性、表达与解释空间、完成与连续性、制作与交付适配、实际观看结果——按任务取用，各有应找证据与常见错误。
* [证据＋状态，而不是单一分数：成立、存在风险、未成立、证据不足、不适用](evidence-status-not-score.md) - 状态是工作判断不是校准测量；“证据不足”与“未成立”必须分开；艺术作品的购买指标是不适用而非低分；未做记忆测试不能填零。
* [观看结果要分变量取证](outcome-variables-separate.md) - 是否看到主体、是否识别产品、是否理解主题、产生什么感受、记住什么、是否知道品牌、是否点击或购买——互有关联但不是一件事，每项结论需要对应证据。
* [按问题选择证据方式：各自能回答什么、不能独自证明什么](evidence-methods-by-question.md) - 自查与专家评审、探索性访谈、有明确条件的任务测试、设计得当的比较研究、发布后表现记录——不是从低到高的固定阶梯。

# 八 分析沉淀与知识复用

* [从资料到知识的四种成熟度：资料保存、案例理解、条件性规则、迁移验证](four-knowledge-maturity-levels.md) - 工作状态而非文献规定的等级；一个条目可以暂时停留在保存阶段，不必为了填满字段编出尚不具备的深层意义。
* [八个模块怎样衔接：主要问题、核心产物、下游用途](eight-module-handoff-map.md) - 概念辨析→视觉观察→融合规则→美术工作→创作解释→方案构想→评价验证→沉淀复用；同一份观察不在每个模块重写成新事实，新解释引用旧观察但保留自己的判断身份。
* [规则的三个层次：表面配方、关系原则、条件性机制](rule-three-levels.md) - 蓝绿背景＋叶子＋水珠＋玻璃是配方；“主体与背景色接近时用反射、遮挡、明暗边界区分”是关系原则；加上任务条件、测试与失效时的调整就是条件性机制。
* [AI 参与时把四种操作分开：观察、外部核查、解释、创作](ai-four-operations.md) - 可以由同一工具完成，但输出身份必须清楚；分成多个 agent 也不自动解决问题——若都读同一份未核实总结，只会重复同一个错误。

# 09 研究来源与适用边界

* [资料性质不能互相替代：五类来源各自能支持什么](source-types-not-interchangeable.md) - 原始理论与实证研究、学术方法梳理与综述、专业机构与行业资料、主创陈述、数据与知识组织规范——每类的用途与不能推出的结论。
