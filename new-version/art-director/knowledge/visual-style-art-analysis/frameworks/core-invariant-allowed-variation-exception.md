# 三类规则

| 类别 | 含义 | 例 |
|---|---|---|
| 核心不变量 | 一旦改变，作品主要组织方式就不同了 | 观看者必须逐步进入一个缩小世界，而不是从外面俯瞰装置 |
| 允许变化项 | 不破坏核心关系前提下可调整 | 具体叶片种类、局部道具形状、某段运动速度 |
| 有条件的例外 | 某叙事节点或展示任务中短暂改变比例、密度或观看方式 | 需明确例外作用的范围 |

# 要点

- 不是越多越专业：短平快广告可能只需三条核心规则；长片可以有多个局部系统。重要的是下游能据此作选择，而不是每次都重新解释“什么算高级”。
- 规则需要**版本**：若导演决定从“玩具世界”改成“真实家居中的玩具异物”，很多看似相同的素材会承担不同角色；应更新概念和规则，不要只换参考板标题。
- 第八篇：不变量应尽可能少，但足够维持概念；具体植物若承担已确认的产品信息，就不能随意替换。
