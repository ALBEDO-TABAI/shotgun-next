# 五问

| 问 | 内容 |
|---|---|
| 覆盖 | 它解释了哪些具体关系，遗漏了什么？ |
| 区分 | 这些关系是否也同样支持很多其他解释？ |
| 约束 | 什么材料会使它需要修改？ |
| 范围 | 适用于一个物件、一个段落，还是整个作品？ |
| 用途 | 它能帮助继续研究、评价或设计什么，而不只是增加修辞？ |

不用“听起来有深度”作为标准。

# Examples

- “作品表达现代人的复杂情绪”——几乎不限制任何观察；
- “作品在人物试图接近时持续保留物理阻隔，而在最后一次行动中移除该阻隔”——提供了具体的结构假设。

具体不等于正确：仍需回到实际镜头检查“持续”是否成立，以及被忽略的反例是否改变解释。
