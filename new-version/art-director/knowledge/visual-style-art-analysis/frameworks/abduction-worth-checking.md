# 依据

学术百科对 abduction 的讨论，把它与演绎保证、一般性的归纳区分，涉及以解释为导向的非必然推理，以及这种推理能得到何种信任。

# 本包的简化形式

1. 我们看见某种关系；
2. 若某个创作问题或选择存在，这种关系便比较容易理解；
3. 因此该解释**值得进一步检查**。

# 边界

- 结论是“值得检查”，不是“已经证明”。
- 不知道幕后过程时，多个原因可能导向相似外观。最能讲通故事的解释，也可能只是我们当前想得到的解释中最好的一种。
- 是哲学方法梳理，不是对创作者动机读取能力的实证证明。
