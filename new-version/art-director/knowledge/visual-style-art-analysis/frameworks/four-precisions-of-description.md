# 四种精度

| 精度 | 问题 | 例 |
|---|---|---|
| 指认精度 | 到底是“某种植物”，还是能确认的茶叶？ | 细节不足时，较宽的名称反而更准确 |
| 位置精度 | “在旁边”是否足够？ | “左前方”“与标签上缘相交”“只在镜头末段进入” |
| 属性精度 | “亮”指物体本色浅、受光强、局部高光，还是整体曝光？ | 这些不是同一件事 |
| 关系精度 | 两对象颜色相近，还是在观看中被组织成一组？ | 后者需说明位置、距离和其他线索 |

# 原则

精度应服从任务：识别产品轮廓时不必精确命名每片叶子的植物学类别；研究某文化母题时，物件身份的精确考证则可能是关键。
