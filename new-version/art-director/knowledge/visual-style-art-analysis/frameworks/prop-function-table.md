# Schema

| 道具作用 | 需要检查的内容 | 不能混淆的判断 |
|---|---|---|
| 行动用途 | 谁接触、怎么用、是否重复、是否会改变状态 | 好看不等于适合表演使用 |
| 叙事信息 | 何时出现、何时被识别、是否与后续有关 | 出现不等于一定是象征 |
| 人物与环境 | 使用习惯、拥有关系、摆放逻辑 | 物件类别不能直接定义人格 |
| 形式组织 | 尺度、方向、遮挡、色块、支撑 | 构图作用不等于实际物理承重 |
| 技术辅助 | 是否产生反射、投影、液体效果或其他条件 | 屏幕效果不能唯一确认工法 |
| 连续性 | 朝向、数量、内容、损耗、替代件 | 一次拍得好不等于多次能一致 |

同一件物品可以同时用于行动、叙事、构图、身份说明和拍摄实现。
