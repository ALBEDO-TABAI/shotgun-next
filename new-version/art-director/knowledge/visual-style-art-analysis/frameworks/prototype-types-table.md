# Schema

| 原型类型 | 适合回答的问题 | 不足以证明什么 |
|---|---|---|
| 关系草图或文字场景 | 概念是否有具体组织方式 | 真实材料和最终质感 |
| 简化空间模型 | 尺度、遮挡、机位是否成立 | 颜色与表面效果 |
| 材料小样 | 边缘、反射、透光等候选外观 | 完整场景在所有镜头下都成立 |
| 动作预演 | 使用、变化与揭示顺序 | 最终表演和成片情绪 |
| 关键视觉 | 某一观看位置的综合关系 | 绕拍、背面和完整连续性 |
| 目标尺寸预览 | 当前版本的信息识别与布局 | 实际传播成效或销售表现 |
