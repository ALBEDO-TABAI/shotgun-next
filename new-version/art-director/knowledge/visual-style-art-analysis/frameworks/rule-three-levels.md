# 三个层次

| 层次 | 例 | 特点 |
|---|---|---|
| 表面配方 | 蓝绿色背景、叶子、水珠、玻璃 | 只是元素组合，适用性很难判断 |
| 关系原则 | 当主体与背景色彩接近时，尝试通过表面反射、遮挡和明暗边界建立区分 | 开始说明问题与办法，但需要具体条件 |
| 条件性机制 | 在需要保持环境同色关联、又要求包装可辨的静态产品画面中，测试不同表面反射及轮廓区分；若目标尺寸压缩了这些差异，调整信息层次或寻找更强区分方式 | 更容易执行和反驳 |

第三种并不是科学定律，而是更容易执行和反驳的设计建议。
