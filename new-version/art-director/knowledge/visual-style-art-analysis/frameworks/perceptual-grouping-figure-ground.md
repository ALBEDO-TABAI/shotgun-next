# 借用什么

Wagemans 等人的综述区分**知觉分组**与**图底组织**，讨论接近、相似、共同变化、连续性、封闭等线索，并把经验和注意纳入研究范围。

# 转化

分析时不仅问“有几个东西”，还问：

- 哪些东西被看成一组？
- 哪些成为背景？
- 哪些边界在相互争夺？

例如比较两片叶子是否因方向相似而形成连续趋势；检查前景枝条是否构成围合区。

# 边界

- 这些是观察和检验方向，不是“相似必然分组”的无条件保证；多条线索可能相互抵消。
- 本次核对的是作者机构收录的摘要，不据此复述全部实验结果或效应量。
