# 五件事

1. **版本和范围**：草图、概念图、材质测试、完整镜头、成片，还是发布后的传播结果？横版与竖版分别确认，一个版本的通过不覆盖另一个。某镜头局部凌乱可能被下一镜头重新组织。
2. **当前阶段应回答什么**：概念阶段查问题是否值得做、组织关系是否有潜力；布局阶段查空间与观看顺序；材料测试关注质感与光；终稿查完整关系与交付。不因灰模没有漂亮纹理否定空间概念，也不因终稿概念不错忽略穿帮。比较方案时留意**完成度不一致**：精修图更易获支持，不证明其概念更适合——可先统一到相近表达层次。
3. **用途与观看情境**：销售主图、品牌形象片、叙事电影、时尚编辑与展览优先级不同；用途不明时输出条件分支，不凭空替作品指定目标再据此批评。
4. **硬要求与可协商价值**：已确认的产品信息、尺寸格式、指定内容和制作限制；表达清晰、陌生感、历史准确、情绪强度需说明在具体项目中的地位。
5. **谁在评价**：创作者、客户、同事、目标受众与陌生观看者提供不同类型信息；记录角色用于解释证据范围，不是按身份决定谁永远正确。对艺术作品，分歧本身也可能是理解作品的重要材料。
