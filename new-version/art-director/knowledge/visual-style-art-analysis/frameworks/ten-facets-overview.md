# 使用约定

- **十不是理论上的神圣数字**，只是为了减少广告、摄影、影片分析中的概念混用。
- 分面不是数学意义上完全独立的变量，也不是每个项目都必须填写。
- 由上一版“用途、题材、历史来源、形式、媒介、情绪”六项升级而来：它们**不是从低到高的层级**。
- 审美评价在分面图之外单独进行，不充当第十一个“风格”。
