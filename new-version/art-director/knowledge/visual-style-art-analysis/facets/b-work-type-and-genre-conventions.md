# 记录什么

作品类型，以及已有充分依据的类型惯例，两者最好保留子字段。

# Examples

- “静物摄影”是作品类型；
- “恐怖片”涉及一种类型预期；
- “产品演示片”涉及用途与结构惯例。

# 边界

**类型与风格交叉，不互相决定。** 可以设想恐怖内容用明亮、规整的画面表达，也可以设想喜剧用低调照明和逼仄空间。不能从一组明暗特征直接推出故事类型。
