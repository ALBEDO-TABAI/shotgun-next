# 记录什么

观看距离、视点、遮挡、尺度感、是否直接面向观众、是否允许进入空间，以及屏幕、印刷或装置等呈现条件。

# 关键问题

> 观众像是在观察、进入、窥视、被展示，还是被置于一个不稳定的位置？

# 边界

这类解释应保留条件，不直接写成普遍心理定律。假设同一人物在两张照片中都位于正中央，是否形成亲近感，仍需看距离、视线、姿态、背景和具体用途。
