# 记录什么

可能的意义关系：类比、替代、并置、反差、夸张、尺度转换、材料错置、图文之间的解释或冲突。

# 关键问题

> 为什么把这些东西放在一起？它们的关系提供了什么理解方向？

“修辞”不是要求每张图都藏一个谜底。

# 边界

**修辞机制不是历史风格归属。** 尺度夸张可以服务于不同项目，不能因为出现尺度夸张就把所有作品归入同一个艺术运动。
