# 记录什么

委托性质、用途、目标对象、发布位置和观看条件。例如：品牌形象传播、销售转化、时尚编辑、叙事表达、艺术展览、个人记录。

# 边界

**商业性是使用情境，不是固定的视觉样式。** 一个商业项目可以刻意粗粝、含混、难以亲近；一个非商业项目也可以精确、华丽、产品化。

# 写法

不写“商业风”，而具体写“以包装识别为优先的销售物料”或“以情绪与品牌联想为主的形象影像”。
