# 案例性质

**虚构教学推演**：画面与细节为训练设定，不是对真实广告的观察，也不是实测数据。假定竖版产品海报：中心偏下浅绿色瓶状产品，上方两片放大叶片，底部不规则浅色台面，一颗水滴状物体与台面之间有间隙，右上角标题。

# 低质量初稿

> 这张图很高级，采用自然超现实风，温柔清爽的绿调营造梦幻氛围；美术通过真叶片和胶片感打造轻盈质感。

问题：真实材料、介质、统一受众感受、历史风格关系被一口气加入了观察。

# 四层

1. **可检查的描述**：浅绿色产品位于中心偏下，标签附近明暗变化多；两片叶状构件长度均大于产品高度；台面轮廓不规则；水滴状物体与台面有间隙，当前静帧未见连接结构；标题在右上方，未与产品轮廓重叠。——故意不写“水滴正在悬浮”：静帧只能确认相对位置和未见支撑。
2. **关系假设**：放大叶状构件使产品与植物比例偏离日常经验；上方构件与底部台面形成包围但两侧保持空场；水滴支撑关系不明确，形成与台面不同的稳定程度。
3. **待检验的观看解释**：可能让产品显得进入微型植物环境；是否轻盈取决于构件厚度、阴影、材质和观看尺寸——小尺寸里叶片若合并成暗块，也可能形成压顶感。两种方向都保留。
4. **最小补证问题**：制作方式找幕后或资产记录；场景概念找提案或创作陈述；观看体验安排受众反馈；小尺寸识别查看目标尺寸版本。这些问题不能互相替代。
