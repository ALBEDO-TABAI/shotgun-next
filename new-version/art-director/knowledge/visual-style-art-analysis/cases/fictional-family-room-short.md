# 案例性质

**虚构教学推演**，无成片或主创资料，只能作为候选方案。

# 任务

一名成年子女回到长期没有居住的旧房间，与父母短暂交谈。不能只决定“复古家具、暖色灯光、旧照片”。

# 拆解

- **行动**：人物是否必须把椅子挪开才能坐下？双方是否隔着书桌？门能否让另一人始终处于门口？
- **生活证据**：房间保存了哪些旧物，又有哪些物品已被他人使用或替换？
- **观看**：镜头从门外看，还是进入房间？

# 多解性

保持原样的房间不必然等于怀念，也可能是长期未处理；新旧混用不必然等于关系变化，也可能来自资源条件。

# 可交付

不是一张“怀旧情绪板”，而是空间与行动草图、物件拥有关系、关键状态、镜头可见范围和需要研究的具体生活细节。
