# 案例性质

**虚构教学推演**：时长、场景、产品要求与方案均为教学假设，不对应真实品牌或已拍摄作品；时间段是创作计划，不是对视频的标注。

# 1. 假设任务

蓝绿色包装；希望植物联想、清爽、轻盈；最终清楚展示产品身份；横版与竖版；不直接使用真实浴室。功效陈述不在假设范围内。

# 2. 视觉命题

> 产品位于一座由放大叶片构成的微型庭院。前段通过局部材料建立感官线索，中段揭示空间比例，最后让环境为产品展示让出明确位置。

核心不变量：“叶片构成空间”与“观看逐步获得尺度信息”，不是绿色越多越好。

# 3. 空间与道具分工

上方叶片负责围合，侧面叶片负责局部遮挡与揭示，底部台面负责稳定参照；水只在能改变光或动作关系的地方出现。产品保持可识别比例与包装版本，环境允许放大——提前说明哪些保持现实、哪些改变尺度。

# 4. 时间方案

| 计划段落 | 主要画面任务 | 美术需要成立的关系 | 待测试问题 |
|---|---|---|---|
| 0—7秒 | 建立局部感官线索 | 叶片边缘与水光可见，但不急于交代全场 | 是否只是无关的漂亮特写？ |
| 7—18秒 | 逐步揭示庭院与产品 | 相对位移让比例关系变得可理解 | 观众能否建立空间，而非认为画面突然换了？ |
| 18—30秒 | 保留环境关系并明确展示 | 主体与背景分离，关键包装信息可辨 | 横竖版是否都保住主要关系？ |

时间比例不是品牌片的固定公式。

# 5. 优先原型

先做无精细材质的尺度与机位测试（叶片像屋顶而不是压在瓶子上）；再做关键边缘材料测试；再做局部到整体的简化运动预演；最后检查目标尺寸中的产品展示。第一步不成立就先改概念或比例，不必继续做高精水珠。

# 6. 允许变化与例外

叶片种类、部分颜色明暗和次要台面轮廓可变；包装身份与关键尺度关系不随意变。独立销售结束画面应视为有条件的段落例外并设计过渡，而不是藏在“后期再接”里。

# 7. 测试后的两种回路

- 观看者无法建立微型庭院 → 增加稳定比例参照或改变揭示顺序，不必立刻放弃植物元素。
- 场景清楚但产品难识别 → 局部调整明暗、遮挡或最后段落职责，不必把整个世界改成白底。
