# 案例性质

**有来源的案例**：依据 MoMA 馆藏记录（覆盖毛皮的杯、碟与勺）及其与当时超现实主义展览关系的说明。“超现实主义”在这里有历史资料支持，不只是看图联想。

# 分面拆解

| 分面或范围 | 可以怎样描述 |
|---|---|
| 被表现／使用的对象 | 熟悉的饮用器具 |
| 材料与制作 | 日常器具被毛皮覆盖，有馆藏记录支持 |
| 历史关系 | 与超现实主义活动及展览存在已记录的联系 |
| 形式与修辞分析 | 原有器具轮廓与新的表面触感发生冲突 |
| 体验解释 | 对触摸的想象，与对饮用的想象可能互相抵触（MoMA 的解释也讨论了这一不相容） |
| 分析对象边界 | 雕塑作品本身，与拍摄它的照片，应分别判断 |

# 两个结论

1. **它不是因为物理上无法存在才产生异常**：物件真实存在，异常发生在熟悉的功能预期和材料关系之间。
2. **把毛皮用到另一条广告里，不会自动继承其全部艺术史身份**：可能迁移的是“改变器物—材料—使用之间的关系”这一机制。

这就是“学到方法”与“复制表面标签”的区别。
