# 案例性质

**有来源的创作陈述案例**：依据 Getty 展览页面收录的 Tim Walker 创作陈述，不进行未提供图像的独立逐帧分析。

# 资料说了什么

在 *Illuminations* 的说明中，Walker 将透明色彩与彩色玻璃等视觉经验联系起来，并把被照亮的红色与母亲制作灯罩的童年记忆、回家的感觉相联系。

# 支持／不支持

- 支持：他公开把私人记忆作为该拍摄的一个创作关联。
- 不支持：“所有红光都象征母亲”“所有观众都会想到家”；也不能独自证明这一记忆是项目的唯一开端。

# 三种不同陈述

1. **资料陈述**：Walker 在该页面如此描述自己的个人联想。
2. **分析推论**：色彩的创作含义可以通过个人经验与材料外观共同形成，不必只从通用象征表中取得。
3. **创作启发**：在新项目中寻找与具体经验相连的光和材料，再测试目标观看者能否以作品需要的方式理解。——这不是前两种的历史事实延续，而是新方法建议。

# 为什么来源让解释更具体

没有陈述，分析者可能套用热情、危险、欲望等宽泛词；获得陈述后，是缩小到资料真正说过的关联，而不是把所有细节都收编进“母亲”主题。良好的研究常常让我们少说不必要的话。
