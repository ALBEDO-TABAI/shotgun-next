# 案例性质

**全部为虚构案例与迁移练习**，不是已拍摄项目或已完成的测试。

# 1. 初始案例的有限设定

一张护肤产品概念图：叶片明显大于包装，围成开敞空间；产品位于平缓台面，背景无具体室内边界；整体偏同色，但瓶身表面与环境反射不同。分析范围只有这张概念图，不含镜头运动、真实材料或受众反馈。

# 2. 决策卡

- **关键选择**：把植物从小型成分装饰放大为主体所处的环境。
- **可见依据**：叶片与包装的比例、叶片形成的顶部及两侧边界、产品与前后景的遮挡关系。
- **作用假设**：观看者可能由“产品旁边有植物”转向“产品进入一个植物空间”——解释，非已测效果。
- **替代解释**：也可能仅被看作巨型道具展示；区分需检查空间线索与观看者描述。
- **实际制作**：未知。不能因非现实尺度就认定全部由三维制作。
- **迁移规则**：将原本用于说明属性的小元素提升为可进入、可遮挡、可组织前后关系的空间结构。
- **失效条件**：放大后仍只贴在背景上；主体被环境吞没；尺度线索在裁切后消失；具体物件含义与新任务冲突。

# 3. 迁移到时尚编辑摄影

新任务：表现人物与记忆空间的关系。可把日常书信、织物或家具局部发展为空间边界，但不能只把模特替换进原产品位置；重新判断人物尺度、动作、服装、观看距离和材料与主题的关系。包装识别不再成立，身体动作与情绪关系成为新限制。保留的是“局部物件变成环境”的操作，而不是叶子、水珠和蓝绿色。

# 4. 再迁移到非商业空间作品

任务改为“可看见但无法进入”：放大的物件构成**阻隔**而非保护主体的庭院——相同尺度操作产生不同观看关系，需要新解释、新构图和新评价标准。

# 5. 回写知识

记录新任务、保留的关系、改变的条件、原型结果和规则修订；失败时记录发生在哪个环节（尺度不成立、材料阻碍动作、规则不适合任务）。不必删除原卡，而是收窄适用范围或拆开混在一起的两个机制。
