# 案例性质

**有来源的过程案例**：Sarah Greenwood（UAL 访谈，2023）；Greenwood 与 Katie Spencer（The Credits，2024 重刊页面）。

# 资料支持什么

- 与摄影及服装相关的测试和协调参与了颜色决策（R10）；
- 二维与实体元素的组合，以及通过绘制并覆盖透明树脂形成泳池表面（R11）。

# 本包提炼的工作原则

- 不要让各部门各自拿着一个“正确的颜色”在成片里互相抵消；
- 围绕所需画面选择制作路径，而不是先把技术排成高低等级。

# 边界

主创自述是过程证据，不是受众效果测量；没有对全片逐帧复核；重刊日不当作首次采访日；案例手段不推广为行业必须采用的做法。
