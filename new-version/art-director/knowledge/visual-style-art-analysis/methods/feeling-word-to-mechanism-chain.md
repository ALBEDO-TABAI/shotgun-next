# 转译链

> 任务 → 想改变的观看关系 → 候选机制 → 可见／可发生的事件 → 场景与材料选择 → 测试问题

这是工作辅助链，不是实际创作必须严格遵循的心理顺序。

# Examples

- “轻盈”可以来自：物件悬浮、薄片结构、少量接触、稀疏布局、缓慢摆动、开放空间，也可以来自人物卸下重物后的动作——它们不是同义词，而是不同设计路线。
- “保护”分三条路线：产品置于包围结构中（强调边界）；外部冲击与内部稳定的对照（强调状态差异）；人物使用后的行为（强调体验）。三条涉及不同场景、动作和证据需求；不能只因为都用了透明罩，就认为表达同一件事。
