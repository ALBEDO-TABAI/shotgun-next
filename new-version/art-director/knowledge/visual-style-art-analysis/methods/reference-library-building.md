# 步骤

1. **收集理由进入条目**：一张图可以因空间关系、材料处理、道具使用、失败的遮挡或异常的观看顺序被收录，不必都是“喜欢的作品”。记录“为何收录”和“与什么问题有关”，未来检索才能找到不同路径和反例。
2. **说明覆盖与偏向**：见 [资料库说明自己的组成](/principles/library-describes-its-composition.md)。
3. **不把转载次数当独立证据**：见 [同一条消息的回声](/principles/echo-sources-not-independent.md)。
4. **为关键概念写编码说明**：见 [编码说明模板](/templates/coding-note.md)；多人先独立分析一小组案例再讨论差异，发现词义或分析单位不清之处。
5. **检索同时支持“像什么”和“解决什么”**：见 [检索可以宽，结论必须窄](/principles/retrieval-wide-conclusion-narrow.md)。
