# 步骤

1. 为当前任务的一个维度写三级（或多级）描述锚点。例：“产品识别”
   - 一级：目标尺寸下产品主要特征无法辨认；
   - 二级：能够辨认但受到局部干扰；
   - 三级：在当前测试条件下能够完成既定识别任务。
2. 说明这是**有序类别**：不意味着二级到三级与一级到二级有相同差距。
3. 若使用均分，说明它只是沟通辅助，不能当成严格等距测量。

# 反模式

“高级感八分”如果没有对象、观看条件与等级含义，几乎无法支持可执行的修改。
