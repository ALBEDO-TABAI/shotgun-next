# 提问顺序

1. 人在这里能做什么？
2. 物体从哪里进入？
3. 一次转身会看见哪些区域？
4. 门、窗、台面和通道如何限制动作？
5. 摄影机有没有观察这些动作的位置？

# Examples

- 若一个场景的情绪依赖“人物必须绕过障碍才能接近另一人”，这个障碍就不是可随意替换的背景装饰，它参与行动结构。
- 静物摄影也有行动逻辑：产品是否需要倾倒、滴落、转动、打开或与液体接触？没有这些要求，承重、重复使用和清洁问题可以简化；有，就不能只按静态美感制作。
