# 步骤

1. 判断冲突类型：
   - 一位说“太空”、另一位说“很克制”→ 可能是**目标不同**；
   - 两位对同一细节描述不同 → 可能是**观看尺寸不同**；
   - 同样条件下仍然有分歧 → 保留**审美立场差异**。
2. 先修正事实错误；
3. 再明确项目决策权；
4. 记录没有被选择的合理解释，而不是把所有异议写成“已解决”。

不是每次都需要投票达成统一。
