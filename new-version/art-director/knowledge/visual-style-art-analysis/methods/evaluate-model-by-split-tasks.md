# 审查维度（本包提出，不是现成统一基准）

1. 对象是否出现；
2. 属性是否有依据；
3. 关系是否定位正确；
4. 引用是否支持对应句子；
5. 未知是否被保留；
6. 创作建议是否明确标为新提案。

# 原则

- 不能用“文字很专业”的总分代替这些维度，也不能把对象识别正确等同于风格分析准确。
- 记录错误率时写清**分母和抽样单位**：核查了哪些可见事实陈述、哪些无法核查；无法核查项不要当作正确，也不要悄悄丢掉。
- 对开放解释问题，说明论证质量往往比强制二选一更合适。
