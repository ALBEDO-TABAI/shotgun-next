# 一条有用的过程线

1. 起初面对的具体问题；
2. 第一次可定位的方案；
3. 触发修改的材料或反馈；
4. 保留与放弃的选择；
5. 最后实现的版本；
6. 后来如何解释这一结果。

获得提案、分镜、试拍和访谈时，按时间追踪关键变化，而不是把所有材料平铺成“参考来源”。

# 原则

- 每一项都可能未知。不能为了让时间线完整，自动补出“导演先提出主题，美术再搜索参考，最后完美执行”的理想流程。
- **不同时间的陈述可能都真实，却回答不同问题**：早期提案强调“保护”，成片访谈强调“隔离”，不一定其中一份错误。先核对版本和陈述语境；确实变化就保留变化；同一时点的冲突则记录分歧，不悄悄删除不一致的材料。
