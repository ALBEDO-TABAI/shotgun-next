# 为什么

视觉分析最容易漏掉的对象，不是画面中的小道具，而是**画面自身的版本与观看条件**。

# 检查项

- 这是原始照片、压缩截图、网页预览、重剪视频、局部裁切还是最终发布版？
- 当前包含声音吗？有完整的镜头起止吗？
- 是否知道画幅、播放速度、显示尺寸？

# 原则

这段说明不需要把未知全部解决，但**必须让未知继续存在**。例如网页上的黄色偏色可以描述为“该预览版本整体偏黄”，不能直接认定现场使用了暖色灯具。
