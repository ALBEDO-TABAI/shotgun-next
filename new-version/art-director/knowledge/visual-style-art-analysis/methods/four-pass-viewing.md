# 步骤（可按任务压缩，不要求机械重复四次）

1. **保留自然观看，不急着解释**：完整观看，记录第一注意对象、整体体验、明显变化和未理解之处；影片先按正常速度看。输出叫“观看记录”。
2. **不带风格名的分段描述**：照片分主体区、背景区和关键接触区；影片优先按镜头或有意义的关系变化分段。分段标准与问题相关——分析“产品如何被发现”，节点可以是遮挡开始变化、主体可识别、标签可读。
3. **提取组织规则和局部反例**：不写“对称＋低饱和＋长镜头”，而写“空间保持正面而稳定，人物的移动成为少数变化来源”；主动寻找例外——一个斜向构图可能在打破前面建立的秩序，不删为噪声。
4. **拿着反对意见回看**：“人物被环境压迫”是否也可能是摄影机距离造成？“主体始终被突出”在小尺寸预览中是否仍可辨？把没有证据的部分降级为候选解释。

分析不需要消灭全部不确定性，但需要让确定与不确定不再混在一句话里。
