# 为什么

同一个词在不同句子中可能落入不同分面，不能给每个汉语词指定一个永远固定的位置。

# Schema

| 字段 | 内容 |
|---|---|
| 名称与词义 | 此处取哪个义项 |
| 所属分面 | 见 [十个分面](/frameworks/ten-facets-overview.md) |
| 适用范围 | 物件／单图／段落／作品／系列 |
| 支持该判断的特征组合 | 组合，而非单一特征 |
| 不能单独作为依据的特征 | 例如“单独添加颗粒”不足以支持“胶片感” |
| 易混淆概念 | 历史运动、相邻形容词 |
| 相关案例 | 正例、反例 |
| 参考来源 | 有来源的定义或历史说明 |

# Examples

“胶片感”词条应允许记录：当前是外观描述还是制作事实？具体观察到哪些特征？这些特征是否也能通过其他方法产生？缺少什么资料才无法进一步判断？

# 边界

借鉴的是概念词典的结构思想，不要求搭建复杂技术系统。
