# Schema（以“主体隔离”为例）

| 字段 | 内容 |
|---|---|
| 含义 | 与其他对象在位置、边界或注意层次上的分离，不只是物件数量少 |
| 可接受的证据 | 可定位的边界、空场、明暗或遮挡关系 |
| 不计入的相似情况 | 仅因元素少而“看起来空” |
| 局部与整体 | 某一局部隔离与整幅图的组织规则分开记录 |
| 正例／反例／难判案例 | 各若干 |

# 用法与边界

- 多人先独立分析一小组案例，再讨论差异，有助于发现词义或分析单位不清楚之处。
- **一致性高不自动等于判断正确**：团队可能共同接受了错误定义。
- 解释性问题存在分歧也不自动意味着流程失败；要区分对象漏看、术语混淆与合理解释差异。
