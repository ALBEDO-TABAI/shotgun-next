# Schema

```yaml
claim_type: "形式解释／意图归因／形成原因／观看效果"
question: "本次真正要回答的问题"
scope: "作品、场景、镜头或物件范围"
hypothesis: "可被修正的解释"
observed_support: []
documented_support: []
alternatives: []
contrary_evidence: []
what_would_change_the_claim: "应能说明改变条件"
conclusion_status: "有支持／部分支持／待确认／已撤回"
next_step: "只有与当前任务相关时才继续补证"
```

# 用法

- 状态描述适用于**某条主张**，不适用于整件作品。
- 一个解释被撤回，不意味着原始观察也被删除；原始材料错误，则相关解释需要回查。
