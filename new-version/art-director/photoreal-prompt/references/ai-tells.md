# AI 痕迹诊断

诊断时按类别扫一遍图，写出“什么东西 + 哪里不对”。每一项都要在提示词里找到对应的修正规则。下表右列是可以直接改写使用的规则片段。

## 全局成像

| 痕迹 | 修正规则片段 |
|---|---|
| 从近到远一样锐利，景深不符合镜头和距离 | 按〈焦段、光圈〉，焦点在〈主体〉，背景随距离自然渐虚 |
| 过度干净，没有噪点和颗粒 | 保留暗部的细小噪点（或胶片颗粒），不要数码降噪后的蜡质平滑 |
| HDR 式影调：暗部全部提亮，高光不溢出 | 暗部允许沉下去，亮处允许轻微过曝，不要每处都有细节 |
| 锐化光晕，边缘像描了线 | 不要过度锐化，边缘自然柔和 |
| 饱和度高、颜色“整洁”，像统一套了预设 | 色彩来自〈设备或胶片〉，不同材质的颜色有各自的偏差 |
| 没有镜头特征 | 边缘有轻微暗角和解析下降（手机则是轻微畸变） |
| 整体“完美中间调”，像广告精修 | 不要商业精修和棚拍质感 |

## 光

| 痕迹 | 修正规则片段 |
|---|---|
| 均匀照明，找不到光源 | 主光来自〈具体光源〉，〈方向〉，形成自然的明暗过渡 |
| 多处光的方向不一致，到处都有轮廓光 | 全画面只有〈1–2〉个一致的光源方向 |
| 灯具亮着，却不照亮周围 | 〈灯〉是真实亮着的光源，只照亮附近一小片区域，并迅速衰减 |
| 缺少反射：眼镜、屏幕、玻璃、桌面 | 〈镜片或玻璃〉上有微弱的环境反光，〈桌面〉有柔和、不完整的倒影 |
| 色温单一 | 混合光：〈灯〉偏暖，〈窗或远处〉偏冷 |

## 构图与瞬间

| 痕迹 | 修正规则片段 |
|---|---|
| 过分居中对称，像海报 | 取景有轻微的不水平，左右留白不均（服从体裁） |
| 摆拍，“营业式”表情 | 像动作进行到一半时拍下的瞬间 |
| 布景像样板间，没有杂物 | 房间有人住、每天在用，有合理的生活杂物 |
| 画面凝固，没有一点动感 | 〈手、头发、衣角〉有轻微的运动模糊 |

## 人物

| 痕迹 | 修正规则片段 |
|---|---|
| 塑料感、蜡质皮肤，或毛孔纹理处处一样 | 保留毛孔、绒毛、细小瑕疵、淡红和油光，不同部位的质地不同 |
| 眼睛过大，两眼的高光一模一样 | 眼睛是现实大小，眼白比例自然，眼神光来自真实光源的方向 |
| 五官完全对称 | 眉、眼、嘴角有极自然的左右差异 |
| 牙齿整齐雪白 | 牙齿颜色和排列自然，不是纯白 |
| 发丝雕塑感，或纹理重复 | 有碎发、毛躁、浮起的发丝和不规则的发束 |
| 手指错误 | 手指数量、关节、长度和交叠方式都自然 |
| 衣褶像雕塑，布料没有重量 | 〈面料〉有重量，褶皱跟着姿势自然下垂，有轻微起球或褶痕 |
| 妆容和发型过于完美 | 妆发像当天早上自己打理的 |

## 物件与环境

| 痕迹 | 修正规则片段 |
|---|---|
| 文字乱码、字母变形 | 文字清晰可读、拼写正确；不确定时只保留图形，不要乱码 |
| Logo 或品牌变形 | 标志形状准确；无法保证准确时，画成看不清细节的小尺寸 |
| 物件崭新，没有使用痕迹 | 有指纹、薄灰、划痕、褪色、歪斜和磨损 |
| 重复元素（相同的书、叶子、砖） | 同类物件的大小、颜色和新旧程度各不相同 |
| 结构错误（透视、支撑、连接） | 家具和建筑的结构、透视、支撑关系都合理 |
| 所有材质带着同一种 CG 光泽 | 木头、纸、布、金属、塑料各有各的反光方式 |
| 植物、食物过于完美 | 叶片大小不一，有枯边和虫孔，食物有不规则的边缘 |

## AI 审美残留

| 痕迹 | 修正规则片段 |
|---|---|
| 橙青调色、梦幻光斑、过度的奶油虚化 | 不要电影预设式的调色，也不要人为添加的光斑 |
| 体积光、丁达尔光随处可见 | 只有在〈烟、尘、雾〉存在时才出现光束 |
| “史诗感”和过度的戏剧化 | 画面平常、安静，像生活中本来就会发生的一幕 |
