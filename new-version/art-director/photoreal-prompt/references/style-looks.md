# 风格翻译

用户点名的风格，在提示词里写成“风格名 + 3–6 条可见特征”。只写一个名字，模型容易取到海报、剧照拼贴或网络上“XX 风”的 AI 图，这些恰恰是 AI 味的来源。

写实语境下，“某某风格”的意思是：像这部片子或这位摄影师**真实拍下的一帧**。因此来历句要写成：

> 像〈年代〉〈导演 / 摄影师〉作品中的一帧真实画面，〈胶片或设备〉拍摄，〈拷贝 / 扫描 / 修复版〉

## 解码任意风格的八个维度

遇到表里没有的风格，按下面八个维度逐项回答，再挑最有辨识度的 3–6 条写进提示词。

1. **媒介**：胶片还是数字？什么画幅比？是修复版还是旧拷贝？
2. **光**：动机光还是影棚光？硬光还是软光？主光来自哪里？
3. **色**：主色调是什么？肤色怎么处理？暗部偏哪个颜色？
4. **镜头与运动**：广角还是长焦？手持还是固定？有没有运动模糊？
5. **构图**：对称还是偏心？前景有无遮挡？景深多深？画框之内有没有第二层画框？
6. **美术与年代物证**：服装、招牌、物件、建筑。
7. **人物状态**：表演的松紧、视线方向、姿态。
8. **瑕疵特征**：这种风格特有的“不完美”（颗粒、拖影、褪色、光晕）。

**时代错位**：如果用户要的内容与风格的年代不符（比如“邵氏风格的便利店”），有两种处理，择一执行并写明假设：

- 把内容换成那个年代的对应物（1970 年代香港的士多店）。
- 保留现代内容，只借用媒介和光色（“像用邵氏片厂的方式拍了一个现代便利店”）。

## 媒介型风格（直接对照成像媒介）

胶片型号、CCD、拍立得、DV、一次性相机等，见 [成像媒介](capture-media.md)。风格名同时指向媒介和人时，比如“90 年代全家福”，媒介和年代物证都要写。

## 两个风格混合

- 先定一个主风格，它决定媒介、光和色。
- 副风格只贡献 1–2 条特征，比如构图，或者某一种特定的光。
- 写明混合关系，例如“以柯达金 200 的媒介拍出是枝裕和式的日常观察”。
