# 主体模块

按画面主体选模块，把里面的规则写进“主体细节”组。每个模块都分两类规则：

- **体裁惯例**：这类画面在现实中本来就应该是什么样子。通用规则和它冲突时，以体裁惯例为准。
- **真实锚点**：模型最容易做假的地方。

## 日常人像 / 生活照

- **体裁惯例**：抓拍，视线可以离开镜头，取景允许不工整。
- **真实锚点**：
  - 骨骼比例写实，眼睛不放大。
  - 左右脸有差异。
  - 笑容和表情只是轻微的肌肉牵动。
  - 皮肤有毛孔、绒毛、红晕，局部有油光。
  - 头发有碎发和毛躁。
  - 手指自然，拿东西的姿势真实。
  - 衣服有褶皱，有重量。
  - 妆发像自己打理的。

## 证件照 / 形象照

- **体裁惯例**：
  - 正面直视，头肩居中，左右对称是规范。
  - 纯色背景，柔光箱正面或 45° 布光，表情平静，不能要求倾斜、抓拍或视线偏离。
- **真实锚点**：
  - 皮肤质感保留，但只做轻度修饰，达到照相馆标准修图的程度，而不是网红滤镜的程度。
  - 发丝边缘和背景之间有自然的过渡，不能像抠图贴上去。
  - 背景有极轻的明暗渐变，不是数值上绝对均匀的纯色。
  - 眼睛里有柔光箱形状的眼神光。
  - 衣领和肩线是真实布料的结构。

## 群像 / 合影

- **体裁惯例**：前排站或坐、后排站；允许有人眨眼，有人没看镜头。
- **真实锚点**：
  - 每个人的身高、体型、肤色、服装新旧各不相同，脸不能像同一个模子。
  - 近处的人比远处的人更大，也更清晰。
  - 人与人之间有遮挡和重叠。

## 儿童 / 老人

- **儿童**：动作模糊很常见，衣服上有污渍，头发乱，表情不受控。
- **老人**：皱纹、老年斑、松弛的皮肤和手上的青筋要写实，不要为了“好看”把这些抹掉。

## 食物

- **体裁惯例**：
  - 家常饭菜：俯拍或斜拍，餐具不配套，有吃过的痕迹。
  - 餐厅出品：盘边干净，但食物形态自然。
- **真实锚点**：
  - 边缘不规则，油光和汤汁只出现在它该出现的地方。
  - 热食有少量热气，只在逆光时可见。
  - 酱汁有滴落的痕迹，碎屑散落在盘边。
  - 桌面有杯印和纹理。

## 产品

- **体裁惯例**：电商白底图可以干净，但必须是实拍质感；生活场景图要有使用环境。
- **真实锚点**：
  - 材质反光准确：拉丝金属、磨砂塑料、玻璃边缘的绿色。
  - 反射中能看到柔光箱的形状。
  - 接触面有落地阴影。
  - Logo 和文字要准确，做不到就缩小或让它看不清。
  - 接缝、螺丝、标签这些工业细节要有。

## 室内空间

- **体裁惯例**：
  - 家居实拍：有人住的痕迹。
  - 室内设计作品图：整洁，但保持实拍透视，竖线保持竖直。
- **真实锚点**：
  - 窗外过曝，或者用窗框压暗。
  - 家具的结构和尺度要合理。
  - 电线、插座、开关、踢脚线、墙面的细小污渍都要有。
  - 书和杂物有歪斜，新旧不一。

## 建筑 / 街景

- **真实锚点**：
  - 招牌文字准确，或者远到看不清。
  - 电线、空调外机、晾晒的衣服、雨水留下的污痕。
  - 路人衣着符合季节和地域。
  - 车辆型号符合年代。
  - 地面有裂缝、积水、落叶。
  - 透视和建筑结构符合当地的建筑类型。

## 自然风景

- **真实锚点**：
  - 天空的亮度远高于地面，需要取舍曝光，不要 HDR 式全都看得清。
  - 大气透视：远处的物体偏蓝、偏灰、偏淡。
  - 植被在种类和季节上保持一致。
  - 水面的反射跟随天空。
  - 前景有杂草和石块，不是修剪整齐的草坪。

## 动物

- **真实锚点**：
  - 毛发有方向，湿处成绺，有换毛和打结的地方。
  - 眼睛湿润，瞳孔形状符合物种。
  - 爪、鼻头和胡须的细节要写实。
  - 动作往往抓不稳，局部会有运动模糊。

## 夜景 / 低光

- **真实锚点**：
  - 噪点明显，暗部大片沉黑。
  - 高光点周围有光晕，胶片还会有红色光晕。
  - 光源稀少，各自带着颜色（钠灯、霓虹、便利店的冷白）。
  - 湿地面上有光源的倒影。
  - 手持拍摄时，画面会轻微糊。

## 车辆 / 交通工具

- **真实锚点**：
  - 车漆有反射和细微划痕，轮胎沾着泥灰。
  - 车牌格式符合地区，不能写真实的号码，可以模糊处理。
  - 车身比例符合真实车型，不要混合多种车型。

## 屏幕 / 文字 / 印刷品

- **真实锚点**：
  - 屏幕内容清晰而合理，或者用反光盖住。
  - 屏幕有摩尔纹，或者能看到像素栅格（翻拍时）。
  - 纸张有厚度、折痕，有光泽或哑光。
  - 印刷有网点，或轻微的套色偏移。
  - 所有文字要么正确可读，要么只保留图形，永远不要出现乱码。
