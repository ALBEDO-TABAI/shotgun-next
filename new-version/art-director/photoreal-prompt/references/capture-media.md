# 成像媒介

每种媒介都要写成“设备 + 它在画面上留下的可见特征”。只写器材名是没有用的。

## 从内容推断默认来历

| 内容线索 | 推断的来历 |
|---|---|
| 对镜头说话、领夹麦、书桌、补光 | 博主口播视频的截帧，微单固定机位，约 35mm，f/2 |
| 自拍角度、伸出的手臂、镜面 | 手机前置摄像头：广角近距、轻微畸变、美颜关闭 |
| 生活日常、朋友、餐桌 | 朋友用手机随手拍的照片 |
| 旅行风景、街道 | 游客用手机或卡片机拍的照片，取景不讲究 |
| 活动、婚礼、演出 | 现场摄影师用单反拍摄，带机顶闪光或高感光度噪点 |
| 商品、菜单、室内设计 | 小商家或设计师用单反自然光拍摄，允许真实的摆拍，但不能是 CG |
| 证件照、形象照 | 照相馆或简易影棚，柔光箱，纯色背景 |
| 历史、年代题材 | 那个年代的主流媒介（见下文“年代默认”） |

## 数码设备

| 设备 | 可见特征 |
|---|---|
| 近年旗舰手机后置 | 计算摄影 HDR：暗部偏亮，画面平、锐，细节有涂抹感，夜景提亮后噪点被抹平，景深较深 |
| 手机前置 | 广角近距导致五官轻微放大变形，画质稍软，逆光时脸发灰 |
| 2010 年代初的手机 | 动态范围窄，高光易溢出，偏色，JPEG 压缩块明显，暗部噪点很重 |
| 2000 年代 CCD 卡片机 | 机顶直闪让脸发白、背景掉黑，色彩浓郁带点荧光感，画面偏小偏软，可能有日期水印 |
| 微单或单反加定焦 | 背景虚化自然，焦外柔和，对焦准，高感光度下有均匀的细噪点 |
| 视频截帧 | 1/50 秒快门，动作带运动模糊，有压缩感，锐度低于照片，Rec.709 的中等对比 |
| DV 摄像机（1990s–2000s） | 隔行扫描，边缘有锯齿，饱和度偏高，白平衡跳变，4:3 画幅，暗部满是彩色噪点 |
| 监控 / 行车记录仪 | 高位广角，鱼眼畸变，夜间黑白，屏幕上有时间码，压缩严重 |

## 胶片（含冲洗与扫描）

| 胶片 | 可见特征 |
|---|---|
| Kodak Gold 200 | 暖黄偏金，红黄饱和，肤色健康偏暖，中等颗粒，高光柔和过渡；曝光不足时暗部偏青绿 |
| Kodak ColorPlus 200 | 与 Gold 相近但更平更暖，颗粒更粗，是廉价日常感 |
| Kodak Portra 400 | 低反差，肤色细腻自然，粉彩感，颗粒细，过曝时依然通透 |
| Kodak Ektar 100 | 极高饱和，红蓝浓烈，颗粒极细，反差高，适合风景，不适合肤色 |
| Fuji Superia 400 / C200 | 偏绿偏冷，绿色鲜明，日常街拍感 |
| Fuji Pro 400H（已停产） | 薄荷绿、空气感、偏淡，日系小清新 |
| CineStill 800T | 灯光钨丝平衡，路灯和霓虹外圈有红色光晕，日光下偏蓝青，夜景颗粒明显 |
| Kodak Tri-X 400 | 经典黑白，颗粒明显，增感冲洗后反差强、颗粒粗 |
| Ilford HP5 Plus | 黑白，中间调宽，颗粒柔和 |
| 一次性相机 | 塑料镜头，四角暗且软，机顶闪光在近处过曝、远处掉黑，画面偏暖或偏绿 |
| 宝丽来 / Instax | 柔、低动态范围，颜色偏移（偏青或偏黄），有白色边框，暗部发灰 |
| 中画幅 120（6×6、6×7） | 方形或近方形构图，焦外过渡极柔，颗粒几乎看不到，影调厚 |

扫描与冲洗环节同样会留下痕迹：

- **冲扫店的 Frontier 扫描**：绿色偏青，肤色偏暖，暗部有轻微的数码噪点。
- **Noritsu 扫描**：更中性，锐一些。
- **翻拍旧相纸**：纸纹、褪色、边缘泛黄，可能有指纹和折痕。

胶片在混合光下的表现：

- **日光型胶片在钨丝灯下**：灯光一带明显偏橙。
- **日光型胶片在荧光灯下**：整体偏绿。
- 这正是胶片观感的主要来源，应该写进提示词。

## 电影影像

| 媒介 | 可见特征 |
|---|---|
| 35mm 电影胶片（柯达 Vision3） | 有机颗粒，高光柔和过渡，肤色厚，暗部有层次 |
| 变形宽银幕（Anamorphic） | 2.39:1 画幅，椭圆焦外，水平拉丝眩光，边缘有轻微畸变 |
| IMAX 65mm | 巨大的画面信息量，大画幅带来的浅景深，颗粒极细，1.43:1 或 1.90:1 |
| ARRI Alexa 数字 | 柔和的数字影像，高光过渡接近胶片，肤色自然，没有颗粒 |
| 老片胶片拷贝或录像带转录 | 褪色（偏红或偏品），划痕和尘点，片门抖动；录像带有信号干扰纹和色彩渗漏 |

## 年代默认

| 年代 | 默认媒介 |
|---|---|
| 1920s–1940s | 黑白银盐，宽容度窄，常有柔焦和晕影 |
| 1950s–1960s | 柯达克罗姆或爱克发彩色反转片，浓郁的原色，偏暖 |
| 1970s | 彩色负片或早期彩色冲印，偏黄偏红，反差低，已经褪色 |
| 1980s–1990s | 消费级彩色负片，傻瓜机加闪光，冲印店出片 |
| 2000s | CCD 卡片机，或早期手机 |
| 2010s | 手机加滤镜 App（VSCO、Instagram 早期滤镜） |

## 现场光源

| 光源 | 在画面上的表现 |
|---|---|
| 晴天直射 | 硬阴影，高反差，肤色暖 |
| 阴天、北窗 | 软光，低反差，偏冷 |
| 黄金时刻 | 低角度暖光，影子长，逆光时有发丝光 |
| 蓝调时刻 | 天空深蓝，室内灯光开始显得暖 |
| 荧光灯管 | 偏绿，顶光，眼窝发暗 |
| 钠灯路灯 | 单色橙黄，其他颜色几乎消失 |
| 家用暖光 LED 或钨丝灯 | 偏橙，衰减快 |
| 冷白 LED | 偏蓝，平 |
| 机顶直闪 | 正面平光，背后贴墙的硬影，红眼或皮肤反光，背景掉黑 |
| 屏幕光 | 脸被冷蓝色从下方或正面照亮，其余部分暗 |
| 霓虹 | 高饱和的单色，照在皮肤和湿地面上会染色 |
