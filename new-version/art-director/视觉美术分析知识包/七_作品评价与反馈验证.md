# 七、怎么评价？先判断作品在解决什么，再判断它解决得怎样
## 条件性审美判断、项目适配与观看验证：理论基础及 skill 规范

> **本篇任务：**把“好看、不高级、太普通、很有感觉”等评价，转化为有对象、有标准、有证据、能够支持修改或保留的判断；同时保留艺术讨论中的多种价值，不把一切都压成商业绩效。
>
> **与第一篇衔接：**风格描述不是质量评价，情绪体验不是效果证明。第二至第六篇分别提供可见事实、组织规则、工作拆解、解释边界与创作方案，本篇判断这些选择在什么条件下成立。
>
> **研究与整合说明：**经验美学、设计研究、批评教学与实验设计提供不同层面的依据。本篇的评审维度、反馈句式和测试流程是应用整合，不是经过整体实证验证的通用审美量表。检索与编订：2026年9月18日。

---

## 一、先拆开“好”包含的不同判断

面对一张照片，可以同时出现这些情况：我不喜欢它的气质，但认可它的组织；它完成了产品识别任务，却没有带来新鲜感；它令人不舒服，但这种不舒服与作品的问题有关；它视觉上完整，却不能证明促进了销售。

这些不是自相矛盾，因为判断对象不同。

本篇建议至少区分五种问题：

| 判断类型 | 实际在问什么 | 合适的输出 |
|---|---|---|
| 感受与偏好 | 我看时经历了什么，是否喜欢？ | 有主体、有情境的体验报告 |
| 形式判断 | 关系、节奏、主次与变化怎样成立？ | 指向具体画面的组织分析 |
| 表达与艺术判断 | 作品提出了什么，表达是否值得继续理解？ | 有论据、允许争议的解释与评价 |
| 项目适配判断 | 对既定用途、对象、媒介和限制是否适合？ | 条件明确的任务评价 |
| 实际效果判断 | 受众实际理解、记住或采取了什么行动？ | 相应的观察、访谈或测试结果 |

这里的“先判断作品在解决什么”，并不意味着作者说自己要做什么，作品就只能按那个目标评价。目标可以被讨论：需求是否合理，作品是否意外打开了更有价值的问题，实际用途是否改变，都可以进入评价。

**目标是判断的上下文，不是替作品免于批评的许可证；个人偏好是有效信息，但不是其他人必须接受的质量结论。**

### 评价不是给描述换一个带褒贬的词

“道具很多”是数量或密度描述。“道具太多”已经隐含了一条标准：这些物件妨碍了什么，超过了什么需要？

假设目标是让观众快速认出产品，密集物件可能需要被检查；假设作品表现物品积累与记忆，删空场景可能反而破坏表达。不能省略中间的条件，只把“少”默认等同于“好”。

评价应写成：**关于某个对象，在某种条件和标准下，由哪些证据支持什么判断。**

## 二、理论依据：经验研究支持什么，又不支持什么

### 1. 审美情绪与审美判断不是同一结果

Leder 等人的审美加工模型区分审美情绪和审美判断，并把感知、分类、理解与评价联系起来。[R24]

本篇借此要求评审保留两个问题：“我有什么感觉？”与“我为什么认为作品成立或不成立？”二者可能相关，但不能自动互相替代。

这也提醒我们，不应把第一次接触时的困惑直接判为失败。另一方面，不能因为作品需要理解，就假设所有困惑最终都会转变成欣赏。是否产生了进一步理解，仍需看作品与观看经验。

本次核对的是论文摘要与卷期信息，不据此复述未经核对的全部加工阶段细节，更不把它改造成输入色彩即可输出分数的算法。

### 2. 新颖与熟悉不是一个简单的零和选择

Hekkert、Snelders 与 van Wieringen 的消费产品研究讨论典型性与新颖性对审美偏好的联合解释，不能只孤立看其中一个变量。[R25]

这为设计评审提供一个问题：方案是缺少有意义的差异，还是已经失去人们识别它所需的线索？但研究对象和任务有边界，不能推出“一切艺术必须既新又熟”，更不能算出七成常规、三成创新的固定比例。

本篇的应用是让评审具体说明：**哪些惯例被保留，哪些关系被改变，这种改变对当前作品有什么作用。**作品也可以主动挑战熟悉性；是否值得这样做，需要在它自己的语境中讨论。

### 3. 观看任务与文化语境参与反应

关于 Yarbus 的眼动研究及回顾提示，观看指令可以改变扫描方式。[R04] 颜色—情绪关联研究则显示，共享模式与语言、地理差异可以同时存在；该研究不是完整画面的情绪因果实验。[R05]

因此，不能先要求参与者“找出产品”，再把他们看向产品当作未经提示的自然注意结果；也不能把某种颜色与词语的关联，直接写成某广告已经制造相应感受。

应用时要保存观看条件：看了什么版本，有没有声音，尺寸多大，任务如何提问，观看前是否已经了解产品或创作解释。没有这些条件，比较两次反馈很容易比较的不是同一件事。

### 4. 修辞分析能够提出效果假设，不能替代效果研究

Phillips 与 McQuarrie 的视觉修辞论文把形式分类与可检验的消费者反应预测联系起来。[R09]

对本篇而言，关键是保留“可检验”。可以提出“这个反差可能让观众停下来理解”的假设，但不能从“存在反差”直接推出“必然提升记忆与购买”。是否停留、理解了什么、记住的是产品还是装置，需要分别验证。

### 5. 批评应指向作品和目标，而不是攻击创作者

Stanford d.school 的反馈教学强调善意批评、讨论目标及作品与个人的区分。[R26]

本篇由此发展的是可执行的评审语言：解释哪一处关系影响哪一项目标，并提出修改与复查方式。友好不是只说赞美，专业也不是使用难懂术语；能让对方理解判断并检验修改，才是反馈的实际价值。

### 6. 测试设计由问题决定，不由“A/B”这个名字决定

NIST 的实验设计说明强调，研究目标、因素数量、资源和错误决策控制会影响设计选择。[R34] 其完全随机设计说明把随机分配与随机执行顺序作为明确的设计概念。[R35]

本篇只借用这些方法原则，不把工程试验表直接套成艺术评审标准。一场内部讨论、一轮访谈、一个随机比较和一次投放测试，是不同层级的证据，不应统一写成“用户验证通过”。

## 三、建立评价上下文：先写清五件事

### 1. 评的是哪个版本和范围

是一张草图、概念图、材质测试、完整镜头、成片，还是发布后的传播结果？同一条影片的横版与竖版应分别确认，不能让一个版本的通过覆盖另一个尚未检查的版本。

时间范围也重要：某个镜头局部凌乱，可能被下一个镜头重新组织；全片某一段失去视觉稳定，可能是有意的变化。评价需要与实际证据范围一致。

### 2. 当前阶段应该回答什么

概念阶段主要检查问题是否值得做、组织关系是否有潜力；布局阶段检查空间与观看顺序；材料测试关注质感与光；终稿检查完整关系及交付要求。

这不是硬性流水线，而是避免用错误精度评审。不能因为灰模没有漂亮纹理就否定空间概念，也不能因为终稿概念不错就忽略显著穿帮。

比较多个方案时，还应留意呈现完成度不一致：精修图可能更容易获得支持，但那不证明其概念更适合。可先统一到相近表达层次，再讨论真正的差异。

### 3. 用途与观看情境是什么

销售主图、品牌形象片、叙事电影、时尚编辑与展览作品并不共享完全相同的优先级。小尺寸快速浏览与大幅长时间观看，也可能需要不同检查。

用途不明时，应输出条件分支：“作为销售主图需要进一步检查识别；作为装置摄影，其含混空间值得保留。”不要凭空替作品指定一个目标，再据此批评它。

### 4. 哪些是硬要求，哪些是可协商的价值

硬要求可以包括已经确认的产品信息、尺寸格式、指定内容和制作限制；表达清晰、陌生感、历史准确、情绪强度等，则需要说明具体项目中的地位。

不要把个人偏好伪装成硬要求，例如“高端品牌只能用黑白”。也不要把确实不可忽视的交付问题稀释成审美意见，例如已经约定必须可读的包装文字在输出中消失。

### 5. 谁在评价，有什么经验与利益位置

创作者、客户、同部门同事、目标受众与陌生观看者，可以提出不同类型的信息。专业人员能够提供形式诊断，但不因此代表所有受众；客户掌握商业约束，也不因此自动证明市场效果。

记录角色的用途是解释证据的范围，不是根据身份决定谁永远正确。对艺术作品，分歧本身也可能是理解作品如何运作的重要材料。

## 四、一个不强求总分的评价框架

以下七个维度是本知识包的工作整合。根据任务取用，不要求每件作品全部评分。

| 维度 | 关键问题 | 应寻找的证据 | 常见错误 |
|---|---|---|---|
| 目标适配 | 视觉选择是否支持当前主要任务？ | 明确目标与对应画面、任务表现 | 把喜欢当成适合 |
| 形式组织 | 主次、节奏、尺度、材料和变化是否有组织？ | 可定位的关系和局部例外 | 把对称、整齐视为唯一好形式 |
| 概念具体性 | 为什么是这些东西及这些关系？ | 关键决策、替代方案、删改后的差别 | 用故事包装任意装饰 |
| 表达与解释空间 | 作品是否产生值得理解的关系？ | 画面支持的解释与观看材料 | 把单义当清晰，把难懂当深刻 |
| 完成与连续性 | 局部完成度是否支持整体，变化是否可解释？ | 版本、镜头、版式及细节检查 | 把有意差异当错误 |
| 制作与交付适配 | 能否在资源和展示条件下成立？ | 测试、实际输出与限制 | 只评价概念图，不评价最终媒介 |
| 实际观看结果 | 人们实际上看见、理解、记住什么？ | 有范围说明的反馈或研究 | 凭静帧预测销售 |

### 形式判断需要说明关系，不必假装没有立场

“这个画面过于封闭”不是完整判断。可以进一步说明：“所有轮廓和视线都在画面内部收束，但该段落需要建立人物向外行动的可能性；目前出口被遮蔽，使这个动作缺少空间准备。”

也可能得出相反结论：画面的封闭使人物被困的处境更具体。评价不是查表，而是检查形式与问题之间的关系。

### 概念具体性不是要求每件道具都有隐喻

一个道具可以主要解决动作、支撑、尺度或构图问题。不能因为它没有象征含义，就称其无意义。

可以进行有限替换思考：把它换成其他物件后，哪些关系不变，哪些作用消失？如果没有任何重要变化，可能说明道具只是一般性填充；也可能说明方案故意保持开放，不依赖特定物件。两种情况需要结合任务判断。

### 表达成功不等于所有人说出同一句解释

对于产品操作说明，理解路径不一致可能值得解决；对于诗性影像，多种解释可能是作品的一部分。应当先说明希望保留什么开放性、哪些信息仍需稳定，再判断含混是否具有作用。

不能用“这是艺术”结束讨论，也不能用“有人没看懂”结束讨论。需要继续问：画面给出了哪些线索，观看者形成了怎样的理解，差异与目标的关系是什么。

## 五、量化能帮助讨论，但不能把标准藏起来

### 1. 优先使用“证据＋状态”，而不是单一分数

建议每个维度输出：成立、存在风险、未成立、证据不足或不适用，并附理由。这里的状态是工作判断，不是经校准的测量单位。

“证据不足”与“未成立”必须分开。尚未做记忆测试，不能把记忆效果填零；艺术作品不以购买为目的，购买指标应是不适用，而不是低分。

### 2. 必须评分时，先写锚点

例如“产品识别”可以建立项目专用的三级描述：目标尺寸下产品主要特征无法辨认；能够辨认但受到局部干扰；在当前测试条件下能够完成既定识别任务。

这是针对一个任务设计的有序类别，不意味着第二级到第三级与第一级到第二级有相同差距。若使用均分，应说明它只是沟通辅助，不能当成严格等距测量。

“高级感八分”如果没有对象、观看条件与等级含义，几乎无法支持可执行的修改。

### 3. 权重是价值选择，不是科学自动算出来的

把包装识别放在情绪陌生感之前，是一种项目优先级；换成艺术展览时可能相反。权重应由任务讨论形成，并明确谁作了选择。

建议先找不可妥协的约束，再比较其他取舍。不要让一个严重的内容错误，被多个“质感不错”的分数平均掉。

若改变合理的优先级就改变方案选择，应如实说明方案之间存在取舍，而不是宣布有一个无条件的最佳方案。

### 4. 证据可信度与作品质量是两根不同的轴

某项判断证据弱，不等于作品差；某位评审十分确定，也不等于判断正确。可以同时记录“我倾向认为空间关系有效”和“目前只看到了单张概念图，运动表现未知”。

把这两根轴分开，能够避免以强硬语气替代证据，也避免因为没有实验就拒绝一切有论据的审美讨论。

## 六、怎样验证观看结果，而不是制造看似科学的结论

### 1. 先区分结果变量

以下问题互有关联，但不是同一件事：是否看到了主体、是否识别产品、是否理解主题、产生什么感受、记住什么、是否知道来自哪个品牌、是否点击或购买。

看到得快不必然记得久；记得画面不必然记得品牌；觉得喜欢不必然采取行动。这里不是声称它们永远无关，而是要求对每一项结论提供对应证据。

眼动可以帮助研究观看分配，但仅凭注视不能确定理解、赞同或购买。关于观看任务影响扫描的研究，也不能单独解决这些更后续的问题。[R04]

### 2. 按问题选择证据强度

| 方式 | 可以帮助回答 | 不能独自证明 |
|---|---|---|
| 创作者自查与专家评审 | 关系、执行问题、可行解释 | 目标受众总体效果 |
| 探索性访谈 | 人们如何理解、哪里困惑、使用了哪些词 | 普遍发生率和因果提升 |
| 有明确条件的任务测试 | 在该条件下能否完成识别或理解任务 | 其他渠道和人群同样表现 |
| 设计得当的比较研究 | 指定变量与结果差异之间的关系 | 未控制因素的独立贡献 |
| 实际发布后的表现记录 | 特定投放条件下出现的结果 | 视觉方案单独造成所有变化 |

这不是从低价值到高价值的固定阶梯。探索新的意义关系时，访谈可能比一个粗糙的点击指标更有用；要声称商业提升时，单纯形式讨论则不够。

### 3. 提问不要预先塞入期待的答案

先问“你看到了什么”“这段画面让你想到什么”，再讨论设计团队关心的具体问题；不要一开始就问“你是否觉得清爽高级”。后者可以用于某个明确测量任务，但不能被当作完全自发的体验报告。

观看前提供创作解释，也会改变测试问题。解释后理解与无解释理解应分开记录，不能混为一项结果。

对陌生的艺术作品，解释后的观看有自身价值；关键不是禁止解释，而是不隐瞒解释的存在。

### 4. 比较时先确定是选整体，还是解释原因

若问题是“这两套完整方案哪套更适合继续”，可以比较整体，但结论不能精确归因于某一种颜色或道具。

若问题是“瓶身区分不足是否由背景纹理造成”，则需要尽量限制其他变化。复杂问题也可以采用多因素设计，不必把“一次只改一个”奉为唯一方法。选择取决于要回答的问题和可用资源。[R34]

随机分配不是按名单轮流分配；随机展示也不是永远先看A再看B。顺序、熟悉程度及比较方式需要明确安排。[R35] 对需要严格推断的研究，还应提前明确样本、主要指标、分析方案及可接受的不确定性。本知识包不提供一个不论任务都适用的样本人数。

### 5. 没有开展研究，就写测试计划

不能为了让报告完整，编造“八成用户觉得更清爽”“大多数人偏好A”。内部几位同事的意见，也不能悄悄扩大成目标人群调查。

测试前写预期，测试后写观察。结果不符合预期时应修改解释，不能只保留支持方案的回答。

尚未测量的内容可以继续作为有价值的创作假设存在，但必须保留身份。

## 七、把反馈写成能产生行动的句子

本篇建议采用五段式：

> **画面证据 → 可能影响 → 所依赖的目标或条件 → 建议动作 → 复查方式。**

例如：

> 瓶身右边缘与背后的弧形高光重叠，主体轮廓在缩小图中难以连续辨认。对于这一张以包装识别为首要任务的销售物料，这可能构成干扰。建议先改变高光的位置或面积，保留现有空间和颜色；再在目标展示尺寸下比较边缘辨识情况。

其中“可能构成干扰”是基于关系提出的风险判断，真正的任务表现仍需检查。反馈没有把一个局部问题扩成“整套不高级，全部重做”。

### 反馈应该包含“保留什么”

只写需要改变的部分，容易让修改者连有效关系一起破坏。可以补充：“叶片与瓶身之间的尺度关系仍然支持概念，暂不改变；本轮只解决轮廓区分。”

保持有效部分不是维护沉没成本，而是明确当前问题的作用范围。若测试说明根本概念存在问题，也应能够回到更早阶段，而不是不断修饰表面。

### 问题与方案不要强行绑定

“主体不清楚”是诊断，“把背景换成白色”是一个候选方案，不是诊断的唯一含义。还可能改变明暗、反射、机位、遮挡或信息密度。

把问题单独保留，允许执行者提出更小成本、更不破坏概念的解决办法。

### 处理意见冲突时，先判断冲突在哪里

一位评审说“太空”，另一位说“很克制”，可能是目标不同；两位对同一细节的描述不同，可能是观看尺寸不同；同样条件下仍然有分歧，则应保留审美立场差异。

不是每次都需要投票达成统一。可以先修正事实错误，再明确项目决策权，最后记录没有被选择的合理解释，而不是把所有异议写成“已解决”。

## 八、完整教学案例：两版护肤产品画面怎样比较

**以下为虚构方案与测试计划，不是实际作品分析，也没有实施受众实验。**

任务设定：同一款蓝绿色护肤产品，需要一张销售展示图和一张品牌形象图。两者共享“植物庭院”的概念，但用途不同。

方案A：产品接近画面中央，叶片退到两侧，背景表面平缓，瓶身轮廓连续。

方案B：放大的叶片与产品交叠，局部水光穿过前景，比例关系更不稳定，瓶身右侧部分被遮挡。

### 1. 不立即给出一个总冠军

| 问题 | 对A的分析方向 | 对B的分析方向 | 尚需什么证据 |
|---|---|---|---|
| 产品识别 | 主体关系更直接，值得检查其目标尺寸表现 | 局部遮挡可能影响识别 | 实际输出与任务检查 |
| 概念体验 | 环境容易成为陪衬，庭院尺度感可能较弱 | 交叠与尺度变化使环境参与更强 | 图像细读与观看反馈 |
| 信息容纳 | 可能有更稳定的文字位置 | 文字可能与环境争夺位置 | 实际文字长度及版式测试 |
| 品牌区分 | 清楚不等于具有品牌特征 | 陌生不等于能认出品牌 | 已知品牌要求与归属测试 |
| 跨版式适配 | 中央关系可能较容易保留，但仍需检查 | 裁切可能改变遮挡与尺度关系 | 横竖版独立输出 |

这里用“可能”和“待检查”不是回避选择，而是忠实呈现当前只有方案描述、没有成图与测试的条件。

### 2. 作出范围明确的下一步选择

可以优先让A进入销售图的识别检查，让B进入品牌图的空间表达检查。这不是证明A只适合销售、B只适合艺术，而是当前两个任务下的工作安排。

如果必须共用一个主视觉，可以尝试保留B的尺度设定，调整产品局部遮挡。但这应作为新候选C进行评审，不能假装同时保留所有优点而没有代价。

### 3. 写两个不同的测试问题

销售图问题：“在计划使用的展示条件下，包装特征和必要信息能否被识别？”

品牌图问题：“观看者把放大的植物理解成环境、成分装饰，还是其他关系？他们记住的是哪部分？”

第二个问题允许开放答案。不能把“没有说出设计文案里的庭院”直接判成失败；要比较他们的理解是否仍然保留了计划表达的核心关系。

### 4. 结果如何改变方案

若销售图的产品清楚，但品牌信息弱，需要另查品牌区分，不应继续无目的放大产品。若品牌图的尺度关系被理解，却误导了具体产品信息，则需要修正信息，而不一定删除整个幻想空间。

每项结果都应影响它对应的决策，不能只在报告末尾写一句“已根据反馈优化”，却看不出改变了什么。

## 九、非商业案例：含混为什么不能直接扣分

**以下仍为虚构教学案例。**一组艺术摄影表现“可以看见，却无法进入的房间”。摄影师只拍门外的局部，保留反射和遮挡，不完整交代房间用途。

用销售展示的“信息越清楚越好”评价，会把它的主要设定当成缺陷。更适合的问题是：遮挡是否持续参与观看？每张图是否只是重复同一种效果？可见线索是否支持进入与阻隔之间的关系？不同观看者的解释是否仍与画面有关？

但不能因为含混是目标，就自动宣布完成。假设每张图的阻隔没有变化，也无法形成新的关系，评审仍可提出“这一系列的观看发展不足”的判断，并用具体图像排序与差异作论据。

艺术性不等于免于证据；评价开放性，也不等于强求一个标准答案。

## 十、从评审意见走向修改与验收

建议把评审输出分成三类：必须修正的已确认问题、值得测试的风险、允许并存的偏好或解释。三类事项不要混入同一个“待办”列表。

每个实际修改应有对象、理由、范围、负责角色和复查方式。例如：“调整镜头03产品右侧高光；仅修改灯位关系；由摄影与美术共同核对；复查竖版裁切及包装识别。”具体职责仍以项目分工为准。

“概念通过”只代表概念层面的认可；不自动批准场景材质、制作成本和最终成片。“局部问题已修正”也不代表其他尚未验证项都完成。

评价的终点不是每个人都说喜欢，而是当前阶段的问题得到足够清楚的回答，项目知道下一步做什么、保留什么，以及哪些结论仍然有限。

## 十一、可直接转写为 skill 的执行规范

### 适用触发

当用户要求评价、比较、复盘、提出修改意见，或判断视觉方案是否满足任务时使用。只有风格识别任务时，不默认扩展为质量排名。

### 必要输入与缺失处理

至少需要可访问的作品或方案，以及明确的分析范围。目标、观看条件、受众、阶段、限制和已有测试可作为补充。

目标缺失不妨碍进行形式讨论，但应保留条件性判断；没有成图时只能评概念描述；没有测试时不能宣布受众效果成立。

### 执行顺序

确认版本与阶段；区分描述、感受、评价和效果；选择相关标准；逐项提供证据；检查反例与取舍；提出最小必要修改；安排与问题匹配的复查；输出完成边界。

### 最小记录示例

```yaml
example_status: fictional_template
work_version: concept_B_v1
scope: single_still_concept
purpose: brand_image
criterion:
  name: spatial_scale_relationship
  reason: 让植物从陪衬转变为产品所处的环境
observation:
  statement: 方案描述中叶片与产品交叠，叶片尺度被放大
  source: supplied_concept_description
judgment:
  status: needs_visual_test
  statement: 这一关系具有概念潜力，尚不能确认成图效果
  limitation: 尚未提供可检查的渲染图或受众材料
preserve: 放大植物构成环境的关系
candidate_change: 仅在包装必要信息处调整遮挡
verification:
  question: 尺度关系与必要产品信息能否同时保留
  evidence_required: 同条件方案图与实际输出检查
approval_scope: null
```

不要把这个示例中的状态转换成真实项目已完成的记录。结构服务于判断，不要求所有日常讨论都先填表。

### 完成条件

每个关键评价能定位对象并说明标准；事实与解释没有混写；没有将未知填成低分；修改建议能对应问题；有条件的优劣没有被包装成无条件真理；未实施的测试保持计划身份。

## 十二、对抗性检查与常见假问题

| 输入或情形 | 容易发生的错误 | 本 skill 应有的反应 |
|---|---|---|
| 用户只说“高级吗” | 输出无依据的高级感分数 | 说明可见关系，并澄清评价条件 |
| 目标是表现压抑 | 因不愉悦判失败 | 区分体验方向与表达质量 |
| 一位专家不喜欢 | 当作普遍受众结论 | 保留角色和判断范围 |
| 两版完成度不同 | 把精修程度当概念优势 | 分离当前阶段与完成度 |
| 没有记忆研究 | 填“记忆点强”作为事实 | 写成机制假设或待测项 |
| A/B同时改变多项内容 | 宣称某一种颜色造成效果 | 只能比较整体或重新设计诊断 |
| 小范围内部讨论 | 宣称市场验证通过 | 如实记录样本与使用边界 |
| 意见来自不同尺寸版本 | 当成无法调和的审美冲突 | 先统一证据条件 |
| 有明确技术错误 | 被其他高分平均掩盖 | 独立处理不可妥协要求 |
| 艺术作品存在多种解释 | 强求所有人复述主题 | 检查解释与画面的关系 |
| 局部识别问题 | 要求整套美术全部重做 | 先提出作用范围更小的候选修改 |
| 客户认可了概念 | 认为所有后续版本获批 | 记录批准对象、版本与范围 |

## 核心原则

> **评价不是给作品贴上好坏标签，而是在明确对象、情境和价值标准后，说明哪些关系成立、哪些存在问题，以及证据能够支持到哪里。感受不等于判断，判断不等于受众结果，受众结果也不自动等于商业因果。保留多种价值和合理分歧，同时把需要行动的问题写清楚：为什么改、改哪里、保留什么，以及怎样知道修改确实回答了原问题。**
