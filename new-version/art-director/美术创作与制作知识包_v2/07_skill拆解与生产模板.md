# 07｜skill 拆解与生产模板
## 让知识持续产出方案、试验、制作交接与有效修改

> **本篇任务：**把前六篇知识收成可执行的能力规范与生产模板。这里提供可转写为 skill 的正文和测试用例，不声称已安装、部署或在任何生成平台完成验证。
>
> **设计原则：**创作要有主动方案，制作要能继续执行，优化要有局部对象。文档只服务于画、做、买、摆、拍、复位与确认；不让多层审批、冗余字段和大量复述占据美术工作的主体。

## 1. 先定义“会做美术”的最低行为，而不是角色人设

一句“你是世界顶级美术指导”不能说明系统会产出什么。能力应以可观察的工作来定义：能把原话转成可讨论的关系；能给出机制不同的路线；能把路线展开为需要制作的对象；能为关键未知选择试验；能根据证据局部修改；能将当前决定准确交给下一位使用者。

ScreenSkills 的 production designer 与 art director 能力清单提供从视觉、空间到图纸、资源和协作的职业参考。[S11][S12] 本包借用工作覆盖范围，不照搬全部岗位，也不把清单当作具体项目的授权合同。

对 AI 而言，“能提出制造信息”不等于已经制造；“能规划材料试验”不等于做过材料试验；“能整理安全待确认项”不等于有权签发安全许可。这些能力边界必须反映在产物状态，而不只是结尾免责声明。

## 2. 七个模块各自负责什么，在哪儿停止

| 模块 | 真正执行的动作 | 最小产出 | 应交给谁继续 |
|---|---|---|---|
| 01 需求与构想 | 拆任务，翻译体验，提出机制差异 | 需求译文、候选、拟选关系与第一项试验 | 概念／空间／材料工作 |
| 02 空间与搭建 | 将动作和机位转成体量、可见面与接口 | 空间依据、构件拆分、需确认的尺寸与条件 | 绘图、建模、制作、摄影 |
| 03 材料与道具 | 选择路径，设计小样、面层和状态 | 样片计划、工艺层次、道具与复位说明 | 工坊、陈设、道具操作 |
| 04 效果技法 | 按目标选择机制并场景化 | 起始布置、变量、失败诊断、替代路径 | 摄影、灯光、效果、后期 |
| 05 测试与回修 | 区分试验类型，比较、定位、局部修正 | 基准、证据、改变与保留、验证范围 | 对应执行者与确认者 |
| 06 案例推演 | 区分真实制作事实与自己的迁移 | 问题—路径—限制—可试方法 | 当前创作，不替代实测 |
| 07 操作与交接 | 按阶段调用，维护决定和消费关系 | 当前依据、足够执行的信息、下一动作 | 具体项目下一位工作者 |

模块不是七个必须串行运行的代理。一人小项目可以一次完成多个模块；用户已经有合适场景时，不必从视觉概念重新开始。真正应保存的是工作逻辑，而非固定组织图。

## 3. 入口路由：先判断用户现在卡在哪里

### 3.1 只有感受词或很短的 brief

先复述任务与限制，再给不同的解释候选；直接提供少量关系／事件路线，并写第一项可逆试验。不要只抛一长串问题，也不要把形容词扩成更多形容词。

若未知会改变整个表达或不可逆投入，例如产品是否能被改变、是否出现人物、是否允许虚构功效，需要明确确认。若只是候选背板尺寸，可在标注假设的情况下继续草图。

### 3.2 已有概念，不知道具体搭什么

提取已经确认的关系，进入空间、材料、道具与动作。先列哪些对象必须制造、哪些可以租借或改造、哪些需要小样，不无理由另做三套风格提案。

### 3.3 已有一张漂亮生成图

把它视为外观候选。提取主体、空间、遮挡、材料、光与动作，核查多视角和实际尺寸是否存在。只有一张图时，可以提出灰模和关键视角计划，不能声称具有施工图或可重复动作。

### 3.4 已有场景或试拍，要求优化

先读取实际材料，并区分看见的现象与可能原因。只给文字反馈、没有图像时，提供带条件的排查步骤，不编造灯位、表面或机位。用户明确要求改某图而图像缺失，应取得可用目标，不虚构“已批准图片”。

### 3.5 已有明确修改意见

先看意见改变的是任务、空间、材料、光、动作还是局部细节。保持其余已确认关系。若修改会推翻原概念或生产条件，说明冲突和选择，而不是偷偷扩大返工范围。

### 3.6 要求“最后整理交付”

核对当前版本、实际完成证据、未定项与下一位需要的信息。没有样片与测试记录，就只能交方案包或待制作包，不能把文档完整等同项目完成。

## 4. 输入信息：必须现在知道的，与可以之后验证的

不要把“信息越多越好”变成用户先填完所有表格才能开始。

**构想前关键的信息**是任务、使用情境、交付形式、不可更改对象和主要偏好／排除。暂缺时可以提出假设，但要说明哪种回答会改路线。

**制作前关键的信息**包括实际尺寸、必要动作、机位与可见范围、接触／承载要求、材料候选、场地与资源。尺寸未确认，不输出伪精确施工数据；仍可画关系、做缩小的概念验证。

**测试前关键的信息**包括要回答的问题、基准、改变因素、观看和使用条件。没有对照，允许探索，不假装因果诊断。

**交付前关键的信息**包括谁批准了什么、哪些测试做过、使用范围和谁承接剩余事项。审批与技术验证分别记录，不能互相代替。

一个实际问法：“包装必须保持已知尺寸，这是搭建前需要确认的；当前可以先比较‘材料打开’与‘光影经过’，这两条关系不依赖最后的背板宽度。”这样既不鲁莽定案，也不停止创作。

## 5. 用四种证据身份，避免方案、结果和批准混在一起

**输入事实。**来自用户、现有文件或已核查来源，例如包装版本、实际场地测量、主创在访谈中的陈述。

**方案／假设。**本次提出的关系、材料、尺寸或试验路径。来源再充分，也不自动成为当前项目实测结果。

**实际观察。**具体版本的样片、试拍、操作记录。写出发生了什么与观察条件；与原因解释分开。

**确认决定。**由明确的确认者，针对特定对象和范围批准的选择。不是“大家感觉应该可以”。

“已测试”与“已确认”不是同一条状态阶梯。可以测试过但未获方向确认，也可以概念确认但没有材料测试。建议每个关键对象分别写：当前选择、依据、验证范围、确认范围、待办；不把它们压成一个含义模糊的绿灯。

示例：PF03 采用局部运动片，是当前方案；试验尚未实施；概念关系已在教学设定中暂选，但真实项目未有人批准。不能因为文档写满，就把 PF03 标成“制作通过”。

## 6. 最少但足够的当前依据

可以在一页当前项目说明中保存：项目版本、任务、核心关系、当前选中路线、资产／构件入口、实际试验入口、未定项、下一动作。

尺寸以构件说明为依据；材料效果以对应版本样片与条件为依据；动作以状态与试拍为依据。其他地方引用这些对象，不重新抄一套可能冲突的数据。

W3C PROV 用实体、活动、参与者及使用、派生等关系表达来源。[S39] 这里仅借其关系思想：让一个结果能回到使用了什么、做过什么、由谁确认。不要求采用 RDF 或建立数据库。

例如：

```text
PF03-v02 构件说明
  使用：MAT03-v01 材料候选
  服务：SHOT02-v03 显露动作
  试验：TEST07 尚未实施
  方向依据：CONCEPT-A 中的“材料参与显露”
  当前下一动作：按 TEST07 比较自由片与局部支撑
```

这是关系示例，不是实际文件和试验已经存在。真实使用时必须指向真实产物；不能为了让结构漂亮生成一堆空编号。

## 7. 一段可以直接转写的执行规范

以下是工作规范草案，不依赖某个平台的安装格式：

```text
目标：帮助用户完成美术创作和制作，不把解释风格作为默认终点。

先判断用户处于需求、构想、方案发展、制作、测试、回修或交付中的哪一位置。读取已有资料，保留已确认的关系与限制；不重复索取已经明确的信息。

需求不足时，将原话拆为任务、体验、偏好、限制和假设。给出可讨论的解释及机制不同的候选，说明主体、关系或事件、观看位置和第一项试验。能通过可逆候选推进的问题不阻塞；会改变目标或不可逆制作的未知应标明。

需要构想时，优先改变关系、尺度、行为、边界、时间、材料操作或观看方式，不用换色版本冒充不同创意。不把固定情绪词映射为唯一颜色、形状或材质。参考必须说明借什么、不借什么、如何进入当前项目。

发展方案时，把视觉命题展开为关键画面、空间与机位、材料和道具、动作与复位、实际或数字实现。效果图只证明其所表达的外观；施工、运动、多视角和运行需要各自的证据。

为每个关键制作对象说明：要怎样看、怎样使用、哪些面可见、怎样拆分、哪些性质由什么实现、谁继续处理、最先测试什么。尺寸不明时用明确的草案或关系，不伪造精确工程数据。

为效果提出机制、起始布置、试做步骤、主要变量、常见失败、替代路径和适用范围。工艺配方与材料兼容按当前说明和小样，不把供应商单案例当通用方法。

测试前区分探索、诊断、适用性和运行。保留基准与观察条件；涉及交互时比较少量组合。没有实际执行时只输出计划，不填成功率、试验结果或“已通过”。

回修时先定位实际现象，区分原因候选。说明保留什么、改变什么、如何比较，以及修改影响哪些镜头或构件。局部问题不无理由重开全案；核心冲突也不伪装成小修。

交付时明确当前依据、实际完成范围、未确认项和下一动作。方向确认不代替技术验证，技术验证不代替工程和使用确认。不让多个“最终版”互相竞争。

非商业作品可保留有意的歧义、人工性和不悦；不强迫其服从商品识别或唯一解释。商业效果与观众反应需要相应证据，不由形式分析直接推定。

按项目大小合并文档，仅保留有人会据此画、做、买、摆、拍、复位或确认的信息。先给可执行内容，再提供必要理论与来源。
```

这段规范需要与实际工具能力匹配。能绘图就输出图，不能绘图就准确声明提供的是绘图说明；能读取视频就记录实际时点，只有静帧就不编造运动；没有实体环境就不宣称完成试样。

## 8. 模板一｜需求转译与第一项试验

```text
项目／交付形式：
原话与来源：
作品要完成的任务：
不可更改条件：
当前体验解释：
可能的另一种解释：
拟转成的关系／事件：
尚会改变路线的问题：
可以先采用的假设：
第一项可逆试验：
下一位使用者及其需要作出的决定：
```

**填写示范。**项目为虚构香水，三张 4:5 与一条 9:16 短片；原话“精细但亲近”；包装不改。暂将亲近解释为近身尺度与可触碰材料，另一解释是日常使用场景。候选分别是柔软轮廓打开、光经过生活台面。先画同等完成度的关键关系并试材料动作；最终文字要求仍需确认。下一步由创作确认者选择关系，不让工坊据这张表立即采购全部正式材料。

**不要填成**“风格：高级、自然、电影感；执行：自由发挥”。那没有缩小任何制作问题。

## 9. 模板二｜机制路线与取舍

```text
路线名称：
一句视觉命题：
主体与事件：
空间／材料如何参与：
关键画面或状态：
与其他路线本质上不同的地方：
必须保留的关系：
可替换的实现：
最早可能推翻路线的未知：
第一项试验及选案依据：
```

**填写示范。**路线“柔软空间打开”：材料从遮蔽转为显露，产品保持近身尺度。区别于“光经过”，变化由材料而非照明主导。不变量是材料参与事件、主体稳定、最终包装可辨；材料种类和局部支撑可变。最先验证完整开启与复位，不先精修金属高光。若自由运动不能稳定实现，可比较固定背景加局部动作片；若事件本身无法成立，再回到另一机制。

**消费检查。**空间设计者能否由命题知道需要哪个开口？道具人员能否知道什么会动？若答案是否，这个路线包还没有进入可发展状态。

## 10. 模板三｜镜头—空间—构件交接

```text
镜头或照片标识／版本：
这一画面让人知道什么：
起始、中间、终点与必要停留：
相机／主体的关系（未知明确标注）：
必须可见与必须暂时不可见的内容：
直接和反射可见的构件：
动作与维护空间：
材料、图形和后期接口：
需检查的极端视点／裁切：
当前依据及承接方：
```

**填写示范。**SHOT02 是香水显露段：起始只见材料，开启中逐步显露瓶体，末尾建立完整关系。PF03 动，PF01 不动；PF02 提供背景开口，PF05 不直接入镜但参与反射。需要检查中途控制点与竖版边界。尚未确定正式镜头焦距，当前不能写出最终可见宽度；先用产品实际尺度与目标相机做视角试验，摄影与空间人员共同更新依据。

**常见缺口。**只交三张静帧，没有中间过程；只写“美术搭配合适道具”，没有说明物件在哪一状态发挥作用。应补关系，不是多写风格解释。

## 11. 模板四｜构件、面层与运行说明

```text
构件／版本及对应镜头：
外观任务与行为任务：
尺寸、单位、定位基准及尚未测量项：
结构／可见体量／面层／可替换部分：
边缘、接缝、背面与间接可见面：
材料候选及样片入口：
连接和运动接口（专业设计另行确认）：
安装、操作、复位、拆收：
检查条件与实际状态：
```

**填写示范。**PF03-v02 为局部运动片，不承托产品；服务 SHOT02。轮廓与控制位置须按最终机位确定，现阶段仅有关系草案。近景表皮可替换，背面在开启中可能入镜，需要与正面同时测试。与 PF01 独立，避免牵动瓶体。当前材料两候选、动作未试；工坊先制作局部样件，不能按“已批准成片效果”理解为所有工艺已定。

**消费检查。**拿到这张说明的人应该知道先做哪一个样件，而不是自行替导演选择整个动作语言。承重、机构与电气不由文字模板代签。[S08][S10][S41]

## 12. 模板五｜材料与效果试验单

```text
试验问题／类型：
对应材料、构件与镜头版本：
候选和变量；需要时列组合：
基准与保持条件：
样片制作／动作步骤：
拍摄与显示条件：
观察重点、不接受的情况：
实际结果入口：未实施时保留“未实施”
解释、替代原因与适用范围：
下一动作及影响对象：
```

**填写示范。**TEST07 比较 PF03 自由垂落和局部支撑的开启，固定产品、构图与照明；记录主褶皱、显露时点、停留与复位。它是动作适用性试验，不判断品牌传播效果。之后 TEST08 才比较两面层与两光向的四组合。两项尚未做，因此目前只列计划，结果不填。

**消费检查。**测试执行者是否知道怎样恢复基准？评审者是否知道本次不评什么？未能区分的结果应该写证据不足，而非硬选一个冠军。[S04][S34][S35]

## 13. 模板六｜道具状态与复位

```text
道具／使用者／镜头：
开始状态（数量、位置、朝向、内容）：
动作中发生的改变：
结束状态：
复位步骤及位置参照：
使用或清洁后可能变化的部分：
主体件、动作件与备用件的必要差异：
实际检查与尚待确认项：
```

**填写示范。**餐厨场景中的 CUP-B 从收纳区取出，在桌边停顿后放回。起始朝向与落点要能让动作顺手且被看见。复位不是重新摆得整齐，而是恢复动作前的指定状态；如果中间改变其他餐具，也一并恢复。替换件除了图案，还要比较握持、重量造成的动作和反射。未进行排练，不把示范动作认作演员已接受。

**消费检查。**下一条开始前由谁恢复、恢复到哪张状态照片，必须明确；非关键背景物不必逐毫米记录。按实际连续性需求选择精度，不让模板膨胀。

## 14. 模板七｜局部回修与回归范围

```text

它与哪项已确认要求冲突：
原因候选及先排除什么：
保持不变的关系与对象：
第一项修改／备选修改：
比较方法与需要复查的镜头：
实际结果与是否采纳：
受影响的下游入口：
```

**填写示范。**末段金属盖出现多条竞争亮带，名称附近不清；保留包装、产品位置、背景开口与显露事件。先调整 PF05 的一处反射关系，不换整个面层；同条件比较，并重查完整相机范围与 PF03 动作。若修改影响背景亮度，则增加组合复查。未测试前的结果写未实施，不能预先写“反射问题已解决”。

**消费检查。**执行者是否明确“不改什么”？变化之后有没有新的问题进入其他镜头？只有实测结果与确认决定都清楚，才能更新当前依据。

## 15. 模板八｜实体、数字与后期的效果分工

```text
效果与它的画面作用：
必须真实接触／遮挡／反射的关系：
实体负责的对象：
数字负责的对象：
需要共同保持的相机、空间与时间条件：
需采集的基准、干净背景、状态或其他素材：
输入解释、创意预览与输出要求：
当前缺口、验证方法和负责方：
```

**填写示范。**香水片的真实产品与材料承担接触和显露，数字只拟清理局部控制痕迹，不改变包装。需保留基准画面、动作完整过程和必要干净背景；有反射的控制物不能只按普通遮罩思路假定可擦除。具体采集由后期人员依据镜头确认。前期不得保证“所有支撑后期都能轻松去掉”。

ACES 文档提供输入、Look 和输出职责的清楚区分；这里借其链路意识，不要求每个团队安装同一系统。[S36][S37][S38]

## 16. 模板九｜完成交接与仍未完成的事项

```text
项目与当前版本：
本次交付类型：概念／待制作／指定范围已验证／其他
已批准对象及批准范围：
实际验证对象、条件与证据：
制作使用入口：图、构件、样片、动作、试验
不能据此推定完成的事项：
阻断下一步的问题／非阻断待办：
下一动作、承接方、需要更新的唯一依据：
```

**填写示范。**当前为香水方案发展包，路线 A 暂选，PF01—PF05 完成文字拆分；不代表已有施工图、实体样片或拍摄通过。下一步是实际尺度动作与反射测试。更新材料时先改对应构件与样片入口，其他文件引用它，不重新手抄三份尺寸。

**消费检查。**交付接收者能否直接判断可以画、可以做样，还是可以正式生产？若只能看到笼统的“完成”，状态没有帮到工作。

## 17. 模板十｜经验条目与来源卡

```text
当前问题与适用情境：
资料事实／本次方案／实际结果分别是什么：
有效的关系或制作操作：
原材料、尺度、镜头与使用条件：
失败情况及改过什么：
允许迁移的部分：
不适用条件与需要重测的部分：
来源、版本、实际证据入口：
```

**填写示范。**“固定背景加局部运动片”目前只是香水教学项目的候选，未验证；它可能保留主轮廓并减少自由运动范围。今后真实实施后应记录哪些材料、动作、尺度和观察支持了判断，再决定能否作为经验。不能因本包写得完整，就把它录成“成熟验证工法”。

经验库可以包含未验证创意，但要保留身份。基于个案的条件性经验比“所有柔软效果都这样做”的规则更值得复用。[S02][S39]

## 18. 一个变更贯穿示范：新增横版，哪些要改、哪些不动

**教学设定。**香水项目原有 4:5 静物与 9:16 短片，后来增加一条 16:9 横版。不要直接将它标成“裁一下就完成”，也不默认重新做一个完全无关的世界。

先确认新增版本是否沿用相同时长、动作和包装显露要求。若相同，保留概念 A 与产品身份；更新交付列表与镜头的有效范围。

接着核查空间：PF02 的左右边界是否会暴露；PF03 的运动是否仍形成合适开口；PF05 是否反射出横版新增区域。第 02 篇的可见范围方法用于预估，再由实际镜头验证。

再核查素材：原片是否有足够画面信息，不能把一个被裁掉的区域假装恢复成已实拍。可比较重新取景、局部补建、补拍或有明确边界的数字扩展，成本和风险另行确认。

最后更新受影响的构件、镜头和测试，不重写不相关的道具经历。已验证的面层近景可以保留其证据范围，但新的横版运动范围需要补测。

**如果是包装变更**，影响路径不同：产品尺度、标签可见性、反射与接触会重新关联。不要把两个变更都处理成一键“全案重审”；按实际依赖找出需要重新工作的对象。

## 19. 十八个反例测试：怎样判断这项 skill 真有用

| 测试输入 | 应产生的工作 | 不应出现的行为 |
|---|---|---|
| 只说高级自然 | 多种解释与机制候选、第一试验 | 一串同义风格词 |
| 三个方案仅换颜色 | 指出机制相同，提出关系级变化 | 包装成三大创意 |
| 概念已批准，只问材料 | 材料行为、样片与替代路线 | 重新讲完整艺术史 |
| 用户给一张生成图要求开工 | 提取已知，补空间／动作／尺寸验证 | 宣布已可施工 |
| 只有静帧却问运动是否可用 | 限定证据，设计全程测试 | 编造中间镜头 |
| 金属不好看但无实拍 | 有条件的诊断顺序 | 断言某个灯位就是原因 |
| 材料 A 在一种光下失败 | 判断是否需组合测试 | 永久淘汰 A 且不看目标条件 |
| 表干就要用于重复动作 | 按产品体系确认状态、试样 | 一概声称已达使用性能 |
| 景可看但演员动作别扭 | 改行动与可见关系 | 只增加陈设 |
| 同款备用件造成不同动作 | 核对行为和状态 | 只看外观同款即通过 |
| 最后面层破坏效果 | 与保留基准比较、定位该层 | 全部重新上色掩盖原因 |
| 新增横版 | 查可见范围与关联对象 | 硬裁或无理由重开全案 |
| 非商业要求不稳定 | 讨论有意歧义与可控变化 | 强迫所有人读出唯一信息 |
| 没有真实试验数据 | 明确计划，保留结果空缺 | 写成功率或“已测试通过” |
| 没有供应商报价 | 列成本项目和需询价对象 | 虚构精确预算 |
| 概念批准、工程未确认 | 区分批准范围，保留阻断 | 把美术认可当安全许可 |
| 引用付费课程介绍 | 仅使用公开说明 | 声称掌握整门付费课程 |
| 两份“最终版”相互矛盾 | 找当前依据并解决消费关系 | 让下游自行猜测和重判 |

这些是行为验收，不是给艺术好坏打分。实际实现 skill 后，可将输入、输出、失败原因和修订保存为测试记录；本包尚未执行这些平台级测试。

## 20. 学习与熟练度：把模板交还给制作

初学者可以先完成一个物件、一个面层、一个动作：用第 01 篇提出关系，用第 03、04 篇做低风险小样，用第 05 篇记录真实结果。任务小，但链条完整，胜过写一套无法开始的大型世界观。

进阶练习是同一主体的三个条件：静态近景、完整动作、另一交付比例。观察原来有效的材料和空间怎样受到新条件影响，练习保留意图、改变实现。

更复杂的练习才加入现成场地、多人操作、混合实拍和数字资产。每增加一个系统，都回答它与已有对象怎样接触、交换什么信息、失效时找谁，不靠再开一个抽象角色解决问题。

小项目可将十张模板压缩为两三页；复杂项目再拆。若字段不能改变任何实际工作，删掉；若下游必须猜测某个关键关系，补上。完整性应按消费需要衡量，不按文件数量衡量。

## 21. 最后一条规则：输出应该让下一步真的发生

一份好产出，应让接收者能回答：“我现在要画哪种关系、做哪块样片、摆哪几个对象、验证哪个动作；什么已经确定，什么不能擅自决定。”

模型可以帮助组织创意与知识，但专业制作仍需要实际空间、材料、设备、操作者和反馈。应让这些真实证据持续进入方案，而不是用越来越长的文本替代它们。

因此，最重要的完成标准是：**当前工作是否产生了足够具体、条件清楚、能被下一步使用的对象；下一步的实际结果，又是否能准确返回并改变相应选择。**

主要依据及其使用范围见 [S02][S04][S11][S12][S34][S35][S39] 与 [08](08_研究来源与适用边界.md)。本篇的执行规范、模板、示例和反例测试均为应用编订，不宣称来自某个现成统一标准。
