> 构图技法卡 C08。卡中的“表达”均为有条件的候选，不是技法的固定情绪翻译；示例均为假设设计（见 [证据边界](/references/evidence-boundaries.md)）。

# 操作与机制

对角关系可以来自物体姿态、建筑线、运动轨迹；滚转则是相机绕观察方向旋转，使画框与重力参照发生变化。斜线构图并不等于荷兰角。

# 选用条件

强调方向、坡度、重力关系、运动对比，或建立一种持续偏斜的形式世界。人物不安只是可能解释之一，也可用于游戏感、图形感或舞蹈。

# 时机与过程

持续偏斜是一套观看常态；从水平转成偏斜是变化事件。两者不能用同一条“倾斜意味着失衡”解释代替。

# 前后镜头

可以保持相近斜向以续接运动，也可以在切点改变斜向形成反差。必须检查实际行动方向是否仍符合希望观众理解的路径。

# 失败与替代

为“动态感”随意倾斜后，标签、人物头部与动作路线互相挤压。可通过物体姿态、构图对角线或侧向运动提供方向，而不滚转相机。

# 假设测试

三个镜头依次从稳定水平走向更强斜线，检查变化是否与形式或事件节点有关系，而不是每个镜头都独立倾斜。
