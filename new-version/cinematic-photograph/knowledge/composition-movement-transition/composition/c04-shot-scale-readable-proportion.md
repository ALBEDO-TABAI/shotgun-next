> 构图技法卡 C04。卡中的“表达”均为有条件的候选，不是技法的固定情绪翻译；示例均为假设设计（见 [证据边界](/references/evidence-boundaries.md)）。

# 操作与机制

决定人物／物体占画面多大，以及多少环境同时可读。景别是相对对象的描述，不能由焦距名称单独决定。[S01](/references/s01-yale-film-analysis-cinematography.md)[S03](/references/s03-pbr-projective-camera-models.md)

# 选用条件

全身动作、两人距离和场景路线优先需要相应关系可见；表情、触点或标签阅读需要相应细节可辨。不是“情绪片就全特写”，而是判断本镜头究竟需要身体、表情、对象还是空间。

# 时机与过程

可以先给关系、再选择细节；也可以先给细节、后揭示整体。先近后远会留下“它属于哪里”的问题，先远后近则把一个已知整体中的部分抽出来。

# 前后镜头

景别变化应带来新的关系或观察条件。连续两个几乎相同的中近景，可能只是重复，也可能让细微表情差异成为主题，需结合任务判断。

# 失败与替代

把使用演示切成漂亮局部，观众无法理解手与包装怎样相接。替代方案是用完整动作的中景作为结构，再以特写补充确实需要的细节。

# 假设测试

一次开盖分别用全动作、局部和两者分切拍摄；让未看过预案的人复述动作顺序，检查哪里存在信息缺口。
