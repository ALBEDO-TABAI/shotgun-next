# Camera Movement · 运镜与镜内调度技法卡库 M01—M17

回答“这种关系怎样随时间变化”。区分轨迹、相对关系、设备品质与替代工具（固定、转焦、调度）。

# 写法与验收
* [写运镜之前，先写七件事](movement-seven-prerequisites.md) - 运动描述的七项顺序与方向参照系要求，并把固定、调度、转焦、直切列为必要比较候选。
* [运动的时间曲线比“快／慢”更有信息](movement-time-curve.md) - 按整体速度、局部变化、事件同步三层记录运动时间结构。
* [运动方案的验收方法](movement-acceptance.md) - 先查内容是否发生，再查过程可读，最后查执行；每个候选保留固定/单一运动/直切对照。

# 固定与转向
* [M01｜固定机位：让变化发生在画框内部](m01-static-camera.md) - 相机位置与朝向稳定，让变化发生在画框内部；是所有运动方案的必要对照。
* [M02｜水平摇摄 Pan：沿方向依次组织信息](m02-pan.md) - 只改变水平朝向的转向观察，沿可理解方向依次组织信息。
* [M03｜俯仰摇摄 Tilt：沿垂直关系显露](m03-tilt.md) - 改变俯仰角沿垂直关系显露，区别于整机升降。

# 位置变化
* [M04｜推进 Dolly/Track In：改变接近的过程](m04-dolly-in.md) - 相机向对象接近，接近过程本身承担表达；终点按新的可读关系而非轨道长度确定。
* [M05｜拉远 Dolly/Track Out：让对象进入更大的关系](m05-dolly-out.md) - 相机离开对象，让更多环境或关系进入，常用于揭示、收束或尺度转换。
* [M06｜横移 Truck/Track：通过视差和遮挡变化观察](m06-truck-lateral.md) - 相机横向改变位置，通过视差与遮挡变化观察，区别于原地摇摄。
* [M07｜弧线／环绕 Arc/Orbit：改变同一对象的关系面](m07-arc-orbit.md) - 沿对象周围弧线移动并改变朝向，重新分配可见面、前后关系与背景。
* [M08｜领拍、跟拍与并行：决定主要给观众哪一种信息](m08-lead-follow-parallel.md) - 领拍/跟拍/并行是相对位置，决定主要给观众面部、前方环境还是侧向关系。
* [M09｜升降、摇臂与高度显露](m09-crane-height-reveal.md) - 相机高度改变以越过前景、显露场地尺度或在身体与整体尺度间转换。

# 光学与复合
* [M10｜变焦 Zoom：让选择的动作可见](m10-zoom.md) - 位置不变改变焦距，调整视场与尺度，让'选择'的动作可见；不产生真实视差。
* [M11｜推拉变焦 Dolly Zoom：保持主体尺度而改变背景关系](m11-dolly-zoom.md) - 联动位移与反向变焦保持主体尺度（f/Z 近似恒定），改变背景关系。
* [M15｜复合运镜与长镜头：把剪辑任务纳入路线](m15-compound-move-long-take.md) - 在连续呈现中组合位置、尺度、调度与焦点变化，把剪辑任务纳入路线。
* [M16｜焦点转移 Rack Focus：相机不动也能改变信息开放](m16-rack-focus.md) - 改变对焦位置安排清晰度先后，相机不动也能改变信息开放；不能解除几何遮挡。

# 运动品质
* [M12｜手持：身体化响应是一种设计变量](m12-handheld.md) - 操作者直接支撑形成的身体化响应，是可设计的运动质地而非纪实的专属符号。
* [M13｜稳定移动：把位置变化与抖动分开考虑](m13-stabilized-movement.md) - 减少不需要的扰动、保留计划的位置/朝向变化；稳定是运动品质，不等于缓慢。
* [M14｜甩镜 Whip Pan：用快速方向变化压缩观察过程](m14-whip-pan.md) - 快速改变朝向压缩观察过程，可用于转移、回应或隐藏接缝。

# 替代运镜
* [M17｜镜内调度替代运镜：让对象改变关系](m17-blocking-instead-of-movement.md) - 通过人物/物体的进出、转身、让位与遮挡让构图发展，替代相机运动。
