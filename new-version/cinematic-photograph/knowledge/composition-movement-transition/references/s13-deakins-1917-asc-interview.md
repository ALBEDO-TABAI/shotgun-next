# 核读范围

《1917》段落中观看位置、动作排练、场景尺度、领拍／跟拍、复合运动和连接问题的相关问答。

# 支持内容

视点、调度、动作时长和场景条件必须联合设计；长镜头不能靠一条运动轨迹替代逐段的信息组织。

# 使用边界

创作者关于沉浸感和“是否适合”的解释是该项目的意图与评价，不是控制实验；不把器材选择推广成普遍处方，不声称整部片真实一次拍摄。
