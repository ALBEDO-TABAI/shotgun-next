仅有“镜号—景别—内容—时长—运镜”，仍可能无法支持制作。它记录了镜头的独立属性，却未必说明动作的哪个阶段需要保留、前后物体状态怎样接续，以及相机为什么此刻移动。

建议用一个主要镜头计划承载已确认的事实；提示词、摄影说明和剪辑说明从它读取，不各自重新发明一版时间线。每个镜头不必填满全部字段，但被确认重要的条件必须有消费它的人或步骤。

最小镜头记录可以包含：

| 字段 | 应写到什么程度 |
|---|---|
| 观看任务 | 让什么信息可读，或发展什么形式关系 |
| 起始状态 | 人物／物体／动作和当前可见范围 |
| 核心变化 | 不是“有运动”，而是谁与谁的关系怎样改变 |
| 触发与切点 | 按事件、动作阶段或形式节拍描述 |
| 画面组织 | 必须同框、可遮挡、允许未知的部分 |
| 相机与对象运动 | 分开写，注明方向参照 |
| 结束状态 | 下一镜头可以继承的内容；允许的未完成部分 |
| 相邻关系 | 连续、省略、重复、类比、反差等 |
| 检查方式 | 用完整播放、对照预演或具体内容检查来验证 |

这不是要求每个镜头都极度复杂，而是让“简单”也有可执行的含义。
