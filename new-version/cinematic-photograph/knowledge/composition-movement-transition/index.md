# 构图—运镜—镜头衔接 · 表达技法与选择时机知识包

补足摄影理论体系中参数与作品之间的“表达技法层”：同一观看任务有哪些可选技法、每种改变什么、何时启动/停止/切换、与前后镜头如何配合、何时应换成调度、固定、转焦或直接剪切。

主线：**画面关系 → 镜内变化 → 镜头间交接 → 段落发展**。不把技法当作固定情绪字典，也不把形式显著、实验性或故意不连续的作品当成“错误连续性”。

适用：广告、叙事影片、纪录与观察性作品、时尚影片、实验影像，以及平面摄影的构图与系列组织。

> 状态：研究综合稿 v1.0（2026-09-18）。技法卡、流程、交接约定、案例与验收题是本包的工作化综合；案例为假设方案，Skill 为设计规范，未宣称执行过实际视频生成、观众试验或部署验收。证据边界见 [研究来源与证据边界](references/evidence-boundaries.md)。

# 三条使用路径
* **分析一条参考片**：先读 [镜头内部三状态](foundations/shot-key-states-and-trigger.md)，按真实材料填写起幅/转折幅/落幅；再从 [构图](composition/)、[运镜](camera-movement/)、[衔接](transitions/) 找相关卡；最后用 [证据边界](references/evidence-boundaries.md) 区分观察、推断和未知。
* **设计一个新段落**：先明确观看或形式命题；按 [联合选择表](foundations/joint-selection-table.md) 提出不同机制的候选；读相关卡的起止与衔接条件；用 [轻量镜头计划模板](skill/shot-plan-record-template.md) 组织方案，不先定器材清单。
* **构建 Skill**：以 [执行流程](skill/execution-workflow.md) 为骨架，技法卡按需检索，[references](references/) 保留来源与不确定性；不要求每次输出整套长报告。

# 技法卡的共同读法
每张卡回答：操作与机制、适用条件、时机与过程、前后关系、失效风险与替代、假设测试——支持“为什么此刻选这个”，而不只回答“这个叫什么”。共 53 张卡（C16 + M17 + E20），是覆盖核心决策问题的一种可用划分，不代表技法只能分为 53 种。
