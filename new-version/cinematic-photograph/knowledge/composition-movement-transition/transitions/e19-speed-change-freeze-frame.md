> 镜头衔接技法卡 E19。卡中的“表达”均为有条件的候选，不是技法的固定情绪翻译；示例均为假设设计（见 [证据边界](/references/evidence-boundaries.md)）。

# 操作与机制

通过变速、停留单帧或其他时间处理，改变动作在播放中的展开。速度变化不是运镜本身；拍摄帧率、单帧曝光、播放速度与插帧也不能混同。

# 选用条件

需要突出动作的某个阶段、让两个不同速度的动作建立关系、把动态图像转为平面呈示，或显露对时间的处理。

# 切点选择

在准备、发力、接触或余波处变速，各强调不同部分。定格前的动作应提供足够背景；从定格转到下一镜头，可以接图形、声音或新的动作起点。

# 两侧约定

检查实际运动速度、模糊程度、物体状态和声音。帧率不同不自动造成问题，强行使所有画面一样模糊也不自动改善衔接。

# 失败与替代

加速掩盖关键用法、减速后动作缺乏连续性、插帧改变手与物体接触形状。可恢复原速、使用更合适的素材，或让速度变化更明确成为形式，而非假装原始记录。

# 假设测试

产品被放下后定格作为落版，对比在接触前定格、接触瞬间定格、停止后定格；检查文字阅读和动作结果是否都成立。
