> 镜头衔接技法卡 E03。卡中的“表达”均为有条件的候选，不是技法的固定情绪翻译；示例均为假设设计（见 [证据边界](/references/evidence-boundaries.md)）。

# 操作与机制

一个镜头提供观看线索，另一个显示可能被看见的对象，随后可出现反应。镜头次序建立“谁看见什么”的解释条件；对象镜头未必严格等于人物眼睛的光学位置。[S02](/references/s02-yale-film-analysis-editing.md)

# 选用条件

需要组织发现、误解、期待或人物与对象的关系。可以先对象后人物，也可以只有人物不交代对象，或者延后反应。

# 切点选择

目光开始移动、目光停住、面部已有反应后再切，分别给观众不同的推断时间。要区分“跟随注意”和“先看到表情再找原因”。

# 两侧约定

检查视线的水平与垂直关系、对象距离线索、是否需要主观镜头的严格位置，以及下一反应发生在知道信息之前还是之后。

# 失败与替代

视线暗示对象在右下，下一镜头却缺乏位置线索；对象镜头看似解释了人物，却不是其可知内容。可补共同空间、调整机位或明确使用非主观插入。

# 假设测试

人物看向空椅：先看空椅再看人、先人再空椅、只留人三版。不要简单用“库里肖夫效应”包办所有解释，具体含义仍依赖情境。
