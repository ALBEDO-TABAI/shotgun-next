> 镜头衔接技法卡 E08。卡中的“表达”均为有条件的候选，不是技法的固定情绪翻译；示例均为假设设计（见 [证据边界](/references/evidence-boundaries.md)）。

# 操作与机制

用形状、轮廓、色块、构图位置或图案相似建立镜头关系。匹配可以跨地点、尺度和对象，未必表达同一事件。[S02](/references/s02-yale-film-analysis-editing.md)

# 选用条件

希望建立类比、视觉韵律、产品结构联想或段落形式统一。先明确想让观众联系什么，不只追求接缝看起来巧妙。

# 切点选择

让主要形状达到适合比较的状态再切，也可以在运动中通过轮廓对应衔接。需要识别具体对象时，别把接缝压缩到只剩抽象形状。

# 两侧约定

确定主要保留的是圆形、方向、位置还是色块；其他差异可以提供对比。不要要求所有图形属性同时匹配，否则可能失去有意义的新信息。

# 失败与替代

把任何两个圆形都接在一起，却没有作品层面的关系；或形式类比被误读为实际材料／效果相同。可改为明确的并置、解释性镜头或普通切换。

# 假设测试

从瓶盖圆形切到水面圆环，仅提出形状联想，不用画面类比充当产品机理证据；检查成片是否保持这一区分。
