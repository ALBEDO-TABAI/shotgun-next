> 镜头衔接技法卡 E02。卡中的“表达”均为有条件的候选，不是技法的固定情绪翻译；示例均为假设设计（见 [证据边界](/references/evidence-boundaries.md)）。

# 操作与机制

两个视点承接同一动作，使画面变化与动作持续同时存在。它利用动作的可理解接续，而不是任何快速运动都能遮住一切错误。[S02](/references/s02-yale-film-analysis-editing.md)[S05](/references/s05-magliano-zacks-event-segmentation.md)

# 选用条件

需要在不明显中断动作的情况下改变景别、观察面或空间位置；例如伸手—接触、起身、开门、放下物品。

# 切点选择

从一段完整动作中寻找可接续的阶段：动作刚启动、执行中、关键接触附近、结果开始出现。接触瞬间重要时，应确保它在某一侧确实可见，而不是被两侧剪裁共同删掉。

# 两侧约定

检查使用哪只手、物体位置与状态、动作阶段、屏幕方向、速度走势以及接触位置。并非数学上完全逐帧重合才成立；必要时可以测试微小省略或重叠，但要防止明显倒退与重复。

# 失败与替代

A 已经开盖，B 又从盖紧开始；手的方向相同却换了一只手；声音在另一个时间点。可选另一个 take、移动切点、插入确有信息作用的镜头，不能靠“运动够快”宣告通过。

# 假设测试

拍一遍完整中景与完整近景开盖，尝试三个动作阶段的切点，先正常播放判断，再逐帧定位问题。
