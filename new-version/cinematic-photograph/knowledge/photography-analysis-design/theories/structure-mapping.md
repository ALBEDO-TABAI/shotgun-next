# 原意

Gentner 的结构映射理论区分对象属性与关系，强调类比可保留关系结构及其系统性，而不只匹配表面特征 [1]。

# 本包的工作化用法

- 两个案例都蓝、都闪亮，不一定解决同一个问题；颜色、对象完全不同的两个案例，却可能都使用“先局部接近，再完整识别”的组织。
- 先明确希望迁移的关系，再检查表面条件是否允许它成立。

用于：[迁移什么](/transfer/what-to-transfer.md)、[来源到目标的关系映射表](/transfer/source-target-mapping.md)。

# 边界

这种转译**不是论文已验证的摄影应用**，也不意味着表面属性不重要——材料、尺度、颜色与对象结构仍会限制实现。
