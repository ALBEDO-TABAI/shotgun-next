# 原意

Bordwell 的电影诗学关心作品如何被组织、这些组织如何发挥作用，以及创作传统、历史条件与观众参与之间的联系——是研究作品运作方式的方向，而不只是寻找主题或分类名称 [1]。

# 本包的工作化用法

分析一个显著选择时依次写出：

> **要处理的观看问题 → 采用的形式关系 → 可能作用 → 还有什么其他解法**

例：“不让背景看清”可以是降低同时需要阅读的信息量、让接触位置更突出、保持某信息尚未显露，或只是制作条件的结果。价值在于把**形式选择、可能功能和替代解释**同时保留下来。

skill 不应只输出：
> 使用浅景深，营造梦幻感。

而应输出：
> 当前画面只让接触位置清楚，环境退为不可辨认的色块。这使接触位置获得更明确的阅读条件；“强化感官体验”是一种合理解释，但尚不能据此确认创作者意图。

用于：[七步风格分析流程](/style/style-analysis-workflow.md) 第 5 步。

# 边界

- 借用的是“研究作品怎样运作”的方法，**不是“每个细节都必然经过精确设计”的假定**；生产条件、合作、偶然性与后期都应保留为解释路径。
- “问题—选择—作用—替代方案”是应用综合，不是书中经逐字核实的固定步骤。
