# 原意

Barron 与 Malik 把单图中的形状、照明和反射恢复视为具有多解性的问题，并通过先验与优化选择解 [1]。

# 本包的工作化用法

- 即使只问物理场景，也不应默认像素唯一决定照明和材料。
- 延伸到创作分析：**不在缺少额外记录时，给一个最终效果指定唯一器材、操作或动机**。
- 多解性要求**比较假设**，而不是“一切解释都同样合理”：有些候选与可见结构矛盾，有些需要更多未观察条件，有些被原始记录支持。
