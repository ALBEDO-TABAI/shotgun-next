# 理论支点

被一个或多个模块使用的外部理论。每条分“原意／本包的工作化用法／边界”三节书写。

# 风格与形式（01）
* [Bordwell & Thompson 的电影史研究方法（Doing Film History）](bordwell-thompson-film-history-method.md) - 风格是技法的模式化运用；研究要区分描述与解释，核验来源与版本，考虑个人与群体层面的多类原因，不把先后当因果。
* [Bordwell 的电影诗学：研究作品怎样被组织出来](bordwell-poetics.md) - 从“它属于什么”转向“它怎样被组织、怎样发挥作用”，转译为“观看问题—形式关系—可能作用—替代方案”的提问结构。
* [Bordwell 的四种风格功能：指示、表现、装饰、象征](bordwell-four-style-functions.md) - 同一技法可同时承担多种功能；形式不必只有叙事理由；用于扩大解释空间，而非每个镜头必填的四格表。
* [Szarkowski《The Photographer’s Eye》：摄影对世界做了哪些选择](szarkowski-photographers-eye.md) - 事物本身、细节、画框、时间、观看位置五个相互依赖的方面，提示先识别“世界如何变成图像”，再识别“图像像哪种风格”。
* [Shore《The Nature of Photographs》：物理载体、描绘结构与心理领会](shore-three-levels.md) - 区分照片作为物理对象、描绘图像与心理领会对象三个层面，据此把材料、图像、解释分开记录。
* [格式塔知觉分组：分析关系，不只盘点元素](gestalt-perceptual-grouping.md) - 邻近、相似、良好连续、共同运动等分组因素及图形—背景组织，支持把风格分析的重点放在元素如何被组织为整体。
* [艺术类别理论：“非常规”必须说明相对于什么](categories-of-art.md) - 审美理解涉及可感特征与作品类别、来源；某特征在一类中常规、在另一类中可能反常——据此要求先声明比较参照。
* [Manovich 的深度可混合性（deep remixability）](manovich-deep-remixability.md) - 混合的不只是不同媒介的内容，还有技法、工作方法与表现方式；来源可以显露为拼贴，也可以无缝融合。

# 观看与注意
* [看见同一处，不等于理解成同一件事（观看研究校准）](gaze-is-not-comprehension.md) - 特定电影片段实验中前文语境显著影响理解与预测，而不同组眼动仍高度同步——本包效果推断分层的主要实证校准。
* [意义引导注意（meaning maps）](meaning-guided-attention.md) - 自然场景中语义相关性对眼动分布有重要解释作用，提示构图分析同时考虑图像特征与对象意义。

# 协作与设计过程（02／05）
* [分布式认知：不要只在某一个人的脑中寻找完整方案](distributed-cognition.md) - 认知活动分布在社会、文化与物质环境中；摄影方案分布在导演描述、分镜、平面图、测试片、镜头记录等载体中。
* [共享原型与并行原型](shared-and-parallel-prototyping.md) - 在网络广告设计实验中，共享多个设计、并行探索多个原型显示出探索、协作与结果上的优势；本包据此主张用具体候选让分歧显形。
* [需求追溯与验证／确认（V&V）](requirements-traceability-and-v-and-v.md) - 目标、约束、需求与方案可迭代追溯；验证检查是否满足规定，确认检查是否适合预期用途——本包称为规格验证与用途确认。
* [问题—方案共同演化](problem-solution-co-evolution.md) - 设计中问题理解与方案探索共同演化；摄影测试不只验证答案，也可能帮助重新认识问题。
* [设计固着：参考可能帮助，也可能限制探索](design-fixation.md) - 范例可能使后续设计受其特征限制；本包据此建议标注“借用的关系”与“不继承的特征”并补一个异形对照。

# 推断、评价与迁移（04／06／07）
* [逆向成像的多解性：同一外观可有多个实现](inverse-rendering-ambiguity.md) - 单图恢复形状、照明和反射是多解问题；据此不在缺少记录时为最终效果指定唯一器材、操作或动机。
* [审美欣赏与审美判断模型](aesthetic-appreciation-model.md) - 审美加工分多个阶段，审美情感与审美判断是不同输出；评价不必最终归为“喜欢／不喜欢”。
* [结构映射理论：类比重视关系系统](structure-mapping.md) - 类比区分对象属性与关系，优先保留关系结构及其系统性；本包据此主张迁移关系而非表面。
* [案例推理（CBR）：检索之后还必须修正与保留](case-based-reasoning.md) - 案例推理以检索、复用、修正、保留四阶段组织循环；案例包含情境与经验，不只是一组标签。
* [来源模型 PROV：让观察、推导和修订保持可追溯](provenance-model.md) - PROV-DM 以实体、活动、使用、生成、推导、修订描述来源；可追溯不等于已经真实。
