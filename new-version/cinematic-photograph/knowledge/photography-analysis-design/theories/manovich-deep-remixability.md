# 原意

《Understanding Hybrid Media》提出“深度可混合性”：被组合的不只是不同媒介的内容，还包括它们的技法、工作方法和表现方式；不同来源可以显露为拼贴，也可以融合得不再显露拼接边界 [1]。

# 本包的工作化用法

面对混合风格，不只写“电影感＋平面设计＋梦幻”，而追问：

- 摄影借用了什么图形组织？
- 图形元素是否按照摄影空间运动？
- 某种光学质地是否被用于非摄影对象？
- 不同形式在何处结合、按什么条件切换？

落地为 [混合风格的组合语法](/style/hybrid-style-grammar.md)（四种记录方式是本包的应用建议，非原文分类）。
