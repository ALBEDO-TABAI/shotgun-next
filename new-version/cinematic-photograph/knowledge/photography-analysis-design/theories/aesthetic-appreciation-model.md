# 原意

Leder 等人 2004 年模型区分审美加工的多个阶段，并把**审美情感**与**审美判断**视为不同输出 [1]。

# 本包的工作化用法

- 一个人可以被作品打动，却认为某技术选择不适合任务；也可以认可形式组织，却没有强烈情感。
- 评价不应要求所有回答最终归为“喜欢／不喜欢”。
- 用于：[四种“好”](/evaluation/four-kinds-of-good.md) 中的“审美判断”一项，以及 [六类问题分类](/evaluation/six-problem-categories.md) 中把个人偏好单列。

# 边界

只核读出版摘要；不把该模型当成已穷尽审美的定律，也不是审美价值统一量尺。
