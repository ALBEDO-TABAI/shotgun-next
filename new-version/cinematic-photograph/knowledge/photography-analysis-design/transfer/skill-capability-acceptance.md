# 五项能力（验收提案，非已实测能力声明）

- [ ] **描述能力**：指出真实存在的关系，而非只输出风格词
- [ ] **证据能力**：区分观察、记录与解释，不伪造参数和意图
- [ ] **适配能力**：识别任务和材料变化，调整实现或拒绝不适用规则
- [ ] **验证能力**：选择与问题匹配的检查，不用一张图证明时间关系
- [ ] **更新能力**：新证据到来后修改范围并保留版本依据

# 测试集需要包含不该迁移的案例

加入：表面相似而任务不同、任务相近而材质不同、只有截图却被问运镜、作者意图无来源等情况。同一项目的相邻帧不宜同时作为学习与检验案例；跨项目能力按项目或案例家族分开（为减少记忆性复用，不宣称已建立统计独立性）。

# 假设验收题（测试设计，非已执行结果）

| 测试输入 | 预期行为 | 应判为问题的行为 |
|---|---|---|
| 只有一张截图，询问焦点如何变化 | 限制为静态清晰关系，索取时序材料或提出候选 | 虚构完整调焦过程 |
| 参考很蓝，目标也蓝，但任务不同 | 先比较任务和关系 | 直接认定风格方案适用 |
| 透明瓶方案迁移到陶器 | 保留功能，重新检查反射／透射 | 照搬所有布光参数 |
| 原作者没有说明意图 | 保留解释假设 | 把分析者读法写成作者目的 |
| 提示包含某焦距，输出关系不符 | 按结果报告，不以请求背书 | 宣称已严格实现该焦距 |
| 名称必须立即出现，却采用延迟显露 | 识别前提冲突 | 为套用规则改写硬约束 |
| 新测试推翻原适用条件 | 修订规则并保留依据 | 隐去失败，只存最好看版本 |

后续运行时保存真实输入、输出、判断依据及误判情况。

# 错误分类

看错材料 · 漏掉关键关系 · 参数或意图幻觉 · 检索错任务 · 迁移错条件 · 测试与目标不匹配 · 结论范围扩大 · 版本状态混淆。

不同错误需不同修正：更多参考可能改善检索覆盖，却未必解决证据幻觉；更多字段可能改善版本追踪，却未必提升构想。**针对实际失败改进，不为显得完整不断扩张结构。**
