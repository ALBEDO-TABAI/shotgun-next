> 本包提出的规则卡，**不是外部标准**；按问题删减，避免每条小知识背负大量空字段。

# 模板

```text
规则名称／编号／版本：
状态：候选、已在所列案例中观察、已在所列条件下测试、已修订或停用。
适用任务：
输入条件与必要材料：
关键对象及其角色：
需要保留的关系：
变化触发条件：
允许变化的部分：
实现候选与限制：
不适用或需重新测试的条件：
原始案例与证据位置：
属于观察、记录还是解释的内容：
已知反例或失败：
检查方法：
本次采用后的实际结果：
```

# 用关系句命名，比用风格词更容易检查

| 风格词命名 | 关系句命名 |
|---|---|
| 梦幻护肤风 | 接触先于身份显露 |
| 高级产品光 | 通过环境反射描述曲率 |
| 文艺长镜头 | 事件结束后保留空场 |

风格词可作为检索别名，但不应成为唯一主键。

# 状态必须带范围

- “已测试”写明在哪个对象、画幅、观看条件和任务里测试；不永久升级为通用真理。
- “已观察”≠“已验证有效”：成片中反复出现只能说明模式存在，对特定任务的作用可能仍是假设。

# 容许变化不是越多越好

如果任务、对象、关系、时序、结果都可变，规则已无法指导判断。指出真正不能丢的结构，同时不锁死无关实现。例：“先接触后识别”的不变量是信息先后及其连贯性；背景颜色、具体焦距可变；若新任务要求第一瞬间明确品牌，则这一顺序可能不适用——**不靠修改措辞继续套用**。
