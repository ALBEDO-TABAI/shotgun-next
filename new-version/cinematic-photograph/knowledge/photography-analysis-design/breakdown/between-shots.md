# 原则

- 前一镜头已交代的空间，下一镜头可以减少说明；顺序被改动，同一近景可能突然缺少对象关系。
- 时序分析分两部分：
  - **镜头内部变化**：运动、焦点与显露（见 [运镜四状态](/breakdown/camera-movement-four-states.md)）；
  - **镜头之间分配**：尺度变化、视点接续、重复与例外。
- 不能把所有镜头间效果归为摄影，也不能把摄影贡献仅限于单帧。

# 观看顺序

1. 先保留正常声音和播放速度完整观看；
2. 再进行静音、暂停或逐帧诊断——静音能聚焦某些视觉关系，但**不自动隔离出真实的摄影因果效应**；
3. 最终解释回到完整作品：视觉提示的关系是否被声音、表演或前后文支持、改变甚至反转。

依据：在特定电影片段研究中，理解条件差异与较强眼动同步可以并存——观看轨迹相近 ≠ 叙事理解相同（见 [看见同一处≠理解相同](/theories/gaze-is-not-comprehension.md)）[1]。
