# 03 摄影拆解：空间、光影、清晰度与时间

把构图、景深、光影、快门翻译成观看关系。更细的构图／运镜／镜头衔接技法卡见姊妹包 composition-movement-transition。

# 总框架
* [摄影拆解的四个层次与正／反向证据链](four-layers-and-evidence-chains.md) - 图像事实、候选机制、观看作用、项目解释四层分开书写；用正向成像链理解技术，用反向证据链分析作品。

# 空间与构图
* [机位、焦距、画幅与裁切：先找观察点，再猜镜头](viewpoint-focal-length-format-perspective.md) - 透视由观察位置决定而非焦段滤镜；焦距须与有效画幅、裁切、距离一起讨论；机位分析至少描述三种关系。
* [构图即信息关系：比较、分组、排除与等待](composition-as-information-relations.md) - 用“什么一起看、什么分开看、什么被排除、什么需要等待”替代三分法检查，并给出可执行的构图检查法与诊断视图边界。

# 清晰度、光与色
* [景深、焦点、锐度与柔化：把“清楚”拆开](clarity-focus-depth-of-field.md) - 对焦位置、景深、背景模糊、锐度是四种不同的清晰问题；景深必须附带条件；焦点应写成信息开放顺序。
* [光影四维度与光源动机](light-four-dimensions-and-motivation.md) - 方向、软硬、明暗反差、整体调子四个维度不能压成“光好不好”；画面光源动机与现场实现是两件事。
* [材质外观与反射：不是打光强度的单变量](material-appearance-and-reflection.md) - 表面外观由入射方向、出射方向与表面散射特性共同决定；控光包括移除反射、安排暗面与遮挡；案例提供路径而非配方。
* [曝光、ISO 与高光：亮度、获得的光和显示不是一回事](exposure-iso-and-highlights.md) - 曝光关系须写出前提；ISO 增益不增加已收集的光；高光观感受场景、记录、输出共同影响，不能作为单一器材指纹。
* [色彩与质地：分清对象、照明、处理和输出](color-and-texture.md) - 颜色不是物体上固定的屏幕数值；创意外观与技术转换位置不同；质地用可见特征描述、暂不确定来源。

# 时间与运动
* [快门、帧率与播放：“取样”与“每次取样的积累”](shutter-frame-rate-playback.md) - 快门角度决定每帧曝光时间，帧率与播放决定时间伸缩；慢动作≠慢快门；闪光可能才是冻结运动的真正限定者。
* [运镜：记录信息状态，而不只记录轨迹名称](camera-movement-four-states.md) - 区分移位、转向、变焦与后期重构；每次运动写进入、触发、变化过程、停留／退出四个状态；相机相对事件的时机常比运动复杂度更值得分析。
* [镜头之间：摄影规则在剪辑和声音中重新获得作用](between-shots.md) - 单镜头需与相邻镜头一起检查；区分镜头内部变化与镜头之间分配；静音、暂停只是诊断，最终解释要回到完整作品。

# 检查
* [摄影拆解常见混淆与降级检查](common-confusions-checklist.md) - 焦距≠透视、景深≠柔化、柔光≠低反差、慢动作≠长曝光等必须区分的概念对，以及材料受限时的降级规则。
