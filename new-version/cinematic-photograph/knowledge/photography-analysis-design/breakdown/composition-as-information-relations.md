# 四个问题（替代“三分法是否正确”）

1. 什么可以一起看？
2. 什么必须分开看？
3. 什么被边界排除？
4. 什么需要等待才出现？

先描述整体分区 → 再描述对象之间的联系 → 最后检查边界。人物居中不代表人物是唯一阅读对象；一只横跨画面的手可能把视线和动作联系到边缘物品。

**注意分配不简化为“人先看最亮处”**：[意义引导注意](/theories/meaning-guided-attention.md) 的研究显示语义相关性对眼动分布有重要解释作用 [1]；但不能据此否定低层特征作用，或宣布任意画面的固定观看路径。

# 可执行的构图检查法

| 步骤 | 列出 | 例子 |
|---|---|---|
| 1 需要被联系的对象 | 以及联系靠什么建立（接近、方向、重叠、相似轮廓、清晰度变化、动作接续） | 使用者与工具、手指与接触点、人物与门外空间、名称与瓶体 |
| 2 竞争对象 | 它们当前是否承担必要任务（不是宣布天然有害） | 背景亮斑、额外人脸、字幕、运动物、局部高反差 |
| 3 边界承诺 | 画框外是否保留事件来源；切掉的部分是否使动作难辨；留白是否真被排版使用 | 只在原图成立、裁切后失效的关系，不宜作为跨画幅通用规则 |

# Examples

> 当前构图把手与产品组织为一组，但标签与高光相交，名称阅读被打断。若本图优先承担识别任务，应首先分离字形与反射，而不是仅调整产品的几何位置。

这比“视觉中心不突出”更接近可修改的问题。

# 诊断视图不是裁判

- 缩小、转灰可检查某些结构，但删除了颜色、细节或观看条件——是**诊断视图**，不是作品本身。
- 局部放大适合检查边缘、字形、伪影，但不代表正常观看时观众一定注意到。
- 报告要说明结论来自哪种视图；静态显著性模型的预测不能写成真实人群的观看行为。代理证据的评价方法见 [指标与测量层级](/evaluation/metrics-and-levels.md)。
