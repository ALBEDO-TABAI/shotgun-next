# 为什么要拆层

最常见的跳跃：看见背景模糊 → 判断用了大光圈 → 判断创作者希望浪漫 → 认定观众一定感到浪漫。这四步分属不同问题。

# 四个层次

| 层 | 问题 | 注意 |
|---|---|---|
| 1 图像事实 | 哪些区域清楚、物体如何排列、亮部在哪、动作怎样变化 | 限于当前材料 |
| 2 候选机制 | 哪些拍摄、场景、处理或合成方式能产生这种外观 | 必须附带成立条件，未必只有一种 |
| 3 观看作用 | 这种安排可能帮助什么被读取、推迟什么发现、建立什么关系 | 是解释，不是效果保证 |
| 4 项目解释 | 是否适合叙事、品牌、纪实或实验任务；实际观众怎样回应 | 需任务与观众证据 |

书写格式：**“可见证据—候选机制—可能作用—任务条件”**，不省略中间步骤。裁切过的截图尤其不宜承担完整技术复原或观众效果判断。

# 正向成像链（教学简化）

```text
对象、表面与照明
    → 观察位置、投影与取景
    → 对焦、孔径与曝光时间
    → 记录、处理、合成与输出
    → 在特定条件下观看
```

物理成像可参考投影、反射与有限孔径模型；颜色呈现还涉及输出目标 [1][2][3]。这不是所有成像系统的完整数学模型。

# 反向证据链

分析成片是沿这条链**反向**提出假设；越往上追溯，越需要额外资料。因此“画面里有什么”与“现场一定用了什么”应保存在不同字段。计算机生成画面也可接受观看关系分析，但不能默认存在一套真实镜头与灯具。

同一外观可有多个实现，见 [逆向成像多解性](/theories/inverse-rendering-ambiguity.md)。
