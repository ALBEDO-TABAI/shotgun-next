# 透视不是一种焦段滤镜

理想针孔透视模型：

```text
x = f·X / Z ,   y = f·Y / Z
```

- 场景坐标相对相机观察中心定义；`f` 为投影尺度，`Z` 为深度；**忽略现实镜头畸变**。[1][2]
- 固定观察位置时，改变焦距主要改变**投影比例与取景**；改变观察位置，才改变对象间的**深度比例与遮挡关系**。

# Examples（数学演示，非实测）

两个同高物体距相机 1 m 与 3 m：像高比 3 : 1。相机沿同一直线后退 3 m → 距离 4 m 与 6 m，比值变为 1.5。为保持前者画面大小换更长焦距，**不会撤销**这个距离比例变化。

→ “长焦压缩”需连同拍摄距离理解；但也不要说焦距没有作用——它改变取景条件，进而影响实际选择的距离、背景范围与可用位置。

# 画幅、裁切与焦距不能混写

理想直线投影、近似无限远对焦时的水平视角：

```text
α = 2·arctan( w / (2f) )      w：有效成像宽度
```

- 同一焦距配合不同有效画幅，取景范围不同；**不是**近摄、非直线投影或复杂镜头的精确校准公式。[1][2]
- 只知道“50mm”还不知道观看关系。只有成片时，更适合写“较近的观察距离与明显的前后大小差异”，而不是断言镜头型号。
- 区分：**透视比例**（鼻部相对耳部显大——先查距离）、**镜头畸变**（直线弯曲）、**倾斜观察**、**后期形变**。可以并存，但不是同义词。

# 机位分析至少描述三种关系

| 关系 | 描述什么 |
|---|---|
| 相机与主体 | 距离是否接近可互动位置；视点在上方、下方还是同高；是否被前景遮蔽 |
| 主体与环境 | 前后物体的大小、遮挡与层次；哪些环境信息被纳入或切掉 |
| 相机与事件 | 提前等待、跟随反应，还是落后于事件（需动态或系列材料） |

“低机位使人有权威”只是待检验解释；低机位也可能为交代上方空间、避开背景、贴近地面物件，或与前一镜头形成关系。见 [不建立固定的“技术—情绪”词典](/principles/no-fixed-emotion-dictionary.md)。
