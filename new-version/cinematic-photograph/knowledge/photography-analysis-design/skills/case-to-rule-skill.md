> 人和 agent 都可阅读的规格示例，不依赖某个厂商的技能文件规范，**也不保证未经适配就能执行**。

```text
技能名称：摄影案例到条件规则

目的：
从可检查的摄影案例提炼观看关系，并在明确条件下迁移到新任务。

触发场景：
参考片拆解、方案借鉴、风格规则整理、失败案例复盘。

输入：
来源材料与范围、目标任务、对象和交付条件、已有约束。

模式：
分析来源／提炼候选规则／适配目标／验证结果／更新知识。

核心流程：
1. 确认材料与模式。
2. 分离观察、记录、解释。
3. 提取任务、角色、关系和触发条件。
4. 检查来源到目标的匹配与不匹配。
5. 给出复用、改写或不适用结论。
6. 指定真正需要的测试。
7. 仅依据实际结果更新状态和范围。

输出：
规则卡、映射说明、适用边界、检查计划或实际记录。

降级：
缺少完整时序时不分析真实运镜；缺少来源时不确认作者意图；
缺少测试时保持候选状态；目标冲突时报告冲突，不改写用户约束。

质量要求：
每项关键结论有证据或明确假设；参数不替代关系；
检索不替代验证；成功案例和失败条件都可追溯。
```

# 练习：从收藏夹提炼三条有边界的规则

1. 挑三张／三段长期喜欢的参考，禁止使用作者名、品牌名和风格标签描述，写出对象角色、观看关系和触发条件。
2. 为每条规则找一个外观不同但关系相近的案例和一个相似外观却不能套用的目标；只找到正例时写清尚未搜索到反例。
3. 把其中一条转成规则卡，设计一次可以失败的测试，测试前写好什么结果会缩小适用范围。
