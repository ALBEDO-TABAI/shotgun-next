# Skill 规范

各模块“可直接拆成 skill”的执行规范（输入／流程／输出／质量／降级／练习），以及模块接口。均为规范草案，不是已安装或已测试的实现。

# 接口
* [七个模块的功能接口与阅读路径](module-interfaces.md) - 01–07 模块之间的功能接口，以及分析已有作品、构想新项目、整理 agent skill 三条使用路径；接口不要求七个独立 agent。

# 各模块 Skill
* [风格分析 Skill 规范（01）](style-analysis-skill.md) - 摄影风格的描述、归纳与归属判断：输入、七步流程、交付物、质量要求与降级。
* [摄影工作分析 Skill 规范（02）](photography-work-skill.md) - 职责分析、方案分解与交接检查：输入、步骤、输出模板、质量检查与练习。
* [摄影拆解 Skill 规范（03）：观测优先，机制有条件，解释有边界](breakdown-skill.md) - 外观分析／机制核对／方案讨论三种模式，执行顺序、标准输出片段、质量检查与降级，附练习。
* [出发点推断 Skill 规范（04）：从问题到可复核结论](inference-skill.md) - 把“为什么”分类、建立低推断观察与证据、提出有区分性的候选、以结论状态输出并说明更新条件。
* [正向构想 Skill 规范（05）](ideation-skill.md) - 从分类 brief、摄影命题、实质不同的候选到条件规则、镜头状态与按风险排序的测试；测试计划不写成测试结论。
* [摄影评价 Skill 规范（06）：评价必须能被复核和采取行动](evaluation-skill.md) - 声明范围、分离硬条件与软目标、按问题观察、分类反馈、提出最小修改与保护项，只对已检查范围给出状态。
* [案例到条件规则 Skill 规范（07）](case-to-rule-skill.md) - 从可检查的摄影案例提炼观看关系，并在明确条件下迁移到新任务；含模式、七步流程、输出、降级与质量要求。
