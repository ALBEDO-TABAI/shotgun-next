# 原则

1. **先查保护什么**：一人要求处处清晰，另一人要求极浅景深——可能前者保护标签，后者保护背景简洁。
2. **找结构解法**：两者未必真正冲突，可以改变物体平面关系、背景距离，或在不同镜头分配任务。
3. **确实不可兼得才显式取舍**：记录牺牲项与接受理由，而不是把不清不楚的折中叫“平衡”。
