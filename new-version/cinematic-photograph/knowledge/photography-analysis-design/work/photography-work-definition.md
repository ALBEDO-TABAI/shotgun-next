# 核心命题

> 摄影工作是在条件约束下，使一种观看方式成立并延续。

把摄影理解成“相机、镜头、灯光和参数”只看见执行端。更完整的分析对象是：一个表达要求怎样变成可讨论的视觉问题 → 怎样被分解成相互配合的选择 → 怎样在现场实现 → 怎样在剪辑、调色、合成与最终观看中保持关键关系。

# 工作定义

> **摄影工作**是对观看位置、空间信息、可见性、时间和成像呈现进行设计、协商、实现与检查的活动。它既生产图像，也生产让图像可以被正确理解、接续和完成的决策依据。

- 这是一种**功能范围**，不是扩大某个部门的独占权：一人可兼任导演、摄影、剪辑；大项目可由不同团队分担。**功能有没有被完成，与项目是否设了某个职位，不是一回事。**
- 外部参照：英国 National Careers Service 的摄影指导职业说明包含与导演讨论拍摄方式、勘景和机位规划、器材测试、组织摄影组、与灯光协作、审看素材以及后期支持 [1]——说明摄影指导不能简化为开机或调曝光；但职业概览不能裁定所有国家、工种体系与项目的权限。
