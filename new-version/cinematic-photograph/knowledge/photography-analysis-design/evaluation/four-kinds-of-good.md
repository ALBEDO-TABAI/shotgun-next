# 核心命题

> 从“我喜不喜欢”，转向“它解决了什么，付出了什么”。
>
> **先声明评价对象、条件和标准，再用相匹配的证据提出判断；把不兼容的目标显式讨论，而不是压成一个总分。**

# 四种“好”

| 种类 | 问题 | 理论依据 |
|---|---|---|
| **实现可靠** | 素材与约定规格、对象关系和处理要求是否相符 | 规格验证（verification）[1] |
| **形式有效** | 摄影选择是否构成可理解的组织，关键变化是否有作用 | 01 模块风格分析 |
| **任务适合** | 在实际使用条件下是否保护了重要目标，代价可否接受 | 用途确认（validation）[1] |
| **审美判断** | 评价者怎样理解、感受和评价，基于什么经验与价值 | 审美情感 ≠ 审美判断 [2] |

- 一个可测量的锐度指标不是作品价值；一个有力的艺术解释也不能证明标签没有出错。
- “按约定导出、名称内容准确、镜头存在所需动作”属于规格验证；“观众在实际观看条件下能理解该动作”属于用途确认——不能用一个“已通过”省略差异（见 [需求追溯与验证／确认](/theories/requirements-traceability-and-v-and-v.md)）。
- 一个人可以被作品打动却认为某技术选择不适合任务；也可以认可形式组织却没有强烈情感（见 [审美欣赏与判断模型](/theories/aesthetic-appreciation-model.md)）。
