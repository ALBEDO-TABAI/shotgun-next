# 摄影分析与设计知识包 · Overview

母题：**摄影风格、摄影工作、技术拆解、出发点推断、正向构想、评价与规则迁移**——原摄影理论体系第 01–07 点。核心命题：风格不是滤镜，而是有组织、有条件的选择；摄影分析要从“用了什么”走到“改变了什么观看关系”，并让每个结论停留在证据能支持的层级。

表达技法层（构图 C01–C16、运镜 M01–M17、镜头衔接 E01–E20）由姊妹包 `composition-movement-transition` 覆盖，本包不重复。

# 三条阅读路径
* **分析已有作品**：[01 风格](style/) → [03 拆解](breakdown/) → [04 推断](inference/) → [06 评价](evaluation/)；需理解制作协作时加入 [02 工作](work/)；最后用 [07 迁移](transfer/) 保存可迁移规则。
* **构想新项目**：[05 构想](ideation/) → [03 拆解](breakdown/) 检查机制与条件 → [02 工作](work/) 明确协作与交接 → [06 评价](evaluation/) 设计检查 → [07 迁移](transfer/) 记录实际经验。
* **整理 agent skill**：从 [Skill 规范](skills/) 与 [模块接口](skills/module-interfaces.md) 开始，按需回查各模块概念；遵守 [最小输出原则](principles/minimum-output-principle.md)。

# 七个模块
* [01 风格](style/) - 风格工作定义、概念分层、五种分析对象、八维剖面、混合风格、命名证据强度、七步流程与交付物
* [02 摄影工作](work/) - 摄影工作定义、六种须分开的东西、六类工作、阶段检查、协作边界、交接、贡献归属
* [03 摄影拆解](breakdown/) - 四个层次与证据链，透视、构图、景深、光影、材质、曝光、色彩、快门、运镜与镜头之间
* [04 出发点推断](inference/) - 六类“为什么”、因果草图、证据账本、竞争假设、四种结论状态、重建测试、作者与影响
* [05 正向构想](ideation/) - brief 拆分、感受词展开、摄影命题、并行候选、五层规则、镜头状态、测试阶梯、风险排序、反馈路由
* [06 评价](evaluation/) - 四种“好”、评价范围、六维度、六类问题、指标层级、三轮评审、A/B 纪律、硬条件决策、反馈卡
* [07 规则迁移](transfer/) - 可迁移知识定义、迁移什么、规则卡、关系映射、按任务检索、CBR 循环、知识库三层、AI 工作流、skill 验收
