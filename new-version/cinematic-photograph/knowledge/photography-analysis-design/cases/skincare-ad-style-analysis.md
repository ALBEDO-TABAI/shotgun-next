> **事实状态：假设案例**，完全为方法演示而设。

# 设定

十二镜头：八个集中于指尖、皮肤和液体接触；三个提供环境与过渡；最后一个稳定、正面地展示完整包装。使用段落环境细节少、接触位置清楚；包装在使用段落中经常不完整，只有结尾获得完整阅读机会。

# 分析演进

| 环节 | 内容 |
|---|---|
| 不充分的分析 | “低饱和、浅景深、慢动作，梦幻、高级、有电影感。”——即使部分正确，也解释不了为什么结尾突然完整、稳定 |
| 形式剖面 | 接近身体的观看位置；局部化画框；信息逐步开放；结尾转向正面、完整和稳定（[八维剖面](/style/eight-dimension-style-profile.md)） |
| 候选主导规则 | **在使用发生时优先开放与接触有关的信息；在识别任务开始时解除局部化限制，让完整包装获得稳定阅读机会。** 两套形式按“接触经验”和“产品识别”分工，不是平均混合（[混合风格组合语法](/style/hybrid-style-grammar.md) 的跨段落切换） |
| 可能功能 | “先接近使用经验，再完成对象识别”；是否让观众舒适或更愿意购买需另行验证 |
| 替代解释 | 局部画框也可能与素材限制、场景条件或构图适配有关；无制作资料不能写成已确认计划 |
| 比较性描述 | “以接触导向的局部观看为主，在结尾切换到图形化产品呈示的摄影组织。”（第 2 级命名，见 [命名的证据强度](/style/naming-evidence-strength.md)） |
| 反事实 | 保持色调但把接触改为远距离旁观，可能保留外观而改变观看关系；保持距离与显露顺序但调整调色，可能保留部分结构，但不能宣称风格完全不变 |
| 可迁移规则 | 接触段落优先保持动作关系可感；识别段落优先保证必要信息可读。不机械迁移品牌、蓝色或假设焦段 |
| 单张平面的对应 | 只能说“这张图以局部、清晰度差异与边界安排突出接触部位”，不能由一张证明整组“先感受、后识别”的时间规则 |

# 教训

- **一个例外镜头可以属于整体风格的规则**，而不只是破坏统一（[五种分析对象](/style/five-analysis-objects.md) 的“发展与例外”）。
