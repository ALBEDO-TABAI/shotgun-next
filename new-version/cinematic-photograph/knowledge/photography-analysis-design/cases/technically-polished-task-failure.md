> **事实状态：假设案例**。

# 情况

某使用说明短片：微距画面清晰、反射整洁、运动顺滑；但观众无法从镜头中判断产品接触的是哪个位置，动作前后关系也被裁掉。

# 评价

- 技术适足性中部分项目可以成立；**信息与时间组织**需要检查（[六个评价维度](/evaluation/six-evaluation-dimensions.md)）。
- 问题类型：**任务失效**，不是技术错误（[六类问题分类](/evaluation/six-problem-categories.md)）。
- 正确反馈不是全面否定摄影，而是指出当前局部化策略不适合这段说明任务，提出补充空间关系或重新安排尺度的候选。

# 任务改变，评价改变

若改成纯材质情绪短片，同样的局部化可能被重新评价——这不是双重标准，而是任务发生了变化。
