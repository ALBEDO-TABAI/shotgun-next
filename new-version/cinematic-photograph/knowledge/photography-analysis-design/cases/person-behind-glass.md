> **事实状态：假设案例**。

# 1. 先写可见事实

当前版本中：四个镜头出现人物与反射重叠；两次人物离开后画面保留反射；最后一个镜头没有明显玻璃遮隔。不能把“隔着玻璃”马上写成“内心封闭”——还要看行为、空间、声音，以及无遮挡镜头发生了什么。

# 2. 竞争解释

| 假设 | 内容 |
|---|---|
| H1 | 玻璃主要建立人物与观看者之间的分隔 |
| H2 | 反射主要把人物与外部环境放在同一画面，形成信息叠置 |
| H3 | 场景限制促成该拍法，后期选择进一步强化反射 |
| H4 | 作品主要关注透明与反光的形式变化，而非人物心理 |

可部分共存，但对关键镜头的解释重点不同。

# 3. 区分性问题

- 人物离开后反射仍被保留 → 可能使 H2 或 H4 更有解释力（还要看停留长度及前后关系）。
- 最后无遮挡镜头若对应人物关系改变 → 可支持 H1 的结构性读法；若只是换场景则不够。
- H3 需要提案、勘景、访谈；没有时仍是**未确认的制作原因**，不能通过成片选出唯一答案。

# 4. 合理报告

> 当前版本反复让人物与玻璃反射重叠，并在两处保留人物离开后的反射画面。相比单纯的“人物被遮挡”，作品还持续强调了反射本身。可以提出分隔、环境叠置和形式探索等读法；现有材料不足以确认作者的唯一意图，也不足以复原反射是否经过后期强化。

不是含糊地说“都有可能”，而是把观察、较有解释力的方向和缺失证据分别说清。
