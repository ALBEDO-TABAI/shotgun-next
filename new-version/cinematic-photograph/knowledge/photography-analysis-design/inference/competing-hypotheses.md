# 1. 提出真正不同的候选

例：人物经常在画面边缘。候选：给排版留位置／维持人物与另一对象的空间关系／形成持续偏置的形式／拍摄地点限制。

- 候选不一定互斥；先判断它们是否**预测不同结果**。若为文案留白，查不同排版版本是否保持该区域；若为人物关系，查无文案时及不同人物互动中是否仍如此。
- “作者喜欢这样”可能为真，但过于宽泛，几乎不能区分机制——继续具体化：这种偏好在什么任务下出现、什么情况下不出现。

# 2. 支持性证据 ≠ 区分性证据

暗背景同时符合“突出人物”“隐藏场景限制”“维持整体暗调”——发现暗背景并不能在它们之间选择。更有区分力的是：前期提案明确目标；场景照片显示背景受限；不同段落持续使用同样的亮暗规则；测试记录显示试过另一方案并写明舍弃原因。

为每个候选写三列：

| 已支持什么 | 什么仍不确定 | 出现什么新证据会改变判断 |
|---|---|---|

这样不必用主观的“80% 可能”制造精确感。

# 3. 用反例检验规则

假设“所有冲突段落都缩短观看距离”，就检查**没有靠近的冲突段落**和**没有冲突却靠近的段落**。它们可能使规则缩小范围，或揭示更好的解释（“只在人物作决定时靠近”）。

**不要为保存最初结论给每个反例发明新理由**。需要无限例外才成立的规则，不适合迁移为 skill。

# 4. 数量与解释力分开

- 出现很多次能支持频率描述；能否解释关键转折是另一个问题。只出现一次的静止镜头也可能承担重要变化。
- 样本必须有分母：这八张样片里，还是完整影片里？精选作品集得到的倾向不能未经检查推广为创作者全部方法。
