# 原则

- 一个字段若没有任何执行或检查环节使用，就不应因看起来专业而设为必填。
- 镜头表、色彩说明、修改意见可以共用同一项决策引用，不必各自复制一份不同措辞的“真相”。
- **单一当前版本 ≠ 删除历史**：历史用于理解变更与追溯，当前版本用于执行，二者用途分开。
- 知识库中：焦距未知但对迁移不关键，记录未知即可，不为字段完整进行无意义猜测；相反，任务前提、对象版本和实际测试范围往往影响使用，不能省略。**轻量不是少记关键关系，而是避免无用途的重复记录。**
