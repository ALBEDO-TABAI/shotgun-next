# 各类证据回答什么

| 证据类型 | 回答什么 | 不能回答什么 |
|---|---|---|
| 光学／成像模型、技术章节 | 成像关系、定义、接口 | 审美；所有现实实现都一致 |
| 观看实验 | 受限任务中的观众行为 | 直接推广到所有创作 |
| 实践／制作案例、职业说明 | 一种实际制作路径、被记录的工作 | 所有地区、团队或对象的统一规则 |
| 规范文档（ITU、NIST、W3C） | 定义、接口或评测条件 | 艺术价值或商业效果 |
| 理论模型 | 组织和解释问题的视角 | 与实验相同强度的实证支持 |
| 机构／出版摘要 | 摘要可见的内容 | 未读的方法细节和全部限制 |

# 特别区分

- 物理可实现 ≠ 艺术有效；
- 作者希望如此 ≠ 观众实际如此；
- 图像被注意 ≠ 被理解（见 [看见同一处≠理解相同](/theories/gaze-is-not-comprehension.md)）；
- 检索到参考 ≠ 迁移已成功（见 [按任务检索](/transfer/task-based-retrieval.md)）。

技术厂商案例主要证明实现路径；其艺术形容词不作为普遍心理学结论。
