# 政策

- 正文引用编号（`[R01]`、`[S1]` 等）支持的是其**旁边的具体理论、方法或事实**，不自动证明整套摄影流程已获科学验证。
- 流程、表格、规则卡、测试安排和跨领域迁移，均注明为**本包提案或工作化综合**。
- 没有通过给自己的框架附一篇论文，就把它宣称为学界标准。
