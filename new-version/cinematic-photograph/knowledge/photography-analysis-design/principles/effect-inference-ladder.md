# 阶梯

```text
形式上突出 → 可能被注意 → 被怎样理解 → 产生何种情绪 → 带来何种行为
```

| 层级 | 可用证据 | 常见越级 |
|---|---|---|
| 形式上突出 | 作品本身（亮、清晰、占比、位置） | — |
| 可能被注意 | 眼动、注意研究、显著性／意义图（有条件） | “热区=理解” |
| 被怎样理解 | 复述、访谈、理解任务 | “看了=认同” |
| 产生何种情绪 | 自述、情感测量（区分情感与判断） | “我感到=观众都感到” |
| 带来何种行为 | 行为数据、转化实验 | “喜欢画面=会购买” |

# 实证校准

特定电影片段实验中，语境显著改变理解与预测，而眼动仍高度同步——**看见同一处 ≠ 理解相同**（[看见同一处≠理解相同](/theories/gaze-is-not-comprehension.md)）。
