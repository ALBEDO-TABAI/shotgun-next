# 四个评价问题

| 问题 | 检查什么 |
|---|---|
| **描述是否可靠** | 结论能否指回作品证据，是否超出材料范围？ |
| **规则是否解释得通** | 能否解释主要关系与有意义的变化，而不是只匹配几个词？ |
| **任务是否适配** | 当前形式优先了什么、牺牲了什么？用户是否接受该取舍？ |
| **历史／比较结论是否成立** | 参照作品是否匹配，是否有来源支持归属或影响？ |

不汇总成一个含糊的“风格分数”。

# 审查原则

- 有风格 ≠ 成功；
- 没有明显流派标签 ≠ 没有形式选择；
- 不同于参照 ≠ 更有创新；
- 统一 ≠ 所有镜头外观相同。

这些是本方法的审查原则，不是统一的审美裁决。允许出现的结论例如：

> “作品具有清楚的风格组织，但不适合当前的产品识别任务。”
> “作品没有明显的历史流派标签，但其观看规则清楚、稳定，并且适合当前目的。”
