# 核心命题

> 风格不只是“一组反复出现的选择”，而是这些选择之间的**关系**、出现的**条件**、变化的**规则**，以及它们相对于某种**语境**所形成的特征。

“风格不是滤镜，而是有组织、有条件的选择”是整个知识包（01–07 模块）的起点命题。

# 工作定义

> **摄影风格**，是在明确的作品范围与观看语境中，关于**视点、空间、可见性、时间与成像质地**的一组有组织的倾向。它体现在形式选择之间的关系、选择出现的条件、相对稳定的规则，以及具有结构作用的变化和偏离。

- 这是**工作化综合**，不是某位学者的原句，也不是唯一可接受的风格定义。
- 出发点来自 [Bordwell & Thompson](/theories/bordwell-thompson-film-history-method.md)：电影风格是**电影技法的模式化运用**，与作品整体形式、模式、类型相区分。电影技法包括场面调度、摄影、剪辑、声音，因此**“影片风格”不能直接等同于“摄影风格”**。[1]

# 四项修正

| 修正 | 说明 |
|---|---|
| 风格不是器材或效果清单 | “浅景深、低饱和、柔光、慢动作”只说明用了哪些处理，没说明它们如何组成整体。 |
| 风格不要求所有画面一样 | 稳定性可以在**变化规则**里：平静时远观、冲突时靠近、事件结束后恢复距离。 |
| 风格 ≠ 强烈的风格化 | 朴素、形式不显眼的作品也可以有稳定观看规则；“一眼认得出”不是必要条件。 |
| 滤镜并非不重要 | 色调、颗粒、柔化乃至某种算法都可能成为主导形式，但仍需说明它与画框、对象、时间、观看距离的关系。 |

# 边界

- “反复出现”不是充分条件：同一器材、地点或模板也可能产生重复外观；还要看与其他选择的关系、变化条件、归纳范围。
- **单张照片并非“没有风格”**：它可以支持画面形式配置的描述和与范例的比较，但不足以独自证明创作者跨项目的稳定习惯。
- 分析时须声明范围：单张／单镜头、组照／段落、完整项目、跨项目作者作品群、历史传统。
