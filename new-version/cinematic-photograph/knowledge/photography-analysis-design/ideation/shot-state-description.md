# 模板

```text
镜头任务：
进入时可见／不可见的信息：
关键对象与必须保持的关系：
触发变化的动作或事件：
变化期间相机、对象、焦点分别做什么：
结束时必须达到的信息状态：
剪辑可使用的进入／退出条件：
实现候选与尚未锁定参数：
必须测试的风险：
```

“尚未锁定参数”可以是合理状态——先确定距离关系再选镜头，比为了文档完整随便填一个焦距更好。

# 不把每个镜头都设计成小型高潮

为段落分配不同任务：建立空间、引发注意、展现动作、完成识别、保留余韵。并非所有镜头都需要明显运镜、焦点转移和材质奇观。（本包创作建议，不是叙事片固定结构；实验作品可以围绕重复和微差构造时间，关键是说明为何持续、什么在变。）

# 平面：时间分配 → 版本与关系分配

- 单张图可在一幅画面中组织主次、遮挡和比较；系列可以分工（完整对象／强调接触／展示环境）。
- 不要求每张图完成系列的全部任务，也不要把系列功能只写在总提案里导致每张图缺少清楚责任。
- 裁切和排版版本需独立检查，不是大图通过后自动通过。
