# 核心命题

> 不要从参数开始，从观众要获得的经验开始。

“清爽、自然、高级、有力量”可以开启讨论，但不能直接作为拍摄指令——同一个词会让参与者想象完全不同的距离、空间、光影和时间。

# 定义

> **摄影构想**：在目的、对象和资源条件下，提出一种观众与对象的关系，再将它展开为相互配合的视觉规则、实施候选和检查方法。

构想不必只为传递单一信息：非商业作品可以希望观众停留、比较、迟疑、感受材质或注意到观看本身。关键是清楚自己在探索什么、什么结果会让自己重新思考。

# 四种产物

| 产物 | 说明 | 不能替代什么 |
|---|---|---|
| **概念** | 为什么值得这样看 | — |
| **视觉规则** | 这种观看怎样组织 | 概念 |
| **制作方案** | 当前条件下怎样做出来 | 规则 |
| **测试证据** | 哪里已成立、哪里仍是假设 | 方案 |

- “用一个慢速推进”只是候选操作；“观众逐渐发现人与环境之间的矛盾”才描述它可能服务的观看任务——两者之间必须有具体信息变化，不能靠“推进具有情绪”连接。
- 一张漂亮测试图不能自动确认完整方案：可能证明局部反射可用，却未证明运动、前后文或最终裁切成立。
