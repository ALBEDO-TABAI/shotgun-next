# 按失败代价排序

方案可能有十个未知，但不是同样重要。问：哪一未知一旦失败会使整个构想或大量镜头重做？哪一未知可稍后低成本调整？

优先检查：
- 对象材料与预想外观是否相容；
- 动作是否可执行；
- 最终画幅是否保留关键关系；
- 镜头是否具有可用时间段。

不会改变这些关系的局部色彩微调可以后处理。（02 模块的同一原则：[前期让最贵的不确定性先暴露](/work/stage-by-stage-checks.md)。）

# 脆弱 ≠ 不可行

- 某反射只在很小角度范围内成立，不等于不可行，而是执行精度、重拍可能与沟通成本更高——可接受这种成本，也可寻找更稳健的替代（参见 [波动管理](/work/six-kinds-of-photography-work.md)）。
- 测试应寻找**可接受范围**，而不仅是一张最佳结果：手部动作、物体转动、不同裁切下关系是否仍成立。范围由实际测试得出，**不事先编造看似专业的容差数值**。

# 预留降级路径

关键风险配一个最小备用，例如：
- 运动镜头保不住标签 → 是否有稳定识别段；
- 日照不符合方案 → 是否允许改变该段光源逻辑；
- 生成结果持续破坏包装 → 是否改用已核实对象素材配合其他制作方式。

备用方案也要维护任务，不只是“先交一个画面”；无需为所有想象中的异常扩张复杂系统。
