# 测试阶梯（按问题选择，不是完成度比赛）

| 精度 | 能检查 | 不能确认 |
|---|---|---|
| 关系草图 | 构图、顺序、信息分配 | 真实材质 |
| 简单模型／替代物 | 空间、遮挡、部分运动 | 最终对象表面一致 |
| 真实对象测试 | 反射、标签、接触 | 完整动态（单张） |
| 短段落测试 | 动作、焦点、运镜与剪辑 | 目标输出中的表现 |
| 目标情境查看 | 缩小、裁切、字幕、播放条件带来的变化 | 未实际检查的其他条件 |

不要求每个项目逐级执行。若问题已知在真实表面上，只画更多分镜不会补齐缺失证据。

# 最小测试卡

```text
待回答问题：
为什么当前答案会影响下一步：
比较的候选及其真实差异：
保持相同的条件：
必须记录的变化与干扰因素：
观察或测量方式：
什么结果会支持、削弱或无法区分候选：
未覆盖的风险：
由谁根据结果决定下一步：
```

- 不预设“通过率 90%”或“至少五人”的通用标准；规模由任务、差异大小、误判代价与推论目标决定 [1]。

# 探索性比较 vs 因果检验

- 两个整体方案同时改变机位、光线、时序，可以帮助选择方向，**不能断言哪个单独变量造成差异**。要找原因就缩小变化，或采用适合多因素问题的设计。
- 拍摄时间、对象差异等非目标变化可参考区组与随机化 [2]。本包**不在未采集数据时报告显著性、效应量或观众偏好**。
