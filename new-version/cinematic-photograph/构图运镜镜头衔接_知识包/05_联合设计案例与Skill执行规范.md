# 联合设计案例与 Skill 执行规范

> 本文把理论、构图卡、运镜卡、衔接卡连接起来。全部案例是本次编写的假设方案，时长仅供制作预演，不是实际拍摄结果，也不是最优参数。  
> 技法编号：C 为构图，M 为运镜／镜内调度，E 为镜头衔接。来源编号 S 见《06_研究来源与证据边界》。

## 1. 为什么分镜表必须同时写“镜内变化”和“镜间关系”

仅有“镜号—景别—内容—时长—运镜”，仍可能无法支持制作。它记录了镜头的独立属性，却未必说明动作的哪个阶段需要保留、前后物体状态怎样接续，以及相机为什么此刻移动。

建议用一个主要镜头计划承载已确认的事实；提示词、摄影说明和剪辑说明从它读取，不各自重新发明一版时间线。每个镜头不必填满全部字段，但被确认重要的条件必须有消费它的人或步骤。

最小镜头记录可以包含：

| 字段 | 应写到什么程度 |
|---|---|
| 观看任务 | 让什么信息可读，或发展什么形式关系 |
| 起始状态 | 人物／物体／动作和当前可见范围 |
| 核心变化 | 不是“有运动”，而是谁与谁的关系怎样改变 |
| 触发与切点 | 按事件、动作阶段或形式节拍描述 |
| 画面组织 | 必须同框、可遮挡、允许未知的部分 |
| 相机与对象运动 | 分开写，注明方向参照 |
| 结束状态 | 下一镜头可以继承的内容；允许的未完成部分 |
| 相邻关系 | 连续、省略、重复、类比、反差等 |
| 检查方式 | 用完整播放、对照预演或具体内容检查来验证 |

这不是要求每个镜头都极度复杂，而是让“简单”也有可执行的含义。

## 2. 案例 A：二十秒乳液广告，如何避免漂亮但接不起来

### 2.1 假设需求与约束

任务是呈现“拿取—开启—按压—双掌摊开—产品识别”的使用片段，观看基调设为轻缓、清楚；不宣称具体功效。产品为桌面上有透明保护盖的泵瓶。只有一位使用者、一张台面与一个主要拍摄区域。

必须保留产品身份、保护盖开合状态、按泵与承接关系，以及最终完整包装。允许省略不重要的等待，不允许让手、瓶盖和泵头在所谓顺滑转场中无解释地换状态。

**候选观看规则：** 使用过程优先保留动作关系；需要看材料时才进入局部；产品识别段解除遮挡、减少相机运动，并给文字出现留出稳定条件。这是本案例提出的设计，不是所有护肤品广告应采用的范式。

### 2.2 第一版镜头计划

| 镜号／草案时长 | 起始与核心动作 | 构图、镜内变化 | 结束状态与下一镜头 |
|---|---|---|---|
| A01／3秒 | 保护盖仍在瓶上；右手进入并接触盖子 | 中景保留手、瓶、台面；固定，允许手入画改变构图；C04、M01 | 动作开始但盖子未完全离开；以动作继续接 A02 |
| A02／3秒 | 同一只右手继续取下保护盖，并放到瓶旁 | 近景仍保留盖子、泵头和落点；不做多余横移；C13、E02 | 盖子已离开瓶身且位于台面约定区域，泵头可用 |
| A03／3秒 | 一只手按泵，另一只手承接乳液 | 能看清按压与承接关系的近景，不因追求局部而切断因果；C04 | 一次按压完成，乳液已在承接手中；下镜头允许省略双手靠拢的部分时间 |
| A04／4秒 | 双掌开始摊开乳液 | 局部优先呈现接触和铺展；先测试固定，必要时只做很小的跟随；C13、M01/M06 | 双手动作减缓；乳液位置与数量保持可解释，不突然消失 |
| A05／2秒 | 双手离开主阅读区域，瓶体再次完整显露 | 同一组空间关系中解除遮挡；可以用走位加转焦，不必推进；C06、M16/M17 | 瓶体在约定区域清晰，盖子保持已取下；接产品识别镜头 |
| A06／5秒 | 完整包装呈示，无新的使用动作 | 固定或极小的有理由运动；文字按实际版式安排；C01/C16 | 产品名与必要信息获得阅读机会；末尾按项目交付需求处理 |

时长必须经预演调整。例如 A02 的动作可能无法在三秒内自然完成，就应改时长、删减无关步骤或重新设计，而不是要求演员异常加速，再称“轻缓”。

### 2.3 三处必须联合设计的接缝

**A01→A02：动作连续，而不是两张图方向相似。** A01 已经抓住保护盖，A02 就不能重新从手尚未接触开始，除非明确采用重复。比较在手接触后、盖子开始上移、盖子刚离开泵头三个位置切。手别、泵头朝向与盖子状态是约定；景别变化是允许改变的变量。

**A03→A04：允许省略，但不能制造操作错觉。** 不必完整展示双手每一步移动，但应让乳液由承接手进入双掌动作的关系可以理解。若材料是生成视频，下一镜头的内容物数量和手部关系必须从实际产出确认，不能只因为提示词写了“继续”就认为连续。

**A05→A06：从发现到识别。** 主要承接的是同一产品与清晰的阅读任务，不必伪装同一连续时刻。可以直接切到更完整的呈示，也可以保留形状或位置呼应。若希望盖子回到瓶上，必须把这识别为新的呈示状态，而不是误称与前镜头严格动作连续。

### 2.4 A05 为什么未必需要推进

提出三个实质不同的候选：

**走位＋转焦。** 手离开后，焦点转到原本就在后方的瓶体。它保留同一空间和发现顺序，前提是瓶体确实可见、距离关系和清晰度可用。

**小幅侧移。** 若手或其他物体形成持续遮挡，相机绕开边界后让产品出现。它改变观察位置，必须有真实的显露关系。

**直接剪切。** 若镜头时间紧，且“逐渐发现”不是必要表达，可以从使用动作直接切完整产品。省去运动过程并不意味着方案低级。

比较的不是哪个更炫，而是它们是否完成已确认任务，以及花在过程中的时间是否值得。A05 只有两秒时，复杂移动与转焦同时发生很可能过载，应优先测试简单方案。

### 2.5 无效捷径与最小修正

“包装左右朝向变了，就把后一镜头水平翻转”可能同时反转文字与不对称结构，不是无代价修复。“接不起来，就加手掌遮挡”也不能修复乳液凭空转移。先判断错误位于主体状态、动作阶段、空间还是接缝视觉，再决定重拍／重生成、换素材还是移动切点。

没有进行实际广告效果测试，因此不能把“产品阅读更清楚”的设计目标写成“更高转化”。

## 3. 案例 B：两人递钥匙，如何选择观察距离与反应时机

### 3.1 不先用“权力感”解释一切

场景只有甲、乙和一把钥匙。甲把钥匙递向乙，乙没有接，随后将钥匙推回桌面中间。甲看向钥匙，再看乙。假设任务是让观众看清“递出未被接受”以及两个人如何继续面对这个结果。

可观察的是动作和先后；“乙冷酷”“甲失去控制”是可能解释，不能仅凭一次低机位或一张无表情的脸确认。

### 3.2 方案一：固定双人构图，以镜内调度表达

起幅保留两人、桌面和交换区域。甲递出钥匙，手进入原先留出的中间区域；乙的手没有立即回应，空出的时间成为可感知变化；乙把钥匙推回，两人的手撤开，钥匙留在画框的关系中心。

相机可以完全不动。此时应该排练的是手进入时是否挡住另一人的表情、钥匙是否太小、两人的注视方向是否可读，而不是先要求轨道推进。[参照方法：S07]

结束时有两种有用选择：留在双人图，让两人同时面对结果；或者在甲从钥匙转向乙时切单人，把观察重心改变。静止镜头也有切点，不是只能等动作全部结束。

### 3.3 方案二：先手部，再反应，指定阅读顺序

| 镜号 | 画面任务 | 候选切点 | 需要保留的条件 |
|---|---|---|---|
| B01 | 双人画面建立关系与递出意图 | 钥匙进入交换区域时 | 两人位置、使用哪只手、交换区 |
| B02 | 看清钥匙没有被接，而是被推回 | 推回开始或到达中间后 | 钥匙方向、动作阶段、手别 |
| B03 | 甲对结果作出可见反应 | 看钥匙、看乙之间的变化 | 反应发生在动作结果之后的时序 |
| B04 | 乙的继续行动或沉默 | 甲的视线为其提供问题后 | 不预设沉默唯一含义 |

这套方案减少同时比较，把观看顺序指定得更明确。它是否更合适，取决于作品是否需要保留两人的同时反应；不能只因为分镜数量更多就认为更电影化。

### 3.4 方案三：相机在拒绝之前先靠近乙

甲递出前，相机已经逐渐靠近乙，并减少甲的画面占比。观众可能更早关注乙会如何回应；这与看到结果后才推进甲的反应，是两套知识与观看顺序。

若目标是让拒绝先作为一个明确动作被看见，这一提前靠近可能反而使钥匙与两人的手退出画框。此时不是推进技术不好，而是选用条件不匹配。

### 3.5 轴线与视线的具体处理

在双人画面中定义主要交流线，标明后续单人的观察侧与视线。乙把钥匙推回并不自动改变交流轴；若某人起身绕到另一侧，则要重新考虑空间关系。可以让这段移动在共同画面中发生，也可以通过其他清楚线索重建；不应插一帧钥匙特写后就默认空间可以任意翻转。

### 3.6 应当比较什么

一遍观看后能否复述钥匙的动作，是内容可读性问题；两人的同时反应是否重要，是创作取舍；更偏好哪一种距离，是审美判断。三者不要折叠为一个虚构的“情绪分数”。

## 4. 案例 C：布料与身体的非叙事实验影像

### 4.1 任务不是解释产品，而是发展形式关系

设定三段素材：布料形成静止折线；舞者带动布料展开；空场中只留下布料缓慢落下。目标是研究“折叠—展开—残留”的时间与图形关系，不需要品牌识别，也不需要完整交代动作地点。

这里相机可以由图形节拍主导，而不是必须追随人物心理。场景方向可以有意不连续，只要作品并不要求观众理解同一条具体行走路线。

### 4.2 方案示例

| 段落 | 构图规则 | 运动／剪辑 | 形成的关系 |
|---|---|---|---|
| C-A | 俯视局部，以折线和留白构成平面结构 | 固定，只有布料细微变化 | 建立形式基线，不急于解释整体 |
| C-B | 身体与布料同时进入斜向关系 | 短弧线运动，途中改变可见面；起点由布料展开的节拍决定 | 平面折线转成体积与身体路径 |
| C-C | 人物离开，保留不同尺度的空场与布料 | 直接切或运动接力后停止；允许静止持续 | 把先前动作转为残留的表面与时间 |

这种关系可以不提供精确地理连续，但不能因此不检查动作质地、布料形状与运动句子的可读性。自由形式不等于没有结构。

### 4.3 两种不同衔接，不分绝对高低

**延续版。** C-B 末尾的布料朝右下运动，C-C 开始以相近的图像运动承接，随后减缓。它把两段组织成一条变化的运动句子。

**对撞版。** C-B 正在快速展开时切到 C-C 的静止平面，声音可以继续或骤停。它保留一个显著断裂，把余波作为新问题。

这两版不应都被“顺滑度”评价。第一版检查续接是否读得通；第二版检查反差是否有结构、是否形成了所需的停顿或重新观看。

### 4.4 平面摄影的转译

把三段改为三张图片时，可以保留折线—身体展开—空场残留的系列关系，但不能再声称实际保留了镜头内的缓入、速度变化或完整动作连续。应改为分析观看顺序、翻页、尺度和图形重复。

## 5. 三个真实制作／研究参照，分别能提供什么

**CODA 的操作员记录：** 手语的可见性会直接改变构图和反应镜头的选择。可迁移的是“先确认交流的载体，再决定景别和剪切”，而不是复制该片每个镜头的比例或器材。[S12](06_研究来源与证据边界.md#source-s12)

**《1917》的摄影访谈：** 需要面部还是前方信息、何时转到新位置、场景尺寸能否容纳动作时间，是联合设计问题。可迁移的是排练与视点的耦合，不是“一镜到底天然沉浸”。[S13](06_研究来源与证据边界.md#source-s13)

**桌边场面的分析与眼动试验：** 人物调度可以与注意组织共同研究。可迁移的是观察方法和可检验的问题，不是把一个十一人样本的注视路径当成所有群像场面的普遍结论。[S06](06_研究来源与证据边界.md#source-s06)[S07](06_研究来源与证据边界.md#source-s07)

## 6. Skill 的能力范围

建议名称：**镜头表达与连续设计**。它不是只识别技法名，而是在三种模式工作。

**分析模式。** 从材料提取画面状态、变化、接缝关系和候选作用；不把推测升级成制作事实。

**设计模式。** 从需求提出实质不同的构图、运镜与剪辑候选；给出选择理由、起止状态、关键接缝与待测试点。

**修订模式。** 对已存在的问题定位到内容、状态、空间、时间、形式或执行；优先提出足够小的修正，不无理由重写整条片子。

无实际运行环境时，本包只提供设计规范与可填写模板，不宣称已经部署、调用或完成视频生成验收。

## 7. 输入要求与材料能力边界

| 输入材料 | 可以可靠开展的工作 | 应保留为未知的内容 |
|---|---|---|
| 完整视频及音轨 | 镜头变化、接缝、时序、声画关系分析 | 未被外部记录证实的器材、意图、作者分工 |
| 无声完整视频 | 视觉关系与动作连续分析 | J/L-cut、声音触发、声场定位与整体声画节奏 |
| 多张截图 | 可见构图与可能的状态变化 | 完整运动路径、实际速度、隐藏剪切、真实切点 |
| 分镜表／文字稿 | 预期表达、矛盾检查、拍摄与剪辑计划 | 成片已经成功实现了这些条件 |
| 只有需求形容词 | 提出候选和需确认的任务 | 唯一正确风格、固定参数、确定观众反应 |

材料缺口会改变结论强度，不必使所有工作停摆。可以在已知范围内提供方案，把依赖未知信息的分支明确标出。

## 8. 推荐执行流程

### 阶段一：确定目标与不可牺牲项

用一两句话写出当前段落让人理解、感受或比较什么；同时标明必须读到的对象／动作、最终载体及制作限制。非叙事任务可以用形式命题，不强制写人物目标。

### 阶段二：按事件与关系分段

先分“关系建立—变化发生—结果或未完成问题”，再决定镜头数。不要先把每句话、每秒或每个漂亮意象都变成一个镜头。

### 阶段三：为每个转折生成少量实质候选

例如背景对象显露，比较调度、横移、转焦与剪切；而不是“慢推进、稍慢推进、更慢推进”三个表面选项。候选差异应落在观看时间、空间或信息组织上。

### 阶段四：写起幅、转折幅、落幅

分别确定构图、动作、清晰度和相机位置；注明触发点。复杂长镜头可增加关键状态，但不必把每一帧列成说明。

### 阶段五：建立必要的相邻约定

每个接缝写“保持什么、允许改变什么、如何检查”。在同一段已采用省略后，不要另一份文件又要求逐帧动作连续。

### 阶段六：原型与比较

优先预演风险最高、最能改变整套方案的接缝和复杂动作。手机排练、简单三维预演或低成本生成都可以是候选工具；没有能力执行时，不声称已经验证。

### 阶段七：修订与冻结

用问题证据定位最小修改。修改某个镜头的结束状态后，重新检查消费它的下一镜头；不要只更新图像而让分镜表和剪辑要求继续保留旧状态。

## 9. 一个轻量记录结构：避免字段重复与假精确

下面是可采用的概念模板，不是某个已实现软件的 API。已知事项填写，未知可以空缺并说明原因；简单场景不需要强迫生成 JSON 或 YAML。

```yaml
sequence_id: A
status: draft
intent: "让开启与使用动作可理解，最后完成完整包装识别"
constraints:
  must_read: ["同一产品身份", "按泵与承接关系"]
  allowed_ellipsis: ["非关键手部移位"]
shots:
  - id: A02
    purpose: "看清保护盖被取下"
    start_state: "右手已抓住盖子，盖子开始向上离开"
    key_change: "泵头显露，盖子被放到台面约定区域"
    end_state: "泵头可用，盖子留在瓶旁"
    framing: "手、盖子、泵头和落点均在可读范围"
    subject_motion: "右手上提后放下盖子"
    camera_motion: "固定"
    trigger: "继承前镜头已经开始的开启动作"
    evidence_status: "planned_not_observed"
    candidates: ["动作开始处切入", "盖子离开泵头时切入"]
transitions:
  - from: A01
    to: A02
    relation: "同一动作继续"
    preserve: ["手别", "产品朝向", "盖子开合阶段"]
    allowed_change: ["景别", "经试剪确认的少量动作省略或重叠"]
    validate: "先整段播放，再检查接缝两侧动作状态"
```

关键是让 `end_state` 真正被相邻镜头和接缝检查消费，而不是写出后再由下游凭空重判。若需要生成工具描述，应由当前确认的镜头计划产生，并回查实际结果；工具请求不能反向充当“已实现”的证据。

## 10. 从镜头计划转为摄影／生成描述

不充分的描述：

> 高级感，电影级，缓慢推镜，浅景深，丝滑衔接。

可执行的描述：

> 起始画面保留右手、带保护盖的瓶体和台面。右手先接触盖子，再向上提起。镜头保持固定，不因手移动而持续校正构图；泵头显露和盖子落在瓶旁的状态都要可读。接前镜头已经开始的同一取盖动作，保留右手与瓶体朝向。结尾盖子已离开瓶体，下一镜头从可按压的泵头状态开始。

进一步需要风格时，再加入有明确作用的层次：例如让背景退后但不模糊关键接触区域；反射不遮住泵头结构；文字段落另给稳定画面。不要同时要求“机位固定、明显横移、真实环绕、背景完全不变”等彼此冲突的目标。

对 AI 生成输出，分别检查主体身份、动作因果、空间、时间和接缝；不要把不同问题全部概括为“提示词不够强”。生成结果未被实际观看时，保持“计划”状态。

## 11. 评价与反馈：把问题定位到正确层级

| 层级 | 典型问题 | 优先处理方向 |
|---|---|---|
| 任务与内容 | 只展示纹理，缺少需要理解的使用关系 | 补必要状态或调整镜头功能 |
| 构图 | 手势被截断、重要对象互相遮挡 | 改范围、站位、动作路径或焦点 |
| 镜内变化 | 相机已经到达，信息却尚未出现 | 改触发和速度，或重设计事件关系 |
| 镜间衔接 | 开盖状态倒退、方向无解释反转 | 查两侧素材状态与切点，不先加转场 |
| 时间与节奏 | 过程重复、结果无停留、每句话都切 | 重排动作阶段和镜头长度 |
| 技术执行 | 运动抖动、焦点失败、视觉生成变形 | 在不改变已确认表达的前提下修复实现 |
| 解释越界 | 用外观直接证明心理、历史或商业效果 | 降低结论强度或另行验证 |

评价句式可以是：

> 在 A03 的按压开始后，承接手退出画框，A04 已经出现双掌摊开。当前剪辑缺少乳液如何进入手中的可见关系。建议扩大 A03 的构图或改用保留承接状态的素材；暂不需要更换整套光影与色彩方案。

这比“这段不高级，重新生成”更有可操作性。

## 12. Skill 验收题库

以下 12 项是应当执行的检查，不是本包已经运行通过的测试报告。

| 编号 | 输入情境 | 合格回应应做到 | 需要防止的失败 |
|---|---|---|---|
| T01 | 只有两张截图，却要求分析运镜 | 分析可见状态，提出候选路径，标明未确认速度与连续性 | 把候选说成实际运镜 |
| T02 | “让人感到压迫，用低机位就行吗” | 给出条件性机制与其他可选关系，提出对照 | 固定技法—情绪字典 |
| T03 | 背景物品完全被人体挡住，要求转焦显露 | 指出转焦不能解除几何遮挡，提供调度／机位方案 | 只强化焦点指令 |
| T04 | 取盖后下镜头盖子仍在瓶上 | 定位物体状态冲突，明确重拍／重生成或承认时间变化 | 用叠化假装连续 |
| T05 | 台词可听，手语也必须完整 | 把手与脸的交流范围纳入构图和切点 | 套用仅保留脸部的反应镜头 |
| T06 | 作品要求故意跳切、失向 | 评价预定形式与不可牺牲内容，不强迫连续性 | 把所有越轴判错 |
| T07 | 需要标识清楚，却同时要求多轴快速运动 | 说明取舍，提出分段或简化方案 | 原样叠加所有需求 |
| T08 | 同一目的给出三个方案 | 候选在信息、时间或空间机制上实质不同 | 只换速度和形容词 |
| T09 | 声画切点不同但无声视频 | 不确认 J/L-cut，列出需音轨验证部分 | 从画面虚构声音桥 |
| T10 | 环绕导致相机换轴侧 | 检查是否可见地重建关系及下一镜头的新方向 | 只因跨线就否决 |
| T11 | 已确认镜头末态被修改 | 重查依赖的下一镜头和接缝，不生成第二套真相 | 只改当前提示词 |
| T12 | 宣称某运镜科学证明提高购买 | 区分脑电／注意／审美／行为证据，要求相应验证 | 从神经指标跳到商业结论 |

## 13. 最终报告的推荐骨架

一段镜头分析或设计报告，建议先给核心判断，再给必要细节：本段的观看命题；实际或计划中的关键状态；构图、运镜和接缝共同承担的任务；两个最重要的取舍；替代方案；当前未验证事项；下一次最值得做的具体测试。

不是每个项目都需要长报告。这里的丰富知识库，目的在于让 skill 能按问题抽取足够细的知识，而不是每次把五十多张技法卡全部输出。
