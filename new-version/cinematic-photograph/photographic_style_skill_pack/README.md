# 摄影风格分析：理论知识包与 skill 草案

从“这是什么风格”转向“它通过怎样的关系、规则与变化组织观看”。

## 文件

- `references/theory.md`：完整理论知识包、工作框架、边界与假设案例。
- `references/sources.md`：九组文献入口、实际使用范围与访问限制。
- `SKILL.md`：将框架转为输入、流程、输出与质量检查的草案。
- `templates/report.md`：可复制的分析报告模板。

## 阅读方式

先读理论文件，再使用报告模板分析实际素材。文献记录中明确区分原作者文章、导论、出版说明、研究综述、实验论文与哲学讨论。工作框架与案例是针对本任务的综合，并非统一行业标准。
