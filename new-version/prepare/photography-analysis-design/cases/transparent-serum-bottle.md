> **事实状态：假设案例**。

# 任务

先看见使用动作，再准确辨认包装；不得让瓶体显得不合理地变形。最初参考强调极浅景深和长条高光。

# 过程

1. **不直接复制参数**。摄影与需求方先确认标签何时必须读到；与美术检查背景是否形成杂乱反射；与动作执行者检查手部是否在显露时遮住名称。
2. **测试发现真正问题**：不是“不够高级”，而是高光经过名称，使字形局部消失（[材质外观与反射](/breakdown/material-appearance-and-reflection.md)）。
3. **候选修改**：减小瓶体转动幅度，改变可反射亮面的位置；给包装识别单独留一个稳定阶段。若修改影响手腕姿态，重新检查接触是否自然；若仅靠后期局部补标签，检查动作和透视是否一致。
4. **交接**保护“接触—显露—识别”的顺序，而不是保护最初未经验证的浅景深数值（[跨阶段保护](/work/six-kinds-of-photography-work.md)、[最小交接单元](/work/minimum-handoff-unit.md)）。

# 摄影的贡献

发现冲突、提出测试、协调动作和光影、取得可用素材，以及明确后期不能破坏的信息关系。
