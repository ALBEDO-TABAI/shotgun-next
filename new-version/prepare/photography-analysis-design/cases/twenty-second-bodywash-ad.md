# Brief

产品关联水、泡沫与日常使用；需同时建立愉悦的使用经验与包装识别；最终含横竖版本。

# 1. 任务定义（[拆 brief](/ideation/brief-decomposition.md)）

| 类别 | 内容 |
|---|---|
| 不可牺牲项 | 包装结构与名称准确；使用动作不造成关系误解；横竖版本各自保留关键信息 |
| 目标假设 | 让细小接触和水的变化值得观看，再把感官经验与明确对象连接 |
| 未知 | 局部镜头是否过于抽象；水与泡沫是否抢走识别任务 |
| 摄影命题 | 先进入接触关系，再逐步获得完整对象；空间不完全消失，保留足以理解日常使用的线索 |

# 2. 两个候选（比较信息顺序，不只是色调）

- **A**：从较完整的使用空间开始 → 进入局部 → 回到包装。
- **B**：先进入局部接触 → 中段通过动作和环境线索建立用途 → 结尾完成包装。

测试分工：草图讨论是否需先交代用途；真实对象测试检查表面、泡沫与名称；短动态测试检查局部到完整的转换——不同测试不互相代替（[测试阶梯](/ideation/test-ladder-and-test-card.md)）。

# 3. 规则与依赖

- 接触阶段允许包装局部化，但动作必须有足够线索；
- 包装阶段运动收敛，保证名称不被反射和遮挡同时干扰；
- 水的动态可以成为变化来源，不强求相机持续运动；
- 竖版无法容纳横版的手、产品与文字关系时，针对竖版重新安排——**中心裁切不等于设计完成**；横竖版本共享命题，不一定共享每个像素位置。

# 4. 测试后的三种可能反馈

| 反馈 | 先查什么 | 不急于做什么 |
|---|---|---|
| 观看者难以复述动作 | 对象关系和顺序 | 加字幕掩盖 |
| 表面被读成另一材质 | 反射与处理候选 | 全部归咎调色 |
| 名称只在暂停时可读 | 停留与最终尺寸 | 用原始大图证明通过 |
