# 案例

各模块的示范案例。除标注“真实”者外均为虚构／假设，见 frontmatter 的 `case_status` 与 [案例与测试的事实状态分开](/principles/case-and-test-factual-status.md)。

# 01 风格
* [护肤品广告的风格分析（假设案例）](skincare-ad-style-analysis.md) - 十二镜头护肤品广告：从“低饱和、浅景深、梦幻高级”的空标签，到“接触导向局部观看＋结尾图形化产品呈示”的有证据风格描述。

# 02 摄影工作
* [透明精华瓶与手部接触（商业，假设案例）](transparent-serum-bottle.md) - 让人先看见使用动作再准确辨认包装；演示摄影如何发现高光与名称冲突、协调动作与光影、保护“接触—显露—识别”顺序。
* [观察一个人整理旧物（非商业，假设案例）](sorting-old-belongings.md) - 保留动作迟疑与环境关系、允许遮挡与即兴；演示预先约定响应原则而非每秒画面，以及实际人物拍摄的同意边界。

# 03 摄影拆解
* [“接触—显露—识别”6 秒镜头的综合拆解（假设方案）](contact-reveal-identify-shot.md) - 从不充分的参数清单到可执行的关系说明，并展示文字不清、反射遮字、动作不明三类相互牵动的修改。
* [broncolor 反光瓶体案例：看似连续的图像可能来自分步骤制作（真实制作案例）](broncolor-bottle-compositing.md) - Urs Recher 的瓶体案例用单一主光配合反射、遮挡、扩散，并拍摄空桌面合成底部——证明一种路径存在，不证明其普遍频率。

# 04 出发点推断
* [为什么人物总在玻璃后面？（竞争假设完整示范，假设案例）](person-behind-glass.md) - 40 秒非商业短片，有完整观看版本但无制作记录；演示可见事实、四个竞争假设、区分性问题与合理报告。
* [为什么护肤广告不让标签一直清楚？（材料不足时的推断，假设案例）](unclear-skincare-label.md) - 只有六张截图、无完整影片时能回答什么、应保留哪些候选、获取影片后如何更新或撤回假设。

# 05 正向构想
* [20 秒洗护产品广告的正向构想（商业，假设示范）](twenty-second-bodywash-ad.md) - 从虚构 brief 到任务定义、两个按信息顺序区分的候选、规则与依赖、横竖版本处理与三种测试反馈。
* [十二张关于“等待”的摄影系列（非商业，假设示范）](waiting-photo-series.md) - 非商业系列的摄影命题、三个候选与测试方式；允许多种理解时不以一致率为唯一标准，但仍检查具体失效。

# 06 评价
* [技术精致，却没有完成当前任务（评价，假设案例）](technically-polished-task-failure.md) - 使用说明短片的微距画面清晰顺滑，却无法判断接触位置；同样的局部化在材质情绪短片中可能被重新评价。
* [不完全清楚，但可能有明确的形式作用（评价，假设案例）](reflective-short-formal-role.md) - 非商业短片反复让人物经过玻璃反射；不能套用产品识别标准，但无意的压缩色块仍可能是技术问题。

# 07 规则迁移
* [规则卡演示：接触先于身份显露（含一次失败与一次需重测的迁移）](contact-before-identity-rule-card.md) - 用完整规则卡演示候选规则的字段、来源分析与来源事实的区分，以及迁移到“即时识别型号”（失败）和“不透明容器”（需重测）的结果。
