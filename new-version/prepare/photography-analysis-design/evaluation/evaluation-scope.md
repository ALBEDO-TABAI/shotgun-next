# 必须记录

当前版本、画幅、是否带声音、观看大小、材料阶段、任务。原始素材、调色预览、带字幕成片和平台压缩版可能支持不同结论。

“这个镜头不清楚”必须说明：原始素材 100% 查看？手机实际大小？截屏放大？——对应不同问题。

# 评审尺度

| 尺度 | 可检查 |
|---|---|
| 单帧 | 对象结构、局部画面 |
| 镜头 | + 动作、变化与时间 |
| 段落 | + 信息分配、视点、声画关系 |
| 系列／作品群 | + 重复、规则与例外 |

一帧漂亮不证明镜头可用；一段漂亮不证明整片任务完成；一组精选案例不证明工作流稳定。**评价应停在实际检查的尺度上。**

# 四种陈述分开写

| 陈述 | 例子 |
|---|---|
| 观察 | “标签右半部在反射中难以辨认” |
| 功能解释 | “这可能妨碍识别” |
| 条件性评价 | “若本镜头承担名称识别，则不满足该目标” |
| 候选修改 | “改变反射区域而不整体提亮” |

可以同段出现，但**建议本身不是问题证据**：想换灯不证明灯是原因；偏好更亮不证明原画面失败。
