# 原意

Jansson 与 Smith 的设计固着研究显示，范例可能使后续设计受其特征限制；论文讨论也提示实验范围与解释边界 [1]。

# 本包的工作化用法（反固着提案）

收集参考时分别标注：

- **借用的关系**：例“先不完整、后完整的显露”；
- **不打算继承的特征**：同一瓶型、蓝绿色、背景或焦段；
- 并补充一个**同任务但形式不同的对照**：完全不同的光影，但完成相似的信息变化。

用于：[并行候选](/ideation/parallel-candidates.md)、[按任务检索](/transfer/task-based-retrieval.md)（异形同构案例 + 反例）。

# 边界

不能简化为“看参考会毁掉创造力”；这是反固着**提案**，不是论文已验证的摄影流程。
