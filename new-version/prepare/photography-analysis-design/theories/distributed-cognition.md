# 原意

Hutchins 的研究自述强调社会、文化与物质环境中的认知活动，并说明其分布式认知理论与航海、航空研究的关联 [1]。

# 本包的工作化用法

把摄影方案看成分布在不同载体中的工作知识：导演描述事件意义；分镜表达观看顺序；场景平面图表达位置约束；测试片让人看见实际反射；镜头记录说明哪次动作可用。**任何一个载体都可能只保存了部分方案。**

实用问题：**关键关系有没有跨载体保存？**

例：“标签出现后要有稳定阅读机会”只写在导演提案里，镜头表只写“微距推进”——现场可能完成了运动却没拍到足够停留。不能简单归为某执行者“不懂创意”，还要查目标是否被正确表达、交接和消费。

分布不是让所有人知道所有事，而是让需要作决定的人获得足够信息，并知道自己依赖的内容来自哪里。

用于：[以决策为中心的协作边界](/work/decision-centered-collaboration.md)、[最小交接单元](/work/minimum-handoff-unit.md)。

# 边界

采用的是作者提出的研究视角，**没有把航空研究直接当成片场绩效证据**；未通读其专著。
