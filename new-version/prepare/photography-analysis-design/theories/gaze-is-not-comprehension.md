# 原意

Loschky 等人在特定电影片段实验中比较有无前文语境的观看者：语境明显影响理解与预测推断，而两组眼动仍有较强同步、差异较小 [1]。

# 本包的工作化用法

> 形式上突出 → 可能被注意 → 被怎样理解 → 产生何种情绪 → 带来何种行为

这些是**不同结论**，不能由第一个自动跳到最后一个（完整阶梯见 [效果推断阶梯](/principles/effect-inference-ladder.md)）。

| 模块 | 用法 |
|---|---|
| 01 风格 | 第五步“检查效果推断有没有越级”：[七步风格分析流程](/style/style-analysis-workflow.md) |
| 03 拆解 | 静音、暂停只是诊断，最终回到完整作品：[镜头之间](/breakdown/between-shots.md) |
| 04 推断 | 不能从“观众看了这里”推出“认同了某个意义”，更不能从分析者的感受反推创作者意图 |
| 06 评价 | 眼动热区不单独证明理解、认可或购买：[指标与测量层级](/evaluation/metrics-and-levels.md) |

# 边界

- 特定刺激与实验条件下的研究，不能当作所有观众与影片都不受语境影响的证明，也**不说语境完全不影响眼动**。
- 题名中的 Jaws 指邦德影片角色，不是鲨鱼电影《大白鲨》。
