# 原意

Aamodt 与 Plaza 的案例推理框架以 **检索（retrieve）、复用（reuse）、修正（revise）、保留（retain）** 组织循环；案例不仅是一组标签，还包含解决问题的情境与经验 [1]。

# 本包的工作化用法

- 检索到“某瓶子拍得很好看”不是完成：需比较新旧任务、调整实现、检查结果，再把成功和失效条件写回。
- 直接把旧参数塞进新项目，省略了适配和修正。

落地为 [案例到规则的完整循环](/transfer/case-rule-cycle.md)。

# 边界

采用该循环作为组织方法，**不声称任何视觉知识库只要有四个步骤就会自动学习或提升质量**；检索到案例本身不是验证通过。
