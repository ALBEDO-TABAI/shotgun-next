# 原意

Wagemans 等人的学术综述讨论视觉分组与图形—背景组织，包括邻近、相似、良好连续、共同运动等因素，以及它们之间的交互 [1]。

# 本包的工作化用法

> 不仅问“有什么颜色、线条和物体”，还要问“什么被组织为一组，什么被分开，什么关系在不同画面中反复出现”。

例：两张产品照都有白瓶、蓝背景、黑字——一张瓶体与背景边界清楚，标签与瓶盖构成稳定关系；另一张瓶体部分融入背景，一块远离产品的反光特别突出。元素清单相似，关系结构不同。

应优先保存：主体轮廓与背景如何分离；哪些局部通过相似性联系；什么因素在竞争；哪些关系需要观看者补全。

用于：[五种分析对象](/style/five-analysis-objects.md) 的“关系”；[构图即信息关系](/breakdown/composition-as-information-relations.md)。

# 边界

这类知觉研究**不能直接证明某种构图必然优美、所有观众都遵循同一路径，或某广告一定更有效**；从分组机制到审美与商业效果，中间仍需证据。
