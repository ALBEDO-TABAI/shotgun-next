# 原意

W3C PROV-DM 以实体、活动与相关来源关系（使用、生成、推导、修订）描述数据来源 [1]。

# 本包的工作化用法

| 模块 | 用法 |
|---|---|
| 04 推断 | 区分“原材料”与“由原材料产生的分析”：[证据账本](/inference/evidence-ledger.md)。有来源链接的说法仍可能是采访者转述、宣传简化或针对另一版本；**多个网站复制同一句话不等于多个独立证据** |
| 07 迁移 | 为原始材料、分析活动、规则版本和测试结果建立联系：规则被质疑时，能找到它依据什么、由哪次分析产生、在哪些条件下被修改：[知识库三层事实分离](/transfer/knowledge-base-three-layers.md) |

# 边界

- **来源图不认证内容真实**，也不自动证明规律有效——保存来源是检查的起点，不是自动认证。
- 本包不要求实现全部规范，简化格式不宣称符合完整 PROV 标准。
