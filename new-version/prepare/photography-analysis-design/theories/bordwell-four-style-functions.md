# 原意

在 Jakob Isak Nielsen 的访谈中，Bordwell 区分 denotative（指示／呈示）、expressive（表现）、decorative（装饰）、symbolic（象征）四种功能，并强调同一技法可同时承担多种功能 [1]。

# 本包的工作化用法

| 功能 | 分析问题 | 假设例子 |
|---|---|---|
| 指示／呈示 | 让什么对象、动作或关系被理解？ | 清晰度转到产品名，使其获得阅读机会 |
| 表现 | 为事件增加怎样的表现性质？ | 动作结束后继续停留，支持“迟疑”的读法 |
| 装饰／形式组织 | 是否发展了不完全由情节决定的形式模式？ | 多次出现形状或运动呼应，但不增加事件信息 |
| 象征 | 是否指向抽象观念或主题？ | 有上下文支持时，把隔断结构读成边界意象 |

用于：[七步风格分析流程](/style/style-analysis-workflow.md) 第 5 步（功能假设）。

# 边界

- “装饰”**不是“无用、低级”的同义词**：一组画面可以让人欣赏线条、节奏、重复与变形，而不必把每种形式翻译成故事信息。
- 反过来，也不能看到一道阴影就急着安排象征意义。
- 不应把叙事片中的功能优先关系机械推广到抽象影片、实验摄影或所有品牌作品。
- 访谈中的工作区分不是穷尽所有艺术功能的普遍定律；**适合扩大解释空间，不适合变成每个镜头必须填写四种功能的表格**。
