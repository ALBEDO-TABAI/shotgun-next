# 原意

Szarkowski 在导论中提出五个方面：**事物本身、细节、画框、时间、观看位置**，并明确它们不是彼此分离的类别，而是同一个问题中相互依赖的方面 [1]。

# 本包的工作化用法

| 方面 | 分析问题 |
|---|---|
| 事物本身 | 什么被选为值得观看的对象？ |
| 细节 | 什么片段被抽出，取得超过其日常位置的重要性？ |
| 画框 | 什么进入画面、什么被排除，边界怎样改变关系？ |
| 时间 | 哪一种瞬间或时间痕迹被保留？ |
| 观看位置 | 这个世界从什么地方被看见？ |

例：同一张餐桌，一张完整交代桌面与用餐者；一张只保留杯口、手和桌布折痕；一张让近处盘子遮住大部分人物——即使色调相同，已经做出不同的摄影选择。不能因为都“偏暖、有颗粒”就忽略对象如何被重新组织。

> **对 skill 的启发：先识别“世界如何变成图像”，再识别“图像像哪种风格”。**

这一问题意识体现在 [八维摄影风格剖面](/style/eight-dimension-style-profile.md)。

# 边界

- 该框架形成于特定摄影史语境；本包借用其问题意识，**不把其中关于摄影本性的历史性论断当作合成影像和生成影像的永久边界**。
- 书 1966 年出版，相关 MoMA 展览 1964 年，二者不混写；导论转录不是校勘版。
