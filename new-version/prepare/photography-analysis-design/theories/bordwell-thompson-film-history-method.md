# 原意

- 电影风格是**电影技法的模式化运用**，与作品整体形式、模式、类型相区分；技法包括场面调度、摄影、剪辑、声音 [1]。
- 研究方法：提出研究问题；区分描述与解释；关注作品版本与来源可靠性；考虑个人与群体层面的原因；**不能把先后顺序直接当成因果**。

# 边界

- 电影总体风格包含摄影以外的部门，不能原封不动归给摄影指导。
- 本包**不**把该方法变成“只有作者开口才能分析”：作品内部关系足以支持功能假设，只是功能假设与历史事实不能互相替换。
