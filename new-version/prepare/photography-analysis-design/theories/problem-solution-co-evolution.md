# 原意

Dorst 与 Cross 研究设计中的问题—方案共同演化；机构摘要说明材料来自 9 位有经验工业设计师的设计过程 [1]。

# 本包的工作化用法

- 先做测试不一定只是“验证答案”，也可能帮助**重新认识问题**。例：实际瓶体反射测试可能表明，“不够真实”并非光太戏剧化，而是缺少能说明表面厚度的关系——此时应更新问题，而不只在原灯光方案中微调。
- 演化**不意味着硬性需求可以被悄悄取消**：已确认约束与探索性解释要分开；方案改变了任务假设时，回到相关决策者确认。
