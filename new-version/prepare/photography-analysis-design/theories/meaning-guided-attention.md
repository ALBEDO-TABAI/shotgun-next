# 原意

Henderson 与 Hayes 在特定自然场景实验中比较意义图（meaning maps）与显著性图，发现语义相关性对解释眼动分布具有重要作用 [1]。

# 本包的工作化用法

注意分配**不简化为“人一定先看最亮的区域”**；构图分析同时考虑图像特征与对象意义。见 [构图即信息关系](/breakdown/composition-as-information-relations.md)。

# 边界

不能据此否定所有低层特征（亮度等）的作用，也不能宣布任意画面存在固定观看路径；静态显著性模型的预测不能写成真实人群的观看行为。
