# 颜色不是物体上的固定屏幕数值

- 白平衡涉及对照明条件的处理；对象本身的颜色与最后的显示颜色不能混为一谈 [1]。“看起来偏蓝”是图像事实，“现场用了蓝灯”需要额外证据。
- 描述时分别记录：主导色域、对象之间的区分、局部色差、跨镜头变化。不把冷暖直接翻译成人物心理，也不把统一肤色数值当作所有条件下的正确目标。
- 品牌色／材料色核对应先约定参考、处理与观看条件；截图像素值能描述截图，未必足以认证实物色彩准确。本模块**不替代色度测量流程**。

# 创意外观与技术转换要有不同位置

ACES 把创意 Look Transform 与输出变换分开说明，整体外观处理也不覆盖逐镜和局部调整 [2][3]——不要把“一套预设”当成风格的全部原因。

工作化记录的五个位置：

1. 对象与光的颜色关系
2. 已知输入处理
3. 整体创意变换
4. 局部处理
5. 最终输出条件

未知就留空，不凭外观替作者补齐整条流程。自行测试时，先确保比较对象处于可比状态（不要拿未正确显示的版本与已完成显示转换的版本比“高级感”）。

# 用可见特征描述质地，暂不确定来源

- 写“高光周边出现扩散”“局部边缘反差较弱”“平坦区域存在细碎亮度变化”“运动边缘留下方向性痕迹”，比“胶片味”“数码味”更能用于检查。
- 需要推断来源时，分别检查光学、曝光、记录、合成、压缩等候选；无证据时不认定颗粒是真实胶片颗粒，也不认定柔和来自某款滤镜。
- 质地也应有任务：允许局部高光扩散，但名称区域不能被吞没；允许表面不完全锐利，但不能让材料差异无法判断。
