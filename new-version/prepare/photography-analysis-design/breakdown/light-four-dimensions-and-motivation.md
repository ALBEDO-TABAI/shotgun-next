# 四个维度

| 维度 | 描述什么 |
|---|---|
| 方向 | 照明与对象、视点的几何关系 |
| 软硬 | 投影边缘的过渡；与**有效光源相对于对象的角尺寸**有关 |
| 明暗反差 | 亮面、暗面及补光关系 |
| 整体调子 | 画面明亮／暗淡区域的分配 |

ARRI 手册的基础说明支持把光质与主辅光关系分开处理 [1]。推论：

- 柔和阴影边缘可以与很深的暗面共存；硬边投影也可在充分补光下保持较低亮暗差。
- 整体暗调 ≠ 记录必然欠曝；整体亮调 ≠ 高光必然截断。
- “大灯很软”不是足够的技术描述：被拍对象“看见”多大的有效发光面，比器材外壳多大更相关。
- 这里只讨论视觉机制，**不提供电气、吊装或高功率灯具的操作规程**。

# 光源动机与现场实现是两件事

- 画面中的窗户可为主光方向提供解释，但**不能证明现场只用了窗光**。“自然主义照明”是视觉判断；“没有人工灯光”是制作事实。
- 先列候选光源逻辑，再看主要明暗是否与之矛盾。矛盾未必是错误：作品可为造型或表现打破现实光源逻辑——评价偏离如何工作，而非要求所有作品模拟自然环境。
- 允许信息不足：画面外可有多个来源，同一种照明关系可由不同设备构成。没有现场资料时，**描述亮暗结构通常比画出唯一布光图更诚实**。
