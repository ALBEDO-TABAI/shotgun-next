# 机制

反射模型把可见表面外观联系到**入射方向、出射方向以及表面散射特性**；粗糙度、方向性、反射与透射都会影响结果 [1]。

# 产品分析应同时检查

- 物体是什么表面；
- 周围有哪些可反射的亮暗形状；
- 相机处于何处；
- 物体如何转动。

一条亮带既可能帮助说明曲率，也可能遮住标签；改变物体方向会同时改变它与光源、视点的关系。

# 控光不仅是“加灯”

也包括移除不需要的反射、安排暗面、改变背景与遮挡。但：

- 看到暗边不能断言那里必然放了黑旗；
- 看到长条高光不能断言必然用了某种条形灯。

# 原始案例提供的是路径，不是普遍配方

Urs Recher 的 broncolor 反光瓶体案例：单一主光 + 反射、遮挡与扩散材料分别处理瓶体与标签，并对底部画面做了合成 [2]。详见 [broncolor 瓶体合成案例](/cases/broncolor-bottle-compositing.md)。

- 它说明最终外观可能由多个环节共同促成；
- 不能证明所有瓶子都适合单灯，或所有类似画面都经过合成；
- 应保存的是**问题类型**：“轮廓如何被辨认”“亮面是否破坏文字”“底部是否与背景混合”。参考案例的器材数字只有在条件相近并经过测试时才有直接操作价值。
