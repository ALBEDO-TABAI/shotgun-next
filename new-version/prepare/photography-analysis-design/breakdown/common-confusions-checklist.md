# 不得混为一谈的概念对

- [ ] 焦距 ≠ 透视（透视由观察位置决定）→ [机位、焦距、画幅与透视](/breakdown/viewpoint-focal-length-format-perspective.md)
- [ ] 画幅 ≠ 裁切 ≠ 焦距
- [ ] 透视比例 ≠ 镜头畸变 ≠ 后期形变
- [ ] 景深 ≠ 柔化 ≠ 背景模糊 ≠ 锐度 → [景深、焦点与锐度](/breakdown/clarity-focus-depth-of-field.md)
- [ ] 柔光 ≠ 低反差；暗调 ≠ 欠曝 → [光影四维度](/breakdown/light-four-dimensions-and-motivation.md)
- [ ] 画面光源动机 ≠ 现场实际光源

- [ ] 创意 look ≠ 技术输出变换 ≠ 全部风格 → [色彩与质地](/breakdown/color-and-texture.md)

# 数值纪律

每个精确数值必须来自**记录、测量或明确的假设计算**。对生成影像，不以提示词作为实际光学实现的证据。

# 降级规则

| 材料状况 | 限制 |
|---|---|
| 被压缩或裁切 | 限制对细节和完整构图的判断 |
| 无原速视频 | 限制对节奏的判断 |
| 只有静帧 | 不输出实际帧率、焦点转移和运镜事实 |
| 机制不能唯一确定 | 保留候选，不为完成表格虚构答案 |
| 无图像 | 可以讨论方案，不能报告已观察到的细节 |
