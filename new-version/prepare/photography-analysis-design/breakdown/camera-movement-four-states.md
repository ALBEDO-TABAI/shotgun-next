# 区分四种机制

| 机制 | 改变什么 |
|---|---|
| 相机位置改变（移位） | 与场景的关系、视差、遮挡 |
| 转动视轴（摇／俯仰） | 观察方向 |
| 固定位置变焦 | 主要改变取景尺度 |
| 后期裁切／重构 | 呈示范围，但不能证明现场出现了相同视点变化 |

理想投影关系能帮助区分这些机制 [1][2]。前后景的相对位移（视差）可作为证据之一，但**一种迹象不足以唯一识别设备或运动装置**；复杂合成也可产生相似变化。

# 每次运动写四个状态

| 状态 | 记录 |
|---|---|
| 进入状态 | 观众知道什么，哪些关系尚未显露 |
| 触发事件 | 人物动作、视线、声音提示，还是摄影自身发起变化 |
| 变化过程 | 哪些对象进入或离开，遮挡怎样解除，清晰与明暗是否同时改变 |
| 停留／退出状态 | 完成后观众得到什么新信息；是否给出相应阅读机会 |

“缓慢环绕产品”不是充分设计：要说明为什么开始——发现背面结构、改变反射，还是制造连续图形变化？若运动没带来需要的差异，**静止也可能是合理候选**。

# 相机相对于事件的时机

- 人物离开后相机是否继续停留、人物尚未行动时相机是否先行转向，可能改变观众与事件的知情关系；具体解释需结合上下文。
- 不要用起始帧和终止帧替代中间过程——关键变化可能在加速、遮挡重叠或短暂停顿中。材料不足时只描述端点差异，不声称重建完整运镜规律。
