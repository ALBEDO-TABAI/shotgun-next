# 四种不同的清晰问题

| 概念 | 含义 |
|---|---|
| 对焦位置 | 哪一距离附近得到最准确聚焦 |
| 景深 | 在给定观看判据下，被认为足够清楚的距离范围 |
| 背景模糊程度 | 特定背景在当前画面里的离焦外观 |
| 锐度／细节呈现 | 还涉及光学、运动、采样与后期 |

它们相关但不是同一项 [1][2]。“景深浅” ≠ “每一处都柔和”：主体可以很锐、背景很虚；也可以主体和背景都受运动或处理影响。分别描述清晰位置、可接受范围、边缘外观和亮部扩散。

# 景深必须附带条件

- 可接受清晰与弥散圈判据涉及放大和观看条件；光圈、距离、焦距参与结果 [2]。
- **不使用“永远前 1/3、后 2/3”的口诀**；不凭一张背景虚化图报出精确光圈。
- 同构图比较要明确哪些变量随之改变：换镜头是否移动了相机？换画幅是否改了焦距、放大或输出尺寸？近摄时还能沿用远距离近似吗？不说明比较条件，“哪个一定更虚”往往没有单一答案。
- 缩小光圈不是无代价地增加清楚区域：衍射等因素会参与细节 [2]。实务上测试所需信息是否都能读到，而不是机械追求最小孔径。

# 把焦点写成“信息开放顺序”

三个记录项：**初始可读对象 → 转移触发事件 → 最终可读对象**。

- 例：手拿起瓶子——从手指先清楚开始，让包装随动作进入清晰；或始终保留瓶体，手作为短暂遮挡。区别在于安排“先感受动作”还是“先认识对象”，不只在难度。
- 看实际时序：焦点**提前到达**可能让观众先发现；**同时到达**可能帮助动作辨认；**滞后到达**可能延迟阅读。这些是关系解释，不自动对应悬念、自然或失误。
- 生成视频中某物逐渐变清楚，**不证明真实发生了光学调焦**；只能确认可见变化。
