# 原则

> 摄影技术的作用，不是为情绪提供一套固定按钮，而是改变对象以何种空间、清晰程度、光影关系与时间方式被看见。

| 常见“词典式”说法 | 为什么不成立 | 应改成 |
|---|---|---|
| 低机位 → 权威 | 低机位也可能为交代上方空间、避开背景、贴近地面物件或与前一镜头形成关系 | 先检查当前作用，再作为待检验解释 |
| 低饱和 → 忧郁 | 冷暖关系不能直接翻译成人物心理 | 结合其他关系解释 |
| 浅景深 → 梦幻 | 可能是降低信息量、突出接触位置、保持信息未显露或制作条件 | 写出“可见关系—候选机制—可能作用—任务条件” |
| 推进 → 情绪 | “推进具有情绪”不能连接操作与观看任务 | 说明具体信息变化 |

# 在正向构想中
