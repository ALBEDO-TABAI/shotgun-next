# 六件事

> 当前实际看到了什么；作出了什么解释；依据什么；哪些条件尚未知；决定改变什么；用什么确认改变是否有效。

| # | 问题 | 本包对应 |
|---|---|---|
| 1 | 实际看到了什么 | 直接观察（[四种结论状态](/inference/four-conclusion-states.md)） |
| 2 | 作出了什么解释 | 解释假设 |
| 3 | 依据什么 | [证据账本](/inference/evidence-ledger.md) |
| 4 | 哪些条件尚未知 | 尚未确定 |
| 5 | 决定改变什么 | [反馈卡](/evaluation/critique-feedback-card.md)、[反馈路由](/ideation/feedback-routing-layers.md) |
| 6 | 用什么确认改变有效 | [测试卡](/ideation/test-ladder-and-test-card.md)、[三轮评审](/evaluation/three-pass-review.md) |

# 使用

- 可先把各模块作为知识文档使用，再按具体任务提取精简技能；**不要求每次局部提问都机械运行所有章节**，只启用相关分析，同时保留必要的证据边界。
- 这六件事比更多风格名、参数和文档字段更重要。
