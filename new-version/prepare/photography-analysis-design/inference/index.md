# 04 出发点推断：证据、竞争假设与创作意图

把看到的、解释的、猜测的分开。

# 问题与因果
* [六类“为什么”：先确定自己问的是哪一种](six-kinds-of-why.md) - 图像机制、制作过程、创作目的、形式功能、观众理解、历史关联六类问题各有主要证据与合理结论形式，不能互相冒充。
* [因果草图：阻止过早归因](causal-sketch.md) - 用“上游原因→拍摄选择→最终图像→观看反应”草图阻止三种倒推；把约束视为候选原因，把意图放进时间。

# 证据与假设
* [证据账本与最小证据记录](evidence-ledger.md) - 每条材料记录它直接支持什么、没有支持什么、是否独立；区分原话、释义与延伸，防止同源重复与版本混用。
* [竞争假设与区分性证据](competing-hypotheses.md) - 从现象出发提出真正不同的候选，寻找能区分它们的证据，用反例检验规则，并把数量与解释力分开。
* [四种结论状态：直接观察、外部记录支持、解释假设、尚未确定](four-conclusion-states.md) - 比单一置信分数更实用的结论标注方式，贯穿风格分析、拆解、推断、评价与规则迁移。
* [正向重建测试：证明路径可行，不证明历史上就这样做](forward-reconstruction-tests.md) - 机制可行性测试、功能测试、历史检验三种测试回答不同问题，不可混用。

# 作者与影响
* [作者、合作与影响：三种不同主张](authorship-influence-claims.md) - 署名不等于决定起点；相似、影响与归属是三种主张；创作说明不垄断观看解释，分析者也不替他人宣布隐藏心理。
