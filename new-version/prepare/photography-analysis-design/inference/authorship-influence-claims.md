# 1. 不把职位署名当成所有决定的起点

- 摄影指导署名证明其与项目的职业关联，不能单独确认某画面是谁首先构想、怎样修改、最后由谁完成（协作功能见 [摄影贡献归属](/work/attributing-photographic-contribution.md)）。
- 当事人说明不一致时，不急于挑“更权威”的人裁决；先查是否指不同阶段、不同镜头或不同意义上的“提出”。真正矛盾则**并列报告**。

# 2. 相似、影响与归属是三种主张

| 主张 | 例子 | 证据要求 |
|---|---|---|
| 相似（比较） | “与某作者常见的正面构图相似” | 作品比较 |
| 影响 | “创作者看过并借鉴该作品” | 接触机会、时间、文献 |
| 归属 | “属于某个历史运动” | 更广的关系与语境、更强的历史材料 [1] |

不能因题材、色调或器材相近就建立影响链；也不能把明显不同的表现方式塞进一个宽泛流派，让命名显得统一。对应 [命名的证据强度](/style/naming-evidence-strength.md) 第 3、4 级。

# 3. 创作说明不垄断观看解释

- 作者说“这是关于距离”，分析者仍可观察作品怎样呈现时间、劳动或表面——但要标明哪些来自自述、哪些来自自己的读法。
- 反之，不能因自己的解释更精致，就说作者“真正想表达的”其实是另一个意思。可以讨论**效果超出自述**，不需要替他人宣布隐藏心理。
