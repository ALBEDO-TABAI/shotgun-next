# 证据不是一条固定等级阶梯

- 原始素材对曝光、运动、合成判断重要；完整作品对段落功能重要；批注分镜对前期计划重要；当事人陈述对其自述目的重要。**没有一种材料能包办全部问题**。
- 拍摄记录写了某焦距，仍需确认对应哪次拍摄、哪条素材、成片是否采用；官方幕后视频可真实展示场景，却未必覆盖补拍和后期。
- 评价来源应围绕**当前主张**，而不是给“官方”或“论文”贴统一可信标签。

# 最小证据记录

```text
证据编号：
材料名称与实际位置：
对应作品／版本／镜头／时间：
材料性质：成片、原始素材、计划、记录、自述、转述或研究。
直接支持的主张：
没有支持的主张：
来源及其与项目的关系：
可能的缺失、剪辑、选择性呈现或版本差异：
与其他证据是否真正独立：
```

“**没有支持的主张**”一项很重要：某记录支持“用了一个光源”，不支持“全片所有镜头都用一个光源”；某访谈说明摄影指导提出方案，不支持导演、美术和后期没有贡献。

# 区分原话、释义和自己的延伸

- 写“作者将目标描述为……”，随后注明“本文据此推测……”；不要把扩展意义接在引号后。
- 只读到摘要、书目介绍或机构简介时写清核读范围（见 [核读范围逐条记录](/principles/record-reading-scope.md)）。

# 防止同源重复和版本混用

- 同一访谈的多次转载记为**同一根来源**；搜索结果多不提高结论强度。
- 广告短版、导演版、不同调色版、平台裁切分别标记；不同版本的截图不能自动排成一个真实段落。版本不清时报告“当前样本由这些材料组成”。
