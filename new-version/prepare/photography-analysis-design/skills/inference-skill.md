> 本模块**不是通过画面识别作者心理的工具**。

# 输入

实际可用作品、研究问题、当前材料范围、已知版本、允许查阅的来源。只有题名或描述而无可检查材料时，改成研究计划或一般方法回答，不声称已完成画面观察。

# 流程

1. 把“为什么”分到 [六类问题](/inference/six-kinds-of-why.md) 之一，必要时拆成两个；
2. 建立低推断观察，收集和核对能回答该问题的证据（[证据账本](/inference/evidence-ledger.md)）；
3. 提出数量有限、有区分性的候选，找反例与缺失条件（[竞争假设](/inference/competing-hypotheses.md)、[因果草图](/inference/causal-sketch.md)）；
4. 以 [结论状态](/inference/four-conclusion-states.md) 输出，说明新证据到来后怎样更新。

不必为每个小细节展开完整研究：若目标仅是为自己项目借鉴一种观看关系，确认关系存在、适用条件清楚，即可进入 07 模块迁移流程，不用先完成全部作者意图考证。

# 输出模板

```text
研究问题类型：
材料范围与版本：
直接观察及位置：
候选解释及其区分点：
支持证据／反例／同源转述：
已确认的制作记录或作者自述：
当前结论状态：
可作出的功能解释：
不能作出的意图／器材／影响判断：
最有价值的补充材料或检验：
结论更新条件：
```

# 自检

- 每个“所以”是否跨过了未被支持的一层？
- 是否用效果替代意图、用自述替代实测、用时间先后替代因果、用同源转载替代独立证据？
- 是否为给出风格名而扩大范围？
- 是否把制作限制认定为无创意，或把复杂设备认定为成功原因？
- 证据不足时保留可完成部分并精确降低结论强度；记录冲突时并列保留冲突与其影响，不悄悄选一个来源写成定论。

# 练习：写出“什么会让自己改判”

1. 选一个很确信的解释（如“这个特写表现了亲密”），写出支撑它的画面关系，再提出一个不同情绪语境下仍可能用相似形式的案例；检查真正支撑解释的是机位、表演、声音、前后文还是组合。
2. 为一张参考图给出两种可行制作路径，设计最小区分材料（原始素材、现场照、另一视角、处理前后版本）——不平均索取所有资料。
3. 写两段报告：一段只报告作品功能，一段只报告制作事实。若不能分开，说明仍在用一种证据回答另一种问题。
