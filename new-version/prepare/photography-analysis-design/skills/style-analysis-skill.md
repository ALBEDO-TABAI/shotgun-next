> 方法草案，**没有宣称通过用户研究、行业认证或特定 agent 平台兼容性验证**。

# 目的

重建一套可检验的观看规则：什么被强调、什么被限制、何时改变、相对于什么显著，以及这些判断有多少证据——而不是更快说出一个风格名字。

# 输入

分析对象（单张／组照／镜头／段落／完整影片／作者作品群）；材料版本、完整性、画幅、是否裁切或二次处理；是否有制作说明；任务与参照集（如有）。

# 流程

[七步风格分析流程](/style/style-analysis-workflow.md)：界定范围 → 低推断描述 → 关系（[八维剖面](/style/eight-dimension-style-profile.md)、[五种分析对象](/style/five-analysis-objects.md)）→ 重复、发展与反例 → 功能与来源假设 → 反事实与效果越级检查 → 最后命名（[命名的证据强度](/style/naming-evidence-strength.md)）。混合风格使用 [组合语法](/style/hybrid-style-grammar.md)。

# 输出

[风格分析交付物](/style/style-analysis-deliverable.md)，每项重要结论标注 [结论状态](/inference/four-conclusion-states.md)。

# 质量要求

- 名称不替代解释；不用无依据比例（“60% 自然主义”）制造精确感；
- 候选规则指向具体帧／图片／已核实时间范围，**不编造时间码**；
- 数量与时长说明分母；
- 效果推断不越级（[效果推断阶梯](/principles/effect-inference-ladder.md)）；
- 评价按四问分开（[分析、解释与评价分开](/style/analysis-interpretation-evaluation-separation.md)）。

# 降级

- 缺少媒体：只生成分析计划或假设，不写成实际观察；
- 单张照片：只做画面形式配置描述，不证明作者跨项目习惯或时间规则；
- 只有精选截图：不推断运镜与剪辑节奏；
- 无历史来源：不做历史归属或影响判断。
