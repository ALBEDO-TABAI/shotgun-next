# 输入与模式

| 模式 | 条件 | 能力边界 |
|---|---|---|
| 外观分析 | 只有成片（图片或视频）+ 分析范围 + 当前问题 | 机制保持候选 |
| 机制核对 | 另有原始素材、镜头信息、布光记录 | 可将部分机制标为“已由记录核实” |
| 方案讨论 | 没有图像 | 不能报告已观察到某细节 |

- 静态模式不输出实际帧率、焦点转移和运镜事实；
- 动态模式必须记录播放版本与时间位置；
- 系列模式说明取样范围，不把选中的几帧当完整分布。

# 执行顺序

1. 确认观看材料；
2. 不带器材归属的整体描述（[四个层次](/breakdown/four-layers-and-evidence-chains.md)）；
3. 按空间、构图、清晰、光影、色彩、时间逐项检查，特别记录**跨维度关系**；
4. 最后提出机制候选和可能功能，必要时给出两种能区分的测试。

并非每次输出全部维度：问题是“瓶体为什么显得扁”，优先检查观察位置、反射结构与轮廓，不自动生成无关的帧率讨论。

# 标准输出片段

```text
对象／时间范围／观看版本：
可见关系：
支持这项观察的具体位置：
可能的拍摄或处理机制：
每种机制成立所需的条件：
可能帮助或限制的观看任务：
其他解释与缺失材料：
候选修改／测试：
修改时必须保留的关系：
结论状态：直接观察／已由记录核实／解释假设／尚未确定。
```

# 练习

1. 找一张喜欢的照片，**禁用**“电影感、高级、日系、胶片感”，写出五条可见关系；挑一条提出两种实现方式并说明如何区分。若无法区分，说明结论应停在哪一层。
2. 对一段短片分别记录相机、人物、焦点与信息显露的时序，检查有效部分来自哪两条时序的配合。
3. 把对象换成不同材质或尺度，保留观看任务重新选择实现——说明哪些关系可迁移、哪些必须重测。
