# 模板

```text
分析对象与范围：
  当前实际看到了哪些材料？哪些没有看到？
可见特征：
  画框、空间、光影、清晰度、时间、质地分别是什么？
关系与规则：
  哪些选择共同出现？在什么条件下出现？有哪些变化与反例？
可能功能：
  它们可能帮助呈示、表现、形式组织或象征什么？
替代解释：
  是否还可能来自任务、制作条件、合作或后期？
风格命名：
  哪些是形式描述，哪些只是比较性称呼？
  是否有足够证据使用历史归属或影响关系的说法？
创作转译：
  哪些关系值得保留？哪些可以变化？适用于什么任务？
  改变后需要测试什么？
```

# 最少应保留

对象与范围、观察证据、候选规则、主要反例、功能假设与替代解释、命名层级、可迁移规则与待测试问题。

# 结论状态标注

每项重要结论标为：**直接观察**／**外部核实**／**解释假设**／**尚未确定**。这些状态不是简单的高低等级——准确的形式观察与准确的历史事实依赖不同证据，不能互相替代。完整定义见 [四种结论状态](/inference/four-conclusion-states.md)。

# 生成影像流程

若用于生成影像流程，应交付**可见结果的约束**与候选实现方法；不能把提示词中的焦段、光圈或作者名称当作实际图像已满足的证据。见 [AI 工作流：意图、请求与结果](/transfer/ai-intent-request-result.md)。
