# 01 风格：描述、归纳与归属判断

风格不是滤镜，而是有组织、有条件的选择。本组把“摄影风格”从命名转向关系、规则与语境。来源：`一.md`（长稿）与 `photographic_style_knowledge_pack.md`（精炼版）合并去重。

# 定义与概念
* [摄影风格的工作定义](photographic-style-working-definition.md) - 摄影风格是在明确作品范围与观看语境中，关于视点、空间、可见性、时间和成像质地的一组有组织的倾向，体现在关系、条件、规则与有结构作用的偏离中。
* [风格相关概念分层（八个不能混成一个标签栏的层面）](style-concept-layers.md) - 用途、题材、模式、技法、外观、感受、风格结构、历史归属八个层面分别回答不同问题、需要不同证据。

# 分析框架
* [风格分析的五个对象：特征、关系、分布、发展与例外、参照](five-analysis-objects.md) - 把风格分析从“特征袋”升级为五种结构，最终归纳为“当＿发生时倾向于＿”的条件规则。
* [八维摄影风格剖面](eight-dimension-style-profile.md) - 观看位置、画框、空间、清晰度、光影、色彩质地、时间运动、建构感八个观察入口，用于系统记录摄影风格。
* [混合风格的组合语法](hybrid-style-grammar.md) - 用同画面分层、跨段落切换、功能分工、技法迁移四种方式记录混合风格，并回答哪条规则主导、如何衔接。
* [风格命名的四级证据强度](naming-evidence-strength.md) - 形式描述、比较性称呼、历史归属、影响／意图四种命名主张各需不同证据，后两种不是前两种的“高级版本”。

# 流程与交付
* [七步风格分析流程](style-analysis-workflow.md) - 界定范围→低推断描述→关系→重复与反例→功能与来源假设→反事实检查→最后命名，是一条有证据约束的风格分析流程。
* [分析、解释与评价必须分开（风格评价四问）](analysis-interpretation-evaluation-separation.md) - 风格评价拆成描述可靠性、规则解释力、任务适配、历史比较四个问题，不汇总为一个“风格分数”。
* [风格分析交付物（有证据范围的风格说明）](style-analysis-deliverable.md) - 风格分析的核心产物不是风格名称，而是包含对象范围、可见特征、关系规则、功能、替代解释、命名层级与创作转译的风格说明。
