# 分层表

以下是分析用的术语分工，**不是互斥的艺术史分类**。

| 层面 | 回答的问题 | 例子 | 不能直接推出什么 |
|---|---|---|---|
| 用途／任务 | 为什么制作、需要完成什么 | 产品识别、品牌情绪、个人表达 | 商业用途不直接决定摄影形式 |
| 题材／内容 | 拍了什么 | 皮肤、城市、家庭、运动 | 题材相同不等于风格相同 |
| 模式／类型 | 与何种作品惯例相关 | 纪录、虚构、实验；悬疑、歌舞 | 一种类型可容纳多种摄影风格 |
| 技法 | 采用了何种可描述处理 | 浅景深、正面闪光、长曝光 | 技法没有唯一情绪译码 |
| 外观／look | 成片表面呈现什么特征 | 偏青、低饱和、颗粒明显 | 不足以概括完整观看组织 |
| 感受／判断 | 某个观看者如何体验它 | 亲密、冷峻、轻盈、“高级” | 不是人人相同的客观属性 |
| 风格结构 | 选择如何配合、何时变化 | 先局部接触，再完整呈示 | 不等同于历史流派身份 |
| 历史归属／影响 | 与哪些历史实践存在何种关系 | 某运动成员、对某作者的借鉴 | 不能仅凭外观相似确定 |

# 最该警惕的三句跳跃

| 句子 | 结论类型 | 所需证据 |
|---|---|---|
| “画面偏冷色。” | 形式描述 | 作品本身 |
| “人物显得冷峻。” | 观看解释 | 作品关系 + 语境 |
| “摄影师借鉴了某位作者。” | 历史因果判断 | 历史／制作来源 |

它们不是同一种结论。这一区分在 [命名的证据强度](/style/naming-evidence-strength.md) 中进一步分级，并与 [六类“为什么”](/inference/six-kinds-of-why.md) 中的问题类型对应。
