# 七步

| 步 | 名称 | 要点 |
|---|---|---|
| 1 | **界定对象与证据范围** | 记录媒介、版本、完整性、画幅、可用时长／图片数、是否裁切或二次处理、是否有制作说明；说明分析单件、系列还是作者作品群。一张照片可支持风格配置描述，不能独自证明作者跨项目习惯；精选作品集最多支持“这个展示样本呈现了某种倾向”。缺少媒体只能生成分析计划或假设。 |
| 2 | **先做不带流派词的低推断描述** | 不先写“日系”“高级”“电影感”；先写位置、相对大小、明暗、清晰、边界、时间状态。事实记录允许“看不清”“无法判断”。顺序：先“人物靠近左边界、右侧大面积空区、手部更易辨认” → 再“这些关系可能让动作比表情更突出” → 最后才讨论情绪或目的。防止早出现的风格词支配后续观察。 |
| 3 | **整理要素之间的关系** | 按 [八维剖面](/style/eight-dimension-style-profile.md) 找共同作用或冲突的选择；每条候选规则指向具体帧、图片或已核实时间范围；**不得编造精确时间码**。记录链：形式特征 → 与其他特征的关系 → 适用范围 → 变化条件 → 反例。 |
| 4 | **检查重复、发展和反例** | 规则是否遍及样本、是否只适用某段落、有无反例。数量与时长须说明分母（“当前拿到的八个镜头中”≠“整部影片始终如此”）。参考集经人工精选时说明偏向。没看到≠不存在。 |
| 5 | **提出功能与来源假设** | 用 [Bordwell 四种风格功能](/theories/bordwell-four-style-functions.md) 提问（不当作必填四格）；另列制作约束、合作与后期等替代解释。功能（在成片中起什么作用）与制作原因（为何在制作中出现）分开。 |
| 6 | **反事实与可检验性检查** | 保持色调改观看距离，关系还在吗？保持构图改信息出现顺序，解释还成立吗？同样技法放进另一内容还会有同样读法吗？这是分析假设，**不是受控实验**；实际因素相互耦合，不能宣称“已证明某形式导致某感受”。同时检查“效果推断”是否越级，见 [效果推断阶梯](/principles/effect-inference-ladder.md)。 |
| 7 | **最后命名并转译为规则** | 输出有范围限制的风格描述、主导与辅助规则、重要例外、历史比较的证据等级（见 [命名的证据强度](/style/naming-evidence-strength.md)）、可迁移原则。 |
