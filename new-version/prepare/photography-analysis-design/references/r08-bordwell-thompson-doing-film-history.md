# 核读范围

01 模块（S1）：核读形式、风格、模式与类型的区分；风格的模式化技术运用；提问、证据与解释关系。02/04 模块（R08）：核读描述与解释、证据、版本、因果、影响和趋势相关段落。

# 支持什么

支持提出问题、校核来源、区分个人与群体层面的多类原因；支持“影片风格≠摄影风格”。

# 限制与边界

电影总体风格包含摄影以外的部门，不能原封不动归给摄影指导；不替代具体作品的制作史证据。
