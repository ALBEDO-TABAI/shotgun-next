# 使用方式

- 编号在各模块一致；引用编号表示该资料支持**相邻主张**，不表示它验证了整篇原创工作框架。
- 同一研究的摘要与全文、同一手册的不同章节、同一作者的不同材料，**不重复计作独立实验证据**。
- 外部地址只作查证用；PDF 来源只提供地址，不随本包再分发原文。

# 资料类型与解释边界

- **原始实验论文**：需同时考虑任务、样本和测量，不能把特定网络广告或电影片段结果推广到所有创作。
- **原始理论与模型**：提供解释框架，不意味着各环节都有相同强度的实证支持；摄影应用另标为综合或提案。
- **技术章节与官方文档**：支持物理、定义或接口；不决定审美，也不证明所有现实实现一致。
- **职业说明与制作案例**：说明被记录的工作和做法，不是所有地区、团队或对象的统一规则。
- **机构／出版摘要**：只支持摘要可见的内容。

公开英语资料占主要部分；未将未读书籍、付费墙后未获取的方法细节、社交媒体转述或器材营销结论当作已核实研究。详见 [证据类型不可互替](/principles/evidence-types-not-interchangeable.md)、[核读范围逐条记录](/principles/record-reading-scope.md)。

# 当前材料没有完成的事情（缺口）

- 没有检验某部用户影片的实际镜头或作者意图；
- 没有测试某个具体生成模型；
- 没有开展观众招募、行为实验或商业转化分析；
- 工作卡、假设案例和技能验收题不能作为上述工作已完成的证据；
- 一些历史理论、专业书籍和研究争议仍可扩展（如 Walton 1970 原文、Shore 全书、Szarkowski 校勘版）。

未来增补优先补**当前结论真正缺少的证据**：具体作品的制作记录、真实对象测试、完整时序材料或相应受众研究，而不是更多风格标签和同义引用。
