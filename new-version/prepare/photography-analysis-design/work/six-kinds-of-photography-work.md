> 用于分析和分配任务的工作化分类，**不是标准工种名录**。

# 1. 问题翻译：从“想表达什么”到“观众怎样看”

- 澄清：观众此前知道什么、本段需要新知道什么；对象应被观察、接触、检验还是保持距离；哪些信息必须明确、哪些可以歧义；持续多久。
- “让人物孤独”不是充分的摄影任务。候选：人物与他人同框却无交流；相机停在人物离开后的空间；人物被拍得近却无法与相机建立视线关系——**不同的表达方案，不是同一情绪的同义参数**。
- 产物可以很短：一段观看任务 + 两个方案差异。不必先生成巨大的视觉术语字典。

# 2. 规则设计：稳定项、变化项和变化条件

- 规则不是“全片同一种焦段”。更有解释力的规则：只有人物主动接近对象时相机才缩短观看距离；使用段落允许包装不完整，识别段落必须恢复完整；环境光逻辑保持可信，但特定物件可获局部强调。
- **稳定项**给连续性，**变化项**响应内容，**触发条件**让变化不依赖现场临时猜测——三者要一起写（详见 [五层规则展开](/ideation/five-layer-rule-expansion.md)）。
- 说明例外如何被批准：临时发现的好反射画面能否打破正面呈示？明确例外改变了什么、是否需同步改相邻镜头。

# 3. 材料与空间实现

- 机位、焦点、照明、物体表面、演员动作、场景布置相互耦合。不默认场景是固定输入，也不默认对象问题都该由灯光补救。
- 例：标签反光遮字，候选解决点在瓶体转角、标签材料、光源反射区域、相机方向或后期合成——先判断问题在哪种关系里，再讨论谁改什么。
- 最值得保留的是**测试条件与可接受范围**，而不是“某镜头很好看”。

# 4. 时间与可剪性实现：拍到转折

- 一个漂亮的中间帧不能代替可用镜头。关键镜头至少回答：进入时观众看见什么；什么动作触发观看改变；信息达到可读的时刻；离开镜头时留下什么关系；需要剪辑完成的表达依赖前后镜头什么条件。
- 平面拍摄也有版本与排列问题：组照顺序、不同裁切中的信息存留；不应只验收单张原始大图。
- 更细的镜头状态写法见 [镜头状态说明](/ideation/shot-state-description.md) 与 [运镜四状态](/breakdown/camera-movement-four-states.md)。

# 5. 波动管理：哪些差异可接受

- 容差三类：不影响任务的小变化／改变局部效果但可接受／使核心信息失效（例：手指轻微位移可能无妨，遮住产品名称则识别失败）。
- 只在极窄位置和时间点成立的设计需要更高执行精度，不自动“不好”，但要提前说清成本；有时稍不极端却更稳健的关系更适合项目（参见 [按失败代价排序](/ideation/risk-ordering-and-fallbacks.md)）。
- 本包不提出具体安全操作规范。

# 6. 跨阶段保护：把不能丢的送到成片

- 需保护的未必是原始参数，而可能是面部与背景的层次、关键反射形状、标签完整、动作先后或镜头间差异。
- 区分“必须保留的结果”与“当时采用的实现手段”：后期换了技术但保住关键关系，不应判失真；沿用同一预设却丢了关键关系，也不能宣称忠实实现。
