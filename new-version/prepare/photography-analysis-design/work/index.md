# 02 摄影工作：职责、协作与视觉决策

摄影做了哪些工作，不能只看最后按了哪些参数。

# 定义与分类
* [摄影工作的定义：使一种观看方式成立并延续](photography-work-definition.md) - 摄影工作是对观看位置、空间信息、可见性、时间和成像呈现进行设计、协商、实现与检查的活动，既生产图像也生产决策依据。
* [分析摄影工作时必须分开的六种东西](six-things-to-separate.md) - 表达任务、视觉决策、实现活动、工作产物、决策权限、结果与归因六个对象需分别填写，避免把器材和职位当成工作本身。
* [摄影的六类工作：看功能，不看职位数量](six-kinds-of-photography-work.md) - 问题翻译、规则设计、材料与空间实现、时间与可剪性、波动管理、跨阶段保护六类功能构成摄影工作。

# 流程与协作
* [按制作阶段检查：每一阶段解决不同的不确定性](stage-by-stage-checks.md) - 接收任务、前期、拍摄、后期、交付五个阶段各自要检查的问题与产物。
* [以决策为中心的协作边界](decision-centered-collaboration.md) - 按“决策问题—参与功能—共享材料—确认人”建立责任接口，而不是按部门名称猜责任。
* [最小交接单元](minimum-handoff-unit.md) - 一次有效交接至少包含对象与版本、已确认决策、允许调整范围、不可丢失关系、接收端下一动作、检查依据。
* [解决冲突，不是把互斥参数取平均](conflict-resolution-not-averaging.md) - 冲突时先查各方在保护什么，寻找结构解法；确实不可兼得时显式取舍并记录牺牲项。

# 归因与工作流差异
* [评价摄影贡献而不过度归功](attributing-photographic-contribution.md) - 用三个问题分开“成片中成立了什么”“实现它需要哪些活动”“谁实际完成或决定了它”，把效果分析与贡献归属分开。
* [平面、动态与 AI 工作流的差异](still-motion-ai-differences.md) - 平面需检查系列与裁切，动态需增加时序与跨镜头接口，AI 工作流取消了工种但没有取消决定，且请求不能证明结果。
