# Schema

| 字段 | 说明 |
|---|---|
| 对象与版本 | 哪个镜头、哪版方案 |
| 已确认决策 | 当前生效的视觉决策 |
| 允许调整范围 | 接收端可以改什么 |
| 不可丢失关系 | 无论怎样改都要保住的关系 |
| 接收端下一动作 | 接收后第一件要做的事 |
| 检查依据 | 用什么判断交接成功 |

# Examples

> 镜头 S04，方案 v3。重点是手离开后名称完整显露。可以缩短起始等待，但不能先切走再露出名称。当前预览已经应用创意外观，原始素材另存。剪辑接收后先确认显露后的可用停留；若停留不足，反馈摄影／导演，不自行把识别要求视为可选。

**“接收后先确认”很重要**：发送者完成制作，与接收者成功消费，是两个事件。

# 色彩交接的特别提醒

ACES 的 AMF 是人机可读的旁车元数据，区分输入、创意外观与输出变换；Look Transform 也不等于全部逐镜、局部调色 [1][2]。由此：

- **技术事实、观看变换与创意意图需分别交接**；
- 不仅检查文件有没有，还要检查接收端是否把正确变换应用到正确素材；
- 原始素材、已烘焙预览、监看参考不因外观接近而互相替代；
- 未核验的元数据只能算“已提供说明”，不能写成“全链路已保持一致”。
