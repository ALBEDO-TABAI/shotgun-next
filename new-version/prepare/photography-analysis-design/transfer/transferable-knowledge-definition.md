# 核心命题

> 把分析沉淀成可迁移的摄影规则，而不是参考图收藏。

一张参考图同时包含对象、场景、观看位置、光影、颜色、质地和呈示语境。只保存“好看”“高级”“像某品牌”，下次检索可能找回相似外观，却找不回解决问题的方法。

# 定义

> **可迁移的摄影知识**：一项在明确条件下关于观看关系的主张，连同它的来源、实现候选、适用边界、已知反例与检查办法。

比“提示词配方”多了条件，比“风格标签”多了因果与功能约束；允许不同对象、器材与工具采用不同实现，只要关键关系得以保留并重新检查。

# 四种保存对象

| 对象 | 保存什么 |
|---|---|
| **素材条目** | 实际图片、片段及其位置和版本 |
| **案例条目** | 任务、条件、选择、结果与证据 |
| **规则条目** | 从案例提炼的候选关系及其边界（见 [规则卡](/transfer/rule-card.md)） |
| **工作原则** | 怎样选择、测试和更新规则 |

素材不是案例，案例不是已验证规律，原则也不是任何场景都适用的命令。把四层合在一个长描述里，后续使用者很容易把推断当事实、把单例当通则。
