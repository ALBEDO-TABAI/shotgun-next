# Examples（虚构）：产品使用短片 → 乐器维护过程

| 来源中的角色或关系 | 目标中的对应 | 值得保留什么 | 必须重新解决什么 |
|---|---|---|---|
| 手指与皮肤接触 | 手与乐器表面接触 | 接触动作可辨、局部关系明确 | 接触尺度、反射、工具和安全边界 |
| 产品在后段完整显露 | 维护对象在后段获得完整定位 | 从局部经验到完整对象的认识 | 是否需要更早交代用途 |
| 亮带说明瓶体曲率 | 反射或明暗说明器物表面 | 表面外观帮助理解形状 | 不能照搬透明瓶体的透射效果 |
| 末段运动收敛 | 完成维护后保留稳定观察 | 让变化后的状态获得观看机会 | 稳定时长与前后段落如何衔接 |

映射成立的不是对象名称相同，而是**角色关系可能相似**。若乐器维护必须先理解操作顺序，延迟显示完整对象就可能不适合——关系相似不免除任务核查。

# 三种迁移结果

| 结果 | 条件 |
|---|---|
| **直接复用局部规则** | 任务和条件接近；仍需当前结果检查 |
| **保留关系、改写实现** | 功能相近，但对象、材料或资源不同 |
| **拒绝适用** | 新任务与规则前提冲突，或无法保住必要信息 |

第三种也是有价值的输出。只能推荐参考、从不说明不适用条件的知识库，容易把熟悉的形式套到所有项目。
