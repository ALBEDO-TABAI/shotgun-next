# 改写检索问题

| 外观式检索 | 任务式检索 |
|---|---|
| 找高级蓝色瓶子 | 找在曲面反射中保持标签可读、并允许物体小幅转动的案例 |
| 找孤独感 | 找人物离开后相机继续停留，并让环境获得独立作用的片段 |

感受词可以保留，但应配合任务、形式与条件。

# 至少比较一个异形同构案例和一个反例

（本包提案，不是实证保证。）

- **异形同构案例**：对象不同但关系相近，帮助摆脱对题材的依赖；
- **反例**：相似形式却不适合目标，帮助明确边界（例：延迟显露在情绪广告中值得探索，在紧急操作说明中可能妨碍理解）。

这与 05 模块的反固着建议一致，见 [设计固着](/theories/design-fixation.md)。

# 检索分数 ≠ 适用置信度

文本或图像检索的相似度只说明系统如何排列结果，不证明两个案例具有相同功能，也不能转化为创作成功概率。检索后核对：任务、材料、关系、时序、输出和失败条件。无法核对的条目保持为**候选参考**。
