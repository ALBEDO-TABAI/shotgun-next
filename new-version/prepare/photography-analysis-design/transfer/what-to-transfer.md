# 五种内容

| 内容 | 问题 |
|---|---|
| **观看功能** | 让观众能理解、等待、比较或感受什么 |
| **关系结构** | 哪些对象、空间和时间条件相互配合 |
| **实现机制** | 原案例已知或可能采用的光学、布光、调度、处理 |
| **表面特征** | 色彩、题材、纹理、造型等外观属性 |
| **条件与代价** | 哪些条件使关系成立，牺牲了哪些信息 |

# 三条关系

1. **同一功能可以有不同实现**：“主体与背景易区分”可由色彩、明暗、轮廓、遮挡、清晰度或空间安排实现（机制见 03 模块）。先问需要的是分离结果还是某种特定分离方式——若关键是人物与环境仍保持联系，过度虚化背景反而破坏任务。
2. **同一机制可以承担不同功能**：局部化画框可强调接触，也可隐瞒空间、形成图形或省略信息。只有“使用浅景深”的条目是操作建议，不是充分的摄影规律；规则卡必须包含任务条件。
3. **表面差异有时正是迁移失败的原因**：透明瓶换成不透明陶器，同一照明未必形成相同透射和边缘关系；平面包装换成曲面包装，文字与反射关系也会变 [1]。“迁移深层结构”不是忽略材料，而是**保留任务与关系，重新求解当前材料下的实现**。
