# 清单

| 表现 | 可能问题 | 有效的下一步 |
|---|---|---|
| 主题很宏大，场景很空 | 缺少可行动的矛盾 | 选择一个具体关系和事件，不先加解释台词 |
| 每个人都说同一种道理 | 人物只是作者传声筒 | 给各方真实目标、代价和不同知识 |
| 画面符合参考，意义却漂移 | 外观移植没有功能移植 | 重新写观看位置和信息任务 |
| 留白造成基础事件不可辨认 | 混淆事实和动机开放 | 补必要证据，保留解释空间 |
| 每次试映后完全改方向 | 未区分误解、偏好与任务变化 | 先给反馈分类，再判断是否改核心命题 |
| 导演用访谈意图反驳观众 | 意图被当成效果证明 | 分别记录目标与实际接受 |
| 商业内容令人感到硬塞 | 产品没有进入表达机制 | 重写动作或信息关系，而非只缩短露出 |
| "真实"成为冒险理由 | 把创作目标凌驾于参与者 | 改实现方式，不索取未经同意的真实痛苦 |
