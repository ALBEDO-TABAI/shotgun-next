# 清单

| 初始说法 | 更精确的研究问题 |
|---|---|
| 这个导演很冷峻 | 哪些时刻限制情绪接近？由表演、景别、声音还是反应分配形成？有何例外？ |
| 这个导演很会留白 | 具体省略了什么？理解仍依赖哪些线索？空缺可形成哪些不同解释？ |
| 这很有电影感 | 哪些可观察特征带来这个印象？是否只在截图中成立？ |
| 这个长镜头很真实 | 它保留了哪些行动连续性？又通过调度、焦点和声音排除了什么？ |
| 这明显在模仿某导演 | 是外观相似、组织规则相似，还是有史料支持的直接借鉴？ |
| 这种混搭不统一 | 哪些关系失配？是否存在可定位的分工或转换规则？ |
| 音乐把这里救活了 | 音乐具体增添了什么结构？是否承担本应由其他材料提供的必要信息？ |
| 观众一定会感动 | 这是创作目标、个人反应还是测量结果？哪些观看条件尚未核对？ |
