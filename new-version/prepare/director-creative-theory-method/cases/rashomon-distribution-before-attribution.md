# 情境

Redfern 的镜头分类案例比较四个主要叙述版本中的相关段落，说明纳入与排除范围，分析景别等变量；妻子的叙述部分显示出不同于其他部分的景别分布。

# 推演

- **方法价值**：不是从几张强烈画面概括作者，而是定义样本、比较相近事件、观察多个形式变量。
- **解释边界**：分布差异本身尚不证明某人物必然更真诚、更主观，或观众一定更同情她。

# 教训

首先分析同一作品为何在不同条件下改变形式，再考虑它是否属于跨作品的作者倾向。

# 适用边界

- 本包未独立验证 Redfern 的全部代码与公式；这是文献层事实。
