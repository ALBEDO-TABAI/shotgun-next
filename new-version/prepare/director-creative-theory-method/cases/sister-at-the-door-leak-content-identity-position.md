# 情境

三个版本都会出现"姐姐"这个信息，但错误并不相同。只检查剧本文字是否隐藏了身份，无法发现全部问题。

# 推演

| 版本 | 泄露发生在 |
|---|---|
| 甲：开头字幕标明"姐姐的脚步" | 信息身份 |
| 乙：无字幕，但提前插入她可辨识的照片与同一衣物 | 画面组合 |
| 丙：最后一句"你终于回来了"提前作声音引入 | 时间位置 |

审核时把线索沿时间排列，注明每条线索可能支持的判断。不是所有观众都会识别照片或衣物，写"可能提前支持身份推断"，不宣布所有人已经知道。

# 教训

部分观众提前猜中，不必立即加密。作品可能更关心重逢如何发生而非来者是谁；观众猜中身份仍可能等待人物反应。最终应修复的是与表达目标不相容的信息分配，而不是追求绝对无法猜中的答案——为阻止猜测删掉所有公平线索，反而使后来的解释失去依据。
