# 案例推演 · Case Studies

文献支持的制作证言案例与自拟教学案例（修理铺、洗衣店、母女告别、45秒洗护片等）。

# 01 导演风格识别
* [《法兰西特派》：变化的外观与保留的组织](french-dispatch-variation-retained-organization.md) - 依据 ASC 制作访谈：黑白／彩色与画幅变化的同时保留对称、深焦等构图倾向，导演预演与团队实施有具体环节；给出文献层事实、可提问题、不能推出的结论与可迁移原则。
* [母女送汤：同样暖色外观，三种不同的导演风格](mother-daughter-soup-three-directions.md) - 虚构练习：女儿离家、母亲装汤。方案A让观众等待人物自行完成关系转向；方案B让观众提前知道母亲已接受离开；方案C不让观众立刻决定这是关心还是控制。三者共享外观却在信息、行动、反应分配与声音关系上不同。
* [《罗生门》：先比较条件和分布，再解释作者](rashomon-distribution-before-attribution.md) - Redfern 的镜头分类案例比较四个叙述版本的景别分布，妻子叙述部分显示不同分布；方法价值在定义样本、比较相近事件、观察多变量，而分布差异本身不证明人物更真诚或观众更同情。

# 02 导演职责与跨部门整合
* [45 秒洗护品牌片：从诉求全部拉满到三段各有主要承担者](45-second-haircare-integration-decisions.md) - 虚构完整案例：清爽柔软有情绪有产品的需求下，摄影、美术、作曲、品牌诉求互相抵消；导演重写任务，指定三段职责，部门提出替代方案，预演暴露问题，现场变更传递给剪辑，最终按关系检查。
* [《赤裸》：一次风格决定如何跨部门实现](naked-dick-pope-cross-department-look.md) - 据 Dick Pope 访谈：视觉处理经历摄影测试，与 Alison Chitty 的颜色板及服化条件共同协调，修复时又调整了部分色偏；外观来自流程互动并随版本变化。
* [修理铺争议会议：从谁的方案更好到此段真正的变化是什么](radio-repair-shop-dispute-meeting.md) - 虚构广告：顾客递出旧收音机，修理员准备接下。创意要传承、品牌要服务信息、演员怕仪式化、摄影要运动、声音要先听异常；导演重述问题，比较两个候选，给出有限决定并传给剪辑，记录分歧。

# 03 创作出发点与导演意图
* [晾衣绳：从感官起点发展作品，而不是替它补出假主题](clothesline-sensory-starting-point.md) - 虚构：被晾衣绳上布料的风、重量、透光与间歇吸引，想做无对白影像。先记录实际变化，提几个形式问题，再比较A保留时间连续、B跨时间剪辑对应、C加入劳动痕迹三种方向，各有主要未知。
* [同一个修理铺，三个不同创作出发点](repair-shop-three-starting-points.md) - 虚构：年轻人送坏台灯到即将关门的修理铺，修理者发现问题很小却迟迟不说。路径A尊严与被需要、路径B知识差与交易信任、路径C手工过程与时间感——同一场地道具情节，不同信息分配、表演任务、拍摄重点、声音与评价标准。

# 04 人物关系、表演与对白
* [《第一头牛》：真实任务怎样支持表演](first-cow-real-task-supports-performance.md) - Reichardt 谈准备时提及演员学习具体生活任务使注意集中在操作本身；可迁移练习是先学会一个安全的相关动作再加入关系任务；技术不熟占满注意时简化、训练或调整，而非赞扬笨拙才真实。
* [修理铺的一场谈话：从宣布传承到检查权与署名责任的移交](repair-shop-apprentice-handover.md) - 虚构：学徒交回修好的台灯希望得到确认，师傅即将把店交给他却没说破。初稿把关系变化直接总结完；重新设计为翻转底座等检查、你试过多久、交付单移过去；三种试演是关系解释不同而非强度不同。
* [合租者与打包的杯子：把一场对话拆成行动交换，而不是情绪曲线](roommates-packed-cup-action-exchange.md) - 虚构：甲打算搬走，乙发现已打包的杯子。五轮表格列表面行为、甲乙可能在做什么、导演应观察的反馈；转折可能是杯子是否被再次拿走；不同阶段承担掩饰、试探、确认、退出。

# 05 世界观、空间与置景
* [夜间借书站的三条规则：世界观从行动阻力进入，世界不能为结尾临时变法](night-book-exchange-station-three-rules.md) - 虚构近未来：凭借阅卡交换书、某书架只接受修补完整的书、唯一明亮工作台由陌生人共享。规则与置景共同设计，三种导演方案对美术要求不同，声音与提示音的泄露问题，结尾变化须有可理解条件；附三种删改的状态对照测试。
* [夜间洗衣店的空间设计：让空间承担冲突，而不是让人物解释冲突](night-laundromat-space-design.md) - 虚构：店员即将关店，顾客发现衣服被误拿。先定生活逻辑，用柜台或折衣台决定制度距离还是临时合作，关灯成为营业与否的行动，烘干机噪声改变交流条件，储物袋边界有限变化；附平面与 AI 变体。
* [《寄生虫》的住宅：同时像有人居住的房子并满足拍摄需求](parasite-house-living-and-shooting.md) - 导演与美术指导参与的制作访谈说明客厅与庭院关系经过专门考虑；本包只据此提出方法问题——空间如何同时支持生活、行动和观看，不声称重做建筑分析，不把上下关系自动归结为象征。

# 06 信息分配、视点与留白
* [撤展时最后一幅画为什么没有被取下：同一事件表，四种信息方案](gallery-last-painting-four-versions.md) - 虚构：年轻工作人员要取下最后一幅画，年长清洁人员让他稍等——她不是作者也无产权，想等一位即将到达的人看最后一眼。A提前知道等人、B只知她没权力、C结尾才发现她非作者、D不揭示等待者是谁。
* [门外的姐姐：把一次意外泄露区分为内容、身份与位置问题](sister-at-the-door-leak-content-identity-position.md) - 虚构片段希望先听见门外声音再知道来者是离家多年的姐姐。版本甲字幕标明姐姐的脚步（身份泄露）；版本乙提前插入可辨识照片与同一衣物（画面组合泄露）；版本丙把你终于回来了提前作声音引入（时间位置泄露）。
* [一把备用钥匙的三种信息结构](spare-key-three-information-structures.md) - 虚构：搬走的一方把钥匙留在桌上，留下的人发现还有另一把备用钥匙。先定事实再写方案：A观众提前看见、B与人物同时发现、C不给最终含义；共同拍摄要求与两组测试问题。

# 07 桥段、场景行动与情节
* [一张成人毕业合照：感谢怎样有时变成对人的强行定义](graduation-group-photo-three-versions.md) - 虚构：摄影师赶时间，某学员每次被安排到中心都退到边缘，负责人认为他应被特别感谢。版本A感谢必须经过协商、B保留未解决的分歧、C喜剧组织；三轮检查桥段是否只靠作者临时安排成立。
* [雨伞与最后一班车：让一次实际合作先于语言和解](umbrella-and-last-bus.md) - 虚构：A 等末班车手拿怕淋湿的纸盒，B 带伞赶到，两人刚有矛盾。初稿递伞—拒绝—道歉—原谅太薄；建立纸盒条件后三次尝试：把帮助当和解、不要求接受者立刻回应、外部任务迫使协作；结尾保留已能合作但关系未解决。

# 08 叙事顺序、时间与节奏
* [45 秒产品片的时间设计练习；短版与循环作品的时间逻辑](45-second-product-film-time-design.md) - 四项任务初始分配 8/14/13/10 秒只是练习条件；使用动作需更长时先看其他段落是否重复而非强迫演员加速；15 秒版重新确定主要任务而非平均缩短；循环作品测试不同入口；指定慢节奏不代表组织了等待。
* [一只失而复得的旅行箱：同一事件表的四种方案，与拿错箱子的三种顺序](lost-suitcase-four-orderings.md) - E1–E6 事件表；A顺序呈现但限制信息、B提前展示另一条行动线、C从物理问题已解决开始、D重复同一瞬间；补充：拿错箱子四事件的三种顺序，为时长分配写理由而非均分，顺序修改后重新核对指代。
* [同一组修理铺事件的三种编排](repair-shop-three-orderings.md) - 基础事实：师傅准备交接、学徒误以为不被信任、争执、师傅把钥匙放进工具箱、学徒发现。版本A按事件推进、B先给发现后调查原因、C观众先知道师傅的决定；不同顺序要求不同表演重点与声音处理。

# 09 调度、摄影与画面
* [Deakins 与《金翅雀》《1917》：同一摄影师面对不同项目](deakins-goldfinch-1917-production-testimony.md) - ASC 文章明确《1917》模拟连续长镜头而非物理上不间断拍摄；用制作证言区分成片连续感、拍摄单元与实现方式；不因作品看似不剪就把所有时间与视点变化当自然发生；同一摄影师不应被归为只会一套外观。
* [母女告别的三个摄影方案](mother-daughter-farewell-three-camera-plans.md) - 同一事件：女儿准备离开，母亲端汤挽留，女儿拒绝坐下，母亲换便携容器，女儿接过离开。A共同空间中的关系变化、B以女儿的接收为中心、C以母亲的让步为中心；比较核心是谁的经验展开、哪些信息延迟、余波由谁承受。
* [三人旧照片场景：四个摄影方案与一份覆盖矩阵](three-person-old-photo-camera-plans.md) - 甲拿出旧照片希望乙说明身份，乙知道但不愿回答，丙不知情正在整理；A共同空间中的信息不对称、B限制在丙的理解范围、C提前让观众看到照片、D不展示照片内容；覆盖矩阵按必要关系而非正反打数量；用一个改变检查整套机位。

# 10 灯光、色彩与氛围
* [深夜餐馆打烊：每次光变可以是人与人之间的行动](late-night-diner-closing-light-changes.md) - 服务员关掉部分灯只保留有客人的区域，客人意识到停留太久准备离开，服务员又把门口灯打开方便整理；A版光变作为明确事件被注意到并反应；B版不突出开关只让空间逐渐改变；哪种合适取决于研究人与人还是场所关闭过程。
* [《赤裸》：外观来自跨部门试验——你希望的外观是否经过真实材料与表演环境的联合验证](naked-pope-look-joint-verification.md) - Dick Pope 谈 Naked 及其修复时描述摄影测试与美术服装化妆的配合，早期环境色处理也涉及后续版本判断；迁移的不是胶片工艺秘诀而是协作问题；访谈说明参与者报告的过程，不据此声称逐镜头色彩测量。
* [一瓶透明护肤精华的三种任务：使用镜头、材料近观、包装确认；测试矩阵](transparent-serum-three-tasks-joint-test.md) - 透明瓶浅色标签半透明液体；使用镜头优先手的握持与标签遮蔽，辨识与自然使用冲突时让相邻镜头承担；材料近观明确实际演示与艺术隐喻；包装确认保证形体颜色文字准确；四行测试矩阵：保持条件、比较变量、首要观察、不应直接推断。
* [同一个暖色厨房，庇护与束缚怎样产生](warm-kitchen-shelter-vs-constraint.md) - 年轻人准备离家，家人在厨房装食物，场景服装主色不变；A关心提供可以离开的支持：行动被允许、身体有余地、关系继续存在；B关心要求对方留在被安排的位置：每次离桌都被安排新小动作，出口较少被说明；比较时先问人物做了什么。

# 11 声音设计与音乐
* [深夜修理店：三种听觉组织，与一份五十秒声画交接草案](late-night-repair-shop-three-auditory-organizations.md) - 店员准备关门，顾客拿来旧收音机，店员犹豫后重新坐下；A工作时间被一件具体事情重新打开、B让顾客的记忆进入但不冒充客观现场、C保留动机的不确定性；五十秒交接表五列：画面行动、声音前景、被保留的背景、不希望提前造成的判断。

# 12 整体成片与媒介适配
* [一条 60 秒影片如何改成 30、15 与 6 秒：重建承诺而不是机械缩短；三种压缩方法](60-to-30-15-6-second-versions.md) - 洗护品牌：从拥挤工作日回到洗护时间；30 秒保留一条完整变化而非所有元素各减半；15 秒重新选择一个承诺；6 秒明确辨识任务且声音重新设计；平面版与竖版；用该版本首次观看者验证；三种压缩：保留同一变化减少旁枝、只保留一个有意义瞬间、建立新的形式结构。

# 13 导演个性、表达与伦理
* [一个导演如何保留个人关切而不复制外观：家庭短片、护肤品牌平面、无人物的材料影像](one-director-three-projects-keep-concern-not-look.md) - 虚构倾向：人们如何通过实际劳动表达不愿说出的关心；A保留动作完成过程让情绪从关系变化中出现；B不照搬厨房暖光慢节奏，把关切转成护理是一种具体而有选择权的行动；C可暂时转为对修复保留细节的研究，或承认本项目主要探索形式；结论承认第三项关系较弱。
* [当参与者认为剪辑改变了自己的行为含义：修理店店员的异议](repair-shop-clerk-edit-changed-meaning.md) - 虚构纪录：店员因机器噪声没听清顾客问题停顿后要求再说一遍，粗剪把问题接到他另一时刻的沉默表情并配强调迟疑的音乐，看起来像拒绝帮助；先区分是不喜欢形象还是剪辑建立了不同因果；备选：恢复时间关系、增加可听见的机器环境、换相邻镜头、说明形式身份；新用途需重新核对。

# 14 拉片研究与迭代工作流
* [把一份模糊简报变成可验证的导演方案：45 秒洗护品牌影像的八步](45-second-haircare-brief-to-verifiable-plan.md) - 简报轻盈清爽有生活感另需 15 秒短版与主视觉，预算产品事实投放限制未给；界定已知与未知；两个本质不同的方向（A人物回到洗护时间的行动变化；B水流泡沫发丝的形态接续）；选 A 写核心关系；按模块分配工作；最小试验；预设判读方式；记录可能修改与影响；交付条件。
