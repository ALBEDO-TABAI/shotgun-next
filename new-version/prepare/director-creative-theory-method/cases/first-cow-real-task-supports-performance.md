# 情境

Reichardt 在访谈中谈到让演员学习具体工作，使注意落在正在做的事情上。本包只使用这一实践主张，不把记者的风格概括当成实验结论，也不建议复制不必要的不舒适。

# 推演

可迁移练习：让演员先学会一个安全、与角色有关的动作，再把关系任务加入其中——一边包好物件，一边设法结束谈话。动作提供节奏和限制，但导演仍要判断它是否遮蔽重要关系。

若演员技术不熟导致全部注意被操作占满，场景可能反而没有倾听。此时简化道具、增加训练或调整动作。

# 教训

真实任务支持表演，不证明"真实劳动越艰苦表演越好"。
