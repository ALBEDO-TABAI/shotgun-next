# 情境

决策练习，不提供普遍法律意见，不预设参与者自动拥有最终剪辑权。

# 推演

1. **区分异议内容**：是他不喜欢自己的形象，还是剪辑建立了与原事件不同的因果和态度？回看素材、时间关系与录音，而不是马上把异议归为参与者想控制作品。
2. 存在事实性的误接→认真修正相应关系。作品明确采用重构或主观叙述→检查观众得到什么提示，以及参与者原先理解的拍摄和使用范围。形式选择的复杂性不能消除说明责任。
3. 争议属于解释而非可直接核实的事件错误→记录双方理解，检查上下文是否提供了公平而足够的信息，评估不同剪法对真实人物的影响。保持创作判断不等于拒绝倾听；认真倾听也不意味着所有异议只能由删除解决。
4. **备选方案**：恢复原有问题和回应的时间关系；保留停顿但增加可听见的机器环境；换用不制造特定态度的相邻镜头；项目确实需要重构时清楚说明形式身份。每个方案重新检查实际声画。
5. **传播范围**：原本在受限场合展示的素材被剪成独立短视频传播时，语境和被识别的可能性不同。把新用途作为需要核对的条件，不默认最初同意覆盖任何未来组合。
