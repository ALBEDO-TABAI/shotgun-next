# 情境

Deakins 在关于《金翅雀》和《1917》的访谈中讨论不同项目条件；文章明确《1917》模拟连续长镜头，而不是一条从头到尾不间断的物理镜头。

# 推演

- 区分**成片连续感、拍摄单元、实现方式**三层。
- 进一步研究核对具体移动、动作、遮挡、衔接与声音，不把"长镜头"直接翻译成沉浸、真实或作者能力。
- 不同影片中的同一摄影师不应被归为只会一套外观。

# 教训

制作证言可以帮助区分表象与制作事实，但只覆盖被访者谈到的部分。
