# 情境

起点是风、重量、透光和间歇，不必立即解释为"人生起伏"。先记录：同一种风如何使不同材质产生不同响应；布料什么时候彼此遮挡；静止与运动怎样交替；声音是否暴露画面外的环境。

再提创作问题：研究同一力量的不同结果？让观众从辨认衣物转向注意材料？通过重复建立一个可以等待的变化？这些是形式问题，并不比主题口号低级。

# 推演

| 方向 | 处理 | 主要未知 |
|---|---|---|
| A 保留时间连续 | 让变化在等待中发生 | 画面内差异是否足以维持观看，而不是有没有"剧情高潮" |
| B 跨时间剪辑 | 建立明暗、形状和声音的对应 | 对照能否被感知，还是只存在于创作者的表格里 |
| C 加入劳动痕迹 | 晾晒顺序、补丁与收回动作 | 引入生活解释后必须重新考虑人物与材料关系，不能直接延续纯形式实验的结论 |

# 教训

选哪个方向可根据兴趣、材料与目标讨论，不必编造统一主题证明选择正确。若创作中出现新意义，记录其形成阶段，不事后宣称从第一天已全部预见。
