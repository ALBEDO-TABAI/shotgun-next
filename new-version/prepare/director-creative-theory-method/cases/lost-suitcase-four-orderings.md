# 情境

| 事件 | 内容 | 会改变什么 |
|---|---|---|
| E1 | 甲发现旅行箱不见 | 行动目标形成 |
| E2 | 工作人员乙找到箱子 | 观众可提前获得另一条信息 |
| E3 | 甲误以为朋友丢下自己 | 人物解释偏差 |
| E4 | 朋友其实去帮助寻找 | 重新判断关系的前提 |
| E5 | 箱子被送到甲面前 | 物理问题解决 |
| E6 | 甲看见朋友手中的寻物记录 | 对朋友的理解改变 |

# 推演

- **A 顺序呈现但限制信息**：E1、E3、E5、E6，E2 与 E4 由后来线索补足。不必叫倒叙，起作用的是信息限制。
- **B 提前展示另一条行动线**：E1–E6 全序。观众比甲知道得多，E6 不再是反转而是人物追上观众的知识；剪辑不能仍把 E6 当巨大揭晓，音乐、停顿和反应任务随之改变。
- **C 从物理问题已解决开始**：先 E5 但保留甲不轻松的反应，再回到 E1、E3，通过 E6 重新解释。收益是重点从物件悬念转向人物理解；代价是观众需重建时间，可能误以为箱子有其他秘密。
- **D 重复同一瞬间**：两次呈现 E5，第二次增加朋友的行动或甲未注意的细节。若第二次改变了关键动作，需说明是新视角、主观记忆还是事件本身不可靠，不能篡改先前事实却只称"另一种角度"。

## 拿错箱子的三种顺序

四事件：发现拿错→打开夹层看见修理单→沿地址返回小店→得知对方也在找自己的箱子。顺序一按先后，观众跟随解决问题；顺序二先呈现交换箱子的结尾，重点转向误会怎样发生；顺序三先给地址再显示匆忙返程，增强原因未知但增加辨认目标的负担。若顺序三让观众把人物理解成追赶欠款者，后来揭示是有意的喜剧反转还是不必要误导，需结合整体语气判断——不能仅因观众先猜错就宣布叙述巧妙。

**为时长写理由**：先不写每镜几秒，写哪些动作必须有足够辨认时间（发现标签不对、决定开箱、读地址、改变路线）；读地址需认出街名就不能只按音乐节拍一闪而过。"留得久一些"要明确等待的对象。

**顺序修改后重新核对**："上次""还是老样子"可能失去参照；反复动作可能从回响变成初次建立。连带核对知识前提、语言指代、道具状态、人物关系、音乐重复。

# 教训

时间设计的最终理由可以很朴素："这里让观众先理解错误，再等待人物如何处理，而不是先制造一个并无后续价值的谜。"
