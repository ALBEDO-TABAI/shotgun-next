# 最小输入

项目目的与媒介；当前材料及版本；关键主创与批准关系；已知事实与限制；争议点；本轮需要决定的范围。未知不等于必须暂停，可先处理不依赖未知的信息，但不得替用户批准预算、授权或核心内容。

# 处理

辨认判断层级，找出相互依赖的部门；把形容词转成可观察关系；生成少量真实不同的方案；比较收益、代价、验证成本；记录当前决定；检查相关执行材料是否消费了该决定。

# 输出

一页导演任务说明；跨部门共同问题表；关键取舍记录；可执行的试验；当前版本与批准边界；下一责任人和下一动作。

# 质量门禁

- 只有职责名称、没有共同问题，不足以交付。
- 决定没有进入下游执行，不视为完成。
- 声称导演拥有未确认权力，不通过。
- 把演员真实边界当作可协商的美学成本，不通过。
- 以"整体感"回避具体矛盾，需重新诊断。
- 两人项目允许把表格缩成几段文字；完整的是决定链，不是文档体积。
