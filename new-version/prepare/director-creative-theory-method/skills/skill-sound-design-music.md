# 最小输入

作品任务、场景行动、信息图、可用画面与音轨、观看条件、音乐与录音资源、授权和交付限制。

# 处理

建立听觉视点→识别声音事件→明确音乐任务→设计前景接力→制作少量对照→联合判断声画→核对字幕及输出→保存版本关系。

# 输出

听觉阐述；声音事件表；配乐任务书；入点退出表；需要拍摄或补录的素材；对照结果；交付检查与未知项。

# 质量门禁

- 听觉身份与必要信息可读。
- 密度与主次经过整体检查。
- 研究结论没有超出样本和任务。
- 缺失音轨时不伪装已经分析。
- 声音素材与参考用途不混淆。
- 版本变化后时间点被重新核对。
