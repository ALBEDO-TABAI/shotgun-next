# 最小输入

段落在全片的任务、人物及已知信息、初始与目标状态、空间与资源、现有文本或素材、媒介类型、伦理及事实限制。

# 处理

区分点子与事件→选择适用机制→建立条件与行动→识别策略变化与关键选择→检查因果和后果→形成有实质区别的变体→与表演、空间、摄影和声音共同试验。

# 输出

桥段说明；前后状态表；行动节拍；必要铺垫；声画职责；替代方案；失败风险与小规模验证。

# 质量门禁

- 不把所有作品强制为目标—障碍—胜利。
- 不把角色作恶或痛苦作为唯一强度来源。
- 不让不存在的规则临时解决问题。
- 不以"观众会懂"掩盖缺失前提。
- 没有素材时只评价潜在结构，不宣称成片情绪已成立。
