# 方法 · Methods

可执行的步骤与流程：研究、排练、测试、交接、诊断、改写。

# 01 导演风格识别
* [从特征清单到条件性创作规则：分布、关系、内外基线与缺席证据](conditional-style-rule.md) - 记录分布而非只记录用什么；关系比单项频率重要；默认规则与例外一起构成风格；没有使用也需要证据；附推荐规则句式。
* [风格研究十步流程：从定义问题到转译原则](style-research-ten-step-workflow.md) - 定义问题与比较对象→语料版本清单→先完整体验再拆解→可复核编码→功能假设与替代解释→比较相似表达问题→查反例→调查生成条件→有范围的画像→可测试原则。

# 02 导演职责与跨部门整合
* [有边界的反馈环：下游发现可以改变上游，但必须指明改了哪条已确认判断](bounded-feedback-loop.md) - 由 Mike Leigh 关于观察、研究、写作、排练与导演相互联系的证言出发，提出演员／空间／声音测试反向修正剧本与场景的规则：说明改动对象与重新批准人。
* [根据决定的可逆性安排讨论顺序](decision-reversibility-ordering.md) - 探索决定可容忍分歧并存；锁定资源的承诺决定要提前暴露跨部门影响；影响真实关系或外部承诺的决定不因文件可重导出就算可逆；对未解问题建立有限回退条件。
* [拍摄现场：判断、授权与变更](on-set-judgment-authorization-change.md) - 一轮指导最好只改变一个主要变量；通过描述问题反馈而不做人格结论；保留现场发现但不偷偷重写作品；安全和同意不是创作可交易的筹码。
* [后期：导演还在重新构成作品](post-production-director-reconstitution.md) - 不让拍摄记忆替代成片判断；用整段关系评价素材；声音不能等画面全定才第一次参与；有条件批准必须带条件关闭，批准只对具体版本与范围成立。
* [创作前期：把想象转成可比较的方案](preproduction-comparable-plans.md) - 导演阐述同时包含肯定与否定；参考材料拆成保留／不借用／待验证；先测试最可能失败的关系；计划保留的是选择权而不是拍摄数量。
* [导演如何提出可工作的修改意见](workable-revision-notes.md) - 有效意见包含观察位置、具体问题、影响的关系、希望尝试的变化、暂时不动的部分；没有感情／摄影太花／音乐太满的三种改写；意见仍是待检验假设。

# 03 创作出发点与导演意图
* [把商业形容词变成可以讨论的导演命题：词语展开表](commercial-adjectives-to-propositions.md) - 自然、专业、轻盈、有记忆点各可指多种含义；为每个词写本项目定义、不表示什么、可观察证据、需外部确认的产品事实、可能误读；再提出两条组织上真正不同的方向做低成本预演。
* [导演阐述：一种能被其他人使用的七段式工作文本](director-statement-seven-paragraphs.md) - 不是宣传文案也不是技术清单；先写功能再写实现假设；留出发现区；七段：注意到什么、让什么关系发生、观众位置、组织原则、最易做错的方向、还需发现什么、任务与现实条件。
* [意图假设树：把错误归因的路堵住，让竞争性解释接受证据区分](intent-hypothesis-tree.md) - 对一个选择列出多个解释（功能A/B/C与条件D），按镜头声音事实→局部关系→同片比较→制作资料的顺序核对；可反驳性指知道什么新证据会缩小或撤回判断；防止克制循环。
* [检验体验假设，而不把试映变成审美投票](testing-experience-hypotheses.md) - 先问理解再问喜欢；把观众差异当材料；不用创作者解释救回测试；一次测试只能支持有限结论，比较版本要考虑顺序、熟悉度、设备、字幕、音量与画幅。

# 04 人物关系、表演与对白
* [选角：选择关系潜力，而非只选单人表现](casting-for-relational-potential.md) - 试镜观察如何接收新要求、倾听对手、在相同台词下改变行动；化学反应不等于亲近；不要求演员证明亲历创伤；非职业者须知道自己在表演、重演还是提供生活材料；平面选角测试人与服装产品姿态的关系。
* [对白修改的四层检验：信息、关系、可说性、时序](dialogue-revision-four-layer-check.md) - 这句话提供什么必要事实；改变什么关系；让演员真正说出来检查呼吸动作对象语气；何时回答本身改变含义——立刻答应、确认后答应、被放弃后才答应是三种关系。
* [排练：分开发现关系、校准条件、验证执行](rehearsal-explore-confirm-prepare.md) - 文本讨论先保留疑问；用完整行动发现节奏；即兴有目的范围与结束条件；从可活转向可拍；连续性不是复制微表情；一个有限四轮排练设计；排练后保存触发、行动顺序、道具状态与关系。
* [把结果型指令改成可执行工作](result-directives-to-workable-actions.md) - 再伤心一点、要更有压迫感、演得自然些、这里要很暧昧、再高级一点、不要演——六种结果型要求为何难以工作，以及可尝试的改写；改写是候选而非标准答案。

# 05 世界观、空间与置景
* [世界如何被介绍：从一次使用、一次失灵、两个使用者的差异、局部逐步扩展进入](introducing-the-world.md) - 让观众跟随人物完成一次任务；平常不被解释的规则在出错时显形，但故障要有后果；同一房间对主人与访客不同；先给工作台再显示它属于哪里，检查延迟的收益。
* [世界规则不是资料越多越好：写成条件—行动—后果，设计有代价的例外，分三层维护](world-rules-that-affect-action.md) - 先记录会影响行动的规则；最小句式：在什么条件下谁能做什么、付出什么、失败后发生什么、谁知道；例外比常态更需设计；团队知识可多于观众知识；核心规则／局部状态／背景细节三层。

# 06 信息分配、视点与留白
* [如何诊断看不懂](diagnosing-i-dont-get-it.md) - 看不懂可能是没看到线索、看到却不认识、知道事实不明关系、明白关系不理解选择、理解但不认同；顺序询问看到什么、说明什么、人物在做什么、还想知道什么、是否觉得作品需要回答；不在测试后立即教会答案；分别记录初看与重看。
* [让信息出现在人物本来就会做的事情中：四种嵌入方式](embedding-information-in-what-characters-do.md) - 误用后的纠正、请求中的条件、行动中的失败、后果中的发现；信息自然嵌入不等于永远不说，关键是出现具有当前行动需求；说明型广告、纪录讲述或实验论述中直接说清本来就合适。
* [最小可理解信息与揭示依赖图：先维护因果和行动](minimum-intelligible-information-and-reveal-dependency.md) - 在当前段落结束前哪些内容若未被理解下一段就无法工作；最小不是越少越好；给关键事实编号画逻辑依赖；三类依赖（理解、情感、形式）修复方式不同；可替代与不可替代的线索。
* [声音能保留画面之外的知识；字幕怎样描述而不提前泄露](sound-keeps-offscreen-knowledge-and-captions.md) - 声音让观众先知道某人到了、设备仍在运行；但音乐可能提前给沉默动作定性，是否导向应在信息设计时决定；关键线索只能被听见时检查投放与无障碍；未确认声源时写远处传来敲击声而非人物姓名。

# 07 桥段、场景行动与情节
* [因果不是然后又发生了一件事：区分联系、删除与替换检查、不用巧合替代人物决定](causality-checks.md) - 条件联系、动机联系、事件联系、形式关系不能互相冒充；删掉前一件事后一件事是否仍同样发生；换人物地点物件是否毫无差别；检查结尾来自人物选择、先前条件、外部偶然还是形式中断。
* [非叙事与产品段落的桥段设计：诗性和材料段落怎样拥有结构](non-narrative-material-setpiece.md) - 没有主人公也可设计初始状态、变化规则、重复与差异、一次显著偏离、收束方式；变化对象转为形态方向密度尺度速度声画联系；形式因果可能被理解为现实因果；非叙事桥段检验表。
* [桥段如何在空间中获得具体性；动作经济不等于信息过载](setpiece-in-space.md) - 先改变一个空间条件观察人物是否必须采用新策略：无法直接递交需经第三人、必须保持手上任务、谈话可能被听见；不让所有空间像剧情机关；一个动作承担太多信息可能让观众无法分辨重点。
* [桥段重写的四种手术：删掉解释保留行动、改变触发不扩大结果、缩小承诺、改变承受者](setpiece-rewrite-four-surgeries.md) - 关系已可见却被对白反复总结→删解释但查必要事实；转向突然→让前面某个回应更有力而非结尾哭更强；短时间无法可信完成巨变→彻底和解改为愿意共同处理一件小事；只关心行动者顿悟→重新分配余波时间。
* [从桥段到场景的协作顺序；桥段的成本、拍摄风险与替代实现](setpiece-to-scene-collaboration-order.md) - 编剧定前后状态→演员测试可执行→美术安排空间道具→摄影确认观看机会→声音确定画外与节奏→粗剪检查；顺序可往返但追踪同一目标；明确不可替代的是具体动作还是它产生的关系；先验证最可能失败的因果。

# 08 叙事顺序、时间与节奏
* [回忆不是统一的视觉外观：六个决定与长度代价](flashback-design-decisions.md) - 谁在回忆、覆盖多少时间、哪些细节可知、如何进入、何时退出、回到当下时发生了什么变化；不必黑白柔焦慢动作也不自动保证准确；回忆越长当下问题越易被搁置，用未完成动作或声音维持联系。
* [节奏问题的诊断树：慢与太快各有多种原因](rhythm-diagnosis-tree.md) - 观众说慢先问在哪一段开始等待、等待什么；再查必要信息是否早已给完、人物是否重复策略、镜头有无新注意对象、声音是否填平时间、前段是否已完成同样功能；太快可能是知识更新过密、空间标记不足或字幕与画面争夺注意。

# 09 调度、摄影与画面
* [摄影反向分析的记录方法：先可观察特征，再可能作用，最后长期倾向](reverse-analysis-recording-cinematography.md) - 记录位置、进出、焦点变化、运动、画外声、切点和前后联系；只看截图时明确不能确认运动剪辑时长声画；缺元数据不给唯一焦距或机型；剧照不等于成片取景，预告不等于正片剪辑；不用这像某导演代替证据。
* [从分镜表到现场，哪些信息必须补全；一个简化的现场检验顺序](storyboard-to-set-what-to-complete.md) - 分镜未必包含演员何时知道什么、道具状态变化、光线是否允许路线、声音是否需提示、切换后空间是否可读；AI 分镜尤需检查连续镜头是否同一空间与人物状态；顺序：安全→人物真实回应→关键行动可被保留→光声反射空间→形式是否符合方向。

# 10 灯光、色彩与氛围
* [从创作问题到灯光方案的可执行流程：观看任务→空间时间逻辑→少量对照→联合测试→完整动作与前后镜头→执行与回退→输出环境复核](lighting-plan-executable-workflow.md) - 先写不超过几个关键关系的观看任务；标记日夜窗门实践光源路线机位与相邻镜头延续；不同时做十种风格；道具服装化妆动作运动声音接近实际；记录不可牺牲的关系而非把设备设置变成权威；技术验收与创作验收分别记录。
* [把灯光参考拆成能被讨论的关系：直接看见的现象、真正想借鉴的关系、不想借用的表面、无法确认的实现条件](lighting-reference-into-discussable-relations.md) - 脸部一侧较少细节是可观察描述，只用一盏灯不是仅凭成片能确认的事实；参考的时间缺口：截图不说明转身后是否仍在同一光区；传播链改变颜色亮度；把一只透明瓶的参考改写成可验证的灯光问题。

# 11 声音设计与音乐
* [与作曲者协作：把任务写清楚，同时保留音乐的发现空间；不让临时音乐悄悄成为不可挑战的结构](composer-brief-fixed-vs-explorable.md) - 不可变的戏剧条件（决定前不以完成感宣布结果、低声对白可理解、结尾转入下一场、不暗示不存在的胜利灾难）与可探索的音乐条件分开；克制要拆解；参考音乐标三层；填写过的任务示例；临时音乐依赖清点。
* [声音密度与前景管理：强烈的整体不等于全部声部都强；前景接力](foreground-relay-density-management.md) - Murch 的混音经验不转写为认知上限；一句关键话在前，动作声确认变化，音乐接住余波，环境始终提供空间但不必每刻同样明显；多层同时争夺注意时增加每层清晰度只会更乱，先定主次；安静要具体说明是哪一种。
* [做声画对照时，移除一条轨道不是天然公平的实验：诊断性拆分与完成度相近的方案比较](sound-comparison-diagnostic-vs-complete.md) - Thom 2019：其他声音已与音乐相互平衡，直接拿掉音乐使剩余部分处于不利状态；诊断性拆分暴露依赖但不评价最终无音乐方案；完成度相近比较的是两种整体方案而非单一变量；记录播放顺序音量设备字幕与是否已知情节；具体诊断路径。
* [声音必须提前进入哪些制作环节：写作与勘景、排练与拍摄、剪辑与配乐、混音与交付](sound-enters-production-stages.md) - 检查故事是否给声音留下发现和变化的机会；勘景记录持续噪声可控程度与录音风险；确认声音动作可执行、演员是否需听到提示；不为真实惊吓对演员使用未经同意的突然刺激；临时音乐必须标为临时；交付数值按实际要求核对。

# 12 整体成片与媒介适配
* [从一条修改意见，追踪它实际影响了哪些交付物；修改关闭需要证据](change-impact-tracking-across-deliverables.md) - 产品名称从第 20 秒提前到第 8 秒：信息顺序、剪辑节奏、声音与音乐、文案与字幕、竖版与短版、审批与发布各需核对什么、不应默认什么；修改记录写成决定编号＋受影响版本＋未影响项；已处理至少对应一个可定位版本和检查结果，否则是待审、阻塞或暂缓。
* [剪辑阶段：每个阶段验证不同的问题；粗剪、精剪与完成版的反馈不应使用同一种语言](editing-stages-verify-different-questions.md) - 素材整理先确保版本条次同步可追踪，不在身份不明时下演员没演出来的结论；结构剪辑用变化影响而非删了多少秒记录；细化比较准备与接收的时间，细剪不只盯切点；画面锁定是生产约定不是真理，持续修改要有问题范围责任与停止条件；三类占位：纯外观、理解性、体验性。
* [返工诊断：把修改放回正确层级；后期评审中的争议怎样从偏好变成可处理问题](rework-diagnosis-correct-layer.md) - 结尾不感人可能来自决定缺依据、音乐过早解决或观看者不认同表达；最短因果说明：观察到什么→影响哪个任务→可能来自哪些层→最小可比较修改→哪些下游更新；记录不修改的理由；太慢太广告太文艺先保留为反馈追问区间与损失；有时保留两种候选而非折中。
* [试映与反馈：先知道在测试什么](test-screening-know-what-you-test.md) - 粗剪讨论可发现理解障碍但不是自动成立的观众研究；参与者是否熟悉项目、知道意图、看过旧版都影响条件；先复述事件与注意位置，再讨论解释，最后问偏好，把没看懂与理解了但不喜欢分开；A/B 至少说明变量、设备音量、次序、问题暗示；不让便利样本生成 90% 会被打动。

# 13 导演个性、表达与伦理
* [建立创作者自我复盘，而不是不断确认自己的风格标签](creator-self-review-page.md) - 每个项目结束后留一页，重点不是获奖传播好评而是判断怎样形成：一个最终保留的冒险选择（原先希望完成什么、材料提供了什么、哪些反馈支持或修正、代价是否值得）；一个最终放弃的个人习惯；一次来自合作者的改变。
* [怎样形成不空泛的批评：具体选择→在作品中的关系→可能收益→代价或盲点→对照或反例→评价范围](criticism-that-is-not-vague.md) - 示例：本片多次在争执后离开受伤者转向解释实施者动机，可能增加行动者复杂性也减少后果被经历的时间；太自恋很有灵气没有温度可表达感受但不能承担分析；对抗性批评自问是否仅因不熟悉某种惯例而判失败、是否把流畅当唯一美学、是否对知名作者额外宽容。
* [什么时候坚持，什么时候修改：三个问题；商业任务与个人表达可以协商，但不能靠含混承诺掩盖冲突](when-to-insist-when-to-revise.md) - 被挑战的是目标、机制还是偏好；是否存在更低代价的等效方案；坚持会让谁承担成本；清晰决定写成保留观看距离因为需同时观察两人策略、修改灯位和道具让关键动作更清楚；立刻显效极度梦幻绝对真实拆成产品事实、感受目标、形式偏好；有边界的表达提案。
* [个人表达可以从哪里生长：反复注意到什么、反复觉得什么被讲得太简单、愿意为哪些东西付出形式代价；观察—假设—形式—反例档案](where-personal-expression-grows.md) - 与其先设计辨识度高的外观，不如建立持续观察的对象；一条观察笔记（某人每次道谢前先检查工具是否归位）比我喜欢诗意影像更有用；观察不是现代人都很孤独而是某人把同一请求说了三遍每次换理由；私人经验需要被转化而不只是被宣布真实。

# 14 拉片研究与迭代工作流
* [创作流程：方向探索、场景与形式设计、声画与空间预演、整体组合与修订](creation-flow-direction-scene-preview-revision.md) - 提出少量真正不同的方向，差异在观看关系、行动、形式结构或声音组织而非形容词；为每个方向写核心问题、必要事实、开放部分、收益、代价、未知；不把所有广告写成三幕故事；原型只能证明它实际测试的部分；问题来自上层行动回到剧本，来自观看距离回到调度。
* [试验设计：验证关系，而不是证明导演永远正确——定性反馈、版本比较、指标与解释、结论范围；试验前写清问题，试验后允许新问题](experiment-design-verify-relations.md) - 你认为他在哪一刻改变了决定比你是否看出母亲的释然更少预设；原话、研究者解释和创作决定分别保存；整套 A/B 与单变量对照不混写；辨认理解记忆情绪偏好行为意向分别测量；观看时间延长不足以区分兴趣与困惑；没有合适设计时输出本次探索性反馈提示；把记录分成原先要检查的与观看中新发现的。
* [拉片流程：先完整体验，再按问题拆解——五遍](film-study-five-passes.md) - 第一遍记录观看中的变化（何时等待、何时改变判断、何时关系断裂，明确是个人反应）；第二遍定位声画与行动，镜头不是唯一单位；第三遍建立可比较口径（景别变化、渐变转场计时、冲突识别）；第四遍形成条件规则与替代解释并查反例；第五遍核对归因与迁移并写出新媒介中可能失效的条件。
* [启动任务：先把要求变成可以处理的问题；用现有材料解决歧义；明确四种工作模式](kickoff-turn-requirements-into-questions.md) - 高级梦幻像某导演有情绪不要出戏可作起点但要转成问题；品牌要有温度可能指照顾行为、亲密语气、生活痕迹、服务关系或暖色外观；未知分为必要项、可显式假设项、可后置项；聚焦分析／项目开发／深度研究／版本诊断各有最小输出与不应假装完成的事。
* [维护这套知识包：更新来源与更新规则是两种工作](maintaining-the-knowledge-pack.md) - 网页变化协议更新或新研究需修正文献说明；新项目的反例可能要求修正工作模型；二者分别记录；新工具支持更精细生成控制不自动改变人物行动或声画关系的判断；每次更新记录被修改的主张、触发证据、原结论如何缩小或改变、哪些模板受影响；未受影响的模块无需包装为全面升级。
* [调研与搜集：问题导向的来源策略、区分取得了什么、搜集相反材料、停止条件；来源卡应记录负结果](research-source-strategy-and-stop-conditions.md) - 概念问题找原作者与学术条目，技术问题找官方文档，制作问题找参与者访谈与明确版本，观众效果找原始研究及限制；记录全文章节摘要目录访谈剧照预告或转述；不只查长镜头为什么好；主要概念与风险清楚且新搜索只带来相同信息时进入试验；本次检索未取得不等于学术界从未研究。
