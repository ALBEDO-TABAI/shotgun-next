# 步骤

1. **信息层**：提供什么必要事实？是否属于人物此刻自然会说的内容？删去后观众缺少的是必要理解，还是创作者希望所有人接受的解释？不把"自然"当成禁止说明的口号——教学、审问、汇报、正式承诺本来可能需要明确陈述。
2. **关系层**：改变什么：请求、许可、拒绝、威胁、示弱、确认、转移？只补背景又无当前行动需求，考虑改用环境或更合适时机。
3. **可说性层**：让演员真正说出来，检查呼吸、动作、对象、语气能否一起完成。精确的长句在忙乱劳动中可能不成立；极短句可能因缺语境显得刻意。保留人物表达习惯，不把所有角色润色成同一种机智作者声音；涉及具体生活与文化时补资料和咨询。
4. **时序层**：立刻答应、确认后答应、被对方放弃后才答应是三种不同关系。重叠、间隙、重复、未完成句可以有功能，但不能为"真实感"随机添加——要知道谁在争取说话机会，谁在保护沉默。
