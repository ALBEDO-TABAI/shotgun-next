# 步骤

1. **列解释**：人物说完伤人的话，镜头继续停在受话者身上。A 让话语后果成为重点；B 保持此人为段落观察中心；C 给后来动作留连续空间；D 素材或剪辑条件使其他处理不便。A、B、C 可同时成立，D 不自动取消形式价值。
2. **证据顺序**：先记录镜头与声音事实→描述局部关系→比较同片其他场景→最后核对制作资料与意图证言。降低"先看访谈再把细节塞进同一解释"的风险，但不意味着分析可完全无偏。
3. **写出可反驳条件**：不是要求所有解释都能实验，而是让读者知道什么新证据会使你缩小或撤回判断。若访谈说明这段因缺少另一位演员的覆盖镜头而形成，应修正"事前有意限制反应"的制作叙述，但仍可保留"成片让观众停留在承受者身边"的观察。
4. **反向推断时调查区分证据**：成片始终不展示某重要人物正脸——限制动机判断／强调主人公经验／形式约束／素材或授权受限／节奏取舍。查剧本原设计、制作资料、其他人物是否同样处理、缺席是否在转折处改变、版本是否不同。功能有支持而生成原因无资料时写："这个处理在作品中限制了某类信息；为何采取及由谁决定尚不确定。"
5. **防循环**：先认为导演克制→把所有信息缺失解释为克制→用这些例子证明克制。对策：外部比较、实际出现机会、不符合规则的段落。
