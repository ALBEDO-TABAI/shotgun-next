# 步骤

1. **一轮一个主要变量**：先改行动目标；确认后再微调机位；最后调声音或节奏。不是禁止一轮改多个，而是要知道自己在验证什么；组合修改时不把结果当单一因素的证明。
2. **描述问题而非人格评价**："你演得假"→"你在她回答之前就完成了失望反应，观众看不到她的话改变了你。试一次，让你仍认为她会留下，直到她把手放到行李箱上。""美术不够电影"→"背景高亮物件比手部动作更早吸引注意，与本场发现顺序冲突"。具体问题允许专业人员提出更好的方案。
3. **保留发现，不偷偷重写**：好看的影子、演员的犹豫可成为新方案，但要检查是否改变人物已知信息、后续逻辑或商业事实。只是实现优化→负责人直接调整；改动核心关系→说明影响、更新批准范围。
4. **安全与同意**：亲密、暴力、危险动作及可能影响参与者边界的内容，由适当专业人员提前组织，不能以"真实反应"临时升级。一个镜头的艺术价值不能成为绕过真实同意的理由；演员同意某种表演目标，不等于同意任何实现方式。
