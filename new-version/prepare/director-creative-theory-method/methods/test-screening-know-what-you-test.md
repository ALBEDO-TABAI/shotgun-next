# 步骤

1. 记录反馈条件：参与者是否熟悉项目、是否知道导演意图、是否看过旧版。
2. **顺序**：先让观看者复述事件与注意位置→再讨论解释→最后问偏好。把"没看懂"与"理解了但不喜欢"分开。
3. 比较 A、B 版本至少说明：变化了哪些变量；是否用相同设备与音量；观看次序如何安排；问题是否带有暗示。整套方案比较服务创作，不把结果归因于单一镜头或音乐。
4. 不让少量便利样本生成"90% 的目标用户一定会被打动"。样本规模、选择方式、指标与分析方法根据真正的研究问题设计，而不是先找一个显得科学的数字。
