# 步骤

1. **记录分布**："经常用近景"至少还缺：给谁、什么时候、与什么景别对照、近景之后发生什么。同一技法在不同作品承担不同任务，不能从技法建立固定情绪词典。
2. **观察关系**：多人同框与反应分切；对白与身体动作；画面可见范围与声音可听范围；叙述明说与观众必须推断的信息。关系让部门特征成为整体形式。
3. **双重基线**：Bordwell 区分作品借用的外部规范与自行建立的内部规范。偏离显著可能因为同类作品通常不这样做，也可能因为本片前面一直不这样做。"突然出现特写"只有知道此前镜头组织后才可称为变化。
4. **缺席证据**：成片中缺席、拍摄方案中删减、主创明确否决是三件事。先确定该手段有没有实际出现机会——没有对话场景的作品不能因缺少正反打被归为反对正反打。
5. **写成规则句式**：

> 在【适用作品／版本／场景条件】中，当【人物关系或形式任务】出现时，作品倾向于以【手段组合】组织【注意、信息、时间或感受】；相较于【基线】，其特征是【可描述的差异】；在【例外条件】下发生改变。现有证据支持【观察范围】，尚不能确认【意图、归因或受众效果中的缺口】。

句式是工作模板，不必每次写成一大句；目的是迫使描述包含条件、关系和边界。

# 适用边界

- 规则约束在证据覆盖的作品／版本内；跨作品外推见分析尺度。
