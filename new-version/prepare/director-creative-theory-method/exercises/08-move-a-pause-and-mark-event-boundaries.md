# 任务

1. 保留全部镜头，只改变一个长停留的位置。比较它在事件之前像等待、在事件之后像余波，还是并未产生这种差异。记录实际观察，不强迫结果符合预设。
2. 把一个短片所有剪切点标出，再另标人物目标、地点、知识与行动阶段的变化。比较二者是否重合——"剪切"与"事件更新"并非同一单位。
3. **最小评审会议**：只选一个问题（"希望观众先知道朋友在帮助，还是让甲的误解主导前段"），准备两个完整片段，不同时改变配色、表演和字幕。让评审者描述何时形成判断、何时改变、哪些部分仍在等待；再讨论节奏感，不先提供导演希望的答案。会后写出保留方案、代价、受影响的声音与版本、未被回答的问题。

# 验收

- 一次剪辑对照可以帮助决策，但不应被包装成关于所有观众时间知觉的科学定律。
