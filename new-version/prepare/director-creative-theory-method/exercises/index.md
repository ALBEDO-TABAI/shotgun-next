# 练习与验证 · Exercises

各模块的训练任务、反例练习与整合训练。

# 02 导演职责与跨部门整合
* [整合的三个压力测试与一项检验任务](02-three-stress-tests.md) - 预算缩减测试、主创更换测试、善意异议测试；加一项任务：为一次跨部门改动分别写出问题、候选、批准、被牺牲的优势、下游收到的信息与成片结果，缺项就标缺失。

# 03 创作出发点与导演意图
* [撤回一条好听但无证据的解释；三层读法练习](03-withdraw-unsupported-interpretation.md) - 对一段喜欢的影像写一句完整解释，标出所有导演想／象征／必然让观众，逐项问证据，保留有证据的、其余改为假设并补替代解释；加父亲移回行李的三层读法。

# 04 人物关系、表演与对白
* [训练任务：同一句你拿走吧的四种行动；解释台词改动作版本](04-you-take-it-four-actions.md) - 把你拿走吧分别作为赠予、试探、驱赶、假装不在意排演，必须改变对象、前提与下一行动，再让对手意外回应观察策略更新；把三句解释性台词的场景改成动作版本比较得失。

# 05 世界观、空间与置景
* [训练任务：同一场争执放进开放厨房与狭窄门厅；普通物件的三种使用关系；三条规则一条例外三种传达](05-kitchen-vs-hallway-and-object-three-uses.md) - 台词不变记录接近退出旁听照顾如何变化，研究空间施加的条件而非证明小空间更紧张；先写三种使用不用象征词再谈抽象意义；为一个场景写三条影响行动的规则和一条有代价的例外，用对白、空间、动作分别让观众理解。

# 06 信息分配、视点与留白
* [练习：两个版本只改一个变量；必须知道与可以不知道；关键揭示审查](06-two-versions-one-variable.md) - 同一组镜头只改一个关键信息的位置不改音乐，比理解再比期待；固定顺序只改音乐入点观察解释漂移；拆解释段落为必须知道／可以不知道逐项删去；选一个揭示写两种先前解释、新增事实、改变与不篡改的前提、仍允许的未知。

# 07 桥段、场景行动与情节
* [训练：人物终于明白的三种动作结尾；去笑点与压前史；同一情境三个版本](07-three-action-endings.md) - 把总结改写成交付责任、停止控制、承担代价三种结尾比较允许与排除的解释；去掉笑点看行动是否连贯，把前史压成一项必要条件看桥段是否仍属于这些人；三版分别通过选择、发现、改变观看位置。

# 08 叙事顺序、时间与节奏
* [练习：移动一个长停留的位置；标记剪切点与事件更新；时间结构的最小评审会议](08-move-a-pause-and-mark-event-boundaries.md) - 保留全部镜头只改一个长停留的位置，比较在事件前像等待、在事件后像余波还是无差异；标出所有剪切点再另标目标地点知识行动阶段的变化比较是否重合；评审会只选一个问题准备两个完整片段。

# 09 调度、摄影与画面
* [练习：交接动作的四种摄影机跟随；同机位改取景 vs 移机保持人物大小；摄影评价的反事实练习](09-handover-camera-follow-variants.md) - 拍一个交物件动作，分别跟随交出者、接收者、物件和完全不动，比较获得与失去的关系而非流畅度；同机位改取景再移机保持人物大小比较背景关系；对重要镜头提出不移动、提前切、延后切、保留另一人、只改声音版本。

# 10 灯光、色彩与氛围
* [训练：同色异义、材质诚实、连续动作审查](10-same-color-material-honesty-continuous-action.md) - 同一空间同一配色通过行动光区声音提出两种体验并说明哪些变化不能归因单一颜色；对同一虚构产品分别写感官隐喻版与使用演示版视觉目标；记录一个人从坐下到离开的全部关键位置检查可读性。

# 11 声音设计与音乐
* [练习：从一段声画关系反推需要前移的制作决定；给同一门铃安排三次不同的关系任务](11-three-hearings-and-doorbell-three-tasks.md) - 先不用音乐写出人物第一次、再次、最后听见同一声音时的差异，若只改音量就继续追问为何重复；检查画面是否给聆听时间、演员有无可执行反应、场景是否允许声源、剪辑是否保留因果；门铃三次响起各自的位置谁听见谁反应；门开了铃不响的反向版本。

# 13 导演个性、表达与伦理
* [个人表达的训练，而非风格包装：观察、替代、限制、反例、协作、伦理六种训练；同一关切不同形式、同一形式不同问题、为自己的选择写反方意见](13-personal-expression-training.md) - 记录具体动作声音空间不急于命名主题；同一情境两种真正不同的观看关系，仅换色调不算；暂时不用最熟悉的手段；找一部与作者画像不一致的作品解释差异；让不同部门提非预期方案；把最有感染力的场景拆成制作步骤逐项判断谁承担什么。

# 14 拉片研究与迭代工作流
* [训练与评估任务库：盲分析、反例、跨媒介、部门冲突、来源核查、版本污染；整合训练六轮](14-training-library-and-integration-drill.md) - 先不看导演名字描述段落再补制作资料记录判断变化；为风格规则找失效情境；同一表达变成 30 秒影片组照与主视觉说明各版本放弃什么；摄影表演声音分别提强化方案再检查重复或抵消；从结论逆向找来源；故意混合旧配乐表与新剪辑从版本标识发现问题；六轮从材料到方案再回到材料。
