# 任务

1. 同一组镜头做两个版本，只改变一个关键信息的出现位置，不改音乐。先比较理解，再比较期待。之后固定顺序，只改音乐入点，观察解释是否漂移。区分信息编排与情绪导向；小样本不外推到所有观众。
2. 把一个解释性段落拆成"必须知道"和"可以不知道"，分别删去一项，记录下游哪处理解受损。目标不是最少信息，而是找到作品真正依赖的关系。
3. **最终审查**：选一个关键揭示，写出观众之前可能持有的至少两种解释；列出揭示真正新增的事实；检查它改变哪些前提而不篡改哪些已知；说明揭示后仍允许什么未知。

# 验收

- 任务 1 的两组比较结果分别记录，不混写。
- 任务 3 能区分"巧妙的重新理解"与"单纯的信息扣留"。
