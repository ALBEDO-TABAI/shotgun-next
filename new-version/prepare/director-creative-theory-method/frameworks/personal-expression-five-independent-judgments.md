# 要点

| 判断 | 问题 | 提醒 |
|---|---|---|
| 可辨认性 | 是否与比较对象不同？形式是否有可描述的规律？ | 回答识别问题，不直接回答好坏；独特的镜头习惯可能在某项目中没有必要 |
| 组织程度 | 选择之间是否有关系，变化是否可理解，例外是否产生作用 | 组织可包括冲突，不等于一切整齐统一 |
| 表达适切性 | 形式是否适合此刻的人物、材料和任务？帮助看见了什么，遮蔽了什么？ | 同一技巧不因前作有效就自动适合下一部 |
| 发现与复杂性 | 是否使原本被忽略的行为、感受或关系变得可见？人物是否超出主题工具？ | 复杂性不是设定多，而是已有关系不被过早压扁 |
| 个人反应与论证 | "我喜欢"和"我认为它在这项任务上成立"可同时出现也可分开 | Leder 等的审美模型区分审美情绪与审美判断，后续回顾把情境列为重要问题；不能充当评分器，但提醒被感动、理解方法、认可价值不一定同步 |

## 标准可以不同，但不免除论证

重视人物经验复杂性与重视材料节奏形式发现的评价者对同一段落判断不同，不必意味着有人看错；但前者仍要说明复杂性在哪里，后者仍要说明形式如何成立。**评价写成三段**：描述可观察的选择→说明所采用的标准及其适用理由→讨论收益与代价。

**三类争议分开**：
1. 可纠正的问题——使用了不存在的镜头、误认声音来源、把访谈当成已观察事实。
2. 价值排序——让人物更清楚表达还是保留关系未决；结合作品目标讨论，不一定有单一答案。
3. 现实责任——素材使用是否超出参与者知情范围；不能改写成"有人喜欢真实、有人喜欢保护"，应核对具体承诺、影响和适用要求。
