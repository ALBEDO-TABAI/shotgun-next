# 要点

**模型**：初始关系 → 人物尝试 → 阻力或意外回应 → 策略调整 → 关键选择 → 新状态 → 后果。不是每个场景必备七个环节，而是用来发现哪里只有事件概述、没有可执行过程。

"母亲终于理解女儿"缺少行动。"母亲端汤，女儿拒绝，母亲哭，女儿拥抱"有动作，也可能只是情绪按钮排列——母亲具体改变了什么要求？女儿是否仍然离开？拥抱意味着理解、妥协还是安慰？

**因果链含选择**：完全由偶然推动的桥段，人物只是被搬运。链条写成：条件变化 → 人物理解或误解 → 采取行动 → 对方或环境回应 → 新的选择条件。比"突然下雨、突然停电、突然遇到熟人"更能说明关系发展。

**三种必要性**：
- 事件必要性：前一事件为后一事件提供条件。
- 人物必要性：行动与已建立的欲望和认知相容。
- 表达必要性：这一段对本作品的目标有作用。

现实中完全可能发生的行动放进作品仍可能多余；与主题高度相关的设计却可能让人物做没有根据的事。三者分别检查，不用其中一项替代其他两项。非因果结构也需要说明自己的组织依据。
