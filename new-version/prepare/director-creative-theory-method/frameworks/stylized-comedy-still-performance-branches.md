# 要点

| 分支 | 要点 | 不做 |
|---|---|---|
| 风格化 | 程式化姿态、平直台词、直视镜头仍可形成明确关系；确定规则何时保持、何时打破；若允许直视镜头，明确何时、对谁、其他人物是否知情 | 一边要求人工性，一边以"生活中不像这样"否定演员；只说"不要演"而不展示规则 |
| 喜剧 | 笑点来自预期、迟疑、错误理解、信息差、动作失败或反应延迟；先明确哪项关系使场景可笑再讨论停顿与切点；喜剧可来自人物认真执行与条件不匹配的目标 | 把克制当唯一高级方式；没有关系时精确到帧的停顿只是空等 |
| 平面 | 单张图像选择能暗示前后过程的动作状态：等待、检查、邀请、保护、使用、支撑、递出、倾听；用连续动作寻找瞬间 | 只让模特"显得自信"；姿势与物件重量或人际关系矛盾 |
| 非职业者 | 做熟悉任务、用自己的语言解释过程、减少必须记忆的对白；尊重其理解与选择 | 把"不懂拍摄"当作获得未设防情绪的优势 |
| 生成角色 | 检查动作是否回应前因、身份与空间是否一致、嘴形与声音是否协调 | 因某一帧脸部"很有情绪"就宣布完成表演导演 |

自然主义不等于不做设计，高度风格化不等于没有真实行动；两者都可检查对象、节奏、回应和形式规则。
