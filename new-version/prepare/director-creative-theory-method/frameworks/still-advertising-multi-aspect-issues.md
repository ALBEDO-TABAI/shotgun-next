# 要点

| 问题 | 内容 |
|---|---|
| 平面是瞬间 | 构图、视线、动作未完成状态、文字与产品位置共同影响注意，不能等同电影镜头的时间控制；不能依赖"先不给看、两秒后再发现" |
| 产品与人物共享动作逻辑 | 包装正面、手部动作和表情可能竞争；为标签持续可见让人以不自然方式使用产品→讨论独立信息镜头或不同版本 |
| 多画幅 | 横版双人距离在竖版可能只剩一人，画外信息因此改变；提前识别必须保留的关系，分别设计或验证裁切 |
| 参考图≠镜头方案 | 参考图说明外观，无法说明进入、移动、焦点变化与结束；面向生成或真人拍摄仍需动作与时间关系描述 |

## 平面动作的瞬间线索

是正在递出还是刚刚收回、身体重量是否有支撑、注意对象是否可理解。允许含混，但要知道含混发生在哪里。组图通过顺序扩展信息，若最终被单张分发，每张独立用途重新检查。产品摄影检查文字与反射、手部与包装、背景与材料之间的竞争——表现力强的角度使产品身份无法辨认时，需另一镜头或版本承担识别。
