# 要点

| 层级 | 典型问题 | 与导演风格的区别 |
|---|---|---|
| 媒介与交付形态 | 长片、广告、单张照片、组照、装置？ | 决定表达条件，不直接决定风格 |
| 项目用途 | 销售、品牌表达、观察记录、艺术探索？ | 是任务，不是外观类别 |
| 题材与类型 | 关于什么？利用了什么类型预期？ | 爱情、犯罪不等于个人特征 |
| 传统／运动／群体实践 | 与哪些历史做法、机构、同代作品有关？ | 相似不等于直接继承，需史料 |
| 表达模式 | 因果叙事、观察、论述、联想、形式实验？ | 描述组织方式，不必归结为某人 |
| 技法与外观 | 长镜头、低照度、正面构图、跳切？ | 候选证据，还不是完整规则 |
| 作品风格 | 手段如何在该作品内形成持续关系？ | 先约束在该作品或版本内 |
| 作者倾向 | 跨作品持续保留和调整了什么？ | 需跨作品比较、协作归因与反例检验 |

一件作品可同时属于多种用途、类型和表达模式。耶鲁术语页也把类型视为由作品惯例和识别活动建立的分类，不是与单一作者相等的标签。

# 适用边界

- 工作分类，不是互斥本体论。
