# 要点

| 没说 | 内容 | 身份 |
|---|---|---|
| 省略过程 | 观众理解结果，无需看每一步（从离家到抵达） | 常规手段 |
| 延迟答案 | 建立了问题，暂不给解决 | 策略 |
| 人物隐瞒 | 角色有理由对别人不说，作品可能让观众知道 | 人物层 |
| 解释开放 | 事实可辨认，动机或意义保持多种读法 | 有组织的开放 |
| 材料缺失 | 作品没提供理解所需条件 | 可能是问题而非策略 |

"观众不知道母亲为什么这样做"可能是有组织的开放；"观众根本没有看清她做了什么"可能阻断场景。

主动失向的形式实验可以成立，但应以感知与形式目标评价。
