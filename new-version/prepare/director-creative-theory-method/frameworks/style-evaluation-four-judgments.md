# 要点

| 判断 | 问题 |
|---|---|
| 可辨认性 | 这些特征足以与比较对象区分吗？ |
| 组织程度 | 手段之间是否形成关系，变化是否有意义？ |
| 表达与任务效果 | 在此作品目的与观看条件下带来什么收益和代价？ |
| 艺术评价与偏好 | 是否有发现力、复杂性、形式愉悦或其他明确重视的价值？这些标准为何适用于此处？ |

容易识别≠优秀；形式统一≠丰富；难以理解≠深刻；商业任务完成≠全部艺术判断已解决；个人不喜欢≠作品没有组织。

**拒绝万能规则**：不规定所有形式必须为剧情让路；不规定好导演必须强烈可见；不规定不显露摄影机才成熟；不规定个人风格越稳定越好。

**创作转译**：可保留对人物判断的延迟方式、观看距离的变化条件、声画互相留位的方法、混合模式的转换规则；需重做新作品的目标、人物生活、材料、产品、媒介、时间与可实现条件。借鉴可见手段并无原罪，但手段迁移后需重新建立功能。

# 适用边界

- 本包建议的评价分层，不是可相加的普遍量表。
