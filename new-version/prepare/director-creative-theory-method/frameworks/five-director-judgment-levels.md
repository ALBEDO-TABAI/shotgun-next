# 要点

| 层级 | 问题 | 提醒 |
|---|---|---|
| 表达任务 | 作品到底要完成什么？哪种观众、什么场景、至少认出什么、允许哪些不同理解、什么即使漂亮也不牺牲 | "高级、动人、商业有效"不能直接并列为验收条件 |
| 作品结构 | 每段为什么存在：推进事件、改变观看位置、形成节奏、建立世界、让余波停留 | 母亲换容器是关系转向，食物特写只负责行动可读性；拍成独立美食广告则局部质量上升、整体功能偏移 |
| 场景机制 | 人物可以做什么、阻力从何而来、观众靠哪些证据认出变化 | 需编剧、演员、美术、摄影共同参与，不能等拍完再讨论 |
| 手段配置 | 同一信息由对白、道具、动作、剪辑或声音提供？ | 影响演员负担、画面空间、字幕、本地化、多版本适配 |
| 实施与检验 | 方案是否真的出现在成品里 | 阐述写得好≠镜头保留了动作；分镜标注"观众发现"≠有足够时长；作曲说"留白"≠混音没被环境声填满 |

# 适用边界

- 层级是判断工具，不是会议次序或组织架构。
