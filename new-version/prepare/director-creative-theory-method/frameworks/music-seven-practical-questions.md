# 要点

不称为完整音乐功能分类学。

| 问题 | 说明 |
|---|---|
| 是否建立时间 | 流动、等待或循环的组织，不一定与每次切镜对应 |
| 是否连接分散空间 | 同一段音乐跨越多地点使其被体验为一个段落；确认事件时间是否被误解 |
| 是否给出态度 | 接近人物感受，或呈现叙述者／品牌的姿态 |
| 是否提前承诺结果 | 过早的和声解决或情绪抬升可能在人物完成决定前宣布结论 |
| 是否建立可辨识形式 | 音型、音色或节奏的重复形成内部关系；无需把每次重复都解释为角色主题 |
| 是否改变材料感 | 轻重、疏密、起落、延音与画面运动形成联系 |
| 是否应该退出 | 停止≠音量拉零；退出可交给环境、对白、动作声或另一种听觉尺度 |

给作曲或音乐编辑的任务包含：段落目标；进入与退出条件；不能提前宣布的事情；对白和音效的空间；参考中值得借鉴的关系；允许偏离的地方。
