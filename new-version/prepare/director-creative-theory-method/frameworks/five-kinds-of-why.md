# 要点

| 为什么 | 内容 |
|---|---|
| 生成原因 | 方案在真实工作中怎样出现：观察、任务、偶然、技术条件、合作 |
| 公开理由 | 主创在访谈、提案或现场怎样解释该方案 |
| 作品功能 | 该声画选择在完成作品中怎样组织人物、信息与观看 |
| 意义解释 | 我们据此怎样理解作品对某问题的态度 |
| 价值判断 | 这种组织在什么目标下有效、丰富、必要，或有什么代价 |

导演说希望让人同情人物，只证明这项公开意图；成片可能使某些观众疏远。一个细节确实有效，也不证明它在拍摄前就被这样设计。

# 适用边界

- 五者是分析工具；实际讨论中常需同时保存多种"为什么"，但要标明各自身份。
