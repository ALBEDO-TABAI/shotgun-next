# 要点

Bordwell 对故事事件与编排方式的区分，使我们可在不改变事件事实的情况下比较不同观看路径。学徒修好灯→师傅决定交钥匙→争执→学徒发现钥匙在工具箱：先展示发现再回到争执，或让观众一开始就知道决定——改变的不只是"是否看懂"，还有注意对象：等待结果、调查原因，还是观察一个决定如何被接收。

**先问**：希望观众先形成什么判断？后来的材料应该确认、修正，还是复杂化它？非线性只有在带来值得付出的体验收益时才有必要。

| 顺序类型 | 作用 | 提醒 |
|---|---|---|
| 回溯与预示 | 补充原因、改变评价、表现记忆；提前呈现后来事件使观众关注过程 | 区分事件真正被展示，还是人物想象、预测或讲述；无线索时不把断裂自动认作回忆 |
| 平行与交替 | 理解为同时发生，或比较不同时间与处境 | 作品要知道自己是否借助同时性期待；最后证明并非同时时检查是否建立了可重新解释的线索 |
| 嵌套与多层 | 讲述中的讲述 | 画幅、声音、表演语气、空间、年龄都可标记层级；任何标记都需在作品中建立 |
| 联想与并列 | 相似形状、动作、声音或主题连接不同时间，不假装情节因果 | 广告、散文影像、实验作品的主要组织原则；形态接力与事实因果不能混用 |
