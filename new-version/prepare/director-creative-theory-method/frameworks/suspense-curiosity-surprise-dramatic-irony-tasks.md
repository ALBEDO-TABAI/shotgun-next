# 要点

| 任务 | 指向 |
|---|---|
| 悬念 | 尚未发生或未完成的结果：会怎样、能否避免、代价是什么 |
| 好奇 | 尚不理解的事实或原因：发生过什么、为何如此、某物来自哪里 |
| 惊讶 | 实际出现与已有预期之间的差异；没有可形成的预期就难说推翻了什么 |
| 戏剧性信息差 | 观众知道人物不知道的事，普通行动读成双重意义 |

同一段落可既让人好奇过去也担心将来；一条广告可能不需要任何秘密，只需清楚而有韵律的体验。有些作品的力量来自观众早知道结局，却终于理解人物怎样走到那里。

# 适用边界

- 分析与创作的区分，不是保证情感强度的定律。
