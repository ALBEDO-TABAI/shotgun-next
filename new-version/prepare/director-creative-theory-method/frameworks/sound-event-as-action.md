# 要点

区别不是由音效库文件名决定的。

## 声音事件卡

| 项目 | 应当明确的内容 |
|---|---|
| 来源与现实层 | 谁或什么发声；人物是否能听见 |
| 进入条件 | 动作发生、注意转移还是叙述层改变 |
| 主要任务 | 信息、空间、材料、关系、节奏或其他 |
| 与画面的关系 | 解释、补充、延迟、对照、遮蔽或接续 |
| 与其他声音的关系 | 谁在前景；谁让位；何时退出 |
| 检验问题 | 去掉或改变它，会失去哪种关系 |

普通环境连续性也可能是必要工作；关键是知道何时需要前景化，而不是使所有声音都异常突出。
