# 要点

| 层级 | 观察问题 | 修改时的常见错误 |
|---|---|---|
| 动作节奏 | 行为怎样开始、受阻、完成 | 只让演员动作更快 |
| 对话节奏 | 谁等待、抢接、修正、沉默 | 删除所有停顿 |
| 镜头节奏 | 时长、变化、连接与空间如何分布 | 只统计平均镜头时长 |
| 信息节奏 | 新问题、答案和解释多久更新 | 加更多字幕或反转 |
| 关系节奏 | 谁的态度或选择何时改变 | 用音乐代替实际变化 |
| 声音与形式节奏 | 音型、音色、静默、运动如何组织 | 所有切点贴着节拍 |

"拖"可能意味着没有新信息，也可能是人物动作缺乏任务、场景顺序重复了已知内容、或观众尚未理解需要等待什么。不用一个"快"字掩盖具体差异。
