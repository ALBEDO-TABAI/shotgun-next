# 要点

| 层 | 内容 |
|---|---|
| 问题层 | 原作品在解决什么人物、感知或形式问题 |
| 规则层 | 在什么条件下选择某种观看距离、时间或声画关系 |
| 实现层 | 使用了什么具体构图、材料、运动或剪辑方案 |
| 标识层 | 哪些外观最容易使观众想到这位创作者 |

借鉴可发生在任一层，但迁移后的价值需重新建立。参考片通过对称构图使人物的偏移显著；新广告同样对称却始终没有偏移、比较或其他组织目标——手段的作用已经不同，不能声称自动继承原片的人物表达。

**原创性**：新关系可由常见材料形成；新技术也可能只重复旧套路。问：这次组合有没有让某种经验以更具体的方式被看见？原创性判断需要历史范围——不了解某种传统不等于其技法从未存在；适合的表述是"在本次比较范围中，这个组合具有某种差异"。素材、台词、音乐或设计的具体使用独立核对权利条件。
