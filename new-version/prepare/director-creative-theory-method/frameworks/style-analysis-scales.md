# 要点

| 尺度 | 对象 | 提醒 |
|---|---|---|
| 局部手段 | 单个镜头或瞬间：一次推近、声音先于画面、不切反应 | 可以很显著，仍可能只是局部方案 |
| 段落与单部作品内部规则 | 某选择是否反复出现、如何建立预期、有无展开变化与例外 | 一部作品可含多个局部系统：现实／回忆、不同叙述层不必共享外观 |
| 导演某一阶段倾向 | 多作品中相似表达问题的处理，记录时间、任务与团队变化 | 不要求全部作品保持相同形式；说明"什么时候变化"常比"永远如此"更有解释力 |
| 合作群体／类型／历史传统 | 导演—摄影—美术组合的共同实践，或某时代工业条件下的通行方案 | 有些反复特征更适合归于此层 |

**从小尺度外推到大尺度，必须增加证据，而不是只增强形容词的语气。**

# 适用边界

- 尺度划分是工作约定；具体作品可能同时在多个尺度上提供证据。
