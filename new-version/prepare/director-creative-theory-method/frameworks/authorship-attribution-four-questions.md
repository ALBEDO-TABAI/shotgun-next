# 要点

| 问题 | 由什么支持 |
|---|---|
| 成片中有什么？ | 实际声画材料 |
| 是谁提出或实现的？ | 可靠生产资料、访谈、记录 |
| 为什么采用？ | 主创自述，或只是研究者解释 |
| 观众实际怎样反应？ | 受众材料，不能只用主创自述 |

有时只能回答第一个问题，这仍是有效成果。

**比较设计**：同一导演更换摄影／剪辑的作品；同一摄影师与不同导演的作品；同一导演不同类型、预算、阶段；必要时比较版本。比较帮助发现混杂因素，不自动分离因果。若导演与某摄影师在全部样本中始终共同出现，允许输出"该合作组合的倾向，个人贡献未能分离"。

**制作证言的限度**：摄影师能可靠说明技术讨论与实施，却不因此证明所有观众按预期感受；导演可陈述意图，意图不等于成片实现。ASC 对 Yeoman 的访谈呈现导演整合与各工种带入贡献的协作关系，校正"整体风格是一个人逐项发明"的归因方式。

**商业项目**：把创意方向、客户要求、产品露出、版本修改、媒介规格列为待核对条件。没有制作资料时写"成片表现为……"而非"导演坚持……"。

# 适用边界

- 归因结论的信心应落在单条判断上，不给整个导演画像统一置信度。
