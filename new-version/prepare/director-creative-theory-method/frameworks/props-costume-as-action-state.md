# 要点

- **多重职责**：功能物、关系资源、信息载体、形式母题、象征。不强迫所有道具成为伏笔，也不认为只负责可信度就没价值。钥匙的戏剧性不在"象征权力"，而在谁能拿到、谁必须请求、谁把它留下——象征解释建立在这些关系上。
- **状态随行动更新**：容器开或关、液体多少、信封是否拆、灯是否接通。连续性不只为防挑错，也保证原因和后果没被无意重写。虚构例：外套起初挂门边（随时要走）→被另一人放进衣柜（改变准备状态）→本人重新取出（关系已不同）；只拍外套"有质感"这些变化就不成立。
- **服装**：影响身体行动、职业身份、使用习惯、时间与关系。紧身制服限制动作、旧外套被谁修补、袖口在工作中怎样变化。不从单个外观特征推断真实人的人格——角色设计与现实人物识别是不同任务。
- **做旧的分布逻辑**：哪里常被摸、哪里受潮、什么被清洁、什么被忽略；均匀涂脏显得人为。是制作观察建议，不是凭磨损鉴定家庭历史的技术。广告中产品样品、演示道具、象征材料要分清；前后镜头用不同状态的产品会改变观众对功能和时间的理解。
- **关键道具五项**：从哪里来；平时谁使用；谁可以移动；当前处于什么状态；何时改变状态。
- **服装妆发与身体同一生活逻辑**：衣物是否支持坐下、取物、弯腰、转身；妆发是否与时间、工作、故事状态相符。"贫穷所以都脏""专业所以一尘不染"是过度简化。美术的解释不应压过表演：若服装道具已把人物写成符号，演员难以保留复杂性。
