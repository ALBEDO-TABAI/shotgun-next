# 要点

| 术语 | 例 |
|---|---|
| 点子 | 即将离开的女儿被母亲以吃饭为由留下 |
| 情境 | 车已到，汤刚盛好，行李箱堵在门口 |
| 事件 | 母亲不再坚持女儿坐下，改为把汤装好让她带走 |
| 场景 | 相对连续时空中组织的一段材料，可含多个事件，也可以观察和停留为主 |
| 桥段 | 一段有独立组织的戏、笑料、动作段落、情绪转向或形式构想；本包每次明确所指 |

一个点子再新也可能没有可展开的行动；一个事件很普通却可能因关系与声画组织非常有力。

## 理论支点

- Hühn：一般状态变化与在具体语境中有更强意义的事件不同；事件性取决于变化相对人物、规范与期待的重要性。
- 《诗学》：行动结构、因果、逆转、发现——特定历史与体裁背景下的资源，不是当代影像都必须遵循的实验结论。
- Bordwell：把"故事发生了什么"与"观众怎样经历它"分开；梗概合理的情节仍可能在表演、时长或信息上失败。
