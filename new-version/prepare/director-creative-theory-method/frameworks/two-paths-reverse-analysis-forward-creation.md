# 要点

**反向分析**：材料与版本 → 可观察选择 → 重复与变化 → 功能解释 → 制作归因与接受材料 → 有条件的结论。

**正向创作**：任务与关切 → 情境或形式结构 → 人物及信息关系 → 空间、时间和声画方案 → 小规模试验 → 整体版本 → 修订与交付。

- 一个镜头可能具有某种功能，不等于导演事先就是这样想的。
- 写下"观众会感动"只表明一种愿望。
- Bordwell 的电影诗学围绕具体问题、作品组织与生成条件展开研究；Design Council 的双钻提供发现、定义、发展、交付的框架。借用的是问题探索与方案收敛的思路，不宣称两者已共同验证本篇所有步骤。
