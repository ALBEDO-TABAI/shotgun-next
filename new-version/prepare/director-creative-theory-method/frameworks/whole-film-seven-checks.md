# 要点

| 层面 | 检查 |
|---|---|
| 事件与信息 | 前提有没有被提供；人物改变行动是否有依据；声画是否意外给出相反事实 |
| 人物与表演 | 相邻镜头中的态度与策略是否可接；剪辑是否把不同表演状态硬拼成不存在的变化 |
| 空间与时间 | 是否有意改变地理或时间；改变是否可读；有没有把技术拼接错误当成风格 |
| 声画主次 | 各部门是否在同一时刻争夺结论；有没有必要的让位与接续 |
| 表达与任务 | 非叙事作品检查形式发展，不被迫补剧情；广告检查品牌或产品关系，不只看电影感 |
| 事实、伦理与授权 | 事实性材料是否被不当重新关联；出镜、素材、音乐、生成内容的使用范围是否确认 |
| 观看与交付 | 在实际语言、画幅、设备和可及性版本中是否仍可用 |
