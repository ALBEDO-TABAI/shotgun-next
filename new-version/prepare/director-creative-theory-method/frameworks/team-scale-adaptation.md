# 要点

| 团队 | 做法 | 避免 |
|---|---|---|
| 两三人 | 角色兼任不代表判断层级消失：先作为表演观察者看关系，再作为摄影判断画面，最后作为剪辑看完整段落。一页当前方向、少量关键镜头意图、明确的未知 | 为模仿大制作创建大量无人维护的文件 |
| 多部门 | 强相互依赖时提前联合试验（透明包装反射同时影响灯光、标签、背景与后期修复，不能只由产品摄影确认）。会议按共同问题组织，每场至少形成一个可执行决定或说明为何不能决定 | 各部门轮流展示完成度 |
| AI 虚拟团队 | 要求各 agent 消费同一版本的核心决定，各自检查特定问题：表演角色查可执行行动，摄影角色查可见性，声音角色查信息提前泄露；检查结果必须指向材料 | 以为拆成多个 agent 就自动产生真实专业分歧；接受"我认为很好" |

生成模型做不出来的镜头，回到表达目标找替代方案；不能让工具偶然擅长的外观悄悄改写人物与品牌任务。
