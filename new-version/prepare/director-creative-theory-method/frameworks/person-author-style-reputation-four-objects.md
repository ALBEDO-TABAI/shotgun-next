# 要点

| 对象 | 内容 |
|---|---|
| 个人 | 现实中的一个人 |
| 作者 | 作品中可以推断的创作倾向 |
| 风格 | 反复出现的形式模式 |
| 声誉 | 行业与公众赋予其的名声 |

创作分析首先研究作品如何组织人和经验，而不是从一个镜头倒推真实人格。熟悉署名不应变成替作品免检的理由。
