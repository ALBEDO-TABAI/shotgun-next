# 要点

| 起点 | 下一步 | 陷阱 |
|---|---|---|
| 人物或关系 | 一个人持续关心另一个人却总把帮助变成控制→寻找这种关系在什么事上出现、对方怎样应对、关心是否也有真实价值 | 人物只为证明主题存在，动作机械 |
| 物件、场所或声音 | 旧修理铺抽屉、夜间通风声、有修补痕迹的桌面→它们提供了什么尚未被看见的关系？适合观察、比较、叙述还是纯形式？ | 声音起点马上退化成"配什么画面"；它可以决定谁在场、什么不可见、时间怎样经过 |
| 形式问题 | "能否不展示脸让观众辨认关系变化？""同一动作三次重复形成不同意义？" | 仅实施一个困难限制不等于作品成立；要说明研究什么、如何判断结果 |
| 商业任务 | 判断任务如何被人实际体验：演示、解释、联想、人物情境、材质变化或可记忆的形式关系 | "希望观众感觉产品有效"代替产品事实；把视觉隐喻当证据 |
| 资源限制或偶然 | 只能拍一个房间→研究进入与退出；演员只有一天→改变时间结构 | 浪漫化所有限制；事后把技术不足写成深思熟虑的美学 |
