# 要点

| 分析轴 | 要观察的事实 | 警惕的直接跳跃 |
|---|---|---|
| 信息与叙述位置 | 谁知道什么；我们何时知道；哪些因果被延迟或省略 | 信息少＝深刻；解释清楚＝肤浅 |
| 表演与人物关系 | 谁对谁采取行动；停顿、身体距离、倾听与言语如何配合 | 低强度＝真实；夸张＝失败 |
| 调度与空间组织 | 谁能进入、被看见、被遮挡；前后景与出入口如何参与关系 | 空间漂亮＝调度成立 |
| 摄影与观看距离 | 景别、角度、焦点、运动如何分配观看；人物与摄影机何时分离 | 近景＝同情；远景＝客观 |
| 时间与剪辑 | 时长、停留、省略、重复、并置、转场如何分布 | 镜头长＝慢；剪辑快＝推进快 |
| 场景外观与物质性 | 布景、服化、光线、色彩、材质怎样随人物和阶段变化 | 某颜色必然对应一种情感 |
| 声音与音乐 | 听觉视点、画外空间、主次、入点与退出怎样与画面互动 | 音乐感人＝导演整体表达有效 |
| 形式规则与媒介意识 | 是否直接对观众说话；是否强调人工性；模式怎样交替 | 看见形式＝出戏；不统一＝没风格 |

不是同等权重打分表：对具体问题选真正相关的轴，并说明哪些轴当前没有材料。

## 人性观与世界观看哪里

人物如何被允许辩解、后果由谁承担、谁的经验获得时间、谁只作为工具出现，可成为解释作者关切的线索。但"作品如何组织人物"与"导演现实中是怎样的人"不能相互替代。推荐写"本段把更多时间留给行为承受者，因此可提出作品优先关注后果的解释"，而非"导演是有同理心的人，所以用了这个镜头"。
