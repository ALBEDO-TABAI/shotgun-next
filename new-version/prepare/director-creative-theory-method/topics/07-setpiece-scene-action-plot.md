# 回答什么问题

一个点子如何成为一段值得经历的行动？怎样让变化发生，而不是让人物轮流解释变化？双重检查：场景中的关系是否发生可描述变化；作品是否提供了经历该变化的条件。

# 核心主张

**好的桥段是让条件、行动和关系在时间中互相改变，而不是把一个聪明点子包装成一串镜头。变化需要有代价、约束或行为差异，才不只是换一个情绪表情。** 状态表、因果检查、桥段变体与压力测试对行动叙事尤其有用，不强迫观察、诗性、论述或实验作品遵守同一戏剧公式。
