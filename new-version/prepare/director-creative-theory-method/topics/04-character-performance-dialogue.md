# 回答什么问题

此刻他想让谁做什么？不愿让对方知道什么？他以为哪种方法有效？对方的反应怎样迫使他改变？

# 核心主张

**好的人物指导不是告诉演员"这个人是什么样"，而是共同找到"此刻他在怎样对待另一个人，以及对方怎样使他改变"。** 不提供心理诊断，不把某一种表演传统当作唯一正确方法；只要场景依赖人与人相互影响，就应检查这种影响是否实际发生。
