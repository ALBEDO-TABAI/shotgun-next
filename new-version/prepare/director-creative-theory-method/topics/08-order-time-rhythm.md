# 回答什么问题

世界中事件怎样发生，与作品怎样让观众经历它们，是两件事。"节奏快慢"要拆成动作、对话、镜头、信息、关系、声音六个层级。不把非线性视为高级，不把剪辑速度视为全部节奏，不提供适用所有广告的秒数公式。

# 核心主张

**导演组织的不是一个抽象的快慢曲线，而是观众在时间中知道、等待、辨认和重新理解的条件。** 好的时间结构让停留与省略各有任务，也允许非线性和顺时推进以不同方式成立。
