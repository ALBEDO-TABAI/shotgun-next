# 原则与边界 · Principles

证据边界、研究外推限度、伦理与安全、Agent 工作边界。

# 01 导演风格识别
* [量化能提供什么、不能提供什么：平均值、比例口径、有序组合、伪独立样本与工具边界](quantification-limits-in-style-analysis.md) - 平均值不能代替组织；数量比例与时长比例不能混用；风格是有序组合不只词频；几百个镜头不是几百部作品；自动标注需抽检；单帧不能反推参数。
* [来源使用与证据边界总原则：五类来源各能支持什么，全包共用一套约定](source-use-and-evidence-boundaries.md) - 跨 14 模块的总约定：原作者理论、主创证言、实证研究、机构材料、本包综合五类来源分别能支持什么、不能支持什么；观察与解释分开、样本不外推、自拟案例只作教学、Agent 自报置信度不算校准概率。

# 02 导演职责与跨部门整合
* [让异议可以出现，不等于降低要求](dissent-and-psychological-safety.md) - Edmondson 的团队心理安全研究可谨慎迁移的只有一个问题：成员能否在代价还小时提出疑问、报告错误；心理安全不取消拍板、不替代专业能力、不容许无限拖延。
* [从成片推断导演工作的边界：三个独立记录，不写成成功学](reverse-inference-from-finished-film.md) - 看到协调可评价整合结果但不能推出导演亲自提出所有方案；建立作品问题／可确认过程／待核对归属三个记录；警惕访谈的回顾性整理；把产生什么、如何产生、是否适合迁移分开。

# 03 创作出发点与导演意图
* [观察性和实验性作品如何避免被命题化压扁，又不失去方向](observational-experimental-not-flattened.md) - 观察项目先定观察问题、接近方式、伦理边界与记录方法而非预定谁成长谁失败；实验作品把问题放在感知层不必翻译成人生道理；开放仍有评价与责任；观察推翻起点时如实承认；出发点审查一页纸。
* [一段访谈能支持到哪里：以 Leigh 的自述为示范](what-an-interview-can-support.md) - 可以写导演把方法与观察现实及整合写作排练联系起来；不能写他所有影片都没剧本或全部即兴；访谈中的一个词不是全片物件的自动解码器；记录日期与语境。

# 04 人物关系、表演与对白
* [表演的伦理边界与三种不宜使用的质量替代指标](performance-ethics-boundaries.md) - 不突然改变身体接触、不要求用真实私人创伤完成表演、不以撤换威胁；公开羞辱不是激发潜能；不用情绪强度替代关系变化、不用拍摄次数替代认真、不用真实痛苦替代虚构可信度。
* [潜台词不能成为分析者任意解释的许可证](subtext-is-not-a-license.md) - 一段台词有多种可能不意味着任何读法同样合理；检查已知事实、先前关系、当前目标与后续行为；给演员选一个主要行动并说明阻碍，而不是十种象征解释；潜台词可由不说话的人承担。

# 05 世界观、空间与置景
* [建筑空间、拍摄空间与银幕空间不能混淆](architectural-shooting-screen-space.md) - 真实建筑不自动适合拍摄；片场连续不等于成片连续；不可能空间也可有形式规则；AI 生成空间尤其需要跨镜头验证，保存关系约束而不只是风格参考图。
* [历史、文化与非虚构材料在空间设计中的证据边界](historical-cultural-nonfiction-evidence-in-space.md) - 区分可核对年代事实、合理复原与主动风格化；文化参考具体到地区时期群体语境；有参考不等于已理解，研究应围绕行动问题；非虚构介入要记录；资料不足时限制细节而非用视觉细节制造超过资料的确定感。

# 06 信息分配、视点与留白
* [广告与说明型作品：清楚不等于没有导演性](clarity-in-ads-and-explanatory-works.md) - 开场说结果再用过程建立可信度，或从需求情境进入再说明产品角色，取决于任务而非先藏产品更艺术；区分必须准确的事实、示意、感官联想、号召；抽象动画不得暗示真实微观过程；平面要分析实际发布组合。
* [不同媒介中的同一信息并不相同](same-information-differs-across-media.md) - 电影用进入时间控制发现，单张照片只能安排图内层级与语境；字幕、标题、缩略图、预告片、商品页都可能提前说明原片保留的未知；每一独立版本接受自己的信息检查，团队不把完整简报脑补进短片。
* [隐瞒的合理性、误导的边界与来源可信度](withholding-legitimacy-and-misdirection-boundaries.md) - 人物为什么不说要在关系中成立；作品为什么不展示要检查限制是否持续有条件；不可靠叙述不是所有矛盾的万能解释；公平性是提供足以参与的条件；可信度与信息量分别设计；不可靠有几种不同情况。

# 07 桥段、场景行动与情节
* [冲突不等于吵架，阻力不等于反派](conflict-is-not-arguing.md) - 两个人都出于善意仍可能需要不相容的事；阻力可来自时间、身体、知识、空间、规则、天气、物件失灵或不愿承认的需要；对方不是主角成长的练习器；冲突强度不等于音量。

# 08 叙事顺序、时间与节奏
* [认知研究可以启发什么，不应被拿来证明什么](cognitive-research-inspire-not-prove.md) - Zacks 等的事件知觉框架启发检查观众何处需更新目标、地点、因果或行动阶段，不能推导每个剪切等于事件边界或每隔几秒刺激大脑；Smith 的注意力连续性不覆盖全部情绪与价值经验。
* [交叉剪辑不自动等于同时发生](cross-cutting-is-not-simultaneity.md) - 两个空间来回切换可表示同时行动、主题比较、记忆侵入或纯节奏；甲赶往失物招领与乙整理箱子交替，可能让人以为同一只箱子且同时；维持时间关系的线索；声桥既能保持连续也能隐藏断裂。
* [叙事秩序与观看信任：短暂失向、持续开放、没有规则的混乱是三种情况](narrative-order-and-viewer-trust.md) - 第一种靠层级标记、重复细节与后续对照；第二种可不提供唯一时间线；第三种要诚实承认未找到组织而非解释成时间的流动性；分析非线性不强补唯一真实时间线；真实事件材料的重排可能改变因果印象。
* [镜头时长计量有用，但平均值远远不够：记录口径与一个可复核的虚构分析](shot-length-metrics-beyond-average.md) - A＝2、2、2、14 与 B＝5、5、5、5 平均相同分布不同，位置改变又不同；同时长段落画内运动、对白密度、声音事件仍可不同；记录转场计时、片头片尾、重复镜头、版本、帧率；没有完整视频不能靠截图数量猜节奏。

# 09 调度、摄影与画面
* [空间关系与连续性：规则是帮助理解的资源，不是不可违反的戒律](continuity-rules-as-resources.md) - 视线、运动方向、轴线、画面位置、动作接续帮助建立关系；越轴、跳切可成为表达，但要知道它们让什么信息变得困难、有无其他线索支撑；犯规的切换可因动作声音空间标记仍清楚，守轴的段落可因缺关系前提而迷惑；检查注意如何被交接。
* [透视、焦点和镜头参数的认知边界：相似图像可由不同参数得到，单帧不足以唯一反推](lens-parameters-cognitive-boundaries.md) - 改变观察位置改变透视，仅改焦距主要改取景范围，实拍常同时改距离；正式项目用真实元数据与测试；焦点不只是主体清楚背景虚化；焦点、遮挡、景深不是独立意义按钮；静态测试漂亮不代表整段表演可用。
* [光、美术与声音不是摄影的附属输入](light-art-sound-not-subordinate-inputs.md) - 门的宽度决定两人能否同时出现，墙面反射影响人物与背景关系，服装材质影响动作和高光，画外声改变注意方向；关键动作在阴影里可能是有意限制也可能是光位与调度冲突；把共同问题说清，好的美术或声音提议可减少不必要镜头。
* [长镜头与覆盖：不做审美身份判断；覆盖不是能拍的角度都拍一遍](long-take-vs-coverage-no-identity-judgment.md) - 选择前问场景依赖什么：多个行动同时、连续身体变化、细节比较、时间省略、反应分配；覆盖的价值在于支持哪些真正不同仍成立的剪辑路径而非机位数量；过度覆盖占用排练时间，不足则无法修复；主动限制后期要拍前验证。
* [摄影决定的不只是好看，还有观看关系：把镜头方案写成观看许可，而非摄影机指令清单](shot-as-viewing-permission.md) - 一个镜头同时做选择与排除、安排相对关系、给予观看距离、让某些动作先被注意、决定跟随或脱离；这里拍近景只是实现层，要问为什么此刻接近、接近什么；每个关键镜头先写观看任务；景别不是情绪词典；观看许可不是心理控制。
* [从单镜头美感转向镜头之间的差异：同时保存镜头内部任务与镜头之间的变化](shot-to-shot-difference-over-single-shot-beauty.md) - 近景是否有力取决于此前距离，突然稳定是否显著取决于之前运动，空镜是否成为余波取决于接在什么行动之后；形式例外若与关键变化相称可获突出地位，也可能重新建立后半段规则；不因现场偶然拍得漂亮就放入。

# 10 灯光、色彩与氛围
* [气氛特殊效果不能代替场景机制：加入前先问它改变什么，用删除测试检查它承担了什么](atmospheric-effects-cannot-replace-scene-mechanism.md) - 烟雾、逆光、反射、水面、闪烁、投影提供形式资源也增加实施安全连续性交付风险，由专业人员评估；唯一理由是别人这样拍很高级不足以确定方案；在草图或安全原型中移除效果观察哪些关系消失；效果只掩盖缺少行动或空间层级时回到上层修订。
* [人物呈现与美化的边界：先说明作品需要什么，参与者理解拍摄与修饰安排](character-presentation-and-beautification-boundaries.md) - 不同人物肤色年龄身体服装需具体观察，不把一种统一外观当所有人的理想；不在没有依据时把皮肤状态或身体特征改写为人格品质；判断真实时问是材料纹理保留还是生活条件可信、是没有修饰还是没有误导；广告前后对比检查是否因光妆角度后期暗示超出证据的效果。
* [颜色与情绪的研究能支持到哪里：词与情绪概念的关联任务不是灯光配方；光色研究的证据审查](color-emotion-research-limits.md) - Jonauskaite 等 2020 年 30 国 4598 人把 20 种情绪概念与 12 个颜色词联系，呈现共享模式与语言地理差异；不能保证某种墙面光源肤色在所有观众中诱发同样情绪；审查研究用色词色块图片还是影片、测量联想偏好自报还是行为、是否涉及因果。
* [物质、光谱、相机与显示：技术可信不能省略；色彩管理与创作外观需要两种交接语言；调色不是修复一切的最后保险](material-spectrum-camera-display-technical-credibility.md) - 肉眼相近的光源不保证在相机服装产品上相同；TLCI 评估电视相机语境下光源色彩再现一致性，不评价布光是否适合这场戏；ACES 组织色彩数据与变换，不决定人物冷暖；同时保存创作意图参考与技术解释信息；调色测试提前到材料与服化确认阶段。

# 11 声音设计与音乐
* [跨设备与可及性：需要保护的是作用而不只是文件；交付前的声音审查单](cross-device-accessibility-protect-function.md) - 影院耳机外放展示空间不是相同聆听条件；每个交付方案写清主要观看环境并实际检查；补充不能随意改变悬念顺序；WCAG 预录字幕包含理解所需的非言语声音，字幕不只是台词转写；未识别的门外声先描述可听性质而非宣布母亲回来了；技术检测与创作判断各有结论。
* [实证研究怎样帮助而不取代导演判断；把音乐表达的情绪、人物的情绪、观众的感受与观众的评价拆成四层](sound-music-empirical-research-limits.md) - Boltz 2004 提示声画在记忆中可能关联，不能推出一致就更有艺术价值；Ansani 2020 两项研究 118 与 92 人部分指标随音乐条件改变但非全部显著；眼动瞳孔不等于感动喜爱购买；四层独立记录不平均成情绪有效性分数。
* [要设计的不是配乐，而是声音在作品中的全部工作](sound-whole-work-not-just-score.md) - 言语、呼吸、动作声、环境、音乐与安静可分别说明事件、创造画外空间、改变距离、建立节奏，也可能竞争；Thom 主张声音应影响写作和视觉构想；音乐负责情绪／音效负责真实／对白负责信息的三分法过于简单。

# 12 整体成片与媒介适配
* [可及性不是最后贴上的文字](accessibility-designed-not-appended.md) - WCAG 预录字幕包含理解所需的非言语声音，音频描述涉及重要视觉内容的可访问表达；与专业人员共同处理谁在说话是否此时识别、声源能否直接命名、哪些行动必须描述、描述能否进入声音间隙、何时需替代版本；不是保留悬念与提供可及性二选一。
* [广告：有效不等于情绪最强，转化不等于全部艺术价值](advertising-effective-not-strongest-emotion.md) - 任务可能是识别、理解、记忆、建立关联或促进行动，创作前明确本次优先与不应同时强加的目标；品牌进入表达结构的方式不只口播特写末帧；戏剧夸张、感官隐喻与事实演示分清；投放指标受受众位置频次预算影响，艺术评价与商业评价分别记录。
* [纪录与实验作品：评价前先辨认作品的承诺](documentary-experimental-identify-promise-first.md) - 纪录中不同时间地点语境的材料并置形成新关联，检查是否产生未经证实的因果印象，不以所有剪辑都是建构免除事实责任；DAWG 框架强调持续反思创作关系与参与者自主性，后期与发行也属于关系过程；实验影像不因无情节判失败，也不因自称实验免于讨论形式是否发展。
* [素材、版本与作品不是同一个东西：单条最好未必全片最合适；把局部好看翻译成在这里起什么作用](footage-version-work-are-not-the-same.md) - 一条表演是局部事件，一组素材是可选范围，一个剪辑版本是特定关系的组织，作品还包含声音颜色文字比例放映条件；动人的母亲近景放在女儿提出离开前会改变整场理解；整体评审做两次反向追问：局部提供了什么、作品为保留它付出了什么。
* [声音、视觉效果与调色不是三个独立装饰层](sound-vfx-color-not-three-decorative-layers.md) - 声音提前进入可能改变镜头停留时长，效果新增细节可能使原切点不留辨认时间，调色强化背景可能改变动作重点；各部门围绕同一份当前剪辑与问题清单；ACES 处理解释一致性不解决创作取舍；效果评审区分物理错误、审美偏好、信息过载与被允许的非写实规则。
* [翻译和本地化会改变时间、关系与含混程度](translation-localization-changes-time-relations.md) - 某种称呼可能明确人物身份而另一语言版本保持模糊；简短回应可能需要较长文字影响阅读时间与反应镜头；旁白语速不宜无限加速；删减优先判断哪些是理解前提；不能删掉限定条件却保留更强的产品结果描述；记录原段落功能而非逐字对应；翻译判断需语言文化能力。

# 13 导演个性、表达与伦理
* [作者论的价值与限度：追踪倾向，不神化控制](auteur-theory-track-tendencies-not-control.md) - Sarris 1987 回顾演讲重审早期表述与过度英雄化倾向；Wartenberg 把作者性视为有争议问题；启发是把导演贡献说明得更精确：持续提出的问题、选择整合的关系、来自合作者的发明、不由他控制的条件；比较不同题材时期合作者资源；允许保留共同实践的归因。
* [风格鲜明并不能自动免除事实责任](style-does-not-exempt-factual-responsibility.md) - 广告的夸张、纪录的诗性结构、历史影像的重构、生成图像的逼真外观都影响观众把什么当成事实；这是我的个人表达不能成为伪造主创证言、捏造真实人物行动或夸大产品功效的理由；可创造虚构但明确作品承诺的身份；事实准确也不意味没有形式选择。
* [风格成长可能表现为变化，而不是越来越像自己](style-growth-may-look-like-change.md) - 虚构导演早期固定远景拍争执，后为听力受限人物用听觉视点与局部近景，再在广告用物件形态接续代替争执；更深的持续关切（一个人或对象如何被允许进入我们的注意）只能作为待验证假设；变化可来自新问题合作者资源媒介，不必是背叛也不自动是进步；评价成长问选择是否更准确更有发现力。

# 14 拉片研究与迭代工作流
* [AI agent 工作边界：知识包不是已经具备能力的证明](ai-agent-working-boundaries.md) - agent 可协助检索归类建立问题比较文稿整理版本提出原型；能否直接理解视频读取音轨测量时间运行工具须由实际环境确认；没有完整素材时输出覆盖范围和待检验项；禁止编造时间码镜头数量参数原话样本观看经历测试结果；同一模型连续一致评价不等于独立评审；外部发布费用支出需明确授权。
* [跨部门交接：下一步必须真的消费当前决定；创作事实、批准状态和下一动作分别标清](handoff-must-consume-current-decisions.md) - 已写在导演阐述里不等于摄影声音剪辑已获得可执行信息；同一场景不应在剧本里已和解、分镜里仍试探、配乐里提前庆祝、剪辑评价里又要求悬念；批准方向不等于批准全部镜头；最小闭环：当前决定→对应产物→核对结果→是否继续生效；旧版本为什么危险；不把流程控制变成表格堆积。
* [这十四个模块共同指向什么](what-fourteen-modules-point-to.md) - 研究不是给作品贴更精致的标签；创作不是让每个部门把表达推到最强；迭代不是不停增加说明和防御规则；整套方法服务于让理解经过可追溯的选择变成能实际观看和聆听的关系，再根据证据经验与合作持续修正；导演判断可以有个性也可以有不确定性。
