# 原则

1. 对白翻译不只替换词语。导演与翻译及字幕团队核对关键人物关系，而不是只核对字面意思。
2. 旁白语速变化可能需要重排信息，不宜无限加速以符合原语言长度。必须删减时优先判断哪些是理解前提、哪些只是修辞装饰。不能在一个版本中删掉限定条件却保留更强的产品结果描述。
3. 对带双关、语气或文化前提的桥段，记录原段落的功能：回避回答、缓和关系、显示专业习惯还是明确拒绝。新的表达是否实现同样功能，比逐字对应更接近导演的问题。
4. 翻译者的具体判断需语言与文化能力支持，不能由不懂该语言的 agent 自动保证。
