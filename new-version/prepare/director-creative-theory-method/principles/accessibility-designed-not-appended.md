# 原则

1. 字幕不仅包含对白，还传递理解所需的非言语声音信息；音频描述涉及重要视觉内容的可访问表达。
2. 导演与专业人员共同处理：谁在说话是否应此时被识别；声音来源能否直接命名；哪些视觉行动必须被描述；描述能否进入现有声音间隙；何时需要替代版本。
3. 可以设计准确且不提前泄露身份的描述，也可能需要重新组织段落，使关键体验不只依赖一种感官。
4. 具体适用规范、语言和交付要求按实际项目核对；本篇没有把某条技术指南自动变成所有场景中的法律义务。
