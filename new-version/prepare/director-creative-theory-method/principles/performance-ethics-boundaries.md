# 原则

1. 导演不应突然改变身体接触、要求演员用真实私人创伤完成表演，或以撤换角色威胁其接受原先未同意的动作。可讨论的是安全的实现方法、可接受的范围和替代方案。
2. 公开羞辱不能被称为"激发潜能"；拍摄效率不应建立在参与者不敢提出问题上。事故与健康事项交给适当专业人员，不由导演或 agent 凭经验处理。
3. **不用情绪强度替代关系变化**：大哭可能没有使场景前进，微小的拒绝却可能改变全场。
4. **不用拍摄次数替代导演认真程度**：无方向的重复消耗表演者而不增加可用材料。
5. **不用真实痛苦替代虚构可信度**：参与者真正受伤或被羞辱不是艺术成立的必要证据。

## 可复核的场景记录

具体刺激、实际行动、对方回应、策略变化、摄影与剪辑是否保留了变化、仍有哪一种合理解释——比"某演员今天状态很好"更能支持下一步。
