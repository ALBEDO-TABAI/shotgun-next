# 原则

1. 先说明作品需要：职业动作的清晰度、生活状态、特定角色的人工造型，还是商业肖像的某种呈现。参与者应理解相关拍摄和修饰安排，尤其当后期会显著改变其外观时。
2. 光与妆发可服务角色，但不在没有依据时把皮肤状态或身体特征改写为人格品质。一个人物显得疲惫，不意味着必须用某种固定色调或面部纹理表达。
3. **判断"真实"时要问**：是材料纹理被保留，还是人物生活条件可信？是没有明显修饰，还是作品没有制造误导？不同真实诉求可能冲突，需要明确而不是用一个词盖住全部取舍。
4. 产品广告检查前后状态比较是否因光、妆、角度或后期变化而暗示超出证据的效果。
