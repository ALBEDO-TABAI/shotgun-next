# 原则

1. **真实建筑不自动适合拍摄**：可能缺乏机位、声音条件、供电或安全通道。保留其生活逻辑再调整实现；"真实场地"不是免于设计的保证。
2. **片场连续≠成片连续**：真实相邻的房间在剪辑中可能毫无联系；不相邻地点可组织成连贯空间。导演维护的是作品要求观众理解的关系，同时保存拍摄连续性记录。空间作弊是正常手段，问题是它是否使必要行动或事实关系发生非预期矛盾。
3. **不可能空间也有形式规则**：梦境、舞台化广告、实验影像可破坏地理一致，但必须确定哪些关系仍稳定：人物走向、动作接续、物件变化、声音方向或形式重复。所有规则都不稳定时观众无法形成期待——可以是被研究的体验，不能用"超现实"掩饰未检查的错误。
4. **AI 生成空间跨镜头验证**：同一名称的场景不保证房门、窗户、台面高度和道具位置一致；每个镜头合理，拼接后仍可能改变可见范围和行动路径。保存关系约束："柜台在入口与工作区之间""人物必须从柜台左侧进入后室"比"同一家复古店"更可检查。工具无法稳定呈现关键道具状态时，修改实现、补拍局部或简化场景，不把"模型会理解"当生产依据。
