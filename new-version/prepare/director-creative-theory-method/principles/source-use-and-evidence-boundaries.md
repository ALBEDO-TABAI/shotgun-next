# 要点

本包所有 14 篇的"来源地图与阅读边界"共用一套约定。任何一条判断在写入方案、报告或 skill 输出之前，都先问：它来自哪一类来源，那一类来源最多能支持到哪里。

| 来源类型 | 能支持 | 不能自动支持 | 本包里的镜像 |
|---|---|---|---|
| 原作者理论（Bordwell、Rabiger、Katz、Chion、Murch、Mamet、Bresson 等） | 概念区分、分析尺度、术语 | 某部具体作品一定如此；理论作者之间彼此一致 | [references/](/references/) 中"原作者理论" |
| 主创证言（导演、摄影、剪辑、美术、声音的访谈与文章） | 参与者报告的过程、意图、协作安排 | 完整决策链；成片效果；对所有观众成立 | "主创证言／实践文章" |
| 实证研究（眼动、镜头长度统计、色彩情绪、音乐感知等） | 在其样本、材料、测量项目内的关系 | 跨类型、跨文化、跨观看情境外推；直接推出创作处方 | "实证研究／理论论文" |
| 机构／技术材料（ASC、Netflix、Dolby、可及性指南、教学大纲） | 特定语境下的实践安排与技术条件 | 作为艺术判断的依据；跨机构通用 | "机构／技术材料""大学教学材料" |
| 本包综合（工作定义、分类轴、检查表、自拟案例） | 组织问题、给出可操作的起手方式 | 作为学界既定分类或团队正式口径 | 各篇标明"本包综合"的框架与模板 |

**六条通用规则**

1. **观察与解释分开保存。** 六种陈述身份见 [证据协议](/frameworks/six-evidence-statement-types.md)；账本落在 [E-H-D-T-V 证据账](/frameworks/evidence-ledger-e-h-d-t-v.md)。
2. **样本不外推。** 认知与感知研究只启发、不证明（[认知研究只启发不证明](/principles/cognitive-research-inspire-not-prove.md)、[色彩情绪研究限度](/principles/color-emotion-research-limits.md)、[声音音乐实证限度](/principles/sound-music-empirical-research-limits.md)、[镜头参数的认知边界](/principles/lens-parameters-cognitive-boundaries.md)）。
3. **访谈是参与者报告，不是决策链。** 见 [访谈能支持什么](/principles/what-an-interview-can-support.md)、[作者归因四问](/frameworks/authorship-attribution-four-questions.md)。
4. **文献事实 ≠ 本次观看事实。** 引用论文分析、预告片、剧照时标明"未直接观看发行版"；量化指标不替代判断（[量化限度](/principles/quantification-limits-in-style-analysis.md)、[镜头长度指标](/principles/shot-length-metrics-beyond-average.md)）。
5. **自拟案例只作教学。** 修理铺、洗衣店、母女告别、45 秒洗护片等均为本包自拟，用来演示方法，不是行业实证。
6. **Agent 输出的置信度不是校准概率。** 见 [AI／Agent 工作边界](/principles/ai-agent-working-boundaries.md)。历史、文化与非虚构题材另有事实责任（[空间中的历史文化非虚构证据](/principles/historical-cultural-nonfiction-evidence-in-space.md)、[风格不免除事实责任](/principles/style-does-not-exempt-factual-responsibility.md)）。

# 适用边界

- 这是使用边界，不是阅读禁令：来源可以广泛阅读，但写进结论时按上表降级。
- 团队若要把"本包综合"升级为正式口径，须在 [log.md](/log.md) 记录决定与责任人。
