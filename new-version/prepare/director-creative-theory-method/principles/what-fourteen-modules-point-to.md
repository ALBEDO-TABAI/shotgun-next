# 原则

1. 研究不是给作品贴上更精致的标签；创作不是让每个部门把自己的表达推到最强；迭代不是不停增加说明和防御规则。
2. 整套方法服务于一件事：**让对人、世界、媒介和任务的理解，经过可追溯的选择，变成能够实际观看和聆听的关系；再根据证据、经验与合作持续修正。**
3. 导演的判断可以有个性，也可以有不确定性。知识包帮助其看得更具体、沟通得更准确、承担取舍，而不是假装艺术已被一套自动公式解决。
4. **最终工作原则**：用理论提出更好的问题，用材料约束解释，用方案承担选择，用观看检查结果；既不让流程代替创作，也不让"个人感觉"代替所有证据。
