# 模板 · Templates

可套用的记录卡与表格：证据卡、取舍卡、工作卡、状态表、验收卡等。

# 01 导演风格识别
* [跨作品比较矩阵](cross-work-comparison-matrix.md) - 作品与版本／相关场景条件／手段组合／例外／合作者与任务差异／支持或修正哪条规则；不为矩阵整齐强行把不同场景视为同等条件。
* [证据卡 E-___](style-evidence-card.md) - 单条风格证据的记录卡：研究问题、对象版本、覆盖身份、观察事实、编码口径、声画关系、功能与替代解释、意图与效果材料、适用范围、反例、信心、来源定位。
* [风格规则卡 R-___：用关系描述，不用导演名字代替规则](style-rule-card.md) - 条件性规则的记录卡：适用作品、场景条件、手段组合、信息时间声音关系、默认与例外、基线、支持与反例证据ID、功能解释、归因边界、可迁移原则与验证方法。

# 02 导演职责与跨部门整合
* [导演取舍卡](director-tradeoff-card.md) - 决定ID与版本、共同问题、不可破坏的关系、候选A/B收益代价、选择理由与未验证假设、实现人与共同确认人、接收材料、批准范围、重检触发、验证结果。
* [会议不讨论所有问题：单问题议程示例](single-question-meeting-agenda.md) - 以母女告别为例：只问换容器这一转向能否被不知剧本的人看见；演员演完整动作、美术说明放置、摄影给两个可见范围、剪辑粗拼时长、声音试有无车辆提示；不顺便决定全片色调。

# 03 创作出发点与导演意图
* [意图归因记录](intent-attribution-record.md) - 具体选择与版本、可观察事实、局部功能解释、意图自述来源与日期、过程资料有无、其他合理解释、本次能确认到哪一层、什么材料会改变结论、禁止外推范围。
* [命题转译表](proposition-translation-table.md) - 观察或起点、材料身份、关注问题、不预先规定的答案、人物行动或形式变化、观众必须知道、允许开放、希望产生的体验、支持证据、替代读法、关键假设与验证。

# 04 人物关系、表演与对白
* [演员工作卡](actor-work-card.md) - 场景版本人物、已知事实、对方此刻重要性、希望对方改变什么、不愿暴露什么、当前策略与动作、哪种回应会改变策略、身体与道具任务、可探索部分、必须稳定项、需协商的边界。
* [排练记录](rehearsal-record.md) - 本轮只重点验证的问题、给演员的工作指令、实际发生的行为、对手回应是否改变下一动作、摄影声音条件是否保留变化、新发现与剧本冲突、保留再试放弃理由、已同步的决定。

# 05 世界观、空间与置景
* [空间与道具检查表](space-prop-check-sheet.md) - 当前场景版本、进入位置与目的、必经关系节点、关键可见与可听范围、拍摄位置与人物视点差异、道具初始与每次动作后状态、影响下一场的后果、实际测试材料、尚未验证的条件。
* [世界规则卡](world-rule-card.md) - 规则名称、适用空间人物时段、日常怎样运作、谁有权改变、违反或例外的后果、支持规则的动作或物件、观众必须知道到什么程度、团队需知但不必展示、资料来源／虚构身份、跨场景保持与允许变化。

# 06 信息分配、视点与留白
* [信息状态表](information-state-table.md) - 段落／时间范围／版本、世界事实、人物 A/B 知道／相信／误解、观众实际获得的证据、希望形成的问题、可接受解释范围、不希望的基础误读、下一次更新触发、删除本段影响哪条依赖。
* [揭示检查卡](reveal-check-card.md) - 要揭示的内容、揭示前观众可能的判断、已有前提及位置、实际载体／可注意时长／竞争信息、人物为何此刻得知或不知、揭示后哪些旧材料被重新理解、声音与字幕是否提前给答案、反例或不公平处、试映证据。

# 07 桥段、场景行动与情节
* [反事实检查与最低成立条件](counterfactual-check.md) - 删去哪个动作转向仍成立、删去哪个理解断裂、换人物产品是否一样、最弱因果、最不可信选择、结尾是否用了前面条件、哪项声画只是重复；最低成立条件：不靠特定台词与音乐高潮，观众仍能辨认谁做了什么、什么变了。
* [桥段卡](setpiece-card.md) - 名称与位置、主要任务（行动／关系／信息／感知／形式／余波）、初始状态、实际做什么、限制与回应、关键变化及证据、最终状态、后果、必要前提、其他读法、各部门承担、可删与不能丢的证据。

# 08 叙事顺序、时间与节奏
* [节奏诊断记录](rhythm-diagnosis-record.md) - 问题段落及版本、原始说法、从何处感到等待或拥挤、六层各发生什么、最可能原因与替代解释、本轮只改变的主要变量、新增收益与损失、是否在整片中复看。
* [时间结构卡](time-structure-card.md) - 事件ID与故事时间、时间关系身份（明确／合理推断／开放）、呈现位置与时长、此次出现增加什么、因果或联想关系、观众此时知道什么、重复时改变的视点或信息、进出标记、压缩或删除损失什么。

# 09 调度、摄影与画面
* [覆盖与适配卡](coverage-adaptation-card.md) - 核心行动必须完整保留的部分、可通过剪辑省略的部分、覆盖镜头分别支持哪种有效版本、不能混用的表演或道具状态、横版竖版方形中必须保持的关系、字幕与产品文字占用区域、真实素材测试结果。
* [镜头意图卡](shot-intent-card.md) - 镜头ID／场景／版本、主要观看任务、人物此刻在做什么、观众应看见与暂不看见、人物调度的开始变化结束、摄影机与人物关系、焦点景别运动的功能、声音与美术必要条件、与前后镜头的连接、技术参数来源（已知／待测试／不适用）、替代方案与代价。

# 10 灯光、色彩与氛围
* [光色决策卡 L-___](light-color-decision-card.md) - 场景／版本／观看任务、必须可见、允许隐藏、空间与故事光源逻辑、人物与摄影机运动、光材质服化关系、颜色角色与变化触发、技术测试与显示条件、观察结果、体验解释及其他可能原因、跨镜头跨画幅风险、回退方案、各部门确认项。

# 11 声音设计与音乐
* [声音／音乐提示卡 Q-___](sound-music-cue-card.md) - 作品与剪辑版本、时间范围与触发动作、观众此时应知与仍不知、听觉视点与声源身份、前景声部／让位声部、承担的具体工作、进入退出方式、禁止提前宣布的情绪或事实、参考可借鉴关系与不可照搬素材、素材来源授权与待核对、替代方案、字幕音频描述与设备风险。

# 12 整体成片与媒介适配
* [版本验收卡 V-___](version-acceptance-card.md) - 作品／版本／用途／语言／画幅、本版优先任务与不承担的任务、相对上版的变化及原因、事件信息表演空间时间检查、声画颜色效果文字检查、产品与事实审查状态、字幕音频描述及可访问版本、技术规格与实际观看条件、已确认的批准主体与范围、仍存在的风险限制或分歧、是否允许发布及依据。

# 13 导演个性、表达与伦理
* [个人表达章程 A-___](personal-expression-charter.md) - 持续关注的问题不只是主题名词、具体经验与观察来源、在这个项目中转化成什么情境、优先保留的观看／聆听关系、允许改变的手段、不应强行套用的旧习惯、真实参与者与合作者的边界、作品的事实身份及可能误解、什么证据会使我修改当前方案、完成后怎样检查是否只是重复自己。

# 14 拉片研究与迭代工作流
* [最小交付协议与停止条件](minimum-delivery-protocol.md) - 任务、当前有效版本、材料覆盖范围与缺失、本次要解决的问题、主要观察与来源定位、功能／意义假设及反例、已批准的决定、本次修改及影响范围、实际执行过的验证、尚未执行不能声称完成的验证、剩余风险及允许用途、下一动作执行者与触发条件；合理停止的五个条件。
