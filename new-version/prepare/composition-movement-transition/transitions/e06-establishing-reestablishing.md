> 镜头衔接技法卡 E06。卡中的“表达”均为有条件的候选，不是技法的固定情绪翻译；示例均为假设设计（见 [证据边界](/references/evidence-boundaries.md)）。

# 操作与机制

为后续局部提供人物、场地、行动路线或关系参照；重新建立镜头则在关系变化后更新这个参照。它不必永远是最远景，也不必永远位于场景开头。[S02](/references/s02-yale-film-analysis-editing.md)

# 选用条件

观众需要理解谁在哪里、路径如何相连、什么位置改变了；或者想在局部之后揭示整体关系。

# 切点选择

在关键行动前建立空间，可让行动被预期；在行动后才给整体，可能改变对先前局部的理解。延后是否有效取决于前段允许多大程度的未知。

# 两侧约定

建立的对象应与随后镜头有关；返回共同画面时，需要让新的站位、缺席或距离变化可辨。

# 失败与替代

用一幅漂亮无人空景当作建立镜头，却不能定位随后人物；或每次换角度都回大全景，造成重复。可用带关键地标的中景、移动显露、声音与动作共同建立关系。

# 假设测试

两人从门走到桌边，比较入口建立、到桌后建立、完全不建立的版本，检查观看任务是否真的需要完整路线。
