# Transitions · 镜头衔接、剪辑与切点技法卡库 E01—E20

回答“观看如何在两个状态之间交接”：动作、视线、轴线、图形、时间、声音与段落。

# 原则与方法
* [“衔接”比“转场效果”更大](transition-beyond-effects.md) - 先决定两镜头的关系（继续、说明、结果、省略、同时、类比、对撞、拒绝关联），再决定接缝实现。
* [跨切点需要区分的几个方向](directions-across-the-cut.md) - 世界方向、屏幕方向、相机运动方向与观众预期关注点四者不一定相同，需注明参照系。
* [切点选择的实际工作法](cut-point-workflow.md) - 先粗粒度定状态顺序再细调帧位；关键接缝比较提前/同步/延后三候选；按材料类型限定结论。

# 连续与视点
* [E01｜直接切换、景别变化与视点差异](e01-straight-cut-scale-change.md) - A 直接换成 B；是否突兀取决于内容、位置、时间、声音和形式关系，硬切不等于糟糕剪辑。
* [E02｜动作匹配 Match on Action](e02-match-on-action.md) - 两个视点承接同一动作，在画面变化中保持动作持续；需核对手别、状态、阶段与方向。
* [E03｜视线—对象—反应与主观视点](e03-eyeline-object-reaction-pov.md) - 视线—对象—反应的镜头次序建立“谁看见什么”的解释条件。
* [E04｜正反打：对话不是台词乒乓球](e04-shot-reverse-shot.md) - 相对观察位置间切换，不要求一人一句、角度镜像或时长均等。
* [E05｜轴线、屏幕方向与重新定向](e05-axis-screen-direction.md) - 以当前关系/路径为参照保持或有意改变观看侧；180° 约定是方向组织工具而非唯一正确。
* [E06｜建立镜头与重新建立镜头](e06-establishing-reestablishing.md) - 为后续局部提供人物、场地、路线参照；关系变化后以重新建立镜头更新参照。
* [E07｜注意位置承接 Eye-trace Planning](e07-eye-trace-planning.md) - 设计切前主要关注区与切后可定位对象的位置关系；无测量不宣称真实注视路径。

# 形式关联
* [E08｜图形匹配 Graphic Match](e08-graphic-match.md) - 以形状、轮廓、色块、位置相似建立镜头关系，可跨地点与尺度，是类比而非同一事件。
* [E09｜运动匹配与方向接力](e09-movement-match-direction-relay.md) - 延续屏幕运动方向、轨迹、节拍或能量阶段；不同对象接力属形式关联。

# 结构与时间
* [E10｜插入镜头与切离镜头](e10-insert-cutaway.md) - 插入镜头让场内细节独立阅读，切离镜头转向主动作外的相关对象；以功能记录。
* [E11｜省略剪辑 Ellipsis：保留因果，不必保留全部过程](e11-ellipsis.md) - 删去部分事件时间、保留因果；必要操作步骤不可随意省略。
* [E12｜跳切 Jump Cut：让时间缺口或形式断裂被察觉](e12-jump-cut.md) - 在足够相似的主体/构图中出现不连续变化，让时间缺口或形式断裂被察觉。
* [E13｜重叠剪辑与重复：延长某个时刻](e13-overlapping-repetition.md) - 相邻镜头重复部分动作以延长某个时刻，轻微重叠与明显回看程度不同。
* [E14｜交叉剪辑与平行组织](e14-cross-cutting-parallel.md) - 在不同动作线或场景间交替，可建立同时性、影响、对比或类比；交替本身不证明同步。
* [E19｜速度变化、定格与时间形态衔接](e19-speed-change-freeze-frame.md) - 变速、定格等时间处理改变动作在播放中的展开；帧率、快门、播放速度与插帧需区分。

# 声音与过渡
* [E15｜J-cut、L-cut 与声音桥](e15-j-cut-l-cut-sound-bridge.md) - J-cut 声音先于画面、L-cut 声音延续到下一画面；声音桥范围更广。
* [E16｜遮挡、甩镜与隐藏剪切](e16-hidden-cut-occlusion-whip.md) - 借遮挡、强运动等降低接缝显著度；隐藏剪切不等于一次拍摄，也不保证动作可信。
* [E17｜叠化、淡入淡出与双重图像](e17-dissolve-fade.md) - 叠化让两幅图像短暂共存，淡入淡出过渡到底色；不自动等于回忆或时间流逝。
* [E18｜强反差切换与骤切 Smash Cut](e18-smash-cut-contrast.md) - 通过尺度、动静、声强、情境的突变形成有意重音；需先有可感知基线。

# 段落
