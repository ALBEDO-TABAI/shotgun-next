| 输入材料 | 可以可靠开展的工作 | 应保留为未知的内容 |
|---|---|---|
| 完整视频及音轨 | 镜头变化、接缝、时序、声画关系分析 | 未被外部记录证实的器材、意图、作者分工 |
| 无声完整视频 | 视觉关系与动作连续分析 | J/L-cut、声音触发、声场定位与整体声画节奏 |
| 多张截图 | 可见构图与可能的状态变化 | 完整运动路径、实际速度、隐藏剪切、真实切点 |
| 分镜表／文字稿 | 预期表达、矛盾检查、拍摄与剪辑计划 | 成片已经成功实现了这些条件 |
| 只有需求形容词 | 提出候选和需确认的任务 | 唯一正确风格、固定参数、确定观众反应 |

材料缺口会改变结论强度，不必使所有工作停摆。可以在已知范围内提供方案，把依赖未知信息的分支明确标出。
