> 构图技法卡 C09。卡中的“表达”均为有条件的候选，不是技法的固定情绪翻译；示例均为假设设计（见 [证据边界](/references/evidence-boundaries.md)）。

# 操作与机制

相机高度、相机俯仰、主体姿态分别影响画面；它们应拆开记录。低机位并非一定仰拍，高机位也可水平看向远处。

# 选用条件

需要看见台面、脚步、面部、头顶关系或建筑高度；需要改变观众与对象的相对位置。先解决可见性和关系，再讨论权力、脆弱等候选读法。

# 时机与过程

同一场景从坐姿高度转为站姿高度，可能在构图上重新分配人与环境；变化是否跟随人物站起、提前发生或独立发生，需要单独设计。

# 前后镜头

对话中不同高度和视线坡度可能有意不对称；但要避免对方实际站位与画面暗示互相冲突。拍摄对象高度不同，不必把两个镜头参数强行做成镜像。

# 失败与替代

为“威严”过度仰拍，结果只突出鼻底或使包装字面难读。替代是体积、尺度对比、留白和场景关系，而非继续降低机位。

# 假设测试

先固定人物动作拍三种高度，再检查脸、手和空间各失去什么；把“关系变化”写出来，不只记录情绪形容词。[S01](/references/s01-yale-film-analysis-cinematography.md)[S03](/references/s03-pbr-projective-camera-models.md)
