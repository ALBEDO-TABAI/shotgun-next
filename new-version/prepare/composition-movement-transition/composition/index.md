# Composition · 构图技法卡库 C01—C16

回答“画面关系怎样组织”。每张卡含操作与机制、选用条件、时机与过程、前后镜头、失败与替代、假设测试。

# 原则与审查
* [构图使用原则：构图的最小单位不是一个漂亮位置](composition-principles.md) - 先写需要比较或发现的关系再决定位置；动态画面至少记录起幅、关系改变瞬间与落幅。
* [构图审查的最短版本](composition-review-checklist.md) - 复述要保留的关系→找支持与竞争线索→查动作全过程与相邻镜头→提出最小修正。

# 空间与平衡
* [C01｜中心、对称与轴向构图](c01-center-symmetry-axial.md) - 把主体放在中心或建立左右/上下可比较关系，用于稳定呈示、比较差异或让偏离可被觉察。
* [C02｜偏心、三分与不等量平衡](c02-off-center-thirds-balance.md) - 主体离开中心、把画面分配给环境或另一对象；三分线只是生成候选位置的工具。
* [C03｜留白、视线余量与动作余量](c03-lead-room-negative-space.md) - 在视线、动作或未出现对象方向留出（或压缩）空间，让等待与进入成为构图事件。
* [C04｜景别、比例与关系的可读尺度](c04-shot-scale-readable-proportion.md) - 按本镜头需要身体、表情、对象还是空间来决定景别与可读尺度。
* [C05｜前中后景与深度分层](c05-depth-layering.md) - 以遮挡、尺度、明暗、清晰度把对象分成前中后层，区别于景深。
* [C06｜框中框、遮挡与逐步显露](c06-frame-within-frame-occlusion-reveal.md) - 利用门窗、物体、身体形成局部边界，设计尚未显露—开始露出—足够辨认的显露过程。

# 图形、方向与视点
* [C07｜平面化、正面性与图形组织](c07-flatness-frontality-graphic.md) - 减弱纵深线索，让线条、轮廓、色块、重复与间距成为主要关系。
* [C08｜斜线、方向张力与滚转画框](c08-diagonal-direction-roll.md) - 对角关系与相机滚转分开处理；持续偏斜是常态，由平转斜才是事件。
* [C09｜俯仰视点、观看高度与参照物](c09-camera-height-angle-reference.md) - 把相机高度、俯仰角与主体姿态分开记录，先解决可见性再讨论权力等读法。

# 人物关系与注意
* [C10｜双人、群像与三角关系](c10-two-shot-group-triangle.md) - 把多人关系同时放入画框，用前后左右、朝向、距离与遮挡显示聚合或分离。
* [C11｜过肩、带前景与干净单人画面](c11-over-shoulder-dirty-clean-single.md) - 过肩/带前景保留关系参照，干净单人让反应单独成立；二者切换是关系组织的变化。
* [C12｜注意层级：明暗、清晰度、动作与语义协同](c12-attention-hierarchy.md) - 把明暗、清晰度、大小、位置、脸手与动作视为协同的注意资源，而非只看最亮点。

# 局部、俯视、动态与版式
* [C13｜局部、微距与触点构图](c13-detail-macro-contact.md) - 抽离表面、接触或结构，提高局部可辨认性，同时可能让对象身份暂时不确定。
* [C14｜俯视、平铺与拓扑关系](c14-top-down-flat-lay-topology.md) - 从上方组织对象，优先呈现位置、排列和路径（谁挨着谁、移动到哪里）。
* [C15｜动态构图：平衡—扰动—重组](c15-dynamic-composition.md) - 把构图设计为平衡—扰动—重组的可阅读状态序列，而非固定图案。
* [C16｜画幅、文字、裁切与系列构图](c16-aspect-ratio-text-crop-series.md) - 把画幅、文字、界面与预定裁切当作同一布局问题，覆盖横竖版与系列组织。
