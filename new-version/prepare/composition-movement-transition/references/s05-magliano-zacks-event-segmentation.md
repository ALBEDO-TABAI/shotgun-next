# 支持内容

研究区分空间／时间／动作的连续程度；其摘要报告动作不连续与事件分段的关系最显著，空间时间变化的影响相对较小。

# 使用边界

这是特定影片和实验条件下的结果；不能推广成所有类型影片的因果权重，不把脑成像结果转成剪辑自动评分或普遍时长公式。
