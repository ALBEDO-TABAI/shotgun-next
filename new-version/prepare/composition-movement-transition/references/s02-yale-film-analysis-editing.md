# 核读范围

剪切、匹配、时长／节奏、连续性、蒙太奇、省略及相关段落文字。

# 支持内容

区分图形匹配、动作匹配、视线关系、连续与省略、时间重复、剪辑与场面调度及声音的共同组织。

# 使用边界

这是术语和分析教学，不是随机对照研究；其个案解释不自动适用于本包的假设案例。本包未复制课程中的影片逐镜头分析，也不把180°约定改写为唯一合法方法。
