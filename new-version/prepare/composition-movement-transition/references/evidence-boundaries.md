# 如何理解来源类型

**原创实证研究**用于约束关于注意、事件理解或神经反应的判断；**作者理论与批评**提供研究问题与解释框架；**官方教学材料／技术文档**用于核对术语或几何机制；**制作参与者记录**说明具体项目为何作出某个选择。后者不是普遍因果证明，前者也不能直接变成艺术创作处方。

全文可公开访问与本次逐字核读全文是两件事。以下只声明实际使用到的范围，不以“已查阅”暗示读过每一页书或观看过每一个嵌入视频。

# 未作为已核读理论依据的扩展书目

Bruce Block 的《The Visual Story》与 Walter Murch 的《In the Blink of an Eye》是本次检索涉及的延伸方向，但未取得足以支撑深入转述的相应原始章节。因此本包没有把“对比／亲和的所有分类”、某种固定剪辑权重百分比或完整理论体系写成已核读成果。

这不表示这些著作不重要，而是避免把广泛流传的二手转述当成作者原论证。后续扩展时应在取得合法原文后补充精确版本、章节及适用范围。

# 推荐引用方式

引用本包的具体技法卡时，同时注明“工作化综合／设计建议”，并保留它关联的来源类型。引用原始研究结果时，直接注明作者、年份和研究条件。模板、假设案例与尚未执行的验收题，不应写成“实证验证通过”。
