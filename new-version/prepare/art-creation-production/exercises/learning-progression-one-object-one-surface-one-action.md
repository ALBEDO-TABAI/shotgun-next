| 阶段 | 练习 |
|---|---|
| 初学 | 一个物件、一个面层、一个动作：01 提出关系 → 03、04 做低风险小样 → 05 记录真实结果 |
| 进阶 | 同一主体的三个条件：静态近景、完整动作、另一交付比例；观察有效的材料和空间怎样受新条件影响，保留意图、改变实现 |
| 复杂 | 加入现成场地、多人操作、混合实拍和数字资产；每增加一个系统，回答它与已有对象怎样接触、交换什么信息、失效时找谁 |

小项目可将十张模板压缩为两三页；复杂项目再拆。字段不能改变任何实际工作就删掉；下游必须猜测某个关键关系就补上。完整性按消费需要衡量，不按文件数量。
