# 四方面

| 方面 | 问题 |
|---|---|
| 视觉 | 看起来怎样（近景断面／远景体量） |
| 行为 | 怎样动、被接触、承托 |
| 制造 | 怎样做出、哪些可替换 |
| 运行 | 重复使用、损耗、清洁、复位 |

同是石头外观，可能需要近景断面、远景体量、演员跪地接触或静物稳定支撑——不是同一选材题。RSC 的绘景与道具说明把演员接触、使用和耐久纳入工作，本包据此把视觉与行为放进同一份任务。

# 示例：香水附近的柔软前景

- **视觉：** 主要轮廓清楚、接触区细腻、近景边缘不露支撑；不需要夸张织纹。
- **行为：** 从遮挡转为显露，停点可重复，不拖动瓶身。
- **制造：** 面层和动作片可单独替换，控制点不进入反射。
- **运行：** 重复开启后仍可恢复，污染与压痕可识别；是否需要备用由实际损耗试验决定。

不先指定面料，也不把“柔软”理解成任何地方都不能有支撑。
