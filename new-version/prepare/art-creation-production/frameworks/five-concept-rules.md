# 五种规则

比例规则、材料规则、空间规则、时间规则、例外规则。规则不是越多越好。

# 香水教学例

| 规则 | 内容 |
|---|---|
| 比例 | 产品保持现实比例 |
| 材料 | 材料承担显露事件而不是背景花边 |
| 空间 | 主褶皱向主体收束 |
| 时间 | 物体保持稳定而材料变化 |
| 例外 | 最终段允许减少气氛以完成辨识 |
