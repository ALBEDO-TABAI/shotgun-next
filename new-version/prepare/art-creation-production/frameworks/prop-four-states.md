# 四个状态

拍摄前 → 动作中 → 动作后 → 复位后

每个状态写：轮廓、朝向、数量、内容物、表面、关键操作、允许变化。

# 主体件／动作件／替代件

近景精度的主体件未必适合特定动作；动作件即使外观相同，也可能因重量和手感改变表演。是否分件取决于使用，不默认每件三套。替代件必须在它要承担的镜头中比较，不能只核对商品名称。
