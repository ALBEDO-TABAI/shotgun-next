# 六个问题

1. 谁做？
2. 给谁用？
3. 用什么工具？
4. 有什么时间与技能？
5. 如何复制？
6. 怎样保存？

# 先信息结构，再风格

维修便条需要真实可用的信息顺序，菜单需要可读分类，信要有写作与折叠关系。先确定故事所需文字及被看见的时点，再选字形、纸张、墨色和老化；不用大量虚构细字填满却与人物操作不符。

# 在实际尺寸与镜头中打样

屏幕放大好看的细字实际可能读不清；纸面反光、透背、折线和背面入镜都要检查；拿起后的遮挡、旋转和手指位置会改变可见信息。静态扫描图不是动作测试。

# 同一世界要有生产差异

连锁机构统一印刷物、个人手写便条、临时价格牌不必同样精致；但不把“手写歪”当作自然的唯一形式。

# 边界

避免误用真实私人资料、有效凭证或可被误认作真实证件的制作；现实品牌或有权利限制的资产另作使用核对，研究参考不替代授权。
