# 三种任务

| 任务 | 回答 | 香水教学例 |
|---|---|---|
| 作品任务 | 它为什么存在 | 建立偏私人而非炫耀性的品牌联想 |
| 视觉任务 | 观众要经历什么 | 产品从一个被触碰过的空间里被发现 |
| 生产任务 | 团队必须制造出什么条件 | 可控的显露动作、精确包装、可用的反射环境、多版式画面 |

生产做对而视觉事件不成立，只是一张干净产品照；视觉说明动人而动作无法复位，也没有形成可用方案。

# 项目开头句式（本包建议）

> 为谁，在什么观看情境中，通过什么可见的关系或变化，使哪一种理解、感受或观看经验有机会发生；有哪些东西不能因此失去。

非商业作品可以把任务写为“持续保持尺度的不确定”“让前后两层无法完全对齐”，但生产目标仍需具体：哪些线应错位、变化是否可被经历、人工痕迹是否主动保留。

# 依据

ScreenSkills 的生产设计与美术指导能力清单同时涉及视觉意图、研究、摄影需求、设计发展与制作沟通；本包据此把“收到需求”视为开始建立可执行关系，而非只写一段视觉形容。
