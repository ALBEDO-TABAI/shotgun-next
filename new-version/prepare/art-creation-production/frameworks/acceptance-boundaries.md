| 边界 | 覆盖 |
|---|---|
| 观看 | 最近和最远使用距离；最大取景；不同交付比例；计划的相机运动 |
| 时间 | 开始、中间、结束与停留；运动材料最差状态可能在两者之间 |
| 操作 | 指定动作、必要复位、替代件、拆装和使用后状态；次数与条件由当前制作确定 |
| 处理 | 最终涂层、清洁、运输、导出与必要后期后再看（云状地布回顾提供具体提醒） |
| 专业 | 人员使用、承重、动景、电气、特殊材料由相应专业确认；HSE 是英国指导入口 |

艺术目标与运行目标分列：可以保留有意的遮蔽、不协调或未解读感；不能把未经控制的断裂、失效和危险自动解释成艺术语言。
