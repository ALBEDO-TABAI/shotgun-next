# 适用

需要在真实体量上出现图形、时间变化或叙事信息，而不是把影片投在墙上。纱幕投影资料说明表面、角度和环境光共同影响呈现；本卡扩展为实体表面测试。

# 起始布置

固定体量和投影位置，用简单网格与轮廓检查覆盖；明确哪些面需要图像、哪些保持暗或留空；先解决几何，再处理复杂内容。

# 试做顺序

简单图形找表面边界 → 校正必要的形状对应 → 检查人物或物体是否遮光 → 加入动画 → 以目标相机检查曝光、采样干扰、文字与速度。电脑上好看不证明经投影、表面和拍摄后仍成立。

# 调节变量

投影位置、内容遮罩、表面颜色与反射、观看角度、动画速度、环境光和拍摄记录条件。

# 失效分支

图像在转角断裂→先处理几何；物体一动就脱离→锁定、实时跟随或改分拍；暗部一直发灰→确认环境与投影黑位限制而非无限调黑素材；演员遮挡成问题→重排位置或写入作品。

> 身份：资料支持机制或前例；试验与诊断顺序为本包整合，未声称本次已实拍验证。不能替代安全、材料兼容和实际相机测试。
