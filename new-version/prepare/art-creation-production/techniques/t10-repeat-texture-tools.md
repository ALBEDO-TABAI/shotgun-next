# 适用

植物群、木纹、砖面、矿物或远景群体，需要密度但不需要逐个制作完整物件。Clausius 的玉米田绘景与 Writz 的木纹工具提供不同尺度的工具选择前例。

# 起始布置

定义纹理最小单位、方向、密度区和前后尺度；用安全的小型印具或普通工具做样，不直接复制大型工具结构。

# 试做顺序

试一个痕迹 → 一排 → 转向和力度变化 → 加入另一种尺度 → 退到目标观看距离 → 决定哪些近景需要手工补形。工具用于重复，不代表每次印记必须相同。

# 调节变量

工具尺寸、着色量、压力、旋转、间隔、分区和覆盖顺序。

# 失效分支

像墙纸→改变非关键重复和分区；远看碎→减少高频细节建立大层次；近看假→用明确形体补关键区；工具磨损导致重要图案失真→换工具并重核首件。

> 身份：资料支持机制或前例；试验与诊断顺序为本包整合，未声称本次已实拍验证。不能替代安全、材料兼容和实际相机测试。
