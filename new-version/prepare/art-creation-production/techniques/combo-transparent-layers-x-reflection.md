# 规则

先指定主机制，再让辅助技法解决它留下的问题；两个机制争夺同一空间、光或时点时必须先处理冲突。

# 本组合

- **主机制：** 透明片制造前后层次；**辅助：** 反射控制帮助瓶身成立。
- **冲突：** 新增每一层都可能反射原本只为瓶盖安排的亮面。
- **做法：** 先做透明片与瓶体的小组合，而不是两套分别通过后直接合并。
- **诊断：** 暂去透明层，确认问题是否来自它，再恢复并调角度。
