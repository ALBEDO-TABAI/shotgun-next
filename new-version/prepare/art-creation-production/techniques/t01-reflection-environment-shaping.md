# 适用

瓶盖、金属器物、亮面包装或透明容器上有杂乱亮斑，或物体失去体积。Recher 的技术案例强调对象与机位先确定，再组织反射；微表面理论提供反射分布的物理背景。

# 起始布置

相机和产品先稳定；整理周围可被反射的明暗区域。用一个主要亮面形成可理解的体量，再用适量暗面分开轮廓；扩散面或明暗卡的尺寸位置由反射画面决定，不默认越大越柔和越好。

# 试做顺序

拍无附加反射控制的基准 → 逐一加亮面观察哪条反射出现 → 加暗面观察切开的是轮廓还是文字 → 检查所有规定角度与运动。每次保留相机和产品位置。

# 调节变量

反射面的可见大小、距离、角度、边缘过渡、明暗比例；不要同时移产品、移灯、调曝光还宣称找到单一原因。

# 失效分支

像白色贴纸→检查亮面是否均匀覆盖太多；像黑洞→先恢复一条主要体积关系；文字被吞→分开文字区与轮廓区；相机侧移后失效→扩展可用反射范围或重新设计运动。完成标准是整个指定过程成立，不是某一帧闪过漂亮高光。

> 身份：资料支持机制或前例；试验与诊断顺序为本包整合，未声称本次已实拍验证。不能替代安全、材料兼容和实际相机测试。
