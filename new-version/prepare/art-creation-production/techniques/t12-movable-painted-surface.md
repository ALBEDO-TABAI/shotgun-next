# 适用

布景需要飘动、折叠、卷收、穿过或在动作中改变图像。Berky 的丝绸试样与 Powers 的地布案例都说明，绘画完成不等于运行条件完成。

# 起始布置

保留未处理材料；明确真正运动的区域和必须精确呈像的区域；先用简单线与色块，不把复杂图画完再试动作。

# 试做顺序

比较未处理、局部薄覆盖、较大覆盖的行为 → 完成展开—停留—恢复 → 按正式收纳方法处理后再做 → 增加图像细节 → 试保护。等待与覆涂按材料说明，不用统一分钟数。

# 调节变量

覆盖范围、层厚、材料方向、控制点、动作行程、停点和图像位置。

# 失效分支

太僵→减少处理范围或分离固定与活动区；颜色透到不需要处→重做兼容样片；图像一动就失去关系→改构图或让变形成为语言；重复后开裂或粘连→回到面层体系和收纳。高处挂装或大幅机械运动属于另外的专业制作。

> 身份：资料支持机制或前例；试验与诊断顺序为本包整合，未声称本次已实拍验证。不能替代安全、材料兼容和实际相机测试。
