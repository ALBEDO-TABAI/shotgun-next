# 适用

希望图形像在发光，但不一定需要真正玻璃霓虹或高复杂度装置。Powers 的教学记录将前后绘制、荧光材料及不同照明比较结合，也反思过覆盖层过多的问题。

# 起始布置

先用简单线条确定中心、边缘和周围区域；明确是绘制的发光联想、背光图形还是实际光源——它们的环境照明作用不同。

# 试做顺序

常规照明下查轮廓 → 比较背光与混合状态 → 需要特殊光源时由专业人员确认适配和暴露 → 观察相机是否保留颜色与邻近细节。

# 调节变量

线宽、中心与周边明暗、局部遮盖、背光分布、周围表面的响应和过渡时点。

# 失效分支

像荧光颜料画线→检查是否只有颜色没有亮度与环境关系；像后期粗描边→减少无理由光晕；颜色丢失→检查记录与显示链及曝光；用来照人物却无真实照明贡献→补实际光或明确当作图形。既有灯具和材料不能未经确认替换为自制电气。

> 身份：资料支持机制或前例；试验与诊断顺序为本包整合，未声称本次已实拍验证。不能替代安全、材料兼容和实际相机测试。
