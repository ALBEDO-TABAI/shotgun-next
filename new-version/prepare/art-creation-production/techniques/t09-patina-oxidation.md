# 适用

旧器物、历史感装置或表面经历。只模拟可见效果，不进行现场化学腐蚀。工艺层次参考 Powers 的绘景经验。

# 起始布置

保留金属关系作为底层，先画可能积留、接触和被擦亮的区域；表现性项目也要明确分布服从什么形式规则。

# 试做顺序

低对比区域变化 → 局部建立沉积 → 用减法露出底层 → 决定是否加少量高点 → 目标照明下检查。先做一小块完整过程，不从全场平均刷绿开始。

# 调节变量

区域范围、对比、边缘硬软、露底比例、光泽和纹理尺度。

# 失效分支

像迷彩→减少孤立高对比斑；像绿塑料→恢复金属基底和表面差异；与人物使用不符→重画经历图；特写露粗填料→换近景表面而非盲目锐化。连续性要求高时记录关键沉积位置和替代件外观。

> 身份：资料支持机制或前例；试验与诊断顺序为本包整合，未声称本次已实拍验证。不能替代安全、材料兼容和实际相机测试。
