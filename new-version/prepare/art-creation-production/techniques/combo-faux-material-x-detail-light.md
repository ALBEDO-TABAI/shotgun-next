# 规则

先指定主机制，再让辅助技法解决它留下的问题；两个机制争夺同一空间、光或时点时必须先处理冲突。

# 本组合

- 细节光可能显露仿材质的真实基底。
- 比较绘景精度、光的方向与观看距离。
- 决定：需要真实面层、局部精修，还是减少不必要的近看。
