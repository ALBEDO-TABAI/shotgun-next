# 适用

背景或道具需要钢材外观，但不要求真实镜面倒影或结构强度。Powers 的具名教程提供深底、金属色与方向处理的思路。

# 起始布置

先让小样形体和边缘合适，保留一块均匀金属色对照；把表面分成平面、折面和转角，不以相同笔触处理。

# 试做顺序

做底层 → 分别试较少与较多覆盖 → 选一个主加工方向 → 比较光泽。用目标镜头正视、偏侧与运动，不只在工坊顶光下看。

# 调节变量

覆盖程度、方向、线条尺度、底层明暗、局部磨损和最后表面；不引用通用“银漆加黑漆比例”。

# 失效分支

像银色塑料→检查均匀亮面是否占满、边缘是否过圆；像刷坏的墙→检查方向和笔触尺度；像旧铁而非精密金属→减少无关做旧；需要准确倒影→改真实反射材料或受控数字材质。不把远景通过当成极近景通过。

> 身份：资料支持机制或前例；试验与诊断顺序为本包整合，未声称本次已实拍验证。不能替代安全、材料兼容和实际相机测试。
