# 适用

在限定视点下让近小远大、远山或超尺度环境成立。Stockhausen 对《小行星城》的访谈说明使用大型微缩与强制透视平衡视觉距离与建造规模；没有提供通用尺寸。

# 起始布置

确定相机位置和主要尺度参照；用简单体量先找相对大小；必须知道错觉在哪些角度成立，不从完整模型开始。

# 试做顺序

测单一视点 → 加入计划的轻微移动 → 检查地平线、接触、遮挡和投影 → 加颜色与纹理 → 验证最终输出和焦点。纹理尺度若暴露真实大小，几何对了也可能失效。

# 调节变量

相对距离、体量比例、轮廓、纹理尺度、允许机位和真实接触范围。

# 失效分支

一点侧移就拆穿→限制视点或改其他实现；像模型而非目标世界→检查尺度参照和表面；需要真实人物跨越交互→分镜或混合制作；全景有效近景失败→分开造关键部分。不用“广角必然夸张”替代实际相机位置和比例计算。

> 身份：资料支持机制或前例；试验与诊断顺序为本包整合，未声称本次已实拍验证。不能替代安全、材料兼容和实际相机测试。
