# 适用

希望暗示窗、树、栅格或某种关系，却不需要把实体放进画面。设计对象是投影或阴影的形、方向、边缘和经过时点，不只是“打个树影”。

# 起始布置

一个安全固定的遮挡形、一处目标面、一组经专业控制的照明；先用简单几何形，不从复杂叶片开始；明确影子作用在背景、人物、产品还是多个层次。

# 试做顺序

固定相机和受影面 → 比较遮挡物靠近或远离受影面 → 改变光源条件 → 确定边缘后才做复杂形状 → 走主体动作，检查是否遮住关键内容。这是几何关系试验。

# 调节变量

光源可见大小、遮挡—受影距离、方向、速度、投影区域与主体亮度关系。

# 失效分支

像贴图→检查是否随体量转折及是否需要这种人工性；过碎→减少形状数量和密度；像有人晃卡片→改成有原因的运动或保持静态；挡住标签→分时或限制作用面。不必为每块阴影搭出它暗示的整件物体。

> 身份：资料支持机制或前例；试验与诊断顺序为本包整合，未声称本次已实拍验证。不能替代安全、材料兼容和实际相机测试。
