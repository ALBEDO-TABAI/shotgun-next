# 适用

纹理地面需要进场快、可替换或多地复用。Bechtel 的制作记录讨论分块地表、接缝和运输安装，提供制作路径而非通用材料配方。

# 起始布置

区分演员行走区、物件接触区、纯背景区；做含拼缝和边缘的试片，确认视觉与使用；不把松散碎料当省事方案放进通行区域。

# 试做顺序

试基底与面层相容 → 试纹理 → 按预计搬运方式折、卷或叠 → 重新铺开 → 拍接缝与低机位 → 由实际使用和安全条件决定能否进场。

# 调节变量

分块形状、接缝方向、边缘处理、纹理高度、总体色域和可换区域。

# 失效分支

拼缝像方格→改分区和局部覆盖而非全场撒东西；铺不平→回到基底与收纳方式；纹理损耗无法接续→做可换工作区；演员接触不适宜→换路径。行走、清洁和维护的确认不能由照片代替。

> 身份：资料支持机制或前例；试验与诊断顺序为本包整合，未声称本次已实拍验证。不能替代安全、材料兼容和实际相机测试。
