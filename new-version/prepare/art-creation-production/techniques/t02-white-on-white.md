# 适用

白色产品、浅色人物或白色装置需要明亮环境。Recher 的白对白案例将背景、主体与接触关系分开处理；案例的具体像素值不作为通用交付标准。

# 起始布置

先只做背景与底面，避免把亮度堆到主体边缘消失；再用有方向的主光描述主体，保留足以产生层次的差异；不自动删除全部接触阴影或倒影。

# 试做顺序

拍背景基准 → 加入产品但不补满 → 让一个主要方向出现体积 → 只在需要处补光或减反射 → 检查小尺寸和近景。纹理细微时整体均匀填光可能抹掉它。

# 调节变量

主光方向、背景与主体距离、底面反射、局部暗面、表面光泽和显示处理。

# 失效分支

轮廓消失→先减少背景或邻近反射，不立即后期描边；灰得脏→分辨光线、材料还是处理链；像悬浮→检查接触；只在一个角度可见→测试不同主体面向。白是作品约定中的白，不要求每个像素同一数值。

> 身份：资料支持机制或前例；试验与诊断顺序为本包整合，未声称本次已实拍验证。不能替代安全、材料兼容和实际相机测试。
