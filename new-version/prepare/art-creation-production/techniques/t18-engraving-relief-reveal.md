# 适用

玻璃刻纹、细小凹凸、压纹或浅表面细节在普通柔光下不明显。Taylor 与 Recher 的公开案例文字描述了用局部更有方向的光显露刻痕的过程。

# 起始布置

先使整体对象可辨，再单独处理细节；主要体量光和细节光分别承担任务，不以更强总照明代替方向选择。

# 试做顺序

拍无细节光状态 → 逐步改变方向观察何处开始显露 → 限制影响区域 → 检查整体反射和完整动作。出现不需要的阴影时改方向、范围或对象面向。

# 调节变量

方向、相对可见大小、作用范围、背景和对象角度。

# 失效分支

刻纹清楚但容器变难看→分开整体与细节任务；颗粒太强→降低细节强化；只在一瞬间成立→改动作或接受分镜；需要不可见细节承担关键信息→重新评估叙事，不只增加后期锐化。

> 身份：资料支持机制或前例；试验与诊断顺序为本包整合，未声称本次已实拍验证。不能替代安全、材料兼容和实际相机测试。
