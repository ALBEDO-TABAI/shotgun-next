# 适用

深色包装或装置需要融入暗环境，但仍保留结构；可与 T01 配合。诊断是反射与可见性原理的应用，不把暗画面等同一种固定的“高级风格”。

# 起始布置

检查主体真正需要显露的轮廓与面，不给每条边都加同样亮线；保留有意义的消失区域，再决定背景哪处提供分离。

# 试做顺序

无附加轮廓光为基准 → 加一条主要显露 → 比较背景局部亮度和第二个必要面 → 在最终观看条件与小尺寸中检查 → 走完整动作。

# 调节变量

显露面积、反射面形状、背景局部明暗、边缘宽度和主体表面。

# 失效分支

变成白线描边→减少均匀轮廓；主体全部发灰→区分整体填光过多还是显示转换不当；看不出信息→决定是合理隐藏还是与任务冲突；后期抬亮出现不想要的表面→重新拍基准。

> 身份：资料支持机制或前例；试验与诊断顺序为本包整合，未声称本次已实拍验证。不能替代安全、材料兼容和实际相机测试。
