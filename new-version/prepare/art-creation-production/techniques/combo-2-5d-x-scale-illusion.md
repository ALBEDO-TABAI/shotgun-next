# 规则

先指定主机制，再让辅助技法解决它留下的问题；两个机制争夺同一空间、光或时点时必须先处理冲突。

# 本组合

- 两者都依赖观看条件，组合后允许的机位可能更窄。
- 先画所有镜头，确定最弱状态。
- 不为一个最终画面牺牲其余运动，再要求后期补全。
- 需要自由移动时，先把关键近景层升级为真实体量。
