# 模板 · Templates

10 张带填写示范与消费检查的生产模板，以及构件卡、勘景记录、基准记录、试验记录、参考条目、技法入库等格式。

# 01 需求转译与方案生成
* [从概念到下一模块的最小交付（一页）](minimum-handoff-concept-to-next-module.md) - 原需求及当前解释、一个核心命题、关键画面与事件、两三个不可失去的关系、允许替换的实现、首先需要验证的问题；交给空间与材料者的是关系而非形容词。
* [参考条目格式：来源对象／借用／不借／当前迁移／待试](reference-entry-format.md) - 合格参考条目比“很有质感，值得参考”多出下一项工作；版权与资产使用资格另行核对，研究用途不赋予成片复制权。

# 02 空间设计与搭建转译
* [构件说明卡（PF-03 香水前方运动片示范）](component-spec-card-pf03.md) - 部件／作用／定位／可见面／接口／可替换／待确认／不能据此做的事——把制造者真正需要回答的问题聚在一起；不是采购单，也不是效果描述。
* [最小勘景记录](minimum-location-scout-record.md) - 净尺寸与高度、进出与运输、光与反射、使用与保护、声音与邻接、后场与运行六项，每项写记录方式与为什么会改变方案；电气、消防、结构由专业人员确认。

# 04 画面效果技法卡
* [新技法入库格式](new-technique-entry-format.md) - 技法名称与作用范围、当前与不适用目标、来源及其真正支持的机制、起始布置、第一轮试验、可调变量与保留条件、静态动态横竖版检查、失败现象→首项诊断→替代路径、实际测试记录、需其他专业确认的条件。

# 05 测试、现场优化与回修
* [试验记录卡（05 篇交付模板）](experiment-record-card.md) - 试验标识、类型、要回答的问题、基准与保留项、改变的变量或组合、保持条件与干扰、步骤、观察与判定依据、实际材料与图像（未实施写未实施）、结果范围、解释、下一动作与受影响对象。
* [建立基准：六组条件的最少记录](test-baseline-record.md) - 改前／改后只有在已知差别下才有诊断价值；空间与对象、摄影、光与环境、材料、图像处理、使用六组各记最少信息；桌面练习可用固定手机与纸面标记，不写成精密色度测量；反光物周围拿走一张白纸也会改变外观。

# 07 skill 拆解与生产模板
* [模板一｜需求转译与第一项试验](t01-requirement-translation-first-test.md) - 项目与交付、原话与来源、作品任务、不可更改条件、当前与另一种体验解释、拟转成的关系、会改变路线的问题、可先采用的假设、第一项可逆试验、下一位使用者需作的决定。
* [模板二｜机制路线与取舍](t02-mechanism-route-tradeoff.md) - 路线名称、视觉命题、主体与事件、空间材料如何参与、关键画面或状态、与其他路线的本质区别、必须保留的关系、可替换实现、最早可能推翻路线的未知、第一项试验与选案依据。
* [模板三｜镜头—空间—构件交接](t03-shot-space-component-handoff.md) - 镜头标识与版本、画面让人知道什么、起中终与停留、相机主体关系、必须可见与暂时不可见、直接和反射可见构件、动作与维护空间、材料图形后期接口、极端视点与裁切、当前依据与承接方。
* [模板四｜构件、面层与运行说明](t04-component-surface-operation.md) - 构件版本与镜头、外观与行为任务、尺寸单位基准与未测项、结构可见体量面层与可替换、边缘接缝背面间接可见面、材料候选与样片入口、连接运动接口、安装操作复位拆收、检查条件与实际状态。
* [模板五｜材料与效果试验单](t05-material-effect-test-sheet.md) - 试验问题与类型、对应材料构件镜头版本、候选变量与组合、基准与保持条件、样片与动作步骤、拍摄显示条件、观察重点与不接受情况、实际结果入口（未实施保留）、解释与适用范围、下一动作与影响对象。
* [模板六｜道具状态与复位](t06-prop-state-and-reset.md) - 道具使用者镜头、开始状态、动作中改变、结束状态、复位步骤与位置参照、使用或清洁后可能变化、主体件动作件备用件的必要差异、实际检查与待确认项。
* [模板七｜局部回修与回归范围](t07-local-revision-regression-scope.md) - 当前基准版本与证据、问题位置时点、与哪项已确认要求冲突、原因候选与先排除什么、保持不变的关系、第一项与备选修改、比较方法与复查镜头、实际结果与是否采纳、受影响的下游入口。
* [模板八｜实体、数字与后期的效果分工](t08-physical-digital-post-division.md) - 效果与画面作用、必须真实接触遮挡反射的关系、实体负责对象、数字负责对象、需共同保持的相机空间时间条件、需采集的基准与干净背景、输入解释创意预览与输出要求、缺口验证方法与负责方。
* [模板九｜完成交接与仍未完成的事项](t09-completion-handoff-open-items.md) - 项目与版本、交付类型（概念／待制作／指定范围已验证）、已批准对象与范围、实际验证对象条件与证据、制作使用入口、不能据此推定完成的事项、阻断与非阻断待办、下一动作承接方与唯一依据。
* [模板十｜经验条目与来源卡](t10-experience-entry-source-card.md) - 当前问题与情境、资料事实／本次方案／实际结果分列、有效关系或操作、原材料尺度镜头使用条件、失败与改动、允许迁移的部分、不适用条件与需重测部分、来源版本与证据入口；经验库可含未验证创意但要保留身份。
