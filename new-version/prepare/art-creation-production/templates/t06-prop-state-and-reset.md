# 填写示范（教学设定）

餐厨场景中的 CUP-B 从收纳区取出，在桌边停顿后放回。起始朝向与落点要让动作顺手且被看见。复位不是重新摆整齐，而是恢复动作前的指定状态；中间改变的其他餐具一并恢复。替换件除图案外还要比较握持、重量造成的动作和反射。未排练，不把示范动作认作演员已接受。

# 消费检查

下一条开始前由谁恢复、恢复到哪张状态照片必须明确；非关键背景物不必逐毫米记录。按实际连续性需求选择精度，不让模板膨胀。
