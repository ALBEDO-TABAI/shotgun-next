# 格式与示范（教学设定）

| 字段 | PF-03 示范 |
|---|---|
| 部件 | PF-03，香水场景前方运动片 |
| 作用 | 由遮挡状态转为引导线，不承担产品重量 |
| 定位 | 相对底面中心线和产品定位件；具体数值待镜头样件确定 |
| 可见面 | 正面、开启时的内侧及上缘 |
| 接口 | 运动控制与产品底座独立；控制区不得进入镜头或瓶身反射 |
| 可替换 | 面层和消耗性活动片独立更换 |
| 待确认 | 材料恢复、完整行程、停点、复位、近景接缝 |
| 不能据此做的事 | 未经结构设计扩展为大型悬吊或人体承托 |
