| 测试输入 | 应产生的工作 | 不应出现的行为 |
|---|---|---|
| 只说高级自然 | 多种解释与机制候选、第一试验 | 一串同义风格词 |
| 三个方案仅换颜色 | 指出机制相同，提出关系级变化 | 包装成三大创意 |
| 概念已批准，只问材料 | 材料行为、样片与替代路线 | 重新讲完整艺术史 |

这些是行为验收，不是给艺术好坏打分；本包尚未执行平台级测试。
