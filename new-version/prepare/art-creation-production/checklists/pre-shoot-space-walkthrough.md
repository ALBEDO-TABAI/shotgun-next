# 两遍

1. **按镜头走**：检查画面与动作。
2. **按复位和维修走**：检查实际运行。

记录问题位于哪个构件、哪个姿态、哪个状态；不只写“全景不够好”。

# 三句完成度

- 需要的东西能否被看见？
- 需要发生的事能否发生？
- 发生之后能否恢复或明确进入下一状态？

安全、使用和场地恢复另有相应确认，不能被艺术效果认可代替。
