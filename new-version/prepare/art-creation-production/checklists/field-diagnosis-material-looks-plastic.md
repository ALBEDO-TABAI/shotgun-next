# 从现象出发，不从整套风格推倒

- 不是看到“塑料感”就统一降低光泽；真实塑料也可以是意图，问题在于是否符合当前所需外观。
- 分开检查：形体厚度、边缘、接缝、纹理尺度、反射。
- 让同一小块绕到最难角度，查看哪一处暴露基底：
  - 几何轮廓错 → 先改形体
  - 均匀反射消除了层次 → 先改环境或面层
  - 最近镜头纹理不够 → 局部升级，不强迫全部背景同一精度
