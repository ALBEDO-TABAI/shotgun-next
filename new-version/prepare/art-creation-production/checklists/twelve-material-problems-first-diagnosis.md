| 问题 | 优先检查 | 第一项可逆动作 |
|---|---|---|
| 像塑料玩具 | 轮廓、厚边、反射和纹理尺度 | 临时降低局部光泽并对照 |
| 像刷了颜色而不像材料 | 大形、方向与边缘 | 用素色光检查形体，再加方向样片 |
| 做旧像迷彩 | 无因果的块状色差 | 压低大范围反差，保留有原因局部 |
| 细节很多却远看平 | 大尺度关系不足 | 暂盖细节，只调整大面明暗 |
| 透明层显脏 | 叠层、反射、连接与表面 | 减为单层找基准 |
| 布上色后太硬 | 覆盖、厚度、材料体系 | 对照未处理片，缩小处理范围 |
| 面层脱落 | 基底、层间与使用不适配 | 停止扩量，做相容性测试 |
| 样片与正式件不同 | 放大方法、批次与光 | 重做含接续的大样 |
| 每次摆景不像同一世界 | 活动区和状态没有基准 | 先恢复骨架与行动物 |
| 备用道具接不上 | 轮廓、重量、文字与反射差异 | 在真实动作镜头比较替代件 |
| 保护后不好看 | 最终表层改变外观或行为 | 与保护前的同条件版本对照 |
| 修一处坏另一处 | 没有确定失效层及依赖 | 先保留基准，停止全场同时改 |

不是鉴定工具；真实结果可能由多个因素造成，首轮动作旨在减少不确定；需要组合测试时转 [05 测试、现场优化与回修：从“这版不够好”到定位、改变、验证](/topics/05-testing-onset-optimization-revision.md)。
