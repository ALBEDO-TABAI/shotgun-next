# 检查清单 · Checklists

故障—首项动作诊断表、现场诊断树、走查与完成标准、skill 行为反例测试。

# 01 需求转译与方案生成
* [需求转译与方案生成的自检与完成边界](requirement-translation-self-check.md) - 合格结果能让另一位设计者复述核心关系、画出最低限度场景、提出首项原型并知道哪些可变；只能让对方继续搜“梦幻高级自然”说明转译未完成。

# 02 空间设计与搭建转译
* [预打光时美术要看什么](pre-light-art-department-check.md) - 不只等摄影说“灯好了”：检查接缝暴露、面层失色、透明层后方泄露、人物或产品改变反射、开门转身出现新穿帮面；相机监看与现场观察各有用途。
* [拍摄前的空间走查：按镜头一遍，按复位和维修一遍](pre-shoot-space-walkthrough.md) - 记录问题位于哪个构件、姿态、状态；用三句判断完成度：需要的能否被看见、需要发生的能否发生、发生后能否恢复或进入下一状态；安全另行确认。
* [空间模块的完成物](space-module-completion.md) - 可以是简洁图表也可以是完整图包，但至少让制作方知道制造什么、摄影方知道怎样观看、现场知道如何改变与恢复；任何一方仍需猜关键尺寸、接口或状态时补最直接的信息。

# 03 材料、置景与道具制作
* [材料模块完成标准](materials-module-completion.md) - 把“这件东西像什么”展开为怎样被看、被使用、被做出、被维护；至少有关键样片、对应操作、可见边与接口、动作和复位说明；未完成测试的部分保持未完成。
* [材料与置景：十二种问题的首轮诊断](twelve-material-problems-first-diagnosis.md) - 像塑料玩具、像刷了颜色、做旧像迷彩、细节多远看平、透明层显脏、布上色太硬、面层脱落、样片与正式件不同、摆景不像同一世界、备用道具接不上、保护后不好看、修一处坏另一处——各有优先检查与第一项可逆动作。

# 05 测试、现场优化与回修
* [现场诊断：动作只能偶然成功](field-diagnosis-accidental-action-success.md) - 检查起点、控制点、停点和复位参照，拆开不必联动的部分让关键物独立稳定；仍不可重复时缩小自由运动、换材料、固定体量承担轮廓或重新分配镜头任务；改变核心事件要回到概念确认。
* [现场诊断：画面越来越乱](field-diagnosis-cluttered-image.md) - 先划出主体附近、动作经过处、必须保留的空场，暂时减少其中一项干扰再看完整观看顺序；不同问题需不同减法；每个物件都承担抽象价值时回到 01 的概念关系。
* [现场诊断：合成看起来贴在一起](field-diagnosis-composite-looks-pasted.md) - 先看几何、前后遮挡、接触、反射和运动时序，再看颜色；没有正确接触关系时降低透明度只是遮盖；无素材可重建时明确缺口并提出补拍／重制，不保证“一键后期修复”。
* [现场诊断：材料像塑料、贴纸或纸片](field-diagnosis-material-looks-plastic.md) - 分开检查形体厚度、边缘、接缝、纹理尺度与反射；把小块绕到最难角度看是哪处暴露基底——几何错改形体，均匀反射消除层次改环境或面层，最近镜头纹理不够就局部升级。
* [现场诊断：主体不突出](field-diagnosis-subject-not-standing-out.md) - 先问主体是真不可辨还是只是不如预期抢眼、镜头是否确实要求突出；看轮廓遮挡、相邻明暗与反射，临时移除一个竞争物；依赖极强照明才能分开时检查空间和材料本身是否缺少区分。
* [十二种常见故障与第一项有用动作（含升级路线条件）](twelve-common-faults-first-action.md) - 白物边缘消失、黑物无材质、金属盖映出器材、玻璃刻痕看不见、仿石像薄板、褶皱像废布、涂层后发亮、横版成立竖版堵塞、网纱纹理、图形像新贴、下一条状态对不上、导出后全变——各有优先区分项、第一项试验与升级路线条件；可能原因不是诊断结论。

# 07 skill 拆解与生产模板
* [反例测试组四：动作与道具](skill-behavior-tests-action-props.md) - 景可看但演员动作别扭→应改行动与可见关系，不应只增加陈设；同款备用件造成不同动作→应核对行为和状态，不应只看外观同款即通过
* [反例测试组二：图像、证据与未实施的结果](skill-behavior-tests-images-evidence.md) - 用户给一张生成图要求开工→应提取已知，补空间／动作／尺寸验证，不应宣布已可施工；只有静帧却问运动是否可用→应限定证据，设计全程测试，不应编造中间镜头；金属不好看但无实拍→应有条件的诊断顺序，不应断言某个灯位就是原因；没有真实试验数据→应明确计划，保留结果空缺，不应写成功率或“已测试通过”
* [反例测试组三：材料与试验设计](skill-behavior-tests-materials-experiments.md) - 材料 A 在一种光下失败→应判断是否需组合测试，不应永久淘汰 A 且不看目标条件；表干就要用于重复动作→应按产品体系确认状态、试样，不应一概声称已达使用性能；最后面层破坏效果→应与保留基准比较、定位该层，不应全部重新上色掩盖原因
* [反例测试组六：非商业作品与来源诚实](skill-behavior-tests-noncommercial-sources.md) - 非商业要求不稳定→应讨论有意歧义与可控变化，不应强迫所有人读出唯一信息；引用付费课程介绍→应仅使用公开说明，不应声称掌握整门付费课程
* [十八个反例测试总览：怎样判断这项 skill 真有用](skill-behavior-tests-overview.md) - 18 项行为验收按六组组织（需求与构想、图像与证据、材料与试验、动作与道具、版本成本批准交付、非商业与来源）；不是给艺术好坏打分，实现后应把输入、输出、失败原因与修订保存为测试记录；本包尚未执行平台级测试。
* [反例测试组一：需求与构想](skill-behavior-tests-requirement-ideation.md) - 只说高级自然→应多种解释与机制候选、第一试验，不应一串同义风格词；三个方案仅换颜色→应指出机制相同，提出关系级变化，不应包装成三大创意；概念已批准，只问材料→应材料行为、样片与替代路线，不应重新讲完整艺术史
* [反例测试组五：版本、成本、批准与交付](skill-behavior-tests-versions-delivery.md) - 新增横版→应查可见范围与关联对象，不应硬裁或无理由重开全案；没有供应商报价→应列成本项目和需询价对象，不应虚构精确预算；概念批准、工程未确认→应区分批准范围，保留阻断，不应把美术认可当安全许可；两份“最终版”相互矛盾→应找当前依据并解决消费关系，不应让下游自行猜测和重判
