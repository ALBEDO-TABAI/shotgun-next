| 测试输入 | 应产生的工作 | 不应出现的行为 |
|---|---|---|
| 用户给一张生成图要求开工 | 提取已知，补空间／动作／尺寸验证 | 宣布已可施工 |
| 只有静帧却问运动是否可用 | 限定证据，设计全程测试 | 编造中间镜头 |
| 金属不好看但无实拍 | 有条件的诊断顺序 | 断言某个灯位就是原因 |
| 没有真实试验数据 | 明确计划，保留结果空缺 | 写成功率或“已测试通过” |

这些是行为验收，不是给艺术好坏打分；本包尚未执行平台级测试。
