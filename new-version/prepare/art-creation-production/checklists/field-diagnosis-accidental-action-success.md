# 从现象出发，不从整套风格推倒

1. 是否有明确起点、控制点、停点和复位参照？
2. 动作中是否同时牵动主体、支撑和装饰？先拆开不必联动的部分，让关键物体保持独立稳定。
3. 仍不可重复时，比增加拍摄次数更值得考虑：缩小自由运动范围、改变材料、让固定体量承担主要轮廓、重新分配镜头任务。
4. 若改变了核心事件，应回到概念确认，不将重大变化伪装为小修。
