# 原则与边界 · Principles

证据边界、专业安全边界、选案与停止条件、反伪精确、最终层复测等约束性规则。

# 阅读导航
* [专业与安全边界：美术认可不是安全许可](professional-safety-boundary.md) - 承重、悬吊、电气、动景、特殊介质与人体接触需相应专业确认；小样不能按比例放大为正式结构；制作图和 AI 输出都不能替代安全签核。

# 01 需求转译与方案生成
* [画面效果要能用普通话说明机制](effect-mechanism-plain-language.md) - “薄雾”“水光”“发光”不是完成的效果方案；写清效果发生在哪、是否与产品接触、是否跨镜头持续、需要真实物理状态还是可见变化，才能去选技法。
* [选案：避免虚假综合分，也避免只说个人偏好](route-selection-without-composite-score.md) - 先过不可协商条件，再比较核心任务、视觉独特性、制作前提与可逆性；安全阻断不能被创意分抵消，未报价成本不能精确排序；用条件式选择句表述。
* [抽象目标要成为有范围的设计变量，不伪装成数字](scoped-design-variables.md) - 不用“高级度 8/10”；写“主产品周边不出现比标签更强的细碎反射”这类可执行关系；可测量的量化，观察式的保留参考、比较条件和判断者。
* [方案三张图用途必须不同：起始条件／核心事件／结束关系](three-images-different-purposes.md) - 不要用同一构图换三个颜色冒充方案发展；每张图旁写一条生产问题；效果图仍是设计表达，不是测试结果。
* [何时停止搜集：剩余未知只能靠试验回答时就开始试](when-to-stop-researching.md) - 现有资料已能产生可比较机制、剩余未知只能靠当前材料或场地试验回答时开始试；但涉及真实文化、年代和生活方式时不能以个人想象替代必要研究。

# 02 空间设计与搭建转译
* [相机位置与焦距分开讨论](camera-position-vs-focal-length.md) - 固定相机换焦距主要改变取景范围；为恢复主体大小而前后移动相机会改变透视。对“更有空间感”不能只交一句“换广角”。
* [每个动作至少检查起点、中间和终点](check-start-middle-end-states.md) - 门开关都好看不代表开门过程不撞摄影机，软片闭合展开都漂亮不代表中间不拉动产品；要补对角、跨越、遮挡转移等最易出问题的中间状态。
* [场地备选是另一条完成核心镜头的方法](executable-backup-location.md) - 备选不是另一张漂亮照片：主方案用真实窗边，备选可以是可控棚内窗口光；主方案依赖长通路，备选可以分成两个明确镜头；比较保留的表达与新增工作，不未经报价宣称更便宜。
* [给不可失去的关系做标记](mark-non-negotiable-relations.md) - 如包覆装置的三个核心关系：产品与运动片分离、最终瓶体可见、主褶皱不压顶；换面层、背板或裁切时都复查这三项；不锁死所有尺寸，也不让“灵活调整”变成随意改关系。
* [资源压缩时保住设计而不平均缩水](resource-cuts-protect-core-relations.md) - 先分“决定核心关系的支出”与“可替代的实现”；主体近景面、动作件、关键开口与复位通常不能先删；费用拆项、不写未报价金额；时间按依赖排；不能删掉活动面还声称概念完整。
* [2.5D 分层平面的适用边界](two-point-five-d-boundary.md) - 固定或受控小幅机位可用分层平面；侧移产生视差、旋转露薄边、交互要求接触和阴影；升级时先把最易穿帮的关键层变为体量，不必一次做满三维。

# 03 材料、置景与道具制作
* [接触痕迹不是“弄脏”](contact-traces-not-dirt.md) - 亲密表面可能需要少量压痕、折线或局部变化，不需要指纹污迹；先以可清洁替代物测试，不在正式包装上做不可逆处理；可以用干净但有形变的表面保留“可触碰”。
* [密度不是数量问题](density-is-not-quantity.md) - 十件物聚成明确活动区可能比五件平均争抢注意更有秩序；先决定观看中心再安排差异；装置可故意平均密度，但应是选择而非逐角填空。
* [表干、可覆涂、可搬运、可弯折、完整性能稳定不是同一状态](drying-states-are-not-equal.md) - 材料厂商说明区分较快表面干燥与更长的干燥／固化过程；按具体产品说明与实际条件安排，不借用统一等待时间；表干就用于重复动作是反例。
* [最终层不是免检的保护动作：处理后重新做关键观看与行为测试](final-layer-requires-retest.md) - Powers 的云状地布回顾记录了耐用、可卷与表面光泽的取舍，某些保护处理使画面细节难以观看；保护、封闭或定形之后不能沿用处理前的批准。
* [原样不可复现时改方案，而不无限重拍](irreproducible-state-change-plan.md) - 核心动作必然产生不可控损耗时，比较可换面层、分次使用件、不同镜头职责或允许的连续变化；不能把实际不可复位的东西继续写成“每次恢复如初”。
* [记录材料的具体标识，而不只写“透明片”](material-identity-record.md) - 名称相近的材料在厚度、刚度、表面和附着上可能不同（Golden 对非多孔基底的测试）；记录来源、规格、处理状态；找不到相同材料时重做关键样片，不把新材料纳入旧批准。
* [翻模与复制先问适配，不先背配方](mold-and-copy-compatibility-first.md) - 特定加成型硅胶说明会列出固化抑制和小范围相容性试验（如 SORTA-Clear 12）；只据此建立“先做相容性确认”规则；由具备条件者确定母型、分模与材料体系，完成首件再扩大，复制也会复制母型错误。
* [不要用未知化学混合掩盖设计问题](no-unknown-chemistry.md) - 想要铜绿先做视觉仿制而非现场腐蚀金属；想要湿润先测局部表面与反射；水、热、粉尘和特殊介质一旦进入项目会改变清洁、人员接触和运行条件，应在方案时明确。
* [物件不必同龄；不以刻板符号代替生活资料](objects-need-not-be-same-age.md) - 以角色经历决定哪些长期保留、替换或修补；具体习惯依据剧本和真实资料；不把贫穷等同脏乱、把年轻人等同统一生活方式。
* [接缝和粘接会变成光学信息](seams-become-optical-information.md) - 透明层接缝正面不显眼，背光与侧光可能暴露；试样必须含实际边和连接区；黏合痕迹不能接受时比较机械隐藏、分层遮挡、局部替代或拆分，不能只在效果图里删接缝。
* [透明不等于没有存在感](transparency-still-has-presence.md) - 透明对象仍有边缘、反射、折射、厚度和接触；先决定想看清后方、只看颜色、只看光还是部分隐藏；比较一层、两层无间距、两层有间距，层数多不天然更丰富。

# 04 画面效果技法卡
* [先做哪张卡：按会改变决定的未知排序](technique-order-by-decision-changing-unknown.md) - 动作能否复位未定先做 T15，空间能否从计划角度成立未定先做 T13/T14，造型正确但反射错误直接做 T01；不按二十张卡逐一打勾；两路线可行时用相同完成度比较关键镜头，偏好差异交给需求方，合成可行性差异必须实测。
* [使用技法卡前先写三个条件，并先建立无效果基准](three-conditions-before-technique-card.md) - 效果服务哪项视觉命题、在哪个镜头和时点起作用、哪些产品人物空间关系必须保持；只回答“增加丰富度”就回 01；效果试验先建无效果基准，涉及材料与光交互时采用少量组合比较。

# 05 测试、现场优化与回修
* [何时停止测试：把资源留给仍有价值的问题](when-to-stop-testing.md) - 关键任务满足、运行条件已查、专业阻断已处理或明确、剩余修改主要是等价偏好交换时提交阶段确认；“没有任何未知”不是完成条件；放弃路线要留原因；区分概念、样片、指定镜头、工程确认四种完成范围。

# 06 真实案例与完整教学推演
* [三个教学项目的共同约定：暂选只为推演，结果保持未实施](teaching-projects-shared-conventions.md) - 按“输入—候选—选定关系—制作展开—试验—可能故障—交付”组织但不要求真实项目同规模；“暂选”不代表客观最佳；故障用“若出现”表达；尺寸属草案；三项目评价标准不互相套用。

# 07 skill 拆解与生产模板
* [“会做美术”以可观察的工作定义，而不是角色人设](art-competence-as-observable-behavior.md) - 六种最低行为：原话转可讨论关系、给出机制不同的路线、展开为需制作的对象、为关键未知选试验、依证据局部修改、把当前决定准确交给下一位；AI 能规划不等于已做，能力边界要反映在产物状态而非结尾免责声明。
* [最后一条规则：输出应该让下一步真的发生](output-must-make-next-step-happen.md) - 好产出让接收者能回答现在要画哪种关系、做哪块样片、摆哪几个对象、验证哪个动作，什么已确定、什么不能擅自决定；模型不能用越来越长的文本替代真实空间、材料、设备、操作者与反馈。

# 08 研究来源与适用边界
* [文献使用限制：只用实际核对到的范围](literature-use-limits.md) - S05/S06 仅用摘要与书目、S07 仅用官网说明、S14 仅用公开课程介绍；嵌入视频不作为看完依据；访谈内容按其明确指向归属。
* [三种内容身份：文献与制作事实／应用方法／教学设定](three-content-identities.md) - 全包的证据约定：带 S 编号的是资料依据；方法表、试验步骤、模板是本包整合；香水、餐厨、显隐等项目与尺寸、镜头、故障是教学设定，均未实测。
* [本知识包没有证明什么](what-this-bundle-does-not-prove.md) - 未测量颜色与亲密感、未证明三案优于两案、未验证涂层通用、未证明影像带来销售；科学性在于分清可以知道什么、怎样测试、结果适用到哪里。
