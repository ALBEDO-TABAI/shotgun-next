# 没有被证明的事

- 某种颜色是否让观众更亲密（未直接测量）。
- 三种方案必然优于两种（并行原型研究不能换算为规定）。
- 某一种涂层能在任意材料上使用。
- 哪条影像能够带来销售增长。

# 科学性的含义

不是给每个美术判断附一个假装精确的分数，而是分清**可以知道什么、怎样测试、结果适用到哪里**。工作经验给出值得尝试的路线，但不能代替当前材料、镜头、场地、人员和交付条件。

# 专业与安全边界

承重、悬挂、动景、电气、特殊光源及人体接触只提供设计与确认问题，不提供工程签核；S41 来自英国，不能当作其他地区法规结论。见 [专业与安全边界：美术认可不是安全许可](/principles/professional-safety-boundary.md)。
