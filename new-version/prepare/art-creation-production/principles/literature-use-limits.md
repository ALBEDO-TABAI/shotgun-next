# 要点

- **只有摘要就不补全文。** S05 使用机构仓储摘要，S06 使用书目与摘要；不补造完整访谈或实验程序。
- **只读说明就不冒称读完。** S07 只用研究团队公开说明，不声称读完全部论文或获得商业卡组；S14 只用公开课程介绍，未读取付费内容。
- **年份按原文。** 公开 PDF 结合文本与页面图示核对；不把课程副本网址中的年份当成论文发表年份（如 S04 是 1997 年原文，路径中的 2012 是课程年份）。
- **视频不算看完。** 网页中的嵌入视频不作为“全部看完”的依据；本包不声称逐镜头观看或重新测量所涉影片。
- **归属按明确指向。** 同一人物在访谈中提到不同影片时按其明确指向归属——尤其不把《布达佩斯大饭店》的服装配色回忆误记为《小行星城》的场景事实（见 [S18｜Asteroid City’s Cinematographer Shares How They Created the Film’s Out-of-This-World Look](/references/s18-yeoman-asteroid-city-cinematography.md)）。
- **历史工法不自动适用**于当前产品、人员或法规环境。
