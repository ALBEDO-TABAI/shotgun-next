# 最低行为

1. 能把原话转成可讨论的关系
2. 能给出机制不同的路线
3. 能把路线展开为需要制作的对象
4. 能为关键未知选择试验
5. 能根据证据局部修改
6. 能将当前决定准确交给下一位使用者

“你是世界顶级美术指导”不能说明系统会产出什么。ScreenSkills 的能力清单提供从视觉、空间到图纸、资源和协作的职业参考；本包借用覆盖范围，不照搬全部岗位，也不当作项目授权合同。

# AI 能力边界

- 能提出制造信息 ≠ 已经制造
- 能规划材料试验 ≠ 做过材料试验
- 能整理安全待确认项 ≠ 有权签发安全许可

这些边界必须反映在**产物状态**，而不只是结尾免责声明。
