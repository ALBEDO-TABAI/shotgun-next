# 美术创作与制作知识包 · Overview

母题：**美术创作与制作**——从理解需求、构想方案，到空间搭建、材料置景与道具、画面效果技法、测试与现场回修，再到把知识收成可执行的 skill 与生产模板。主问题不是“这是什么风格”，而是“怎样把一个含混需求变成能画、能搭、能试、能改、能交接的场景”。适用于广告与品牌视觉、平面摄影、叙事影片、舞台化影像及非商业艺术创作。

来源为《美术创作与制作知识包 v2》（`new-version/art-director/美术创作与制作知识包_v2/`，00 导航 + 01—07 正文 + 08 研究来源，2026-09-18 编订）。姊妹包：`knowledge/visual-style-art-analysis`（视觉风格与美术分析，偏“看懂与解释”；本包偏“做出来”）。

全包证据约定：带 S 编号的是资料依据（研究、主创访谈、机构说明、具名工艺记录、厂商资料，性质不同）；方法表、试验步骤、模板是本包整合；香水、餐厨、显隐、植物精华等项目及其尺寸、镜头、故障是**教学设定，均未实测**。见 [三种内容身份](principles/three-content-identities.md)、[四种证据身份](frameworks/four-evidence-identities.md)、[专业与安全边界](principles/professional-safety-boundary.md)、[本包没有证明什么](principles/what-this-bundle-does-not-prove.md)。

# 阅读路线（不需要每次从第一篇读到最后）

* **完全没有方案**：从 [01 需求转译与方案生成](topics/01-requirement-translation-ideation.md) 开始，先做机制草图或材料动作（[形容词转译链](methods/adjective-translation-chain.md)、[八种构想操作](frameworks/eight-ideation-operations.md)），再选 [03](topics/03-materials-set-props.md)、[04](topics/04-effect-technique-cards.md) 中一项实际试验。不要一开始填写全部模板。
* **已有漂亮画面但不知道怎样做**：直接读 [02 空间设计与搭建转译](topics/02-space-design-build-translation.md)（[镜头包络](frameworks/shot-envelope.md)、[三种面](frameworks/three-surface-types.md)），接 [材料任务](frameworks/material-task-four-aspects.md) 和相关 [技法卡](frameworks/technique-card-task-routing.md)。检查画外操作区与反射，不只看正面。
* **已有场景但效果不理想**：以真实问题进入 [05 测试、现场优化与回修](topics/05-testing-onset-optimization-revision.md)，先 [建立基准](templates/test-baseline-record.md)，再用 [十二种常见故障](checklists/twelve-common-faults-first-action.md) 返回 02、03 或 04 的失效位置。不要默认重做全部概念。
* **需要一个完整范本**：读 [06](topics/06-real-cases-teaching-projects.md) 中对应项目——[香水](cases/teaching-project-a-perfume-overview.md) 面向商品静物与短片，[餐厨](cases/teaching-project-b-kitchen-overview.md) 面向叙事空间，[显隐](cases/teaching-project-c-visibility-overview.md) 面向非商业观看；然后回查相关技术概念。
* **准备编写 skill 或团队工作说明**：先理解前六篇，再用 [07](topics/07-skill-breakdown-production-templates.md) 的 [入口路由](skills/entry-routing-six-situations.md)、[执行规范](skills/art-production-execution-spec.md)、十张模板与 [十八项反例测试](checklists/skill-behavior-tests-overview.md)。模板是结果的容器，不是创作的替代品；本包没有声称已经安装某个平台 skill。
* **核查某个说法的依据**：[按问题找来源](frameworks/sources-by-question-routing.md) → [references](references/)。

# 主题枢纽 · Topics

* [01 需求转译与方案生成](topics/01-requirement-translation-ideation.md) - 从含混语言到有机制差异、可继续制作的视觉方案：三种任务、六种信息、转译链、研究线、八种构想操作、组合盘、五种规则、选案与失效条件、最小交付。
* [02 空间设计与搭建转译](topics/02-space-design-build-translation.md) - 把画面意图变成能拍、能用、能安装和修改的空间：动作先行、勘景、镜头几何、镜头包络、四种原型、分层发展、基准尺寸接口、路径选择、拆件、安装、数字制造思维。
* [03 材料、置景与道具制作](topics/03-materials-set-props.md) - 从材质名称到形体、面层、行为、经历和复位：材料任务、实现路径、四类小样、兼容、形体策略、表面五层与十种操作、典型表面、陈设四轮、做旧、道具状态、图形道具。
* [04 画面效果技法卡](topics/04-effect-technique-cards.md) - 二十种从机制、试做、调节到失效诊断的工作路径，五种技法组合，先做哪张卡与入库格式。
* [05 测试、现场优化与回修](topics/05-testing-onset-optimization-revision.md) - 四种测试、先后次序、可测试问题、基准、色彩链路、单变量与四格组合、区组与重复、四种判定、诊断树、故障表、完整回修示范、回归、验收边界、反馈与停止。
* [06 真实案例与完整教学推演](topics/06-real-cases-teaching-projects.md) - 八则真实制作案例与三个教学项目（香水、餐厨、显隐）的完整链条及横向比较。
* [07 skill 拆解与生产模板](topics/07-skill-breakdown-production-templates.md) - 最低行为、七模块职责、入口路由、证据身份、当前依据、执行规范、十张模板、变更贯穿、十八项反例测试。
