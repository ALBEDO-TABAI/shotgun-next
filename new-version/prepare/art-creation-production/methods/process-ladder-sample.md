# 阶梯

A 保留基底 → B 加底层 → C 加大变化 → D 加细节 → E 加最终表层

# 记录

- 样片背面：材料、批次、操作顺序、层间状态、制作日期。
- 影像：相机、光、距离、显示处理。不知道照片用了什么滤镜，就不适合作为精确校样依据。
