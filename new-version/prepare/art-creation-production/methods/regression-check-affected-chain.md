# 顺序

1. 被改对象本身的外观与动作。
2. 邻接、阴影、反射、接触和跨镜头状态。

# 受影响的消费方

变更单加一句：“PF03 更换材料，影响动作复位、最近镜头、后期遮罩以及收尾面层；不影响已确定的产品标识、入口路线或其他房间。”

# 规则

- 局部修改不能成为漏检借口：一处门宽改变可能牵动表演、摄影机、搬入与结构条件。**按依赖关系决定复查范围，不按修改面积决定。**
- 保留旧版用于比较，但明确只有哪个版本是当前批准依据；不建立多份互相竞争的最终文件。
