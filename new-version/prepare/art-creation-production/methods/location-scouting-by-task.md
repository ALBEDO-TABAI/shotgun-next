# 例

- 有漂亮窗户，但产品镜头需要稳定反射、外部车流持续进入反射面 → 可能不适合。
- 装修普通，但动线、采光控制和搬运条件合适 → 可能只需局部改造。

# 五组记录

固定条件／可改部分／现成优势／操作限制／尚未确认。照片应有方向和位置参照，而不只拍最好看的角度。
