# 步骤

1. 拍保留基准。
2. 实施一个明确改变。
3. 同样条件下拍摄。
4. 并列看目标关系。
5. 必要时恢复基准重拍，排查环境是否漂移。

前后样片在底色、纹理和厚度上也不同时，不能把全部差异归给保护层；制作时就留出同来源对照。

# 局限

NIST 指出单因素方法不能充分揭示因素间的交互作用：一个因素的结果可能取决于另一个因素处于什么状态。美术中尤其警惕：先在一种光下淘汰材料，再在另一种光下发展剩余材料，却从未看过被淘汰材料在目标光下会怎样。
