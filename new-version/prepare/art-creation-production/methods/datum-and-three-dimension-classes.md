# 基准

- 部件不能分别从各自方便的位置测量。统一用底面前缘、中心线和上表面；建筑场景用商定的轴线与标高。
- 每张图说明单位和测量对象，区别净空、外包尺寸与材料厚度。
- 只写“离边 100”没有完成沟通：哪条边？外皮还是结构？成品还是毛坯？

# 三类尺寸

| 类 | 含义 |
|---|---|
| 关键尺寸 | 影响动作、镜头或装配 |
| 可调尺寸 | 允许在预设范围内寻找效果 |
| 派生尺寸 | 由已确定基准与材料厚度计算，不让工坊另作猜测 |

# 公差

按实际材料、制造能力、装配方式和镜头要求商定；不规定所有布景必须某个毫米精度。高精度用错位置是浪费，关键接口没有共同容差会装配失败。
