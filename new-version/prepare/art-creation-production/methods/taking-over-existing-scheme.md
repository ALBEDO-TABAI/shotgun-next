# 三类标记

1. 已经明确认可的意图
2. 尚未验证的实现
3. 仅由参考图暗示的细节（例：参考图似有半透明顶棚，但用户只确认“柔软包覆”，不能把顶棚材料当作已批准采购）

# 最小重述

> “我保留 X 和 Y，接下来只解决 Z；为此比较两个实现，暂不改变其他部分。”

# 原方案确有矛盾时

指出具体冲突、受影响镜头与可保留关系；提出保持表达目标的替代路径（自由布面改固定背景加局部运动片；连续绕拍改为两个固定视点），不笼统说“不专业”。
