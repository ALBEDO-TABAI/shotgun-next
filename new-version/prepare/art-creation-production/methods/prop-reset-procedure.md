# 杯子示例

1. 确认是否需要清空或补到指定状态。
2. 恢复朝向、落点和接触痕迹。
3. 检查边缘、污迹和反射。
4. 在复位照片中对照。

数量和顺序来自当前镜头要求，不“凭感觉差不多”。位置参照可以是场外标记、定位件、照片或测量，按精度和表面条件选择；不为定位破坏正式包装或租赁物。
