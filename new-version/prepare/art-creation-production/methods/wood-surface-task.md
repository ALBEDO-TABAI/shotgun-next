# 练习路径

1. 纸面画板块方向。
2. 已确认基底上给总体木色。
3. 薄层和方向性工具建立主要纹理。
4. 少量局部差异。
5. 最后试光泽。每步在目标距离检查。

# 要点

- 普通木纹贴图可能没有解释板缝、纹理方向和结构；不同板块可略有差异，但不能无理由把同一印迹完全镜像重复。
- 近景需要真实纹理深度或反射时，比较实材／贴面，不强迫绘景承担全部工作。
- Writz 的大型木纹工具来自特定“玩具剧场”尺度，纹理夸张有设计理由；不搬到真实家具近景。
