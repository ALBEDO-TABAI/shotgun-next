# 资料

Dorst 与 Cross 的研究提出问题空间与方案空间共同演变的描述；本次仅核对到摘要与机构书目，不补写完整实验程序。

# 应用方法（本包）

提出一个小方案 → 观察它使原问题发生了什么变化 → 修正问题表述。

例：尝试“全场蓝绿色”后发现包装失去区分，把问题从“每样东西同色”修正为“环境与产品连续，但产品仍有辨识位置”。这不是任意改 brief，而是以可见问题说明为何改变解释。
