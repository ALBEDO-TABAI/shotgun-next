# 三类优先问题

1. **作品用途和观看条件**
2. **不可牺牲的关系**
3. **不可逆投入的前提**

其他未知不必暂停一切：产品尺寸未给时，桌面造型仍可做比例草图，但不下精确加工单；是否允许出现人物未定时，可先做有人与无人的机制对照。

# 可用问法

> “这两种做法都能让产品显得亲近，前者通过手的接触，后者通过材料被使用的痕迹；哪一种更接近你希望的关系？”

把需求方放在可判断的选择前，而不是要求其掌握美术术语。
