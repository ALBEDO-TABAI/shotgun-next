# 问法

- 不要一上来问“是不是清爽了很多”。
- 先问：“先看见什么？”“哪一处变化被注意到？”“何时认出产品／空间？”“哪一处影响了观看？”
- 需要感受时，请对方用自己的语言描述，并记录其观看条件。

# 区分三类反馈者

| 反馈者 | 能支持 | 不能支持 |
|---|---|---|
| 项目确认者 | 批准方向 | 代表所有观众 |
| 专业同事 | 指出工艺问题 | 市场效果 |
| 少量目标观看者 | 发现误解 | 销量、转化或普遍情绪 |

# 非商业作品

问“你注意到什么关系改变了”“哪些地方想继续看”，不要求同一故事解释。作者可以不采纳建议，但说明保留的是哪种表达，而不是以“你不懂艺术”终止讨论。

# 保存分歧

一组人觉得亲密、另一组觉得被包裹得紧——提示检查围合与开口，而不是加权成一个无从行动的数字。
