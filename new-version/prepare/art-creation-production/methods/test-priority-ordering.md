# 三问

1. 若判断错误，会不会换掉核心事件？
2. 会不会推翻空间或多人接口？
3. 能不能便宜地局部替换？

香水片中：布能否开启并复位关系到主要事件；金属盖近景关系到主体；远处小纹理通常更局部。

# 推荐次序

1. **可发生性**：动作、显隐、空间关系是否真的有实现路径。
2. **最难的观看条件**：最近、最宽、最低、反射最多或变化最大的镜头。
3. **跨环节组合**：单独正确的服装、墙面和灯光放在一起是否仍成立。
4. **运行与收尾**：面层处理后、拆装后、实际操作后是否保留已确认性质。

不计算虚假的“风险系数”；一句“这个变量改变会连带重做背景、动作片和灯位”足以解释为何先测。
