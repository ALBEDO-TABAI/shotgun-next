# 五件事

1. 原项目的具体问题
2. 资料记录的解决路径
3. 它保留什么、替换什么
4. 当前还不知道什么
5. 怎样设计一个自己的试验

# 规则

- 来源只展示漂亮结果时，不补写“经过三轮讨论最终决定”；过程未知就保留未知。
- 迁移操作而非物件：别人把笔触立体化，学“把二维关系转为空间”，不必同样悬挂线与珠；别人做可卷地布，学“拆收方式从一开始参与设计”，不必采用相同填料与保护层。
- 每则真实案例分为**资料事实／工作启发／自己的练习／迁移限制**；启发和练习由本包提出，不能倒过来算作原项目做过的步骤。
