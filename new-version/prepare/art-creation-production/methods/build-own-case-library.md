# 条目句式

> 在什么条件下，哪种关系由哪种实现支撑；如何试验；出现了什么；最后保留与改变什么。

不要只收一张最终图和五个风格词。

# 例

若香水项目未来真实施，发现局部运动片比整幅自由布稳定，应记录实际材料、尺度、镜头、动作和替代代价；没有这些条件，结论容易退化成“以后都用固定背景”。

真实案例支持可追溯经验，教学案例支持操作练习；两者互补，但不能混成一份看似全部拍过的作品集。
