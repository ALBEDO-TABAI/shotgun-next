# 资料

Dow 等的网页广告研究比较了并行与串行原型发展，结果支持在该任务中保留替代方向的价值。本包**不移植其效果量，也不规定美术项目必做三案**。

# 应用方法

- 候选以相近完成度出现：同样数量的关键画面、同样清楚的动作、同样坦诚的风险。
- 只有一个方案被精修、另两个只有一句话时，评审差异混入了表达投入，不能只解释为创意优劣。
- 选案后仍不分配“高级版／普通版”。
