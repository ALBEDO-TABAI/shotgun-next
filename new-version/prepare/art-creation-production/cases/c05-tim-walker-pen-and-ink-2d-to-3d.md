# 资料事实

Getty 收录的创作说明中，Walker 将 Beardsley 的笔触表现视为可转入三维空间的问题，并提到悬挂线与珠形成仿佛在空中绘画的关系。

# 工作启发

借用参考时可以选择“怎样留下线条”这一操作，而不是整张图的物件与姿态。跨媒介转译会提出新的工作问题：线在空间中如何相交，阴影是否参与，换角度是否仍可读。

# 自己的练习

选一段自己画的线，先用纸条或安全的小型立体结构转成桌面体量；拍正面与偏侧面，比较哪一种关系保留、哪一种被新媒介改变；把变化当作创作材料，而非只努力伪装成原画。
