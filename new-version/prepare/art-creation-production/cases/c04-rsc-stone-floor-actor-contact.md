# 资料事实

RSC 绘景部门对《暴风雨》的实例说明，演员跪地这一使用条件影响了石地的材料处理，并不只是按真实石材外观决定。

# 工作启发

“像石头”不是完整任务。要被踩、跪、坐、触摸的表面，需要同时考虑接触、动作、声音、清洁和重复使用。真实材料也不天然是最适用的路线。

# 自己的练习

只做非承重表面样片，用三个不同近景角度比较轮廓与纹理，再写出若人物需要接触还缺少哪些验证；不让家用样片承担未经确认的人体使用测试。

# 迁移限制

历史案例的替代材料不自动满足当前项目，也不证明所有舞台工艺经得起摄影近景；学习的是任务拆分，不是材料清单。
