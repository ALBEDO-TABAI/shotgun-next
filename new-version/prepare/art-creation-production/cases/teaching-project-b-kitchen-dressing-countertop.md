# B5 四轮陈设

1. **骨架：** 只摆操作面、桌、椅和主要储物，走完整动作，先让拥挤、距离、停顿位置成立。
2. **行动物：** 会被拿、放、打开的碗杯和餐具；确定从哪里拿、怎样握、放到哪里，不用无关小物掩盖动作问题。
3. **使用系统：** 与人物有关的少数活动（清洁、临时放置、充电、储藏）；物件位置服务生活，不是装饰密度比赛。
4. **经历差异：** 某处修补、常用区细微变化、部分用品较新。假设空间一直被照料，不全场同样脏；不借脏乱暗示人物阶层或品质。

每轮从拟定机位复看；景内细节可以不都被读懂，但不能遮挡核心动作。不把每个空位都填满，也不为了“孤独”清空真实使用系统。

# B6 旧台面的制作任务

- 目标：长期使用、持续清理、局部有难以消除的变化——不是“旧得明显”。
- 先选实际旧物或兼容表面路径；只差局部外观时不急着定制整套家具。
- 画经历分区（常接触、长期遮挡、曾被移动、合理修补）；先大范围低对比变化，再少量局部细节，到镜头里检查再决定是否加强。
- 小样含边缘、拼接和最终面层；角色接触区、拍摄声音和清洁复位要求一并提交。
