# A3 五个需要制作的对象

| 构件 | 承担 | 要点 |
|---|---|---|
| PF01 底面与产品基准 | 主体落点与相机对应 | 拉布动作不拖动产品；表皮可更换 |
| PF02 固定背景体量 | 大部分包覆轮廓 | 先用粗模定开口、厚度、主方向；不要求所有可见部分自由运动 |
| PF03 局部运动片 | 只负责显露事件 | 起点、控制点、停点、复位；不承担瓶体支撑 |
| PF04 近景面层与替换部分 | 触感、边缘与使用痕迹 | 易损位置可换；近景与背景精度可不同 |
| PF05 反射环境 | 镜头外工作对象 | 服务金属盖、玻璃边缘与标签区，随相机与产品角度共同测试 |

意义：塌轮廓改 PF02，开启不稳改 PF03，表面不成立改 PF04——不必每次重造整套。

# A4 空间草案（未验证）

底面约 1200 × 900 mm；产品落点在底面中心线、距前缘约 420 mm；背景初设宽约 1000 mm，高度候选 250—350 mm。先用产品替身与粗体量在预定镜头检查；4:5 与 9:16 分别画有效范围与留白；背景不仅不能直接穿帮，也不能经瓶盖与玻璃间接暴露支撑和现场。小模型可研究围合，但布料行为、微距透视和反射不能按比例自动转移。
