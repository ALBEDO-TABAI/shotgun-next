# B7 道具状态让习惯真正可重复

| 阶段 | 关键关系 | 需记录的状态 |
|---|---|---|
| 开始 | 两套可按旧习惯拿取 | CUP-A、CUP-B 的收纳位置、朝向与数量 |
| 取出 | 动作不应像专门演示道具 | 握持顺序、重量差异、其他物件是否干扰 |
| 到桌边 | 第二份的存在进入观看 | 落点、相邻物、身体遮挡与声音接口 |
| 停顿 | 意识变化留给表演 | 手与杯的可见位置，不额外堆象征 |
| 改变 | 使用关系由二变一 | 哪件被放回、哪处保持空、动作终点 |
| 复位 | 下一条回到相同起点 | 状态照片、位置参照、损耗或替换差别 |

近景件、动作件、备用件必要时分开，但比较轮廓、表面与实际动作；杯中是否需液体由相关人员确认，本例不默认。

# B8 排练与试拍分两轮

1. 第一轮不讨论够不够伤感，只查动作是否顺手、观众何时知道第二个位置、是否有不必要遮挡；画面与表演关系交导演、摄影、演员共同判断。
2. 第二轮加入正式面层和必要陈设，查新物件是否改变通路、反射和声音；比较实际前后状态而非全景陈设照。
反馈“没有感觉”时先定位：看不出动作关系、揭示太早、停顿不足，还是生活系统不可信——不能都转成“美术多放一张合照”。

# B9 三种可能故障

- **寓意太直白：** 减少额外成对物件和解释性照片，降低第二位置的初始展示强度，把变化交回动作。
- **观众不知道发生了什么：** 先检查取出—停顿—放回在观看上是否关联，调整可见角度和时点；解释文字是另一种表达选择，不是自动补丁。
- **生活像展台：** 让实际使用者完整操作，改顺手关系、密度中心和临时存放；不靠全场加脏或随机散落。

# B10 资源受限时保护什么

保护行动区、关键道具、可见第二位置与核心镜头所需边缘；可减少不入镜且不承担反射、操作或安全功能的背景精度；不取消必要复位、固定支撑或通路。交付空间—动作图、生活资料与取舍、关键面层、道具状态、机位相关陈设记录、当前版本和待验证项。
