# 资料事实

美术设计师 Lee Ha-jun 在直接访谈中说明，建造前通过持续设计与三维模拟考虑演员运动和摄影机位置；他也谈到垂直层次这一组织方向。

# 工作启发

“一间现代住宅”只是对象类别；“哪些人在什么位置能相互看见，如何移动和隐藏”才开始决定平面。空间的叙事任务不是装修完成后再附加的意义。

# 自己的练习

选一段包含进入、取物、停顿和离开的动作，不指定装修风格，先用几个纸块标门、桌、遮挡物；分别从两个观察位置走完整动作，记录信息出现先后；之后才选择墙面和陈设。

# 迁移限制

访谈不提供足以复制住宅的工程图、尺寸与成本；“使用三维模拟”不意味着小场景必须先购买或掌握复杂软件，关键在于事先验证空间关系。
