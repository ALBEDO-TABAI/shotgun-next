> 内容身份：教学设定，原创线与形，不复制真实艺术家作品图像。

# C1 命题

艺术意图暂写：“不是有一个东西突然出现，而是观看者意识到自己之前只能看到一部分。”作品关注可见条件与认识，不要求唯一故事。短片固定相机与展览自由观看不是同一任务，先推演前者；改成现场装置需另测观看范围、人员流动和场地条件。

# C2 三条机制及选择条件

| 机制 | 适合 |
|---|---|
| A 前后空间 + 纱幕，分区照明改变可见性 | 希望变化在同一物理现场发生 |
| B 前后绘制的透光景片 | 平面关系本身就是主要对象 |
| C 分层实拍与合成 | 需要较自由视角或局部时间重组，但要补齐遮挡、反射与运动 |

暂选 A（依据 ShowTex 技术说明），不是因为更“纯粹”，而是本例希望同一物理空间改变可见状态；测试不支持时允许换路径。

# C3 内容先简化，再研究显隐

前层一组线与断开的轮廓，后层一个与它部分对应但不完全重合的形体。第一轮只判断：能否把同一位置误认成完整整体，后来怎样被新信息修正。两层只是任意图案叠加时，技术显隐再成功，作品也只像打开一盏灯——显露要带来关系变化，而不只是亮度变化。
