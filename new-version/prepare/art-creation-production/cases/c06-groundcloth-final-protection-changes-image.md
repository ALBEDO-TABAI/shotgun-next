# 资料事实

Angelique Powers 对《Earthquakes in London》地布的制作回顾涉及绘画、行走、卷收和最终光泽之间的取舍；保护处理是视觉问题的一部分，而非自动的收尾。

# 工作启发

把“表面画完”作为完成点太早。涂层、卷收、清洁与重新安装可能改变之前成立的关系，应在计划里留出完成处理后的再次观看。

# 自己的练习

使用已确认适合的材料做并排小样，记录完成前后与弯曲前后的差异；保持一块未经后续处理的基准，避免只剩最终样片后无法追查变化在哪一步出现。

# 迁移限制

作者的项目经验不是通用耐用性保证；不复制其配比和使用方式为所有布景的标准，也不由一张样片推算实际使用寿命。
