# A7 进入正式制作前的最小测试包（均未实施）

1. PF03 动作与复位，保留完整片段而非只截漂亮停点。
2. 瓶体、盖体与 PF05 的反射，拟定范围内走完整取景；不随意更换包装样件。
3. PF04 在最近镜头与完成处理后比较：颜色、光泽、刚度和接触。
4. 组合后再走全部镜头；组合通过后才把样片与图纸绑定——**不把四个独立小样的成功相加成整体成功**。
5. 拆装与更换动作片后恢复；核实替换件差别在取景中是否可见。

# A8 三条可能的回修路径

- **瓶盖反射杂乱：** 保持构图与对象，只简化 PF05 的竞争明暗面，重看末帧和运动；不直接改盖材质或整幅压暗。
- **展开后像散落衣物：** 先减少次要褶皱、明确主方向；仍不稳则缩小自由运动区、增加受控体量；若事件不再可读，返回概念比较 B，而不是无限加控制点。
- **竖版拥挤：** 调整 PF02 开口与 PF03 运动方向，保留近身尺度；简单缩小主体会破坏亲近关系。

每条留下改前基准、改变对象、需保留关系与验证镜头；本例未试拍，不能宣称一定修复。

# A9 资源减少时

优先保留核心动作、最终包装镜头、近景面层和反射控制；可减少无叙事作用的绕拍、全景外精细背面或附加粒子效果。镜头数改变时重查三张照片是否仍覆盖交付任务。实际成本分项取得，不给未经查询的金额和标准天数。

# A10 交付的是执行包

需求译文、三路线选择说明、关键画面与动作、空间草案、PF01—PF05 工作说明、样片与试验记录、已确认项和未定项；图纸和样片注明一致版本。
