# 本篇概览

本篇解决：东西像塑料玩具、表面做旧平均而假、布料上色后不能动、道具好看但不好用、同款备用件无法连戏、材料小样漂亮却无法放大制作。

**主线：** [材料任务四方面：看起来怎样／行为怎样／怎样制造／运行中遇到什么](/frameworks/material-task-four-aspects.md) → [五种材料实现路径：现成物／局部改造／通用骨架加面层／定制形体／数字或分层合成](/frameworks/five-implementation-paths.md) → [四类小样：材料片／工艺片／接口片／行为片](/frameworks/four-sample-types.md) → [三项先做的兼容小检查：基底与面层附着／层间相容／处理后承受实际动作](/methods/three-compatibility-checks.md) → [先做形体再做皮肤：四种形体策略](/frameworks/four-form-strategies.md) → [表面制作的五层工作：基底／基色／大变化／细节／最终表面](/frameworks/five-surface-layers.md) → 十种表面操作 → [陈设四轮：骨架→行动物→信息密度→经历](/methods/set-dressing-four-rounds.md) → [道具的四个状态：拍摄前／动作中／动作后／复位后](/frameworks/prop-four-states.md) → [材料与置景：十二种问题的首轮诊断](/checklists/twelve-material-problems-first-diagnosis.md)。

**实践边界：** 手作练习限定为不承重、无人体危险接触的小样；水性不等于可食用、可触肤或没有风险；不提供未知材料混配、化学腐蚀和结构许可。

# 本篇概念

## 框架 · Framework

* [五种材料实现路径：现成物／局部改造／通用骨架加面层／定制形体／数字或分层合成](/frameworks/five-implementation-paths.md) - 选材是多目标取舍而非档次排序；各路径有优先条件与需特别检查的项；不以“定制最多”证明美术工作最多。
* [表面制作的五层工作：基底／基色／大变化／细节／最终表面](/frameworks/five-surface-layers.md) - 工作分解而非要求真实涂五遍；基底问题不靠面漆，基色负责大关系不负责所有材质，大变化要有尺度与分布，最终层不是免检动作。
* [先做形体再做皮肤：四种形体策略](/frameworks/four-form-strategies.md) - 实体空壳与支撑分离、板片分层、可控软形、现成物作为结构或母体；非承重小样做法不能直接放大到人体尺度。
* [四类小样：材料片／工艺片／接口片／行为片](/frameworks/four-sample-types.md) - 小样要回答问题而非收集色卡；最常遗漏的是接口片——画面暴露的往往是薄板边、拼接、转角和支撑；只测中心面不能声称全部成立。
* [图形道具：从故事世界中的制造者出发的六个问题](/frameworks/graphic-props-six-questions.md) - 谁做、给谁用、用什么工具、有什么时间与技能、如何复制、怎样保存（由 Annie Atkins 的公开说明转化）；先做信息结构再做风格，按实际尺寸与镜头打样，同一世界要有生产差异。
* [材料任务四方面：看起来怎样／行为怎样／怎样制造／运行中遇到什么](/frameworks/material-task-four-aspects.md) - “石头、金属、玻璃”还不是材料任务；先写需要保留的性质再选实材、改造、外壳、绘景或数字；真实材料是条件时照办，但不默认真实总是最佳。
* [道具的四个状态：拍摄前／动作中／动作后／复位后](/frameworks/prop-four-states.md) - 道具不是采购到就完成的资产，而是被动作使用的对象；每个状态写轮廓、朝向、数量、内容物、表面、关键操作和允许变化。

## 方法 · Method

* [做旧：先画经历的因果，再决定痕迹](/methods/aging-by-causal-history.md) - 关键物经历简写为制造—获得—使用—维护—改变—当下，只写影响可见状态的事件；按原因选痕迹并检查是否成立；先做低对比版本再在目标镜头加必要信息。
* [小样比较必须包含目标观看条件](/methods/compare-under-target-viewing.md) - 在最近使用镜头查边缘与纹理、最远镜头查大关系、动作过程中查反射与状态；准备一个普通对照，避免越看越夸张；先探索后定样。
* [布料上色后要重测动作](/methods/fabric-painting-retest-motion.md) - 上色、定形、保护可能改变刚度和恢复；保留未处理对照，比较不同覆盖范围而非只比颜色；图像必须精细区与需要自由运动区可分开，结果由当前样件判断。
* [仿钢表面：底层、覆盖与方向分开测试（三块对照）](/methods/faux-steel-surface-task.md) - 同一平整基底做均匀金属色、深底薄金属层、深底薄层加方向性三块，比较完整角度变化；需要真实镜面倒影时比较实际反射材料或数字；写清“金属感”的接受范围。
* [纸与薄片：用折线控制形，不必一味模拟织物](/methods/paper-and-thin-sheet-forms.md) - 纸建立精确转折与恢复规则，薄片形成连续曲面，织物有下垂与细褶；同尺寸做自由放置、局部支撑与开合比较，不以材料名预判哪种更高级；纸边不合适时可设计成语言或只升级关键部分。
* [铜绿／旧金属：分布需要原因](/methods/patina-old-metal-task.md) - 先画结构、雨水或接触的候选路径，再分配沉积、高点与露底；用绘景层次而非化学腐蚀；像迷彩降低无理由块状反差，像绿漆检查是否掩盖金属关系。
* [过程阶梯样片：A 基底→B 底层→C 大变化→D 细节→E 最终表层](/methods/process-ladder-sample.md) - 同一基底分区或同类小板逐级加层，问题出现时可追溯在哪一步发生；样片背面写材料、批次、顺序、层间状态和日期，影像记录相机、光、距离与显示处理。
* [复位步骤要能被另一人执行](/methods/prop-reset-procedure.md) - 以杯子为例：确认清空或补到指定状态、恢复朝向落点与接触痕迹、检查边缘污迹与反射、与复位照片对照；位置参照按精度与表面条件选择，不破坏正式包装或租赁物。
* [从小样到大面积：放大的是方法，不只是尺寸](/methods/scale-up-sample-to-large-area.md) - 先分大区、设置接续方式，再做含接续边的大样；固定总体色域与主方向、可见纹理尺度、目标光下的完成关系；工作站按状态分区；维修准备替换面层、样片与记录。
* [陈设四轮：骨架→行动物→信息密度→经历](/methods/set-dressing-four-rounds.md) - 陈设不是家具目录加“有故事的小物”，先决定这里发生哪些活动；每轮从规定机位和使用者位置各检查一次。
* [石感表面：轮廓、断面与纹理层次相互支持](/methods/stone-surface-task.md) - 先问是平整石板、自然断面还是粗糙体量；石感不只来自随机黑点，大形转折、颗粒、色差区与边缘厚度共同参与；接触或支撑时视觉外壳与使用条件分别确认。
* [三项先做的兼容小检查：基底与面层附着／层间相容／处理后承受实际动作](/methods/three-compatibility-checks.md) - 用供应方建议的方法检查剥离划伤，不在正式主体上做破坏测试；关注起泡、返溶、变色、分离；刚柔组合看弯折位置，透明片胶痕会成为光学信息。
* [木感表面：先判断是板、切面、纹理还是使用经历](/methods/wood-surface-task.md) - 先确定一块“板”的边界再组织纹理流向，不无理由镜像重复；练习路径由板块方向到光泽逐步检查；近景需要真实纹理深度时比较实材／贴面；Writz 的夸张木纹属于玩具剧场尺度。

## 原则 · Principle

* [接触痕迹不是“弄脏”](/principles/contact-traces-not-dirt.md) - 亲密表面可能需要少量压痕、折线或局部变化，不需要指纹污迹；先以可清洁替代物测试，不在正式包装上做不可逆处理；可以用干净但有形变的表面保留“可触碰”。
* [密度不是数量问题](/principles/density-is-not-quantity.md) - 十件物聚成明确活动区可能比五件平均争抢注意更有秩序；先决定观看中心再安排差异；装置可故意平均密度，但应是选择而非逐角填空。
* [表干、可覆涂、可搬运、可弯折、完整性能稳定不是同一状态](/principles/drying-states-are-not-equal.md) - 材料厂商说明区分较快表面干燥与更长的干燥／固化过程；按具体产品说明与实际条件安排，不借用统一等待时间；表干就用于重复动作是反例。
* [最终层不是免检的保护动作：处理后重新做关键观看与行为测试](/principles/final-layer-requires-retest.md) - Powers 的云状地布回顾记录了耐用、可卷与表面光泽的取舍，某些保护处理使画面细节难以观看；保护、封闭或定形之后不能沿用处理前的批准。
* [原样不可复现时改方案，而不无限重拍](/principles/irreproducible-state-change-plan.md) - 核心动作必然产生不可控损耗时，比较可换面层、分次使用件、不同镜头职责或允许的连续变化；不能把实际不可复位的东西继续写成“每次恢复如初”。
* [记录材料的具体标识，而不只写“透明片”](/principles/material-identity-record.md) - 名称相近的材料在厚度、刚度、表面和附着上可能不同（Golden 对非多孔基底的测试）；记录来源、规格、处理状态；找不到相同材料时重做关键样片，不把新材料纳入旧批准。
* [翻模与复制先问适配，不先背配方](/principles/mold-and-copy-compatibility-first.md) - 特定加成型硅胶说明会列出固化抑制和小范围相容性试验（如 SORTA-Clear 12）；只据此建立“先做相容性确认”规则；由具备条件者确定母型、分模与材料体系，完成首件再扩大，复制也会复制母型错误。
* [不要用未知化学混合掩盖设计问题](/principles/no-unknown-chemistry.md) - 想要铜绿先做视觉仿制而非现场腐蚀金属；想要湿润先测局部表面与反射；水、热、粉尘和特殊介质一旦进入项目会改变清洁、人员接触和运行条件，应在方案时明确。
* [物件不必同龄；不以刻板符号代替生活资料](/principles/objects-need-not-be-same-age.md) - 以角色经历决定哪些长期保留、替换或修补；具体习惯依据剧本和真实资料；不把贫穷等同脏乱、把年轻人等同统一生活方式。
* [接缝和粘接会变成光学信息](/principles/seams-become-optical-information.md) - 透明层接缝正面不显眼，背光与侧光可能暴露；试样必须含实际边和连接区；黏合痕迹不能接受时比较机械隐藏、分层遮挡、局部替代或拆分，不能只在效果图里删接缝。
* [透明不等于没有存在感](/principles/transparency-still-has-presence.md) - 透明对象仍有边缘、反射、折射、厚度和接触；先决定想看清后方、只看颜色、只看光还是部分隐藏；比较一层、两层无间距、两层有间距，层数多不天然更丰富。

## 表面操作 · Surface Operation

* [薄罩染：改变关系而不抹掉底层](/techniques/surface-op-01-thin-glaze.md) - 在已达覆涂条件的底层上试透明／半透明色层保留底层信息；停止标准是需要的关系出现且底层仍承担工作。
* [擦除与减法：通过露出而不是不断叠加](/techniques/surface-op-02-wipe-subtractive.md) - 在合适操作窗口内用清洁工具局部移走新层，沿高点、触碰或流动关系组织，而非随机擦到好看。
* [干擦：让凸起和边缘被选择性显露](/techniques/surface-op-03-dry-brush.md) - 工具少量带色轻触已有形体，选局部而非平均描遍全部边缘；物体变成亮色描边模型时减少覆盖回到大关系。
* [点拍与揉擦：打破均匀而不制造壁纸](/techniques/surface-op-04-sponge-stipple.md) - 先定密度区再改变方向、力度与间隔；连续重复同一印迹会暴露制作节奏；目标不是随机，仍需解释哪里密哪里疏。
* [拖拉：建立加工或流动方向](/techniques/surface-op-05-dragging.md) - 预画主方向，从一端完成受控长线再加少量短差异；方向关系比线数量重要，仿拉丝或木纹方向相反会破坏材料逻辑。
* [模板与遮罩：控制边界和重复](/techniques/surface-op-06-stencil-masking.md) - 先在废样测试边缘、渗入与移除影响；模板规定区域但不意味所有边一样硬；移除时破坏底层说明材料层次或时机需要改变。
* [印拓与自制纹理工具：先设计一次动作的痕迹](/techniques/surface-op-07-printing-texture-tools.md) - 选一组大小与方向关系做小型印具，观察同一工具能产生的变化；远景大面用重复工具提效，近景关键区补明确形体，保留工具磨损检查点。
* [湿边衔接与区域过渡](/techniques/surface-op-08-wet-edge-blending.md) - 在允许的颜料系统中练两块色的连接，明确软过渡还是保留界面；工坊无法在正式面积维持同样操作窗口时改分区、接缝或分层。
* [局部光泽：把表面反应当设计变量](/techniques/surface-op-09-local-gloss.md) - 同色表面可通过不同反射区分；先做小范围前后对照拍规定角度与运动；全场刷亮可能让纹理和体量同时消失。
* [边缘处理：补形与表面一起工作](/techniques/surface-op-10-edge-treatment.md) - 近景中的边应包含厚度、倒角或断面的视觉逻辑；毛边涂同色不一定隐藏材料，可重做局部、包覆、改为合理接缝或调整可见范围。

## 检查清单 · Checklist

* [材料模块完成标准](/checklists/materials-module-completion.md) - 把“这件东西像什么”展开为怎样被看、被使用、被做出、被维护；至少有关键样片、对应操作、可见边与接口、动作和复位说明；未完成测试的部分保持未完成。
* [材料与置景：十二种问题的首轮诊断](/checklists/twelve-material-problems-first-diagnosis.md) - 像塑料玩具、像刷了颜色、做旧像迷彩、细节多远看平、透明层显脏、布上色太硬、面层脱落、样片与正式件不同、摆景不像同一世界、备用道具接不上、保护后不好看、修一处坏另一处——各有优先检查与第一项可逆动作。

## 教学设定 · Teaching Scenario
