# 要点

Clark 与 Brennan 把交流看成共同建立"足够理解"的活动：需要反馈等依据，并受媒介条件影响。共同理解不是双方永远完全同知，而是足以支撑当前目的。用于对白，须把**消息发出**与**交流完成**分开。

例：甲说"下周二"，乙点头，可能只表示听见；看到乙记错日期，甲补一句"不是明天"。这个修正既交代事实，也能显示耐心、急躁、熟悉程度或权力。

## 1. 角色各自以为哪些事已知

| 信息 | 甲的假设 | 乙可能的理解 |
|---|---|---|
| 修理费 | 上次说过由我付 | "我来"只被理解为我来取 |
| 到场者 | 家里人当然都来 | 自己只承诺个人到场 |
| 明天再说 | 明确推迟到明天 | 一种不愿正面拒绝的表达 |

这种差异可以生成戏，但需要来路；不能让人物在每个简单词上都故意误会，只为延长剧情。

## 2. 反馈有不同强度

"嗯"、复述、追问、执行、反对、沉默并不等价。"我知道"可能是确认，也可能是要求停止解释。下一句若继续从头科普，要说明为什么忽视反馈，或承认文本没有真正安排倾听。

## 3. 人物共同知识不等于观众共同知识

- 熟人一句简称可互相明白，观众未必懂；观众先见到信，则可能理解人物不知道的停顿。
- 对白不能永远为陌生观众上课，也不能以"人物都知道"为由取消观众必需的信息。
- 需要补的信息可由前场、动作、字幕或自然追问承接，不必全塞进同一句。

# 适用边界 / 不应自动做什么

- 向创作与部门交接迁移 grounding 概念是本包的综合，不是原理论的结论。
- 不把每次点头都当成同意，也不把每次沉默都当成拒绝。
