# 要点

Wolf 对审美幻觉的讨论强调：投入再现世界可以与知道它是作品并存，并受作品、接收者和情境共同影响。[2] 因此不出戏**不是绝对禁止人工痕迹**。

## 五种约定

| 约定 | 可分析的问题 | 自拟提醒 |
|---|---|---|
| 世界约定 | 作品建立的能力、限制、代价形成期待；新例外是否有依据 | 魔法不必守现实物理，但要守自己的规则 |
| 人物约定 | 意外行动与毫无根据不同；突变若是内容，应给理解线索 | 不只要求观众接受 |
| 语言和表演约定 | 文学化台词可以成立；全改口语可能毁掉形式 | 日常对白后结尾突然背诵品牌价值，需要处理转调 |
| 信息约定 | 一直限于某人所知却突然出现作者全知秘密；像事实的旁白后来毫无线索被否定 | 不是禁止，但改变了观看关系，需有意识组织 |
| 传播框架 | 品牌落版可作故事外署名，不必在剧情里安插品牌发言人 | 字幕不必然中断，关键看它在说明、评论、转调还是提供界面信息 |

## 有意距离与意外破坏

人物看镜头、评论拍摄、暴露装置，都可能从体验转向反思。应问：**中断了什么，建立了什么新关系**。只有中断没有新组织，再讨论是否失败。

> “我意识到这是作品”不自动为坏；“作者说这是间离”也不自动为好。

# 适用边界 / 不应自动做什么

- 不把任何人工痕迹一律判为出戏；也不因作者声称“间离”就免检。
