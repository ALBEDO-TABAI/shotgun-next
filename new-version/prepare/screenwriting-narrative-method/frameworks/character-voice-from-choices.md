# 要点

"遮住姓名仍能认出人物"可以是练习，不是所有作品必须通过的门槛。同一家人可共享语言习惯，同一个人在不同关系中也会变。

## 五种有用的观察维度

| 维度 | 观察什么 |
|---|---|
| 注意对象 | 先问结果、过程、价格，还是谁承担后果 |
| 组织方式 | 先结论后理由，先铺垫后请求，明确责任还是省略主体 |
| 不确定性处理 | 承认不知道、用类比靠近、假装确定或把问题推回 |
| 关系风险处理 | 道歉、幽默、提供替代、装作事务讨论或直接设限 |
| 回避对象 | 避开姓名、某次往事、价格，或替他人定义感受；应说明在何种关系中回避，不把所有场景写成神秘 |

## 声音应有弹性

- 平时话多的人在重要时刻只说"帮我一下"，可能比继续话多更有力量，前提是语境已建立。人物声音不是输出模板。
- 方言、职业术语与年代语言需要研究。**不要用口音拼写快捷表示智力、道德或阶层**。没有足够材料时，普通准确的表达比仿造的"地方味"更可靠。

# 适用边界 / 不应自动做什么

- 不用口头禅、固定句式"配置"人物。
- 不从年龄、性别或地域直接推定固定语言性格。
- 听起来专业不等于已经正确；未经查证的职业用语须标注。
