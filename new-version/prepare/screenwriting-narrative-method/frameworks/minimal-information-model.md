# 要点

信息设计安排的是：观众现在需要理解什么、可以疑惑什么、依据哪些线索形成哪些推断、何时修正或保留这些推断。做这件事的前提是把四种状态分开，混淆它们会让角色知道不可能知道的事、把回忆误当客观证据、把作者知道的背景当成观众已获得的内容。

| 状态 | 记录什么 | 常见误用 |
|---|---|---|
| 世界状态 | 作品当前已确立的事件、规则和处境（如"箱子已搬到门外"） | 只在作者笔记里写过、作品未建立的背景被当作观看证据 |
| 人物知识与信念 | 亲见、听说、推断、误信、愿望、想象分别记录 | "看见信封"被等同于读过信；读过被等同于相信；相信被等同于内容为真 |
| 实际呈现的信息 | 对白、旁白、动作、声音、字幕、剪辑关系中实际出现的内容 | 角色说的话被自动当成作品最终事实 |
| 观众可形成的理解 | 由实际出现、足以辨认、能联系语境的线索支持的理解 | 作者心中的完整故事被当作观众已获得的理解 |

补充规则：
- 某些世界有意不完备或不可统一，应保留未定与竞争版本，不强行补出唯一时间线。
- 人物信念只记录会影响选择和理解的项目，不为全部生活细节建数据库。
- 一个通道提出判断，另一个通道可以反驳；呈现层内部可以有冲突。
- 分析提出的是"可支持的理解"，观众实际是否获得仍需接收证据。

## 五档理解状态

替代"交代过／没交代"的二分：**明确呈现 / 强支持推断 / 有竞争解释 / 尚未提供 / 刻意未定**。

# 适用边界

- 理论提供区分工具，不保证某一种信息顺序产生固定情绪。
- 本模型是应用综合，不是已验证的心理阶段模型。
