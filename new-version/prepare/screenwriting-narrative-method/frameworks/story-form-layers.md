# 要点

"故事形式"不是作品身上的一个名字。"这是品牌广告""这是家庭故事""这是非线性叙事""这是诗性表达""这是冷幽默"分别可能在谈**传播用途、内容领域、时间组织、表达方式和语调**。把它们并列成一张"故事风格分类表"，就会出现概念混用。

学术研究也没有一套覆盖所有媒介、所有作品的单一分类法：文本类型研究、电影形式研究、类型研究和叙事学的对象与分类依据本来就不同。最核心的区分是：**作品为了什么被使用，与作品内部怎样组织内容，不是同一个问题。** 一部作品可以用于说服，却不必在形式上采用论证。

## 三个关键修正

| 修正 | 内容 |
|---|---|
| 1. "事件型、关系型、谜题型"不宜与"论证型、联想型"并列 | 前者描述叙事内部靠什么变化或问题支撑继续观看；后者是作品整体怎样组织材料。层级不同。 |
| 2. "写实、虚构、梦境、纪录"不属于同一个轴 | 写实涉及呈现惯例；虚构／事实性涉及作品对现实指涉的承诺；梦境是故事内部的一种经验或世界状态；纪录还涉及作品如何建立与现实材料的关系。经过选择和组织的材料不因此自动成为虚构。 |
| 3. "诗性、克制、荒诞、冷幽默"需要指明作用位置 | 诗性是文案修辞、镜头间联想，还是整部作品不以因果推进？克制是人物不表达、叙述少解释，还是视听手段不强调？ |

## 概念分流表

| 常见描述 | 真正需要追问的问题 | 优先落入的分析字段 |
|---|---|---|
| "这是一条品牌片" | 谁在传播？希望形成什么认识？ | 传播任务与使用情境 |
| "这是一个家庭故事" | 家庭是内容背景，还是调用了特定类型惯例？ | 题材／类型 |
| "这是一个悬疑故事" | 是类型归属，还是某段信息被延迟造成的观看期待？ | 类型／信息组织 |
| "这是碎片化叙事" | 碎片之间按时间、人物、主题还是意象连接？ | 情节结构／组织原则 |
| "这是写实风格" | 哪些表达惯例建立了现实感？它是否声称记录真实事件？ | 风格／事实性约定 |
| "这是诗性广告" | 诗性发生在文字、声画关系还是整体结构？ | 表达方式／组织原则 |
| "这很感人" | 是我的实际反应，还是对目标观众反应的预测？ | 接收记录／效果假设 |

这张表不是新的作品分类表，而是一个**概念分流器**：先知道自己正在判断什么，再判断得是否准确。

# 适用边界 / 不应自动做什么

- 不把这张表当作一个新的"风格分类法"去给作品贴标签。
- 分流之后的字段各自需要证据，分流本身不产生结论。
- 后续的字段、流程和检查规则是综合研究提出的工作方法，不是某一位学者的原始分类体系。
