# 要点

| 段 | 记录什么 | 提示 |
|---|---|---|
| 进入状态 | 人物此刻在哪里、知道什么、希望做什么；关系处于何种位置；观众在等什么 | 条件不必全部用开场对白交代，但作者要分清哪些已建立。"她来道歉"与"她来取东西却被要求道歉"在同一地点生成不同场景。 |
| 作用过程 | 阻力、合作、误会、发现、等待、共同注意或感官变化 | 不要把所有作用都改写成争吵。合作中可观察配合从生硬到顺畅、谁首次让出决定权、谁开始接受对方的专业判断——它们推进关系，不必有人为阻挠者。 |
| 离开状态 | 任务、知识、关系、风险或形式期待有什么不同 | 变化可以很小，例如一个问题终于问出口。场景结束不等于世界问题已解决。外部事件不变时，还可检查经验是否积累、重复是否形成对照；不只用目标是否成功判断存在价值。 |

## 模型的边界

- 抽象视听段落可改记为**形式初态、变奏规则与阶段形态**。
- 不可能时间或多重矛盾叙述，不必强行重建唯一现实事件图。Alber 的非自然叙事研究讨论超出日常物理、逻辑或经验约定的形式：发现不可能关系时，先识别作品约定，再判断是否构成问题。

# 适用边界 / 不应自动做什么

- 模型用于分析和写作时的记录，不是所有作品必须满足的三段结构。
- 不为填表而虚构剧情；非叙事段落允许不适用因果字段（见 [skill 接口](/skills/scene-plot-and-rhythm-design.md)）。
