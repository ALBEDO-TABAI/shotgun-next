# 练习

| 练习 | 做法 | 判断规则 |
|---|---|---|
| 行为依据测试 | 让不知道小传的读者说明人物为何采取关键动作 | 若必须由作者补课，检查文本；若有多种合理解释，不自动判失败 |
| 换人测试 | 把台词和动作交给另一个角色，观察关系是否毫无差异 | 不是每句必须独特的命令，而是定位个体依据的工具 |
| 规则移除测试 | 去掉一条规则，看核心困境是否不变 | 只是背景的可保留；结尾依赖的规则必须有适当建立 |
| 状态缩小练习 | 把"人物成长"改写为作品实际证明的变化 | 一次不道歉的回复≠一生的边界重建，一次邀请≠全面和解 |
| 双向关系练习 | 同一拒绝分别发生在同事、父亲与陌生人之间 | 说明任务和代价差异，不只替换称呼 |

# 完成条件

最终交付不是百科全书，而是：关键行为依据、双向关系、生成后果的规则、保留的未知，以及正在验证它们的场景。

> 人物扎实，是关键选择有依据；世界扎实，是作品依赖的规则确实产生后果，而不是设定表越来越长。
