# 要点

- **改变关系**：可以改变行动主体、信息先后、物件对不同人的用途，或让原先的阻碍成为新选择的条件。每次只改一个关键关系，更容易看出实际作用。
- **元素多不等于组合有根据**：爱情、科幻、悬疑、诗性画面都加入后若互不支持，应先减少或明确主从，而不是继续加解释。
- **具体性不等于消费私人痛苦**：一个人的生活不需要罕见悲剧才值得表达；研究其经验不意味着可以擅自公开隐私。对细节的兴趣应与使用边界一起工作。
- **新意不必以难懂为代价**：陌生形式仍可给观众进入线索，直接表达也可能有新的观察。检查究竟重组了什么，不用"看不懂 / 一眼懂"当优劣标签。
- **转换形式可能比增加剧情更有效**：一个情节前提写不下去，可能不是需要更多反转，而是更适合观察、论证或图像组。返回第一篇的形式坐标，允许题材找到不同归宿。
- **原创性的另一个入口**（深化应用）：问"这一版让我注意到以前被忽略的什么关系"，而不是只问有无前人用过相同题材。修旧物很常见，但把顾客决定权放进工艺协商，与借亡亲往事催泪，是不同的具体观察。这不是版权或原创性的法律判断。

# 适用边界 / 不应自动做什么

- 不把"新颖"当成扩大品牌承诺或虚构事实的理由。
- 不用形式陌生度替代对关系重组的说明。
