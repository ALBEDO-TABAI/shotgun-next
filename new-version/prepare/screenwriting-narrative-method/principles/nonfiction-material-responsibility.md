# 原则

| 项 | 要求 | 例 |
|---|---|---|
| 事件、说法与演示分别标记 | 资料身份可追溯 | 采访者说"那天他没来"是一项说法；空椅子镜头可说明缺席感，但未必是当天现场 |
| 剪辑可以改变指向 | 叙事连贯不能替代事实关系 | 把别处反应移接到一句话后可能制造当事人未作出的回应；时间压缩可能把间隔久的事写成直接因果 |
| 真实人物不是可随意重写的角色 | 区分参与采访、公开引用、改编、虚构合并等使用方式 | 曾同意一种用途不等于全部允许（口述史原则：知情参与、资料使用、语境） |
| 无须伪装无立场的摄像机 | 承认取舍、范围和视角 | 没有展现不代表不存在；无法确认不能补成事实；艺术组织可以，前提是承诺被处理 |
| AI 材料需要来源状态 | 生成影像只可用于构想或明确标示的再现 | 不能悄悄作为原始现场证据；模型总结中的引用要回原材料核查 |

DAWG 框架强调非虚构制作中的关怀、透明和责任关系；本包只使用其机构与框架介绍，不当作本地法律意见。
