> 自拟教学案例：非真实品牌方案或验证结果。这是测试**设计**，不是测试已通过。

# 五个阶段

| 阶段 | 做什么 | 能回答 / 不能回答 |
|---|---|---|
| 1. 材料与事实 | 核实真实产品动作、信息情境、目标界面、品牌资产和使用范围 | 没有这些，制作草稿可前进，但发布版本不能假装已确认 |
| 2. 低成本时间草稿 | 文字界面、简易走位、临时声轨测试 45 秒是否装得下 | 能定位时长问题；不评最终摄影与表演质量 |
| 3. 不提示主题的首看 | 问："她开始在做什么？消息要求什么？她后来怎样处理？你依据哪里这样理解？"再问情绪与人物关系 | **不要**先问"是否感受到女性力量"（研究者已提供意义）；不要求参与者猜创作者的正确答案 |
| 4. 分开记录 | 事实理解、开放情感、品牌归属、产品归因、个人喜好分别记录 | 一个人觉得轻松不证明品牌识别完成；认出品牌不证明故事自然 |
| 5. 比较最关键变量 | 先比较期限线索、发送可读性或音乐强调中的**一个**问题 | 不一次改变演员、调色、文案、片长后把差异归给某项因素 |

- 不同版本观看顺序会影响已有知识，可考虑独立首看或平衡顺序。
- 没有真实数据时**只写测试设计**，不填样本数、百分比和显著性。

# 假设性反馈如何使用

| 假设有人说 | 先核对什么 |
|---|---|
| "她干脆不回了" | 发送状态是否可见 |
| "产品让她更敢拒绝" | 剪辑顺序与配乐 |
| 看懂但不在意 | 问题可能不在信息，而在内容相关性或形式表现 |

这些是**模拟诊断**，不是已经收集到的观众原话。
