# 十五秒版

候选任务：清楚表现一次回应安排与护理继续；**不保证**完整建立长期习惯或微小心理转折。

| 时间草案 | 内容 | 主要风险 |
|---|---|---|
| 0—3 秒 | 晚间动作与可延期工作信息 | 文字可能读不完 |
| 3—7 秒 | "我明早看"发送，手机放下 | 没有原草稿，不能宣称完整策略变化 |
| 7—12 秒 | 连续产品步骤 | 真实使用方式需要验证 |
| 12—15 秒 | 品牌与短文案 | 归属与阅读时间 |

- 若首段读不清：减少字数、改变请求情境，或让短版依靠字幕直接设定；但**不能假定所有人看过长版**。
- 若广告位过短：可能更适合单一生活意象，不应执着保留与长版相同的全部叙事任务。

# 平面版

单幅图能支持前后推断，但不等于完整呈现删改与重新决定——媒介条件决定平面版必须**缩小主张**。

- 候选画面：手机已翻面，产品容器仍打开，她的手正在完成一个明确步骤。可支持"暂时不让手机打断这段时间"，**不能**单凭图像证明她已安排明早回复。
- 标题候选：
  - "我明早看"——作为人物文字与画面的组合，直接承担安排；不再声称文字全部来自图像。
  - "今晚，也留一点给自己"——更开放，不证明具体工作协商。
- 裁切应保护手、手机状态与产品动作之间的关系，而不只保留脸。只剩人物和瓶子时可能变成常规产品肖像，应更新形式描述。
