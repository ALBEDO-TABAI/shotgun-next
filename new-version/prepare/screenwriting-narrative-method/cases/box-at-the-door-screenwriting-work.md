# 案例声明
以下为**自拟场景**，未实拍、未做受众测试。

# 1. 任务与薄弱初稿
- 任务：父女久别重见，观众要理解**父亲允许女儿回来**，但不宣称所有旧矛盾解决。
- 初稿：女儿说"我不知道你还愿不愿意让我回来"，父亲说"当然，我一直在等你"，两人拥抱。
- 诊断：并非天然不好，但把许可、和解、情绪收束挤在一起。若作品要保持复杂关系，就要**缩小结论**，而不是把台词写得更煽情。

# 2. 选材与建构
- 只保留来到门口的时刻，不回顾完整往事。
- 暂定：父亲擅长处理生活事务、难以直接谈关系；女儿容易预期拒绝。这两项是**创作假设**，必须通过行为逐步建立，不能当作未呈现行为的永久解释。
- 行李不是先被选作"人生象征"，而是确实需要位置、确实挡住通行。**物件的实际功能先成立，关系意义才能依附。**

# 3. 场景稿
```text
女儿拖着箱子停在门口。
父亲："别把箱子堵门口。"
她把箱子往外拉。
父亲向后退半步，门内空出一个位置。
父亲："往里放。"
女儿停了一下，把箱子推过门槛。
```

# 4. 组织与分配
- 先出现一个可被误解的事务性指令，再由动作确定方向。观众可能与女儿一起修正，也可能较早猜到；不能保证每个人都经历一次惊讶。
- 本场清楚建立的是**允许进入**。父亲是否道歉、女儿是否原谅、以后怎样，仍然开放——省略不是因为问题不存在，而是本场不承担全部解决。

# 5. 转译与执行依赖
- 父亲后退需要让空间变化可见。
- 女儿误拉不能演成长时间绝望，否则尺度过大。
- 配乐不必在第一句之前就把父亲定义为温柔，否则认知过程会改变。
- 若只拍父亲脸部特写，观众未必看见邀请的物理依据——此时不能只指责演员情绪不到位，应先检查动作与空间是否被呈现。

# 6. 制作限制触发的替代
- 门口太窄时：父亲移开鞋架，指向屋内说"放这里"。
- 可能保住"腾出位置"的关系，却减少原来的误解空间，也可能显得早有准备。
- 因此"动作等价"不是自动结论：替代后重看人物预期、信息先后和结束状态，决定是否需要修改其他部分。

# 适用边界
- 这是一份可使用的示范，不是已运行的程序或已通过的验收记录。
- 缩小结论是对"保持复杂关系"这一任务的选择，不是对拥抱结尾的普遍否定。
