# 要点

第二遍的任务是把"看到的经历"转成可复查的结构描述。五个步骤：

| 步骤 | 做什么 | 注意 |
|---|---|---|
| 1. 识别主导组织 | 调用形式档案，判断整体与局部主要靠事件、分类、论证、联想还是抽象形式连接 | 不用角色目标模型强行筛所有作品 |
| 2. 分开两条顺序 | 故事世界中事情怎样发生；作品中观众怎样得知 | 关系型、谜题型作品尤其要分开；作品有意保持矛盾时间时，列出竞争版本与不可确定部分，不为表格完整制造唯一真实顺序 |
| 3. 选择适当单位 | 镜头、动作、场景、序列各有用途 | 一镜到底可能有多个变化，快剪蒙太奇也可能承担同一任务 |
| 4. 描述进入与离开状态 | 人物知道什么、尝试什么、行动条件怎样改变；观众知道什么、解释什么、仍在等什么 | 非叙事段落可记录形式规律、对照和注意变化 |
| 5. 检查材料通道 | 电影信息来自语言、动作、声音、构图和剪辑，不只对白 | 为每项重要结论指出载体，避免"剧本说了"替代实际可见 |

认知叙事研究讨论理解中的线索、经验与推断，提供多种研究路径，但不直接给出通用的"注意力按钮"。

# 适用边界 / 不应自动做什么
- 不为了表格完整而给有意矛盾的时间线编一个唯一顺序。
- 不把剧本文字当作成片中实际可见的证据。
