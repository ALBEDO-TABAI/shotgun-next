# 要点

第三遍先在脑中或低成本草稿中比较，**不自动改动原作品**。六种操作：

| 操作 | 问什么 | 提醒 |
|---|---|---|
| 1. 删除 | 删去一条台词、一段准备或某次重复，会失去什么？ | 梗概仍能讲清，不代表情感、空间或形式体验没有损失 |
| 2. 换序 | 先知道结果、先看另一人物、先展示物件来历，会改变哪种问题？ | 好奇、悬念、惊讶可用于描述改变，但不是每部作品都必须制造它们 |
| 3. 换载体 | 说明换成动作、画外音换成画面，比较理解确定性、时间与关系 | 不预设动作版本更高级 |
| 4. 换条件 | 门没锁、工作很紧急、顾客已知工序，同一行为还能成立吗？ | 定位人物依赖的世界条件 |
| 5. 分离通道 | 只读台词、看无声画面、只听声轨，定位分工 | 完整作品依赖声音不是失败；通道独立生存不是普遍质量标准 |
| 6. 改结束点 | 提前或延后结束，事实是否清楚、余味是否变化？ | 保留停顿也可能有价值，但应能说明它承接什么 |

# 方法边界
- 反事实可以支持**作用假设**，不能证明真实观众反应或作者当时意图。
- 一次修改若同时改变多项条件，不能把效果全部归给其中一项。
