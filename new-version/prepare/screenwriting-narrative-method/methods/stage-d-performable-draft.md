# 要点

## 四项工作

1. **对白先写互动，后写声音**：先确定人物如何相互作用，再检查信息和策略，最后处理措辞、停顿、动作、旁白与字幕。不用大量金句补救任务不足。
2. **场所和动作接受现实检验**：空间是否允许移动，人物能否看见关键行为，工具是否真实可用，演员能否在所需时间完成。August 关于地点、参与者和行动的实践提问可参考，但不是普遍硬规则。
3. **声画分工**：精确信息由谁承担，空间关系怎样建立，情绪强调发生在哪里。不默认导演会补上全部缺失，也不必编剧锁死每个焦距。
4. **制作说明**：分开"必须成立的关系"与"候选执行"。例如必须看到信息已发送；采用屏幕特写还是其他可辨载体可以讨论。

## 交付

可阅读的场景稿、关键执行说明、待核查事实、替代方案及代价。复杂注释移到附记，不把正文变成心理百科和生产数据库。

# 适用边界 / 不应自动做什么

- 不把每句都改成潜台词或金句。
- 制作说明保护意义关系而非锁死手段。
