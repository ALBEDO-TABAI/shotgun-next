# 要点

问题不应只问"是什么故事"，而应先问：**它主要是在讲述变化、组织知识、建立判断、连接意象，还是展开形式变化？**

来源采用 Bordwell 对电影形式的五种组织入口：**叙事、分类、修辞／论证、联想、抽象形式**。它们可以在同一作品中组合。"抽象"指颜色、形状、运动、声音等形式关系成为主要组织依据，不是"意义难懂"。

## 同一题材（一把旧伞被修复）的五种组织

| 主导组织原则 | 核心连接方式 | 同一题材可以怎样呈现 |
|---|---|---|
| 叙事性组织 | 时间中的变化、行动与后果、经验的发展 | 一个人必须在某次见面前修好旧伞，行动逐步产生结果 |
| 分类性组织 | 类别、属性、组成部分 | 分别展示伞骨、伞面、伞柄的损坏方式与修复工艺 |
| 修辞／论证性组织 | 围绕某种判断安排理由、例证和诉求 | 提出"哪些旧物值得修复"，用案例说明判断依据 |
| 联想性组织 | 相似、对照、隐喻、情感关联 | 伞骨与树枝、缝线与伤痕、雨声与记忆中的声音相互连接 |
| 抽象形式组织 | 形状、色彩、运动、节奏的变化 | 伞面开合、圆形旋转、雨滴与敲击声构成视听变化 |

## 两个辨别点

1. **"有人的行动"不代表整体由叙事主导。** 工艺展示里也有人拿工具、转零件；若主要推进方式是"从伞骨讲到伞面再到伞柄"，则主要由分类组织。反之，故事片里的长段工艺描述仍可服务于行动过程。**局部是什么，与整体由什么主导，应当分别记录。**
2. **"商业目的"不代表整体采用论证形式。** 广告可以通过小故事、意象联想或抽象形式建立品牌联想而没有理由链；故事也可嵌入更大的论证成为例证（来源引 Iversen 关于修辞话语中的叙事）。不能写"因为它是广告，所以组织方式是论证"；应写"它具有商业传播用途；整体采用什么组织原则需要另外检查"。

## 判断步骤

1. 记录整体与各局部分别通过哪种方式连接（允许复合，不强制唯一标签）。
2. 做分析性试验：**如果改变某种连接关系，整部作品最重要的成立方式会不会被破坏？**
   - 打乱行动后果，人物经历难以成立 → 事件组织重要。
   - 打乱类别层次，知识结构混乱 → 分类关系重要。
   - 保留全部镜头但改变相似与对照的排列，意味明显变化 → 联想组织重要。
3. 把结果写成"整体由 X 主导，局部 Y 由 Z 组织"，而不是一个形容词。

# 适用边界 / 不应自动做什么

- 这是分析性试验，**不是证明被删掉的部分没有价值**；它定位结构依赖，不能替代观看测试。
- 不由传播用途反推组织形式；不由"有人物动作"反推叙事主导。
