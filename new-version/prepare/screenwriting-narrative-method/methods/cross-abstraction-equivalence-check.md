# 问题
一个简短改动可以跨越几层："明早看"改成"以后看"，字数相近却从明确时间变成不确定安排；人物主动交钥匙改为父亲取走钥匙，物件终态相同，选择权却不同。**交接不能只核对名词、终态或台词大意。**

# 四种等价（本包建议）

| 等价类型 | 检查什么 | 检查难度 |
|---|---|---|
| 事实等价 | 世界里发生的事是否相同 | 容易 |
| 行动关系等价 | 谁冒风险、谁选择、谁允许是否相同 | 容易 |
| 信息时机等价 | 观众何时知道什么是否相同 | 依赖实际版本 |
| 经验等价 | 观众经历的判断过程是否相同 | 依赖接收条件 |

不能因终态相同就宣称四种全部保持。例如父亲先说"欢迎回来"再移开鞋架，与先说"别挡门口"再让出位置，都允许进入，但前者明确、后者包含短暂误判——哪个更适合取决于当前任务。

# 操作步骤
1. 写出原安排与替代方案。
2. 逐一填写"保留"与"改变"两列（见下表格式）。
3. 判断被改变的层是否正是当前任务依赖的层。
4. 若是，要么放弃替代，要么**明确记录牺牲**并检查下游。

## 对照表格式（自拟示例）
| 原安排 | 替代 | 保留 | 改变 |
|---|---|---|---|
| 女儿先问能否回来 | 父亲先说欢迎 | 都可建立许可 | 谁冒着被拒绝的风险 |
| 父亲后退让出位置 | 直接剪到女儿已坐屋内 | 进入结果 | 选择过程和空间动作 |
| 结尾才看到旧物 | 开场先看到整理 | 保存事实 | 观众问题与揭示时机 |
| 轻声确认时间 | 文字字幕说明时间 | 精确信息 | 说话者、关系与语调 |

这个表不是禁止替代：有时明确牺牲一次反转换来更真切的关系，正是有价值的修订。

# 附：识别无人消费的工作
- 检查文件接收者能否说出它会改变哪个决定。人物报告若只被当成情绪词库，履历没有被使用；信息表若确实指导了画外声身份与字幕处理，它就参与了执行。
- 未使用材料不必都删除：研究笔记可保存为潜在资源，但不要与当前执行说明放在同一入口，也不要把整理数量当成完成度。
