# 问题

写了"她害怕失去认可"，后续所有动作都被解释成同一原因：自洽却不可反驳，任何行为都能事后讲圆。

# 操作

1. **给关键解释配竞争假设**。她写长回复，可能因为担心关系，也可能因为任务复杂、需要留记录。两种原因生成不同场景：前者对不同对象的回应会变化，后者主要随任务信息变化。创作可以选择，分析需要证据。
2. **从"能解释"到"有区分力"**。若一项设定无论人物怎样做都能解释，先降低它的确定程度；让场景显示条件差异，比补心理独白更有区分力。这不是要求文学人物服从实验控制，而是防止分析者拿不可核查的心理故事替作品补课。
3. **行动与价值交叉检查**。同一世界可有互相冲突的价值（忠诚、诚实、照顾、自主），人物也可能不知怎样平衡。不必给每种价值配一个代表人物朗诵立场；通过资源和时间让价值进入行动：只有一张车票、只能带走一件物品、需要在对方回来前决定。限制的作用是具体化，不是每个作品都要升级为极端困境。
4. **稳定人物也能成为变化中心**。一个人始终坚持先问对方需要什么，故事可写周围人如何误解、接受或利用；变化发生在关系和认识。人物尝试改变后又重复旧策略也可以有意义，但作品应显示反复的条件或代价，不把每次回到原点当作免费重启。
5. **世界规则的修订检查**。改变资源限制可能扩大选项；改变权限可能重写关系；改变知识分布可能重写责任；改变价值秩序可能使同一选择从被赞许变成被排斥。规则改动要查"哪些动作因此有了新可能"；角色结尾能做某事不证明开头已经能做，必须带着时间和条件检查。
