# 主题枢纽 · Topic Guides

每篇来源文档一个入口：回答什么问题、核心主张、本篇概念清单、与其它篇的交接。


# topic-01
* [第一篇：叙事形式识别与建模——从给作品贴标签，转向建立有证据的形式档案](01-narrative-form-identification.md) - 用户提供的原体系第一篇（参考原文），建立整个知识包的形式定位基础：分开命名依据、分析尺度与证据强度，先识别主导组织原则，再拆类型、事实性、世界规则、动力／结构／时间／信息与媒介通道，最后转成 skill 与双重尺度评价。

# topic-02
* [第 02 篇：编剧工作与协作贡献建模](02-screenwriting-work-and-contribution.md) - 把编剧工作理解为一组可追溯的选择——在什么材料和约束下，谁改变了什么叙事关系，通过哪些成果传递，是否进入实际作品；从文字产量转向可追溯的叙事决策。

# topic-03
* [第 03 篇：创作起点与具体问题建构](03-creative-origin-and-question.md) - 怎样把在意的东西转成值得研究的具体问题，再让问题生成不止一种表达方案；对应原十二点体系第③点。

# topic-04
* [第 04 篇：人物行为、关系与世界规则](04-character-relation-world.md) - 建立人物行动、关系网络与世界规则的联合模型；重点不是设定多，而是选择是否有根据。对应原十二点体系第④点。

# topic-05
* [第 05 篇：场景、情节与剧情进度](05-scene-plot-rhythm.md) - 看"什么发生了变化"而不只是发生了多少事：统一分析尺度、场景状态模型、空间与物件、连接类型、进度、时间、分层节奏、案例、诊断表、序列方法与 skill 接口。

# topic-06
* [第 06 篇：对白、潜台词与话语行动](06-dialogue-as-interaction.md) - 一句话既在传递意思，也在对另一个人做事：语言、关系、信息与表演的联合设计；对应原体系第⑥点。

# topic-07
* [第07篇：信息分配、留白与揭示设计](07-information-design.md) - 讲什么、不讲什么：组织事实、信念、线索与理解时机，不把信息量等同字幕字数或反转次数，不假定隐瞒越多越高级。

# topic-08
* [第 08 篇：精准、有效、不出戏、巧妙——审美判断的证据化](08-expression-evaluation.md) - 将四种审美判断分别转成可讨论的证据与取舍，不建立艺术总分算法；含评价前的陈述分层、四个标准的操作定义、标准冲突表、钥匙案例、反馈与分歧处理方法及 skill 接口。

# topic-09
* [第 09 篇：广告、影片与平面叙事的媒介适配](09-medium-purpose-adaptation.md) - 用传播用途、媒介条件、事实性承诺、观看情境四轴替代"广告／电影／平面"分类，处理品牌联系、产品因果、非虚构责任、单幅平面、裁切短版与多物料分工。

# topic-10
* [第 10 篇 · 护肤品牌短片的完整案例推演（「我明早看」）](10-skincare-film-case.md) - 用一条虚构的 45 秒护肤短片把前九篇的问题放到一起：从拆 brief、缩小命题、比较形式，到信息表、时间草案、场景稿、部门分工、关键关系、对抗性修改、短版与平面、验证计划与交付状态。

# topic-11
* [第11篇：作品分析诊断与证据化评价](11-close-reading-diagnosis.md) - 面对一部现成作品怎样实际分析和评价：三遍观察、证据分层、竞争解释与最小修改，输出形式描述、作用解释、问题诊断和可验证建议，而不是评分排行榜。

# topic-12
* [第十二篇：创作迭代、验证与协作交付流程](12-iteration-and-handoff.md) - 把前十一篇转成可调用的工作过程——四类输入、发散收敛、阶段A–G、最小协作架构、Agent 与人的分工、按问题调用模块、统一 skill 接口与最终交付检查；同时收纳全包的统一输入输出与协作保留条件。
