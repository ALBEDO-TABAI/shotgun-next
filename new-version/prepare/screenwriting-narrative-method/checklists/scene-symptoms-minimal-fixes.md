# 检查表

| 症状 | 先检查 | 候选修改 |
|---|---|---|
| 事件多却不推进 | 前事是否改变后事条件 | 建立一条真实后果关系 |
| 快剪仍费解 | 关键动作与文字是否可读 | 延长一个必要观察点 |
| 看懂后继续解释 | 信息任务是否已经完成 | 删重复结论，而非删行动后果 |
| 长镜头被说拖 | 段内注意或关系是否变化 | 检查持续的作用，不直接切碎 |
| 反转像突然换片 | 原有期待是否被处理 | 补连接，或承认整体方向要改 |
| 情绪尚未建立就结束 | 是否只给结果而省去选择 | 展开具体过程，不只加音乐 |
| 每场都强却疲劳 | 强度与功能是否单一重复 | 增加整合、对照或呼吸空间 |

# 使用规则

- 这些是**诊断假设**，不能按表自动改稿。
- 不能先决定"必须删 20%"，再寻找支持理由。
- 修改后要比较获得与损失（见 [案例 §修改的实际代价](/cases/moving-a-dining-table.md)）。
