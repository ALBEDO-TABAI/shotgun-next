# 检查条件（不能互相替代）

- 完整观看 / 静音 / 目标画幅 / 真实尺寸，各检查不同条件，不用一个结果替代另一个。

# 检查问题（分别问）

| 问题 | 做法 |
|---|---|
| 品牌认出 | 先开放复述，再进入具体问题，避免问题本身给出答案 |
| 内容理解 | 同上 |
| 情感解释 | 同上 |
| 现实行动 | 同上，不由前三项推出 |

# 平面专项

比较不同裁切和图文；不能仅凭停留久判断喜欢，停留也可能来自费解。观察与解释分开。

# 按作品类型追加

| 类型 | 追加复核 |
|---|---|
| 非虚构 | 来源和语境复核 |
| 工艺演示 | 专业核对 |
| 实际品牌 | 事实性陈述检查 |

它们不等于通用"观众觉得不错"验收。

# 状态

本包未执行这些测试；所有方案都需真实材料和相应条件才可给结果。
