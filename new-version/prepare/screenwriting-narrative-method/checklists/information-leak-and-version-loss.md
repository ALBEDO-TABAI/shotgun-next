# 检查项

| # | 检查 | 说明 |
|---|---|---|
| 1 | 剧本之外的通道 | 海报、标题、字幕、镜头范围、声音是否提前揭示？（字幕姓名可能揭示本要延迟的身份） |
| 2 | 版本裁切 | 竖屏裁切后，需要观众看见的邀请是否只剩面部表情？ |
| 3 | 关键揭示三项 | 为少数影响结构的信息写"最早允许明确"、"此前允许哪些线索"、"后续哪些行动依赖已知" |
| 4 | 泄露后的动力转换 | 提前知道寄件人，身份谜题变为等待收件人反应——作品是否完成了动力转换？改版提前则信息表、剪辑节奏与分析说明都应承认新结构 |
| 5 | "应该知道"的精度 | 区分：必须准确知道日期 / 只需知道不紧急 / 知道大致关系 / 仅需记住物件出现过。不同精度对应不同载体与时长 |
| 6 | 有意误解的行动条件 | 人物明知对方误会却长期不解释，需要实际成立的原因（没听见、以为指另一批物品、正忙于真实任务），不能分析时临时补 |
| 7 | 信息公平的期待 | 先识别作品与观众建立了什么期待（解谜承诺 vs 记忆不确定），再讨论是否背离 |

# 补充判断

- 泄露不总是坏事，问题是动力是否转换。
- 护肤片需要"可延期"，不一定需要观众牢牢记住"明天下午"四个字；把日期逐字回忆当唯一通过条件可能在测试错误任务。
- 更简单的路线常常是让人物立即说"没扔"，把关注移向怎样保存与双方回应。不必为维护初稿结构牺牲人物可信度。
- 形式开放不能免除事实性作品对真实证据的责任，也不能用不可靠叙述替普通制作矛盾兜底。解释发生在哪一层始终要清楚。
