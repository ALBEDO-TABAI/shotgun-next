# 23｜改图：说清改哪里，也要说清改完之后是什么样

## 问题在哪里

> 把这个房间弄得温暖一点。

这句话可能意味着：改光、改材质、改家具、还是全改？主体要保持吗？AI 不知道，你也没说。

## 先说清编辑范围

改图的核心结构：**原图 + 目标区域 + 操作 + 预期结果 + 重要保留项。**

先选目标：只改光，还是要换家具？主体必须保持吗？要复用哪张可靠的原图？

## 怎么指出"是哪一个"：从简单到复杂

只有一只杯子时，"桌上的杯子"就够了。东西很多时，用框、箭头、编号、局部裁切，或者工具支持的蒙版来减少歧义。

**别不分任务一律画满辅助标记。**

还有一个重要区别：图上的红箭头是**看得见的提示**，蒙版是**工具接口里的编辑范围**。它们不是同一种机制。即使给了蒙版，也不要假设外面的像素绝对不变——OpenAI 的官方文档明确说过，它的图像蒙版是"指导"，不保证精确沿着蒙版形状执行（见[图像工具的官方说法](/references/official-image.md)）。

## 四种常用操作，各有不同的后果

| 操作 | 要说清的事 | 要检查的事 |
| --- | --- | --- |
| 删除 | 只删对象，还是连影子、倒影一起删？ | 背景修复得怎样、有没有残影、纹理是否重复 |
| 替换 | 继承原来的尺寸和姿态，还是连结构一起改？ | 接触点、材质、主体身份 |
| 移动 | 原位置不留副本，新位置怎么落地？ | 透视、比例、阴影和遮挡 |
| 重打光 | 哪个光源、哪个区域变？造型要保持吗？ | 光影合理性、脸和产品有没有被重新生成 |

## 一条可用的"移动"说明

```text
用没打标的原图作为画面基础，打标图只帮助定位。把标 1 的这只花瓶移到标 2 的桌面空位，原位置修复成同一张桌面的连续纹理，不保留第二只花瓶。保持瓶型、花枝数量和主要朝向，按新位置匹配透视和接触阴影。人物、桌子结构和画幅不变，最终画面没有任何定位标记。
```

只有工具能同时理解这两张输入、并且分工清楚时，才这样提交。否则用一张轻标注的图，或者用原生蒙版。**别为了"信息完整"上传互相矛盾的多张底图。**

## 用保留项保护任务，别堆无关禁令

需要保住包装文字，就把字标列为重点。背景远处无关纹理的变化，按用途决定接不接受。

如果要求逐像素保留非编辑区域，最好在后期把通过的局部合成回可靠的原图，**而不是依赖一大段"其他地方绝对不动"。**

标记别盖住你想保留的结构。已经盖住了，另给一张没遮挡的原图或清晰的局部。AI 不能从不存在的信息里还原精确的设计。

## 完成后做两次比较

**第一次**：只看编辑目标对不对。
**第二次**：看原本正确的区域有没有被连带改了。

品牌、包装、连续人物，这两步同样重要。

连续编辑发生漂移，就退回最后通过的版本，分区域分步处理。**别把每张中间结果都叫"最终图"。** 怎么记最少的状态，见[资产与多镜头](/workflows/05-assets-multishot.md)。

## 一句话记住

**改图说五件事：原图、改哪、怎么改、改完什么样、什么不能动。红箭头是提示，不是锁。**

## 动手试试

想一个改图任务（比如"把左边的椅子挪到窗边"）。按"原图 + 目标区域 + 操作 + 预期结果 + 保留项"的结构写一遍。然后检查：你有没有说清原位置怎么处理？有没有说清新位置的阴影？
