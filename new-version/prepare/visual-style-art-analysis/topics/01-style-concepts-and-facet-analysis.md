# 回答什么问题

“这是什么风格”为什么难回答？一句话里混合了用途、历史来源、形式、再现、媒介外观与评价等不同性质的判断。怎样明确每个判断在说什么、作用于哪里、依据是什么？

# 核心主张

**不要把视觉风格识别理解为给作品分配一个唯一标签。** 先限定分析对象与证据范围，再按分面区分判断性质；风格概括建立在特征之间的组织关系上；历史归属、制作事实、创作意图和观看效果各需适当证据；缺少可靠名称时保留准确描述，缺少可靠证据时保留明确的未知。（源文件为用户原有基础篇；导出式引用标记已按来源归并到 Reference。）

# 本篇概念

## Framework

- [特征 → 特征关系 → 组织模式 → 有范围的风格概括](/frameworks/feature-to-style-progression.md) - 区分“某种特征”与“某种风格”的四级递进；以“留白”为例说明何时才有理由概括为简约呈现，且仍不等于 Minimalism。
- [分面分类：借 Getty AAT 的组织原则](/frameworks/faceted-classification-aat.md) - 围绕概念区分词义，再用层级、关联、同义关系连接概念；“广告”“青铜”“印象派”“对称”可共同描述对象，但不是同一组互斥选项。
- [沃尔夫林五组比较轴（改写为看片提问）](/frameworks/wolfflin-five-comparison-axes.md) - 线描性／绘画性、平面／纵深、封闭／开放、多样性／统一性、绝对／相对清晰——先比较“怎么看见”，再判断“看见了什么风格”。
- [图像志与图像学：三层解释框架（经 ICON 论文整理）](/frameworks/panofsky-three-levels-via-icon.md) - 识别对象和动作 → 识别约定主题、故事或形象 → 解释文化意义；对现代广告最重要的用途是限制解释的跳跃。
- [Bordwell 电影诗学：用可核查的中层问题代替风格名](/frameworks/bordwell-mid-level-questions.md) - 传统提供哪些选项、作品如何使用、哪些证据支持解释、反例能否修正理论；风格变化与创作者面对的具体问题相连。
- [视觉符号学：物象意义与造型意义分层](/frameworks/object-meaning-vs-plastic-meaning.md) - 可辨识的对象、人物、场景，与形状、色彩、纹理和空间关系不是同一分析层面；不内置“圆形永远温柔”一类无条件规则。
- [Rose 视觉研究方法：图像构成与使用场合分别记录](/frameworks/rose-image-and-its-context.md) - 同一张照片放在展览、详情页、杂志与私人相册里，分析任务不同；不能凭精致认定商业，也不能因来自广告就取消形式分析。
- [经验美学：审美情绪与审美判断是两种输出](/frameworks/leder-emotion-vs-judgment.md) - Leder 等的模型把感知、分类、理解、评价联系起来并区分情绪与判断；体验报告、机制解释、条件性评价、综合判断四句话不能互相代替。
- [十个描述分面（A–J）总览](/frameworks/ten-facets-overview.md) - 实践情境、类型、题材、历史谱系、再现方式、形式组织、修辞、媒介外观、观看关系、情绪体验——不是层级，不必全填，审美评价在分面之外。
- [十个分面之间的关系图（分析图，不是创作因果链）](/frameworks/facet-relationship-map.md) - 情境与类型提供问题和惯例，题材提供内容，谱系提供参照，再现、形式、修辞、媒介共同参与呈现，观看条件与观众参与体验形成；评价在图外。
- [分析范围五级：物件、单图／镜头、段落、完整作品、系列／作品群](/frameworks/analysis-scope-levels.md) - 每级适合判断什么、常见越界是什么；作品群可交叉，风格的稳定不等于所有部分都长得一样。
- [混合的三种工作类型：组织规则＋局部引用／同分面异质结合／跨分面有意冲突](/frameworks/three-hybrid-work-types.md) - 真正值得分析的是“什么与什么发生了关系”；判断“有意”仍需区分资料事实与分析假设，无证据时先说“形成了这种冲突”。
- [判断的证据身份（第一篇六类）](/frameworks/evidence-identity-six-kinds.md) - 可见描述、资料事实、分析解释、历史关系判断、目的或体验记录、评价——分别记录性质，而不用一个笼统置信度统治整份报告。

## Facet

- [A 实践与传播情境：这件作品在做什么事？](/facets/a-practice-and-communication-context.md) - 记录委托性质、用途、目标对象、发布位置与观看条件；商业性是使用情境，不是固定视觉样式。
- [B 作品类型与类型惯例：它属于哪一种作品活动？](/facets/b-work-type-and-genre-conventions.md) - 记录作品类型与有依据的类型惯例（宜分子字段）；类型与风格交叉但不互相决定，不能从明暗特征推出故事类型。
- [C 题材、对象与图像母题：它表现什么？](/facets/c-subject-object-motif.md) - 记录实际出现的对象、人物关系、事件、场所及有证据的反复母题；题材不等于形式，物件不自动等于象征。
- [D 历史、文化与作者谱系：它与哪些传统相关？](/facets/d-history-culture-lineage.md) - 记录可验证的历史风格、运动、地区与设计传统、亚文化、作者或作品参照，并写明关系类型；相似性不是影响关系的证明。
- [E 再现方式与现实约定：这个世界以什么方式成立？](/facets/e-representation-and-reality-conventions.md) - 至少分开三问：物体外观是否逼真、事件与空间是否符合现实规则、作品是否在作事实性主张；三者不能互相推出。
- [F 形式组织与视觉关系：画面怎样被组织？](/facets/f-formal-organization-and-visual-relations.md) - 覆盖空间、尺度、形态、色彩、明暗、表面、构图、文字布局与动态的运动和时间组织；重点是谁支配谁、何者重复、差异如何出现。
- [G 修辞与意义组织：不同元素怎样共同产生解释？](/facets/g-rhetoric-and-meaning-organization.md) - 记录类比、替代、并置、反差、夸张、尺度转换、材料错置、图文关系等可能的意义关系；修辞机制不是历史风格归属。
- [H 媒介、材料、技术与影像外观：它是什么做的，又看起来像什么？](/facets/h-medium-material-technique-look.md) - 至少分两组记录：有资料支持的实际制作方式，与画面可见的材料和影像外观；“像手工／像三维／像微缩”都是待核查判断。
- [I 观看关系与呈现环境：作品怎样安排观看者？](/facets/i-viewing-relation-and-presentation.md) - 记录观看距离、视点、遮挡、尺度感、是否直面观众、是否允许进入空间，以及屏幕、印刷、装置等呈现条件；解释须保留条件。
- [J 情绪调性与预期体验：希望怎样被感受，又实际被怎样感受？](/facets/j-emotional-tone-and-expected-experience.md) - 区分需求方要求的体验、分析者自己的体验、根据画面提出的体验假设、实际受众反馈；可参与风格概括，但不能替代形式描述。

## Term

- [视觉风格（工作定义）](/glossary/visual-style-working-definition.md) - 视觉风格是在明确作品范围内，由一组相互关联的视觉选择及其组织方式形成的相对可识别的呈现模式；识别靠比较，归属与意义需语境证据。
- [形式／风格／类型／Look／美术设计／审美评价：协作术语约定](/glossary/form-style-genre-look-terms.md) - 六个常被混用的词各自回答的问题：怎样构成、持续怎样呈现、属于哪类作品、看起来怎样、谁决定了什么、是否成立。
- [“极简”：消歧词条](/glossary/term-minimal.md) - 先澄清：指元素稀少、信息控制，还是历史上的 Minimalism？ 不足以成立的依据：白底加一个物件。
- [“复古”：消歧词条](/glossary/term-retro.md) - 先澄清：相对于何时？指哪个地区、媒介或设计领域？ 不足以成立的依据：发黄、颗粒、旧物。
- [“写实”：消歧词条](/glossary/term-realistic.md) - 先澄清：指外观逼真、生活经验可信，还是特定艺术史概念？ 不足以成立的依据：细节多、材质精细。
- [“超现实”：消歧词条](/glossary/term-surreal.md) - 先澄清：指非日常效果、某种修辞，还是 Surrealism 的历史关系？ 不足以成立的依据：只要有怪异物体。
- [“胶片感”：消歧词条](/glossary/term-film-look.md) - 先澄清：指什么可见特征？是否真的知道拍摄或输出介质？ 不足以成立的依据：单独添加颗粒。
- [“电影感”：消歧词条](/glossary/term-cinematic.md) - 先澄清：指构图、空间、照明、时间组织，还是某类电影的联想？ 不足以成立的依据：宽画幅、黑边或某套调色。
- [“日式／东方”：消歧词条](/glossary/term-japanese-oriental.md) - 先澄清：指具体何时、何地、哪种生活或视觉传统？ 不足以成立的依据：木材、留白、某种植物。
- [“拼贴”：消歧词条](/glossary/term-collage.md) - 先澄清：指实际制作、可见的碎片组合，还是观念层面的并置？ 不足以成立的依据：出现多个来源不明的元素。
- [“高级感”：消歧词条](/glossary/term-premium.md) - 先澄清：谁的评价？在哪种使用情境下？具体由什么支撑？ 不足以成立的依据：价格联想或个人好恶。

## Method

- [视觉风格分面描述：六步核心流程](/methods/six-step-facet-description.md) - 限定对象与证据范围 → 不带风格名描述 → 拆解每个标签 → 从特征推导组织模式 → 比较并核查（含替代解释）→ 输出有条件的概括。

## Principle

- [理论分工：每种学术方法只负责一种问题](/principles/theories-each-own-question.md) - 分面分类、比较形式、图像学、电影诗学、视觉符号学、视觉方法论、经验美学不拼成大一统解释器；著名理论也不应成为每次分析的必经关卡。
- [对象本身与对象的影像呈现分开分析](/principles/object-vs-its-image.md) - 椅子的设计传统与拍它的照片的构图、照明、色彩与观看方式是两个对象；场景中有古典建筑元素不等于影像采用古典构图组织。
- [风格的稳定不等于所有部分都长得一样](/principles/style-stability-allows-local-contrast.md) - 规范应允许“整体以某种方式为主，局部通过相反处理形成对照”，否则会把作品中最有意义的变化误判为“不一致”。
- [只分析实际获得的材料：范围限定而非补全](/principles/analyze-only-obtained-material.md) - 一张海报不能证明整个系列，一个预告片不能证明正片，一张压缩截图不足以判断原始颗粒与印刷色彩；正确输出是范围限定。
- [先排除“伪混合”：多个分面同时存在不等于风格融合](/principles/multi-facet-is-not-fusion.md) - “商业＋极简＋梦幻＋三维”很可能是使用性质＋形式组织＋预期体验＋制作方式的多分面描述；只有澄清词义后才有必要讨论融合。
- [用关系句代替百分比](/principles/relation-sentences-not-percentages.md) - “70%极简＋20%巴洛克＋10%赛博”在没有特征、计量单位与比较样本定义时，只是把感觉伪装成测量；关系句说明谁主导、谁被引用、作用在哪、怎样协调。
- [创作者自述只证明“他这样说明”，不单独证明效果已产生](/principles/creator-statement-proves-the-statement.md) - 主创陈述首先证明某人在某时某场合公开这样说明；可与制作记录互证材料使用，但不能代替受众材料证明观众感受。
- [文献收录四要素：解决的问题、已核对范围、可转化规则、适用限制](/principles/source-entry-four-fields.md) - 知识库不只存一份“推荐书单”；每份资料都应说明它解决什么问题、本次核对到哪里、转化出什么规则、不能推出什么。
- [什么时候可以停止补证](/principles/when-to-stop-gathering-evidence.md) - 已有材料足以完成当前任务且进一步研究不太可能改变决定；关键结论依赖无法获得的材料时停在条件性结论；问题问错时转向形式功能或新方案实验。

## Checklist

- [第一篇反例测试：风格概念辨析](/checklists/p01-counterexample-tests.md) - 八个应通过的判断：古典道具、数字颗粒、明亮恐怖、超写实不可能事件、段落差异、无合适风格名、需求当结果、多观看者分歧。

## Template

- [词义与适用条件词条（不是风格词库）](/templates/term-meaning-condition-entry.md) - 一个词条至少保留：名称与词义、所属分面、适用范围、支持的特征组合、不能单独作为依据的特征、易混淆概念、相关案例、参考来源。
- [分面分析的最小输出结构（六部分）与一句话综合句式](/templates/six-part-minimal-output.md) - 分析范围、分面描述、主导组织规则、风格与参照判断、证据与替代解释、一句话综合描述；内部可细，呈现可压缩。

## Case Study

- [Meret Oppenheim《Object》（1936）：毛茸茸的杯子不只是一个风格标签](/cases/oppenheim-object-fur-teacup.md) - 有馆藏记录支持的案例：用分面与范围得出不同性质的结论；可迁移的是“改变器物—材料—使用关系”的机制，而不是完整的艺术史身份。
- [虚构案例：“植物、清爽、轻盈”护肤广告的合格初步描述](/cases/fictional-skincare-ad-plant-fresh-light.md) - 虚构教学推演：不强行命名，排除把需求当效果、外观当技术、非现实关系当历史归属、题材当风格四类错误。

## Skill Interface

- [Skill：视觉风格概念辨析与分面描述](/skills/skill-style-concept-facet-description.md) - 把含混的风格问题转化为有范围、有证据、可继续分析的描述；暂不负责制作拆解、预算、心理判断、效果预测与评分。
