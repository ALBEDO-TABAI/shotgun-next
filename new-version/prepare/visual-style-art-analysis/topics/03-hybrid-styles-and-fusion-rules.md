# 回答什么问题

多个视觉来源在一件作品中如何被选择、改变、连接或故意保持冲突？怎样把这一机制转化为可继续创作的规则？

# 核心主张

**混合风格不是给多个标签寻找一个好听的总名，而是解释不同来源怎样被选择、变换和组织。** 优先描述关系与作用范围，允许统一，也允许有意义的冲突；能指出保留什么、改变什么、为何仍然成立，才真正理解了融合。

# 本篇概念

## Framework

- [形式分析：元素与组织原则（Getty 教学资料）](/frameworks/formal-analysis-elements-principles.md) - 线条、形状与体积、空间、色彩、质感作为观察入口，再以强调、平衡、运动、节奏讨论组织；两遍工作：先找特征，再找关系。
- [混合的四种情况：多分面并存、局部引用、同层面异质结合、跨媒介转译](/frameworks/four-hybrid-situations.md) - 每种情况实际发生的事与分析重点不同；实际作品可同时包含几种，任务是说清楚而不是选一个标签。
- [结构映射：真正值得借的是关系，而不是长相](/frameworks/structure-mapping-relations-over-looks.md) - Gentner 区分关系结构迁移与对象属性匹配；“借叶片形状”近于复制，“借叶片围合空场的关系”可换成织物或建筑构件后仍保留组织逻辑。
- [概念整合：组合不只是两个来源相加](/frameworks/conceptual-integration-selective-projection.md) - Fauconnier 与 Turner 的选择性投射与整合空间中的新结构；“植物＋建筑”弱组合只是花盆进房间，强组合让叶片成屋顶、茎成柱、露珠成照明点。
- [来源关系的证据身份：明确引用／有过程资料支持的影响／仅形式相似／来源未知](/frameworks/source-relation-evidence-status.md) - 给来源关系设证据身份，而不是给风格算概率；多个弱线索不自动累积成历史结论；分析旧作不能把自己的主动参照倒写成原作者的参照。
- [寻找融合规则的六类组织位置](/frameworks/six-organizing-positions.md) - 主导秩序、局部引用、跨对象映射、材料转译、冲突管理、时间分配——是分析位置，不是六种新流派；主导不按面积投票。
- [变换操作库：从“像什么”转向“改了什么”](/frameworks/transformation-operations-library.md) - 选择与删减、尺度重设、材料替换、维度转换、角色转移、程度统一、局部例外、顺序重排、接缝显露；每个操作应回答“改变了什么关系”。
- [把分析变成创作约束：核心不变量、允许变化项、有条件的例外](/frameworks/core-invariant-allowed-variation-exception.md) - 三类规则而非一长串同等禁令；下游能据此选择，规则也需要版本——概念从“玩具世界”改为“真实家居中的玩具异物”时应更新规则而非只换参考板标题。

## Term

- [混合视觉系统（工作定义）](/glossary/hybrid-visual-system-definition.md) - 把不同来源、组织方式或现实约定的视觉材料经选择和变换建立关系，形成可描述的整体或有作用的异质结构；混合不一定以消除差异为目标。

## Method

- [判断融合是否成立的五类诊断](/methods/five-fusion-diagnostics.md) - 去标签测试、去元素测试、换材料测试、跨镜头与跨版式测试、陌生参照测试——发现问题的工具，不是统一审美分数。

## Principle

- [先排除“伪混合”：多个分面同时存在不等于风格融合](/principles/multi-facet-is-not-fusion.md) - “商业＋极简＋梦幻＋三维”很可能是使用性质＋形式组织＋预期体验＋制作方式的多分面描述；只有澄清词义后才有必要讨论融合。
- [用关系句代替百分比](/principles/relation-sentences-not-percentages.md) - “70%极简＋20%巴洛克＋10%赛博”在没有特征、计量单位与比较样本定义时，只是把感觉伪装成测量；关系句说明谁主导、谁被引用、作用在哪、怎样协调。
- [“我认出两个来源”还不等于解释了作品](/principles/recognizing-sources-is-not-explanation.md) - 识别复杂器皿与空旷几何空间各自联想什么只完成参照定位；还要问谁是密集区、轮廓是否呼应、尺度是否改变、靠颜色连接还是靠反差、去掉后损失什么。
- [视觉修辞：图像结构与受众反应是两个研究问题](/principles/visual-rhetoric-structure-vs-response.md) - 类比、并置、替代、尺度错置是描述候选机制的词汇，能帮助提出测试问题，但不能独自证明观众理解了隐喻、记住了品牌或更愿购买。
- [相同材料也可能构成不同系统：“共同出现什么”≠“由谁组织整体”](/principles/same-materials-different-systems.md) - 相同的叶片、玻璃和水可以形成稀疏陈列，也可以形成密集包围；同色不保证同一种风格关系；形式分析描述结构，不证明历史来源。
- [混合可以来自创作问题与解决路径，而不只是流派宣言](/principles/hybrid-from-production-problems.md) - 实景无法容纳透视而引入绘景、演员需接触物体而保留实体、景深改变材料表面；不把技术妥协贬为缺陷，也不把结果美化成预先规划的观念。
- [多个来源也可能只是同一条消息的回声](/principles/echo-sources-not-independent.md) - 同一采访被三个网站转载仍是一条来源链；保留最接近原始陈述的记录，转载作查找或版本线索；真正的相互印证是不同材料从不同角度限制解释。
- [批评指向作品和目标，而不是攻击创作者](/principles/critique-the-work-not-the-person.md) - d.school 反馈教学强调善意批评、讨论目标及作品与个人的区分；友好不是只说赞美，专业也不是用难懂术语；能让对方理解判断并检验修改才是反馈价值。

## Checklist

- [混合失败时的诊断表：落在关系而不是风格名上](/checklists/hybrid-failure-diagnosis.md) - “不够统一”“像拼素材”“都好看但不成片”“高级与自然打架”“变化太少”“风格太杂”各自对应的可操作诊断与修订方向。
- [第三篇反例测试：混合风格与融合规则](/checklists/p03-counterexample-tests.md) - 广告＋胶片＋浪漫＋对称、无单一主导中心、单只历史器皿、同色但尺度矛盾、主创否认致敬、怪异即超现实、只有特写有效、要求百分比。

## Template

- [参照单元记录：来源—所借特征—证据—作用范围—变换—未保留部分](/templates/reference-unit-record.md) - 一个来源不必是整个流派；“未保留部分”防止参考图不断获得额外权力，直到作品变成参考的变体。
- [混合视觉最小规则卡（hybrid_visual_rule）](/templates/hybrid-visual-rule-card.md) - scope、source_relations（参照／证据状态／所借关系）、transformation、organizing_rule、preserved、excluded、allowed_variations、exceptions、failure_condition。

## Case Study

- [《芭比》：世界规则不等于“粉色加复古”](/cases/barbie-toy-world-rule.md) - 依据两份主创访谈：玩具研究、缩小比例、绘景与假透视、二维与实体组合、绘制泳池覆透明树脂；分析性概括为“可被真人进入的玩具世界”。
- [虚构案例：植物庭院与实验秩序怎样共处（三方案）](/cases/fictional-plant-courtyard-three-orders.md) - 虚构教学推演：“植物来源、精确感、轻盈”初稿只是四张符号标签；三方案——实验秩序组织植物、植物空间容纳精确操作、让冲突成为内容，并写成可交接关系句。

## Exercise

- [训练：抽出三条关系，换掉所有具体物件生成两个方案](/exercises/p03-extract-relations-swap-objects.md) - 新方案只是换色换皮→抽出的仍是表面；完全失去原关系→迁移时没保住关键条件；目标是检验描述是否抓住可迁移结构。

## Skill Interface

- [Skill：混合风格与融合规则分析](/skills/skill-hybrid-fusion-rules.md) - 输入作品或标记方案、分面判断、关键观察与参照资料；输出参照关系表、主导组织句、变换操作、保留与排除项、冲突作用、迁移条件与未知项。
