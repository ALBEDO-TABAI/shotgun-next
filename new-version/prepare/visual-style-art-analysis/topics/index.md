# 主题枢纽 · Topics

每篇源文档一个枢纽：回答什么问题、核心主张、本篇概念与跨篇交接。

* [00 阅读导航与使用说明](00-reading-guide-and-usage.md) - 全包导航：八篇与原有框架的对应、每篇应带走的能力、阅读路径 A–D、贯穿全包的证据规则、“科学性”的含义、最小练习与交付边界。
* [一 视觉风格的概念辨析与分面分析](01-style-concepts-and-facet-analysis.md) - 先分清“风格”到底是哪一层：风格的工作定义、七种学术方法的分工、十个描述分面（A–J）、分析范围、词义与适用条件库、伪混合、Oppenheim 案例、六步流程、证据身份与最小输出。
* [二 视觉观察与形式证据](02-visual-observation-and-formal-evidence.md) - 分析的第一步不是联想，而是把“看见了什么”说准确：视觉描述定义、四种精度、形式分析与知觉组织、观看任务与色彩边界、材料版本与四种缺失、对象—属性—关系—变化、观察菜单、四次观看、工具边界、案例与 skill。
* [三 混合风格与融合规则](03-hybrid-styles-and-fusion-rules.md) - 面对混合风格，重点不是拆出几个标签而是找出融合规则：混合视觉系统定义、四种情况、结构映射与概念整合、视觉修辞边界、参照单元、来源证据身份、六类组织位置、变换操作库、《芭比》案例、五类诊断与规则卡。
* [四 美术工作与设计决策](04-art-work-and-design-decisions.md) - “美术做了哪些工作”要从设计决策看，不只从物件数量看：工作定义、三种问题、岗位与部门边界、七类决策对象、世界规则、空间三张地图、陈设与做旧、道具作用、材料与颜色、制作取舍与风险、交接与连续性、案例、三栏分析与交接卡。
* [五 创作出发点与解释边界](05-creative-origin-and-interpretation-limits.md) - 怎样推测出发点又不变成过度解读：四个“为什么”、溯因推理、作品机制与生产条件、解释是有人提出的主张、七类证据身份、来源回声、三种解释强度、六种出发点、假设矩阵、过程追踪、Tim Walker 案例、反事实限制、解释质量与换轨。
* [六 从抽象需求到场景方案](06-abstract-brief-to-scene-proposal.md) - 真正开始构想场景时怎样从抽象要求走到具体方案：视觉构思定义、双钻与共同演变、原型是提问工具、brief 五种信息、感受词转译链、概念三层次、路线与变体、参考板、七层展开、原型类型、三十秒品牌片案例、AI 辅助构思与方案卡。
* [七 作品评价与反馈验证](07-evaluation-feedback-and-validation.md) - 先判断作品在解决什么再判断解决得怎样：五种判断、目标与偏好的地位、经验美学与测试设计边界、评价上下文五件事、七个维度、证据＋状态、评分锚点与权重、结果变量与证据方式、提问与比较、五段式反馈、A/B 案例、验收与批准范围。
* [八 分析沉淀与知识复用](08-knowledge-capture-and-reuse.md) - 把分析用于日常拆片、参考研究或 AI 分析时最后应留下什么：可复用知识定义、四种成熟度、PROV/标注/SKOS/ICON/FAIR/Datasheets 的借用、对象幻觉边界、八模块衔接、决策卡与规则卡、迁移链案例、参考库、版本与定位、AI 四操作、交接消费、结构化记录与维护。
* [09 研究来源与适用边界](09-sources-and-applicability-limits.md) - 第二至第八篇统一资料目录：35 项来源（R01–R35）的资料性质、核对范围、用途与限制，资料性质不能互相替代，二次整理中易丢失的限制，以及后续补充资料的原则；另含第一篇补充来源 S01–S06。
