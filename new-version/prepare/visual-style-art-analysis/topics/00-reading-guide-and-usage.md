# 回答什么问题

这套知识包怎样读、怎样组合使用？各篇负责什么，证据规则是什么，哪些内容是虚构教学推演、哪些有来源支持？

# 核心主张

**用途、题材、历史来源、形式、媒介和情绪是不同分面，不是高低层级；可见事实、资料事实、分析解释、体验与评价需要区分。** 八篇是可组合的方法模块，不是强制的八重审批；本包不重新发明竞争性的分类，也不把执行流程说成某一位学者的通行理论。

# 本篇概念

## Framework

- [八个模块怎样衔接：主要问题、核心产物、下游用途](/frameworks/eight-module-handoff-map.md) - 概念辨析→视觉观察→融合规则→美术工作→创作解释→方案构想→评价验证→沉淀复用；同一份观察不在每个模块重写成新事实，新解释引用旧观察但保留自己的判断身份。

## Principle

- [贯穿全包的证据规则（五条）](/principles/evidence-rules-across-pack.md) - 不同资料负责不同问题；工作框架不是普遍规律；教学案例不是已验证项目；没有全文不扩写全文结论；比较条件和未知项必须留下。
- [本包怎样理解“科学性”与研究范围](/principles/scientific-meaning-of-this-pack.md) - 问题清楚、概念分明、证据可追溯、结论不过界、替代解释可比较、方法可被反例修正；定向跨学科调研而非系统综述；35 项来源不是“35 项实验证明本框架有效”。

## Exercise

- [全包最小练习：一张图的五条关系、两个解释、一条带失效条件的迁移规则](/exercises/minimal-practice-one-image.md) - 选一张可合法访问、来源清楚的图片；写五条可见关系→选一项提两个解释→查能区分解释的资料→写一条带失效条件的迁移规则→换任务迁移并说明保留什么、需重测什么。

## Skill Interface

- [Skill：视觉风格与美术分析全包模块路由（阅读路径 A–D）](/skills/skill-visual-analysis-module-routing.md) - 模块可组合而非八重审批：建立理解走 A；拆图拆片走 B（一→二→三/四/五→七→八）；新方案走 C（六为入口）；团队模板或 AI 知识走 D（先八）；交付是研究型知识文档，未部署任何插件。
