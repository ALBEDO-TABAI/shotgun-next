# 递进

> **特征 → 特征关系 → 稳定的组织模式 → 有范围限定的风格概括**

# Examples

以“留白”为假设案例：

1. **特征**：有留白。
2. **特征关系**：产品周围留白较多，文字和道具退到边缘。
3. **组织模式**：主体始终被孤立展示，信息数量受控制，局部变化不能破坏大面积空场。
4. **风格概括**：才比较有理由概括为“以稀疏组织和主体隔离为核心的简约呈现”。

# 边界

- 第 4 步仍**不自动等于**艺术史上的 Minimalism，也不能证明创作者受过相关运动的直接影响（历史关系见 [分面 D](/facets/d-history-culture-lineage.md)）。
- 不能只把原词换成更多近义词（“梦幻”→“唯美、空灵、浪漫”）而冒充从特征推导出了组织模式。
