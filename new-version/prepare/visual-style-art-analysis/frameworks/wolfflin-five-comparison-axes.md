# 比较轴与观察问题

| 比较轴 | 实际观察问题 |
|---|---|
| 线描性／绘画性 | 形体主要靠清晰轮廓被识别，还是通过色块、明暗与边缘交融被感知？ |
| 平面层次／纵深推进 | 空间主要沿平行层次展开，还是强调前后穿透？ |
| 封闭形式／开放形式 | 关系主要在画面内部收束，还是明显向画外延伸？ |
| 多样性／统一性 | 各部分保留较强独立性，还是服从一个整体效果？ |
| 绝对清晰／相对清晰 | 形体是否尽量充分显露，还是让遮蔽和不确定参与呈现？ |

以上不是逐字翻译，而是改写成可用于看片的提问。

# 转化为 skill

先比较“怎么看见”，再判断“看见了什么风格”。避免误译式误判：

- “绘画性”不等于油画滤镜；
- “多样性”不等于物件多；
- “清晰性”不等于像素锐利。

# 边界

这些概念来自对特定欧洲艺术传统的比较，不能直接当作全球艺术的完整分类；原文也强调过渡与相对判断。
