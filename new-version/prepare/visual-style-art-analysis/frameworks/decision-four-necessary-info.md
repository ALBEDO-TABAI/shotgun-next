# 消费者视角

一个方案不是在概念图通过时就自动进入成片，还要经过绘图、制作、现场摆放、拍摄和后期；每次交接都可能改变原来的设计理由。对关键决定保留简单的“消费者视角”：

- 下一位接手者需要什么？
- 如何判断自己收到的是正确版本？
- 哪些问题不能自行重判？

# 四个必要信息

1. 要实现什么关系；
2. 为什么重要；
3. 有哪些已确认限制；
4. 由谁在什么产物上确认。

# Examples

“叶片薄且轻盈”仍然不足：制作方需知道哪些镜头显露边缘；摄影需知道透光是否核心；后期需知道哪些支撑允许移除；现场需知道朝向与复位方式。

不是要求所有部门共写一份巨大的文件，而是让同一关键决定在不同交接中保持语义一致。
