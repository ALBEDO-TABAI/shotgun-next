# 结果变量

1. 是否看到了主体；
2. 是否识别产品；
3. 是否理解主题；
4. 产生什么感受；
5. 记住什么；
6. 是否知道来自哪个品牌；
7. 是否点击或购买。

# 原则

- 看到得快不必然记得久；记得画面不必然记得品牌；觉得喜欢不必然采取行动。不是声称它们永远无关，而是要求对每一项结论提供对应证据。
- 眼动可以帮助研究观看分配，但仅凭注视不能确定理解、赞同或购买。
