# 五种关系

获得、使用、维护、存放、淘汰。

# Examples

一张老桌子可能被长期保留，但新灯具已经替换；一块地毯可能遮住损坏处；某件常用物品被放在顺手的位置。——这些是**可供构思的生活逻辑**，不是看到旧物就能确认的真实历史。

# 不要让所有东西拥有同一个年龄

“某年代的房间”不等于房间内每件物品都在同一年制造。若追求生活可信度，应研究具体人物如何积累物件，而不只是搜集某年代流行物。

# 边界

这是创作检查建议，不应反推现实中每个家庭都按同一种规律拥有新旧混合物；文化、资源、居住历史与个人习惯都需要具体资料。
