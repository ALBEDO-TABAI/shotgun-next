# 六种类型（工作菜单，不是完整的创意心理学模型）

1. **任务与传播问题**：要让谁在什么条件下理解什么？概念可能始于具体观看难题。分析既有作品时先确认真实用途，不把编辑摄影自动当成销售物料来解释。
2. **叙事与人物问题**：人物需要做什么，观众需要知道或暂时不知道什么？门的位置、物品是否顺手都可能是入口；物件不必象征人物性格，为动作提供条件已足够重要。
3. **形式与媒介问题**：怎样把一条线变成空间、让静物显得处于变化、用有限画幅表现尺度？给形式实验留位置。
4. **材料与工艺发现**：意外外观、模型改变对比例的理解、试拍暴露新可能。真实项目须有实验或陈述支持，否则只能说是可行入口。
5. **个人经验与文化材料**：童年空间、档案、绘画、仪式、地方工艺、日常物件。要具体化来源，不以“东方文化”“女性气质”等宽标签代替研究；个人联想不能直接普遍化。
6. **资源、协作与偶然**：场地、演员、预算、时间、已有资产、团队建议、偶然发现。不必视为低级，也不能因结果成功就把每次妥协补写成早已计划好的巧思。
