# Schema

| 维度 | 关键观察问题 | 适合使用的描述 | 容易越界的说法 |
|---|---|---|---|
| 空间与尺度 | 有哪些层次？边界在哪里？主体与环境如何比照？ | 前景遮挡主体下缘；产品高度约占当前画面一半 | 现场一定是超大摄影棚 |
| 形态与方向 | 哪些轮廓反复出现？曲直如何相接？ | 多条弧线在主体上方形成相似走势 | 曲线必然体现女性气质 |
| 色彩与明暗 | 颜色分别占据哪里？主体如何区分？ | 深色标签与浅色瓶身形成局部差异 | 蓝绿色一定令人舒缓 |
| 材料与表面 | 哪些反射、透射、纹理可见？ | 表面呈磨砂外观，边缘存在透光 | 使用了某种具体树脂 |
| 图底与构图 | 哪些部分成组？谁被隔离？边缘怎样收束？ | 主体被留白包围，前景枝条局部围合 | 观众必定先看主体 |
| 人物与物件 | 姿态、视线、接触与使用痕迹是什么？ | 手部与杯柄接触，杯口未接近嘴部 | 人物内心已经释怀 |
| 图文关系 | 文字解释、重复还是改变图像理解？ | 标题与产品分列两侧，并由同一水平线联系 | 文案一定提高转化 |
| 时间与变化 | 哪条关系保持，哪条被改变？ | 前半段被遮挡，末段通过相对位移露出标签 | 导演一定为了制造悬念 |

# 用法

这是**提问菜单**，不是全填表格。选择对当前作品最有区分力的维度，比把每一格填成空泛术语更有效。
