# 五种来源

1. 物体自身运动；
2. 摄影机运动；
3. 光或材料变化；
4. 剪辑导致的画面更换；
5. 文字或数字效果的出现。

# 原则

- 同一片叶子从左移到右，可能来自叶子移动，也可能来自镜头移动。信息不足时先写“叶片在画面中的相对位置发生变化”，不提前确定世界中的运动方式。
- 产品只在镜头末尾显露时，前半段的遮挡不是静态缺点，而是时间结构的一部分。结论应覆盖“何时看见”。
