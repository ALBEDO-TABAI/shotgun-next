# 三个层次

| 层次 | 回答 | 例 |
|---|---|---|
| 意义方向 | 作品在讨论、展示或让人联想到什么 | 与植物亲近 |
| 视觉命题 | 通过什么关系让它成为可见的东西 | 进入叶片构成的庭院 |
| 执行原则 | 哪些选择必须保持，哪些允许变化 | 叶片作为空间结构，而非四处撒放的配料 |

三者应连接，但不应混成一句只能反复解释的修辞。

# 弱概念与可工作的概念

- 弱：“自然、轻盈、未来感的高级护肤世界。”
- 可工作：“产品位于放大叶片围合的微型庭院中；光与水的变化逐步显露包装，但环境始终不给出真实人类尺度。”

后者不是因为更长才更好，而是能回答：要不要真实浴缸？叶片为什么放大？人物是否出现？镜头为什么从局部进入？哪些材料会破坏设定？有用的概念通常包含对象、关系、变化或观看位置中的几项。
