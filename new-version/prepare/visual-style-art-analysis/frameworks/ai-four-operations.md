# 四种操作

| 操作 | 内容 |
|---|---|
| 观察 | 记录能定位的对象、属性、关系和变化 |
| 外部核查 | 寻找制作、历史或作者陈述，标注来源范围 |
| 解释 | 基于已有证据提出关系与动机假设，保留替代解释 |
| 创作 | 把当前需求和参考机制组合成新方案，明确这是**提出**而非**发现** |

# 要点

- 这四种操作可以由同一工具完成，但输出身份必须清楚。
- 分成多个 agent 也不会自动解决问题：若都读取同一份未经核实的总结，只会重复同一个错误。
