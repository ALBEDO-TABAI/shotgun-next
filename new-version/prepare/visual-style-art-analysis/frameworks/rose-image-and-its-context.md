# 借用什么

Gillian Rose《视觉方法论》不只讨论构图，也涵盖内容分析、符号学、话语、机构与展示、受众研究、数字影像等方法，并区分研究语境、研究设计、具体方法与传播。

# 转化为 skill

- 把“**图像本身怎样构成**”与“**谁在何种场合使用、观看它**”分别记录，再讨论两者关系。
- 同一张照片放在艺术展览、商品详情页、杂志专题和私人相册里，分析任务不应完全相同。
- 不能仅凭画面精致就认定它是商业作品；也不能因为它来自广告，就取消对其形式和观念的分析。

# 边界

核对范围为作者说明、出版社目录及配套资源，不据此声称核对了整本书。
