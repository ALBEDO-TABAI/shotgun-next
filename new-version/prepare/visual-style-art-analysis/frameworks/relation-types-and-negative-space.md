# 关系类型

位置关系、相似关系、对比关系、遮挡关系、支撑关系、尺度关系、方向关系。

# 三句话不是同一类证据

| 陈述 | 性质 |
|---|---|
| “石头在产品下方” | 位置关系 |
| “石头托住产品” | 加入了对接触和支撑的解释 |
| “石头象征可靠” | 意义推测 |

三句话可以连续出现，但不能被当作同一类证据。

# 负空间

两个人物之间的空白不是一件物体，却可能是组织关系的关键。它需要通过**边界、面积和变化**来描述，而不是因为“没有东西”就跳过。
