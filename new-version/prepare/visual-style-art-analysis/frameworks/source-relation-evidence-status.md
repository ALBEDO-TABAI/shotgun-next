# 四种身份

- 明确引用
- 有过程资料支持的影响
- 仅形式相似
- 来源未知

# 原则

- 多个弱线索不一定能累积成一个确定的历史结论。
- 同一套文章彼此转载，也不等于多份独立证据。
- 一个著名艺术家的作品很像成片，只能先支持比较，不能直接支持“致敬”这个因果词。
- 生成新方案时可以主动选定参照；**分析既有作品时，不能把自己的主动参照倒写成原作者已经使用的参照。**
- 反例测试：提供主创明确否认某致敬的记录 → 修正因果归属，可保留形式比较。
