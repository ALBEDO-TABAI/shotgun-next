# Schema

| 信息类型 | 例子 | 应怎样处理 |
|---|---|---|
| 要完成的任务 | 让产品身份在最终展示段可辨 | 明确出现时点、对象和观看条件 |
| 已确认限制 | 必须使用现有包装版本 | 作为方案约束，变更需重新确认 |
| 体验目标 | 希望清爽、轻盈、带植物联想 | 转成多个候选机制，不能当成已实现效果 |
| 偏好与排除 | 不希望出现真实浴室 | 核对理由与适用范围，避免无限扩大 |
| 未证实假设 | 受众都喜欢浅色、叶片越多越自然 | 保持假设身份，必要时研究或测试 |
