# 三种类型

1. **组织规则与局部引用**：整体由一种形式规则主导，只在道具、服饰或局部装饰上引入另一个参照。
2. **同一分面内的异质结合**：例如同一场景的物件在形态、材料或年代线索上形成明显差异，需要说明这些差异如何共处。
3. **不同分面之间的有意冲突**：例如严肃题材采用轻快的观看方式；熟悉器物被换成与使用习惯不相容的材料。

# 边界

判断“有意”仍需区分资料事实与分析假设；没有证据时，可以先说“形成了这种冲突”。
