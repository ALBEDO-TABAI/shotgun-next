# Schema

|---|---|---|
| [世界规则](/frameworks/world-rules-three-scales.md) | 这个世界允许什么、不允许什么？ | 概念说明、视觉规则、参照及排除项 |

# 要点

- 可以由不同岗位共同完成，也可以在小团队中集中于同一个人。
- 产物不是越齐全越好：简单主图不需要长片规模的文档体系，但关键决定仍需要明确依据和承接者。没有被任何人使用的文件，不会因为文件名专业就自动增加质量。
