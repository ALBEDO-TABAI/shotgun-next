# 框架

Panofsky 的三层解释框架可简化为：

1. 识别对象和动作；
2. 识别约定的主题、故事或形象；
3. 解释其文化意义。

# 转化为 skill

- “看见一位人物拿着某件物品”、“认出一个特定神话角色”、“认为它体现某种文化价值”需要**不同知识**，后者还需要进一步论证。
- 第一步也不是完全没有经验参与的“纯客观观看”。
- 对现代广告，这套方法最重要的用途是**限制解释的跳跃**，而不是鼓励每张图都挖出一个宏大隐喻。

# 边界

- 本轮核对的是 ICON 研究论文对该框架的整理，**不是逐页核对 Panofsky 原著**。
- ICON 论文指出该框架原本主要面对西方中世纪与文艺复兴艺术，不能不加调整地套用于一切影像。
