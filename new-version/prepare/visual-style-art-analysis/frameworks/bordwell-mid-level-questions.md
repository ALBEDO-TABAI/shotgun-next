# 中层问题

Bordwell 在《电影诗学》导论中提倡可核查的中层问题：

- 具体传统提供了哪些创作选项？
- 作品如何使用这些选项？
- 哪些证据支持解释？
- 反例能否修正理论？

其风格史说明把风格变化与创作者面对的**具体问题和解决办法**联系起来，而不只归因于抽象的时代精神。

# 转化为 skill

不要只写“这是一种冷峻风格”，还要追问：

- 哪些镜头、空间与色彩关系产生了这种判断？
- 这些关系在哪里保持、在哪里改变？对观看有什么作用？
- 这是有资料支持的创作动机，还是我们根据成片提出的解释？

“让概念和证据接受反例修正”是分面描述流程第五步的工作原则。

# 边界

本包执行流程不是 Bordwell 原有算法；没有宣称通读整本书。
