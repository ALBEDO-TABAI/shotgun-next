# 模型要点

Leder 等人的审美加工模型将感知、分类、理解和评价联系起来，并明确区分**审美情绪**与**审美判断**两种输出。应当把它当作一种研究模型，而不是普适的审美计算公式。

# 四句话不能互相代替

| 句子 | 性质 |
|---|---|
| “我觉得压抑” | 体验报告 |
| “作品可能通过这些关系制造压抑” | 机制解释 |
| “这种压抑适合此处的表达任务” | 条件性评价 |
| “作品做得好” | 进一步的综合判断 |

# 在评审中的应用（第七篇）

- 评审保留两个问题：“我有什么感觉？”与“我为什么认为作品成立或不成立？”
- 不应把第一次接触时的困惑直接判为失败；也不能假设所有困惑最终都会转成欣赏。

# 边界

本轮只核对论文摘要与卷期信息（期刊年份 2004），不复述未经核对的全部加工阶段，不把它改造成输入色彩即可输出分数的算法。
