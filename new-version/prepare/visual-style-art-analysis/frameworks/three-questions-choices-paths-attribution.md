# 三种问题

| 问题 | 主要依据 |
|---|---|
| 这套画面有哪些**设计选择**？ | 作品本身 |
| 这些选择可能由哪些**工作实现**？ | 可提出候选路径 |
| **实际**是谁、在什么阶段作出这些选择？ | 过程资料 |

# 要点

- “美术可能做了哪些工作”与“实际美术做了哪些工作”应在标题上分开：前者用于学习和方案推演，后者涉及真实归因，证据标准更高。
- 合作成果可以写“该效果涉及空间、表面与摄影的协同”，而不是未经核查全归给某位创作者。Bordwell 将作品机制与生产条件放在同一研究视野，为分开检验提供方法参照。
