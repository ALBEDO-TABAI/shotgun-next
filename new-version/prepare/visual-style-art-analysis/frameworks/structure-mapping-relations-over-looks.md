# 依据

Gentner 的结构映射理论区分类比中的**关系结构迁移**与**对象属性匹配**，强调结构之间的对应，而不只是表面相似（本次核对原始论文摘要）。

# 转化

- “借一片叶子的形状”更接近对象属性复制；
- “借叶片之间围合一个空场的关系”允许换成织物、纸片或建筑构件后仍保留某种组织逻辑。
- 第六篇：一张参考图可只借主体与边界的距离，另一张借材料透光方式，第三张借空间逐步揭示的顺序；把三张图全部外观一起复制，不等于三种方法得到有效整合。

# 边界

这是方法建议，不能证明某次设计一定原创，也不能替代来源与使用资格的核查。关系描述提高分析和迁移精度，**不给模仿提供免责说辞**。
