# Schema

| 资料性质 | 用于 | 不能 |
|---|---|---|
| 原始理论与实证研究 | 概念、研究问题与其范围内的结论 | 摘要不足以支持细节、完整量表或未出现的因果结论 |
| 学术方法梳理与研究综述 | 组织问题、说明讨论历史及争议 | 不意味着所有理论可以拼成一个无矛盾的总模型 |
| 专业机构与行业资料 | 职责、工作过程与方法参考 | 地区、制作规模和组织方式会改变具体适用情况 |
| 主创陈述 | 公开表述的研究来源、想法或制作选择 | 不单独证明观众确实产生相同体验 |
| 数据与知识组织规范 | 来源、定位、概念和访问结构 | 不自动保证内容正确，也不要求本包实现完整技术标准 |

各 Reference 概念均记录其资料性质、本轮核对范围、主要用途与适用限制。
