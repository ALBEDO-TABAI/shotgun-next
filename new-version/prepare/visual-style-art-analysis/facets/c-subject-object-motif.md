# 记录什么

实际出现的对象、人物关系、事件、场所，以及**有证据支持**的反复母题。例如：身体、植物、家庭、都市劳动、镜子、门槛、破碎物、旅行。

# 边界

- **题材不等于形式，物件不自动等于象征。**
- “出现植物”和“自然主义风格”是不同判断。
- “出现镜子”和“表达身份分裂”之间，需要具体的关系证据。
