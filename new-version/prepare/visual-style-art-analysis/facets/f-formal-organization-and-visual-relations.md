# 覆盖范围

空间、尺度、形态、色彩、明暗、表面、构图、文字布局，以及动态作品中的运动和时间组织。这是狭义视觉风格描述的核心之一。

# 关键问题

> 谁支配谁？谁衬托谁？哪些重复？哪些被隔离？差异如何出现？变化服从什么规则？

不是只记录“有蓝色、有圆形、有对称”。

# 边界

- 影片只有静帧时，应明确**时间组织尚未分析**；
- 静态海报不必硬填镜头运动。
