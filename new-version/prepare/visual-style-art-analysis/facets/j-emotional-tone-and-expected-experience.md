# 四种来源要分开

1. 需求方要求的体验；
2. 分析者自己的体验；
3. 根据画面提出的体验假设；
4. 实际受众反馈。

# 边界

- “希望轻盈”不能作为“已经轻盈”的证据。
- “我觉得疏离”也不能直接变成“所有观众都会疏离”。
- 这部分可以参与风格概括，但不能反过来替代形式描述。
