# 分面 · Facets

第一篇提出的十个描述分面（A–J），各自回答的问题与边界。


# 一 风格概念辨析与分面分析

* [A 实践与传播情境：这件作品在做什么事？](a-practice-and-communication-context.md) - 记录委托性质、用途、目标对象、发布位置与观看条件；商业性是使用情境，不是固定视觉样式。
* [B 作品类型与类型惯例：它属于哪一种作品活动？](b-work-type-and-genre-conventions.md) - 记录作品类型与有依据的类型惯例（宜分子字段）；类型与风格交叉但不互相决定，不能从明暗特征推出故事类型。
* [C 题材、对象与图像母题：它表现什么？](c-subject-object-motif.md) - 记录实际出现的对象、人物关系、事件、场所及有证据的反复母题；题材不等于形式，物件不自动等于象征。
* [D 历史、文化与作者谱系：它与哪些传统相关？](d-history-culture-lineage.md) - 记录可验证的历史风格、运动、地区与设计传统、亚文化、作者或作品参照，并写明关系类型；相似性不是影响关系的证明。
* [E 再现方式与现实约定：这个世界以什么方式成立？](e-representation-and-reality-conventions.md) - 至少分开三问：物体外观是否逼真、事件与空间是否符合现实规则、作品是否在作事实性主张；三者不能互相推出。
* [F 形式组织与视觉关系：画面怎样被组织？](f-formal-organization-and-visual-relations.md) - 覆盖空间、尺度、形态、色彩、明暗、表面、构图、文字布局与动态的运动和时间组织；重点是谁支配谁、何者重复、差异如何出现。
* [G 修辞与意义组织：不同元素怎样共同产生解释？](g-rhetoric-and-meaning-organization.md) - 记录类比、替代、并置、反差、夸张、尺度转换、材料错置、图文关系等可能的意义关系；修辞机制不是历史风格归属。
* [H 媒介、材料、技术与影像外观：它是什么做的，又看起来像什么？](h-medium-material-technique-look.md) - 至少分两组记录：有资料支持的实际制作方式，与画面可见的材料和影像外观；“像手工／像三维／像微缩”都是待核查判断。
* [I 观看关系与呈现环境：作品怎样安排观看者？](i-viewing-relation-and-presentation.md) - 记录观看距离、视点、遮挡、尺度感、是否直面观众、是否允许进入空间，以及屏幕、印刷、装置等呈现条件；解释须保留条件。
* [J 情绪调性与预期体验：希望怎样被感受，又实际被怎样感受？](j-emotional-tone-and-expected-experience.md) - 区分需求方要求的体验、分析者自己的体验、根据画面提出的体验假设、实际受众反馈；可参与风格概括，但不能替代形式描述。
