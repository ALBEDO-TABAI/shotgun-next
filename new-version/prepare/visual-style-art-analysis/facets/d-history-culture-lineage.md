# 记录什么

可验证的历史风格、艺术运动、地区传统、设计传统、亚文化、特定作者或作品参照。

# 关系要写明确

> 属于某传统／明确引用／经资料证实受到影响／仅有形式相似／来源待确认

# 边界

- **相似性不是影响关系的证明。** 某张广告与某幅绘画构图相近，可以作为比较发现；除非有进一步资料，不应写“导演致敬了该画家”。
- 不把“东方”“日式”“欧洲古典”等宽泛词直接当成已完成的历史解释。
