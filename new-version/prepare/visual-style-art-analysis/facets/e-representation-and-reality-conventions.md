# 三个问题

1. **物体外观是否逼真？** 材质、光影和形体是否具有可辨识的物理外观？
2. **事件与空间是否符合现实规则？** 尺度、重力、因果和空间关系是否符合日常经验？
3. **作品是否在作事实性主张？** 它要求观众相信这是记录，还是明确允许虚构、表演和想象？

# 边界

这三者不能互相推出，避免被“写实／不写实”二选一压扁：

- 一片材质极其逼真的悬浮海洋，可以是外观逼真、事件不现实；
- 一张粗糙简图，也可能准确表达真实空间关系。

**“看着像真的”不等于“事情真的发生过”。**
