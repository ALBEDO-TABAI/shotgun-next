# 步骤

1. 先**覆盖**可获得片段（避免只取开头、中间、结尾而漏掉短暂但关键的变化）。
2. 为关键遮挡、动作、场景切换**增加事件样本**。
3. 需要判断持续时间时，回到**连续播放**。
4. 没有检查的区间留下**范围限制**。

# 反模式

只挑最漂亮的帧，可能把不稳定的片段伪装成统一风格。
