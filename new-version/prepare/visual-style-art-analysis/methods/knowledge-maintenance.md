# 步骤

1. **新增时检查是否真有新知识**：与已有卡片只有颜色不同，可能只需增加一个案例；出现新的失效条件、新的组织关系或不同任务，才值得新建或修订规则。不以数量作为唯一进展指标——能否回答新的设计问题、能否找到原证据、能否避免重复犯错更接近实际用途。
2. **更新时保留理由，不覆盖历史**：见 [版本变化传播](/principles/version-change-propagates.md)。
3. **定期检查失效链接与权限**：见 [可复用不等于全部公开](/principles/reusable-not-all-public.md)。
4. **用新任务做回归测试**：从新需求出发检索旧卡，尝试提出与原案例外观不同的方案，再检查是否仍保留了正确的关系。若只会产出原图变体，说明知识可能仍停留在表面配方。

# 边界

“回归测试”是工作类比：检查修订后的方法是否仍能处理既有问题，不宣称艺术创作具有唯一标准答案。有新测试结果时，更新相应规则或适用范围，不只把结果附在末尾。
