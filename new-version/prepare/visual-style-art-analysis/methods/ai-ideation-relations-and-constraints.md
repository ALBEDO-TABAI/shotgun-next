# 步骤

1. 把生成任务拆成“**当前要探索的关系**”和“**不得破坏的条件**”，而不只堆叠风格形容词。
2. 分轮探索：一轮只研究叶片与产品的相对尺度；另一轮研究光如何通过叶片；再一轮研究竖版中的空间开口。
3. 评估时明确**通过了什么**：可能概念方向通过但材料未通过；静态布局通过但空间连续性未通过；气氛通过但包装身份未通过。不让一个“好”字解锁全部后续工作。
4. 规则改变后，相应的提示词、参考板、关键图和测试标准都要检查是否需要更新——不能一边要求薄而透光，一边继续用旧版厚重叶片的参考图。

# 边界

- 生成数量增加不等于概念探索增加；十张近似图可能只是同一路线里抖动细节。
- 真实项目中的预算、付费调用和对外发布需要对应授权；文字方案不是自动执行许可。
