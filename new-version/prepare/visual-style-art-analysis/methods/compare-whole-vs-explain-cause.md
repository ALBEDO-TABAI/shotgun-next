# 步骤

1. 明确问题类型：
   - **选整体**：“这两套完整方案哪套更适合继续？”→ 可以比较整体，但结论不能精确归因于某一种颜色或道具。
   - **解释原因**：“瓶身区分不足是否由背景纹理造成？”→ 尽量限制其他变化；复杂问题也可采用多因素设计，不必把“一次只改一个”奉为唯一方法。
2. 安排比较条件：随机分配不是按名单轮流分配；随机展示也不是永远先看A再看B；顺序、熟悉程度及比较方式需要明确安排。
3. 需要严格推断时，提前明确样本、主要指标、分析方案及可接受的不确定性。

# 边界

本包不提供一个不论任务都适用的样本人数。反例测试：A/B 同时改变多项内容 → 只能比较整体或重新设计诊断，不宣称某种颜色造成效果。
