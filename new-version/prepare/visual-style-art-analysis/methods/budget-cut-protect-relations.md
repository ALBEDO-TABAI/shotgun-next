# 步骤

1. 区分**核心不变量**和**可替换实现**。
2. 列出候选调整：换材料、缩小可见范围、调整镜头、简化重复结构。
3. 逐项检查哪种变化会破坏主要关系。
4. 讨论的问题是：哪一项不做会让概念不成立？哪一项可以用另一条路径保留作用？

# 反模式

“全部降一级”通常无法回答这个问题。
