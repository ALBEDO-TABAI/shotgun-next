# 原则

- 关键视觉可以说明一个观看位置，但不能自动证明横向移动、低机位或反打都能成立。
- 空间设计需要知道：哪些区域会被看见，哪些边界需要开放，哪些对象会在运动中互相遮挡。

# 步骤

1. 列出最关键的观察位置与运动；
2. 用低成本空间模型或简化预演检查；
3. 再决定制作到什么程度。

# 边界

这是为了回答具体问题，不是给每个项目增加三维建模步骤。反例测试：关键视觉通过，但要新增绕拍 → 重新检查可见范围与支撑，而非默认已完成。
