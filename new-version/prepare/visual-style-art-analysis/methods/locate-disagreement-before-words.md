# 步骤

1. 先比较**定位和证据**，再比较词。两人都说“清爽”不一定一致（一个指浅色背景，另一个指动作节奏）；一个说“稀疏”、另一个说“留白较多”可能指同一关系。
2. 给争议分类：对象边界不同／词义不同／观察材料不同／机制解释不同／价值判断不同。只有第一类和部分第二类适合通过更精细描述直接解决。
3. AI 生成的句子按同一标准检查：文字丰富不代表观察丰富；不能指出在哪里看见某对象的自动报告，不因语言自信升级为事实。
4. 为减少诱导，观察阶段可先不提供“想要的风格名”，让系统描述关键特征，再与需求对照。

# 边界

第 4 步是工作策略，需要在实际样本中比较效果，不声称一定消除所有偏差。
