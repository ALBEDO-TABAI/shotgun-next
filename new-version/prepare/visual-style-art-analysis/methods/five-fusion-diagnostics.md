# 五类诊断

1. **去标签测试**：拿掉“未来、东方、极简”等名称，只用关系描述，还能否说明作品怎样工作？若只剩物件清单，可能尚未找到融合机制。
2. **去元素测试**：暂时移除一个关键元素，观察概念、构图、使用关系或时间结构损失了什么。无明显损失可能是可替换装饰，也可能你还没找到其作用——不要立即把所有可删除元素判为多余。
3. **换材料测试**：保留轮廓和位置，换成另一种候选材料。概念不变→原材料可能不是核心；识别、触感或世界约定改变→材料承担更深作用。需实际样图或测试确认，纯文字推演易忽略光、尺度和表面的相互作用。
4. **跨镜头与跨版式测试**：只在一张关键视觉中成立，不代表整条影片或所有裁切都成立——镜头移动揭示背面和支撑，竖版可能切断围合关系，近景可能暴露材质接缝。区分“可接受的局部变化”与“使核心机制失效的变化”。
5. **陌生参照测试**：不认识历史参照的观看者还能否感知主要关系？若作品必须依赖特定知识才成立，应写出这一条件；有些艺术作品要求专门知识，某些传播任务需降低门槛。

# 边界

诊断工具不是统一审美分数。
