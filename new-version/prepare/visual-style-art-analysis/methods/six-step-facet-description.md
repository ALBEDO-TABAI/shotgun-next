# 步骤

1. **限定对象与证据范围**：原作、复制图、海报、静帧、完整镜头、片段还是完整作品；记录已有来源和用途；没有的信息标为未知。
2. **先作不带风格名的描述**：关键对象、空间、形态、色彩、材料外观、观看位置和时间变化；目标是找出最能区分当前作品的特征与关系，而非无穷细清单。
3. **拆解输入中的每个标签**：对“复古、电影感、高级”逐一判断——此处是什么词义？属于哪个分面？是需求、观察、解释还是评价？多义时保留歧义。
4. **从特征推导组织模式**：主导关系、重复模式、局部例外和相互冲突；不把原词换成更多近义词。
5. **比较并核查**：为历史归属、作者参照、材料与制作事实找适当来源；测试替代解释——同一特征是否也见于其他传统？是否把常见手段误当独特身份？
6. **输出有条件的概括**：先主要描述，再说明历史关系、未知项与限制。**保留一个准确的无名描述，优于提供一个错误的有名分类。**
