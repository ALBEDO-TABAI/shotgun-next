# 步骤

1. 明确该物件或空间的**完成条件**：出现在哪些镜头、是否被绕拍、触摸、破坏或浸湿？
2. 区分“**镜头需要的精度**”与“**工艺默认能做到的精度**”。
3. 按完成条件决定制作程度。

# Examples

- 只在固定正面镜头出现的背景，不一定需要完整四面制作；
- 会被绕拍、触摸、破坏或浸湿的物件，不能只凭单一关键视觉决定完成度。
