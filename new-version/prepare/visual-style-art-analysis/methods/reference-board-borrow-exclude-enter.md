# 每张参考三句话

**借什么；不借什么；如何进入当前方案。**

- 太宽：“借这张的清爽感。”
- 可用：“借上方构件与主体之间保留的空隙；不借色彩和物件；用于检验庭院是否显得开放。”

# 按问题组织

空间关系板、材料与光板、人物与物件互动板、时间揭示板、历史资料板，各自回答不同问题。小项目可以合并，但应保留引用目的。不要让一张完成度很高的参考图同时替代所有答案——构图合适，产品尺度、实际材料和使用条件可能完全不适合。

# 反参考与边界案例

- **反参考**不是“难看的图片”，而是对当前任务不适用的关系：这张叶片太厚，缩小后形成压顶；那张玻璃反射太多，包装信息难读。
- **边界案例**帮助说明允许变化到什么程度；只有正面示例的规则，很难让别人知道哪里会失效。
