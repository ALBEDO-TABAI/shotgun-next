# 步骤

1. 先说明**哪个具体判断**需要更多证据。
2. 选择对应资料：
   - 讨论实际材料 → 优先制作记录或主创信息；
   - 讨论观看效果 → 与目标人群、任务和媒介相匹配的研究；
   - 讨论历史引用 → 比较形式并核对历史联系。
3. 发现更正或反例时，**修改受影响的判断与范围**，而不是只在目录末尾增加一条链接。

# 原则

新增一份看起来权威、却没有支持当前句子的文献，并不会让结论更可靠。
