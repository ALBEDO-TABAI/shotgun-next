# 步骤

1. 对每件关键物件问：“拿掉会损失什么？”
2. 若回答只有“更有氛围”，继续问氛围通过哪一条关系发生。
3. 具体作用示例：叶片遮出光斑、杯子迫使人物停顿、镜子显露画外空间。
4. “因为这种片子通常有这些东西”可能只是在复制类型外观。

# 边界

不能把这项练习当成极端删减原则。作品可以保留多义、冗余和环境密度，只要知道它们共同承担什么，而不是把所有不能一句话解释的物件都清除。
