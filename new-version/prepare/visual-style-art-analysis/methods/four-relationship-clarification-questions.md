# 四个问题

1. 谁在什么条件下看？
2. 作品希望改变哪一种理解或感受？
3. 什么信息必须出现、何时出现？
4. 哪些内容宁可不做也不能误表达？

# 优先级

- 不必一开始问完二十个表格，优先澄清**会改变概念选择**的问题。
- 横竖版用途尚未确定且会影响空间方案 → 很重要；
- 一种背景石材的真实名称未知但只是外观候选 → 可以稍后再决定。
- 反例测试：客户只说“高级一些” → 提取实际不满意之处和任务，不直接套石材金属。
