# 两项检查

1. 拿着概念面对**两个不同道具**时，能否说明为什么选一个？
2. **拿掉关键关系**后，概念是否仍能原封不动套用？

# 判读

- 若任何方案都符合概念 → 可能过于宽泛；
- 若只允许完全复制一张参考 → 可能只是具体外观的别名，而不是能继续生成选择的概念。
