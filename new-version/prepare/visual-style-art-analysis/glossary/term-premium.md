# 首先要澄清什么

谁的评价？在哪种使用情境下？具体由什么支撑？

# 不足以成立的依据

价格联想或个人好恶

# 说明

“高级感”是评价词，不是风格名。应改写为可见特征与条件性评价；不能输出没有定义的“高级感得分”。

# 用法

同一个词在不同句子中可能落入不同分面；存在多个合理义项时，保留歧义而不是提前锁死（见 [六步分面描述](/methods/six-step-facet-description.md) 第三步）。
