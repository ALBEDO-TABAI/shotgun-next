# 定义

> 视觉风格，是在**明确的作品或作品集合**中，由一组**相互关联**的视觉选择及其组织方式，形成的**相对可识别**的呈现模式。它的识别依赖**具体比较**，其**历史归属与意义解释**则还需要语境证据。

# 不能省略的五个限定

| 限定词 | 约束了什么 |
|---|---|
| 明确的作品或作品集合 | 先限定分析范围：单个道具、一个镜头、一条广告、一个品牌多年影像不是同一判断对象 |
| 相互关联 | 不能只数元素；要说明对称、低饱和、缓慢运动如何**共同组织观看** |
| 相对可识别 | 不要求每种风格都有专属名称，也不要求特征独一无二 |
| 具体比较 | “更简约／更写实／更舞台化”必须说明相对于什么 |
| 历史归属需要语境证据 | 区分“看起来相似”与“确实属于、引用或受影响” |

# 边界

- 这是本包为广告、平面摄影与影片分析整合的**工作定义**，与 Bordwell 把整体构造、局部呈现、生产条件和观众体验联系起来的取向相容，但不是任何学者提出的“通行十层风格理论”。
- 一种 Look 不足以概括整套风格；一种风格也不等于某个部门的全部工作。
