# 定义

> 视觉描述，是对一个**明确版本、明确范围**内的可见对象、属性、相互关系和时间变化，作出**可定位、可复核、与证据相称**的陈述。

# 要点

- 准确描述不等于写下画面中所有名词：“产品、叶子、水、石头、白色背景”仍不能说明这张图与其他使用同样物件的图有何不同。
- “可复核”不意味着每个人必须产生同一种感受，而是别人能找到你在说什么，并区分分歧出现在对象识别、边界划分、关系判断还是效果解释。

# Examples

“画面很疏离”无法直接复核 → “人物位于画面右侧，身体未朝向另一人；两人之间有一片没有家具的区域”提供了可讨论的依据；之后才提出“这些安排可能参与制造疏离”的解释。
