# 定义

本包把“关键道具”定义为：**会显著影响行动、理解、主体识别或镜头完成的物件**。它可能很便宜，也可能画面面积很小。

# 要点

- 英雄道具与普通陈设不能只按价格区分。
- 对这类道具，外观、可操作性、替代件和状态变化往往需要一起测试。一个标签非常清楚的包装模型，如果无法按镜头要求开启，仍然没有完成对应工作。
- 只在远景出现的物件，不必默认拥有近景级别的全部细节。
