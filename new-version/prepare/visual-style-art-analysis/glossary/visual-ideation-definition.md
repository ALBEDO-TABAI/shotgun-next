# 定义

> 视觉构思，是在具体任务和限制下，提出**能够组织场景关系的概念**，并通过制作、观看和反馈逐步检验、修订这些关系的过程。

# 要点

- “高级、自然、梦幻”这些话可能指出需求方不喜欢现有方案的方向，但不足以决定产品放哪、场景多大、为什么用叶片、镜头如何移动。
- 不能只用另一组同义词回应（“高级”→“克制、精致、奢华”）：词变多了，决定没有变清楚。
- “概念”不是事后包装方案的文案，而是一项能帮助作选择的设定。“把产品置于被放大叶片围合的微型庭院”已开始决定尺度、空间和观看位置；“天然高级”还没有。
