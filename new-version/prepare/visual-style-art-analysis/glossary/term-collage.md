# 首先要澄清什么

指实际制作、可见的碎片组合，还是观念层面的并置？

# 不足以成立的依据

出现多个来源不明的元素

# 说明

拼贴可能落在媒介（制作）、形式（可见碎片）或修辞（并置）分面；混合情形另见“伪混合”的排除。

# 用法

同一个词在不同句子中可能落入不同分面；存在多个合理义项时，保留歧义而不是提前锁死（见 [六步分面描述](/methods/six-step-facet-description.md) 第三步）。
