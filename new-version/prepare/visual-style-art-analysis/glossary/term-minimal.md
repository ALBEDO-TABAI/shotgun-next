# 首先要澄清什么

指元素稀少、信息控制，还是历史上的 Minimalism？

# 不足以成立的依据

白底加一个物件

# 说明

Minimalism 的历史语境还涉及材料、空间、序列与重复等问题（MoMA 相关专题按这些方面展开），并不是“东西越少越属于这个运动”。“以稀疏组织和主体隔离为核心的简约呈现”可作为无名描述。

# 用法

同一个词在不同句子中可能落入不同分面；存在多个合理义项时，保留歧义而不是提前锁死（见 [六步分面描述](/methods/six-step-facet-description.md) 第三步）。
