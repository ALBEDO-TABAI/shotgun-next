# 步骤

1. 选择一张**可合法访问、来源清楚**的图片，限定只分析这张图。
2. 写五条可见关系。
3. 选择一项关键关系，提出两个可能解释。
4. 查找能区分解释的资料。
5. 写出一条带失效条件的迁移规则。
6. 用一个不同任务尝试迁移：改变产品、人物、媒介或表达目标，但不要只替换同一位置上的物件；说明保留了什么、为什么仍然成立、什么需要重测。

# 目的

不是一次产出最完整的报告，而是把“我觉得好看”推进到“我知道哪些关系值得继续研究和使用”。
