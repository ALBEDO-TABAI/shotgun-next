# 步骤

1. 从一张作品中抽出三条关系。
2. 换掉所有具体物件，生成两个方案。
3. 检查：
   - 新方案只是换色换皮 → 抽出的可能还是表面；
   - 完全失去原关系 → 迁移时没有保住关键条件。

# 目的

不是证明原创，而是检验描述是否真正抓住可迁移的结构。
