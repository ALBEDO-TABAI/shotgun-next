# 案例性质

**虚构教学推演**。

# 叙事片段

两个人物一开始被门框分开，随后一人跨过门槛，但摄影机保持原位。

- 静帧描述只得到“室内、两人、门”。
- 动态关系描述记录：门框何时把人物分置两侧，跨越后是否仍有物件分隔，两人朝向是否改变。
- 由此才可提出“空间边界发生变化，但关系未必已经缓和”的解释。

# 非商业摄影系列

每张都把主体置于远处，并保留大量模糊前景。

- 不能只凭这些评价“主体不突出”。
- 更适当的分析：远距离与遮挡怎样持续规定观看位置，哪些照片打破这一模式，系列的观看顺序是否让这些差异成立。

# 要点

同一种观察程序可以服务不同目的，但不应把产品展示的“标签可读”标准带入所有作品。第二篇解决的是证据组织，不提前决定作品应该清楚、悦目或方便消费。
