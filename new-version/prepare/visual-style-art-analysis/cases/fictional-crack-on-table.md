# 案例性质

**虚构教学推演**：一张非商业静物照片，瓶状物体放在有裂缝的台面上，背景空旷，物体没有明显使用痕迹。有人提出：“裂缝象征环境崩坏，瓶子代表消费主义的冷漠。”——可以成为一种读法，但尚未具备区分证据。

# 四步

1. **固定观察**：裂缝在何处，是否与瓶子接触，是否延伸到画外，是否在系列中重复？瓶子与裂缝是否共享方向关系？没有原图或系列时仍是待观察问题。
2. **分开解释目标**：“这张画面可以怎样被理解”→比较读法与可见关系的相容程度；“作者为什么放这道裂缝”→需要制作、选材或作者陈述；“能否借用到护肤品广告”→转换为新任务（是否造成不希望的产品联想、是否影响主体识别）。
3. **列出区分性候选**：构图中的方向线；完好产品与破损环境的对照；特定社会或个人主题；场地与材料条件、后续未被赋予主题。可以共存。
4. **写受限制的结论**：

> 裂缝与物体完好外观之间形成可供解释的差异。现有材料不足以确定它是否承担某一特定社会寓意，也不足以确认是主动制作还是现成表面。若要作为创作参考，可先研究“稳定物体与受损支撑的关系”，而不复制尚未核实的作者动机。

这段结论没有放弃理解，而是把理解推进到证据允许的位置。
