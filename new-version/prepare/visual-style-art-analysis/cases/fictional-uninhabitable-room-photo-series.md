# 案例性质

**虚构教学推演**。

# 第六篇：构思

- 不一定需要把概念解释清楚，也不必让主体像商品一样迅速可辨。
- 关系句：观看者始终站在门外，能够看到光但看不到完整空间；每张允许不同阻隔，但保持无法进入的观看位置。
- 测试问题：阻隔是否具有差异而非机械重复？未知空间是否足以维持张力？是否无意中只剩形式套路？

# 第七篇：评价

- 摄影师只拍门外局部，保留反射和遮挡，不完整交代房间用途。用销售展示的“信息越清楚越好”评价，会把主要设定当成缺陷。
- 更适合的问题：遮挡是否持续参与观看？每张是否只是重复同一效果？可见线索是否支持进入与阻隔之间的关系？不同观看者的解释是否仍与画面有关？
- 但含混是目标不等于自动完成：若每张阻隔没有变化，仍可判断“这一系列的观看发展不足”，并用具体图像排序与差异作论据。艺术性不等于免于证据。

# 第八篇：迁移

放大的物件构成阻隔，而非保护主体的庭院。相同的尺度操作产生了不同观看关系，需要新解释、新构图和新评价标准；不能把护肤案例的清爽、轻盈自动复制成预期效果。
