# 案例性质

**虚构教学推演**。

# 从关系出发拆解

- **空间**：产品与叶片之间是否可穿行、哪些间隙能让镜头看见标签；
- **道具**：叶片是否需要真实转动；
- **材料**：边缘厚度和透光外观；
- **制作**：哪些构件实体完成、哪些作为后续效果候选；
- **现场**：产品是否需要可重复定位。

# 条件改变工作量

- 只拍静态海报 → 可减少运动要求；
- 镜头从叶片背后绕到正面 → 必须检查背面和支撑；
- 需要水滴与产品接触 → 增加状态和复拍问题。

“同一场景”并不拥有一个固定工作量。

# 两个案例共同说明

美术工作不是显眼程度的同义词：家庭房间主要依赖关系和生活证据；产品庭院主要依赖尺度、材料和实现路径。两者都需要设计判断，不能用同一套“道具数量＋制作复杂度”粗糙相加。
