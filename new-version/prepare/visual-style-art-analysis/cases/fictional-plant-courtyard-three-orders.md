# 案例性质

**虚构教学推演**：为护肤品广告构思设定，没有真实提案、画面或测试结果。

# 初稿的问题

绿色叶子、玻璃器皿、金属台座、水珠和几何背景全部加入——叶子负责自然、玻璃负责科技、金属负责高级、水珠负责清爽，只是**四张符号标签贴在同一画面里**，元素还没有分工。

# 三个方案（相似物件，不同主导秩序）

1. **由实验秩序组织植物**：明确间距与分区，叶片像样本一样独立展示，产品位于联系点；借“分类、对照、可辨”的关系，而不是靠放一只烧杯宣布科学性。风险：植物失去生命感？产品被误读为医疗器材？
2. **由植物空间容纳精确操作**：叶片构成可进入的围合空间，产品沿清楚路径出现；环境不规则，产品与少数关键构件边界精确——精确物件成为自然空间中的局部例外。
3. **让冲突成为内容**：植物不断突破整齐边界，产品既参与秩序又被包围；可能不适合销售主图，却可能适合讨论自然与控制关系的非商业短片——评价要问冲突是否在时间和画面关系中成立，而非“是否足够干净”。

# 可交接的关系句

> 在当前广告方案中，由稀疏、分区明确的空间组织负责可辨性；植物提供不规则轮廓和局部生长方向，但不改变主要间距；产品必须与背景保持可检查的轮廓差异。玻璃只在有必要表现透射关系时使用，不因“科技感”默认加入。

换一种叶片或减少一个台座时，仍能判断是否破坏主导规则。
