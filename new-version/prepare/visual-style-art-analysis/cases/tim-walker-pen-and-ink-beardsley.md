# 案例性质

**有来源的创作陈述案例**：Getty《Tim Walker: Wonderful Things》展览页 *Pen and Ink* 一节。

# 资料说了什么

Tim Walker 谈到把 Beardsley 的笔触转译为三维空间，并使用悬挂的线与珠子形成类似在空中画线的关系。

# 启发

不是先选一个风格标签再配道具，而是抓住一种**具体形式问题**——平面标记怎样变成可拍摄空间。本包把这一类问题当成概念来源之一，不要求所有项目都这样创作。对应 [变换操作库](/frameworks/transformation-operations-library.md) 中的“维度转换”与 [四种混合情况](/frameworks/four-hybrid-situations.md) 中的“跨媒介转译”。
