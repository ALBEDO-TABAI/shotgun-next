# 案例性质

**虚构教学推演**：假设一张护肤品牌广告，已知需求“植物、清爽、轻盈”；画面有产品、放大叶片、悬浮水珠和细颗粒纹理，没有制作资料。

# 合格的初步描述（要点）

- 这是以护肤产品为主题的品牌广告（情境＋题材）；
- 采用低密度的主体组织（形式）；
- 通过放大叶片和悬浮水珠改变日常尺度与重力关系（再现／修辞）；物体外观仍追求细腻、可辨的材质表现（外观）；
- 可描述为“具有非现实空间关系的简约产品影像”；
- “植物、清爽、轻盈”目前是**已知需求**，哪些体验实际成立需分别分析；
- 画面颗粒只能支持外观描述，不能证明使用胶片；现有信息不足以确认具体历史风格来源。

# 排除的四类错误

把需求当效果；把外观当技术；把非现实关系当历史归属；把题材当风格。
