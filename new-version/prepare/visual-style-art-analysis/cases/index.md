# 案例 · Case Studies

有来源的制作／创作陈述案例（《芭比》《小斧子》Tim Walker、Oppenheim《Object》）与明确标注的虚构教学推演。


# 一 风格概念辨析与分面分析

* [Meret Oppenheim《Object》（1936）：毛茸茸的杯子不只是一个风格标签](oppenheim-object-fur-teacup.md) - 有馆藏记录支持的案例：用分面与范围得出不同性质的结论；可迁移的是“改变器物—材料—使用关系”的机制，而不是完整的艺术史身份。
* [虚构案例：“植物、清爽、轻盈”护肤广告的合格初步描述](fictional-skincare-ad-plant-fresh-light.md) - 虚构教学推演：不强行命名，排除把需求当效果、外观当技术、非现实关系当历史归属、题材当风格四类错误。

# 二 视觉观察与形式证据

* [虚构案例：把一张假想护肤海报从形容词变成证据（四层）](fictional-skincare-poster-four-layers.md) - 虚构教学推演：低质量初稿 → 可检查描述 → 关系假设 → 待检验的观看解释 → 最小补证问题；故意不写“水滴正在悬浮”。
* [虚构案例：门框分隔的叙事片段与远景模糊前景的摄影系列](fictional-doorframe-film-and-distant-photo-series.md) - 同一观察程序用于叙事片与非商业摄影：记录门框何时分隔与跨越后的朝向；远距离与遮挡如何规定观看位置，而不是评价“主体不突出”。

# 三 混合风格与融合规则

* [《芭比》：世界规则不等于“粉色加复古”](barbie-toy-world-rule.md) - 依据两份主创访谈：玩具研究、缩小比例、绘景与假透视、二维与实体组合、绘制泳池覆透明树脂；分析性概括为“可被真人进入的玩具世界”。
* [虚构案例：植物庭院与实验秩序怎样共处（三方案）](fictional-plant-courtyard-three-orders.md) - 虚构教学推演：“植物来源、精确感、轻盈”初稿只是四张符号标签；三方案——实验秩序组织植物、植物空间容纳精确操作、让冲突成为内容，并写成可交接关系句。

# 四 美术工作与设计决策

* [虚构案例 A：家庭短片中的旧房间（看不见的设计）](fictional-family-room-short.md) - 虚构教学推演：成年子女回到长期无人居住的旧房间；从行动、生活证据、观看三方面拆出选择，交付空间与行动草图、物件拥有关系等，而不是怀旧情绪板。
* [虚构案例 B：护肤品微型庭院的美术工作拆解（显眼的装置）](fictional-skincare-micro-courtyard-production.md) - 虚构教学推演：“产品位于放大叶片形成的庭院中，水光逐步显露包装”；工作量由可见范围、使用关系、变化要求和完成条件决定，而非场景本身。
* [《小斧子》（Small Axe）：看似自然的场景由研究与跨部门选择形成](small-axe-research-and-collaboration.md) - 依据 BAFTA 2021 主创座谈文字记录：照片、档案、记忆与具体生活经验，美术与服装持续协调；不据此声称观看者反应或每个物件来历已核实。
* [《芭比》：颜色跨部门测试与二维／实体实现路径](barbie-color-and-2d-physical-paths.md) - 依据两份主创访谈：颜色决策涉及与摄影、服装的测试协调；二维与实体手段共同参与环境呈现（绘制泳池覆透明树脂）；手段不推广为行业必须做法。

# 五 创作出发点与解释边界

* [Tim Walker《Illuminations》：一束红光为什么不能被解释成通用色彩象征](tim-walker-illuminations-red-light.md) - 依据 Getty 展览页收录的创作陈述：透明色彩与彩色玻璃经验、被照亮的红色与母亲制作灯罩的童年记忆；资料让解释更具体而不是更宏大。
* [虚构案例：台面上的一道裂缝可以意味着什么？](fictional-crack-on-table.md) - 虚构教学推演：面对“裂缝象征环境崩坏、瓶子代表消费主义冷漠”，按固定观察→分开解释目标→列区分性候选→写受限制结论四步推进到证据允许的位置。

# 六 从抽象需求到场景方案

* [Tim Walker《Pen and Ink》：把 Beardsley 的笔触转译为可拍摄的三维空间](tim-walker-pen-and-ink-beardsley.md) - 依据 Getty 展览页收录的创作陈述：用悬挂的线与珠子形成类似在空中画线的关系；启发是抓住“平面标记怎样变成可拍摄空间”这一具体形式问题。
* [虚构案例：一条假想的三十秒护肤品品牌片（微型庭院）](fictional-30s-skincare-brand-film.md) - 虚构教学推演：视觉命题、核心不变量、空间道具分工、三段时间方案、优先原型、允许变化与例外、测试后的两种回路。
* [虚构案例：“可以看见却无法进入的房间”艺术摄影系列](fictional-uninhabitable-room-photo-series.md) - 虚构教学推演（六、七、八篇共用）：关系句构思、测试问题随任务改变；含混不能直接扣分，但也不自动完成；尺度操作迁移后产生阻隔而非庭院。

# 七 作品评价与反馈验证

* [虚构案例：两版护肤产品画面怎样比较（销售图 vs 品牌图）](fictional-skincare-ab-two-versions.md) - 虚构教学推演：方案A中央轮廓连续、方案B叶片交叠局部遮挡；不立即给总冠军，按任务分配下一步检查，写两个不同测试问题，结果只影响对应决策。

# 八 分析沉淀与知识复用

* [虚构案例：从植物庭院决策卡到新任务的迁移链](fictional-plant-courtyard-transfer-chain.md) - 虚构教学推演：一张护肤概念图 → 决策卡（关键选择、依据、作用假设、替代解释、制作未知、迁移规则、失效条件）→ 迁移到时尚编辑摄影 → 再迁移到非商业空间作品 → 回写知识。
