# 案例性质

**虚构方案与测试计划**，不是实际作品分析，也没有实施受众实验。同一款蓝绿色护肤产品，需要一张销售展示图和一张品牌形象图，共享“植物庭院”概念。

- 方案A：产品接近中央，叶片退到两侧，背景平缓，瓶身轮廓连续。
- 方案B：放大叶片与产品交叠，局部水光穿过前景，比例关系更不稳定，瓶身右侧部分被遮挡。

# 1. 不立即给出总冠军

| 问题 | 对A的分析方向 | 对B的分析方向 | 尚需什么证据 |
|---|---|---|---|
| 产品识别 | 主体关系更直接，值得检查目标尺寸表现 | 局部遮挡可能影响识别 | 实际输出与任务检查 |
| 概念体验 | 环境易成陪衬，庭院尺度感可能较弱 | 交叠与尺度变化使环境参与更强 | 图像细读与观看反馈 |
| 信息容纳 | 可能有更稳定的文字位置 | 文字可能与环境争夺位置 | 实际文字长度及版式测试 |
| 品牌区分 | 清楚不等于具有品牌特征 | 陌生不等于能认出品牌 | 已知品牌要求与归属测试 |
| 跨版式适配 | 中央关系可能较易保留，仍需检查 | 裁切可能改变遮挡与尺度关系 | 横竖版独立输出 |

# 2. 范围明确的下一步

A 进入销售图的识别检查，B 进入品牌图的空间表达检查——这是当前两个任务下的工作安排，不是证明A只适合销售、B只适合艺术。若必须共用主视觉，保留B的尺度设定、调整局部遮挡，作为**新候选C**评审，不假装同时保留所有优点而没有代价。

# 3. 两个测试问题

- 销售图：“在计划使用的展示条件下，包装特征和必要信息能否被识别？”
- 品牌图：“观看者把放大的植物理解成环境、成分装饰，还是其他关系？他们记住的是哪部分？”——允许开放答案，不把“没说出设计文案里的庭院”直接判成失败。

# 4. 结果如何改变方案

销售图产品清楚但品牌信息弱 → 另查品牌区分，不无目的放大产品；品牌图尺度被理解却误导产品信息 → 修正信息，不一定删除幻想空间。每项结果只影响它对应的决策。
