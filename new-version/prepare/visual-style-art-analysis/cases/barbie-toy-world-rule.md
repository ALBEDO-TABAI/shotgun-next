# 案例性质

**有来源的过程案例**：依据两份主创访谈分析其公开说明的工作逻辑，**不声称完成全片逐帧分析**。

# 资料说了什么

- Sarah Greenwood（伦敦艺术大学访谈）谈到对玩具和玩耍方式的研究、缩小的空间比例、传统绘景与假透视等做法；重点不只是照搬玩具外观。
- Greenwood 与 Katie Spencer（The Credits 访谈）说明了二维与实体元素的组合，以及通过绘制并覆盖透明树脂形成泳池表面的做法。

# 分析性概括（本篇整合，不是逐字引用）

> 建筑、比例、表面和环境效果共同服从一个**可被真人进入的玩具世界**，而不是各自寻找漂亮参考后并排放置。

- 玩具提供现实约定和尺度问题；建筑参照提供空间语汇；绘景与实体决定制作和观看关系。不必属于同一历史风格，不换算为百分比。
- 反事实：只保留粉色、恢复普通住宅比例、增加日常材料和生活痕迹，这个世界是否仍以相同方式成立？若关键关系明显改变，说明颜色不是充分解释。——这是**思考工具**，不是已拍摄并测试的对照实验。

# 可迁移／不可直接迁移

- 可迁移：先确立一个世界约定，再让多个部门的选择响应它；二维、实体和尺度可以共同服务同一设定。
- 不可直接迁移：“所有项目都缩小同一比例”“粉色能保证玩具感”“实体一定优于数字”。
