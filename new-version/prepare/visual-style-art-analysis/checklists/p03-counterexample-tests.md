# 反例测试

| 测试 | 期望处理 |
|---|---|
| 输入“广告＋胶片＋浪漫＋对称” | 先分类，不宣布四种风格融合 |
| 整体没有单一主导中心 | 允许分析多中心与有组织的断裂 |
| 仅有一只历史样式的器皿 | 将历史判断限制在物件，不扩大为全图 |
| 两种来源颜色相同但尺度矛盾 | 识别“同色”没有解决全部关系 |
| 提供主创明确否认某致敬的记录 | 修正因果归属，可保留形式比较 |
| 把所有怪异设计称为超现实主义 | 区分非现实机制与历史关系 |
| 一种融合只有特写有效 | 写明适用镜头，不宣称系列通用 |
| 要求用百分比表示混合 | 无计量定义时改为作用范围与主导关系 |
