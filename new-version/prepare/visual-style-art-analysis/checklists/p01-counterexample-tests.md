# 反例测试

| 测试情形 | 应通过的判断 |
|---|---|
| 一个古典道具出现在现代广告里 | 不把道具归属扩大成整体风格 |
| 数字图像带明显颗粒 | 不声称使用胶片拍摄 |
| 明亮规整的恐怖场景 | 不用明暗直接否定其内容类型 |
| 超写实材质配合不可能事件 | 区分外观逼真与世界规则 |
| 同一作品不同段落差异显著 | 分析变化的作用，不机械判为不一致 |
| 没有合适的既有风格名 | 提供分面描述，不强行命名 |
| 需求写“高级清爽”，画面证据不足 | 不把要求当作实际结果 |
| 多位观看者的感受不同 | 保留观察条件与分歧，不制造唯一正确感受 |

这些测试是把理论变成可靠判断习惯的关键。
