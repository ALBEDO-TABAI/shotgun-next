# 反例测试

| 情形 | 应有处理 |
|---|---|
| 客户只说“高级一些” | 提取实际不满意之处和任务，不直接套石材金属 |
| 三个方案只是不同色调 | 说明它们是变体，继续寻找机制差异 |
| 参考图构图合适但题材不合适 | 记录局部借用，不整图复制 |
| 原型很好看但没回答问题 | 不作为该问题的通过证据 |
| 关键视觉好看但新增运动镜头 | 重新检查空间、背面和连续性 |
| 气氛通过，包装仍错误 | 分维度记录，不宣布整体通过 |
| 测试显示需求中的两个目标冲突 | 回到优先级或分段职责，而非让执行者强行兼顾 |
| 非商业作品需要保留含混 | 不以销售物料的清晰标准消除其表达 |
| AI 生成很多近似图 | 不把数量当成多路线探索的证明 |
