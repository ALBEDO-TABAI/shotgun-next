# 输入

实际作品、研究问题、可见观察、过程或背景资料。没有作品时可做方法教学；没有过程资料时不得声称还原真实创作链。

# 执行过程

澄清正在问形成原因、意图、形式功能还是效果（[四个问题](/frameworks/four-why-questions.md)）；整理证据身份；提出少量有区分价值的假设（[假设矩阵](/templates/hypothesis-matrix.md)）；检索能改变判断的资料；比较反例与替代解释；建立必要的时间与版本关系（[过程追踪](/methods/process-tracing.md)）；输出可支持、待确认和不能支持的结论。

# 输出

问题类型、证据表、候选解释、支持与反证、过程线索、结论范围和有价值的下一步。

# 完成条件

关键动机归因有来源，或明确维持假设身份；至少保留有意义的替代解释；主创自述与观看效果没有混淆；不把相似性当影响证据；读者能知道什么新材料会改变结论。

# 核心原则

解释可以超出表面，但不能越过自己的证据身份。真正有力量的解释不是最宏大的故事，而是能说明具体关系、经得起替代解释、知道如何被新证据修正的主张。
