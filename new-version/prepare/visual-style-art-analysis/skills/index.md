# Skill 接口 · Skill Interfaces

各篇可直接转写为 skill 的触发、输入、过程、输出、禁止越界与完成条件。


# 00 阅读导航与使用说明

* [Skill：视觉风格与美术分析全包模块路由（阅读路径 A–D）](skill-visual-analysis-module-routing.md) - 模块可组合而非八重审批：建立理解走 A；拆图拆片走 B（一→二→三/四/五→七→八）；新方案走 C（六为入口）；团队模板或 AI 知识走 D（先八）；交付是研究型知识文档，未部署任何插件。

# 一 风格概念辨析与分面分析

* [Skill：视觉风格概念辨析与分面描述](skill-style-concept-facet-description.md) - 把含混的风格问题转化为有范围、有证据、可继续分析的描述；暂不负责制作拆解、预算、心理判断、效果预测与评分。

# 二 视觉观察与形式证据

* [Skill：视觉观察与形式证据提取](skill-visual-observation-evidence.md) - 触发：描述画面、分析构图与美术特征、比较视觉形式或为后续分析建立证据；输出材料说明、关键观察、组织关系、时间变化、候选解释、缺口。

# 三 混合风格与融合规则

* [Skill：混合风格与融合规则分析](skill-hybrid-fusion-rules.md) - 输入作品或标记方案、分面判断、关键观察与参照资料；输出参照关系表、主导组织句、变换操作、保留与排除项、冲突作用、迁移条件与未知项。

# 四 美术工作与设计决策

* [Skill：美术决策与制作工作拆解](skill-art-decision-production-breakdown.md) - 确认是成片复盘还是新方案；提取世界、空间、陈设、道具、材料、制作、连续性决定；区分作用与真实来源；输出决策地图、实现候选、已核实工作、部门接口与未决问题。

# 五 创作出发点与解释边界

* [Skill：创作出发点与解释边界分析](skill-creative-origin-interpretation.md) - 澄清在问形成原因、意图、形式功能还是效果；整理证据身份；提出少量有区分价值的假设；输出可支持、待确认和不能支持的结论。

# 六 从抽象需求到场景方案

* [Skill：抽象需求到视觉场景方案](skill-abstract-brief-to-scene.md) - 区分任务、限制、目标、偏好和假设；提出不同机制的概念路线；写出关系命题；展开空间道具材料光时间；原型回答问题；输出下游能消费的方案与确认范围。

# 七 作品评价与反馈验证

* [Skill：作品评价与反馈验证](skill-evaluation-feedback-validation.md) - 触发：评价、比较、复盘、提修改意见或判断方案是否满足任务；只有风格识别任务时不默认扩展为质量排名；确认版本阶段→区分描述感受评价效果→按标准取证→最小必要修改→匹配复查。

# 八 分析沉淀与知识复用

* [Skill：分析沉淀与知识复用](skill-analysis-knowledge-reuse.md) - 触发：保存拆片成果、整理参考库、形成可迁移方法、建立团队分析模板或为 AI 准备可靠知识；输出按个人练习／团队复盘／长期 AI 资料库分级；不默认上传外部服务。
