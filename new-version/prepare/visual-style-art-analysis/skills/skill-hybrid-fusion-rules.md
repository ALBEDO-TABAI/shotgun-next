# 输入

实际作品或明确标记的设计方案；第一篇形成的分面判断；第二篇形成的关键观察；有则提供参照与过程资料。

# 核心过程

先消歧；列出异质来源或不同约定；核查来源关系；判断每一项作用范围；提取选择与变换；分析整体秩序和局部例外；提出替代解释；用删除、替换和跨场景测试检查规则。

# 输出

参照关系表、主导组织句、变换操作、保留与排除项、冲突作用、迁移条件和未知项（见 [最小规则卡](/templates/hybrid-visual-rule-card.md)）。

# 不输出

没有定义的风格比例；无证据的致敬关系；仅凭相似度确认作者；“融合越自然越好”的无条件判断。

# 完成条件

至少能说明一个“关系如何形成”的机制，而不只有来源名称；历史判断有适当证据身份；规则能帮助决定保留、替换或删除；局部与整体没有混淆；没有把形式相似自动改写成因果影响。

# 核心原则

混合风格不是给多个标签寻找一个好听的总名，而是解释不同来源怎样被选择、变换和组织。允许统一，也允许有意义的冲突。能指出保留什么、改变什么、为何仍然成立，才真正理解了融合。
