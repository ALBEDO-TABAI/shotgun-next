# 边界

- **负责**：把含混的风格问题，转化为有范围、有证据、可继续分析的描述。
- **暂不负责**：完整的美术制作拆解、预算估算、创作者心理判断、受众效果预测或最终审美评分——属于后续模块。这不是减少深度，而是避免第一步就把所有任务混在一起。

# 核心原则（可直接写进 skill）

不要把视觉风格识别理解为给作品分配一个唯一标签。首先限定分析对象与证据范围，再区分实践情境、类型、题材、历史谱系、再现方式、形式组织、修辞关系、媒介与外观、观看条件及体验判断。风格概括应建立在特征之间的组织关系上；历史归属、制作事实、创作意图和观看效果需要各自适当的证据。混合表达应说明各参照作用于何处、如何连接或冲突，而不是列出标签比例。**缺少可靠名称时，保留准确的描述；缺少可靠证据时，保留明确的未知。**
