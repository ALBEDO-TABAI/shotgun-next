# 触发条件

用户要求描述画面、分析构图与美术特征、比较视觉形式，或为后续风格和创作分析建立证据。

# 输入

可访问图像或视频、版本与范围信息、具体研究问题。没有真实材料时，只能提供方法或明确标为假设的演示。

# 核心动作

确认材料范围；保留初始体验；分离对象、属性、关系与变化；定位关键证据；比较局部与整体；提出受限制的组织规则；记录替代解释和未检查部分（流程见 [四次观看](/methods/four-pass-viewing.md)）。

# 输出

材料说明、关键观察、组织关系、时间变化、候选解释、缺口与下一步。优先保留决定作品的几项关系，不生成没有用途的百科式清单。记录格式见 [单条观察记录](/templates/visual-observation-record.md)。

# 禁止越界

不得仅凭外观确认工艺、材质、作者意图或所有观众反应；不得把没有获得的材料记为不存在；不得把局部样本扩大成全片或整个作者的风格。

# 完成条件

另一位读者能找到主要证据，知道哪些是可见描述、哪些是解释；重要关系有范围限定；静态和动态没有混淆；至少检查过一个有意义的替代解释；未知项没有被漂亮文字填满。

# 核心原则

先把看见的东西说成可检查的关系，再讨论它可能意味着什么。能定位的描述优于漂亮的形容词；有边界的解释优于看似完整的猜测。
