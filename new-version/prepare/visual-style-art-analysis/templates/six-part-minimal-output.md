# 六部分

1. **分析范围**：当前结论覆盖哪张图、哪些镜头或哪组作品。
2. **分面描述**：只列与当前问题相关的分面，缺失内容明确标注。
3. **主导组织规则**：用关系句说明哪些选择共同构成了当前呈现。
4. **风格与参照判断**：区分确定归属、明确引用、形式相似和待确认来源。
5. **证据与替代解释**：关键判断如何成立，哪些其他解释尚未排除。
6. **一句话综合描述**：保留用途、形式、再现方式与必要限定，不堆砌标签。

# 一句话综合句式

> 该作品在\_\_\_\_情境中，以\_\_\_\_为主要题材／对象，采用\_\_\_\_的形式组织，并通过\_\_\_\_的再现或修辞关系形成\_\_\_\_的观看方向。其与\_\_\_\_的关系目前属于\_\_\_\_；有关\_\_\_\_的制作、意图或体验结论，尚需\_\_\_\_证据。

不必让用户每次面对十张表。
