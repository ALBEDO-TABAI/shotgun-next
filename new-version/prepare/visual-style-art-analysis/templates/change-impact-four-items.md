# 原则

- 不能只在美术图上改尺寸，假设所有下游都会自动理解。
- 没有影响的部门不必被拖进来；确实受到影响的消费者不能只收到一句“已更新”。
- 反例测试：图纸已更新，下游仍使用旧版 → 把交接消费作为问题，而不只检查文件是否存在。
