# 原则

- 把“共同出现什么”与“由谁组织整体”分开。
- 相同的叶片、玻璃和水，可以形成稀疏陈列，也可以形成几乎没有空隙的密集包围；同色并不保证同一种风格关系。
- 形式分析负责描述结构，不负责证明历史来源：两件作品的相似组织可能来自不同传统、相似问题或独立选择。
