# 原则

- 让同一个模型把结论再解释一次，可以用于发现内部矛盾，但不能证明图像中确实存在所说对象。
- 应把关键判断**重新绑定到实际材料**，由人工或独立的证据检查过程核对。
- 反例测试：模型解释流畅且重复一致 → 回到实际证据逐项核对，不当作已独立验证。
