# 依据

Bordwell 对风格史方法的说明，将变化与创作者面对的问题、方案和惯例联系起来，而不只归因于笼统的时代精神。

# 原则

一件作品中的混合也可能由实际问题推动：

- 实景空间无法容纳想要的透视 → 引入绘景；
- 演员需要接触物体 → 保留实体；
- 景深要求 → 改变材料表面。

分析不能把所有技术妥协都贬为缺陷，也不能把所有结果都美化成预先规划的观念，它们可能在制作中共同形成最终规则。
