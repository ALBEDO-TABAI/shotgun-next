# 原则

- 双钻框架把更广泛地探索与更聚焦地行动交替组织。让“还有哪些本质不同的方案”与“哪一个值得继续”分开进行。
- **发散时**先比较组织机制，不急着打磨细节；**聚焦时**明确任务、证据和代价。
- 混在一起的两种失败：每想到一个新点子就推翻全部方案；或第一张漂亮图出现后便停止探索。
