# 原则

《芭比》的主创访谈记录了二维与实体手段共同参与环境呈现的案例，说明可以**围绕所需画面选择制作路径**，而不是先把技术排成高低等级。

在具体项目里，实景、布景、绘景、微缩、数字环境和合成都应接受同样的问题：

- 需要什么互动？
- 哪些机位？
- 如何修改？
- 哪里必须重复？
- 最终呈现是否成立？

技术名称本身不能替代这些判断。反例测试：数字生成的场景 → 同样检查世界、空间、道具和连续性，不因无实物而取消美术任务。
