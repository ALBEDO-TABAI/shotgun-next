# 原则

- 叙事片：区分故事时间中的合理变化与拍摄顺序中的意外变化。
- 产品片：区分创意变形与包装身份改变。
- 数字制作：区分允许变化的局部细节与必须保持的尺度和位置关系。
- 连续性记录可以包括物体状态、数量、朝向、液体量、损耗和画面位置，但**只应记录真正影响下一镜头或复拍的内容**。记录过多且无人使用，同样增加混乱。
