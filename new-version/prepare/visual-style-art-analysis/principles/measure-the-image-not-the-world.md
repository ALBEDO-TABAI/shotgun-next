# 原则

- 跨图比较时，可记录主体高度占画面高度的比例或对象包围区域的相对位置；**比例的分母、裁切版本和对象边界要一致**。
- 产品高度占画面高度的三分之一是一个图像比例，不能告诉你产品在现场有多高。
- 两个版本裁切不同，不能直接比较比例后断言置景尺度发生变化。
- 不必要的测量会制造**假精确**：判断明显的遮挡关系，不需要先算到小数点后两位。只有数值能帮助区分方案或发现变化时才值得记录。
