# 原则

- 一张图片适合用于理解关系，不意味着它就是可以直接进入成片的资产。研究、设计和使用核查是不同工作；本包不提供具体授权结论，应在项目中另行确认。
- 同样适用于生成图片：它可以是构思材料，但不能因为已经生成就自动成为正确、可执行、可以发布的成品。
- 00 导航：外部链接不代表相关图片、字体、影片或其他资产已获得项目使用许可。
