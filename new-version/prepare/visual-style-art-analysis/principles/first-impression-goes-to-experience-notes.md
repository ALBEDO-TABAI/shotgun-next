# 原则

第一印象值得保留，但建议先放进**体验笔记**，不要让它悄悄变成观察表的结论。

# Examples

同时记录：

- 体验：“我第一眼觉得沉重”；
- 观察：“主体轮廓宽厚、支撑面较大、向上运动很少”。

而不是把前一句伪装成后一句的客观同义词。

# 边界

第一遍自然观看的输出叫“观看记录”，不叫“受众研究”：分析者此时就是一个具体观看者，不代表总体人群。
