# 原则

**风格的稳定，不等于所有部分都长得一样。** 分析规范应允许“整体以某种方式为主，局部通过相反处理形成对照”。

# 为什么

否则系统会把作品中最有意义的变化错误识别为“不一致”。反例测试“同一作品不同段落差异显著”的合格处理是：分析变化的作用，不机械判为不一致。

# 延伸

- 第二篇：一个镜头中的斜向构图可能是在打破前面建立的秩序，不应立即删除为噪声。
- 第三篇：规则卡中保留“有条件的例外”。
