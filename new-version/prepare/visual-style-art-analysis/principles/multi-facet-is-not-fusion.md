# 原则

“商业＋极简＋梦幻＋三维”未必是四种风格的混合；它们可能分别表示：

> 使用性质＋形式组织＋预期体验＋制作方式。

这首先是一个**多分面描述**。只有澄清词义以后，才有必要讨论“融合”。

# 第三篇的延伸

“商业极简、东方梦幻、胶片三维”：商业是传播情境，极简可能只是元素控制，东方需要具体地域时期，梦幻可能是需求方感受词，胶片可能指外观或介质，三维可能是制作方式——它们同时存在不必然构成六种风格融合。

反例测试：输入“广告＋胶片＋浪漫＋对称”→先分类，不宣布四种风格融合。
