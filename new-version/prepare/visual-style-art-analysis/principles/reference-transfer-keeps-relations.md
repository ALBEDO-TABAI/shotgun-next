# 原则

Gentner 的结构映射理论为区分表面属性与关系对应提供方法参照。

- 一张参考图可以只借**主体与边界的距离**；
- 另一张借**材料透光的方式**；
- 第三张借**空间被逐步揭示的顺序**。

把三张图的全部外观一起复制，不等于三种方法得到有效整合。
