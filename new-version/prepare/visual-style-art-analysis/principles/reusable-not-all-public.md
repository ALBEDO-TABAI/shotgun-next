# 依据

FAIR 原则讨论可发现、可访问、互操作和可复用，并允许必要的认证与授权访问。

# 原则

- 对项目资料，同时记录**来源、访问条件和用途限制**。
- 能在某处看见一张图片，不代表项目已经获得所有使用方式的许可；保存分析记录，也不必把客户内部原始资产公开。
- 资料无法公开时，仍可在授权范围内维护元数据和内部证据关系。
- 来源失效不一定立刻否定已核对的笔记，但会降低再次验证的便利；应记录状态。公开可访问的研究链接与可直接商用的图片资产不是同一类东西。

# 边界

资料管理建议，不替代具体权限确认或法律判断。反例测试：某案例权限不明确 → 区分知识参考与具体资产使用。
