# 原则

- “道具很多”是数量或密度描述；“道具太多”已隐含一条标准：这些物件妨碍了什么，超过了什么需要？
- 目标是让观众快速认出产品 → 密集物件可能需要检查；作品表现物品积累与记忆 → 删空场景可能反而破坏表达。
- 不能省略中间的条件，只把“少”默认等同于“好”。

# 句式

> 关于**某个对象**，在**某种条件和标准**下，由**哪些证据**支持**什么判断**。
