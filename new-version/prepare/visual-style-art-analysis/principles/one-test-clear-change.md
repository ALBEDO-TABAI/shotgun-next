# 原则

- 若同时换了背景、材料、机位和产品大小，虽然可能找到更喜欢的版本，却很难知道哪项改变起作用。
- **探索阶段**允许整体替换；**诊断阶段**应尽量收窄变化。
- 不强迫艺术创作永远只改一个变量，而是区分“寻找更好方案”和“判断某因素作用”的不同目的。
