# 原则

- 门口有人朝外看，可以说明作品设置了朝向画外的关系，**不能凭空描述门外的完整房间**。
- 不要把“未出现生活杂物”直接解释成“人物没有生活”：可能是裁切、场景用途、拍摄时点或设计删减，具体原因留给其他证据。

# 延伸

第四篇区分“结果中缺少”（画面可支持）与“主创主动排除”（需要过程证据）。
