# 依据

Datasheets for Datasets 提出记录数据集动机、组成、收集过程和推荐用途的思路（本包仅借用资料说明思想）。

# 资料集说明可包含

收录目的、媒介与年代范围、选择方式、排除规则、公开程度、已知空缺、维护者和更新日期。

# 原则

- 说明这些案例为什么被选择，偏向哪些媒介与预算，是否只包含获奖作品，有没有失败或反例，哪些范围尚未覆盖。
- 若主要来自品牌官网、获奖广告和大型电影，内容可能偏向有公开材料的制作；不要把缺少资料的小型项目误认为缺少设计工作。
- 精心策划的案例库不等于具有统计代表性的样本：没有系统取样，不应声称它代表“当代广告的普遍风格”。
