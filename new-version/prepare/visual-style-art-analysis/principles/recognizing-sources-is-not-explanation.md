# 原则

假设一张广告把复杂装饰的器皿放在空旷几何空间里。识别器皿和空间各自让人联想到什么，**仅完成了参照定位**。

# 下一步必须说明

- 器皿是唯一的视觉密集区吗？
- 它的轮廓与空间有没有呼应？
- 空间是否因为器皿而改变尺度？
- 两者通过颜色被连接，还是通过反差被强调？
- 去掉器皿后，作品的主题或观看方式会发生什么变化？

只有进入这些关系，才从“识别出处”转向“理解组织”。
