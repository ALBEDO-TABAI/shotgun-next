# 原则

- 失败不是浪费，只要它明确减少了哪一种不确定性：“叶片在小尺寸中显得厚重”可以改变材料、比例或观看角度；“包装被水光遮住”可以改变呈现时点。
- 若测试记录只保留成功图，后续团队可能重新走过已经失败的路径，却不知道当时为什么放弃。
- 第八篇：迁移失败时记录失败发生在哪个环节（尺度不成立、材料阻碍动作、规则根本不适合任务）；不必删除原卡，而是收窄适用范围或拆分机制。
