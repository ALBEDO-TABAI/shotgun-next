# 原则

- 不能为了让报告完整，编造“八成用户觉得更清爽”“大多数人偏好A”。
- 内部几位同事的意见，不能悄悄扩大成目标人群调查。
- 测试前写预期，测试后写观察。结果不符合预期时应修改解释，不能只保留支持方案的回答。
- 尚未测量的内容可以继续作为有价值的创作假设存在，但必须保留身份。
- 反例测试：没有记忆研究 → 写成机制假设或待测项，不填“记忆点强”作为事实；小范围内部讨论 → 如实记录样本与使用边界，不宣称市场验证通过。
