# 原则

- 实际输入是原图、低分辨率缩略图、关键帧、完整视频，还是别人写的描述？**模型输出的覆盖范围不应超过输入。**
- 没有图像时，可以帮助制定观察问题或分析文字材料，但不能声称看到了道具纹理。
- 没有完整片段时，不能把抽样帧拼成确定的动作过程。
- 反例测试：没有实际图片，只提供风格描述 → 只分析文字，列待观察问题；只有一张关键帧 → 限定单帧或已有片段范围。
