# 用途

“拿掉这片空场会怎样？”“换成透明材料，物体还会被理解为沉重吗？”——删除后解释完全不受影响，原解释可能太宽；只改一个关系就改变整体读法，这条关系值得进一步检验。

# 三个限制

1. **想象版本不等于实际版本**：文字里换材料，可能忽略光影和尺度的连锁变化。
2. **局部变化不一定只改变一个因素**：删除道具可能同时改变密度、色彩和叙事信息。
3. **今天能够这样重做，不证明当时就是这样思考**：反事实更适合检验分析和生成方案，历史归因仍需过程证据。

# 标注

报告应标注“**分析性反事实**”“**原型测试**”或“**已发生的版本比较**”，三者证据强度不能混为一谈。反例测试：将反事实重做结果当成原作动机 → 区分新实验与历史过程。
