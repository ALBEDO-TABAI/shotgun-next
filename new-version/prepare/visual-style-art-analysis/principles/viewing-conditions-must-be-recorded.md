# 原则

观看指令可以改变扫描方式；颜色—情绪关联既有共享模式也有语言地理差异。因此应用时要保存观看条件：

- 看了什么版本？
- 有没有声音？
- 尺寸多大？
- 任务如何提问？
- 观看前是否已经了解产品或创作解释？

没有这些条件，比较两次反馈很容易比较的不是同一件事。反例测试：意见来自不同尺寸版本 → 先统一证据条件，不当成无法调和的审美冲突。
