# 原则

每份资料都附上：**解决的问题、已核对范围、可转化规则、适用限制。**

# 第一篇核心来源的收录示例

| 来源 | 收进知识包的主要内容 | 本次使用范围 |
|---|---|---|
| Getty AAT：About the AAT | 分面、概念与词形、层级和关联关系 | 官方结构说明 |
| Wölfflin《Principles of Art History》 | 比较形式；五组观察轴 | 英文文本导论及相关段落 |
| Bordwell《Poetics of Cinema》 | 形式、历史条件、观看效果的中层分析 | 公开导论与作者说明 |
| Bordwell《On the History of Film Style》 | 风格史部分由问题与解决方案组成 | 作者对方法与内容的说明 |
| Sartini 等：ICON，2023 | 解释层次、解释者、来源与多重解释 | 论文理论部分；非逐页核对 Panofsky 原著 |
| Andersson：Sensory Qualities as Signs? | 物象与造型意义区分及理论分歧 | 公开论文相关论述 |
| Rose《Visual Methodologies》 | 构图研究放回语境、方法与受众研究 | 作者说明、目录与配套资源 |
| Leder 等 2004 | 区分认知加工、情绪体验与评价 | 原始论文摘要及书目信息 |
