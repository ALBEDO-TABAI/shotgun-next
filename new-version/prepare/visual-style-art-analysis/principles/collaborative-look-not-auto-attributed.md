# 原则

- 颜色可能涉及美术表面、服装、照明、曝光和后期；体积可能涉及空间、镜头位置和渲染；一个道具的叙事作用还可能受到表演和剪辑改变。
- 成片中“某处很好”不能直接归因给单个岗位。
- 专业分析可以准确讨论**形式贡献**，同时**暂缓个人署名判断**。这不是回避作者性，而是把归因建立在适当证据上。
- 反例测试：影片画面非常统一 → 不把所有视觉贡献归给单一岗位。
