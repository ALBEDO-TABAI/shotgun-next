# 原则

> 创作者自述可以证明“他这样解释自己的意图”，但不能单独证明作品已经产生了预期效果。

# 展开（第五篇）

- 陈述首先证明：某人在某个时间、场合公开这样说明。它可能涉及最初想法，也可能涉及后来对结果的理解。
- 这不是预先不相信创作者，而是让来源承担它能承担的任务：关于材料使用，陈述可与幕后照片或制作记录互相印证；关于观众是否受到感动，创作者的希望不能代替受众材料。
- 主创说“我希望轻盈”，不能证明观众已这样感受；观众喜欢成片，也不能证明使用了真实叶片。

# 案例

Tim Walker 的红光陈述只支持“他公开把私人记忆作为该拍摄的一个创作关联”，不支持“所有红光都象征母亲”。
