# 依据

BFDG 资源说明提到团队规模影响部门构成，英美制作中道具与陈设的职责边界也可能不同。

# 原则

- 角色图应是**当前项目的工作地图**，不是永久有效的行业真理。
- 小型静物拍摄中，一个人可能同时设计、采购和摆放；大型制作中，同一件物体可能经过研究、绘图、制作、使用和连续性管理等多人交接。
- “一个人兼多岗”不意味着可以跳过这些功能；“很多岗位”也不意味着必须增加更多审批层级。保留真正需要完成的决策和核验，不按人数衡量专业程度。
