# 原则

- “包装必须正确”可能是**硬限制**，通常需要明确满足与否；
- “保持轻盈”可能是**软目标**，常需比较、解释和观看反馈，但并不因此不重要。
- 反过来，不能把某个习惯性偏好未经讨论就变成硬限制。例如“所有画面必须有产品”可能影响叙事空间，应确认它是否真的来自任务，而不是某阶段的临时想法。
- 第七篇：不要把个人偏好伪装成硬要求，也不要把确实不可忽视的交付问题稀释成审美意见。
