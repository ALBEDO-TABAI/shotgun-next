# 原则

- 转成灰度可以帮助检查部分明暗关系，但会删除色相和饱和度信息；缩略图可以模拟部分小尺寸观看，却会损失细节。它们不能成为唯一审美裁判。
- 遮住某个道具再看画面是一种诊断练习：若画面变得更清楚，获得的是“该道具可能参与当前竞争关系”的线索，**不是严格证明移除它会提高广告效果**。
- 所有经过处理的辅助图都应与原图分开标注；不要让分析版本倒过来成为“原作具有这些特征”的证据。
