# 原则

- “请再找一些支持疏离的资料”，容易让研究只朝一个方向发展。
- 更有价值的问题：“有没有不同场地仍使用这一布局的段落？”“有没有早期方案显示空白原来承担动作？”
- 一个补证动作应对应**具体的不确定性**。若无论找到什么都不会改变结论，说明假设可能被写成了无法反驳的故事。
