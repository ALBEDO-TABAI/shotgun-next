# 原则

- 平均颜色相同的两张图，颜色可以分布在完全不同的位置；颜色面积相近，也不代表产生同样体验。
- 工具输出应回答窄问题，例如“两个候选版本中，标签附近的局部明暗差异是否改变”。
- 它不应直接输出“高级感得分”。在没有明确操作定义时，复杂图表只会把模糊判断包装得更像测量。
