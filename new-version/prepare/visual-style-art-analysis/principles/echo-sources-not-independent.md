# 原则

- 同一采访被三个网站转载，关于那次陈述仍然主要是**一条来源链**。资料数量增加，不等于独立证据增加。
- 保留最接近原始陈述的记录，再把转载作为查找或版本线索。
- 真正有帮助的相互印证，是不同材料从不同角度限制解释，而不是同一句话重复出现很多次。
- 第八篇：五篇文章都转述同一位主创的采访，应知道它们共享来源；资料链断裂时保留“转引未核对原文”，不要把引号和作者姓名复制得越多就越确信。

反例测试：找到三篇同源转载 → 不当作三条独立过程证据。
