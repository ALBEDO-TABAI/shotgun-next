# 原则

- 模型提出的场景、材料和动作还需要经过第六篇的原型问题与第七篇的评价。
- 某张概念图被选中，也不自动批准全部制作细节。
- 工作记录要保存**批准的是概念、构图、材质还是终稿**，不能让后续工具因为看见“通过”两个字就跳过未完成检查。
- 反例测试：候选图被选中 → 记录批准维度与剩余检查，不推定所有制作环节已批准。
