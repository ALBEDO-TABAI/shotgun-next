# 原则

- 悬挂、液体、演员接触、特殊材料等要求一旦改变，会同时影响美术、拍摄和执行条件。
- 本包不提供工程安全许可或具体施工指导；应把**需要合格专业人员确认的事项列为未完成条件**，而不是由概念图或 AI 文字代签。
- 具体资产的使用资格、品牌信息、历史资料和文化呈现也需要相应核查。视觉上“像真的”不代表制作可执行或使用无问题。
- skill 完成条件：安全、使用资格或实际工艺未核实时，没有被写成通过。
