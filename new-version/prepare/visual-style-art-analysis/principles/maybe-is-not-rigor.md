# 原则

在所有句子前面加“可能”，并不能自动使分析严谨。关键是说明：哪部分已经知道，哪部分在推测，支持在哪里，还有什么合理替代解释。

# Examples

- 差：“可能为了表达孤独，可能用了很多留白。”（没有区分观察与动机）
- 好：“人物与群体之间存在明显空场；孤立化是对此关系的一种解释；是否属于预设意图，目前没有过程资料支持。”
