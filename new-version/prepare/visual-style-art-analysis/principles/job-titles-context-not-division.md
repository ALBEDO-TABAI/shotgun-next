# 依据

British Film Designers Guild 的职位资料区分生产设计、美术指导、概念、绘图、陈设、研究等职责，涉及从视觉规划到施工转译和现场组织的不同工作。

# 原则

- 不据此建立“一个中文岗位对应一个英文岗位”的硬映射。同一个中文“美术指导”在广告代理、平面摄影、电视剧和长片中可能承担不同职能。
- 复盘真实项目时，先看合同、演职员表、制作说明和团队陈述，再讨论名称。
- 没有这些资料，就用“视觉概念决策”“空间设计工作”“陈设选择”等**功能词**，不武断认定具体个人负责。
