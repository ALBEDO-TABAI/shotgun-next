# 原则

分析对象本身与对象被拍摄、呈现出的影像，应分别进行。

# Examples

- 拍摄一把具有某种历史设计特征的椅子：“椅子的设计传统”与“这张照片的构图、照明、色彩和观看方式”应分别分析。椅子具有某种传统，不意味着照片整体自动属于同一种风格。
- 场景中有古典建筑元素，不等于影像本身采用古典的构图组织。
- Oppenheim《Object》：雕塑作品本身与拍摄它的照片应分别判断。

这是视觉分析中非常重要的防误判规则。
