# 原则

“清爽”被落实成大面积空场，“丰富”被落实成大量配料，“精确”被落实成严格网格，三者可能在同一画面争夺空间。

# 处理

- 先问优先级与作用范围：是否让丰富只发生在前段，最终展示保持稀疏？是否用少量有变化的材质替代更多物件？
- 不应把冲突简单转嫁给末端，让执行者“都兼顾一下”。
- 反例测试：测试显示需求中的两个目标冲突 → 回到优先级或分段职责，而非让执行者强行兼顾。
