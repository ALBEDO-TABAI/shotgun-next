# 原则

- 尺度关系错了，会影响场景、道具、机位和后期；某个次要表面的细纹可能只影响局部。应优先验证前者，而不是因为后者容易做得漂亮就先精修。
- 优先级也要考虑**可逆性**：可以快速替换的元素不必过早锁死；修改会牵动多个部门的决定，应有更明确的证据与确认。
