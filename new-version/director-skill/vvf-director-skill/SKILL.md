# VVF 导演分镜

把“观众在何时看到、听到、理解什么”落实成可执行的镜头。中文默认，服从用户语言、媒介、时长与交付格式。知识库提供选择，不规定唯一的好电影。

## 开始与加载

先辨认本次是构思、改编、分镜、参考拆解、局部修改、编译提示、审片还是审阅；只处理所需阶段。已有可靠材料直接使用。会改变故事事实或制作条件的缺项才询问；其余采用可撤回的假设并简述。

入口读完后，通常只选下表中与当前问题直接相关的 1–3 份文件；编译或审片任务会再加骨架、脚本与相邻参考。复杂任务逐步追加，读够能做出当前决定就停。不要递归读取全库。长篇按场景处理，连续编辑只读当前场、相邻进出状态和受影响约定。

## 核心工作法

1. 锁定用户事实、观众任务和制作约束。标开“原文事实 / 推断 / 本次新增”，不悄悄换结局、删台词、补功效。
2. 找到场景发生的变化，再决定视点、表演和空间关系。风格落实为可观察的画面组织，不能只有作者名和“高级感”。
3. 每镜写清起始状态、画面内行动或有意的持续状态、终止状态及衔接理由；关键道具与动作写初始、变化、结果。景别、运动、光色只写会改变执行的内容；固定镜头、长镜头、特写、平面化都有成立的任务，不设配额。
4. 有时间限制时核算声画可执行性；人物、道具、方向及声音跨镜保持可追踪；每个可见角色有自己的任务与时点；参考资产一项一职。写实遵守真实条件，风格化遵守已声明的世界规则。
5. 用用户目标和实际材料检查结果，先修叙事、覆盖、连续性和不可实现的问题，再做美感微调。交付最终方案及必要的取舍说明，无需展开思考过程或打印整套自检。

## 约束的层级

用户明确要求与已定事实优先；物理事实只约束声称写实的部分；连续剪辑惯例、色彩联想和风格卡是条件性工具。工具上限、参考句柄语法、模型能力是带日期的当期参数，不进通用规则。证据区分见[来源与证据](references/sources.md)。实验性处理可以打破常规，但要说明观众仍能抓住什么，或为何希望其迷失。

本技能独立可用。需要分工时按交接文件的职责发送具体任务，不要求加载其他技能；若另外安装了图像反推或场记技能可以配合，没有也能完成。分镜文案完成不代表影片已生成、已实拍或获用户批准；调用外部工具沿用用户实际授权。
