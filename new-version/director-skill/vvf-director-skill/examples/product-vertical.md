# 原创示例：18 秒竖屏器物展示

## 输入

虚构练习产品：深蓝色旋盖随行杯，杯身唯一文字为“日日”；用户只要求表现开盖、倒入温水和握持便携，不提供保温、耐摔、密封等证据。9:16，18秒，真人手部或产品动画皆可，不露脸，无旁白。

## 完成版

视觉关系：深蓝杯体与暖灰桌面对照，柔亮反射用于辨认曲面；只在开盖时改变物件状态。品牌字形由可控原始贴图/后期层承载；没有现成品牌素材时制作清楚的两字图形，真实商用须用户确认字样。画幅为竖屏设计，不从横片居中裁切。

| ID / 时间 | 画面与动作 | 画面组织 | 声音/文字 | 状态 |
|---|---|---|---|---|
| P01 / 0–4s | 一只闭盖杯立在桌面中央偏下，右手从下方进入扶杯，停在不遮字的位置 | 留上部负空间；杯身轮廓与字样清楚，固定 | 一次指腹接触声；不附功效文字 | closed；右手扶杯 |
| P02 / 4–8s | 左手旋开杯盖，右手稳定杯身；左手把盖放在杯左侧 | 近一些，手、盖、杯口同时可读 | 旋盖摩擦、落桌轻声 | closed→open；盖在左 |
| P03 / 8–13s | 右手放开杯；从右上方出现水壶，少量温水倒入杯内，然后水壶撤出 | 侧上方取景，杯口和水流完整，背景简洁 | 倒水声主导；无蒸汽特效保证“热/保温” | open，水位上升，无洒出 |
| P04 / 13–18s | 左手取回左侧杯盖拧紧，右手握住杯体向上提起；结束在手和杯体完整可见位置 | 固定中近景，提起后字不被手挡；不抛接 | 拧紧轻响；末尾保留一秒稳定字样 | open→closed→held |

时间闭合为 18 秒。P04需试演确认旋盖和提起可以在5秒内清楚完成；若杯盖螺纹较长，减少P01静置时间给P04，保留全片18秒。不能让下一镜自动恢复盖好而没有说明动作。

AI执行时P02和P04分别保留初始/结束状态参考；分镜不是必须对应四次生成。用户未提供模型时不写虚构模型参数。

## 检查与边界

只演示给定的动作和可见属性，无耐摔/不漏/保温推断。手机尺寸预览时检查字与手的遮挡；平台按钮位置按实际发布界面复核，不固定所有平台通用安全区数字。成片待制作，当前交付是导演方案。
