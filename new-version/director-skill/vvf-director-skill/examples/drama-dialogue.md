# 原创示例：40 秒《留下的钥匙》

## 输入

单房间、两位成年人、白昼、16:9，手机固定拍摄，不加旁白和音乐。情节：阿宁要搬走，把备用钥匙还给阿乔；阿乔没有阻拦，只把第二把椅子从桌下拉出。台词逐字保留：“钥匙放这儿了。”“你以后，还会来吗？”“会。”不增加哭泣或拥抱。

## 完成版

让观众从物件的归还与座位的保留读出关系。共享空间、固定机位、日常声持续。房间左侧为门，右侧为桌；阿宁靠门，阿乔在桌后。桌前两把椅子，靠门那把起初收在桌下。钥匙一直由阿宁右手持有，放下后无人再拿。

| ID / 成片时间 | 画面与动作 | 观看方式 | 对白与声音 | 衔接 |
|---|---|---|---|---|
| S01 / 0–8s | 两人同框。阿宁站在门边，走至桌前，把右手钥匙放在桌面靠自己的一侧，收回手。阿乔停止擦杯 | 固定双人中全景，门和椅子可见 | 3–6s 阿宁：“钥匙放这儿了。”钥匙轻响；远处车辆声 | 切在阿乔抬眼，动作已停止 |
| S02 / 8–18s | 留在阿乔。他看阿宁，手仍托着杯子，问完把杯子放下 | 固定中近景，阿宁肩部只作空间边缘 | 10–14s 阿乔：“你以后，还会来吗？”；14–18s保留等答 | 声音空间不断；切向他等待的对象 |
| S03 / 18–28s | 阿宁仍站桌前，先看桌上的钥匙，再看阿乔，答完没有马上离开 | 固定中景，不放大为眼泪特写 | 22–23s 阿宁：“会。”；之后只有房间底声 | 切到同框前，阿宁尚未转身 |
| S04 / 28–40s | 回到S01机位。阿宁转身走回门口；阿乔把靠门的椅子从桌下拉出，停在可入座的位置。阿宁门口停一步，不回身；结束时两人仍分处画面两侧 | 固定中全景；桌上钥匙保持原位 | 椅脚摩擦在32–34s；不加煽情音乐 | 尾部留在既有空间，40s切黑 |

总时长 8＋10＋10＋12＝40 秒，时间列是设计分配，尚未实演计时。每句有足够估计窗口；实演若行动超时，优先减少入场走动，不偷改台词。摄影先用手机现场预览确认人、门与椅子的可读位置；无需伪造镜头毫米数。

## 这个示例检验什么

四镜全部固定仍可完成目标；人物特写不是情感强度的唯一载体；声音不是背景音乐的同义词。关键状态：钥匙归还、椅子由收起到拉出、阿宁站位有可追踪变化。该例只证明方案可核对，不能证明演员表演或实拍画面已成功。
