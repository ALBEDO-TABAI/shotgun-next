# 质量审阅与停止条件

用当前目标评作品。不要给“电影感”或情绪效力伪造百分制科学分数。没有画面时能审的是方案，不能声称最终视觉已合格；已有生成片段或粗剪时改用[生成审片](generation-review.md)，那里按时间码、Take 和提示词版本分级修复。

## 先修使作品无法成立的问题

| 层级 | 检查 | 修复方向 |
|---|---|---|
| 事实与范围 | 原文、台词、产品信息是否被偷改或漏掉 | 回到源范围与覆盖关系 |
| 观众理解 | 必要因果、注意落点和信息时机是否成立 | 调整揭示、表演、机位或声画 |
| 空间与状态 | 人、道具、动作相位和声音是否连接 | 修状态拥有者与相邻镜头 |
| 时间与可行性 | 台词/动作能否完成，制作条件是否已知 | 实测或收窄；改可执行路径 |
| 风格一致与变化 | 主导关系是否可见，变化是否有规则 | 删除冲突装饰，补关键关系 |
| 局部细节 | 材质、措辞、辅助镜头是否有贡献 | 只改影响结果的内容 |

硬问题优先解决，但不要把审阅变成只能保守写实的闸门。实验作品检验其自定任务及规则。

## 审美上的反例测试

- 如果全部固定，表演和构图能否仍完成目标？能，就不为多样性加运动。
- 如果去掉音乐，信息和动作还成立吗？音乐本是核心媒介时换问“画面如何与其形成关系”。
- 同一情绪用相反景别是否也能成立？说明真正起作用的是具体关系，而非词典映射。
- 只改色调而不改空间、时间、行为，作品是否已经等于另一种风格？若不是，风格描述还太浅。
- 新加的规则有没有使一个明确成立的反例不合格？有则改为条件性指导。

## 多模式试用

检验至少一个真实任务的完整输出，而不只检查文档标题：给原始需求，按入口选择参考，完成分镜，核对事实、时间、连续性和用户所需深度。复杂技能适合由未参与编写的人独立试用；不要提前给它标准答案。

若发生失败，找失败对应的决策知识或加载入口。修真正拥有问题的文件，再用同类变体复测；不把每个案例堆成一条新铁律。

## 何时交付

必要内容覆盖、关键动作可执行、跨镜状态接得上、用户指定格式/时长满足、仍未实测处被准确说明。创作可以存在选择空间，不需要消灭所有歧义。

## 何时停止继续扩库

已处理发现的实质缺口；新资料不再改变任务分流、选择、失效边界或执行方式；再增加内容主要是同义词和重复范例时停止。丰富度应降低用户任务中的不确定性，而非增大每次阅读量。
