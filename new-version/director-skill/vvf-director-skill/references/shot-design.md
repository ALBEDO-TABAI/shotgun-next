# 镜头设计：从观看任务到镜头内事件

## 一镜需要什么

最小描述是：主体与环境关系 → 发生的动作 → 注意落点 → 结束状态。镜头目的可以是信息、身体体验、节奏或形式关系。不能只有“中景、缓推、冷色、悲伤”。

示例：“桌上两只杯子同框。她把其中一只翻扣，手停在杯沿；另一人的手伸来又收回。镜头不动，最后停在两只手之间的空处。”选择可执行，且表演承担了变化。

## 景别和取景

景别描述主体在画面中的尺度，与焦距、场地面积不是同一个量。室内也可以拍空间远景；是否容得下取决于真实机位、视场、开口与布景，不由平方米阈值决定。

| 观看任务 | 候选取景 | 应检查 |
|---|---|---|
| 关系和同时行动 | 双人/群体同框、纵深或横向排列 | 重要动作是否被身体遮挡 |
| 操作与因果 | 让动作与对象同时可见 | 手、工具和结果是否在同一可读范围 |
| 情绪不确定性 | 保留持续表演、反应或环境关系 | 特写会不会提前替观众下结论 |
| 察觉细节 | 局部或视线引导 | 观众在切前是否有找细节的理由 |
| 尺度或处境 | 人与环境的大小/距离关系 | 画面太小时能否仍读到关键行为 |
| 图形与节奏 | 平面、对称、不平衡、重复 | 是否为形式目的牺牲了必须理解的信息 |

交给生成或需要核对时，把景别落成主体占画面的大致比例和九宫格落位，例如“车身局部占满画面，标识在正中偏右”；口径见[帧描述规范](frame-description.md)。“局部占满”只写在文件里而不进提示与检查，生成会自动退回整体展示。

焦距只有在执行需要时写；注明传感器/等效口径，未知就写视场和空间效果。机位距离主要决定透视关系，焦距影响取景范围；“长焦压缩”通常涉及为了保持主体大小而改变机位，不能说换镜头自身改了站在原处的透视。光学细节见[光色材质](lighting-colour-material.md)及来源。

## 运动选择

| 运动 | 何时有用 | 常见失败与替代 |
|---|---|---|
| 固定 | 让表演/构图内关系成为变化 | 若看不清关键动作，先改调度或构图 |
| 摇/俯仰 | 在固定站位上追随或揭示 | 无可读落点像巡视；可直接切到新信息 |
| 推/拉 | 改变观众与事物的距离、逐步排除或纳入环境 | 仅因“情绪增强”机械推近；让人物靠近亦可 |
| 横移/跟随 | 显露遮挡后空间，跟随行动 | 动作路径和机位通道冲突；分段或固定等待 |
| 升降 | 揭示高度/空间关系，改变尺度 | 布景顶棚或吊装不可用；改位置或剪接 |
| 环绕 | 显露关系、让视点转移 | 人物只站着供炫技；用一段有终点的弧线 |
| 手持/身体承载 | 观察现场、共享身体反馈 | 随机抖动遮住任务；有跟随目标与稳定落点 |
| 变焦 | 改变画幅内尺度且保留站位，形成明显观看动作 | 冒充物理推进；明确需要的是取景变化还是视差 |
| 虚拟/不可能机位 | 动画、实验或主观世界的空间转换 | 写实段突然穿墙；标转换条件或选可行路线 |

先问静止是否更有力量。要动就写起点、触发、速度曲线、落点（结束构图），必要时写阻挡/对焦；夸张运镜也要有可读的起点、高潮和落点。速度用“跟到门口后停下”等行动关系，未测量不要伪造 cm/s。承托系统与快慢速的具体写法由摄影工种决定。抽象动画也优先用一致的轨迹与相对关系；需要坐标时明确画幅、单位和同一几何定义，避免近似坐标与“精确闭合”的承诺冲突。

## 焦点与层次

先决定同时需要看懂什么，再选景深。浅景深可以引导，也会抹掉关系；深景深可以让观众选择，也需要构图和表演帮助。拉焦注明从谁/什么到谁/什么及触发，不把“电影感”当动机。

前景、中景层、背景可同时由遮挡、大小、透视、明暗、色彩、清晰度、运动视差、声音远近共同构成，不要求只准使用一种。图形平面化也可有意成立。多层时写遮挡序（谁遮谁）和主体在哪一层，虚化只说明离对焦面远，不说明前后。

## 单镜与生成单位

一镜内可有多个动作，但必须在时间和表演上可完成。技术实现可分为多个生成片段后拼接，或一个片段含多个剪辑镜头；保留两者对应，不能让工具片长替你决定叙事。多人动作优先写角色各自位置、目标和相互作用；不为所谓人数上限删掉原剧情。实现困难时比较同框简化、插入反应、分组覆盖或合成，而非一律减人。

参考资产分工、字段、接缝与重试见[提示词编译](prompt-compilation.md)。未实测的生成限制标为待验证，避免跨版本万能负面词。
