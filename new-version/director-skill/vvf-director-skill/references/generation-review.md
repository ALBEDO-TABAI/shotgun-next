# 生成审片与最小返工

用于已有生成片段、粗剪或时间线。没有画面时只能审方案，见[质量审阅](quality-review.md)。

先完整看一遍，不暂停记小问题，回答：这场戏是否讲清；观众是否知道该看谁；空间是否可信；表演是否成立；摄影是否支持而非遮蔽主戏；最好的一刻在哪。第二遍再按时间码记录问题，关联镜头 ID、Take、提示词版本和实际可用区间。总判断只取一种：通过、有条件通过、需局部返工、需重新设计。不从车牌、皮肤纹理和小穿帮开始堆意见。

## 分级

- **P0 必修**：叙事信息错误或缺失；身份、目标、关系看不懂；空间方向、视点、动作因果崩溃；关键道具状态错误；表演与剧情状态相反；观看任务被改变，如该抽象的变清晰、该局部的变整体。
- **P1 优先**：情绪转折无过程；重要信息无反应时间；节奏单一、长对白无调度变化；背景像静止布景；权力关系、危险感、人物入口不明；相邻段接缝明显；摄影没有实现已确认的命题。
- **P2 集中处理**：局部纹理、车牌、商标、小范围背景漂移；轻微光影与肤质；不影响理解的次要连续性；可统一替换的临时声音。

实验作品按自定规则检验，不套剧情标准。

## 保护好表演

好表演比小连续性难重现。整场情绪成立而只有小错时，优先：删掉错误区间；插主观人物反应；插环境、道具或手部特写；裁切或重新构图；只补过渡状态；用声音和画外空间连接。只有错误破坏叙事、空间或核心表演且无法被覆盖，才扩大重做。

## 返工路由

1. **剪辑可解**：删减、换序、延长反应、声音先入或延续、裁切、现有覆盖。
2. **单镜补拍**：反应、关系、建立、动作关键状态、过渡、余波。
3. **小节重做**：一个节拍的空间、表演或动作条件整体错误。
4. **整场重设计**：场次目的、权威空间、视点或核心调度从根上错误。

每项写保留区间、首选修法、备选修法、是否需要新资产、验收条件。次数与成本只能作估计，不写成保证。

## 症状与根因

| 症状 | 常见根因 | 首选修法 |
|---|---|---|
| 人物左右、背景漂移 | 没有 master 或锚点含糊 | 停止补近景，重建关系图与机位侧 |
| 局部特写变整体，抽象变清晰 | 画面要求没进提示与检查；参考职责冲突 | 把占比、落位、抽象程度写进提示与检查项，图文同景别 |
| 情绪突然跳变 | 两段之间无过渡状态 | 补呼吸、收身、转移注意的桥接镜头 |
| 所有人盯主角，同步反应 | 背景没有独立任务 | 逐人写任务、时点、强度 |
| 台词都很快 | 未标重要信息与反应 | 揭示点加停顿、反应、环境静默 |
| 动作漂浮 | 未拆状态、重量、接触 | 重写初始、发力、结果、余波，必要时拆镜 |
| 画面脏或塑料感 | 低质参考传代、职责混杂 | 回到干净原图或线稿，减少每张参考的职责 |
| 同角度跳切 | 只生成孤立近景 | 补关系、过肩、动作中切换或不同景别 |
| 反复同错 | 第二次没有诊断 | 分类根因并改变条件，不续抽 |
| 人物像巨人，建筑像模型 | 没有尺度契约 | 用门高、人车比、层高重建比例 |
| 人物贴在背景上 | 面部补光固定，不响应环境 | 写人物穿越光区的变化 |
| 烟、食物、门、伤妆跳变 | 没有状态机 | 写初始、变化、结果并按镜核对 |
| 表情精致但像在演戏，反应早于刺激 | 无对手刺激、通道过载、时序未写 | 改写刺激、调整、动作链，只留少数通道 |
| 运镜花哨无张力 | 没有触发、路径、落点 | 重写起点、触发、速度曲线、落点 |
| 光斑、拉丝、眩光堆叠 | 效果没有来源与时点 | 只留 1 至 2 项并绑定光源或动作 |
| 相邻镜头运动断裂 | 动势、速度、重心未接续 | 对齐方向与切点，或有动机的反向切换 |
| 同人换脸、衣服换款、多人融合 | 身份母版或空间分配不清 | 身份母版与服装结构、各自空间与动作，见角色技能一致性表 |

症状与根因分开写：“人物僵硬”是症状，“没有真实任务”才可能是根因。

## Take 结论

每个 Take 一个主结论：**过**（可作主版本，记首选可用区间）、**保**（不是完整版本，但有稀缺表演或接缝区间必须保存）、**修**（核心成立，写保留区间与最小修法）、**废**（无可用区间，仍记失败类型避免重复）。附各岗短评；导演作结论，场记原样记录。导演未裁时写“建议结论，待终裁”。观看者报告的“可用”是输入，不是裁定：有 P0 问题的段不能直接记为全段可用。

## 通过标准

观众能说出发生了什么与为何重要；关键人物的目标、注意力与情绪变化可见；空间与动作因果无硬错；大全景比例与人物同环境光的关系可信；每个可见角色有具体任务；关键道具与动作状态可追踪；重要信息有反应时间；至少一个关系或环境镜头支撑场面；P0 清零；剩余 P1、P2 不反向破坏已成立的表演和结构。有条件通过必须写出条件。

## 学习闭环

单次成功或失败只记观察。同一镜多次随机结果只能形成模型倾向，属带日期的当期参数。至少两个独立镜头或场次出现同样因果，或导演明确设为规范，才形成候选原则或项目设定。跨模型仍成立、无关键反例、步骤可复现，才升为高置信。记录格式与知识卡见场记技能；本文只保留结论，不记录冗长分析。
