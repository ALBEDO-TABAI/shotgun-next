# 表演、关系与身体行动

镜头不能替不存在的表演补情绪。将角色状态写成可演的意图、对象和行为；留给演员/动画表演不同解释的空间。

## 从形容词变成行动

“害怕”可以是说话前确认门有没有关；“控制对方”可以是替对方收起还没喝完的杯子；“不愿认输”可以是在没人要求时继续把桌面擦干。这些是具体场景的提案，不是普遍心理征兆。

常用可演任务：争取、拖延、试探、安抚、掩饰、迫使、避开、证明、照料、挽留。明确对象与障碍：谁在拖延谁、为了何事、用什么行动。不要只让人物眉眼完成整场戏。

## 刺激与时序

把一拍写成时间链：看见或听见刺激 → 眼神或呼吸先有最小调整 → 手头任务被打断或改变 → 台词或动作作为策略出现 → 句后余波与新状态。反应落在刺激之后，角色不预知下一句。

一个节拍只让 2–4 个通道发生关键变化，其余保持稳定，观众才看得见那一次变化。通道：目光落点与移开原因、呼吸深浅与气口、面部单一细微变化、重心前倾或后撤、手部任务的握松折擦停、声音的音量速度句尾、刺激后延迟与停顿长度。

记退出状态：镜头结束时的位置、视线、持物、表演强度，供下一镜入口核对。真人、动画、生成都适用；生成尤其需要，因为“更悲伤”这类结果词会驱动全部通道同时夸张。

## 台词与潜台词

分别考虑说了什么、想让对方怎么反应、身体正在做什么。台词可以与动作一致，也可以冲突；冲突需要情境，不是每句都必须“口是心非”。

标明对白是否原文锁定、允许口语化或可改写。保留说话者、打断、重叠、停顿与句子跨镜的连续关系。不要为凑镜头把完整意思拆坏，也不因听者重要就漏掉说者台词。

一句话通常只保一个核心重音，服务策略变化；停顿必须有行为：观察对方、压住冲动、找借口、重新组织。允许动作跨过台词，说话时继续倒水、折纸、找出口。

## 双人与群戏

先设计听与看：听者可以承载关键反应，画外说话并不需要补一个说者镜头。也可以始终同框，用靠近/退开和动作时机组织关系。

群戏中给每个关键角色当下任务，区分主行动与背景反应；当多点同时重要时用空间层次、时机错开或多镜覆盖。不要每个人都看镜头、同时做显著动作。人数限制只能来自已知制作条件。背景人物的逐人任务表见[空间与状态](space-and-continuity.md)。

## 多媒介表演

- 真人：给行动目标与调度边界，避免把毫秒级眨眼作为表演考核。
- 二维/三维：轮廓和关键姿态先可读；夸张幅度由角色与世界规则决定，不能自动强制真实人体运动。
- 定格/物件：重量、支点、接触和节拍让物体有生命；没有脸也能表演。
- 生成：优先清晰的可见动作及前后状态，精细情绪通过可控制行为和声画关系承载；效果需看实际输出。

## 生成表演的常见失真

| 症状 | 常见根因 | 改法 |
|---|---|---|
| 眉眼嘴同时夸张变化 | 情绪结果词驱动全部通道 | 只指定首发通道和一个后续动作 |
| 每句都点头、摊手、抿嘴 | 没有真实身体任务 | 分配持续物理任务并写何时中断 |
| 像背稿或播报 | 台词无对象、无目标、重音平均 | 写对谁做什么，标刺激词与策略词 |
| 反应早于刺激 | 时序没写或片段拼接错位 | 写“听见后短暂停顿，再……” |
| 眼神漂浮 | 没有具体目光落点 | 用空间锚点：左侧门把、桌上信封、对手右眼 |
| 两人同频表演 | 没有主次和反应时差 | 一人行动一人接收，再交换主动权 |

文字难以精确控制复杂口型、手势或节奏时，转用表演驱动素材、拆镜或反应镜头，不无限加词。这些是从生成结果观察到的常见模式，模型与版本差异需实测。

## 不用伪心理学

脸型、眼距、肤色、身体差异不证明道德或性格；表情动作不证明内心，更不能充当测谎。角色设计可使用文化语境中的视觉习惯，但应说明这是创作编码并检查刻板化风险。需要角色外观/服装细化时交给角色工种，导演提供叙事和行动需求。

## 排练式检查

把对白读出并做简化动作：谁何时接触道具，停顿是否有对象，下一镜接在哪里。无法实际排练时说明是桌面估算；不称“节奏已经实测”。表演完成度的最终证据是试演/animatic/成片，不是描述长度。
