# 光、颜色与材质的有限精度

## 先决定画面关系

写清哪里需要被看见、哪里的信息可以隐去；光影如何随人物行动变化。自然光、棚光、均匀光、硬光、彩色光都可用，不能以“电影/广告高低贵贱”筛选。

**写实方案**记录主导来源、方向、柔硬、相对明暗、反射和环境补光；来源可以在画外，不要求每个灯具出镜。漫射天空与墙面反射也是合理来源。远光源近似平行、延展面光源与近似点源的衰减条件不同，不能强迫所有画面“近亮远暗”。

**风格化方案**记录舞台、平面、绘画或心理光的规则与转换条件，不借假物理解释。现实中的动机照明也是创作安排，并非真实现场唯一可能的光。

人物穿过不同光区时，脸部亮度、色温、方向应随之变化；无来源的固定面部补光会让人像贴在背景上。

## 少而有效的可调变量

| 变量 | 如何落地 | 注意 |
|---|---|---|
| 方向 | 人物/物件与来源的相对位置，动作后是否变化；写法用钟点加高低，如“左前约 10 点、略高于视平线” | “顶光=压迫”等只能作为项目联想 |
| 柔硬 | 阴影边缘、光源相对主体的视角大小 | 更亮不等于更硬；柔光也可能有明显方向 |
| 明暗分配 | 主体和背景谁更亮，阴影里保留什么 | 深黑可表达隐藏，但关键行动不能无意丢失 |
| 色彩关系 | 主/辅/强调色面积，人物与环境如何区别 | 不靠单个色温数值定义整张图 |
| 反射 | 光源形状如何出现在玻璃、金属、水面 | 反光位置需随视点变化；不把所有高光擦掉 |
| 表面 | 粗糙、磨损、织物、皮肤、涂层的尺度 | “真实”不是满屏纹理，也不是一律去皮肤细节 |

## 颜色不是一个滤镜

至少区分物体本色、照明光谱、记录/白平衡、观看/后期。设定“暖灰墙＋青色工作服＋红色工具”比笼统“青橙电影感”更能让不同工种一致。

写方案或读参考时区分固有色与光染色：白墙偏橙是光染，暗处仍绿的植物是固有。至少对主体和最大背景面做这个区分；反推参考图时用高光与阴影的色偏判色温。

数字色值是指定显示环境下的意图，不保证实物/印刷/不同屏幕一致。不要把真实胶片型号写成固定色彩配方。Kodak 500T 的钨丝灯平衡及曝光信息有厂家资料；作品最终外观还受照明、曝光、冲洗、扫描与调色影响。[来源](sources.md)

## 材质由光学行为写

材质是从表面对光的反应读出来的，写方案时也照此写，生成才有可复现的依据：

| 材质 | 可见的光学签名 |
|---|---|
| 金属 | 强镜面反射映出环境轮廓；有色金属高光带色；拉丝为长条状高光 |
| 玻璃/透明体 | 透射与折射使后方错位；边缘与掠射角强反射；高光锐利 |
| 水/湿表面 | 锐利明亮的高光加折射；湿使表面变暗、高光集中 |
| 皮肤 | 薄处逆光透暖红；柔和漫反射加小而散的油光高光 |
| 哑光布 | 漫反射为主，几乎无高光，可见织纹 |
| 丝/缎 | 柔光带随褶皱走向滑动 |
| 木 | 漫反射加方向性木纹；上漆多一层清漆高光 |
| 塑料 | 均匀漫反射加单一集中高光，可亮可哑 |
| 陶瓷/釉 | 光滑漫反射底加锐利高光 |

只写 1–3 处对观看任务重要的表面，不做材质报告。

## 介质、景深与纹理

在声称写实的真空中不默认添加大气光束；烟、雾、尘会改变散射、对比与可见性，但不是所有体积效果都需要画内灯具。远景结构也可能因天气/散射真的看不清，不强制远处始终锐利。

颗粒、光晕、扩散、失焦、运动模糊属于不同机制，不按“最多两个全开”的数字限制。一起使用前明确谁在承担表达，比较主体识别、字形、纹理和时间稳定性是否受损。只描述关键效果；AI 执行时不要堆砌会争夺画面的词，光斑、拉丝、眩光、虚焦通常只留一至两项主导，并说明来源与时点。

## 冲突修复例

- “极浅焦但三个人同时表演必须清楚”：同焦平面调度、加深景深或改变叙事焦点，而非保留矛盾形容词。
- “极暗环境但必须读瓶身小字”：增加有意的展示段、改变反射/标签角度，或把文字交给后期；不要直接提亮全场。
- “镜头处处柔糊但要看粗布与皮肤”：限定软化作用区域与强度，先用光向呈现材质。
- “黄金时刻贯穿很长实拍场次”：制片评估窗口与补拍匹配；不要承诺太阳一直在同一位置。
