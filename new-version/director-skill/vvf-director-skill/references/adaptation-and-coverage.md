# 原文覆盖、改编与参考复刻

## 源材料的权力边界

先区分用户要求逐字保留、允许压缩或自由改编。原文事实、观众需要理解的因果和确切台词分别标记；“忠实”不一定是逐句画面化，但不能自行删掉决定结局的信息。

给关键源段一个简短定位：场次、段落、用户原句或文件位置。生成分镜后检查每项是画面表达、声音表达、合并表达、明确省略还是尚未处理。短任务在正文自然完成；长篇才建覆盖表。

| 源内容 | 可用改编 | 必须防止 |
|---|---|---|
| 内心判断 | 行动、反应、对照、主观声画或旁白 | 把推断冒充人物明确做过的事 |
| 长时间概述 | 省略、蒙太奇、阶段对比 | 丢掉事件先后或状态变化 |
| 景物描写 | 作为行动条件、观看节奏或象征 | 为每个形容词增加一镜 |
| 解释性对白 | 保留、经允许改行动或视觉证据 | 擅改原句导致人物关系变了 |
| 多线并行 | 交叉剪辑、分段或同框 | 时间同步关系不清 |
| 不可靠叙述 | 明确叙述者的表现层与现实层 | 下游把主观想象当事实资产 |

## 长篇分批

先列范围与场次，按剧情依赖拆工作单元。当前单元只加载对应原文、全局已定约定、角色/道具进入状态、未回收线索；结束保存退出状态和未完成范围。

续写时保留镜头 ID 与项目版本。若没拿到上一段的实际记录，不假装记得，指出缺少哪份材料；能独立做的部分继续完成。不要把简短摘要当作原文全部覆盖的证据。

## 参考片的四层拆解

1. **观察**：实际看到/听到的主体、动作、构图、时序、声音，附时间位置。代表帧按[帧描述规范](frame-description.md)清点：景别与主体占比、深度层与遮挡序、光向、色调、材质、文字；每条带依据，认不出写“不可辨”。
2. **机制推断**：何种选择可能形成何种体验，写明置信度及其他解释。
3. **保留项**：用户真正要复刻的节奏、观看关系、动作因果、视觉组织。
4. **变化项**：人物、产品、空间、文案、文化语境及由此必须改变的镜头。

只有静帧时不推断整个运镜和剪辑。只有无声视频时不编造原音轨。镜头边界、演员身份、器材型号无法确定就保留未知。

复刻时给每个源镜头记下它的观看任务：是看清局部、感受速度、还是认识整体。抽象段（如光轨中只感到速度）和局部段（如标识占满画面）在替换后必须保持同一任务；把它们统一换成清晰的整体展示，是改变了作品而非复刻。

## 替换不是词汇替换

把杯子换成面霜瓶，抓握、打开、使用、尺度、反射和标签可读性都会变化；把成年人换成儿童，动作与现场条件也会变化。保留的是创意机制时，允许调整执行路径；如果用户要求精确复刻某项，说明冲突并提供具体可行取舍。

高风险变更先定位最短证据镜头。例如需要包装正面清楚，先验证最关键展示镜，再扩展其它镜头；不盲目把同一错误分发到全片。

## 忠实与权利

标记来源、用途和已知使用许可状态。自行撰写新示例，不把受版权作品长篇复制进知识库。用户提供文本可按任务处理；再发布、使用真实人物形象、商用素材等具体行为仍服从实际授权，不能从“帮我做分镜”推定所有外部权利已解决。
