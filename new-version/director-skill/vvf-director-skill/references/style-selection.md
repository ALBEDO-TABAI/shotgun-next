# 风格的选择、组合与演化

只有要选风格、解释参考或修正“好看但不对”时读本文件。目录见[风格家族](styles/index.md)；先选有关家族，再打开具体文件，毋须遍历。

## 先拆开四件事

- **内容/类型**：讲什么、如何形成预期，如家庭、恐怖、教程。
- **媒介/工艺**：真人、二维、定格、三维、拼贴、生成等。
- **视觉语法**：注意如何被空间、明暗、色块、运动、构图和剪辑组织。
- **观看/传播任务**：理解操作、信任证据、感受孤独、欣赏材质、进入陌生世界等。

四者可以组合。恐怖不必低饱和，商业不必高亮，动画不必可爱，纪实不必手持。这些关联是候选方案，不是分类公理。

## 把风格词转成可执行关系

用户说“克制、高级、电影感、温柔、赛博、国风”时，先用场景和参考缩小含义。必要时给一组**真正有区别**的短例，而不递交几十个名词让用户挑。

| 维度 | 具体描述方式 | 会改变的决定 |
|---|---|---|
| 观看距离与主次 | 环境压过人物，或观众贴近身体；同时行动或单点引导 | 景别、遮挡、焦点、声画视点 |
| 空间组织 | 纵深通道、平面色块、封闭框中框、开放视野、破碎几何 | 场景设计、机位、人物位置 |
| 时间组织 | 等待、连续、跳跃、重复、迟到的反应、突然中断 | 镜长、动作过程、切点 |
| 动作与表演 | 节制、仪式、写实劳动、夸张弹性、机械重复 | 姿态、动作幅度、节拍 |
| 光与影调 | 阴影边界、亮暗面积、可见细节、光源关系 | 打光/绘制、曝光层次 |
| 色彩 | 主/辅/强调色的面积、角色和场景的色彩关系、跨段变化 | 服装、材料、场景与后期 |
| 质地与边缘 | 柔硬、透明/反射、颗粒尺度、手工不齐、印刷网点 | 素材、照明、媒介处理 |
| 声音 | 空间距离、干湿、画外线索、音乐与动作的同/异步 | 收音、声音设计、剪辑 |

不要求每个维度都填。选真正起组织作用的维度，删掉“电影级”“8K”等不能解释画面关系的词。

## 风格小约定

用短段落写：观看任务；两三条主导关系；可变化处；必须避免的冲突；一条测试镜头。例如：

> 让观众看见两人同处一室却无法靠近。以门框切割共享空间；人物动作少，门外日常声继续；暖光不替关系提供安慰。近景可用于最后交还钥匙，之前不靠哭泣特写解释。测试：一人离开后保留另一人与空椅同框，检查是否仍能读出失去。

这里“两三条”是压缩示例，不是创作配额。

## 组合规则

让不同来源各自负责不同的维度：例如观察式表演＋图形化布景，或写实环境＋主观声音。说清楚谁主导、哪里转换、观众凭什么识别转换。

如果两种选择争夺同一资源，明确优先级：复杂背景与字幕的阅读、极浅焦与多人同时反应、强纹理与小字、随意手持与精密几何对齐。可以保留冲突作为表达，但要试一镜看它是张力还是噪音。

风格可随叙事演化：以关系、时间、人物主观状态等可追踪事件触发；不要求整片锁死同一调色，也不要求每次转折换色。

## 有据地拓展风格库

先看真实参考，再记录**观察到的选择 → 可能作用 → 置信度与其他解释**。同一作品的一张图无法证明作者签名或镜头运动。要主张稳定规则，需跨不同内容/时期的多份样本，并找反例。没有足够语料就称“本项目工作性方案”。见[参考研究](reference-reading.md)。

新卡只有在增加新的目标—选择关系、边界或可执行例子时入库。单换颜色或作者名，合并到现有卡。类别不适合当前作品时可以直接定义新语法，不强行归类。
