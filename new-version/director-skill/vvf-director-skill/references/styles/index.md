# 风格家族检索

先确定观看任务，再选会改变镜头决策的方案。本库 12 个家族文件、49 个 profile，是 **工作性创作方案**，不是艺术史完备分类或经过实验验证的风格处方。家族只是索引：题材、媒介、地区、色调和传播目的不互斥，也不一一对应。

先读与目标最接近的一个文件；只有某个判断仍缺替代路径时再开另一个。已知画面关系足够明确时可不用库。不要整库加载、默认穷举或把全部属性塞进提示词。选出的 profile 必须改写成当前场景的动作、空间、色彩和时间关系。

|---|---|---|

| 让观众理解人物关系与事件变化 | [古典叙事](narrative.md) | N01 关系对话；N02 主观发现；N03 深度调度；N04 并行会合 |

跨家族组合例：O04 过程证据 + B01 物性展示可以拍真实手作产品，但禁止为漂亮画面伪造工艺结果；M01 空间留白 + E03 明亮不安可用空旷白天表达压力，而无需低照度；A02 剪纸层景 + H03 长卷展开共享层次与展开方式，但地区纹样须另找证据。

组合时分别说明谁负责空间、谁负责色彩/材质、谁负责时间，冲突按场景观看任务解决。不能让同一镜头既要求严格静止观察又无理由高速巡游。

每个 profile 都给目标、可观察语法、适用场景、失效点、替代方案与微型镜头。它们是起点而非必填清单；编号用于检索，不写进面向观众的作品。原始证据见[来源与边界](../style-sources.md)，具体选择过程见[风格选择](../style-selection.md)。
