# 喜剧、动态与运动节奏

先定义观众在何时知道规则、预见结果、发现偏差；不用“快剪、夸张、大广角”代替笑点和动作。真实拍摄的身体风险应交由专业执行，分镜可以用错位、替身或剪辑实现视觉效果。

## K01 全身动作因果

- **目标/适用**：让身体、障碍和结果形成清楚的可见逻辑；适合动作喜剧、舞蹈、体育示范与动画。
- **组织语法**：尽量在关键段保留起点、接触与结果；身体剪影和落脚点可辨，背景不与轮廓竞争。机位帮助看动作，不把反应全切成脸。
- **时间/声音**：预备动作给观众形成预期的时间，结果后留读懂的余量；不要默认每次跌倒都配夸张音效。
- **失效**：切镜掩掉因果，观众不知是谁触发；危险动作被写成普通人可直接照做。
- **同目标替代**：利用画外、错位接触、替身或动画表现同一结果；重点仍是关系可读。
- **微镜头**：全身景中人物踮脚够架子，脚下矮凳被一只扫地机器人缓慢推走；他抓住上方横杆后，脚才发现悬空。

## K02 冷面错位

- **目标/适用**：让庄重呈现方式与微小荒谬事实相撞；适合制度讽刺、日常喜剧、编辑短片。
- **组织语法**：构图、光和表演保持克制，异常由动作或物件关系产生；摄影机不抢先告诉观众“这里该笑”。
- **时间/声音**：常态声场继续，停顿让错误逐渐可见；不要过早切到夸张反应者。
- **失效**：异常太弱或不清楚，观众只看到无事发生；冷淡表演把角色的真实意图也抹去。
- **同目标替代**：给一次明确的正常示范，再呈现相同动作中的偏差；或放大物件尺度而非表情。
- **微镜头**：会议室每人依次认真盖章，最后一人端起水杯在纸上压出圆水印，仍平静地推给下一位。

## K03 连锁升级

- **目标/适用**：由一次具体尝试引发越来越大的后果；适合闹剧、广告故事、动画与动作段落。
- **组织语法**：每次升级改变一个真实条件，后果来自前一个动作；保留最初目标作为参照。规模可以变大，但规则不能每轮重写。
- **节奏**：建立模式、让观众预测、再有意义地偏离；重复次数不固定，删去没有新信息的一轮。
- **失效**：只是把同一笑点重复三次；最后靠无因爆炸/新增角色解决，前面选择没有后果。
- **同目标替代**：减少环节，转为一次期待与反转；空间受限时让声音显示更大后果。
- **微镜头**：人物用胶带粘住摇晃桌角，胶带黏到鞋底；起身带倒椅子，又为扶椅子把桌布拽出，原本那杯水却一直没洒。

## K04 节奏运动

- **目标/适用**：使身体、对象或群体的运动形成能量变化；适合运动影像、舞蹈、音乐短片和动力展示。
- **组织语法**：动作方向、速度、密度或尺度中选主变量；切镜连接运动阶段或故意改变方向。运镜必须有观看对象与路径。
- **声音/时间**：按加速、峰值、恢复等动作结构安排，不必每拍一切；关键动作的完成和停下也有节奏价值。
- **失效**：速度变化掩盖真实性，观众看不出动作是否完成；满屏运动挤掉主体。
- **同目标替代**：固定机位让运动穿过画面，以进入/离开和声音建立速度；或把群体变化限制在同一画幅。
- **微镜头**：跑者从远处进入固定画幅，跨过地面标线后减速；切至近景不是加速冲刺，而是鞋底停住扬起的一小圈尘。

依据：[A01](../style-sources.md#a01) 可启发运动预期的衔接，[A04](../style-sources.md#a04) 只说明运动具有注视预测价值，不说明更快更有趣；[V03](../style-sources.md#v03) 提供静态轮廓也能表达力量关系的观察。本页没有把喜剧效果声称为普遍心理定律。
