# 观察写实

在“观众应看见什么真实关系”上选择，不以手持、低饱和或颗粒判定真实性。纪实中不能要求当事人重演未发生的行为；虚构的写实外观也应标为虚构。以下是工作性方案。

## O01 固定观察

- **目标/适用**：让一个行为的完整进程及等待本身可见；适合纪实段落、现实剧情、过程直播中的单一空间。
- **组织语法**：先选能看见动作起因与结果的位置；景别容纳身体和操作对象。保持机位，允许人物暂时不在构图中心；光线维持场所可解释的变化，保留环境声。
- **时间**：镜头长短由行动、感官观察和观看任务决定；停顿可以等待，也可以让人感受持续状态，不强加即将发生的事件。不给“长镜天然真实”背书。
- **失效**：重要动作被遮住或落在画外，长时间等待没有信息变化；固定镜头可能只留下混乱。
- **同目标替代**：为关键动作补一个可核对的细节角度，或选择 O02 跟随；说明省略了哪段时间。
- **微镜头**：修鞋台中景，师傅穿针失败后换了一个角度；针终于穿过，才切至下一工序，保留两次摩擦声。

## O02 伴随行动

- **目标/适用**：让观众体验身体在环境中的选择与阻碍；适合人物纪实、行走剧情、实地演示及虚构 AI 片段。
- **组织语法**：明确跟随谁、站在哪一侧、与其保持什么关系；移动由人物决定或障碍触发。背景经过的变化交代位置，优先保留脚步、呼吸和目的地声源。
- **取景**：贴近不等于持续特写；遇分岔或多人会合，退开使选择可见。手持稳定程度服务所需信息，不添加无因抖动。
- **失效**：摄影机比人物更忙，路径不清或身体反应被切掉；可能让普通行动像追逐。
- **同目标替代**：两个固定观察点承接同一路径，用声音连接；减少跟拍造成的干扰。
- **微镜头**：跟随送餐员走至被堵门口，他停住看另一入口，镜头随视线侧移才显出楼梯。

## O03 环境群像

- **目标/适用**：让人物处境由他人与环境关系产生；适合社区、劳动、家庭群戏和有意开放观看的剧情。
- **组织语法**：分配前中后景行动，明确哪些同时发生；人物的出入、遮挡与声源距离组织注意，保留具有实际功能的环境细节。
- **时间**：只在关系改变或需要细辨时收近；不要把所有背景人物降为永远模糊的装饰。
- **失效**：多个重要动作同一瞬间竞争，小屏看不清；环境可辨却不知道人物想做什么。
- **同目标替代**：先用一镜建立共同空间，再按行动目标分组；让背景保留声音而暂不承担视觉任务。
- **微镜头**：前景母亲数硬币，中景层孩子等饭，背景老板翻“休息”牌；母亲抬头时老板停手，三者关系在同镜改变。

## O04 过程证据

- **目标/适用**：让观众核对一件事如何完成；适合工艺、教学、产品实际使用及调查解释。
- **组织语法**：对象、操作者、关键接触面至少在关键步中同时可辨；操作前后保留相同参照。照明先保证现象可看清，真实反射与材质比“电影质感”优先。
- **时间**：可省略重复劳动，但标明省略；结果镜头承接相同样本，不暗换状态。声画必要时保留真实操作阻力。
- **失效**：漂亮特写使人无法判断力施在哪、样本是否同一个；广告剪法可能假造即时效果。
- **同目标替代**：分屏前后对照、示意图解释不可见步骤，明确示意与实拍的边界。
- **微镜头**：杯口缺口旁放尺寸参照，手将密封圈压入，同角度倒水测试；必要时字幕说明静置时间。

证据启发：[V04](../style-sources.md#v04) 支持区分可见动作与内心解释；[A02](../style-sources.md#a02) 提醒时间省略不必打断同一行动；[A03](../style-sources.md#a03) 不支持“控制越少越高级”。这些证据没有验证本页四分法。
