# 古典叙事与关系可读性

“古典”在此是清楚组织因果与视点的入口，不是历史时期、服装类型或必需的大场面。四个方案可以用于当代生活、动画、广告故事和长片。

## N01 关系对话

- **目标/适用**：让观众读出谁试图影响谁、关系何时变化；适合谈判、家庭对话和人物广告。
- **组织语法**：先建立双方位置及共享对象。景别变化对应信息或权力变化；反打的高度、距离、画外空间有具体理由，不机械一人一句切换。
- **表演/声音**：保留听者的选择、迟疑和身体动作；台词可越过反打，视觉与发言权不必同属一人。
- **失效**：只剩交替大头，观众看不到共同处境；过度对称反打反而抹平关系差异。
- **同目标替代**：用双人中景让距离、阻挡和物件移动表达关系，再只在必要处收近。
- **微镜头**：双人桌边，甲将合同推过去；乙不接，只把水杯压住合同，切近的是这只手而非说话人的脸。

## N02 主观发现

- **目标/适用**：让观众与人物同步识别线索，或有意比人物早/晚一步；适合悬疑、学习、初见及无对白叙事。
- **组织语法**：区分客观镜头、人物视线提示和主观所见；线索大小/位置足以辨认，视线镜头不能默认等同脑中真实想法。
- **时间/声音**：按“引发注意—看见—重新行动”组织；反应镜可以省略或延迟，声源可以先触发寻找。
- **失效**：观众误以为两个空间相连，或中性表情被并置成未授权的恶意/爱慕。
- **同目标替代**：让线索与人物在同镜进入关系，或用人物动作验证其确实看懂，而不依赖反应特写。
- **微镜头**：钥匙转不开，人物看向门牌；插入“六楼”，回中景他退一步看楼梯，再转身下楼。

## N03 深度调度

- **目标/适用**：在少切镜中让观众看见关系同时变化；适合群戏、空间误会、室内权力关系。
- **组织语法**：前中后景各有任务；走位、转身、门框和明暗控制显隐。需要读取的层级保持可辨，不因追求虚化丢失行动。
- **时间**：通过一人离开、另一人进入、站坐交换改变构图中心；镜头只为新的关系调整。
- **失效**：复杂走位抢夺注意，深景堆满却没有行动主次；小屏细节不可读。
- **同目标替代**：把同时事件拆成两条清楚的行动线，保留一处共同空间确认镜头。
- **微镜头**：前景员工交钥匙，中景层主管签字，背景门打开露出接任者；员工先听见脚步，主管随后抬头。

## N04 并行会合

- **目标/适用**：通过多条行动的时空关系制造期待；适合救援、赴约、比赛、喜剧误会。
- **组织语法**：每条线有可识别位置、目标与剩余障碍；切换时承接问题，不仅交替地点。建立共同时间参照或明确只是主题并置。
- **声音/节奏**：同一声响可连接线索，但不能无意伪造同时性；加快切换之前保证每条线的状态被读懂。
- **失效**：没有证据却暗示两事件同步、同地或因果；切越快越难判断谁接近目标。
- **同目标替代**：先完整呈现一线，再延迟揭示另一线的时间；用明确时标或并屏减少误解。
- **微镜头**：女孩等末班车，父亲回店找钥匙；公交到站声持续到父亲跑出门，随后全景确认街对面就是车站。

依据：[A01](../style-sources.md#a01) 支持注意衔接；[A02](../style-sources.md#a02) 区分镜头与事件；[A05](../style-sources.md#a05)、[A06](../style-sources.md#a06) 只支持有限情境归因，不保证具体情绪。四个方案是创作组织法。
