# 动画：形态、材料与时间

媒介不决定题材和观众年龄。先定义物体怎样存在、怎样动、怎样变化，再选择二维、立体、实物或混合工艺。下列不是软件操作指南；“看起来像某工艺”不代表真的采用该工艺。

## A01 线绘姿态

- **目标/适用**：以清楚轮廓和关键姿态组织动作；适合二维角色、解释短片、风格化剧情和有限动画。
- **组织语法**：用动作线、剪影、重心与视线区分姿态；脸部细节不是唯一表演渠道。背景可简化，但角色与接触物的关系不可省掉。
- **时间**：决定哪些姿态停住、哪里快速转移；可有选择地减少中间帧，不能把卡顿当作风格说明。
- **失效**：角色始终只动嘴，身体不回应重量/情绪；停格时长不支持读动作。
- **同目标替代**：保留静态角色，以物件位置、画面切换和声音完成行动；或改用更少角色的完整动作。
- **微镜头**：小人抬起大箱，背先弯、脚后滑，手松开时箱仍不动；他改成拖行，重心向后才完成位移。

## A02 剪纸层景

- **目标/适用**：以平面层次、遮挡和铰接动作讲故事；适合纸偶、拼贴、长卷、教育与文化短片。
- **组织语法**：区分前后纸层、关节和可拆部件；景深感来自层间关系与有限视差，材质边缘保留但不遮关键轮廓。
- **时间**：角色可用摆动、翻面、替换形完成转折；如需透视旋转，先说明另画替换片还是有意保持平面。
- **失效**：二维纸片突然作无解释的完整立体转身；各层漂移，手无法接触道具。
- **同目标替代**：固定正面舞台，仅用开合、进出与遮挡；减少无必要的镜头绕行。
- **微镜头**：纸门被推开，前景门片遮住人物；门片滑过后人物变成戴帽版本，帽子来自门后挂钩而非突然出现。

## A03 偶与物

- **目标/适用**：让重量、触感和有限材料带来表演；适合定格、物件寓言、桌面产品与手作影像。
- **组织语法**：姿态受骨架/物体形状约束；地面接触、物件抓取、留下的凹痕与影子一致。微小手工差异可保留，关键状态不能漂移。
- **时间/声音**：步伐与停顿反映质量；摩擦、碰击和弯折可放大，但有明确聆听尺度。
- **失效**：所谓手工质感只是表面噪点，物体运动仍无重量；道具每帧改变结构。
- **同目标替代**：将复杂动作拆成可执行关键姿态，画外完成不可实现的转换；或改用三维替身并说明。
- **微镜头**：黏土角色坐下，凳面慢慢下陷；它挪到边缘，凳子另一侧翘起，动作结果保留到下一镜。

## A04 流体绘画

- **目标/适用**：用擦除、扩散、重画和形态转化表现联想或情绪过程；适合玻璃绘画、沙画、水墨模拟及实验叙事。
- **组织语法**：保留变化的物质逻辑，例如边缘晕开、颗粒迁移或颜料被抹去；连续变形至少保留一个可追踪轮廓/动作。
- **时间**：形变本身可以代替切镜；关键形象先被认出，再转成下一形象，不把全过程都化成噪声。
- **失效**：每帧随机重绘造成身份消失；“水彩”被固定为柔美儿童风，无法承担其他情境。
- **同目标替代**：形体保持稳定，只让背景材质变化；或用少数硬切的静态画面建立同一联想。
- **微镜头**：一只手抹开桌上墨迹，墨迹沿掌心形成河道；仍保留手的轮廓，直到小船从指缝驶出才转场。

## A05 三维造型与风格化表面

- **目标/适用**：需要空间转动、重复角色或稳定物件时，保留鲜明图形设计；适合三维动画、混合制作和产品角色片。
- **组织语法**：先定体量、剪影与关节范围，再定平涂、笔触或真实材质；镜头绕行时主要轮廓仍成立。线条和贴图不能只在单一角度正确。
- **光/时间**：材质与灯光共同保证形体可读；运动可夸张，但接触、相对比例与动作状态连续。
- **失效**：表面有笔触却角色比例泛化；绕到侧面才发现道具穿插，或为了写实渲染失去图形辨识度。
- **同目标替代**：限制观看角度，用二维替换关键表情；只为真正需要空间变化的镜头使用三维。
- **微镜头**：方形机器人转身进入窄门，先侧转肩壳再收拢手臂；镜头随到侧面仍认得其单侧缺角与磨损位置。
