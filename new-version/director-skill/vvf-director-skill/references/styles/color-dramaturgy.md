# 色彩、纹样与戏剧关系

颜色不是情绪按钮。把色彩设计写成“在哪、占多少、与谁相邻、什么时候变化、观众要借此认出什么”；面积不需要套固定比例。下面的色彩可替换，只保留项目确实需要的关系。

## C01 色场舞台

- **目标/适用**：以少数大色面建立场景整体感，让局部动作更易识别；适合棚拍、舞蹈、产品短片和风格化剧情。
- **组织语法**：背景、地面可共享主色；人物/道具靠轮廓、明度或一个局部色分离。让色面参与遮挡和行动，不只是后期铺色。
- **机位/声音**：正面、侧面或俯视依动作关系选择；静止背景可衬托具体声音或物件进入。
- **失效**：主体与背景合并，产品真实色被改变；整齐的色面消除了生活空间该有的功能。
- **同目标替代**：用材质统一而保留自然色，或只把一面墙/一块布设为主色。
- **微镜头**：陶土色台面与墙连成一面，手将白碗推入，水在碗沿形成一圈可见波纹；无须同时移动摄影机。

## C02 色彩阵营

- **目标/适用**：用重复色关系帮助观众识别人物、空间或阶段；适合多人剧情、比赛、动画、系列短片。
- **组织语法**：先把色与对象关联，再通过进入、交换或污染改变关系。阵营可以由服装、道具或光区承担，不必把人全身涂成标签。
- **连续性**：色彩更改要跟随故事事实和服化状态；不要依赖颜色作为唯一识别信息，兼用形状/位置。
- **失效**：观众尚未学会对应就开始变色；色盲/小屏条件下阵营不辨，或文化语义与意图相反。
- **同目标替代**：不同轮廓、动作习惯或声响维持识别，颜色退为辅助。
- **微镜头**：两队用不同形状且不同色的夹子标记作品；终场一人把自己的夹子夹到对方修好的模型上。

## C03 主观色变

- **目标/适用**：让同一场所随人物感知发生转换；适合主观剧情、音乐影像、记忆与幻想段落。
- **组织语法**：保留可认地点和动作，明确改变的是光源、布景、调色还是主观世界；色变最好与一次发现、决定或声源变化挂钩。
- **时间**：先提供基准，再让变化可读；若需突变，给出进入/退出主观段的标记。
- **失效**：无依据变色像设备故障，或把叙事状态只寄托在“暖=幸福、冷=悲伤”。
- **同目标替代**：色相不变，改对比、反射、声场或人物在光区的位置表达同一转折。
- **微镜头**：人物读完信，窗外广告屏熄灭，房间彩色闪烁退去，只剩桌灯；他第一次把信平放而非攥住。

## C04 纹样丰盛

- **目标/适用**：让衣饰、环境和身份呈现繁复但有秩序的关系；适合肖像、时尚编辑、家庭陈列与地方文化叙事。
- **组织语法**：决定哪种纹样属主体、哪种属环境；用尺度差、方向差、明度或清楚姿态区分层级。背景可丰富，脸和关键动作仍有呼吸空间。
- **机位/时间**：正面姿态有助于与满幅图案合作；移动时检查纹样闪烁/摩尔纹，不能只看静帧。
- **失效**：图案全是随机“异域元素”，真实文化被混拼；复杂衣料吞没动作或暗示未经证实的阶级。
- **同目标替代**：保留一个有来源的纹样，其余用织物肌理、物件数量或声音表达丰盛。
- **微镜头**：裁缝坐在自己拼接的布帘前，先摊开素色衬布使手势清楚，再把相同纹样的小补片缝回衣袖。
