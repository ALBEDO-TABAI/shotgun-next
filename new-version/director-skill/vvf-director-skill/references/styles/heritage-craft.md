# 历史、地方与工艺

这里是“如何让历史或在地知识改变画面”的入口，不把朝代、民族和艺术流派并成一种复古滤镜。写清地点、时期、阶层/职业、场合、材料来源及推断；资料没有覆盖的部分保留未定。

## H01 日常物质史

- **目标/适用**：让过去作为有人实际生活的世界成立；适合历史剧情、生活短片、博物馆解释。
- **组织语法**：从照明、起居、劳动和物件使用方式组织房间；新旧程度按故事当时的使用历史决定。古代物件在当时可能是新的，不把全部表面做旧。
- **机位/行动**：用穿戴、取火、收纳等具体动作验证形制可用；关键物件在镜头中有可辨功能。
- **失效**：只依据后世绘画混搭跨地域器物；现实生活被拍成无人使用的古董展。
- **同目标替代**：缩小到证据充分的一个空间/动作，用更少但可信的物件完成故事。
- **微镜头**：人物进门先把湿外衣挂在能滴水的位置，再移开靠火过近的木凳；照明与摆设由动作而非年代标签说明。

## H02 礼仪空间

- **目标/适用**：通过座次、门槛、路径和行为约束显示秩序；适合宫廷、宗教/地方仪式、现代制度与虚构典礼。
- **组织语法**：依据特定场合证据确认谁能坐、站、接近或发声；建筑轴线和服饰层级服务行动。正式场面未必人人对称。
- **时间/声音**：等待、响应、唱诵或动作顺序有实际规则；虚构仪式明确是设计，不借真文化名义编造。
- **失效**：纹样与仪式步骤互不相容，或以一套礼法代表整个文化；只剩俯拍队形。
- **同目标替代**：不用具体真实礼仪，建立清楚的虚构规则；仍保留进入、许可与越界后果。
- **微镜头**：来客站在门槛外，室内人物移动坐垫才允许他入座；一次让位改变关系，比空泛宏伟大全景更具体。

## H03 长卷展开

- **目标/适用**：通过行进揭示地点与群体活动的连续关系；适合长镜设计、动画横卷、展览影像及旅程叙事。
- **组织语法**：以路径、桥、建筑或空隙串起活动节点；疏密交替，每个段落既有局部事件又有继续前进的方向。多视点是设计选择，不伪称摄影测量。
- **时间**：决定沿途是同一时刻、连续行程还是压缩时间；观众遇节点时获得新的信息。
- **失效**：横向卷动只是观看名胜清单；没有方向、尺度或叙事边界。
- **同目标替代**：用几个固定局部加共同路径标记，也可借人物动作接续完成展开。
- **微镜头**：镜头沿河从修网人移向渡口，空水面短暂停顿，渡船进入后带出对岸等候者；路线让人物关系自然出现。

## H04 在地工艺

- **目标/适用**：使某种材料和制作逻辑成为影像形式；适合工艺故事、文化传播、动画和产品叙事。
- **组织语法**：先核验工艺怎样成形、可用颜色和连接方式；让视觉转场借用真实的折、压、染、编、镂空逻辑。具体纹样注明出处和用途。
- **声画**：材料的硬软、阻力、透光和声音参与节奏；数字模拟不得冒充工艺师实作证据。
- **失效**：把多地纹样拼成“东方/民族风”，或用漂亮纹理盖掉工艺与人的真实关系。
- **同目标替代**：不挪用具体文化符号，只提取有说明的材料动作，另给原创图形。
- **微镜头**：纸被折成三层，剪刀剪出缺口，展开后缺口成为窗；镜头从窗中进入下一场，但不用未考证的仪式纹样。

来源：[V08](../style-sources.md#v08) 显示长卷可连接真实与想象地点，因此不能直接当复原证据；[V03](../style-sources.md#v03)、[V07](../style-sources.md#v07) 仅是特定地区具体作品；[T02](../style-sources.md#t02) 说明传统故事也会因时代改编。真实服化、建筑、礼仪仍需项目级材料。
