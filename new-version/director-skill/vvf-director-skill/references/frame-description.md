# 帧描述规范：把一个画面说到能重画

三种用途：读参考图或源片代表帧；写首帧、关键帧的生成描述；比对参考帧与生成帧（审片、接镜）。它只描述一个时刻。运动、时长、声音由镜头设计与时间事实负责，静帧不能证明它们。

若另外安装了独立的图像反推技能（可能不存在），读图可直接用它的结构化结果；本文是同一方法的精简版和 VVF 的字段口径，独立使用足够。

## 坐标语言

- **画幅与朝向**：比例与横/竖/方。
- **位置**：九宫格命名为主（左上、上中、右上、左中、正中、右中、左下、下中、右下，以及四个三分交点）。比对或需要精确重画时并写归一化坐标，x 从左 0 到右 1，y 从上 0 到下 1，跨区元素给范围。
- **空间锚点**：视平线的 y、灭点位置与透视类型、机位高度（虫视/低/平/高/顶）、角度（正/侧/四分之三/背，是否荷兰角）。
- **景别与深度层分开命名**：景别写远景/全景/中景/近景/特写，并记主体占画面高度或面积的大致比例；深度层写前景/中景层/背景。不让两个“中景”打架。
- **精度分级**：给生成模型的提示用九宫格、语义锚点和占比；归一化坐标用于帧描述、比对和需要精确重画的场合，不进提示。未测量不写小数点后的精确值。

## 深度与主体

先判深度结构类型，再决定用几层，不对每张图硬塞三层：平面图形（层是叠放顺序）、单层或浅景深（主体面加模糊背景）、标准三层、纵深连续（按自然断点分层）。

每层四项：内容（可辨识，不写“一个人”）、方位、处理（实焦或虚化程度、受光或背光、动态模糊）、占比。

写遮挡序：A 遮 B 遮 C。前景框景元素单独点出。遮挡成环是矛盾信号。

主体定位把显著性轴接到深度轴上：主体在哪一层，为什么读作主体（唯一实焦、最大占比、最高对比、强势位、被光打亮、视线或朝向引导、色彩跳出），陪体是谁，环境是哪些。主体可以在任何一层。虚化只说明离对焦面远，不说明在前还是在后，前后靠遮挡与相对大小定。

## 光、色、材质

光是因，色彩与材质是果，按此顺序判。

- **光**：主光方向用钟点加高低，如“左前约 10 点、略高于视平线”；光质看投影边缘（锐利为硬、渐变为软）；色温看高光与阴影的色偏；光比粗估；第二光源看另一组高光或投影；面部可见时才写光型（伦勃朗、蝴蝶、分割、环形）。
- **色**：主、辅、点缀色用“色名加修饰”，如釉质暖橙、低饱和灰青；需要复现色板时补 HSL 或 Hex。区分固有色与光染色：白墙偏橙是光染，暗处仍绿的植物是固有。对比关系落到画面哪两处。
- **材质**：只写 1 至 3 处主要表面的光学签名。金属映出环境、有色金属高光带色；透明玻璃有折射与边缘亮线；磨砂或半透明体的高光散成柔和渐变、透出内容物或光的亮边、没有锐利镜面反射；湿表面变暗、高光集中；皮肤薄处逆光透红；哑光布无高光、见织纹；缎面高光随褶皱滑动；木有方向纹理；釉面是漫反射底加锐利高光。
- **文字与标识**：清晰则逐字转录，给位置、字体特征、层级；认不出写“不可辨”，不猜品牌。

## 取证句式与存疑

每条判断写成“结论加依据”：判为俯视，依据是桌面顶部可见、地平线压在上部约四分之一处。依据不足写“不可辨”，不补一个看起来合理的假设。

互斥线索（多套投影方向、遮挡成环、哑光面出现镜面锐利高光、远处比近处更艳更锐）记入存疑清单。本层只记录证据对不上，不判断它是合成还是生成。

## 自检

- **可逆性**：只凭这段文字，另一个人或模型能否把布局重画出来？会画错的地方就是缺口，补上或写进存疑。
- **一致性**：光向应解释投影与受光面；色温应解释高光色偏；材质应解释高光形态；深度应解释虚化程度；遮挡不成环；同类物大小顺序与深度顺序一致。

## 从描述到生成描述

把结构化清点熔回一段连贯文字，交给生成工具或人：

1. 结论留，依据删。写“一束冷光勾出发缘”，不写“判为逆光，依据……”。
2. 分轴合体。描述主体时同一句带出它的材质、打在它身上的光、它的颜色。
3. 存疑收敛。只有确实影响重建且无法定论的才写“介于 X 与 Y 之间”，其余择最可能读法写定。

动线：定场句（画幅、景别、场景类型、整体气质）→ 主体及其光色材质 → 由主体向前景和背景展开，说清遮挡序 → 全局光与色调 → 构图、视觉重心、裁切 → 细节与文字 → 收束句。可用能转成像素的词：柔和、暖、雾蒙、低饱和、哑光。不用只表达好坏的词：高级、惊艳、廉价。工具句法与参考句柄由[提示词编译](prompt-compilation.md)加。

## 用于比对

接镜或审片时，对上一镜最后可用帧与本镜第一可用帧各做一次精简清点：主体位置与朝向、持物手、遮挡序、光向、色调。差异按硬、表演、软分级，见[空间与状态](space-and-continuity.md)。

方法综合了图像深度线索的常识与艺术批评里“描述先于判断”的纪律，是工作约定，未经生成对照实验；见[来源](sources.md)。
