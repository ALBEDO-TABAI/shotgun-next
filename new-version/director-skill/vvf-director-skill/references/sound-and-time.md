# 声画与时间

## 三种时间不能混用

故事内过去了多久；成片让观众观看多久；拍摄/生成单元有多长。明确用户限制针对哪一种。没有精确时长要求时给建议区间；有要求时让时间表闭合。

台词时长优先用实际朗读或已存在录音。字数/语速仅粗估，情绪、语言、停顿和重叠都影响结果；不从“每分钟固定字数”推出精确帧数。无法装下时说明取舍：延长、删改获准内容、并行声画或改变镜头数量，不能写一段明显念不完的台词然后称完成。

## 一条可核对的成片时间轴

采用连续的 `入点—出点` 或时长列；相邻切镜边界相接。跨镜台词/音乐只保留一条事件并写覆盖范围，不在每镜重复累计。叠化的片段源时长与成片占时分开；表格已使用成片入出点时，不再重复减叠化时长。

时间不足首先审查内容负担：每镜多少动作、多少新信息、多少文字。快剪可以压缩过渡，不能使阅读和物理动作无限加速。

## 每个声音要有任务

| 声音选择 | 可承担的作用 | 代价/反例 |
|---|---|---|
| 画内对白 | 传达事实或关系行动 | 不必让所有信息都说出口 |
| 画外对白 | 留在听者、物件或空间上 | 需清楚谁在说及在哪 |
| 环境底 | 建立地点、时间、持续世界 | 换镜硬断可能像换场 |
| 关键动作声 | 强化接触、节拍、因果 | 夸张过头会改变媒介与尺度感 |
| 画外声线索 | 提前建立空间或预期 | 不能声称画面未显示的事实已被证实 |
| 主观听觉 | 显露注意、记忆或身体状态 | 标出进入/退出的触发，避免无规则滤波 |
| 音乐 | 组织情感、运动、联想或反讽 | 不自动全程铺底，不替代缺失表演 |
| 静默/减声 | 聚焦、制造等待或暴露空间 | 写清是无音乐、抽掉环境还是全静音 |

J-cut 是下一场/镜声音先进入，L-cut 是前一场/镜声音继续覆盖；名称不重要，交付时写出开始与结束事件。声音桥可以使转场连贯，也能故意制造错误预期。

## 节奏不等于镜长递减

节奏由镜内变化、信息密度、运动、对白、停顿和切点共同形成。固定长镜可以紧张；快剪可以松散。以观众的等待对象判断时间：在等动作发生、答案揭晓、身体恢复，还是纯粹欣赏图形/材质。

喜剧可让反应晚于观众察觉；悬疑可让日常动作占据等待；操作说明需让手的位置和结果有足够辨认时间。没有跨品类通用的“每三秒刺激”。

## 交给声音/剪辑工种

提供镜头 ID、成片时间、对白全文及版本、空间与主观视点、必须同步的动作、可独立移动的声音、音乐使用意图。技术响度/格式按具体交付目标查官方规范，不把某个平台的数字当通则。未获得的音乐/声音素材标为待制作或待授权，不能写“已清权”。
