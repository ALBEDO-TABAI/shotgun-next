# 从事件到导演选择

以下是工作性启发，不是所有故事必须经历的固定段落。

## 场景的最小结构

先回答：谁此刻试图做什么；什么阻力使其改变策略；结束时关系、知识、资源或处境变了什么。没有戏剧冲突也可由发现、等待、劳动过程、感官变化组织。静止和重复若本身承担体验，不为“变化”硬加事故。

把原文转为一个**可观察的变化**：不要只写“他很失望”，可以是“把仍烫的第二杯茶推回自己面前”。行动不是情绪诊断；同一动作可表达多个意思，由上下文支持。

一句导演命题把这些压在一起，例如“表面是交代任务，真正要拍的是新人第一次意识到规则残酷，并决定隐藏恐惧”。命题不清时，对白容易被同一速度念完，画面只剩说明。

## 视点与信息

| 想让观众处于什么位置 | 可用选择 | 代价/反例 |
|---|---|---|
| 与角色一起发现 | 随行动揭示、限制反打、声音先于可见物 | 会减少其他角色信息；不必每镜都是眼睛主观 |
| 比角色先知道 | 先露危险/误会源，保留角色盲区 | 悬念变为等待后果；别再按“惊喜揭底”节奏剪 |
| 比角色晚知道 | 保留行为，延后原因 | 需要公平且能回读的线索；否则像随意隐瞒 |
| 观察关系而不站队 | 同框、距离、空间阻隔、允许同时行动 | 画面内焦点需可辨；并非“客观真相”保证 |
| 体验身体/感官 | 呼吸、触感、视野受限、运动反馈 | 失去环境定位时需决定是否恢复 |
| 观看结构或观念 | 重复、对照、尺度、图形变化 | 不能用传统情节完整度评判所有实验作品 |

信息安排例：女儿收起一封信。先给信内容，是“观众知道她隐瞒什么”；只见折信，是“观众想知道为何隐瞒”；不拍信而保留她避开桌面的手，是“关系变化优先”。三者不是景别替换，而是观众任务不同。

## 场面调度先于镜头清单

确定入口、出口、阻挡物、可触及物件、人物目光和动线，再选观众观看的位置。动作改变关系时，机位/构图可以保持不变，让演员完成变化。

场面调度的高收益变量：

- **距离**：谁主动靠近，谁承担跨越距离的成本。
- **高度/姿态**：谁坐、谁站、谁被迫仰视；不要据此自动判定权力。
- **占有与通行**：谁拿着钥匙、挡住门、控制物件；空间功能比装饰更能推动戏。
- **同步/错拍**：一人开始做，另一人晚一步；关系可由时机显现。
- **可见/不可见**：前景遮挡、画外行动、镜面或屏幕。反射需有对应空间，实验画面则标规则。

## 节拍与调度状态

长对白或关系明显变化的场面，先按力量变化拆节拍，再定 2–3 个调度状态。静观段、过程段可以只有一个状态，不为填表制造转折。

| 节拍 | 事件 | 目标与阻力 | 必须看见的行为 | 反应时间 |
|---|---|---|---|---|

每个节拍至少有事件、人物目标、阻力和一个必须被看见而非只被说出的行为。重要信息揭示后留一种可感知的承接：停顿、目光、呼吸变化、他人反应、环境静默或动作中断。反应镜头同时承担证明听懂、给观众消化、调节节奏、掩盖接缝四种功能，不必每次都用。

调度状态写：人物位置与朝向、相对距离、空间锚点、谁拥有行动主动权、进入下一状态的动机。例：门口防御 → 桌边谈判 → 窗前回避。移动由心理或行动触发，不为画面丰富而走动。人物状态来自情境与前因，不来自服装或字面标签；穿睡衣不等于困倦。

## 镜头存在的检验

问“删除后观众损失了什么”：事实、预期、空间、身体体验、节奏、形式关系均可成立。若只损失某个技法的出现次数，优先删。反过来，不因没有新情节就删除有意的等待、情绪余波或形式重复。

换镜常见动机：视点变化、动作完成/打断、信息被察觉、关系重排、时间压缩、空间迁移、节奏反差。未必每次动作结束都切，也不必每次说话者变化都切。

## 有意义的备选

只在关键未定选择上比较路径，避免每镜列三套：

- 同一目标，两种观看关系。例如“原谅”可通过近距离呼吸，也可通过始终隔开的全景里递出座位。
- 写清各自保留、牺牲、实现成本和最先应测试的镜头。
- 用户已明确风格时优先完成该路线；不要把自己的品味伪装成优化。

## 自检

逐镜连读时能否理解发生什么；所需歧义是否仍有线索；表演是否承担核心变化；视觉与声音是否重复解释；风格是否改变了取景与时间安排。审阅进一步见[质量审阅](quality-review.md)。

职业边界参考见[来源](sources.md)。以上场景方法是本包综合设计，不声称某条研究证明它适用于一切作品。
